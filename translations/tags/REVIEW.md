# 태그 번역 검토

새 번역은 모두 `unreviewed`입니다. 한국어 사람 검토가 필요합니다.
태그 번역은 `ko.json`에 모으며, 일반 UI 메시지 사전과 분리합니다. 기존에 저장된 번역과 검토 상태는 이전하되, UI 승인만 있던 용어의 태그 문맥은 별도 검토가 필요합니다.

## 후속 변경

최종 삭제 기준은 **문제 수가 2개 이하이면서 solved.ac 대응 태그가 없는 경우**입니다.
전체 저빈도 태그를 제외했던 처리를 정정해 solved.ac 대응 66개를 복구했습니다.
이 작업으로 삭제된 항목은 267개이며, 수정 직후 번역 항목은 247개입니다.
영문 태그 제외와 사용자가 직접 삭제한 항목은 유지합니다.

solved.ac 재확인: `precomputation`은 공식적으로 ‘런타임 전의 전처리’이며,
일반적인 전처리보다 범위가 좁습니다. 원문의 `前処理`는 문제 수가 2개이므로
이번 기준에 따라 삭제했습니다. 승인된 한국어를 재검색만으로 덮어쓰지 않았습니다.
출처: https://solved.ac/problems/tags/precomputation 및 https://solved.ac/problems/tags?page=2

사용자 요청에 따라 영문 이름·약어로만 된 태그 92개를 번역 파일에서 삭제했습니다.
기존 승인 여부와 관계없이 원문으로 표시합니다. 일본어가 섞인 이름은 유지했습니다.
아래 초기 집계 이후 사용자 검토 중 삭제·수정된 항목도 있으므로 현재 상태는 `ko.json`이 기준입니다.

## 출처와 선별 기준

- yukicoder 태그 및 문제 수: https://yukicoder.me/api/v1/statistics/tags
- solved.ac 명칭: 사용자가 제공한 `data/stray/tag.json` (229개), https://solved.ac/api/v3/tag/list
- 메모리 통계 원문: https://yukicoder.me/statistics/language_memory
- 작업일: 2026-09-09. 문제 수는 수집 시점 기준이며 자동 갱신하지 않습니다.
- 10문제 이상인 태그는 전부 번역합니다. 그 미만도 범용 알고리즘·자료 구조·수학 용어이면 포함합니다.
- 특정 문제의 농담·맥락 의존 명칭과 의미가 불명확한 이름은 제외합니다.
- solved.ac와 개념이 대응하는 경우 제공된 한국어 명칭을 사용합니다. 의미 범위가 다른 경우 원문의 구체성을 유지합니다.
- 태그 검색 링크의 표시 문자열만 번역합니다. 링크 목적지, 입력값, 원문 태그 식별자, 문제 수, 정렬 기준은 보존합니다.
- 명칭 대응은 번역안이며 사용자가 승인한 대응표가 아닙니다. 특히 가도마쓰 수열, DM 분해, 일본어 기법 별칭과 저빈도 수학 용어를 검토해 주세요.

## 메모리 통계

페이지 사전과 경로 연결을 추가했습니다. 설명, 표 머리글, 수치 해설과 통계 메뉴를 번역합니다.
최대 필요 메모리와 표의 측정값은 원문 숫자를 그대로 보존하고, 설명의 메모리 제한 상한은 플레이스홀더로 처리합니다.
문제 제목은 UI 사전에 포함하지 않습니다. 참고 문제 제목·링크 및 인라인 강조·코드 요소는 보존합니다. 한국어 조사와 인라인 요소 사이의 공백은 화면 검토가 필요합니다.
