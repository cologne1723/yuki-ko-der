# 태그 번역

`ko.json`에 원문 태그별 한국어 번역을 한 번씩 저장합니다. 일반 UI 사전인
`translations/ko.messages.json`과 분리되어 UI 검토 목록에 나타나지 않습니다.

- `source`: yukicoder의 원문 태그 식별자. 검색 URL에도 이 값을 유지합니다.
- `target`: 표시할 한국어 이름.
- `reviewStatus`: `unreviewed` 또는 사람이 승인한 `approved`.
- `problemCount`: 선별 시점의 문제 수. 화면의 실시간 문제 수를 대체하지 않습니다.
- `solvedAcKey`: 대응되는 solved.ac 태그가 있는 경우의 식별자.

태그별 선정·제외 근거와 검토 대상은 [REVIEW.md](REVIEW.md)를 참고하세요.
한국어 변경은 사람 검토 전까지 `unreviewed`로 저장합니다.

`pnpm build`가 형식과 중복 식별자를 검사한 뒤 확장 기능 번들에 포함합니다.
`src/tag-translations.ts`는 원래 태그 검색 URL과 표시 문자열이 일치하는 링크만
번역하며, 문제 수·검색값·링크 목적지를 보존합니다. 페이지의 동적 갱신과
확장 기능 설정 변경에도 적용 및 원문 복원이 이루어집니다.

`pnpm review`를 실행한 뒤 탐색 메뉴의 **태그 번역**(`/tags`)에서 검색·편집·저장·승인할
수 있습니다. 승인된 문구를 변경해 저장하면 미검토로 돌아갑니다. 파일을 외부에서
수정했거나 다른 검토 창에서 먼저 저장했다면 충돌을 표시하고 덮어쓰지 않습니다.

목록의 행 어디를 눌러도 해당 태그를 편집할 수 있습니다. **승인하고 다음**은
저장·승인 성공 후 현재 검색·상태 필터 안의 다음 미검토 태그로 이동합니다.
뒤쪽에 남은 항목이 없으면 앞쪽의 미검토 항목으로 돌아가며, 목록 페이지도
선택 항목에 맞춥니다. 남은 항목이 없으면 완료 안내와 승인한 태그를 표시합니다.

**원문 그대로 두기**는 선택한 태그를 `ko.json`에서 삭제하고 다음 미검토 태그로
이동합니다. 번역 항목이 없는 태그는 확장 기능에서 원문으로 표시됩니다.
승인된 항목도 삭제할 수 있으며, 수정 충돌 시에는 삭제하지 않습니다.
확장 기능에 변경을 적용하려면 `pnpm build` 후 확장 기능을 다시 불러오세요.

영문 이름·약어로만 된 태그는 번역 항목에 넣지 않고 원문으로 유지합니다.
일본어가 섞인 이름은 별도로 검토합니다.

문제 수가 2개 이하이면서 solved.ac 대응 태그가 없는 경우에만 저빈도를 이유로
번역 항목에서 제외합니다. `solvedAcKey`가 있으면 문제 수와 관계없이 번역을 유지합니다.
영문 이름·약어를 원문으로 유지하는 기준은 별도로 적용합니다.
