# 의미 보존과 한국어 문체

초안을 작성하기 직전에 이 파일을 다시 읽는다.

`pnpm glossary -- data/problems-source/NUMBER.html`을 실행하고 출력된 항목만 읽는다.
출력이 없으면 적용 항목이 없다. 번역 작업에서 glossary 전체를 열지 않는다.
출력된 표준 표기를 사용하고 금지 표기는 피한다.

- 원문에 없는 풀이, 힌트, 가정, 조건을 추가하지 않는다.
- 조건, 예외, 순서, 횟수, 경계, 종료·승패 조건을 빠뜨리지 않는다.
- 여러 대상의 선택은 `각각 선택한다`와 `모두 같은 것을 선택한다`를 구분해 쓴다.
  `모든 대상을 ... 중 하나로`처럼 둘 다 가능한 문장은 예제로 뜻을 확정해 고친다.
- 부정문의 범위를 구분한다. "아무도 모른다"와 "전원을 아는 것은 아니다"는 다르다.
  앞뒤 정의와 예제를 실제로 따라가며 해석을 검증한다. 문맥으로 확정되면 근거를 기록하고,
  확정되지 않으면 충돌을 보고한다. 한국어로 옮기기만 하고 모순을 방치하지 않는다.
- 이야기, 인물, 대화, 공지, 예제 설명을 보존한다.
- 링크 대상·이미지·프로그램 코드도 보존한다. 중복 설명은 합칠 수 있지만 정보는 빠뜨리지 않는다.
- 같은 대상과 연산에는 문서 전체에서 같은 용어를 사용한다.
  그래프의 `辺/edge`는 `간선`으로 쓴다. 기하 도형의 변과 구분한다.
- 분수의 모듈러 값은 정수 나눗셈의 나머지가 아니다. 기댓값은 ‘법 $p$에서의 값’으로
  쓰고, 원문의 $RQ\equiv P\pmod p$ 정의와 유일성 조건을 보존한다.
- 설명은 `합니다`체로 쓰고 요구 동작은 `구하세요` 또는 `출력하세요`로 쓴다.
- 식별자, 문자열, 날짜, 버전, 코드와 실제 예제 데이터는 번역·자동 서식화하지 않는다.
- 불명확한 오타나 원문·예제 충돌은 추측하지 말고 미해결 사항으로 기록한다.
- 일본어 단어 치환으로 번역문을 만들지 않는다.
- glossary에 없는 인명·팀명·단체명은 추정하거나 일부만 음역하지 않고 원문으로 남긴다.
  완료 보고의 확인 요청에 모은다. 일반 용어도 뜻이 불확실하면 사전·공식 자료로 확인한다.
  인명에서 유래한 수학 상수·정리명은 일반 학술 용어다. 표준 한국어 명칭을 확인해 번역하고, 확인되지 않은 항목만 원문으로 남긴다.
- 이름과 호칭은 glossary의 명시적 대응이 없으면 함께 원문을 유지한다.
  호칭이 생략되어도 같은 인물인지 문맥으로 확인한다. 예: `物理好き`의 생일 파티를
  ‘물리를 좋아하는 사람들의 생일 파티’로 풀거나, 원문 이름 앞에 뜻풀이를 덧붙이지 않는다.
  예: `eiramくん`을 `eiram군`으로 바꾸지 않는다. 일반 제목·음식·아이템명은
  고유명사로 취급해 번역을 생략하지 않는다.
  `sourceTitle` 원문 보존은 메타데이터 규칙이다. `title`까지 원문을 유지하라는
  뜻이 아니다. 예: `Speedrun Query` → `스피드런 질의`, `Hard` → `어려움`.
  참고 링크의 문제 제목도 같은 기준으로 번역하고 URL은 보존한다. glossary에 없다는 이유만으로 일반 제목을 미확정 이름으로 분류하지 않는다.
  `Writer`처럼 사람의 역할을 나타내는 말은 이름이 아니다. 주변 문장으로 역할인지 확인해 `출제자`로 번역하고, 실제 사용자명만 원문을 유지한다.
