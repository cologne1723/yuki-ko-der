## 문제 설명

양의 정수 $N$이 주어집니다. $\mu(N)$을 구하세요.

### 배경

양의 정수 $N$에 대해 $\mu(N)$의 값은 다음과 같이 정의됩니다.

- $N=1$일 때, $\mu(N)=1$입니다.
- $N$이 어떤 소수의 제곱으로 나누어떨어질 때, $\mu(N)=0$입니다.
- $N$이 서로 다른 소수 $K$개의 곱과 같을 때, $\mu(N)=(-1)^K$입니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- $1\leq N\leq 10^{12}$
- $N$은 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
30
```

#### 출력

```text
-1
```

$30$은 $2\times 3\times 5$와 같이 $3$개의 서로 다른 소수의 곱으로 나타낼 수 있습니다. 따라서 $\mu(30)=(-1)^3=-1$입니다.

### 예제 2 {file=""}

#### 입력

```text
54
```

#### 출력

```text
0
```

$54$는 소수 $3$의 제곱인 $3^2=9$로 나누어떨어집니다. 따라서 $\mu(54)=0$입니다.
