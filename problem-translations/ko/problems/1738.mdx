`N`개의 상자에 같은 무게의 공이 들어 있습니다. 공 하나의 무게는 양의 실수이고, 상자 `i`의 공 무게 합은 `W_i`입니다. 모든 공 개수의 합이 `M`일 때 각 상자의 공 개수를 구하세요.

## 제약

- `1 <= N <= 1000`
- `0 <= M,W_i <= 10^9`
- 해는 유일하게 존재합니다.

## 입력

`N`, 총 공 개수 `M`, 각 상자의 무게 합 `W_i`가 주어집니다.

## 출력

각 상자의 공 개수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 30
1 2 3
```

#### 출력

```text
5 10 15
```

공 하나의 무게가 $0.2$이고 상자 $1$부터 차례대로 공이 $5$개, $10$개, $15$개 들어 있다면 모든 조건을 만족합니다.

공 하나의 무게가 정수라는 보장은 없다는 점에 주의하세요.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 100
100 0 0
```

#### 출력

```text
100 0 0
```

무게 $1$인 공이 상자 $1$에 $100$개 들어 있습니다. 공이 없는 상자도 있을 수 있다는 점에 주의하세요.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
5 3267948
399576 2653028 2603840 54518 824934
```

#### 출력

```text
199788 1326514 1301920 27259 412467
```

공 하나의 무게는 $2$입니다.
