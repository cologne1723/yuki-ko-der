`N`개의 상자에 같은 무게의 공이 들어 있습니다. 공 하나의 무게는 양의 실수이고, 상자 `i`의 공 무게 합은 `W_i`입니다. 모든 공 개수의 합이 `M`일 때 각 상자의 공 개수를 구하세요.

## 제약

- `1 <= N <= 1000`
- `0 <= M,W_i <= 10^9`
- 해는 유일하게 존재합니다.

## 입력

`N`, 총 공 개수 `M`, 각 상자의 무게 합 `W_i`가 주어집니다.

## 출력

각 상자의 공 개수를 출력하세요.
