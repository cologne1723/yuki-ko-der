## 문제 설명

東京科学大学デジタル創作同好会 traP에서는 각 부원이 traQ ID라고 하는 사용자 ID를 가지고 있습니다.

traQ ID는 다음 조건을 만족해야 합니다.

- 길이가 $1$ 이상 $32$ 이하인 문자열입니다.
- 영문 대문자·영문 소문자·아라비아 숫자·밑줄·하이픈인 `A~Z a~z 0~9 _ -` 이외의 문자를 포함하지 않습니다.
- $1$번째 문자와 마지막 문자가 밑줄·하이픈인 `_ -`이 아닙니다.

이제 traP에 가입하려는 여러분은 주어지는 문자열 $S$를 traQ ID로 등록하려고 합니다. 위 조건을 만족한다면 $200$을, 그렇지 않다면 $400$을 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$S$
```

## 제한

- $1\leq |S|\leq100$
- 문자열 $S$는 ASCII code로 $33$ 이상 $126$ 이하로 표현되는 문자로 이루어집니다. 특히 반각 공백을 포함하지 않습니다.

## 출력

문제 설명에 따라 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
zoi_dayo
```

#### 출력

```text
200
```

출제 당시 traP 대표의 사용자 ID입니다. 조건을 만족합니다.

### 예제 2 {file=""}

#### 입력

```text
CPCTF{dummy}
```

#### 출력

```text
400
```

사용할 수 없는 문자 `{`가 포함되어 있으므로 조건을 만족하지 않습니다.
