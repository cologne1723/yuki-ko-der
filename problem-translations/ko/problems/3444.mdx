## 문제 설명

양의 정수 $N$과 음이 아닌 정수 $M$이 주어집니다.

$N$개의 정점을 가진 가중 완전 그래프 $G$의 각 정점에는 $0$부터 $N-1$까지 번호가 붙어 있습니다. 모든 $0\leq a<b<N$에 대하여 정점 $a$와 정점 $b$를 연결하는 간선의 가중치는 $(a+M)\mathbin{\oplus}(b+M)$입니다. 여기서 $\mathbin{\oplus}$는 비트별 배타적 논리합을 나타냅니다.

$G$의 최소 신장 트리에 포함된 간선의 가중치 합을 구하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$case_{1}$
$case_{2}$
$\vdots$
$case_{T}$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ M$
```

## 제한

- $1\leq T\leq 10^5$
- $1\leq N\leq 2\times 10^9$
- $0\leq M\leq 2\times 10^9$
- 입력은 모두 정수입니다.

## 출력

$T$줄 출력하세요.

$i$번째 줄에는 $case_{i}$에 대한 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
3 2
167 924
1234567890 1234567890
```

#### 출력

```text
7
2551
21772702017
```

$1$번째 테스트 케이스에 대해 간선의 가중치는 다음과 같습니다.

- 정점 $0$과 정점 $1$을 연결하는 간선의 가중치는 $(0+2)\mathbin{\oplus}(1+2)=1$입니다.
- 정점 $0$과 정점 $2$를 연결하는 간선의 가중치는 $(0+2)\mathbin{\oplus}(2+2)=6$입니다.
- 정점 $1$과 정점 $2$를 연결하는 간선의 가중치는 $(1+2)\mathbin{\oplus}(2+2)=7$입니다.

따라서 최소 신장 트리를 구성하는 간선은 정점 $0$과 정점 $1$을 연결하는 간선, 정점 $0$과 정점 $2$를 연결하는 간선의 $2$개입니다.

$1$번째 줄에는 이 간선들의 가중치 합인 $1+6=7$을 출력합니다.
