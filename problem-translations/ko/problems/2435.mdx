$N$개의 도시를 모두 연결하기 위해 서로 다른 두 도시를 잇는 다리 $N-1$개를 건설합니다. $K$개의 회사 각각은 여러 주문 가능한 다리 목록을 가지고 있습니다. 모든 회사에 한 번 이상 주문하면서 주문한 다리들이 도시 전체를 연결하도록 하는 주문 방법의 수를 $998244353$으로 나눈 나머지를 구하세요.

## 조건

- $2\le N\le50$, $1\le K\le5$
- 모든 다리는 서로 다른 두 도시를 잇습니다.
- 전체 주문 가능한 다리 수는 $10^5$ 이하입니다.

## 입력

```text
N K
t1
a1,1 b1,1
...
tK
...
```

## 출력

조건을 만족하는 주문 방법의 수를 출력하세요.

#### 출력
