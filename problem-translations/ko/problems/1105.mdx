## 문제 설명

$N$개 원소의 정수 수열 $A$, $B$, $C$를 생각합니다.

이 수열의 값이 $2 \leq i \leq N$에서 다음 조건을 만족한다고 합시다.

- $A_i = A_{i-1}-B_{i-1}$
- $B_i = B_{i-1}-C_{i-1}$
- $C_i = C_{i-1}-A_{i-1}$

$(A_1,B_1,C_1)$이 주어질 때, $(A_N,B_N,C_N)$을 각각 $10^9+7$로 나눈 나머지를 구하세요.

이 문제에서 정수 $X$를 $10^9+7$로 나눈 나머지란, 어떤 정수 $q$를 사용하여 $X = q \times (10^9+7) + r$로 나타낼 수 있고 $0 \leq r < 10^9+7$를 만족하는 유일한 정수 $r$을 뜻합니다.

## 입력

```text
$N$
$A_1\ B_1\ C_1$
```

입력은 모두 정수입니다.

## 제한

$2 \leq N \leq 10^{18}$

$0 \leq A_1,B_1,C_1 \leq 10^9$

## 출력

$(A_N,B_N,C_N)$을 각각 $10^9+7$로 나눈 나머지를 공백으로 구분하여 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="sample01"}

#### 입력

```text
2
1 2 3
```

#### 출력

```text
1000000006 1000000006 2
```

$-1$을 $10^9+7$로 나눈 나머지는 $10^9+6$입니다.

### 예제 2 {file="sample02"}

#### 입력

```text
3
0 0 0
```

#### 출력

```text
0 0 0
```

### 예제 3 {file="sample03"}

#### 입력

```text
10
1000000000 998244353 924844033
```

#### 출력

```text
945425885 912366722 142207407
```
