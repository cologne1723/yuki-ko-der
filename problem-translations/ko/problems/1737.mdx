처음 `X=1`입니다. 2 이상인 정수 `K`를 골라 `K`엔을 지불하고 `X`를 `KX`로 바꾸는 작업을 원하는 만큼 할 수 있습니다.

`X=N`으로 만들기 위한 최소 지불 금액을 구하세요.

## 제약

- `1 <= N <= 3 * 10^5`

## 입력

`N`이 주어집니다.

## 출력

최소 금액을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
12
```

#### 출력

```text
7
```

처음에는 $X=1$입니다. 첫 번째 작업에서 $K=3$으로 정하면 $3$엔을 지불하고 $X$가 $3\times1=3$으로 바뀝니다.

두 번째 작업에서 $K=4$로 정하면 $4$엔을 지불하고 $X$가 $4\times3=12$로 바뀝니다.

이렇게 합계 $7$엔을 지불해 $X=N$으로 만들 수 있습니다. $7$엔 미만으로는 불가능하므로 $7$을 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
123456
```

#### 출력

```text
658
```

### 예제 3 {file=""}

#### 입력

```text
1
```

#### 출력

```text
0
```

처음부터 $X=1$이므로 돈을 지불할 필요가 없습니다.
