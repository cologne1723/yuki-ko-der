집합 $S_1,\ldots,S_m$가 주어집니다. $f(T)$를 $\lvert S_i\cap T\rvert\ge k$인 집합의 개수라 하고, $g(p)$를 $f(T)\ge p$인 $T$의 최소 크기라 할 때 모든 $p$의 $g(p)$를 구하세요.

## 조건

- $1\le k\le n\le24$, $1\le m\le3\times10^5$
- 각 $S_i$는 원소를 $k$개 이상 포함합니다.

## 입력

```text
$n\ m\ k$
$S_1$
$S_2$
$\vdots$
$S_m$
```

## 출력

각 $g(p)$를 한 줄에 하나씩 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text

11001
00101
01110
10110
```

#### 출력

```text
2
2
3
4
```
