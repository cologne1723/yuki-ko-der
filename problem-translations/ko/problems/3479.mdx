## 문제 설명

정사각형 내부에 서로 독립적으로 균등하게 무작위로 $N$개의 점을 찍습니다.

이 $N$개의 점을 서로 모두 선분으로 연결할 때, 그 선분에 의해 정사각형 내부가 분할되어 생기는 영역 개수의 기댓값을 법 $998\,244\,353$에서의 값으로 구하세요.

### 기댓값의 법 $998\,244\,353$에서의 값의 정의

이 문제의 제약 아래에서 구하는 기댓값은 반드시 유리수가 되며, $x \not\equiv 0 \pmod {998\,244\,353}$인 정수 $x$와 정수 $y$를 사용하여 $\frac{y}{x}$로 나타낼 수 있음이 보장됩니다.

이때 $xz \equiv y \pmod {998\,244\,353}$를 만족하는 $0$ 이상 $998\,244\,353$ 미만의 정수 $z$가 유일하게 존재하므로, 그 값을 출력하세요.

## 입력

```text
$N$
```

입력은 다음 제한을 만족하는 정수 $N$ $1$개로 주어집니다.

## 제한

- $1 \le N \le 10^9$
- 입력은 모두 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
```

#### 출력

```text
526851191
```

$N=4$일 때 답은 $\dfrac{169}{36}$입니다.

### 예제 2 {file="02_sample_02.txt"}

#### 입력

```text
1000000000
```

#### 출력

```text
751221712
```
