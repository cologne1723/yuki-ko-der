## 문제 설명

제$0$항부터 제$N-1$항까지 $N$개의 항으로 이루어진 양의 정수열 $A$가 있습니다.

단, $0$개 이상의 일부 항은 그 값을 자유롭게 정할 수 있습니다.

제$0$항부터 제$N-1$항까지 $N$개의 항으로 이루어진 양의 정수열 $B$를 다음과 같이 정의합니다.

$B_k = \sum_{\substack{0 \le i,j < N \\ i\mathbin{\&}j=k}}(A_i \times A_j)$

$\&$는 [비트 AND](https://ja.wikipedia.org/wiki/%E3%83%93%E3%83%83%E3%83%88%E6%BC%94%E7%AE%97#AND)를 나타냅니다.

$B$의 모든 항의 값의 약수인 가장 큰 양의 정수를 $B$의 최대공약수라고 정의합니다.

$A$의 항 값을 최적으로 정했을 때, $B$의 최대공약수의 최댓값을 구하세요.

단, 최대공약수의 최댓값이 존재하지 않는 경우에는 $-1$을 출력하세요.

## 입력

```text
$N$
$A_0\ A_1\ \ldots\ A_{N-1}$
```

## 제한

- $1 \le N \le 2 \times 10^5$
- $1 \le A_i \le 10^9$ 또는 $A_i=-1$ ($0 \le i < N$)
- $A_i=-1$인 경우에, 그리고 그 경우에만 제$i$항의 값을 양의 정수 범위에서 자유롭게 정할 수 있습니다.
- 입력은 모두 정수입니다.

## 출력

답을 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
-1 -1 -1
```

#### 출력

```text
-1
```

아무리 큰 정수 $M$에 대해서도, 각 항의 값을 정하여 최대공약수가 $M$보다 커지도록 할 수 있습니다.

### 예제 2 {file=""}

#### 입력

```text
5
7 9 3 5 1
```

#### 출력

```text
1
```

### 예제 3 {file=""}

#### 입력

```text
5
-1 54 -1 12 -1
```

#### 출력

```text
36
```
