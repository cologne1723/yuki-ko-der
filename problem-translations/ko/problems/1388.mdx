## 문제

`H×W` 격자에서 두 사람이 `(1,1)`에서 동시에 같은 속도로 아래 또는 오른쪽으로 이동해 `(H,W)`로 갑니다. 매 순간 두 사람이 있는 칸의 맨해튼 거리가 `K` 이하가 되는 경로쌍의 수를 `998244353`으로 나눈 나머지를 구하세요.

## 입력

`H W K`가 주어집니다.

## 출력

경로쌍의 수를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 3 2
```

#### 출력

```text
34
```

### 예제 2 {file=""}

#### 입력

```text
10 10 0
```

#### 출력

```text
48620
```

### 예제 3 {file=""}

#### 입력

```text
314 1592 653
```

#### 출력

```text
13839116
```
