## 문제

회전 초밥집을 간단히 시뮬레이션합니다. 좌석에는 1부터 20까지 번호가 붙어 있습니다.

손님은 먹고 싶은 초밥 목록을 가지고 있다가 자신 앞에 목록의 초밥이 오면 반드시 집어 목록에서 한 접시를 삭제합니다. 초밥은 1번 좌석부터 20번 좌석까지 한 번씩 지나가며, 아무도 집지 않으면 버려집니다.

데이터는 시간 순서대로 한 줄씩 주어집니다.

- 데이터 0: 좌석 $i$에 손님이 앉고 먹고 싶은 목록이 주어집니다.
- 데이터 1: 초밥 한 접시가 좌석 1부터 20까지 순서대로 돕니다.
- 데이터 2: 좌석 $i$의 손님이 계산하러 갑니다.

같은 좌석에 여러 손님이 앉거나 빈 좌석에서 손님이 일어나는 일은 없습니다. 데이터 1이 주어질 때 초밥을 집는 손님의 좌석 번호를 한 줄에 출력하세요. 아무도 집지 않으면 -1을 출력하세요. 데이터 1이 처음 나올 수도 있습니다.

## 입력

~~~text
$N$
$U_1$
\dots
$U_N$
~~~

$2\leq N\leq5005$이며 $N$은 데이터 개수입니다. 모든 데이터는 공백으로 구분됩니다.

데이터 0은 $0\ n_i\ m_i\ A_{i,1}\ \dots\ A_{i,m_i}$ 형식이며 좌석 $n_i$에 손님이 앉고 목록은 $m_i$개의 초밥 이름으로 이루어집니다. $1\leq n_i\leq20$, $1\leq m_i\leq10$입니다. 초밥 이름은 소문자 알파벳으로 이루어진 길이 1 이상 17 이하 문자열입니다.

데이터 1은 $1\ B_i$ 형식이며 초밥 이름 $B_i$가 좌석 1부터 20까지 돕니다. 원하는 손님을 만나면 그 손님이 집고 목록에서 해당 초밥 하나만 삭제합니다.

데이터 2는 $2\ C_i$ 형식이며 좌석 $C_i$의 손님이 떠나고 목록이 사라집니다. $1\leq C_i\leq20$입니다.

초밥 종류는 최대 53개라고 가정해도 됩니다.

## 출력

데이터 1이 주어질 때마다 초밥을 집는 좌석 번호를 한 줄에 출력하세요. 한 바퀴 동안 아무도 손을 내밀지 않으면 -1을 출력하세요.

#### 출력

~~~text
-1
-1

14
-1
-1
-1
14
14
~~~

처음 두 접시는 손님이 없어 버려집니다. 좌석 14의 손님만 앉아 있습니다. unagi는 한 접시만 원하므로 두 번째 접시는 지나치지만 maguroakami는 두 접시를 원하므로 두 번째 접시도 집습니다. 나머지는 원하는 접시가 아니어서 버려집니다.
