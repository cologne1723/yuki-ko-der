## 문제

두 사람이 카드 게임을 합니다. 카드 `i`에는 정수 `c_i`가 적혀 있고, 번갈아 한 장씩 가져갑니다. A가 선공입니다.

게임이 끝났을 때 A의 카드 합을 `a`, B의 카드 합을 `b`라 하면 점수는 각각 `|a|`, `|b|`입니다. 점수 차이 `|a|-|b|`를 A는 최대화하고 B는 최소화합니다. 두 사람이 최선으로 행동할 때 점수 차이를 구하세요.

## 입력

`N`과 `c_1,...,c_N`이 주어집니다.

## 출력

최종 점수 차이를 출력하세요.
