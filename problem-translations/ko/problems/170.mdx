## 문제 설명

길이 $8$ 이하의 문자열 $S$가 주어집니다.

문자열 $S$를 이루는 문자 중 임의의 서로 이웃한 $2$개의 문자를 교환하는 조작을 원하는 횟수만큼 할 수 있을 때, 만들 수 있는 문자열 종류의 수를 구하세요. 단, 입력 문자열 $S$와 같은 문자열은 세지 않습니다.

## 입력

```text
$S$
```

$1$번째 줄에 문자열 $S$가 주어집니다.

## 제한

- $1 \le |S| \le 8$
- $S$는 대문자 영문 알파벳(`A`~`Z`)으로만 이루어집니다.

## 출력

조작으로 만들 수 있는 문자열 중 입력 문자열 자체를 제외한 종류의 수를 정수로 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
ABC
```

#### 출력

```text
5
```

`ABC`의 이웃한 $2$개의 문자를 여러 번 교환하면 `ABC`, `ACB`, `BAC`, `BCA`, `CAB`, `CBA`의 $6$가지 문자열을 만들 수 있습니다. 입력 문자열을 제외하면 $5$가지입니다.

### 예제 2 {file=""}

#### 입력

```text
DDDDDD
```

#### 출력

```text
0
```

아무리 교환해도 `DDDDDD` 외에는 만들 수 없습니다. 입력 문자열을 제외하면 $0$가지입니다.

### 예제 3 {file=""}

#### 입력

```text
XYZYX
```

#### 출력

```text
29
```
