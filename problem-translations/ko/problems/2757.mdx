## 문제

수직선 위에 좌표 `X_i`의 핀이 `N`개 있습니다. 일부를 제거해 남은 모든 핀 사이의 거리가 `K` 이상이 되도록 할 때, 남길 수 있는 핀의 최대 개수를 구하세요.

## 제약

- `1 ≤ N ≤ 3×10^5`, `1 ≤ K ≤ 10^9`
- `-10^9 ≤ X_1 < ... < X_N ≤ 10^9`

## 입력

```text
N K
X_1 X_2 ... X_N
```

## 출력

최대 개수를 출력하세요.
