## 문제 설명

$1$부터 $N$까지의 수가 쓰인 카드가 $1$이 위에 오고 $N$이 아래에 오도록 번호 순서대로 쌓여 있습니다. 이 상태를 초기 상태라고 합니다.

이 카드 더미를 셔플하는 방법에는 다음 $2$가지가 있습니다.

- 교환 셔플: 위아래로 맞닿아 있는 카드 $2$장을 서로 바꿉니다.
- 마술사 셔플: 가장 위의 카드를 꺼내 카드 사이 또는 카드 더미의 맨 아래에 넣습니다.

예를 들어 카드의 상태가 위에서부터 $3, 4, 2, 1$일 때, 교환 셔플을 하면 $4, 3, 2, 1$, $3, 2, 4, 1$, $3, 4, 1, 2$ 중 $1$개의 상태로 만들 수 있습니다. 마술사 셔플을 하면 $4, 3, 2, 1$, $4, 2, 3, 1$, $4, 2, 1, 3$ 중 $1$개의 상태로 만들 수 있습니다.

eiramくん은 초기 상태에서 가장 위의 카드를 꺼내 $K$가 쓰인 카드와 $K + 1$이 쓰인 카드 사이에 넣는 마술사 셔플을 했습니다.

nauclhltくん은 반대로 하는 것을 좋아하기 때문에, 같은 상태를 초기 상태에서 교환 셔플만 사용하여 재현하려고 합니다.

교환 셔플을 최소 몇 번 해야 하는지 구하세요.

## 입력

```text
$N\ K$
```

$1$번째 줄에 카드의 수를 나타내는 정수 $N$과, 카드에 쓰인 수를 나타내는 정수 $K$가 공백으로 주어집니다.

입력은 다음 제한을 만족합니다.

## 제한

- $3 \le N \le 10^{10}$
- $2 \le K < N$

## 출력

교환 셔플을 해야 하는 최소 횟수 $ans$를 출력하고, 마지막에 줄 바꿈을 출력하세요.

```text
$ans$
```
