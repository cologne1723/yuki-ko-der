## 이야기

드디어 4월이 시작된 날, 오늘은 개학식 날입니다.

## 문제 설명

yukicoder 小学校의 어느 반에는 $N$명의 학생이 있습니다. $i$번째 $(1 \leq i \leq N)$ 학생은 봄방학 동안 공부했으면 $f_i=1$, 공부하지 않았으면 $f_i=0$입니다.

선생님인 당신은 그 반에서 봄방학 동안 공부한 학생이 몇 명인지 보고해야 합니다. 이를 위한 프로그램을 작성하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

여기서 $\mathrm{case}_i$는 $i$번째 테스트 케이스의 입력을 나타냅니다. 각 테스트 케이스의 입력은 다음 형식으로 주어집니다.

```text
$N$
$f_1\ f_2\ \cdots\ f_N$
```

$1$번째 줄에 테스트 케이스의 수를 나타내는 정수 $T$가 주어집니다.

각 테스트 케이스에 대해 $1$번째 줄에 학생 수를 나타내는 정수 $N$이 주어지고, $2$번째 줄에 각 학생이 봄방학 동안 공부했는지를 나타내는 정수 $f_1,f_2,\ldots,f_N$이 공백으로 구분되어 주어집니다.

## 제한

- $1 \leq T \leq 2\,000$
- $1 \leq N \leq 60$
- $f_i$ $(1 \leq i \leq N)$는 $0$ 또는 $1$입니다.
- 입력되는 값은 모두 정수입니다.

## 출력

$T$개의 줄에 출력하세요. $j$번째 줄 $(1 \leq j \leq T)$에는 $j$번째 테스트 케이스에서 반에서 봄방학 동안 공부한 학생 수를 나타내는 $0$ 이상 $N$ 이하의 정수를 출력하세요. 또한 마지막에 개행 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
5
1 0 0 1 1
```

#### 출력

```text
3
```

이 입력 예제는 테스트 케이스 $1$개로 이루어져 있습니다.

$N=5$, $(f_1,f_2,f_3,f_4,f_5)=(1,0,0,1,1)$이므로 학생 $1$, $4$, $5$가 봄방학 동안 공부했고, 학생 $2$, $3$은 봄방학 동안 공부하지 않았습니다. 따라서 봄방학 동안 $3$명이 공부했습니다.
