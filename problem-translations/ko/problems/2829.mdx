## 문제 설명

정수 $N$이 주어집니다. 다음 동작을 $N$이 $1$이 될 때까지 반복합니다.

- $1$ 이상 $N$ 이하인 정수 $M$을 같은 확률로 무작위로 선택합니다.
- $N$을 $\gcd(N,M)$으로 바꿉니다.

$N$이 $1$이 될 때까지 걸리는 횟수의 기댓값을 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

$1$번째 줄에 정수 $N$이 주어집니다.

```text
$N$
```

## 제한

- $2 \leq N \leq 10^7$
- $N$은 정수입니다.

## 출력

횟수의 기댓값을 출력하세요.

답이 정수가 아닐 수 있습니다. 참값과의 오차가 $10^{-10}$ 이하가 되도록 작성된 모범 답안과의 절대 오차 또는 상대 오차 중 어느 한쪽이 $10^{-5}$ 이하이면 정답으로 인정됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
```

#### 출력

```text
2
```

각 시도에서 $M=1$이 선택될 확률은 $\frac{1}{2}$이고, $\gcd(1,2)=1$이 되어 종료합니다. 구하는 값은 $\sum_{i=1}^{\infty}i2^{-i}$이며, 이는 $2$입니다.

### 예제 2 {file=""}

#### 입력

```text
3
```

#### 출력

```text
1.5
```

### 예제 3 {file=""}

#### 입력

```text
4
```

#### 출력

```text
2
```
