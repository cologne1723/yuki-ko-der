매번 서로 다른 6문제가 출제되는 대회에 참가합니다. 문제를 순서대로 풀며 총 풀이 시간이 60분 이하인 최대 개수까지 풉니다. 지금까지 푼 문제 중 최근 $N$개와 이름이 같은 문제는 기시감이 있어 풀이 시간이 $\min(d,K)$분으로 줄어듭니다.

유형 1은 문제 $s$를 푼 기록을 추가하고, 유형 2는 6개의 문제와 풀이 시간을 주어 이번 대회에서 푼 문제 수를 출력한 뒤 실제로 푼 문제를 기록합니다.

## 조건

- $1\le N,Q\le500$
- $1\le K\le100$
- 각 풀이 시간은 $1$ 이상 $100$ 이하입니다.

## 입력

$N,K,Q$와 쿼리가 주어집니다.

## 출력

각 유형 2 쿼리의 풀이 문제 수를 출력하세요.
