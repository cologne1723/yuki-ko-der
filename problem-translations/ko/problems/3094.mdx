## 문제 설명

종이 $N$장이 겹쳐 있습니다. 스테이플러를 사용하면 서로 겹쳐 이웃한 종이들을 연결할 수 있습니다. 연결된 종이들은 $1$개의 묶음이 되며, 연결하는 데 사용한 심을 모두 제거할 때까지 묶음으로 남아 있습니다.

$Q$개의 질의가 주어집니다. 각 질의를 순서대로 처리하세요.

- $1\ L\ R$: 위에서 $L$번째 종이부터 $R$번째 종이까지를 스테이플러로 고정합니다.
- $2\ q$: $q$번째 질의에서 고정하는 데 사용한 심을 제거합니다. $q$번째 질의는 종류가 $1$인 질의임이 보장됩니다.
- $3$: 현재 종이 묶음의 개수를 출력합니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$Q$
$\mathrm{query}_1$
$\mathrm{query}_2$
$\vdots$
$\mathrm{query}_Q$
```

각 질의에는 먼저 질의의 종류 $c_i$가 주어집니다. $c_i$는 $1$, $2$, $3$ 중 $1$개입니다. 질의의 종류가 $1$인 경우에는 정수 $L$, $R$이, 질의의 종류가 $2$인 경우에는 정수 $q$가 추가로 주어집니다.

각 질의는 다음 $3$가지 형식 중 $1$개로 주어집니다.

```text
$1\ L\ R$
```

```text
$2\ q$
```

```text
$3$
```

## 제한

- $1\leq N\leq 10^6$
- $1\leq Q\leq 10^5$
- 입력은 모두 정수입니다.

## 출력

종류가 $3$인 질의가 주어질 때마다 답을 순서대로 출력하세요.

마지막에 개행 문자를 출력하세요.
