## 문제 설명

정점이 $N$개이고 간선이 $N-1$개인 무방향 트리가 있습니다. 정점에는 $1$부터 $N$까지, 간선에는 $1$부터 $N-1$까지 각각 번호가 붙어 있으며, $i$번째 간선은 정점 $u_i$와 $v_i$를 양방향으로 연결합니다. 또한 각 간선에는 색이 칠해져 있습니다. 색은 모두 $K$종류이고, $i$번째 간선의 색은 $c_i$입니다.

이 트리의 경로 $(p, q)$ ($p < q$) 중 경로에 포함된 간선의 색이 **정확히 $2$종류**인 경로의 개수를 구하세요. 경로 $(p, q)$에 포함된 간선이란 정점 $p$에서 정점 $q$까지 최단 경로로 이동할 때 지나는 간선의 집합을 의미합니다.

## 입력

```text
N K
u_1 v_1 c_1
\vdots
u_{N-1} v_{N-1} c_{N-1}
```

첫째 줄에 트리의 정점 수 $N$과 색의 종류 수 $K$가 주어집니다.

둘째 줄부터 $N-1$개의 줄에는 트리의 간선 정보가 주어집니다. $1+i$번째 줄($1 \leq i \leq N-1$)은 $i$번째 간선이 정점 $u_i$와 정점 $v_i$를 양방향으로 연결하고 있으며 간선의 색이 $c_i$임을 나타냅니다.

## 제한

- 입력은 모두 정수로 주어집니다.
- $1 \leq N \leq 2 \times 10^5$
- $1 \leq K \leq 2 \times 10^5$
- $1 \leq u_i, v_i \leq N$ ($1 \leq i \leq N-1$)
- $1 \leq c_i \leq K$ ($1 \leq i \leq N-1$)
- 주어지는 그래프는 트리입니다.

## 출력

답을 한 줄에 출력하세요.

## 예제

### 예제 1 {file="sample1.in"}

#### 입력

```text
5 5
1 2 3
1 3 1
2 4 5
3 5 1
```

#### 출력

```text
3
```

다음 $3$개의 경로가 조건을 만족합니다.

- $(1, 4)$
- $(2, 3)$
- $(2, 5)$

색을 한 종류만 사용하는 경로 등, 정확히 $2$종류의 색을 사용하는 경로가 아닌 것은 세지 않는다는 점에 주의하세요.
