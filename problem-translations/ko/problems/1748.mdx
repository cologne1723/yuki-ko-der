번호 `1`부터 `N`까지의 주차 공간에 `N`대의 차가 순서대로 주차합니다. 첫 차는 `K`번 공간에 주차합니다.

주차된 공간과의 번호 차이 절댓값 중 최솟값을 편안함이라 할 때, 이후 차는 편안함이 가장 큰 빈 공간에 주차하며 여러 곳이면 번호가 가장 작은 곳을 선택합니다.

마지막 차가 주차하는 공간 번호를 구하세요.

## 제약

- `1 <= K <= N <= 10^9`

## 입력

`N K`가 주어집니다.

## 출력

마지막 차의 주차 공간 번호를 출력하세요.
