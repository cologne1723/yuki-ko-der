## 문제 설명

일직선 위에 아메바가 $N$마리 있습니다.
각 아메바의 초기 좌표가 주어지며, 초기 좌표는 모두 정수입니다.

아메바는 1초 후 세 마리로 분열합니다. 그 후 한 마리는 현재 좌표에서 $-D$만큼, 다른 한 마리는 현재 좌표에서 $+D$만큼 이동하고, 마지막 한 마리는 현재 좌표에 그대로 있습니다.
아메바가 같은 좌표에 두 마리 이상 있으면 합쳐져 한 마리가 됩니다.

처음에 $N$마리였던 아메바가 $T$초 후 몇 마리가 되는지 구하세요.

## 입력

```text
N D T
X_0 X_1 ... X_{N-1}
```

$N$은 아메바의 수입니다. $(1 \le N \le 100)$
$D$는 이동 거리입니다. $(1 \le D \le 1\,000\,000\,000)$
$T$는 경과 시간입니다. $(1 \le T \le 1\,000\,000\,000)$
$X_i$는 $i$번째 아메바의 초기 위치입니다. $(-1\,000\,000\,000 \le X_i \le 1\,000\,000\,000)$

## 출력

$T$초 후 아메바의 수 $Ans$를 출력하세요. 답이 32비트 값에 들어가지 않을 수 있으므로 주의하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1

#### 입력

```text
2 3 1
0 7
```

#### 출력

```text
6
```

처음에는 좌표 0과 7에 각각 한 마리씩 있습니다. 1초 후 좌표 -3, 0, 3, 4, 7, 10에 총 6마리가 있습니다.

### 예제 2

#### 입력

```text
2 3 2
0 6
```

#### 출력

```text
7
```

처음에는 좌표 0과 6에 각각 한 마리씩 있습니다. 1초 후 좌표 -3, 0, 3, 6, 9에 총 5마리가 있고, 좌표 3에서 아메바가 합쳐져 한 마리가 됩니다. 2초 후 좌표 -6, -3, 0, 3, 6, 9, 12에 총 7마리가 있습니다.

### 예제 3

#### 입력

```text
2 3 1
0 2
```

#### 출력

```text
6
```

처음에는 좌표 0과 2에 각각 한 마리씩 있습니다. 1초 후 좌표 -3, -1, 0, 2, 3, 5에 총 6마리가 있습니다.
분열 후 이동하는 동안에는 아메바가 합쳐지지 않습니다. 같은 좌표에 있을 때만 합쳐집니다.
