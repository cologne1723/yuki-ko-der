## 문제 설명

nok0 군은 산수를 못합니다. nok0 군을 대신해 $P$가 소수인지 판정하고, $P$가 소수라면 $A^{P!} \pmod P$를 구하세요.

$T$개의 테스트 케이스에 답하세요.

입출력량이 많으므로 빠른 입출력을 강하게 권장합니다. Writer와 Tester는 PyPy3으로 제한 시간에 여유를 두고 정답을 받을 수 있음을 확인했지만, Python3으로 정답을 받을 수 있는지는 확인하지 않았습니다. Python으로 제출할 때는 충분히 주의하세요.

## 입력

```text
$T$
$A\ P$
```

첫 번째 줄에 $T$가 주어집니다. 이어지는 $T$개의 줄은 각각 하나의 테스트 케이스이며, 각 줄에 $A$, $P$가 주어집니다.

- $1 \leq T \leq 5 \times 10^5$
- $1 \leq A \leq 10^{18}$
- $1 \leq P \leq 5 \times 10^6$
- 입력은 모두 정수입니다.

## 출력

각 테스트 케이스에 대해 $P$가 소수이면 $A^{P!} \pmod P$를, 소수가 아니면 $-1$을 표준 출력에 출력하세요. 테스트 케이스마다 줄을 바꾸세요.

## 예제

### 예제 1 {file=""}
#### 입력
```text
2
33 4
2 3
```
#### 출력
```text
-1
1
```

첫 번째 테스트 케이스에서는 $4$가 소수가 아니므로 $-1$을 출력합니다. 두 번째 테스트 케이스에서는 $3$이 소수이고 $2^{3!}=64$를 $3$으로 나눈 나머지가 $1$이므로 $1$을 출력합니다.
