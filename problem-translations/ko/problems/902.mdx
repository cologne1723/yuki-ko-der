## 문제 설명

niuez는 다섯 번째 문제를 만들어서 기쁜 나머지, 짓궂게도 쿼리를 늘려 버렸습니다.

처음에는 $0$부터 $N-1$까지 번호가 붙은 $N$개의 정점과 $N-1$개의 간선으로 이루어진 무방향 트리가 있습니다.
$i$번 간선의 양 끝점은 $u_i$번 정점과 $v_i$번 정점이며, 가중치는 $w_i$입니다. $0 \le i < N-1$입니다.

다음 두 형식의 쿼리 $Q$개를 처리하세요.

$1\ u_i\ v_i\ w_i\ x_i$

유형 $1$ 쿼리: 트리에서 $u_i$번 정점과 $v_i$번 정점을 잇는 간선을 삭제하고, $v_i$번 정점과 $w_i$번 정점을 잇는 가중치 $x_i$의 간선을 새로 추가합니다.
이 쿼리를 처리하기 전과 후에 그래프가 $N$개의 정점으로 이루어진 무방향 트리임이 보장됩니다.

$2\ k_i\ x_0\ x_1\ \cdots\ x_{k_i-1}$

유형 $2$ 쿼리: 트리의 연결된 부분 그래프 중, 서로 다른 $k_i$개의 정점 $x_0, x_1, \ldots, x_{k_i-1}$을 모두 포함하면서 정점 수가 최소인 부분 그래프에 포함된 간선의 가중치 합을 구합니다(2019/10/4 21:44 용어 오류를 수정했습니다).
이러한 트리의 부분 그래프는 유일하게 정해짐을 증명할 수 있습니다.

## 입력

```text
$N$
$u_0\ v_0\ w_0$
$\vdots$
$u_{N-2}\ v_{N-2}\ w_{N-2}$
$Q$
$\mathrm{query}_0$
$\vdots$
$\mathrm{query}_{Q-1}$
```

$\mathrm{query}_i$는 다음 두 형식 중 하나로 주어집니다. $0 \le i < Q$입니다.

유형 $1$ 쿼리:

```text
$1\ u_i\ v_i\ w_i\ x_i$
```

유형 $2$ 쿼리:

```text
$2\ k_i\ x_0\ x_1\ \cdots\ x_{k_i-1}$
```

초기 간선 정보의 $w_i$는 가중치이고, 유형 $1$ 쿼리의 $w_i$는 정점 번호입니다.
입력은 모두 정수입니다.

## 제한

- $2 \le N \le 10^5$
- 초기 간선 정보에서 $0 \le u_i, v_i < N$이며 $u_i \ne v_i$입니다. $0 \le i < N-1$입니다.
- 초기 간선 정보에서 $(u_i, v_i) = (u_j, v_j) \Leftrightarrow i = j$입니다. $0 \le i, j < N-1$입니다.
- 초기 간선의 가중치는 $0 \le w_i \le 10^5$입니다. $0 \le i < N-1$입니다.
- $1 \le Q \le 10^5$
- 유형 $1$ 쿼리에서 $0 \le u_i, v_i, w_i < N$이며 $u_i \ne v_i$, $v_i \ne w_i$입니다.
- 유형 $1$ 쿼리에서 $0 \le x_i \le 10^5$입니다.
- 유형 $2$ 쿼리에서 $1 \le k_i \le N$입니다.
- 유형 $2$ 쿼리에서 $0 \le x_j < N$입니다. $0 \le j < k_i$입니다.
- 유형 $2$ 쿼리의 $x_0, x_1, \ldots, x_{k_i-1}$은 서로 다릅니다.
- $0$번부터 $Q-1$번까지의 쿼리 중 유형 $2$인 쿼리에 대한 $k_i$의 합은 $1$ 이상 $10^5$ 이하입니다.

## 출력

유형 $2$ 쿼리의 개수만큼 줄을 출력하세요. $i$번째 줄에는 $i$번째 유형 $2$ 쿼리의 답을 정수로 출력하세요.
