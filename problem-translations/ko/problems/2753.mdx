## 문제

상호작용 문제입니다. `N`개의 비둘기집에 양의 정수 마릿수가 비내림차순으로 들어 있고, 마지막 집의 마릿수는 `N` 미만입니다. 정확히 10번 집을 질의한 뒤, 같은 마릿수를 가진 서로 다른 두 집이 존재하는지 판정하고 그런 두 집을 출력하세요.

## 제약

- `2 ≤ N ≤ 1000`
- 질의는 정확히 10번 수행합니다.

## 상호작용

매번 `? i`를 출력하고 답을 입력받습니다. 10번 질의 후, 같은 값의 두 집이 없으면 `No`, 있으면 `Yes i j`를 출력하세요.
