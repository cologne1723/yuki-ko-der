## 문제

돌 `N`개에서 차례로 `3^k`개를 제거합니다. 제거할 수 없게 된 사람이 승리하며, 당신이 선공입니다. 두 사람이 최적으로 행동할 때 당신이 이기는지 판정하세요.

## 입력

`1\le N\le10^9`인 `N`이 주어집니다.

## 출력

이기면 `YES`, 지면 `NO`를 출력하세요.
