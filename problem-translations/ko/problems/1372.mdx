## 문제

양의 정수 `N`에 대해 `S_N={x | x AND N=x, x는 양의 정수}`로 정의합니다. `S_N`의 원소 수는 홀수입니다. `S_N`을 정렬했을 때 중앙값, 즉 `(|S_N|+1)/2`번째 값을 출력하세요.

## 입력

`1\le N<2^{60}`인 정수 `N`이 주어집니다.

## 출력

`S_N`의 중앙값을 출력하세요.
