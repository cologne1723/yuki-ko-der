## 문제

서로 다른 비음이 아닌 정수로 이루어진 길이 $N$의 수열 중 원소 합이 $M$이고 역전 수가 $K$인 수열을 하나 구성하세요.

조건을 만족하는 수열이 적어도 하나 존재하는 입력만 주어집니다.

## 입력

$N,M,K$가 주어집니다.

- $1\leq N\leq10^5$
- $0\leq M,K\leq10^{10}$

## 출력

조건을 만족하는 수열 하나를 출력하세요.
