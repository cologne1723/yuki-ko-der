## 문제 설명

양의 정수 $N,K$와 길이 $N$의 양의 정수 수열 $A=(A_1,A_2,\ldots,A_N)$이 주어집니다.

$1,2,\ldots,N$의 순열 $P=(P_1,P_2,\ldots,P_N)$에 대해 정수 $B(P)$를 다음과 같이 정의합니다.

$B(P)=\mathop{\mathrm{lcm}}\limits_{1\le i\le N-K+1}\gcd(A_{P_i},A_{P_{i+1}},\ldots,A_{P_{i+K-1}})$

$1,2,\ldots,N$의 모든 순열 $P$에 대한 $B(P)$의 최대공약수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

표준 입력으로 다음 형식의 입력이 주어집니다.

```text
$N\ K$
$A_1\ A_2\ \ldots\ A_N$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $2\le N\le 2\times 10^5$
- $1\le K\le N$
- $1\le A_i\le 10^6$ $(1\le i\le N)$

## 출력

답을 출력하세요.

2
