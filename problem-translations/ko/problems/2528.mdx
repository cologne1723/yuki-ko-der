수열 $(1,2,\ldots,2N+1)$에서 $N$번 작업합니다. 현재 수열의 양끝 두 원소 또는 양끝을 제외한 두 원소를 골라 삭제합니다. 작업 후 하나만 남는 값 $k$별 작업열의 수를 $998244353$으로 나눈 나머지로 출력하세요.

## 조건

- $1\le N\le2000$

## 입력

```text
N
```

## 출력

$k=1,\ldots,2N+1$의 답을 각 줄에 출력하세요.
