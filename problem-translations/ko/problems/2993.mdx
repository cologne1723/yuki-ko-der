**문제의 실행 시간 제한은 $10\,000$ms입니다. 출제자의 정답 코드 실행 시간은 C++에서 $415$ms, PyPy3에서 $5\,293$ms, Python3에서는 시간 초과였으므로 빠른 언어·처리계의 사용을 권장합니다.**

## 문제 설명

다음과 같은 문제를 생각합니다.

입력으로 $2$ 이상인 정수 $B$와 $2$개의 음이 아닌 정수 $N$, $M$이 주어집니다.

다음 $2$가지 조건을 모두 만족하는 정수 $a$가 존재하는지 판정하고, 존재한다면 그러한 정수 $a$를 $1$개 구하세요.

1. $0\leq a<B^N$입니다.
2. 어떤 음이 아닌 정수 $n_0$가 존재하여, $n_0$ 이상인 임의의 음이 아닌 정수 $n$에 대해 $M^{B^n}\equiv 1+B^n a\pmod {B^{n+N}}$입니다.

이하에서는 위 $2$가지 조건을 이 문제의 해 조건이라고 부릅니다.

입력의 $1$번째 줄에 양의 정수 $T$가 주어집니다. $T$개의 문제에 답하세요.

## 입력

$1\leq t\leq T$인 각 정수 $t$에 대해, $t$번째 문제의 입력 $B$, $N$, $M$을 각각 $B_t$, $N_t$, $M_t$로 나타내겠습니다. 입력은 표준 입력에서 다음 형식으로 $1+T$줄에 걸쳐 주어집니다.

```text
$T$
$B_1\ N_1\ M_1$
$\vdots$
$B_T\ N_T\ M_T$
```

- $1$번째 줄에 $T$가 주어집니다.
- $1\leq t\leq T$인 각 정수 $t$에 대해, $(1+t)$째 줄에 $t$번째 문제의 입력 $B_t$, $N_t$, $M_t$가 반각 공백으로 구분되어 주어집니다.

## 제한

입력은 다음 조건을 만족합니다.

- $T$는 $1\leq T\leq 10^5$인 정수입니다.
- $1\leq t\leq T$인 임의의 정수 $t$에 대해 다음이 성립합니다.
  - $B_t$는 $2\leq B_t\leq 10^6$인 정수입니다.
  - $N_t$는 $0\leq N_t$이고 $B_t^{N_t}\leq 10^6$인 정수입니다.
  - $M_t$는 $0\leq M_t\leq 10^{18}$인 정수입니다.

## 출력

$1\leq t\leq T$인 각 정수 $t$에 대해, $t$번째 문제의 해 조건을 만족하는 정수 $a$가 존재한다면 그러한 $a$를 $t$번째 줄에 출력하세요. 존재하지 않는다면 $t$번째 줄에 $-1$을 출력하세요.

마지막에 줄바꿈을 출력하세요.

이 문제는 스페셜 저지 문제입니다. 정답이 여러 개라면 그중 무엇을 출력해도 됩니다.

**단, 출력은 위 형식을 엄격하게 따라야 합니다. 예를 들어 불필요한 공백이 있을 때 저지가 어떻게 동작할지는 보장되지 않습니다.**

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
2 0 0
```

#### 출력

```text
-1
```

정수 $a$가 테스트 케이스 $(B,N,M)=(2,0,0)$에 대한 해 조건을 만족한다는 것은 다음 $2$가지 조건을 만족한다는 뜻입니다.

1. $0\leq a<1$입니다.
2. 어떤 음이 아닌 정수 $n_0$가 존재하여, $n_0$ 이상인 임의의 음이 아닌 정수 $n$에 대해 $0\equiv 1+2^n a\pmod {2^n}$입니다.

조건 $1$에 의해 $a$는 $0$으로 정해집니다. 하지만 $a=0$으로 하면 음이 아닌 정수 $n_0$를 어떻게 정하더라도 $n=\max\{n_0,1\}$일 때 $0\equiv 1+2^n a\pmod {2^n}$이 성립하지 않습니다. 따라서 조건 $2$가 성립하지 않으며, 해 조건을 만족하는 정수 $a$는 존재하지 않습니다.

### 예제 2 {file=""}

#### 입력

```text
1
2 0 1
```

#### 출력

```text
0
```

정수 $a$가 테스트 케이스 $(B,N,M)=(2,0,1)$에 대한 해 조건을 만족한다는 것은 다음 $2$가지 조건을 만족한다는 뜻입니다.

1. $0\leq a<1$입니다.
2. 어떤 음이 아닌 정수 $n_0$가 존재하여, $n_0$ 이상인 임의의 음이 아닌 정수 $n$에 대해 $1\equiv 1+2^n a\pmod {2^n}$입니다.

$a=0$으로 정하면 조건 $1$을 만족합니다. 또한 $n_0=0$으로 정하면 $n_0$ 이상인 임의의 음이 아닌 정수 $n$에 대해 $1\equiv 1+2^n a\pmod {2^n}$도 성립하므로 조건 $2$도 만족합니다. 따라서 $a$는 해 조건을 만족합니다.
