정수열 $A=(A_0,\ldots,A_{N-1})$ 중 $1\le A_i\le M-1$이고 $\sum_{i=0}^{N-1}A_iK^i$가 $M$의 배수인 것의 개수를 $998244353$으로 나눈 나머지를 구하세요.

## 조건

- $1\le N,K\le10^9$
- $2\le M\le998244352$

## 입력

```text
N M K
```

## 출력

답을 출력하세요.
