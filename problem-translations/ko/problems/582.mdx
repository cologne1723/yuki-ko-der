## 문제

사탕을 넣을 수 있는 상자가 N개 있습니다. i번째 상자에는 Ci개의 사탕이 들어 있습니다.

A와 B는 다음 규칙의 게임을 합니다.

* A가 선공이며 B와 번갈아 조작합니다.
* A는 한 번에 원하는 사탕 상자 하나를 골라 사탕 1개를 꺼냅니다.
* B는 한 번에 원하는 상자 하나를 골라 사탕 1개 또는 2개를 꺼냅니다.
* A와 B는 조작을 건너뛸 수 없습니다.
* 모든 상자가 비어 사탕을 꺼낼 수 없게 된 사람이 패배합니다.
* A와 B는 이기기 위해 최선의 전략을 사용합니다.

처음 상태가 주어질 때 마지막에 누가 이기는지 답하세요.

## 입력

```text
N
C1 C2 … CN
```

N은 사탕 상자의 수입니다. 1 ≤ N ≤ 150

Ci는 i번째 상자에 처음 들어 있는 사탕 수입니다. 0 ≤ Ci ≤ 1000000000 = 10^9

## 출력

A가 이기면 A, B가 이기면 B를 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
2
1 2
```

출력:

```text
A
```

상자 2개 중 하나에는 사탕 1개, 다른 하나에는 사탕 2개가 있습니다. 선공 A가 사탕 2개인 상자에서 1개를 꺼내고, B가 어느 한 상자에서 1개를 꺼립니다. A가 남은 사탕을 꺼내면 모든 상자가 비고 B는 꺼낼 수 없으므로 A가 이깁니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
1
3
```

출력:

```text
B
```

상자 하나에 사탕 3개가 있습니다. A가 1개, B가 2개를 꺼내면 상자가 비고 A가 꺼낼 수 없으므로 B가 이깁니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
5
1 1 2 4 0
```

출력:

```text
B
```

B가 이깁니다.
