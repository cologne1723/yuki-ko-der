## 문제 설명

세로 $H$행, 가로 $W$열의 격자의 각 칸에 $1$ 이상 $M=H\times W$ 이하인 모든 정수를 각각 $1$번씩 써넣습니다.

다음 조건을 만족하도록 써넣는 방법을 $1$개 찾아 출력하세요.

- 상하좌우 $4$가지 방향 중 $1$가지로 인접한 임의의 $2$개 칸에 써넣은 정수 $a,b$가 **좋은 쌍**입니다.

정수 $a,b$가 **좋은 쌍**이라는 것은 다음 조건 중 적어도 $1$개를 만족하는 것을 말합니다.

- $ax\equiv b\pmod M$를 만족하는 정수 $x$가 존재합니다.
- $a\equiv bx\pmod M$를 만족하는 정수 $x$가 존재합니다.

이 문제의 제한에서 조건을 만족하는 써넣는 방법이 반드시 존재한다는 것을 증명할 수 있습니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$H\ W$
```

## 제한

- 입력은 모두 양의 정수입니다.
- $1\leq H\times W\leq 2\times 10^5$

## 출력

조건을 만족하는 써넣는 방법을 다음 형식으로 $1$개 출력하세요. 단, $A_{i,j}$는 $i$행 $j$열에 써넣는 수입니다.

```text
$A_{1,1}\ A_{1,2}\ \cdots\ A_{1,W}$
$A_{2,1}\ A_{2,2}\ \cdots\ A_{2,W}$
$\vdots$
$A_{H,1}\ A_{H,2}\ \cdots\ A_{H,W}$
```

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 3
```

#### 출력

```text
1 2 4
3 5 6
```

이 격자에는 $1$ 이상 $2\times 3=6$ 이하인 양의 정수가 모두 $1$번씩 써넣어져 있으며, 인접한 $2$개 칸에 써넣은 어떤 $2$개의 양의 정수도 좋은 쌍입니다.

다음과 같이 써넣는 방법에서는 $2x\equiv 3\pmod 6$을 만족하는 $x$와 $2\equiv 3x\pmod 6$을 만족하는 $x$가 존재하지 않으므로 $2,3$은 좋은 쌍이 아닙니다.

```text
1 2 3
4 5 6
```

### 예제 2 {file=""}

#### 입력

```text
1 1
```

#### 출력

```text
1
```
