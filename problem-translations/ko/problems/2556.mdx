모든 성분이 양의 정수인 $N$차 정사각행렬 중 다음 조건을 만족하는 행렬의 개수를 구하고, $998244353$으로 나눈 나머지를 출력하세요.

## 조건

- 각 행은 넓은 의미에서 단조 증가합니다.
- 각 열은 넓은 의미에서 단조 증가합니다.
- $i=1,2,\ldots,N$에 대해 $(i,i)$ 성분은 $A_i$입니다.

## 조건

- $1 \le N \le 10^5$
- $1 \le A_1 \le A_2 \le \cdots \le A_N \le 10^9$
- 입력은 모두 정수입니다.

## 입력

```text
$N$
$A_1$ $A_2$ $\cdots$ $A_N$
```

## 출력

행렬의 개수를 $998244353$으로 나눈 나머지를 출력하세요.
