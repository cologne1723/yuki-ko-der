정사각 영역 안의 체크포인트를 모두 한 번 이상 지나는 닫힌 드론 경로를 하나 출력하세요. 경로의 점 수는 최대 $2N$이고 총 맨해튼 이동 비용은 $1000L$ 이하이어야 합니다.

## 조건

- $1\le T\le10^5$, 모든 테스트 케이스에서 $N$의 합은 $2\times10^5$ 이하입니다.
- $2\le N\le2\times10^5$, $1\le L\le10^9$

## 입력

```text
$T$
$N$ $L$
$X_1$ $Y_1$
\vdots
$X_N$ $Y_N$
```

## 출력

각 테스트 케이스마다 경로의 길이와 점 좌표를 출력하세요.
