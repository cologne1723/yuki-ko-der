$N$면 주사위를 반복해서 굴려 나온 눈만큼 $X$를 증가시키고, $X\ge M$이 되면 종료합니다. 이때 필요한 횟수의 기댓값을 $f(M)$이라 할 때 $\lim_{M\to\infty}f(M)/M$을 $998244353$으로 계산하세요.

## 조건

- $1\le N\le2\times10^5$

## 입력

```text
$N$
```

## 출력

답을 출력하세요.
