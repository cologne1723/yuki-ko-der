$N$면 주사위를 반복해서 굴려 나온 눈만큼 $X$를 증가시키고, $X\ge M$이 되면 종료합니다. 이때 필요한 횟수의 기댓값을 $f(M)$이라 할 때 $\lim_{M\to\infty}f(M)/M$을 $998244353$으로 계산하세요.

## 조건

- $1\le N\le2\times10^5$

## 입력

```text
$N$
```

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1
```

#### 출력

```text
1
```

주사위에서는 $1$만 나오므로 $f(M)=M$입니다. 따라서 $\displaystyle\lim_{M\rightarrow\infty}\frac{f(M)}{M}=1$이므로 $1$을 출력합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
100
```

#### 출력

```text
780804989
```
