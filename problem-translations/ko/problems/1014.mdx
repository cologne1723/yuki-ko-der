## 문제 설명

otamay 씨는 격투 게임 플레이어입니다. 오늘도 자신의 주 캐릭터를 연구하고 있는 것 같습니다.

상대에게 연속해서 맞힐 수 있는 기술의 연결을 콤보라고 합니다.

이 게임에서는 기술을 맞힌 뒤, 발동이 직전에 사용한 기술의 (위력)-(경직) 이하인 다른 기술을 사용하면 콤보를 이어 갈 수 있습니다.

다음 질문에 답하세요.

양의 정수 $N$이 주어집니다. $N$은 기술의 수를 나타냅니다.

각 $i$($1 \le i \le N$)에 대해 기술의 발동 $A_i$, 기술의 위력 $B_i$, 기술의 경직 $C_i$가 주어집니다.

$N$개의 기술 각각에 대해, 해당 기술을 시작으로 하는 콤보의 위력 합의 최댓값을 구하세요.

단, 같은 기술을 연속해서 사용할 수 없다고 합니다.

콤보를 무한히 이어 갈 수 있는 경우 `BAN`을 출력하세요.

더 형식적으로는 다음 문제를 풀게 됩니다.

- $k_1=i$
- $1 \le k_n \le N$ ($n \ge 2$)
- $A_{k_{n+1}} \le B_{k_n}-C_{k_n}$
- $k_{n+1} \ne k_n$

위 조건을 모두 만족하는 길이 $1$ 이상인 수열 $\{k_1, \dots\}$에 대해 $\displaystyle \sum_{n \ge 1}B_{k_n}$의 최댓값을 모든 $i$($1 \le i \le N$)에 대해 각각 구하세요.

답이 $\infty$라면 `BAN`을 출력하세요.

## 입력

```text
N
A_1 B_1 C_1
\vdots
A_N B_N C_N
```

입력은 모두 정수로 주어집니다.

## 제한

$1 \le N \le 10^5$

$1 \le A_i,B_i,C_i \le 10^9$

## 출력

각 $i$($1 \le i \le N$)에 대한 답을 줄바꿈으로 구분하여 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
3 3 4
5 5 1
4 6 3
```

#### 출력

```text
3
14
9
```

기술 $2$ → 기술 $3$ → 기술 $1$ 순서로 콤보를 이어 갈 수 있습니다. 기술 $1$은 콤보로 이어 갈 기술이 없으므로 기술 $1$의 위력인 $3$이 그대로 답이 됩니다.
