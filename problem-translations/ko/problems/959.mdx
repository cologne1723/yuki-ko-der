## 문제 설명

$N \times M$개의 칸이 있습니다. 처음에는 각 칸에 확률 $P$로 나무가 있고, 나무가 없는 칸에는 불이 있습니다.

불의 $4$방향 이웃(불과 변을 공유하는 칸)에 있는 나무는 사라집니다.

사라지지 않은 나무의 개수의 기댓값을 구하세요.

상대 오차 또는 절대 오차가 $10^{-6}$ 이하이면 정답으로 인정합니다.

## 입력

```text
$N\ M$
$P$
```

## 제한

- $1 \le N, M \le 10^9$
- $0 \le P \le 1$
- $N$, $M$은 정수입니다.
- $P$는 소수점 이하 최대 $7$자리인 실수입니다.

## 출력

사라지지 않은 나무의 개수의 기댓값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 2 
0.5            
```

#### 출력

```text
0.5000000000
```

사라지지 않은 나무의 개수가 $0$이 될 확률은 $0.75$입니다.

사라지지 않은 나무의 개수가 $2$가 될 확률은 $0.25$입니다.

따라서 기댓값은 $0.5$입니다.

### 예제 2 {file=""}

#### 입력

```text
2 2
0.25
```

#### 출력

```text
0.0625000000
```

### 예제 3 {file=""}

#### 입력

```text
1333 79
0.63
```

#### 출력

```text
10615.7879680041
```
