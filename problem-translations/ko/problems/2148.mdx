히카리 씨는 B, G, R 중 하나의 색과 값 하나가 적힌 카드 $N$장을 가지고 있다냥. 같은 색과 같은 값을 모두 가지는 카드는 존재하지 않는다냥. 원하는 카드 하나를 처음 낸 뒤, 직전에 낸 카드와 색이 같거나 값이 같은 카드를 계속 내는 방식으로 모든 카드를 낼 수 있는지 판정하라냥.

## 조건

- $1\le T\le1000$
- $1\le N\le2\times10^5$
- $C_i$는 B, G, R 중 하나이다냥.
- $1\le D_i\le N$
- 모든 테스트 케이스의 $N$의 합은 $2\times10^5$ 이하이다냥.

## 입력

```text
T
N
C_1 D_1
\vdots
C_N D_N
```

## 출력

모든 카드를 낼 수 있으면 `YES`, 없으면 `NO`를 테스트 케이스마다 출력하라냥.
