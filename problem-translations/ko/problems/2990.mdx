## 문제 설명

정수 $N$과 길이 $M$인 정수 쌍의 수열 $(L_1, R_1), (L_2, R_2), \cdots, (L_M, R_M)$이 주어집니다.

모든 정수 $i$ ($1 \leq i \leq M$)에 대해 $0 \leq L_i \leq R_i \leq 2^N - 1$이 성립합니다.

각 정수 $x$ ($0 \leq x \leq 2^N - 1$)에 대해 다음 조건을 모두 만족하는 길이 $M$의 정수열 $A$의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

1. $L_i \leq A_i \leq R_i$ ($1 \leq i \leq M$)
2. $A_1 \mathbin{\oplus} A_2 \mathbin{\oplus} \cdots \mathbin{\oplus} A_M = x$

여기서 $\mathbin{\oplus}$는 비트 단위 XOR 연산을 나타냅니다.

### 배경

비트 단위 XOR 연산이란

음이 아닌 정수 $A$, $B$의 비트 단위 XOR $A \mathbin{\oplus} B$를 다음과 같이 정의합니다.

- $A \mathbin{\oplus} B$를 이진 표기로 나타냈을 때 $2^k$ ($k \geq 0$)의 자리의 수는, $A$, $B$를 이진 표기로 나타냈을 때 $2^k$의 자리의 수 중 정확히 $1$개만 $1$이면 $1$이고, 그렇지 않으면 $0$입니다.

예를 들어 $3 \mathbin{\oplus} 5 = 6$입니다(이진 표기로 나타내면 $011 \mathbin{\oplus} 101 = 110$).

일반적으로 $k$개의 음이 아닌 정수 $p_1, p_2, p_3, \dots, p_k$의 비트 단위 XOR은 $(\cdots ((p_1 \mathbin{\oplus} p_2) \mathbin{\oplus} p_3) \mathbin{\oplus} \cdots \mathbin{\oplus} p_k)$로 정의합니다. 이는 $p_1, p_2, p_3, \dots, p_k$의 순서와 관계없이 같다는 것이 증명되어 있습니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ M$
$L_1\ R_1$
$\vdots$
$L_M\ R_M$
```

## 제한

- $0 \leq N \leq 20$
- $1 \leq M \leq 2 \times 10^5$
- $0 \leq L_i \leq R_i \leq 2^N - 1$ ($1 \leq i \leq M$)
- 입력은 모두 정수입니다.

## 출력

$2^N$줄 출력하세요.

$i+1$번째 줄 ($0 \leq i \leq 2^N - 1$)에는 $x=i$일 때의 답을 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 2
1 2
0 2
```

#### 출력

```text
2
1
1
2
```

$x = 0$일 때 조건을 만족하는 수열 $A$는 $(1, 1)$, $(2, 2)$의 $2$개입니다.

$x = 1$일 때 조건을 만족하는 수열 $A$는 $(1, 0)$의 $1$개입니다.

$x = 2$일 때 조건을 만족하는 수열 $A$는 $(2, 0)$의 $1$개입니다.

$x = 3$일 때 조건을 만족하는 수열 $A$는 $(1, 2)$, $(2, 1)$의 $2$개입니다.
