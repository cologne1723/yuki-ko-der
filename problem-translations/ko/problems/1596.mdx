## 문제

$(0,0)$에서 $(N,N)$으로 이동합니다. 아래 또는 오른쪽 이동은 기본적으로 1원을 냅니다.

$M$개의 지정된 이동은 무료이며, 무료 이동에는 돈을 내는 이동을 사용할 수 없습니다. 가능한 모든 이동 방법에 대해 이동 비용을 더한 값을 $10^9+7$로 나눈 나머지를 구하세요.

## 입력

$N,M$과 무료 이동 $(t_i,x_i,y_i)$가 주어집니다. $t_i=1$이면 아래 이동, $t_i=2$이면 오른쪽 이동입니다.

## 출력

모든 경로의 이동 비용 합을 출력하세요.
