## 문제

문자열 $S$를 적절히 재배열해 `kyoprotenkei90`을 만들 수 있는지 판정하세요.

## 입력

영소문자 또는 숫자로 이루어진 길이 14의 문자열 $S$가 주어집니다.

## 출력

가능하면 `Yes`, 불가능하면 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
90kyoprotenkei
```

#### 출력

```text
Yes
```

### 예제 2 {file=""}

#### 입력

```text
tenkei90mondai
```

#### 출력

```text
No
```

### 예제 3 {file=""}

#### 입력

```text
cospleermusora
```

#### 출력

```text
No
```
