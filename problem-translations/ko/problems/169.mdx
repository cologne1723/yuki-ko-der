## 이야기

ゆきこちゃん은 큰 파일을 복사하려고 합니다. 복사에 시간이 걸리므로 잠시 후 확인해 보니 “$K$% 완료되었습니다. 앞으로 $S$분 걸립니다.”라고 표시되어 있었습니다.

ゆきこちゃん은 파일 복사에 전체 몇 분이 걸리는지 알고 싶지만 계산을 잘하지 못합니다.

## 문제 설명

ゆきこちゃん 대신 전체 처리 시간(분)을 구하세요.

시간당 복사 속도는 일정하다고 가정합니다. 화면에 표시된 완료율은 소수도 표시되지만, 정확히 정수가 된 시점이라고 가정해도 됩니다.

## 입력

```text
$K$
$S$
```

입력은 모두 정수입니다. $K$의 단위는 퍼센트입니다.

## 제한
- $1 \le K \le 99$
- $1 \le S \le 1\,000\,000=10^6$

## 출력

처리에 걸리는 시간을 출력하세요. 소수점 이하는 버리고 정수 부분만 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
50
30
```

#### 출력

```text
60
```

$50$%가 지났다는 것은 정확히 절반이므로 전체 시간은 남은 시간의 $2$배인 $60$분입니다.

### 예제 2 {file=""}

#### 입력

```text
99
1000
```

#### 출력

```text
100000
```
