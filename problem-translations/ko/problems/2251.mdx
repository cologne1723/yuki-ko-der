각 칸에 정수가 적힌 $H\times W$ 격자에서 하나 이상의 칸을 선택해 표시한다냥. 모든 2x2 영역에서 표시된 칸 수가 짝수인 표시 방법을 좋은 방법이라 하자냥. 좋은 방법들의 점수(표시된 칸의 정댓값) 합을 구하라냥.

## 조건

- $2\le H,W\le1000$
- $1\le A_{i,j}\le998244352$

## 입력

```text
H W
A_{1,1} \cdots A_{1,W}
\vdots
A_{H,1} \cdots A_{H,W}
```

## 출력

점수 합을 $998244353$으로 나눈 나머지를 출력하라냥.
