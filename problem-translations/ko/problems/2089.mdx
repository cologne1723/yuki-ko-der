정수 $N\ge2$와 $N$차 순열 $A$가 주어집니다. 순열 $A$의 부호를 구하세요.

<details>
<summary>순열과 그 부호를 모르는 사람을 위한 설명 (클릭하면 열립니다)</summary>

양의 정수 $n$에 대해, $n$차 순열은 대략 $n$ 이하의 양의 정수를 섞는 함수입니다. 정확히는 다음과 같이 정의합니다.

**정의 (순열)**

$n$ 이하의 양의 정수 전체의 집합을 $I_n$이라 둡니다. $n$차 순열은 $I_n$에서 $I_n$으로 가는 전단사 함수입니다.

$n\ge2$이고 $a$가 $n$차 순열일 때, $a$가 전치라는 것은 대략 $a$가 정확히 두 수를 서로 바꾼다는 뜻입니다. 정확히는 다음 조건을 만족하는 $n$ 이하의 양의 정수 $i,j$가 존재한다는 뜻입니다.

1. $i\ne j$이다.
2. $a(i)=j$이다.
3. $a(j)=i$이다.
4. $n$ 이하의 임의의 양의 정수 $k$에 대해 $k\ne i$이고 $k\ne j$이면 $a(k)=k$이다.

$a$의 부호는 정수 $\operatorname{sgn}(a)$로 쓰며 다음과 같이 정의합니다.

1. $a$가 짝수 개의 전치의 합성으로 표현되면 $\operatorname{sgn}(a)=1$이다.
2. $a$가 짝수 개의 전치의 합성으로 표현되지 않으면 $\operatorname{sgn}(a)=-1$이다.

단, $0$은 짝수이며, 전치 $0$개의 합성은 항등 순열로 정의합니다.

</details>

## 입력

```text
N
A_1 A_2 ... A_N
```

## 출력

순열의 부호를 출력하세요.
