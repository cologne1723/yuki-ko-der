## 문제 설명

타로는 난해한 프로그래밍 언어인 Whitespace로 프로그램을 만드는 데 열중하고 있습니다. Whitespace는 공백, 탭, 줄 바꿈만 문법에 사용하고 나머지는 무시합니다.

타로는 소스 코드의 아름다움에 신경 쓰며, 모든 줄의 너비가 같을 때 소스 코드가 “완벽하다”고 부릅니다. 타로는 자신이 작성한 Whitespace 소스 코드에 전각 공백을 삽입하여 완벽하게 만들려고 합니다.

한 줄의 일반 공백 수를 $a$, 탭 수를 $b$, 전각 공백 수를 $c$라고 할 때 줄의 너비는 $a+4b+2c$입니다. 일반적인 편집기와 달리 탭의 위치는 너비에 영향을 주지 않습니다. 필요한 전각 공백 수의 최솟값을 구하세요.

## 입력

```text
N
a_1 b_1
:
a_N b_N
```

- $2 \le N \le 1000$
- $0 \le a_i,b_i \le 10^7$
- 소스 코드에는 공백·탭·줄 바꿈 이외의 문자가 없습니다.

## 출력

소스 코드를 완벽하게 만들 수 있으면 필요한 전각 공백 수의 최솟값을 출력하세요. 만들 수 없으면 $-1$을 출력하세요.

## 예제

### 예제 1 {file=""}

```text
2
1 1
3 0
```

```text
1
```

첫째 줄의 너비는 5, 둘째 줄의 너비는 3입니다. 둘째 줄에 전각 공백 하나를 추가하면 모두 너비 5가 됩니다.

### 예제 2 {file=""}

```text
4
0 0
0 0
0 0
0 0
```

```text
0
```

처음부터 모든 줄의 너비가 0입니다.

### 예제 3 {file=""}

```text
2
0 0
1 0
```

```text
-1
```

전각 공백을 추가해도 두 너비를 같게 만들 수 없습니다.

### 예제 4 {file=""}

```text
4
30 0
20 10
10 20
0 30
```

```text
90
```
