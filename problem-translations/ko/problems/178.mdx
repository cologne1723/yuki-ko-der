## 이야기

太郎君은 난해한 프로그래밍 언어인 Whitespace로 프로그램을 만드는 데 열중하고 있습니다. Whitespace는 공백, 탭, 줄 바꿈만 문법에 사용하고 나머지는 무시합니다.

## 문제 설명

太郎君은 소스 코드의 아름다움에 신경 쓰며, 모든 줄의 너비가 같을 때 소스 코드가 “완벽하다”고 부릅니다. 太郎君은 자신이 작성한 Whitespace 소스 코드에 전각 공백을 삽입하여 완벽하게 만들려고 합니다.

$1$줄의 일반 공백 수를 $a$, 탭 수를 $b$, 전각 공백 수를 $c$라고 할 때 줄의 너비는 $a+4b+2c$입니다. 일반적인 편집기와 달리 탭의 위치는 너비에 영향을 주지 않습니다. 필요한 전각 공백 수의 최솟값을 구하세요.

## 입력

```text
$N$
$a_1\ b_1$
$\vdots$
$a_N\ b_N$
```

$1$번째 줄에 太郎君이 완벽하게 만들고 싶은 소스 코드의 줄 수 $N$이 주어집니다. 이어지는 $N$줄은 소스 코드의 각 줄에 대한 정보입니다. $a_i$, $b_i$는 소스 코드의 $i$번째 줄에 있는 일반 공백과 탭의 개수입니다.

## 제한

- $2 \le N \le 1\,000$
- $0 \le a_i,b_i \le 10^7$
- 소스 코드에는 공백·탭·줄 바꿈 이외의 문자가 없습니다.
- 소스 코드가 Whitespace 문법에 맞는다고 보장되지는 않습니다.

## 출력

소스 코드를 완벽하게 만들 수 있으면 필요한 전각 공백 수의 최솟값을 출력하세요. 만들 수 없으면 $-1$을 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
1 1
3 0
```

#### 출력

```text
1
```

$1$번째 줄은 일반 공백이 $1$개, 탭이 $1$개이므로 너비가 $1+1\times4=5$입니다. $2$번째 줄은 일반 공백이 $3$개, 탭이 $0$개이므로 너비가 $3+0\times4=3$입니다. 그대로는 완벽하지 않지만 $2$번째 줄에 전각 공백 $1$개를 추가하면 모든 줄의 너비가 $5$가 되어 완벽해지므로 $1$을 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
4
0 0
0 0
0 0
0 0
```

#### 출력

```text
0
```

처음부터 모든 줄의 너비가 $0$으로 이미 완벽합니다. 전각 공백을 추가할 필요가 없으므로 $0$을 출력합니다.

### 예제 3 {file=""}

#### 입력

```text
2
0 0
1 0
```

#### 출력

```text
-1
```

$1$번째 줄의 너비는 $0$이고 $2$번째 줄의 너비는 $1$입니다. 전각 공백을 어떻게 추가해도 완벽하게 만들 수 없으므로 $-1$을 출력합니다.

### 예제 4 {file=""}

#### 입력

```text
4
30 0
20 10
10 20
0 30
```

#### 출력

```text
90
```
