길이 $M+1$의 수열에서 정확히 하나의 원소만 다른 값이고 나머지 $M$개가 같은 수열을 검은 수열이라 합니다. 각 원소를 1씩 증감해 검은 수열로 만드는 최소 조작 횟수를, 정점 0에서 각 정점까지의 경로에 있는 값 수열에 대해 구하세요.

## 조건

- $1\le N\le2\times10^5$
- $0\le A_i\le10^9$
- 입력 그래프는 정점 0부터 $N$까지의 트리입니다.

## 입력

```text
$N$ $A_0$ $\cdots$ $A_N$
$u_1$ $v_1$
\vdots
$u_N$ $v_N$
```

## 출력

각 정점까지의 거리가 2 이상이면 해당 최소 조작 횟수를, 아니면 `-1`을 출력하세요.
