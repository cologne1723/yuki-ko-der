**선택하는 프로그래밍 언어에 따라서는 이 문제를 풀기 어려울 수 있습니다.**

**특히 C++이나 PHP로는 이 문제를 풀 수 없을지도 모릅니다.**

평소 사용하는 언어로 정답을 얻을 수 없는 경우에는 번거로우시겠지만 다른 언어의 사용도 검토해 주세요.

출제자는 C 언어, C#, Python, Ruby 등으로 이 문제를 풀 수 있음을 확인했습니다.

## 이야기

太郎君은 $2$개의 자연수로 이루어진 쌍 $(a_i, b_i)\:(i = 0, 1, \cdots, N - 1)$을 $N$개 가지고 있습니다.

太郎君은 각 쌍 $(a_i, b_i)$에 대해 $a_i$와 $b_i$의 대소를 비교하는 프로그램을 작성하려고 했습니다.

그런데 대체 무슨 일이 있었을까요? 아무리 해도 컴퓨터에 `<`와 `>`를 입력할 수 없습니다.

## 문제 설명

곤경에 처한 太郎君을 대신하여 위 프로그램을 작성하세요.

물론 제출하는 소스 코드에는 **`<` 및 `>`가 각각 $1$글자도 포함되어서는 안 됩니다.**

## 입력

입력은 총 $(N + 1)$개의 줄로 주어집니다.

제$0$번째 줄에는 자연수 $N$이 주어집니다.

제$(i + 1)$번째 줄$(i = 0, 1, \cdots, N - 1)$에는 자연수인 $a_i$와 $b_i$가 공백으로 구분되어 주어집니다.

여기서 $i\ne j$이면 $(a_i, b_i) \ne (a_j, b_j)$가 성립합니다.

```text
$N$
$a_0\ b_0$
$a_1\ b_1$
$\vdots$
$a_i\ b_i$
$\vdots$
$a_{N-1}\ b_{N-1}$
```

## 제한

- $N$은 자연수입니다.
- $1\le N\le 100$입니다.
- $a_i$와 $b_i$는 자연수이고, $1\le a_i \le 10^8$, $1\le b_i \le 10^8$입니다.
- $i\ne j$이면 $(a_i, b_i) \ne (a_j, b_j)$입니다.

## 출력

출력은 총 $N$개의 줄로 이루어집니다.

제$i$번째 줄$(i = 0, 1, \cdots, N - 1)$에는 다음과 같이 정해지는 문자열 $S_i$를 출력하세요.

```text
$S_0$
$S_1$
$\vdots$
$S_i$
$\vdots$
$S_{N - 1}$
```

- $a_i \gt b_i$이면 $S_i$는 `>`입니다.
- $a_i = b_i$이면 $S_i$는 `=`입니다.
- $a_i \lt b_i$이면 $S_i$는 `<`입니다.

마지막에는 줄바꿈을 출력하세요.

단, **소스 코드에 `<` 및 `>` 중 $1$개 이상이 $1$글자라도 포함되어 있으면 출력 내용과 관계없이 오답**입니다.

**출력에는** `<` 및 `>`를 포함해도 되지만, **소스 코드에는** 이 기호들을 포함해서는 안 된다는 점에 주의하세요.
