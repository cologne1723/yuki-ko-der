## 문제

1차원 수직선 위에 `N+M`개의 비구름이 있습니다. 처음 `N`개는 보통 비구름이고, 나머지 `M`개는 희귀 비구름입니다. 시각 0에서 `i`번째 비구름은 닫힌 구간 `[L_i, R_i]`에 있습니다.

보통 비구름은 속도 1로 양의 방향으로 이동하여 시각 `t`에 `[L_i+t, R_i+t]`에 있습니다. 희귀 비구름은 속도 1로 음의 방향으로 이동하여 `[L_i-t, R_i-t]`에 있습니다.

수직선 위에는 `P_1 < P_2 < ... < P_K`에 집이 있습니다. 각 위치에 대해, 그 위치가 두 개 이상의 비구름에 덮이는 시각이 존재하는지 판정하세요. 시각은 음수일 수도 있습니다.

## 제약

- `1 ≤ N ≤ 10^5`, `1 ≤ M ≤ 10^3`
- `-10^9 ≤ L_i ≤ R_i ≤ 10^9`
- `1 ≤ K ≤ 10^3`
- `-10^9 ≤ P_i ≤ 10^9`, `P_i < P_{i+1}`

## 입력

```text
N M
L_1 R_1
⋮
L_{N+M} R_{N+M}
K
P_1 P_2 ... P_K
```

## 출력

각 위치에 대해 조건을 만족하면 `1`, 만족하지 않으면 `0`을 공백으로 구분해 출력하세요.
