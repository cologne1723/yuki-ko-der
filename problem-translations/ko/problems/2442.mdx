길이 $2^N$인 수열 $A$가 주어집니다. 각 원소는 $2^{64}$ 미만의 음이 아닌 정수입니다. 모든 $0\le i,j<2^N$에 대해

$$A_{i\mathbin{\mathrm{XOR}}j}=A_i\mathbin{\mathrm{XOR}}A_j$$

를 만족하면 좋은 수열입니다. 좋은 수열인지 판정하세요.

## 조건

<details>
<summary>비트 단위 XOR를 모르는 사람을 위한 설명</summary>

$i\mathbin{\mathrm{XOR}}j$는 다음 조건을 만족하는 유일한 음이 아닌 정수 $k$입니다.

- 임의의 음이 아닌 정수 $d$에 대해 다음이 성립합니다.
  - $i$와 $j$의 $2$진법 표기에서 $2^d$ 자리 숫자가 같으면, $k$의 해당 자리 숫자는 $0$입니다.
  - $i$와 $j$의 $2$진법 표기에서 $2^d$ 자리 숫자가 다르면, $k$의 해당 자리 숫자는 $1$입니다.

단, 음이 아닌 정수 $n$의 $2^d$ 자리 숫자는 $n$을 $2^d$로 나눈 몫을 다시 $2$로 나눈 나머지를 뜻합니다.

</details>

- $N$은 문제의 제한을 만족하는 음이 아닌 정수입니다.
- 수열의 길이는 $2^N$입니다.

## 입력

```text
N
A0 A1 ... A(2^N-1)
```

## 출력

좋은 수열이면 `Yes`, 아니면 `No`를 출력하세요.
