## 문제 설명

소수 $p$와 정수 $a_1, a_2, \ldots, a_n$, $k$, $b$가 주어집니다. $a_1x_1^k+a_2x_2^k+\cdots+a_nx_n^k$를 $p$로 나눈 나머지가 $b$가 되도록 하는 $0$ 이상 $p-1$ 이하의 정수 순서 있는 튜플 $(x_1, x_2, \ldots, x_n)$은 몇 개인지 구하세요. 답은 커질 수 있으므로, $10^9+7$로 나눈 나머지를 구하세요.

## 입력

```text
$p\ n\ k\ b$
$a_1\ a_2\ \ldots\ a_n$
```

## 제한

- $2 \le p \le 10^5$
- $p$는 소수입니다.
- $1 \le n \le 500$
- $1 \le k \le 10^5$
- $0 \le b \le p-1$
- $0 \le a_i \le p-1$
- 입력은 모두 정수입니다.

## 출력

조건을 만족하는 정수 순서쌍의 개수를 $10^9+7$로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 3 2 2
1 1 2
```

#### 출력

```text
6
```

$x_1^2+x_2^2+2x_3^2$를 $3$으로 나눈 나머지가 $2$가 되도록 하는 $0$ 이상 $2$ 이하의 정수 순서 있는 튜플 $(x_1, x_2, x_3)$은 $(0, 0, 1)$, $(0, 0, 2)$, $(1, 1, 0)$, $(1, 2, 0)$, $(2, 1, 0)$, $(2, 2, 0)$의 $6$가지입니다.

### 예제 2 {file=""}

#### 입력

```text
7 5 3 6
3 1 4 1 5
```

#### 출력

```text
2373
```

### 예제 3 {file=""}

#### 입력

```text
10007 1 314 159
0
```

#### 출력

```text
0
```
