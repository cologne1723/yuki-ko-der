## 문제 설명

ポケットモンスター에서 ダルマッカ의 전국도감 번호는 $554$이며, $4$와 $5$로만 이루어져 있습니다.

이처럼 $4$와 $5$로만 이루어진 양의 정수를 좋은 수라고 정의합니다.

$N$ 이하인 좋은 수 중 가장 큰 것을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

## 제한

- $4 \leq N < 10^{100\,000}$
- 입력은 모두 정수입니다.

## 출력

답을 $1$줄에 출력하세요.

## 예제

### 예제 1 {file="01_sample_01"}

#### 입력

```text
52
```

#### 출력

```text
45
```

좋은 수는 작은 순서대로 $4$, $5$, $44$, $45$, $54$, $\cdots$이므로, $52$ 이하에서 가장 큰 $45$를 출력합니다.

### 예제 2 {file="01_sample_02"}

#### 입력

```text
554
```

#### 출력

```text
554
```

### 예제 3 {file="01_sample_03"}

#### 입력

```text
12345678901234567890
```

#### 출력

```text
5555555555555555555
```

입력은 $64$비트 정수로 표현할 수 없을 수 있음에 주의하세요.
