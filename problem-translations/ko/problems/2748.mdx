## 문제

`T3,T4,T6`은 각각 `N`자리 3진수, 4진수, 6진수를 표시하는 타이머입니다. 시작 후 매초 표시값이 1씩 증가하고, 표시 가능한 최댓값 다음 초에는 0으로 돌아갑니다.

시작 시 세 표시가 모두 같지는 않았습니다. 시작 후 `M`초 뒤 처음으로 세 표시가 모두 같아졌을 때, 가능한 시작 표시 상태의 수를 구하세요.

## 제약

- `1 ≤ N ≤ 15`
- `1 ≤ M ≤ 10^18`

## 입력

```text
N M
```

## 출력

가능한 상태 수를 출력하세요.
