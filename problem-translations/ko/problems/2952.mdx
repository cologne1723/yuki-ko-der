## 문제 설명

양의 정수 $N$, $M$과 양의 정수열 $D=(D_1,D_2,\dots,D_N)$이 주어집니다.

다음 조건을 만족하는 모든 양의 정수열 $A=(A_1,A_2,\dots,A_N)$에 대한 역전수의 총합을 $998\,244\,353$으로 나눈 나머지를 구하세요.

- $1 \leq A_i \leq M$ $(1 \leq i \leq N)$
- 각 $i$ $(1 \leq i \leq N)$에 대해 $A_i$는 $D_i$의 배수입니다.

수열 $X=(X_1,X_2,\dots,X_{|X|})$의 역전수란 $1 \leq i < j \leq |X|$이면서 $X_i > X_j$를 만족하는 정수 쌍 $(i,j)$의 개수입니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ M$
$D_1\ D_2\ \dots\ D_N$
```

$1$번째 줄에 정수 $N$, $M$이 공백으로 구분되어 주어집니다. $N$은 수열의 길이이고, $M$은 각 원소의 값에 대한 상한입니다.

$2$번째 줄에 양의 정수 $D_1,D_2,\dots,D_N$이 공백으로 구분되어 주어집니다.

## 제한

- $2 \leq N \leq 5\times 10^4$
- $1 \leq M \leq 5\times 10^4$
- $1 \leq D_i \leq M$ $(1 \leq i \leq N)$
- 입력은 모두 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4 7
3 2 5 4
```

#### 출력

```text
19
```

조건을 만족하는 $A$는 다음 $6$가지입니다.

- $A=(3,2,5,4)$일 때 역전수는 $2$입니다.
- $A=(3,4,5,4)$일 때 역전수는 $1$입니다.
- $A=(3,6,5,4)$일 때 역전수는 $3$입니다.
- $A=(6,2,5,4)$일 때 역전수는 $4$입니다.
- $A=(6,4,5,4)$일 때 역전수는 $4$입니다.
- $A=(6,6,5,4)$일 때 역전수는 $5$입니다.

따라서 답은 $2+1+3+4+4+5=19$입니다.
