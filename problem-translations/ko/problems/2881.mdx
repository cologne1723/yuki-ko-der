## 문제 설명

양의 정수 $N$이 주어집니다.

$1 \le i \le N$을 만족하는 각 정수 $i$에 대해 함수 $f_i(x) = (x \times 2^i + 1) \bmod 2^N$을 정의합니다.

음이 아닌 정수 $X$, $Y$가 주어집니다. $(0 \le X, Y < 2^N)$

길이 $K$인 수열 $A = (A_1, A_2, \ldots, A_K)$ $(0 \le K \le 10^6)$ 중 $1 \le A_i \le N$ $(1 \le i \le K)$를 만족하면서 다음 조건을 만족하는 것이 존재하는지 판정하고, 존재한다면 그러한 $K$, $A$를 출력하세요.

- $i = 1, 2, \ldots, K$에 대해 $X$를 $f_{A_i}(X)$로 갱신하는 연산을 수행합니다.

이 연산을 $K$번 수행한 뒤 $X = Y$가 되어야 합니다.

자세한 출력 형식은 출력 절을 참고하세요.

## 입력

```text
$N\ X\ Y$
```

$N$은 양의 정수이고, $X$, $Y$는 음이 아닌 정수입니다. 입력은 모두 정수입니다.

## 제한

- $1 \le N \le 60$
- $0 \le X, Y < 2^N$
- 입력은 모두 정수입니다.
- $K$는 입력으로 주어지지 않습니다.

## 출력

문제 설명에서 설명한 $K$, $A$가 존재하지 않는 경우 `-1`을 출력하세요.

존재하는 경우, $0 \le K \le 10^6$ 및 $1 \le A_i \le N$을 만족하도록 $K$, $A$를 다음 형식으로 출력하고 마지막에 줄바꿈하세요.

```text
$K$
$A_1\ A_2\ \ldots\ A_K$
```

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 3 11
```

#### 출력

```text
2
2 1
```

$X = 3$을 $f_2(3) = (3 \times 2^2 + 1) \bmod 2^4 = 13$으로 갱신합니다.

$X = 13$을 $f_1(13) = (13 \times 2^1 + 1) \bmod 2^4 = 11$로 갱신합니다.

$X = Y = 11$이 되었으므로 정답입니다.

### 예제 2 {file=""}

#### 입력

```text
6 4 1
```

#### 출력

```text
1
6
```

$X = 4$를 $f_6(4) = (4 \times 2^6 + 1) \bmod 2^6 = 1$로 갱신합니다.

$X = Y = 1$이 되었으므로 정답입니다.

$A_i > N$인 출력은 잘못된 출력이지만, $A_i = N$인 출력은 허용됩니다.

### 예제 3 {file=""}

#### 입력

```text
1 1 0
```

#### 출력

```text
-1
```

$X = Y$로 만드는 방법은 없습니다.

### 예제 4 {file=""}

#### 입력

```text
5 3 3
```

#### 출력

```text
0

```

연산을 수행하지 않는 것도 허용됩니다.
