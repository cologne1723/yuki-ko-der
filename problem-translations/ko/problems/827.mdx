## 문제

정점 1부터 $N$으로 이루어진 루트 트리 $T$가 있고 루트는 1입니다. 각 정점에 1부터 $N$까지의 값을 중복 없이 써서 값 배열이 순열이 되게 합니다.

정점 $i$의 값이 자신을 제외한 모든 조상 값보다 크면 그 정점을 신동이라고 합니다. 루트는 항상 신동입니다. 신동인 정점 수를 신동 수라고 합니다.

모든 $N!$가지 값 배치에 대해 신동 수의 합을 구해 $10^9+7$로 나눈 나머지를 출력하세요.

## 입력

~~~text
$N$
$u_1\ v_1$
$\vdots$
$u_{N-1}\ v_{N-1}$
~~~

$1\leq N\leq2\times10^5$이고 입력 그래프는 $N$개 정점의 트리입니다.

## 출력

모든 값 배치에서의 신동 수 합을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
2
1 2
~~~

#### 출력

~~~text
3
~~~

두 값 배치에서 신동 수를 합하면 3입니다.
