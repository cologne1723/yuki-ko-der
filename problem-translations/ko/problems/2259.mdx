$L$리터 이상 $R$리터 이하의 정수만큼 주유하고, 리터당 $C$엔을 낸다냥. 1000엔 지폐만 사용해 지불할 때 가능한 거스름돈의 최솟값을 구하라냥.

## 입력

```text
L R C
```

## 출력

가능한 거스름돈의 최솟값을 출력하라냥.
