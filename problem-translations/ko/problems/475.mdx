## 참고

메리 크리스마스♪

오늘은 Advent Calendar Contest의 마지막 날입니다.

실제로 문제에서 설명하는 방식으로 순위를 정하지는 않습니다.

## 문제

나는 Advent Calendar Contest의 마지막 날을 담당하게 되었습니다. 하지만 크리스마스를 너무 즐긴 나머지 문제를 생각하는 것을 잊었고, 정신을 차려 보니 출제 시각이 되어 있었습니다.

그래서 마지막 날에는 문제를 출제하지 않고 무작위로 순위를 정하기로 했습니다.

즉 아직 AC되지 않은 참가자(Writer 제외) 중 한 명을 무작위로 골라 그 참가자를 AC로 처리하는 절차를 모든 사람이 AC될 때까지 반복하여 순위를 정하는 무모한 일을 저질렀습니다. Tester는 없다고 합니다.

마지막 날 문제의 별 개수가 $S$개이고 그 문제에서의 순위가 $R$위라면 $\left\lfloor50S+\frac{50S}{0.8+0.2R}\right\rfloor$점을 받습니다.

Writer에게는 조건 없이 $100S$점을 줍니다.

각 대회 참가자의 전날까지 점수와 마지막 날 문제의 별 개수가 주어질 때, 나(Writer)가 우승할 확률을 구하세요.

우승이란 마지막 날 점수와 전날까지의 총점을 더한 최종 점수가 참가자 중 가장 높은 것을 말합니다. 최고 점수가 동점인 경우도 우승으로 봅니다.

## 입력

```text
$N\ S\ writer\_id$
$a_0\ a_1\ a_2\ a_3\ \cdots\ a_{N-1}$
```

입력은 모두 정수입니다.

$N$은 참가자 수, $S$는 별 개수입니다. 각 참가자에게는 0부터 시작하는 id $0,1,\ldots,N-1$이 부여됩니다.

$a_i$는 id $i$인 참가자의 전날까지 총점이며, `writer_id`는 Writer(나)의 id입니다.

$3\leq N\leq77777$

$1\leq S\leq500000$

$0\leq a_i\leq100000000$

## 출력

내가 우승할 확률을 한 줄에 출력하세요.

절대 오차 또는 상대 오차가 $10^{-9}$ 이하이면 허용됩니다.

마지막에 줄바꿈을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3 3 0
1 0 2
```

출력:

```text
0.5
```

마지막 날 문제는 별 3개이므로 순위가 높은 순서대로 300점, 275점을 받습니다.

Writer는 $1+300=301$점입니다. id 1 참가자가 1위, id 2 참가자가 2위이면 내가 우승할 수 있습니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
3 3 0
2 2 2
```

출력:

```text
1.0
```

Writer는 300점을 받지만, 나머지 두 사람 중 누가 마지막 날 1위가 되더라도 Writer가 우승합니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
20 3 5
6834 6368 6098 5975 5962 5516 5453 5102 4866 4692 4679 4652 4650 4481 4324 4181 4150 3934 3784 3628
```

출력:

```text
0.0
```

이 데이터는 12월 24일 오후 9시 시점의 실제 상위 20명 데이터이며, `writer_id`에는 나를 지정했습니다. 이 규칙에서도 내가 우승할 확률은 0.0이라고 합니다. 아이고……
