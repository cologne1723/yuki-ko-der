## 문제 설명

ループさん은 $0$ 또는 $1$로 이루어진 길이 $2$의 수열 $A=(A_1,A_2)$를 숨겨 가지고 있습니다. **이 $A$는 입력으로 주어지지 않는다는 점에 유의하세요.**

$A$에 대해 다음 연산을 정확히 $Q$회 반복합니다. 여기서 $n$은 각 연산 직전의 $A$의 길이입니다.

- $1\leq i<j\leq n$을 만족하는 정수의 순서쌍 $(i,j)$를 선택하고, $A_i\mathbin{\overline{\land}}A_j$를 $A$의 끝에 추가합니다.

여기서 부정 논리곱 $\overline{\land}$은 다음을 만족하는 이항 연산으로 정의됩니다.

- $0\mathbin{\overline{\land}}0=1$, $0\mathbin{\overline{\land}}1=1$, $1\mathbin{\overline{\land}}0=1$
- $1\mathbin{\overline{\land}}1=0$

ループさん이 숨겨 가지고 있는 $A$가 무엇이더라도, 연산 후의 $A$의 합이 $K$ 이하가 되도록 하는 연산이 존재하는지 판정하세요.

존재한다면 그러한 연산열을 $1$개 제시하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$Q\ K$
```

$Q$와 $K$가 주어집니다.

## 제한

- $1\leq Q\leq 2\times 10^5$
- $2\leq K\leq Q+2$
- $Q$와 $K$는 정수입니다.

## 출력

문제의 조건을 만족하는 연산이 존재한다면 `Yes`를, 존재하지 않는다면 `No`를 출력하세요.

또한 `Yes`인 경우에는 개행한 뒤 다음 형식으로 연산을 출력하세요.

```text
$i_1\ j_1$
$i_2\ j_2$
$\vdots$
$i_Q\ j_Q$
```

여기서 $i_k,j_k$는 $k$번째 연산($1\leq k\leq Q$)에서 선택하는 $i,j$를 나타냅니다.

정답이 여러 개 존재하는 경우, 그중 어느 것을 출력해도 정답으로 판정됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 3
```

#### 출력

```text
Yes
1 2
2 3
1 4
```

예를 들어 ループさん이 $A=(1,0)$을 숨겨 가지고 있었다면, 다음과 같이 연산이 진행됩니다.

- $(i,j)=(1,2)$를 선택합니다. $1\mathbin{\overline{\land}}0=1$이므로 $A$는 $(1,0,1)$로 갱신됩니다.
- $(i,j)=(2,3)$을 선택합니다. $0\mathbin{\overline{\land}}1=1$이므로 $A$는 $(1,0,1,1)$로 갱신됩니다.
- $(i,j)=(1,4)$를 선택합니다. $1\mathbin{\overline{\land}}1=0$이므로 $A$는 $(1,0,1,1,0)$으로 갱신됩니다.

이때 $A$의 합은 $3$이고 $K=3$ 이하입니다. 이는 ループさん이 처음에 어떤 $A$를 숨겨 가지고 있었더라도 성립함을 보일 수 있습니다.

### 예제 2 {file=""}

#### 입력

```text
4 2
```

#### 출력

```text
No
```

$Q=4$, $K=2$일 때 조건을 만족하는 연산은 존재하지 않습니다.
