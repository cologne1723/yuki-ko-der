## 문제 설명

다음 조건을 모두 만족하는 문자열 $S$가 존재하는지 판정하세요.

- $S$는 영소문자로 이루어진 길이 $N$인 문자열입니다.
- $S$를 $P$개 이어 붙인 문자열을 $T$라고 합니다. 이때 $T$는 시작 위치가 서로 다른 연속 부분 문자열로서 `hello`를 정확히 $K$개 포함해야 합니다.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $\mathrm{case}_i\ (1\leq i\leq T)$는 $i$번째 테스트 케이스를 나타냅니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ P\ K$
```

## 제한

- 입력은 모두 정수입니다.
- $1\leq T\leq 10^3$
- $1\leq N\leq 10^8$
- $1\leq P\leq 10^8$
- $0\leq K\leq NP$

## 출력

$T$줄에 걸쳐 출력합니다. $i$번째 줄에는 $i$번째 테스트 케이스에서 조건을 만족하는 문자열 $S$가 존재하면 `Yes`를, 존재하지 않으면 `No`를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
7 3 3
1 5 1
10 5 3
100 100 1000
```

#### 출력

```text
Yes
No
No
Yes
```

$1$번째 테스트 케이스에서 예를 들어 $S$가 `helloab`라면 $T$는 `helloabhelloabhelloab`가 됩니다. $T$에는 연속 부분 문자열로서 `hello`가 정확히 $3$개 있으므로 조건을 만족합니다.

$2$번째 테스트 케이스에서 조건을 만족하는 문자열 $S$는 존재하지 않습니다. 예를 들어 $S$가 `a`라면 $T$는 `aaaaa`가 되지만, $T$에는 연속 부분 문자열로서 `hello`가 없습니다.
