## 문제 설명

정수 $X,K$가 주어집니다. $X\equiv N^K\pmod{10^9+7}$를 만족하는 정수 $N$을 구하세요. 해가 여러 개면 아무 것이나 출력해도 됩니다.

## 입력

```text
T
X K
\vdots
X K
```

- $1\leq T\leq10^5$
- $0\leq X<10^9+7$
- $1\leq K\leq5\times10^8$
- $K$는 홀수입니다.

## 출력

각 테스트 케이스에 대해 $0\leq N<10^9+7$인 해 $N$을 한 줄에 출력하세요. 항상 존재합니다.
