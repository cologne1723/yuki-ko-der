밑면이 한 변 1인 정`N`각형이고 옆 모서리 길이가 2인 정`N`각기둥 `Γ_N`의 `2N`개 꼭짓점을 두 색으로 칠합니다.

회전에 의해 일치하는 색칠은 같은 것으로 볼 때 가능한 색칠 방법의 수를 구하세요.

## 제약

- `T=1`
- `3 <= N <= 10`
- 색 수 `C=2`

## 입력

`N C`가 주어집니다.

## 출력

회전까지 고려한 서로 다른 색칠 방법의 수를 출력하세요.
