## 문제 설명

$2$개의 정수 $x,y$에 대해 $f(x,y)$를 다음과 같이 정의합니다.

- $x<0$이고 $y<0$이면 $f(x,y)=-x-y$입니다.
- 그렇지 않으면 $f(x,y)=|x-y|$입니다.

길이 $N$인 정수 수열 $A=(A_1,A_2,\dots,A_N)$이 주어집니다. $A$의 원소를 자유롭게 재배열할 수 있을 때, 다음 값의 최솟값을 구하세요.

$\displaystyle \sum_{i=1}^{N-1} f(A_i,A_{i+1})$

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$A_1\ A_2\ \dots\ A_N$
```

## 제한

- 입력은 모두 정수입니다.
- $2\leq N\leq 2\times 10^5$
- $-10^9\leq A_i\leq 10^9$

## 출력

$\displaystyle \sum_{i=1}^{N-1} f(A_i,A_{i+1})$가 가질 수 있는 최솟값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
-1 -3 4
```

#### 출력

```text
9
```

예를 들어 $(4,-1,-3)$의 순서로 재배열하면 최솟값 $9$를 달성할 수 있습니다.

- $f(4,-1)=|4-(-1)|=5$입니다.
- $f(-1,-3)=-(-1)-(-3)=4$입니다.

### 예제 2 {file=""}

#### 입력

```text
6
1 1 0 0 -1 -1
```

#### 출력

```text
4
```

예를 들어 $(-1,-1,0,0,1,1)$의 순서로 재배열하면 최솟값 $4$를 달성할 수 있습니다.

### 예제 3 {file=""}

#### 입력

```text
9
117 96 102 55 -104 -123 -108 79 -131
```

#### 출력

```text
912
```
