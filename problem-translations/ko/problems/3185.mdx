## 문제 설명

길이 $N$인 정수열 $A=(A_1,A_2,\cdots,A_N)$이 주어집니다. 여기서 $N\geq 3$입니다.

$1\leq i<j<N$을 만족하는 $2$개의 정수 $i,j$를 선택합니다.

점수는 $|A_1+A_2+\cdots+A_i|+|A_{i+1}+A_{i+2}+\cdots+A_j|+|A_{j+1}+A_{j+2}+\cdots+A_N|$입니다.

얻을 수 있는 점수의 최댓값을 구하세요.

$T$개의 테스트 케이스가 주어지므로 각각에 대해 답을 구하세요.

## 입력

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

여기서 $\mathrm{case}_i$는 $i$번째 테스트 케이스를 의미하며, 각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$A_1\ \ A_2\ \cdots\ A_N$
```

## 제한

- $1\leq T\leq 10^5$
- $3\leq N\leq 2\times 10^5$
- $-10^9\leq A_i\leq 10^9$
- 입력은 모두 정수입니다.
- $1$개의 입력 파일에서 $N$의 합은 $5\times 10^5$ 이하입니다.

## 출력

각 테스트 케이스에 대한 답을 $1$줄에 출력하고, 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
6
6 5 -4 3 -2 1
3
0 0 0
5
1 1 1 1 1
```

#### 출력

```text
17
0
5
```

- $1$번째 테스트 케이스에서 $i=2,j=3$을 선택하면 점수는 $|6+5|+|-4|+|3+(-2)+1|=17$입니다. $18$ 이상의 점수는 얻을 수 없으므로 답은 $17$입니다.
- $2$번째 테스트 케이스에서 선택할 수 있는 것은 $i=1,j=2$뿐입니다. 이때 점수는 $|0|+|0|+|0|=0$입니다.
- $3$번째 테스트 케이스에서는 $i,j$의 선택과 관계없이 점수는 $5$입니다.
