## 문제 설명

부모의 혈액형에 관한 유전 정보가 `A`, `B`, `O`로 이루어진 길이 $2$의 문자열 $S$, $T$로 주어집니다.

아이의 **혈액형**은 다음 규칙으로 결정됩니다.

$S$와 $T$에서 문자를 각각 $1$개씩 독립적이고 균등하게 무작위로 선택하여 각각 $s$, $t$라고 합니다.

- $\{s,t\}$에 `A`가 포함되고 `B`가 포함되지 않으면 혈액형은 **A형**입니다.
- $\{s,t\}$에 `B`가 포함되고 `A`가 포함되지 않으면 혈액형은 **B형**입니다.
- $\{s,t\}$에 `A`와 `B`가 모두 포함되면 혈액형은 **AB형**입니다.
- 위 어느 경우에도 해당하지 않으면 혈액형은 **O형**입니다.

아이가 각 혈액형이 될 확률을 백분율 [%]로 각각 구하세요. 단, 구해야 하는 답은 모두 정수임이 보장됩니다.

## 입력

입력은 표준 입력에서 다음 형식으로 주어집니다.

```text
$S$
$T$
```

$S$, $T$는 부모의 유전 정보를 나타내는 길이 $2$의 문자열입니다.

## 제한

- $S$와 $T$는 각각 `AA`, `AB`, `AO`, `BB`, `BO`, `OO` 중 $1$개입니다.

## 출력

아이의 혈액형이 A형, B형, AB형, O형이 될 확률을 각각 $P_A$[%], $P_B$[%], $P_{AB}$[%], $P_O$[%]라고 합니다.

다음 형식으로 출력하세요. 구해야 하는 답은 모두 정수임이 보장되므로 정수로 출력하세요.

```text
$P_A\ P_B\ P_{AB}\ P_O$
```

## 예제

### 예제 1 {file=""}

#### 입력

```text
AO
BO
```

#### 출력

```text
25 25 25 25
```

아이의 혈액형을 결정하는 선택 방법은 다음과 같습니다.

- $S$에서 `A`, $T$에서 `B`를 선택합니다. 아이의 혈액형은 AB형입니다.
- $S$에서 `A`, $T$에서 `O`를 선택합니다. 아이의 혈액형은 A형입니다.
- $S$에서 `O`, $T$에서 `B`를 선택합니다. 아이의 혈액형은 B형입니다.
- $S$에서 `O`, $T$에서 `O`를 선택합니다. 아이의 혈액형은 O형입니다.

이 선택 방법들은 같은 확률이므로 A형, B형, AB형, O형이 될 확률은 모두 $25$[%]입니다.

### 예제 2 {file=""}

#### 입력

```text
AB
OO
```

#### 출력

```text
50 50 0 0
```

아이의 혈액형은 A형 또는 B형이 될 확률이 각각 $50$[%]입니다. AB형과 O형이 될 수는 없습니다.

### 예제 3 {file=""}

#### 입력

```text
AO
AB
```

#### 출력

```text
50 25 25 0
```
