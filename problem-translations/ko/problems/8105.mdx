## 문제 설명

길이가 $L$인 수열 $X$의 ‘균등도’를 다음과 같이 정의합니다.

- 수열의 각 원소에 $1$ 또는 $-1$을 곱했을 때 원소들의 합의 절댓값 중 최솟값

예를 들어 $X=(3,11,19)$일 때 $|-3-11+19|=5$이므로 균등도는 $5$입니다.

길이가 $N$인 등차수열 $A$가 주어집니다.

이 수열의 비어 있지 않은 모든 부분수열에 대해 균등도를 구했을 때, 그 균등도의 총합을 구하세요.

답이 클 수 있으므로 $P$로 나눈 나머지를 출력하세요.

## 입력

$1$번째 줄에 테스트 케이스의 수 $T$가 주어집니다.

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ P$
$A_1\ A_2\ \cdots\ A_N$
```

## 제한

- $1\leq T\leq6\,000$
- $1\leq N\leq300$
- $10^8\leq P\leq10^9$
- $1\leq A_i\leq10^9\ (1\leq i\leq N)$
- 모든 테스트 케이스에서 $N$의 합은 $6\,000$ 이하입니다.
- 모든 입력은 소수입니다.

## 출력

각 테스트 케이스에 대한 답을 $1$줄에 $1$개씩 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}
#### 입력
```text
2
3 998244353
3 5 7
7 100000007
192638191 323841571 455044951 586248331 717451711 848655091 979858471
```
#### 출력
```text
24
89473822
```

$1$번째 테스트 케이스에서 각 부분수열의 균등도는 다음과 같습니다.

- $(3)=\min(|3|,|-3|)=3$
- $(5)=\min(|5|,|-5|)=5$
- $(3,5)=\min(|3+5|,|-3+5|,|3-5|,|-3-5|)=2$
- $(7)=\min(|7|,|-7|)=7$
- $(3,7)=\min(|3+7|,|-3+7|,|3-7|,|-3-7|)=4$
- $(5,7)=\min(|5+7|,|-5+7|,|5-7|,|-5-7|)=2$
- $(3,5,7)=\min(|3+5+7|,|-3+5+7|,|3-5+7|,|-3-5+7|,|3+5-7|,|-3+5-7|,|3-5-7|,|-3-5-7|)=1$

따라서 답은 $3+5+2+7+4+2+1=24$입니다.
