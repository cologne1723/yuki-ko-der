## 문제 설명

피보나치 수열 $F_0=F_1=1$, $F_{i+2}=F_{i+1}+F_i$를 정의합니다. 수열에 포함된 수를 피보나치 수라고 합니다.

$N$개의 과일이 있고 $i$번째 과일의 신선도는 $F_{A_i}$입니다. $A_i$는 서로 다른 양의 정수입니다. 하나 이상 $N$개 이하의 과일을 골라 신선도의 합이 피보나치 수가 되도록 하는 선택 방법의 수를 구하세요.

## 입력

문제 설명에 따라 $N$과 서로 다른 양의 정수 수열 $A$가 주어집니다.

## 출력

조건을 만족하는 선택 방법의 수를 출력하세요.
