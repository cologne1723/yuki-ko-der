## 문제 설명

$A \oplus X = B$를 만족하는 유일한 정수 $X$를 출력하세요.

### 배경

$\oplus$는 이진수로 나타냈을 때 각 비트별 XOR을 의미합니다. 예를 들어
$ (7)_{10} \oplus (5)_{10} = (111)_2 \oplus (101)_2 = (010)_2 = (2)_{10}$입니다.

$0$ 또는 $1$ 중 하나인 수 $a$, $b$에 대해 $a \oplus b$는 $a$와 $b$의 값이 다르면 $1$, 그렇지 않으면 $0$으로 정의됩니다.

## 입력

입력은 표준 입력에서 십진수로 주어집니다.

```text
$A\ B$
```

## 제한

- $0 \leq A,B \leq 255$
- 입력은 모두 정수입니다.

## 출력

방정식을 만족하는 유일한 정수 $X$를 십진수로 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1 2
```

#### 출력

```text
3
```

$ (1)_{10} \oplus X = (2)_{10}$를 만족하는 유일한 정수 $X$는 $(3)_{10}$입니다.

이는 $ (1)_{10} \oplus (3)_{10} = (01)_2 \oplus (11)_2 = (10)_2 = (2)_{10}$이기 때문입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
11 5
```

#### 출력

```text
14
```

$ (11)_{10} \oplus X = (5)_{10}$를 만족하는 유일한 정수 $X$는 $(14)_{10}$입니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
240 121
```

#### 출력

```text
137
```

$ (240)_{10} \oplus X = (121)_{10}$를 만족하는 유일한 정수 $X$는 $(137)_{10}$입니다.
