## 문제

2^2^2는 (2^2)^2로 계산해도 ((2^2)^2 = 4^2 = 16), 2^(2^2)로 계산해도 (2^(2^2) = 2^4 = 16) 결과가 같지만, 일반적으로 거듭제곱 연산은 결합법칙을 만족하지 않습니다.

양의 정수 A, B, C가 `A^B^C` 형식으로 주어집니다. (A^B)^C와 A^(B^C)의 값을 구하여 공백으로 구분해 한 줄에 출력하세요.

매우 큰 수가 될 수 있으므로 10^9 + 7로 나눈 나머지를 출력하세요.

## 입력

양의 정수 A, B, C (1 ≤ A,B,C ≤ 10^16)가 `^`로 구분되어 한 줄에 주어집니다. 입력에 불필요한 공백은 포함되지 않습니다.

```text
A^B^C
```

## 출력

(A^B)^C와 A^(B^C)의 값을 각각 10^9 + 7로 나눈 나머지를 공백으로 구분해 한 줄에 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
2^2^2
```

### 샘플 1 출력 {file="sample1.out"}

```text
16 16
```

문제문에 설명한 대로입니다.

### 샘플 2 {file="sample2.in"}

```text
2^3^2
```

### 샘플 2 출력 {file="sample2.out"}

```text
64 512
```

(2^3)^2 = 8^2 = 64, 2^(3^2) = 2^9 = 512입니다.

### 샘플 3 {file="sample3.in"}

```text
10^10^10
```

### 샘플 3 출력 {file="sample3.out"}

```text
226732710 206165314
```

10^9 + 7로 나눈 나머지를 출력하세요.
