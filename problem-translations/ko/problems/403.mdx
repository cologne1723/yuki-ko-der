## 문제 설명

$2{\char94}2{\char94}2$는 $(2^2)^2$로 계산해도 $((2^2)^2 = 4^2 = 16)$, $2^{(2^2)}$로 계산해도 $(2^{(2^2)} = 2^4 = 16)$ 결과가 같지만, 일반적으로 거듭제곱 연산은 결합법칙을 만족하지 않습니다.

양의 정수 $A, B, C$가 $A{\char94}B{\char94}C$ 형식으로 주어집니다. $(A^B)^C$와 $A^{(B^C)}$의 값을 구하여 공백으로 구분해 한 줄에 출력하세요.

매우 큰 수가 될 수 있으므로 $10^9 + 7$로 나눈 나머지를 출력하세요.

## 입력

입력에 불필요한 공백은 포함되지 않습니다.

```text
$A{\char94}B{\char94}C$
```

## 제한

- $1 \leq A,B,C \leq 10^{16}$

## 출력

$(A^B)^C$와 $A^{(B^C)}$의 값을 각각 $10^9 + 7$로 나눈 나머지를 공백으로 구분해 한 줄에 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2^2^2
```

#### 출력

```text
16 16
```

문제문에 설명한 대로입니다.

### 예제 2 {file=""}

#### 입력

```text
2^3^2
```

#### 출력

```text
64 512
```

$(2^3)^2 = 8^2 = 64$, $2^{(3^2)} = 2^9 = 512$입니다.

### 예제 3 {file=""}

#### 입력

```text
10^10^10
```

#### 출력

```text
226732710 206165314
```

$10^9 + 7$로 나눈 나머지를 출력하세요.
