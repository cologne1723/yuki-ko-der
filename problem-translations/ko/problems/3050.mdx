## 문제 설명

양의 정수 $N$, $K$와 길이가 $N$인 정수 수열 $A=(A_1,A_2,\ldots,A_N)$가 주어집니다.

현재 suisen 君의 만족도는 $0$입니다. suisen 君은 앞으로 $i=1,2,\ldots,K$의 순서로 다음을 수행합니다.

수열 $A$의 길이를 $\lvert A\rvert$라고 할 때,

- $\lvert A\rvert=0$이면 suisen 君의 만족도를 $-10^{100}$으로 설정합니다.
- $\lvert A\rvert\geq 1$이면 $1\leq p\leq\lvert A\rvert$를 만족하는 정수 $p$를 선택하여 $A$의 앞에서 $p$개의 원소를 제거합니다. 이때 제거한 원소의 합을 $S$라고 하면 suisen 君의 만족도는 $S\times i$만큼 증가합니다.

예를 들어 $A=(-3,2,1)$일 때 $p=2$를 선택하면 앞에서부터 원소 $-3,2$가 제거되어 $A=(1)$이 됩니다. 이때 제거한 원소의 합은 $(-3)+2=-1$이므로 suisen 君의 만족도는 $(-1)\times i$만큼 증가합니다.

모든 작업을 끝낸 후 suisen 君의 만족도의 최댓값을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ K$
$A_1\ A_2\ \cdots\ A_N$
```

$N$, $K$, $A_1, A_2, \ldots, A_N$은 모두 정수입니다.

## 제한

- $1\leq K\leq N\leq 5\times 10^5$
- $\lvert A_i\rvert\leq 10^7$

## 출력

답을 $1$줄에 출력하고, 마지막에 줄바꿈하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 3
3 2 0 1 -1
```

#### 출력

```text
10
```

$N=5$, $K=3$, $A=(3,2,0,1,-1)$입니다. 다음과 같이 작업을 수행하면 최종 만족도는 $10$이 됩니다.

- $i=1$: $A=(3,2,0,1,-1)$이고 수열 $A$의 길이는 $5$입니다. $p=1$을 선택하면 앞에서부터 $1$개의 원소 $3$이 제거되어 $A=(2,0,1,-1)$이 됩니다. 이때 제거한 원소의 합은 $3$이므로 만족도에 $3\times 1=3$이 더해져 만족도는 $3$이 됩니다.
- $i=2$: $A=(2,0,1,-1)$이고 수열 $A$의 길이는 $4$입니다. $p=1$을 선택하면 앞에서부터 $1$개의 원소 $2$가 제거되어 $A=(0,1,-1)$이 됩니다. 이때 제거한 원소의 합은 $2$이므로 만족도에 $2\times 2=4$가 더해져 만족도는 $7$이 됩니다.
- $i=3$: $A=(0,1,-1)$이고 수열 $A$의 길이는 $3$입니다. $p=2$를 선택하면 앞에서부터 $2$개의 원소 $0,1$이 제거되어 $A=(-1)$이 됩니다. 이때 제거한 원소의 합은 $1$이므로 만족도에 $1\times 3=3$이 더해져 만족도는 $10$이 됩니다.

만족도가 $10$을 넘는 작업 방법은 존재하지 않으므로 답으로 $10$을 출력합니다.
