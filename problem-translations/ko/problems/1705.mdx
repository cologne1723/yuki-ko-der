값 `1`부터 `M`까지의 등장 횟수 `a_i`가 주어진 배열 `A`를 관리합니다.

## 질의

- `T_i=1`: `X_i`를 `Y_i`개 추가합니다.
- `T_i=2`: `X_i`를 `Y_i`개 제거합니다.
- `T_i=3`: 최빈값을 출력합니다. 최빈값이 여러 개면 가장 큰 값을 출력합니다.

## 입력

초기 배열 정보와 `Q`개의 질의가 주어집니다.

## 출력

각 3번 질의의 답을 한 줄에 하나씩 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text

10
1 1 5
3 0 0
1 2 8
3 0 0

3 0 0
1 1 10
3 0 0
1 2 7
3 0 0
```

#### 출력

```text
1
2
2
1
2
```
