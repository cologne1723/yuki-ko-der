## 문제 설명

양의 정수 $X$를 십진법으로 나타냈을 때(맨 앞에 $0$이 오지 않는 형태), $0$부터 $9$까지의 각 숫자가 나타나는 횟수가 모두 짝수 번이면 $X$를 **좋은 수**라고 정의합니다.

예를 들어 $77$과 $144100$은 각 숫자가 짝수 번씩 나타나므로 좋은 수입니다. $110$과 $1213$은 좋은 수가 아닙니다.

$N$ 이하의 양의 정수 중 좋은 수의 개수를 구하세요. 답이 매우 커질 수 있으므로, 답을 소수 $998244353$으로 나눈 나머지를 계산하세요.

## 입력

```text
N
```

$1\leq N\leq10^{10000}$

$N$은 양의 정수입니다.

## 출력

답을 $998244353$으로 나눈 나머지를 한 줄에 출력하세요. 마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1019
```

#### 출력

```text
11
```

$1019$ 이하의 좋은 수는 $11,22,33,\ldots,99,1001,1010$으로, 모두 $11$개입니다.

### 예제 2 {file=""}

#### 입력

```text
37181
```

#### 출력

```text
261
```

### 예제 3 {file=""}

#### 입력

```text
31415926535897
```

#### 출력

```text
15778096
```

소수 $998244353$으로 나눈 나머지를 출력하세요.
