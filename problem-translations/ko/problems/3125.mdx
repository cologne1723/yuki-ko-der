## 문제 설명

$N \times N$ 그리드 $A$가 있습니다. 위에서 $i$번째, 왼쪽에서 $j$번째 칸을 칸 $(i, j)$라고 합니다. 그리드 $A$의 칸 $(i, j)$는 $A_{i, j}$가 `#`이면 검은색, `.`이면 흰색으로 칠해져 있습니다.

**대칭 그리드:** $N \times N$ 그리드 $X$가 다음 조건을 만족할 때(그리고 그때에만) 그리드 $X$를 대칭 그리드라고 합니다.

- 모든 $i, j$ ($1 \leq i, j \leq N$)에 대해 그리드 $X$의 칸 $(i, j)$에 칠해진 색과 칸 $(i, N + 1 - j)$에 칠해진 색이 같습니다.

또한, 茜ちゃん과 葵ちゃん은 다음 조작을 $0$회 이상 원하는 횟수만큼 반복할 수 있습니다.

**조작:** 다음 행동을 순서대로 수행합니다.

1. 茜ちゃん이 현재 검은색으로 칠해진 그리드 $A$의 칸 $(i, j)$를 선택합니다.
2. 葵ちゃん이 현재 흰색으로 칠해진 그리드 $A$의 칸 $(i', j')$를 선택합니다.
3. 그리드 $A$의 칸 $(i, j)$를 흰색으로, 칸 $(i', j')$를 검은색으로 다시 칠합니다.

조작을 반복해서 그리드 $A$를 대칭 그리드로 만들 수 있는지 판정하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$A_{1, 1}A_{1, 2}\ldots A_{1, N}$
$A_{2, 1}A_{2, 2}\ldots A_{2, N}$
$\vdots$
$A_{N, 1}A_{N, 2}\ldots A_{N, N}$
```

## 제한

- $N$은 $1 \leq N \leq 500$을 만족하는 정수입니다.
- $A_{i, j}$는 `#` 또는 `.` 중 $1$개입니다.

## 출력

조작을 반복해서 그리드 $A$를 대칭 그리드로 만들 수 있다면 `Yes`를, 만들 수 없다면 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
##.
#..
...
```

#### 출력

```text
Yes
```

예를 들어 다음과 같이 조작하면 대칭 그리드로 만들 수 있습니다.

- 茜ちゃん이 칸 $(2, 1)$을, 葵ちゃん이 칸 $(1, 3)$을 선택합니다. 그러면 그리드는 다음과 같아지고, 이는 대칭 그리드입니다.

```text
###
...
...
```

### 예제 2 {file=""}

#### 입력

```text
6
......
.###..
.###..
.###..
......
......
```

#### 출력

```text
No
```

어떻게 조작해도 대칭 그리드로 만들 수 없습니다.

### 예제 3 {file=""}

#### 입력

```text
4
#..#
.##.
.##.
#..#
```

#### 출력

```text
Yes
```

이미 대칭 그리드입니다.
