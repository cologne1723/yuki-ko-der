## 문제 설명

내용물을 볼 수 없는 주머니 A와 주머니 B가 있습니다. 주머니 A에는 흰 바둑돌이 $A_w$개, 검은 바둑돌이 $A_b$개 있고, 주머니 B에는 흰 바둑돌이 $B_w$개, 검은 바둑돌이 $B_b$개 있습니다.

먼저 주머니 A에서 색을 보지 않고 바둑돌 $C$개를 꺼내 주머니 B로 옮깁니다. 다음으로 주머니 B에서 색을 보지 않고 바둑돌 $D$개를 꺼내 주머니 A로 옮깁니다.

마지막에 주머니 A에 들어 있는 흰 바둑돌의 수로 가능한 최댓값을 구하세요.

## 입력

```text
$A_w\ A_b$
$B_w\ B_b$
$C\ D$
```

## 제한

- $0 \le A_w,A_b \le 100\,000$
- $0 \le B_w,B_b \le 100\,000$
- $0 \le C \le 200\,000$
- $0 \le D \le 400\,000$
- $C,D$는 항상 꺼낼 수 있는 개수로 주어집니다.

## 출력

이동 후 주머니 A에 들어 있을 수 있는 흰 바둑돌 수의 최댓값을 $1$줄에 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 1
1 2
2 3
```

#### 출력

```text
3
```

처음 주머니 A에는 흰 돌 $2$개와 검은 돌 $1$개, 주머니 B에는 흰 돌 $1$개와 검은 돌 $2$개가 있습니다. A에서 B로 옮기는 $2$개가 모두 흰 돌이고, 이어서 B에서 A로 옮기는 $3$개도 모두 흰 돌이면 A의 흰 돌이 최대로 $3$개가 됩니다.

### 예제 2 {file=""}

#### 입력

```text
2 0
0 3
2 1
```

#### 출력

```text
1
```

처음 A에서 B로 옮기는 $2$개는 반드시 흰 돌입니다. 다음에 B에서 A로 옮기는 $1$개가 흰 돌이면 A의 흰 돌은 최대로 $1$개입니다.

### 예제 3 {file=""}

#### 입력

```text
3 0
2 3
0 5
```

#### 출력

```text
5
```

처음에는 A에서 B로 바둑돌을 $0$개 옮기므로 바둑돌의 수는 변하지 않습니다. 다음에 B에서 A로 옮기는 $5$개가 흰 돌 $2$개와 검은 돌 $3$개이면 A의 흰 돌은 최대로 $5$개입니다.

### 예제 4 {file=""}

#### 입력

```text
43682 82641
54647 3647
92674 64591
```

#### 출력

```text
98240
```
