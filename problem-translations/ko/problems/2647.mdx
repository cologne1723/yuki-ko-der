하루 동안 풍력계 프로펠러가 $x$회 회전하면 그날의 풍력은 $x/A$를 반올림한 정수입니다. $D$일 동안의 회전 수가 주어질 때 각 날의 풍력을 구하세요.

## 조건

- $1\le T,D\le100$
- $1\le A\le10^{18}$, $0\le X_d\le10^{18}$

## 입력

```text
$T$
$D$ $A$ $X_1$ $\cdots$ $X_D$
```

## 출력

각 테스트 케이스의 반올림 결과를 출력하세요.
