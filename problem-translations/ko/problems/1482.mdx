## 문제

`0,...,M-1`의 등차 순열과 두 수열 `B,C`가 주어집니다. 각 `K=1,...,N`에 대해 정의된 순열 변환 결과를 구하세요.

## 입력

`N`, 소수 `M`, 수열 `B,C`가 주어집니다.

## 출력

각 질의의 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 3
0 1
2 1
0 2
```

#### 출력

```text
1
6
60
```
