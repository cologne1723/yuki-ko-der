길이 $3N$인 문자열 $S$가 주어집니다. 원하는 횟수만큼 $S_i$와 $S_{i+3}$을 교환할 수 있습니다. 조작 후 문자열에 포함된 연속 부분 문자열 `con`의 개수의 최댓값을 구하세요.

## 입력

```text
N
S
```

$1\le N\le2\times10^5$이고 $S$의 길이는 $3N$입니다.

## 출력

최댓값을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
toscenter
```

#### 출력

```text
1
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3
conconfox
```

#### 출력

```text
2
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
5
kudagitsunecoon
```

#### 출력

```text
0
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
9
yukicoderprogrammingcontest
```

#### 출력

```text
2
```

#### 입력

```text
33
paracetamoxyfrusebendroneomycinsupercalifragilisticexpialidocioussupercalifragilisticexpialidocious
```

#### 출력

```text
3
```
