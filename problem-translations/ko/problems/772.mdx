## 문제

정점 $N$개의 숲이 있습니다. 정점 번호는 1부터 $N$까지입니다. 처음에는 간선이 없고 각 정점 $v$의 정수 $X_v$는 모두 1입니다. $Q$개의 질의를 온라인으로 처리하세요.

- 타입 1: 정점 $a,b$와 정수 $c$를 받아 두 정점 사이에 가중치 $c$인 간선을 추가합니다. 추가 후에도 숲이라는 것이 보장됩니다.
- 타입 2: 정점 $a,b$를 받아 두 정점을 직접 잇는 간선을 삭제합니다. 해당 간선은 존재합니다.
- 타입 3: 정점 $a$의 $X_a$를 $1-X_a$로 바꾼 뒤, $a$가 속한 나무의 정점이 $v_1,\ldots,v_k$일 때

$$\min_{1\leq i\leq k}\left\{\sum_{1\leq j\leq k}dist(v_i,v_j)\times X_{v_j}\right\}$$

를 구합니다. $dist(v_i,v_j)$는 두 정점 사이 경로의 간선 가중치 합입니다.

각 질의에서 지정되는 정점 번호는 암호화되어 있습니다. 입력 번호가 $x$이고 지금까지 타입 3 답의 합이 $S$이면, 복호화한 번호는 $(x-1+S)\bmod N+1$입니다.

## 입력

~~~text
$N\ Q$
$Query_1$
$Query_2$
$\vdots$
$Query_Q$
~~~

$1\leq N\leq10^5$, $1\leq Q\leq3\times10^5$입니다.

타입 1은 $1\ a\ b\ c$ ($1\leq a,b\leq N$, $a\ne b$, $1\leq c\leq10^8$), 타입 2는 $2\ a\ b$ ($1\leq a,b\leq N$, $a\ne b$), 타입 3은 $3\ a$ ($1\leq a\leq N$)입니다.

## 출력

타입 3 질의의 답을 한 줄에 하나씩 출력하세요. 마지막에는 줄바꿈을 출력하세요.

## 예제

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
3 7
1 1 2 3
1 3 1 1
3 1
2 1 3
3 1
1 2 1 2
3 2
~~~

#### 출력

~~~text
4
0
0
~~~

첫 번째 타입 3 시점에는 1–2 사이에 가중치 3, 1–3 사이에 가중치 1의 간선이 있습니다. $X_1$이 1에서 0이 되어 $X_2=X_3=1$이고, 정점 1에서의 합은 4이며 이것이 최솟값입니다. 다음 타입 2에서 삭제되는 간선은 복호화 결과 $((1-1+4)\bmod3+1,(3-1+4)\bmod3+1)=(2,1)$입니다. 두 번째 타입 3에서는 $X_2$가 1에서 0으로 바뀌어 $(X_1,X_2,X_3)=(0,0,1)$입니다. 정점 2만 남은 나무의 답이 0입니다. 세 번째 타입 3에서는 1–3 사이에 가중치 1, 2–3 사이에 가중치 2의 간선이 있습니다. $X_3$가 1에서 0으로 바뀌어 모든 $X$가 0이므로 답이 0입니다. 첫 번째와 세 번째 답은 각각 $dist(1,1)X_1+dist(1,2)X_2+dist(1,3)X_3=4$와 $0$으로 달성됩니다.
