양의 정수 수열 `a`가 주어집니다. 구간 `I=[l,r]`의 곱의 제곱근이 정수가 되는 구간의 개수를 구하세요.

## 제약

- `1 <= n <= 2 * 10^5`
- `1 <= a_i <= 10^6`

## 입력

`n`과 수열 `a`가 주어집니다.

## 출력

조건을 만족하는 구간의 개수를 출력하세요.
