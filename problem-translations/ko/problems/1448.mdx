## 문제

정수 `A,B,C,D`와 양의 정수 `N`이 주어집니다. `A\le a_0\le B`, `C\le b_0\le D`이고

\[
a_i=a_{i-1}-b_{i-1},\quad b_i=a_{i-1}+b_{i-1}
\]

인 수열을 생각합니다. 가능한 `a_N+b_N`의 최댓값을 `10^9+7`로 나눈 나머지를 출력하세요.

## 입력

`A B C D N`이 주어집니다.

## 출력

최댓값의 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 3 4 5
1
```

#### 출력

```text
6
```

### 예제 2 {file=""}

#### 입력

```text
-5 -4 -3 -2
2
```

#### 출력

```text
1000000005
```

### 예제 3 {file=""}

#### 입력

```text
3141 5926 5358 9793
238462643383279502
```

#### 출력

```text
845706131
```
