문자열 $X$의 `010` 부분 수열 개수를 $f(X)$라 하자냥. `0`, `1`, `?`로 이루어진 문자열 $S$의 모든 물음표를 0 또는 1로 바꾼 문자열에 대한 $f$의 합을 구하라냥.

## 조건

- $1\le|S|\le2\times10^5$

## 입력

```text
S
```

## 출력

모든 치환에 대한 합을 $998244353$으로 나눈 나머지를 출력하라냥.
