## 문제 설명

수열 $a$와 $b$에 대해 수열 $a*b$를 다음 재귀식으로 정의합니다.

$\displaystyle (a*b)_n=a_n+b_n+\sum_{i+j+k=n}a_i b_j (a*b)_k$

여기서 수열은 길이가 무한한 음이 아닌 정수열을 의미합니다. 수열 $a$와 양의 정수 $n$에 대해 $a_n$은 $a$의 $n$번째 성분을 나타냅니다. 위 식의 우변에서 $i,j,k$는 $i+j+k=n$을 만족하는 순서 있는 $3$개의 양의 정수 $(i,j,k)$ 전체를 범위로 합니다.

수열 $a$와 양의 정수 $m$에 대해 수열 $a^m$을 다음 재귀식으로 정의합니다.

$\displaystyle a^m=\left\{\begin{array}{ll}a&(m=1)\\a^{m-1}*a&(m>1)\end{array}\right.$

즉, $a^m$은 $*$에 대한 $a$의 $m$제곱을 왼쪽 결합으로 계산한 것입니다.

입력으로 양의 정수 $N,M$, 소수 $P$, 그리고 $N+1$ 이상의 임의의 양의 정수 $n$에 대해 $A_n=0$을 만족하는 수열 $A$가 주어집니다.

$N$ 이하의 각 양의 정수 $n$에 대한 $(A^M)_n$을 $P$로 나눈 나머지를 구하세요.

### 배경

대수학을 아는 사람을 위해 배경을 설명합니다. 임의의 음이 아닌 정수 $i,j$에 대해 $F_{i,j}$가 유리수인, 유리수 계수의 $2$변수 형식적 멱급수 $F(x,y)=\sum_{i,j=0}^{\infty}F_{i,j}x^i y^j$가 다음 조건을 만족한다고 합시다.

- $F_{0,0}=0$
- $F_{1,0}=F_{0,1}=1$
- $F(F(x,y),z)=F(x,F(y,z))$ ($3$변수 형식적 멱급수의 등식)

이러한 것을 유리수 계수의 형식군 법칙이라고 합니다. 예를 들어 $x+y$는 형식군 법칙이며, 유리수 대수 위의 $2$변수 함수로서는 덧셈군의 연산과 일치합니다. $x+y+xy$도 형식군 법칙이며, 유리수 위의 $2$변수 함수로서는 단위원 $1$을 중심으로 전개한 영이 아닌 원소의 곱셈군 연산과 일치합니다. 일반적인 형식군 법칙이 일반적인 유리수 대수 위의 연산을 반드시 정의하는 것은 아니지만, 예를 들어 형식적 멱급수환 $\mathbb{Q}[[x]]$의 아이디얼 $x\mathbb{Q}[[x]]$ 위에 군 연산을 정의합니다.

이 문제의 $*$ 연산은 유리수 계수의 형식군 법칙 $\frac{x+y}{1-xy}$가 $x\mathbb{Q}[[x]]$ 위에 정의하는 군 연산을 수열의 언어로 옮긴 것입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 $2$개의 줄로 주어집니다.

```text
$N\ M\ P$
$A_1\ \cdots\ A_N$
```

$1$번째 줄에 $N$, $M$, $P$가 공백으로 구분되어 주어집니다.

$2$번째 줄에 $N$ 이하의 각 양의 정수 $n$에 대한 $A_n$이 $n$이 작은 순서대로 공백으로 구분되어 주어집니다.

## 제한

- $N$은 $1\leq N\leq 500$을 만족하는 정수입니다.
- $M$은 $1\leq M\leq 10^{18}$을 만족하는 정수입니다.
- $P$는 $N<P<10^9$를 만족하는 소수입니다.
- $N$ 이하의 임의의 양의 정수 $n$에 대해 $A_n$은 $0\leq A_n\leq 10^{18}$을 만족하는 정수입니다.

## 출력

$N$ 이하의 각 양의 정수 $n$에 대한 $(A^M)_n$을 $P$로 나눈 나머지를 $n$이 작은 순서대로 공백으로 구분하여 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1 2
1
```

#### 출력

```text
1
```

$A=(1,0,\ldots)$이고 $A^M=A^1=A=(1,0,\ldots)$입니다. $1$을 $P=2$로 나눈 나머지인 $1$을 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
2 2 3
1 2
```

#### 출력

```text
2 1
```

$A=(1,2,0,\ldots)$이고,

$A^M=A^2=A*A=(2,4,2,12,26,36,82,188,330,660,\ldots)$입니다.

따라서 $2,4$를 각각 $P=3$으로 나눈 나머지인 $2,1$을 출력합니다.

### 예제 3 {file=""}

#### 입력

```text
3 3 5
1 1 1
```

#### 출력

```text
3 3 1
```

$A=(1,1,1,0,\ldots)$이고,

$A^M=A^3=(A*A)*A=(2,2,4,6,14,24,44,80,150,274,\ldots)*A=(3,3,11,24,72,176,480,1\,248,3\,320,8\,712,\ldots)$입니다.

따라서 $3,3,11$을 각각 $P=5$로 나눈 나머지인 $3,3,1$을 출력합니다.
