## 문제

`Hitsuji ga N hiki` 형식의 문자열이 $T$개 주어집니다. 각 문자열의 $N$을 $N+1$로 바꿔 출력하세요.

## 입력

첫째 줄에 테스트 케이스 수 $T$가 주어집니다. 이후 각 줄에 `Hitsuji ga N hiki`가 주어집니다.

- $1\leq T\leq 100$
- $1\leq N\leq 100$

## 출력

각 입력에 대해 $N$을 $N+1$로 바꾼 문자열을 한 줄에 하나씩 출력하세요.
