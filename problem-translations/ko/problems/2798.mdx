## 문제 설명

$2$ 이상의 정수 $N$이 주어집니다.

길이가 $1$ 이상인 양의 정수열 $(A_1,A_2,\dots,A_L)$ $(L\ge 1)$ 중 다음 조건을 만족하는 것의 개수를 구하세요.

- $A_1\ge 2$
- $i=1,2,\dots,L-1$에 대해 $A_{i+1}$은 $A_i$의 배수입니다.
- $A_1\times A_2\times\dots\times A_L=N$입니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
```

$N$은 정수입니다.

## 제한

- 입력은 모두 정수입니다.
- $2\leq N\leq 10^{18}$

## 출력

조건을 만족하는 양의 정수열의 개수를 출력하세요.


## 예제

### 예제 1 {file=""}

#### 입력

```text
4
```

#### 출력

```text
2
```

조건을 만족하는 양의 정수열은 다음 $2$개입니다.

- $(2,2)$
- $(4)$

### 예제 2 {file=""}

#### 입력

```text
999999999999999989
```

#### 출력

```text
1
```

### 예제 3 {file=""}

#### 입력

```text
963761198400
```

#### 출력

```text
110
```
