## 문제

yurufuWAcoder에서 별이 $N$개인 문제를 $K$번째로 풀었을 때의 점수 $f(N,K)$는 다음 식으로 정해집니다.

$$
f(N,K) = 50 \times N +  \left\lfloor \frac{ 50 \times N }{ 0.8+ 0.2×K} \right\rfloor
$$

여기서 $\lfloor x\rfloor$는 $x$의 소수점 이하를 버림을 뜻합니다.

두 자연수 $A,B$가 주어질 때 $f(A,B)$를 출력하세요.

## 입력

```text
$A\;B$
```

$1\leq A\leq6$

$1\leq B\leq10^3$

## 출력

답을 한 줄에 출력하세요.
