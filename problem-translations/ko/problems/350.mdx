## 문제 설명

$1$개의 방향으로 등속 운동을 합니다. 속도(m/s)가 소수점 이하 $4$자리까지 주어지고 시간(s)이 정수로 주어질 때, 이동한 거리(m)의 소수점 이하를 버린 값을 출력하세요.

속도는 $0$m/s보다 크고 $1$m/s보다 작음이 보장됩니다. 또한 속도는 반드시 소수점 이하 $4$자리까지 표시되고 소수점 $5$번째 자리 이후는 표시되지 않지만 $0$이 계속된다고 합니다. 시간은 반드시 양의 정수입니다.

## 입력

```text
$v\ t$
```

$v$는 속도(m/s)이며 반드시 소수점 이하 $4$자리까지 표시됩니다.

$t$는 시간(s)이며 반드시 양의 정수입니다.

## 제한

- $0.0000\lt v\lt1.0000$
- $1\le t\le10\,000=10^4$

## 출력

이동한 거리(m)의 소수점 이하를 버린 값을 $1$줄에 출력하세요. 마지막에 개행하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0.5000 8
```

#### 출력

```text
4
```

$0.5$m/s의 속도로 이동하면 $8$초 후 $4$m 이동합니다.

### 예제 2 {file=""}

#### 입력

```text
0.0123 45
```

#### 출력

```text
0
```

답은 소수점 이하를 버리므로 $0$m입니다.

### 예제 3 {file=""}

#### 입력

```text
0.2820 7000
```

#### 출력

```text
1974
```
