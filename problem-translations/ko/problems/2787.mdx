## 문제 설명

먼저 표기와 용어를 정의합니다. 음이 아닌 정수 $n$과 $2$ 이상의 정수 $b$에 대해, 음이 아닌 정수 $G_b(n)$을 다음 재귀식으로 정의합니다.

$\displaystyle G_b(n) = \left\{\begin{array}{ll} \displaystyle n &\displaystyle (n < b) \\ \displaystyle G_b \left(\frac{n - (n \bmod b)}{b} \right) \times (b + 1) + (n \bmod b) &\displaystyle (n \geq b) \end{array}\right.$

여기서 $n \bmod b$는 $n$을 $b$로 나눈 나머지를 나타냅니다.

음이 아닌 정수 $n$과 $2$ 이상의 정수 $b$에 대해 다음 일련의 연산을 $P(n,b)$라고 합니다.

1. 정수 변수 $n'$과 $b'$의 값을 각각 $n$과 $b$로 정하고, 다음 단계로 진행합니다.
2. $n'$의 값이 양수이면 다음 단계로 진행하고, 그렇지 않으면 4단계로 진행합니다.
3. $n'$의 값을 $G_{b'}(n') - 1$의 값으로 바꾸고, $b'$의 값을 $b' + 1$로 바꾼 뒤 2단계로 돌아갑니다.
4. 연산을 종료합니다.

정의에 따라 $P(n,b)$에서 4단계가 실행되는 횟수는 최대 $1$회입니다. $P(n,b)$에서 4단계가 실행되는 것을 $P(n,b)$가 정지한다고 합니다. $P(n,b)$가 정지하는 경우, 그때까지 1, 2, 3단계를 실행한 횟수의 합을 $P(n,b)$의 정지 단계 수라고 합니다.

음이 아닌 정수 $c$에 대해, $P(n,b)$가 $c$단계 이내에 정지한다는 것은 $P(n,b)$가 정지하고 정지 단계 수가 $c$ 이하라는 뜻입니다.

$P(N,B)$가 정지하는지 판정하세요. 정지한다면 $C$단계 이내에 정지하는지도 판정하고, $C$단계 이내에 정지한다면 정지 단계 수를 구하세요.

### 배경

음이 아닌 정수 $n$과 $2$ 이상의 정수 $b$를 생각합니다. $n$이 $b^b$ 미만이라면, $P(n,b)$에서의 $n'$의 변화는 첫 항이 $n$인 굿스타인 수열을 정의할 때 $2$ 대신 $b$를 최초의 기수로 사용하여 얻는 수열과 같습니다.

[굿스타인 수열](https://ja.wikipedia.org/wiki/%E3%82%B0%E3%83%83%E3%83%89%E3%82%B9%E3%82%BF%E3%82%A4%E3%83%B3%E3%81%AE%E5%AE%9A%E7%90%86#%E3%82%B0%E3%83%83%E3%83%89%E3%82%B9%E3%82%BF%E3%82%A4%E3%83%B3%E6%95%B0%E5%88%97%E3%81%AE%E5%AE%9A%E7%BE%A9)

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ B\ C$
```

$1$번째 줄에 $N$, $B$, $C$가 반각 공백으로 구분되어 주어집니다.

## 제한

- $N$은 $10^{18}$ 이하의 음이 아닌 정수입니다.
- $B$는 $2$ 이상 $10^{18}$ 이하의 정수입니다.
- $C$는 $10^{18}$ 이하의 음이 아닌 정수입니다.

## 출력

$P(N,B)$가 정지한다면, 첫 번째 줄에 `Yes`를 출력하세요.

- $P(N,B)$가 $C$단계 이내에 정지한다면, 두 번째 줄에 `Yes`를 출력하고 세 번째 줄에 정지 단계 수를 출력하세요.
- $P(N,B)$가 $C$단계 이내에 정지하지 않는다면, 두 번째 줄에 `No`를 출력하세요.

$P(N,B)$가 정지하지 않는다면, 첫 번째 줄에 `No`를 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 2 10
```

#### 출력

```text
Yes
Yes
4
```

연산 $P(1,2)$에서 단계 번호와 단계 실행 후 정수 변수 $n'$, $b'$의 값이 어떻게 변하는지 쓰면 다음과 같습니다.

- 1단계: $(n',b') = (1,2)$
- 2단계: $(n',b') = (1,2)$
- 3단계: $(n',b') = (G_2(1)-1,3) = (0,3)$
- 2단계: $(n',b') = (0,3)$
- 4단계: $(n',b') = (0,3)$

따라서 $P(1,2)$는 정지하고 정지 단계 수는 $4$입니다. 특히 $10$단계 이내에 정지합니다.
