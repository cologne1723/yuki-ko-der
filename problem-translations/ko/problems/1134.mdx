## 문제 설명

NaN 군의 반에는 $N$명의 학생이 있습니다. 시험을 치른 결과 각 학생의 점수는 $100$점 만점의 $x_1,x_2,\ldots,x_N$점이었습니다. 학생 $M$의 편차값을 소수점 아래 버림으로 구하세요. 여기서 ‘소수점 아래 버림’은 $0$ 방향으로 정수 반올림하는 것을 뜻합니다.

편차값은 다음과 같이 구합니다.

1. 전체 평균 점수와 각 점수의 차이의 제곱을 구합니다.
2. 1에서 구한 값의 평균의 제곱근을 구합니다.
3. 평균 점수와 해당 점수의 차이에 $10$을 곱한 뒤 2에서 구한 값으로 나눕니다. 2에서 구한 값이 $0$이면 편차값을 $50$으로 합니다.
4. 해당 점수가 평균보다 높으면 $50$에 3에서 구한 값을 더하고, 그렇지 않으면 뺍니다.

## 입력

```text
$N$
$x_1\ x_2\ \cdots\ x_N$
$M$
```

$1 \leq N \leq 100\,000$

$0 \leq x_i \leq 100$

$1 \leq M \leq N$

$N$, $M$, $x_i$는 정수입니다.

## 출력

학생 $M$의 편차값을 정수로 한 줄에 출력하세요. 예를 들어 $65$를 `65.0`으로 출력하면 오답입니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
10
50 90 60 60 40 100 40 40 50 70
2
```

#### 출력

```text
65
```

평균 점수는 $60$점이고 평균과의 차이의 제곱 평균의 제곱근은 $20$입니다. 평균과의 차이에 $10$을 곱하고 $20$으로 나누면 $30 \times 10 / 20 = 15$이므로, 평균보다 높아 $50+15=65$입니다.
