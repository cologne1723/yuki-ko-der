형은 주어진 정수에 $A$를 곱한 뒤 동생에게 넘긴다냥. 동생은 받은 정수에서 $B$를 빼도 0 이하가 되지 않으면 $B$를 빼고, 그렇지 않으면 아무것도 하지 않는다냥. 최종적으로 동생이 가진 수가 양의 정수 $C$가 되었다냥. 주어진 $A,B,C$에 대해 가능한 처음의 양의 정수 $N$을 모두 오름차순으로 출력하라냥.

## 조건

- $1\le A,B,C\le10^5$

## 입력

```text
A B C
```

## 출력

가능한 $N$을 오름차순으로 한 줄에 하나씩 출력하라냥. 없으면 $-1$을 출력하라냥.
