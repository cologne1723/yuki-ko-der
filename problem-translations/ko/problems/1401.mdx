## 문제

길이 `d_i`인 작업 문자열 `S_i`가 최대 `N`개 주어집니다. `1` 이상 `2000` 이하의 정수 수열 `A`를 반복 입력하는 매크로로 모든 작업을 완료하세요.

매크로의 각 입력과 일치하는 작업 문자열의 현재 문자 위치를 진행시키며, 모든 작업이 완료되는 순간이 매크로의 마지막 입력 직후가 되도록 하는 `A`를 하나 구성하세요.

## 입력

작업 문자열들의 정보가 주어집니다.

## 출력

조건을 만족하는 매크로를 출력하세요.
