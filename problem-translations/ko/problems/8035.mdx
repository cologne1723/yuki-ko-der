## 이야기

드디어 새 연도(2018년도)도 시작됐어! 여기서 퀴즈를 낼게~!

## 문제 설명

수열 $a$가 숨겨져 있어. 이 수열은 $1$번째 항부터 시작해. $N$번째 항의 값을 알려줘~!

어려울 것 같으니 큰 힌트! 이 수열은 어떤 조건을 만족하는 수를 작은 순서대로 나열한 거야~! $2\,018$과 $2\,019$가 동시에 조건을 만족하는 성질은 무엇일까~?

## 입력

입력은 다음 형식으로 표준 입력에서 $1$줄에 주어집니다.

```text
$N$
```

정수 $N$이 $1$번째 줄에 주어집니다.

## 제한

- $N$은 $1 \leq N \leq 10^6$을 만족하는 정수입니다.

## 출력

$a_N$을 $1$줄에 출력해~! 마지막에는 개행을 넣는 것을 잊지 마아아아아아아아아아아★★★★★!
