$N$개의 케이크 중 원하는 개수를 골라 먹을 수 있습니다. 먹은 케이크의 맛 합을 기쁨이라 할 때, 가능한 모든 $2^N$가지 기쁨을 큰 순서로 정렬했을 때 $K$번째 값을 출력하세요. 같은 값은 여러 번 셉니다.

## 조건

- $1\le N\le30$
- $-10^9\le A_i\le10^9$
- $1\le K\le\min(2^N,3\times10^5)$

## 입력

첫째 줄에 $N,K$, 둘째 줄에 $A_1,\ldots,A_N$이 주어집니다.

## 출력

$K$번째 기쁨을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 3
1 2 4
```

#### 출력

```text
5
```


```text
-13
```
