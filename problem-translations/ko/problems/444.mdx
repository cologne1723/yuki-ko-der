## 문제

서로 다른 감칠맛을 곱하면 감칠맛의 세기가 크게 높아지는 현상을 감칠맛의 상승 효과라고 합니다.

여기 감칠맛이 $n$종류 있고, 각 감칠맛의 세기는 $a_i$입니다.

$n$종류의 감칠맛으로 만드는 ‘$c$개 감칠맛의 상승 효과’는 다음과 같이 정해집니다.

- $n$종류의 감칠맛에서 중복을 허용하여 $c$개를 고릅니다.
- 고른 $c$개가 모두 같은 종류의 감칠맛 성분이라면 상승 효과가 생기지 않으므로 세지 않습니다.
- 그렇지 않다면 고른 $c$개의 감칠맛 세기를 곱합니다.

$c$개를 고르는 가능한 모든 조합에 대해 이렇게 곱한 값을 더한 것이 ‘$c$개 감칠맛의 상승 효과’입니다.

$n$종류의 감칠맛 세기 $a_i$와 양의 정수 $c$가 주어질 때 ‘$c$개 감칠맛의 상승 효과’를 구하세요.

답은 매우 커질 수 있으므로 $10^9+7$로 나눈 나머지를 출력하세요.

## 입력

```text
$n\ c$
$a_1\ a_2\ ...\ a_n$
```

$1\leq n\leq80$, $n\in\mathbb{N}$

$1\leq c\leq10^{18}$, $c\in\mathbb{N}$

$0\leq a_i\leq10^9$, $a_i\in\mathbb{Z}$

## 출력

문제에서 정의한 ‘$c$개 감칠맛의 상승 효과’를 $10^9+7$로 나눈 나머지를 한 줄에 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3 2
2 3 4
```

출력:

```text
26
```

‘$2$개 감칠맛의 상승 효과’는 `2*3+3*4+4*2`입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
3 3
2 3 4
```

출력:

```text
186
```

‘$3$개 감칠맛의 상승 효과’는 `2*2*3+2*2*4+2*3*3+2*3*4+2*4*4+3*3*4+3*4*4`입니다.

### 샘플 2 {file="sample3.in"}

입력:

```text
3 3
2 3 3
```

출력:

```text
132
```

‘$3$개 감칠맛의 상승 효과’는 `2*2*3+2*2*3+2*3*3+2*3*3+2*3*3+3*3*3+3*3*3`입니다.

감칠맛의 세기가 같더라도 감칠맛 자체가 다르면 중복하여 센 것으로 처리하지 않습니다.

### 샘플 3 {file="sample4.in"}

입력:

```text
2 10
1000000000 0
```

출력:

```text
0
```

한 감칠맛의 세기가 $0$이므로 상승 효과도 $0$이 됩니다.

입력:
