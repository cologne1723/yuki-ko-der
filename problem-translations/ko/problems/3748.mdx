## 문제 설명

정점에 $1,2,\ldots,N$의 이름이 붙은 정점 $N$개의 무방향 트리에 대해, $(1,2,\ldots,N)$의 순열 $X$가 다음 조건을 만족하면 **가지치기 순서**(Pruning Order)라고 합니다.

- $i=1,2,\ldots,N$ 순서로 정점 $X_i$와 이를 끝점으로 하는 모든 간선을 삭제합니다. 이때 모든 $i=1,2,\ldots,N-1$에 대해 삭제 직전의 정점 $X_i$는 리프여야 합니다.

$(1,2,\ldots,N)$의 순열 $P,Q,R$이 주어집니다. 정점에 $1,2,\ldots,N$의 이름이 붙은 무방향 트리 중 $P,Q,R$이 모두 가지치기 순서인 트리의 수를 $M$으로 나눈 나머지를 구하세요.

테스트 케이스는 총 $T$개입니다.

## 입력

표준 입력으로 다음 형식의 입력이 주어집니다. $\mathrm{case}_i$는 $i$번째 테스트 케이스입니다.

```text
$T$
$\text{case}_1$
$\text{case}_2$
$\vdots$
$\text{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N \ M$
$P_{1} \ P_2 \ \ldots \ P_{N}$
$Q_{1} \ Q_2 \ \ldots \ Q_{N}$
$R_{1} \ R_2 \ \ldots \ R_{N}$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $1\le T\le 10^5$
- $1\le N\le 10^5$
- $2\le M\le 10^9$
- $P,Q,R$은 $(1,2,\ldots,N)$의 순열입니다.
- 모든 테스트 케이스의 $N$의 합은 $10^5$ 이하입니다.

## 출력

$T$줄을 출력하세요. $i$번째 줄에는 $\text{case}_i$의 답을 출력하세요.
