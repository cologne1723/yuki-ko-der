## 문제 설명

네코아라 군은 한 번이라도 실수하면 즉시 종료되는 ‘단판 승부’를 플레이하고 있습니다. 한 단어를 실수 없이 입력할 확률 $p$가 주어질 때, 한 번의 도전에서 입력하는 단어 수의 기댓값을 구하세요. 단, 제한 시간은 없다고 합니다.

## 입력

```text
$p$
```

$p$는 실수이며 소수점 이하 넷째 자리까지 주어집니다.

## 제한

$0 \le p < 1$

## 출력

문제의 답을 한 줄에 출력하세요.

답은 소수가 될 수 있지만, 절대 오차 또는 상대 오차가 $10^{-5}$ 이하여야 합니다.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
0.5
```

#### 출력

```text
1
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
0.8
```

#### 출력

```text
4
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
0
```

#### 출력

```text
0
```
