## 문제 설명

양의 정수 $N$, $M$이 주어집니다.

$N$ 이하의 양의 정수 $a$와 $M$ 이하의 양의 정수 $b$의 순서쌍 중, $a$와 $b$의 최대공약수가 $1$인 것의 개수를 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ M$
```

## 제한

- $1\leq N,M\leq 10^7$
- $N$, $M$은 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 5
```

#### 출력

```text
12
```

$(a,b)=(1,1),(1,2),(1,3),(1,4),(1,5),(2,1),(2,3),(2,5),(3,1),(3,2),(3,4),(3,5)$인 $12$개입니다.

### 예제 2 {file=""}

#### 입력

```text
13 31
```

#### 출력

```text
266
```

### 예제 3 {file=""}

#### 입력

```text
10000000 10000000
```

#### 출력

```text
60792712854483
```
