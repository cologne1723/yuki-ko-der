## 문제 설명

P君은 소셜 게임을 하고 있습니다. 어떤 캐릭터를 최고 레벨까지 강화하는 데 경험치가 $a$만큼 필요하고, 강화 재료 $1$개로 경험치를 $b$만큼 올릴 수 있습니다.

가끔 “경험치 $1.5$배 캠페인”이 열리며, 캠페인 기간에는 재료 $1$개로 경험치를 $c$만큼 올릴 수 있습니다. $c=1.5b$가 아닐 수도 있습니다.

P君은 캠페인 기간에 필요한 강화 재료 수가 평소의 $2/3$ 이하이면 충분하다는 가설을 세웠습니다. 이 가설이 맞는지 판정하세요.

강화 재료 $1$개를 필요한 만큼 나누어 사용할 수는 없습니다. 예제 2를 참고하세요.

## 입력

```text
$a$
$b$
$c$
```

## 제한

- $a,b,c$는 모두 양의 정수입니다.
- $0 < a < 1\,000\,000$
- $0 < b < c < 1\,000\,000$

## 출력

P君의 가설이 맞으면 `YES`, 틀리면 `NO`를 출력하세요. 답을 출력한 뒤에는 줄바꿈을 하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
60000
10000
15000
```

#### 출력

```text
YES
```

평소에는 재료 $6$개, 캠페인 중에는 $4$개가 필요하므로 가설이 맞습니다.

### 예제 2 {file=""}

#### 입력

```text
50000
10000
15000
```

#### 출력

```text
NO
```

평소에는 $5$개로 최고 레벨까지 강화할 수 있습니다. 캠페인 중에는 $50\,000 \div 15\,000=3.333\ldots$이므로 $3$개로는 부족합니다. $4$번째 재료의 $1/3$만 사용할 수 없고 온전한 $1$개가 필요하므로, 캠페인 중에는 $4$개로 최고 레벨까지 강화할 수 있습니다. 따라서 가설에 따른 $5 \times 2/3=10/3$개로는 부족합니다.

#### 입력

```text

15776

#### 출력

NO
```

평소에는 $6$개가 필요합니다. 캠페인 중에는… 어! $4$개로는 부족하다고요?! 왜죠?!
