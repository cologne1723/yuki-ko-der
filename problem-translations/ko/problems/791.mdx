## 문제

수열 $E$의 $i$번째 항을 $E_i=1\underbrace{333\cdots3}_{i\text{개}}$로 정의합니다. 즉 10진법으로 1 뒤에 3이 $i$개 이어진 수입니다. ($i$는 양의 정수입니다.)

정수 $N$이 주어질 때 $N$이 수열 $E$의 몇 번째 항인지 구하세요. $N$이 수열에 나타나지 않으면 -1을 출력하세요.

## 입력

~~~text
$N$
~~~

$1\leq N\leq10^{100}$인 정수입니다.

## 출력

답을 한 줄에 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
1333
~~~

#### 출력

~~~text
3
~~~

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
1334
~~~

#### 출력

~~~text
-1
~~~
