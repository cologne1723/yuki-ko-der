`N`개의 돌 더미가 있고 더미 `i`에는 `A_i`개의 돌이 있습니다. Alice부터 번갈아 다음 연산을 합니다.

돌이 남은 더미를 골라 하나 이상 제거합니다. 더미를 모두 비우면 보너스로 동전 하나를 얻습니다. 또는 가진 동전 하나를 버릴 수 있습니다. 더 이상 연산할 수 없는 사람이 패배합니다.

두 사람이 최적으로 플레이할 때 승자를 판정하세요.

## 제약

- `1 <= T <= 2 * 10^5`
- `1 <= N <= 2 * 10^5`, `1 <= A_i <= 10^9`
- 모든 테스트 케이스에서 `N`의 합은 `5 * 10^5` 이하입니다.

## 입력

테스트 케이스마다 `N`과 더미 크기가 주어집니다.

## 출력

각 테스트 케이스의 승자를 출력하세요.
