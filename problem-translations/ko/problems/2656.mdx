수직선 위의 슬라임 두 마리를 골라 임의의 위치로 이동시킨 뒤 합칠 수 있습니다. 이동 비용은 두 이동 거리의 합이고, 합쳐진 슬라임의 정수는 두 정수의 XOR입니다. 모든 합체 비용의 합을 $C$, 마지막 슬라임들의 정수 합을 $S$라 할 때 $C+S$의 최솟값을 구하세요.

## 조건

- $2\le N\le5000$
- $1\le X_1<\cdots<X_N\le10^9$, $1\le A_i<2^{30}$

## 입력

```text
$N$
$X_1$ $\cdots$ $X_N$
$A_1$ $\cdots$ $A_N$
```

## 출력

$C+S$의 최솟값을 출력하세요.
