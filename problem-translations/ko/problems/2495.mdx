세 수열 $A,B,C$와 각각의 부분집합 $S_A,S_B,S_C$가 주어질 때

$$\left(\sum_{i\in S_A}A_i\right)|S_B|+\left(\sum_{j\in S_B}B_j\right)|S_C|+\left(\sum_{k\in S_C}C_k\right)|S_A|$$

의 최댓값을 구하세요.

## 조건

- 각 수열 길이는 $1$ 이상 $10^5$ 이하입니다.
- 각 원소의 절댓값은 $3000$ 이하입니다.

## 입력

```text
NA NB NC
A1 ... ANA
B1 ... BNB
C1 ... CNC
```

## 출력

최댓값을 출력하세요.
