세 수열 $A,B,C$와 각각의 부분집합 $S_A,S_B,S_C$가 주어질 때

$$\left(\sum_{i\in S_A}A_i\right)\lvert S_B\rvert+\left(\sum_{j\in S_B}B_j\right)\lvert S_C\rvert+\left(\sum_{k\in S_C}C_k\right)\lvert S_A\rvert$$

의 최댓값을 구하세요.

## 조건

- 각 수열 길이는 $1$ 이상 $10^5$ 이하입니다.
- 각 원소의 절댓값은 $3000$ 이하입니다.

## 입력

```text
$N_A\ N_B\ N_C$
$A_1\ A_2\ \cdots\ A_{N_A}$
$B_1\ B_2\ \cdots\ B_{N_B}$
$C_1\ C_2\ \cdots\ C_{N_C}$
```

## 출력

최댓값을 출력하세요.
