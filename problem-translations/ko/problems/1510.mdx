## 문제

양의 정수 수열 $A$가 주어집니다. 다음 적분을 $998244353$로 나눈 값을 구하세요.

\[
\frac1\pi\int_{-\infty}^{\infty}\prod_{i=1}^{N}\frac1{x^2+A_i^2}\,dx
\]

## 입력

$N$과 $A_1,\ldots,A_N$이 주어집니다.

- $1\leq N\leq100$
- $1\leq A_i\leq10^6$

## 출력

적분값을 문제의 방식으로 $998244353$로 나눈 값을 출력하세요.
