## 문제 설명

어느 날 숙제로 다항식 나눗셈 문제가 나왔습니다. 하지만 당신은 다항식 나눗셈을 매우 어려워합니다.
그래서 프로그램을 만들어 컴퓨터에게 대신 계산하게 하기로 했습니다.

주어진 다항식을 $x^3-x$로 나눈 나머지를 출력하세요.

## 입력

```text
D
a_0 a_1 \ldots a_D
```

- $D$는 나누어지는 다항식의 차수입니다. $(0 \le D \le 10\,000)$
- $a_i$는 나누어지는 다항식의 정수 계수입니다. $(-100 \le a_i \le 100)$
- 나누어지는 다항식은 $a_Dx^D+a_{D-1}x^{D-1}+\ldots+a_2x^2+a_1x+a_0$입니다.
- $D \ge 1$이면 $a_D \ne 0$임이 보장됩니다.

## 출력

주어진 다항식을 $x^3-x$로 나눈 나머지를 출력하세요.

## 출력 형식

```text
D'
b_0 b_1 \ldots b_{D'}
```

- $D'$는 나머지 다항식의 차수입니다.
- $b_i$는 나머지 다항식의 계수입니다.
- 나머지 다항식은 $b_{D'}x^{D'}+b_{D'-1}x^{D'-1}+\ldots+b_2x^2+b_1x+b_0$입니다.
- $D' \ge 1$이면 $b_{D'} \ne 0$이어야 합니다.

답이 다항식 `0`인 경우 실제로는 0차식이 아니지만 여기서는 $D'=0$으로 출력하세요.

## 예제

### 예제 1

#### 입력

```text
5
1 1 1 0 0 1
```

#### 출력

```text
2
1 2 1
```

### 예제 2

#### 입력

```text
8
0 -5 0 4 0 1 -1 0 1
```

#### 출력

```text
0
0
```

실제로는 0차식이 아니지만 여기서는 0을 답으로 출력합니다.

### 예제 3

#### 입력

```text
5
-5 0 -1 1 1 1
```

#### 출력

```text
1
-5 2
```
