## 문제

처음 산 파스텔 세트 `A`와 어떤 색 하나가 사라진 세트 `B`가 주어집니다. 사라진 색 `S`를 출력하세요.

## 입력

두 파스텔 세트가 주어집니다.

## 출력

사라진 색을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
Red Blue Violet Red
Red Blue Red
```

#### 출력

```text
Violet
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
2
Blue Red
Red
```

#### 출력

```text
Blue
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
6
Red Red Red Red Red Red
Red Red Red Red Red
```

#### 출력

```text
Red
```
