## 문제 설명

길이가 $3$ 이상인 음이 아닌 정수 수열 $A$가 다음 조건을 만족하면 $A$를 **좋은 수열**이라고 합니다.

- $i=2,3,\cdots,|A|-1$에 대해 $|A_{i-1}-A_{i+1}|=A_i$가 성립합니다.

음이 아닌 정수 $X$, $Y$, $Z$가 주어집니다. $1$번째 원소가 $X$이고 마지막 원소가 $Y$이며, $1$번째와 마지막을 제외한 원소 중 $Z$를 포함하는 **좋은 수열** 중 가장 짧은 것 $1$개를 구성하세요.

조건을 만족하는 **좋은 수열**이 존재하지 않으면 $-1$을 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$X\ Y\ Z$
```

## 제한

- 입력은 모두 정수입니다.
- $0\leq X,Y,Z\leq 10^{12}$

## 출력

문제의 조건을 만족하는 **좋은 수열** 중 가장 짧은 것과 그 길이 $k$를 다음 형식으로 출력하세요.

```text
$k$
$A_1\ A_2\ \cdots\ A_k$
```

조건을 만족하는 **좋은 수열**이 존재하지 않으면 $-1$을 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 3 2
```

#### 출력

```text
3
5 2 3
```

$|5-3|=2$이므로 이는 좋은 수열입니다.

또한 $5$로 시작하고 $3$으로 끝나며, 중간에 $2$를 포함하므로 문제의 조건을 만족합니다.

길이가 $3$보다 짧은 좋은 수열은 존재하지 않으므로 이것이 유일한 답입니다.

### 예제 2 {file=""}

#### 입력

```text
0 0 1
```

#### 출력

```text
4
0 1 1 0
```

중간에 $1$을 여러 개 포함해도 괜찮습니다.

### 예제 3 {file=""}

#### 입력

```text
2025 523 2025
```

#### 출력

```text
-1
```

$1$번째와 마지막을 제외한 위치에 $2\,025$를 포함해야 합니다. 따라서 예를 들어 $[2\,025,1\,502,523]$은 문제의 조건을 만족하지 않습니다.
