## 문제

문자열 `S`의 끝에 소문자 하나를 추가한 뒤 문자를 임의의 순서로 재배열해 `T`를 만들 수 있으면 `T`를 `S`의 치마타그램이라고 합니다.

문자열 `S_1,...,S_N`이 주어질 때, 정확히 하나의 `S_i`의 치마타그램이 되는 문자열 `T`가 존재하는지 판정하고, 존재하면 하나 출력하세요.

## 제약

- `1 ≤ N ≤ 10^3`
- 각 문자열은 길이 1 이상 10 이하의 소문자 문자열입니다.

## 입력

```text
N
S_1
⋮
S_N
```

## 출력

조건을 만족하는 `T`를 출력하세요. 존재하지 않으면 `-1`을 출력하세요.
