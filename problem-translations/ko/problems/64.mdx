## 문제 설명

정수열 $\{F_k\}$를 다음 점화식으로 정의합니다.

$F_k=F_{k-1}\oplus F_{k-2}$ $(k \ge 2)$

여기서 $\oplus$는 비트 XOR 연산자입니다.
$F_0$, $F_1$이 주어질 때 $F_N$을 계산하세요.

## 입력

```text
F_0 F_1 N
```

$0 \le F_0,F_1,N \le 1\,000\,000\,000\,000\,000\,000$
이 값들은 32비트 정수형에 들어가지 않을 수 있습니다.

## 출력

$F_N$의 값을 한 줄에 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
88 79 2
```

#### 출력

```text
23
```

### 예제 2 {file=""}

#### 입력

```text
88 79 0
```

#### 출력

```text
88
```

### 예제 3 {file=""}

#### 입력

```text
88 79 82
```

#### 출력

```text
79
```
