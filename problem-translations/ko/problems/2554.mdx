MMA 문자열이란 두 종류의 알파벳으로 이루어진 길이 $3$의 문자열이며, 첫 번째 문자와 두 번째 문자가 같은 것을 말합니다.

길이 $N$인 영대문자 문자열 $S$가 주어집니다. $Q$개의 쿼리를 순서대로 처리하세요. 쿼리는 다음 두 종류 중 하나입니다.

## 쿼리

- `1 x c`: $S$의 $x$번째 문자를 $c$로 바꿉니다.
- `2 l r`: 부분 문자열 $S_lS_{l+1}\dots S_r$에서 연속일 필요가 없는 부분 수열 중 MMA 문자열인 것의 개수를 구합니다.

뽑은 부분 수열의 문자열이 같더라도 선택한 위치들의 집합이 다르면 다른 방법으로 셉니다.

## 조건

- $3 \le N \le 5 \times 10^4$
- $S$는 영대문자만으로 이루어진 길이 $N$의 문자열입니다.
- $1 \le Q \le 5 \times 10^4$
- $1 \le x \le N$
- $c$는 영대문자입니다.
- $1 \le l \le r \le N$
- $N,Q,x,l,r$는 정수입니다.

## 입력

```text
$N$
$S$
$Q$
쿼리 1
쿼리 2
$\vdots$
쿼리 $Q$
```

각 쿼리는 다음 형식 중 하나입니다.

```text
1 x c
```

```text
2 l r
```

## 출력

두 번째 종류의 쿼리 개수를 $q$라고 할 때, $q$줄을 출력하세요. $j$번째 줄에는 $j$번째 두 번째 종류 쿼리의 답을 출력하세요.
