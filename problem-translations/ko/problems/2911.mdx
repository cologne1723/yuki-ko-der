## 문제 설명

숫자 $0$과 $1$만으로 이루어진 문자열을 비트열이라고 합니다.

$2$개의 양의 정수 $N$, $M$과, 길이가 $N$인 비트열만을 원소로 가지는 원소 개수가 $M$인 집합 $S$가 주어집니다.

$S$가 좋은 비트열 집합이라는 것은 다음 $3$가지 조건을 모두 만족하는 것을 말합니다.

- 숫자 $1$만으로 이루어진 길이 $N$인 문자열이 $S$에 속합니다.
- $S$의 임의의 $2$개 원소 $s_0$, $s_1$에 대해, $s_0$과 $s_1$의 비트 AND가 $S$에 속합니다.
- $S$의 임의의 부분집합 $S'$에 대해, $S'$의 모든 원소의 비트 OR가 $S$에 속합니다.

단, 조건 $3$에서 $S'$의 모든 원소의 비트 OR란 숫자 $0$과 $1$만으로 이루어진 길이 $N$인 유일한 문자열 $s$를 말하며, $N$ 이하의 임의의 양의 정수 $n$에 대해 다음 $2$가지 조건을 만족합니다.

- $s$의 오른쪽에서 $n$번째 문자가 $1$이면, $S'$에 속하는 원소 중 오른쪽에서 $n$번째 문자가 $1$인 원소 $s'$가 존재합니다.
- $s$의 오른쪽에서 $n$번째 문자가 $0$이면, $S'$에 속하는 원소 중 오른쪽에서 $n$번째 문자가 $1$인 원소 $s'$가 존재하지 않습니다.

$S$가 좋은 비트열 집합인지 판정하세요.

### 배경

$N$ 이하의 양의 정수 전체의 집합을 $I_N$이라 하고, 각 $s \in S$에 대해 「$s$의 오른쪽에서 $i$번째 문자가 $1$이다」를 만족하는 $i \in I_N$ 전체의 집합을 $U_s$라 하겠습니다. 집합족 $\{U_s \mid s \in S\}$를 $\mathcal{O}_S$라 하면, $S$를 $I_N$의 부분집합으로 이루어진 집합족 $\mathcal{O}_S$로 옮길 수 있습니다.

현대 집합론에서 기하학을 정식화할 때는 위상 공간이라는 개념을 자주 사용합니다. 순서쌍 $(I_N,\mathcal{O}_S)$가 위상 공간이 되기 위한 필요충분조건은 다음 $3$가지 조건을 모두 만족하는 것입니다.

- $I_N$이 $\mathcal{O}_S$에 속합니다.
- $\mathcal{O}_S$의 임의의 $2$개 원소 $U_0$, $U_1$에 대해 $U_0 \cap U_1$이 $\mathcal{O}_S$에 속합니다.
- $\mathcal{O}_S$의 임의의 부분집합 $\mathcal{U}$에 대해 $\bigcup_{U \in \mathcal{U}} U$가 $\mathcal{O}_S$에 속합니다.

따라서 정의에 의해 이 조건은 $S$가 좋은 비트열 집합이라는 것과 동치입니다. 즉, 이 문제는 $(I_N,\mathcal{O}_S)$가 위상 공간인지 판정하는 문제와 같습니다.

## 입력

$S$의 원소에 $M$ 이하의 각 양의 정수 $m$으로 번호를 매겨 $s_m$이라 하겠습니다.

이때 입력은 다음 형식으로 표준 입력에서 $1+M$개의 줄에 걸쳐 주어집니다.

- $1$번째 줄에 $N$, $M$이 공백으로 구분되어 주어집니다.
- $M$ 이하의 각 양의 정수 $m$에 대해, $1+m$번째 줄에 $s_m$이 주어집니다.

```text
$N\ M$
$s_1$
$\vdots$
$s_M$
```

## 제한

입력은 다음 제한을 만족합니다.

- $N$은 $1 \leq N \leq 16$인 정수입니다.
- $M$은 $1 \leq M \leq \min \{2^N,2^{12}\}$인 정수입니다.
- $M$ 이하의 임의의 양의 정수 $m$에 대해, $s_m$은 숫자 $0$과 $1$만으로 이루어진 길이 $N$인 문자열입니다.

## 출력

$S$가 좋은 비트열 집합이면 `Yes`를, 그렇지 않으면 `No`를 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1
0
```

#### 출력

```text
No
```

$S = \{0\}$은 조건 $1$을 만족하지 않습니다. 실제로 $S$는 $0$ 이외의 원소를 가지지 않으며, 문자열 $0$은 숫자 $1$만으로 이루어진 문자열이 아닙니다.

또한 $(I_N,\mathcal{O}_S) = (\{1\},\{\{\}\})$입니다. $I_N \notin \mathcal{O}_S$이므로 $(I_N,\mathcal{O}_S)$는 위상 공간이 아닙니다.

### 예제 2 {file=""}

#### 입력

```text
1 1
1
```

#### 출력

```text
No
```

$S = \{1\}$은 조건 $3$을 만족하지 않습니다. 실제로 $S$의 부분집합 $S'$를 공집합으로 정하면 그 비트 OR는 $0$이지만, $0$은 $S$에 속하지 않습니다.

또한 $(I_N,\mathcal{O}_S) = (\{1\},\{\{1\}\})$입니다. $\mathcal{U} := \{\}$로 두면 $\mathcal{U} \subset \mathcal{O}_S$이지만 $\bigcup_{U \in \{\}} U = \{\} \notin \mathcal{O}_S$이므로 $(I_N,\mathcal{O}_S)$는 위상 공간이 아닙니다.

### 예제 3 {file=""}

#### 입력

```text
1 2
0
1
```

#### 출력

```text
Yes
```

$S = \{0,1\}$은 조건 $1$, $2$, $3$을 모두 만족하므로 좋은 비트열 집합입니다.

또한 $(I_N,\mathcal{O}_S) = (\{1\},\{\{\},\{1\}\})$입니다. 위상 공간을 아는 사람에게 말하자면 $(I_N,\mathcal{O}_S)$는 이산 위상 공간이면서 비이산 위상 공간입니다. 대수기하를 아는 사람에게 말하자면 $(I_N,\mathcal{O}_S)$는 $p$진수체 $\mathbb{Q}_p$에 대응하는 아핀 스킴 $\textrm{Spec}(\mathbb{Q}_p)$과 위상동형인 위상 공간입니다.

### 예제 4 {file=""}

#### 입력

```text
3 4
000
011
110
111
```

#### 출력

```text
No
```

$S = \{000,011,110,111\}$은 조건 $2$를 만족하지 않습니다. 실제로 $011$과 $110$은 $S$의 원소이지만, $2$개의 비트열을 비트 AND한 결과인 $010$은 $S$에 속하지 않습니다.

또한 $(I_N,\mathcal{O}_S) = (\{1,2,3\},\{\{\},\{2,3\},\{1,2\},\{1,2,3\}\})$입니다. $\{2,3\}$과 $\{1,2\}$는 $\mathcal{O}_S$의 원소이지만 $\{2,3\} \cap \{1,2\} = \{2\} \notin \mathcal{O}_S$이므로 $(I_N,\mathcal{O}_S)$는 위상 공간이 아닙니다.
