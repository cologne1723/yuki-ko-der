> **주의**
>
> **이 문제의 실행 시간 제한은 $6\,000$ms입니다.**

## 문제 설명

다음 문제를 생각합니다.

양의 정수 $N$이 주어집니다.

$N$을 서로 다른 소수 유한 개의 합으로 나타낼 수 있는지 판정하세요.

단, 소수 $1$개의 합은 그 소수 자체를 나타내는 것으로 합니다.

입력의 처음에 양의 정수 $T$가 주어집니다. $T$개의 문제에 답하세요.

### 배경

$4$ 이상의 임의의 짝수가 서로 다를 필요가 없는 $2$개의 소수의 합으로 나타내어질까요?

적어도 $4 \times 10^{18}$ 이하의 짝수에는 반례가 존재하지 않는다는 사실이 2014년에 Tomás Oliveira e Silva, Siegfried Herzog, Silvio Pardi에 의해 증명되었다고 합니다[1]. 하지만 실제로 반례가 존재하지 않는지는 알려져 있지 않습니다. 즉, 이는 수학의 미해결 문제이며, 반례가 존재하지 않는다는 추측을 골드바흐 추측이라고 합니다.

골드바흐 추측 자체를 푸는 것은 너무 어렵기 때문에, 그 주장을 약화한 여러 변형이 고안되었습니다. 예를 들어 정확히 $2$개가 아니라 최대 $6$개의 합이어도 된다는 버전은 1995년에 Olivier Ramaré에 의해 증명되었다고 합니다[2].

그렇다면 합을 취하는 개수에는 제한을 두지 않는 대신, 합에 사용할 수 있는 소수가 서로 달라야 한다고 요구하면 어떻게 될까요? 이번에는 이 문제를 생각해 봅니다.

## 입력

$T$ 이하의 각 양의 정수 $t$에 대해, $t$번째 문제의 입력 $N$을 $N_t$로 나타냅니다.

입력은 다음 형식으로 표준 입력에서 $2$개의 줄로 주어집니다.

- $1$번째 줄에 $T$가 공백으로 구분되어 주어집니다.
- $2$번째 줄에 $T$ 이하의 각 양의 정수 $t$에 대한 $N_t$가 $t$가 작은 순서대로 공백으로 구분되어 주어집니다.

```text
$T$
$N_1\ \cdots\ N_T$
```

## 제한

입력은 다음 제한을 만족합니다.

- $T$는 $1 \leq T \leq 10^5$를 만족하는 정수입니다.
- $T$ 이하의 임의의 양의 정수 $t$에 대해, $N_t$는 $1 \leq N_t$를 만족하는 정수입니다.
- **$\displaystyle\sum_{t=1}^{T} N_t \leq 10^{14}$입니다.**

부분점은 다음과 같습니다.

| 부분 문제 | 배점 | 추가 제한 |
| --- | ---: | --- |
| small | $25$점 ($10$%) | $N_t \leq 10^5$ |
| large | $225$점 ($90$%) | 없음 |

## 출력

$T$ 이하의 각 양의 정수 $t$에 대해, $N_t$를 서로 다른 소수 유한 개의 합으로 나타낼 수 있다면 `Yes`를, 나타낼 수 없다면 `No`를 $t$번째 줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
8
1 2 3 4 5 6 7 8
```

#### 출력

```text
No
Yes
Yes
No
Yes
No
Yes
Yes
```

$1$, $4$, $6$은 서로 다른 소수 유한 개의 합으로 나타낼 수 없습니다.

$2 = 2$, $3 = 3$, $5 = 5$, $7 = 7$, $8 = 3 + 5$는 서로 다른 소수 유한 개의 합으로 나타낼 수 있습니다.
