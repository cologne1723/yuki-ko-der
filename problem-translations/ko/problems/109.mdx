## 문제 설명

$N! \bmod M$을 구하세요.

## 입력

```text
$T$
$N_1\ M_1$
$\vdots$
$N_T\ M_T$
```

입력은 여러 테스트 케이스로 이루어집니다. 첫째 줄에 테스트 케이스 수를 나타내는 정수 $T$가 주어지고, 둘째 줄부터 각 테스트 케이스가 주어집니다.

## 제한

- $1 \le T \le 100$
- $1 \le M_i \le 1\,000\,000\,000$ $(1 \le i \le T)$
- $\max(0,M_i-100\,000) \le N_i \le 1\,000\,000\,000$ $(1 \le i \le T)$

## 출력

각 테스트 케이스에 대해 $N_i!$을 $M_i$로 나눈 나머지를 한 줄에 출력하고 줄 바꿈하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
0 2
5 100
999999936 999999937
1000000000 1
```

#### 출력

```text
1
20
999999936
0
```

$0!=1$입니다. $5!=120$이고 이를 $100$으로 나눈 나머지는 $20$입니다. $999\,999\,936! \equiv 999\,999\,936 \pmod{999\,999\,937}$입니다. 어떤 수든 $1$로 나눈 나머지는 $0$입니다.
