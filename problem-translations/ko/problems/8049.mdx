## 문제 설명

`Yes`를 $1$줄에 출력하세요.

## 입력

이 문제에서는 입력이 주어지지 않습니다.

## 제한

이 문제에서는 저지가 특수합니다.

서로 다른 $5$개의 저지가 내부에 준비되어 있습니다. 그중 통과한 저지의 개수에 따라 다음 점수가 주어집니다.

| 통과한 저지의 개수 | 점수 |
| ---: | ---: |
| $0$개 | $0$점 |
| $1$개 | $150$점 |
| $2$개 | $200$점 |
| $3$개 | $250$점 |
| $4$개 | $300$점 |
| $5$개 | $100$점 |

길이가 $64$자를 초과하는 문자열을 출력한 경우 저지의 정당성은 보장되지 않습니다.

또한 `Yes`를 출력하면 $5$개의 저지를 모두 통과한다는 것이 보장되며, 정확히 $4$개의 저지를 통과하도록 하는 출력이 존재한다는 것도 보장됩니다.

이 문제는 스코어 문제이므로, `CE`를 제외하고 제출 간격을 $5$분 이상 두어야 하는 제한이 있다는 점에도 주의하세요.

## 출력

`Yes`를 $1$줄에 출력하세요.
