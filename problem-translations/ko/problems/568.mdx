## 문제

JOI는 어떤 합숙의 선발을 진행하는 것 같습니다.

이 대회에서는 푼 시간이나 WA 수를 전혀 고려하지 않고, 단순히 완전 정답 수가 중요합니다.

본선에 낼 문제 중 3문제는 정해졌지만 A와 B 두 문제만 정해지지 않았습니다.

두 문제의 난이도는 각각 0 이상 100001 이하의 정수로 독립적으로 정할 수 있습니다.

JOI가 개최하는 본선에는 n명의 참가자가 있습니다. 1 ≤ n ≤ 100000

합숙 예산이 없으므로, 위원회는 남은 두 문제의 난이도를 적절히 조정해 2솔 이상인 사람을 m명 이상으로 만들면서 3솔 이상인 사람 수를 최소화하려고 합니다. 1 ≤ m ≤ n

각 사람의 능력에 따라 (Xi,Ai,Bi)가 주어집니다.

Xi는 이미 정해진 문제 중 완전 정답을 낼 수 있는 수입니다.

전체적인 A 문제의 난이도를 SA라 할 때 Ai ≥ SA이면 A 문제를 완전히 풀 수 있다는 뜻입니다. B도 같은 방식으로 Bi ≥ SB이면 풀 수 있습니다.

그때 3솔 이상인 사람 수를 출력하세요.

이 문제는 허구이며 실제 조직이나 인물과는 관계가 없습니다.

## 입력

```text
N M
xi ai bi
```

1 ≤ n ≤ 100000, 1 ≤ m ≤ n

0 ≤ Xi ≤ 3, 0 ≤ Ai,Bi ≤ 100000

## 출력

마지막에는 줄바꿈을 출력하세요.
