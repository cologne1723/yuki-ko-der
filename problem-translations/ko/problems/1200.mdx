## 문제 설명

초콜릿 $X$개와 쿠키 $Y$개가 있습니다. $A$명의 아이에게 초콜릿을 $B$개씩 나누어 주었더니 $C$개가 남았고, 쿠키를 $C$개씩 나누어 주었더니 $B$개가 남았습니다. 단, 과자를 가능한 만큼 모두 나누어 주었다는 뜻은 아닙니다.

양의 정수 $X,Y$가 주어질 때, 이 조건을 만족하는 양의 정수쌍 $A,B,C$의 개수를 구하세요.

## 입력

첫 줄에 테스트 케이스 수 $S$가 주어집니다. 이어지는 $S$줄에 각 테스트 케이스가 주어집니다.

```text
S
X Y
\vdots
X Y
```

- $1\leq S\leq 10^4$
- $1\leq X,Y\leq 5\times10^8$
- 입력은 모두 정수입니다.

## 출력

각 테스트 케이스의 답을 한 줄에 하나씩 출력하세요. 마지막에 줄바꿈을 넣으세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}
#### 입력
```text
1
23 13
```
#### 출력
```text
3
```

조건을 만족하는 조합은 $(A,B,C)=(2,11,1),(11,2,1),(3,7,2)$입니다.

### 예제 2 {file="01_sample_02.txt"}
#### 입력
```text
5

8753 4321

875432 86557
```
#### 출력
```text
0
0
0
0
0
```
