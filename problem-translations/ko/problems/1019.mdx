## 문제 설명

좌표 평면 위에서 $x$, $y$ 좌표가 모두 정수인 점을 **격자점**이라고 합니다.

세 꼭짓점이 모두 격자점인 삼각형의 넓이는 반드시 $\frac{1}{2}$ 이상입니다. 이제부터 격자점으로 이루어진 넓이 $\frac{1}{2}$인 삼각형을 **최소 격자 삼각형**이라고 부릅니다.

우시코 씨는 최소 격자 삼각형을 매우 좋아합니다. 특히 좌표가 큰 삼각형을 발견했을 때 큰 기쁨을 얻습니다. 우시코 씨가 얻는 기쁨의 총합을 계산하세요.

$N$을 양의 정수라고 할 때, 다음 값을 계산하세요.

- 세 점 $O(0,0)$, $P(p_1,p_2)$, $Q(q_1,q_2)$가 최소 격자 삼각형을 이룰 때 그 **기쁨**을 $|p_1| + |p_2| + |q_1| + |q_2|$로 정의합니다.
- $OP \le \sqrt{N}$ 및 $OQ \le \sqrt{N}$을 만족하는 최소 격자 삼각형 $OPQ$에 대한 기쁨의 총합을 $998244353$으로 나눈 나머지를 답하세요.

같은 삼각형($P$, $Q$만 서로 바꾼 경우)은 한 번만 센다는 점에 주의하세요.

## 입력

```text
$N$
```

## 제한

$1 \le N \le 10^{12}$

## 출력

한 줄에 기쁨의 총합을 $998244353$으로 나눈 나머지를 출력하세요.

마지막에 줄바꿈하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1
```

#### 출력

```text
8
```

예를 들어 $P(1,0)$, $Q(0,1)$은 최소 격자 삼각형을 이룹니다. 이 삼각형에서 얻는 기쁨은 $2$입니다.

이 삼각형을 $O$를 중심으로 $90$도씩 회전하여 얻는 삼각형 $4$개가 계산 대상입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
25
```

#### 출력

```text
1208
```

예를 들어 $P(4,-3)$, $Q(-3,2)$는 최소 격자 삼각형을 이룹니다. 이 삼각형에서 얻는 기쁨은 $12$입니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1000000
```

#### 출력

```text
741919871
```

$998244353$으로 나눈 나머지를 출력합니다.
