## 문제 설명

타로는 늘 잔돈을 저금통에 넣어 저축하고 있습니다.
저금통 안에 돈이 어느 정도 모였으므로 타로는 은행에 가서 교환하기로 했습니다.

타로의 나라에는 통화로 $1\,000$엔 지폐와 $100$엔, $25$엔, $1$엔 동전이 있습니다. 그 밖의 금액인 지폐나 동전은 없습니다.

교환은 다음과 같이 할 수 있습니다.

- $1$엔 동전 $25$개를 $25$엔 동전 $1$개로 교환
- $25$엔 동전 $4$개를 $100$엔 동전 $1$개로 교환
- $100$엔 동전 $10$개를 $1\,000$엔 지폐 $1$장으로 교환

저금통에 들어 있는 각 동전의 개수가 주어질 때, 교환하여 손에 남는 동전의 총 개수가 최소가 되도록 했을 때 최종적으로 가진 동전의 총 개수를 출력하세요.

교환은 수수료 없이 몇 번이든 할 수 있으며, 교환 전후에 총액이 변해서는 안 됩니다.

## 입력

```text
$L$
$M$
$N$
```

$100$엔, $25$엔, $1$엔 동전의 개수를 나타내는 정수 $L$, $M$, $N$이 각각 한 줄에 주어집니다.

## 제한

$0 \le L,M,N \le 1\,000$

## 출력

동전의 총 개수를 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
7
20
10
```

#### 출력

```text
12
```

$25$엔 동전 $20$개를 $100$엔 동전 $5$개로 교환하고, 다시 $100$엔 동전 $10$개를 $1\,000$엔 지폐로 교환하는 것이 동전 수를 가장 줄입니다.

### 예제 2 {file=""}

#### 입력

```text
0
0
0
```

#### 출력

```text
0
```

저금통이 비어 있었습니다.
