## 문제 설명

타로는 늘 잔돈을 저금통에 넣어 저축하고 있습니다.
저금통 안에 돈이 어느 정도 모였으므로 타로는 은행에 가서 환전하기로 했습니다.

타로의 나라에는 통화로 1000엔 지폐와 100엔, 25엔, 1엔 동전이 있습니다. 그 밖의 금액인 지폐나 동전은 없습니다.

환전은 다음과 같이 할 수 있습니다.

- 1엔 동전 25개를 25엔 동전 1개로 교환
- 25엔 동전 4개를 100엔 동전 1개로 교환
- 100엔 동전 10개를 1000엔 지폐 1장으로 교환

저금통에 들어 있는 각 동전의 개수가 주어질 때, 환전하여 손에 남는 동전의 총 개수가 최소가 되도록 했을 때 최종적으로 가진 동전의 총 개수를 출력하세요.

환전은 수수료 없이 몇 번이든 할 수 있으며, 환전 전후에 총액이 변해서는 안 됩니다.

## 입력

```text
L
M
N
```

첫째 줄에 100엔 동전의 개수 $L$이 주어집니다. $(0 \le L \le 1000)$
둘째 줄에 25엔 동전의 개수 $M$이 주어집니다. $(0 \le M \le 1000)$
셋째 줄에 1엔 동전의 개수 $N$이 주어집니다. $(0 \le N \le 1000)$

## 출력

동전의 총 개수를 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
7
20
10
```

#### 출력

```text
12
```

25엔 동전 20개를 100엔 동전 5개로 환전하고, 다시 100엔 동전 10개를 1000엔 지폐로 환전하는 것이 동전 수를 가장 줄입니다.

### 예제 2 {file=""}

#### 입력

```text
0
0
0
```

#### 출력

```text
0
```

저금통이 비어 있었습니다.
