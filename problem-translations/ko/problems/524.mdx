## 문제

당신은 꿈을 꾸었습니다.

기르던 개 치와와가 마왕 Yekocidur에게 납치되는 꿈입니다.

치와와를 구하기 위해 모험을 거듭해 마침내 마왕 Yekocidur를 쓰러뜨렸습니다.

하지만 너무 쉽게 쓰러뜨린 것이 의문스러워 치와와를 찾던 중, 치와와가 뭔가 엄청난 상태가 되어 있는 것을 발견했습니다.

치와와 옆에는 동전이 올라간 접시가 몇 개 있습니다. 아무래도 이 동전을 사용하는 게임에서 이기면 치와와가 원래대로 돌아오는 듯합니다.

게임의 규칙은 다음과 같습니다.

* 당신이 선공, 치와와가 후공으로 번갈아 동전을 가져갑니다.
* 한 번에 몇 개든 가져갈 수 있지만, 한 번마다 반드시 같은 접시 하나에서만 가져가야 합니다.
* 반드시 한 개 이상 가져가야 합니다.
* 동전이 없는 상태에서 자신의 차례가 되면 패배합니다. 게임은 끝나며, 패배하지 않은 쪽이 승리합니다.

접시는 N개이고, i번째 접시(1-indexed)에는 동전이 i개 놓여 있습니다.

N이 주어질 때 당신이 이기는지 판정하세요. 양쪽 모두 항상 이기기 위해 최선을 다한다고 가정합니다.

## 입력

```text
N
```

정수 N (0 < N < 2^32)이 한 줄에 주어집니다.

## 출력

당신이 이기면 O를, 치와와가 이기면 X를 한 줄에 출력하세요. 인용 부호는 출력하지 않습니다.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3
```

출력:

```text
X
```

접시에 놓인 동전의 수는 [1, 2, 3]입니다. 안타깝게도 이 경우 치와와는 원래대로 돌아오지 못합니다. 기적을 기대해 봅시다.

### 샘플 2 {file="sample2.in"}

입력:

```text
788
```

출력:

```text
O
```

### 샘플 3 {file="sample3.in"}

입력:

```text
33554432
```

출력:

```text
O
```
