$N$개의 도시가 있고 도시 $i$의 고도는 $H_i$이다냥. 도시 $i$의 순간이동기를 사용하면 고도가 $T_i$ 이하인 다른 도시로 이동할 수 있다냥. 각 질의에 대해 도시 $A_k$에서 $B_k$로 가는 최소 순간이동 횟수를 구하고, 불가능하면 $-1$을 출력하라냥.

## 조건

- $2\le N,Q\le2\times10^5$
- $1\le H_i,T_i\le10^9$
- $A_k\ne B_k$

## 입력

```text
N
H_1 \cdots H_N
T_1 \cdots T_N
Q
A_1 B_1
\vdots
A_Q B_Q
```

## 출력

각 질의의 답을 한 줄에 하나씩 출력하라냥.
