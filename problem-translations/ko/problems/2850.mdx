## 문제 설명

やきとりくん은 슬라임을 만들려고 합니다.

슬라임 $1$개를 만들려면 세탁용 풀 $A$ml와 붕사 $B$g가 필요합니다.

やきとりくん은 세탁용 풀 $C$ml와 붕사 $D$g를 가지고 있습니다.

やきとりくん이 만들 수 있는 슬라임 개수의 최댓값을 구하세요.

## 입력

```text
$A\ B\ C\ D$
```

입력은 다음 형식으로 주어집니다.

- $A$, $B$, $C$, $D$는 정수입니다.

## 제한

- $0 \leq A,B,C,D \leq 1\,000$
- $1 \leq A+B$
- 입력은 모두 정수입니다.

## 출력

やきとりくん이 만들 수 있는 슬라임 개수의 최댓값을 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
100 5 250 25
```

#### 출력

```text
2
```

슬라임 $1$개를 만들면 세탁용 풀과 붕사가 각각 $150$ml, $20$g 남습니다.

슬라임 $2$개를 만들면 세탁용 풀과 붕사가 각각 $50$ml, $15$g 남습니다.

슬라임 $3$개째는 세탁용 풀이 부족하므로 만들 수 없습니다.

따라서 やきとりくん이 만들 수 있는 슬라임 개수는 최대 $2$개이므로 $2$를 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
0 1 0 38
```

#### 출력

```text
38
```
