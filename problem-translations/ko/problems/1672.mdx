HTTP 상태 코드는 웹 서버 응답의 의미를 나타내는 세 자리 양의 정수입니다. 이 문제에서는 백의 자리가 4 또는 5일 때에만 오류 코드라고 정의합니다.

상태 코드 `S`가 오류 코드인지 판정하세요.

## 제약

- `100 <= S <= 599`

## 입력

`S`가 주어집니다.

## 출력

오류 코드이면 `Yes`, 아니면 `No`를 출력하세요.
