양의 정수 $N,A,B$가 주어집니다. $S_i\in\{-1,1\}$인 수열 $S$에 대해

$$f(S)=A\sum_{i=1}^{N-1}S_iS_{i+1}-B\sum_{i=1}^N S_i$$

로 정의할 때 $f(S)$의 최솟값을 구하세요.

## 입력

```text
N A B
```

$2\le N\le10^{10}$, $1\le A,B\le1000$입니다.

## 출력

최솟값을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 2 1
```

#### 출력

```text
-5
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
10 3 6
```

#### 출력

```text
-33
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
666 222 999
```

#### 출력

```text
-517704
```
