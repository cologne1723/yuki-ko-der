## 문제 설명

$N$장의 꽃잎을 가진 꽃이 $1$송이 있습니다. 神無さん과 宮田さん은 이 꽃을 사용해 꽃점과 같은 게임을 합니다.

게임은 神無さん이 선공으로 시작하며, $2$명은 번갈아 꽃에서 꽃잎을 $1$장부터 $3$장까지 뽑습니다.

꽃잎을 $1$장 뽑은 뒤에는 「좋아」, $2$장째를 뽑은 뒤에는 「싫어」, $3$장째를 뽑은 뒤에는 「좋아」가 되는 식으로, 꽃잎을 $1$장 뽑을 때마다 「좋아」에서 시작해 「좋아」와 「싫어」 상태가 번갈아 바뀝니다.

게임의 승패는 마지막으로 꽃잎을 뽑은 뒤 「좋아」가 되었다면 마지막에 뽑은 사람이 승리하고, 「싫어」가 되었다면 마지막에 뽑은 사람이 패배합니다.

게임 시작 시 꽃잎의 수 $N$이 주어질 때, 양쪽이 최선의 수를 두었을 경우 선공인 神無さん이 이길 수 있다면 `Yes`, 그렇지 않다면 `No`를 출력하세요.

## 입력

```text
$N$
```

$N$은 게임 시작 시 꽃잎의 수를 나타냅니다.

## 제한

- $1 \le N \le 1\,000$
- $N$은 정수입니다.

## 출력

`Yes` 또는 `No`를 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
7
```

#### 출력

```text
Yes
```

神無さん이 $1$번째 수로 $3$장을 뽑으면 $\to$「좋아」$\to$「싫어」$\to$「좋아」가 되고 남은 꽃잎은 $4$장이 됩니다. 그러면 宮田さん이 남은 $4$장에서 어떻게 뽑더라도 다음에 神無さん이 남은 꽃잎을 모두 뽑을 수 있으므로 $\to$「싫어」$\to$「좋아」$\to$「싫어」$\to$「좋아」가 되어 神無さん이 이길 수 있습니다.

### 예제 2 {file=""}

#### 입력

```text
724
```

#### 출력

```text
Yes
```
