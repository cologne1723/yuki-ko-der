## 문제

`H×W` 격자의 각 칸에 0~9의 촉매를 최대 하나 배치합니다. 모든 칸을 중심으로 하는 `3×3` 범위의 촉매 합이 `X`가 되는 배치의 수를 `998244353`으로 나눈 나머지를 구하세요.

## 입력

`T`개의 테스트 케이스에 `W_i H_i X_i`가 주어집니다.

## 출력

각 테스트 케이스의 배치 수를 출력하세요.
