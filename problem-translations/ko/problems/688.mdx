## 문제

다음 조건을 만족하는 수열 $b$를 구성하세요.

- $b$에서 0개 이상의 수를 고를 수 있습니다. 길이가 $N$이면 선택 방법은 $2^N$가지입니다.
- 고른 수의 합이 2가 되는 선택 방법이 정확히 $K$가지입니다.
- $b_i$는 0 또는 1입니다.
- 수열 길이 $N$은 1 이상 30 이하입니다.

## 입력

```text
K
```

$0\le K\le1{,}000{,}000{,}000$이며 조건을 만족하는 수열이 존재함이 보장됩니다.

## 출력

첫째 줄에 $b$의 길이 $N$, 둘째 줄에 수열 값을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
4
```

출력:

```text
4
0 0 1 1
```

3,4번을 고르는 경우와 여기에 1번 또는 2번 또는 둘 다를 추가하는 4가지가 합 2가 됩니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
80
```

출력:

```text
8
0 1 0 1 1 0 1 1
```

합이 정확히 2가 되는 선택 방법이 80가지입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
96
```

출력:

```text
8
0 1 0 1 1 0 1 0
```
