## 문제

`N`개의 상자에 원소가 하나씩 들어 있고, 기계는 처음 1번 상자를 가리킵니다. 한 번의 작업으로 기계를 왼쪽 또는 오른쪽 인접 상자로 이동하거나 현재 상자의 원소를 촬영할 수 있습니다. 촬영에는 비용이 없고 이동에는 1의 비용이 듭니다.

주어진 `B_1,...,B_Q`를 순서대로 촬영하는 최소 이동 비용을 구하세요. 촬영 후 기계의 위치는 다음 작업으로 이어집니다.

## 제약

- `1 ≤ N,Q ≤ 1000`
- `1 ≤ A_i,B_j ≤ 10^9`
- 각 `B_j`는 어떤 `A_i`와 같습니다.

## 입력

```text
N Q
A_1 ... A_N
B_1 ... B_Q
```

## 출력

최소 비용을 출력하세요.
