## 문제

수열 `A`에서 서로 다른 네 정수 `a<b<c<d`를 고르는 방법 중

`10^a + 9^b + 7^c + 5^d`를 `P`로 나눈 나머지가 `Q`인 방법의 수를 구하세요.

## 제약

- `4 ≤ N ≤ 200`
- `2 ≤ Q < P ≤ 10^5`
- `1 ≤ A_i ≤ 2 × 10^6`이며 모든 `A_i`는 서로 다릅니다.

## 입력

```text
N P Q
A_1 A_2 ... A_N
```

## 출력

조건을 만족하는 선택 방법의 수를 출력하세요.
