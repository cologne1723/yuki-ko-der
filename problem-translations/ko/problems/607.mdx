## 문제

철도 회사 A사는 올해 777주년을 맞았습니다. 이를 기념해 ‘777 캠페인’을 개최합니다.

이 캠페인은 N량 편성 열차를 M개 역 구간 운행하여, 어떤 구간에서 승차 인원 합이 777명이 되는 연속한 여러 차량(또는 한 차량에 777명)이 있으면 성공하는 행사입니다. 각 구간마다 직전 구간과 비교한 승차 인원 증감 데이터가 주어질 때 캠페인이 성공했는지 출력하세요. 처음에는 모든 차량의 승차 인원이 0명이고, 인원 상한은 없습니다. 모든 구간에서 승차 인원이 0명 이상임이 보장됩니다.

## 입력

```text
N M
a1_1 a1_2 ... a1_N
...
aM_1 aM_2 ... aM_N
```

정수 $N,M$은 각각 열차가 $N$량 편성이고 $M$개 역 구간을 운행했음을 뜻합니다. 이어지는 $M$개 줄에는 직전 구간과 비교한 각 차량의 승차 인원 증감이 주어집니다. 양수는 증가, 음수는 감소입니다.

- $1 \le N,M \le 1000$
- $-1000 \le a_{i,j} \le 1000$

## 출력

캠페인이 성공할 수 있으면 YES, 그렇지 않으면 NO를 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
5 3
10 700 0 0 3
0 0 70 7 -1
1 1 1 1 1
```

출력:

```text
YES
```

각 구간의 승차 인원은 각각 10 700 0 0 3, 10 700 70 7 2, 11 701 71 8 3입니다. 두 번째 구간에서 2, 3, 4번째 차량의 합이 777명이므로 성공합니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
6 1
350 350 70 2 3 4
```

출력:

```text
NO
```

1, 2, 3, 5, 6번째 차량의 합은 777명이지만 연속한 차량이 아니므로 실패합니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
5 5
100 0 100 0 100
200 100 200 100 200
300 200 300 200 300
100 -100 -200 -100 200
0 -200 -330 -200 -793
```

출력:

```text
YES
```

최종 승차 인원은 700 0 70 0 7입니다. 0명인 차량이 끼어 있지만 1~5번째 차량은 연속해 있고 합이 777명이므로 성공합니다.
