## 문제 설명

길이가 $N$인 음이 아닌 정수열 $(A_1,A_2,...,A_N)$이 주어집니다.

$1\leq i\leq N$을 만족하는 $1$개의 정수 $i$를 선택하여 $A_i$를 $1$ 감소시키는 연산을 최대 $K$회까지 원하는 횟수만큼 수행할 수 있습니다. 연산을 수행하지 않아도 됩니다.

연산을 적절히 수행했을 때 $\displaystyle\sum_{i=0}^{N} |A_i-A_{i+1}|$의 최솟값을 구하세요. 단, $A_0=A_{N+1}=0$으로 간주합니다.

## 입력

```text
$N\ K$
$A_1\ A_2\ \cdots\ A_N$
```

## 제한

- $1\leq N\leq 2\times 10^5$
- $0\leq K\leq 2\times 10^{14}$
- $0\leq A_i\leq 10^9$
- 입력은 모두 정수입니다.

이 문제에는 서브태스크에 의한 부분점이 설정되어 있습니다.

| 서브태스크 이름 | 배점 | 제한 |
| --- | ---: | --- |
| 서브태스크 $1$ | $5$% | $N=1$ |
| 서브태스크 $2$ | $5$% | $N=2$ |
| 서브태스크 $3$ | $20$% | $N\leq 7,\ K\leq 7$ |
| 서브태스크 $4$ | $30$% | $N\leq 2\,000,\ K\leq 2\,000$ |
| 서브태스크 $5$ | $10$% | $N\leq 2\,000$ |
| 서브태스크 $6$ | $30$% | 추가 제한 없음 |

## 출력

답을 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
6 11
1 6 9 2 3 1
```

#### 출력

```text
6
```

$A_2$를 $4$회, $A_3$을 $7$회 감소시킨 $A=(1,2,2,2,3,1)$은 $\displaystyle\sum_{i=0}^{N} |A_i-A_{i+1}|=6$이 됩니다.

답을 $6$ 미만으로 만들 수 없으므로 $6$이 답입니다.

### 예제 2 {file=""}

#### 입력

```text
5 100
0 0 0 0 0
```

#### 출력

```text
0
```

연산을 $0$회 수행해도 됩니다.
