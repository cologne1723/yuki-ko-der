> **주의**
>
> 실행 시간 제한은 $6\,000$밀리초입니다. 실행 시간이 빠듯하므로 빠른 언어·실행 환경을 사용하는 것을 권장합니다.
>
> 참고로 출제자 풀이의 실행 시간은 C++에서 $163$밀리초, PyPy3에서 $4\,309$밀리초, Python3에서는 $10\,000$밀리초를 초과하여 `TLE`가 됩니다.

## 문제 설명

처음에 $2$개의 양의 정수 $N$, $Q$와 길이가 $N$인 음이 아닌 정수열 $A$가 주어집니다.

아래에서 설명하는 $Q$개의 질의를 입력으로 주어진 순서대로 처리하여 $A$를 갱신하세요.

각 질의가 주어졌을 때의 $A$의 길이를 $n$이라 하면, 각 질의는 $n$ 이하의 양의 정수 $i$, 음이 아닌 정수 $x$, 그리고 $1 \leq \ell \leq r \leq n+1$을 만족하는 양의 정수 $\ell$, $r$로 이루어진 순서 있는 $4$개의 정수 $(i,x,\ell,r)$입니다.

$Q$ 이하의 각 양의 정수 $q$에 대해, $q$번째 질의를 $(i_q,x_q,\ell_q,r_q)$로 나타냅니다.

질의 $(i,x,\ell,r)$를 다음과 같이 처리합니다.

1. 먼저 $A$의 $i$번째 성분 바로 뒤에 $x$를 삽입하여 $A$를 갱신합니다.
2. 그다음 갱신된 $A$에 대해 구간 합 $\displaystyle\sum_{j=\ell}^{r} A_j$를 계산합니다. 이하 이 값을 이 질의에 대한 답이라고 합니다.

단, $A$와 그 길이 이하의 각 양의 정수 $i$에 대해 $A_i$는 $A$의 $i$번째 성분을 나타냅니다.

## 입력

입력은 다음 형식으로 표준 입력에서 $2+Q$개의 줄에 걸쳐 주어집니다.

```text
$N\ Q$
$A_1\ \cdots\ A_N$
$i_1\ x_1\ \ell_1\ r_1$
$\vdots$
$i_Q\ x_Q\ \ell_Q\ r_Q$
```

- $1$번째 줄에 $N$, $Q$가 반각 공백으로 구분되어 주어집니다.
- $2$번째 줄에 $N$ 이하의 각 양의 정수 $i$에 대한 $A_i$가 $i$가 작은 순서대로 반각 공백으로 구분되어 주어집니다.
- $Q$ 이하의 각 양의 정수 $q$에 대해, $2+q$번째 줄에 $i_q$, $x_q$, $\ell_q$, $r_q$가 반각 공백으로 구분되어 주어집니다.

## 제한

입력은 다음 제한을 만족합니다.

- $N$은 $1 \leq N \leq 6\times 10^4$를 만족하는 정수입니다.
- $Q$는 $1 \leq Q \leq 2\times 10^4$를 만족하는 정수입니다.
- $N$ 이하의 임의의 양의 정수 $i$에 대해 $A_i$는 $0 \leq A_i \leq 10^4$를 만족하는 음이 아닌 정수입니다.
- $Q$ 이하의 임의의 양의 정수 $q$에 대해 다음을 만족합니다.
  - $i_q$는 $1 \leq i_q \leq N+q-1$를 만족하는 정수입니다.
  - $x_q$는 $0 \leq x_q \leq 10^4$를 만족하는 정수입니다.
  - $\ell_q$, $r_q$는 $1 \leq \ell_q \leq r_q \leq N+q$를 만족하는 정수입니다.

## 출력

$Q$ 이하의 각 양의 정수 $q$에 대해, $q$번째 줄에 $q$번째 질의에 대한 답을 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1
0
1 1 1 2
```

#### 출력

```text
1
```

처음에는 $A=(0)$으로 주어집니다.

$1$번째 질의 $(i_1,x_1,\ell_1,r_1)=(1,1,1,2)$에 의해 먼저 $A$가

$ (A_1=A_{i_1},x_1)=(0,1) $

로 갱신되고, 그다음

$ \displaystyle\sum_{j=\ell_1}^{r_1} A_j=A_1+A_2=0+1=1 $

을 출력합니다.

이번에는 $Q=1$이므로 이것으로 모든 질의를 처리했습니다.

### 예제 2 {file=""}

#### 입력

```text
1 2
1
1 2 2 2
2 3 1 3
```

#### 출력

```text
2
6
```

처음에는 $A=(1)$으로 주어집니다.

$1$번째 질의 $(i_1,x_1,\ell_1,r_1)=(1,2,2,2)$에 의해 먼저 $A$가

$ (A_1=A_{i_1},x_1)=(1,2) $

로 갱신되고, 그다음

$ \displaystyle\sum_{j=\ell_1}^{r_1} A_j=A_2=2 $

를 출력합니다.

$2$번째 질의 $(i_2,x_2,\ell_2,r_2)=(2,3,1,3)$에 의해 먼저 $A$가

$ (A_1,A_2=A_{i_2},x_2)=(1,2,3) $

로 갱신되고, 그다음

$ \displaystyle\sum_{j=\ell_2}^{r_2} A_j=A_1+A_2+A_3=1+2+3=6 $

을 출력합니다.

이번에는 $Q=2$이므로 이것으로 모든 질의를 처리했습니다.

### 예제 3 {file=""}

#### 입력

```text
2 2
0 1
1 2 2 3
2 3 1 4
```

#### 출력

```text
3
6
```

처음에는 $A=(0,1)$로 주어집니다.

$1$번째 질의 $(i_1,x_1,\ell_1,r_1)=(1,2,2,3)$에 의해 먼저 $A$가

$ (A_1=A_{i_1},x_1,A_2)=(0,2,1) $

로 갱신되고, 그다음

$ \displaystyle\sum_{j=\ell_1}^{r_1} A_j=A_2+A_3=2+1=3 $

을 출력합니다.

$2$번째 질의 $(i_2,x_2,\ell_2,r_2)=(2,3,1,4)$에 의해 먼저 $A$가

$ (A_1,A_2=A_{i_2},x_2,A_3)=(0,2,3,1) $

로 갱신되고, 그다음

$ \displaystyle\sum_{j=\ell_2}^{r_2} A_j=A_1+A_2+A_3+A_4=0+2+3+1=6 $

을 출력합니다.

이번에는 $Q=2$이므로 이것으로 모든 질의를 처리했습니다.
