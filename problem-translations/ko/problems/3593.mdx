## 문제 설명

각 원소가 $0$ 이상 $8$ 이하인 정수로 이루어진 $9 \times 9$ 행렬에 대하여, 다음 $3$가지 조건을 모두 만족하면 이를 "스도쿠 행렬"이라고 합니다.

1. 각 행에는 $0$부터 $8$까지의 정수가 정확히 $1$개씩 나타납니다.
2. 각 열에는 $0$부터 $8$까지의 정수가 정확히 $1$개씩 나타납니다.
3. 행렬을 $3 \times 3$ 블록으로 나누었을 때, 각 블록에는 $0$부터 $8$까지의 정수가 정확히 $1$개씩 나타납니다.

이제 $2$개의 스도쿠 행렬 $A$, $B$를 생각합니다. 이 [행렬의 곱](https://ja.wikipedia.org/wiki/%E8%A1%8C%E5%88%97%E3%81%AE%E4%B9%97%E6%B3%95#%E4%BA%8C%E3%81%A4%E3%81%AE%E8%A1%8C%E5%88%97%E3%81%AE%E7%A9%8D) $C = AB$를 계산하고, $C$의 각 원소를 $9$로 나눈 나머지로 바꾼 행렬을 $C'$이라고 합니다.

여러분의 목표는 $C'$도 스도쿠 행렬이 되도록 하는 스도쿠 행렬 $A$, $B$의 조를 $1$개 찾아 출력하는 것입니다.

**※ 이 문제는 Output-only(출력만) 문제입니다. 입력은 주어지지 않습니다.**

## 입력

입력은 주어지지 않습니다.

## 제한

- 출력하는 행렬 $A$, $B$는 모두 $9 \times 9$ 스도쿠 행렬이어야 합니다.
- 출력하는 행렬 $A$, $B$의 각 원소는 $0$ 이상 $8$ 이하인 정수여야 합니다.
- 조건을 만족하는 $(A, B)$의 조가 존재함이 보장됩니다. 여러 조가 존재하는 경우에는 어느 것을 출력해도 정답으로 인정됩니다.

## 출력

행렬 $A$의 원소를 처음 $9$개 행에, 행렬 $B$의 원소를 이어지는 $9$개 행에 출력하세요.

각 행은 $9$개의 정수를 공백으로 구분하여 출력하세요. 전체적으로 $18$개 행을 출력하게 됩니다.

```text
$A_{1,1}\ A_{1,2}\ \cdots\ A_{1,9}$
$\vdots$
$A_{9,1}\ A_{9,2}\ \cdots\ A_{9,9}$
$B_{1,1}\ B_{1,2}\ \cdots\ B_{1,9}$
$\vdots$
$B_{9,1}\ B_{9,2}\ \cdots\ B_{9,9}$
```
