길이 `N`인 양의 정수 수열 `A`가 주어집니다. 곱이 `K`의 배수인 비어 있지 않은 부분 수열의 개수를 `10^9+7`로 나눈 나머지를 구하세요.

## 제약

- `1 <= N <= 2000`
- `1 <= K <= 10^9`
- `1 <= A_i <= 10^18`

## 입력

`N K`와 수열 `A`가 주어집니다.

## 출력

조건을 만족하는 부분 수열의 개수를 출력하세요.
