## 문제

치킨은 문자 '(' $N$개와 문자 ')' $N$개를 가지고 있습니다. 이 두 종류의 문자를 모두 사용해 올바른 괄호열을 만들 수 있는 경우의 수를 구하세요.

## 정의

- 빈 문자열은 올바른 괄호열입니다.
- 문자열 $s$가 올바른 괄호열이면 $(s)$도 올바른 괄호열입니다.
- 문자열 $s,t$가 모두 올바른 괄호열이면 $s$와 $t$를 이어 붙인 문자열도 올바른 괄호열입니다.

## 입력

~~~text
$N$
~~~

$1\leq N\leq13$

## 출력

올바른 괄호열의 개수를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
2
~~~

#### 출력

~~~text
2
~~~

(())와 ()()의 두 가지뿐입니다. 예를 들어 ())(는 괄호가 완전히 닫히지 않았으므로 올바르지 않습니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
3
~~~

#### 출력

~~~text
5
~~~

((())), ()()(), ()(()), (())(), (()())의 5가지가 조건을 만족합니다. 세 번째와 네 번째 문자열은 서로 다르게 셉니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
11
~~~

#### 출력

~~~text
58786
~~~

많군요.
