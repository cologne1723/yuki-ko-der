## 문제

주의: 이야기를 읽는 것보다 샘플 1, 2, 3을 읽는 편이 빠릅니다.

Yuuki와 Kouda는 문자열을 사용하는 액세서리를 만들었습니다.

액세서리는 알파벳이 한 글자 그려진 돌 몇 개를 끈으로 일렬로 연결한 것입니다. 알파벳은 대문자이며, 하나의 액세서리에 같은 알파벳은 두 개 없습니다.

돌을 끈으로 연결하면 앞에서 끝을 향하는 방향으로 문자열을 읽을 수 있습니다.

Yuuki와 Kouda는 같은 문자열의 액세서리를 2개 만들어 하나씩 가져갔습니다.

10년 후, 두 사람은 서로의 액세서리를 가지고 모였습니다. 그러나 두 액세서리의 끈이 약해 여러 군데 끊어져 있었습니다. 테스트 케이스에는 전혀 끊어지지 않은 경우도 있습니다.

두 사람은 원래 어떤 문자열이 적혀 있었는지 완전히 잊었습니다. 다행히 돌은 하나도 잃어버리지 않고 모두 남아 있습니다.

두 사람은 서로의 부서진 액세서리를 단서로 원래 문자열을 떠올릴 수 있을까요? 가능하면 그 문자열을 출력하고, 불가능하면 -1을 출력하세요.

## 입력

```text
N
A0
A1
…
A{N-1}
M
B0
B1
…
B{M-1}
```

N은 Yuuki 액세서리 조각의 개수입니다. 1 ≤ N ≤ 26입니다.

Ai는 Yuuki 액세서리의 i번째 조각에서 읽을 수 있는 문자열입니다.

M은 Kouda 액세서리 조각의 개수입니다. 1 ≤ M ≤ 26입니다.

Bi는 Kouda 액세서리의 i번째 조각에서 읽을 수 있는 문자열입니다.

문자열의 왼쪽에서 오른쪽 방향이 액세서리의 시작에서 끝으로 향하는 방향에 해당합니다.

문자열에 포함된 문자는 모두 영문 대문자입니다.

하나의 액세서리에 같은 문자가 2개 이상 포함되지 않습니다.

Yuuki 액세서리에 포함된 알파벳은 반드시 Kouda 액세서리에도 포함됩니다.

## 출력

원래 액세서리에 적혀 있던 문자열을 하나로 확정할 수 있으면 한 줄에 출력하세요.

확정할 수 없으면 -1을 한 줄에 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
2
YUKI
CODER
3
YU
KICO
DER
```

출력:

```text
YUKICODER
```

Yuuki는 “Y-U-K-I”와 “C-O-D-E-R”이 연결된 두 조각을 가지고 있습니다.

Kouda는 “Y-U”, “K-I-C-O”, “D-E-R”이 연결된 세 조각을 가지고 있습니다.

먼저 Kouda의 정보로 “I”와 “C”가 이 순서로 연결되어 있음을 알 수 있습니다. 또한 Yuuki의 “Y-U-K-I”와 “C-O-D-E-R”은 원래 이 순서로 연결되어 있었음을 알 수 있습니다.

따라서 서로 다른 알파벳으로 이루어진 액세서리의 문자열은 “Y-U-K-I-C-O-D-E-R”로 확정됩니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
2
EA
T
2
T
EA
```

출력:

```text
-1
```

문자열은 “EAT”일 수도 있고 “TEA”일 수도 있습니다. 가능한 경우가 2가지이므로 원래 문자열을 알 수 없습니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
1
X
1
X
```

출력:

```text
X
```

액세서리는 “X” 한 글자뿐이므로 답도 “X”입니다.

IDPWXHQVMA
