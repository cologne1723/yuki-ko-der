## 문제 설명

문자열 $X$가 `good`을 연속 부분 문자열로 포함할 때, $X$를 **좋은 문자열**이라고 합니다.

`d`, `o`, `g`의 $3$종류 문자만으로 이루어진 같은 길이의 문자열 $S$, $T$가 주어집니다. $S$, $T$는 모두 좋은 문자열이 아닙니다.

문자열 $S$에 대해 다음 연산을 $0$회 이상 원하는 횟수만큼 수행할 수 있습니다.

- 현재 문자열에서 **서로 인접한 $2$개의 문자**를 선택하여 서로 교환합니다.
- 단, 교환한 뒤의 문자열이 **좋은 문자열**이 된다면 이 교환 연산을 수행할 수 없습니다.

$Q$개의 테스트 케이스가 주어집니다. 각 테스트 케이스에 대해 이 연산만을 사용하여 $S$를 $T$와 같게 만들 수 있는지 판정하세요.

이 연산은 더 형식적으로 다음과 같이 나타낼 수 있습니다.

- 현재 문자열을 $X=x_1x_2\cdots x_{|X|}$라고 하고, $1 \leq i < |X|$를 만족하는 정수 $i$를 선택하여
  $X'=x_1x_2\cdots x_{i-1}x_{i+1}x_ix_{i+2}\cdots x_{|X|}$로 둡니다.
- 이때 $X'$가 `good`을 연속 부분 문자열로 포함하지 않는 경우에만 $X$를 $X'$로 갱신합니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $q$번째 테스트 케이스를 $\mathrm{case}_q$라고 나타냅니다($1 \leq q \leq Q$).

```text
$Q$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_Q$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$S$
$T$
```

여기서 $S$, $T$는 해당 테스트 케이스의 문자열을 나타냅니다.

## 제한

- $1 \leq Q \leq 100\,000$
- $1 \leq |S| = |T|$
- 모든 테스트 케이스에서 $|S|$의 합은 $200\,000$ 이하입니다.
- $S$, $T$는 `d`, `o`, `g`만으로 이루어진 문자열입니다.
- $S$, $T$는 모두 좋은 문자열이 아닙니다.
- $Q$는 정수입니다.

## 출력

$Q$줄에 걸쳐 출력하세요. $i$번째 줄에는 $i$번째 테스트 케이스에서 $S$를 $T$와 같게 만들 수 있다면 `Yes`를, 그렇지 않다면 `No`를 출력하세요.

## 예제

### 예제 1 {file="01_sample_1.txt"}

#### 입력

```text
3
dog
god
gooodd
gdoood
doggod
odddog
```

#### 출력

```text
Yes
No
No
```

$1$번째 테스트 케이스에서는 예를 들어 `dog` $\to$ `odg` $\to$ `ogd` $\to$ `god`와 같이 연산할 수 있습니다.

$2$번째 테스트 케이스에서는 어떤 방식으로 연산해도 좋은 문자열을 거치지 않고 $S$를 $T$와 같게 만들 수 없습니다.
