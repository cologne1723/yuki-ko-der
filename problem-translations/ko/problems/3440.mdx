## 문제 설명

$1$ 이상 $5$ 이하의 정수 $N$이 주어집니다. 문자열 `Short`의 앞에서부터 $N$번째 문자까지 출력하세요.

## 입력

```text
$N$
```

입력은 정수 $N$으로 주어집니다.

## 제한

- $1 \leq N \leq 5$
- 입력은 모두 정수입니다.

## 출력

문제의 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
```

#### 출력

```text
Sho
```
