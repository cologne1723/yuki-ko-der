## 문제 설명

책상 위에 패널이 $N$개 나란히 놓여 있습니다. 각 패널에는 소문자 알파벳이 쓰여 있습니다. 이 패널들을 재배열하여 여러 열로 만들고, 각 열에 있는 패널을 위에서부터 읽어 문자열을 만듭니다.

각 열에서 만들어진 문자열이 `yuki`보다 사전순으로 크면 행복도가 $1$ 증가합니다. 행복도를 최대로 만들 때의 값을 구하세요.

같은 문자열을 여러 번 만들어도 됩니다.

## 입력

```text
$N$
$S$
```

$1$번째 줄에 패널의 개수를 나타내는 정수 $N$이 주어집니다.

$2$번째 줄에 길이 $N$의 소문자 알파벳 문자열 $S$가 주어집니다.
$i$번째 패널에 쓰인 문자는 $S$의 $i$번째 문자입니다.

## 제한

- $1 \le N \le 100\,000$

## 출력

얻을 수 있는 행복도의 최댓값을 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
xyz
```

#### 출력

```text
2
```

`yx`와 `z`라는 $2$개의 문자열을 만들 수 있으며, 모두 `yuki`보다 사전순으로 큽니다.

### 예제 2 {file=""}

#### 입력

```text
4
yuki
```

#### 출력

```text
0
```

문자열 `yuki`는 `yuki`와 같으므로 사전순으로 크지 않습니다.

### 예제 3 {file=""}

#### 입력

```text
3
zzz
```

#### 출력

```text
3
```

같은 문자열을 여러 번 만들어도 됩니다.

### 예제 4 {file=""}

#### 입력

```text
11
kyuukyuusya
```

#### 출력

```text
3
```
