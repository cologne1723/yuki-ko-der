다음 조건을 모두 만족하는 $N$개의 문자열 $(S_1,S_2,\ldots,S_N)$을 하나 출력하라냥.

$S_i$는 `(`와 `)`로만 이루어지고, $|S_i|\ge1$이며, 전체 길이는 $N^2$ 이하이어야 한다냥. $(1,2,\ldots,N)$의 순열 $P$ 중 $S_{P_1}+S_{P_2}+\cdots+S_{P_N}$이 올바른 괄호열이 되는 순열이 정확히 하나 존재해야 한다냥. 여기서 올바른 괄호열은 빈 문자열이거나, 올바른 괄호열 두 개의 연결이거나, 올바른 괄호열을 괄호로 감싼 문자열이다냥.

## 조건

- $2\le N\le8$

## 입력

```text
N
```

## 출력

$S_i$를 $i$번째 줄에 출력하라냥. 조건을 만족하는 답이 여러 개라면 아무거나 출력해도 된다냥.
