구별되는 공 `N`개를 `M`명에게 나눠 줍니다. 공을 받지 못하는 사람이나 공이 있어도 됩니다.

조건 `X_i`를 받은 공의 수가 `i`의 배수라는 뜻으로 정의합니다. `i`번째 사람은 `X_{A_{i,1}},...,X_{A_{i,k_i}}` 중 하나 이상을 만족하지 않으면 화를 냅니다.

아무도 화내지 않도록 공을 나누는 방법의 수를 소수 `90001`로 나눈 나머지를 구하세요.

## 제약

- `1 <= N <= 10^200000`
- `1 <= M <= 10`
- `1 <= k_i <= 6`, `1 <= A_{i,j} <= 6`

## 입력

`N M`과 각 사람의 조건 목록이 주어집니다.

## 출력

답을 `90001`로 나눈 나머지를 출력하세요.
