길이 $N$의 비음이 아닌 정수열을 두 부분 수열 $B,C$로 나누어, 두 부분 수열의 XOR가 모두 0이 되도록 할 수 있는지 판정하세요. 두 부분 수열은 모두 비어 있지 않아야 합니다.

## 조건

- $2\le N\le5\times10^5$
- $0\le A_i\le5000$

## 입력

```text
$N$
$A_1$ $A_2$ $\cdots$ $A_N$
```

## 출력

가능하면 `Yes`, 불가능하면 `No`를 출력하세요.
