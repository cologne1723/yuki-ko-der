## 문제

당신은 예전에 바다 위를 떠다니는 배를 타고 있었습니다.

배는 세계에 고정된 XY 좌표계에서 점 $(x_a,y_a)$에 있었고, 방향 $\theta_a$를 향하고 있었습니다. 방향은 수학에서 사용하는 극좌표의 방향과 같습니다. 배에도 배에 고정된 XY 좌표계가 설치되어 있으며, 배의 방향을 X축으로 삼습니다. 이 좌표계는 배가 움직이면 함께 움직입니다.

바다에는 절대 움직이지 않는 말뚝 두 개가 있습니다. 말뚝 1은 세계 좌표계의 $(x_{11},y_{11})$에, 말뚝 2는 $(x_{12},y_{12})$에 있습니다. 배에 설치된 장치로 배 좌표계에서 본 두 말뚝의 좌표를 측정할 수 있습니다.

얼마 후 배가 떠내려가 현재 위치를 알 수 없게 되었습니다. 그래서 배가 예전 위치와 방향에 그대로 있다고 가정하고, 예전 배의 위치와 장치로 측정한 두 말뚝의 좌표를 이용해 말뚝의 ‘겉보기 세계 좌표’를 계산했습니다. 말뚝 1과 2의 겉보기 세계 좌표는 각각 $(x_{21},y_{21})$, $(x_{22},y_{22})$였습니다.

겉보기 세계 좌표와 말뚝의 실제 좌표를 비교해 현재 배의 위치를 계산할 수 있다는 것을 알아냈습니다. 현재 배의 세계 좌표계에서 본 위치 $(x_b,y_b)$와 방향 $\theta_b$를 구하세요.

## 입력

~~~text
xa ya θa
x11 y11
x12 y12
x21 y21
x22 y22
~~~

$x_a,y_a,\theta_a$는 예전 배의 세계 좌표와 방향이고, 실수로 주어집니다.

$x_{11},y_{11}$부터 $x_{12},y_{12}$까지는 두 말뚝의 세계 좌표이고, 실수로 주어집니다.

$x_{21},y_{21}$부터 $x_{22},y_{22}$까지는 현재 두 말뚝의 ‘겉보기 세계 좌표’이고, 실수로 주어집니다.

말뚝 1과 말뚝 2는 구별할 수 있으며, 두 말뚝의 위치는 서로 다릅니다.

$0^\circ\leq\theta_a\leq360^\circ$

$-10000\leq x_a,y_a,x_{11},\ldots,y_{22}\leq10000$

두 실제 말뚝 사이의 유클리드 거리와 두 겉보기 좌표 사이의 유클리드 거리는 최소 $10^{-9}$의 정밀도로 같습니다.

## 출력

~~~text
xb yb θb
~~~

$x_b,y_b,\theta_b$는 현재 배의 세계 좌표와 방향인 실수입니다.

현재 배의 좌표와 방향을 사용해 $(x_{11},y_{11})$, $(x_{12},y_{12})$를 새로운 겉보기 좌표로 변환했을 때, 각각이 $(x_{21},y_{21})$, $(x_{22},y_{22})$와 유클리드 거리 $10^{-5}$ 미만이면 정답으로 인정합니다. $\theta_b$를 $0^\circ$ 이상 $360^\circ$ 이하로 제한할 필요는 없습니다.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
0 0 90
0 1
-1 1
1 0
1 1
~~~

#### 출력

~~~text
0 0 180
~~~

말뚝 1이 $(0,1)$에서 $(1,0)$으로, 말뚝 2가 $(-1,1)$에서 $(1,1)$으로 이동한 것처럼 보이게 하려면 배 좌표계의 위쪽을 $+x$, 왼쪽을 $+y$로 정하면 됩니다. 이런 좌표계를 만들려면 배가 추가로 90° 회전하면 됩니다.

0.0 0.0 180.0으로 출력해도 정답입니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
1 2 0
3 3
4 4
2 2
3 3
~~~

#### 출력

~~~text
2 3 0
~~~

말뚝 1이 $(3,3)$에서 $(2,2)$로, 말뚝 2가 $(4,4)$에서 $(3,3)$으로 이동한 것처럼 보이게 하려면 배 좌표계의 원점이 세계 좌표 $(1,1)$을 지나도록 정하면 됩니다. 그러려면 배를 $x$ 방향으로 1, $y$ 방향으로 1 이동시키면 됩니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
1 1 90
2 1
2 0
0 -3
-1 -3
~~~

#### 출력

~~~text
-2 2 180
~~~

회전과 평행 이동을 조합하면 이와 같이 됩니다.
