## 문제 설명

사람이 $2N$명 있고, 순서대로 사람 $i\ (1\leq i\leq 2N)$라고 부릅니다. 각 사람은 정직한 사람이거나 거짓말쟁이입니다.

사람 $i\ (1\leq i\leq N)$는 사람 $P_i\ (1\leq P_i\leq N,\ i\neq P_i)$가 정직한 사람인지 거짓말쟁이인지 말합니다.

사람 $i$가 정직한 사람이라면, 사람 $P_i$가 정직한 사람일 때는 「사람 $P_i$는 정직한 사람이다」라고 말하고, 사람 $P_i$가 거짓말쟁이일 때는 「사람 $P_i$는 거짓말쟁이다」라고 말합니다.

반대로 사람 $i$가 거짓말쟁이라면, 사람 $P_i$가 정직한 사람일 때는 「사람 $P_i$는 거짓말쟁이다」라고 말하고, 사람 $P_i$가 거짓말쟁이일 때는 「사람 $P_i$는 정직한 사람이다」라고 말합니다.

또한 사람 $(i+N)\ (1\leq i\leq N)$은 사람 $i$의 발언 내용을 말합니다.

사람 $(i+N)$이 정직한 사람이라면, 사람 $i$가 「사람 $P_i$는 정직한 사람이다」라고 말했을 때는 「사람 $i$는 『사람 $P_i$는 정직한 사람이다』라고 말했다」라고 말하고, 사람 $i$가 「사람 $P_i$는 거짓말쟁이다」라고 말했을 때는 「사람 $i$는 『사람 $P_i$는 거짓말쟁이다』라고 말했다」라고 말합니다.

반대로 사람 $(i+N)$이 거짓말쟁이라면, 사람 $i$가 「사람 $P_i$는 정직한 사람이다」라고 말했을 때는 「사람 $i$는 『사람 $P_i$는 거짓말쟁이다』라고 말했다」라고 말하고, 사람 $i$가 「사람 $P_i$는 거짓말쟁이다」라고 말했을 때는 「사람 $i$는 『사람 $P_i$는 정직한 사람이다』라고 말했다」라고 말합니다.

다음 조건을 모두 만족하도록 각 사람 $i\ (\boldsymbol{1}\leq i\leq \boldsymbol{2N})$을 정직한 사람 또는 거짓말쟁이로 정할 수 있다면 `Yes`를, 어떻게 정하더라도 조건 중 $1$가지 이상을 만족하지 못한다면 `No`를 출력하세요.

- 주어진 $A_i\ (1\leq i\leq N)$에 대해, $A_i=0$이면 사람 $(i+N)$이 「사람 $i$는 『사람 $P_i$는 정직한 사람이다』라고 말했다」라고 말하도록, $A_i=1$이면 사람 $(i+N)$이 「사람 $i$는 『사람 $P_i$는 거짓말쟁이다』라고 말했다」라고 말하도록 정해져 있습니다.
- 주어진 $K$에 대해 사람 $i\ (\boldsymbol{1}\leq i\leq \boldsymbol{2N})$ 중 정직한 사람이 정확히 $K$명입니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ K$
$P_1\ P_2\ P_3\ \ldots\ P_N$
$A_1\ A_2\ A_3\ \ldots\ A_N$
```

## 제한

- 입력은 모두 정수입니다.
- $2\leq N\leq 1\,000$
- $0\leq K\leq 2N$
- $1\leq P_i\leq N\ (1\leq i\leq N)$
- $i\neq P_i\ (1\leq i\leq N)$
- $A_i\in\{0,1\}\ (1\leq i\leq N)$

## 출력

조건을 만족하도록 정직한 사람 또는 거짓말쟁이로 정할 수 있다면 `Yes`를, 정할 수 없다면 `No`를 출력하고 마지막에 개행하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 5
2 3 1
0 0 1
```

#### 출력

```text
Yes
```

사람 $1,2,3,4,5$가 정직한 사람인 경우를 생각합니다.

사람 $1$은 「사람 $2$는 정직한 사람이다」라고 말하고, 사람 $2$는 「사람 $3$은 정직한 사람이다」라고 말하며, 사람 $3$은 「사람 $1$은 정직한 사람이다」라고 말합니다.

따라서 사람 $4$는 「사람 $1$은 『사람 $2$는 정직한 사람이다』라고 말했다」라고 말하고, 사람 $5$는 「사람 $2$는 『사람 $3$은 정직한 사람이다』라고 말했다」라고 말하며, 사람 $6$은 「사람 $3$은 『사람 $1$은 거짓말쟁이다』라고 말했다」라고 말합니다.

이는 조건을 만족하도록 정하는 방법이므로 `Yes`를 출력합니다.

$0\leq K\leq 2N$임에 주의하세요.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
2 0
2 1
0 1
```

#### 출력

```text
No
```

모든 사람이 거짓말쟁이인 경우에는 $A_1=0,\ A_2=1$의 조건을 만족하지 않습니다.
