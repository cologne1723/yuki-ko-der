## 문제 설명

정수 $N$이 주어집니다. `Hello world!`를 $N$줄 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

## 제한

- $0 \leq N \leq 1.3\times 10^{6}$
- 입력은 모두 정수입니다.

## 출력

`Hello world!`를 $N$줄 출력하세요.

마지막에 개행 문자를 출력하세요.
