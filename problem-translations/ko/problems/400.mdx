## 문제 설명

`<`와 `>`로 이루어진 문자열이 있습니다. 이 문자열을 거울에 비추어 좌우 반전하면 어떻게 되는지 알아봅시다. 자세한 내용은 예제, 특히 예제 $2$를 확인하세요.

## 입력

$S$는 `<`와 `>`로 이루어진 문자열입니다.

```text
$S$
```

## 제한

- $1 \leq \lvert S\rvert \leq 20$

## 출력

거울에 비추어 좌우 반전한 문자열을 한 줄에 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
<<<
```

#### 출력

```text
>>>
```

좌우 반전은 바로 이런 것입니다.

### 예제 2 {file=""}

#### 입력

```text
<>>
```

#### 출력

```text
<<>
```

### 예제 3 {file=""}

#### 입력

```text
>>><<<
```

#### 출력

```text
>>><<<
```

문자열이 좌우 대칭이면 좌우 반전해도 같아집니다.

### 예제 4 {file=""}

#### 입력

```text
><<><<<><><
```

#### 출력

```text
><><>>><>><
```
