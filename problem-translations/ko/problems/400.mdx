## 문제

`<`와 `>`로 이루어진 문자열이 있습니다. 이 문자열을 거울에 비추어 좌우 반전하면 어떻게 되는지 알아봅시다. 자세한 내용은 샘플, 특히 샘플 2를 확인하세요.

## 입력

문자열 S가 주어집니다. S는 `<`와 `>`로 이루어진 문자열이며, 길이는 1 ≤ |S| ≤ 20입니다.

```text
S
```

## 출력

거울에 비추어 좌우 반전한 문자열을 한 줄에 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
<<<
```

### 샘플 1 출력 {file="sample1.out"}

```text
>>>
```

좌우 반전은 바로 이런 것입니다.

### 샘플 2 {file="sample2.in"}

```text
<>>
```

### 샘플 2 출력 {file="sample2.out"}

```text
<<>
```

### 샘플 3 {file="sample3.in"}

```text
>>><<<
```

### 샘플 3 출력 {file="sample3.out"}

```text
>>><<<
```

문자열이 좌우 대칭이면 좌우 반전해도 같아집니다.

### 샘플 4 {file="sample4.in"}

```text
><<><<<><><
```

### 샘플 4 출력 {file="sample4.out"}

```text
><><>>><>><
```
