길이 `2N`인 수열 `X`가 처음에 `X_i=i`, `X_{i+N}=i`를 만족합니다. 길이 `2N`인 수열 `A`가 주어질 때, 다음 연산을 원하는 횟수만큼 수행해 `X`를 `A`로 만들 수 있는지 판정하세요.

`X_l=X_r`인 `l<r`을 골라 구간 `[l,r]`을 뒤집습니다.

## 제약

- `1 <= T <= 100`
- `1 <= N <= 1000`
- `1 <= A_i <= N`
- 모든 테스트 케이스에서 `N`의 합은 `1000` 이하입니다.

## 입력

테스트 케이스 수 `T`와 각 테스트 케이스의 `N,A`가 주어집니다.

## 출력

각 테스트 케이스에 대해 가능 여부를 출력하세요.
