## 문제

정수 $N$이 십진법으로 두 자리 수인지 판정하세요.

## 입력

$1\leq N\leq999$인 정수 $N$이 주어집니다.

## 출력

두 자리 수이면 `Yes`, 아니면 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
17
```

#### 출력

```text
Yes
```

### 예제 2 {file=""}

#### 입력

```text
368
```

#### 출력

```text
No
```

### 예제 3 {file=""}

#### 입력

```text
9
```

#### 출력

```text
No
```
