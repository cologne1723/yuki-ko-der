## 문제 설명

어떤 온라인 저지에 $N$개의 제출이 순서대로 이루어졌습니다. 이 제출들은 각각 서로 다른 저지 서버에 할당되었으며, 제출 $i$의 실행 시간은 $A_i$밀리초입니다.

제출 $i$가 제출 $j$보다 먼저 이루어졌는데($i<j$) 실행 시간이 더 길어서($A_i>A_j$) 결과가 반환되는 순서가 뒤집히는 경우를 **역전**이라고 합니다.

역전 횟수를 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$A_1\ A_2\ \ldots\ A_N$
```

$1$번째 줄에 제출 수를 나타내는 정수 $N$이 주어집니다.

$2$번째 줄에 각 제출의 실행 시간을 나타내는 정수 $A_1,A_2,\ldots,A_N$이 주어집니다.

## 제한

- 모든 입력은 정수입니다.
- $1\leq N\leq 200\,000$
- $1\leq A_i\leq 10^9$

## 출력

역전 횟수를 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
3 1 4 1
```

#### 출력

```text
3
```

제출 $1$($3$ms)과 제출 $2$($1$ms): 제출 $2$의 결과가 먼저 반환됩니다 → 역전

제출 $1$($3$ms)과 제출 $4$($1$ms): 제출 $4$의 결과가 먼저 반환됩니다 → 역전

제출 $3$($4$ms)과 제출 $4$($1$ms): 제출 $4$의 결과가 먼저 반환됩니다 → 역전

### 예제 2 {file=""}

#### 입력

```text
3
1 2 3
```

#### 출력

```text
0
```

실행 시간이 제출 순서대로 짧은 것부터 나열되어 있으므로 역전은 일어나지 않습니다.

### 예제 3 {file=""}

#### 입력

```text
3
3 2 1
```

#### 출력

```text
3
```

모든 쌍에서 역전이 일어납니다.
