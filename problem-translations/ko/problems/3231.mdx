## 문제 설명

소수 $p=10^9+7$로 둡니다. 정수 $a,b$에 대해 $a-b$가 $p$로 나누어떨어질 때, "$a,b$는 합동이다"라고 하며 $a\equiv b$로 나타냅니다.

행렬 $A=(A_{i,j})$, $B=(B_{i,j})$의 각 성분 $A_{i,j}$와 $B_{i,j}$가 합동일 때 $A\equiv B$로 나타냅니다.

정수를 성분으로 갖는 $2\times2$ 행렬 $A,B$가 주어집니다. 정수를 성분으로 갖는 $2\times2$ 행렬

$P=\begin{pmatrix}a&b\\c&d\end{pmatrix}$

중 다음 $2$가지 조건을 모두 만족하는 것이 존재하는지 판정하세요.

- $ad-bc\not\equiv0$
- $PA\equiv BP$

존재한다면 `Yes`를, 존재하지 않는다면 `No`를 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$A_{1,1}\ A_{1,2}$
$A_{2,1}\ A_{2,2}$
$B_{1,1}\ B_{1,2}$
$B_{2,1}\ B_{2,2}$
```

입력의 모든 값은 정수입니다. 행렬 $A$와 $B$는 다음과 같이 정의됩니다.

$A=\begin{pmatrix}A_{1,1}&A_{1,2}\\A_{2,1}&A_{2,2}\end{pmatrix}$, $B=\begin{pmatrix}B_{1,1}&B_{1,2}\\B_{2,1}&B_{2,2}\end{pmatrix}$

## 제한

- $p=10^9+7$는 소수입니다.
- $0\le A_{i,j},B_{i,j}<p$

## 출력

`Yes` 또는 `No`를 출력하세요.

출력 마지막에는 줄바꿈을 넣으세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 3
1 3
102 999999865
69 999999911
```

#### 출력

```text
Yes
```

$P=\begin{pmatrix}3&13\\2&9\end{pmatrix}$로 하면

$P\begin{pmatrix}3&3\\1&3\end{pmatrix}\equiv\begin{pmatrix}102&-142\\69&-96\end{pmatrix}P$가 됩니다.

${\rm mod}\,10^9+7$에서는 $-142\equiv 999\,999\,865$, $-96\equiv 999\,999\,911$임에 주의하세요.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 0
0 2
1 0
0 8
```

#### 출력

```text
No
```

고윳값이 다르므로 닮음일 수 없습니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
0 1

0 0
```

#### 출력

```text
No
```
