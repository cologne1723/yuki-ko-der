`H`행 `W`열 격자의 각 칸은 빈칸 `.`, 단단한 벽 `#`, 부술 수 있는 벽 `@` 중 하나입니다. 로봇은 `(x_s,y_s)`에서 출발해 `(x_t,y_t)`에 도착하려 합니다.

출발 전에 부술 수 있는 벽을 원하는 개수 `x`개 부술 수 있으며 비용은 `P*x`입니다. 이후 빈칸으로 상하좌우 이동할 수 있고, 방향별 이동 비용은 각각 `U,D,R,L`입니다.

총 비용 `K` 이하로 목적지에 도착할 수 있으면 `Yes`, 그렇지 않으면 `No`를 출력하세요.

## 제약

- `2 <= H,W <= 100`
- `0 <= U,D,R,L <= 100`, `0 <= K <= 10^13`, `0 <= P <= 10^9`
- 각 칸은 `.`, `#`, `@` 중 하나입니다.
- 시작점과 도착점은 서로 다른 빈칸입니다.

## 입력

격자 크기, 이동 및 파괴 비용, 격자, 시작점과 도착점이 주어집니다.

## 출력

조건을 만족하면 `Yes`, 만족하지 않으면 `No`를 출력하세요.
