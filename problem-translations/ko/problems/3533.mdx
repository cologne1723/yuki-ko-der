## 문제 설명

$N\times N$ 크기의 $2$차원 격자가 있습니다. 이 격자의 위에서 $i$번째($1\leq i\leq N$) 행, 왼쪽에서 $j$번째($1\leq j\leq N$) 열에 있는 칸을 칸 $(i,j)$라고 합니다.

칸 $(1,1)$에서 인접한 칸으로 이동하는 것을 $0$회 이상 반복하여 칸 $(N,N)$에 도달하는 경로 중, 같은 칸을 $2$번 이상 지나지 않는 경로를 **좋은 경로**라고 합니다.

$N$이 주어질 때, **좋은 경로**의 총 개수를 구하세요. 답은 매우 커질 수 있으므로 $2$로 나눈 나머지를 구하세요.

여러 테스트 케이스에 대해 문제를 해결하세요.

### **좋은 경로**의 형식적 정의

칸의 좌표 전체의 집합을 $I=\lbrace (i,j)\mid i,j\in\lbrace 1,2,\cdots,N\rbrace\rbrace$라고 합니다.

이때 **좋은 경로**란 다음 조건을 모두 만족하는 수열 $X=(X_1,X_2,\cdots,X_K)$입니다.

- $i=1,2,\cdots,K$에 대해 $X_i\in I$입니다.
- $X_1=(1,1)$입니다.
- $X_K=(N,N)$입니다.
- $X_1,X_2,\cdots,X_K$는 서로 다릅니다.
- $1\leq i\leq K-1$인 임의의 정수 $i$에 대해, $X_i$가 나타내는 칸과 $X_{i+1}$이 나타내는 칸은 변을 $1$개 공유하여 인접합니다.
  - 즉, $X_i=(i_1,j_1)$, $X_{i+1}=(i_2,j_2)$를 만족하는 $i_1,j_1,i_2,j_2$를 택하면 $|i_1-i_2|+|j_1-j_2|=1$입니다.

경로 $A,B$는 다음 중 $1$가지를 만족할 때에만 서로 다른 경로로 셉니다.

- $|A|\neq |B|$입니다.
- $|A|=|B|$이고, 어떤 $i$($1\leq i\leq |A|$)에 대해 $A_i\neq B_i$입니다.

여기서 $|A|,|B|$는 각각 수열 $A,B$의 길이를 나타냅니다.

### 여러 테스트 케이스

이 문제의 입력 파일 $1$개에는 여러 테스트 케이스가 포함됩니다.

$1$번째 줄에 테스트 케이스의 수를 나타내는 양의 정수 $T$가 주어집니다. 이를 입력받은 뒤, 이어서 $T$번 위 문제를 해결하세요.

실행 시간은 파일별로 측정됩니다. 즉, $T$개의 테스트 케이스를 각각 $2$초 이내에 해결했더라도 $T$번을 합친 실행 시간이 $2$초를 초과하면 TLE가 된다는 점에 주의하세요.

## 입력

```text
$T$
$N_1$
$N_2$
$\vdots$
$N_T$
```

$N_i$는 $i$번째 테스트 케이스에서 $N$의 값입니다.

## 제한

- $1\leq T\leq 1\,000$
- $1\leq N_i\leq 10^9$ ($1\leq i\leq T$)
- 입력은 모두 정수입니다.

## 출력

각 테스트 케이스에 대해 **좋은 경로**의 총 개수를 $2$로 나눈 나머지를 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1
2
4
```

#### 출력

```text
1
0
0
```

- $1$번째 테스트 케이스에서 $N=1$이면 칸 $(1,1)$만 존재하고 이동할 수도 없으므로, 칸 $(1,1)$에서 이동하지 않는 **좋은 경로**가 정확히 $1$가지 존재합니다. 따라서 답은 $1$입니다.
- $2$번째 테스트 케이스에서 $N=2$이면 **좋은 경로**가 정확히 $2$가지 존재하므로 답은 $0$입니다.
- $3$번째 테스트 케이스에서 $N=4$이면 **좋은 경로**가 정확히 $184$가지 존재하므로 답은 $0$입니다.
