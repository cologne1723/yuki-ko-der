## 문제

$N\times N$ 격자로 표현되는 악기 보관고에 $1\times(N-1)$ 직사각형인 트롬본을 $X$개 넣습니다. 트롬본은 회전할 수 있지만 격자 안에 있어야 하므로 모든 변이 격자 구분선 위에 놓여야 합니다. 트롬본은 겹칠 수 없고 장애물이 있는 칸을 차지해서도 안 됩니다. 모든 트롬본을 보관할 수 있는 $X$의 최댓값을 구하세요.

## 입력

```text
N
S1,1 S1,2 ... S1,N
...
SN,1 SN,2 ... SN,N
```

$S_{i,j}$가 #이면 위에서 $i$번째, 왼쪽에서 $j$번째 칸에 장애물이 있고, .이면 장애물이 없습니다.

- $3\le N\le75$

## 출력

답을 한 줄에 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3
#..
...
..#
```

출력:

```text
3
```

가능한 배치를 숫자로 표시하면 다음과 같습니다.

```text
#11
23.
23#
```

4개 이상은 놓을 수 없으므로 답은 3입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
5
#.#.#
.....
#.#.#
#.#.#
.....
```

출력:

```text
3
```

다음과 같이 3개의 트롬본을 보관할 수 있습니다.

```text
#1#2#
.1.2.
#1#2#
#1#2#
3333.
```
