## 문제 설명

선형 합동법이라는 의사 난수 생성법이 있습니다. 양의 정수 $a$, $b$, $m$을 사용하여 $x_{i+1}=ax_i+b \pmod{m}$이라는 점화식으로 난수를 생성합니다. 예를 들어 $a=3$, $b=1$, $m=7$, $x_0=0$일 때 $x_1=1$, $x_2=4$, $x_3=6$, $x_4=5$, $x_5=2$, $x_6=0$, $x_7=1$, $\dots$가 됩니다.

나머지를 구하는 연산은 보통 느리지만, $m=2^{32}$일 때 32비트 부호 없는 정수형으로 $ax_i+b$를 계산하면 오버플로로 나머지를 계산할 수 있으므로 빠르게 계산할 수 있습니다. 이때 $a$를 $4$로 나눈 나머지가 $1$인 정수로 하고 $b$를 홀수로 하면 최대 주기 $2^{32}$가 된다고 알려져 있습니다. 이하에서는 $m=2^{32}$로 합니다.

주사위를 구현하려면 $1$부터 $6$까지의 정수가 대략 같은 확률로 나오는 난수가 필요하므로, $x_i$를 $6$으로 나눈 나머지에 $1$을 더한 정수를 주사위의 눈으로 사용합니다.

다카하시 군과 아오키 군은 이 주사위를 사용하여 다음과 같은 보드게임을 하기로 했습니다.

두 사람 모두 처음에는 칸 $0$에 있습니다. 다카하시 군을 선공으로 하여 번갈아 주사위를 굴리고, 나온 눈만큼 이동합니다. 멈춘 칸이 홀수이면 검은 돌을, 짝수이면 흰 돌을 얻습니다. 이를 $N$번 반복하고, 검은 돌과 흰 돌의 쌍 하나마다 $1$점을 얻습니다.

예를 들어 $N$이 $3$이고 나온 눈이 $1, 3, 2, 6, 4, 5$일 때, 다카하시 군은 칸 $1, 3, 7$에 멈춰 검은 돌 $3$개를 얻고, 아오키 군은 칸 $3, 9, 14$에 멈춰 검은 돌 $2$개와 흰 돌 $1$개를 얻습니다. 점수는 각각 $0$점과 $1$점입니다.

$a$, $b$, $x_0$, $N$이 주어질 때 다카하시 군과 아오키 군의 각각의 점수를 구하세요. 단, 주사위의 첫 번째 눈은 $x_1$을 $6$으로 나눈 나머지에 $1$을 더한 정수입니다.

## 입력

```text
$a\ b\ x_0\ N$
```

입력은 모두 정수입니다.

## 제한

- $0 \le a, b, x_0, N < 2^{32}$
- $a$를 $4$로 나눈 나머지는 $1$입니다.
- $b$는 홀수입니다.

## 출력

다카하시 군과 아오키 군의 점수를 공백으로 구분하여 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 1 1 1
```

#### 출력

```text
0 0
```

$x_1 = 6$, $x_2 = 31$이므로 다카하시 군은 $1$을 내고 칸 $1$에 멈춰 검은 돌을 얻습니다. 다음으로 아오키 군이 $2$를 내고 칸 $2$에 멈춰 흰 돌을 얻습니다. 두 사람 모두 검은 돌과 흰 돌의 쌍이 없으므로 점수는 $0$점입니다.

### 예제 2 {file=""}

#### 입력

```text
3000000001 3000000001 3000000001 0
```

#### 출력

```text
0 0
```

주사위를 굴리지 않는 경우도 있습니다.
