## 문제 설명

양의 정수 $N$이 주어집니다. 다음 $2$개의 조건을 모두 만족하는 양의 정수 $A$, $B$의 순서쌍에 대한 $A \bmod B$의 값의 총합을 $998\,244\,353$으로 나눈 나머지를 구하세요.

- $1 \leq A \leq N$
- $B \times (A \bmod B) < A$

단, $A \bmod B$는 $A$를 $B$로 나눈 나머지의 값($0$ 이상 $B$ 미만)을 나타냅니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- $1 \leq N \leq 10^{12}$
- $N$은 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
```

#### 출력

```text
4
```

조건을 만족하는 $(A,B)$의 순서쌍은 다음 $14$개입니다.

- $(A,B) = (1,1)$ … $A \bmod B = 0$
- $(A,B) = (2,1)$ … $A \bmod B = 0$
- $(A,B) = (2,2)$ … $A \bmod B = 0$
- $(A,B) = (3,1)$ … $A \bmod B = 0$
- $(A,B) = (3,2)$ … $A \bmod B = 1$
- $(A,B) = (3,3)$ … $A \bmod B = 0$
- $(A,B) = (4,1)$ … $A \bmod B = 0$
- $(A,B) = (4,2)$ … $A \bmod B = 0$
- $(A,B) = (4,3)$ … $A \bmod B = 1$
- $(A,B) = (4,4)$ … $A \bmod B = 0$
- $(A,B) = (5,1)$ … $A \bmod B = 0$
- $(A,B) = (5,2)$ … $A \bmod B = 1$
- $(A,B) = (5,4)$ … $A \bmod B = 1$
- $(A,B) = (5,5)$ … $A \bmod B = 0$

이 $A \bmod B$의 총합은 $4$이므로 $4$를 출력합니다.
