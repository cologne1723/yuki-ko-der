## 문제

숫자를 사용하는 점괘를 알고 있나요? 숫자 0〜9로 이루어진 숫자열 S = {s₁,s₂,...,sₙ}에 다음 연산을 수행합니다.

1. 숫자열 S의 길이를 K라고 합니다. K = 1이면 종료합니다.
2. 이웃한 두 숫자 sᵢ, sᵢ₊₁ (1 ≤ i ≤ K − 1)의 합을 s′ᵢ로 정합니다.
3. s′ᵢ ≥ 10이면 십의 자리와 일의 자리를 더한 값으로 바꿉니다. (예를 들어 s′ᵢ = 13이면 s′ᵢ = 1 + 3 = 4로 바꿉니다.)
4. S를 {s′₁,s′₂,...,s′ₖ₋₁}로 바꿉니다.
5. 1번으로 돌아갑니다.

이 연산으로 얻은 하나의 숫자로 운세를 알 수 있습니다. 예를 들어 S = {3,5,8,2}는 {8,4,1}, {3,5}, {8}로 변하므로 최종 숫자는 8입니다.

숫자열 S가 주어질 때 점괘 결과를 구하세요.

## 입력

첫째 줄에 테스트 케이스 수 T가 주어집니다. 각 테스트 케이스는 숫자열 Sᵢ 하나로 이루어집니다.

```text
T
S₁
S₂
⋮
S_T
```

- 1 ≤ T ≤ 10^5
- 1 ≤ |Sᵢ| ≤ 10^5
- Σ|Sᵢ| ≤ 10^5

## 출력

각 테스트 케이스의 숫자열 Sᵢ에 대한 점괘 결과를 한 줄에 출력하세요.
