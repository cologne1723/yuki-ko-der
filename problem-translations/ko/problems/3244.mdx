## 문제 설명

길이 $M$인 문자열 $X$에 대한 **연산**을 다음과 같이 정의합니다.

- **연산**: $1 \leq i \leq M - 1$을 만족하는 정수 $i$를 $1$개 선택하고, $X$의 $i$번째 문자와 $i+1$번째 문자를 서로 바꿉니다.

$1$부터 $9$까지의 숫자로 이루어진 문자열 $T$에 대해 $f(T)$를 다음과 같이 정의합니다.

- $T$에 대해 **연산**을 $0$회 이상 원하는 횟수만큼 수행할 수 있을 때, $T$를 십진 표기한 정수가 $8$의 배수가 되도록 하는 데 필요한 **연산** 횟수의 최솟값입니다. 어떤 방식으로 **연산**을 수행해도 불가능하다면 $f(T) = -1$로 정의합니다.

$1$부터 $9$까지의 숫자만으로 이루어진 길이 $N$인 문자열 $S$가 주어집니다.

다음 $Q$개의 질의가 주어지므로 각각에 답하세요.

- 질의 $i$: $1 \leq l_i \leq r_i \leq N$을 만족하는 정수쌍 $(l_i, r_i)$가 주어집니다. $S$의 $l_i$번째 문자부터 $r_i$번째 문자까지로 이루어진 부분 문자열을 $S[l_i, r_i]$라고 할 때, $f(S[l_i, r_i])$를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ Q$
$S$
$l_1\ r_1$
$l_2\ r_2$
$\vdots$
$l_Q\ r_Q$
```

- $1$번째 줄에 문자열의 길이 $N$과 질의의 개수 $Q$가 주어집니다.
- $2$번째 줄에 $1$부터 $9$까지의 숫자만으로 이루어진 길이 $N$의 문자열 $S$가 주어집니다.
- 이어지는 $Q$개의 줄에 $i$번째 질의를 나타내는 정수쌍 $(l_i, r_i)$가 주어집니다.

## 제한

- $N$, $Q$, $l_i$, $r_i$는 정수입니다.
- $S$는 $1$부터 $9$까지의 숫자로 이루어진 길이 $N$의 문자열입니다.
- $1 \leq N \leq 2.88 \times 10^5$
- $1 \leq Q \leq 2.88 \times 10^5$
- $1 \leq l_i \leq r_i \leq N$

## 출력

$Q$줄에 걸쳐 출력하세요. $i$번째 줄에는 $i$번째 질의에 대한 답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
15 4
123456789111141
6 9
3 6
10 13
8 15
```

#### 출력

```text
3
0
-1
7
```

$1$번째 질의에서는 $S[6, 9] = $`6789`입니다. 이를 $T$라고 하겠습니다. 다음과 같이 연산을 수행하면 $3$회의 연산으로 $T$를 십진 표기한 정수가 $8$의 배수가 되게 할 수 있습니다.

- $i = 1$을 선택합니다. $T$의 $1$번째 문자와 $2$번째 문자를 서로 바꾸면 $T = $`7689`가 됩니다.
- $i = 3$을 선택합니다. $T$의 $3$번째 문자와 $4$번째 문자를 서로 바꾸면 $T = $`7698`이 됩니다.
- $i = 2$를 선택합니다. $T$의 $2$번째 문자와 $3$번째 문자를 서로 바꾸면 $T = $`7968`이 됩니다.

$7\,968 = 996 \times 8$이므로 $7\,968$은 $8$의 배수입니다. $2$회 이하의 연산으로 $T$를 십진 표기한 정수가 $8$의 배수가 되게 할 수는 없으므로 답은 $3$입니다.

$2$번째 질의에서는 $S[3, 6] = $`3456`입니다. $432 \times 8 = 3\,456$이므로 연산을 $1$번도 수행하지 않아도 처음부터 $S[3, 6]$을 십진 표기한 정수는 $8$의 배수입니다.

$3$번째 질의에서는 $S[10, 13] = $`1111`입니다. 어떤 방식으로 연산을 수행해도 $S[10, 13]$을 십진 표기한 정수가 $8$의 배수가 되게 할 수 없으므로 $-1$을 출력하세요.
