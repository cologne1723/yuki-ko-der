## 이야기

당신은 천재 해커이며, 적의 로봇을 해킹하여 비밀 이미지 데이터를 손에 넣었습니다.

하지만 이미지 데이터에 가벼운 $2$차원 컨볼루션 처리가 되어 있었고, 보안을 통과할 때 화소의 순서가 무작위로 바뀌었다는 것을 알아차렸습니다.

원래 이미지 데이터를 유일하게 복원하기는 어려워졌지만, 그래도 원래 이미지로 생각할 수 있는 예를 만들어 보면 알 수 있는 것이 있을지도 모릅니다.

원래 이미지 데이터의 $1$가지 예를 구성하는 프로그램을 작성하세요.

## 문제 설명

$N \times N$ 행렬 $A$가 있습니다. 행렬 $A$의 각 원소가 **음이 아닌 정수**라는 것을 알고 있습니다.

이제 다음과 같이 $(N-1) \times (N-1)$ 행렬 $B$를 정의합니다.

$B_{i,j} = A_{i,j} + A_{i,j+1} + A_{i+1,j} + A_{i+1,j+1}$

$B$의 $(N-1)^2$개 원소를 무작위 순서로 나열하여 얻은 배열 $C$가 주어집니다. $A$로 가능한 행렬 중 $1$개를 구하세요.

그러한 행렬이 존재하지 않는다면 그 사실을 보고하세요.

$T$개의 테스트 케이스가 주어지므로 각각에 답하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $case_i$는 $i$번째 테스트 케이스를 뜻합니다.

```text
$T$
$case_1$
$case_2$
$\vdots$
$case_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$C_1\ C_2\ \cdots\ C_{(N-1)^2}$
```

## 제한

- 모든 입력값은 정수입니다.
- $1 \leq T \leq 10\,000$
- $2 \leq N \leq 700$
- $0 \leq C_i \leq 10^6-1$
- $1$개의 입력 파일에서 $N^2$의 총합은 $5 \times 10^5$를 초과하지 않습니다.

## 출력

각 테스트 케이스에 대해 $A$로 가능한 행렬이 존재하지 않는다면 $-1$을 출력하세요. 존재한다면 다음 형식으로 그중 $1$개를 출력하세요.

```text
$A_{1,1}\ A_{1,2}\ \cdots\ A_{1,N}$
$A_{2,1}\ A_{2,2}\ \cdots\ A_{2,N}$
$\vdots$
$A_{N,1}\ A_{N,2}\ \cdots\ A_{N,N}$
```

각 테스트 케이스에 대한 출력의 마지막에는 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
3
2 0 2 5
2
9
4
3 1 4 1 5 9 2 6 5
```

#### 출력

```text
2 0 1
0 0 1
0 0 4
2 0
2 5
1 1 0 0
1 0 0 1
2 2 0 4
1 4 0 0
```

$1$번째 테스트 케이스에서 $A=\begin{pmatrix} 2 & 0 & 1 \\ 0 & 0 & 1 \\ 0 & 0 & 4 \end{pmatrix}$로 정하면 다음이 성립합니다.

- $B_{1,1} = A_{1,1}+A_{1,2}+A_{2,1}+A_{2,2} = 2$
- $B_{1,2} = A_{1,2}+A_{1,3}+A_{2,2}+A_{2,3} = 2$
- $B_{2,1} = A_{2,1}+A_{2,2}+A_{3,1}+A_{3,2} = 0$
- $B_{2,2} = A_{2,2}+A_{2,3}+A_{3,2}+A_{3,3} = 5$

$[2,2,0,5]$를 적절히 재배열하면 $C$와 일치하므로, 이 출력은 $A$의 $1$가지 예로 적절합니다.
