## 문제 설명

$3$개의 원소로 이루어진 수열 $A_1,A_2,A_3$가 다음 $2$가지 조건을 만족하면 카도마츠 열이라고 합니다.

- $A_1,A_2,A_3$가 모두 다릅니다.
- $3$개의 원소 중 $A_2$가 가장 크거나 가장 작습니다.

$N$자리($3\le N$) 양의 정수 $X$의 위에서 $i$번째 자릿수를 $X_i$라고 합니다. 수열 $X_i,X_{i+1},X_{i+2}$($1\le i\le N-2$)가 모두 카도마츠 열이면 $X$를 카도마츠 숫자라고 합니다. 예를 들어 $4\,514$와 $893$은 카도마츠 숫자지만 $114\,514$와 $89$는 아닙니다.

$X$가 카도마츠 숫자이고 $X$보다 작은 카도마츠 숫자가 $K$개 존재하면 $X$를 $K+1$번째 카도마츠 숫자라고 합니다. $1$번째는 $102$, $404$번째는 $893$, $1\,000$번째는 $3\,296$입니다.

양의 정수 $K$가 주어질 때 $K$번째 카도마츠 숫자를 구하세요.

## 입력

```text
$T$
```

$1$번째 줄에 테스트 케이스 수 $T$가 주어집니다. 이어지는 $T$줄에 각 테스트 케이스의 $K$가 다음 형식으로 주어집니다.

```text
$K$
```

입력은 모두 정수입니다.

## 제한

- $1\le T\le10$
- $1\le K\le10^{10}$

## 출력

각 테스트 케이스마다 $K$번째 카도마츠 숫자를 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
1
2
3
4
5
```

#### 출력

```text

103
104
105
106
```

$1$자리와 $2$자리 카도마츠 숫자는 존재하지 않는다는 점에 주의하세요.

```

```

### 예제 3 {file=""}

#### 입력

```text
1
10000000000
```

#### 출력

```text
37294859064823
```

최댓값 사례입니다. $10^{10}$은 $32$비트 정수형에 들어가지 않으므로 계산뿐 아니라 입출력 시 오버플로에도 주의하세요. 이 사례는 테스트 마지막 부분에 있으므로 이 사례에서 TLE로 녹아웃되는 일은 없습니다.
