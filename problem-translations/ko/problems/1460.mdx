## 문제

길이 `K`인 양의 정수 수열 `B`와 초기값 `A_0,...,A_{K-1}`가 주어집니다. `i\ge K`에 대해

\[
A_i=\max_{0\le j<K}\min(A_{i-K+j},B_j)
\]

로 정의할 때 `A_N`을 구하세요.

## 입력

`K N`과 초기 수열이 주어집니다.

## 출력

`A_N`을 출력하세요.
