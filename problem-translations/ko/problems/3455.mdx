## 문제 설명

양의 정수 $N$과 $Q$개의 양의 정수 $X_i$가 주어집니다.

$X$가 $N$-베아츠 수라는 것은 다음 $2$가지 조건 중 적어도 $1$가지가 성립하는 것으로 정의합니다.

1. $X$가 $N$의 배수입니다.
2. $N$이 $X$의 연속하는 부분 문자열로 포함됩니다.

$i$ $(1 \le i \le Q)$번째 줄에 $X_i$가 $N$-베아츠 수라면 `Yes`를, 그렇지 않다면 `No`를 출력하세요.

## 입력

```text
$N\ Q$
$X_1$
$X_2$
$\vdots$
$X_Q$
```

$1$번째 줄에 $N$과 $Q$가 공백으로 구분되어 주어집니다.

이후 $Q$개의 줄에 $X_1, X_2, \ldots, X_Q$가 각각 주어집니다.

## 제한

- $1 \le N \le 1\,000$
- $1 \le Q \le 5 \times 10^4$
- $1 \le X_i \le 2 \times 10^4$ $(1 \le i \le Q)$
- 입력은 모두 정수입니다.

## 출력

$i$ $(1 \le i \le Q)$번째 줄에 $X_i$가 $N$-베아츠 수라면 `Yes`를, 그렇지 않다면 `No`를 출력하세요.

마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
10 4
1
20
100
101
```

#### 출력

```text
No
Yes
Yes
Yes
```

$X_i$가 $10$-베아츠 수인지 확인하려면, $X_i$가 $10$의 배수인지 또는 $X_i$의 연속하는 부분 문자열로 `10`을 포함하는지 확인하면 됩니다.

$1$은 $10$-베아츠 수가 아닙니다.

$20$은 $10$의 배수이므로 $10$-베아츠 수입니다.

$100$은 $2$가지 조건을 모두 만족하므로 $10$-베아츠 수입니다.

$101$은 연속하는 부분 문자열로 `10`을 포함하므로 $10$-베아츠 수입니다.
