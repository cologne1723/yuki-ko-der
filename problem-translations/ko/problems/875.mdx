## 문제

원소가 $N$개인 순열 $A=\{a_1,a_2,\ldots,a_N\}$이 주어집니다. 다음 두 종류의 질의가 모두 $Q$개 주어집니다. 주어진 순서대로 처리하세요.

- `1 l r`: $a_l$과 $a_r$의 값을 교환합니다.
- `2 l r`: $\displaystyle\arg\min_{i\in[l,r]}a_i$를 출력합니다. 즉, 구간에서 최솟값을 갖는 원소의 인덱스입니다. $A$가 순열이므로 이 값은 유일합니다.

## 입력

~~~text
N Q
a_1 a_2 ... a_N
query_1
query_2
...
query_Q
~~~

첫째 줄에 수열의 길이 $N$과 질의의 수 $Q$가 이 순서대로 공백으로 구분되어 주어집니다. $(1\le N,Q\le10^5)$

둘째 줄에 $N$개의 정수가 공백으로 구분되어 주어집니다. $i$번째 정수는 $a_i$의 초기값입니다. $(1\le i\le N;\ 1\le a_i\le N)$ 서로 다른 인덱스의 원소는 모두 다릅니다.

다음 $Q$개 줄의 $i$번째 줄에 $i$번째 질의가 주어집니다. $(1\le i\le Q)$ 각 질의는 `1 l r` 또는 `2 l r` 형식입니다. 첫 번째 종류에서는 $1\le l<r\le N$, 두 번째 종류에서는 $1\le l\le r\le N$입니다. 두 번째 종류의 질의는 적어도 하나 있습니다.

입력은 모두 정수이며 총 $Q+2$줄입니다.

## 출력

두 번째 종류의 질의마다 $\displaystyle\arg\min_{i\in[l,r]}a_i$를 한 줄에 하나씩 출력하세요.

## 예제

### 입력 1 {file="stdin"}

~~~text
3 3
2 1 3
2 1 3
1 2 3
2 1 3
~~~

### 출력 1 {file="stdout"}

~~~text
2
3
~~~
