## 문제

음이 아닌 정수 $n,i$에 대해 $n_i$를 $n$을 십진법으로 나타냈을 때 $10^i$의 자리 숫자로 정의합니다.

양의 정수 $n$이 단조롭다는 것은 $i\lt j$이면 $n_i\geq n_j$라는 뜻입니다. 한 자리 양의 정수는 단조롭습니다. 예를 들어 123, 2233355555, 1은 단조롭지만 321, 998244353은 단조롭지 않습니다.

양의 정수 $n$이 영원히 단조롭다는 것은 모든 음이 아닌 정수 $k$에 대해, $n$을 각 자리 숫자의 합으로 바꾸는 연산을 $k$번 반복한 뒤의 수가 단조롭다는 뜻입니다.

음이 아닌 정수 $N$이 주어집니다. $10^N$ 이상인 영원히 단조로운 정수 중 최솟값을 구하세요. 답이 매우 커질 수 있으므로 $998244353$으로 나눈 나머지를 출력합니다.

$T$개의 테스트 케이스에 답하세요.

## 제약

- $1\leq T\leq10^5$
- $0\leq N\leq10^{14}$

## 입력

~~~text
T
N
~~~

## 출력

각 테스트 케이스의 답을 $998244353$으로 나눈 나머지를 한 줄에 출력하세요.

## 샘플

### 입력 {file="stdin"}

~~~text
6
0
2
9
1024
123456789
99999999999999
~~~

### 출력 {file="stdout"}

~~~text
1
111
112866759
614307571
646823187
411251028
~~~

$N=0$일 때 답은 1입니다. $N=9$일 때 답은 $1111111112$이며, 자리수 합 11과 그 자리수 합 2도 모두 단조롭습니다. 답을 $998244353$으로 나눈 나머지에 주의하세요.
