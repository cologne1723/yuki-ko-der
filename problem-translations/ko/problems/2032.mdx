$L$ 이상 $R$ 이하인 $K$의 배수를 십진법으로 각각 한 번씩 쓸 때 숫자 $C$가 쓰이는 횟수를 구하세요.

## 입력

```text
T
L R K C
```

$1\le T\le5\times10^4$, $1\le L\le R<10^9$, $1\le K<10^9$, $1\le C\le9$입니다.

## 출력

각 테스트 케이스의 답을 한 줄에 출력하세요.
