## 이야기

yukiくん은 자전거 열쇠의 비밀번호를 잊어버렸습니다. 적당한 번호를 yukiくん에게 알려 주어 어떻게든 열쇠를 여는 것을 도와주세요.

## 문제 설명

비밀번호는 $3$자리 숫자(`000`〜`999`)입니다.

## 입력

$3$자리 숫자를 출력하면 판정기가 표준 입력으로 `locked` 또는 `unlocked` 중 $1$개를 반환합니다.

`locked`가 반환되면 열쇠는 아직 열리지 않은 것이므로 다른 숫자를 시도하세요. `unlocked`가 반환되면 열쇠가 열린 것이므로 프로그램을 종료하세요.

## 출력

앞의 $0$을 포함한 $3$자리 숫자를 표준 출력으로 출력하세요. **열쇠를 연 쿼리 뒤에 불필요한 출력을 하면 오답입니다.**

시간 제한 안에서는 몇 번이든 시도할 수 있습니다.


이 문제는 인터랙티브 문제입니다. 문제의 내용에 따라 입출력 작업을 수행하세요. 특히 **각 출력을 개행하고 flush하는 것을 잊지 마세요.**

인터랙티브 문제의 입출력에 관한 주의사항은 [yukicoder wiki의 인터랙티브 형식 문제 정리](http://yukicoder.me/wiki/reactive), [문제 246](http://yukicoder.me/problems/551), [문제 253](http://yukicoder.me/problems/687) 등을 참고하세요.

## 판정 코드 (참고)

판정에 사용되는 코드입니다. C++로 작성되었으며, 명령줄 인수의 $1$번째 파일에서 정답 문자열을 읽습니다.

**2016/05/04: 판정 코드를 변경했습니다. 숫자 이외의 출력 등 잘못된 형식, $1$줄에 여러 출력을 하는 경우, 열쇠를 연 뒤 불필요한 출력을 하는 경우에는 오답이 됩니다.**

```cpp html="code"
#include <iostream>
#include <fstream>
#include <cassert>
using namespace std;

string input(istream& is){
    string ret;
    getline(is, ret);         //回答コードから受け取った文字列
    assert(ret.size() == 3);  //長さは 3
    for(char c : ret){        //数字のみかチェック
        assert('0' <= c && c <= '9');
    }
    return ret;
}

int main(int argc, char* argv[]){
    ifstream ifs(argv[1]);
    string ans = input(ifs);     //第一引数のファイルから正解の文字列を取得
    cerr << "Answer : " << ans << endl;

    while(1){
        string in = input(cin);  //標準入力から回答の文字列を取得
        if(in == ans){           //正解なら "unlocked" を出力して終了
            cout << "unlocked" << endl;
            if(getline(cin,in)){  //余計な出力がないか確認
                cerr << "Wrong Answer : too many outputs, \"" << in << "\"" << endl;
                abort();
            }
            return 0;
        }else{                   //不正解なら "locked" を出力
            cout << "locked" << endl;
        }
    }
    return 0;
}
```
