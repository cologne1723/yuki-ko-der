$N$개의 양의 정수쌍 $(A_i,B_i)$가 주어집니다. 각 쌍에서 하나를 집합 $S$, 다른 하나를 집합 $T$에 배치하세요.

## 문제

어떤 $s\in S,t\in T$를 골라도 $s$와 $t$를 이어 붙인 십진수가 소수가 아니도록 배치할 수 있는지 판정하세요.

## 입력

```text
N
A_1 B_1
...
A_N B_N
```

$1\le N\le500$, $1\le A_i,B_i<1000$입니다.

## 출력

가능하면 `Yes`, 불가능하면 `No`를 출력하세요.
