## 문제 설명

A와 B는 카드 게임을 좋아합니다. 1부터 $2N$까지의 숫자가 하나씩 적힌 $2N$장의 카드로 게임합니다. 두 사람에게 각각 $N$장씩 카드가 배분됩니다.

게임은 간단합니다. 각자 자유롭게 카드 한 장을 내고 숫자가 큰 쪽이 한 경기에서 이깁니다. 한 번 낸 카드는 다시 사용할 수 없습니다. 총 $N$경기를 진행하여 이긴 횟수가 많은 쪽이 게임에서 이깁니다. 승리 횟수가 같으면 무승부입니다.

카드는 이미 배분되어 있을 때, $N$경기가 끝났을 때 A가 게임에서 이길 확률을 구하세요. 두 사람은 생각하지 않고 무작위로 카드를 낸다고 합니다.

## 입력

```text
N
A_0 A_1 ... A_{N-1}
B_0 B_1 ... B_{N-1}
```

- $1 \le N \le 4$
- $A_0,\ldots,A_{N-1}$과 $B_0,\ldots,B_{N-1}$은 $1$부터 $2N$까지의 수를 포함합니다.
- 두 사람의 카드 사이에 중복되는 숫자는 없습니다.

## 출력

A가 이길 확률을 한 줄에 출력하세요. 오차는 ±0.01까지 허용됩니다.

## 예제

### 예제 1 {file=""}

```text
2
2 4
1 3
```

```text
0.5
```

A가 2와 4, B가 1과 3을 받습니다. 각자의 카드를 내는 순서는 2가지씩이므로 전체 4가지 결과 중 A가 이기는 2가지의 확률은 0.5입니다.

### 예제 2 {file=""}

```text
2
3 4
1 2
```

```text
1
```

어떻게 해도 A가 이깁니다.

### 예제 3 {file=""}

```text
1
1
2
```

```text
0
```

어떻게 해도 A는 이길 수 없습니다.

### 예제 4 {file=""}

```text
3
6 2 3
1 5 4
```

```text
0.666667
```
