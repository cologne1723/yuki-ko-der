## 이야기

A君과 B君은 카드 게임을 좋아합니다.

## 문제 설명

카드 게임은 $1$부터 $2N$까지의 숫자가 각각 $1$개씩 적힌 $2N$장의 카드로 진행합니다. A君과 B君에게 각각 $N$장씩 카드가 배분됩니다.

게임은 간단합니다. 각자 자유롭게 카드 $1$장을 내고 숫자가 큰 쪽이 $1$경기에서 이깁니다. $1$번 낸 카드는 다시 사용할 수 없습니다. 총 $N$경기를 진행하여 이긴 횟수가 많은 쪽이 게임에서 이깁니다. 승리 횟수가 같으면 무승부입니다.

카드는 이미 배분되어 있습니다. $N$경기가 끝났을 때 A君이 게임에서 이길 확률을 구하세요. A君과 B君은 생각하지 않고 무작위로 카드를 낸다고 합니다.

## 입력

```text
$N$
$A_0\ A_1\ \dots\ A_{N-1}$
$B_0\ B_1\ \dots\ B_{N-1}$
```

$1$번째 줄에 정수 $N$이 주어집니다. $2$번째 줄에는 A君의 카드에 적힌 $N$개의 수 $A_0,\ldots,A_{N-1}$이, $3$번째 줄에는 B君의 카드에 적힌 $N$개의 수 $B_0,\ldots,B_{N-1}$이 주어집니다. 각 행의 숫자는 공백으로 구분됩니다.

## 제한

- $1 \le N \le 4$
- $A_0,\ldots,A_{N-1}$과 $B_0,\ldots,B_{N-1}$은 $1$부터 $2N$까지의 수를 포함합니다.
- A君과 B君의 카드 사이에 중복되는 숫자는 없습니다.

## 출력

A君이 이길 확률을 $1$줄에 출력하세요. 오차는 $\pm 0.01$까지 허용됩니다. 출력한 뒤 줄을 바꾸세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
2 4
1 3
```

#### 출력

```text
0.5
```

A君이 $2$와 $4$, B君이 $1$과 $3$을 받습니다. 각자의 카드를 내는 순서는 $2$가지씩이므로 전체 $4$가지 결과 중 A君이 이기는 $2$가지의 확률은 $2/4=0.5$입니다.

### 예제 2 {file=""}

#### 입력

```text
2
3 4
1 2
```

#### 출력

```text
1
```

어떻게 해도 A君이 이깁니다.

### 예제 3 {file=""}

#### 입력

```text
1
1
2
```

#### 출력

```text
0
```

어떻게 해도 A君은 이길 수 없습니다.

### 예제 4 {file=""}

#### 입력

```text
3
6 2 3
1 5 4
```

#### 출력

```text
0.666667
```
