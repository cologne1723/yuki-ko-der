## 문제 설명

**이 문제는 대화형 문제입니다.**

길이 $N$인 정수 수열 $A$가 있습니다.

당신과 저지 $2$명은 번갈아 행동합니다. **선공과 후공 중 어느 쪽을 맡을지는 당신이 선택할 수 있습니다.**

행동할 때는 다음 연산을 차례로 수행합니다. 처음에는 $K=10^{100}$입니다.

- 정수 $x$ ($1 \leq x \leq K$)를 선택합니다.
- $x \leq A_i$를 만족하는 $i$ ($1 \leq i \leq N$)를 선택합니다.
- $A_i \leftarrow A_i-x$, $K \leftarrow x$로 갱신합니다.

적절한 행동을 할 수 없게 된 쪽이 패배하고, 패배하지 않은 쪽이 승리합니다.

적절하게 행동하여 승리하세요.

## 입력

먼저 정수 $N$이 주어집니다.

```text
$N$
```

다음으로 정수 수열 $A$가 공백으로 구분되어 $1$줄에 주어집니다.

```text
$A_1\ A_2\ \cdots\ A_N$
```

### 저지의 차례

저지가 행동에서 선택한 $i,x$가 공백으로 구분되어 $1$줄에 주어집니다.

```text
$i\ x$
```

그 후 문제의 상태를 나타내는 정수 $\mathrm{ret}$가 주어집니다.

```text
$\mathrm{ret}$
```

- $\mathrm{ret}=0$이면 행동을 계속합니다.
- $\mathrm{ret}=-1$이면 당신이 패배했다는 뜻입니다. 프로그램을 종료하세요.

### 당신의 차례

당신이 행동을 출력한 후 문제의 상태를 나타내는 정수 $\mathrm{ret}$가 주어집니다.

```text
$\mathrm{ret}$
```

- $\mathrm{ret}=1$이면 당신이 승리했다는 뜻입니다. 프로그램을 종료하세요.
- $\mathrm{ret}=0$이면 행동을 계속합니다.
- $\mathrm{ret}=-1$이면 당신이 패배했다는 뜻입니다. 프로그램을 종료하세요.

## 제한

- $1 \leq N \leq 10^4$
- $1 \leq A_i \leq 10^4$ ($1 \leq i \leq N$)
- $\sum_{i=1}^{N} A_i \leq 10^4$

## 출력

처음에 $N$, $A$를 받은 후 선공과 후공 중 어느 쪽을 선택할지 정하고, 이를 나타내는 문자열 $s$를 $1$줄에 출력하세요. 선공을 선택하는 경우 `First`, 후공을 선택하는 경우 `Second`를 출력하세요.

```text
$s$
```

그 후 번갈아 행동합니다.

당신의 차례에는 다음과 같이 출력합니다.

당신이 행동에서 선택한 $i,x$를 공백으로 구분하여 $1$줄에 출력하세요.

```text
$i\ x$
```

출력할 때마다 flush하세요.

저지가 최적으로 행동하여 당신의 패배가 확정된 경우, 게임이 끝나기 전에 $\mathrm{ret}=-1$이 될 수 있습니다.

출력 형식이 잘못되었거나 제한을 만족하지 않으면 저지 결과가 정의되지 않을 수 있습니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
```

$N=2$입니다.

#### 입력

```text
1 2
```

$A=(1,2)$입니다.

#### 출력

```text
First
```

당신은 선공을 선택했습니다.

#### 출력

```text
2 1
```

당신은 $i=2,x=1$로 행동하여 $K \leftarrow 1$로 갱신했습니다.

#### 입력

```text
0
```

게임은 계속됩니다.

#### 입력

```text
1 1
```

저지는 $i=1,x=1$로 행동했습니다.

#### 입력

```text
0
```

게임은 계속됩니다.

#### 출력

```text
2 1
```

당신은 $i=2,x=1$로 행동했습니다.

#### 입력

```text
1
```

현재 $A=(0,0)$이므로 더 이상 행동할 수 없습니다. 당신이 승리했습니다.
