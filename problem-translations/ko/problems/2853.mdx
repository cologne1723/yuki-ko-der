## 문제 설명

$1 \leq A, B \leq N$을 만족하는 정수에 대해, 다음 조건을 모두 만족하는 $(A, B)$의 순서 있는 쌍이 몇 개인지 구하세요.

- $A + B = N$
- $A\ \mathrm{AND}\ B = 0$

여기서 $\mathrm{AND}$는 비트별 논리곱을 나타냅니다.

또한 문제의 제한 아래에서 답이 $2^{60}$ 미만이라는 것을 증명할 수 있습니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

## 제한

- $1 \leq N < 2^{60}$
- 입력은 모두 정수입니다.

## 출력

문제의 답을 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
```

#### 출력

```text
2
```

$(A, B) = (1, 4), (4, 1)$이 조건을 만족합니다.

### 예제 2 {file=""}

#### 입력

```text
1125899906842624
```

#### 출력

```text
0
```

입력이 $32$비트 정수형에 들어가지 않을 수 있다는 점에 주의하세요.
