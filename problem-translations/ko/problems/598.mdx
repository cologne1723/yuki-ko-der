## 문제

컴퓨터 게임 Toaru Fantasy에서는 $N$비트 부호 있는 정수([2의 보수](https://ja.wikipedia.org/wiki/2%E3%81%AE%E8%A3%9C%E6%95%B0))를 사용해 여러 수치를 관리합니다.

최근 오버플로 버그가 발견되어 이를 이용한 공략법이 연구되고 있습니다.

보통은 적을 공격해 체력을 0 이하로 만들면 적을 쓰러뜨릴 수 있습니다. 반면 오버플로 버그 공략에서는 적의 체력을 일부러 회복시키고, 오버플로로 체력이 0 이하가 될 때도 쓰러뜨림 판정이 되는 점을 이용합니다.

적의 초기 체력을 X, 한 번 공격할 때 줄일 수 있는 체력을 A, 한 번 회복할 때 늘릴 수 있는 체력을 B라고 합니다.

공격과 회복은 각각 1단위 시간이 걸릴 때 적을 쓰러뜨리는 최소 시간을 구하세요. 적이 스스로 체력을 증감시키는 일은 없습니다.

### 2의 보수를 모르는 분을 위한 정보

정수 $x$는 비트열 $a_{N-1},a_{N-2},\ldots,a_0$를 사용해 $N$비트 부호 있는 정수로 표현할 수 있습니다. $(-2^{N-1}\le x<2^{N-1})$

[이진법](https://ja.wikipedia.org/wiki/%E4%BA%8C%E9%80%B2%E6%B3%95)을 참고하세요.

$x = -2^{N-1} \times a_{N-1} + \sum_{k=0}^{N-2} 2^k \times a_k$

각 $a_i$는 0 또는 1입니다. 각 비트가 나타내는 값은 최상위 비트가 $-2^{N-1}$, 그다음이 $2^{N-2}$, …, 8, 4, 2, 1입니다.

두 정수 $x,y$의 덧셈은 일반 정수형과 같습니다. $(-2^{N-1}\le x,y<2^{N-1})$ 최상위 비트보다 왼쪽으로 넘친 값(carry flag)은 무시합니다.

[2의 보수 덧셈](https://en.wikipedia.org/wiki/Two%27s_complement#Addition)

의사코드로는 다음과 같습니다.

```text
// Bit Array A + B => C
carry = 0
for i in [0, N) :
    C[i] = (A[i] + B[i] + carry) % 2
    carry = floor( (A[i] + B[i] + carry) / 2 )
return C
```

## 입력

```text
N
X
A
B
```

첫 번째 줄에 게임에서 사용하는 정수형의 비트 길이 N, 두 번째 줄에 적의 초기 체력 X, 세 번째 줄에 공격으로 줄어드는 체력 A, 네 번째 줄에 회복으로 늘어나는 체력 B가 주어집니다.

모든 입력은 정수입니다.

$2\le N\le32$

$1\le X,A,B<2^{N-1}$

## 출력

적을 쓰러뜨리는 최소 시간을 출력하세요.

## 예제

### 샘플 1 {file="sample1.in"}

입력:

```text
4
4
3
1
```

출력:

```text
2
```

모든 수치는 4비트 부호 있는 정수형으로 관리됩니다. 공격을 2번 하면 최단 시간에 쓰러뜨릴 수 있습니다. 아래 두 계산은 첫 번째와 두 번째 공격입니다. `1101`은 $-A=-3$의 2의 보수 표현이며, 체력은 4에서 1, 다시 -2가 됩니다.


```text
  0100 ( 敵の体力 4 )
+)1101 ( -A(=-3) を 2 の補数で表現 )
------
  0001 ( 残り体力 1 )
```

```text
  0001 ( 敵の体力 1 )
+)1101 ( -A(=-3) を 2 の補数で表現 )
------
  1110 ( 残り体力 -2 )
```

### 샘플 2 {file="sample2.in"}

입력:

```text
4
6
2
1
```

출력:

```text
2
```

적의 체력을 2번 회복하면 오버플로되어 쓰러뜨림 판정이 됩니다. 아래 계산에서 체력 6에 $B=1$을 더하면 7이 되고, 다시 1을 더하면 -8이 됩니다.


```text
  0110 ( 敵の体力 6 )
+)0001 ( B(=1) )
------
  0111 ( 残り体力 7 )

  0111 ( 敵の体力 7 )
+)0001 ( B(=1) )
------
  1000 ( 残り体力 -8 )
```

### 샘플 3 {file="sample3.in"}

입력:

```text
26
16777221
20
20
```

출력:

```text
838861
```

공격으로는 $838\,862$번, 회복으로는 $838\,861$번이면 쓰러뜨릴 수 있습니다.
