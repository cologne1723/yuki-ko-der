## 문제 설명

다항식 해시(롤링 해시, 카프-라빈 지문이라고도 합니다)는 정수 $P$, $B$를 매개변수로 사용하며, 문자열 $S$에 대해 다음과 같이 정의됩니다.

$h_{P,B}(S) = (\sum_{i=1}^{|S|} B^{|S|-i} {\rm ord}(S_i)) \bmod P$

여기서 $|S|$는 $S$의 길이를 나타냅니다. ${\rm ord}(c)$는 문자 $c$의 아스키 코드('a'~'z'는 $97$~$122$)를 나타냅니다. $x \bmod P$는 $x$를 $P$로 나눈 나머지를 나타냅니다.

정수 $P$, $B$가 주어집니다. 다음 조건을 모두 만족하는 $2$개의 문자열 $S$, $T$를 $1$쌍 구하세요.

- $S \neq T$
- $|S| = |T|$
- $1 \leq |S|, |T| \leq 10^5$
- $S$, $T$는 각각 영소문자('a'~'z')만으로 이루어집니다.
- $h_{P,B}(S) = h_{P,B}(T)$

답이 여러 가지라면 그중 어느 것이나 출력해도 됩니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$P$
$B$
```

$1$번째 줄에 다항식 해시 함수의 매개변수인 정수 $P$, $2$번째 줄에 정수 $B$가 주어집니다.

## 제한

테스트 케이스는 $1$개뿐이며, 입력은 다음과 같음이 보장됩니다.

```text
1000000000000000003
123456789987654321
```

## 출력

출력은 다음 형식으로 주어집니다.

```text
$S$
$T$
```

문제문의 조건을 만족하는 $S$, $T$를 $2$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1009
123
```

#### 출력

```text
bab
wbe
```

$h_{P,B}(S) = h_{P,B}(T) = 342$입니다.

### 예제 2 {file=""}

#### 입력

```text
1000000007
123456789
```

#### 출력

```text
hkmpqvm
axlszsi
```

$h_{P,B}(S) = h_{P,B}(T) = 409\,775\,251$입니다.

## 힌트

테스트 케이스의 $P$, $B$에는 특별히 깊은 의미가 없습니다.

$0 \leq B < P \leq 10^{18}$이라고 하더라도, 예상 풀이가 임의의 입력에 대해 제한 시간 안에 반드시 올바른 답을 출력한다고 보장되지는 않습니다.

다만 단순히 정답을 하드코딩한 것이 아니라, 테스트 케이스에 대해서는 제한 시간 안에 답을 생성하고 있음이 확실합니다.

따라서 정답 하드코딩 이외의 방법으로 해결하세요.
