## 문제 설명

$\varphi = \dfrac{1+\sqrt{5}}{2}$로 정의합니다.

양의 정수 $N$, $R$, $B$가 주어집니다.

정점 $1$, $2$, $\dots$, $N$으로 이루어진 무방향 그래프에 다음 조건으로 간선을 추가합니다.

$1$ 이상 $N$ 이하인 모든 정수 $i$에 대해 다음 연산을 수행합니다.

- $1 \le \left\lfloor i\varphi \right\rfloor \le N$이면 정점 $i$와 정점 $\left\lfloor i\varphi \right\rfloor$ 사이에 가중치가 $R$인 빨간색 간선을 추가합니다.
- $1 \le \left\lfloor i\varphi^2 \right\rfloor \le N$이면 정점 $i$와 정점 $\left\lfloor i\varphi^2 \right\rfloor$ 사이에 가중치가 $B$인 파란색 간선을 추가합니다.

처음에는 그래프의 모든 정점이 검은색으로 칠해져 있습니다.

양의 정수 $Q$와 $Q$개의 질의가 주어집니다. $q$번째 질의는 정수의 쌍 $(t_q, x_q)$로 주어지며, 내용은 다음과 같습니다.

- $t_q = 1$일 때, 정점 $x_q$가 흰색이면 검은색으로, 검은색이면 흰색으로 칠합니다.
- $t_q = 2$일 때, 빨간색 간선의 가중치를 $x_q$로 설정합니다.
- $t_q = 3$일 때, 파란색 간선의 가중치를 $x_q$로 설정합니다.

각 질의를 처리할 때마다 다음 문제의 답을 구하세요.

간선을 $0$개 이상 삭제하여 모든 흰색 정점을 연결할 수 있는지 판정하고, 가능하다면 남은 간선 가중치의 합으로 가능한 최솟값을 구하세요. 연결할 수 없다면 $-1$을 출력하세요. 흰색 정점이 $0$개라면 답은 $0$입니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ R\ B$
$Q$
$t_1\ x_1$
$t_2\ x_2$
$\vdots$
$t_Q\ x_Q$
```

## 제한

- 입력은 모두 정수입니다.
- $1 \le N, Q \le 2 \times 10^5$
- $1 \le R, B \le 10^9$
- $1 \le t_q \le 3 ~ (1 \le q \le Q)$
- $1 \le x_q \le N ~ (1 \le q \le Q, t_q = 1)$
- $1 \le x_q \le 10^9 ~ (1 \le q \le Q, t_q \in \{2, 3\})$

## 출력

$Q$개의 줄에 출력하세요. $q$번째 줄에는 $q$번째 질의를 처리한 직후의 문제에 대한 답을 출력하세요.
