## 이야기

[岩井星人さん](https://www.youtube.com/@yiwiy9)은 경기 프로그래밍 대회에 참가했을 때의 모습을 실황 영상으로 만들어 YouTube에 게시하고 있습니다.

대회 전에 岩井星人さん은 영상 시청자에게 오프닝 토크를 하지만, 대회가 시작해도 문제를 풀기 시작하지 않고 계속 이야기하는 경우가 있습니다.

## 문제 설명

岩井星人さん은 이제 경기 프로그래밍 대회인 **IWAtCoder Beginner Contest 003** (**IWABC003**)에 참가합니다.

IWABC003의 대회 시간은 $6\,000$초이고, $7$개의 문제가 출제됩니다. $i (1 \leq i \leq 7)$번째 문제를 문제 $i$라고 부릅니다.

岩井星人さん은 IWABC003이 시작되는 동시에 $0$초 이상 **수다**를 떤 뒤, IWABC003이 끝날 때까지 문제 $1,2,\ldots,7$을 **이 순서로** 풉니다.

岩井星人さん이 문제를 풀기 시작했다면, 그 문제를 풀기 전에는 다음 문제를 풀기 시작하지 않습니다.

또한, 수다를 끝낸 뒤 문제 $1$을 풀기 시작할 때까지의 시간과 문제를 푼 뒤 다음 문제를 풀기 시작할 때까지의 시간은 $0$초라고 합니다.

岩井星人さん이 문제 $i (1 \leq i \leq 7)$를 풀기 시작한 뒤 끝낼 때까지 걸리는 시간은 $T_i$초입니다.

단, $T_i=-1$인 경우에는 岩井星人さん이 문제 $i$를 풀기 시작하면 대회가 끝날 때까지 계속 푸는 것으로 합니다.

각 $i (1 \leq i \leq 7)$에 대해, IWABC003 중에 岩井星人さん이 문제 $1,2,\ldots,i$를 모두 풀어 끝내는 것을 **$i$ 완**이라고 정의합니다.

岩井星人さん이 $i$ 완을 하고 싶을 때, 수다를 최대 몇 초 동안 떨 수 있는지 구하세요.

단, 岩井星人さん이 $i$ 완을 할 수 없다면 $-1$을 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T_1\ T_2\ \cdots\ T_7$
```

## 제한

- 입력은 모두 정수입니다.
- $1 \leq T_i \leq 6\,000$ 또는 $T_i=-1\ (1 \leq i \leq 7)$입니다.

## 출력

$7$줄 출력하세요.

$i (1 \leq i \leq 7)$번째 줄에는 岩井星人さん이 $i$ 완을 하고 싶을 때 수다를 최대 몇 초 동안 떨 수 있는지 출력하세요. 단, 岩井星人さん이 $i$ 완을 할 수 없다면 $-1$을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
204 507 241 694 2293 -1 -1
```

#### 출력

```text
5796
5289
5048
4354
2061
-1
-1
```

예를 들어, 岩井星人さん이 $5\,289$초 동안 수다를 떨면 문제 $1$을 풀기 시작한 뒤 끝낼 때까지 $204$초, 문제 $2$를 풀기 시작한 뒤 끝낼 때까지 $507$초가 걸리고, 이들의 합은 $5\,289+204+507=6\,000$초입니다. 이는 대회 시간과 같으므로 岩井星人さん은 $2$ 완을 할 수 있으며, 이보다 오래 수다를 떨면 $2$ 완을 할 수 없다는 것을 알 수 있습니다.

따라서 岩井星人さん이 $2$ 완을 하고 싶을 때 수다를 최대 $5\,289$초 동안 떨 수 있으므로, $2$번째 줄에는 $5\,289$를 출력합니다.

또한 岩井星人さん은 $6$ 완을 할 수 없으므로, $6$번째 줄에는 $-1$을 출력합니다.
