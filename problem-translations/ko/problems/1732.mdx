16진수 표기가 길이 `N`이고 `A`부터 `F`만 포함하는 양의 정수 중, 8진수 표기에서 숫자 `1`부터 `7`의 출현 횟수가 모두 같은 수를 16진수로 하나 출력하세요. 없으면 `-1`을 출력하세요.

## 제약

- `1 <= T <= 200`
- `1 <= N <= 200`

## 입력

테스트 케이스 수 `T`와 각 테스트 케이스의 `N`이 주어집니다.

## 출력

각 테스트 케이스의 답을 출력하세요.
