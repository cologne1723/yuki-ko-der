비음이 아닌 정수 $A_0,A_1,\ldots,A_5$가 주어집니다. 셰퍼 기호 `|`는 NAND를 뜻합니다. 다음 명제 논리식이 만족 가능한지 판정하세요.

$$((P_{A_0}\mid P_{A_1})\mid P_{A_2})\mid((P_{A_3}\mid P_{A_4})\mid P_{A_5})$$

<details>
<summary>명제 논리에 익숙하지 않은 사람을 위한 용어 설명 (클릭하여 펼치기)</summary>

명제 변수의 진리값 할당은 대략 각 비음이 아닌 정수 $i$에 대해 $P_i$가 참인지 거짓인지 정하는 대응입니다. 더 형식적으로는 비음이 아닌 정수 전체의 집합 $\mathbb{N}$에서 $\{0,1\}$로 가는 함수입니다. 이 형식화가 익숙하다면 이 설명은 필요하지 않으므로 여기서는 대략적인 설명만 합니다.

명제 논리식 $F$가 만족 가능하다는 것은 $F$를 참으로 만드는 명제 변수의 진리값 할당이 존재한다는 뜻입니다. 예를 들어 논리식 $P_0\land(P_1\lor P_0)$는 모든 명제 변수(단, $P_2$ 이후는 관계없습니다)를 참으로 두면 전체 식이 참이므로 만족 가능합니다. 반면 $P_0\land(\neg P_0)$는 만족 가능하지 않습니다. 실제로 $P_0$가 참이면 오른쪽 부분 식 $\neg P_0$가 거짓이고, $P_0$가 거짓이면 왼쪽 부분 식 $P_0$가 거짓이므로, 어떤 진리값 할당에서도 전체 식이 거짓입니다.

</details>

## 입력

```text
A_0 A_1 A_2 A_3 A_4 A_5
```

## 출력

만족 가능하면 `Yes`, 불가능하면 `No`를 출력하세요.
