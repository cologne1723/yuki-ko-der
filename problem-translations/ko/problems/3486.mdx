## 문제 설명

색에 대해 서로 다른 문화를 가진 $2$개의 나라 yuki 국과 coder 국이 있습니다. 이 $2$개의 나라 사이에는 문화의 차이 때문에 **같은 물체라도 색을 나타내는 방법이 다르다**는 특징이 있습니다.

또한 yuki 국과 coder 국에서는 문화의 차이 때문에 무지개를 구성하는 색도 서로 다릅니다.

구체적으로 yuki 국에서 무지개는 색 $1, 2, \dots, M$의 $M$가지 색으로 구성되고, coder 국에서 무지개는 색 $M+1, M+2, \dots, M+L$의 $L$가지 색으로 구성됩니다.

여기에 $N$개의 펜이 있습니다. $i$번째 펜은 **yuki 국에서는** 색 $A_i$이고, **coder 국에서는** 색 $B_i$입니다.

서로 다른 펜 사이에는 $2$개의 나라에서의 색 대응 관계가 없다는 점에 주의하세요. (서로 다른 $i, j$에 대해 $A_i=A_j$여도 $B_i=B_j$라고 할 수는 없습니다.)

$N$개의 펜에서 $1$개 이상을 선택하는 방법은 $2^N-1$가지입니다. 이 중 다음 조건을 만족하는 선택 방법의 수를 구하세요.

- yuki 국과 coder 국 모두에서, 선택한 펜에 해당 국가의 무지개를 구성하는 모든 색이 포함되어 있습니다.

답은 매우 커질 수 있으므로, $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ M\ L$
$A_1\ B_1$
$A_2\ B_2$
$\vdots$
$A_N\ B_N$
```

$1$번째 줄에 펜의 개수 $N$, yuki 국의 무지개 색 개수 $M$, coder 국의 무지개 색 개수 $L$이 주어집니다.

다음 $N$개의 줄에 $i$번째 펜의 yuki 국에서의 색 $A_i$와 coder 국에서의 색 $B_i$가 주어집니다.

## 제한

- 입력은 모두 정수입니다.
- $1 \leq N \leq 2\times 10^5$
- $1 \leq M,L \leq 18$
- $1 \leq A_i \leq M$
- $M+1 \leq B_i \leq M+L$

## 출력

조건을 만족하는 펜 선택 방법의 수를 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4 2 2
1 3
1 4
2 3
2 4
```

#### 출력

```text
7
```

예를 들어 $1$번째 펜과 $4$번째 펜을 선택한 경우, 색 $1$은 $1$번째 펜에, 색 $2$는 $4$번째 펜에 포함되어 있으므로 yuki 국에서 무지개를 구성하는 색이 모두 포함됩니다.

coder 국에서도 색 $3$은 $1$번째 펜에, 색 $4$는 $4$번째 펜에 포함됩니다. 따라서 이 선택 방법은 조건을 만족합니다.

선택하는 펜의 집합을 $S$라고 하면, 조건을 만족하는 $S$는 $\{1, 4\}, \{2, 3\}, \{1, 2, 3\}, \{1, 2, 4\}, \{1, 3, 4\}, \{2, 3, 4\}, \{1, 2, 3, 4\}$의 $7$가지입니다.

#### 출력

어떤 펜에도 포함되지 않는 색이 존재할 수도 있습니다.
