## 문제 설명

지로는 난해한 프로그래밍 언어인 Whitespace로 아름다운 프로그램을 작성하는 데 열중하고 있습니다. Whitespace는 공백, 탭, 줄 바꿈만 문법에 사용하고 나머지는 무시합니다.

타로는 소스 코드에 전각 공백을 섞어 쓰고 있었지만, 지로는 일부 인터프리터에서 오류가 날 수 있다는 것을 알아차렸습니다. 지로는 $N$줄의 소스 코드를 작성했고, $i$번째 줄에는 공백이 $a_i$개, 탭이 $b_i$개 있습니다.

지로는 편집기의 탭 너비 $x$를 바꾸어 소스 코드의 “추함”을 최소화하려 합니다. 추함은 모든 줄 너비의 최댓값에서 최솟값을 뺀 값입니다. 양의 정수 탭 너비 $x$에 대해

$$f(x)=\left(\max_{1 \le i \le N}(a_i+b_ix)\right)-\left(\min_{1 \le i \le N}(a_i+b_ix)\right)$$

입니다. 탭의 위치가 아니라 공백과 탭의 개수만 너비를 결정합니다. $f(x)$를 최소로 만드는 양의 정수 $x$ 중 가장 작은 것을 출력하세요.

## 입력

```text
N
a_1 b_1
:
a_N b_N
```

- $1 \le N \le 1000$
- $0 \le a_i,b_i \le 10^9$
- 소스 코드에는 공백·탭·줄 바꿈 이외의 문자가 없습니다.

## 출력

$f(x)$를 최소로 만드는 양의 정수 $x$ 중 가장 작은 값을 출력하세요.

## 예제

### 예제 1 {file=""}

```text
2
1 1
3 0
```

```text
2
```

탭 너비를 2로 하면 두 줄의 너비가 모두 3이 되어 추함이 0입니다.

### 예제 2 {file=""}

```text
4
0 0
0 0
0 0
0 0
```

```text
1
```

모든 $x \ge 1$에서 $f(x)=0$이므로 가장 작은 양의 정수 1을 출력합니다.

### 예제 3 {file=""}

```text
2
1 4
9 1
```

```text
3
```

$f(x)$가 최솟값을 갖는 것은 $x=3$일 때뿐이며, 이때 $f(x)=13-12=1$입니다.

