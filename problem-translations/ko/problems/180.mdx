## 이야기

太郎君의 동생 次郎君은 난해한 프로그래밍 언어인 Whitespace로 아름다운 프로그램을 작성하는 데 열중하고 있습니다. Whitespace는 공백, 탭, 줄 바꿈만 문법에 사용하고 나머지는 무시합니다.

太郎君은 소스 코드에 전각 공백을 섞어 쓰고 있었지만, 次郎君은 일부 인터프리터에서 오류가 날 수 있다는 것을 알아차렸습니다.

## 문제 설명

次郎君은 $N$줄의 소스 코드를 작성했고, $i$번째 줄에는 공백이 $a_i$개, 탭이 $b_i$개 있습니다.

次郎君은 편집기의 탭 너비 $x$를 바꾸어 소스 코드의 “추함”을 최소화하려 합니다. 추함은 모든 줄 너비의 최댓값에서 최솟값을 뺀 값입니다. 양의 정수 탭 너비 $x$에 대해

$f(x)=\left(\max_{1 \le i \le N}(a_i+b_ix)\right)-\left(\min_{1 \le i \le N}(a_i+b_ix)\right)$

입니다. 일반적인 편집기와 달리 탭의 위치가 아니라 공백과 탭의 개수만 너비를 결정합니다. $f(x)$를 최소로 만드는 양의 정수 $x$ 중 가장 작은 것을 출력하세요.

## 입력

```text
$N$
$a_1\ b_1$
$\vdots$
$a_N\ b_N$
```

$1$번째 줄에 소스 코드의 줄 수 $N$이 주어집니다. 이어지는 $N$줄에는 각 줄의 정보가 주어지며, $i$번째 줄의 공백 개수 $a_i$와 탭 개수 $b_i$를 나타냅니다.

## 제한

- $1 \le N \le 1\,000$
- $0 \le a_i,b_i \le 10^9$
- 소스 코드에는 공백·탭·줄 바꿈 이외의 문자가 없습니다.
- 소스 코드가 Whitespace 문법에 맞는다는 보장은 없습니다.

## 출력

$f(x)$를 최소로 만드는 양의 정수 $x$ 중 가장 작은 값을 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
1 1
3 0
```

#### 출력

```text
2
```

$1$번째 줄에는 공백이 $1$개, 탭이 $1$개 있습니다. $2$번째 줄에는 공백이 $3$개, 탭이 $0$개 있습니다.

탭 너비를 $2$로 하면 $1$번째 줄의 너비는 $1 + 1 \times 2 = 3$, $2$번째 줄의 너비는 $3 + 0 \times 2 = 3$이 되어 추함이 $0$입니다. 추함이 $0$이 되는 탭 너비는 $2$뿐이므로 $2$를 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
4
0 0
0 0
0 0
0 0
```

#### 출력

```text
1
```

$4$줄 모두 빈 줄입니다. 모든 $x \ge 1$에서 $f(x)=0$이므로 가장 작은 양의 정수 $1$을 출력합니다.

### 예제 3 {file=""}

#### 입력

```text
2
1 4
9 1
```

#### 출력

```text
3
```

$f(x)$가 최솟값을 갖는 것은 $x=3$일 때뿐이며, 이때 $f(x)=13-12=1$입니다.
