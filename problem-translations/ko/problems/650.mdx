## 문제

정점 $n$개인 트리가 주어집니다. 정점 번호는 $0\le i\lt n$, 루트는 0입니다. 변 번호는 $0\le i\lt n-1$이고 변 $i$는 $a_i,b_i$를 연결합니다. 각 변의 $2\times2$ 행렬 $X_i$ 초기값은 단위행렬입니다.

다음 질의를 처리하세요.

- 변경 질의 x: $X_i$를 $\begin{pmatrix}x_{00}&x_{01}\\x_{10}&x_{11}\end{pmatrix}$로 변경합니다.
- 획득 질의 g: $i$가 $j$의 조상이며, $i$에서 $j$까지 경로의 행렬을 모두 곱해 각 원소를 $10^9+7$로 나눈 값을 출력합니다. 루트 쪽을 왼쪽, 잎 쪽을 오른쪽으로 곱합니다.

## 입력

```text
n
a0 b0
...
a(n-2) b(n-2)
q
query1
...
queryq
```

- $2\le n\le100000$
- $1\le q\le20000$
- 변경 질의에서 $0\le i\lt n-1$, $0\le x_{st}\le1000$
- 획득 질의에서 $0\le i,j\lt n$
- 획득 질의가 하나 이상 있습니다.

## 출력

답이 $\begin{pmatrix}c_{00}&c_{01}\\c_{10}&c_{11}\end{pmatrix}$이면 $c_{00}\ c_{01}\ c_{10}\ c_{11}$ 순서로 출력하세요.
