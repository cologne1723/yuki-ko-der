음이 아닌 정수 수열 `A_1,...,A_N`의 인접한 항 사이에 `+`, `-`, `*` 중 하나를 넣어 식을 만듭니다. 곱셈은 다른 연산보다 먼저 계산합니다.

가능한 모든 `3^(N-1)`개 식의 계산 결과 합을 `10^9+7`로 나눈 나머지를 구하세요.

## 제약

- `2 <= N <= 2 * 10^5`
- `0 <= A_i <= 10^9`

## 입력

`N`과 수열 `A`가 주어집니다.

## 출력

답을 `10^9+7`로 나눈 나머지를 출력하세요.
