문자열 `F_1=X`, `F_n=F_{n-1}+Y+rev(F_{n-1})`를 정의합니다. `F_{10^100}`의 구간 `[L_i,R_i]`에 문자 `C_i`가 몇 개 포함되는지 각 질의에 답하세요.

## 제약

- `1 <= |X|,|Y| <= 10^5`
- `1 <= Q <= 5 * 10^4`
- `1 <= L_i <= R_i <= 10^9`
- `X,Y`는 소문자 영어 문자열입니다.

## 입력

문자열 `X,Y`와 `Q`개의 질의가 주어집니다.

## 출력

각 질의의 문자 개수를 출력하세요.
