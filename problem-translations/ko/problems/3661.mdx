## 문제 설명

행이 $H$개이고 열이 $W$개인 격자가 있습니다. 처음에는 어떤 칸에도 색이 칠해져 있지 않습니다.

sepa와 ryota는 이 격자를 사용해 게임을 합니다.

sepa를 선공, ryota를 후공으로 하여 $2$명이 번갈아 다음 조작 중 $1$개를 수행합니다.

- 이 게임에서 아직 선택되지 않은 $1 \leq i \leq H$를 만족하는 정수 $i$를 선택합니다. 이어서 검은색 또는 흰색 중 $1$가지 색을 선택하고, 격자의 $i$번째 행에 있는 모든 칸을 그 색으로 다시 칠합니다.
- 이 게임에서 아직 선택되지 않은 $H+1 \leq j \leq H+W$를 만족하는 정수 $j$를 선택합니다. 이어서 검은색 또는 흰색 중 $1$가지 색을 선택하고, 격자의 $j-H$번째 열에 있는 모든 칸을 그 색으로 다시 칠합니다.

차례가 되었을 때 조작을 수행할 수 없으면 게임을 종료합니다.

게임이 끝났을 때 검은색 칸의 개수에서 흰색 칸의 개수를 뺀 값이 $0$ 이상이면 sepa의 승리이고, 그렇지 않으면 ryota의 승리입니다.

$2$명이 모두 최적으로 행동할 때 어느 쪽이 승리하는지 구하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$H\ W$
```

## 제한

- $1 \leq T \leq 10^5$
- $1 \leq H,W \leq 10^9$
- 입력은 모두 정수입니다.

## 출력

$T$줄 출력하세요.

$k$번째 줄에는 $k$번째 테스트 케이스에서 sepa가 승리한다면 문자열 `sepa`를, ryota가 승리한다면 문자열 `ryota`를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01"}

#### 입력

```text
3
1 1

1000000000 1000000000
```

#### 출력

```text

```
