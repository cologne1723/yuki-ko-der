## 문제 설명

정수를 삼각형 모양으로 배열하여 $3$개의 수열을 만들고, 그 수열들의 LIS 길이를 모두 같은 값으로 만들어 봅시다.

다음 조건을 모두 만족하는 $3$개의 정수열 $A$, $B$, $C$가 존재하는지 판정하고, 존재한다면 예를 $1$개 제시하세요.

- $A$, $B$, $C$의 길이는 모두 $N$입니다.
- $A$, $B$, $C$의 최장 증가 부분 수열(LIS)의 길이는 모두 $K$입니다.
- $A_N=B_1$
- $B_N=C_1$
- $C_N=A_1$
- 길이 $3N-3$인 수열 $P$를
  $P = \{A_1, A_2, \dots, A_{N-1}, B_1, B_2, \dots, B_{N-1}, C_1, C_2, \dots, C_{N-1}\}$
  로 정의합니다. 이때 수열 $P$에는 $1$ 이상 $3N-3$ 이하인 정수가 각각 정확히 $1$개씩 포함되어야 합니다.

$T$개의 테스트 케이스가 주어집니다. 각 테스트 케이스에 대해 답하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $\mathrm{case}_i$ ($1 \leq i \leq T$)는 $i$번째 테스트 케이스를 나타냅니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ K$
```

## 제한

- $T \geq 1$
- $2 \leq N \leq 10^5$
- $1 \leq K \leq N$
- $1$개의 입력 파일에서 $N$의 총합은 $10^5$ 이하입니다.

## 출력

각 테스트 케이스에 대해 조건을 만족하는 정수열 $A$, $B$, $C$가 존재하지 않는다면 `No`를 출력하고, 마지막에 줄 바꿈을 출력하세요.

존재한다면 다음 형식으로 정수열 $A$, $B$, $C$를 출력한 뒤, 마지막에 줄 바꿈을 출력하세요. 조건을 만족하는 정수열 $A$, $B$, $C$가 여러 개 존재한다면 그중 어느 것이나 정답으로 인정됩니다.

```text
Yes
$A_1\ A_2\ \dots\ A_N$
$B_1\ B_2\ \dots\ B_N$
$C_1\ C_2\ \dots\ C_N$
```

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
2 1
3 2
5 5
```

#### 출력

```text
No
Yes
3 6 5
5 1 4
4 2 3
No
```

$1$번째 테스트 케이스에 대해 조건을 만족하는 정수열 $A$, $B$, $C$는 존재하지 않습니다. 예를 들어 $A = \{1, 2\}, B = \{2, 3\}, C = \{3, 1\}$로 두면 $2$번째 조건을 제외한 조건은 모두 만족하지만, $A$, $B$, $C$의 LIS 길이는 각각 $2$, $2$, $1$이므로 $2$번째 조건을 만족하지 않습니다.

$2$번째 테스트 케이스에 대해 정수열 $A = \{3, 6, 5\}, B = \{5, 1, 4\}, C = \{4, 2, 3\}$은 모든 조건을 만족합니다. 조건을 만족하는 정수열 $A$, $B$, $C$는 이외에도 존재하지만, 그중 어느 것이나 정답으로 인정됩니다.
