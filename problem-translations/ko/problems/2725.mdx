## 문제

변수 `y=N`에서 시작합니다. 번갈아 `2 ≤ x ≤ y`인 정수 중 `x`가 `N`의 약수가 아니고 `x`와 `y`가 서로소인 것을 골라 `y=x`로 바꿉니다. 더 이상 움직일 수 없게 된 사람이 패배합니다.

## 제약

- `1 ≤ T ≤ 10^5`
- `2 ≤ N ≤ 10^18`

## 입력

```text
T
N_1
⋮
N_T
```

## 출력

코어가 이기면 `K`, 파체가 이기면 `P`를 출력하세요.
