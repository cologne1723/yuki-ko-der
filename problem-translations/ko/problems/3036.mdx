## 이야기

`nauclhlt`가 `null`과 `acht`로 이루어져 있다는 사실은 잘 알려져 있습니다.

## 문제 설명

길이 $N$인 문자열 $S$가 주어집니다. 길이가 같은 문자열의 쌍 $(P, Q)$ 중, 이에 대응하는 **Nauclhlt형 문자열**이 $S$와 일치하는 것이 존재하는지 판정하고, 존재한다면 그러한 $(P, Q)$를 구하세요.

$|X|=|Y|=L$을 만족하는 문자열의 쌍 $(X, Y)$에 대응하는 **Nauclhlt형 문자열**이란, 각 $i$($1 \leq i \leq L$)에 대해 $Z_{2i-1}=X_i$, $Z_{2i}=Y_i$를 만족하는 길이 $2L$의 문자열 $Z$를 말합니다.

예를 들어, (`bu`, `le`)에 대응하는 **Nauclhlt형 문자열**은 `blue`입니다.

### 문자열에 관한 표기

문자열 $A$에 대해 $|A|$는 $A$의 길이를, $A_i$($1 \leq i \leq |A|$)는 $A$의 $i$번째 문자를 나타냅니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$S$
```

입력은 다음 제한을 만족합니다.

## 제한

- $1 \leq N \leq 100\,000$
- $S$는 영소문자로 이루어진 길이 $N$의 문자열입니다.
- $N$은 정수입니다.

## 출력

조건을 만족하는 $(P, Q)$가 존재한다면, $1$번째 줄에 `Yes`를 출력하고 $2$번째 줄에 $P$, $Q$를 이 순서대로 공백으로 구분하여 출력하세요. 존재하지 않는다면 `No`만 출력하세요.

마지막에 줄 바꿈을 출력하세요.
