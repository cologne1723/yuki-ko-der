## 이야기

eiramくん은 대응이 맞는 괄호열을 좋아하지만, `()()()`보다 `((()))`의 가치가 더 높다고 생각합니다.

길이가 주어진 대응이 맞는 괄호열에 eiramくん은 얼마나 큰 가치를 느낄까요?

## 문제 설명

문자열 $X$가 **대응이 맞는 괄호열**이라는 것은 다음 조건을 만족한다는 뜻입니다. (이는 프로그래밍 대회 문제에서 자주 사용되는 정의와 같습니다.)

- $X$에 연속 부분 문자열로 포함된 `()`를 삭제하는 작업을 $0$회 이상 반복하여 $X$를 빈 문자열로 만들 수 있습니다.

예를 들어 `()(())`와 `()()()()`는 **대응이 맞는 괄호열**이지만, `))((`와 `)()()(` 등은 **대응이 맞는 괄호열**이 아닙니다.

대응이 맞는 괄호열 $T$에 대해 다음 절차를 수행한 뒤의 $x$ 값을 $f(T)$로 정의합니다.

- 처음에 $S$를 빈 집합, $x=0$으로 하고, $i=1,2,\dots,N$ 순서로 다음을 수행합니다.
  - $T_i=$`(`이면 $S$에 $i$를 추가합니다.
  - $T_i=$`)`이면, 문자열 $T$의 열린 구간 $(j,i)$에 해당하는 문자열이 **대응이 맞는 괄호열**이 되도록 하는 $j$ ($1\leq j<i$)를 $S$에서 제거한 뒤, $x$에 $S$의 원소 수를 더합니다.

예를 들어, $T$가 `()(())`이면 $f(T)=1$이고, $T$가 `()()()`이면 $f(T)=0$입니다.

양의 정수 $N$이 주어집니다. 길이 $N$인 대응이 맞는 괄호열 $S$로 가능한 모든 문자열에 대한 $f(S)$의 합을 구하세요.

답은 매우 커질 수 있으므로, $998\,244\,353$으로 나눈 나머지를 구하세요.

### 문자열에 관한 표기

문자열 $A$의 길이를 $|A|$라고 할 때, $A_i$ ($1\leq i\leq |A|$)로 $A$의 $i$번째 문자를 나타냅니다.

## 입력

```text
$N$
```

## 제한

- $1\leq N\leq 2\,000$
- 입력은 모두 정수입니다.

## 출력

$f(S)$의 합을 $998\,244\,353$으로 나눈 나머지를 $r$이라고 할 때, 다음 형식으로 한 줄에 출력하세요.

```text
$r$
```

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
```

#### 출력

```text
0
```

길이가 $2$인 대응이 맞는 괄호열은 `()` 하나뿐입니다. $T$가 `()`이면 $f(T)=0$이므로 `0`을 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
4
```

#### 출력

```text
1
```

길이가 $4$인 대응이 맞는 괄호열은 `(())`과 `()()` 두 개입니다. $T$가 `(())`이면 $f(T)=1$이고, $T$가 `()()`이면 $f(T)=0$이므로 합은 `1`입니다.

### 예제 3 {file=""}

#### 입력

```text
11
```

#### 출력

```text
0
```

길이가 $11$인 대응이 맞는 괄호열은 존재하지 않습니다.
