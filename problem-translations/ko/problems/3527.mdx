## 문제 설명

길이 $N$인 정수열 $A$, $B$가 주어집니다. 유리수 $x$에 대해 함수 $f(x)$를 다음과 같이 정의합니다.

$f(x) = \sum_{i=1}^N |A_i x - B_i|$

$f(x)$가 최솟값을 갖는 $x$ 중 가장 작은 $x$를 $\mathrm{mod} 10^9+7$로 출력하세요.

단, 그러한 $x$가 존재하며 $\mathrm{mod} 10^9+7$에서 유일하게 표현될 수 있음이 보장됩니다.

### 유리수 $x$에 대한 $x\mathop{\rm mod} 10^9+7$의 정의

이 문제에서는 답인 $x$를 기약분수 $\frac{P}{Q}$로 나타냈을 때 $Q \not\equiv 0 (\mathrm{mod} 10^9+7)$임이 보장됩니다. 따라서

$R \times Q \equiv P (\mathrm{mod}\ 10^9+7)$이고 $0 \le R < 10^9+7$인 $R$이 유일하게 정해집니다. 이 $R$을 답으로 출력하세요.

## 입력

```text
$N$
$A_1\ A_2\ A_3\ \cdots\ A_N$
$B_1\ B_2\ B_3\ \cdots\ B_N$
```

## 제한

- $1 \le N \le 2\times 10^5$
- $|A_i|, |B_i| \le 10^9$
- $A_i \ne 0$인 $i$가 존재합니다. ($1 \le i \le N$)
- 답인 $x$를 기약분수로 나타냈을 때, 분모는 $10^9+7$의 배수가 아닙니다.
- 입력은 모두 정수입니다.

## 출력

조건을 만족하는 $x$의 최솟값을 $\mathrm{mod} 10^9+7$로 출력하세요. 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
1 1 1
1 1 -1
```

#### 출력

```text
1
```

$f(x) = |x-1| + |x-1| + |x+1|$입니다. $x=1$일 때 최솟값 $f(1)=2$를 가지므로 $1$을 출력하세요.


#### 출력

```text
166666669
```
