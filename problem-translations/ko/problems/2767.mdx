## 문제

`A ≤ B`인 양의 정수 `A,B`가 주어집니다. `B+X`가 `A+X`의 배수가 되는 음이 아닌 정수 `X`가 존재하는지 판정하고, 존재하면 최솟값을 구하세요.

## 제약

- `1 ≤ T ≤ 100`
- `1 ≤ A ≤ B ≤ 10^9`

## 입력

```text
T
A_1 B_1
⋮
A_T B_T
```

## 출력

가능한 `X`의 최솟값을 출력하세요. 없으면 `-1`을 출력하세요.
