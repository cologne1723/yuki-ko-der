## 문제 설명

$H$행 $W$열의 이차원 배열 $A$가 주어집니다. 이 이차원 배열에 대해 교차값 $C_{i,j}$를 $i$번째 행의 합과 $j$번째 열의 합의 곱으로 정의합니다. 즉, 다음과 같습니다.

$C_{i,j} = \left(\sum_{k=1}^W A_{i,k}\right) \times \left(\sum_{l=1}^H A_{l,j}\right)$

또한 이 이차원 배열 $A$에 대한 점수 $S$를 $C_{i,j}$의 최댓값으로 정의합니다. 즉, 다음과 같습니다.

$S = \max_{1 \le i \le H, 1 \le j \le W} C_{i,j}$

$A$에 대해 다음 조작을 $0$회 이상 수행할 수 있습니다.

- 임의의 $i,j$ $(1 \le i \le H, 1 \le j \le W)$를 선택하고, 비용 $2^{B_{i,j}}$를 사용하여 $A_{i,j}$를 $1$ 증가시킵니다.

비용을 합계 $K$까지 사용할 수 있을 때, 조작 후 이차원 배열 $A$의 점수 $S$의 최댓값을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$H\ W\ K$
$A_{1,1}\ A_{1,2}\ \ldots\ A_{1,W}$
$A_{2,1}\ A_{2,2}\ \ldots\ A_{2,W}$
$\vdots$
$A_{H,1}\ A_{H,2}\ \ldots\ A_{H,W}$
$B_{1,1}\ B_{1,2}\ \ldots\ B_{1,W}$
$B_{2,1}\ B_{2,2}\ \ldots\ B_{2,W}$
$\vdots$
$B_{H,1}\ B_{H,2}\ \ldots\ B_{H,W}$
```

$1$번째 줄에 행의 수 $H$, 열의 수 $W$, 사용할 수 있는 비용의 합계 $K$가 주어집니다.

다음 $H$개 행에 이차원 배열 $A$가 주어집니다. $i$번째 행의 $j$번째 수는 $A_{i,j}$입니다.

그다음 $H$개 행에 각 원소를 $1$ 증가시키는 데 필요한 비용의 지수를 나타내는 이차원 배열 $B$가 주어집니다. $i$번째 행의 $j$번째 수는 $B_{i,j}$입니다.

## 제한

- $2 \le H,W \le 600$
- $1 \le K \le 2^{30}$
- $1 \le A_{i,j} \le 10^6$
- $0 \le B_{i,j} \le 30$
- 모든 입력은 정수입니다.

## 출력

조작 후 $A$의 점수의 최댓값을 출력하세요. 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 2 6
1 2
3 4
1 1
2 2
```

#### 출력

```text
64
```

다음과 같이 조작합니다.

- $i=1,j=2$를 선택하고, 비용 $2^1$을 사용하여 $A_{1,2}$를 $1$ 증가시킵니다.
- $i=2,j=2$를 선택하고, 비용 $2^2$를 사용하여 $A_{2,2}$를 $1$ 증가시킵니다.

조작 후 $A$는 다음과 같습니다.

```text
1 3
3 5
```

이때 $C_{2,2} = (3+5) \times (3+5) = 64$가 되고, $C_{i,j}$ 중 최댓값이므로 $A$의 점수가 됩니다. 다른 어떤 방식으로 조작해도 점수를 $64$보다 크게 만들 수 없으므로 $64$가 답입니다.
