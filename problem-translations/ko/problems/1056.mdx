이 문제의 실행 시간 제한은 $3$초이며, C++ 이외의 언어로는 정답을 맞히기 어려울 수 있습니다. 입출력에는 `scanf`/`printf`를 사용하는 것을 권장합니다.

## 문제 설명

$N$행 $N$열의 격자 모양으로 $N^2$개의 램프가 배치되어 있습니다. 위에서 $i$번째 행, 왼쪽에서 $j$번째 열에 있는 램프를 램프 $(i,j)$라고 합니다.

$N^2$개 램프의 상태를 나타내는 보드가 $M$개 주어집니다. $A_{i,j,k}$가 `#`이면 $i$번째 보드의 램프 $(j,k)$가 켜져 있고, `.`이면 꺼져 있습니다.

$1 \le i < j \le M$을 만족하는 모든 $i,j$에 대해, $A_i$의 보드에서 시작하여 다음의 방법으로 $A_j$의 보드를 만들 수 있는지 판정하세요.

정수 $k$를 선택하여 다음 중 하나를 실행하는 작업을 $0$회 이상 원하는 횟수만큼 수행할 수 있습니다.

- $i=k$인 모든 램프 $(i,j)$에 대해, 켜져 있으면 끄고 그렇지 않으면 켭니다.
- $j=k$인 모든 램프 $(i,j)$에 대해, 켜져 있으면 끄고 그렇지 않으면 켭니다.
- $i+j=k$인 모든 램프 $(i,j)$에 대해, 켜져 있으면 끄고 그렇지 않으면 켭니다.
- $i-j=k$인 모든 램프 $(i,j)$에 대해, 켜져 있으면 끄고 그렇지 않으면 켭니다.

## 입력

```text
$N\ M$
$A_{1,1,1}A_{1,1,2}A_{1,1,3}\dots A_{1,1,N}$
$A_{1,2,1}A_{1,2,2}A_{1,2,3}\dots A_{1,2,N}$
$A_{1,3,1}A_{1,3,2}A_{1,3,3}\dots A_{1,3,N}$
$\hspace{55pt} \vdots$
$A_{1,N,1}A_{1,N,2}A_{1,N,3}\dots A_{1,N,N}$

$A_{2,1,1}A_{2,1,2}A_{2,1,3}\dots A_{2,1,N}$
$A_{2,2,1}A_{2,2,2}A_{2,2,3}\dots A_{2,2,N}$
$A_{2,3,1}A_{2,3,2}A_{2,3,3}\dots A_{2,3,N}$
$\hspace{55pt} \vdots$
$A_{2,N,1}A_{2,N,2}A_{2,N,3}\dots A_{2,N,N}$

$\hspace{60pt} \vdots$

$A_{M,1,1}A_{M,1,2}A_{M,1,3}\dots A_{M,1,N}$
$A_{M,2,1}A_{M,2,2}A_{M,2,3}\dots A_{M,2,N}$
$A_{M,3,1}A_{M,3,2}A_{M,3,3}\dots A_{M,3,N}$
$\hspace{55pt} \vdots$
$A_{M,N,1}A_{M,N,2}A_{M,N,3}\dots A_{M,N,N}$
```

## 제한

$1 \le N \le 200$

$2 \le M \le 200$

$N$, $M$은 정수입니다.

$A_{i,j,k}$는 `#` 또는 `.`입니다.

## 출력

다음 형식에 따라 출력하세요.

```text
$B_{1,2}B_{1,3}B_{1,4}B_{1,5}\dots B_{1,M}$
$B_{2,3}B_{2,4}B_{2,5}\dots B_{2,M}$
$B_{3,4}B_{3,5}\dots B_{3,M}$
$\hspace{17pt} \vdots$
$B_{M - 1,M}$
```

$B_{i,j}$는 $A_i$의 보드에서 $A_j$를 만들 수 있는 경우 `1`, 만들 수 없는 경우 `0`이어야 합니다.

마지막에는 개행을 넣으세요. 즉, 총 정확히 $M - 1$개의 개행을 출력하세요. (2020/05/15 22:29 추가)

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 3
.....
.....
.....
.....
.....

....#
...#.
..#..
.#...
#....

#.##.
#..##
.#.#.
...#.
.#...
```

#### 출력

```text
10
0
```

보드 $1$에서 보드 $2$를 만드는 것은 $i+j=6$인 램프를 반전하면 가능하다. 보드 $1$에서 보드 $3$을 만드는 것과 보드 $2$에서 보드 $3$을 만드는 것은 어떤 방법으로도 불가능하다.
