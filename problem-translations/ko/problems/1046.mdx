## 문제 설명

$N$개의 과일이 있고, $i$번째 과일의 신선도는 $A_i$입니다.

여기에서 $1$개 이상 $K$개 이하의 과일을 골라 믹스 주스를 만듭니다.

믹스 주스의 **맛**을 고른 과일의 신선도 총합으로 정의합니다.

맛의 최댓값을 구하세요.

## 입력

```text
N K
A_1 A_2 \dots A_N
```

## 제한

$N$, $K$, $A_i$는 정수입니다.

$1 \le K \le N \le 100$

$|A_i| \le 100$

## 출력

맛의 최댓값을 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2
1 3 2
```

#### 출력

```text
5
```

신선도가 $2$, $3$인 과일을 고르는 것이 최적입니다.

### 예제 2 {file=""}

#### 입력

```text
4 3
1 2 -1 -2
```

#### 출력

```text
3
```

신선도가 $1$, $2$인 과일을 고르는 것이 최적입니다. 과일을 반드시 $K$개 골라야 하는 것은 아니라는 점에 주의하세요.

### 예제 3 {file=""}

#### 입력

```text
5 5
0 0 0 0 0
```

#### 출력

```text
0
```

맛있지도 맛없지도 않습니다.
