소수 $P$가 주어집니다. $P=i^2+j^2$를 만족하는 양의 정수쌍 $(i,j)$가 존재하는지 판정하세요.

## 조건

- $P$는 $10^8$ 이하의 소수입니다.

## 입력

소수 $P$가 주어집니다.

## 출력

존재하면 `Yes`, 존재하지 않으면 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
```

#### 출력

```text
No
```

### 예제 2 {file=""}

#### 입력

```text
5
```

#### 출력

```text
Yes
```

### 예제 3 {file=""}

#### 입력

```text
7
```

#### 출력

```text
No
```
