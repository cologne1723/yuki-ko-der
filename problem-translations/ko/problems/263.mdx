## 문제

예전에 [Common Palindromes](http://judge.u-aizu.ac.jp/onlinejudge/description.jsp?id=2292)라는 문제가 있었습니다. 이름 그대로 두 문자열의 공통 부분 회문 쌍의 개수를 구하는 문제였고, 당시 참가자들을 크게 괴롭혔습니다. 그로부터 3년 이상 지나 CPU 성능과 경쟁 프로그래머의 실력도 크게 향상되었습니다. Common Palindromes의 최단 실행 시간이 0.05초 아래라고 하니 문자열 길이를 10배로 늘려도 풀 수 있을 것입니다.

문자열 $S,T$가 주어질 때 다음 조건을 모두 만족하는 순서 있는 튜플 $(i,j,k,l)$의 개수를 구하세요. 문자열 $U$의 $x$번째 문자부터 $y$번째 문자까지의 연속 부분 문자열을 $U[x,y]$로 나타냅니다.

- $1 \leq i \leq j \leq |S|$
- $1 \leq k \leq l \leq |T|$
- $S[i,j]=T[k,l]$
- $S[i,j]$는 회문입니다.

## 입력

```text
S
T
```

- $1 \leq |S| \leq 500000$
- $1 \leq |T| \leq 500000$
- $S,T$는 영대문자(`A`〜`Z`)만으로 이루어집니다.
- 위 제약에 따라 답은 항상 $10^{18}$ 이하임이 보장됩니다.
- 원문 공개 코드를 그대로 복사해 맞히지 못하도록 제약이 다소 강하게 설정되어 있습니다.

## 출력

순서 있는 튜플 $(i,j,k,l)$의 개수를 출력하세요. 마지막에 개행을 넣으세요.

## 샘플

### 입력 1 {file="stdin"}

```text
AABA
BAAB
```

### 출력 1 {file="stdout"}

```text
9
```

가능한 튜플은 $(1,1,2,2),(1,1,3,3),(2,2,2,2),(2,2,3,3),(4,4,2,2),(4,4,3,3),(3,3,1,1),(3,3,4,4),(1,2,2,3)$로 총 9개입니다.

### 입력 2 {file="stdin"}

```text
USAGI
MYON
```

### 출력 2 {file="stdout"}

```text
0
```

원문 문제의 샘플 케이스도 통과합니다.
