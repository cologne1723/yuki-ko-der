## 문제 설명

이 문제는 에스퍼하지 않으면 풀 수 없습니다.

## 입력

```text
$S\ K$
```

정수 $S$, $K$가 주어집니다.

## 제한

- $1 \leq S \leq 10^9$
- $1 \leq K \leq 10^9$

## 출력

에스퍼하여 답을 출력하세요.

마지막에 개행하세요.
