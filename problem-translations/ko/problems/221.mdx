## 문제

인구가 1,000,000명인 도시가 있습니다. 이 도시에는 마피아가 숨어 있으며, 마피아 탐지기는 사람 한 명이 마피아인지 아닌지를 99%의 정확도로 판별합니다. 즉, 마피아를 마피아라고 판정할 확률과 마피아가 아닌 사람을 마피아가 아니라고 판정할 확률이 각각 99%입니다.

탐지기가 마피아라고 판정한 사람은 모두 체포됩니다. 이 도시에는 마피아가 정확히 $N$명 있습니다. 체포된 사람 중 마피아가 아닌 사람의 비율을 백분율로 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
N
```

- $0 \leq N \leq 10000$

## 출력

체포된 사람 중 마피아가 아닌 사람의 비율을 백분율로 출력하세요. 절대 오차 또는 상대 오차가 $10^{-2}$ 이하이면 정답으로 인정됩니다.

## 샘플

### 입력 1 {file="stdin"}

```text
100
```

### 출력 1 {file="stdout"}

```text
50
```

### 입력 2 {file="stdin"}

```text
2500
```

### 출력 2 {file="stdout"}

```text
2.94117647058824
```

### 입력 3 {file="stdin"}

```text
1
```

### 출력 3 {file="stdout"}

```text
99.0196078431373
```
