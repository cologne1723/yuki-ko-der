## 문제 설명

Y시는 마피아 구성원이 많이 살아 범죄의 온상이 되어 있습니다. 이에 Y시는 마피아 탐지기를 도입해 구성원으로 판정된 사람을 모두 체포하기로 했습니다.

인구가 $1\,000\,000$명인 Y시에서 마피아 탐지기는 사람 $1$명이 마피아인지 아닌지를 $99$%의 정확도로 판별합니다. 즉, 마피아를 마피아라고 판정할 확률과 마피아가 아닌 사람을 마피아가 아니라고 판정할 확률이 각각 $99$%입니다.

Y시의 모든 주민을 탐지기로 판정하여 마피아라고 판정한 사람은 모두 체포합니다. 그런데 실제로는 주민 $10\,000$명당 마피아가 $N$명밖에 없다는 사실이 밝혀졌습니다. 체포된 사람 중 마피아가 아닌 사람의 비율을 백분율로 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- $N$은 정수입니다.
- $0 \leq N \leq 10\,000$

## 출력

체포된 사람 중 마피아가 아닌 사람의 비율을 백분율로 출력하세요. 절대 오차 또는 상대 오차가 $10^{-2}$ 이하이면 정답으로 인정됩니다. 단위는 붙이지 않아도 됩니다. 마지막에 줄바꿈을 하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
100
```

#### 출력

```text
50
```

$10\,000$명당 마피아가 $100$명이라면, 오인 체포일 확률은 $50$%로 예상됩니다.

### 예제 2 {file=""}

#### 입력

```text
2500
```

#### 출력

```text
2.94117647058824
```

$10\,000$명 중 마피아가 $2\,500$명이라면, 오인 체포일 확률은 약 $2.940$%로 예상됩니다.

### 예제 3 {file=""}

#### 입력

```text
1
```

#### 출력

```text
99.0196078431373
```

$10\,000$명 중 마피아가 $1$명이라면, 오인 체포일 확률은 $99$% 이상으로 예상됩니다.
