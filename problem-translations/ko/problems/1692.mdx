`1`부터 `M`까지의 정수 중 `N`개를 골라 `N`명에게 하나씩 나누어 줍니다. 사람 `i`가 `A_i`를 가지고 있다고 예측할 때, 실제로 맞는 예측 수의 가능한 최댓값과 최솟값을 구하세요.

## 제약

- `1 <= N <= M <= 2 * 10^5`
- `1 <= A_i <= M`

## 입력

`N M`과 `A_1,...,A_N`이 주어집니다.

## 출력

가능한 맞는 예측 수의 최댓값과 최솟값을 출력하세요.
