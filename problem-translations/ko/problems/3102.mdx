## 문제 설명

음이 아닌 정수 $N$이 주어집니다. 음이 아닌 정수 $k$ 중에서
$\lfloor \sqrt{k} \rfloor \oplus k = N$을 만족하는 것이 있는지 판정하고,
있다면 그중 $1$개를 찾으세요.

여기서 $\oplus$는 비트별 XOR을 나타냅니다. 또한 실수 $x$에 대하여
$\lfloor x \rfloor$는 $x$를 넘지 않는 가장 큰 정수를 나타냅니다. 예를 들어
$\lfloor 3.14 \rfloor = 3$, $\lfloor 4 \rfloor = 4$입니다.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 문제를 해결하세요.

## 입력

```text
$T$
$\text{case}_1$
$\text{case}_2$
$\vdots$
$\text{case}_T$
```

여기서 $\text{case}_i$ $(1\leq i\leq T)$는 $i$번째 테스트 케이스를 나타냅니다.
각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- 입력은 모두 정수입니다.
- $1\leq T\leq 100$
- 각 테스트 케이스에 대하여 $0\leq N<2^{60}$

## 출력

$T$줄을 출력하세요. $i$ $(1\leq i\leq T)$번째 줄에는 $i$번째 테스트 케이스의
$N$에 대하여 $\lfloor \sqrt{k} \rfloor \oplus k = N$을 만족하는 음이 아닌 정수
$k$가 있다면 $k$를 $1$개 출력하세요. 그러한 음이 아닌 정수 $k$가 없다면 $-1$을
출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
8
1
2
10
0
11
12
998244353
1152921504606846975
```

#### 출력

```text
-1
3
9
0
-1
15
998275946
1152921503533105152
```

$1$번째 테스트 케이스에서는 $\lfloor \sqrt{k} \rfloor \oplus k = 1$을 만족하는
음이 아닌 정수가 존재하지 않습니다.

$2$번째 테스트 케이스에서는 $\lfloor \sqrt{3} \rfloor \oplus 3 = 1 \oplus 3 = 2$이므로,
$3$을 출력합니다.

$3$번째 테스트 케이스에서는 $\lfloor \sqrt{k} \rfloor \oplus k = 10$을 만족하는
음이 아닌 정수가 $k=8$과 $k=9$ $2$개가 존재하지만, 어느 것을 출력해도 됩니다.

$4$번째 테스트 케이스에서는 $\lfloor \sqrt{k} \rfloor \oplus k = 0$을 만족하는
음이 아닌 정수가 $k=0$과 $k=1$ $2$개가 존재하지만, 어느 것을 출력해도 됩니다.
