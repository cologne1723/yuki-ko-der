$N$개의 정점과 $N$개의 간선으로 이루어진 연결 단순 무방향 그래프를 $K$가지 색으로 색칠합니다. 인접한 정점은 같은 색을 사용할 수 없습니다. 가능한 색칠 수를 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
N K
u1 v1
...
uN vN
```

## 출력

답을 출력하세요.
