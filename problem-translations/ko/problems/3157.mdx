## 문제 설명

다음 조건 중 $1$가지 이상을 만족하는 양의 정수를 **ナベアツ数**라고 부릅니다.

- $3$의 배수입니다.
- $10$진수로 표기했을 때 $3$을 포함합니다.

양의 정수 $N$이 주어집니다. $N$ 이하의 양의 정수 중 ナベアツ数가 아닌 것의 최댓값을 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

## 제한

- $N$은 $10^{10^6}=10^{1\,000\,000}$ 이하의 양의 정수입니다.

## 출력

$N$ 이하의 양의 정수 중 ナベアツ数가 아닌 것의 최댓값을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
430
```

#### 출력

```text
428
```

$430$은 $3$을 포함하므로 ナベアツ数입니다.

$429$는 $3$의 배수이므로 ナベアツ数입니다.

$428$은 $3$의 배수가 아니고 $3$을 포함하지도 않으므로 ナベアツ数가 아닙니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
333
```

#### 출력

```text
299
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
271828182845904523536
```

#### 출력

```text
271828182845904522998
```

$N$은 매우 클 수 있습니다.
