## 문제 설명

사부로는 주류점에서 일하며 주문받은 상품을 트럭으로 배달하려고 합니다.

출발지인 주류점과 모든 배달지는 2차원 평면에 있고, 주류점은 $(X_0,Y_0)$, $i$번째 배달지는 $(X_i,Y_i)$입니다. 각 배달지에서는 무게 $W_i$인 상품을 트럭에서 내려 전달합니다.

마을의 길은 격자 모양으로 정비되어 있어 상하좌우로 이동할 수 있습니다. 무게 $W$의 짐을 싣고 1만큼 이동하는 데 걸리는 시간 $T$는 다음과 같습니다.

$T=\frac{W+100}{120}$

각 배달지에서 무게 $W_i$인 짐을 내리는 데에는 $W_i$의 시간이 걸립니다.

주류점에서 모든 짐을 싣고 각 배달지를 방문하여 배달을 끝낸 뒤 주류점으로 돌아오는 최소 시간을 구하세요.

- 트럭에는 배달할 짐 이외의 것을 싣지 않습니다.
- 이동 중 어떤 이유로도 정지하거나 감속하지 않고 등속으로 이동합니다.
- 처음 짐을 싣는 시간은 포함하지 않습니다.

## 입력

```text
X_0 Y_0
N
X_1 Y_1 W_1
X_2 Y_2 W_2
$\vdots$
X_N Y_N W_N
```

주류점 좌표와 배달지 수 $N$이 주어집니다. $(1 \le N \le 13)$

이어지는 $N$개 행에 각 배달지 $i$의 좌표를 나타내는 정수 $(X_i,Y_i)$와 배달할 짐의 무게 $W_i$가 주어집니다. $W_i$는 소수점 이하 6자리까지의 소수 또는 정수입니다. $(1 \le i \le N,\ 1 \le W_i \le 100)$

주류점과 배달지의 좌표는 모두 $0 \le X_i,Y_i \le 1000$ 범위입니다.

## 출력

모든 짐의 배달을 마칠 때까지의 최소 시간을 출력하세요. 절대 오차 또는 상대 오차가 $10^{-7}$ 이하이면 정답으로 인정합니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0 0
3
100 178 100
23 25 40
34 31 90
```

#### 출력

```text
989.75
```

주류점에서 출발해 배달지 2, 3, 1 순서로 방문하는 것이 최소입니다.

### 예제 2 {file=""}

#### 입력

```text
0 0
5
0 0 100
0 0 100
0 0 100
0 0 100
0 1000 1
```

#### 출력

```text
2076
```

주류점과 배달지가 같은 위치이거나 같은 위치에 여러 배달지가 있을 수 있습니다. 1~4번째 배달지는 이동할 필요 없이 짐을 내리는 데 총 400이 걸립니다. 5번째 배달지로 가는 데 842.666667, 주류점으로 돌아오는 데 833.333333이 걸립니다.
