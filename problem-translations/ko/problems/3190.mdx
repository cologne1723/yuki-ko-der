## 이야기

기말고사의 배점은 교사들이 제안한 배점의 중앙값으로 결정하기로 했습니다.

## 문제 설명

길이가 $N$이고 총합이 $S$인 모든 음이 아닌 정수열로 이루어진 집합을 $A$라고 합니다. $A$가 유한 집합임을 보일 수 있습니다.

길이 $N$인 음이 아닌 정수열 $V_1,V_2,\cdots,V_M$을 각각 $A$에서 균등하게 무작위로 선택합니다. 각 수열은 서로 독립적으로 정합니다.

또한 길이 $N$인 음이 아닌 정수열 $W=(W_1,W_2,\cdots,W_N)$를 $W_i$가 수열 $(V_{1,i},V_{2,i},\cdots,V_{M,i})$의 중앙값이 되도록 정합니다. 여기서 $V_{j,i}$는 $V_j$의 $i$번째 원소입니다.

길이 $M$인 수열의 중앙값은 내림차순으로 정렬했을 때 $\left\lfloor\frac{M+1}{2}\right\rfloor$번째인 값으로 정의합니다.

$W_1+W_2+\cdots+W_N$의 기댓값을 법 $998\,244\,353$에서의 값으로 구하세요.

입력으로 주어지는 $N,S,M$과 소수 $P=998\,244\,353$에 대해 기댓값의 법 $P$에서의 값이 정의되는 경우만 주어집니다.

엄밀히 말하면, 입력으로 주어지는 $N,S,M$에 대해 $W_1+W_2+\cdots+W_N$의 기댓값은 항상 유리수이며, 서로소인 음이 아닌 정수 $x,y$를 사용하여 $\frac{x}{y}$로 나타낼 수 있습니다. 또한 $y\not\equiv0\pmod P$가 보장됩니다. 이때 $yz\equiv x\pmod P$, $0\leq z<P$를 만족하는 음이 아닌 정수 $z$가 유일하게 정해지므로, 이 $z$를 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ S\ M$
```

## 제한

- $1\leq N\leq 2\times 10^5$
- $1\leq S\leq 2\times 10^5$
- $1\leq M\leq 2\times 10^5$
- 입력은 모두 정수입니다.
- 답이 법 $998\,244\,353$에서 정의됩니다.

## 출력

$W_1+W_2+\cdots+W_N$의 기댓값을 법 $998\,244\,353$에서의 값으로 출력하고, 마지막에 개행하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 1 3
```

#### 출력

```text
1
```

$A=\{(0,1),(1,0)\}$입니다. 예를 들어 $V_1=(0,1),V_2=(1,0),V_3=(1,0)$일 때 $W=(1,0)$이 됩니다.

### 예제 2 {file=""}

#### 입력

```text
1 2 3
```

#### 출력

```text
2
```

$A=\{(2)\}$입니다. 예를 들어 $V_1=(2),V_2=(2),V_3=(2)$일 때 $W=(2)$가 됩니다.

#### 입력

```text
4 1 2
```

#### 출력

```text
249561090
```

$W_1+W_2+\cdots+W_N$의 기댓값은 $\frac{7}{4}$입니다.
