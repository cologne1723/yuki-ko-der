정점에 문어 또는 소 그림이 붙은 `N`개 정점의 트리를 문어소 나무라고 합니다. 문어 정점의 차수는 8 이하, 소 정점의 차수는 4이며, 같은 그림의 정점끼리는 인접하지 않습니다.

## 조건

차수가 8인 문어 정점을 완전한 문어라고 할 때, 완전한 문어가 정확히 `P`개인 나무의 개수를 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `2 <= N <= 5 * 10^5`
- `0 <= P <= N`

## 입력

`N P`가 주어집니다.

## 출력

답을 출력하세요.
