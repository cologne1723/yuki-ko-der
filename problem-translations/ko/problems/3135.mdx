## 문제 설명

문자 `A`, `B`, `C`만으로 이루어지며, 각 문자를 적어도 $1$번씩 사용하는 길이 $N$의 문자열을 생각합니다.

가능한 모든 문자열을 사전순으로 정렬했을 때, 작은 것부터 $S$번째인 문자열을 출력하세요.

그러한 문자열이 없다면 $-1$을 출력하세요.

## 입력

```text
$N$
$S$
```

$1$번째 줄에 문자열의 길이 $N$이, $2$번째 줄에 찾을 문자열의 사전순 순위를 나타내는 정수 $S$가 주어집니다.

## 제한

- $3\le N\le 12$
- $1\le S\le 1\,000\,000$
- 입력은 모두 정수입니다.

## 출력

정답을 표준 출력에 $1$줄로 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
1
```

#### 출력

```text
AAABC
```

### 예제 2 {file=""}

#### 입력

```text
3
6
```

#### 출력

```text
CBA
```

### 예제 3 {file=""}

#### 입력

```text
5
151
```

#### 출력

```text
-1
```
