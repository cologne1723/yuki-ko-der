0부터 9까지의 숫자로 이루어진 길이 12의 문자열 $S$가 주어진다냥. 뒤 12자리가 $S$와 같은 13자리 이상의 제곱수가 존재하는지 판정하라냥.

## 조건

- $S$는 숫자로 이루어진 길이 12의 문자열이다냥.

## 입력

```text
S
```

## 출력

그러한 제곱수가 존재하면 `YES`, 존재하지 않으면 `NO`를 출력하라냥.

## 예제

### 예제 1 {file=""}

#### 입력

```text
000000000000
```

#### 출력

```text
YES
```

### 예제 2 {file=""}

#### 입력

```text
000000000001
```

#### 출력

```text
YES
```

### 예제 3 {file=""}

#### 입력

```text
000000000002
```

#### 출력

```text
NO
```

### 예제 4 {file=""}

#### 입력

```text
290312864656
```

#### 출력

```text
YES
```

### 예제 5 {file=""}

#### 입력

```text
267589775753
```

#### 출력

```text
NO
```
