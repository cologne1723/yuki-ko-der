## 문제 설명

정점 $N$개와 간선 $N - 1$개로 이루어진 트리가 있습니다. $i$번째 간선은 정점 $A_i$와 정점 $B_i$를 거리 $1$로 양방향 연결합니다.

처음에는 모든 정점의 가중치가 $0$입니다.

$Q$개의 쿼리가 시간 순서대로 주어지므로 모두 처리하세요. $i$번째 쿼리는 다음을 의미합니다.

- 정점 $X_i$의 현재 가중치를 출력하고, 정점 $X_i$에서의 최단 거리가 $Y_i$ 이하인 모든 정점(정점 $X_i$를 포함)의 가중치에 $Z_i$를 더합니다.

## 입력

```text
$N$ $Q$
$A_1$ $B_1$
$A_2$ $B_2$
$\vdots$
$A_{N-1}$ $B_{N-1}$
$X_1$ $Y_1$ $Z_1$
$X_2$ $Y_2$ $Z_2$
$\vdots$
$X_Q$ $Y_Q$ $Z_Q$
```

## 제한

- $2 \leq N \leq 100\,000$
- $1 \leq Q \leq 100\,000$
- $1 \leq A_i, B_i \leq N$
- $1 \leq X_i \leq N$
- $0 \leq Y_i \leq N - 1$
- $1 \leq Z_i \leq 1\,000\,000\,000$
- 입력은 모두 정수입니다.
- 주어지는 그래프는 트리입니다.

## 출력

$Q$개의 줄에 걸쳐 출력합니다. $i$번째 줄에는 $i$번째 쿼리 시점에서 정점 $X_i$의 가중치를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 5
1 2
1 3
2 4
2 5
1 2 1
2 1 10
1 0 100
4 4 1000
5 1 10000
```

#### 출력

```text
0
1
11
11
1011
```

- 처음에 정점 $1, 2, 3, 4, 5$의 가중치는 각각 $\{0, 0, 0, 0, 0\}$입니다.
- $1$번째 쿼리에서는 정점 $1$에서의 최단 거리가 $2$ 이하인 정점 $1, 2, 3, 4, 5$의 가중치에 $1$을 더합니다. 결과는 $\{\mathbf{1}, \mathbf{1}, \mathbf{1}, \mathbf{1}, \mathbf{1}\}$입니다.
- $2$번째 쿼리에서는 정점 $2$에서의 최단 거리가 $1$ 이하인 정점 $1, 2, 4, 5$의 가중치에 $10$을 더합니다. 결과는 $\{\mathbf{11}, \mathbf{11}, 1, \mathbf{11}, \mathbf{11}\}$입니다.
- $3$번째 쿼리에서는 정점 $1$에서의 최단 거리가 $0$ 이하인 정점 $1$의 가중치에 $100$을 더합니다. 결과는 $\{\mathbf{111}, 11, 1, 11, 11\}$입니다.
- $4$번째 쿼리에서는 정점 $4$에서의 최단 거리가 $4$ 이하인 정점 $1, 2, 3, 4, 5$의 가중치에 $1000$을 더합니다. 결과는 $\{\mathbf{1111}, \mathbf{1011}, \mathbf{1001}, \mathbf{1011}, \mathbf{1011}\}$입니다.
- $5$번째 쿼리에서는 정점 $5$에서의 최단 거리가 $1$ 이하인 정점 $2, 5$의 가중치에 $10000$을 더합니다. 결과는 $\{1111, \mathbf{11011}, 1001, 1011, \mathbf{11011}\}$입니다.
