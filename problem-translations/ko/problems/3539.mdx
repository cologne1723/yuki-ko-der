## 문제 설명

문자열 $X$에 부분 문자열로 포함된 `()`를 반복해서 삭제하여 $X$를 빈 문자열로 만들 수 있을 때, 그리고 그럴 때에만 $X$를 **올바른 괄호열**이라고 합니다.

양의 정수 $N$과 `.`, `(`, `)`로 이루어진 길이 $N$의 문자열 $T_1,T_2,\cdots,T_N$이 주어집니다.

각 $T_1,T_2,\cdots,T_N$에 포함된 `.`를 모두 `(` 또는 `)`로 치환하여 서로 다른 $N$개의 **올바른 괄호열**을 만들 수 있는지 판정하세요. 가능하다면 조건을 만족하는 $N$개 문자열의 조합 $1$개를 구성하세요.

정확히는 다음 조건을 모두 만족하는 길이 $N$의 문자열 $N$개 $S_1,S_2,\cdots,S_N$이 존재하는지 판정하세요. 존재한다면 조건을 만족하는 $N$개 문자열의 조합 $1$개를 구성하세요.

- 각 $i$ ($1\leq i\leq N$)에 대해 $S_i$는 **올바른 괄호열**입니다.
- $T_{i,j}$ ($1\leq i,j\leq N$)가 `.`가 아니라면 $S_{i,j}=T_{i,j}$입니다.
- $1\leq i,j\leq N$에 대해 $i\ne j$라면 $S_i\ne S_j$입니다.

문자열 $X$에 대해 $X_i$는 $X$의 $i$번째 문자입니다.

## 입력

```text
$N$
$T_1$
$T_2$
$\vdots$
$T_N$
```

입력은 다음 형식으로 주어집니다.

- $1$번째 줄에 정수 $N$이 주어집니다.
- 다음 $N$개 줄에 문자열 $T_1,T_2,\cdots,T_N$이 주어집니다.

## 제한

- $1\leq N\leq 200$
- $T_i$는 `.`, `(`, `)`로 이루어진 길이 $N$의 문자열입니다.
- $N$은 정수입니다.

## 출력

조건을 만족하는 $S_1,S_2,\cdots,S_N$의 조합이 존재한다면 다음 형식으로 $N$줄에 걸쳐 출력하세요.

```text
$S_1$
$S_2$
$\vdots$
$S_N$
```

존재하지 않는다면 $-1$을 출력하세요.

```text
$-1$
```

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
8
(.......
.......)
.(......
....)...
......()
........
()......
.(....).
```

#### 출력

```text
((()()))
((())())
(()(()))
(()()())
((()))()
(()())()
()((()))
(((())))
```

해는 여러 개 존재할 수 있지만, 여기서는 조건을 만족하는 $N$개 문자열의 조합 $1$개를 보여 줍니다.

### 예제 2 {file=""}

#### 입력

```text
2
..
..
```

#### 출력

```text
-1
```

조건을 만족하는 $S_1,S_2$는 존재하지 않습니다. 따라서 $-1$만 출력합니다.

### 예제 3 {file=""}

#### 입력

```text
4
))))
((((
....
....
```

#### 출력

```text
-1
```
