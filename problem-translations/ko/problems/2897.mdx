이 문제의 실행 시간 제한은 $3\,500$ms입니다.

2024-09-21에 이 장의 제목을 「문제 설명」에서 「주의」로 수정했습니다. 문제의 내용 자체에는 변경이 없습니다.

## 문제 설명

양의 정수 $N$과 $xy$ 평면 위의 서로 다른 $N$개의 점으로 이루어진 집합 $S$, 양의 정수 $M$과 $xy$ 평면 위의 서로 다른 $M$개의 점으로 이루어진 집합 $T$가 주어집니다.

$S$의 원소 $s=(x,y)$와 $T$의 원소 $t=(z,w)$ 사이의 거리 $d(s,t)$를 $\ell^1$ 거리(맨해튼 거리)인 다음 값으로 정의합니다.

$|x-z|+|y-w|$

또한 $S$와 $T$ 사이의 거리 $D(S,T)$를 $s$와 $t$가 각각 $S$와 $T$의 모든 원소를 순회할 때의 $d(s,t)$의 최솟값, 즉 다음 값으로 정의합니다.

$\min_{(s,t)\in S\times T}d(s,t)$

$D(S,T)$를 구하세요.

## 입력

$S$의 원소에 $N$ 이하의 각 양의 정수 $n$으로 번호를 매기고 $s_n=(x_n,y_n)$이라 하며, $T$의 원소에 $M$ 이하의 각 양의 정수 $m$으로 번호를 매기고 $t_m=(z_m,w_m)$이라 합니다.

입력은 다음 형식으로 표준 입력에서 $2+N+M$개의 줄로 주어집니다.

```text
$N$
$x_1\ y_1$
$\vdots$
$x_N\ y_N$
$M$
$z_1\ w_1$
$\vdots$
$z_M\ w_M$
```

- 첫 번째 줄에 $N$이 주어집니다.
- $N$ 이하의 각 양의 정수 $n$에 대해 $1+n$번째 줄에 $x_n$, $y_n$이 공백으로 구분되어 주어집니다.
- $2+N$번째 줄에 $M$이 주어집니다.
- $M$ 이하의 각 양의 정수 $m$에 대해 $2+N+m$번째 줄에 $z_m$, $w_m$이 공백으로 구분되어 주어집니다.

## 제한

입력은 다음 조건을 만족합니다.

- $N$은 $1\leq N\leq 2\times 10^5$인 정수입니다.
- $N$ 이하의 임의의 양의 정수 $n$에 대해 다음 조건을 만족합니다.
  - $x_n$은 $0\leq x_n<10^3$인 정수입니다.
  - $y_n$은 $0\leq y_n<10^3$인 정수입니다.
- $N$ 이하의 임의의 양의 정수 $n_0$, $n_1$에 대해 $n_0\neq n_1$이면 $s_{n_0}\neq s_{n_1}$입니다.
- $M$은 $1\leq M<2\times 10^5$인 정수입니다.
- $M$ 이하의 임의의 양의 정수 $m$에 대해 다음 조건을 만족합니다.
  - $z_m$은 $0\leq z_m<10^3$인 정수입니다.
  - $w_m$은 $0\leq w_m<10^3$인 정수입니다.
- $M$ 이하의 임의의 양의 정수 $m_0$, $m_1$에 대해 $m_0\neq m_1$이면 $t_{m_0}\neq t_{m_1}$입니다.

## 출력

$D(S,T)$를 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
0 0
1
1 1
```

#### 출력

```text
2
```

$S=\{(0,0)\}$이고 $T=\{(1,1)\}$입니다. 두 집합의 원소가 각각 $1$개뿐이므로 $S$와 $T$ 사이의 거리 $D(S,T)$는 유일한 두 원소 사이의 거리와 같습니다.

$d((0,0),(1,1))=|0-1|+|0-1|=2$

### 예제 2 {file=""}

#### 입력

```text
2
0 1
1 0
2
1 0
1 1
```

이처럼 $S$와 $T$가 공통된 점을 가질 수도 있습니다.

#### 출력

```text
0
```

$S=\{(0,1),(1,0)\}$이고 $T=\{(1,0),(1,1)\}$입니다. 두 집합의 원소는 각각 $2$개입니다.

다음 네 거리 중 최솟값을 구합니다.

- $d((0,1),(1,0))=|0-1|+|1-0|=2$
- $d((0,1),(1,1))=|0-1|+|1-1|=1$
- $d((1,0),(1,0))=|1-1|+|0-0|=0$
- $d((1,0),(1,1))=|1-1|+|0-1|=1$

따라서 $S$와 $T$ 사이의 거리 $D(S,T)$는 이 값들의 최솟값인 $0$입니다.

### 예제 3 {file=""}

#### 입력

```text
3
0 0
1 0
2 0
2
0 1
1 1
```

#### 출력

```text
1
```

$S=\{(0,0),(1,0),(2,0)\}$이고 $T=\{(0,1),(1,1)\}$입니다.

다음 여섯 거리 중 최솟값을 구합니다.

- $d((0,0),(0,1))=|0-0|+|0-1|=1$
- $d((0,0),(1,1))=|0-1|+|0-1|=2$
- $d((1,0),(0,1))=|1-0|+|0-1|=2$
- $d((1,0),(1,1))=|1-1|+|0-1|=1$
- $d((2,0),(0,1))=|2-0|+|0-1|=3$
- $d((2,0),(1,1))=|2-1|+|0-1|=2$

따라서 $S$와 $T$ 사이의 거리 $D(S,T)$는 이 값들의 최솟값인 $1$입니다.
