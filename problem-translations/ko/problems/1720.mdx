오름차순으로 정렬했을 때 인접한 원소의 차가 모두 1인 수열을 아름다운 수열이라고 합니다. 순열 `P`를 아름다운 연속 부분 수열 `B_1,...,B_X`로 분할하는 방법의 수를 각 `X=1,...,K`에 대해 구하세요.

## 제약

- `1 <= N <= 2 * 10^5`

## 입력

순열 `P`와 정수 `K`가 주어집니다.

## 출력

각 `X`에 대한 분할 수를 `998244353`으로 나눈 나머지로 출력하세요.
