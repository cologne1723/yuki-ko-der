$1$ 이상 $2^N$ 미만이며 popcount가 $M$ 이하인 모든 정수의 합을 $998244353$으로 나눈 나머지를 구하라냥. popcount는 이진 표현에서 1의 개수이다냥.

## 조건

- $1\le T\le2\times10^5$
- $1\le M\le N\le2\times10^5$

## 입력

```text
T
N_1 M_1
\vdots
N_T M_T
```

## 출력

각 테스트 케이스의 답을 한 줄에 하나씩 출력하라냥.
