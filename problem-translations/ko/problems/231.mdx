## 문제

메구루는 현재 정확히 레벨 98이 되었고 경험치는 0입니다. 내일 길드전 전까지 최고 레벨에 도달해 위엄을 지키고 싶지만, 사망 패널티가 심해서 어떤 사냥터가 좋을지 고민하고 있습니다.

던전이 $N$개 있고, 던전 $i$에서는 1시간에 약 $G_i$의 경험치를 얻습니다. 하지만 사망할 때마다 레벨 98에서 레벨 99가 되는 데 필요한 경험치의 1%, 즉 경험치 30000을 잃습니다. 던전 $i$에서는 1시간에 약 $D_i$번 사망합니다. 따라서 던전 $i$에서 1시간 사냥하면 약 $G_i-30000D_i$의 경험치를 얻습니다.

1시간 지속되는 아이템을 사용하므로 1시간 동안은 같은 던전에서 사냥해야 합니다. 오늘 밤부터 내일 아침까지 약 6시간 플레이할 예정이라 1시간 사냥을 6번 하려고 합니다. 내일 아침까지 레벨업할 수 있도록 방문할 던전을 정하세요.

필요 경험치는 정확히 채워도 되고 초과해도 됩니다. 30000이 1%라는 점을 이용하세요. 같은 던전을 여러 번 방문해도 됩니다. 아래 출력 설명의 기분 전환은 하지 않아도 됩니다. 6번보다 일찍 레벨업하더라도 던전은 6번 방문해야 합니다.

## 입력

```text
N
G_1 D_1
G_2 D_2
⋮
G_N D_N
```

- $1 \leq N \leq 1000$
- $1 \leq G_i \leq 1000000=10^6$
- $0 \leq D_i \leq 100$
- $G_i-30000D_i \geq 0$

## 출력

6시간 사냥으로 레벨 99가 될 수 있으면 첫째 줄에 `YES`를 출력하고, 다음 6개 줄에 각 시간에 사냥할 던전 번호를 출력하세요. 예상 경험치를 정확히 얻는다고 할 때 6시간 후 레벨 99가 되는 조합이어야 합니다. 같은 던전을 여러 번 방문해도 됩니다.

불가능하면 `NO`만 한 줄에 출력하세요.

이 문제는 스페셜 저지이므로 형식이 잘못되면 오답입니다. 샘플도 저지 테스트에 포함되어 있으므로 형식을 확인하세요.

## 샘플

### 입력 1 {file="stdin"}

```text
3
1000000 0
1000000 0
1000000 0
```

### 출력 1 {file="stdout"}

```text
YES
1
2
3
1
2
3
```

최근 추가된 3속성 던전입니다. 모두 효율이 좋고 잘 죽지 않습니다.

### 입력 2 {file="stdin"}

```text
2
30000 1
300000 10
```

### 출력 2 {file="stdout"}

```text
NO
```

임시 파티를 모집해 한 번에 역전하는 수밖에 없을 것 같습니다.
