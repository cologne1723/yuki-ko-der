## 이야기

안녕하세요, 선배!
고민하는 표정이라고요? 선배치고는 묘하게 날카로우시네요….

めぐる는 현재 정확히 레벨 $98$이 되었고 경험치는 $0$입니다. 내일 길드전 전까지 최고 레벨에 도달해 위엄을 지키고 싶지만, 사망 패널티가 심해서 어떤 사냥터가 좋을지 고민하고 있습니다.

예를 들어 이 사냥터는 경험치 효율이 약 $200$k/h인데, $1$시간에 약 $3$번 죽습니다. 무슨 말인지 모르시겠다고요? 선배도 이해할 수 있게 설명하겠습니다!

## 문제 설명

던전이 $N$개 있고, 던전 $i$에서는 $1$시간에 약 $G_i$의 경험치를 얻습니다. 하지만 사망할 때마다 레벨 $98$에서 레벨 $99$가 되는 데 필요한 경험치의 $1$%, 즉 경험치 $30\,000$을 잃습니다. 던전 $i$에서는 $1$시간에 약 $D_i$번 사망합니다. 따라서 던전 $i$에서 $1$시간 사냥하면 약 $G_i-30\,000D_i$의 경험치를 얻습니다.

$1$시간 지속되는 아이템을 사용하므로 $1$시간 동안은 같은 던전에서 사냥해야 합니다. 오늘 밤부터 내일 아침까지 약 $6$시간 플레이할 예정이라 $1$시간 사냥을 $6$번 하려고 합니다. 내일 아침까지 레벨업할 수 있도록 방문할 던전을 정하세요.

필요 경험치는 정확히 채워도 되고 초과해도 됩니다. $30\,000$이 $1$%라는 점을 이용하세요. 같은 던전을 여러 번 방문해도 됩니다. 아래 출력 설명의 기분 전환은 하지 않아도 됩니다. $6$번보다 일찍 레벨업하더라도 던전은 $6$번 방문해야 합니다.

## 입력

```text
$N$
$G_1\ D_1$
$G_2\ D_2$
$\vdots$
$G_N\ D_N$
```

## 제한

- $1 \leq N \leq 1\,000$
- $1 \leq G_i \leq 1\,000\,000=10^6$
- $0 \leq D_i \leq 100$
- $G_i-30\,000D_i \geq 0$

## 출력

$6$시간 사냥으로 레벨 $99$가 될 수 있으면 $1$번째 줄에 `YES`를 출력하고, 다음 $6$개 줄에 각 시간에 사냥할 던전 번호를 출력하세요. 이 $6$개 줄 중 $i$번째 줄에는 $i$시간째에 방문할 던전 번호를 출력하세요. 예상 경험치를 정확히 얻는다고 할 때 $6$시간 후 레벨 $99$가 되는 조합이어야 합니다. 같은 던전을 여러 번 방문해도 됩니다. 가능하면 여러 던전에 가는 편이 めぐる에게는 기분 전환이 되어 좋습니다….

저기요, 듣고 계세요, 선배!?

불가능하면 `NO`만 $1$줄에 출력하세요.

이 문제는 스페셜 저지이므로 형식이 잘못되면 오답(`WA`)입니다. 샘플도 저지 테스트에 포함되어 있으므로 형식을 확인하세요.
