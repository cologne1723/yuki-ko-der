공이 매초 한 행 아래로 떨어지는 $H\times W$ 격자에서 좌우 버튼으로 공을 움직여 장애물을 피합니다. 각 초 동안 누른 버튼 수의 최댓값을 최소화할 때, 각 시작 열에 대한 최솟값을 구하세요.

## 조건

- $3\le H\le10^5$, $1\le W\le10^5$, $HW\le5\times10^5$
- 첫 행과 마지막 행에는 장애물이 없습니다.

## 입력

```text
$H$ $W$
$S_1$
\vdots
$S_H$
```

## 출력

시작 열별 최솟값을 한 줄에 하나씩 출력하세요.
