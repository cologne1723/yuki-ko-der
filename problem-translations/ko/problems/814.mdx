## 문제

돌고래는 카드에 적힌 수를 알 수 있으므로 게임 전에 지지 카드의 숫자를 찾으려 합니다. $N$명이 지지누키를 시작하며, 짝이 되는 카드는 이미 버려졌습니다.

플레이어 $i$는 $K_i$장의 카드를 가지고 있고, 카드 숫자는

$\{L_i,L_i+2^{D_i},L_i+2\times2^{D_i},\ldots,L_i+(K_i-1)\times2^{D_i}\}$

입니다. 어떤 정수 $x$가 존재하여, $x$가 적힌 카드를 가진 플레이어 수는 홀수이고 $x$ 이외의 모든 정수 $y$에 대해서는 그런 플레이어 수가 짝수입니다. $x$를 구하세요.

카드 숫자는 0 이상 $10^{18}$ 이하이고, 각 종류의 카드는 $10^{100}$장씩 있다고 생각할 수 있습니다. $x$인 카드 한 장을 제거한 뒤 나머지를 나누고, 각 플레이어가 같은 수의 카드를 받을 필요는 없습니다. 각자는 같은 숫자의 카드 쌍을 더 이상 버릴 수 없을 때까지 버립니다.

## 입력

~~~text
$N$
$K_1\ L_1\ D_1$
$\vdots$
$K_N\ L_N\ D_N$
~~~

$1\leq N\leq3\times10^5$, $K_i\geq1$, $0\leq D_i\leq59$입니다. $0\leq L_i\leq L_i+(K_i-1)2^{D_i}\leq10^{18}$이며 입력은 모두 정수입니다. 조건을 만족하는 $x$는 유일합니다.

## 출력

$x$를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
1
1 1 50
~~~

#### 출력

~~~text
1
~~~

플레이어가 한 명뿐인 경우도 있습니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
2
5 1 0
6 0 0
~~~

#### 출력

~~~text
0
~~~

첫 번째 손은 {1,2,3,4,5}, 두 번째 손은 {0,1,2,3,4,5}입니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
3
6 1 0
3 1 1
2 2 2
~~~

#### 출력

~~~text
4
~~~
