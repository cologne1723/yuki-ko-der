## 문제

$N$개 정점 $M$개 간선의 단순 그래프가 주어집니다. 차수가 같은 서로 다른 정점의 쌍이 존재하는지 판정하세요.

## 입력

첫째 줄에 테스트 케이스 수 $T$가 주어집니다. 각 테스트 케이스에 그래프가 주어집니다.

- $1\leq T\leq10^4$
- $1\leq N\leq10^5$
- $0\leq M\leq2\times10^5$

## 출력

각 테스트 케이스에 대해 존재하면 `Yes`, 아니면 `No`를 출력하세요.
