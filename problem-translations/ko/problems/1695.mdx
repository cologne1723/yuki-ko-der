문자열 `S`에 다음 연산을 원하는 순서와 횟수로 수행할 수 있습니다.

## 연산

- `i`를 골라 `S`를 `S[1:i] + rev(S[1:i])`로 바꿉니다.
- `i`를 골라 `S`를 `rev(S[i:|S|]) + S[i:|S|]`로 바꿉니다.

유한 번의 연산으로 `S`를 문자열 `T`와 같게 만들 수 있는지 판정하고, 가능하면 최소 연산 횟수를 구하세요.

## 제약

- `1 <= N <= 5 * 10^5`
- `2 <= M <= 5 * 10^5`
- `S,T`는 소문자 영어 문자열입니다.

## 입력

`N M`, 문자열 `S`, 문자열 `T`가 주어집니다.

## 출력

가능하면 최소 연산 횟수를, 불가능하면 `-1`을 출력하세요.
