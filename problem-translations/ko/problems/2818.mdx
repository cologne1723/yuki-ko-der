highlighter「한가하네... 너무 한가해... 맞다! 그 게임을 하자!」

## 문제 설명

각 테스트 케이스에 대해 다음 문제를 해결하세요.

모든 원소가 $0$으로 초기화된 길이 $S$인 정수 수열 $C$가 있습니다. 또한 변수 $X$가 있으며, 처음에 $X$의 값은 $0$입니다.

이제 highlighter君은 다음 연산을 원하는 횟수만큼 수행합니다.

- $1\leq i\leq S$를 만족하는 양의 정수 $i$를 $1$개 선택하고, $C_i$에 $1$을 더합니다.
- $X$에 $\displaystyle\prod_{j\neq i}C_j$를 더합니다.

연산을 끝냈을 때 $X=N$이 되는 경우에 가능한 모든 연산 후의 (21:25 추가) $C$에 대해 $\displaystyle\sum_{i=1}^{S}C_i$를 구하고, 그 총합을 출력하세요. 답은 매우 커질 수 있으므로 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $\mathrm{case}_i$는 $i$번째 테스트 케이스를 나타냅니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ S$
```

## 제한

- $1\leq T\leq 2\times 10^5$
- 각 테스트 케이스에 대해 다음 조건을 만족합니다.
  - $N$의 모든 소인수는 $100$ 이하입니다.
  - $1\leq N\leq 10^{18}$
  - $2\leq S\leq 10^{18}$
- 입력은 모두 정수입니다.

## 출력

$T$줄 출력하세요. $i$번째 줄에는 $\mathrm{case}_i$에 대한 답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
3 3
1 2
1 998244353
```

#### 출력

```text
15
2
0
```

테스트 케이스 $1$에서는 $i=1,i=3,i=3,i=2,i=3$의 순서로 연산을 $5$번 수행하면 최종적으로 $X=3$이 됩니다.

테스트 케이스 $3$에서는 $998\,244\,353$으로 나눈 나머지를 출력해야 한다는 점에 주의하세요.
