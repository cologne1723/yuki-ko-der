## 문제

$H\times W$ 격자에 $N$명의 참가자를 배치합니다. 한 칸에 여러 명을 배치해도 됩니다. 모든 참가자 쌍의 맨해튼 거리 합이 최대가 되도록 배치했을 때 그 최댓값을 구하세요.

## 입력

격자 크기와 참가자 수가 주어집니다.

## 출력

가능한 거리 합의 최댓값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2 2
```

#### 출력

```text
4
```

### 예제 2 {file=""}

#### 입력

```text
100 1 1
```

#### 출력

```text
0
```

### 예제 3 {file=""}

#### 입력

```text
100000000 100 100
```

#### 출력

```text
495000000000000000
```
