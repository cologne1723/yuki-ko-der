## 문제 설명

길이가 $N$인 음이 아닌 정수열 $X$가 있습니다. 처음에 $X$의 모든 원소는 $0$입니다.

이때 $X$에 다음 연산을 수행할 수 있습니다.

- 정수 $l,r$ ($1 \leq l \leq r \leq N$)을 고릅니다. $X_l,X_{l+1},\dots,X_r$에 $0$이 하나라도 포함되어 있으면 $X_l,X_{l+1},\dots,X_r$를 각각 $1$ 증가시킵니다. 그렇지 않으면 $X_l,X_{l+1},\dots,X_r$를 각각 $1$ 감소시킵니다.

길이가 $N$인 음이 아닌 정수열 $A$가 주어집니다. $X$에 연산을 $0$번 이상 수행하여 $X$와 $A$를 같게 만들 수 있는지 판정하세요.

## 입력

```text
$N$
$A_1\ A_2\ \dots\ A_N$
```

입력은 다음 제한을 만족합니다.

## 제한

- $1 \leq N \leq 2 \times 10^5$
- $0 \leq A_i \leq 10^9$ ($1 \leq i \leq N$)
- 입력은 모두 정수입니다.

## 출력

$X$와 $A$를 같게 만들 수 있다면 `Yes`, 그렇지 않다면 `No`를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
0 1 2 1
```

#### 출력

```text
Yes
```

처음에 $X=(0,0,0,0)$입니다. 다음 순서로 연산을 수행하면 $X=(0,1,2,1)$로 만들 수 있습니다.

- $(l,r)=(1,3)$으로 연산을 수행하면 $X=(1,1,1,0)$이 됩니다.
- $(l,r)=(2,4)$로 연산을 수행하면 $X=(1,2,2,1)$이 됩니다.
- $(l,r)=(1,2)$로 연산을 수행하면 $X=(0,1,2,1)$이 됩니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3
1000000000 1000000000 1000000000
```

#### 출력

```text
No
```

$X=(10^9,10^9,10^9)$로 만들 수 없습니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1
1
```

#### 출력

```text
Yes
```

$(l,r)=(1,1)$로 연산을 수행하면 됩니다.

```text
23

```
