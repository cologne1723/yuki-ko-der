## 이야기

“프로그래밍 콘테스트 챌린지 북”, 통칭 “개미책”이라는 유명한 책이 있습니다.

이 책은 제$1$판이 $316$쪽이고 제$2$판이 $368$쪽입니다.

## 문제 설명

이를 바탕으로 개미책의 페이지 수는 판이 $1$ 올라갈 때마다 $52(=368-316)$쪽씩 증가하는 등차수열이라는 예측을 세웠습니다.

이 예측에 따라 개미책 제 $N$판의 페이지 수를 계산하세요.

## 입력

```text
$N$
```

$N$은 다음 조건을 만족하는 정수입니다.

## 제한

- $1 \le N \le 10^{10}$

## 출력

예측되는 개미책 제 $N$판의 페이지 수를 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
316
```

제$1$판은 $316$쪽입니다.

### 예제 2 {file=""}

#### 입력

```text
2
```

#### 출력

```text
368
```

제$2$판은 $368$쪽입니다.

### 예제 3 {file=""}

#### 입력

```text
987654321
```

#### 출력

```text
51358024956
```

개미책 제$987\,654\,321$판은 $51\,358\,024\,956$쪽이며, 제$1$판의 약 $162\,525\,395$배의 페이지 수가 될 것으로 예측됩니다.
