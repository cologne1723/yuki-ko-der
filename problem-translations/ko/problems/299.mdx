## 문제

“프로그래밍 콘테스트 챌린지 북”, 통칭 “개미책”이라는 유명한 책이 있습니다.

이 책은 초판이 316쪽이고 2판이 368쪽입니다.

이를 바탕으로 개미책의 페이지 수는 판이 하나 올라갈 때마다 $52(=368-316)$쪽씩 증가하는 등차수열이라는 예측을 세웠습니다.

이 예측에 따라 개미책 제 $N$판의 페이지 수를 계산하세요.

## 입력

```text
N
```

$N$은 다음 조건을 만족하는 정수입니다.

- $1 \le N \le 10^{10}$

## 출력

예측되는 개미책 제 $N$판의 페이지 수를 한 줄에 출력하세요.

마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
1
```

### 샘플 1 {file="sample1.out"}

```text
316
```

초판은 316쪽입니다.

### 샘플 2 {file="sample2.in"}

```text
2
```

### 샘플 2 {file="sample2.out"}

```text
368
```

2판은 368쪽입니다.

### 샘플 3 {file="sample3.in"}

```text
987654321
```

### 샘플 3 {file="sample3.out"}

```text
51358024956
```

개미책 제 987654321판은 51358024956쪽이며, 초판의 162525395배의 페이지 수가 될 것으로 예측됩니다.
