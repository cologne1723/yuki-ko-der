양의 정수열 $A$가 주어집니다. $A$의 길이 $2$ 이상인 부분 수열 중 등차수열이고 공차가 $1$인 것의 개수를 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
N
A_1 A_2 ... A_N
```

$2\le N\le2\times10^5$, $1\le A_i\le10^9$입니다.

## 출력

답을 출력하세요.
