0과 1로 이루어진 길이 `N`의 배열 `A`에 대해, 인접한 두 원소의 XOR로 새 배열을 만드는 연산을 반복합니다. `N-1`번 후 남는 값이 1이 되도록 숨겨진 원소를 채우는 방법의 수를 `998244353`으로 나눈 나머지를 구하세요.

입력 배열 `B`에서 `0,1`은 고정값이고 `-1`은 숨겨진 값입니다.

## 제약

- `2 <= N <= 2 * 10^5`
- `B_i`는 `-1,0,1` 중 하나입니다.

## 입력

`N`과 배열 `B`가 주어집니다.

## 출력

조건을 만족하는 배열의 개수를 출력하세요.
