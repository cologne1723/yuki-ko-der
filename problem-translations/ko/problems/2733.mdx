## 문제

단순 무방향 그래프에서 각 정점을 정확히 `K`번 사용하는 워크의 수를 `998244353`으로 나눈 나머지를 구하세요.

<details>
<summary>워크란</summary>

그래프 $G$의 워크란 양의 정수 $k$에 대해 $k$개의 정점과 $k-1$개의 변을 번갈아 나열한 열 $(v_1,e_1,v_2,\ldots,v_{k-1},e_{k-1},v_k)$이며, 변 $e_i$는 정점 $v_i$와 $v_{i+1}$을 잇습니다.

</details>

## 제약

- `1 ≤ N ≤ 6`, `0 ≤ M ≤ N(N-1)/2`, `1 ≤ K ≤ 8`

## 입력

```text
N M K
u_1 v_1
⋮
u_M v_M
```

## 출력

조건을 만족하는 워크 수를 출력하세요.
