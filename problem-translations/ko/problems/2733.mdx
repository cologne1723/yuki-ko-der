## 문제

단순 무방향 그래프에서 각 정점을 정확히 `K`번 사용하는 워크의 수를 `998244353`으로 나눈 나머지를 구하세요. 워크는 정점과 변을 번갈아 나열한 수열이며, 연속한 두 정점을 잇는 변을 사용합니다.

## 제약

- `1 ≤ N ≤ 6`, `0 ≤ M ≤ N(N-1)/2`, `1 ≤ K ≤ 8`

## 입력

```text
N M K
u_1 v_1
⋮
u_M v_M
```

## 출력

조건을 만족하는 워크 수를 출력하세요.
