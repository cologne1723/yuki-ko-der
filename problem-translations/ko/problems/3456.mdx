## 문제 설명

길이 $N$인 정수열 $A=(A_1,A_2,\dots,A_N)$와 양의 정수 $D$가 주어집니다. $A$의 부분수열 중 길이가 $3$이고 공차가 $D$인 등차수열인 것의 개수를 구하세요.

더 엄밀하게는 다음 조건을 만족하는 인덱스 선택 $(i,j,k)$의 개수를 구하세요.

- $1\leq i<j<k\leq N$
- $A_i<A_j<A_k$
- $A_j-A_i=A_k-A_j=D$

## 입력

```text
$N\ D$
$A_1\ A_2\ \cdots\ A_N$
```

$1$번째 줄에 정수 $N$과 $D$가 공백으로 구분되어 주어집니다.

$2$번째 줄에 정수열 $A_1,A_2,\dots,A_N$이 공백으로 구분되어 주어집니다.

## 제한

- $3\leq N\leq 10^5$
- $1\leq D\leq 5\times 10^8$
- $0\leq A_i\leq 10^9$ $(1\leq i\leq N)$
- 입력은 모두 정수입니다.

## 출력

조건을 만족하는 인덱스 선택 $(i,j,k)$의 개수를 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
7 2
0 2 5 1 4 3 6
```

#### 출력

```text
2
```

조건을 만족하는 $A$의 부분수열은 $(A_i,A_j,A_k)=(0,2,4),(2,4,6)$의 $2$개입니다.

### 예제 2 {file=""}

#### 입력

```text
6 1
1 1 2 2 3 3
```

#### 출력

```text
8
```

$(A_i,A_j,A_k)$가 수열로서 같더라도 $(i,j,k)$를 선택하는 방법이 다르면 구별하여 세는 것에 주의하세요.
