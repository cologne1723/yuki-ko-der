딸기가 들어 있는 $H\times W$ 격자에서 각 딸기에 행 방향 누적 개수와 열 방향 누적 개수의 쌍 $(A_{x,y},B_{x,y})$를 라벨로 붙입니다. 빈 칸에 딸기를 추가해 모든 딸기의 라벨이 서로 달라지도록 하는 데 필요한 최소 추가 개수를 구하세요.

## 조건

- $1\le H,W\le300$
- 각 칸은 0 또는 1입니다.

## 입력

```text
H W
S1
...
SH
```

## 출력

필요한 최소 추가 개수를 출력하세요.
