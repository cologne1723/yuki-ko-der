## 문제 설명

세로 $H$칸, 가로 $W$칸의 격자판이 있습니다. 위에서 $i$($1 \leq i \leq H$)번째이고 왼쪽에서 $j$($1 \leq j \leq W$)번째인 칸을 칸 $(i,j)$로 나타냅니다.

처음에 칸 $(sx,sy)$에 퀸 말이 있습니다. 퀸 말은 격자판 범위 안의 칸에는 자유롭게 드나들 수 있지만, 범위 밖의 칸에는 드나들 수 없습니다.

이제 현재 퀸 말이 있는 칸에서 이동할 수 있는 칸을 $1$개 선택하여 그 칸으로 이동하는 것을 $K$번 반복합니다. 단, 이동할 때는 다음 조건을 만족해야 합니다.

- $C_k(i,j)$를 $1$번째 이동부터 $k$번째 이동까지 칸 $(i,j)$를 이동할 칸으로 선택한 횟수라고 합니다. 퀸 말이 처음 놓여 있던 상태는 방문 횟수에 세지 않으며, 이후 이동으로 그 칸을 목적지로 선택한 경우는 셉니다. 이때 $k=1,2,\dots,K$에 대하여 $\displaystyle \max_{1 \leq i \leq H,\ 1 \leq j \leq W}C_k(i,j)-\displaystyle \min_{1 \leq i \leq H,\ 1 \leq j \leq W}C_k(i,j) \leq 1$이 성립해야 합니다.

이 조건을 만족하는 이동 방법 중 $K$번 이동한 후 퀸 말이 칸 $(gx,gy)$에 있는 것의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

어떤 $k$가 존재하여 $k$번째 이동에서 이동할 칸으로 선택한 칸이 $2$개의 이동 방법에서 서로 다르면, $2$개의 이동 방법을 서로 다른 것으로 셉니다.

### 퀸 말의 이동 방법

퀸 말은 $1$번의 이동에서 세로, 가로, 대각선 방향으로 지나가는 경로의 모든 칸에 드나들 수 있는 동안 원하는 칸 수만큼 이동할 수 있습니다. 단, 현재 있는 칸에 머무르는 것은 $1$번의 이동으로 셀 수 없습니다. 정확히 말하면, 칸 $(i,j)$에 있는 퀸 말은 다음과 같이 이동할 수 있습니다.

- 양의 정수 $k$에 대하여, 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i,j+l)$이 퀸 말이 드나들 수 있는 칸일 때, 그리고 그때에만 칸 $(i,j+k)$로 이동할 수 있습니다.
- 양의 정수 $k$에 대하여, 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i,j-l)$이 퀸 말이 드나들 수 있는 칸일 때, 그리고 그때에만 칸 $(i,j-k)$로 이동할 수 있습니다.
- 양의 정수 $k$에 대하여, 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i+l,j)$가 퀸 말이 드나들 수 있는 칸일 때, 그리고 그때에만 칸 $(i+k,j)$로 이동할 수 있습니다.
- 양의 정수 $k$에 대하여, 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i-l,j)$가 퀸 말이 드나들 수 있는 칸일 때, 그리고 그때에만 칸 $(i-k,j)$로 이동할 수 있습니다.
- 양의 정수 $k$에 대하여, 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i+l,j+l)$이 퀸 말이 드나들 수 있는 칸일 때, 그리고 그때에만 칸 $(i+k,j+k)$로 이동할 수 있습니다.
- 양의 정수 $k$에 대하여, 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i+l,j-l)$이 퀸 말이 드나들 수 있는 칸일 때, 그리고 그때에만 칸 $(i+k,j-k)$로 이동할 수 있습니다.
- 양의 정수 $k$에 대하여, 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i-l,j+l)$이 퀸 말이 드나들 수 있는 칸일 때, 그리고 그때에만 칸 $(i-k,j+k)$로 이동할 수 있습니다.
- 양의 정수 $k$에 대하여, 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i-l,j-l)$이 퀸 말이 드나들 수 있는 칸일 때, 그리고 그때에만 칸 $(i-k,j-k)$로 이동할 수 있습니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$H\ W\ sx\ sy\ gx\ gy\ K$
```

## 제한

- 입력은 모두 정수입니다.
- $2 \leq H \leq 4$
- $2 \leq W \leq 4$
- $1 \leq sx,gx \leq H$
- $1 \leq sy,gy \leq W$
- $1 \leq K \leq 10^{18}$

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2 2 1 1 1 2 2
```

#### 출력

```text
2
```

칸 $(1,1)$에서 $2$번의 이동으로 칸 $(1,2)$에 도착하는 방법은 다음 $2$가지입니다.

- $(1,1) \rightarrow (2,1) \rightarrow (1,2)$
- $(1,1) \rightarrow (2,2) \rightarrow (1,2)$

$2$개의 이동 방법 모두 $k=1,2$에서 $\displaystyle \max_{1 \leq i \leq H,\ 1 \leq j \leq W}C_k(i,j)-\displaystyle \min_{1 \leq i \leq H,\ 1 \leq j \leq W}C_k(i,j) \leq 1$을 만족하므로 조건을 만족합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 3 1 1 3 3 3
```

#### 출력

```text
23
```

예를 들어 다음 이동 방법은 조건을 만족합니다.

- $(1,1) \rightarrow (1,2) \rightarrow (2,2) \rightarrow (3,3)$

이와 같은 이동 방법은 위의 방법을 포함하여 $23$가지입니다.

다음 이동 방법은 $k=3$에서 $\displaystyle \max_{1 \leq i \leq H,\ 1 \leq j \leq W}C_k(i,j)-\displaystyle \min_{1 \leq i \leq H,\ 1 \leq j \leq W}C_k(i,j) \leq 1$을 만족하지 않으므로 $23$가지에 포함되지 않습니다.

- $(1,1) \rightarrow (3,3) \rightarrow (1,1) \rightarrow (3,3)$
