## 문제 설명

음이 아닌 정수 $N$과 소수 $P$가 주어집니다.

$\sum_{i=0}^{N} n^i$가 $P$로 나누어떨어지도록 하는 양의 정수 $n$이 존재하는지 판정하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 $1$줄에 주어집니다.

```text
$N\ P$
```

$1$번째 줄에 $N$과 $P$가 공백으로 구분되어 주어집니다.

## 제한

- $N$은 $0 \leq N \leq 10^{18}$을 만족하는 정수입니다.
- $P$는 $2 \leq P \leq 10^{18}$을 만족하는 소수입니다.

## 출력

$\sum_{i=0}^{N} n^i$가 $P$로 나누어떨어지도록 하는 양의 정수 $n$이 존재한다면 `Yes`를, 존재하지 않는다면 `No`를 출력하세요.

출력 끝에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0 2
```

#### 출력

```text
No
```

임의의 양의 정수 $n$에 대해

$\displaystyle \sum_{i=0}^{N} n^i = \sum_{i=0}^{0} n^i = n^0 = 1$

이므로 $P=2$로 나누어떨어지지 않습니다.

### 예제 2 {file=""}

#### 입력

```text
1 3
```

#### 출력

```text
Yes
```

$n=2$일 때

$\displaystyle \sum_{i=0}^{N} n^i = \sum_{i=0}^{1} 2^i = 2^0 + 2^1 = 3$

이므로 $P=3$으로 나누어떨어집니다.

### 예제 3 {file=""}

#### 입력

```text
2 7
```

#### 출력

```text
Yes
```

$n=2$일 때

$\displaystyle \sum_{i=0}^{N} n^i = \sum_{i=0}^{2} 2^i = 2^0 + 2^1 + 2^2 = 7$

이므로 $P=7$로 나누어떨어집니다.
