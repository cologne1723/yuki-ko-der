## 문제 설명

돌 $N$개가 쌓인 더미 하나가 있습니다. A와 B가 번갈아 돌을 나누는 게임을 합니다. 돌을 나눌 때는 2개의 더미 또는 3개의 더미로 나눕니다.

양의 정수 $x$에 대해 다음과 같이 나눕니다.

- $2x$개를 $x$개와 $x$개로 나눕니다.
- $2x+1$개를 $x$개와 $x+1$개로 나눕니다.
- $3x$개를 $x$개, $x$개, $x$개로 나눕니다.
- $3x+1$개를 $x$개, $x$개, $x+1$개로 나눕니다.
- $3x+2$개를 $x$개, $x+1$개, $x+1$개로 나눕니다.

위 조작 중 하나를 선택하여 진행합니다. 더 이상 돌을 나눌 수 없는 사람이 패배합니다. A가 선공이고 두 사람 모두 최선을 다할 때, 처음 돌의 수 $N$에 따라 승자가 A인지 B인지 판정하세요.

예를 들어 돌 5개로 시작하면 A가 먼저 2개, 2개, 1개로 나눌 수 있습니다. B가 2개 더미를 나누고, A가 남은 2개 더미를 나누면 돌 1개짜리 더미 5개가 되어 B가 더 이상 나눌 수 없습니다. 반대로 A가 3개와 2개로 나누어도 B와 A가 차례로 나눌 수 있지만 마지막에는 A가 나눌 차례에 돌 1개만 남습니다.

## 입력

```text
N
```

- $1 \le N \le 100$

## 출력

승자의 이름 `A` 또는 `B`를 한 줄에 출력하세요.

## 예제

### 예제 1

```text
2
```

```text
A
```

A가 먼저 돌 2개를 1개씩 나누면 B는 더 이상 나눌 수 없습니다.

### 예제 2

```text
1
```

```text
B
```

A는 처음부터 돌을 나눌 수 없습니다.

### 예제 3

```text
5
```

```text
A
```

문제 설명과 같은 경우입니다.

### 예제 4

```text
20
```

```text
A
```
