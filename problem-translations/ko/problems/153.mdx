## 문제 설명

돌 $N$개가 쌓인 더미 $1$개가 있습니다. A君과 B君이 번갈아 돌을 나누는 게임을 합니다. 돌을 나눌 때는 $2$개의 더미 또는 $3$개의 더미로 나눕니다.

양의 정수 $x$에 대해 다음과 같이 나눕니다.

- $2x$개를 $x$개와 $x$개로 나눕니다.
- $2x+1$개를 $x$개와 $x+1$개로 나눕니다.
- $3x$개를 $x$개, $x$개, $x$개로 나눕니다.
- $3x+1$개를 $x$개, $x$개, $x+1$개로 나눕니다.
- $3x+2$개를 $x$개, $x+1$개, $x+1$개로 나눕니다.

위 조작 중 $1$개를 선택하여 진행합니다. 더 이상 돌을 나눌 수 없는 사람이 패배합니다. A君이 선공이고 $2$명 모두 최선을 다할 때, 처음 돌의 수 $N$에 따라 승자가 A君인지 B君인지 판정하세요.

예를 들어 처음에 돌 $5$개가 쌓인 더미가 $1$개 있다고 합시다.

경우 $1$:

먼저 A君이 $2$개, $2$개, $1$개로 나눕니다. B君이 돌 $2$개인 더미를 나누면 $2$개, $1$개, $1$개, $1$개가 됩니다. A君도 돌 $2$개인 더미를 나누어 $1$개짜리 더미 $5$개로 만듭니다. B君은 돌 $1$개를 더 이상 나눌 수 없습니다.

경우 $2$:

먼저 A君이 $3$개와 $2$개로 나눕니다. B君이 돌 $3$개를 $2$개와 $1$개로 나누면 $2$개, $2$개, $1$개가 됩니다. A君이 돌 $2$개인 더미를 나누면 $2$개, $1$개, $1$개, $1$개가 됩니다. B君도 돌 $2$개인 더미를 나누어 $1$개짜리 더미 $5$개로 만듭니다. A君은 돌 $1$개를 더 이상 나눌 수 없습니다.

따라서 처음에 돌이 $5$개라면 경우 $1$처럼 선공인 A君이 먼저 $3$개의 더미로 나누면 반드시 이길 수 있습니다.

## 입력

```text
$N$
```

## 제한

- $1 \le N \le 100$

## 출력

승자의 이름 `A` 또는 `B`를 $1$줄에 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
```

#### 출력

```text
A
```

A君이 먼저 돌 $2$개를 $1$개씩 나누면 B君은 더 이상 나눌 수 없으므로 A君이 이깁니다.

### 예제 2 {file=""}

#### 입력

```text
1
```

#### 출력

```text
B
```

A君은 처음부터 돌을 나눌 수 없으므로 B君이 이깁니다.

### 예제 3 {file=""}

#### 입력

```text
5
```

#### 출력

```text
A
```

문제 설명과 같은 경우입니다.

### 예제 4 {file=""}

#### 입력

```text
20
```

#### 출력

```text
A
```
