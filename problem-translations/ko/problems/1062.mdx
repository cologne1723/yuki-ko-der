## 문제 설명

길이가 $N$인 순열 $(1, 2, \dots, N)$에 대해 다음과 같은 $2$가지 연산을 생각합니다.

연산 $i$ ($i = 1$, $2$):

1. $K = A_i$ ($1 \le A_i \le N - 1$)로 설정합니다.
2. 순열에서 $K$보다 큰 원소 중 가장 왼쪽에 있는 원소와 $K$ 이하인 원소 중 가장 오른쪽에 있는 원소를 선택합니다. 전자를 $U$, 후자를 $V$라고 합니다.
3. $U$가 $V$보다 왼쪽에 있다면 $U$와 $V$를 교환하고 $2$번으로 돌아갑니다. 그렇지 않다면 연산을 종료합니다.

순열의 「점수」를 다음과 같이 정의합니다. 순열에 연산 $1$을 수행한 뒤의 순열을 $P$, 연산 $2$를 수행한 뒤의 순열을 $Q$라고 할 때, $P_i = Q_i$인 $i$ ($1 \le i \le N$)의 개수가 점수입니다.

연산 $2$는 연산 $1$을 수행한 뒤의 순열이 아니라 원래 순열에 대해 수행한다는 점에 주의하세요. (5/22 22:18 추가)

여기서 $P_i$는 $P$의 $i$번째 원소를 나타냅니다.

길이가 $N$인 가능한 모든 순열의 점수를 합한 값은 얼마일까요?

답은 매우 커질 수 있으므로, $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
$N\ A_1\ A_2$
```

## 제한

$2 \le N \le 100\,000$

$1 \le A_1 \le N - 1$

$1 \le A_2 \le N - 1$

입력은 모두 정수입니다.

## 출력

길이가 $N$인 가능한 모든 순열의 점수를 합한 값을 $998244353$으로 나눈 나머지를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 1 2
```

#### 출력

```text
8
```

순열이 $(1, 2, 3)$일 때 연산 $1$을 수행하면 $(1, 2, 3)$이 되고, 연산 $2$를 수행하면 $(1, 2, 3)$이 되므로 점수는 $3$입니다.

순열이 $(1, 3, 2)$일 때 연산 $1$을 수행하면 $(1, 3, 2)$가 되고, 연산 $2$를 수행하면 $(1, 2, 3)$이 되므로 점수는 $1$입니다.

순열이 $(2, 1, 3)$일 때 연산 $1$을 수행하면 $(1, 2, 3)$이 되고, 연산 $2$를 수행하면 $(2, 1, 3)$이 되므로 점수는 $1$입니다.

순열이 $(2, 3, 1)$일 때 연산 $1$을 수행하면 $(1, 3, 2)$가 되고, 연산 $2$를 수행하면 $(2, 1, 3)$이 되므로 점수는 $0$입니다.

순열이 $(3, 1, 2)$일 때 연산 $1$을 수행하면 $(1, 3, 2)$가 되고, 연산 $2$를 수행하면 $(2, 1, 3)$이 되므로 점수는 $0$입니다.

순열이 $(3, 2, 1)$일 때 연산 $1$을 수행하면 $(1, 2, 3)$이 되고, 연산 $2$를 수행하면 $(1, 2, 3)$이 되므로 점수는 $3$입니다.

따라서 이들을 합한 $8$을 출력하면 됩니다.

### 예제 2 {file=""}

#### 입력

```text
5 3 3
```

#### 출력

```text
600
```

이 경우 $2$가지 연산은 같습니다.

즉, 어떤 순열에 연산을 수행해도 모든 원소가 일치하므로 어떤 경우에도 점수는 $5$입니다.

따라서 구하는 값은 $5 \times 5! = 600$입니다.
