허수 단위 $i$를 $i^2=-1$로 정의합니다. 정수 $A$, $B$, $C$, $D$가 주어질 때 다음 식을 만족하는 정수 $N$, $M$을 출력하세요.

$(A+Bi)(C+Di)=N+Mi$

## 조건

- $-10^9 \le A,B,C,D \le 10^9$

## 입력

입력은 다음 형식으로 주어집니다.

```text
A B
C D
```

## 출력

$N$과 $M$을 공백으로 구분하여 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1 1
2 -1
```

#### 출력

```text
3 1
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
0 0
0 0
```

#### 출력

```text
0 0
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
123456789 1
123456789 -1
```

#### 출력

```text
15241578750190522 0
```
