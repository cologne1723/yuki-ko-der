$N$개의 양의 정수열 $A$를 하나 출력하세요. 모든 $A_i\le10^8$, $A_i<A_{i+1}$이고, $\operatorname{lcm}(A_i,A_{i+1})>\operatorname{lcm}(A_{i+1},A_{i+2})$를 만족해야 합니다.

## 조건

- $3\le N\le25$
- 조건을 만족하는 수열이 존재함이 보장됩니다.

## 입력

```text
$N$
```

## 출력

조건을 만족하는 수열 하나를 공백으로 출력하세요.
