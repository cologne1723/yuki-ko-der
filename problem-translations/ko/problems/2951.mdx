## 문제 설명

정수 수열 $A=(A_1,A_2,\dots,A_{|A|})$와 정수 $k$에 대해 $f(A,k)$를 다음과 같이 정의합니다.

- $f(A,k)$ = $A$에 포함되지 않는 $k$ 이상인 가장 작은 정수

양의 정수 $N,M,K$가 주어집니다.

각 원소가 $1$ 이상 $M$ 이하인 정수인 길이 $N$의 수열 $A$는 $M^N$개 있습니다. 이 모든 수열에 대한

$\displaystyle \prod_{k=1}^{K}f(A,k)$

의 합을 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ M\ K$
```

## 제한

- $1\leq N,M,K\leq 300$
- 입력은 모두 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2 3 2
```

#### 출력

```text
43
```

조건을 만족하는 $A$는 다음 $9$개입니다.

- $A=(1,1)$일 때, $f(A,1)\cdot f(A,2)=2\cdot 2=4$
- $A=(1,2)$일 때, $f(A,1)\cdot f(A,2)=3\cdot 3=9$
- $A=(1,3)$일 때, $f(A,1)\cdot f(A,2)=2\cdot 2=4$
- $A=(2,1)$일 때, $f(A,1)\cdot f(A,2)=3\cdot 3=9$
- $A=(2,2)$일 때, $f(A,1)\cdot f(A,2)=1\cdot 3=3$
- $A=(2,3)$일 때, $f(A,1)\cdot f(A,2)=1\cdot 4=4$
- $A=(3,1)$일 때, $f(A,1)\cdot f(A,2)=2\cdot 2=4$
- $A=(3,2)$일 때, $f(A,1)\cdot f(A,2)=1\cdot 4=4$
- $A=(3,3)$일 때, $f(A,1)\cdot f(A,2)=1\cdot 2=2$

따라서 답은 $4+9+4+9+3+4+4+4+2=43$입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 1 1
```

#### 출력

```text
2
```

$A=(1)$일 때 $f(A,1)=2$입니다.

따라서 답은 $2$입니다.
