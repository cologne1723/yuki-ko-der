## 문제 설명

Malia는 주어진 식을 계산하려고 합니다.
식은 변수 $x$ 하나로만 이루어져 있으며, $i$번째 항은 $x$의 $a_i$제곱입니다. 즉 다음과 같은 형태입니다.

$x^{a_1} + x^{a_2} + \dots + x^{a_N}$

직접 $x$의 거듭제곱을 계산하는 일이 어렵다는 것을 알게 된 당신이 대신 계산해 주기로 했습니다.

$x$와 각 $a_i$가 주어질 때 식의 값을 구하세요. 결과가 매우 커질 수 있으므로 $1\,000\,003$으로 나눈 나머지를 출력하세요.
계산 중간의 값이 32비트에 들어가지 않을 수 있습니다.

## 입력

```text
x N
a_1 a_2 \dots a_N
```

첫째 줄에 변수 값 $x$와 항의 개수 $N$이 공백으로 구분되어 주어집니다. $(1 \le x \le 100; 1 \le N \le 100)$
둘째 줄에 각 항의 지수 $a_i$가 공백으로 구분되어 주어집니다. $(0 \le a_i \le 100\,000\,000)$

## 출력

$x^{a_1} + x^{a_2} + \dots + x^{a_N}$을 계산한 값을 $1\,000\,003$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 3
1 2 3
```

#### 출력

```text
14
```

$x+x^2+x^3$에서 $x=2$이므로 $2+4+8=14$입니다.

### 예제 2 {file=""}

#### 입력

```text
2 2
0 100
```

#### 출력

```text
253110
```

$x^0+x^{100}=1+1267650600228229401496703205376=1267650600228229401496703205377$이지만, 이를 $1\,000\,003$으로 나눈 나머지는 $253110$입니다.
