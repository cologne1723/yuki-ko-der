## 문제 설명

$6$면체 일반 주사위가 $N$개 있습니다. 모두 굴렸을 때 나온 눈의 합의 기댓값을 구하세요.

## 입력

```text
$N$
```

주사위의 개수 $N$이 주어집니다. $N$은 양의 정수입니다.

## 제한

$1 \le N \le 1\,000\,000$

## 출력

기댓값을 한 줄에 출력하세요. 오차는 $\pm0.01$까지 허용합니다. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
3.5
```

기댓값은 (나온 눈의 합)과 (확률)의 곱을 모두 더해 계산합니다. 따라서 $1\times1/6+2\times1/6+3\times1/6+4\times1/6+5\times1/6+6\times1/6=3.5$입니다.

### 예제 2 {file=""}

#### 입력

```text
2
```

#### 출력

```text
7
```

$2\times(1/36)+3\times(1/18)+4\times(1/12)+5\times(1/9)+6\times(5/36)+7\times(1/6)+8\times(5/36)+9\times(1/9)+10\times(1/12)+11\times(1/18)+12\times(1/36)=7$입니다.
