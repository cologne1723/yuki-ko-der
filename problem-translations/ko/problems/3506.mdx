## 문제 설명

양의 정수 $N$이 주어집니다. 다음 조건을 만족하는 $N$개 정점과 $M$개 간선의 가중치가 있는 연결 무방향 그래프를 $1$개 구성하세요. 정점에는 $1$부터 $N$까지, 간선에는 $1$부터 $M$까지 번호가 붙어 있다고 합니다.

- 자기 자신으로 돌아오는 간선은 포함하지 않습니다. 다중 간선은 허용됩니다.
- $M \leq 2N-3$입니다.
- $1 \leq i < j \leq N$을 만족하는 모든 정수 쌍 $(i,j)$에 대해, 정점 $i$에서 정점 $j$로 가는 단순 경로 중 경로에 포함된 간선의 가중치 합이 제곱수인 경로가 존재합니다.
- 모든 간선의 가중치는 서로 다른 $1$ 이상 $200$ 이하의 정수입니다.

또한, 구성한 그래프에서 정점 $i$에서 정점 $j$로 가는 단순 경로 중 경로에 포함된 간선의 가중치 합이 제곱수인 경로 $1$개를 $P_{i,j}$라고 합니다. $P_{i,j}$가 지나는 간선의 번호를 지나는 순서대로 나열한 수열을 $Q_{i,j}$라고 합니다. $1 \leq i < j \leq N$을 만족하는 모든 정수 쌍 $(i,j)$에 대해 $Q_{i,j}$를 출력하세요.

제한 조건 아래에서 조건을 만족하는 그래프를 항상 구성할 수 있음이 증명되어 있습니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

$N$은 정수입니다.

## 제한

- $2 \leq N \leq 100$
- 입력은 모두 정수입니다.

## 출력

먼저 조건을 만족하는 그래프를 출력하세요. $1$번째 줄에 간선의 개수 $M$을 출력하고, 이어지는 $M$개의 줄 중 $i$번째 줄에는 간선 $i$의 양 끝점 $U_i$, $V_i$와 가중치 $C_i$를 다음 형식으로 출력하세요.

```text
$U_i\ V_i\ C_i$
```

그다음 $1 \leq i < j \leq N$을 만족하는 모든 정수 쌍 $(i,j)$에 대해 $(i,j)$의 사전순으로 다음 형식의 출력을 수행하세요.

```text
$|Q_{i,j}|\ Q_{i,j}$
```

$Q_{i,j}$의 각 원소는 공백으로 구분하세요.
