복소수 $z_i=x_i+y_i\sqrt{-1}$가 주어집니다. $S=\sum_{i<j}\left\lvert z_i/z_j-z_j/z_i\right\rvert^2$를 $998244353$으로 계산하세요.

## 조건

- $1\le T\le10^5$, 모든 테스트 케이스에서 $N$의 합은 $3\times10^5$ 이하입니다.
- $2\le N\le3\times10^5$, $\lvert x_i\rvert,\lvert y_i\rvert\le2\times10^4$, $z_i\ne0$

## 입력

```text
$T$
$\textrm{Testcase}_1$
$\textrm{Testcase}_2$
$\vdots$
$\textrm{Testcase}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$x_1\ y_1$
$x_2\ y_2$
$\vdots$
$x_N\ y_N$
```

## 출력

각 답을 한 줄에 출력하세요.
