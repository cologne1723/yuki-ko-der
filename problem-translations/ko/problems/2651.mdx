복소수 $z_i=x_i+y_i\sqrt{-1}$가 주어집니다. $S=\sum_{i<j}\left|z_i/z_j-z_j/z_i\right|^2$를 $998244353$으로 계산하세요.

## 조건

- $1\le T\le10^5$, 모든 테스트 케이스에서 $N$의 합은 $3\times10^5$ 이하입니다.
- $2\le N\le3\times10^5$, $|x_i|,|y_i|\le2\times10^4$, $z_i\ne0$

## 입력

```text
$T$
$N$
$x_1$ $y_1$
\vdots
$x_N$ $y_N$
```

## 출력

각 답을 한 줄에 출력하세요.
