## 문제

`H`행 `W`열 격자에서 `#`은 장애물, `.`은 빈 칸입니다. 바깥 테두리는 모두 장애물입니다.

처음에 소는 `(r_a,c_a)`, 히카리는 `(r_b,c_b)`에 있습니다. 두 사람은 현재 칸과 상하좌우로 인접한 빈 칸 중 아무도 없는 칸으로 한 번에 한 사람씩 이동할 수 있습니다.

두 사람의 위치를 서로 바꿀 수 있는지 판정하고, 가능하다면 필요한 총 이동 횟수의 최솟값을 구하세요.

## 입력

첫째 줄에 `H W r_a c_a r_b c_b`가 주어지고, 이어서 격자가 주어집니다.

`4 \le H,W \le 1333`이며, 두 시작 칸은 빈 칸이고 격자 테두리는 장애물입니다.

교환이 가능하면 최소 총 이동 횟수를, 불가능하면 `-1`을 출력하세요.

## 문제

양의 정수 `N,K`와 음이 아닌 정수 수열 `A_1,...,A_N`, `B_1,...,B_N`이 주어집니다. 두 수열의 합은 모두 `K`입니다.

행과 열의 합이 각각 `A_i`, `B_i`이고 모든 원소가 음이 아닌 정수인 `N×N` 행렬의 집합을 `G`라 합니다. 음이 아닌 정수 행렬 `P`가 주어질 때 다음 값을 구하세요.

\[
\min_{Q\in G}\|P-Q\|_F^2
\]

여기서 `\|R\|_F^2=\sum_{i=1}^N\sum_{j=1}^N R_{i,j}^2`입니다.

## 입력

`N K`, 수열 `A`, 수열 `B`, 그리고 행렬 `P`가 주어집니다.

모든 입력은 정수입니다.

## 출력

구한 최솟값을 출력하세요.

## 문제

길이 `N`인 정수 수열 `A=(a_1,...,a_N)`가 주어집니다. 원래 순서를 유지하며 일부 원소를 골라 부분 수열 `B=(b_1,...,b_M)`를 만듭니다. 아무것도 고르지 않은 경우도 허용합니다.

`B`의 점수를 `\sum_{i=1}^{M} i\times b_i`로 정의하고, 가능한 모든 부분 수열의 점수 합을 `998244353`으로 나눈 나머지를 구하세요. 선택한 인덱스가 다르면 값이 같은 수열이어도 서로 다른 부분 수열로 셉니다.

첫째 줄에 `N`, 둘째 줄에 `a_1,...,a_N`이 주어집니다.

`1 \le N \le 500000`, `1 \le a_i \le 10^9`입니다.

## 출력

답을 `998244353`으로 나눈 나머지를 출력하세요.
