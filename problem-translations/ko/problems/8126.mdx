## 이야기

난해한 프로그래밍 언어 중 $1$개로 Brainfxxk(xx=uc)라는 언어가 있습니다. 이 언어는 `+`, `-`, `>`, `<`, `.`, `,`, `[`, `]`의 $8$종류 명령으로 이루어져 있습니다.

ゆーてぃーさん은 $8$종류 명령 중 `+`, `-`, `>`, `<`의 $4$종류 명령을 재현하기로 했습니다.

## 문제 설명

각 명령의 내용은 다음과 같습니다.

- `+`: 포인터가 가리키는 데이터의 값을 $1$ 증가시킵니다.
- `-`: 포인터가 가리키는 데이터의 값을 $1$ 감소시킵니다.
- `>`: 포인터의 번호를 $1$ 증가시킵니다.
- `<`: 포인터의 번호를 $1$ 감소시킵니다.

데이터와 데이터의 값은 다음과 같이 정합니다.

- $N$개의 데이터가 일렬로 놓여 있으며, 각 데이터의 번호는 앞에서부터 $1$, $2$, $\cdots$, $N$입니다.
- 각 데이터의 값은 처음에 모두 $0$으로 초기화되어 있습니다.
- 포인터의 번호는 처음에 $1$입니다.

데이터의 수와 코드 문자열이 주어집니다. 코드를 실행한 후 각 데이터의 값을 출력하세요.

단, 실행 중 포인터가 존재하지 않는 데이터의 번호를 $1$번이라도 가리키게 되면 `error`를 출력하세요.

## 입력

```text
$N$
$S$
```

$1$번째 줄에 데이터의 수를 나타내는 정수 $N$이 주어집니다.

$2$번째 줄에 코드 문자열 $S$가 주어집니다.

## 제한

- $1 \le N \le 10$
- $1 \le |S| \le 100$
- 문자열 $S$는 `+`, `-`, `>`, `<`로만 이루어집니다.

## 출력

포인터가 존재하지 않는 데이터의 번호를 $1$번이라도 가리키게 되면 `error`를 출력하세요.

그렇지 않으면 각 데이터의 값을 공백으로 구분하여 $1$줄에 출력하세요.

마지막으로 개행하세요.

## 예제

### 예제 1 {file="sample01"}

#### 입력

```text
3
+++>--
```

#### 출력

```text
3 -2 0
```

포인터가 가리키는 $1$번 데이터의 값을 $3$번 증가시키고, 포인터 번호를 $1$에서 $2$로 증가시킨 다음 포인터가 가리키는 $2$번 데이터의 값을 $2$번 감소시킵니다.

### 예제 2 {file="sample02"}

#### 입력

```text
3
<>>>>
```

#### 출력

```text
error
```

포인터 번호를 $1$에서 $0$으로 감소시켜 존재하지 않는 데이터를 가리키므로 `error`를 출력합니다. $1$번째 문자의 `error`를 무시하더라도 그 후 포인터 번호가 $4$ 증가하여 $4$가 되므로 존재하지 않는 데이터를 가리킵니다.

### 예제 3 {file="sample03"}

#### 입력

```text
1
+-+-+-+-+-
```

#### 출력

```text
0
```
