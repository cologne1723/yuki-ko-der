## 문제

피보나치 수열의 N번째 항을 M으로 나눈 나머지를 구하세요. 초보자는 오버플로와 나머지 계산에 주의하세요.

피보나치 수열의 첫 번째 항은 0, 두 번째 항은 1입니다.

피보나치 수열의 예와 정의는 다음과 같습니다.

F1 = 0

F2 = 1

F3 = F3−1 + F3−2 = F2 + F1 = 1 + 0 = 1

F4 = F4−1 + F4−2 = F3 + F2 = 1 + 1 = 2

…

FN = FN−1 + FN−2

## 입력

```text
N M
```

N과 M이 반각 공백으로 구분되어 주어집니다.

10 ≤ N ≤ 5000000 = 5 × 10^6

2 ≤ M < 2^31

## 출력

피보나치 수열의 N번째 항을 M으로 나눈 나머지를 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
10 20
```

출력:

```text
14
```

N=10, M=20이므로 피보나치 수열의 10번째 항을 20으로 나눈 나머지를 계산합니다.

F1=0, F2=1, F3=1, F4=2, F5=3, F6=5, F7=8, F8=13, F9=21, F10=34이므로 20으로 나눈 나머지는 14입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
20 1000
```

출력:

```text
181
```

### 샘플 3 {file="sample3.in"}

입력:

```text
30 17
```

출력:

```text
13
```
