왼쪽에서 오른쪽으로 $N$장의 카드가 놓여 있고, 각 카드에는 양의 정수가 쓰였거나 비어 있습니다. 상태는 $A_i$로 표현하며 $A_i=0$이면 비어 있습니다.

## 문제

빈 카드에 원하는 양의 정수를 하나씩 쓴 뒤 모든 카드를 원하는 순서로 재배열할 수 있습니다. 최종 수열 $B$가 등차수열이 되도록 할 수 있는지 판정하세요.

## 입력

```text
N
A_1 A_2 ... A_N
```

$3\le N\le2\times10^5$, $0\le A_i\le10^{15}$입니다.

## 출력

가능하면 `Yes`, 불가능하면 `No`를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
5
0 7 3 0 9
```

#### 출력

```text
Yes
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
7
4 0 9 5 11 0 0
```

#### 출력

```text
No
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
4
1 1 0 1
```

#### 출력

```text
Yes
```
