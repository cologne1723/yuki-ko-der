완성까지 필요한 연산 횟수의 기대값을 `998244353`에서의 값으로 구하세요.

## 제약

- `2 <= N <= 250`
- 간선은 중복이나 자기 루프가 없습니다.

## 입력

그래프의 간선 정보가 주어집니다.

## 출력

기대값을 출력하세요.
