현장 대회에 $N$명이 참가했습니다. 2명 또는 3명으로 그룹을 만들고, 모든 사람이 정확히 하나의 그룹에 속하도록 나눕니다.

2명 그룹은 3명 그룹보다 불리하므로, 2명 그룹의 수를 가능한 한 적게 하려 합니다. 가능한 최소 2명 그룹 수를 구하세요.

## 조건

- $2\le N\le10^9$
- 이 조건에서는 항상 그룹을 만들 수 있습니다.

## 입력

정수 $N$이 주어집니다.

## 출력

최소 2명 그룹 수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
7
```

#### 출력

```text
2
```

$7$명을 $3$명, $2$명, $2$명으로 나누면 됩니다. $2$명 그룹을 $2$개 미만으로 만들 수는 없습니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
5
```

#### 출력

```text
1
```

$5$명을 $3$명, $2$명으로 나누면 됩니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
3
```

#### 출력

```text
0
```

$3$명이 현장 대회에 와 주었습니다. 이 $3$명을 그대로 $1$개 그룹으로 만들어 대회를 엽니다.

### 예제 4 {file="01_sample_034txt"}

#### 입력

```text
998244353
```

#### 출력

```text
1
```

$998\,244\,353$명이 현장 대회에 와 주었습니다. 경쟁 프로그래밍의 미래는 든든하네요.
