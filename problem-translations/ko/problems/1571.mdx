## 문제

$N$개 정점의 완전 그래프를 구성하세요. 각 간선 비용은 0 이상 100 이하의 정수이고, 정점 1에서 시작해 모든 정점을 한 번씩 방문한 뒤 돌아오는 순환 경로의 비용 합이 항상 $T$가 되도록 해야 합니다.

$Q$개의 테스트 케이스를 처리하세요. 구성할 수 없는 경우의 출력 형식은 원문을 따릅니다.

## 입력

각 테스트 케이스에 $N,T$가 주어집니다.

- $1\leq Q\leq200$
- $2\leq N\leq8$
- $0\leq T\leq100$

## 출력

각 테스트 케이스에 대해 조건을 만족하는 완전 그래프를 출력하세요.
