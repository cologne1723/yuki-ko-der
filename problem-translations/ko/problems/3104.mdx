## 문제 설명

정점이 $N$개이고 간선이 $M$개인 연결 단순 무방향 그래프 $G$가 주어집니다. $G$의 정점에는 정점 $1,2,\cdots,N$, 간선에는 간선 $1,2,\cdots,M$의 번호가 붙어 있습니다. 간선 $i$는 정점 $U_i$와 정점 $V_i$를 잇는 무방향 간선입니다.

또한 수열 $A=(A_1,A_2,\cdots,A_N)$이 있으며, 처음에는 모든 $A_i=0$으로 초기화되어 있습니다.

다음 연산을 $i=1,2,\cdots,M$의 순서로 수행합니다.

- $0$ 이상 $998\,244\,353$ 미만의 정수 $x_i$를 선택하고, $A_{U_i}$와 $A_{V_i}$ 모두에 $x_i$를 더합니다. 그 후 $A_{U_i}$와 $A_{V_i}$를 각각 $998\,244\,353$으로 나눈 나머지로 바꿉니다.

수열 $B=(B_1,B_2,\cdots,B_N)$가 주어집니다. 연산의 결과 수열 $A$와 수열 $B$를 같게 만들 수 있는지 판정하세요. 가능하다면 그러한 연산 방법을 $1$가지 구성하세요.

## 입력

```text
$N\ M$
$B_1\ B_2\ \cdots\ B_N$
$U_1\ V_1$
$U_2\ V_2$
$\vdots$
$U_M\ V_M$
```

## 제한

- 입력은 모두 정수입니다.
- $2 \le N \le 10^5$
- $N-1 \le M \le \min\{10^5,N(N-1)/2\}$
- $1 \le U_i \lt V_i \le N$ ($1 \le i \le M$)
- $(U_i,V_i) \ne (U_j,V_j)$ ($i \ne j$)
- $G$는 연결 그래프입니다.
- $G$는 단순 그래프입니다. 즉, 다중 간선이나 자기 루프를 포함하지 않습니다.
- $0 \le B_i \lt 998\,244\,353$ ($1 \le i \le N$)

## 출력

연산의 결과 $A=B$로 만들 수 있다면, 그러한 연산 방법 중 $1$가지에 대해 각 연산에서 선택한 $x_i$를 다음 형식으로 출력하세요.

```text
$x_1\ x_2\ \cdots\ x_M$
```

답이 여러 개라면 그중 아무 것이나 출력해도 됩니다.

연산의 결과 $A=B$로 만들 수 없다면 $-1$을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2
2 1 998244352
1 2
2 3
```

#### 출력

```text
2 998244352
```

다음과 같이 조건을 만족시킬 수 있습니다.

$1$번째 연산에서 $x_1=2$를 선택합니다. 연산 후에는 $(A_1,A_2,A_3)=(2,2,0)$이 됩니다.

$2$번째 연산에서 $x_2=998\,244\,352$를 선택합니다. 연산 후에는 $(A_1,A_2,A_3)=(2,1,998\,244\,352)$가 됩니다.

#### 입력

```text

```

#### 출력

```text
-1
```

어떻게 연산해도 조건을 만족시킬 수 없습니다.
