## 문제 설명

십진법의 유한 소수로 나타낼 수 있는 양의 실수 $X$가 주어집니다.

$X$를 $X^{-1}$의 소수 부분으로 바꾸는 작업을 $X$가 양수인 동안 반복합니다.

단, 실수 $x$의 소수 부분이란 $x$에서 $x$를 초과하지 않는 최대 정수 $\lfloor x \rfloor$를 뺀 값 $x-\lfloor x \rfloor$입니다.

작업이 수행되는 횟수를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 $1$줄로 주어집니다.

- $X$가 정수라면, $X$가 십진법의 반각 정수로 주어집니다.
- $X$가 정수가 아니라면, $X$가 십진법의 반각 유한 소수로 주어지며 끝에 불필요한 $0$이 붙지 않습니다.

```text
$X$
```

## 제한

- $X$는 $0<X<10^9$를 만족하는 실수입니다.
- $10^9X$는 정수입니다.

## 출력

작업이 유한 번만 수행된다면 그 횟수를, 무한 번 수행된다면 `infty`를 $1$줄에 출력하세요.

마지막에 개행 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
1
```

처음에는 $X$가 $1$로 주어집니다.

$1$회째 작업에서 $X$가 $1^{-1}=1$의 소수 부분인 $0$으로 바뀝니다.

$X=0$이 되었으므로 더 이상 작업을 수행하지 않습니다.

### 예제 2 {file=""}

#### 입력

```text
1.5
```

#### 출력

```text
3
```

처음에는 $X$가 $1.5$로 주어집니다.

$1$회째 작업에서 $X$가 $1.5^{-1}=0.666\cdots$의 소수 부분인 $0.666\cdots$로 바뀝니다.

$2$회째 작업에서 $X$가 $(0.666\cdots)^{-1}=1.5$의 소수 부분인 $0.5$로 바뀝니다.

$3$회째 작업에서 $X$가 $0.5^{-1}=2$의 소수 부분인 $0$으로 바뀝니다.

$X=0$이 되었으므로 더 이상 작업을 수행하지 않습니다.

### 예제 3 {file=""}

#### 입력

```text
2
```

#### 출력

```text
2
```

처음에는 $X$가 $2$로 주어집니다.

$1$회째 작업에서 $X$가 $2^{-1}=0.5$의 소수 부분인 $0.5$로 바뀝니다.

$2$회째 작업에서 $X$가 $0.5^{-1}=2$의 소수 부분인 $0$으로 바뀝니다.

$X=0$이 되었으므로 더 이상 작업을 수행하지 않습니다.

### 예제 4 {file=""}

#### 입력

```text
999999999.999999999
```

#### 출력

```text
4
```

처음에는 $X$가 $999\,999\,999.999999999$로 주어집니다.

$1$회째 작업에서 $X$가 $999\,999\,999.999999999^{-1}=0.00000000100000000000000000100000000000000000100000\cdots$의 소수 부분인 $0.00000000100000000000000000100000000000000000100000\cdots$로 바뀝니다.

$2$회째 작업에서 $X$가 $(0.00000000100000000000000000100000000000000000100000\cdots)^{-1}=999\,999\,999.999999999$의 소수 부분인 $0.999999999$로 바뀝니다.

$3$회째 작업에서 $X$가 $0.999999999^{-1}=1.00000000100000000100000000100000000100000000100000\cdots$의 소수 부분인 $0.00000000100000000100000000100000000100000000100000\cdots$로 바뀝니다.

$4$회째 작업에서 $X$가 $(0.00000000100000000100000000100000000100000000100000\cdots)^{-1}=999\,999\,999$의 소수 부분인 $0$으로 바뀝니다.

$X=0$이 되었으므로 더 이상 작업을 수행하지 않습니다.
