## 문제 설명

상자 $N$개가 일렬로 놓여 있습니다. 상자에는 왼쪽부터 차례대로 $0$번부터 $N-1$번까지 번호가 붙어 있습니다.

$i$번 상자에 공이 $B_i$개 들어 있습니다.

($B_i$가 $0$이면 공이 들어 있지 않습니다.)

모든 상자에 들어 있는 공의 개수 합은 $N$개입니다.

어떤 상자의 왼쪽 또는 오른쪽 바로 옆 상자로 공 $1$개를 이동시키는 것을 연산 $1$회로 합니다.

모든 상자에 공이 정확히 $1$개씩 들어 있도록 만들기 위해 필요한 최소 연산 횟수를 구하세요.

## 입력

```text
$N$
$B_0\ B_1\ \dots\ B_{N-1}$
```

첫째 줄에 상자의 개수 $N$이 주어집니다.

둘째 줄에 $i$번 상자에 처음 들어 있는 공의 개수 $B_i$가 주어집니다. $B_i$는 $i=0,1,\ldots,N-1$에 대해 주어집니다.

## 제한

- $N$은 양의 정수입니다.
- $1 \le N \le 100\,000 = 10^5$
- $B_i$는 음이 아닌 정수입니다.
- $0 \le B_i \le 100\,000 = 10^5$
- $B_0$부터 $B_{N-1}$까지의 합은 정확히 $N$입니다.

## 출력

정답을 한 줄에 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
0 3 0
```

#### 출력

```text
2
```

상자 $3$개가 있고 가운데 상자에 공이 $3$개 들어 있습니다.

공 $1$개를 왼쪽 상자로 $1$칸 이동시키고, 공 $1$개를 오른쪽 상자로 $1$칸 이동시킵니다.

이제 모든 상자에 공이 $1$개씩 들어 있습니다. 필요한 연산 횟수는 $2$회입니다.

### 예제 2 {file=""}

#### 입력

```text
3
3 0 0
```

#### 출력

```text
3
```

가장 왼쪽 상자의 공 $1$개를 오른쪽 바로 옆 상자로 이동시킵니다.

가장 왼쪽 상자의 공 $1$개를 오른쪽 바로 옆 상자로 다시 이동시킵니다.

가운데 상자의 공 $1$개를 오른쪽 바로 옆 상자로 이동시킵니다.

필요한 연산 횟수는 $3$회입니다.


#### 출력

```text
0
```

연산은 필요하지 않습니다.
