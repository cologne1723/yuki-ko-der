## 이야기

어떤 규칙으로 생성되는 이진 문자열을 분석하고 있습니다.

## 문제 설명

길이 $|T|$인 문자열 $T$와 양의 정수 $K$가 주어집니다. 문자열 $S$는 $T$를 $K$번 차례로 이어 붙여 생성되며, 그 길이는 $N=|T|\times K$입니다.

문자열 $S$의 부분 수열(연속할 필요는 없음) 중 인접한 문자끼리 같은 문자가 아닌 것을 교대 부분 수열이라고 합니다. 비어 있지 않은 모든 교대 부분 수열을 생각하고, 각 부분 수열의 길이의 제곱을 점수로 정의합니다.

비어 있지 않은 모든 교대 부분 수열의 점수 합을 $1\,000\,000\,007=10^9+7$로 나눈 나머지를 구하세요.

단, $2$개의 교대 부분 수열이 문자열로는 같더라도 선택한 위치가 다르면 서로 다른 것으로 세어 점수에 포함합니다.

## 입력

```text
$T$
$K$
```

## 제한

- $1\leq |T|\leq 2\times 10^5$
- 문자열 $T$는 `0`과 `1`만으로 이루어집니다.
- $1\leq K\leq 10^{18}$

## 출력

비어 있지 않은 모든 교대 부분 수열의 점수 합을 $1\,000\,000\,007=10^9+7$로 나눈 나머지를 출력하세요.

출력 끝에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
01
2
```

#### 출력

```text
54
```

$T=$ `01`, $K=2$이므로 대상 문자열 $S$는 `0101`입니다.

비어 있지 않은 교대 부분 수열과 그 점수는 다음과 같습니다.

- 길이 $1$: `0` ( $2$가지), `1` ( $2$가지) $\rightarrow$ 점수: $1^2\times (2+2)=4$
- 길이 $2$: `01` ( $3$가지), `10` ( $1$가지) $\rightarrow$ 점수: $2^2\times (3+1)=16$
- 길이 $3$: `010` ( $1$가지), `101` ( $1$가지) $\rightarrow$ 점수: $3^2\times (1+1)=18$
- 길이 $4$: `0101` ( $1$가지) $\rightarrow$ 점수: $4^2\times 1=16$

이를 모두 더하면 정답은 $54$입니다.

`01`이 만들어지는 방법이 $3$가지라는 점에 주의하세요. $1$번째 문자와 $2$번째 문자를 선택하는 방법, $1$번째 문자와 $4$번째 문자를 선택하는 방법, $3$번째 문자와 $4$번째 문자를 선택하는 방법입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
0
1000000000000000000
```

#### 출력

```text
49
```

$S$는 `0`이 $10^{18}$개 나열된 문자열입니다.

비어 있지 않은 교대 부분 수열은 `0` 중 $1$개를 선택하는 $10^{18}$가지 방법입니다.

따라서 $1^2\times 10^{18}\mod (10^9+7)=49$를 출력합니다.
