$N$개의 정점과 $N$개의 변을 가진 연결 단순 무방향 그래프가 주어집니다. 각 변에 방향을 정해 모든 정점의 진출 차수가 1인 유향 그래프로 만드세요.

## 조건

- $3\le N\le2\times10^5$
- $1\le A_i<B_i\le N$
- 그래프는 연결된 단순 그래프입니다.

## 입력

첫째 줄에 $N$, 다음 $N$개 줄에 변 $(A_i,B_i)$가 주어집니다.

## 출력

$i$번째 변을 $A_i\to B_i$로 정하면 `->`, $A_i\leftarrow B_i$로 정하면 `<-`를 $i$번째 줄에 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
5
1 2
2 3
3 4
1 4
4 5
```

#### 출력

```text
->
->
->
<-
<-
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
7
1 2
2 4
4 5
1 7
2 3
3 7
3 6
```

#### 출력

```text
<-
<-
<-
->
<-
<-
<-
```
