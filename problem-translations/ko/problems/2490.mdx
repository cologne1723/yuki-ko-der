길이 $2N$의 수열 $A$가 주어집니다. $A_i\ne-1$이면 $B_i=A_i$이고, 어떤 정수쌍 $(s,t)$가 존재해 모든 $0\le i<N$에 대해 $B_{(s+i)\bmod2N}=B_{(t-i)\bmod2N}$가 되도록 $B$를 만들 수 있는지 판정하세요.

## 조건

- $1\le N\le5\times10^4$
- $A_i=-1$ 또는 $1\le A_i\le2N$

## 입력

```text
N
A0 A1 ... A(2N-1)
```

## 출력

가능하면 `Yes`, 불가능하면 `No`를 출력하세요.
