$N$개의 기어가 일렬로 맞물려 있고 기어 $i$의 이 수는 $A_i$이다냥. $M$가지 색으로 모든 톱니를 칠하며, 회전해서 서로 일치하는 색칠은 같은 것으로 센다냥. 색칠 방법의 수를 $998244353$으로 나눈 나머지를 구하라냥.

## 조건

- $2\le N\le1000$
- $1\le M\le10^9$
- $3\le A_i<998244353$

## 입력

```text
N M
A_1 \cdots A_N
```

## 출력

색칠 방법의 수를 출력하라냥.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 2
3 3
```

#### 출력

```text
24
```

### 예제 2 {file=""}

#### 입력

```text
2 3
3 4
```

#### 출력

```text
264
```

### 예제 3 {file=""}

#### 입력

```text
3 4
3 5 7
```

#### 출력

```text
11701248
```

### 예제 4 {file=""}

#### 입력

```text
4 100
10 1000 100000 100000000
```

#### 출력

```text
827082837
```
