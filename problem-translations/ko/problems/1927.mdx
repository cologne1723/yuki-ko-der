A,B,C,D로 이루어진 문자열 $S$가 주어집니다. 인접한 서로 다른 두 문자를 골라 교환할 수 있지만, `AB`, `BA`, `CD`, `DC`인 쌍은 고를 수 없습니다.

## 문제

조작 후 얻을 수 있는 서로 다른 문자열의 개수를 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
N
S
```

$2\le N\le3\times10^5$입니다.

## 출력

가능한 문자열의 종류 수를 출력하세요.
