## 문제

`H×W` 격자에서 변을 공유하는 빈 두 칸에 블록 두 개를 놓는 배치를 여러 번 합니다. 그 뒤 블록이 가득 찬 행을 삭제하고, 블록이 아래로 떨어지게 합니다.

최종 상태 `s`가 주어질 때 이를 만드는 배치 방법을 하나 출력하세요.

## 입력

`H W`와 최종 격자가 주어집니다.

## 출력

조건을 만족하는 배치 방법을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4 3
...
...
..#
#..
```

#### 출력

```text
Yes
..a
bba
c..
cdd
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 3
.#.
.#.
.#.
```

#### 출력

```text
No
```
