## 참고

작성자는 테스터를 붙이지 않기를 희망했습니다.

## 문제

Yuki는 다음 완성 그림이 되는 4행 4열 퍼즐을 얻었습니다.

```text
ABCD
EFGH
IJKL
MNOP
```

하지만 얻은 퍼즐은 완성되지 않은 상태였습니다.

퍼즐에는 다음 조작을 할 수 있습니다.

* 한 번의 조작으로 선택한 r행을 오른쪽으로 a칸 회전할 수 있습니다.
* 한 번의 조작으로 선택한 c열을 아래쪽으로 b칸 회전할 수 있습니다.

Yuki는 이 퍼즐을 완성 그림과 같게 만드는 절차를 100번 이내의 조작으로 준비해야 합니다.

얻은 퍼즐은 100번 이내의 조작으로 완성 그림과 같게 만들 수 있음이 보장됩니다. 단, 처음부터 완성된 퍼즐은 주어지지 않습니다.

## 입력

```text
S0
S1
S2
S3
```

Si는 i행 패널의 문자 정보입니다( i는 0-index).

문자열 Si는 항상 4글자입니다. i행의 j번째 문자가 j열의 문자입니다(j는 0-index).

퍼즐 안의 알파벳은 대문자 A부터 P까지 16글자이며 중복되지 않습니다.

## 출력

먼저 필요한 조작 횟수 N을 한 줄에 출력하세요. 1 ≤ N ≤ 100

그다음 필요한 조작을 첫 번째 조작부터 N줄에 걸쳐 출력하세요.

행 조작은 다음 형식입니다.

```text
R r a
```

대문자 R, r행을 나타내는 정수 r, 오른쪽으로 a칸 회전할 정수 a를 공백으로 구분해 출력하세요. 0 ≤ r ≤ 3, 1 ≤ a ≤ 3

열 조작은 다음 형식입니다.

```text
C c b
```

대문자 C, c열을 나타내는 정수 c, 아래쪽으로 b칸 회전할 정수 b를 공백으로 구분해 출력하세요. 0 ≤ c ≤ 3, 1 ≤ b ≤ 3

수치가 제약을 만족하지 않으면 오답이 되므로 주의하세요. 조건만 만족하면 어떤 절차로 완성해도 정답입니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
BCDA
EFGH
IJKL
MNOP
```

출력:

```text
1
R 0 1
```

0행을 오른쪽으로 1칸 회전하면 퍼즐이 완성됩니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
ANCD
EBGH
IFKL
MJOP
```

출력:

```text
1
C 1 3
```

1열을 아래쪽으로 3칸 회전하면 퍼즐이 완성됩니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
FHLE
MOIC
DNPB
AKGJ
```

출력:

```text
14
C 0 2
C 3 1
R 1 3
C 3 2
R 2 1
R 1 2
C 2 2
R 0 1
R 0 3
R 0 2
C 3 1
R 0 1
C 1 3
R 2 1
```

최단 정답은 아니지만 어쨌든 100번 이내에 완성하면 정답입니다.
