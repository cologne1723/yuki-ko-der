네 큐를 다음과 같이 초기화합니다: `queue0=(A,E)`, `queue1=(B)`, `queue2=(C)`, `queue3=(D)`.

`i+1`번째 작업에서 `queue(i mod 4)`의 앞 원소를 꺼내 `queue((i+1) mod 4)`의 뒤에 넣습니다. `K`번 작업 후 네 큐의 상태를 출력하세요.

## 제약

- `1 <= K <= 100`

## 입력

`K`가 주어집니다.

## 출력

네 큐의 상태를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
E
BA
C
D
```

### 예제 2 {file=""}

#### 입력

```text
4
```

#### 출력

```text
ED
A
B
C
```

### 예제 3 {file=""}

#### 입력

```text
100
```

#### 출력

```text
AE
B
C
D
```
