## 문제

treeone은 임의의 사용자 ID를 “이름 + 적당한 수 X” 형식으로 만들기로 했습니다.

사용자 ID 끝에 붙일 수 X는 다음 절차로 정합니다.

먼저 적당한 양의 정수 N을 하나 고릅니다.

그다음 곱이 N이 되는 양의 정수 두 수의 순서쌍을 나열합니다.

마지막으로 앞에서 나열한 순서쌍의 두 수를 문자열로 이어 붙인 것을 X의 후보로 합니다.

예를 들어 N=6이면 두 수의 곱이 6인 순서쌍은 (1,6), (2,3)의 2개이므로 X의 후보는 16, 61, 23, 32의 4개입니다.

N이 주어질 때 X의 후보가 몇 개인지 구하세요.

## 입력

```text
N
```

1 ≤ N ≤ 10^12

N은 정수입니다.

## 출력

X의 후보 개수를 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
6
```

출력:

```text
4
```

문제에서 든 예입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
63
```

출력:

```text
6
```

곱이 63인 양의 정수 두 수의 순서쌍은 (1,63), (3,21), (9,7)이므로 X의 후보는 163, 631, 321, 213, 97, 79의 6개입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
49
```

출력:

```text
3
```

X의 후보는 149, 491, 77의 3개입니다.
