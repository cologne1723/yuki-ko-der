## 문제 설명

정점 집합 $V_1,V_2$의 정점 수가 각각 $L,R$이고, 간선 수가 $M$인 이분 그래프가 주어집니다.
$i$번째 간선은 $V_1$의 정점 $a_i$와 $V_2$의 정점 $b_i$를 연결합니다.

각 정점에 연결된 간선 색의 집합이 서로 같은 간선 색칠 중에서, 사용한 색 수가 최대인 것을 구성하세요.

### 배경

그래프 $G=(V,E)$의 간선 색칠이란 전사 함수 $c:E\rightarrow S$입니다. 이 중 임의의 $2$개의 정점 $u,v$에 대해 다음을 만족하는 간선 색칠 $c$를 생각합니다.

$\{ c(e) \mid e \in E(u) \}=\{ c(e) \mid e \in E(v) \}$

여기서 $E(v)$는 정점 $v$에 연결된 간선의 집합입니다. $|S|$가 최대가 되는 $c$를 구성하세요. 이 색칠을 무지갯빛 색칠이라고 부릅니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$L\ R\ M$
$a_1\ b_1$
$\vdots$
$a_M\ b_M$
```

그래프에는 고립점이 존재하지 않습니다.

## 제한

- $1 \le L,R \le 1\,000$
- $1 \le M \le 10\,000$
- $0 \le a_i < L$
- $0 \le b_i < R$

다음은 AC와 무관한 숙련자용 테스트 케이스(evil 케이스)입니다.

- $1 \le L,R \le 100\,000$
- $1 \le M \le 100\,000$

## 출력

$K$는 색 수를, $c_i$는 $i$번째 간선의 색을 나타내는 정수입니다. $c_i$는 $0 \le c_i < K$를 만족해야 합니다. 조건을 만족하는 색칠이 여러 개 존재하는 경우, 그중 아무 것이나 출력해도 됩니다.

다음 형식으로 출력하세요.

```text
$K$
$c_1$
$\vdots$
$c_M$
```
