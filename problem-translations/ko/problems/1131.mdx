## 문제 설명

NaN 군의 반에는 $N$명의 학생이 있습니다. 시험을 치른 결과 각 학생의 점수는 $100$점 만점의 $x_1,x_2,\ldots,x_N$점이었습니다. 모든 학생의 대략적인 편차값을 소수점 아래 버림으로 구하세요.

학생 $i$의 대략적인 편차값 $D_i$는 학생 $i$를 포함한 $N$명의 평균 점수를 $A$라고 할 때 다음과 같습니다.

$D_i = 50 - \frac{A-x_i}{2}$

## 입력

```text
$N$
$x_1\ x_2\ \cdots\ x_N$
```

$1 \leq N \leq 100\,000$

$0 \leq x_i \leq 100$

$N$과 $x_i$는 정수입니다.

## 출력

$N$명의 학생의 대략적인 편차값을 소수점 아래 버림하여 $N$줄에 출력하세요.
