## 문제 설명

$xy$ 평면 위에 $2N$마리의 게가 있습니다. 처음에 $i$번 게($1 \leq i \leq 2N$)는 좌표 $(X_i, Y_i)$에 있습니다.

또한 $C_i$가 `x`일 때 $i$번 게는 $x$축과 평행한 방향으로, $C_i$가 `y`일 때는 $y$축과 평행한 방향으로 자유롭게 이동할 수 있습니다. 그 외의 방향으로 이동할 수는 없습니다.

$2N$마리의 게를 겹치지 않게 $N$개의 쌍으로 나누는 방법 중 다음 조건을 만족하는 것이 존재하는지 판정하세요.

- 각 게가 이동할 수 있는 방향으로 자유롭게 이동했을 때, 같은 쌍에 속한 게끼리 같은 좌표에 있는 상태를 만들 수 있습니다.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$X_1\ \ Y_1\ \ C_1$
$X_2\ \ Y_2\ \ C_2$
$\vdots$
$X_{2N}\ \ Y_{2N}\ \ C_{2N}$
```

## 제한

- $1 \leq T \leq 10^4$
- $1 \leq N \leq 10^5$
- $1 \leq X_i, Y_i \leq 10^9$
- $C_i$는 `x` 또는 `y` 중 $1$개입니다.
- $1$개의 입력 파일에서 $N$의 총합은 $2 \times 10^5$를 넘지 않습니다.
- $T$, $N$, $X_i$, $Y_i$는 정수입니다.

## 출력

각 테스트 케이스에 대한 답을 순서대로 줄바꿈으로 구분하여 출력하세요.

각 테스트 케이스에서 조건을 만족하는 $N$개의 쌍의 집합 $M$이 존재한다면 `Yes`를, 그렇지 않다면 `No`를 출력하세요.


- $1$번 게와 $2$번 게는 좌표 $(3, 2)$에 모일 수 있습니다.
