## 공지

예상 풀이에서도 제한 시간이 매우 빠듯하므로 C++에 준하는 속도의 언어를 사용하는 것을 강하게 권장합니다.

## 이야기

읽지 않아도 되는 이야기입니다.

도서관 사서인 Akiさん은 도서관에 있는 책의 전체 가치를 높이고 싶어 합니다.

그래서 몇 가지 시리즈의 책을 연속된 책장에 보관하여 책장의 가치를 높이기로 했습니다.

그리고 얼마나 빠르게 개선할 수 있었는지 알아보기로 했습니다.

## 문제 설명

길이 $N$인 수열 $A$가 주어집니다. $K$개의 업데이트 쿼리가 주어지며, $i$번째 업데이트 쿼리에서는 다음 연산을 수행합니다.

- $3$개의 양의 정수 $L_i$, $R_i$, $X_i$가 주어집니다. $L_i \le j \le R_i$를 만족하는 각 정수 $j$에 대해 $A_j$를 $\max(A_j, X_i)$로 변경합니다.

또한 $Q$개의 질의 쿼리가 주어집니다. $i$번째 질의 쿼리는 다음과 같습니다.

- $3$개의 양의 정수 $L_i$, $R_i$, $X_i$가 주어집니다. $\sum_{j=L_i}^{R_i}{A_j} \ge X_i$가 처음으로 성립하는 것은 몇 번째 업데이트 쿼리 직후인지 출력하세요.

단, $1$번째 업데이트 쿼리 전에 이미 조건을 만족한다면 $0$, $K$번째 업데이트 쿼리 후에도 조건을 만족하지 않는다면 $-1$을 출력하세요.

각 질의 쿼리에 대한 답을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ K\ Q$
$A_1\ A_2\ \cdots\ A_N$
$Update_1$
$\vdots$
$Update_K$
$Query_1$
$\vdots$
$Query_Q$
```

$Update_i$와 $Query_i$는 각각 업데이트 쿼리와 질의 쿼리를 나타내며, 모두 다음 형식으로 주어집니다.

```text
$L_i\ R_i\ X_i$
```

## 제한

- 입력은 모두 정수입니다.
- $1 \le N, Q \le 5 \times 10^4$
- $1 \le K \le 10^4$
- $1 \le A_i \le 10^9$
- 업데이트 쿼리는 다음 조건을 만족합니다.
  - $1 \le L_i \le R_i \le N$
  - $1 \le X_i \le 10^9$
- 질의 쿼리는 다음 조건을 만족합니다.
  - $1 \le L_i \le R_i \le N$
  - $1 \le X_i \le 5 \times 10^{13}$

## 출력

$Q$개의 줄에 출력하세요. $i$번째 줄에는 $i$번째 질의 쿼리에 대한 답을 출력하고 개행하세요.

```text

```

시작 직후와 각 업데이트 쿼리 후의 $A$의 값은 다음과 같습니다.

- $[1, 10, 7, 6, 2, 3, 1, 1, 11, 2]$
- $[3, 10, 7, 6, 3, 3, 1, 1, 11, 2]$
- $[3, 10, 7, 6, 3, 3, 3, 1, 11, 2]$
- $[3, 10, 7, 6, 3, 3, 3, 5, 11, 5]$
- $[3, 10, 7, 7, 7, 7, 3, 5, 11, 5]$
- $[6, 10, 7, 7, 7, 7, 3, 5, 11, 5]$
- $[6, 10, 9, 9, 9, 7, 3, 5, 11, 5]$
- $[8, 10, 9, 9, 9, 8, 8, 5, 11, 5]$

예를 들어 질의 쿼리 $1$에서는 처음에 합이 $10+7+6+2=25<26$이므로 조건을 만족하지 않습니다. 하지만 업데이트 쿼리 $1$ 후에는 $10+7+6+3 \ge 26$이므로 답은 $1$입니다.

마찬가지로 질의 쿼리 $2$에서는 업데이트 쿼리 $5$ 후의 합이 $68$이지만 업데이트 쿼리 $6$ 후에는 $74$가 되므로 답은 $6$입니다.

질의 쿼리 $3$이나 $6$처럼 마지막까지 조건을 만족하지 않는 경우도 있고, 처음부터 조건을 만족하는 경우도 있다는 점에 주의하세요.
