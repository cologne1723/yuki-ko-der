길이 `N`인 문자열 `S`가 주어집니다. 각 문자는 소문자 영어 문자 또는 `?`입니다.

모든 `?`를 소문자로 치환해 만들 수 있는 문자열 중, 길이가 2 이상인 회문을 연속 부분 문자열로 포함하지 않는 문자열의 개수를 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `1 <= N <= 5 * 10^4`
- `S`는 소문자 영어 문자와 `?`로 이루어집니다.

## 입력

`N S`가 주어집니다.

## 출력

답을 `998244353`으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
a??d
```

#### 출력

```text
552
```

### 예제 2 {file=""}

#### 입력

```text
10
palindrome
```

#### 출력

```text
1
```

#### 입력

```text

```

#### 출력

```text
0
```
