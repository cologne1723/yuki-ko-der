`N`개의 집합 `A_i`가 주어집니다. `A_i`의 원소 수는 `k_i`이고 원소는 `C_{i,1},...,C_{i,k_i}`입니다.

하나 이상의 집합을 선택하는 방법 중, 선택한 모든 집합의 교집합이 빈 집합인 방법의 개수를 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `1 <= N <= 500`
- `0 <= k_i <= 12`
- 원소는 `1` 이상 `12` 이하이며 각 집합 안에서 서로 다릅니다.

## 입력

`N`과 각 집합의 원소가 주어집니다.

## 출력

조건을 만족하는 선택 방법의 개수를 출력하세요.
