## 참고

이 문제는 Advent Calendar Contest Advent Calendar 2015의 16일차 문제로 만들어졌습니다. 출제자는 Java와 PyPy2에서 여유 있게 통과하는 것을 확인했지만 Python2에서는 시간 초과가 났습니다. 비교적 느린 언어를 사용하는 경우 실행 시간에 주의하세요.

## 문제

다로 군은 직사각형 빈터에서 눈사람을 만들며 눈덩이를 굴리고 있습니다.

빈터를 $H$행 $W$열의 격자로 나타냅니다. $i$행($0\le i\le H-1$), $j$열($0\le j\le W-1$)의 칸을 $(i,j)$라고 합니다.

처음에 눈덩이는 $(S_i,S_j)$에 있고 크기는 $A$입니다. 다로 군은 눈덩이를 상하좌우 중 하나의 인접한 칸으로 옮길 수 있지만 빈터 밖으로 나갈 수는 없습니다. 이동한 칸에 눈이 쌓여 있으면 눈덩이 크기가 1 증가하고, 그렇지 않으면 1 감소합니다. 크기가 0 이하가 되면 눈덩이가 녹으므로 크기는 항상 1 이상이어야 합니다.

눈덩이 크기를 정확히 $B$로 만들어 $(G_i,G_j)$로 옮길 수 있는지 판정하세요.

## 입력

```text
H W
A S_i S_j
B G_i G_j
M_0
M_1
⋮
M_{H-1}
```

첫째 줄에 $H,W$, 둘째 줄에 $A,S_i,S_j$, 셋째 줄에 $B,G_i,G_j$가 주어집니다. 넷째 줄부터 $H$개의 줄에 길이 $W$인 문자열 $M_0,\ldots,M_{H-1}$이 주어집니다. $M_i$의 $j$번째 문자가 `*`이면 $(i,j)$에 눈이 쌓여 있고, `.`이면 쌓여 있지 않습니다.

- $1 \le H,W \le 50$
- $1 \le A,B \le 1000$
- $0 \le S_i,G_i \le H-1$
- $0 \le S_j,G_j \le W-1$
- $(A,S_i,S_j)\ne(B,G_i,G_j)$

## 출력

눈덩이 크기를 정확히 $B$로 만들어 $(G_i,G_j)$에 옮길 수 있으면 `Yes`, 불가능하면 `No`를 출력하세요.

마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
2 4
2 0 0
2 1 3
*.*.
.*.*
```

### 샘플 1 {file="sample1.out"}

```text
Yes
```

오른쪽, 오른쪽, 오른쪽, 아래로 이동하면 목표 칸에 도착하고 눈덩이 크기는 2가 됩니다. 크기는 $2\to1\to2\to1\to2$로 변합니다.

### 샘플 2 {file="sample2.in"}

```text
2 1
1 0 0
4 1 0
*
*
```

### 샘플 2 {file="sample2.out"}

```text
Yes
```

아래, 위, 아래로 3번 이동하면 목표 칸에 도착하고 크기는 4가 됩니다. 처음 아래로 이동한 직후에도 목표 칸에 있지만, 그 시점에는 크기가 부족합니다.

### 샘플 3 {file="sample3.in"}

```text
4 4
3 3 0
8 0 3
.***
..**
...*
....
```

### 샘플 3 {file="sample3.out"}

```text
No
```

도중에 눈덩이 크기가 0 이하가 되면 안 되므로 목표 칸에 도달할 수 없습니다.

### 샘플 4 {file="sample4.in"}

```text
8 10
1 1 4
5 1 4
....*.*.*.
.........*
..........
.*.*.*...*
*...**....
.........*
*.........
.*.*.*.*.*
```

### 샘플 4 {file="sample4.out"}

```text
Yes
```

처음 눈덩이가 있는 칸과 목표 칸이 같을 수도 있습니다.
