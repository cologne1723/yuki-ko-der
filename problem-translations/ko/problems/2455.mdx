1부터 $N$까지의 양의 정수를 문자열로 보아 사전순으로 정렬한 숫자 사전이 있습니다. 정수 $K$가 사전에서 몇 번째인지 구하세요.

## 조건

- $1\le T\le10^4$
- $1\le K\le N<10^{18}$

## 입력

```text
T
N K
```

## 출력

각 테스트 케이스의 순위를 출력하세요.
