## 문제 설명

주사위 $X$에는 $6$개의 면이 있고, 각 면에는 $1$부터 $6$까지의 정수가 $1$개씩 쓰여 있습니다.

눈의 합이 $N$ 이상이 될 때까지 주사위 $X$를 계속 던집니다.

몇 번 던지게 되는지 그 기댓값을 구하세요.

여러 번 던졌을 때 각 주사위 눈은 서로 독립이라고 가정합니다. (주사위의 각 면이 나올 확률은 같지 않을 수도 있습니다.)

## 입력

```text
$T$
$N_1$
$N_2$
$\vdots$
$N_T$
```

테스트 케이스 수 $T$가 주어집니다. 이후 $T$개의 줄에 각 테스트 케이스의 $N$ 값이 주어집니다. $k$번째 테스트 케이스의 $N$ 값을 $N_k$로 나타냅니다.

샘플 테스트와 저지 테스트에서 주사위 $X$는 같은 주사위를 의미합니다.

## 제한

- $1 \le T \le 50$
- $1 \le N_k \le 1\,000\,000$ $(1 \le k \le T)$

## 출력

$k$번째 줄에 $k$번째 테스트 케이스의 답을 출력하세요.

상대 오차가 $10^{-5}$ 이하이면 정답으로 인정합니다.
