## 문제

정수 $A$에 정수 $B$를 곱하고, 이어서 정수 $C$를 곱한 뒤, 마지막으로 정수 $D$로 나눈 나머지를 구하세요.

## 입력

```text
A B C D
```

$A,B,C,D$는 양의 정수이며 $1\le A,B,C,D\le1000000000=10^9$입니다.

## 출력

계산 결과를 한 줄에 출력하세요. 마지막에 개행을 잊지 마세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
1 2 3 4
```

### 샘플 1 {file="sample1.out"}

```text
2
```

“1 곱하기 2 곱하기 3을 4로 나눈 나머지”는 2입니다.

### 샘플 2 {file="sample2.in"}

```text
2 2 2 2
```

### 샘플 2 {file="sample2.out"}

```text
0
```

“2 곱하기 2 곱하기 2를 2로 나눈 나머지”는 0입니다.
