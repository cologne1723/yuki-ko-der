## 문제 설명

정수 $A$에 정수 $B$를 곱하고, 이어서 정수 $C$를 곱한 뒤, 마지막으로 정수 $D$로 나눈 나머지를 구하세요.

## 입력

```text
$A\ B\ C\ D$
```

양의 정수 $A,B,C,D$가 공백으로 구분되어 주어집니다.

## 제한

$1\le A,B,C,D\le1\,000\,000\,000=10^9$

## 출력

계산 결과를 $1$줄에 출력하세요. 마지막에 개행을 잊지 마세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 2 3 4
```

#### 출력

```text
2
```

“$1$ 곱하기 $2$ 곱하기 $3$을 $4$로 나눈 나머지”는 $2$입니다.

### 예제 2 {file=""}

#### 입력

```text
2 2 2 2
```

#### 출력

```text
0
```

“$2$ 곱하기 $2$ 곱하기 $2$를 $2$로 나눈 나머지”는 $0$입니다.
