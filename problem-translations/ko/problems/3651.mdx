## 문제 설명

양의 정수 $N$과 양의 정수 $K$가 주어집니다.

양의 정수 $x$에 대해, $x$의 모든 양의 약수의 합을 $100\,003$으로 나눈 나머지를 $f(x)$로 정의합니다.

길이 $K$인 수열 $A=(A_1,\ldots,A_K)$를 다음과 같이 정의합니다.

- $A_1=N$
- $A_{i+1}=f(A_i)$ ($i$는 $1$ 이상 $K-1$ 이하인 정수)

이때 수열의 $K$번째 항인 $A_K$의 값을 구하세요.

또한 이 문제의 제한에서 $K$ 이하인 양의 정수 $z$ 중 $A_z=0$이 되는 것은 존재하지 않는다는 것이 보장됩니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ K$
```

## 제한

- $1 \leq N \leq 3 \times 10^6$
- $1 \leq K \leq 10^{18}$
- 입력되는 값은 모두 정수입니다.

## 출력

$A_K$의 값을 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
6 1
```

#### 출력

```text
6
```

$A_1=6$입니다.

### 예제 2 {file=""}

#### 입력

```text
6 2
```

#### 출력

```text
12
```

$A_1=6$이고, $A_2=f(6)=(1+2+3+6) \bmod 100\,003=12$가 됩니다.

### 예제 3 {file=""}

#### 입력

```text
6 3
```

#### 출력

```text
28
```

$A_3=f(A_2)=f(12)=(1+2+3+4+6+12) \bmod 100\,003=28$이 됩니다.
