## 문제

유키 왕국에서 코딩 전쟁이 일어났습니다. 공격자는 문제를 제출하고, 방어자 측의 모든 프로그래머는 적어도 하나의 문제를 담당해야 합니다. 또한 모든 문제에는 적어도 한 명의 담당자가 있어야 하며, 각 프로그래머는 정확히 하나의 문제만 담당할 수 있습니다. 담당하지 않은 문제에 대해서는 조언할 수도 없습니다. 하나의 문제를 여러 프로그래머가 담당해도 됩니다.

공격자가 제출한 문제가 방어자 측 프로그래머 수보다 많으면 반칙으로 공격자의 자동 패배가 됩니다. 이 경우의 방법 수는 0가지입니다. 방어자 측 프로그래머가 N명이고 공격자가 제출한 문제가 M개일 때, 조건을 만족하는 담당 방법의 수를 구하세요. 답은 $1{,}000{,}000{,}007$로 나눈 나머지를 출력하세요.

### 제약 조건

- $1 le N le 10^{12}$
- $1 le M le 10^5$

### 입력

입력은 다음 형식으로 주어집니다.

```text
N M
```

### 출력

조건을 만족하는 방법의 수를 한 줄에 출력하세요.

### 샘플 1 {file="sample1.in"}

```text
3 3
```

### 샘플 1 출력 {file="sample1.out"}

```text
6
```

### 샘플 2 {file="sample2.in"}

```text
7 3
```

### 샘플 2 출력 {file="sample2.out"}

```text
1806
```

### 샘플 3 {file="sample3.in"}

```text
100 1
```

### 샘플 3 출력 {file="sample3.out"}

```text
1
```

### 샘플 4 {file="sample4.in"}

```text
1000000000000 3
```

### 샘플 4 출력 {file="sample4.out"}

```text
692089859
```
