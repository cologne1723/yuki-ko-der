## 문제 설명

yuki국에는 $1, 2, \ldots, N$번 도시 $N$개와 $1, 2, \ldots, M$번 도로 $M$개가 있습니다. 도로 $i$ ($1 \le i \le M$)는 도시 $a_i$와 도시 $b_i$를 연결합니다. $c_i=1$일 때 도로 $i$는 양방향으로 통행할 수 있고, $c_i=2$일 때 도로 $i$는 도시 $a_i$에서 도시 $b_i$ 방향으로만 통행할 수 있습니다.

락스크 군은 어떤 도시에서 출발하여 도로를 통해 몇 개의 도시를 방문한 다음 원래 도시로 돌아오는 관광 계획을 세우려고 합니다. 이때 출발점을 제외한 도시를 $1$개 이상 방문해야 하며, 종점 이외의 도시를 두 번 방문하거나 같은 도로를 두 번 통과하지 않도록 하려고 합니다. 이것이 가능한지 판정하세요.

## 입력

```text
N M
a_1 b_1 c_1
a_2 b_2 c_2
:
a_M b_M c_M
```

첫째 줄에 도시의 수 $N$과 도로의 수 $M$이 주어집니다.

그다음 $M$개 줄의 $i$번째 줄에 도로 $i$의 정보 $a_i$, $b_i$, $c_i$가 주어집니다.

## 제한

- $2 \le N \le 10^5$
- $1 \le M \le 2 \times 10^5$
- $1 \le a_i, b_i \le N$
- $1 \le c_i \le 2$
- $a_i \ne b_i$
- $c_i=1$일 때 $a_i < b_i$
- $i \ne j$일 때 $(a_i, b_i, c_i) \ne (a_j, b_j, c_j)$
- 입력은 모두 정수입니다.

## 출력

어떤 도시에서 출발하여 같은 도시를 두 번 방문하거나 같은 도로를 두 번 통과하지 않고 원래 도시로 돌아올 수 있다면 `Yes`를, 불가능하다면 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 4
1 3 1
2 4 2
2 3 1
4 3 2
```

#### 출력

```text
Yes
```

도시 $2$에서 출발하여 도로 $2$, $4$, $3$을 지나 도시 $2 \to 4 \to 3 \to 2$로 이동하면 됩니다.


#### 출력

```text
No
```

#### 출력

```text
Yes
```
