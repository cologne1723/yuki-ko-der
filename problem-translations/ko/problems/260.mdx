## 문제

어떤 개그맨은 3의 배수 또는 숫자에 3이 들어간 수일 때 ‘바보’가 되고, 8의 배수일 때 ‘청춘’한다고 합니다.

$A$ 이상 $B$ 이하의 정수 중 ‘바보’이면서 ‘청춘’하지 않는 수의 개수를 $10^9+7$로 나눈 나머지를 구하세요.

## 입력

```text
A B
```

모든 입력은 정수입니다.

- $1 \leq A \leq 10^{10000}$
- $A \leq B \leq 10^{10000}$

## 출력

$A$ 이상 $B$ 이하의 정수 중 조건을 만족하는 수의 개수를 $10^9+7$로 나눈 나머지를 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

```text
1 100
```

### 출력 1 {file="stdout"}

```text
40
```

### 입력 2 {file="stdin"}

```text
114 514
```

### 출력 2 {file="stdout"}

```text
211
```

### 입력 3 {file="stdin"}

```text
1234 567890
```

### 출력 3 {file="stdout"}

```text
339733
```
