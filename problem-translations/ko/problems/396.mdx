## 문제

올해도 반을 바꿀 시기가 왔습니다. 사립 유키 고등학교에서는 매년 다음 알고리즘으로 N명의 학생을 M개의 반에 배정합니다.

1. 학생을 성적순으로, 즉 1등, 2등, 3등, ..., N등의 순서로 나열합니다.
2. 줄의 앞에서부터 학생 M명을 차례로 1반, 2반, ..., M-1반, M반에 배정하고 줄에서 제외합니다. 도중에 줄의 마지막에 도달하면 그 시점에 종료합니다.
3. 이어서 학생 M명을 차례로 M반, M-1반, ..., 2반, 1반에 배정하고 줄에서 제외합니다. 도중에 줄의 마지막에 도달하면 그 시점에 종료합니다.
4. 2번으로 돌아갑니다.

유키 고등학교 학생 하나코의 올해 성적은 N명 중 X등입니다. 하나코가 좋아하는 타로의 성적은 N명 중 Y등입니다.

두 사람이 다음 학년에 같은 반이 될 수 있는지 판정하세요. 같은 반이 될 수 있으면 `YES`, 될 수 없으면 `NO`를 출력하세요. 성적순에서 같은 등수를 가진 학생 조합은 없습니다.

## 입력

첫째 줄에 학생 수 N과 반 수 M이 주어집니다. 둘째 줄에 하나코의 성적 순위 X와 타로의 성적 순위 Y가 주어집니다.

```text
N M
X Y
```

입력은 모두 정수이며 다음 제약을 만족합니다.

- 2 ≤ N ≤ 10^9
- 1 ≤ M ≤ 10^9
- 1 ≤ X ≤ N
- 1 ≤ Y ≤ N
- X ≠ Y

## 출력

같은 반이 될 수 있으면 `YES`, 될 수 없으면 `NO`를 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
10 4
4 5
```

### 샘플 1 출력 {file="sample1.out"}

```text
YES
```

축하합니다! 하나코와 타로는 다음 학년에도 같은 4반입니다!

### 샘플 2 {file="sample2.in"}

```text
50 40
50 1
```

### 샘플 2 출력 {file="sample2.out"}

```text
NO
```

아쉽게도 하나코는 31반, 타로는 1반입니다.

### 샘플 3 {file="sample3.in"}

```text
150 7
63 35
```

### 샘플 3 출력 {file="sample3.out"}

```text
YES
```
