## 문제

1행 N열의 아직 색칠하지 않은 칸이 있습니다.

다음 규칙에 따라 색칠합니다.

* 빨강, 초록, 파랑으로 각각 지정된 수만큼 칸을 칠합니다.
* 빈칸이 남아도 됩니다. 빈칸은 색칠한 칸으로 세지 않습니다.
* 같은 색을 각 열에서 서로 인접한 두 칸에 칠할 수 없습니다.
* 다른 색이라면 연속한 두 칸까지 인접하게 칠할 수 있습니다.
* 연속한 3칸 이상을 색칠할 수 없습니다.

위 규칙에 따른 색칠 방법의 수를 1000000007로 나눈 나머지를 구하세요.

## 입력

```text
N R G B
```

N,R,G,B는 정수입니다. 1 ≤ N ≤ 3000, 0 ≤ R,G,B ≤ 3000

N은 칸의 열 수이고, R,G,B는 각각 빨강, 초록, 파랑으로 칠할 칸의 수입니다.

## 출력

답을 한 줄에 출력하세요. 가능한 색칠 방법이 없으면 0입니다.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
5 2 0 2
```

출력:

```text
4
```

왼쪽부터 빨강, 파랑, 빈칸, 빨강, 파랑; 빨강, 파랑, 빈칸, 파랑, 빨강; 파랑, 빨강, 빈칸, 빨강, 파랑; 파랑, 빨강, 빈칸, 파랑, 빨강의 4가지입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
3 2 0 0
```

출력:

```text
1
```

왼쪽부터 빨강, 빈칸, 빨강 한 가지뿐입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
7 0 1 0
```

출력:

```text
7
```

7칸 중 하나를 초록색으로 칠하므로 7가지입니다.

### 샘플 4 {file="sample4.in"}

입력:

```text
3 1 1 1
```

출력:

```text
0
```

빨강, 초록, 파랑을 하나씩 칠해야 하지만 연속한 3칸 이상을 칠할 수 없으므로 방법이 없습니다.

### 샘플 5 {file="sample5.in"}

입력:

```text
6 2 1 1
```

출력:

```text
54
```

### 샘플 6 {file="sample6.in"}

입력:

```text
300 10 20 0
```

출력:

```text
470935914
```

답은 1000000007로 나눈 나머지이므로 주의하세요.
