## 문제 설명

$N$개의 정점으로 이루어진 트리 $T$가 있습니다. 정점에는 $1$부터 $N$까지의 번호가 붙어 있습니다.

$1 \leq i \leq N-1$에 대해, $i$번째 간선은 정점 $u_i$와 $v_i$를 연결하며 가중치는 $w_i$입니다.

$T$의 임의의 두 정점을 잇는 단순 경로 중, 경로에 포함된 간선 가중치의 합이 가장 큰 값을 출력하세요. 두 정점이 같은 경우 경로의 가중치 합은 $0$입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$u_1\ v_1\ w_1$
$\vdots$
$u_{N-1}\ v_{N-1}\ w_{N-1}$
```

첫 번째 줄에 정수 $N$이 주어집니다. 다음 $N-1$개의 줄에 간선의 양 끝점 $u_i$, $v_i$와 가중치 $w_i$가 주어집니다.

## 제한

- $2 \leq N \leq 2 \times 10^5$
- $1 \leq u_i, v_i \leq N$
- $|w_i| \leq 10^9$
- 주어지는 그래프는 트리입니다.
- 입력은 모두 정수입니다.

## 출력

답을 출력하세요.
