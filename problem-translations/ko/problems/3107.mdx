## 문제 설명

정수 $N$이 주어집니다. $N^2$을 구하세요.

## 입력

입력은 정수 $N$ 하나로 주어집니다.

```text
$N$
```

## 제한

- $1\leq N\leq 45$
- $N$은 정수입니다.

## 출력

답을 한 줄에 출력하세요.

#### 입력

```text
45
```

```text
2025
```
