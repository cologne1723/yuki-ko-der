처음 모두 0인 $n\times m$ 행렬 $B$에 행 전체 또는 열 전체에 어떤 값과 XOR하는 작업을 수행해 행렬 $A$를 만들 수 있는지 판정하세요. 가능하면 필요한 최소 작업 횟수를 구하세요. 행 작업의 값은 $R_i$ 이하, 열 작업의 값은 $C_j$ 이하입니다.

## 입력

```text
T
n m
R1 ... Rn
C1 ... Cm
A의 행렬
```

## 출력

가능하지 않으면 문제의 지정 형식에 따라 표시하고, 가능하면 최소 작업 횟수를 출력하세요.
