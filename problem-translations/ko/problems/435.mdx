## 참고

이 문제는 [점괘](http://yukicoder.me/problems/467)의 제약을 강화한 버전입니다. 숫자열 길이의 상한을 높이고 메모리 제한을 낮췄습니다. 또한 입력 형식이 다르므로 주의하세요. C++14, Java8, C#으로 정답 처리할 수 있음을 확인했습니다. PyPy3로 시도했을 때는 TLE와 MLE로 어려웠지만, 상당히 노력하면 정답 처리가 가능합니다.

## 문제

숫자를 사용하는 점괘를 알고 있나요? 숫자 0〜9로 이루어진 숫자열 S = {s₁,s₂,...,sₙ}에 다음 연산을 수행합니다.

1. 숫자열 S의 길이를 K라고 합니다. K = 1이면 종료합니다.
2. 이웃한 두 숫자 sᵢ, sᵢ₊₁ (1 ≤ i ≤ K − 1)의 합을 s′ᵢ로 정합니다.
3. s′ᵢ ≥ 10이면 십의 자리와 일의 자리를 더한 값으로 바꿉니다. (예를 들어 s′ᵢ = 13이면 s′ᵢ = 1 + 3 = 4로 바꿉니다.)
4. S를 {s′₁,s′₂,...,s′ₖ₋₁}로 바꿉니다.
5. 1번으로 돌아갑니다.

이 연산으로 얻은 하나의 숫자로 운세를 알 수 있습니다. 예를 들어 S = {3,5,8,2}는 {8,4,1}, {3,5}, {8}로 변하므로 최종 숫자는 8입니다.

숫자열 S가 주어질 때 점괘 결과를 구하세요.

단, 숫자열 S가 매우 길기 때문에 매개변수 (n,x,a,b,m)를 바탕으로 다음 방법으로 생성됩니다.

- r₁ = x
- rᵢ = ((rᵢ₋₁ XOR a) + b) mod m (2 ≤ i ≤ n)
- S = {r₁ mod 10, r₂ mod 10, ..., rₙ mod 10}

여기서 XOR는 배타적 논리합 연산자입니다.

## 입력

첫째 줄에 테스트 케이스 수 T가 주어집니다. 각 테스트 케이스는 한 줄에 5개의 매개변수 nᵢ, xᵢ, aᵢ, bᵢ, mᵢ로 이루어집니다. nᵢ은 숫자열 Sᵢ의 길이이고, 나머지 매개변수는 숫자열 Sᵢ를 생성하는 데 사용됩니다.

```text
T
n₁ x₁ a₁ b₁ m₁
n₂ x₂ a₂ b₂ m₂
⋮
n_T x_T a_T b_T m_T
```

- 1 ≤ T ≤ 10^5
- 1 ≤ nᵢ ≤ 10^7
- Σnᵢ ≤ 10^7
- 0 ≤ xᵢ,aᵢ,bᵢ ≤ 10^9
- 1 ≤ mᵢ ≤ 10^9

## 출력

각 테스트 케이스의 숫자열 Sᵢ에 대한 점괘 결과를 한 줄에 출력하세요.
