## 문제

$5 \times 5$칸이 그려진 카드를 사용해 빙고 게임을 합니다. 카드의 25칸에는 1부터 99까지의 숫자 중 25개가 중복 없이 쓰여 있습니다. 세로, 가로 또는 대각선으로 숫자 5개가 한 줄로 모이면 빙고 1개입니다.

A 군은 숫자가 무작위로 적힌 빙고 카드를 받았습니다. 이제 1부터 99까지의 숫자 중 $N$개가 중복 없이 무작위로 불립니다. $N$개의 숫자가 불린 뒤 만들어지는 빙고 개수의 기대값을 구하세요.

## 입력

```text
N
```

불릴 숫자의 개수 $N$이 주어집니다.

- $N$은 정수입니다.
- $1 \leq N \leq 99$

## 출력

만들어지는 빙고 개수의 기대값을 한 줄에 출력하세요. 허용 오차는 $10^{-6}$입니다. 마지막에 개행을 넣으세요.

## 샘플

### 입력 1 {file="stdin"}

```text
4
```

### 출력 1 {file="stdout"}

```text
0
```

숫자가 4개만 불리면 빙고는 하나도 만들 수 없습니다.

### 입력 2 {file="stdin"}

```text
62
```

### 출력 2 {file="stdout"}

```text
1.0856908639251
```

숫자가 62개 불려야 기대값이 겨우 1을 넘습니다.

### 입력 3 {file="stdin"}

```text
99
```

### 출력 3 {file="stdout"}

```text
12
```

모든 숫자가 불리면 세로, 가로, 대각선이 모두 빙고가 됩니다.
