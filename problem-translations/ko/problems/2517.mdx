원 위의 점 $P_i=(\cos(2\pi A_i/M),\sin(2\pi A_i/M))$가 주어집니다. $i<j<k$인 세 점이 직각삼각형을 이루는 조합의 수를 구하세요.

## 조건

- $3\le N\le3\times10^5$, $N\le M\le10^9$
- $A_i$는 서로 다릅니다.

## 입력

```text
N M
A1 A2 ... AN
```

## 출력

답을 출력하세요.
