## 문제 설명

소수 $P$와 자연수 $N$이 주어집니다.

제$1$항부터 제$P - 1$항까지 $P - 1$개의 항으로 이루어진 수열 $A$에서 $i$번째 항의 값을 다음과 같이 정의합니다.

$A_i = (i \times N) \% P$

단, 양의 정수 $x$, $y$에 대해 $x \% y$는 $x$를 $y$로 나눈 나머지를 나타냅니다.

$P$ 미만인 양의 정수의 순서쌍 $(i, j)$ 중 $i < j$이고 $A_i > A_j$를 만족하는 것의 개수를 $2$로 나눈 나머지를 구하세요.

## 입력

```text
$P \; N$
```

## 제한

- $2 \le P \le 2^{31} - 1$
- $1 \le N \le P - 1$
- $P$는 소수입니다.
- 입력은 모두 정수입니다.

## 출력

답을 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 1
```

#### 출력

```text
0
```

### 예제 2 {file=""}

#### 입력

```text
7 3
```

#### 출력

```text
1
```
