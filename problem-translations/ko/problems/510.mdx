## 문제

점화식으로 정의된 수열 ai, bi (0 ≤ i ≤ n)가 있습니다.

ai+1 = xi × bi^2 + ai

bi+1 = yi × bi + 1

a0 = b0 = 1

xi, yi (0 ≤ i < n)는 2n개의 점화식 매개변수입니다. 이들의 초기값은 0입니다.

다음 q개의 쿼리를 처리하세요.

(1) x i v: xi를 v로 변경합니다.

(2) y i v: yi를 v로 변경합니다.

(3) a i: ai를 10^9+7로 나눈 나머지를 출력합니다.

## 입력

```text
n
q
query1
…
queryq
```

모든 입력은 정수입니다.

1 ≤ n ≤ 100000

1 ≤ q ≤ 20000

쿼리 x:

x i v

0 ≤ i < n

0 ≤ v ≤ 100000

쿼리 y:

y i v

0 ≤ i < n

0 ≤ v ≤ 100000

쿼리 a:

a i

0 ≤ i ≤ n

쿼리 a는 적어도 하나 주어집니다.

## 출력

각 쿼리 a를 처리할 때마다 줄바꿈하여 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
2
7
a 2
x 1 1
y 0 3
y 1 2
a 2
y 0 0
a 2
```

출력:

```text
1
17
2
```

첫 번째 쿼리 a에서 a0 = 1, a1 = 1, a2 = 1, b0 = 1, b1 = 1, b2 = 1입니다.

두 번째 쿼리 a에서 a0 = 1, a1 = 1, a2 = 17, b0 = 1, b1 = 4, b2 = 9입니다.

세 번째 쿼리 a에서 a0 = 1, a1 = 1, a2 = 2, b0 = 1, b1 = 1, b2 = 3입니다.
