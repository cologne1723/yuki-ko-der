가치가 `W_i`인 동전 종류 `N`개가 각각 매우 많이 있습니다. 동전을 하나 이상 골라 만들 수 있는 `1` 이상 `L` 이하의 서로 다른 금액 개수를 구하세요. 같은 종류를 여러 개 골라도 됩니다.

## 제약

- `1 <= N <= 20`
- `1 <= L <= 10^12`
- `1 <= W_i <= 10^6`이며 서로 다릅니다.

## 입력

`N L`과 동전 가치 `W`가 주어집니다.

## 출력

가능한 금액의 개수를 출력하세요.
