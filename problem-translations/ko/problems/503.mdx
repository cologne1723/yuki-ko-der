## 문제

MAK의 취미는 배열 모으기입니다.

MAK는 매일 배열장이라는 장소에 가서 배열을 찾으며 시간을 보냅니다. 배열장에서 얻을 수 있는 배열은 모두 길이가 N이고, 모든 원소의 값이 1입니다. MAK는 길이가 K보다 작은 배열만 운반할 수 있으므로, 배열장에서 얻은 배열의 길이가 K보다 작아질 때까지 다음 조작을 수행합니다. 조작 전 배열을 A라고 하고, 배열 A의 i번째 원소 값을 Ai로 나타내며 배열의 인덱스는 1부터 셉니다.

* A에서 길이 K인 연속 부분 배열 B를 제거하고, 제거한 부분에 새로운 값 x = D × B1 × B2 × ... × BK를 삽입합니다.

예를 들어 A = {2,2,1,3,1}, K = 3, D = 2일 때 구간 2 ≤ i ≤ 4에 대해 조작하면 A = {2,12,1}이 되고, 구간 3 ≤ i ≤ 5에 대해 조작하면 A = {2,2,6}이 됩니다.

길이가 K보다 작아져 운반할 수 있게 된 배열은 MAK의 배열 컬렉션(Array Collection, 줄여서 AC)에 보관됩니다. 그러나 MAK는 새로운 것만 좋아하므로, 각 원소가 모두 같은 배열이 이미 배열 컬렉션에 보관되어 있다면 운반한 배열을 팔아 용돈으로 바꿉니다. MAK는 배열을 여러 번 모았고, 얻을 수 있는 배열을 모두 모았습니다.

배열 컬렉션에 보관된 모든 배열의 원소 합, 즉 배열 컬렉션에 보관된 배열의 집합을 S, 배열의 길이를 L이라 할 때 sum(A in S) sum(i=1 to L) Ai의 값을 구하세요. 이 값은 매우 커질 수 있으므로 1,000,000,007 = 10^9+7로 나눈 나머지를 출력하세요.

## 입력

```text
N K D
```

2 ≤ N ≤ 10^6, 2 ≤ K ≤ N, 1 ≤ D ≤ 10^6

N, K, D는 정수입니다.

## 출력

배열 컬렉션에 보관된 모든 배열의 원소 합을 1,000,000,007로 나눈 나머지를 출력하세요. 출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
8 4 2
```

출력:

```text
14
```

MAK가 가진 배열 컬렉션은 {1,4}, {2,2}, {4,1}의 3개이며, 출력할 값은 1+4+2+2+4+1=14입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
8 4 1
```

출력:

```text
2
```

MAK가 가진 배열 컬렉션은 {1,1} 하나뿐입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
12345 67 89
```

출력:

```text
967411319
```

출력할 값은 1,000,000,007로 나눈 나머지임에 주의하세요.
