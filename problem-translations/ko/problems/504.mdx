## 문제

K는 게임 대회에 참가했습니다.

이 게임은 가능한 한 높은 점수를 목표로 하는 게임입니다.

K를 포함해 N명이 참가합니다.

차례로 한 번씩 플레이하며 그때마다 랭킹이 갱신됩니다.

K가 가장 먼저 플레이합니다.

각 사람이 플레이를 끝냈을 때 K가 몇 위인지 구하세요.

점수가 높은 사람의 순위가 더 높습니다. 동점이면 먼저 플레이한 사람의 순위가 더 높습니다.

## 입력

```text
N
a0
a1
...
aN-1
```

첫 번째 줄에 N이 주어집니다.

두 번째 줄부터 각 사람의 점수 ai가 주어집니다. a0이 K의 점수입니다.

모든 입력은 정수입니다.

1 ≤ N ≤ 10^5

1 ≤ ai ≤ 10^9

## 출력

각 시점의 K 순위를 N줄에 걸쳐 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3
2
3
1
```

출력:

```text
1
2
2
```

### 샘플 2 {file="sample2.in"}

입력:

```text
6
1
1
4
5
1
4
```

출력:

```text
1
1
2
3
3
4
```
