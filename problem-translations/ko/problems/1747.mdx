`1`부터 `9`로 이루어진 문자열 `S`의 인접한 문자 사이에 `+`를 원하는 만큼 삽입할 수 있습니다. 연속된 `+`는 허용하지 않습니다.

완성된 문자열을 식으로 계산했을 때 값이 소수가 되는 경우의 수를 구하세요.

## 제약

- `1 <= |S| <= 10`
- `S`는 `1`부터 `9`로만 이루어집니다.

## 입력

문자열 `S`가 주어집니다.

## 출력

조건을 만족하는 식의 개수를 출력하세요.
