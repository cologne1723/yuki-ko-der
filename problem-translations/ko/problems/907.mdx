## 문제

파란 별 $x$개와 빨간 별 $y$개가 있고, 각 간선은 파란 별과 빨간 별을 잇습니다. 모든 별은 적어도 하나의 별과 인접하며, 같은 두 별 사이에 여러 간선이 있을 수 있습니다.

적어도 $\lceil(x+y)/2\rceil$개의 별을 포함하면서, 집합에 속한 임의의 파란 별에 대해 인접하면서 집합에 속한 빨간 별의 수가 홀수가 되도록 하는 집합 하나를 출력하세요. 그런 집합은 반드시 존재합니다.

## 제약

- 모든 테스트 케이스에서 $x+y+m$의 합은 $10^5$ 이하입니다.
- $x,y,m\geq1$

## 입력

~~~text
T
x y m
u_1 v_1
⋮
u_m v_m
~~~

## 출력

각 테스트 케이스에서 선택한 파란 별 번호와 빨간 별 번호를 다음 형식으로 출력하세요.

~~~text
k_1 k_2
a_1 ... a_{k_1}
b_1 ... b_{k_2}
~~~
