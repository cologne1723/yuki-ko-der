## 문제 설명

다음 방법으로 길이가 $N$인 **실수** 수열 $a_1, \ldots, a_N$을 만들 때, 만들어진 수열이 카도마츠 수열일 확률을 구하세요.

- $A_i$ 이상 $B_i$ 이하인 **실수**를 균등하게 무작위로 골라 $a_i$로 정합니다. $1 \le i \le N$입니다.

수열 $a_1, \ldots, a_N$이 카도마츠 수열이라는 것은 $a_1 \le a_2 \ge a_3 \le a_4 \ge a_5 \le \cdots$를 만족한다는 뜻입니다.
즉, 모든 $1 \le i \le N-1$에 대해 다음이 성립해야 합니다.

- $i$가 홀수이면 $a_i \le a_{i+1}$입니다.
- $i$가 짝수이면 $a_i \ge a_{i+1}$입니다.

만드는 수열은 정수 수열이 아니라 **실수 수열**이라는 점에 주의하세요.

## 입력

```text
$N$
$A_1\ B_1$
$\vdots$
$A_N\ B_N$
```

입력은 모두 정수입니다.

## 제한

- $3 \le N \le 200$
- $1 \le A_i < B_i \le 10^9$이며 $1 \le i \le N$입니다.

## 출력

답은 기약분수 $p/q$로 나타낼 수 있으므로, $p\,q^{-1} \bmod{10^9+7}$을 출력하세요.
즉, $xq \equiv p \pmod{10^9+7}$을 만족하는 가장 작은 음이 아닌 정수 $x$를 출력하세요.
이 문제에서는 이 값이 항상 존재합니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 3
1 3
1 3
```

#### 출력

```text
333333336
```

답은 $1/3$입니다.
이는 실수 $3$개를 무작위로 생성했을 때 두 번째 값이 최댓값일 확률과 같으며, 대칭성에 의해 $1/3$입니다.
만드는 수열은 정수 수열이 아니라 **실수 수열**이라는 점에 주의하세요.

### 예제 2 {file=""}

#### 입력

```text
3
1 2
2 3
1 2
```

#### 출력

```text
1
```

답은 $1/1$입니다.

### 예제 3 {file=""}

#### 입력

```text
3
2 3
1 2
2 3
```

#### 출력

```text
0
```

답은 $0/1$입니다. 가능한 카도마츠 수열은 $2, 2, 2$뿐이지만, 이 수열이 나올 확률은 $0$입니다.
