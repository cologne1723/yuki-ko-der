## 문제 설명

영어 대문자로만 이루어진 문자열 $S$가 주어집니다. $S$와 길이가 같고, 모든 문자가 $S$의 $1$번째 문자와 같은 문자열을 출력하세요.

## 입력

```text
$S$
```

## 제한

- $S$는 길이가 $1$ 이상 $100$ 이하인 문자열입니다.
- $S$에는 영어 대문자만 들어 있습니다.

## 출력

조건을 만족하는 문자열을 출력하세요.

답 이외에는 아무것도 출력하지 마세요. 입력을 요청하는 문장 등도 출력하지 마세요.

답안 형식은 연습 문제나 그 답안 예시를 참고해도 되지만, 링크는 제공하지 않는다는 점에 주의하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
SUKEN
```

#### 출력

```text
SSSSS
```


### 예제 2 {file=""}

#### 입력

```text
A
```

#### 출력

```text
A
```


### 예제 3 {file=""}

#### 입력

```text
JAPANESEOLYMPIADININFORMATICS
```

#### 출력

```text
JJJJJJJJJJJJJJJJJJJJJJJJJJJJJ
```
