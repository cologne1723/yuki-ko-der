## 문제

$1$ 이상 $10^N$ 이하의 정수 중 7의 배수인 수의 비율을 구하세요.

## 입력

~~~text
$N$
~~~

$0\leq N\leq10^5$입니다.

## 출력

정답을 1줄에 출력하고 마지막에는 줄바꿈을 추가하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
0
~~~

#### 출력

~~~text
0
~~~

1 이상 $10^0=1$ 이하에는 7의 배수가 0개이므로 비율은 $\frac01=0$입니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
4
~~~

#### 출력

~~~text
0.1428
~~~

1 이상 $10^4=10000$ 이하에는 7의 배수가 1428개이므로 비율은 $\frac{1428}{10000}=0.1428$입니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
100
~~~

#### 출력

~~~text
0.1428571428571428571428571428571428571428571428571428571428571428571428571428571428571428571428571428
~~~

7의 배수의 비율은 $0.142857142857\ldots$입니다.
