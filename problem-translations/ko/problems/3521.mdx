**이 문제는 상호작용 형식(채점 프로그램과 상호작용하며 실행해야 하는 형식)의 문제입니다.**

상호작용 형식의 문제에 익숙하지 않다면 [상호작용 형식 문제에 대한 정리](https://yukicoder.me/wiki/reactive)도 참고하세요.

## 문제 설명

처음에 음이 아닌 정수 $D$가 주어집니다.

**接線大好きbot**은 **접선**을 아주 좋아하는 봇입니다.

**接線大好きbot**은 영다항식이 아닌 $D$차 음이 아닌 정수 계수 다항식 $f(x)$를 숨겨 가지고 있으며, 등식 $y=f(x)$가 정하는 $xy$ 평면 위의 곡선을 $C$라고 합니다.

**接線大好きbot**은 곡선 $C$의 **접선**의 기울기로 가능할 수 있는 정수 $1$개를 알고 싶어 합니다.

따라서 다음과 같은 상호작용(이하 질문이라고 합니다)을 $0$회 이상 $10$회 이하의 원하는 횟수만큼 수행합니다.

1. 먼저 조건 $0\leq n\leq 10^2$를 만족하는 정수 $n$을 $1$개 선택하고, $f(x)$의 $n$에서의 값 $f(n)$을 질문합니다.
2. 이어서 **接線大好きbot**이 $f(n)$을 대답합니다.

그 후 음이 아닌 실수 $x_0$를 조건 $0\leq x_0\leq 10^2$ 아래에서 움직였을 때 곡선 $C$의 점 $(x_0,f(x_0))$에서의 **접선**의 기울기 $f'(x_0)$로 가능할 수 있는 정수가 존재하는지 판정하고, 존재한다면 그러한 정수 $1$개를 구하세요.

## 입력

먼저 $D$가 표준 입력으로 $1$줄에 주어집니다.

```text
$D$
```

그 후 $0$회 이상 $10$회 이하의 원하는 횟수만큼 질문하세요. 각 질문은 표준 입출력을 사용해 다음 형식으로 수행합니다.

1. 먼저 조건 $0\leq n\leq 10^2$를 만족하는 정수 $n$을 `?`와 반각 공백으로 구분해 $1$줄에 출력하세요.

```text
$?\ n$
```

2. 이어서 $f(n)$의 값이 $1$줄에 주어집니다.

```text
$f(n)$
```

## 제한

입력으로 주어지지는 않지만, $f(x)$는 다음을 만족합니다.

- $f(x)$는 영다항식이 아닌 $D$차 음이 아닌 정수 계수 다항식으로 모든 질문 전에 고정되어 있으며, 즉 질문 전후로 변하지 않습니다.
- $D$ 이하의 임의의 음이 아닌 정수 $d$에 대해 $f(x)$의 $d$차 계수 $f_d$는 다음을 만족하는 정수입니다.
  - $d<D$이면 $0\leq f_d<10^2$입니다.
  - $d=D$이면 $0<f_d<10^2$입니다.

입력은 다음 제한을 만족합니다.

- $D$는 $0\leq D<10^2$를 만족하는 정수입니다.
- 조건 $0\leq n\leq 10^2$를 만족하는 임의의 정수 $n$에 대해, $f(x)$의 $n$에서의 값을 질문했을 때 답으로 주어지는 입력 $f(n)$은 $0\leq f(n)<10^{2(D+1)}$를 만족하는 정수입니다.

또한 $D=99$일 때 $f(10^2)$의 상한은 $10^{200}-1$이며, $64$비트 정수에 들어가지 않는다는 점에 주의하세요.

## 출력

이 문제에 대한 답을 표준 출력으로 다음 형식에 맞춰 출력하세요.

- 음이 아닌 실수 $x_0$를 조건 $0\leq x_0\leq 10^2$ 아래에서 움직였을 때 곡선 $C$의 점 $(x_0,f(x_0))$에서의 **접선**의 기울기 $f'(x_0)$로 가능할 수 있는 정수가 존재한다면, 그러한 값의 예를 $c$라고 하고 `!`과 $c$를 반각 공백으로 구분해 $1$줄에 출력하세요.

```text
$!\ c$
```

- 존재하지 않는다면 `!`과 `NaN`을 반각 공백으로 구분해 $1$줄에 출력하세요.

```text
! NaN
```

마지막에 개행을 출력하세요.

이 문제에서 다음 지시를 따르지 않은 제출의 채점 결과는 보장하지 않습니다.

- 출력은 지정된 형식을 엄격하게 지키세요. 예를 들어 불필요한 공백을 넣지 마세요.

출력할 때마다 끝에 개행을 넣고 표준 출력을 flush하세요. 이 문제에 대한 답을 출력한 뒤에는 프로그램을 즉시 종료하세요.

## 예제

다음은 $f(x)=1+x+2x^2$인 경우의 입출력 예입니다.

### 예제 1 {file=""}

#### 입력

```text
2
```

$D=2$가 입력으로 주어졌습니다. 이에 따라 $f(x)$가 $2$차라는 것이 확정됩니다.

#### 출력

```text
? 0
```

$f(0)$의 값을 질문했습니다.

#### 입력

```text
1
```

**接線大好きbot**은 $f(0)=1+0+2\cdot 0^2$가 $1$이라고 대답했습니다.

#### 출력

```text
? 1
```

$f(1)$의 값을 질문했습니다.

#### 입력

```text
4
```

**接線大好きbot**은 $f(1)=1+1+2\cdot 1^2$가 $4$라고 대답했습니다.

#### 출력

```text
? 2
```

$f(2)$의 값을 질문했습니다.

#### 입력

```text
11
```

**接線大好きbot**은 $f(2)=1+2+2\cdot 2^2$가 $11$이라고 대답했습니다.

#### 출력

```text
? 3
```

$f(3)$의 값을 질문했습니다.

#### 입력

```text
22
```

**接線大好きbot**은 $f(3)=1+3+2\cdot 3^2$가 $22$라고 대답했습니다.

#### 출력

```text
! 2
```

음이 아닌 실수 $x_0$를 조건 $0\leq x_0\leq 10^2$ 아래에서 움직였을 때 곡선 $C$의 점 $(x_0,f(x_0))$에서의 **접선**의 기울기 $f'(x_0)$로 가능할 수 있는 정수로 $2$를 대답했습니다. 실제로 $f'(x)=4x+1$이고, 예를 들어 $x_0=4^{-1}$로 정하면 $0\leq x_0\leq 10^2$이며 $f'(x_0)=2$가 성립합니다.
