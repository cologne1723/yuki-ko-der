※ 이 문제는 팝카운트와 합 (쉬움)과 제한이 다른 문제입니다.

## 문제 설명

음이 아닌 정수 $k$에 대하여, $k$를 이진수로 나타냈을 때 $1$의 개수를 $p(k)$로 정의합니다.

또한 함수 $f(a,b)$를 다음과 같이 정의합니다.

$f(a,b) = \left\{ \begin{array}{cc} a\ \&\ b & (p(a) = p(b)) \\ 0 & (\text{그 외}) \end{array} \right.$

여기서 $a\ \&\ b$는 $a$와 $b$의 비트 AND를 나타냅니다.

예를 들어 $3\ \&\ 5 = 1$이고, 이진수로 나타내면 $011_{(2)}\ \&\ 101_{(2)} = 001_{(2)}$입니다.

정수 $n$이 주어질 때, 다음 값을 $998\,244\,353$으로 나눈 나머지를 구하세요.

$\displaystyle\sum_{a=0}^{n}\sum_{b=a}^{n}f(a,b)$

## 입력

입력은 다음 형식으로 주어집니다.

```text
$n$
```

입력은 정수입니다.

## 제한

- $0 \leq n \leq 10^{18}$
- 입력은 정수입니다.

## 출력

답을 정수로 출력하세요.
