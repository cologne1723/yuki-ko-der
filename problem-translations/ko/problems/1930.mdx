비음이 아닌 정수 $L,R$이 주어집니다. $L\le i\le j\le R$이고 $i+j\le L+R$인 모든 $(i,j)$에 대해 $i+j$를 비트별 XOR한 값을 구하세요.

## 입력

```text
T
L R
```

$1\le T\le10^5$, $0\le L\le R<2^{50}$입니다.

## 출력

각 테스트 케이스의 답을 출력하세요.
