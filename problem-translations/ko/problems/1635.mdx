`1,2,...,N`을 재배열한 순열 `P` 중 다음 조건을 만족하는 것이 존재하는지 판정하고, 존재하면 하나 구성하세요.

`|P_1-P_2| + |P_2-P_3| + ... + |P_{N-1}-P_N| = K`

## 입력

`N K`가 주어집니다.

## 제약

- `2 <= N <= 10^6`
- `1 <= K <= 10^18`

## 출력

조건을 만족하는 순열이 없으면 `-1`을 출력하세요. 존재하면 순열 `P_1 P_2 ... P_N`을 출력하세요.
