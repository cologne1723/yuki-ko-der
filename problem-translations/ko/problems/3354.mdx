## 문제 설명

$2$개의 유리수 $P$, $Q$가 주어집니다.

$P$, $Q$의 대소를 판정하세요.

## 입력

입력은 표준 입력에서 다음 형식으로 $2$줄에 걸쳐 주어집니다.

```text
$N_1\ D_1$
$N_2\ D_2$
```

- $1$번째 줄에 $P=\frac{N_1}{D_1}$을 만족하는 정수 $N_1$과 양의 정수 $D_1$이 공백으로 구분되어 주어집니다.
- $2$번째 줄에 $Q=\frac{N_2}{D_2}$를 만족하는 정수 $N_2$와 양의 정수 $D_2$가 공백으로 구분되어 주어집니다.

## 제한

- $N_1$은 $-10^9\leq N_1\leq 10^9$를 만족하는 정수입니다.
- $D_1$은 $1\leq D_1\leq 10^9$를 만족하는 정수입니다.
- $N_2$는 $-10^9\leq N_2\leq 10^9$를 만족하는 정수입니다.
- $D_2$는 $1\leq D_2\leq 10^9$를 만족하는 정수입니다.

## 출력

$P<Q$이면 `<`를 출력하고, $P>Q$이면 `>`를 출력하며, $P=Q$이면 `=`를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0 1
0 2
```

#### 출력

```text
=
```

$P=\frac{0}{1}=\frac{0}{2}=Q$입니다.

### 예제 2 {file=""}

#### 입력

```text
-1 2
1 1
```

#### 출력

```text
<
```

$P=\frac{-1}{2}<\frac{1}{1}=Q$입니다.

### 예제 3 {file=""}

#### 입력

```text
-2 3
-3 2
```

#### 출력

```text
>
```

$P=\frac{-2}{3}>\frac{-3}{2}=Q$입니다.
