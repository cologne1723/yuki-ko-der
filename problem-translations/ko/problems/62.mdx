## 문제 설명

이 문제는 [리벨리온](http://yukicoder.me/problems/113)의 제약을 강화한 문제입니다.

마미와 호무라는 너비 $W$, 깊이 $H$인 직사각형 방 안에 있습니다.

호무라는 시간을 멈추고 최후의 한 발을 쏩니다. 시간이 멈춘 세계에서는 호무라와 총알만 움직일 수 있습니다. 총알은 벽에 부딪힐 때 입사각과 반사각이 같고 속도가 줄지 않으며, 영원히 날아갑니다.

마미의 위치 $(M_x,M_y)$, 호무라가 발사한 위치 $(H_x,H_y)$, 총알의 속도 $(V_x,V_y)$, 시간이 멈추는 시간 $D$가 주어집니다. 총알이 $D$초 이내에 마미에게 맞는지 판정하세요.

마미와 총알의 크기는 무시합니다. 호무라는 자신의 총알에 맞지 않습니다.

## 입력

첫째 줄에 질의 수 $Q$가 주어집니다. 이어지는 $Q$개 줄에 각 질의가 다음 형식으로 주어집니다.

```text
W H D M_x M_y H_x H_y V_x V_y
```

- $1 \le Q \le 10\,000$
- $2 \le W,H \le 1\,000\,000\,000$
- $1 \le D \le 1\,000\,000\,000$
- $0 < M_x,H_x < W$
- $0 < M_y,H_y < H$
- $-1\,000\,000\,000 \le V_x,V_y \le 1\,000\,000\,000$
- 마미와 호무라의 위치는 서로 다릅니다.
- $(V_x,V_y) \ne (0,0)$

모든 값은 정수입니다.

## 출력

각 질의에 대해 총알이 마미에게 맞으면 `Hit`, 맞지 않으면 `Miss`를 한 줄에 하나씩 출력하세요.
