## 문제 설명

다음 조건을 만족하는 수열 $X$를 시토시토토 수열이라고 정의합니다.

- $|X|=5$
- $X_1=X_3$
- $X_2=X_4=X_5$
- $X_1\neq X_2$

길이 $5N$인 양의 정수열 $(A_1,A_2,\ldots,A_{5N})$이 주어집니다. $A$를 $N$개의 연속하는 부분 수열로 분할하는 방법 중 모든 부분 수열이 시토시토토 수열이 되는 방법이 존재하는지 판정하세요.

$T$개의 테스트 케이스가 주어지므로, 모든 테스트 케이스에 대해 답하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$T$
$\text{case}_{1}$
$\text{case}_{2}$
$\vdots$
$\text{case}_{T}$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$A_1\ A_2\ \cdots\ A_{5N}$
```

## 제한

- $1\leq T\leq 10^5$
- $1\leq N\leq 10^5$
- 모든 테스트 케이스에서 $N$의 합은 $10^5$ 이하입니다.
- $1\leq A_i\leq 10^9$
- 입력은 모두 정수입니다.

이 문제에는 서브태스크에 의한 부분점이 설정되어 있습니다.

| 서브태스크 이름 | 배점 | 제한 |
| --- | ---: | --- |
| 서브태스크 $1$ | $10$% | $N=1$ |
| 서브태스크 $2$ | $20$% | $N=2$ |
| 서브태스크 $3$ | $70$% | 추가 제한 없음 |

## 출력

$T$줄 출력하세요.

$i$번째 줄에는 테스트 케이스 $i$에 대해 문제의 조건을 만족하는 방법이 존재하면 `Yes`를, 그렇지 않으면 `No`를 출력하세요.
