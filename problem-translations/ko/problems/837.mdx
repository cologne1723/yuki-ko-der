## 문제

점 $N$개가 주어지고 점 $i$의 높이는 $Y_i$입니다. Noel은 점의 높이를 자유롭게 바꿀 수 있습니다. 모든 점의 높이가 정확히 두 종류가 되도록 바꿀 때 필요한 거리 합의 최솟값을 구하세요. 각 점의 높이는 정수 거리만큼 바꿀 수 있습니다.

## 입력

~~~text
$N$
$Y_1\ Y_2\ \cdots\ Y_N$
~~~

$2\leq N\leq10^5$, $-10^9\leq Y_i\leq10^9$입니다.

## 출력

거리 합의 최솟값을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
5
1 3 4 6 6
~~~

#### 출력

~~~text
3
~~~

$Y_1,Y_2,Y_3$을 3으로, $Y_4,Y_5$를 6으로 바꾸면 거리 합은 3입니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
3
3 3 4
~~~

#### 출력

~~~text
0
~~~

바꿀 필요가 없습니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
3
3 3 3
~~~

#### 출력

~~~text
1
~~~

반드시 높이를 두 종류로 만들어야 하며 정수 거리만큼 바꿀 수 있으므로 최솟값은 1입니다.

### 샘플 4 {file="sample4.in"}

#### 입력

~~~text
10
-3 14 15 92 65 35 89 79 32 38
~~~

#### 출력

~~~text
116
~~~
