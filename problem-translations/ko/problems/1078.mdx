## 문제 설명

정수 $N$과 길이가 $N$인 배열 $S$, $T$, $U$가 주어집니다. 다음 조건을 만족하는 $N \times N$ 행렬 $a$를 하나 구성하세요.

- $a_{i,j}$는 $0$ 또는 $1$입니다.
- $1 \le i,j \le N$을 만족하는 모든 순서쌍 $(i,j)$에 대해 $a_{S_i,j}+a_{j,T_i} \times 2 \ne U_i$입니다.

조건을 만족하는 행렬이 존재하지 않을 수도 있습니다.

## 입력

```text
$N$
$S_1\ S_2\ \cdots\ S_N$
$T_1\ T_2\ \cdots\ T_N$
$U_1\ U_2\ \cdots\ U_N$
```

입력은 모두 정수입니다.

## 제한

$1 \le N \le 500$

$1 \le S_i,T_i \le N$

$0 \le U_i \le 3$

## 출력

조건을 만족하는 행렬이 존재한다면, 그러한 행렬 하나를 다음 형식으로 출력하세요.

```text
$a_{1,1} \cdots\ a_{1,N}$
$\vdots$
$a_{N,1} \cdots\ a_{N,N}$
```

조건을 만족하는 행렬이라면 무엇을 출력해도 된다는 점에 유의하세요.

조건을 만족하는 행렬이 존재하지 않는다면 `-1`을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
2 1 2
3 3 1
3 1 0
```

#### 출력

```text
0 0 0
1 0 1
0 0 0
```

예를 들어 $(i,j)=(1,2)$인 경우에는 $a_{2,2}+a_{2,3} \times 2=2 \ne 3$이므로 조건을 만족합니다.

### 예제 2 {file=""}

#### 입력

```text
4
4 4 3 3
2 1 1 2
1 0 0 3
```

#### 출력

```text
-1
```
