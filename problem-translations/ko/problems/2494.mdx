단순 무방향 그래프의 각 정점에 정수 $A_i$가 적혀 있습니다. 각 정점 $x$에 대해 $x$와 연결된 모든 정점의 값의 합을 구하고, 이 $N$개의 합의 곱을 $998244353$으로 나눈 나머지를 출력하세요.

## 조건

- $1\le N\le2\times10^5$
- $0\le M\le2\times10^5$
- $0\le A_i<998244353$

## 입력

```text
N M
A1 A2 ... AN
U1 V1
...
UM VM
```

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 1
3 1 2
1 2
```

#### 출력

```text
32
```

### 예제 2 {file=""}

#### 입력

```text
5 3
100 200 300 400 500
1 4
2 5
3 4
```

#### 출력

```text
230959687
```
