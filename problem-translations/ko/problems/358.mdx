## 문제 설명

$3$개의 원소로 이루어진 수열 $A_1,A_2,A_3$가 다음 $2$가지 조건을 만족하면 카도마츠 열이라고 합니다.

- $A_1,A_2,A_3$가 모두 다릅니다.
- $3$개의 원소 중 $A_2$가 가장 크거나 가장 작습니다.

$3$개의 원소 수열 $A=A_1,A_2,A_3$가 주어집니다. 수열 $A$와 양의 정수 $p$($1\le p$)로 결정되는 수열 $B_p$를 다음과 같이 정의합니다.

$B_p=(A_1\bmod p),(A_2\bmod p),(A_3\bmod p)$

여기서 $x\bmod y$는 $x$를 $y$로 나눈 나머지입니다.

$B_p$가 카도마츠 열이 되도록 하는 양의 정수 $p$의 개수를 출력하세요. 무한히 존재하면 `INF`를 출력하세요.

## 입력

```text
$A_1\ A_2\ A_3$
```

입력은 모두 정수입니다.

## 제한

$1\le A_i\le1\,000$

## 출력

$B_p$가 카도마츠 열이 되도록 하는 양의 정수 $p$의 개수를 출력하세요. 무한히 존재하면 `INF`를 출력합니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 6 7
```

#### 출력

```text
3
```

$B_3=2,0,1$, $B_6=5,0,1$, $B_7=5,6,0$이 카도마츠 열이므로 답은 $3$입니다.

### 예제 2 {file=""}

#### 입력

```text
5 1 4
```

#### 출력

```text
INF
```

어쩐지 무한히 존재하는 것 같습니다.


#### 출력

```text
16
```

### 예제 4 {file=""}


#### 출력

```text
0
```
