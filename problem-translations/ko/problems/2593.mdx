길이 $N$인 숫자 문자열 $S$를 재배열해 얻는 문자열을 양의 정수로 보았을 때, 이를 $120$으로 나눈 나머지로 가능한 값의 종류 수를 구하세요.

## 조건

- $1\le N\le200000$
- $S$는 숫자 `1`부터 `9`만으로 이루어집니다.

## 입력

```text
$N$
$S$
```

## 출력

가능한 나머지의 종류 수를 출력하세요.
