## 문제

3차원 공간의 점 `O=(0,0,0)`과 `P_1,P_2,P_3`가 주어집니다. `N`번의 턴 동안 현재 차례인 사람이 `j,k`를 골라 `P_j ← P_j + A_i P_k`로 바꿉니다. 턴 순서는 문자열 `S`에서 `K`면 코어, `P`면 파체입니다.

종료 후 네 점이 만드는 사면체의 부피 `V`를 구합니다. `V`가 양의 정수가 아니면 무승부, 양의 정수이고 `V mod 101 ≥ K`이면 코어 승리, 그 외에는 파체 승리입니다. 최선의 전략에서 결과를 판정하세요.

## 제약

- `1 ≤ T,N ≤ 10^4`, 모든 테스트 케이스의 `N` 합은 `10^4` 이하
- `1 ≤ K ≤ 100`, `1 ≤ A_i ≤ 99`
- 좌표는 `-10^6` 이상 `10^6` 이하입니다.

## 입력

```text
T
N K
p_{1,1} p_{1,2} p_{1,3}
p_{2,1} p_{2,2} p_{2,3}
p_{3,1} p_{3,2} p_{3,3}
A_1 ... A_N
S
```

## 출력

코어 승리면 `K`, 파체 승리면 `P`, 무승부면 `D`를 출력하세요.
