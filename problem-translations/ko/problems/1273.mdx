## 문제 설명

양의 정수 $x$가 주어집니다. 리만 제타 함수 $\zeta(n)=\displaystyle\sum_{i=1}^{\infty}1/i^n$에 대해

$\displaystyle\sum_{i=x}^{\infty}(\zeta(i)-1)$

에 $10^6$을 곱한 값을 소수점 이하 버림하여 출력하세요.

## 입력

```text
x
```

- $2\leq x\leq10^4$

## 출력

조건의 값을 계산해 소수점 이하를 버린 값을 출력하세요.
