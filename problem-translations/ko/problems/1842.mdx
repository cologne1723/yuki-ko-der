$A/B$의 소수점 이하 $C$번째 숫자를 구하세요. 한 입력 파일에 $T$개의 테스트 케이스가 주어집니다.

## 주의

표현 방법이 여러 가지인 경우 소수점 아래에 0이 무한히 이어지는 표현을 사용합니다.

## 입력

```text
T
A B C
... 
```

$1\le T\le10^5$, $1\le A,B,C\le10^9$이고 입력은 모두 정수입니다.

## 출력

각 테스트 케이스의 답을 출력하세요.
