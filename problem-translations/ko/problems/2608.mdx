$1$부터 $N$까지의 수를 파란색과 빨간색 두 그룹으로 나누어 두 그룹의 합이 같아지게 할 수 있는지 판정하고, 가능하면 한 가지 방법을 출력하세요.

## 조건

- $1\le T\le100$, $1\le N\le100$

## 입력

```text
$T$
$N$
```

## 출력

불가능하면 `-1`, 가능하면 길이 $N$의 문자열을 출력하세요. 왼쪽에서 $i$번째 문자가 `0`이면 파란색, `1`이면 빨간색입니다.
