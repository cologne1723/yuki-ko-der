## 문제

$X$개의 빈 상자와 충분한 담배가 있습니다. $N$번의 작업마다 담배 두 개를 원하는 상자에 넣습니다. 두 개를 같은 상자에 넣어도 되고, 서로 다른 두 상자에 하나씩 넣어도 됩니다.

배치의 좋음은 각 상자의 담배 수의 곱입니다. 매 작업 뒤 B는 좋음이 최소가 되도록 상자 하나를 골라 담배 한 개를 제거합니다. 선택지가 여러 개면 무작위로 고릅니다.

$X=1,2,\ldots,M$ 각각에 대해 A가 얻을 수 있는 최종 좋음의 최댓값을 $10^9+7$로 나눈 나머지를 출력하세요.

## 입력

$N,M$이 주어집니다.

- $1\leq M\leq N\leq2\times10^5$

## 출력

$M$줄에 답을 출력하세요.
