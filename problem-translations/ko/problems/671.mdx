## 문제

A군은 1000000007을 입력하려다 1과 7 사이의 0 개수를 잘못 입력했습니다. A군이 입력한 $N$이 주어질 때 1000000007과 0 개수가 몇 개 다른지 구하세요.

## 입력

문자열로 보았을 때 $N$은 1로 시작하고 7로 끝나며 그 사이는 모두 0입니다. $N$은 100 이상 $10^{15}$ 이하이고, 1000000007과 0 개수가 다릅니다.

## 출력

0 개수가 몇 개 다른지 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
100000007
```

출력:

```text
1
```

0이 하나 부족하므로 답은 1입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
100000000007
```

출력:

```text
2
```

0이 두 개 많으므로 답은 2입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
100000000000007
```

출력:

```text
5
```

$N$이 최댓값인 테스트 케이스입니다.
