## 문제 설명

원의 원주 위에 서로 독립적이고 균일하게 무작위로 점 $2$개를 찍고, 그 점들을 선분으로 잇는 작업을 $N$번 수행합니다. 이 $N$개의 선분으로 원의 내부가 분할되어 생기는 영역 개수의 기댓값을 법 $998\,244\,353$에서 구하세요.

기댓값은 이 문제의 제한 아래에서 반드시 유리수가 되며, $998\,244\,353$의 배수가 아닌 정수 $x$와 정수 $y$를 사용하여 $\frac{y}{x}$로 나타낼 수 있음이 보장됩니다.

이때 $xz \equiv y \pmod{998\,244\,353}$를 만족하는 $0$ 이상 $998\,244\,353$ 미만의 정수 $z$가 유일하게 존재하므로, 그 값을 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

$N$은 정수입니다.

## 제한

- $1 \le N \le 10^9$
- 입력은 모두 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
8
```

#### 출력

```text
332748136
```

$N=8$일 때 답은 $\dfrac{55}{3}$입니다.

### 예제 2 {file=""}

#### 입력

```text
1000000000
```

#### 출력

```text
952678484
```
