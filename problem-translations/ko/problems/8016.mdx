**주의**

> C++만을 대상으로 하는 문제입니다. 사정상 메모리 제한을 상당히 엄격하게 설정했으므로, 언어에 따라서는 아무것도 묻지 않고 MLE가 발생합니다($10$MB → $48$MB로 늘렸습니다. 이제 대부분 괜찮을 것이라고 생각합니다).

> 해시 함수를 독자적으로 정의한 코드를 (시스템 테스트에서) 떨어뜨리는 취지의 문제가 아닙니다.

양해 바랍니다.

## 문제 설명

정수 $N$개 $A_1, A_2, \cdots, A_N$과 정수 $M$개 $B_1, B_2, \cdots, B_M$이 주어집니다.

$A_1, A_2, \cdots, A_N$ 중 $B_i$와 같은 것의 개수를 $C_i$라고 합니다.

$C_1, C_2, \cdots, C_M$을 출력하세요.

## 입력

$1$번째 줄에 $N$과 $M$이 공백으로 구분되어 주어집니다.

$2$번째 줄에 $A_1, A_2, \cdots, A_N$이 공백으로 구분되어 주어집니다.

$3$번째 줄에 $B_1, B_2, \cdots, B_M$이 공백으로 구분되어 주어집니다.

```text
$N\ M$
$A_1\ A_2\ \cdots\ A_N$
$B_1\ B_2\ \cdots\ B_M$
```

입력은 모두 정수입니다.

## 제한

- $1 \leq N, M \leq 10^5$
- $0 \leq A_i \leq 10^{12}$ ($i = 1, 2, \cdots, N$)
- $0 \leq B_i \leq 10^{12}$ ($i = 1, 2, \cdots, M$)

## 출력

$C_1, C_2, \cdots, C_M$을 공백으로 구분하여 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 3
3 2 4 1
2 10 4
```

#### 출력

```text
1 0 1
```

### 예제 2 {file=""}

#### 입력

```text
3 5
1 1 1
1 1 1 1 1
```

#### 출력

```text
3 3 3 3 3
```

### 예제 3 {file=""}

#### 입력

```text
2 2
0 1000000000000
0 1000000000000
```

#### 출력

```text
1 1
```
