서로소인 양의 정수 $p,q$로 $u=p/q$를 나타내자냥. $1\le p(u)<q(u)$인 양의 유리수를 정점으로 하고, $u$에서 $(p(u)+1)/(q(u)+1)$로 향하는 간선을 만든 그래프를 생각하자냥. $r=(10^{100}-1)/10^{100}$을 포함하는 연결 요소는 트리이며, 그 트리를 루트 $r$로 보았을 때 두 정점의 최소 공통 조상을 구하라냥.

## 조건

- $1\le Q\le3000$
- 입력되는 분수의 분자와 분모는 서로소이고 $1\le p<q\le10^9$이다냥.

## 입력

```text
Q
p(u_1) q(u_1) p(v_1) q(v_1)
\vdots
```

## 출력

각 최소 공통 조상의 분자와 분모를 공백으로 구분해 출력하라냥.
