$\sum_{i=1}^N\sum_{j=1}^N A_i^{A_j}$를 구하라냥.

## 조건

- $1\le N\le2\times10^5$
- $1\le A_i\le8$

## 입력

```text
N
A_1 A_2 \cdots A_N
```

## 출력

답을 출력하라냥.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
1 2 3
```

#### 출력

```text
56
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1
3
```

#### 출력

```text
27
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
4
8 8 4 8
```

#### 출력

```text
151204096
```
