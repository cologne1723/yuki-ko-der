$\sum_{i=1}^N\sum_{j=1}^N A_i^{A_j}$를 구하라냥.

## 조건

- $1\le N\le2\times10^5$
- $1\le A_i\le8$

## 입력

```text
N
A_1 A_2 \cdots A_N
```

## 출력

답을 출력하라냥.
