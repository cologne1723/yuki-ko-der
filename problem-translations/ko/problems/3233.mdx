실행 시간 제한은 $1\,000$ms입니다.

## 문제 설명

$2$개의 양의 정수 $N$, $M$이 주어집니다.

다음 조건으로 유일하게 정해지는 길이 $N$의 정수열 $A$가 순열인지 판정하세요.

- $N$ 이하의 모든 양의 정수 $i$에 대해, $A$의 $i$번째 성분은 $i^M$을 $N$으로 나눈 나머지입니다.

여기서 $A$가 순열이라는 것은 $A$의 모든 성분이 서로 다르다는 뜻입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ M$
```

$1$번째 줄에 $N$, $M$이 공백으로 구분되어 주어집니다.

## 제한

- $1\leq N\leq 10^5$입니다.
- $1\leq M\leq 10^2$입니다.

## 출력

$A$가 순열이면 `Yes`를, 그렇지 않으면 `No`를 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1
```

#### 출력

```text
Yes
```

$A=(1^M\bmod N)=(1^1\bmod 1)=(0)$이고, $A$는 성분이 $1$개뿐입니다. 따라서 $A$는 순열입니다.

### 예제 2 {file=""}

#### 입력

```text
2 1
```

#### 출력

```text
Yes
```

$A=(1^M\bmod N,2^M\bmod N)=(1^1\bmod 2,2^1\bmod 2)=(1,0)$이고, $A$의 모든 성분이 서로 다릅니다. 따라서 $A$는 순열입니다.

### 예제 3 {file=""}

#### 입력

```text
3 2
```

#### 출력

```text
No
```

$A=(1^M\bmod N,2^M\bmod N,3^M\bmod N)=(1^2\bmod 3,2^2\bmod 3,3^2\bmod 3)=(1,1,0)$이고, $A$의 $1$번째 성분과 $2$번째 성분이 모두 $1$로 같습니다. 따라서 $A$는 순열이 아닙니다.
