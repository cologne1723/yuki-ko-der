## 문제

정점에 `1`부터 `N`까지 번호가 붙은 단순 연결 무방향 그래프의 수를 `f(N,M)`이라 합니다. 다음 값을 `10^9+7`로 나눈 나머지를 구하세요.

\[
\sum_M (-1)^M f(N,M)
\]

## 입력

정수 `N`이 주어집니다. 입력 파일은 매우 클 수 있습니다.

`N\ge2`입니다.

## 출력

위 값을 `10^9+7`로 나눈 나머지를 출력하세요.
