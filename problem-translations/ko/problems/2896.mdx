## 문제 설명

양의 정수 $n, m$에 대해, 다음 조건을 모두 만족하는 길이 $n$인 정수열 $a = (a_1, a_2, \cdots, a_n)$의 개수를 $f(n, m)$이라고 정의합니다.

- $2 \leq a_i$
- $\displaystyle \prod_{i = 1}^n a_i = m$
- $1 \leq i < j \leq n$일 때, $a_i$의 임의의 소인수 $p$와 $a_j$의 임의의 소인수 $q$에 대해 $p \leq q$입니다.

또한 양의 정수 $x$가 있고, 처음에 $x = 1$입니다.

다음과 같이 설명되는 $Q$개의 쿼리가 주어지므로, $k = 1, 2, \cdots, Q$의 순서로 처리하세요.

- $x$를 $x \times A_k$로 갱신합니다. 그 후 $f(B_k, x)$를 $998\,244\,353$으로 나눈 나머지를 출력합니다.

### 배경

#### 소인수

$2$ 이상인 정수 $n$의 소인수란 다음 조건을 모두 만족하는 집합 $P = \{P_1, P_2, \cdots, P_{|P|}\}$의 원소를 말합니다.

- $P_i$는 소수입니다.
- $i \neq j$이면 $P_i \neq P_j$입니다.
- 다음 조건을 만족하는 길이 $|P|$인 정수열 $E = (E_1, E_2, \cdots, E_{|P|})$가 존재합니다.

  - $1 \leq E_i$
  - $\displaystyle \prod_{i = 1}^{|P|} P_i^{E_i} = n$

이러한 $P$는 유일하게 정해진다는 것을 증명할 수 있습니다.

#### $\prod$ (총곱 기호)

길이 $n$ ($1 \leq n$)인 수열 $a = (a_1, a_2, \cdots, a_n)$에 대해 $\displaystyle \prod_{i = 1}^n a_i$는 $a_1 \times a_2 \times \cdots \times a_n$을 의미합니다.

## 입력

```text
$Q$
$A_1\ B_1$
$A_2\ B_2$
$\vdots$
$A_Q\ B_Q$
```

$Q$는 쿼리의 개수입니다.

첫 줄 이후 $Q$개 줄 중 $k$번째 줄에는 $k$번째 쿼리에서 사용하는 정수 $A_k, B_k$가 공백으로 구분되어 주어집니다.

## 제한

- $1 \leq Q \leq 10^5$
- $2 \leq A_k \leq 10^5$
- $1 \leq B_k \leq 10^5$
- 입력은 모두 정수입니다.

## 출력

$Q$개의 줄에 출력하세요. $k$번째 줄에는 $k$번째 쿼리의 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
12 2
15 3
7 7
```

#### 출력

```text
2
6
0
```

각 쿼리에 대해 다음과 같이 됩니다.

- $1$번째 쿼리에서는 다음과 같습니다.

  - $x$를 $1 \times 12 = 12$로 갱신합니다.
  - 그 후 $f(2, 12)$를 계산합니다. 조건을 만족하는 정수열은 $(2, 6), (4, 3)$의 $2$개입니다. 그 이유는 다음과 같습니다.

    - $(2, 6)$에 대해 $2 = 2$, $6 = 2 \times 3$입니다. 모든 원소가 $2$ 이상이고 총곱이 $12$이며, $2 \leq 2$, $2 \leq 3$이므로 조건을 만족합니다.
    - $(4, 3)$에 대해 $4 = 2^2$, $3 = 3$입니다. 모든 원소가 $2$ 이상이고 총곱이 $12$이며, $2 \leq 3$이므로 조건을 만족합니다.

- $2$번째 쿼리에서는 다음과 같습니다.

  - $x$를 $12 \times 15 = 180$으로 갱신합니다.
  - 그 후 $f(3, 180)$을 계산합니다. 조건을 만족하는 정수열은 $(2,2, 45), (2, 6, 15), (2, 18, 5), (4, 3, 15), (4, 9, 5), (12, 3, 5)$의 $6$개입니다.

- $3$번째 쿼리에서는 다음과 같습니다.

  - $x$를 $180 \times 7 = 1\,260$으로 갱신합니다.
  - 그 후 $f(7, 1\,260)$을 계산합니다. 조건을 만족하는 정수열은 존재하지 않으므로 $0$개입니다.
