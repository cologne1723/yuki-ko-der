수직선 위에 `N`명의 사람과 `M`개의 장애물이 있습니다. 사람 `i`는 `X_i`에서 양의 방향으로 속도 1로 걷고, 장애물 위치에 도달하면 멈춥니다.

각 사람이 걷는 거리를 구하세요. 장애물이 없어 무한히 걷는다면 `Infinity`를 출력하세요.

## 제약

- `1 <= N,M <= 1000`
- `0 <= X_i,Y_j <= 10^9`
- 모든 `X_i,Y_j`는 서로 다릅니다.

## 입력

`N M`, 사람 위치 `X`, 장애물 위치 `Y`가 주어집니다.

## 출력

각 사람의 이동 거리를 한 줄에 하나씩 출력하세요.
