## 문제 설명

빨간색 버튼과 파란색 버튼이 있습니다. MMA くん은 이 버튼을 눌러 놀기로 했습니다.

MMA くん은 점수라고 하는 수를 가지고 있으며, 처음에는 점수가 $0$입니다.

빨간색 버튼을 누르면 MMA くん의 점수가 $A$만큼 증가합니다.

파란색 버튼을 누르면 MMA くん의 점수가 $B$배가 됩니다.

버튼을 최대 $K$번까지 누를 수 있을 때, MMA くん이 달성할 수 있는 점수의 최댓값을 구하세요.

단, 답이 매우 커질 수 있으므로 $998\,244\,353$으로 나눈 나머지를 출력하세요.

$T$개의 테스트 케이스가 주어지므로 각각에 대해 풀이하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\text{case}_1$
$\text{case}_2$
$\vdots$
$\text{case}_T$
```

$1$번째 줄에 테스트 케이스의 개수 $T$가 주어집니다.

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$A\ B\ K$
```

각 테스트 케이스에서 $A$, $B$, $K$는 공백으로 구분되어 주어집니다.

## 제한

- $1 \leq T \leq 2 \times 10^{5}$
- $|A|, |B| \leq 10^{9}$
- $1 \leq K \leq 10^{9}$
- 입력은 모두 정수입니다.

## 출력

$T$줄에 출력하세요.

$i$번째 줄에는 $i$번째 테스트 케이스에 대한 답을 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
4 2 3
23 57 38
```

#### 출력

```text
16
343383691
```

$1$번째 테스트 케이스에서는 다음과 같이 버튼을 누르면 점수 $16$을 달성할 수 있습니다.

- 빨간색 버튼을 누릅니다. 점수는 $0 + 4 = 4$가 됩니다.
- 빨간색 버튼을 누릅니다. 점수는 $4 + 4 = 8$이 됩니다.
- 파란색 버튼을 누릅니다. 점수는 $8 \times 2 = 16$이 됩니다.

$16$보다 큰 점수는 달성할 수 없으므로 $16$을 출력합니다.

$2$번째 테스트 케이스에서는 달성할 수 있는 점수의 최댓값을 $998\,244\,353$으로 나눈 나머지를 출력해야 한다는 점에 주의하세요.
