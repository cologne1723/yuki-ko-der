## 문제 설명

$2$개의 양의 정수 $L$, $R$에 대해 $S(L, R)$를 다음과 같이 정의합니다.

$S(L, R) \coloneqq \sum_{i = L}^R i^3$

양의 정수 $N$이 주어집니다. 다음 $2$가지 조건을 모두 만족하는 양의 정수의 순서쌍 $(L, R)$을 모두 구하세요.

- $1 \le L \le R$
- $S(L, R) = N$

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

$N$은 정수입니다.

## 제한

- $1 \le N \le 10^{18}$
- 입력되는 $N$은 정수입니다.

## 출력

문제의 조건을 만족하는 순서쌍을 해라고 부릅니다. 이 문제의 제한 아래에서는 해가 유한 개임을 증명할 수 있습니다.

해가 모두 $C$개이고, 사전순으로 작은 순서대로

$(L_1, R_1), (L_2, R_2), \dots, (L_C, R_C)$

라고 할 때, 다음 형식으로 $C + 1$줄을 출력하세요. 각 줄은 공백으로 구분하고, 마지막에도 줄바꿈을 출력하세요.

```text
$C$
$L_1\ R_1$
$L_2\ R_2$
$\vdots$
$L_C\ R_C$
```

## 예제

### 예제 1 {file=""}

#### 입력

```text
2025
```

#### 출력

```text
1
1 9
```

다음 식이 성립합니다.

- $S(1, 9) = 1^3 + 2^3 + 3^3 + 4^3 + 5^3 + 6^3 + 7^3 + 8^3 + 9^3 = 2\,025$

$(1, 9)$는 유일한 해입니다.

### 예제 2 {file=""}

#### 입력

```text
2026
```

#### 출력

```text
0
```

해가 $1$개도 없을 수도 있습니다.

### 예제 3 {file=""}

#### 입력

```text
216
```

#### 출력

```text
2
3 5
6 6
```

해가 여러 개일 수도 있습니다. $L = R$이어도 된다는 점에 주의하세요.

다음 식이 성립합니다.

- $S(3, 5) = 3^3 + 4^3 + 5^3 = 216$
- $S(6, 6) = 6^3 = 216$

$(3, 5)$가 $(6, 6)$보다 사전순으로 작으므로 이 순서로 출력하세요.
