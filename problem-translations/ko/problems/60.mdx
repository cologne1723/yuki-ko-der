## 문제 설명

마법소녀 마도카는 마녀 발푸르기스의 밤과 그 사역마들을 쓰러뜨리려고 합니다.

사역마가 여러 마리라서 짧은 시간 안에 모든 적에게 피해를 주어야 합니다. 마도카는 범위 공격 마법을 사용합니다. 발푸르기스의 밤과 사역마들의 좌표 및 체력, 그리고 각 공격의 직사각형 범위와 피해량이 주어질 때, 쓰러지지 않은 적들의 남은 체력 합을 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
N K
X_1 Y_1 HP_1
:
X_N Y_N HP_N
AX_1 AY_1 W_1 H_1 D_1
:
AX_K AY_K W_K H_K D_K
```

모든 값은 정수입니다.

- $1 \le N \le 100\,000$
- $1 \le K \le 100\,000$
- $-500 \le X_i,Y_i \le 500$
- $1 \le HP_i \le 10\,000$
- $-500 \le AX_j,AY_j \le 500$
- $1 \le W_j,H_j \le 500$
- $1 \le D_j \le 10\,000$
- 적들의 좌표는 서로 다릅니다.

각 적의 위치는 $(X_i,Y_i)$이고 체력은 $HP_i$입니다. $j$번째 공격은 직사각형

$$AX_j \le X \le AX_j+W_j, \qquad AY_j \le Y \le AY_j+H_j$$

안에 있는 모든 적에게 $D_j$만큼 피해를 줍니다. 같은 공격을 여러 번 사용할 수도 있습니다.

## 출력

받은 피해가 체력 이상인 적은 쓰러집니다. 쓰러지지 않은 적들의 남은 체력 합을 출력하세요.
