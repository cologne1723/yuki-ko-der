## 이야기

![yukicoder 로고](../images/60/1.png)

마법소녀 Madoka는 마녀 Walpurgisnacht와 싸우고 있었습니다.

Walpurgisnacht는 여러 사역마를 거느리고 있으므로, 짧은 시간 안에 모든 적에게 피해를 주지 않으면 쓰러뜨릴 수 없습니다. 그래서 Madoka는 적을 효율적으로 쓰러뜨리기 위해 범위 공격 마법을 사용하기로 했습니다.

## 문제 설명

Walpurgisnacht와 그 사역마들의 좌표 및 체력, 그리고 각 공격의 직사각형 범위와 피해량이 주어질 때, 쓰러지지 않은 적들의 남은 체력 합을 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ K$
$X_1\ Y_1\ HP_1$
$X_2\ Y_2\ HP_2$
$\vdots$
$X_N\ Y_N\ HP_N$
$AX_1\ AY_1\ W_1\ H_1\ D_1$
$AX_2\ AY_2\ W_2\ H_2\ D_2$
$\vdots$
$AX_K\ AY_K\ W_K\ H_K\ D_K$
```

$N$은 적의 수이고 $K$는 Madoka의 공격 횟수입니다. 모든 값은 정수이며 각 줄의 값은 공백으로 구분되어 주어집니다.
각 적의 위치는 $(X_i,Y_i)$이고 체력은 $HP_i$입니다. 적들의 좌표는 서로 다릅니다.
$j$번째 공격은 $AX_j \le X \le AX_j+W_j$와 $AY_j \le Y \le AY_j+H_j$를 모두 만족하는 위치의 적에게 $D_j$만큼 피해를 줍니다. 같은 공격이 여러 번 주어질 수도 있습니다.

## 제한

- $1 \le N,K \le 100\,000$
- $-500 \le X_i,Y_i \le 500$ $(1 \le i \le N)$
- $1 \le HP_i \le 10\,000$ $(1 \le i \le N)$
- $-500 \le AX_j,AY_j \le 500$ $(1 \le j \le K)$
- $1 \le W_j,H_j \le 500$ $(1 \le j \le K)$
- $1 \le D_j \le 10\,000$ $(1 \le j \le K)$

## 출력

받은 피해가 체력 이상인 적은 쓰러집니다. 쓰러지지 않은 적들의 남은 체력 합을 출력하세요.
