## 문제 설명

길이가 $N$인 음이 아닌 정수열 $A=(A_1,A_2,\dots,A_N)$이 주어집니다. 다음 조건을 만족하는 음이 아닌 정수 $x$의 개수를 구하세요.

- 어떤 $i$($1\le i\le N$)가 존재하여 $x\ \mathrm{OR}\ A_i=A_i$가 성립합니다. 여기서 $\mathrm{OR}$는 비트별 논리합을 나타냅니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$A_1\ A_2\ \dots\ A_N$
```

## 제한

- $1\le N\le 2\times 10^5$
- $0\le A_i<2^{30}$
- 입력은 모두 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
1 2
```

#### 출력

```text
3
```

$x=0,1,2$의 $3$개가 조건을 만족합니다.

### 예제 2 {file=""}

#### 입력

```text
3
5 6 8
```

#### 출력

```text
7
```

$x=0,1,2,4,5,6,8$의 $7$개가 조건을 만족합니다.
