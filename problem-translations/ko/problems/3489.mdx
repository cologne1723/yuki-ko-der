## 문제 설명

$2$ 이상의 정수 $N$과 $N$ 이하의 양의 정수로 이루어진 길이 $N$의 순열 $P$가 주어집니다.

다음 조건을 모두 만족하는 위에서 아래로 내려가는 형태의 [사다리 타기](https://atcoder.jp/contests/abc013/tasks/abc013_4?lang=ja) $A$가 존재하는지 판정하세요.

- $A$는 세로선을 정확히 $N$개 가집니다. 세로선들은 서로 평행합니다.
- $A$는 가로선을 최대 $N^2$개 가집니다. 가로선들은 세로선과 수직이고 서로 평행하며, 서로 다른 높이에 있습니다.
- $1$ 이상 $N$ 이하의 임의의 양의 정수 $i$에 대해, $A$의 왼쪽에서 $i$번째 세로선의 가장 위에서 시작해 사다리 타기의 규칙에 따라 선을 아래로 따라가면 $A$의 왼쪽에서 $P_i$번째 세로선의 가장 아래에 도착합니다.

단, $P_i$는 $P$의 $i$번째 성분을 나타냅니다.

## 입력

입력은 표준 입력에서 다음 형식으로 $2$줄에 걸쳐 주어집니다.

- $1$번째 줄에 $N$이 주어집니다.
- $2$번째 줄에 $N$ 이하의 각 양의 정수 $i$에 대한 $P_i$가 $i$가 작은 순서대로 공백으로 구분되어 주어집니다.

```text
$N$
$P_1\ \cdots\ P_N$
```

## 제한

- $2\leq N\leq 100$
- $P$는 $N$ 이하의 양의 정수로 이루어진 길이 $N$의 순열입니다.

## 출력

조건을 만족하는 사다리 타기 $A$가 존재하지 않으면 `No`를 출력하세요.

존재한다면 그러한 $A$를 $1$개 선택하세요. $A$의 가로선 개수를 $M$이라 하고, $1$ 이상 $M$ 이하의 각 양의 정수 $j$에 대해 $A$의 위에서 $j$번째 가로선이 $A$의 왼쪽에서 $i_j$번째 세로선과 왼쪽에서 $i_j+1$번째 세로선을 연결하도록 $N$ 미만의 양의 정수 $i_j$를 정합니다. 다음 형식으로 출력하세요.

- $1$번째 줄에 `Yes`를 출력합니다.
- $2$번째 줄에 $M$을 출력합니다.
- $1$ 이상 $M$ 이하의 각 양의 정수 $j$에 대해 $j+2$번째 줄에 $i_j$를 출력합니다.

마지막에는 개행을 출력하세요.

이 문제는 스페셜 저지 문제입니다. 정답은 $1$개로 정해지지 않을 수 있지만, 그중 $1$개만 출력하세요.

단, 출력은 위에서 설명한 형식을 엄격하게 따라야 합니다. 예를 들어 불필요한 공백이 있을 때 저지가 어떻게 동작할지는 보장되지 않습니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
1 2
```

#### 출력

```text
Yes
0
```

세로선이 $2$개이고 가로선이 $0$개인 사다리 타기가 조건을 만족합니다. 이 밖에도 다음과 같은 출력이 정답입니다.

#### 출력

```text
Yes
2
1
1
```

반면 다음 출력은 정답이 아니라는 점에 주의하세요. 이 예에서는 가로선이 $6$개이므로 $N^2=4$개 이하라는 조건을 만족하지 않습니다.

#### 출력

```text
Yes
6
1
1
1
1
1
1
```

### 예제 2 {file=""}

#### 입력

```text
2
2 1
```

#### 출력

```text
Yes
1
1
```

세로선이 $2$개이고 가로선이 $1$개이며, 위에서 $1$번째 가로선이 왼쪽에서 $1$번째 세로선과 왼쪽에서 $2$번째 세로선을 연결하는 사다리 타기가 조건을 만족합니다.

### 예제 3 {file=""}

#### 입력

```text
3
3 1 2
```

#### 출력

```text
Yes
2
1
2
```

세로선이 $3$개이고 가로선이 $2$개이며,

- 위에서 $1$번째 가로선이 왼쪽에서 $1$번째 세로선과 왼쪽에서 $2$번째 세로선을 연결합니다.
- 위에서 $2$번째 가로선이 왼쪽에서 $2$번째 세로선과 왼쪽에서 $3$번째 세로선을 연결합니다.
