## 문제

양의 정수 $N,K$가 주어집니다. $1$ 이상 $N$ 이하의 정수로 이루어진 길이 $N$의 수열 $A=(A_1,A_2,\dots,A_N)$와 $1$ 이상 $K$ 이하의 정수로 이루어진 길이 $N$의 수열 $C=(C_1,C_2,\dots,C_N)$의 쌍은 $(NK)^N$개 있습니다.

그중 $C_i=C_{A_i}$를 만족하는 $1\leq i\leq N$이 정확히 하나 존재하는 쌍의 수를 $998244353$으로 나눈 나머지를 구하세요.

## 제약

- $1\leq N\leq10^6$
- $1\leq K\leq10^{18}$

## 입력

~~~text
N K
~~~

## 출력

조건을 만족하는 $A,C$의 쌍의 수를 $998244353$으로 나눈 나머지를 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

~~~text
2 3
~~~

### 출력 1 {file="stdout"}

~~~text
12
~~~

### 입력 2 {file="stdin"}

~~~text
271 828
~~~

### 출력 2 {file="stdout"}

~~~text
516955559
~~~

### 입력 3 {file="stdin"}

~~~text
1000000 1839286755214161
~~~

### 출력 3 {file="stdout"}

~~~text
130737125
~~~
