## 문제 설명

$H$행 $W$열의 행렬 $A$가 주어집니다.

처음에 행렬 $A$의 $i$행 $j$열에 있는 원소는 $A_{i,j}$입니다. 여기서 $A_{i,j}$는 `0` 또는 `1`입니다.

행렬 $A$가 빈 행렬이 될 때까지 다음 연산 중 $1$개를 원하는 순서로 원하는 횟수만큼 반복할 수 있습니다.

- 연산 $1$: 모든 값이 같은 행을 $1$개 선택하여 삭제합니다.
- 연산 $2$: 모든 값이 같은 열을 $1$개 선택하여 삭제합니다.
- 연산 $3$: 행을 $1$개 선택하여 삭제합니다.

행렬 $A$를 빈 행렬로 만들 때 수행하는 연산 $3$의 횟수로 가능한 최솟값을 구하세요.

## 입력

```text
$H\ W$
$A_{1,1}A_{1,2}\cdots A_{1,W}$
$A_{2,1}A_{2,2}\cdots A_{2,W}$
$\vdots$
$A_{H,1}A_{H,2}\cdots A_{H,W}$
```

$1$번째 줄에 행렬의 행 수와 열 수를 나타내는 정수 $H$, $W$가 공백으로 구분되어 주어집니다.

이후 $H$개의 줄에 행렬 $A$가 주어집니다. $i$번째 줄에는 $A_{i,1}A_{i,2}\cdots A_{i,W}$가 공백 없이 주어집니다.

## 제한

- $1 \le H,W \le 500$
- $A_{i,j}$는 `0` 또는 `1`입니다.

## 출력

연산 $3$의 횟수로 가능한 최솟값을 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 3
101
111
010
010
```

#### 출력

```text
1
```

다음 순서로 행렬 $A$를 빈 행렬로 만들 수 있습니다.

1. $1$번째 행에 연산 $3$을 수행합니다.
2. $1$번째 행에 연산 $1$을 수행합니다.
3. 각 열에 연산 $2$를 수행합니다.

```text
101 -> 111 -> 010 -> 10 -> 0 -> (빈 상태)
111    010    010    10    0
010    010
010
```
