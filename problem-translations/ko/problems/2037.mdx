0 또는 1이 적힌 블록 $N$개가 있습니다. 아래에서부터 블록을 쌓을 때 바로 아래 두 블록이 모두 1이면 0, 그 외에는 1인 블록을 놓습니다.

위에서 $K$번째 줄에 있는 블록들의 숫자를 출력하세요.

## 입력

```text
N K
S
```

$2\le N\le4\times10^5$, $1\le K<N$이며 $S$는 0과 1로 이루어진 길이 $N$ 문자열입니다.

## 출력

위에서 $K$번째 줄을 문자열로 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
5 3
01011
```

#### 출력

```text
001
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
2 1
11
```

#### 출력

```text
0
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
16 6
0110010100111011
```

#### 출력

```text
000001
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
20 3
01001101011001011011
```

#### 출력

```text
101
```
