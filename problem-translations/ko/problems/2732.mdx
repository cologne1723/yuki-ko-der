## 문제

`1,...,N`의 서로 다른 두 순열 `P'`, `P''`가 존재하여

`⊕(P'_i + A_i) = ⊕(P''_i + A_i)`

를 만족하는지 판정하고, 존재하면 하나 출력하세요. `⊕`는 전체 XOR입니다.

<details>
<summary>전체 XOR란?</summary>

$\bigoplus$는 수열에서 지정한 원소들의 전체 XOR을 뜻합니다. 길이 $N$인 수열 $(A_1,A_2,\ldots,A_N)$에 대해 $\bigoplus_{i=1}^{N}A_i$를 $A_1\oplus A_2\oplus\cdots\oplus A_N$으로 정의합니다.

</details>

<details>
<summary>XOR란?</summary>

XOR(배타적 논리합)은 두 값 사이의 논리 연산으로, 같은 비트 위치의 값이 다르면 $1$, 같으면 $0$을 반환합니다. $a$와 $b$의 배타적 논리합은 $a\oplus b$로 씁니다. 예를 들어 $5\oplus3=6$입니다. 이는 $101\oplus011=110$이라는 비트별 연산에 따른 결과입니다.

</details>

## 제약

- `1 ≤ N ≤ 2×10^5`
- `0 ≤ A_i ≤ 2×10^5`

## 입력

```text
N
A_1 A_2 ... A_N
```

## 출력

조건을 만족하는 순열 두 개를 각각 한 줄에 출력하세요. 없으면 `-1`을 출력하세요.
