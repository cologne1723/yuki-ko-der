## 문제 설명

양의 정수 $N$, 소수 $P$, 음이 아닌 정수 $C$, 길이가 $N$인 음이 아닌 정수열 $A$가 주어집니다.

$1 \leq \ell \leq r \leq N$이고

$\displaystyle \prod_{i = \ell}^{r} A_i \equiv C \pmod{P}$

를 만족하는 정수쌍 $(\ell,r)$의 개수를 구하세요.

단, $N$ 이하의 각 양의 정수 $i$에 대해 $A_i$는 $A$의 $i$번째 성분을 나타냅니다. 즉, $A = (A_1,\ldots,A_N)$입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 $2$줄에 걸쳐 주어집니다.

- $1$번째 줄에 $N$, $P$, $C$가 공백으로 구분되어 주어집니다.
- $2$번째 줄에 $N$ 이하의 각 양의 정수 $i$에 대한 $A_i$가 $i$가 작은 순서대로 공백으로 구분되어 주어집니다.

```text
$N\ P\ C$
$A_1\ \cdots\ A_N$
```

## 제한

입력은 다음 제한을 만족합니다.

- $N$은 $1 \leq N \leq 10^5$를 만족하는 정수입니다.
- $P$는 $1 \leq P \leq 10^9$를 만족하는 소수입니다.
- $C$는 $0 \leq C < P$를 만족하는 정수입니다.
- $N$ 이하의 임의의 양의 정수 $i$에 대해 $A_i$는 $0 \leq A_i < P$를 만족하는 정수입니다.

## 출력

조건을 만족하는 정수쌍 $(\ell,r)$의 개수를 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 2 0
0
```

#### 출력

```text
1
```

$(N,P,C) = (1,2,0)$이고 $A = (0)$입니다. $1 \leq \ell \leq r \leq N$을 만족하는 정수쌍은 $(1,1)$ $1$개뿐이며,

$\displaystyle \prod_{i=1}^{1} A_i = A_1 = 0 \textcolor{blue}{\equiv} C \pmod{P}$

입니다.

### 예제 2 {file=""}

#### 입력

```text
2 2 1
1 1
```

#### 출력

```text
3
```

$(N,P,C) = (2,2,1)$이고 $A = (1,1)$입니다. $1 \leq \ell \leq r \leq N$을 만족하는 정수쌍은 $(1,1),(1,2),(2,2)$의 $3$개이며,

$\displaystyle \begin{array}{rcccl}
\displaystyle \prod_{i=1}^{1} A_i &\displaystyle = &\displaystyle A_1 &\displaystyle = &\displaystyle 1 &\displaystyle \textcolor{blue}{\equiv} &\displaystyle C \pmod{P} \\
\displaystyle \prod_{i=1}^{2} A_i &\displaystyle = &\displaystyle A_1 A_2 &\displaystyle = &\displaystyle 1 &\displaystyle \textcolor{blue}{\equiv} &\displaystyle C \pmod{P} \\
\displaystyle \prod_{i=2}^{2} A_i &\displaystyle = &\displaystyle A_2 &\displaystyle = &\displaystyle 1 &\displaystyle \textcolor{blue}{\equiv} &\displaystyle C \pmod{P}
\end{array}$

입니다.

### 예제 3 {file=""}

#### 입력

```text
2 2 0
1 0
```

#### 출력

```text
2
```

$(N,P,C) = (2,2,0)$이고 $A = (1,0)$입니다. $1 \leq \ell \leq r \leq N$을 만족하는 정수쌍은 $(1,1),(1,2),(2,2)$의 $3$개이며,

$\displaystyle \begin{array}{rcccl}
\displaystyle \prod_{i=1}^{1} A_i &\displaystyle = &\displaystyle A_1 &\displaystyle = &\displaystyle 1 &\displaystyle \textcolor{red}{\not\equiv} &\displaystyle C \pmod{P} \\
\displaystyle \prod_{i=1}^{2} A_i &\displaystyle = &\displaystyle A_1 A_2 &\displaystyle = &\displaystyle 0 &\displaystyle \textcolor{blue}{\equiv} &\displaystyle C \pmod{P} \\
\displaystyle \prod_{i=2}^{2} A_i &\displaystyle = &\displaystyle A_2 &\displaystyle = &\displaystyle 0 &\displaystyle \textcolor{blue}{\equiv} &\displaystyle C \pmod{P}
\end{array}$

입니다.

### 예제 4 {file=""}

#### 입력

```text
2 3 1
2 2
```

#### 출력

```text
1
```

$(N,P,C) = (2,3,1)$이고 $A = (2,2)$입니다. $1 \leq \ell \leq r \leq N$을 만족하는 정수쌍은 $(1,1),(1,2),(2,2)$의 $3$개이며,

$\displaystyle \begin{array}{rcccl}
\displaystyle \prod_{i=1}^{1} A_i &\displaystyle = &\displaystyle A_1 &\displaystyle = &\displaystyle 2 &\displaystyle \textcolor{red}{\not\equiv} &\displaystyle C \pmod{P} \\
\displaystyle \prod_{i=1}^{2} A_i &\displaystyle = &\displaystyle A_1 A_2 &\displaystyle = &\displaystyle 4 &\displaystyle \textcolor{blue}{\equiv} &\displaystyle C \pmod{P} \\
\displaystyle \prod_{i=2}^{2} A_i &\displaystyle = &\displaystyle A_2 &\displaystyle = &\displaystyle 2 &\displaystyle \textcolor{red}{\not\equiv} &\displaystyle C \pmod{P}
\end{array}$

입니다.
