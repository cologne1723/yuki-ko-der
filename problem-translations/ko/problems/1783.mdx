이 문제는 **지식이 필요한 문제**입니다. 문제를 읽고 떠오르는 것이 없다면 여러 가지를 찾아보는 것을 권합니다.

<details>
<summary>힌트 2</summary>

출제 의도 풀이의 계산량은 대략 $O(10^K K^2\log K)$입니다. <s>상수 배수가 커서 빠른 언어를 권장합니다.</s>

**추가: 출제 의도 풀이의 계산량은 $B=10$, $P=120\,524\,861$일 때 $O(B^K(K^2\log B\log(BK)+BK+\log P))$입니다.**

제한 시간이 예상보다 빡빡하지 않아 출제 의도와 다른 풀이도 통과할 수 있지만, $B^K K^2\log B\log M$이 붙는 풀이를 적극적으로 탈락시키려 했으므로 통과하기 어려울 수도 있습니다. 양해 바랍니다.

구별되는 공 `N`개와 정수 `K,M,T`가 주어집니다. 공 `i`에는 `a_i`가 적혀 있습니다.

현재 수 `x`와 공의 수 `y`를 더해 `K`자리 십진수의 각 자리에서, 낮은 `T`개 자리는 올림이 발생하면 종료하고 나머지 자리는 나머지 연산으로 계산합니다. 공을 총 `M`번 선택한 뒤 가질 수 있는 각 수 `0` 이상 `10^K` 미만의 경우의 수를 `120586241`로 나눈 나머지로 출력하세요.

## 제약

- `1 <= K <= 5`, `0 <= T <= K`
- `1 <= N <= 10^5`
- `0 <= a_i < 10^K`, `2 <= M <= 10^18`

## 입력

`N K M T`와 공에 적힌 수가 주어집니다.

## 출력

각 최종 수의 경우의 수를 한 줄에 하나씩 출력하세요.
