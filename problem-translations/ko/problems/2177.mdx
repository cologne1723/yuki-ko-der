정수 $N$이 주어질 때 다음 조건을 만족하는 정수 튜플 $(p,a,b)$의 개수를 구하라냥. $2\le p\le10^9$, $0\le a,b\le\min(p,10)-1$, $a\ne b$이고, $x>1/N$이며 $p$진법 순환소수 `0.ababab...`의 값인 유리수 $x$가 존재해야 한다냥.

## 조건

- $1\le N\le10^8$

## 입력

```text
N
```

## 출력

조건을 만족하는 튜플의 개수를 출력하라냥.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2
```

#### 출력

```text
355
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1
```

#### 출력

```text
0
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
100000000
```

#### 출력

```text
40500192564
```
