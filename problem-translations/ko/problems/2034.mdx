길이 $N$인 소문자 문자열 $S$가 주어집니다. 가능한 모든 길이 $N$ 문자열 $26^N$개를 사전순으로 정렬했을 때, $S$가 앞에서 $k$번째라면 뒤에서 $k$번째인 문자열을 출력하세요.

## 입력

```text
N
S
```

$1\le N\le2\times10^5$입니다.

## 출력

구한 문자열을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
aab
```

#### 출력

```text
zzy
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1
n
```

#### 출력

```text
m
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
9
bfprxlwvi
```

#### 출력

```text
yukicoder
```
