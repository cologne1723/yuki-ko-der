## 프롤로그

여름 방학이라고 하면, 필자가 어렸을 때는 여름 방학 숙제로 계산 연습장에서 대량의 계산 연습을 하곤 했습니다.

이것은 여름 방학 숙제로 이차방정식 연습을 산더미처럼 받았던 어느 여름날의 일입니다.

kuuso 소년: “매일매일 이차방정식만 풀다니, 아무래도 질렸어.”

신: “그럼 이건 어떠냐?”

하늘에서 목소리가 들린 것 같더니 눈앞의 계산 연습장이 갑자기 눈부시게 빛났습니다.

눈부셔서 눈을 감고 잠시 후 조심스럽게 눈을 뜨자, 그곳에는 어딘가 낯선 문제가 실린 계산 연습장이 있었습니다.

kuuso 소년: “방금 그 빛은 대체 뭐였지. 뭐, 됐어.”

혼잣말하며 계산 연습장을 펼치자 낯선 위화감이 느껴졌습니다.

“(문제) 다음 삼차방정식을 풀어라”

X^3 − 6X^2 + 11X − 6 = 0

아무래도 신의 변덕으로 차수가 1 올라간 모양입니다.

아직 삼차방정식을 배우지 않았는데 어떻게 해야 할지 완전히 절망한 kuuso 소년.

신: “이건 보너스다, 허허.”

정신을 차려 보니 문제문 뒤에 힌트 같은 문장이 추가되어 있었습니다.

## 문제

정수 계수의 삼차방정식 X^3 + AX^2 + BX + C = 0이 주어집니다.

주어지는 삼차방정식은 −10^9 < α,β,γ < 10^9를 만족하는 서로 다른 정수해 α,β,γ를 3개 가진다는 것이 보장됩니다.

이 세 정수해를 모두 구해 작은 순서대로 출력하세요.

## 입력

```text
A B C
```

모든 입력은 정수이며 다음 제약을 만족합니다.

−10^18 < A,B,C < 10^18

방정식 X^3 + AX^2 + BX + C = 0이 서로 다른 세 정수해 α,β,γ를 가지며 −10^9 < α,β,γ < 10^9를 만족하는 것이 보장됩니다.

## 출력

서로 다른 세 정수해 α,β,γ를 오름차순으로 공백으로 구분해 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
0 -1 0
```

출력:

```text
-1 0 1
```

주어진 삼차방정식은 X^3 − X = 0입니다. X(X−1)(X+1)=0으로 변형하면 해가 X=−1,0,1임을 알 수 있습니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
-6 11 -6
```

출력:

```text
1 2 3
```

주어진 삼차방정식은 X^3 − 6X^2 + 11X − 6 = 0입니다. (X−1)(X−2)(X−3)=0으로 변형하면 해가 X=1,2,3임을 알 수 있습니다.

일반적으로 정수 계수 n차방정식은 서로 다른 해를 n개 찾으면 그 외에는 해가 존재하지 않는 것이 보장됩니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
113405 -128550416 -177999416460
```

출력:

```text
-114514 -810 1919
```

오름차순이니까 어쩔 수 없네요.
