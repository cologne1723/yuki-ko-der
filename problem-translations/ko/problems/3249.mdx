## 문제 설명

길이가 $n$인 배열 $b$가 주어집니다. 임의의 $1 \leq i \leq n$에 대해 $b_i = i \operatorname{AND} x$가 성립하도록 하는 가장 작은 양의 정수 $x$를 구하세요. 해가 존재하지 않는 경우 $-1$을 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$n$
$b_1\ b_2\ \cdots\ b_n$
```

$1$번째 줄에 배열의 길이 $n$이 주어집니다. $2$번째 줄에 배열 $b$의 원소 $b_1,b_2,\ldots,b_n$이 공백으로 구분되어 주어집니다.

## 제한

- $1 \leq n$
- $0 \leq b_i \leq 2 \times 10^5$

## 출력

조건을 만족하는 가장 작은 $x$를 출력하세요. 해가 존재하지 않는 경우 $-1$을 출력하세요.
