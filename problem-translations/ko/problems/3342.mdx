## 문제 설명

$0$개 이상의 `A`와 $1$개의 `B`를 이 순서로 나열한 문자열을 `AAB` 문자열이라고 합니다.

예를 들어 `AAB`와 `B`는 `AAB` 문자열입니다. `AABB`와 `A`는 `AAB` 문자열이 아닙니다.

`A`와 `B`로 이루어진 길이 $N$의 문자열 $S$가 주어집니다. $S$의 $i$번째 문자부터 $j$번째 문자까지의 연속 부분 문자열을 $S[i,j]$로 나타냅니다.

Alice와 Bob은 이 문자열을 사용해 다음과 같은 게임을 합니다.

- Alice부터 시작해 $2$명이 번갈아 가며 차례를 진행합니다.
- 각 차례에 $S[i,j]$가 `AAB` 문자열이 되도록 $i,j$($1 \leq i \leq j \leq N$)를 선택하고, $S[i,j]$에 포함된 각 문자를 `A`라면 `B`로, `B`라면 `A`로 치환합니다.

더 이상 연산할 수 없는 플레이어가 패배하고, 패배하지 않은 플레이어가 승리합니다.

이 게임은 반드시 유한한 차례 안에 종료된다는 것을 증명할 수 있습니다.

$2$명이 최적으로 행동할 때 어느 쪽이 승리하는지 판정하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$S$
```

$1$번째 줄에 문자열의 길이 $N$이 주어집니다.

$2$번째 줄에 `A`와 `B`로 이루어진 길이 $N$의 문자열 $S$가 주어집니다.

## 제한

- $1 \leq N \leq 2\times 10^5$
- $S$는 길이 $N$이고 `A`와 `B`로 이루어진 문자열입니다.
- $N$은 정수입니다.

## 출력

$2$명이 최적으로 행동할 때 Alice가 승리한다면 `Alice`를, Bob이 승리한다면 `Bob`을 출력하세요.

#### 출력

```text

```

$1$번째 차례에 Alice는 $S$를 `BA` 또는 `AA`로 만들 수 있습니다.
