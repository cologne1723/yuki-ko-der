사용자 $N$명의 이름 $S_i$가 주어집니다. 두 이름의 길이가 같고 서로 정확히 한 글자만 다르면 두 사용자를 닮은꼴이라고 합니다.

각 사용자에 대해 자신을 제외한 사용자 중 닮은꼴인 사람의 수를 구하세요.

<details>
<summary>정확한 정의 (클릭하여 펼치기)</summary>

조건을 정확히 쓰면 다음과 같습니다.

- $|S_i|=|S_j|$입니다. 여기서 $|S|$는 문자열 $S$의 길이입니다.
- $S_i[k]\ne S_j[k]$인 정수 $k$ ($1\le k\le |S_i|=|S_j|$)가 정확히 하나 존재합니다. $S[k]$는 문자열 $S$의 앞에서 $k$번째 문자를 뜻합니다.

</details>

## 입력

```text
N
S_1
S_2
...
S_N
```

$2\le N\le5\times10^4$이고 이름은 소문자로 이루어진 길이 $1$ 이상 $10$ 이하의 서로 다른 문자열입니다.

## 출력

각 사용자의 닮은꼴 수를 한 줄에 출력하세요.
