## 문제 설명

하루카와 유우는 매우 사이가 좋아서 둘이 포키 게임을 하기로 했습니다.

길이 $L$mm인 포키를 두 사람이 양 끝에서 중앙을 향해 각각 갉아 먹습니다. 두 사람은 매번 같은 타이밍에 $K$mm씩 갉습니다.

유우는 부끄럼을 많이 타므로, 다음 차례에 두 사람이 모두 갉으면 입술이 닿는다는 사실을 알게 되는 즉시 갉기를 멈춥니다. 남은 포키는 전부 하루카가 먹습니다.

이때 유우가 먹는 포키의 길이를 구하세요.

## 입력

```text
L K
```

입력 $L$, $K$는 정수입니다. 포키의 길이 $L$은 $(1 \le L \le 1\,000\,000\,000)$, 한 번에 갉는 길이 $K$는 $(1 \le K \le 50)$입니다.
남은 포키의 길이가 0 이하가 되면 입술이 닿는 것으로 합니다.

## 출력

유우가 먹는 포키의 길이를 출력하세요.

## 예제

### 예제 1

#### 입력

```text
90 20
```

#### 출력

```text
40
```

세 번째로 갉으려 하면 입술이 닿으므로 유우는 40mm를 먹습니다.

### 예제 2

#### 입력

```text
100 50
```

#### 출력

```text
0
```

유우가 한 번도 갉지 않는 경우도 있습니다.

### 예제 3

#### 입력

```text
1111 11
```

#### 출력

```text
550
```
