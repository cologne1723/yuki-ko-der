길이 `N`인 비음이 아닌 정수 수열 `A` 중 다음 조건을 만족하는 것의 개수를 `998244353`으로 나눈 나머지를 구하세요.

## 조건

- `0 <= A_i <= 2^M-1`
- 서로 다른 `K`개 원소의 비트 OR의 최솟값이 `X`입니다.

## 제약

- `1 <= N,M <= 200`
- `1 <= K <= N`
- `0 <= X <= 2^M-1`

## 입력

`N M K`와 `M`자리 이진수 `X`가 주어집니다.

## 출력

조건을 만족하는 수열의 개수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 2 2
10
```

#### 출력

```text
16
```

66725
