## 문제 설명

타카하시 군은 직육면체대학교(약칭: 직대)의 학생입니다.

직육면체대학교는 졸업 작품을 만들 계절입니다. 이 대학에는 졸업 작품을 만들 때 조금이라도 날림으로 한 사람은 유급시킨다는 소문이 있기 때문에, 타카하시 군은 조금이라도 좋은 것을 만들고 싶습니다.

타카하시 군은 미리 졸업 작품을 위해 모아 둔 $N$개의 직육면체를 쌓아 기념비를 만들기로 했습니다. $i$번 직육면체의 $3$개 변의 길이는 각각 $A_i$, $B_i$, $C_i$입니다. 타카하시 군이 기념비를 만들 때 지켜야 하는 조건은 다음과 같습니다. 하나의 직육면체의 윗면에 직접 접하도록 쌓을 수 있는 직육면체는 정확히 하나이고, 아래 직육면체보다 세로 또는 가로의 크기가 큰 직육면체를 위에 쌓아서는 안 되며, 위 직육면체는 아래 직육면체의 세로 또는 가로 어느 한 변에 평행한 변이 존재하도록 놓아야 합니다. 반대로 위 조건을 만족하는 한 어떤 방식으로 쌓아도 되며, $3$개 변을 각각 세로, 가로, 높이 중 어느 방향에 대응시킬지는 자유롭습니다.

기념비의 훌륭함은 그 높이와 같습니다. 타카하시 군이 만들 수 있는 가장 훌륭한 기념비의 훌륭함을 구하세요.

(21:29 추가 공지) 모든 직육면체를 다 사용할 필요는 없습니다. 사용하는 직육면체가 하나뿐이어도 됩니다.

## 입력

```text
$N$
$A_1\ B_1\ C_1$
$A_2\ B_2\ C_2$
$\vdots$
$A_N\ B_N\ C_N$
```

## 제한

$1 \le N \le 16$

$1 \le A_i,B_i,C_i \le 10^7$

입력은 모두 정수입니다.

## 출력

타카하시 군이 만들 수 있는 기념비의 훌륭함의 최댓값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
1 2 3
```

#### 출력

```text
3
```

길이 $3$인 변을 높이로 하는 방향으로 놓는 것이 좋습니다.

