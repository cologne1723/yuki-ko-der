처음에는 모든 칸이 흰 $H\times W$ 격자입니다. 가능한 $K\times K$ 스탬프 위치를 매번 균등하게 골라 총 $N$번 찍습니다. 흰 칸은 검게 변하고 검은 칸은 그대로입니다. 최종 검은 칸 수의 기댓값을 $998244353$으로 나눈 값을 구하세요.

## 조건

- $1\le H,W\le998244352$
- $1\le N\le5\times10^5$
- $1\le K\le\min(H,W)$

## 입력

```text
H W N K
```

## 출력

기댓값을 $998244353$으로 나눈 값을 출력하세요.
