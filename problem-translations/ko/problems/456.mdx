## 문제

경쟁 프로그래머들은 기록이 시작된 이래 수백만 번 제출해 왔습니다.

AtCoder에서는 100만 건이 넘는 제출이 있었고, 그중 $m$개는 다항식 시간 복잡도의 알고리즘이었다고 합니다.

조사 결과, $i$번째로 제출된 프로그램은 양의 입력 크기 $n$에 대해 계산 시간이 $n^{a_i}\log^{b_i}n$초 걸린다는 사실을 알게 되었습니다. 여기서 $n$은 정수일 필요가 없고, `log`는 자연로그입니다.

또한 $i$번째 제출은 실제로 $t_i$초가 걸렸다는 사실도 알게 되었습니다.

각 제출은 어떤 입력 크기 $n$에 대해 실행되었습니다. 가능한 $n$ 중 최댓값을 구하세요.

## 입력

```text
m
a_1 b_1 t_1
...
a_m b_m t_m
```

$1\leq m\leq1000000$이며 정수입니다.

$0\leq a_i,b_i\leq10$이며 정수입니다.

모든 $i$에 대해 $a_i$와 $b_i$ 중 어느 것도 0이 아닙니다.

$0.1\leq t_i\leq10$이며 소수점 이하 4자리까지 주어집니다. 소수점 이하 5자리 이상은 주어지지 않습니다.

## 출력

총 $m$개의 줄을 출력합니다. $i$번째 줄에는 $i$번째 제출을 실행한 입력 크기 $n$ 중 최댓값을 출력하세요.

오차는 $10^{-9}$까지 허용됩니다. 마지막에 줄바꿈을 출력하세요.

출력 크기 제한 때문에 소수점 이하 12자리보다 많이 출력하면 OLE(Output Limit Exceed)가 발생할 수 있습니다.

소수점 이하 12자리 이내로 답을 출력하는 것을 권장합니다.

## 참고

- 빠른 언어를 사용하는 것을 권장합니다. C++와 C#으로 통과할 수 있음이 확인되었습니다.
- 출력 크기 사양상 마지막 테스트 케이스의 채점에 매우 오랜 시간이 걸릴 수 있으므로 양해 바랍니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3
2 0 9.0000
1 1 10.0000
0 1 2.0000
```

출력:

```text
3
5.728925565387
7.389056098933
```

첫 번째 줄은 $n^2=9$이므로 $n=3$입니다.

두 번째 줄은 $n\log n=10$입니다. 유일한 해는 $n\fallingdotseq5.728925565387$입니다.

세 번째 줄은 $\log n=2$이므로 $n=e^2\fallingdotseq7.389056098933$입니다.
