수열 $B$의 길이가 1이 될 때까지 다음을 반복한다냥. 최댓값을 가지는 원소 중 가장 왼쪽 원소 $B_i$를 고르고, 모든 $j<i$에 대해 $B_j$에 $B_i$를 더한 뒤 $B_i$를 삭제한다냥. 주어진 수열 $A$의 구간 $[L_i,R_i]$을 이 기계에 입력했을 때 남는 값의 질의별 결과를 구하라냥. 질의는 서로 독립이다냥.

## 조건

- $1\le N,Q\le2\times10^5$
- $0\le A_i<998244353$
- $1\le L_i\le R_i\le N$

## 입력

```text
N Q
A_1 A_2 \cdots A_N
L_1 R_1
\vdots
L_Q R_Q
```

## 출력

각 답을 $998244353$으로 나눈 나머지로 한 줄에 하나씩 출력하라냥.
