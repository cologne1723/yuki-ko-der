## 문제 설명

어떤 SNS에는 게시한 문장에 특정 단어가 포함되어 있으면 자동으로 반응하여 답장을 보내는 'BOT'이라는 계정이 존재합니다. BOT은 게시된 문장에 $T$가 **연속 부분 문자열**로 포함된 경우에 반응합니다.

SF 군은 문자열 $S$로 나타내는 문장을 게시하려고 합니다. SF 군은 BOT의 반응을 원하지 않으므로, $S$의 적절한 위치에 문자 `.`을 삽입하여 BOT이 반응하지 않도록 하기로 했습니다.

BOT이 반응하지 않게 만들 수 있는지 판정하고, 가능하다면 반응하지 않게 만들기 위해 삽입해야 하는 문자 `.`의 최소 개수를 구하세요.

## 입력

```text
$S$
$T$
```

## 제한

$S$와 $T$는 영소문자로만 이루어진 길이 $1$ 이상 $1\,000$ 이하의 문자열입니다.

## 출력

반응하지 않게 만드는 것이 불가능하면 `-1`을 출력하세요. 가능하면 삽입해야 하는 문자 `.`의 최소 개수를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
doyouknowsegmenttreeiknowsegmenttree
segmenttree
```

#### 출력

```text
2
```

이대로 게시하면 $S$에 `"segmenttree"`가 연속 부분 문자열로 포함되어 있으므로 BOT이 반응합니다. 예를 들어 문자 `.`을 두 곳에 삽입하여 $S$를 `"doyouknowsegment.treeiknowsegment.tree"` 등으로 만들면 됩니다. 한 곳 이하로 삽입해서는 반응을 막을 수 없으므로 이것이 답입니다.

### 예제 2 {file=""}

#### 입력

```text
youaretouristofworldofwakingup
zekki
```

#### 출력

```text
0
```

삽입하지 않아도 반응하지 않습니다.

### 예제 3 {file=""}

#### 입력

```text
sumomomomomomomomonouchi
momo
```

#### 출력

```text
4
```

예를 들어 `"sumo.mom.omom.omom.omonouchi"`로 만들면 반응하지 않습니다.
