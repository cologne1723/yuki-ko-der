양의 정수 $N$이 주어집니다. $N$이 $1200$ 미만이면 `green`, 그렇지 않으면 `difficult`를 출력하세요.

## 조건

- $1 \le N \le 4000$
- $N$은 정수입니다.

## 입력

```text
$N$
```

## 출력

정답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
800
```

#### 출력

```text
green
```

이 대회는 경쟁 프로그래밍 초보자도 현장 대회를 즐길 수 있도록, AtCoder Problems의 difficulty가 초록색 이하라고 예상되는 문제만 출제합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1600
```

#### 출력

```text
difficult
```

출제 과정에서 너무 어렵다고 판단한 문제는 엑스트라 문제로 모았습니다. 이 대회가 시작한 지 $30$분 뒤부터 yukicoder에서 풀 수 있으니, 관심이 있다면 도전해 보세요! 이 대회의 순위에는 영향을 주지 않습니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1200
```

#### 출력

```text
difficult
```

`green`을 출력하는 것은 $N$이 **$1\,200$ 미만일 때**라는 점에 주의하세요.
