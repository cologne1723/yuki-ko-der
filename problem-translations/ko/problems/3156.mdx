## 문제 설명

양의 정수 $K$, $N$이 주어집니다.

양의 정수 $x$, $y$, $z$를 사용하여 $n=Kz^2=x^6+y^4$로 나타낼 수 있을 때, 양의 정수 $n$을 **좋은 수**라고 합니다.

$N$ 이하의 서로 다른 양의 정수 중 좋은 수가 몇 개인지 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$K\ N$
```

## 제한

- $1 \le K \le N \le 10^{15}$
- 입력은 모두 정수입니다.

## 출력

답을 출력하세요. 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
9 10000
```

#### 출력

```text
1
```

이 입력에서 $n$이 좋은 수인 조건은 양의 정수 $x$, $y$, $z$를 사용하여 $n=9z^2=x^6+y^4$로 나타낼 수 있다는 것입니다.

$N=10\,000$ 이하의 양의 정수 중 좋은 수인 것은 $2\,025\ (=9\cdot 15^2=3^6+6^4)$ 하나뿐이므로 $1$을 출력합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
4097 4097
```

#### 출력

```text
1
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
3 1000000000000000
```

#### 출력

```text
0
```

입력값이 $32$비트 정수형에 들어가지 않을 수 있습니다.

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
9 1000000000000000
```

#### 출력

```text
43
```
