## 문제 설명

점 $(x_1,y_1)$과 $(x_2,y_2)$ 사이의 맨해튼 거리는 $|x_1-x_2|+|y_1-y_2|$입니다.

$(0,0),(x,0),(0,y),(x,y)$ 네 점으로 둘러싸인 직사각형 범위 안에, $(0,0)$에서 맨해튼 거리가 $d$인 격자점이 몇 개 있는지 구하세요.

## 입력

```text
x y d
```

모든 입력은 정수입니다.

- $1 \le x,y \le 1\,000\,000\,000$
- $0 \le d \le 2\,000\,000\,000$

## 출력

범위 안에 있는 $(0,0)$에서 맨해튼 거리가 $d$인 격자점의 개수를 출력하세요.

## 예제

```text
1 1 1
```

```text
2
```

$(1,0)$과 $(0,1)$의 2개입니다.

```text
1 1 0
```

```text
1
```

$(0,0)$ 하나입니다.

```text
1 1 5
```

```text
0
```

범위 안에 점이 하나도 없습니다.
