## 문제 설명

전설의 빵 장인인 Breadくん은 $N$개의 프랑스빵을 가지고 있습니다. $i$번째 프랑스빵의 길이는 $A_i$입니다.

Breadくん은 프랑스빵을 $1$개로 합치기 위한 전통 의식인 ‘빵 늘어놓기’를 하려고 합니다.

먼저 ‘빵 늘어놓기’를 준비하기 위해, $i$번째 프랑스빵이 왼쪽에서 $i$번째에 놓이도록 프랑스빵을 $1$줄로 늘어놓습니다. 그다음 프랑스빵이 $1$개가 될 때까지 다음 조작을 반복합니다.

- 서로 인접한 프랑스빵을 $2$개 선택합니다. $2$개의 프랑스빵의 길이를 각각 $X$, $Y$라고 합니다. 이 $2$개의 프랑스빵과 $X\times Y$골드를 사용하여 길이 $X+Y$인 프랑스빵을 $1$개 만듭니다. 그 후 새로운 프랑스빵을 줄의 오른쪽 끝 또는 왼쪽 끝에 놓습니다. 사용한 프랑스빵은 사라집니다.

Breadくん은 구두쇠이므로 ‘빵 늘어놓기’에 사용하는 골드의 양을 최대한 줄이려고 합니다.

Breadくん을 위해 사용하는 골드의 양의 최솟값을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
```

## 제한

- $2\leq N\leq 2\times 10^5$
- $1\leq A_i\leq 10^4$ ($1\leq i\leq N$)
- 입력은 모두 정수입니다.

### 부분점

이 문제에는 부분점이 설정되어 있습니다.

| 부분 문제 | 배점 | 제한 |
| --- | ---: | --- |
| 부분 문제 $1$ | $20$점 | $N=2$ |
| 부분 문제 $2$ | $80$점 | $N\leq 8$ |
| 부분 문제 $3$ | $100$점 | 추가 제한 없음 |

## 출력

‘빵 늘어놓기’에서 Breadくん이 사용하는 골드의 양의 최솟값을 출력하세요.
