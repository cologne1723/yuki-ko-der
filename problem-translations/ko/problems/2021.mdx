문자 `A`, `B`로 이루어진 문자열 $S$가 주어집니다. 연속한 두 문자를 골라 둘 다 `B`로 바꾸는 조작을 정확히 한 번 수행합니다. 조작 후 가능한 서로 다른 문자열의 수를 구하세요.

## 입력

```text
N
S
```

$2\le N\le2\times10^5$입니다.

## 출력

가능한 문자열의 수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
AABA
```

#### 출력

```text
3
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3
ABB
```

#### 출력

```text
2
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
7
ABABABA
```

#### 출력

```text
4
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
40
ABBAABABAAABABBAABABAAABAAABBABAAAABBABA
```

#### 출력

```text
31
```
