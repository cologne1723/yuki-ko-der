## 이야기

검은 것을 좋아하는 사람이라 문자열에서 부분 수열(Subsequence) `KUROI`를 많이 만들기로 했습니다.

## 문제 설명

$1$번 부분 수열에 사용한 문자는 다른 부분 수열의 문자로 사용할 수 없습니다.

몇 개를 만들 수 있는지 세려고 보니 몇몇 문자가 사라져 있었습니다. 사라진 위치에는 부분 수열 `KUROI`의 개수가 최대가 되도록 문자를 적을 수 있습니다.

만들 수 있는 부분 수열 `KUROI`의 개수의 최댓값을 구하세요.

느린 언어로는 통과하지 못할 수도 있습니다.

## 입력

```text
$S$
```

$1$줄에 문자열 $S$가 주어집니다.

- $S$는 대문자 알파벳 `A`〜`Z` 또는 `?`로 이루어집니다.
- `?`는 해당 위치의 문자가 사라졌음을 나타냅니다.

## 제한

- $1 \le |S| \le 100$

## 출력

문자열에서 만들 수 있는 부분 수열 `KUROI`의 개수의 최댓값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
KKUROI
```

#### 출력

```text
1
```

### 예제 2 {file=""}

#### 입력

```text
KOIRU
```

#### 출력

```text
0
```

### 예제 3 {file=""}

#### 입력

```text
KUROIME?UR?CHA?
```

#### 출력

```text
2
```

### 예제 4 {file=""}

#### 입력

```text
KKUURROOII
```

#### 출력

```text
2
```
