평면의 $N$개 점이 주어집니다. 점 $i$에 대해 다른 점까지의 맨해튼 거리의 최댓값과 최솟값의 차의 절댓값을 $P_i$라 할 때, $P_i$의 최솟값을 구하세요.

## 조건

- $2\le N\le2\times10^5$
- $1\le X_i,Y_i\le N$
- 점들은 서로 다릅니다.

## 입력

```text
N
X1 Y1
...
XN YN
```

## 출력

$P_i$의 최솟값을 출력하세요.
