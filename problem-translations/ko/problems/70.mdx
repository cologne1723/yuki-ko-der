## 문제 설명

타로는 건강을 위해 매일 잠든 시각과 일어난 시각을 기록합니다.

잠든 시각과 일어난 시각의 목록이 주어질 때, 총 수면 시간을 출력하세요.

타로는 한 번에 $24$시간 이상 계속 잠들어 있지 않습니다.

타로의 세계에서는 하루가 $24$시간이고, $1$시간은 $60$분입니다.

## 입력

```text
$N$
$H_1:M_1\ h_1:m_1$
$H_2:M_2\ h_2:m_2$
$\vdots$
$H_i:M_i\ h_i:m_i$
$\vdots$
$H_N:M_N\ h_N:m_N$
```

첫째 줄에 기록의 개수를 나타내는 정수 $N$이 주어집니다.
이어지는 $N$개의 줄에 한 번의 수면에 대한 잠든 시각과 일어난 시각이 주어집니다.
각 기록은 `H:M h:m` 형식이며, 시와 분은 반각 콜론 `:`으로 구분하고 잠든 시각($H$시 $M$분)과 일어난 시각($h$시 $m$분)은 반각 공백으로 구분합니다.

## 제한

- $1 \le N \le 30$
- $0 \le H_i,h_i \le 23$ $(1 \le i \le N)$
- $0 \le M_i,m_i \le 59$ $(1 \le i \le N)$

## 출력

총 수면 시간을 분 단위로 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
22:24 5:9
22:46 5:37
1:11 7:11
```

#### 출력

```text
1176
```

각각 $6$시간 $45$분, $6$시간 $51$분, $6$시간 $0$분 동안 잤으므로 합계는 $19$시간 $36$분입니다. 이를 분 단위로 바꾸면 $1\,176$분입니다.

