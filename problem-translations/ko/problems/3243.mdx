## 문제 설명

정수 $N$이 주어집니다. 각 원소가 $1$, $2$, $-1$, $-2$ 중 하나인 길이 $N$의 수열 $A$ 중 다음 조건을 만족하는 것의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

수열 $A$를 비어 있지 않은 $1$개 이상의 구간으로 나누었을 때, 나뉜 모든 구간에서 구간 내 원소의 총곱이 $8$이 되는 분할 방법이 존재합니다.

더 엄밀하게는, 양의 정수 $L$과 $0 = B_1 < B_2 < \dots < B_L = N$을 만족하는 길이 $L$의 정수열 $B$ 중 다음 조건을 만족하는 것이 존재합니다.

$A_{B_i + 1} \times A_{B_i + 2} \times \dots \times A_{B_{i+1}} = 8 \quad (1 \leq i \leq L - 1)$

각각의 테스트 케이스에 대해 답하세요.

## 입력

입력은 다음 형식으로 주어집니다. 여기서 $\mathrm{case}_i$는 $i$번째 테스트 케이스를 나타냅니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

$1$번째 줄에 테스트 케이스의 개수인 정수 $T$가 주어집니다.

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
```

각 테스트 케이스에는 정수 $N$이 주어집니다.

## 제한

- 입력은 모두 정수입니다.
- $1 \leq T \leq 888$
- $1 \leq N \leq 8.88 \times 10^{17}$

## 출력

각 테스트 케이스에 대한 답을 $T$줄에 걸쳐 출력하세요. $i$번째 줄에는 $i$번째 테스트 케이스에 대한 답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
8
1
3
4
8
88
888
888888888
888000000000000000
```

#### 출력

```text
0
4
32
9200
744976062
355614226
995875110
722933621
```

$1$번째 테스트 케이스에 대해서는 조건을 만족하는 길이 $1$의 수열 $A$가 존재하지 않으므로 답은 $0$가지입니다.

$2$번째 테스트 케이스에서 조건을 만족하는 길이 $3$의 수열 $A$는 $(2, 2, 2)$, $(2, -2, -2)$, $(-2, 2, -2)$, $(-2, -2, 2)$의 $4$가지입니다.

$3$번째 테스트 케이스에서 조건을 만족하는 길이 $4$의 수열 $A$의 예로 $(1, 2, -2, -2)$와 $(-2, -2, -2, -1)$ 등을 들 수 있으며, 모두 $32$가지입니다.

$4$번째 테스트 케이스에서 조건을 만족하는 길이 $8$의 수열 $A$의 예로 $(2, 2, -2, 1, -1, -2, 2, -2)$를 들 수 있습니다. 이 수열을 $(2, 2, -2, 1, -1)$과 $(-2, 2, -2)$로 나누면, 나뉜 수열의 각 원소의 곱이 모두 $8$이 되기 때문입니다.

조건을 만족하는 수열 $A$의 개수를 $998\,244\,353$으로 나눈 나머지를 출력해야 한다는 점에 유의하세요.
