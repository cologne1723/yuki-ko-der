## 이야기

이번에는 $N$이 큰 것 같습니다.

## 문제 설명

문자열 $X$가 **올바른 괄호열**이라는 것은 다음 조건을 만족하는 것을 말합니다.

- $X$에 연속 부분 문자열로 포함된 `()`를 삭제하는 작업을 $0$회 이상 반복하여 $X$를 빈 문자열로 만들 수 있습니다.

예를 들어 `()(())`와 `()()()()`는 **올바른 괄호열**이지만, `))((`와 `)()()(` 등은 올바른 괄호열이 아닙니다.

어떤 **올바른 괄호열** $T$에 대해 다음 절차를 수행한 뒤의 $x$의 값을 $f(T)$라고 합니다.

- 처음에 $S$를 빈 집합, $x=0$으로 하고, $i=1,2,\dots,N$ 순서로 다음을 수행합니다.
  - $T_i$가 `(`이면 $S$에 $i$를 추가합니다.
  - $T_i$가 `)`이면 $S$에 포함된 최댓값을 $j$라고 하고, $T$의 열린 구간 $(j,i)$에서 꺼낸 문자열에 연속 부분 문자열로 포함된 `()`의 개수를 $x$에 더합니다. 그 후 $S$에서 $j$를 제거합니다.

예를 들어 $f($`()(())`$)=1$, $f($`(()()())`$)=3$입니다.

양의 정수 $N$이 주어집니다. 길이가 $N$인 **올바른 괄호열** $S$로 생각할 수 있는 모든 문자열에 대한 $f(S)$의 총합을 구하세요.

답이 매우 커질 수 있으므로 $998\,244\,353$으로 나눈 나머지를 구하세요.

문자열 $A$의 길이를 $|A|$라고 할 때, $A_i$($1\leq i\leq |A|$)는 $A$의 $i$번째 문자를 나타냅니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$T$
$case_1$
$case_2$
$\vdots$
$case_T$
```

$T$는 테스트 케이스의 수를 나타내는 정수입니다. $case_i$는 $i$번째 테스트 케이스를 나타냅니다.

이후 $T$개의 테스트 케이스가 주어지며, 각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- $1\leq T\leq 10^5$
- 각 테스트 케이스에 대해 $1\leq N\leq 10^6$

## 출력

$T$개의 줄에 출력하세요. $1\leq k\leq T$를 만족하는 $k$에 대해, $k$번째 줄에는 $k$번째 테스트 케이스에 대한 답을 출력하세요.

각 테스트 케이스에 대해 $f(S)$의 총합을 $998\,244\,353$으로 나눈 나머지를 $r$이라고 할 때, 다음 형식으로 출력하세요.

```text
$r$
```

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
4
2
11
```

#### 출력

```text
1
0
0
```

$1$번째 테스트 케이스에서 길이가 $4$인 **올바른 괄호열**은 `()()`와 `(())`의 $2$개입니다. $f($`()()`$)=0$, $f($`(())`$)=1$이므로 $1$을 출력합니다.

$3$번째 테스트 케이스에서 길이가 $11$인 **올바른 괄호열**은 존재하지 않습니다. 따라서 $0$을 출력합니다.
