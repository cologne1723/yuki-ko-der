## 문제

엔스쿠미 섬은 특수한 생태계로 평화가 유지되고 있습니다.

* n마리의 동물이 살고 있습니다.
* 동물 i는 동물 i+1을 잡아먹을 수 있습니다(1 ≤ i ≤ n−1).
* 동물 n은 동물 1을 잡아먹을 수 있습니다.

동물들은 잡아먹히고 싶지 않으므로 서로 억제력이 되는 약속을 했습니다. 즉 항상 모든 동물이 포식자라면 동시에 피식자이기도 한 상태를 유지하기로 합의했습니다.

현재 엔스쿠미 섬의 동물들은 뉴엔스쿠미 섬으로 이사를 생각하고 있습니다.

이사는 최대 m마리가 탈 수 있는 배 n척을 사용해 다음 절차로 진행합니다.

* 모든 배는 처음에 엔스쿠미 섬에 있습니다.
* 배에 한 마리 이상 타고 있으면 엔스쿠미 섬과 뉴엔스쿠미 섬 사이를 정확히 편도 1일에 이동할 수 있습니다.
* 충돌 위험 때문에 하루에 동시에 2척 이상의 배를 바다에 내보낼 수 없습니다.
* 모든 동물이 뉴엔스쿠미 섬에 도착한 시점에 이사를 끝냅니다.
* 배를 모두 사용할 필요는 없습니다. 즉 엔스쿠미 섬에 남은 배는 버려도 됩니다.

약속을 지키면서 이사하는 데 필요한 최소 일수를 구하세요. 이사가 불가능하면 -1을 출력하세요.

## 입력

```text
n m
```

2 ≤ n ≤ 100000

2 ≤ m ≤ 50

## 출력

약속을 지키면서 이사하는 데 필요한 최소 일수를 출력하세요.

이사가 불가능하면 -1을 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3 2
```

출력:

```text
-1
```

서로 물고 물리는 세 동물의 경우를 생각해 봅시다.

예를 들어 동물 1과 동물 2가 먼저 배를 타고 이동하려고 하면, 동물 1은 동물 2를 일방적으로 잡아먹을 수 있으므로 배 안의 동물 2가 죽음의 공포에 시달립니다.

동물 1만 먼저 배를 타고 이동하려고 하면, 엔스쿠미 섬에 남은 동물 2가 동물 3을 일방적으로 잡아먹을 수 있으므로 섬에서 동물 3이 죽음의 공포에 시달립니다.

다른 경우도 마찬가지로 아무리 노력해도 이사할 수 없습니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
3 3
```

출력:

```text
1
```

서로 물고 물리는 세 동물의 경우를 생각해 봅시다. 배는 3인승이므로 세 마리가 동시에 타면 항상 서로 물고 물리는 상태를 유지하면서 이동할 수 있습니다. 따라서 1일 만에 이사할 수 있습니다.
