## 문제 설명

yukicoder 가위바위보는 가위바위보를 하여 유루후와 포인트가 더 많은 쪽이 이기는 게임입니다.

$2$명의 플레이어의 이름, 유루후와 포인트, 가위바위보의 손이 주어질 때 승자의 이름을 출력하세요. $2$명의 사람의 포인트가 같으면 무승부이므로 $-1$을 출력합니다.

## 입력

```text
$S_A\ P_A\ X_A$
$S_B\ P_B\ X_B$
```

$1$번째 줄에는 $1$번째 사람의 이름 $S_A$, 유루후와 포인트 $P_A$, 낸 손 $X_A$가 주어집니다. $2$번째 줄에는 $2$번째 사람의 이름 $S_B$, 유루후와 포인트 $P_B$, 낸 손 $X_B$가 주어집니다.

`R`은 바위, `S`는 가위, `P`는 보를 나타냅니다.

## 제한

- $S_A \ne S_B$
- $1 \le |S_A|,|S_B| \le 100$
- $2$개의 이름은 영문 대소문자로만 이루어집니다.
- $0 \le P_A,P_B < 10^{10\,000}$
- 포인트는 앞에 $0$이 붙지 않는 정수입니다.
- $X_A,X_B$는 `R`, `S`, `P` 중 $1$개입니다.

## 출력

승자의 이름을 출력하세요. 무승부이면 $-1$을 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
Alice 114 R
Bob 514 S
```

#### 출력

```text
Bob
```

일반 가위바위보라면 바위 `R`을 낸 Alice가 가위 `S`를 낸 Bob을 이기지만, 이 게임에서는 유루후와 포인트가 더 많은 Bob이 이깁니다.

### 예제 2 {file=""}

#### 입력

```text
touritsu 99999999999999999999 P
Peter 99999999999999999998 R
```

#### 출력

```text
touritsu
```

유루후와에 진심인 touritsuさん과 Peterさん의 대결입니다. 근소한 차이지만 touritsuさん이 이깁니다.

### 예제 3 {file=""}

#### 입력

```text
Taro 0 R
Hanako 0 S
```

#### 출력

```text
-1
```

아직 초보자인 $2$명은 유루후와 포인트가 없습니다. 모두 $0$포인트이므로 무승부입니다.
