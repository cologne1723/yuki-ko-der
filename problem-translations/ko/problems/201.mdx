## 문제 설명

yukicoder 가위바위보는 가위바위보를 하여 유루후와 포인트가 더 많은 쪽이 이기는 게임입니다.

두 플레이어의 이름, 유루후와 포인트, 가위바위보의 손이 주어질 때 승자의 이름을 출력하세요. 두 사람의 포인트가 같으면 무승부이므로 `-1`을 출력합니다.

## 입력

```text
S_A P_A X_A
S_B P_B X_B
```

`R`은 바위, `S`는 가위, `P`는 보를 나타냅니다.

- $S_A \ne S_B$
- $1 \le |S_A|,|S_B| \le 100$
- 두 이름은 영문 대소문자로만 이루어집니다.
- $0 \le P_A,P_B < 10^{10000}$
- 포인트는 앞에 0이 붙지 않는 정수입니다.
- $X_A,X_B$는 `R`, `S`, `P` 중 하나입니다.

## 출력

승자의 이름을 출력하세요. 무승부이면 `-1`을 출력합니다.

## 예제

### 예제 1 {file=""}

```text
Alice 114 R
Bob 514 S
```

```text
Bob
```

일반 가위바위보라면 바위를 낸 Alice가 가위를 낸 Bob을 이기지만, 이 게임에서는 유루후와 포인트가 더 많은 Bob이 이깁니다.

### 예제 2 {file=""}

```text
touritsu 99999999999999999999 P
Peter 99999999999999999998 R
```

```text
touritsu
```

포인트가 조금 더 많은 touritsu가 이깁니다.

### 예제 3 {file=""}

```text
Taro 0 R
Hanako 0 S
```

```text
-1
```

두 사람 모두 포인트가 0이므로 무승부입니다.
