## 문제 설명

직선 위에 $N$개의 지점 $1, 2, \dots, N$이 순서대로 놓여 있고, 지점 $i$에는 코인이 $A_i$개 있습니다.

소는 처음에 지점 $K$에 있습니다. 소는 다음 행동을 여러 번 할 수 있습니다.

1. 현재 지점에 머무르거나 인접한 지점으로 이동합니다. 단, 이미 코인이 없는 지점에는 머무르거나 이동할 수 없습니다.
2. 그 지점에 있는 코인을 $1$개 가져갑니다.

소가 최종적으로 지점 $K$에 있도록 할 때, 가져갈 수 있는 코인 개수의 최댓값을 구하세요.

## 입력

```text
$N$ $K$
$A_1$ $A_2$ ... $A_N$
```

첫째 줄에 지점의 수 $N$과 소의 초기 지점 $K$가 주어집니다.

둘째 줄에 $N$개의 정수가 공백으로 구분되어 주어집니다. $i$번째 정수 $A_i$는 지점 $i$의 코인 개수를 나타냅니다.

## 제한

$1 \le N \le 200\,000$

$1 \le K \le N$

$0 \le A_i \le 10^9$

## 출력

소가 가져갈 수 있는 코인 개수의 최댓값을 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 1
3 2 2 1
```

#### 출력

```text
8
```

모든 지점의 코인을 모을 수 있습니다. 예를 들어 지점 `1 → 2 → 3 → 4 → 3 → 2 → 1 → 1 → 1` 순서로 행동합니다.

### 예제 2 {file=""}

#### 입력

```text
5 3
2 1 0 1 2
```

#### 출력

```text
0
```

지점 $3$에서 다른 지점으로 이동하면 최종적으로 지점 $3$으로 돌아올 수 없으므로 이동할 수 없습니다.

### 예제 3 {file=""}

#### 입력

```text
5 3
3 1 3 1 3
```

#### 출력

```text
5
```

예를 들어 지점 `3 → 2 → 3 → 4 → 3 → 3` 순서로 이동합니다.
