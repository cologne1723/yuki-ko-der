정수 $A,B$가 주어집니다. 당신이 답한 수에 $A$를 곱하고 $B$를 더한 수를 정답으로 정하는 봇과 숫자 맞히기 게임을 합니다. 게임의 정답을 맞히도록 답을 출력하세요.

## 입력

```text
A B
```

## 출력

봇이 정답으로 정한 수를 맞히는 답을 출력하세요.
