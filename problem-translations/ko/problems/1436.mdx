## 문제

유향 그래프의 각 간선을 빨강 또는 초록으로 칠합니다. 상대는 시작 정점 `u`와 목표 정점 `v`를 고르고, 이동 경로에서 빨간 간선 수와 초록 간선 수가 같게 만들 수 있으면 승리합니다.

두 사람이 최적으로 행동할 때 상대가 무엇을 골라도 승리하도록 간선 색을 구성하세요. 불가능하면 이를 보고하세요.

## 입력

`N M`과 유향 간선들이 주어집니다.

`2\le N\le1000`, `1\le M\le2000`입니다.

## 출력

조건을 만족하는 색칠 또는 불가능을 출력하세요.
