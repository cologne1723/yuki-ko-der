※ 이 문제는 회문 경로 (쉬움)과 제한이 다른 문제입니다.

## 문제 설명

$N \times N$개의 칸으로 이루어진 격자가 있습니다. 각 칸 $(i,j)$ $(1 \leq i,j \leq N)$에는 영소문자 $c_{i,j}$가 쓰여 있습니다.

왼쪽 위 칸 $(1,1)$에서 시작하여 오른쪽 또는 아래쪽으로만 이동하는 것을 반복하고, 오른쪽 아래 칸 $(N,N)$인 도착점으로 이동합니다.

이때 지나간 $2N-1$개의 칸(시작점과 도착점을 포함)에 쓰인 문자를 순서대로 읽은 문자열을 $S$라고 합니다.

$(1,1)$에서 $(N,N)$으로 가는 경로 중 문자열 $S$가 회문인 경로의 수를 구하세요.

길이 $M$인 문자열 $T$가 회문이라는 것은 모든 $1 \leq i \leq M$에 대해 $T$의 $i$번째 문자와 $(M+1-i)$번째 문자가 일치하는 것을 의미합니다.

정답은 매우 커질 수 있으므로 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 입력

```text
$N$
$c_{1,1}c_{1,2}\cdots c_{1,N}$
$c_{2,1}c_{2,2}\cdots c_{2,N}$
$\vdots$
$c_{N,1}c_{N,2}\cdots c_{N,N}$
```

$1$번째 줄에 격자의 크기 $N$이 주어집니다.

다음 $N$개 줄에 격자의 각 행이 주어집니다. $i$번째 행에는 $c_{i,1}c_{i,2}\cdots c_{i,N}$이 주어지며, 각 문자는 영소문자입니다.

## 제한

- $2 \leq N \leq 200$
- $c_{i,j}$는 영소문자입니다.

## 출력

회문이 되는 경로의 총 개수를 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
aba
aba
aba
```

#### 출력

```text
2
```

$N=3$이므로 $(1,1)$에서 $(3,3)$으로 이동하는 방법은 $6$가지입니다.

- $(1,1)\to(1,2)\to(1,3)\to(2,3)\to(3,3)$: `abaaa` (회문이 아님)
- $(1,1)\to(1,2)\to(2,2)\to(2,3)\to(3,3)$: `abbaa` (회문이 아님)
- $(1,1)\to(1,2)\to(2,2)\to(3,2)\to(3,3)$: `abbba` (회문)
- $(1,1)\to(2,1)\to(2,2)\to(2,3)\to(3,3)$: `aabaa` (회문)
- $(1,1)\to(2,1)\to(2,2)\to(3,2)\to(3,3)$: `aabba` (회문이 아님)
- $(1,1)\to(2,1)\to(3,1)\to(3,2)\to(3,3)$: `aaaba` (회문이 아님)

회문이 되는 경로는 $2$가지입니다.

### 예제 2 {file=""}

#### 입력

```text
3
ynu
cpc
con
```

#### 출력

```text
0
```

어떤 경로에서도 $S$가 회문이 되지 않으므로 $0$을 출력합니다.
