`L <= A <= B <= R`을 만족하면서 `A+(A+1)+...+B`가 소수가 되는 정수쌍 `(A,B)`의 개수를 구하세요.

## 제약

- `1 <= L <= R <= 10^10`

## 입력

`L R`이 주어집니다.

## 출력

조건을 만족하는 쌍의 개수를 출력하세요.
