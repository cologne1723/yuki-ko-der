## 이야기

**確率的素数判定大好きbot**은 확률적 소수 판정을 아주 좋아하는 봇입니다.

**確率的素数判定大好きbot大好きbot**은 **確率的素数判定大好きbot**을 아주 좋아하는 봇입니다. 물론 이 $2$개의 봇은 서로 다른 봇입니다.

여기서 다음과 같은 문제를 생각해 봅시다.

## 문제 설명

입력으로 양의 정수 $N$과 $100$ 이하의 음이 아닌 정수 $P$, $Q$가 주어집니다.

**確率的素数判定大好きbot**에 양의 정수를 입력하면 다음과 같이 동작합니다.

1. 입력한 양의 정수가 소수라면 $P$%의 확률로 `Yes`라고 답하고, $(100-P)$%의 확률로 `No`라고 답합니다.
2. 입력한 양의 정수가 소수가 아니라면 $Q$%의 확률로 `No`라고 답하고, $(100-Q)$%의 확률로 `Yes`라고 답합니다.

**確率的素数判定大好きbot大好きbot**은 $N$ 이하의 양의 정수 전체에서 양의 정수 $n$을 무작위로 선택합니다. 각 양의 정수가 선택될 확률은 같습니다. 그리고 선택한 $n$을 **確率的素数判定大好きbot**에 입력했습니다. 당신은 $n$의 값을 모르지만, **確率的素数判定大好きbot**이 `Yes`라고 답했다는 사실만 확인했습니다.

위 정보가 주어진 상황에서 $n$이 소수일 확률을 구하세요. 이하 이 값을 이 문제의 답이라고 부릅니다.

입력의 $1$번째 줄에 양의 정수 $T$가 주어집니다. 그 후 $T$개의 문제에 답하세요.

## 입력

입력은 표준 입력에서 다음 형식으로 $1+T$줄에 걸쳐 주어집니다.

- $1$번째 줄에 $T$가 주어집니다.
- $1\leq t\leq T$인 각 양의 정수 $t$에 대해, $t$번째 문제의 입력이 입력 전체의 $1+t$번째 줄에 주어집니다.

```text
$T$
$(1\text{번째 문제의 입력})$
$\vdots$
$(T\text{번째 문제의 입력})$
```

$1\leq t\leq T$인 각 양의 정수 $t$에 대해, $t$번째 문제의 입력은 다음 형식으로 주어집니다.

- $N$, $P$, $Q$가 공백으로 구분되어 입력 전체의 $1+t$번째 줄에 주어집니다.

```text
$N\ P\ Q$
```

각 문제에서의 미지수 $n$은 입력으로 주어지지 않습니다.

## 제한

입력은 다음 제한을 만족합니다.

- $1\leq T\leq10^5$
- $1\leq N\leq10^5$
- $0<P\leq100$
- $0\leq Q\leq100$
- $N>1$이고 $0<P$이거나, $Q<100$입니다.

## 출력

$1\leq t\leq T$인 각 양의 정수 $t$에 대해, $t$번째 문제의 답을 소수로 표현하여 $t$번째 줄에 출력하세요.

마지막에 줄바꿈을 출력하세요.

**이 문제는 소수 오차 허용 문제입니다.** 정확한 답을 소수점 이하 $10$자리까지 근사한 값과의 절대 오차 또는 상대 오차가 $10^{-5}$ 이하이면 정답으로 처리됩니다.

단, 실수 $x$의 소수점 이하 $10$자리까지의 근사값이란 소수점 이하 $10$자리 이하의 유한 소수 중 $x$ 이하인 가장 큰 실수를 뜻합니다.

또한 저지 시스템의 사정에 따라 각 출력은 $500$자리 미만이어야 합니다.
