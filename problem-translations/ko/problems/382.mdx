## 문제

경쟁 프로그래밍 참가자들이 수줍음이 많다는 것은 이미 말했습니다. 어떤 대회에서 온사이트까지 살아남은 참가자 중 몇 명을 골라 팀을 만들고 릴레이 경기 같은 행사를 하려고 합니다. 하지만 팀을 잘못 나누면 대화가 전혀 없어질 수 있습니다.

이를 피하기 위해 조사한 결과, 온사이트 참가자는 $N$명이고 $i$번째 사람과 $j$번째 사람의 친밀도를 나타내는 음이 아닌 정수 $F_{ij}=F_{ji}$를 계산했습니다. 친밀도가 임계값 $P$ 미만이면 두 사람이 대화하지 않을 수 있습니다. 반대로 팀 안에 친밀도가 $P$ 이상인 한 쌍이라도 있으면 대화하기 쉬운 분위기가 퍼진다고 생각합니다.

공평하게 팀은 무작위로 정합니다. 따라서 $k$명($2\le k\le N$)으로 팀을 어떻게 만들더라도 친밀도가 $P$ 이상인 한 쌍이 반드시 존재하게 되는 최소 $k$를 구하세요. 모든 사람이 참가하는 행사가 아니며 반드시 경쟁할 필요도 없으므로, $k$에 따라 한 팀만 만들거나 남는 사람이 생겨도 괜찮습니다.

필요한 정보는 난수로 생성되고 입력에는 난수의 시드 $S$만 주어집니다. 다음 의사 코드로 정보를 생성합니다.

```text
S is given
S = (S × 12345) mod 1000003
N = (S mod 120) + 2
S = (S × 12345) mod 1000003
P = S
for (i = 1; i <= N; i++) {
    for (j = i + 1; j <= N; j++) {
        S = (S × 12345) mod 1000003
        F_{i,j} = F_{j,i} = S
    }
}
```

## 입력

```text
S
```

$1\le S<1000003$이고 $S\in\mathbb Z$입니다.

## 출력

조건을 만족하는 최소 $k$를 한 줄에 출력하세요. 그런 $k$가 없으면 대신 `-1`을 출력하세요.

$k$가 존재하면 확인을 위해 다음 줄에, $k-1$명으로 이루어진 팀 중 모든 사람 사이의 친밀도가 $P$ 미만인 팀의 구성원 번호를 공백으로 구분해 출력하세요. 그런 팀이 여러 개면 하나를 출력하면 됩니다.

스페셜 저지이므로 불필요한 공백 등 사소한 형식 차이도 WA가 될 수 있습니다.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
657
```

### 샘플 1 {file="sample1.out"}

```text
3
1 3
```

난수로 정보를 만들면 $N=3$, $P=859050$이고 친밀도가 $P$ 이상인 쌍은 1번과 2번뿐입니다. 따라서 두 사람을 모두 포함해야 하므로 최소 $k=3$입니다. 2명 팀에서 이 쌍을 포함하지 않는 팀으로 1·3번 또는 2·3번을 선택할 수 있습니다.
