## 문제

양의 정수 `B`와 그 약수 `C`가 주어집니다. 주어진 조건을 만족하는 정수 계수 2×2 행렬을 정점으로 하는 무한 그래프가 정의됩니다. 이 그래프의 연결 성분 수가 100보다 큰지 판정하고, 100 이하라면 그 수를 출력하세요.

## 제약

- `1 ≤ B ≤ 600`
- `C`는 `B`의 약수이고 `1 ≤ C ≤ B`입니다.

## 입력

```text
B C
```

## 출력

연결 성분 수가 100보다 크면 `100+`, 아니면 그 수를 출력하세요.
