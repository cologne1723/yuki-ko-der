이 문제는 리액티브 형식입니다. 일반적인 문제와 형식이 다르므로 주의하세요.

## 문제 설명

kamipeipaa君은 $1$부터 $10^9$까지의 어떤 정수 $x$를 매우 좋아합니다. 하지만 장난꾸러기라 그 수를 알려주지 않습니다. 대신 ‘$x$가 어떤 정수 $y$ 이상인가?’를 질문할 수 있고, kamipeipaa君은 질문에 정직하게 답하기로 했습니다.

kamipeipaa君은 바쁘므로 질문에 최대 $100$번만 답합니다. $100$번 이내의 질문으로 kamipeipaa君이 좋아하는 정수를 맞히세요.

## 입력

질문 질의를 출력하면 응답 프로그램이 답변 프로그램의 표준 입력으로 결과를 돌려줍니다. $x$가 $y$ 이상이면 $1$, 그렇지 않으면 $0$이 입력됩니다.

## 출력

제출한 프로그램(이하 답변 프로그램)은 표준 출력으로 $2$종류의 질의를 출력해야 합니다. 질문 질의는 $x$가 어떤 정수 $y$ 이상인지 묻는 질문 질의이고, 답변 질의는 $x$가 어떤 정수 $y$라고 답하는 답변 질의입니다.

질문 질의의 형식은 다음과 같습니다.

```text
$?\ y$
```

답변 질의의 형식은 다음과 같습니다.

```text
$!\ y$
```

각 질의의 끝에는 개행을 넣으세요.

**출력한 뒤에는 반드시 출력 버퍼를 flush하세요.** flush하지 않으면 응답 프로그램이 입력을 처리하지 못해 시간 제한을 초과할 수 있습니다. 또한 **질문 질의를 실행한 뒤에는 반드시 그 결과를 받아야 합니다.** 그렇지 않으면 응답 프로그램이 입력을 처리하지 못해 오답이 될 수 있습니다.

답변 질의를 실행한 뒤에는 즉시 프로그램을 종료하세요. 종료가 늦어 시간 제한을 초과할 수 있습니다.

이 문제는 스페셜 저지입니다. 제한 시간 안에 종료하고, 질문 횟수가 $100$회 이내이며, 답변 질의로 출력한 $y$가 $x$와 일치하면 정답으로 인정됩니다.

## 주의 사항

- 질문 질의와 답변 질의에서 $y$가 $64$비트 부호 있는 정수의 범위를 벗어날 때 결과는 정의되지 않습니다.
- 저지의 제한 시간은 $2$초이며 응답 프로그램의 반응 시간도 포함됩니다.
- $2$종류의 질의 이외의 내용을 출력하면 오답입니다.
- 표준 에러 출력은 질문 질의, 답변 질의, 잘못된 출력 중 어느 것으로도 간주하지 않습니다.

## 프로그램 예시

```python
import sys
iter = 1
res = 1
while iter <= 4:
    print ("? %d" % iter)
    sys.stdout.flush()
    res = int(input())
    iter += 1
if res==1:
    print("! %d" % res)
else:
    print("! %d" % 2)
sys.stdout.flush()
```
