## 문제 설명

원형으로 나열된 길이 $2$ 이상인 배열 중, 인접한 원소의 합이 서로 같은 경우가 없는 것을 황금 고리라고 정의합니다.

즉, 다음 조건을 모두 만족하는 배열 $A$는 황금 고리입니다.

- $2 \le N$
- $A$는 길이 $N$인 배열입니다.
- $S_i=A_i+A_{i+1}$ ($1 \le i \le N-1$)입니다.
- $S_N=A_N+A_1$입니다.
- $i \ne j$이면 $S_i \ne S_j$입니다.

$1$부터 $N$까지를 나열한 배열 $(1,2,\ldots,N)$이 주어집니다. 이 배열을 자유롭게 재배열하여 황금 고리를 만들 수 있는지 판정하세요. 만들 수 있다면 그 배열을 구하세요.

## 입력

표준 입력에서 다음 형식으로 입력이 주어집니다.

```text
$N$
```

$N$은 배열의 길이를 나타내는 정수입니다.

## 제한

- $2 \le N \le 2\,000$
- $N$은 정수입니다.

## 출력

황금 고리가 되는 배열 $A$를 만들 수 있다면 다음 형식으로 답을 출력하세요.

```text
Yes
$A_1\ A_2\ \ldots\ A_N$
```

해가 여러 개 존재한다면 그중 아무 것이나 출력해도 정답으로 인정됩니다.

만들 수 없다면 `No`를 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
```

#### 출력

```text
Yes
1 3 4 2
```

$A=(1,3,4,2)$로 재배열하면 인접한 원소의 합은 각각 $1+3=4$, $3+4=7$, $4+2=6$, $2+1=3$이므로 $S=(4,7,6,3)$이 됩니다. $S$ 안에 중복되는 값이 없으므로 이 배열은 황금 고리입니다.

그 밖에도 예를 들어 $A=(4,2,1,3)$은 조건을 만족하므로 정답입니다.

$A=(1,2,3,4)$로 만들면 $S=(3,5,7,5)$가 되어 값이 중복되므로 오답입니다.

#### 입력

```text
5
```

#### 출력

```text
Yes
```
