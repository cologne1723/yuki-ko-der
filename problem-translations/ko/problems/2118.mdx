비음이 아닌 정수 $n$에 대해 집합 $S_n$을 정의합니다. $n$의 이진 표현에서 $2^i$의 비트가 $1$인 모든 $i$에 대해 $S_i$를 원소로 갖는 집합들의 모음이 $S_n$입니다. 재귀적으로 정의된 $S_N$을 구하세요.

## 입력

```text
N
```

## 출력

$S_N$을 출력하세요.
