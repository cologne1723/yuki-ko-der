## 문제 설명

yukicoder No.1부터 No.20까지(양 끝 번호를 포함) 사용된 테스트 케이스가 주어집니다. yukicoder No.1부터 No.20까지 중 해당 테스트 케이스가 사용된 문제 번호를 출력하세요.

해당 테스트 케이스와 같은 내용의 파일이 여러 문제에 사용되었다면, 문제 번호가 작은 순서대로 반각 공백으로 구분하여 출력하세요.

여기서 테스트 케이스란 프로그램이 올바른지 판정할 때 사용하는 입력 파일과 출력 파일을 말하며, 샘플에만 작성된 입출력 예제는 포함하지 않습니다.

## 출력

해당 테스트 케이스가 사용된 문제 번호를 문제 번호가 작은 순서대로 반각 공백으로 구분하여 출력하세요.
