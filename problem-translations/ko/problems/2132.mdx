돌이 $n$개 있는 게임을 생각하자냥. Alice가 먼저 시작하고 두 사람이 번갈아 가며 돌을 가져간다냥. 각 차례에는 돌을 1개 가져가거나, 돌을 $X$개 가져갈 수 있냥. $X$개를 가져가는 수를 선택했다면 다음 자신의 차례에는 그 수를 선택할 수 없냥. 돌을 가져갈 수 없는 사람이 패배한다냥.

두 사람이 최적으로 플레이할 때, 게임 $1,2,\ldots,N$ 중 Alice가 이기는 게임의 수를 구하라냥. 답은 $998244353$으로 나눈 나머지를 출력하라냥.

## 조건

- $1 \le T \le 2\times 10^5$
- $1 \le N,X \le 10^{18}$

## 입력

입력은 다음 형식으로 주어진냥.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ X$
```

## 출력

각 테스트 케이스에 대한 답을 한 줄에 하나씩 출력하라냥.


## 예제

### 예제 1 {file=""}

#### 입력

```text
3
4 3
1 1
10000000000 99999999
```

#### 출력

```text
2
1
8778235
```

첫 번째 테스트 케이스에서는 게임 $1$과 게임 $3$에서 Alice가 이깁니다. 게임 $1$에서는 처음에 돌을 $1$개, 게임 $3$에서는 처음에 돌을 $3$개 가져가면 됩니다.

세 번째 테스트 케이스의 답은 $5\,000\,000\,000$이지만, 이를 $998\,244\,353$으로 나눈 나머지를 출력해야 한다는 점에 주의하세요.
