## 이야기

대학생이 된 당신은 아르바이트를 시작하기로 했습니다.

아르바이트를 할 후보로 KCPC사와 KUPC사가 있습니다.

## 문제 설명

KCPC사의 일급 초기값은 $A$엔이고, $B$일 근무할 때마다 $C$엔씩 인상됩니다.

KUPC사의 일급 초기값은 $D$엔이고, $E$일 근무할 때마다 $F$엔씩 인상됩니다.

단, 일급 초기값이 $x$엔이고 $y$일 근무할 때마다 $z$엔씩 인상된다는 것은 정확히 다음을 뜻합니다.

- 처음 근무하는 날을 $1$일째라고 할 때, $i$일째의 일급은 $\displaystyle x+z \times \left\lfloor \frac{i-1}{y} \right\rfloor$엔입니다. ($\lfloor x \rfloor$는 $x$의 소수점 이하를 버린 값입니다.)

당신은 $2$개 회사 중 $1$곳에서 앞으로 매일 근무할 것입니다.

어느 회사에서 아르바이트를 해야 더 빨리 $N$엔을 벌 수 있는지 구하세요.

KCPC사인 경우 `KCPC`, KUPC사인 경우 `KUPC`, $2$개 회사에서 걸리는 일수가 같은 경우 `Same`을 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$A\ B\ C$
$D\ E\ F$
```

## 제한

- $1\leq N\leq 10^{16}$
- $1\leq A,B,C,D,E,F\leq 10^6$
- 입력은 모두 정수입니다.

다음과 같은 부분점수가 설정되어 있습니다.

| 부분점 | 배점 | 제한 |
| --- | ---: | --- |
| 부분점 $1$ | $10$% ($20$점) | $N\leq 10^6$ |
| 부분점 $2$ | $40$% ($80$점) | $N\leq 10^9$ |
| 부분점 $3$ | $50$% ($100$점) | 추가 제한이 없습니다. |

## 출력

정답이 KCPC사인 경우 `KCPC`, KUPC사인 경우 `KUPC`, $2$개 회사에서 걸리는 일수가 같은 경우 `Same`을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
10000
1200 2 100
1500 3 50
```

#### 출력

```text
KUPC
```

KCPC사의 일급은 $1$일째부터 차례로 $1\,200,1\,200,1\,300,1\,300,1\,400,1\,400,1\,500,1\,500,\dots$엔이며, $8$일째에 합계가 $10\,000$엔 이상이 됩니다. KUPC사의 일급은 $1$일째부터 차례로 $1\,500,1\,500,1\,500,1\,550,1\,550,1\,550,1\,600,1\,600,\dots$엔이며, $7$일째에 합계가 $10\,000$엔 이상이 됩니다.

KUPC사가 $10\,000$엔을 더 빨리 벌 수 있습니다.


#### 출력

```text
Same
```

### 예제 3 {file=""}

