## 문제 설명

$H$행 $W$열의 격자가 있습니다.

위에서 $i$번째, 왼쪽에서 $j$번째 칸을 칸 $(i,j)$로 나타냅니다.

칸 $(i,j)$는 $C_{i,j}$가 `#`일 때만 벽이고, $C_{i,j}$가 `.`, `S`, `G`일 때는 길입니다.

高橋くん은 처음에 칸 $(S_x,S_y)$에 있습니다.

현재 있는 칸을 $(x,y)$라고 할 때, 다음 $4$가지 조작 중 길 칸으로 이동하는 $1$가지를 선택하여 몇 번이든 수행할 수 있습니다.

#### 조작 A

- 칸 $(x+1,y)$로 이동합니다.

#### 조작 B

- 칸 $(x-1,y)$로 이동합니다.

#### 조작 C

- 칸 $(x,y+1)$로 이동합니다.

#### 조작 D

- 칸 $(x,y-1)$로 이동합니다.

각 조작을 소수 번씩 수행하여 칸 $(G_x,G_y)$로 이동하는 방법이 있는지 판정하세요.

존재한다면 조작 횟수의 최솟값을 구하세요.

더 엄밀하게는 다음 조건을 만족하는 조작열이 존재하는지 판정하세요.

- 조작 A를 수행한 횟수를 $A$라고 합니다.
- 조작 B를 수행한 횟수를 $B$라고 합니다.
- 조작 C를 수행한 횟수를 $C$라고 합니다.
- 조작 D를 수행한 횟수를 $D$라고 합니다.

$A,B,C,D$가 모두 소수이고, 조작을 수행한 뒤 칸 $(G_x,G_y)$에 도착해야 합니다.

존재한다면 $A+B+C+D$로 가능한 최솟값을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$H\ W$
$S_x\ S_y$
$G_x\ G_y$
$C_{1,1}\ C_{1,2}\ \cdots\ C_{1,W}$
$\vdots$
$C_{H,1}\ C_{H,2}\ \cdots\ C_{H,W}$
```

## 제한

- $1 \le H \le 40$
- $1 \le W \le 40$
- $1 \le S_x,G_x \le H$
- $1 \le S_y,G_y \le W$
- $(S_x,S_y) \ne (G_x,G_y)$
- $C_{i,j}$는 `#`, `.`, `S`, `G` 중 $1$개입니다.
- $C_{S_x,S_y}=$ `S`
- $C_{G_x,G_y}=$ `G`
- $(i,j) \ne (S_x,S_y)$일 때 $C_{i,j} \ne$ `S`
- $(i,j) \ne (G_x,G_y)$일 때 $C_{i,j} \ne$ `G`

## 출력

조건을 만족하는 조작열이 존재하지 않는다면 $-1$을 출력하세요.

조건을 만족하는 조작열이 존재한다면 조작 횟수의 최솟값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 3
1 1
3 3
S..
.#.
.#G
```

#### 출력

```text
16
```

조건을 만족하는 조작열로 `CCDCDCDCAABABABA`가 있습니다. 길이는 $16$입니다.

$15$회 이하의 조작으로 조건을 만족할 수는 없습니다.

### 예제 2 {file=""}

#### 입력

```text
2 8
1 1
2 8
S.......
.......G
```

#### 출력

```text
-1
```

어떻게 조작해도 조건을 만족할 수 없습니다.
