2차원 평면에 서로 다른 $N$개의 점이 있고 점 $i$의 좌표는 $(X_i,Y_i)$입니다. 두 점 사이 거리는 체비쇼프 거리 $\max(\lvert x_0-x_1\rvert,\lvert y_0-y_1\rvert)$로 정의합니다.

## 문제

점 1에서 점 $N$까지 여러 점을 거쳐 이동하는 경로 중 총 이동 거리가 최소인 것의 개수를 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
$N$
$X_1\ Y_1$
$X_2\ Y_2$
$\vdots$
$X_N\ Y_N$
```

$2\le N\le2\times10^5$, $-10^9\le X_i,Y_i\le10^9$이며 점은 서로 다릅니다.

## 출력

최단 경로 수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
0 0
0 1
1 2
```

#### 출력

```text
2
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
5
0 6
1 5
3 2
5 5
3 0
```

#### 출력

```text
4
```

14
