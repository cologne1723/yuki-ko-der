## 문제 설명

양의 정수 $A,B,C,D,E,F$가 주어집니다. 처음에 양의 정수 $A,B,C$를 가지고 있을 때, 다음 작업으로 $(A,B,C)$를 순서대로 $(D,E,F)$로 바꿀 수 있는지 판정하세요.

- 두 실수 $X,Y$를 골라 $X'=(X+Y)/\sqrt2$, $Y'=(X-Y)/\sqrt2$로 바꿉니다.
- 세 수의 순서를 임의로 바꿉니다.

작업은 반드시 한 번 이상 수행해야 하며, 가능한 경우 최소 작업 횟수를 출력하세요.

## 입력

```text
A B C D E F
```

## 출력

가능하면 최소 작업 횟수를, 불가능하면 `-1`을 출력하세요.
