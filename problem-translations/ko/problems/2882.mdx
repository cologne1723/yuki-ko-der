## 문제 설명

$A < B$를 만족하는 양의 정수 $A$, $B$가 주어집니다.

$A \bmod m \geq B \bmod m$를 만족하는 양의 정수 $m$의 개수를 구하세요.

이 제한에서 답이 유한하다는 것을 증명할 수 있습니다.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

## 입력

```text
$T$
$case_1$
$case_2$
$\vdots$
$case_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$A\ B$
```

## 제한

- $T \leq 10$
- $1 \leq A < B \leq 10^9$
- 입력은 모두 정수입니다.

## 출력

$answer_i$를 $case_i$에 대한 답이라고 할 때, 다음 형식으로 출력하고 마지막에 개행을 출력하세요.

```text
$answer_1$
$answer_2$
$\vdots$
$answer_T$
```

#### 입력

```text
3
```

