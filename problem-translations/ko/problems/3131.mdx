## 이야기

퍼즐 게이머인 茜ちゃん과 葵ちゃん은 똑같은 슬라이드 퍼즐을 갖고 싶어 합니다.

## 문제 설명

정수 $N$과 $N$차 정사각행렬 $A$가 주어집니다. 또한, $N$차 정사각행렬 $X$가 있으며 처음에는 $X_{i,j}=(i-1)N+(j-1)$입니다.

$X_{i,j}=0$인 $(i,j)$와 이에 인접한 $(i',j')$를 선택하여 $X_{i,j}$와 $X_{i',j'}$를 맞바꾸는 것을 **슬라이드 조작**이라고 정의합니다.

여기서 $(i,j)$와 $(i',j')$가 인접한다는 것은 $|i-i'|+|j-j'|=1$을 만족하는 것을 말합니다.

또한, $N$차 정사각행렬 $M$에 대한 **즐거움**을 $\displaystyle\sum_{i=1}^N \sum_{j=1}^N (A_{i,j} \times M_{i,j})$로 정의합니다.

다음 조건을 모두 만족하는 $N$차 정사각행렬의 쌍 $(P,Q)$가 존재하는지 판정하고, 존재한다면 $1$개를 제시하세요.

- $P \ne Q$
- $X$에 대해 슬라이드 조작을 $0$회 이상 원하는 횟수만큼 반복하여 $X=P$로 만들 수 있습니다.
- $X$에 대해 슬라이드 조작을 $0$회 이상 원하는 횟수만큼 반복하여 $X=Q$로 만들 수 있습니다.
- $P$의 즐거움과 $Q$의 즐거움이 같습니다.

## 입력

```text
$N$
$A_{1,1}\ A_{1,2}\ \cdots\ A_{1,N}$
$A_{2,1}\ A_{2,2}\ \cdots\ A_{2,N}$
$\vdots$
$A_{N,1}\ A_{N,2}\ \cdots\ A_{N,N}$
```

첫째 줄에 정수 $N$이 주어집니다.

이후 $N$개의 줄에 행렬 $A$의 각 원소 $A_{i,j}$가 주어집니다. 각 줄에는 $N$개의 정수가 공백으로 구분되어 주어집니다.

## 제한

- $2 \leq N \leq 500$
- $1 \leq A_{i,j} \leq 10^8$
- 입력은 모두 정수입니다.

## 출력

조건을 모두 만족하는 행렬의 쌍 $(P,Q)$가 존재하지 않으면 `No`만 출력하세요.

존재한다면 $(P,Q)$를 다음 형식으로 출력하세요. 답이 여러 개 존재하는 경우, 그중 어느 것이든 정답으로 판정됩니다.

```text
Yes
$P_{1,1}\ P_{1,2}\ \cdots\ P_{1,N}$
$P_{2,1}\ P_{2,2}\ \cdots\ P_{2,N}$
$\vdots$
$P_{N,1}\ P_{N,2}\ \cdots\ P_{N,N}$
$Q_{1,1}\ Q_{1,2}\ \cdots\ Q_{1,N}$
$Q_{2,1}\ Q_{2,2}\ \cdots\ Q_{2,N}$
$\vdots$
$Q_{N,1}\ Q_{N,2}\ \cdots\ Q_{N,N}$
```

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
1 2
3 4
```

#### 출력

```text
Yes
0 2 
3 1 
0 3 
1 2
```

$P=\left[\begin{array}{cc}0&2\\3&1\end{array}\right]$, $Q=\left[\begin{array}{cc}0&3\\1&2\end{array}\right]$일 때 다음을 만족하므로 문제의 조건을 만족합니다.

- $P \ne Q$입니다.
- 처음에 $X=\left[\begin{array}{cc}0&1\\2&3\end{array}\right]$인 상태에서 슬라이드 조작을 반복하면 $X=P$와 $X=Q$를 각각 모두 만들 수 있습니다.
- $\displaystyle\sum_{i=1}^N \sum_{j=1}^N (A_{i,j} \times P_{i,j})=17$, $\displaystyle\sum_{i=1}^N \sum_{j=1}^N (A_{i,j} \times Q_{i,j})=17$이므로 $2$개의 행렬의 즐거움이 같습니다.

### 예제 2 {file=""}

#### 입력

```text
3
1 10 100
1000 10000 100000
1000000 10000000 100000000
```

#### 출력

```text

```

이 경우 문제의 조건을 만족하는 $P,Q$는 존재하지 않습니다.
