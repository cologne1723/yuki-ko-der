## 문제 설명

거듭제곱의 근삿값을 구하려고 합니다.

$A^B \simeq X.Y \times 10^Z$

여기서 $A,B,X,Y,Z$는 정수이고 $1 \le X \le 9$, $0 \le Y \le 9$입니다. **$Y$보다 낮은 자릿수는 버립니다.** $A,B$가 여러 쌍 주어질 때 그에 맞는 $X,Y,Z$를 구하세요. $Z$는 $0$이 아니라고 가정합니다.

허용 오차는 출력이 나타내는 값들을 순서대로 정렬했을 때 정답 바로 앞 또는 바로 뒤의 값도 정답으로 인정하는 방식입니다. 예를 들어 정답이 $1.0 \times 10^8$이면 다음과 같이 출력합니다.

```text
        1 0 8 
```

다음 $2$가지 출력도 정답으로 인정합니다.

$1.1 \times 10^8$

```text
        1 1 8
```

$9.9 \times 10^7$

```text
        9 9 7
```

## 입력

```text
$N$
$A_1\ B_1$
$\vdots$
$A_N\ B_N$
```

$A_i,B_i$는 $i$번째 거듭제곱의 매개변수입니다.

## 제한

- $1 \le N \le 10\,000$
- $2 \le A_i,B_i \le 2\,100\,000\,000$
- $10 \le A_i^{B_i}$

## 출력

```text
$X_1\ Y_1\ Z_1$
$\vdots$
$X_N\ Y_N\ Z_N$
```

각 쌍에 대한 근삿값 $X_i,Y_i,Z_i$를 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
2 10
9 9
```

#### 출력

```text
1 0 3
3 8 8
```

$9^9=387\,420\,489$는 **$10^8$ 규모**의 $9$자리 수이며, 최상위 숫자는 $3$, $2$번째 숫자는 $8$입니다. $3$번째 숫자 $7$ 이하는 버립니다.
