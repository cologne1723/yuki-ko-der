## 문제 설명

$N$명의 참가자를 $2$개의 팀으로 나눕니다.

$Q$개의 요구 사항이 있으며, $i$번째 요구 사항은 $t_i$, $a_i$, $b_i$로 나타냅니다.

$t_i=0$일 때 참가자 $a_i$와 $b_i$는 같은 팀이어야 하고, $t_i=1$일 때는 다른 팀이어야 합니다.

모든 요구 사항을 만족하는 나누는 방법의 수를 $998\,244\,353$으로 나눈 나머지를 구하세요.
요구 사항을 만족하는 나누는 방법이 존재하지 않는 경우에는 $0$을 출력하세요.

단, $2$개 팀 중 $1$개의 팀이 비어 있어도 됩니다.
또한, $2$개의 팀은 서로 구별됩니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ Q$
$t_1\ a_1\ b_1$
$\vdots$
$t_Q\ a_Q\ b_Q$
```

## 제한

- $1\le N\le 2\times 10^5$
- $0\le Q\le 2\times 10^5$
- $t_i$는 $0$ 또는 $1$입니다.
- $1\le a_i<b_i\le N$
- 입력은 모두 정수입니다.

## 출력

요구 사항을 모두 만족하는 나누는 방법의 수를 $998\,244\,353$으로 나눈 나머지를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="1_sample_1.txt"}

#### 입력

```text
4 2
0 1 2
1 3 4
```

#### 출력

```text
4
```

참가자 $1$, $2$는 같은 팀이고 참가자 $3$, $4$는 다른 팀이어야 합니다. 독립적으로 정할 수 있는 묶음이 $2$개이므로 $2^2=4$가지입니다.

### 예제 2 {file="1_sample_2.txt"}

#### 입력

```text
3 3
0 1 2
1 2 3
0 1 3
```

#### 출력

```text
0
```

$1$과 $2$가 같고 $2$와 $3$이 다르다면 $1$과 $3$은 달라야 하지만, $3$번째 요구 사항과 모순됩니다.
