## 문제 설명

이 문제는 2014년 11월 26일 2시 35분에 문제문이 수정되었습니다.

A는 `helloworld`를 매우 좋아합니다.

문자열 $S$의 helloworld 수를 다음 조건을 만족하는 순서쌍 $(i_0,\ldots,i_9)$의 개수로 정의합니다.

$$S[i_0]S[i_1]\cdots S[i_9]=\text{\"helloworld\"}$$

$$i_0 < i_1 < \cdots < i_9$$

각 알파벳의 개수가 주어질 때, 각 알파벳을 정확히 그 개수만큼 사용하여 만들 수 있는 문자열 중 helloworld 수의 최댓값을 구하세요.

## 입력

```text
C_a
C_b
:
C_z
```

$C_{\alpha}$ $(0 \le C_{\alpha} \le 100)$는 알파벳 $\alpha$의 개수입니다.

## 출력

A가 얻을 수 있는 helloworld 수의 최댓값을 한 줄에 출력하세요.

출력 마지막에는 줄 바꿈이 있어야 합니다.
