$N$명의 사람이 있으며, 각 사람은 정직한 사람이거나 거짓말쟁이입니다. $Q$개의 주장 중 $i$번째 주장은 사람 $A_i$가 말했습니다.

$C_i=0$이면 사람 $B_i$는 정직한 사람이라고 주장하고, $C_i=1$이면 거짓말쟁이라고 주장합니다.

정직한 사람은 사실을 그대로 말하고, 거짓말쟁이는 정직한 사람을 거짓말쟁이라고, 거짓말쟁이를 정직한 사람이라고 말합니다.

어떤 주장과도 모순되지 않는 정직한 사람과 거짓말쟁이의 배치를 $998244353$으로 나눈 개수를 구하세요.

## 조건

- $2\le N,Q\le 10^5$
- $1\le A_i,B_i\le N$
- $A_i\ne B_i$
- $(A_i,B_i)$는 서로 다릅니다.
- $C_i$는 $0$ 또는 $1$입니다.

## 입력

```text
N Q
A_1 B_1 C_1
...
A_Q B_Q C_Q
```

## 출력

답을 출력하세요.
