Alice는 무게 합이 $W$ 이하가 되도록 선물을 골라 가치 합을 최대로 한다냥. 최댓값을 만드는 선택이 여러 개면 그중 하나를 무작위로 고른다냥. Bob은 무게 $X$인 선물을 준비하며, Alice가 반드시 고르도록 하는 최소 양의 정수 가치 $V$를 $X=1,\ldots,W$마다 구하라냥.

## 조건

- $1\le N\le100$
- $1\le W,w_i\le10^5$
- $1\le v_i\le10^7$

## 입력

```text
N W
w_1 v_1
\vdots
w_N v_N
```

## 출력

$X=1$부터 $W$까지의 $V$를 한 줄에 하나씩 출력하라냥.
