## 문제 설명

함수 $f(X)$를 다음과 같이 정의합니다.

$f(X) = \left\{ \begin{array}{ll} X & (X < 10) \\ f(X의 자릿수 합) & (10 \le X)\end{array} \right.$

다음 조건을 만족하는 원소 수 $N$인 정수 수열 $A$를 "아름다운 수열"이라고 정의합니다.

- 모든 $i$($1 \le i \le N$)에 대해 $10^{L_i} \le A_i < 10^{R_i}$ 또는 $A_i = 0$입니다.
- 모든 $i$($1 \le i \le N$)에 대해 $f(f(A_1) + f(A_2) + \dots + f(A_i)) = D_i$입니다.

정수 $N$과 정수 수열 $L$, $R$, $D$가 주어집니다. "아름다운 수열"의 개수를 $10^9+7$로 나눈 나머지를 구하세요.

## 제한

$1 \le N \le 10^5$

$0 \le L_i < R_i \le 10^{18}$ ($1 \le i \le N$)

$0 \le D_i \le 9$ ($1 \le i \le N$)

$N$, $L_i$, $R_i$, $D_i$는 정수입니다.

## 입력

```text
$N$
$L_1\ L_2\ \dots\ L_N$
$R_1\ R_2\ \dots\ R_N$
$D_1\ D_2\ \dots\ D_N$
```

첫 번째 줄에 정수 $N$이 주어집니다.

두 번째 줄에 정수 수열 $L$이 공백으로 구분되어 주어집니다.

세 번째 줄에 정수 수열 $R$이 공백으로 구분되어 주어집니다.

네 번째 줄에 정수 수열 $D$가 공백으로 구분되어 주어집니다.

## 출력

"아름다운 수열"의 개수를 $10^9+7$로 나눈 나머지를 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
0 1
1 2
3 4
```

#### 출력

```text
10
```

"아름다운 수열"의 예로 $(3,10)$, $(3,55)$ 등을 들 수 있습니다.

이 입력은 다음 조건을 의미합니다.

- $1 \le A_1 < 10$ 또는 $A_1 = 0$
- $10 \le A_2 < 100$ 또는 $A_2 = 0$
- $f(f(A_1)) = 3$
- $f(f(A_1) + f(A_2)) = 4$
