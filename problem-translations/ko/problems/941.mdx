## 문제 설명

칠판에 하나의 양의 정수 $x$가 쓰여 있습니다.

이제 다음 두 단계를 순서대로 수행하는 연산을 $0$회 이상 반복합니다.

1. 칠판에 쓰인 수 하나를 골라 칠판에서 지웁니다. 지운 수를 $a$라고 합니다.
2. 양의 정수 $k$를 하나 골라 $a$를 $k$로 나눈 몫과 나머지, 두 수를 칠판에 새로 씁니다.

연산을 적절히 수행하여 칠판에 쓰인 수들의 모음을 정확히 $A$와 같게 만들고 싶습니다. 더 정확히 말하면, 모든 정수 $i$에 대해 $A$에 나타나는 $i$의 횟수와 칠판 위에 있는 $i$의 개수가 같아지도록 만들고 싶습니다.

$x = 1, 2, 3, \dots, X$에 대해 그러한 일이 가능한지 판정하세요.

## 입력

```text
$N \; X$
$A_1 \; A_2 \; A_3 \; \dots \; A_N$
```

$N$은 $A$의 원소 개수입니다. $A_i$는 $A$의 $i$번째 원소입니다.

## 제한

- $1 \le N \le 100$
- $1 \le X \le 5 \times 10^5$
- $1 \le A_i \le X$ ($1 \le i \le N$)
- 입력은 모두 정수입니다.

## 출력

길이 $X$인 문자열 $S$를 출력하세요.

$S$의 앞에서 $i$번째 문자는 $x = i$일 때 가능하면 `1`, 가능하지 않으면 `0`이어야 합니다. $1 \le i \le X$입니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 5
1 1
```

#### 출력

```text
00111
```

예를 들어 $x = 4$인 경우, 처음 칠판에 쓰여 있는 유일한 정수 $4$를 고르고 $k = 3$으로 하면 됩니다.

```text

```

#### 출력

```text
0000000101
```

