다음 값을 $M$으로 나눈 나머지를 구하라냥.

$$\sum_{n=L}^{R}\left(\left(\prod_{i=1}^{n}\frac1{i^2}\right)\sum_{i=1}^{n-1}\left(\prod_{j=1}^{i}(n-j+1)^2\prod_{j=i+1}^{n}j^2\right)\right)$$

## 조건

- $2\le L\le R\le10^{18}$
- $R-L\le10^5$
- $1\le M\le10^6$

## 입력

```text
L R M
```

## 출력

답을 출력하라냥.

예제는 원문을 참고하라냥.
