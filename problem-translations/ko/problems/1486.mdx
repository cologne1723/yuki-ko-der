## 문제

두 로봇을 동시에 켭니다. 첫 로봇은 `A`초 움직이고 `B`초 멈추는 주기를, 둘째는 `C`초 움직이고 `D`초 멈추는 주기를 반복합니다.

시작 후 `E`초까지 두 로봇이 동시에 움직인 시간의 합을 구하세요.

## 입력

`A B C D E`가 주어집니다.

## 출력

동시에 움직인 시간을 출력하세요.
