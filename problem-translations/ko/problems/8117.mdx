## 이야기

심플하고 세련된 것을 매우 좋아하는 forループさん은 **$2$중 이상으로 중첩할 수 없는** 프로그래밍 언어 `Simplang`을 만들었습니다.

`Simplang`을 사용하여 다음 문제를 해결하는 프로그램을 작성하세요.

## 문제 설명

세로 $H$칸, 가로 $W$칸의 그리드가 $2$개 주어지며, 각각 그리드 $A$, 그리드 $B$라고 합니다. 그리드의 위에서 $i$번째, 왼쪽에서 $j$번째 칸을 칸 $(i, j)$라고 합니다.

그리드 $A$의 칸 $(i, j)$에는 정수 $A_{i,j}$가, 그리드 $B$의 칸 $(i, j)$에는 정수 $B_{i,j}$가 쓰여 있습니다.

$A_{i,j} \ne B_{i,j}$인 칸 $(i, j)$가 **정확히 $1$개** 존재하는 것이 보장됩니다. 그러한 칸 $(i, j)$를 구하세요.

### Simplang의 개요

여기서는 `Simplang`의 언어 사양을 설명합니다. 이 사양을 만족하지 않는 `Simplang` 프로그램을 출력하면 판정 결과가 **WA**가 되므로 주의하세요.

`Simplang`의 샘플 프로그램과 인터프리터 소스 코드는 [Qiita: yukicoder April Fool Contest 2025 「간단한 프로그래밍 언어」(한정 공개)](https://qiita.com/loop0919/private/038cfdd37bac21d0a384)를 참고하세요.

- 값 리터럴에는 $0$ 이상 $10^{100}$ 미만의 정수를 사용할 수 있습니다. 예를 들어 $314$를 정의하려면 `314`라고 쓰면 됩니다.
- 변수는 `$n` 형식으로 사용할 수 있습니다. 여기서 $n$은 $0$ 이상 $10^{100}$ 미만의 정수입니다. 예를 들어 `$0`, `$1`, `$998244353` 등을 사용할 수 있습니다.
- 모든 변수는 처음에 $0$으로 초기화됩니다.
- `변수 = 값` 형식으로 변수에 값을 대입합니다. 예를 들어 `$1 = 2`로 변수 $1$에 정수 $2$를 대입할 수 있습니다.
- 값을 계산할 때 이항 연산자 `+`, `-`, `*`, `/`, `%`를 사용할 수 있습니다.
  - `+`는 덧셈을 나타냅니다. 예를 들어 `$1 + $2`는 (변수 $1$) $+$ (변수 $2$)를, `$1 + 1`은 (변수 $1$) $+$ $1$을 나타냅니다.
  - `-`는 뺄셈을 나타냅니다. 예를 들어 `$1 - $2`는 (변수 $1$) $-$ (변수 $2$)를, `$1 - 1`은 (변수 $1$) $-$ $1$을 나타냅니다.
  - `*`는 곱셈을 나타냅니다. 예를 들어 `$1 * $2`는 (변수 $1$) $\times$ (변수 $2$)를, `$1 * 10`은 (변수 $1$) $\times$ $10$을 나타냅니다.
  - `/`는 버림 나눗셈을 나타냅니다. 예를 들어 `$1 / $2`는 (변수 $1$) $\div$ (변수 $2$) 이하인 정수 중 가장 큰 값을 나타냅니다.
  - `%`는 나머지 연산을 나타냅니다. 예를 들어 `$1 % $2`는 (변수 $1$)을 (변수 $2$)로 나눈 나머지를 나타냅니다.
  - `C`, `C++`, `Java` 등과 버림 나눗셈이나 나머지 연산의 사양이 다르다는 점에 주의하세요.
- 계산 순서는 일반적인 사칙연산과 같지만, 나머지 연산은 곱셈·버림 나눗셈과 같은 우선순위를 가집니다. 괄호 `()`를 사용하면 계산 우선순위를 바꿀 수 있습니다.
- 계산 과정에서 $|x| < 10^{100}$의 범위를 벗어나는 정수 $x$가 만들어져서는 안 됩니다.
- 계산 과정에서 $0$으로 버림 나눗셈을 하거나 $0$으로 나눈 나머지를 구해서는 안 됩니다.
- 단항 연산자와 복합 대입 연산자는 없습니다.
- 각 상수는 값으로 사용할 수 있지만, 그 상수에 새 값을 대입할 수는 없습니다.
  - 예를 들어 `$0 = A[H,$1]`이라고 하면 변수 $0$에 그리드 $A$의 칸 $(H, \text{변수 }1)$에 쓰인 정수를 대입합니다.
- 문제의 값은 다음 상수로 주어집니다.
  - $H$는 상수 `H`로 주어집니다.
  - $W$는 상수 `W`로 주어집니다.
  - $A_{i,j}$는 상수 `A[i,j]`로 주어집니다. 여기서 $1 \le i \le H$, $1 \le j \le W$입니다.
  - $B_{i,j}$는 상수 `B[i,j]`로 주어집니다. 여기서 $1 \le i \le H$, $1 \le j \le W$입니다.
- `A[i,j]`, `B[i,j]`에서 $i$, $j$는 $1 \le i \le H$, $1 \le j \le W$를 만족하는 정수 값이어야 합니다. 인덱스는 $1$부터 시작합니다.
- 제어 구문으로 `if`-`end`문과 `while`-`end`문만 사용할 수 있습니다.
  - `if`-`end`문은 다음 형식의 제어 구문입니다.

    ```text
    if(조건)
      조건이 참일 때만 실행되는 문장
      ...
    end
    ```

    예를 들어 변수 $1$의 절댓값을 구하는 프로그램은 다음과 같습니다.

    ```text
    if($1 < 0)
      $1 = 0 - $1
    end
    ```

  - `while`-`end`문은 다음 형식의 제어 구문입니다.

    ```text
    while(조건)
      조건이 참인 동안 반복 실행되는 문장
      ...
    end
    ```

    예를 들어 $A_{1,1}, A_{1,2}, \cdots, A_{1,W}$의 총합을 변수 $0$에 저장하는 프로그램은 다음과 같습니다.

    ```text
    $1 = 1
    while($1 <= W)
      $0 = $0 + A[1,$1]
      $1 = $1 + 1
    end
    ```
- `if`-`end`문과 `while`-`end`문의 조건은 비교 연산자 `op`를 사용하여 `값 op 값` 형식으로 작성해야 합니다.
- 비교 연산자로 사용할 수 있는 연산은 다음과 같습니다.
  - `<`: 왼쪽 변이 오른쪽 변보다 작으면 참이고, 그렇지 않으면 거짓입니다. 예를 들어 `$1 < H`일 때 (변수 $1$) $<$ $H$이면 참입니다.
  - `<=`: 왼쪽 변이 오른쪽 변 이하이면 참이고, 그렇지 않으면 거짓입니다. 예를 들어 `$1 <= H`일 때 (변수 $1$) $\leq$ $H$이면 참입니다.
  - `>`: 왼쪽 변이 오른쪽 변보다 크면 참이고, 그렇지 않으면 거짓입니다. 예를 들어 `$1 > H`일 때 (변수 $1$) $>$ $H$이면 참입니다.
  - `>=`: 왼쪽 변이 오른쪽 변 이상이면 참이고, 그렇지 않으면 거짓입니다. 예를 들어 `$1 >= H`일 때 (변수 $1$) $\geq$ $H$이면 참입니다.
  - `==`: 왼쪽 변과 오른쪽 변이 같으면 참이고, 그렇지 않으면 거짓입니다. 예를 들어 `$1 == H`일 때 (변수 $1$) $=$ $H$이면 참입니다.
  - `!=`: 왼쪽 변과 오른쪽 변이 다르면 참이고, 그렇지 않으면 거짓입니다. 예를 들어 `$1 != H`일 때 (변수 $1$) $\ne$ $H$이면 참입니다.
- 조건을 변수에 대입할 수는 없습니다.
- 칸 $(i, j)$를 답할 때 `return`문은 **코드의 마지막 줄**에 다음 형식으로 작성합니다.

  ```text
  return(i,j)
  ```

- **$2$중 이상으로 중첩할 수 없습니다.** “$2$중 이상으로 중첩한다”는 것은 다음 조건을 만족하는 $1 \le i < j \le P$ ($P$는 제출한 프로그램의 행 수)가 존재한다는 뜻입니다.
  - $i$번째 줄과 $j$번째 줄 모두 `end`를 부분 문자열로 포함합니다.
  - $i < k < j$인 모든 $k$에 대해 $k$번째 줄은 `if` 또는 `while`을 부분 문자열로 포함하지 않습니다.

  예를 들어 다음 프로그램은 $2$중 이상으로 중첩되어 있으므로 올바른 `Simplang` 프로그램이 아닙니다.

  ```text
  $0 = 0
  $1 = 0
  while($0 < 3)
    if($0 == 2)
      $1 = $0
    end
    $0 = $0 + 1
  end
  return($0, $1)
  ```

  반대로 다음 프로그램은 $2$중 이상으로 중첩되지 않으며 올바른 `Simplang` 프로그램입니다.

  ```text
  $0 = 0
  while($0 < 3)
    $0 = $0 + 1
  end
  if($0 == 3)
    $1 = $0 + 1
  end
  return($0, $1)
  ```
- 프로그램 안의 반각 공백과 탭은 실행할 때 모두 무시됩니다.
- 프로그램의 행 수는 $100$ 이하이어야 하며, 각 행에 포함되는 문자는 반각 공백과 탭을 포함하여 $100$자 이하이어야 합니다.
- 프로그램을 실행할 때 각 행의 실행 횟수 합은 $10^5$ 이하이어야 합니다.

  예를 들어 다음 `Simplang` 프로그램을 생각해 봅시다.

  ```text
  $1 = H
  while($0 < 2)
    $0 = $0 + 1
    $1 = $1 - W
  end
  return($0, $1)
  ```

  이때 다음 순서로 실행됩니다.

  1. `$1 = H`: 변수 $1$에 상수 $H$를 대입합니다.
  2. `while($0 < 2)`: 변수 $0$이 $2$보다 작으면 `while`-`end`문의 처리를 반복합니다. 변수 $0$은 $0$으로 초기화되어 있으므로 조건을 만족합니다.
  3. `  $0 = $0 + 1`: 변수 $0$에 변수 $0$ $+$ $1$을 대입합니다.
  4. `  $1 = $1 - W`: 변수 $1$에 변수 $1$ $-$ 상수 $W$를 대입합니다.
  5. `while($0 < 2)`: 조건을 확인합니다. 이번에는 조건을 만족합니다.
  6. `  $0 = $0 + 1`: 같은 방식으로 덧셈을 합니다.
  7. `  $1 = $1 - W`: 같은 방식으로 뺄셈을 합니다.
  8. `while($0 < 2)`: 조건을 확인합니다. 이번에는 조건을 만족하지 않으므로 `end`문 바로 뒤로 이동합니다.
  9. `return($0, $1)`: $(\text{변수 }0, \text{변수 }1)$을 답으로 냅니다.

  이와 같이 $9$번 실행하여 처리를 완료합니다.

## 입력

표준 입력으로 주어지는 입력은 없습니다. 채점에서는 표준 출력으로 출력된 `Simplang` 프로그램에 대해 $H$, $W$, $A$, $B$가 주어집니다.

## 제한

- $H$, $W$는 $1 \le H, W \le 10$을 만족하는 정수입니다.
- $A_{i,j}$, $B_{i,j}$는 $1 \le A_{i,j}, B_{i,j} \le 100$을 만족하는 정수입니다.
- $A_{i,j} \ne B_{i,j}$인 칸 $(i, j)$가 **정확히 $1$개** 존재합니다.

## 출력

문제의 조건을 만족하는 칸 $(i, j)$를 구하는 `Simplang` 프로그램을 표준 출력으로 출력하세요.

`Simplang` 코드를 직접 작성했다면 제출 언어로 `Text (cat 8.3)`을 선택하여 그대로 제출할 수 있습니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
H: 3
W: 3
A: 1 2 3
   4 5 6
   7 8 9
B: 1 2 3
   4 5 6
   7 9 9
```

#### 출력

```text
(3,2)
```

그리드 $A$의 칸 $(3, 2)$에는 정수 $8$이 쓰여 있지만, 그리드 $B$의 칸 $(3, 2)$에는 정수 $9$가 쓰여 있습니다.

따라서 $A_{3,2} \ne B_{3,2}$이므로 $(3, 2)$를 출력해야 합니다.
