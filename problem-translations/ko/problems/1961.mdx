정규 괄호열을 정의합니다. 괄호열에서 정규 괄호열인 비어 있지 않은 연속 부분 문자열을 하나 삭제하고 남은 문자열을 이어 붙이는 조작을 더 할 수 없을 때까지 수행합니다. 이때 가능한 조작 횟수의 최솟값을 점수라 합니다.

## 문제

`(`, `)`, `?`로 이루어진 문자열 $S$의 `?`를 각각 괄호로 바꿔 얻는 문자열의 점수 최댓값을 구하세요.

## 입력

```text
N
S
```

$1\le N\le2\times10^5$입니다.

## 출력

점수의 최댓값을 출력하세요.
