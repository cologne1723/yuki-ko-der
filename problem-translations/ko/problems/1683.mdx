원점에서 양의 `x`축을 향한 로봇이 있습니다. `G` 명령은 바라보는 방향으로 1칸 전진하고, `T` 명령은 반시계 방향으로 90도 회전합니다.

`G`를 `A`회, `T`를 `B`회 수행해 최종 위치가 `(X,Y)`가 되도록 하는 명령 순서의 개수를 `10^9+7`로 나눈 나머지를 구하세요.

## 입력

`A B X Y`가 주어집니다.

## 출력

조건을 만족하는 명령 순서의 개수를 `10^9+7`로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 1 1 1
```

#### 출력

```text
1
```

### 예제 2 {file=""}

#### 입력

```text
1 6 0 1
```

#### 출력

```text
2
```

### 예제 3 {file=""}

#### 입력

```text
998 244 35 3
```

#### 출력

```text
634338670
```
