0과 1로 이루어진 길이 $N$의 문자열 $M$개로 집합 $S$가 주어진다냥. 서로 다른 두 위치 $n_0,n_1$에 대해 어떤 문자열 $s\in S$가 존재하여 오른쪽에서 $n_0$번째와 $n_1$번째 문자가 다르면 $S$를 좋은 비트열 집합이라고 하자냥. $S$가 좋은지 판정하라냥.

## 조건

- $N,M$은 양의 정수이다냥.
- 각 원소는 길이 $N$의 0과 1 문자열이다냥.

## 입력

```text
N
M
s_1
\vdots
s_M
```

## 출력

좋은 비트열 집합이면 `Yes`, 아니면 `No`를 출력하라냥.
