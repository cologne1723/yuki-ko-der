양의 정수 $N$이 주어집니다. $xy+yz+zx=N$을 만족하는 모든 비음이 아닌 정수쌍 $(x,y,z)$를 출력하세요.

## 조건

- $1\le N\le10^7$

## 입력

정수 $N$이 주어집니다.

## 출력

첫째 줄에 해의 개수 $T$를 출력하고, 다음 $T$개 줄에 서로 다른 해 $(x_i,y_i,z_i)$를 출력하세요. 순서는 자유입니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
```

#### 출력

```text
6
0 1 2
0 2 1
1 0 2
1 2 0
2 0 1
2 1 0
```

### 예제 2 {file=""}

#### 입력

```text
5
```

#### 출력

```text
9
0 1 5
1 0 5
5 0 1
1 5 0
0 5 1
2 1 1
1 1 2
5 1 0
1 2 1
```
