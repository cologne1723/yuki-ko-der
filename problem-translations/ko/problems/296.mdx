## 문제

유키 씨는 아침에 약합니다. 자명종이 울려도 무심코 알람을 끄고 다시 잡니다. 자명종은 알람을 반복하지만, 유키 씨는 계속 알람을 끄고 최종적으로 일어날 때까지 3번, 4번, …, $n$번 다시 잡니다.

자명종이 처음 울리는 시각과 그 이후 알람이 울리는 간격이 주어질 때, 유키 씨가 $n$번 다시 잔다면 최종적으로 일어나는 시각을 구하세요.

다음 사항에 주의하세요.

- $n$번 다시 잔다는 것은 처음 깬 뒤 최종적으로 일어날 때까지 $n-1$번 깨어나는 것을 의미합니다.
- 유키 씨는 알람이 울리면 반드시 깹니다.
- 자명종은 처음 울린 뒤 유키 씨가 최종적으로 일어날 때까지 일정한 간격으로 알람을 반복합니다.
- 최종적으로 일어나는 경우를 제외하면, 유키 씨는 깨어날 때마다 알람을 끄고 다시 잡니다. 이 동작은 순간적으로 끝난다고 가정합니다.
- 서머타임은 고려하지 않습니다.

## 입력

```text
N H M T
```

- $1 \le N \le 10^6$
- $0 \le H \le 23$
- $0 \le M \le 59$
- $1 \le T \le 1440$

$N$은 유키 씨가 다시 자는 횟수입니다. $H$는 처음 알람이 울리는 시각의 24시간제 시 값이고, $M$은 분 값입니다. $T$는 처음 알람이 울린 뒤 알람이 반복되는 간격(분)입니다.

## 출력

유키 씨가 최종적으로 일어나는 시각의 24시간제 시 값과 분 값을 개행으로 구분해 출력하세요.

마지막에 개행을 출력하세요.

시 값은 0 이상 23 이하여야 합니다. 시 값이 0인 경우를 제외하고 앞에 0을 붙이면 안 됩니다.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
2 7 30 5
```

### 샘플 1 {file="sample1.out"}

```text
7
35
```

7시 30분 알람으로는 일어나지 못하고 2번 다시 잤습니다. 결국 다음 알람이 울린 7시 35분에 일어났습니다.

### 샘플 2 {file="sample2.in"}

```text
1 8 0 5
```

### 샘플 2 {file="sample2.out"}

```text
8
0
```

8시 0분 알람이 한 번 울렸을 때 일어날 수 있었습니다.

### 샘플 3 {file="sample3.in"}

```text
7 8 0 5
```

### 샘플 3 {file="sample3.out"}

```text
8
30
```

8시 0분 알람으로는 일어나지 못하고 7번 다시 잤습니다. 결국 8시 30분에 일어났습니다.
