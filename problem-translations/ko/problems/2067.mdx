정수 $n$에서 시작해 $X$를 $X\pm2^k$로 바꾸는 조작의 최소 횟수를 $f(n)$이라 합니다. 각 테스트 케이스에서 $\sum_{n=1}^N f(n)$을 구하세요.

## 입력

```text
T
N_1
...
N_T
```

$1\le T\le10^4$, $1\le N_i\le10^{17}$입니다.

## 출력

각 답을 한 줄에 출력하세요.
