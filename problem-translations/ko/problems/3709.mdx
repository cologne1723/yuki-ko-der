## 문제 설명

유티씨는 $H\times W$ 격자에서 보물을 찾고 있습니다.

각 칸은 좌표 $(r,c)$ $(1 \leq r \leq H, 1 \leq c \leq W)$로 나타냅니다. $r$은 위에서부터 센 행 번호이고, $c$는 왼쪽에서부터 센 열 번호입니다.

유티씨는 미리 $N$개의 정보를 얻었습니다. $i$번째 정보는 왼쪽 위 칸 $(r_{1,i},c_{1,i})$와 오른쪽 아래 칸 $(r_{2,i},c_{2,i})$로 지정한 직사각형 영역에 보물이 **없다**는 뜻입니다.

모든 정보를 바탕으로 보물이 있을 가능성이 있는 칸의 수를 구하세요.

## 입력

```text
$H\ W\ N$
$r_{1, 1}\ c_{1, 1}\ r_{2, 1}\ c_{2, 1}$
$r_{1, 2}\ c_{1, 2}\ r_{2, 2}\ c_{2, 2}$
$\vdots$
$r_{1, N}\ c_{1, N}\ r_{2, N}\ c_{2, N}$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $1 \leq H,W \leq 2\,000$
- $1 \leq N \leq 2\times 10^5$
- $1 \leq r_{1,i} \leq r_{2,i} \leq H$
- $1 \leq c_{1,i} \leq c_{2,i} \leq W$

## 출력

보물이 있을 가능성이 있는 칸의 수를 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 4 2
1 1 3 2
1 2 1 4
```

#### 출력

```text
8
```

각 정보를 반영하면 다음과 같습니다. `x`는 보물이 없는 칸, `.`은 보물이 있을 가능성이 있는 칸입니다.

```text
....      xx..      xxxx
....  ->  xx..  ->  xx..
....      xx..      xx..
....      ....      ....
```

보물이 있을 가능성이 있는 칸은 $8$개이므로 $8$을 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
3 3 3
1 1 3 1
1 2 3 2
1 3 3 3
```

#### 출력

```text
0
```

각 정보를 반영하면 다음과 같습니다.

```text
...      x..      xx.      xxx
...  ->  x..  ->  xx.  ->  xxx
...      x..      xx.      xxx
```

### 예제 3 {file=""}

#### 입력

```text

5 5 5 5
```

#### 출력

```text
80
```

각 정보를 반영하면 다음과 같습니다.

```text
.........    .........
.........    .........
.........    .........
.........    .........
......... -> ....#....
.........    .........
```
