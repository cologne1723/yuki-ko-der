2차원 평면에 빨간색 또는 파란색으로 칠해진 점 `N`개가 있습니다.

`A_i=0`이면 빨간 점으로, 시각 `T_i`에 `(B_i,0)`에서 출발해 단위 시간당 `y`축 양의 방향으로 1만큼 이동합니다. `A_i=1`이면 파란 점으로, 시각 `T_i`에 `(0,B_i)`에서 출발해 단위 시간당 `x`축 양의 방향으로 1만큼 이동합니다.

빨간 점과 파란 점이 같은 시각에 같은 좌표에 존재하는 점 쌍의 개수를 구하세요.

## 제약

- `1 <= N <= 2 * 10^5`
- `A_i`는 0 또는 1입니다.
- `1 <= B_i <= 2 * 10^5`, `0 <= T_i <= 2 * 10^5`

## 입력

각 점의 색, 출발 좌표, 출발 시각 `A_i B_i T_i`가 주어집니다.

## 출력

충돌하는 빨간 점과 파란 점 쌍의 개수를 출력하세요.
