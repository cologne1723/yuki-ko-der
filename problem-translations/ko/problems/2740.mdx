## 문제

짝수 `N`에 대한 순열 `p`가 있습니다. `p`가 빌 때까지 인접한 두 원소 `x,y`를 골라 이 순서 그대로 `q`의 끝에 추가하고 `p`에서 제거합니다. 사전순으로 가장 작은 `q`를 구하세요.

## 제약

- `2 ≤ N ≤ 2×10^5`, `N`은 짝수입니다.
- `p`는 `1,...,N`의 순열입니다.

## 입력

```text
N
p_1 p_2 ... p_N
```

## 출력

사전순 최소인 `q`를 출력하세요.
