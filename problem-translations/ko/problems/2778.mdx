## 이야기

자, 여기서 유~ 씨의 과거에 대해 이야기해 보겠습니다.

유~ 씨는 연애에 좋은 추억이 없습니다.

게다가 고등학교와 대학교 시절에는 거의 여자와 어울리지 않았기 때문에 유~ 씨는 매우 꼬여 버렸습니다.

그렇습니다. 유~ 씨는 서로 잘 맞는 녀석들이 같은 공간에 있는 것을 참을 수 없게 되었습니다. 이는 문자열에서도 마찬가지입니다.

즉, 문자열에 같은 문자가 여러 개 포함되는 것을 참을 수 없는 것입니다.

여러분의 일은 주어진 문자열이 유~ 씨에게 허용되는 문자열인지 아닌지를 유~ 씨의 눈에 띄기 전에 판정하는 것입니다.

## 문제 설명

$N$개의 문자로 이루어진 문자열 $S$가 주어집니다.

문자열 $S$에 같은 문자가 $2$개 이상 존재하는지 판정하세요.

더 엄밀하게는 다음과 같습니다.

- 정수 쌍 $(i, j)$ 중 $1 \le i < j \le N$을 만족하면서 $S$의 $i$번째 문자와 $j$번째 문자가 같은 것이 존재하는지 판정하세요.

## 입력

```text
$N$
$S$
```

입력은 다음 형식으로 주어집니다.

- 첫째 줄에 문자열의 길이인 정수 $N$이 주어집니다.
- 둘째 줄에 영문 대문자로만 이루어진 문자열 $S$가 주어집니다.

## 제한

- $N$은 정수입니다.
- $S$는 영문 대문자로 이루어진 문자열입니다.
- $2 \le N \le 26$
- $|S| = N$

## 출력

같은 문자가 $2$개 이상 존재한다면 `Yes`를, 그렇지 않다면 `No`를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
5
TOKYO
```

#### 출력

```text
Yes
```

`O`가 $2$개 포함되어 있으므로 `Yes`를 출력합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
7
ATCODER
```

#### 출력

```text
No
```

`ATCODER`에 $2$개 이상 포함된 문자는 없습니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
19
QAWSEDRFTGYHUJIKOLP
```

#### 출력

```text
No
```
