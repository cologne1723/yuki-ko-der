## 문제 설명

다음 조건을 만족하는 수열 $X$를 시토시토토 수열이라고 정의합니다.

- $|X|=5$
- $X_1=X_3$
- $X_2=X_4=X_5$
- $X_1\neq X_2$

양의 정수 $N$이 주어집니다. 모든 원소가 $1$ 이상 $N$ 이하인 정수열 $X$ 중 시토시토토 수열인 것의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

```text
$N$
```

## 제한

- $1\leq N\leq 10^6$
- $N$은 정수입니다.

이 문제에는 서브태스크에 의한 부분점이 설정되어 있습니다.

| 서브태스크 이름 | 배점 | 제한 |
| --- | ---: | --- |
| 서브태스크 $1$ | $10$% | $N\leq 2$ |
| 서브태스크 $2$ | $30$% | $N\leq 30$ |
| 서브태스크 $3$ | $60$% | 추가 제한 없음 |

## 출력

답을 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
```

#### 출력

```text
6
```

예를 들어, $X=(3,2,3,2,2)$ 및 $X=(1,2,1,2,2)$ 등은 조건을 만족합니다.

조건을 만족하는 $X$는 모두 $6$개이므로 $6$을 출력하세요.

### 예제 2 {file=""}

#### 입력

```text
1
```

#### 출력

```text
0
```

조건을 만족하는 수열은 존재하지 않습니다.

### 예제 3 {file=""}

#### 입력

```text
169231
```

#### 출력

```text
688120246
```

답을 $998\,244\,353$으로 나눈 나머지로 출력해야 한다는 점에 주의하세요.
