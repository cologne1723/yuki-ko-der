양의 정수 `N`이 주어집니다. `floor(sqrt(N))`을 구하세요. 여러 테스트 케이스를 처리합니다.

## 제약

- `1 <= T <= 10^4`
- `1 <= N <= 10^18`

## 입력

첫째 줄에 `T`, 각 테스트 케이스에 `N`이 주어집니다.

## 출력

각 테스트 케이스의 답을 한 줄에 하나씩 출력하세요.
