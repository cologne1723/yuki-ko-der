각 테스트 케이스에서 $\prod_{i=1}^N A_i$가 제곱수인지 판정하세요.

## 입력

```text
T
N
A_1 A_2 ... A_N
```

$1\le T\le500$, $1\le N\le1000$이고 모든 테스트 케이스의 $N$ 합은 $2000$ 이하입니다.

## 출력

곱이 제곱수이면 `Yes`, 아니면 `No`를 출력하세요.
