## 문제 설명

음이 아닌 정수 $N$과 양의 정수 $B$가 주어집니다.

$Ni \equiv 1 \pmod{B}$를 만족하는 음이 아닌 정수 $i$가 존재하는지 판정하고, 존재한다면 그러한 $i$의 최솟값을 구하세요.

단, 음이 아닌 정수 $n,m$에 대해 $n \equiv m \pmod{B}$라는 것은 $n-m=kB$를 만족하는 정수 $k$가 존재한다는 뜻입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 $1$줄로 주어집니다.

```text
$N\ B$
```

$1$번째 줄에 $N$과 $B$가 반각 공백으로 구분되어 주어집니다.

## 제한

- $N$은 $0 \leq N \leq 10^{19}$을 만족하는 정수입니다.
- $B$는 $1 \leq B \leq 10^6$을 만족하는 정수입니다.

## 출력

$Ni \equiv 1 \pmod{B}$를 만족하는 음이 아닌 정수 $i$가 존재한다면 그러한 $i$의 최솟값을 $1$줄에 출력하세요. 존재하지 않는다면 `NaN`을 출력하세요.

출력 끝에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1
```

#### 출력

```text
0
```

$(N,B)=(1,1)$입니다. $i=0$으로 정하면 $i$는 음이 아닌 정수이고 $Ni=0 \equiv 1 \pmod{B}$를 만족합니다. $0$보다 작은 음이 아닌 정수는 존재하지 않으므로, $0$은 문제에서 $i$에 부과된 조건을 만족하는 음이 아닌 정수의 최솟값입니다.

### 예제 2 {file=""}

#### 입력

```text
0 2
```

#### 출력

```text
NaN
```

$(N,B)=(0,2)$입니다. 어떤 음이 아닌 정수 $i$에 대해서도 $Ni=0 \not\equiv 1 \pmod{B}$입니다.

### 예제 3 {file=""}

#### 입력

```text
1 2
```

#### 출력

```text
1
```

$(N,B)=(1,2)$입니다. $i=1$로 정하면 $i$는 음이 아닌 정수이고 $Ni=1 \equiv 1 \pmod{B}$를 만족합니다. $1$보다 작은 음이 아닌 정수는 $0$뿐이며, $0$은 문제에서 $i$에 부과된 조건을 만족하지 않으므로 $1$은 조건을 만족하는 음이 아닌 정수의 최솟값입니다.

### 예제 4 {file=""}

#### 입력

```text
2 3
```

#### 출력

```text
2
```

$(N,B)=(2,3)$입니다. $i=2$로 정하면 $i$는 음이 아닌 정수이고 $Ni=4 \equiv 1 \pmod{B}$를 만족합니다. $2$보다 작은 음이 아닌 정수는 $0,1$뿐이며, $0,1$은 모두 문제에서 $i$에 부과된 조건을 만족하지 않으므로 $2$는 조건을 만족하는 음이 아닌 정수의 최솟값입니다.

### 예제 5 {file=""}

#### 입력

```text
2 4
```

#### 출력

```text
NaN
```

$(N,B)=(2,4)$입니다. 어떤 음이 아닌 정수 $i$에 대해서도 $Ni \equiv 0 \not\equiv 1 \pmod{2}$이고, $2$는 $B$의 약수이므로 특히 $Ni \not\equiv 1 \pmod{B}$입니다.

### 예제 6 {file=""}

#### 입력

```text
10000000000000000000 7
```

#### 출력

```text
5
```

이처럼 $N$이 $32$비트 정수의 범위에 들어가지 않을 수도 있습니다.

$(N,B)=(10^{19},7)$입니다. $i=5$로 정하면 $i$는 음이 아닌 정수이고 $Ni=5 \times 10^{19} \equiv 1 \pmod{B}$를 만족합니다. $5$보다 작은 음이 아닌 정수는 어느 것도 문제에서 $i$에 부과된 조건을 만족하지 않으므로, $5$는 조건을 만족하는 음이 아닌 정수의 최솟값입니다.

여기서 중간 계산에 나타나는 $5 \times 10^{19}$가 $64$비트 정수의 범위에도 들어가지 않는다는 점에 주의하세요.
