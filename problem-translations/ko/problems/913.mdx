## 문제 설명

나무 $N$그루가 가로로 한 줄로 심어져 있으며, 왼쪽에서 $i$번째 나무의 가치는 $A_i$입니다.

원하는 연속 구간을 골라 그 안의 나무를 모두 태웁니다.
태운 나무의 수를 $x$라고 할 때, **슬픔**을 $x^2$에 (태운 나무의 가치의 합)을 더한 값으로 정의합니다.

각 나무에 대해, 그 나무를 반드시 태울 때의 **슬픔**의 최솟값을 구하세요.

## 입력

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
```

입력은 모두 정수입니다.

## 제한

- $1 \le N \le 2 \times 10^5$
- $|A_i| \le 10^9$이며 $1 \le i \le N$입니다.

## 출력

$N$개의 줄을 출력하세요. $i$번째 줄에는 왼쪽에서 $i$번째 나무를 반드시 태울 때의 **슬픔**의 최솟값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
-2 -5 100
```

#### 출력

```text
-3
-4
99
```

- 첫 번째 나무를 반드시 태우는 경우, 구간 $[1, 2]$의 나무를 태우는 것이 최적입니다. 이때 **슬픔**은 $2^2+(-2-5)=-3$입니다.
- 두 번째 나무를 반드시 태우는 경우, 구간 $[2, 2]$의 나무를 태우는 것이 최적입니다. 이때 **슬픔**은 $1^2+(-5)=-4$입니다.
- 세 번째 나무를 반드시 태우는 경우, 구간 $[2, 3]$의 나무를 태우는 것이 최적입니다. 이때 **슬픔**은 $2^2+(-5+100)=99$입니다.

### 예제 2 {file=""}

#### 입력

```text
5
-10000 0 -10000 0 -10000
```

#### 출력

```text
-29975
-29975
-29975
-29975
-29975
```

어느 나무를 반드시 태우는 경우이든 모든 나무를 태우는 것이 최적입니다.

### 예제 3 {file=""}

#### 입력

```text
1
0
```

#### 출력

```text
1
```
