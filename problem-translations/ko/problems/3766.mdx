## 문제 설명

양의 정수 $N$과 음이 아닌 정수 $K$가 주어집니다. $\color{red}(0,1,\dots,N-1)$의 순열 쌍 $(P=(P_1,P_2,\dots,P_N),Q=(Q_1,Q_2,\dots,Q_N))$ 중 다음 조건을 만족하는 것이 있는지 판별하고, 있다면 하나 구하세요.

- $\displaystyle\bigvee_{i=1}^{N}\ (P_i \land Q_i)=K$

$\land$는 비트 단위 AND를 나타냅니다. $\displaystyle\bigvee_{i=1}^{N}$은 $i=1,\dots,N$에 대한 비트 단위 OR를 나타냅니다.

## 입력

```text
$N\ K$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $1 \leq N \leq 2\times 10^5$
- $0 \leq K < 2^{18}$

## 출력

조건을 만족하는 쌍 $(P,Q)$가 없으면 `No`를 출력하세요. 있다면 첫째 줄에 `Yes`, 둘째 줄에 $P$, 셋째 줄에 $Q$를 다음 형식으로 출력하세요.

```text
Yes
$P_1\ P_2\ \dots\ P_N$
$Q_1\ Q_2\ \dots\ Q_N$
```

조건을 만족하는 쌍이 여러 개이면 어느 것이든 정답으로 인정됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 2
```

#### 출력

```text
Yes
2 3 0 1
3 2 1 0
```

비트 단위 OR의 이항 연산자를 $\lor$로 나타냅니다.

$P=(2,3,0,1),Q=(3,2,1,0)$에 대해 $\bigvee_{i=1}^{N}\ (P_i \land Q_i)=(2\land 3)\lor(3\land 2)\lor(0\land 1)\lor(1\land 0)=2\lor 2\lor 0\lor 0=2$이므로 조건을 만족합니다.

### 예제 2 {file=""}

#### 입력

```text
6 10
```

#### 출력

```text
No
```

조건을 만족하는 쌍 $(P,Q)$가 없습니다.

### 예제 3 {file=""}

#### 입력

```text
9 12
```

#### 출력

```text
Yes
0 1 2 3 4 5 6 7 8
3 6 1 0 7 2 5 4 8
```
