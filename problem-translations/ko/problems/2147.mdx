3개의 기둥 A, B, C와 크기가 서로 다른 $N$개의 원판으로 이루어진 하노이 탑 장난감이 있다냥. 원판에는 작은 것부터 $1$번부터 $N$번까지 번호가 붙어 있고, 처음에는 모든 원판이 작은 원판이 위에 오도록 기둥 A에 꽂혀 있다냥. 한 번의 조작에서는 원판이 꽂힌 기둥 하나의 맨 위 원판 $D$를 빼고, $D$보다 작은 원판이 꽂혀 있지 않은 다른 기둥 하나에 $D$를 꽂는다냥.

현재 상태가 주어질 때 초기 상태로 되돌리는 데 필요한 조작 횟수의 최솟값을 $10^9+7$로 나눈 나머지를 출력하라냥.

## 조건

- $1\le N\le1000$
- 문자열 $S$는 `A`, `B`, `C`로만 이루어진 길이 $N$의 문자열이다냥.

## 입력

```text
N
S
```

문자열 $S$의 $i$번째 문자는 $i$번 원판이 꽂힌 기둥을 나타낸다냥.

## 출력

최솟값을 $10^9+7$로 나눈 나머지를 출력하라냥.

## 예제

예제는 원문을 참고하라냥.
