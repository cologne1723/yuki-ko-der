## 문제 설명

디렉터리 `/bin` 바로 아래의 내용을 사전순으로 출력하세요. 단, `.`으로 시작하는 항목은 제외하세요.

## 입력

입력은 주어지지 않습니다.

## 출력

`/bin`의 내용을 사전순으로, 각 항목을 $1$줄에 $1$개씩 출력하세요.


#### 출력

```text

sh
```
