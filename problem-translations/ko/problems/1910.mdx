정수열에서 모든 앞 원소보다 큰 원소를 ‘높은 항’이라 합니다. $R_1=C_1=1$인 길이 $H,W$의 수열 $R,C$가 주어집니다.

## 문제

각 원소가 $1$ 이상 $10^9$ 이하이고, 각 행의 높은 항 수가 $R_i$, 각 열의 높은 항 수가 $C_j$가 되는 $H\times W$ 행렬을 하나 구성하세요.

## 입력

```text
H W
R_1 ... R_H
C_1 ... C_W
```

$1\le H,W\le500$, $1\le R_i\le W$, $1\le C_j\le H$입니다.

## 출력

조건을 만족하는 행렬을 출력하세요.
