## 문제 설명

$2$명의 손을 겹쳐 잡고, 암호는 "도파민"입니다.

어느 링크에서든 같은 파일을 받을 수 있습니다.

- [Dropbox](https://www.dropbox.com/sh/zd58dk0erk52e5o/AABy_mz29pB6N6KOeTQ7uTqea?dl=0)
- [Google Drive](https://drive.google.com/open?id=1lAyJmhfpA0oHDZTpypEQHraWYpDAseVI)

## 입력

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
```

## 제한

- 입력은 모두 정수입니다.
- $1 \leq N \leq 2 \times 10^5$
- $1 \leq A_i \leq 10^9$

## 출력

답을 $1$행에 출력하고, 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
1 2 3 4 5
```

#### 출력

```text
2
```
