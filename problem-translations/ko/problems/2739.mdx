## 문제

`N`개의 도시와 양방향 도로가 있습니다. 도로 `i`는 통행료 `C_i`엔, 이동 시간 `T_i`시간이 듭니다. 도시 1에서는 일할 수 있고, 1시간 일할 때마다 `X`엔을 얻습니다.

현재 도시 1에 돈 0엔으로 있습니다. 도시 1에서 도시 `N`으로 이동할 때 필요한 최소 시간을 구하세요. 도달할 수 없으면 `-1`을 출력합니다.

## 제약

- `2 ≤ N,M ≤ 2×10^5`, `1 ≤ X ≤ 2×10^5`
- `1 ≤ C_i,T_i ≤ 2×10^5`

## 입력

```text
N M X
u_1 v_1 C_1 T_1
⋮
u_M v_M C_M T_M
```

## 출력

최소 시간을 출력하세요.
