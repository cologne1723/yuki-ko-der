무한한 격자 도시에서 집은 $(0,0)$입니다. 도로는 음이 아닌 정수 $n,m$에 대해 $x=An$, $y=Bm$인 직선뿐입니다. 양의 정수 좌표 $(x,y)$에 카페를 지으려 합니다.

## 문제

$x+y\le N$이고 도로 위만 지나 집에서 도달 가능한 후보지의 개수를 구하세요.

## 입력

```text
T
N A B
```

$1\le T\le10^5$, $2\le N\le10^9$, $1\le A,B\le10^9$입니다.

## 출력

각 테스트 케이스의 답을 출력하세요.
