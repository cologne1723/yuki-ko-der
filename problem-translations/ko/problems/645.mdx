## 문제

다음 조건을 만족하는 $(1,2,\ldots,N)$의 순열 $A$ 개수를 $1{,}000{,}000{,}007$로 나눈 나머지로 구하세요.

조건: $f(B)=A$를 만족하는 순열 $B$의 개수가 $L$ 이상 $R$ 이하입니다. $f(B)$는 $B$에 다음 연산을 수행한 결과입니다. $i=1,2,\ldots,N-1$ 순서로, $B_i>B_{i+1}$이면 두 값을 교환합니다.

## 입력

```text
N L R
```

- $2\le N\le10^5$
- $0\le L\le R\le10^{18}$

## 출력

조건을 만족하는 순열의 개수를 나머지로 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
5 2 7
```

출력:

```text
17
```

예를 들어 $B=(2,4,1,3,5)$에 연산을 적용하면 $(2,1,3,4,5)$가 됩니다. $i=2,3$에서 각각 인접한 역순을 교환하고, 나머지는 그대로 둡니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
10 0 3628800
```

출력:

```text
3628800
```

이는 $10!=3628800$이므로 모든 순열이 조건을 만족합니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
1000 1000 1000
```

출력:

```text
0
```

### 샘플 4 {file="sample4.in"}

입력:

```text
100 1000000000 1000000000000000000
```

출력:

```text
2041684
```
