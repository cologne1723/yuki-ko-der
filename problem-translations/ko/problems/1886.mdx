순열 $P$에 대해 $1\le K\le N$일 때

$$f_K(P)=\sum_{i=1}^{N-K+1}\max(P_i,P_{i+1},\ldots,P_{i+K-1})$$

로 정의합니다.

## 문제

모든 $N!$개의 순열에 대해 $f_K(P)$를 계산한 총합을 $K=1,\ldots,N$ 각각에 대해 $998244353$으로 나눈 나머지로 출력하세요.

## 입력

```text
N
```

$1\le N\le2\times10^5$입니다.

## 출력

$K=1,\ldots,N$의 답을 각각 한 줄에 출력하세요.
