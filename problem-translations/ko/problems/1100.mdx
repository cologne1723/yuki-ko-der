## 문제 설명

서로 구별되는 공 $N$개를 서로 구별되는 상자 $K$개에 넣습니다.

단, 공이 하나도 들어 있지 않은 상자의 개수가 홀수가 되도록 하고 싶습니다.

조건을 만족하도록 공을 넣는 방법의 수를 구하세요.

답은 매우 커질 수 있으므로, $998244353$으로 나눈 나머지를 출력하세요.

## 입력

```text
$N\ K$
```

입력은 다음 제한을 만족합니다.

## 제한

- 입력은 모두 정수입니다.
- $1 \leq N \leq 10^7$
- $1 \leq K \leq 10^5$

## 출력

조건을 만족하도록 공을 넣는 방법의 수를 $998244353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 3
```

#### 출력

```text
6
```

공이 $2$개, 상자가 $3$개 있습니다.

두 공을 같은 상자에 넣으면 공이 하나도 들어 있지 않은 상자의 개수는 $2$개가 되어 조건을 만족하지 않습니다.

두 공을 서로 다른 상자에 넣으면 공이 하나도 들어 있지 않은 상자의 개수는 $1$개가 되어 조건을 만족합니다.

따라서 답은 두 공을 서로 다른 상자에 넣는 방법의 수와 같으며, $6$가지입니다.

### 예제 2 {file=""}

#### 입력

```text
4 1
```

#### 출력

```text
0
```

모든 공을 같은 상자에 넣게 되므로, 어떻게 넣어도 공이 하나도 들어 있지 않은 상자의 개수는 $0$개(짝수)가 됩니다.

### 예제 3 {file=""}

#### 입력

```text
5 4
```

#### 출력

```text
604
```

### 예제 4 {file=""}

#### 입력

```text
1000 100
```

#### 출력

```text
656749944
```

답을 $998244353$으로 나눈 나머지를 출력하세요.
