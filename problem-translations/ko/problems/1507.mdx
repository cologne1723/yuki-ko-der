## 문제

$N$개 정점의 트리에서 서로 다른 정점 $A,B$ 두 개와 간선 $E$ 하나를 무작위로 고릅니다. 간선 $E$를 제거한 뒤에도 $A,B$가 연결되어 있을 확률을 $998244353$로 나눈 값으로 출력하세요.

## 입력

$N$과 트리의 간선이 주어집니다.

- $2\leq N\leq10^5$

## 출력

확률을 $p/q$라 할 때 $qk\equiv p\pmod {998244353}$를 만족하는 $0\leq k<998244353$를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
1 2
2 3
3 4
```

#### 출력

```text
776412275
```

### 예제 2 {file=""}

#### 입력

```text
2
1 2
```

#### 출력

```text
0
```

### 예제 3 {file=""}

#### 입력

```text
5
4 5
2 1
5 1
1 3
```

#### 출력

```text
648858830
```
