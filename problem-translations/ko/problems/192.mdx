## 문제 설명

정수 $N$이 주어집니다. $N-100$ 이상 $N+100$ 이하인 합성수를 $1$개 찾아 출력하세요.

합성수란 $1$과 자기 자신 이외의 양의 약수를 가지는 양의 정수입니다.

## 입력

```text
$N$
```

## 제한

- $101 \le N \le 1\,000$

## 출력

$N-100$ 이상 $N+100$ 이하인 합성수를 $1$개 출력하세요. 앞뒤의 공백 문자는 무시됩니다. 입력 제한을 만족하는 모든 $N$에 대해 이러한 수가 존재합니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
101
```

#### 출력

```text
4
```

$1, 2, 3$은 합성수가 아니지만 $4$는 $1$과 $4$ 이외에 $2$를 약수로 가지므로 합성수입니다.

### 예제 2 {file=""}

#### 입력

```text
1000
```

#### 출력

```text
1000
```

$N$ 자체가 합성수라면 그것을 출력해도 정답입니다.
