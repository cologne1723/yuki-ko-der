잠깐. 기다리세요. 흥분한 것은 알겠지만 서두르면 안 됩니다. 조금만 더 기다리세요.………자, 귤 표면의 하얀 섬유 이름을 알고 있나요?

생각해 본 적도 없는 모양이군요. 버리기만 하며 관심도 갖지 않고 살아왔겠지만, 이제부터는 껍질을 벗길 때 이름을 떠올릴 수 있게 되겠군요.

대답할 준비는 되었나요? 흠흠. 그렇군요, 그렇게 생각했군요. 틀렸습니다. 정답은 「알베도」입니다.

잘 기억에 새겨 두세요.

## 문제 설명

문제문에 쓰여 있는 수치를 구하세요.

## 입력

이 문제는 여러 테스트 케이스로 구성됩니다.

$T$는 테스트 케이스의 수입니다.

각 테스트 케이스에 대해 정수 $N_i$가 주어집니다. $N_i$는 $i$번째 테스트 케이스의 정수이며, $1 \leq i \leq T$입니다.

```text
$T$
$N_1$
$N_2$
$\vdots$
$N_T$
```

## 제한

- $1 \leq T \leq 10^5$
- $1 \leq N_i \leq 10^5$ ($1 \leq i \leq T$)

## 출력

문제문에 쓰여 있는 수치를 구하세요.
