문자열 `X`가 특정 조건을 만족하면 두드리기 쉽다고 합니다. 문자열 `Y'`가 `Y`의 배열이라는 것은 길이가 같고 `.`,`d`,`k`만으로 이루어지며, 원래 문자가 `.`이 아니면 그대로이고 인접한 조건을 만족하는 것을 뜻합니다.

길이 `16N`인 문자열 `S`가 주어질 때, `S`의 배열 중 두드리기 쉬운 것의 개수를 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `1 <= N <= 12500`
- `S`는 `.`,`d`,`k`로 이루어진 길이 `16N` 문자열입니다.

## 입력

`N`과 16글자씩 나뉜 문자열 `S`가 주어집니다.

## 출력

조건을 만족하는 배열의 개수를 출력하세요.
