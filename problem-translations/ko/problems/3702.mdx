## 이야기

コワスギ高校의 학생인 すうけん君은 이제 시험을 치르려고 합니다.

## 문제 설명

すうけん君이 치를 시험은 $N$개입니다. すうけん君은 미래를 예지할 수 있어서 각 시험의 점수를 확인해 보았더니, $i$번째 시험의 점수는 $A_i$점이었습니다. 현재 간신히 유급을 면하고 있는 すうけん君은 시험에서 $1$개라도 낙제점, 즉 $30$점 미만을 받으면 유급이 확정됩니다.

하지만 학교의 너무나 무서운 방침에 따라, 적어도 $K$개의 시험을 치르지 않으면 그 시점에 유급이 됩니다. 원하는 개수만큼 시험을 치르지 않아 그 점수를 무시할 수 있을 때, 유급을 피할 수 있는지 판정하세요.

## 입력

```text
$N\ K$
$A_1\ A_2\ A_3\ \cdots\ A_N$
```

## 제한

- $1 \le K \le N \le 100$
- $0 \le A_i \le 100$
- 입력은 모두 정수입니다.

## 출력

유급하지 않도록 시험을 치르는 방법이 존재하면 `Yes`를, 그렇지 않으면 `No`를 출력하세요.

답 이외에는 아무것도 출력하지 마세요. 입력을 요청하는 문장 등도 출력하지 마세요.

답안 형식은 연습 문제나 그 답안 예시를 참고해도 되지만, 링크는 제공하지 않는다는 점에 주의하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 3
49 24 14 83 30
```

#### 출력

```text
Yes
```

$2$번째 과목과 $3$번째 과목의 시험을 치르지 않으면, 시험을 치른 모든 과목의 점수가 $30$점 이상이 됩니다.


### 예제 2 {file=""}

#### 입력

```text
5 5
0 0 0 0 0
```

#### 출력

```text
No
```


### 예제 3 {file=""}

#### 입력

```text
7 4
29 83 43 12 30 0 5
```

#### 출력

```text
No
```
