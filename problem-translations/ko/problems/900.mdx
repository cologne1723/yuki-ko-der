## 문제 설명

niuez는 나무를 성장시키는 첨가물을 만들어 그 효과를 시험해 보려고 합니다.
하지만 나무가 얼마나 커질지 짐작도 못한 채 시험하는 것은 위험하므로, 미리 시뮬레이션하기로 했습니다.

$0$부터 $N-1$까지 번호가 붙은 $N$개의 정점과 $N-1$개의 간선으로 이루어진 방향 트리가 있습니다. 루트는 $0$번 정점입니다.
$i$번 간선은 $u_i$번 정점에서 $v_i$번 정점으로 향하며, 가중치는 $w_i$입니다. $0 \le i < N-1$입니다.

다음 두 형식의 쿼리 $Q$개를 순서대로 처리하세요.

$1\ a\ x$

유형 $1$ 쿼리: $a$번 정점을 루트로 하는 서브트리에 포함된 모든 간선의 가중치에 $x$를 더합니다.

$2\ b$

유형 $2$ 쿼리: $0$번 정점에서 $b$번 정점으로 가는 경로에 포함된 간선의 가중치 합을 구합니다.

## 입력

```text
$N$
$u_0\ v_0\ w_0$
$\vdots$
$u_{N-2}\ v_{N-2}\ w_{N-2}$
$Q$
$\mathrm{query}_0$
$\vdots$
$\mathrm{query}_{Q-1}$
```

$\mathrm{query}_i$는 위에서 설명한 두 형식 중 하나로 주어집니다. $0 \le i < Q$입니다.
입력은 모두 정수입니다.

유형 $1$ 쿼리의 입력 형식은 다음과 같습니다.

```text
$1\ a\ x$
```

유형 $2$ 쿼리의 입력 형식은 다음과 같습니다.

```text
$2\ b$
```

## 제한

- $2 \le N \le 10^5$
- $0 \le u_i, v_i < N$이며 $u_i \ne v_i$입니다. $0 \le i < N-1$입니다.
- $(u_i, v_i) = (u_j, v_j) \Leftrightarrow i = j$입니다. $0 \le i, j < N-1$입니다.
- $0 \le w_i \le 10^5$이며 $0 \le i < N-1$입니다.
- $1 \le Q \le 10^5$
- 유형 $1$ 쿼리에서 $0 \le a < N$이고 $0 \le x \le 10^5$입니다.
- 유형 $2$ 쿼리에서 $0 \le b < N$입니다.

## 출력

유형 $2$ 쿼리의 답을 쿼리 순서대로 한 줄에 하나씩 출력하세요.
