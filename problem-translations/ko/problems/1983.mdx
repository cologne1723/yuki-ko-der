섬 $N$개와 양방향 다리가 주어집니다. 두 섬 사이를 오가는 경로가 단순 경로 하나뿐인지, 즉 서로 다른 정점으로 이루어진 경로가 유일하게 존재하는지 각 질의에 답하세요.

## 입력

```text
N M Q
u_1 v_1
...
u_M v_M
x_1 y_1
...
x_Q y_Q
```

$2\le N\le2\times10^5$, $0\le M,Q\le2\times10^5$입니다.

## 출력

각 질의에 대해 경로가 유일하면 `Yes`, 아니면 `No`를 출력하세요.

## 예제

### 예제 1 {file="1_Sample_1.txt"}

#### 입력

```text
7 6 3
1 2
2 3
3 1
1 4
2 5
6 7
1 4
1 2
1 7
```

#### 출력

```text
Yes
No
No
```

### 예제 2 {file="1_Sample_2.txt"}

#### 입력

```text
4 0 4
1 2
2 3
3 4
4 1
```

#### 출력

```text
No
No
No
No
```

```text
1 3

1 3
```

#### 출력

```text
Yes
Yes
Yes
Yes
Yes
```
