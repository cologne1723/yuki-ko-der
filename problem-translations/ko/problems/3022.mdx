## 문제 설명

다음과 같은 문제를 생각합니다.

입력으로 정수 $N$, $M$ $2$개가 주어집니다.

$Nk+M \equiv 0 \pmod{10^9}$

을 만족하는 양의 정수 $k$가 존재하는지 판정하고, 존재한다면 그러한 $k$의 최솟값을 구하세요.

단, 정수 $n$에 대해 $n \equiv 0 \pmod{10^9}$라는 것은 $n$이 $10^9$로 나누어떨어진다는 뜻입니다.

입력의 처음에 양의 정수 $T$가 주어집니다. 그 후 $T$개의 문제에 답하세요.

## 입력

각 $t=1,2,\ldots,T$에 대해, $t$번째 문제의 입력 $N$, $M$을 각각 $N_t$, $M_t$로 나타냅니다.

입력은 다음 형식으로 표준 입력에서 $1+T$줄에 걸쳐 주어집니다.

```text
$T$
$N_1\ M_1$
$\vdots$
$N_T\ M_T$
```

$1$번째 줄에 $T$가 주어집니다.

각 $t=1,2,\ldots,T$에 대해, $t$번째 문제의 입력 $N_t$, $M_t$가 $1+t$번째 줄에 반각 공백으로 구분되어 주어집니다.

## 제한

- $1\leq T\leq 10^5$입니다. $T$는 정수입니다.
- 각 $t=1,2,\ldots,T$에 대해 $1\leq N_t\leq 10^{18}$입니다. $N_t$는 정수입니다.
- 각 $t=1,2,\ldots,T$에 대해 $1\leq M_t\leq 10^{18}$입니다. $M_t$는 정수입니다.

## 출력

각 $t=1,2,\ldots,T$에 대해,

$N_tk+M_t \equiv 0 \pmod{10^9}$

를 만족하는 양의 정수 $k$가 존재한다면 그 최솟값을 $t$번째 줄에 출력하세요. 존재하지 않는다면 $-1$을 $t$번째 줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
1 1
1 2
2 1
3 1
```

#### 출력

```text
999999999
999999998
-1
333333333
```

$1$번째 문제에 대해,

$k+1 \equiv 0 \pmod{10^9}$

을 만족하는 양의 정수 $k$가 존재하고, 그 최솟값은 $999\,999\,999$입니다.

$2$번째 문제에 대해,

$k+2 \equiv 0 \pmod{10^9}$

를 만족하는 양의 정수 $k$가 존재하고, 그 최솟값은 $999\,999\,998$입니다.

$3$번째 문제에 대해서는

$2k+1 \equiv 0 \pmod{10^9}$

를 만족하는 양의 정수 $k$가 존재하지 않습니다.

$4$번째 문제에 대해,

$3k+1 \equiv 0 \pmod{10^9}$

를 만족하는 양의 정수 $k$가 존재하고, 그 최솟값은 $333\,333\,333$입니다.
