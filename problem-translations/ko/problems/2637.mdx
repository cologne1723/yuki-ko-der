Alice는 양의 정수 $A,B$의 곱 $P=A\times B$를 알려주었습니다. 조건을 만족하는 $(A,B)$ 하나를 구하세요.

## 조건

- $1\le P\le10^{12}$
- $A,B$는 양의 정수이고 $A\times B=P$

## 입력

```text
$P$
```

## 출력

조건을 만족하는 $A,B$를 출력하세요.
