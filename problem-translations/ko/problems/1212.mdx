## 문제

$N$개 정점의 가중 트리가 주어집니다. 각 질의 $(x,y)$에 대해, $x$에서 시작해 $y$에서 끝나는 정점열 중 길이가 두 번째로 짧은 것의 길이를 구하세요.

연속한 두 정점은 간선으로 직접 연결되어야 하며, 같은 간선은 정점열에서 두 번까지만 사용할 수 있습니다. 길이가 같아도 정점열이 다르면 서로 다른 것으로 셉니다. 존재하지 않으면 $-1$을 출력하세요.

## 입력

$N$, $N-1$개의 간선 $(u_i,v_i,w_i)$, $Q$, $Q$개의 질의 $(x_i,y_i)$가 주어집니다.

- $2\leq N,Q\leq10^5$
- $1\leq w_i\leq10^9$
- 질의의 두 정점은 서로 다릅니다.

## 출력

각 질의의 답을 한 줄에 출력하세요.
