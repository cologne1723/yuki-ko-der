## 문제 설명

경쟁 프로그래밍부에는 $100$명의 부원이 있고, 경쟁 프로그래밍부의 동아리방에는 $10^9$대의 컴퓨터가 있습니다. 시각 $0$일 때, 그중 $N$대의 컴퓨터를 사용할 수 있습니다.

$Q$개의 사건이 주어집니다. $i\ (1 \leq i \leq Q)$번째 쿼리는 시각 $i$에 일어난 사건을 나타냅니다. 쿼리는 다음 형식 중 하나로 주어집니다.

- 쿼리 $1$: $1\ s\ r$ 형식으로 주어집니다. 레이트가 $r$인 부원 $s$가 동아리방에 옵니다.
- 쿼리 $2$: $2\ x$ 형식으로 주어집니다. $x$대의 컴퓨터를 사용할 수 없게 됩니다.
- 쿼리 $3$: $3\ s\ x$ 형식으로 주어집니다. 동아리방에 있는 부원 $s$가 $x$대의 컴퓨터를 사용할 수 있게 합니다.

컴퓨터는 현재 사용할 수 있는 컴퓨터 수에 따라 다음 순서로 한 사람당 한 대씩 사용합니다.

- 컴퓨터를 한 대라도 사용할 수 있게 한 적이 있는 사람 중 레이트가 높은 순서
- 위 조건에 해당하는 모든 사람이 사용한 뒤에도 사용할 수 있는 컴퓨터가 남아 있다면, 위 조건에 해당하지 않는 사람 중 레이트가 높은 순서

현재 동아리방에 있는 부원의 수가 사용할 수 있는 컴퓨터의 수보다 많아지면, 위 순서에 따라 컴퓨터를 사용할 부원을 정하고 컴퓨터를 사용하지 못하는 부원은 즉시 동아리방을 나갑니다.

한 번 동아리방을 나간 사람은 다시 동아리방에 오지 않습니다.

동아리방을 나간 사람의 이름을, 나간 시각이 이른 사람부터 한 줄에 한 명씩 모두 출력하세요.

여러 사람이 동시에 나간 경우에는 동시에 나간 사람들의 이름을 레이트가 낮은 순서로 출력하세요.

## 입력

```text
$N\ Q$
$\text{query}_1$
$\text{query}_2$
$\vdots$
$\text{query}_Q$
```

첫 번째 줄에 사용할 수 있는 컴퓨터의 수 $N$과 사건의 수 $Q$가 주어집니다.

이후 $Q$개의 쿼리가 주어집니다. 각 쿼리는 다음 형식 중 하나입니다.

```text
$1\ s\ r$
$2\ x$
$3\ s\ x$
```

쿼리 $1$에서 $s$는 동아리방에 오는 부원의 이름이고, $r$은 그 부원의 레이트입니다.

쿼리 $2$에서 $x$는 사용할 수 없게 되는 컴퓨터의 수입니다.

쿼리 $3$에서 $s$는 동아리방에 있는 부원의 이름이고, $x$는 그 부원이 사용할 수 있게 하는 컴퓨터의 수입니다.

## 제한

- $1 \leq N \leq 100$
- $1 \leq Q \leq 100\,000$
- $0 \leq r \leq 4\,000$
- $1 \leq x \leq 10$
- $1 \leq |s| \leq 100$
- $s$는 영문 소문자로만 이루어집니다.
- $s$ 이외의 입력은 모두 정수입니다.
- 부원의 이름 종류는 최대 $100$개입니다.
- 부원의 이름과 레이트는 각각 서로 다릅니다.
- 사용할 수 있는 컴퓨터의 수는 항상 $1$ 이상입니다.
- 쿼리 $1$로 주어지는 부원은 아직 동아리방에 오지 않았습니다.
- 쿼리 $3$으로 주어지는 부원은 동아리방에 있습니다.

## 출력

동아리방을 나가야 하게 된 사람의 이름을 문제 설명에서 설명한 순서대로 한 줄에 한 명씩 모두 출력하세요.
