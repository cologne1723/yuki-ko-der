## 문제 설명

`Python3`, `PyPy3`에서는 코드 골프(짧은 코드 길이로 `AC`를 받는 행위)에서 다음과 같은 코드를 작성하는 경우가 있습니다.

```text
print("YNeos"[x::2])
```

이 코드는 $x=0$일 때 `Yes`를, $x=1$일 때 `No`를 출력합니다.

이 `YNeos`와 같은 문자열을 다른 출력 형식에도 응용할 수 있는지 생각해 봅시다.

영문 대문자와 소문자로 이루어진 문자열 $X$, $Y$가 주어집니다.

다음 조건을 만족하는 영문 대문자와 소문자로 이루어진 문자열 $S$가 존재하는지 판정하고, 존재한다면 그 $S$를 출력하세요.

- $S$의 홀수 번째 문자를 뽑아 그 순서대로 이어 붙인 문자열은 $X$입니다.
- $S$의 짝수 번째 문자를 뽑아 그 순서대로 이어 붙인 문자열은 $Y$입니다.

존재하지 않는다면 물음표(`?`)를 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$X$
$Y$
```

$X$, $Y$는 각각 영문 대문자와 소문자로 이루어진 문자열입니다.

## 제한

- $1 \le |X|, |Y| \le 100$ ($|X|$, $|Y|$는 각각 $X$, $Y$의 길이입니다.)

## 출력

문제 설명의 조건을 만족하는 $S$가 존재한다면 그 $S$를 출력하세요.

존재하지 않는다면 물음표(`?`)를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
Yes
No
```

#### 출력

```text
YNeos
```

`YNeos`의 홀수 번째 문자를 뽑으면 `Yes`가 되고, 짝수 번째 문자를 뽑으면 `No`가 됩니다.

### 예제 2 {file=""}

#### 입력

```text
Takahashi
Aoki
```

#### 출력

```text
?
```

조건을 만족하는 $S$가 존재하지 않습니다. 이 경우 `?`를 출력하세요.

### 예제 3 {file=""}

#### 입력

```text
Alice
Bruno
```

#### 출력

```text
ABlriucneo
```
