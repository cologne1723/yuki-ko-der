## 문제 설명

`A`, `B`, `C`로 이루어진 길이 $N$의 문자열 $S$가 주어집니다.

Alice さん과 Bob さん은 $S$를 사용하여 다음과 같은 게임을 합니다.

Alice さん이 선공, Bob さん이 후공으로 다음 연산 중 $1$개를 선택하여 번갈아 수행합니다.

- 상대가 선택한 적이 없는 $1$ 이상 $N$ 이하의 정수 $i$를 $1$개 선택하여 다음 치환을 수행합니다.
  - $S$의 $i$번째 문자가 `A`이면 `B`로 바꿉니다.
  - $S$의 $i$번째 문자가 `B`이면 `C`로 바꿉니다.
  - $S$의 $i$번째 문자가 `C`이면 `A`로 바꿉니다.
- 종료를 선언합니다.

플레이어 중 $1$명이 종료를 선언하거나, $2$명의 플레이어가 각각 $10^{100}$번씩 연산을 수행한 시점에 게임이 종료됩니다.

Alice さん의 목표는 게임 종료 시점의 $S$를 사전순으로 가능한 한 작게 만드는 것입니다.
반대로 Bob さん의 목표는 게임 종료 시점의 $S$를 사전순으로 가능한 한 크게 만드는 것입니다.

양쪽이 최선을 다했을 때의 게임 종료 시점의 $S$를 구하세요.

양쪽이 최선을 다한다는 것은 다음을 뜻합니다. `A`, `B`, `C`로 이루어진 길이 $N$의 문자열 $X$ 중 다음 조건을 모두 만족하는 것은 정확히 $1$개만 존재한다는 것을 보일 수 있습니다.

- Bob さん이 어떻게 연산하더라도 Alice さん이 적절하게 게임을 진행하면 게임 종료 시점의 $S$를 사전순으로 $X$ 이하로 만들 수 있습니다.
- Alice さん이 어떻게 연산하더라도 Bob さん이 적절하게 게임을 진행하면 게임 종료 시점의 $S$를 사전순으로 $X$ 이상으로 만들 수 있습니다.

이 $X$를 양쪽이 최선을 다했을 때의 게임 종료 시점의 $S$로 정의합니다.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

## 입력

입력은 표준 입력에서 다음 형식으로 주어집니다. 여기서 $\mathrm{case}_t$ $(1 \leq t \leq T)$는 $t$번째 테스트 케이스를 나타냅니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$S$
```

## 제한

- $1 \leq T \leq 10^4$
- $T$는 정수입니다.
- 각 테스트 케이스에 대해 다음 조건을 모두 만족합니다.
  - $1 \leq N \leq 5 \times 10^5$
  - $N$은 정수입니다.
  - $S$는 `A`, `B`, `C`로 이루어진 길이 $N$의 문자열입니다.
- 입력 파일 $1$개에서 $N$의 총합은 $5 \times 10^5$ 이하입니다.

## 출력

$T$줄 출력하고, $t$번째 줄에는 $t$번째 테스트 케이스에 대한 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
3
ABC
5
CBABC
```

#### 출력

```text
ABC
ACABC
```

$1$번째 테스트 케이스에서는 Alice さん이 처음에 종료를 선언하는 것이 최선입니다.

$2$번째 테스트 케이스에서는 양쪽이 최선을 다하면 다음과 같이 연산하여 $S$가 `ACABC`가 됩니다.

- Alice さん이 $i = 1$을 선택합니다. `C`를 `A`로 바꿉니다.
- Bob さん이 $i = 2$를 선택합니다. `B`를 `C`로 바꿉니다.
- Alice さん이 종료를 선언합니다.
