## 문제 설명

다음과 같은 문제를 생각합니다.

입력으로 정수 $N$이 주어집니다.

$N^4+4$가 소수인지 판정하고, 또 그 끝에 $0$이 몇 자리 있는지, 즉 $N^4+4$가 $10$으로 몇 번 나누어떨어지는지 구하세요.

입력의 첫 줄에 양의 정수 $T$가 주어집니다. 그 후 $T$개의 문제에 답하세요.

## 입력

$T$ 이하의 각 양의 정수 $t$에 대해 $t$번째 문제의 입력을 $N_t$라고 합니다.

입력은 다음 형식으로 표준 입력에서 $1+T$줄에 걸쳐 주어집니다.

```text
$T$
$N_1$
$\vdots$
$N_T$
```

- 첫째 줄에 $T$가 주어집니다.
- $T$ 이하의 각 양의 정수 $t$에 대해, $t$번째 문제의 입력 $N_t$가 $1+t$번째 줄에 주어집니다.

## 제한

- $T$는 $1 \leq T \leq 10^5$를 만족하는 정수입니다.
- $T$ 이하의 임의의 양의 정수 $t$에 대해, $N_t$는 $-10^9 \leq N_t \leq 10^9$를 만족하는 정수입니다.

## 출력

출력은 다음 형식으로 표준 출력에 $2T$줄에 걸쳐 출력하세요.

- $T$ 이하의 각 양의 정수 $t$에 대해 다음을 출력합니다.
  - $N_t^4+4$가 소수라면 `Yes`를, 소수가 아니라면 `No`를 $2t-1$번째 줄에 출력하세요.
  - $N_t^4+4$가 $10$으로 나누어떨어지는 횟수를 $2t$번째 줄에 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
0
```

#### 출력

```text
No
0
```

$N_1^4+4=0^4+4=4$는 소수가 아니며, $10$으로 한 번도 나누어떨어지지 않습니다.

### 예제 2 {file=""}

#### 입력

```text
1
-1
```

음의 정수가 주어지는 경우도 있습니다.

#### 출력

```text
Yes
0
```

$N_1^4+4=(-1)^4+4=5$는 소수이며, $10$으로 한 번도 나누어떨어지지 않습니다.

### 예제 3 {file=""}

#### 입력

```text
2
2
-3
```

#### 출력

```text
No
1
No
0
```

$1$번째 문제에서 입력은 $N_1=2$입니다. $N_1^4+4=2^4+4=20$은 소수가 아니며 $10$으로 정확히 $1$번 나누어떨어집니다.

$2$번째 문제에서 입력은 $N_2=-3$입니다. $N_2^4+4=(-3)^4+4=85$는 소수가 아니며 $10$으로 한 번도 나누어떨어지지 않습니다.
