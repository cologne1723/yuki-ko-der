하루 일하면 스트레스가 `A` 증가하고, 하루 쉬면 스트레스가 1 감소합니다. 처음 스트레스는 0이며, 1일째부터 `B`일째까지 일하고 `B+1`일째부터 쉽니다.

스트레스가 다시 0이 되는 날짜를 구하세요.

## 제약

- `1 <= T <= 100`
- `1 <= A,B <= 1000`

## 입력

첫째 줄에 테스트 케이스 수 `T`, 다음 `T`개 줄에 `A B`가 주어집니다.

## 출력

각 테스트 케이스의 답을 한 줄에 하나씩 출력하세요.
