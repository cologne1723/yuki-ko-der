## 문제

MAK는 자연수를 매우 좋아합니다.

MAK는 1부터 N까지의 자연수를 각각 N개 이상 가지고 있습니다. 그중 일부를 상자에 넣으려고 했습니다. 마침 서로 구별되는 N개의 상자가 가로로 한 줄에 놓여 있습니다.

각 상자에 가진 자연수 중 하나를 넣으려 하지만 다음 조건을 만족해야 합니다. 왼쪽에서 i번째 상자에 들어가는 자연수를 Ai라고 하겠습니다.

각 i (1 ≤ i ≤ N)에 대해 왼쪽 이웃을 L, 오른쪽 이웃을 R이라 할 때 다음을 만족해야 합니다. i=1이면 L=N, 아니면 L=i−1이고, i=N이면 R=1, 아니면 R=i+1입니다.

AL − L < Ai < AR + R

MAK는 위 조건을 만족하는 자연수 보관 방법의 수가 궁금해졌습니다. 이 값은 매우 커질 수 있으므로 1,000,000,007 = 10^9+7로 나눈 나머지를 출력하세요.

## 입력

```text
N
```

3 ≤ N ≤ 2000

## 출력

조건을 만족하는 보관 방법의 수를 1,000,000,007로 나눈 나머지를 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3
```

출력:

```text
7
```

조건을 만족하는 보관 방법은 {1,1,1}, {1,2,1}, {2,2,1}, {2,2,2}, {2,3,2}, {3,3,2}, {3,3,3}의 7가지입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
5
```

출력:

```text
366
```

예를 들어 {3,4,5,4,2}는 조건을 만족합니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
100
```

출력:

```text
35646100
```

출력할 값은 1,000,000,007로 나눈 나머지임에 주의하세요.
