## 알림

이 문제의 원문이 된 문제는 [2496번 문제](https://yukicoder.me/problems/no/2496)이지만, 원문 문제의 풀이를 몰라도 이 문제를 푸는 데에는 영향이 없습니다.

## 문제 설명

**이 문제는 인터랙티브 문제입니다.**

양의 정수 $N$이 주어집니다. 또한 $(1,2,\dots,N)$의 순열 $A=(A_1,A_2,\dots,A_N)$, $B=(B_1,B_2,\dots,B_N)$가 숨겨져 있습니다.

다음 질문을 최대 $3N$번 할 수 있습니다.

- **질문**: $1$ 이상 $N$ 이하인 정수 $i,j$를 선택하고, $\gcd(A_i,B_j)$의 값을 묻습니다.

$A,B$를 알아내세요.

## 입력

처음에 표준 입력으로 순열의 길이 $N$이 주어집니다.

```text
$N$
```

질문에 대한 답은 표준 입력으로 다음 형식으로 주어집니다.

```text
$X$
```

여기서 $X=\gcd(A_i,B_j)$입니다.

## 제한

- $1\leq N\leq 1\,000$
- 입력은 모두 정수입니다.

## 출력

$A,B$를 알아낼 때까지 질문을 반복하세요. 질문은 다음 형식으로 표준 출력에 출력합니다.

```text
$?\ i\ j$
```

$1$ 이상 $N$ 이하인 정수 $i,j$를 선택하고, $\gcd(A_i,B_j)$의 값을 묻습니다.

$A,B$를 알아냈다면 다음 형식으로 표준 출력에 출력하세요. **$1$행으로 출력해야 합니다.** 그 후 즉시 프로그램을 종료하세요.

```text
$!\ A_1\ A_2\ \cdots\ A_N\ B_1\ B_2\ \cdots\ B_N$
```

## 주의

- 출력할 때마다 끝에 줄바꿈을 넣은 후 표준 출력을 flush하세요. 그렇게 하지 않으면 `TLE`가 될 수 있습니다.
- $3N$번을 초과해 질문하거나 잘못된 출력을 한 경우의 저지 결과는 정의되지 않습니다.
- 답을 출력했다면 즉시 프로그램을 종료하세요. 그렇게 하지 않은 경우의 저지 결과는 정의되지 않습니다.
- 이 문제의 저지 프로그램은 적응형이며, 제한과 이전 출력에 모순되지 않는 범위에서 $A,B$를 변경할 수 있습니다.

## 예제

$N=3,A=(1,2,3),B=(3,1,2)$인 경우의 입출력 예입니다.

### 예제 1 {file=""}

#### 입력

```text
3
```

처음에 $N$이 주어집니다.

#### 출력

```text
? 1 2
```

$i=1,j=2$로 질문합니다.

#### 입력

```text
1
```

$\gcd(A_1,B_2)=1$입니다.

#### 출력

```text
? 3 2
```

$i=3,j=2$로 질문합니다.

#### 입력

```text
1
```

$\gcd(A_3,B_2)=1$입니다.

#### 출력

```text
? 3 3
```

$i=3,j=3$으로 질문합니다.

#### 입력

```text
1
```

$\gcd(A_3,B_3)=1$입니다.

#### 출력

```text
! 1 2 3 3 1 2
```

$A=(1,2,3),B=(3,1,2)$라고 답합니다.
