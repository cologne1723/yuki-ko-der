수열 $A,B$와 제외할 정점쌍 $M$개가 주어집니다. $x<y$인 쌍에 대해 제외되지 않았으면 $A_x<B_y$일 때 $x\to y$, 그렇지 않으면 $y\to x$의 유향 간선을 추가한 그래프 $G$를 정의합니다.

## 문제

그래프 $G$와 도달 가능성이 같은 정점 $N$개, 간선 $3\times10^5$개 이하의 단순 유향 그래프 $G'$를 구성하세요.

## 입력

```text
N M
A_1 ... A_N
B_1 ... B_N
u_1 v_1
...
u_M v_M
```

$1\le N\le5\times10^4$, $0\le M\le10^5$입니다.

## 출력

조건을 만족하는 $G'$의 간선을 출력하세요.
