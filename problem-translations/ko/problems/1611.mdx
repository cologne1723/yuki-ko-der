## 문제

양의 정수 $X$에 대해 $X$의 배수이고 양의 약수 개수가 $X$의 정확히 두 배인 가장 작은 양의 정수 $Y$를 구하세요.

## 입력

$T$개의 정수 $X_i$가 주어집니다.

## 출력

각 테스트 케이스의 $Y$를 한 줄에 출력하세요.
