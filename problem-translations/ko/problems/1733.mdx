양의 정수 수열 `A=(A_0,...,A_{N-1})`가 주어집니다. 각 구간 `[l,r]`을 정렬한 수열을 `B`라 하고 `f(l,r)=sum(B_i*2^i)`로 정의합니다.

모든 `l,r`에 대한 `f(l,r)`의 합을 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `1 <= N <= 2 * 10^5`
- `1 <= A_i <= 10^8`

## 입력

`N`과 수열 `A`가 주어집니다.

## 출력

답을 `998244353`으로 나눈 나머지를 출력하세요.
