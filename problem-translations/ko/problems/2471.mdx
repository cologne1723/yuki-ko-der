돌이 놓이지 않은 트리가 주어집니다. 각 정점에 초록 또는 파란 돌을 놓는 $2^N$가지 방법 중, 어떤 잎 하나를 돌과 함께 제거하기 전과 후 모두 제미니 트리가 될 수 있는 돌 배치의 수를 $998244353$으로 나눈 나머지를 구하세요. 제미니 트리는 인접 정점의 돌을 교환한 뒤 최대 한 간선을 제거해 각 연결 성분이 한 색만 가지도록 만들 수 있는 트리입니다.

## 입력

```text
N
u1 v1
...
uN-1 vN-1
```

## 출력

조건을 만족하는 돌 배치의 수를 출력하세요.
