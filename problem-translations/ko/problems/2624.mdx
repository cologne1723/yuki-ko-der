시험 점수는 $0$부터 $100$까지의 정수입니다. 전체 평균을 소수 넷째 자리에서 버림한 값이 공개된 평균점 $S$입니다. 응시자 수가 $N$ 이하일 때 가능한 응시자 수의 개수를 구하세요.

## 조건

- $1\le T\le1000$, $1\le N\le10^{13}$
- $0\le S\le100$, $S$는 소수 셋째 자리까지 주어집니다.

## 입력

```text
$T$
$N$ $S$
```

## 출력

각 테스트 케이스의 답을 출력하세요.
