## 문제 설명

$N\times N$ 격자가 있습니다. $N$은 **짝수**입니다.

각 칸에 $0$ 또는 $1$을 적어 다음 조건을 모두 만족시킬 수 있는지 판별하고, 가능하면 방법을 하나 제시하세요.

- 각 $i=1,2,\ldots,N$에 대해 위에서 $i$번째 행과 $i+1$번째 행의 해밍 거리는 $A$입니다.
- 각 $i=1,2,\ldots,N$에 대해 왼쪽에서 $i$번째 열과 $i+1$번째 열의 해밍 거리는 $B$입니다.

단, $N+1$번째 행과 열은 각각 첫째 행과 첫째 열을 뜻합니다.

테스트 케이스는 총 $T$개입니다.

## 입력

표준 입력으로 다음 형식의 입력이 주어집니다. $\mathrm{case}_i$는 $i$번째 테스트 케이스입니다.

```text
$T$
$\text{case}_1$
$\text{case}_2$
$\vdots$
$\text{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ A\ B$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $1\le T\le 1\,000$
- $2\le N\le 500$
- $N$은 짝수입니다.
- 모든 테스트 케이스의 $N^2$의 합은 $250\,000$ 이하입니다.
- $0\le A,B\le N$

## 출력

각 테스트 케이스의 답을 줄바꿈으로 구분해 출력하세요.

조건을 만족시킬 수 없으면 $-1$을 출력하세요. 가능하면 `0`과 `1`로 이루어진 길이 $N$의 문자열 $S_1,\ldots,S_N$을 각각 한 줄에 출력하세요. $S_i$의 $j$번째 문자는 위에서 $i$번째 행, 왼쪽에서 $j$번째 열에 적는 문자입니다.

답이 여러 개이면 아무거나 출력해도 됩니다.
