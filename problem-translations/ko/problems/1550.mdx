## 문제

## 입력

$0\leq n\leq2^{63}-1$

## 출력

나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
1
```

### 예제 2 {file=""}

#### 입력

```text
1000000007
```

#### 출력

```text
0
```

### 예제 3 {file=""}

#### 입력

```text
9223372036854775807
```

#### 출력

