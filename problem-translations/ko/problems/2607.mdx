양의 정수 $N$이 주어집니다. $N$의 맨 앞, 맨 뒤 또는 숫자 사이에 한 자리 숫자를 정확히 한 번 삽입해 만들 수 있는, 맨 앞이 0이 아닌 수의 종류 수를 구하세요.

## 조건

- $1\le N\le10^9$
- $N$은 0으로 시작하지 않습니다.

## 입력

```text
$N$
```

## 출력

답을 출력하세요.
