한 자리 양의 정수가 `N`개 있고, 정수 `i`는 `c_i`개 있습니다 (`1 <= i <= 9`). 이들을 재배열해 만들 수 있는 모든 `N`자리 십진수 `M`의 최대공약수를 구하세요.

가능한 `M`이 하나뿐이면 그 `M`을 답으로 합니다. 답을 `10^9+7`로 나눈 나머지를 출력하세요.

## 입력

첫째 줄에 `N`, 둘째 줄에 `c_1, c_2, ..., c_9`가 주어집니다.

## 제약

- `1 <= N <= 10^9`
- `c_i >= 0`, `sum(c_i) = N`

## 출력

답을 `10^9+7`로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 1 1 0 0 0 0 0 0
```

#### 출력

```text
3
```

### 예제 2 {file=""}

#### 입력

```text
3
1 2 0 0 0 0 0 0 0
```

#### 출력

```text
1
```

### 예제 3 {file=""}

#### 입력

```text
1
0 1 0 0 0 0 0 0 0
```

#### 출력

```text
2
```

### 예제 4 {file=""}

#### 입력

```text
900000000
100000000 100000000 100000000 100000000 100000000 100000000 100000000 100000000 100000000
```

#### 출력

```text
9
```
