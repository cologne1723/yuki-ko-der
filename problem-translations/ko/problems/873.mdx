## 문제

바이너리를 "0과 1만으로 이루어진 문자열"이라고 정의합니다.

01열을 "인접한 문자가 서로 다른 바이너리"라고 정의합니다.

바이너리의 위험도를, 바이너리를 같은 문자가 연속되는 지점에서 나누었을 때 각 01열의 길이의 제곱을 더한 값으로 정의합니다.

예를 들어 `01011011000`은 `0101`, `101`, `10`, `0`, `0`으로 나뉘며, 위험도는 $4^2+3^2+2^2+1^2+1^2=31$입니다.

양의 정수 $N$이 주어집니다. 위험도가 $N$인 바이너리 중 길이가 가장 짧은 것을 구하세요.

답이 여러 개라면 그중 사전순으로 가장 작은 것을 구하세요.

## 입력

~~~text
N
~~~

입력은 정수로 주어집니다.

- $1 \leq N \leq 3 \times 10^5$

## 출력

답을 출력하고 마지막에 줄 바꿈을 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

~~~text
1
~~~

### 출력 1 {file="stdout"}

~~~text
0
~~~

위험도가 1인 바이너리는 `0`과 `1`이며, 둘 다 길이가 1이므로 사전순으로 작은 `0`을 출력합니다.

### 입력 2 {file="stdin"}

~~~text
5
~~~

### 출력 2 {file="stdout"}

~~~text
001
~~~

### 입력 3 {file="stdin"}

~~~text
32
~~~

### 출력 3 {file="stdout"}

~~~text
01011010
~~~
