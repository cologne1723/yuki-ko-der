$3\le N\le3000$인 정수 $N$이 주어집니다.

## 조건

다음 조건을 모두 만족하는 길이 $N$의 두 비음이 아닌 정수열 $A,B$를 하나 구성하세요.

- $0\le A_1<\cdots<A_N\le10000$
- $0\le B_1<\cdots<B_N\le10000$
- 모든 원소의 합이 같습니다.
- 임의의 $i,j,k,l$에 대해 $A_i+A_j\ne B_k+B_l$입니다.

## 입력

```text
N
```

## 출력

첫째 줄에 $A$, 둘째 줄에 $B$를 공백으로 구분해 출력하세요. 가능한 답이 여러 개면 아무거나 출력합니다.
