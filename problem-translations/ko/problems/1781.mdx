각 원소가 양의 정수인 길이 `N`의 모든 수열 `A`에 대해 `floor(M/lcm(A))`의 합을 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `1 <= N,M <= 10^11`

## 입력

`N M`이 주어집니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2
```

#### 출력

```text
9
```

### 예제 2 {file=""}

#### 입력

```text
3 4
```

#### 출력

```text
44
```

### 예제 3 {file=""}

#### 입력

```text
200000 200000
```

#### 출력

```text
68905
```

### 예제 4 {file=""}

#### 입력

```text
100000000000 100000000000
```

#### 출력

```text
369470795
```
