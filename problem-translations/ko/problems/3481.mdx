## 문제 설명

$3$자리의 양의 정수 $N$이 주어집니다. $N$의 백의 자리, 십의 자리, 일의 자리 숫자를 각각 $a$, $b$, $c$라고 합니다.

이때 $a+c=b$인지 판정하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

## 제한

- $N$은 정수입니다.
- $100 \leq N \leq 999$

## 출력

$a$, $b$, $c$를 각각 $N$의 백의 자리, 십의 자리, 일의 자리 숫자라고 할 때, $a+c=b$이면 `Yes`를, 그렇지 않으면 `No`를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
495
```

#### 출력

```text
Yes
```

$a=4$, $b=9$, $c=5$입니다. $4+5=9$이므로 $a+c=b$가 성립하여 `Yes`를 출력합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
999
```

#### 출력

```text
No
```

$a=9$, $b=9$, $c=9$입니다. $9+9=18$이므로 $a+c=b$가 성립하지 않아 `No`를 출력합니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
121
```

#### 출력

```text
Yes
```
