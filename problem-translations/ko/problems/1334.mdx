## 문제

양의 정수 `A_1,...,A_N` 사이의 각 연산자를 `+` 또는 `×`로 정해 식의 값을 최대로 만드세요. 곱셈이 덧셈보다 먼저 계산됩니다.

## 입력

`N`과 `A_1,...,A_N`이 주어집니다.

`2\le N\le2\times10^5`, `1\le A_i\le10^9`입니다.

## 출력

최댓값을 `10^9+7`로 나눈 나머지를 출력하세요.
