## 문제 설명

양의 정수 $K$가 주어집니다.

다음 조건을 모두 만족하는 가장 작은 양의 정수 $n$을 구하세요.

- $n$의 각 자릿수의 합은 $K$입니다.
- $n$을 십진수로 해석했을 때 $10^i$의 자리의 값을 $n_i$로 정의합니다. 어떤 음이 아닌 정수 $i$가 존재하여 $n_{i+2} > n_{i+1} + n_i$를 만족해야 합니다.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $\mathrm{case}_i$는 $i$번째 테스트 케이스를 나타냅니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$K$
```

## 제한

- 입력은 모두 정수입니다.
- $1 \leq T \leq 1\,000$
- $1 \leq K \leq 1\,000\,000$
- 모든 테스트 케이스에서 $K$의 합은 $1\,000\,000$ 이하입니다.

## 출력

각 테스트 케이스에 대한 답을 순서대로 줄 바꿈으로 구분하여 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
4
1
18
```

#### 출력

```text
301
100
1908
```

$1$번째 테스트 케이스에서 $301$의 각 자릿수의 합은 $4$이고, $i=0$일 때 $3 > 0 + 1$을 만족합니다. 따라서 $301$은 조건을 만족합니다. $300$ 이하인 조건을 만족하는 양의 정수는 존재하지 않으므로 $301$이 답입니다.

$3$번째 테스트 케이스에서 $n=1\,908$일 때, $i=1$에 대해서는 $n_{i+2} > n_{i+1} + n_i$를 만족하지 않지만 $i=0$일 때는 만족합니다. 각 자릿수의 합은 $18$이므로 조건을 만족합니다.

답이 $2^{64}$ 이상이 되는 경우가 있음에 유의하세요.
