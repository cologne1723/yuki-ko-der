## 문제 설명

다카하시 군은 어떤 문제의 출제자입니다. 테스터인 Iot 군은 다카하시 군의 풀이가 조금 수상하다고 생각했습니다.

그래서 Iot 군은 테스트 케이스를 몇 개 늘려 다카하시 군의 풀이로 올바른 답이 출력되는지 시험해 보기로 했습니다.

시간 제한을 초과하면 `TLE`가, 메모리 제한을 초과하면 `MLE`가, 답이 틀리면 `WA`가, 올바른 답이면 `AC`가 문자열 $S$에 쉼표로 구분되어 기록됩니다.

문자열 $S$가 주어질 때 다카하시 군의 풀이가 올바른지 판정하세요. 단, 풀이가 올바르다는 것은 $S$에 `AC` 이외의 결과가 포함되어 있지 않다는 뜻입니다.

## 입력

```text
$S$
```

문자열 $S$가 주어집니다.

## 제한

- $2 \le |S| \le 4 \times 10^5 - 1$
- $S$에는 각 케이스의 결과가 쉼표로 구분되어 포함됩니다. 케이스 수는 $1$ 이상 $10^5$ 이하입니다.
- $S$에는 결과(`AC`, `WA`, `TLE`, `MLE`)와 결과 사이의 쉼표 `,` 이외에는 포함되지 않습니다.
- 결과를 구성하는 문자를 섞어 만든 문자열(예: `CA`, `LTE`, `LME`, `A,CW,ATL` 등)은 포함되지 않는 것이 보장됩니다.

## 출력

다카하시 군의 풀이가 올바르면 `Done!`을, 올바르지 않으면 `Failed...`를 출력하고 마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
AC,AC,AC,AC,AC
```

#### 출력

```text
Done!
```

다카하시 군의 풀이는 올바릅니다.

### 예제 2 {file=""}

#### 입력

```text
AC,AC,AC,AC,AC,WA,AC
```

#### 출력

```text
Failed...
```

다카하시 군의 풀이는 잘못되었습니다.

### 예제 3 {file=""}

#### 입력

```text
AC,AC,AC,TLE,TLE,TLE,TLE,MLE
```

#### 출력

```text
Failed...
```
