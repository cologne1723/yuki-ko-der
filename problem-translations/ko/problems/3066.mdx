## 문제 설명

수직선 위에 동전이 $N$개 있습니다. $i$번째 동전은 좌표 $c_i$에 있습니다. 어떤 $2$개의 동전의 좌표도 서로 다릅니다.

처음에 좌표 $0$에 있습니다. 양의 방향 또는 음의 방향으로 거리 $1$만큼 이동하는 것을 몇 번이든 할 수 있습니다.

동전이 있는 좌표와 같은 좌표에 있을 때, 그리고 그때에만 해당 동전을 획득할 수 있습니다.

모든 동전을 모은 뒤 **마지막에 좌표 $0$으로 돌아오는 것**이 목표입니다. 목표를 달성하는 데 필요한 총 이동 거리의 최솟값을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$c_1\ c_2\ \dots\ c_N$
```

$1$번째 줄에 동전의 개수 $N$이 주어집니다. $2$번째 줄에 $i$번째 동전의 좌표 $c_i$가 $N$개 주어집니다.

## 제한

- 입력은 모두 정수입니다.
- $1 \leq N \leq 10^5$
- $-10^8 \leq c_1 < c_2 < \dots < c_N \leq 10^8$

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
-1 1 3
```

#### 출력

```text
8
```

$1$번째, $3$번째, $2$번째 동전 순서로 회수하면 $0 \rightarrow -1 \rightarrow 3 \rightarrow 1 \rightarrow 0$으로 좌표를 이동하게 됩니다. 따라서 총 이동 거리는 $1 + 4 + 2 + 1 = 8$입니다.

모든 동전을 회수한 뒤 반드시 좌표 $0$으로 돌아와야 한다는 점에 주의하세요.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
9
-31415296 -26457513 -24494897 -17320508 -14142135 0 22360679 27182818 31622776
```

#### 출력

```text
126076144
```
