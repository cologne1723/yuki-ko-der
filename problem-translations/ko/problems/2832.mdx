## 문제 설명

ナナ는 마법의 나라에 왔습니다. 이 나라는 $N$개의 마을과 $M$개의 도로로 이루어져 있습니다. 도로 $i$ $(1 \leq i \leq M)$는 마을 $U_i$와 $V_i$를 양방향으로 연결합니다.

ナナ는 $X$일 동안 이 마법의 나라를 모험하게 되었습니다. $i$일째 $(1 \leq i \leq X)$에는 다음과 같이 행동합니다.

- 현재 있는 마을에 연결된 도로 중 $1$개를 무작위로 선택하고, 그 도로를 이용해 이동합니다. 단, $2$일째부터는 전날 선택한 도로를 선택하지 않습니다. 또한 이동할 수 있는 도로가 없으면 그날은 이동하지 않습니다.

후보 도로 중 어느 도로가 선택되는지는 모두 같은 확률입니다. $1$일째 이동을 시작하기 전에는 마을 $1$에 있습니다.

각 $t=1,2,\ldots,N$에 대해, $X$일째 행동을 마친 뒤 ナナ가 마을 $t$에 있을 확률을 $\bmod 998\,244\,353$로 구하세요. 즉, 각 확률은 분모가 $998\,244\,353$과 서로소인 기약분수로 나타낼 수 있습니다. 확률이 기약분수 $\frac{p}{q}$로 나타난다면, $qx=p\pmod{998\,244\,353}$를 만족하는 정수 $x$ $(0 \leq x \leq 998\,244\,352)$를 구하세요.

이 나라에는 같은 마을로 돌아오는 도로가 있을 수 있습니다. 또한 어떤 $2$개의 마을 사이를 연결하는 도로가 여러 개 있을 수 있으며, 마을 $1$에서 여러 도로를 거쳐도 도달할 수 없는 마을이 있을 수 있습니다. 즉, 그래프는 비연결일 수 있고 다중 간선이나 자기 루프 간선을 포함할 수 있습니다.

## 입력

```text
$N\ M\ X$
$U_1\ V_1$
$U_2\ V_2$
$\vdots$
$U_M\ V_M$
```

$1$번째 줄에 마을의 수 $N$, 도로의 수 $M$, 모험하는 날의 수 $X$가 주어집니다.

이후 $M$개의 줄에 $i$번째 도로가 연결하는 $2$개의 마을 $U_i$, $V_i$가 주어집니다.

## 제한

- $2 \leq N \leq 10$
- $1 \leq M \leq 1\,000$
- $1 \leq X \leq 10^8$
- $1 \leq U_i,V_i \leq N$ $(1 \leq i \leq M)$
- $N,M,X,U_i,V_i$ $(1 \leq i \leq M)$는 모두 정수입니다.

## 출력

$N$개의 줄에 걸쳐 출력하세요. $i$번째 줄에는 마을 $i$에 있는 확률을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 5 2
1 2
1 2
2 2
1 3
3 3
```

#### 출력

```text
332748118
332748118
332748118
```

먼저 ナナ는 $1$일째에 도로 $1,2,4$를 각각 $\frac{1}{3}$의 확률로 선택합니다. 도로 $1$을 선택했다면 $2$일째에는 마을 $2$에 있고, 도로 $2,3$을 각각 $\frac{1}{2}$의 확률로 선택해 이동합니다.

이와 같이 이동하면 $2$일째 행동을 마친 뒤 마을 $1,2,3$에 있을 확률은 각각 $\frac{1}{3}$입니다.

### 예제 2 {file=""}

#### 입력

```text
5 5 11
1 2
2 3
3 4
4 5
5 5
```

#### 출력

```text
0
1
0
0
0
```

$10$일째에는 전날 도로 $1$을 지나 마을 $1$에 반드시 있지만, 전날 선택한 도로는 선택할 수 없으므로 행동할 수 없습니다. 그러나 $11$일째에는 도로 $1$을 선택할 수 있습니다.

### 예제 3 {file=""}

#### 입력

```text
3 2 100000000
1 1
2 2
```

#### 출력

```text
1
0
0
```

애초에 마을 $1$에서 나갈 수 없는 경우도 있습니다.
