## 문제

당신은 송년회를 열 음식점을 찾고 있습니다. 세상에는 음식점이 많아서 모두 확인할 시간은 없으므로, 다음 세 가지 평가값을 이용해 확인할 음식점 수를 줄이려 합니다.

음식점 $i$의 가격 평가값 $P_i$, 체류 가능 시간 평가값 $T_i$, 후기 평가값 $R_i$가 주어집니다. 다음 조건 중 하나라도 성립하면 음식점 $j$를 음식점 $i$의 하위 호환이라고 합니다.

1. $P_j\lt P_i$이고 $T_j\leq T_i$이며 $R_j\leq R_i$.
2. $P_j\leq P_i$이고 $T_j\lt T_i$이며 $R_j\leq R_i$.
3. $P_j\leq P_i$이고 $T_j\leq T_i$이며 $R_j\lt R_i$.

어떤 음식점의 하위 호환도 아닌 음식점을 오름차순으로 나열하세요.

※ C++와 Rust로는 정답을 확인했지만, PyPy로는 출제자가 정답을 얻지 못했습니다.

## 입력

~~~text
$N$
$P_1\ T_1\ R_1$
$P_i\ T_i\ R_i$
$P_N\ T_N\ R_N$
~~~

첫째 줄에 음식점 수 $N$이 주어집니다. 이어지는 $N$개 줄 중 $i$번째 줄에는 음식점 $i$의 가격 평가값 $P_i$, 체류 가능 시간 평가값 $T_i$, 후기 평가값 $R_i$가 공백으로 구분되어 주어집니다.

$1\leq N\leq10^5$

$0\leq P_i,T_i,R_i\leq10^4$

$i\ne j$일 때 $(P_i,T_i,R_i)\ne(P_j,T_j,R_j)$입니다.

## 출력

조건을 만족하는 음식점의 번호를 오름차순으로 출력하세요. 마지막에는 줄바꿈을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
5
5 2 1
4 4 4
3 3 1
0 0 1
5 8 0
~~~

#### 출력

~~~text
1
2
5
~~~

음식점 3은 음식점 2의 하위 호환이고, 음식점 4는 음식점 1, 2, 3의 하위 호환이므로 제외합니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
3
1 0 0
0 1 0
0 0 1
~~~

#### 출력

~~~text
1
2
3
~~~

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
3
1 1 1
2 3 4
5 5 5
~~~

#### 출력

~~~text
3
~~~
