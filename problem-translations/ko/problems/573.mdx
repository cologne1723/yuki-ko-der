## 문제

모든 i (0 ≤ i ≤ N−1)에 대해 다음 두 조건을 모두 만족하는 정수열 {a[0],a[1],…,a[N−1]}은 몇 개인가요?

* 0 ≤ a[i] ≤ N−1
* a[a[i]] = a[i]

그 개수를 10^9+7로 나눈 나머지를 구하세요.

## 입력

```text
N
```

1 ≤ N ≤ 100000

## 출력

조건을 만족하는 수열이 X개라면 X를 10^9+7로 나눈 나머지를 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3
```

출력:

```text
10
```

a = {0,0,0}, {0,0,2}, {0,1,0}, {0,1,1}, {0,1,2}, {0,2,2}, {1,1,1}, {1,1,2}, {2,1,2}, {2,2,2}의 10개가 조건을 만족합니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
9
```

출력:

```text
293608
```

### 샘플 3 {file="sample3.in"}

입력:

```text
100000
```

출력:

```text
818317402
```

출력은 10^9+7로 나눈 나머지입니다.
