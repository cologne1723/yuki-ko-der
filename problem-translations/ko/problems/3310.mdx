## 이야기

아, 네, 늘 그렇듯이 $\mod998$…가 아니잖아?!

## 문제 설명

$T$개의 테스트 케이스가 주어집니다. 각 테스트 케이스에 대해 다음 문제를 해결하세요.

음이 아닌 정수 $N$과 양의 정수 $M$이 주어집니다. $M$개의 음이 아닌 정수 $K_1,K_2,\dots,K_M$이 주어질 때, 각 $K_j$에 대해

$\sum_{i=0}^{K_j}N^i\bmod 998$

을 구하세요.

단, 이 문제에서는 $0^0=1$로 정의합니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$T$
$testcase_1$
$\vdots$
$testcase_T$
```

여기서 $testcase_i$는 $i$번째 테스트 케이스를 나타내며, 각각 다음 형식으로 주어집니다.

```text
$N_i\ M_i$
${K_i}_1$
$\vdots$
${K_i}_{M_i}$
```

## 제한

- 입력은 모두 정수입니다.
- $1\le T\le 50$
- 각 테스트 케이스에 대해 다음 조건을 만족합니다.
  - $0\le N_i<998$
  - $1\le M_i\le 10^3$
  - $0\le {K_i}_j<10^{10^5}$
  - 각 테스트 케이스에서 ${K_i}_j$의 십진수 표기 자릿수의 합은 $10^5$ 이하입니다.

## 출력

각 테스트 케이스의 답을 순서대로 출력하세요.

테스트 케이스 $i$에 대해 $M_i$개의 줄을 출력하며, $j$번째 줄에는 ${K_i}_j$에 대한 답을 출력하고 줄바꿈하세요.

#### 출력

```text

1

```

예를 들어 케이스 $1$의 $1$번째 질의에서는 $\sum_{i=0}^{3}4^i=1+4+16+64=85$이고, $85\bmod 998=85$이므로 답은 $85$입니다.

또한 $2$번째 질의에서는 $\sum_{i=0}^{5}4^i=1+4+16+64+256+1\,024=1\,365$이고, $1\,365\bmod 998=367$이므로 답은 $367$입니다.

케이스 $4$와 같이 $64$비트 정수에 들어가지 않는 입력이 주어질 수도 있다는 점에 주의하세요.
