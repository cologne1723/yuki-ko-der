## 문제 설명

소수 주사위의 면에는 $2,3,5,7,11,13$, 합성수 주사위의 면에는 $4,6,8,9,10,12$가 쓰여 있습니다. 0번 칸에서 시작하여 $N$번 칸에 도착하면 골인하는 보드게임에서, 매 턴 주사위 눈의 합만큼 이동하되 $N$을 넘으면 $N$에서 멈춥니다.

같은 종류의 주사위는 구별하지 않을 때 골인하는 방법의 패턴 수를 $10^9+7$로 나눈 나머지를 구하세요.

## 입력

```text
N P C
```

- $1 \le N \le 10^{18}$
- $0 \le P,C \le 50$
- $P+C \ge 1$

## 출력

골인하는 방법의 패턴 수를 $10^9+7$로 나눈 나머지를 출력하세요.
