길이 $N$의 수열 $A$를 비어 있지 않은 연속 부분 수열들로 나누는 방법 중, 각 부분 수열의 최솟값을 나열한 수열이 넓은 의미로 단조 증가하는 방법의 개수를 $998244353$으로 나눈 나머지를 구하세요.

## 조건

- $1\le N\le2\times10^5$
- $1\le A_i\le10^9$

## 입력

```text
N
A1 A2 ... AN
```

## 출력

조건을 만족하는 분할 방법의 수를 출력하세요.
