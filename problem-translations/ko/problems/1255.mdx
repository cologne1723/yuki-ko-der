## 문제 설명

원소 $2N$개의 배열 $\mathcal A=[a_1,\ldots,a_N,b_1,\ldots,b_N]$에 대해

$\pi(\mathcal A)=[a_1,b_1,a_2,b_2,\ldots,a_N,b_N]$

으로 정의하고, $\pi^0(\mathcal A)=\mathcal A$, $\pi^n(\mathcal A)=\pi(\pi^{n-1}(\mathcal A))$로 정의합니다. $\mathcal A=[1,2,\ldots,2N]$일 때 $\pi^K(\mathcal A)=\mathcal A$가 되는 최소 양의 정수 $K$를 구하세요. 존재하지 않으면 $-1$을 출력합니다.

## 입력

```text
T
N
\vdots
N
```

- $1\leq T\leq100$
- $1\leq N\leq10^9$

## 출력

각 테스트 케이스의 답을 한 줄에 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}
#### 입력
```text
3
3
2
26
```
#### 출력
```text
4
2
8
```
