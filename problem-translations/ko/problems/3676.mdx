## 문제 설명

같은 크기의 직육면체 $A$, $B$가 $2$개 있습니다.

각 직육면체는 왼쪽과 오른쪽 방향으로 $X$개, 앞쪽과 뒤쪽 방향으로 $Y$개, 아래쪽과 위쪽 방향으로 $Z$개의 작은 정육면체를 격자 모양으로 배열한 것이며, 총 $XYZ$개의 작은 정육면체로 이루어져 있습니다.

직육면체 $A$에서 왼쪽에서 $x$번째, 앞에서 $y$번째, 아래에서 $z$번째 위치($1\le x\le X$, $1\le y\le Y$, $1\le z\le Z$)를 $(x,y,z)$라고 합니다. 이 위치에 있는 작은 정육면체를 $A_{x,y,z}$라고 나타냅니다.

마찬가지로 직육면체 $B$의 위치 $(x,y,z)$에 있는 작은 정육면체를 $B_{x,y,z}$라고 나타냅니다.

각 작은 정육면체의 종류는 검은색 불투명 블록, 흰색 불투명 블록, 투명 블록 중 $1$개입니다.

직육면체 $B$에 대해 다음 조작을 원하는 순서로 $0$회 이상 수행할 수 있습니다.

- 조작 $1$: 가장 왼쪽 층을 제거해 가장 오른쪽에 놓습니다.
- 조작 $2$: 가장 앞쪽 층을 제거해 가장 뒤쪽에 놓습니다.
- 조작 $3$: 가장 아래쪽 층을 제거해 가장 위쪽에 놓습니다.

정확히 말하면 각 조작에 의해 직육면체 $B$의 모든 작은 정육면체가 동시에 다음과 같이 이동합니다.

- 조작 $1$: 조작 전 위치 $(x,y,z)$에 있던 작은 정육면체는 $x=1$이면 위치 $(X,y,z)$로, $2\le x\le X$이면 위치 $(x-1,y,z)$로 이동합니다.
- 조작 $2$: 조작 전 위치 $(x,y,z)$에 있던 작은 정육면체는 $y=1$이면 위치 $(x,Y,z)$로, $2\le y\le Y$이면 위치 $(x,y-1,z)$로 이동합니다.
- 조작 $3$: 조작 전 위치 $(x,y,z)$에 있던 작은 정육면체는 $z=1$이면 위치 $(x,y,Z)$로, $2\le z\le Z$이면 위치 $(x,y,z-1)$로 이동합니다.

조작 후에도 위치 $(x,y,z)$에 있는 작은 정육면체를 $B_{x,y,z}$라고 나타냅니다. 어떤 조작을 하더라도 각 작은 정육면체의 색은 변하지 않습니다.

조작을 끝낸 뒤 $2$개의 직육면체에서 같은 위치에 있는 작은 정육면체끼리 비교합니다.

이때 $A_{x,y,z}$와 $B_{x,y,z}$가 모두 불투명 블록이고 한쪽이 검은색, 다른 한쪽이 흰색인 위치 $(x,y,z)$의 개수를 **불일치 수**라고 정의합니다.

불일치 수의 최솟값을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$X\ Y\ Z$
$A_1$
$A_2$
$\vdots$
$A_Z$
$B_1$
$B_2$
$\vdots$
$B_Z$
```

여기서 $A_z\ (1\le z\le Z)$는 직육면체 $A$에서 아래에서 $z$번째 층을 나타내는 데이터이며, 다음 $Y$개 행으로 주어집니다.

```text
$A_{z,1}$
$A_{z,2}$
$\vdots$
$A_{z,Y}$
```

각 문자열 $A_{z,y}\ (1\le y\le Y)$의 길이는 $X$이며, $x$번째 문자($1\le x\le X$)는 작은 정육면체 $A_{x,y,z}$를 나타냅니다.

$B_z$에 대해서도 마찬가지로 $B_{z,y}$의 $x$번째 문자가 작은 정육면체 $B_{x,y,z}$를 나타냅니다.

각 문자는 작은 정육면체의 종류를 다음과 같이 나타냅니다.

- `B`: 검은색 불투명 블록
- `W`: 흰색 불투명 블록
- `.`: 투명 블록

각 직육면체에 대해 아래층부터 위층 순서로, 각 층에서는 앞쪽 행부터 뒤쪽 행 순서로 $Z\times Y$개의 문자열이 주어집니다.

직육면체 $A$를 나타내는 $Z\times Y$개의 행 다음에 직육면체 $B$를 나타내는 $Z\times Y$개의 행이 이어집니다. 이들 사이에는 빈 줄이 없습니다.

## 제한

- $2\le X,Y,Z$
- $XYZ\le 2^{18}$
- 입력되는 문자열은 `B`, `W`, `.`만으로 이루어집니다.
- 입력되는 수는 모두 정수입니다.

## 출력

불일치 수의 최솟값을 출력하고, 마지막에 개행 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2 2
BWB
BWB
B.W
BW.
.BB
WWW
WBW
BBW
```

#### 출력

```text
2
```

조작을 하지 않은 경우 불일치 수는 $5$입니다.

직육면체 $B$에 조작 $1$을 $1$회 수행한 뒤 조작 $3$을 $1$회 수행하면 불일치 수는 $2$가 됩니다.

어떻게 조작하더라도 불일치 수를 $1$ 이하로 만들 수 없으므로 답은 $2$입니다.

### 예제 2 {file=""}

#### 입력

```text
2 2 2
BB
BB
WW
WW
WW
WW
BB
BW
```

#### 출력

```text
1
```

조작을 하지 않은 경우 불일치 수는 $7$입니다. 직육면체 $B$에 조작 $3$을 $1$회 수행하면 불일치 수가 $1$이 되며, 이것이 최솟값입니다.

### 예제 3 {file=""}

#### 입력

```text
2 2 2
B.
..
..
..
.W
..
..
..
```

#### 출력

```text
0
```

조작을 하지 않은 경우 $A_{1,1,1}$은 검은색 불투명 블록이고 $B_{2,1,1}$은 흰색 불투명 블록입니다. 한편 $B_{1,1,1}$과 $A_{2,1,1}$은 투명 블록입니다. 이처럼 적어도 한쪽이 투명 블록인 위치는 불일치 수에 세지 않습니다.

### 예제 4 {file=""}

#### 입력

```text
2 2 2
WB
BB
BB
BB
BB
BW
BB
BB
```

#### 출력

```text
0
```

직육면체 $B$에 조작 $1$을 $1$회 수행한 뒤 조작 $2$를 $1$회 수행하면 모든 위치에서 색이 일치합니다.
