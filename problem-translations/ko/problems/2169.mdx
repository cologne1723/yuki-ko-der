길이 $N$의 정수열 $A$가 주어진다냥. 한 번의 조작으로 구간 $[l,r]$의 모든 원소를 1씩 증가시킬 수 있다냥. 각 질의의 공차 $d_i$에 대해, $A$를 공차가 $d_i$인 등차수열로 만드는 최소 조작 횟수를 구하라냥.

## 조건

- $2\le N,Q\le2\times10^5$
- $1\le A_i\le10^9$
- $|d_i|\le10^9$

## 입력

```text
N Q
A_1 A_2 \cdots A_N
d_1
\vdots
d_Q
```

## 출력

각 질의의 답을 한 줄에 하나씩 출력하라냥.
