## 문제

수열 `A`, `1 ≤ L ≤ R ≤ N`, 서로 다른 정점 `S,T`가 주어집니다. `F(i)=A_i`라 하고, 모든 `i`와 `L ≤ k ≤ R`에 대해 `i`에서 `F^k(i)`로 향하는 간선을 추가한 그래프를 만듭니다.

정점 `S`에서 `T`로 도달 가능한지 판정하세요. 가능한 모든 입력 `(A,L,R,S,T)`의 수 중 도달 가능한 입력의 수를 소수 `P`로 나눈 나머지를 구하세요.

## 제약

- `2 ≤ N ≤ 10^5`
- `10^8 ≤ P ≤ 10^9`, `P`는 소수입니다.

## 입력

```text
N P
```

## 출력

답을 출력하세요.
