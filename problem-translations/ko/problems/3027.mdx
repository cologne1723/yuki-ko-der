## 문제 설명

정수 계수를 가지는 다항식 $F(X) = F_0 X^N + F_1 X^{N-1} + \dots + F_N$이 입력으로 주어집니다.

$F(X-1) = H_0 X^N + H_1 X^{N-1} + \dots + H_N$이 되도록 하는 정수 $H_i$들을 구하고, $H_0,\dots,H_N$의 순서로 $1$칸의 반각 스페이스로 구분하여 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$F_0\ F_1\ \dots\ F_N$
```

## 제한

- $1 \leq N \leq 25$
- $-10^8 \leq F_i \leq 10^8$이며 $F_i$는 정수입니다.

## 출력

$H_0,\dots,H_N$의 순서로 $1$칸의 반각 스페이스로 구분하여 출력하세요. 단, $H_i$는 $32$비트 정수 범위에 들어간다고 보장되지 않습니다.

마지막에 개행 문자를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
1 3 3 1
```

#### 출력

```text
1 0 0 0
```

$F(X) = X^3 + 3X^2 + 3X + 1 = (X+1)^3$이므로 $F(X-1) = X^3$입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
4
1 2 3 4 5
```

#### 출력

```text
1 -2 3 0 3
```
