## 문제

4×4 격자에 1부터 16까지의 서로 다른 정수를 배치합니다. 상하좌우로 인접한 모든 칸의 값 차이 절댓값 합을 점수로 정의할 때, 점수가 정확히 $K$인 배치의 수를 구하세요.

## 입력

정수 $K$가 주어집니다.

## 출력

조건을 만족하는 배치의 수를 출력하세요.
