$(1,2,\ldots,N)$의 순열 $P=(P_1,P_2,\ldots,P_N)$가 주어집니다. $P$의 LIS(최장 증가 부분 수열)는 여러 가지일 수 있습니다. 모든 LIS에 포함되는 원소를 나열하세요.

## 입력

```text
N
P_1 P_2 ... P_N
```

$1\le N\le3\times10^5$이고, $P$는 $(1,2,\ldots,N)$의 순열입니다.

## 출력

첫째 줄에 모든 LIS에 포함되는 원소의 개수를 출력합니다. 둘째 줄에 해당 원소를 인덱스 오름차순으로 공백으로 구분해 출력합니다. 개수가 0이면 둘째 줄은 빈 줄로 출력합니다.
