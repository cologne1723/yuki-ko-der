## 문제 설명

당신은 점술사입니다. 점술관에 손님 $1$명이 찾아왔습니다. 손님의 이름은 $S$입니다.

손님은 당신을 시험하기 위해 "제 퍼스널 컬러를 맞혀 보세요"라고 말했습니다.

장사가 번창하도록 손님의 퍼스널 컬러를 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$S$
```

손님의 이름 $S$가 주어집니다.

## 제한

- $S$의 길이는 $3$ 이상 $16$ 이하입니다.
- $S$에는 반각 영숫자와 밑줄만 포함됩니다.
- 2026/04/01 현재 답이 존재합니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
tatyam
```

#### 출력

```text
FF6040
```

### 예제 2 {file=""}

#### 입력

```text
potato167
```

#### 출력

```text
028FF4
```
