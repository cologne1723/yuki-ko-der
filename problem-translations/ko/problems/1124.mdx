## 문제 설명

ABC시는 $N$채의 집과 $N-1$개의 도로로 이루어져 있습니다. 집에는 $1$, $2$, $3$, ..., $N$의 번호가 붙어 있습니다. $i$번째 도로는 집 $A_i$와 집 $B_i$를 연결하며, 어떤 두 집도 여러 도로를 거쳐 연결되어 있습니다.

ABC시는 절벽이 많기 때문에 지진이 발생하면 산사태로 인해 일부 도로가 끊어집니다.

이제 ABC시의 시장인 AGC 씨는 지진에 대한 안전성을 조사하기 위해 다음과 같이 **시의 안전도** $S$를 정의했습니다.

- $D_i$를 집 $i$에서 끊어지지 않은 도로만 지나서 갈 수 있는 집의 수로 정의합니다(집 $i$ 자신을 포함합니다).
- $S = left(D_{1}ight)^2 + left(D_{2}ight)^2 + left(D_{3}ight)^2 + cdots + left(D_{N}ight)^2$로 정의합니다.

도로는 $N-1$개이므로 도로가 끊어지는 방식은 $2^{N-1}$가지입니다. 모든 경우에 대한 시의 안전도 총합을 구하세요.

답은 매우 커질 수 있으므로 $1\,000\,000\,007$로 나눈 나머지를 출력하세요.

## 입력

```text
$N$
$A_1\ B_1$
$A_2\ B_2$
$A_3\ B_3$
$\hspace{4pt}\vdots\hspace{12pt}$
$A_{N-1}\ B_{N-1}$
```

입력은 $N$개의 줄로 주어집니다.

첫 번째 줄에 정수 $N$이 주어집니다.

$1+i$번째 줄 $(1 \leq i \leq N-1)$에 정수 $A_i$, $B_i$가 공백으로 구분되어 주어집니다.

## 제한

$1 \leq N \leq 300\,000$

- $1 \leq A_i < B_i \leq N$
- 어떤 두 집도 여러 도로를 거쳐 연결되어 있습니다.
- 입력은 모두 정수입니다.

## 출력

한 줄에 시의 안전도 총합을 $1\,000\,000\,007$로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 2
2 3
```

#### 출력

```text
48
```

다음 $4$가지 경우를 생각합니다.

- 어떤 도로도 끊어지지 않는 경우: $D_1 = 3, D_2 = 3, D_3 = 3$이 되므로 시의 안전도는 $3^{2} + 3^{2} + 3^{2} = 27$입니다.
- 도로 $1$이 끊어지는 경우: $D_1 = 1, D_2 = 2, D_3 = 2$가 되므로 시의 안전도는 $1^{2} + 2^{2} + 2^{2} = 9$입니다.
- 도로 $2$가 끊어지는 경우: $D_1 = 2, D_2 = 2, D_3 = 1$이 되므로 시의 안전도는 $2^{2} + 2^{2} + 1^{2} = 9$입니다.
- 모든 도로가 끊어지는 경우: $D_1 = 1, D_2 = 1, D_3 = 1$이 되므로 시의 안전도는 $1^{2} + 1^{2} + 1^{2} = 3$입니다.

따라서 시의 안전도 총합은 $27 + 9 + 9 + 3 = 48$입니다.
