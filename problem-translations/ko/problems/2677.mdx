트리의 모든 정점은 흰색입니다. eoeo가 정점 하나를 검게 칠한 뒤 NokonoKotlin이 인접한 검은 정점이 생기지 않도록 흰 정점을 추가로 칠합니다. eoeo는 최종 검은 정점 수를 최소화하고, NokonoKotlin은 최대화할 때 최종 개수를 구하세요.

## 조건

- $1\le N\le2\times10^5$
- 입력 그래프는 트리입니다.

## 입력

```text
$N$
$u_1$ $v_1$
\vdots
$u_{N-1}$ $v_{N-1}$
```

## 출력

최종 검은 정점 수를 출력하세요.
