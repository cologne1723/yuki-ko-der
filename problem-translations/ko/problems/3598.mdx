이 문제는 **대화형 문제**(여러분이 작성한 프로그램과 채점 프로그램이 표준 입출력을 통해 상호작용하는 형식의 문제)입니다.

## 문제 설명

세로 $H$칸, 가로 $W$칸의 격자가 있습니다. 위에서 $i$번째($1 \leq i \leq H$), 왼쪽에서 $j$번째($1 \leq j \leq W$) 칸을 칸 $(i,j)$로 나타냅니다.

처음에 칸 $(1,1)$에 퀸 말이 있고, 칸 $(H,W)$에 킹 말이 있습니다. 퀸 말과 킹 말은 격자 안의 칸에는 자유롭게 출입할 수 있지만, 격자 밖의 칸에는 출입할 수 없습니다.

이제 Alice와 Bob이 다음 게임을 합니다. **Bob부터 시작하여** Alice와 Bob이 번갈아 다음 조작을 수행합니다.

- Alice는 현재 퀸 말이 놓인 칸에서 $1$회 이동으로 도달할 수 있고 킹 말이 놓여 있지 않은 칸을 $1$개 선택하여, 퀸 말을 그 칸으로 이동시킵니다.
- Bob은 현재 킹 말이 놓인 칸에서 $1$회 이동으로 도달할 수 있고 퀸 말이 놓여 있지 않으며 **퀸 말이 $1$회 이동으로 도달할 수도 없는** 칸을 $1$개 선택하여, 킹 말을 그 칸으로 이동시킵니다.

Bob의 차례에 킹 말을 이동할 수 있는 칸이 존재하지 않으면 게임이 종료됩니다. 그렇지 않으면 게임을 계속합니다.

여러분의 프로그램은 Alice로, 채점 프로그램은 Bob으로 행동합니다.

Alice의 목표는 자신의 차례 $3$회 이내에 게임을 종료시키는 것입니다. 적절하게 말을 이동하여 자신의 차례 $3$회 이내에 게임을 종료시키세요.

$T$개의 테스트 케이스가 주어지므로 각각에 답하세요.

### 퀸 말의 이동 방법

퀸 말은 $1$회 이동에서 세로, 가로 또는 대각선 방향으로, 지나가는 경로의 칸이 모두 출입 가능한 한 원하는 만큼의 칸을 이동할 수 있습니다. 단, 현재 칸에 계속 머무는 것은 $1$회 이동으로 세지 않습니다.

엄밀하게는 칸 $(i,j)$에 있는 퀸 말은 양의 정수 $k$에 대해 다음 조건을 만족하는 경우에, 그리고 그 경우에만 해당 칸으로 이동할 수 있습니다.

- 칸 $(i,j+k)$: 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i,j+l)$이 퀸 말이 출입 가능한 칸입니다.
- 칸 $(i,j-k)$: 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i,j-l)$이 퀸 말이 출입 가능한 칸입니다.
- 칸 $(i+k,j)$: 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i+l,j)$가 퀸 말이 출입 가능한 칸입니다.
- 칸 $(i-k,j)$: 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i-l,j)$가 퀸 말이 출입 가능한 칸입니다.
- 칸 $(i+k,j+k)$: 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i+l,j+l)$이 퀸 말이 출입 가능한 칸입니다.
- 칸 $(i+k,j-k)$: 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i+l,j-l)$이 퀸 말이 출입 가능한 칸입니다.
- 칸 $(i-k,j+k)$: 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i-l,j+l)$이 퀸 말이 출입 가능한 칸입니다.
- 칸 $(i-k,j-k)$: 모든 정수 $l$($1 \leq l \leq k$)에 대해 칸 $(i-l,j-l)$이 퀸 말이 출입 가능한 칸입니다.

### 킹 말의 이동 방법

킹 말은 $1$회 이동에서 세로, 가로 또는 대각선 방향으로 인접한 출입 가능한 칸으로 이동할 수 있습니다. 즉, 칸 $(i,j)$에 있는 킹 말은 다음 각 칸이 출입 가능하면 이동할 수 있습니다.

$(i+1,j)$, $(i+1,j+1)$, $(i,j+1)$, $(i-1,j+1)$, $(i-1,j)$, $(i-1,j-1)$, $(i,j-1)$, $(i+1,j-1)$

## 입력

이 문제는 **대화형 문제**(여러분이 작성한 프로그램과 채점 프로그램이 표준 입출력을 통해 상호작용하는 형식의 문제)입니다.

여러분의 프로그램은 Alice로, 채점 프로그램은 Bob으로 행동합니다.

먼저 테스트 케이스의 수 $T$가 주어집니다.

```text
$T$
```

각 테스트 케이스에서 처음으로 $H$, $W$가 표준 입력으로 주어집니다.

```text
$H\ W$
```

그다음 Bob의 차례에 조작 내용이 표준 입력으로 주어집니다.

```text
$x\ y$
```

여기서 다음과 같이 해석합니다.

- $(x,y) \neq (0,0)$이고 $(x,y) \neq (-1,-1)$이면 Bob이 자신의 차례에 킹 말을 칸 $(x,y)$로 이동했다는 뜻입니다. 이 이동은 문제 설명의 규칙을 따릅니다.
- $(x,y) = (0,0)$이면 Bob이 자신의 차례에 킹 말을 이동할 수 없어 게임이 종료되었다는 뜻입니다. 다음 테스트 케이스가 있으면 계속 처리하고, 없으면 프로그램을 종료하세요.
- $(x,y) = (-1,-1)$이면 Alice의 차례에 규칙을 따르지 않는 출력이 이루어졌거나 Alice의 차례를 $3$회 수행한 시점에 게임이 종료되지 않았다는 뜻입니다. 이 경우 이미 오답 판정을 받았으므로 프로그램을 즉시 종료하세요.

## 제한

- 입력은 모두 정수입니다.
- $1 \leq T \leq 1\,000$
- $3 \leq H,W \leq 100$

## 출력

Alice의 차례에는 그 차례에 퀸 말을 이동시킬 칸 $(x,y)$를 다음 형식으로 출력하세요.

```text
$x\ y$
```

이 이동은 규칙을 따라야 합니다.

## 주의점

**출력할 때마다 반드시 표준 출력을 flush하세요. 그렇게 하지 않으면 TLE가 될 수 있습니다.**

잘못된 출력을 한 경우 채점 결과는 정의되지 않습니다.

입력으로 $(x,y)=(-1,-1)$이 주어진 뒤 프로그램을 즉시 종료하지 않으면 채점 결과는 정의되지 않습니다.

모든 테스트 케이스에 답한 뒤에는 프로그램을 즉시 종료하세요. 그렇지 않으면 채점 결과는 정의되지 않습니다.

인터랙티브 문제에 익숙하지 않다면 [인터랙티브 형식의 문제에 관한 안내](https://yukicoder.me/wiki/reactive)도 확인하세요.

```text
2 2
```

Alice의 $1$번째 차례입니다. 칸 $(1,1)$에 있던 퀸 말을 칸 $(2,2)$로 이동시킵니다. **퀸 말은 킹 말이 $1$회 이동으로 도달할 수 있는 칸으로 이동해도 된다는 점에 주의하세요.**

#### 입력

```text
3 4
```

Bob의 $2$번째 차례입니다. 칸 $(2,4)$에 있던 킹 말을 칸 $(3,4)$로 이동시켰습니다.

#### 출력

```text
1 2
```

Alice의 $2$번째 차례입니다. 칸 $(2,2)$에 있던 퀸 말을 칸 $(1,2)$로 이동시킵니다.

#### 입력

```text
2 4
```

Bob의 $3$번째 차례입니다. 칸 $(3,4)$에 있던 킹 말을 칸 $(2,4)$로 이동시켰습니다.

#### 출력

```text
2 3
```

Alice의 $3$번째 차례입니다. 칸 $(1,2)$에 있던 퀸 말을 칸 $(2,3)$으로 이동시킵니다.

#### 입력

```text
0 0
```

Bob이 킹 말을 이동할 수 없게 되어 게임이 종료되었습니다. 모든 테스트 케이스에 답했으므로 프로그램을 종료하세요.
