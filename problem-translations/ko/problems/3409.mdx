## 문제 설명

산타클로스의 창고 안 어느 구획에는 정육면체 모양의 선물 상자가 쌓여 있습니다.

이 구획은 남북 방향으로 $H$칸, 동서 방향으로 $W$칸인 격자이며, 각 칸의 크기는 선물 상자의 크기와 같습니다.

격자의 각 칸에는 선물 상자가 $0$개 이상 쌓여 있습니다.

이 격자를 서쪽에서 보면, 북쪽에서 $i$번째 행 $(1\leq i\leq H)$에 있는 동서 방향으로 일렬로 늘어선 칸에 쌓인 선물 상자 수의 최댓값이 $A_i$개라는 것을 알 수 있습니다.

마찬가지로 이 격자를 남쪽에서 보면, 서쪽에서 $j$번째 열 $(1\leq j\leq W)$에 있는 남북 방향으로 일렬로 늘어선 칸에 쌓인 선물 상자 수의 최댓값이 $B_j$개라는 것을 알 수 있습니다.

격자 안에 쌓인 선물 상자 총 개수로 가능한 값 중 최솟값과 최댓값을 구하세요.

단, 답이 매우 커질 수 있으므로 $10^9+7$로 나눈 나머지를 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$H\ W$
$A_1\ A_2\ \cdots\ A_H$
$B_1\ B_2\ \cdots\ B_W$
```

$1$번째 줄에 격자의 행 수 $H$와 열 수 $W$가 공백으로 구분되어 주어집니다.

$2$번째 줄에 $i$번째 행의 최댓값 $A_i$가 $i$가 작은 순서대로 공백으로 구분되어 주어집니다.

$3$번째 줄에 $j$번째 열의 최댓값 $B_j$가 $j$가 작은 순서대로 공백으로 구분되어 주어집니다.

## 제한

- $1\leq H\leq 100\,000$
- $1\leq W\leq 100\,000$
- $0\leq A_i,B_j\leq 1\,000\,000\,000$
- 주어진 조건을 만족하도록 선물 상자를 쌓는 방법이 존재합니다.
- 입력은 모두 정수입니다.

## 출력

$2$줄에 걸쳐 출력하세요.

$1$번째 줄에 가능한 선물 상자 총 개수의 최솟값을 출력하세요.

$2$번째 줄에 가능한 선물 상자 총 개수의 최댓값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 5
1 3 2
0 1 3 2 1
```

#### 출력

```text
7
17
```

각 칸에 쌓인 선물 상자 수가 다음과 같을 때 선물 상자 총 개수는 $7$개입니다. 선물 상자 총 개수를 $6$개 이하로 만들 수는 없습니다.

`0 1 0 0 1`

`0 0 3 0 0`

`0 0 0 2 0`

각 칸에 쌓인 선물 상자 수가 다음과 같을 때 선물 상자 총 개수는 $17$개입니다. 선물 상자 총 개수를 $18$개 이상으로 만들 수는 없습니다.

`0 1 1 1 1`

`0 1 3 2 1`

`0 1 2 2 1`
