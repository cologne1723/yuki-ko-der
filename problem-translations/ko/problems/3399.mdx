## 문제 설명

정수 $N$이 주어집니다.

또한 변수 $x$가 $x=1$로 초기화되어 있습니다. 여기서 $x<N$인 동안 다음 $5$가지 연산 중 $1$가지를 골라 수행하는 것을 반복합니다.

1. $x$를 $x+1$로 갱신합니다.
2. $x$를 $x+2$로 갱신합니다.
3. $x$를 $x+3$으로 갱신합니다.
4. $x$를 $2x$로 갱신합니다.
5. $x$를 $3x$로 갱신합니다.

연산을 끝냈을 때 $x=N$이 되도록 연산하는 방법의 수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

```text
$N$
```

입력은 정수 $N$으로 주어집니다.

## 제한

- $1\leq N\leq 10^{18}$

## 출력

연산하는 방법의 수를 $998\,244\,353$으로 나눈 나머지를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
1
```

초기 상태에서 $x=1$이므로 연산을 끝냅니다.
연산을 수행하지 않으므로 $1$가지입니다.

### 예제 2 {file=""}

#### 입력

```text
2
```

#### 출력

```text
2
```

연산을 $1$번 수행하면 $x<2$를 만족하지 않게 됩니다.
$1$번의 연산으로 $x=2$가 되는 연산 방법은 연산 $1$ 또는 연산 $4$를 선택하는 경우뿐입니다.
따라서 $2$가지를 출력합니다.

### 예제 3 {file=""}

#### 입력

```text
3
```

#### 출력

```text
4
```
