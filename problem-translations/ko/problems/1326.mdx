## 문제

연결된 단순 무방향 그래프가 주어집니다. 정점 `x`와 `y`가 주어졌을 때, `x`나 `y`가 아닌 정점 하나와 그 정점에 인접한 모든 간선을 삭제하여 `x`와 `y`가 서로 다른 연결 요소에 속하게 만들 수 있는 정점의 수를 구하세요.

`Q`개의 질의에 답하세요.

## 입력

그래프와 질의 `(x,y)`가 주어집니다.

`3 \le N \le 5\times10^4`, `N-1 \le M \le 10^5`, `1 \le Q \le 10^5`입니다.

## 출력

각 질의에 대한 답을 한 줄에 출력하세요.
