## 문제 설명

$1$부터 $6$까지의 정수가 같은 확률로 나오는 일반적인 주사위가 있습니다.

주사위 눈의 합이 정확히 $N$이 될 때까지 주사위를 계속 굴립니다. 단, 도중에 눈의 합이 $N$을 초과하면 그때마다 눈의 합을 $0$으로 초기화합니다.

주사위를 굴리게 되는 횟수의 기댓값을 구하는 프로그램을 작성하세요. 주사위를 굴리는 시행은 서로 독립이라고 가정합니다.

힌트: [완전히 같은 문제](https://yukicoder.me/problems/129)가 있습니다.

## 입력

$1$번째 줄에 테스트 케이스 수 $T$가 주어집니다. 각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- $1 \le T \le 10^4$
- $1 \le N \le 10^{18}$

## 출력

각 테스트 케이스마다 주사위를 굴리는 횟수의 기댓값을 $1$줄에 출력하세요. 상대 오차가 $10^{-12}$ 이하이면 정답으로 인정됩니다.
