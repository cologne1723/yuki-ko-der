## 문제

YUKI국에는 액면가가 삼각수인 동전이 유통됩니다. 즉 모든 양의 정수 $k$에 대해 $k(k+1)/2$엔 동전이 있습니다. 액면가를 작은 순서로 나열하면 1, 3, 6, 10, 15, 21, 28, …엔입니다.

눈남군은 모든 액면가의 동전을 각각 $10^{100}$개씩 가지고 있고 $N$엔짜리 물건을 사려 합니다. 동전으로 정확히 $N$엔을 지불할 때 사용하는 동전 수를 최소화하세요.

## 입력

```text
N
```

$1\le N\le10^7$이고 $N$은 정수입니다.

## 출력

최소 동전 수를 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
8
```

출력:

```text
3
```

6엔 동전 1개와 1엔 동전 2개로 8엔을 지불할 수 있으며, 3개가 최솟값입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
10
```

출력:

```text
1
```

액면가 10엔 동전 1개로 지불하는 것이 최솟값입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
15415
```

출력:

```text
2
```

액면가 15엔과 15400엔 동전 1개씩, 총 2개로 지불할 수 있습니다.
