## 문제 설명

여러분은 변수 $x=0$을 가지고 있습니다. 각 $i=1,2,\dots,2^N-1$에 대해 다음 연산을 순서대로 수행합니다.

- $i$를 이진 표기했을 때 끝에 연속하는 $0$의 개수를 $k$라고 합니다. 예를 들어 $i=6$일 때 $6$의 이진 표기는 $110$이므로 $k=1$입니다.
- $0\leq y\leq 2^k$이고 $(x+y)\ \text{AND}\ i=(x+y)$를 만족하는 정수 $y$를 선택하여, $x$를 $x+y$로 바꿉니다.

단, $\text{AND}$는 비트별 논리곱을 나타냅니다. 연산의 구체적인 예는 예제 $1$을 참고하세요.

$2^N-1$회의 연산 중 $M$회는 $y\geq 1$인 $y$를 선택하고, 나머지 $2^N-1-M$회는 $y=0$을 선택합니다.

$2^N-1$회의 가능한 연산열의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

$2$개의 연산열이 같다는 것은 모든 연산에서 선택한 정수 $y$가 서로 같은 것을 의미합니다.

## 입력

```text
$N\ M$
```

$N$과 $M$은 정수입니다.

## 제한

- $1\leq N,M\leq 500$
- 입력은 모두 정수입니다.

## 출력

답을 정수로 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2 2
```

#### 출력

```text
2
```

연산은 $2^N-1=3$회 수행하며, 그중 $y\geq 1$이 되도록 수행한 횟수가 $2$회인 연산열을 셉니다.

조건을 만족하는 $2$개의 연산열에 대해 각 연산 전후의 $x$를 나타내면 다음과 같습니다. 화살표 위의 정수는 해당 연산에서 선택한 $y$의 값입니다.

$0\overset{0}{\to}0\overset{2}{\to}2\overset{1}{\to}3$

$0\overset{1}{\to}1\overset{1}{\to}2\overset{0}{\to}2$

예를 들어 다음과 같은 연산열은 가능한 연산열이 아닙니다.

$0\overset{1}{\to}1\overset{0}{\to}1\overset{2}{\to}3$

$2$번째 연산에서 $(x+y)\ \text{AND}\ i=(x+y)$를 만족하지 않기 때문입니다.

$0\overset{0}{\to}0\overset{0}{\to}0\overset{3}{\to}3$

$3$번째 연산에서 $y\leq 2^k$를 만족하지 않기 때문입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 7
```

#### 출력

```text
1
```

다음의 $1$개만 조건을 만족합니다. 표기는 예제 $1$과 같습니다.

$0\overset{1}{\to}1\overset{1}{\to}2\overset{1}{\to}3\overset{1}{\to}4\overset{1}{\to}5\overset{1}{\to}6\overset{1}{\to}7$

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1 500
```

#### 출력

```text
0
```

연산을 $1$회만 수행하므로 $y\geq 1$이 되도록 수행할 수 있는 횟수는 많아야 $1$회입니다. 따라서 조건을 만족하는 연산열은 존재하지 않습니다.

### 예제 4 {file="01_sample_04.txt"}

```text
234 432
```

#### 출력

```text
611707541
```
