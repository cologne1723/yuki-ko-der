## 문제 설명

여러분은 문자 `y` $Y$개, 문자 `i` $I$개, 문자 `w` $W$개를 가지고 있습니다. 이 문자들을 모두 사용하여 적절히 일렬로 배열하면 길이 $Y+I+W$인 문자열 $S$를 만들 수 있습니다.

이때 $S$에 포함된 **연속하지 않아도 되는** 부분수열 중 문자열 `yiwiy`와 같은 것의 개수를 $P$라 하고, $S$에 포함된 **연속한** 부분문자열 중 문자열 `iwiwi`와 같은 것의 개수를 $Q$라 하면 $S$의 **매력도**는 $AP+BQ$입니다. 단, $A$, $B$는 입력으로 주어지는 음이 아닌 정수이며, $2$개의 부분수열 또는 부분문자열은 문자를 꺼내는 위치가 다를 때 그리고 그때에 한해서 서로 다른 것으로 셉니다.

여러분이 만들 수 있는 문자열 $S$ 중 매력도가 가장 높은 것을 $1$개 출력하세요.

정답 후보가 여러 개라면 그중 어느 $1$개를 출력해도 됩니다.

$T$개의 테스트 케이스가 주어지므로 각각에 대해 답을 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$T$
$\text{case}_1$
$\text{case}_2$
$\vdots$
$\text{case}_T$
```

여기서 $\text{case}_i$는 $i$번째 테스트 케이스의 입력을 의미하며, 각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$Y\ I\ W\ A\ B$
```

## 제한

- $1 \leq T \leq 10^5$
- $1 \leq Y+I+W \leq 10^6$
- $0 \leq Y,I,W$
- $0 \leq A,B \leq 10^9$
- 입력은 모두 정수입니다.
- 모든 테스트 케이스에서 $Y+I+W$의 합은 $10^6$ 이하입니다.

## 출력

다음 형식으로 출력하세요.

```text
$\text{answer}_1$
$\text{answer}_2$
$\vdots$
$\text{answer}_T$
```

여기서 $\text{answer}_i$는 $i$번째 테스트 케이스의 출력을 의미합니다.

각 테스트 케이스에 대해, 여러분이 만들 수 있는 문자열 중 매력도가 가장 높은 것 중 $1$개가 $S$였다고 할 때 다음 형식으로 출력하세요.

```text
$S$
```

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
2 3 2 1 1
1 2 8 100 0
6 6 3 2 5
```

#### 출력

```text
yiwiwiy
yiwiwwwwwww
yyyiiiwwwiiiyyy
```

$1$번째 테스트 케이스에서는 문자열 `yiwiwiy`를 만들면 매력도 $5$를 달성할 수 있습니다. 매력도가 $5$보다 큰 문자열을 만드는 것은 불가능하므로, 이 문자열을 출력하면 정답입니다.

$2$번째 테스트 케이스에서 `yiwiwwwwwww`의 매력도는 $0$입니다. 매력도가 $1$ 이상인 문자열을 만드는 것은 불가능하므로, 이 문자열을 출력하면 정답입니다. 이 입력에 대해서는 `wwwwiyiwwww` 등 문제의 조건을 만족하는 다른 매력도 $0$인 문자열을 출력해도 정답입니다.

$3$번째 테스트 케이스에서 달성할 수 있는 매력도의 최댓값은 $486$입니다.
