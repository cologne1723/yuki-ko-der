## 문제 설명

소수 $p$와 $2$ 이상의 정수 $n$을 사용하여 $p^n$으로 나타낼 수 있는 수를 **81과 같은 수**라고 정의합니다.

예를 들어 $81$, $125$, $2\,401$은 각각 $3^4$, $5^3$, $7^4$로 나타낼 수 있으므로 81과 같은 수입니다.

한편 $6$, $11$, $144$ 등은 소수 $p$와 $2$ 이상의 정수 $n$을 사용하여 $p^n$의 형태로 나타낼 수 없으므로 81과 같은 수가 아닙니다.

정수 $N$이 주어질 때, $N$ 이하인 81과 같은 수의 총합을 구하세요.

제한의 조건에서 답은 $2^{63}$ 미만임이 보장됩니다.

## 입력

```text
$N$
```

## 제한

- $2 \le N \le 10^{10}$
- $N$은 정수입니다.

## 출력

$N$ 이하인 81과 같은 수의 총합을 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
81
```

#### 출력

```text
315
```

$81$ 이하인 81과 같은 수는 $4$, $8$, $9$, $16$, $25$, $27$, $32$, $49$, $64$, $81$이므로 이들의 합인 $315$를 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
216
```

#### 출력

```text
858
```

### 예제 3 {file=""}

#### 입력

```text
10000000000
```

#### 출력

```text
30756925116342
```
