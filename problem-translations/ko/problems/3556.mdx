## 문제 설명

$N$개의 길이 $N$인 문자열 $S_1,S_2,\dots,S_N$이 주어집니다.

주어지는 문자열은 다음 $2$개의 [ASCII 아트](https://ja.wikipedia.org/wiki/%E3%82%A2%E3%82%B9%E3%82%AD%E3%83%BC%E3%82%A2%E3%83%BC%E3%83%88) 중 $1$개를 $k$배 닮음 확대한 것입니다. $k$는 $1 \le k \le 10$을 만족합니다.

원래 ASCII 아트는 $2$개 모두 $11$행 $11$열입니다.

ASCII 아트 `KCPC`

```text
#...#.#####
#.##..#....
##....#....
#.##..#....
#...#.#####
...........
####..#####
#...#.#....
####..#....
#.....#....
#.....#####
```

ASCII 아트 `KUPC`

```text
#...#.#...#
#.##..#...#
##....#...#
#.##..#...#
#...#.#####
...........
####..#####
#...#.#....
####..#....
#.....#....
#.....#####
```

양의 정수 $k$에 대해 ASCII 아트의 $k$배 닮음 확대를 다음과 같이 정의합니다.

- 원래 ASCII 아트가 $n$행 $n$열이라고 합니다.
- 확대 후 ASCII 아트는 $kn$행 $kn$열입니다.
- 확대 후 ASCII 아트의 위에서 $i$번째 행, 왼쪽에서 $j$번째 열에 쓰인 문자는 원래 ASCII 아트의 위에서 $\displaystyle 1+\left\lfloor\frac{i-1}{k}\right\rfloor$번째 행, 왼쪽에서 $\displaystyle 1+\left\lfloor\frac{j-1}{k}\right\rfloor$번째 열에 쓰인 문자와 같습니다. ($1 \le i,j \le kn$)

원래 ASCII 아트가 `KCPC`라면 `KCPC`를, `KUPC`라면 `KUPC`를 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$S_1$
$S_2$
$\vdots$
$S_N$
```

$N$은 문자열의 개수이자 각 문자열의 길이입니다. $S_i$는 $i$번째 문자열입니다.

## 제한

- 어떤 $k$ ($1 \le k \le 10$)가 존재하며, 문자열 $S_1,S_2,\dots,S_N$은 `KCPC` 또는 `KUPC` ASCII 아트를 $k$배 닮음 확대한 것입니다.

다음과 같은 부분점이 설정되어 있습니다.

| 부분점 | 배점 | 제한 |
| --- | ---: | --- |
| 부분점 $1$ | $5$% ($5$점) | $k=1$ |
| 부분점 $2$ | $5$% ($5$점) | $k=2$ |
| 부분점 $3$ | $5$% ($5$점) | $k=3$ |
| 부분점 $4$ | $5$% ($5$점) | $k=4$ |
| 부분점 $5$ | $5$% ($5$점) | $k=5$ |
| 부분점 $6$ | $6$% ($6$점) | $k=6$ |
| 부분점 $7$ | $7$% ($7$점) | $k=7$ |
| 부분점 $8$ | $8$% ($8$점) | $k=8$ |
| 부분점 $9$ | $9$% ($9$점) | $k=9$ |
| 부분점 $10$ | $10$% ($10$점) | $k=10$ |
| 부분점 $11$ | $5$% ($5$점) | 답이 `KCPC`입니다. |
| 부분점 $12$ | $5$% ($5$점) | 답이 `KUPC`입니다. |
| 부분점 $13$ | $25$% ($25$점) | 추가 제한이 없습니다. |

## 출력

원래 ASCII 아트가 `KCPC`라면 `KCPC`를, `KUPC`라면 `KUPC`를 출력하세요.
