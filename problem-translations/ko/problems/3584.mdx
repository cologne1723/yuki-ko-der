## 문제 설명

문자열 `camouflage`에는 `mole`이 연속하지 않아도 되는 부분수열로 숨겨져 있습니다.

`a-z`의 영소문자 $26$개로 이루어진 길이 $N$인 문자열 $S$에 대해, $f(S)$를 $S$의 부분수열 중 문자열 `mole`과 일치하는 것의 개수라고 정의합니다.

더 엄밀히 말하면, $f(S)$는

$1 \leq i < j < k < l \leq N$이고 $S_i=$`m`, $S_j=$`o`, $S_k=$`l`, $S_l=$`e`를 만족하는 $4$개 정수의 순서 있는 조 $(i,j,k,l)$의 개수입니다.

길이 $N$인 영소문자 문자열은 모두 $26^N$개 있습니다. 이 모든 문자열 $S$에 대한 $f(S)$의 총합을 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 $1$줄에 주어집니다.

```text
$N$
```

## 제한

- $4 \leq N \leq 2 \times 10^5$
- 입력은 모두 정수입니다.

## 출력

답을 $998\,244\,353$으로 나눈 나머지를 $1$줄에 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
```

#### 출력

```text
1
```

길이 $4$인 문자열 중 `mole`을 부분수열로 포함하는 것은 문자열 자체가 `mole`인 $1$가지뿐입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
6
```

#### 출력

```text
10140
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
100
```

#### 출력

```text
774511835
```

답은 매우 커질 수 있으므로 $998\,244\,353$으로 나눈 나머지를 출력하세요.
