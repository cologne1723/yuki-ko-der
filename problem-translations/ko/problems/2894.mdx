## 문제 설명

`<`와 `>`로 이루어진 길이 $N$인 문자열 $S$가 주어집니다. 여기서 $S_i$는 $S$의 $i$번째 문자입니다.

모든 $i=1,2,\cdots,N$에 대해 다음 조건을 만족하는 실수 함수 $f(x)$를 생각합니다.

- $i-1 \leq a < b \leq i$를 만족하는 임의의 실수 $a,b$에 대해,
  - $S_i$가 `<`라면 $f(a) < f(b)$를 만족합니다.
  - $S_i$가 `>`라면 $f(a) > f(b)$를 만족합니다.

$0 \leq x \leq N$을 만족하는 실수 $x$ 중 $f(x)=0$을 만족하는 것의 개수로 가능한 최댓값을 구하세요.

단, 답은 유한함이 증명될 수 있습니다.

## 입력

```text
$N$
$S$
```

- $1$번째 줄에 정수 $N$이 주어집니다.
- $2$번째 줄에 `<`와 `>`로 이루어진 길이 $N$인 문자열 $S$가 주어집니다.

## 제한

- $1 \leq N \leq 5 \times 10^5$
- $N$은 정수입니다.
- $S$는 `<`와 `>`로 이루어진 길이 $N$인 문자열입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}
#### 입력

```text
3
><<
```

#### 출력

```text
2
```

예를 들어 $f(x)=|x-1|-1$과 같은 함수는 조건을 만족합니다. 이 함수는 $x=0,2$일 때 $f(x)=0$을 만족합니다.

$f(x)=0$을 만족하는 $x$가 $3$개 이상이 되도록 할 수는 없으므로, $f(x)=0$을 만족하는 $x$의 개수의 최댓값인 $2$를 출력합니다.

### 예제 2 {file=""}
#### 입력

```text
7
<<<<<<<
```

#### 출력

```text
1
```

### 예제 3 {file=""}
#### 입력

```text
17
<<<<><>>><><<><<<
```

#### 출력

```text
9
```
