$(1,2,\ldots,N)$의 순열 $P$ 중 $P_1=X$, $P_N=Y$, 모든 $i$에 대해 $\lvert P_{i+1}-P_i\rvert\le2$를 만족하는 것의 개수를 구하세요.

## 입력

```text
$N\ X\ Y$
```

$2\le N\le2\times10^5$, $1\le X,Y\le N$, $X\ne Y$입니다.

## 출력

조건을 만족하는 순열의 개수를 $998244353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4 1 4
```

#### 출력

```text
2
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
6 3 5
```

#### 출력

```text
1
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
4 3 2
```

#### 출력

```text
0
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
31415 9265 3589
```

#### 출력

```text
889048175
```
