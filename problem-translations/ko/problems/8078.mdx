## 문제 설명

정점에 $1$부터 $N$까지, 간선에 $1$부터 $M$까지 번호가 붙은 $N$개 정점 $M$개 간선의 단순 연결 무향 그래프가 주어집니다. 간선 $i$는 정점 $u_i$와 정점 $v_i$를 가중치 $w_i$로 양방향 연결합니다.

어떤 정점에서 출발하여 모든 정점을 정확히 $1$번씩 지나고 출발점으로 돌아오는 순회로 중 가중치가 최소인 순회로의 가중치를 구하세요.

이 문제의 제약 아래에서는 그러한 순회로가 적어도 $1$개 존재한다는 것을 보일 수 있습니다.

## 입력

```text
$N\ M$
$u_1\ v_1\ w_1$
$u_2\ v_2\ w_2$
$\vdots$
$u_M\ v_M\ w_M$
```

입력은 모두 정수입니다.

## 제한

- 주어지는 그래프는 단순하고 연결되어 있습니다.
- $2 \leq N \leq 500$
- $M=\displaystyle \frac{N(N-1)}{2}$
- $1 \leq u_i,v_i \leq N$
- $w_i=1$

## 출력

문제 설명의 조건을 만족하는 순회로의 가중치 최솟값을 $1$행에 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

#### 입력

```text

```

#### 출력

```text

```

왕복해서 돌아오는 수밖에 없습니다.
