이 문제는 반응형 형식의 문제(저지 측 프로그램과 대화하며 실행해야 하는 문제)입니다.

반응형 형식의 문제에 익숙하지 않은 분은 [반응형 형식의 문제에 관한 정리](https://yukicoder.me/wiki/reactive)도 참고할 수 있습니다.

## 문제 설명

처음에 $3$개의 음이 아닌 정수 $N$, $M$, $L$이 주어집니다.

**冪乗大好きbot**은 **거듭제곱**을 매우 좋아하는 봇입니다.

**冪乗大好きbot**은 양의 정수 $B$를 숨겨 두고 있으며, $N^{(M^L)}$($N$의 「$M$의 $L$제곱」제곱)을 $B$로 나눈 나머지 $N^{(M^L)} \bmod B$를 알고 싶어 합니다.

단, 여기서는 $0^0$을 $1$로 정의합니다.

이제 다음 질의를 $0$회 이상 $100$회 이하로 원하는 횟수만큼 수행합니다.

1. 먼저 $10^9$ 이하의 음이 아닌 정수 $i$, $j$를 선택하고, $i^j$를 $B$로 나눈 나머지 $i^j \bmod B$를 질의합니다.
2. 이어서 **冪乗大好きbot**이 $i^j \bmod B$를 답합니다.

마지막으로 $N^{(M^L)} \bmod B$를 구하세요.

## 입력

처음에 $N$, $M$, $L$이 반각 공백으로 구분되어 표준 입력으로 $1$줄에 주어집니다.

```text
$N\ M\ L$
```

## 제한

입력에는 주어지지 않지만 $B$는 다음 제한을 만족합니다.

- 모든 질의 전에 $B$는 고정되어 있으며, 즉 질의 전후에 $B$의 값은 변하지 않습니다.
- $B$는 $1 \leq B \leq 10^9$를 만족하는 정수입니다.

입력은 다음 제한을 만족합니다.

- $N$은 $0 \leq N \leq 10^2$를 만족하는 정수입니다.
- $M$은 $0 \leq M \leq 10^2$를 만족하는 정수입니다.
- $L$은 $0 \leq L \leq 10^2$를 만족하는 정수입니다.
- $10^9$ 이하의 임의의 음이 아닌 정수 $i$, $j$에 대해 $i^j$를 $B$로 나눈 나머지를 질의했을 때, 그 답인 입력 $i^j \bmod B$는 $0 \leq i^j \bmod B < B$를 만족하는 정수입니다.

## 출력

그 후 질의를 $0$회 이상 $100$회 이하로 원하는 횟수만큼 수행합니다. 질의는 표준 입출력을 사용하여 다음 형식으로 수행합니다.

1. 먼저 $10^9$ 이하의 음이 아닌 정수 $i$, $j$를 선택하고, `?`와 $i$, $j$를 반각 공백으로 구분하여 $1$줄에 출력합니다.

```text
$?\ i\ j$
```

2. 이어서 $i^j \bmod B$가 $1$줄에 주어집니다. 이때 저지 측의 계산량은 $O(\log_2 \max\{1,j\})$임이 보장됩니다.

```text
$i^j \bmod B$
```

다음으로 이 문제의 답을 표준 출력에 다음 형식으로 출력합니다.

- `!`과 $N^{(M^L)} \bmod B$를 반각 공백으로 구분하여 $1$줄에 출력합니다.

```text
$!\ N^{(M^L)}\bmod B$
```

마지막으로 개행을 출력하세요.

이 문제에서 다음 지시를 따르지 않은 제출의 채점 결과는 보장하지 않습니다.

출력 형식을 엄격하게 지켜야 합니다. 예를 들어 불필요한 공백을 넣지 마세요.

출력할 때마다 끝에 개행을 넣고 표준 출력을 flush하세요.

이 문제의 답을 출력한 뒤에는 프로그램을 즉시 종료하세요.

## 예제

### 예제 1 {file=""}

**冪乗大好きbot**이 $B = 10$을 숨겨 두었을 때의 대화 예시입니다.

#### 입력

```text
4 3 2
```

$(N,M,L) = (4,3,2)$가 입력으로 주어졌습니다.

#### 출력

```text
? 0 0
```

당신은 $0^0$을 $B$로 나눈 나머지를 질의했습니다.

#### 입력

```text
1
```

**冪乗大好きbot**은 $0^0 = 1$을 $B = 10$으로 나눈 나머지가 $1$이라고 답했습니다.

#### 출력

```text
? 5 2
```

당신은 $5^2$를 $B$로 나눈 나머지를 질의했습니다.

#### 입력

```text
5
```

**冪乗大好きbot**은 $5^2 = 25$를 $B = 10$으로 나눈 나머지가 $5$라고 답했습니다.

#### 출력

```text
? 2 5
```

당신은 $2^5$를 $B$로 나눈 나머지를 질의했습니다.

#### 입력

```text
2
```

**冪乗大好きbot**은 $2^5 = 32$를 $B = 10$으로 나눈 나머지가 $2$라고 답했습니다.

#### 출력

```text
? 10 1
```

당신은 $10^1$을 $B$로 나눈 나머지를 질의했습니다.

#### 입력

```text
0
```

**冪乗大好きbot**은 $10^1 = 10$을 $B = 10$으로 나눈 나머지가 $0$이라고 답했습니다.

#### 출력

```text
? 4 9
```

당신은 $4^9$를 $B$로 나눈 나머지를 질의했습니다.

#### 입력

```text
4
```

**冪乗大好きbot**은 $4^9 = 262\,144$를 $B = 10$으로 나눈 나머지가 $4$라고 답했습니다.

#### 출력

```text
! 4
```

당신은 $N^{(M^L)} = 4^{(3^2)}$를 $B = 10$으로 나눈 나머지가 $4$라고 답했습니다. 이는 정답입니다.
