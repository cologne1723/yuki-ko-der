## 문제

샹퍼노운 상수 $C_{10}$은 $0.$ 뒤에 1 이상의 모든 정수를 10진수 표기로 오름차순 연결한 수입니다. $C_{10}=0.1234567891011121314151617\ldots$일 때 소수점 이하 $D$번째 숫자를 출력하세요.

## 입력

~~~text
$D$
~~~

$1\leq D\leq100$이며 $D$는 정수입니다.

## 출력

$C_{10}$의 소수점 이하 $D$번째 숫자를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
1
~~~

#### 출력

~~~text
1
~~~

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
11
~~~

#### 출력

~~~text
0
~~~

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
96
~~~

#### 출력

~~~text
5
~~~
