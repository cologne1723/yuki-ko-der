## 문제 설명

양의 정수 $A$, $B$가 주어집니다.

어떤 음이 아닌 정수 $x$, $y$가 존재하여 $N=Ax+By$로 나타낼 수 있을 때, 그리고 그때에 한해 $N$을 좋은 정수라고 정의합니다.

좋은 정수가 아닌 양의 정수의 개수를 구하세요.

그러한 정수의 개수가 유한하지 않다면 $-1$을 출력하세요.

## 입력

```text
$A\ B$
```

## 제한

- $1\leq A,B\leq100$
- 입력은 모두 정수입니다.

## 출력

답을 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 2
```

#### 출력

```text
0
```

### 예제 2 {file=""}

#### 입력

```text
4 18
```

#### 출력

```text
-1
```

### 예제 3 {file=""}

#### 입력

```text
21 16
```

#### 출력

```text
150
```
