## 문제 설명

$T$개의 테스트 케이스가 주어집니다.

각 테스트 케이스에 대해 정수 $N$, $X$, $Y$, $A$, $B$가 주어지므로 $f^N(X,Y)$를 출력하세요.

단, $f^N(X,Y)$를 다음과 같이 정의합니다.

- $X+Y<0$일 때 $f(X,Y)=(X+A,Y)$입니다.
- $X+Y\geq 0$일 때 $f(X,Y)=(X,Y-B)$입니다.
- $N=1$일 때 $f^N(X,Y)=f(X,Y)$입니다.
- $N\geq 2$일 때 $f^N(X,Y)=f(f^{N-1}(X,Y))$입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\text{case}_1$
$\text{case}_2$
$\vdots$
$\text{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ X\ Y\ A\ B$
```

## 제한

- $1\leq T\leq 10^5$
- $1\leq N\leq 10^9$
- $|X|,|Y|,|A|,|B|\leq 10^9$
- 입력은 모두 정수입니다.

다음과 같은 부분점이 설정되어 있습니다.

| 부분점 | 배점 | 제한 |
| --- | ---: | --- |
| 부분점 $1$ | $10$% ($25$점) | $N\leq 10$ |
| 부분점 $2$ | $60$% ($150$점) | $0<A$이고 $0<B$ |
| 부분점 $3$ | $30$% ($75$점) | 추가 제한 없음 |

## 출력

$T$줄에 걸쳐 출력하세요.

$i$번째 줄에는 $i$번째 테스트 케이스의 답 $f^N(X,Y)=(P,Q)$에 대해 $P$와 $Q$를 공백으로 구분하여 출력하세요.

## 예제

### 예제 1 {file="01_sub1_sample_01.txt"}

#### 입력

```text
3
3 -3 2 1 1
5 3 4 -3 4
4 -1 0 5 3
```

#### 출력

```text
-1 1
-6 -4
9 -6
```

$1$번째 테스트 케이스에서는 $A=B=1$이고, $f(-3,2)=(-2,2)$, $f(-2,2)=(-2,1)$, $f(-2,1)=(-1,1)$입니다.

따라서 $f^3(-3,2)=f(f^2(-3,2))=f(f(f(-3,2)))=f(f(-2,2))=f(-2,1)=(-1,1)$입니다.
