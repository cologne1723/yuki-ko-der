`0`과 `1`로만 이루어진 문자열 `S`가 주어집니다. 인접한 두 문자를 골라 값이 작지 않은 문자를 삭제하는 작업을 원하는 만큼 수행할 수 있습니다.

작업 후 만들 수 있는 서로 다른 문자열의 개수를 `924844033`으로 나눈 나머지를 구하세요.

## 제약

- `1 <= |S| <= 3 * 10^6`
- `S`는 `0`과 `1`로만 이루어집니다.

## 입력

문자열 `S`가 주어집니다.

## 출력

답을 `924844033`으로 나눈 나머지를 출력하세요.
