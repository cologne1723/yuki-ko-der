길이 $N$의 정수열 $A_1,A_2,\ldots,A_N$이 주어집니다. 이 수열의 공집합이 아닌 부분 수열 $2^N-1$개의 지그재그도의 합을 $10^9+7$로 나눈 나머지를 구하세요.

길이 $M$인 수열 $B$의 지그재그도는 $2\le i\le M-1$인 인덱스 중 $B_i$가 양옆보다 모두 크거나 양옆보다 모두 작은 인덱스의 개수입니다.

## 입력

```text
N
A_1 A_2 ... A_N
```

$1\le N\le10^5$, $1\le A_i\le10^9$입니다.

## 출력

답을 출력하세요.
