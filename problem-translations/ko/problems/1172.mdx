## 문제 설명

정수열 $(a_i)_{i \geq 0}$의 첫 $K$개 항 $a_0,\ldots,a_{K-1}$와 $K$개의 정수 $c_1,\ldots,c_K$가 주어집니다. 수열의 $K$번째 항 이후를 다음 점화식으로 정의합니다.

$\displaystyle a_i=\sum_{k=1}^{K}c_k a_{i-k}\quad(i \geq K)$

길이 $N$인 배열 $(x_0,\ldots,x_{N-1})$의 모든 원소를 $0$으로 초기화하고, 다음 연산을 $j=1,\ldots,M$ 순서로 수행합니다.

- 연산 $j$: $l_j \leq i < r_j$인 모든 정수 $i$에 대해 $x_i \gets x_i+a_{i-l_j}$로 갱신합니다.

모든 연산을 수행한 뒤 각 $i$($0 \leq i < N$)에 대한 $x_i$를 $10^9+7$로 나눈 나머지를 구하세요.

## 입력

```text
$K\ N\ M$
$a_0\ a_1\ \cdots\ a_{K-1}$
$c_1\ c_2\ \cdots\ c_K$
$l_1\ r_1$
$l_2\ r_2$
$\vdots$
$l_M\ r_M$
```

- $1 \leq K \leq 200$
- $1 \leq N \leq 100\,000$
- $1 \leq M \leq 100\,000$
- $0 \leq a_i \leq 10^9$($0 \leq i < K$)
- $0 \leq c_i \leq 10^9$($1 \leq i \leq K$)
- $0 \leq l_j < r_j \leq N$($1 \leq j \leq M$)
- 입력은 모두 정수입니다.

## 출력

$(i+1)$번째 줄($0 \leq i < N$)에 모든 연산 후의 $x_i$를 $10^9+7$로 나눈 나머지를 출력하세요. 마지막에 줄바꿈을 넣으세요.

## 예제

### 예제 1 {file=""}
#### 입력
```text
2 6 3
3 1
1 2
2 4
0 5
3 6
```
#### 출력
```text
3
1
10
13
24
7
```

점화식은 $a_i=a_{i-1}+2a_{i-2}$이고 $a_0=3$, $a_1=1$, $a_2=7$, $a_3=9$, $a_4=23$입니다. 각 연산 후 배열은 각각 $(0,0,3,1,0,0)$, $(3,1,10,10,23,0)$, $(3,1,10,13,24,7)$입니다.
