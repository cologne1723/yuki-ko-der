## 문제 설명

다음과 같이 수열 $F=(F_1,F_2,\ldots)$를 정의합니다.

- $F_1=1$
- $F_2=1$
- $F_i=F_{i-1}+F_{i-2}\ (i\geq3)$

양의 정수 $N$, $K$가 주어집니다.

$\displaystyle \left(\sum_{i=1}^{N}F_i^{\ K}\right)\bmod 998\,244\,353$

을 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ K$
```

## 제한

- $1\leq N\leq10^{18}$
- $1\leq K\leq100$
- $N$, $K$는 정수입니다.

## 출력

답을 출력하고, 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 3
```

#### 출력

```text
37
```

$F_1=1$, $F_2=1$, $F_3=2$, $F_4=3$이므로 답은 $(1^3+1^3+2^3+3^3)\bmod 998\,244\,353=37$입니다.

### 예제 2 {file=""}

#### 입력

```text
1 1
```

#### 출력

```text
1
```

$N=1$ 또는 $K=1$인 경우도 있습니다.

### 예제 3 {file=""}

#### 입력

```text
1000000000000000000 100
```

#### 출력

```text
741845682
```
