봉투에 흰 칩 `A`개, 검은 칩 `B`개, 갈색 칩 `C`개가 있습니다. `N`번 반복해서 칩 두 개를 무작위로 뽑습니다.

두 칩의 색이 같으면 하나를 얻고 다른 하나를 봉투에 돌려놓습니다. 색이 다르면 두 칩 모두 돌려놓습니다. 최종적으로 얻은 각 색 칩 개수의 기대값을 흰색, 검은색, 갈색 순서로 출력하세요.

## 제약

- `1 <= A,B,C,N <= 50`

## 입력

`A B C N`이 주어집니다.

## 출력

기대값을 공백으로 구분해 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 2 1 1
```

#### 출력

```text
0.2 0.06666666666666667 0.0
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 1 1 50
```

#### 출력

```text
0.0 0.0 0.0
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
4 3 2 13
```

#### 출력

```text
1.7966653641138075 1.0669842436070012 0.4428093340194705
```
