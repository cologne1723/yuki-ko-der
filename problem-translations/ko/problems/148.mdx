## 문제 설명

부정행위를 막기 위해 학생들은 같은 책상에서 서로 이웃한 좌석에 앉을 수 없습니다. 의자가 3개 있는 책상에 학생 2명이 앉는 경우 양 끝 의자만 사용할 수 있고, 학생 1명이 앉는 경우에는 3개 중 어느 의자든 사용할 수 있습니다.

어떤 방에는 책상이 하나만 있고 의자가 $C$개 있습니다. 이 방에서 $P$명의 학생이 시험을 볼 때 학생을 배치하는 방법의 수를 $10^9+7$로 나눈 나머지를 구하세요. 시험 감독 (2)와 달리 학생은 서로 구별된다는 점에 주의하세요.

프로그램이 1초 이내에 실행되면서 정답을 출력하고 yukicoder가 허용하는 프로그램이라면 정답으로 인정됩니다.

## 입력

첫째 줄에 테스트 케이스 수 $T$가 주어집니다. 각 테스트 케이스는 다음 형식입니다.

```text
C P
```

- $1 \le T \le 30$
- $1 \le C \le 10^{10000}$
- $1 \le P \le 10^{10000}$

## 출력

각 테스트 케이스에 대해 학생 배치 방법의 수를 $10^9+7$로 나눈 나머지를 한 줄에 출력하세요.
