서로 다른 양의 정수열 $A$를 자유롭게 재배열해 $B$를 만듭니다. $B_{N+1}=B_1$로 두고 점수 $\sum_{i=1}^N(B_i\bmod B_{i+1})$의 최댓값을 구하세요.

## 조건

- $2\le N\le3\times10^5$
- $1\le A_1<\cdots<A_N\le10^6$

## 입력

```text
N
A1 A2 ... AN
```

## 출력

점수의 최댓값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 2 3
```

#### 출력

```text
3
```

### 예제 2 {file=""}

#### 입력

```text
3
3 5 9
```

#### 출력

```text
9
```

### 예제 3 {file=""}

#### 입력

```text
10
12985 24371 98519 119747 180021 188891 211609 241216 248205 263054
```

#### 출력

```text
1331923
```
