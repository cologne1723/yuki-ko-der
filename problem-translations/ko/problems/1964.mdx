길이 $n$인 배열의 입력은 보통 공백으로 구분된 한 줄의 형태로 주어집니다. 배열 $a$에 대해 $f(a)$를 $a$를 입력했을 때의 입력 길이로 정의합니다. 단, 마지막 개행은 제외합니다.

$f(a)=\sum_{i=1}^{n}a_i$를 만족하는 길이 $n$의 양의 정수 배열 $a$의 개수를 구하세요. 답을 $998244353$으로 나눈 나머지를 출력하세요.

## 입력

```text
n
```

$1\le n\le200$입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2
```

#### 출력

```text
2
```

$a=(1,2),(2,1)$의 $2$가지입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1
```

#### 출력

```text
1
```

$a=(1)$뿐입니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
17
```

#### 출력

```text
609415864
```
