## 문제 설명

$N$칸의 주사위 놀이를 합니다. 매 턴 $1$칸 또는 $2$칸 앞으로 이동할 수 있습니다. 처음에는 $0$번 칸에 있습니다.
정확히 $N$번 칸에 도착하는 방법은 몇 가지인지 구하세요.

## 입력

```text
$N$
```

주사위 놀이의 칸 수를 나타내는 정수 $N$이 주어집니다.

## 제한

$2 \le N \le 50$

## 출력

정확히 $N$번 칸에 도착하는 방법의 수를 출력하세요. 답이 $2^{32}$에 들어가지 않을 수 있지만 $64$비트 정수형에는 들어갑니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
```

#### 출력

```text
2
```

$2$번 칸에 가는 방법은 $1\cdot1$과 $2$의 $2$가지입니다.

### 예제 2 {file=""}

#### 입력

```text
3
```

#### 출력

```text
3
```

$3$번 칸에 가는 방법은 $1\cdot1\cdot1$, $2\cdot1$, $1\cdot2$의 $3$가지입니다. $2\cdot1$과 $1\cdot2$는 서로 다른 방법입니다.

### 예제 3 {file=""}

#### 입력

```text
5
```

#### 출력

```text
8
```

$1\cdot1\cdot1\cdot1\cdot1$, $2\cdot1\cdot1\cdot1$, $1\cdot2\cdot1\cdot1$, $1\cdot1\cdot2\cdot1$, $1\cdot1\cdot1\cdot2$, $1\cdot2\cdot2$, $2\cdot1\cdot2$, $2\cdot2\cdot1$의 $8$가지입니다.

### 예제 4 {file=""}

#### 입력

```text
50
```

#### 출력

```text
20365011074
```

답이 $2^{32}$를 초과하므로 `int`에 들어가지 않습니다.
