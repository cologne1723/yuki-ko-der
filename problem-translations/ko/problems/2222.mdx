일렬로 놓인 $N$칸 중 일부에는 함정이 있다냥. $1$번 칸에서 시작해 $N$번 칸에 정확히 멈출 때까지 매번 같은 확률로 다음 중 하나를 고른다냥: 오른쪽으로 1칸 이동, 2칸 이동, 현재 위치를 저장한다냥. 이동 결과가 범위를 벗어나거나 함정 칸에 멈추면 게임 오버가 되고 저장 위치로 돌아간다냥. 전체 조작 횟수의 기댓값을 구하라냥.

## 조건

- $2\le N\le2\times10^5$
- $S$는 `.`과 `#`으로 이루어지고 양 끝은 `.`이다냥.
- `#`은 연속해서 두 개 이상 나오지 않는다냥.

## 입력

```text
N
S
```

## 출력

기댓값을 출력하라냥.
