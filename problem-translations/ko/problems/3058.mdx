## 문제 설명

다음 조건 중 $1$개를 만족하는 문자열을 **올바른 괄호열**이라고 정의합니다.

- 빈 문자열입니다.
- 어떤 **올바른 괄호열** $A$가 존재하며, `(`, $A$, `)`를 이 순서대로 연결한 문자열입니다.
- 비어 있지 않은 **올바른 괄호열** $A$, $B$가 존재하며, $A$, $B$를 이 순서대로 연결한 문자열입니다.

빈 문자열 $S$가 있습니다. 처음에 점수는 $0$점이며, 이제 다음 연산을 총 $2N$회 수행합니다.

- $i$번째 연산에서는 다음 $2$가지 중 $1$개를 선택합니다. 여기서 $C_i$는 `(` 또는 `)`입니다.
  - $S$의 맨 앞에 문자 $C_i$를 추가하고, 점수에 $L_i$를 더합니다.
  - $S$의 맨 뒤에 문자 $C_i$를 추가하고, 점수에 $R_i$를 더합니다.

$2N$회의 연산을 수행한 뒤 문자열 $S$가 **올바른 괄호열**이 되도록 연산할 때, 최종 점수의 최댓값을 구하세요.

문제의 제약 조건에 따라 $2N$회의 연산을 수행한 뒤 문자열 $S$가 **올바른 괄호열**이 되도록 하는 선택 방법이 항상 존재합니다.

## 입력

```text
$N$
$C_1\ L_1\ R_1$
$C_2\ L_2\ R_2$
$\vdots$
$C_{2N}\ L_{2N}\ R_{2N}$
```

$1$번째 줄에 정수 $N$이 주어집니다.

다음 $2N$개의 줄에 각각 문자 $C_i$와 정수 $L_i$, $R_i$가 주어집니다. 각 값은 공백으로 구분되어 있습니다.

## 제한

- $1 \le N \le 10^5$
- $L_i$와 $R_i$는 정수입니다.
- $1 \le L_i, R_i \le 10^9$
- $C_i$는 `(` 또는 `)`입니다.
- $C_1,C_2,\dots,C_{2N}$ 중 `(`와 `)`는 각각 $N$회씩 나타납니다.

## 출력

최종 점수의 최댓값을 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
( 5 1
) 10 1
( 1 7
) 100 100
```

#### 출력

```text
116
```

다음과 같이 연산하면 점수는 $116$점이 됩니다.

- $1$번째 연산에서는 맨 앞에 추가합니다. $S=$ `(`가 되고 점수는 $5$점이 됩니다.
- $2$번째 연산에서는 맨 앞에 추가합니다. $S=$ `)(`가 되고 점수는 $15$점이 됩니다.
- $3$번째 연산에서는 맨 앞에 추가합니다. $S=$ `()(`가 되고 점수는 $16$점이 됩니다.
- $4$번째 연산에서는 맨 뒤에 추가합니다. $S=$ `()()`가 되고 점수는 $116$점이 됩니다.
