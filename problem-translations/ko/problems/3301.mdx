## 문제 설명

길이가 $L$인 변을 포함하고, 모든 변의 길이가 양의 정수인 직각삼각형을 구성하세요.

## 입력

```text
$T$
$L_1$
$L_2$
$\vdots$
$L_T$
```

$T$개의 테스트 케이스가 주어집니다.

## 제한

- 입력은 모두 정수입니다.
- $1 \le T \le 10^5$
- $3 \le L_i \le 10^9$

## 출력

구성한 삼각형의 각 변의 길이가 $A$, $B$, $C$일 때, $A$, $B$, $C$를 출력하세요. $A$, $B$, $C$의 순서는 임의로 정해도 됩니다.

```text
$A_1\ B_1\ C_1$
$A_2\ B_2\ C_2$
$\vdots$
$A_T\ B_T\ C_T$
```

출력되는 변에 $10^9$를 초과하는 길이가 포함되어도 됩니다.
