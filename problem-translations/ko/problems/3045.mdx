## 이야기

nauclhltくん은 평범한 누적합으로는 만족할 수 없게 되었습니다. 또한 누적합을 구하는 횟수도 보통 수준으로는 만족할 수 없습니다.

예를 들어, 누적합을 $10^9$번 구해 보는 것처럼 말입니다……

## 문제 설명

수열 $P$의 **가중치 $K$인 누적합**을 다음 조건을 만족하는 길이 $|P|$인 수열 $Q$로 정의합니다.

$\displaystyle Q_i=\sum_{j=1}^i K^{i-j}P_j\ (1\leq i\leq |P|)$

여기서 $|P|$는 수열 $P$의 길이입니다.

길이 $N$인 수열 $A=(A_1, A_2, \cdots, A_N)$이 주어집니다.

다음 형식으로 주어지는 $Q$개의 질의를 순서대로 처리하세요.

- $1\ k\ x$: $A$를 $A$의 **가중치 $k$인 누적합**으로 바꾸는 작업을 $x$번 반복합니다.
- $2\ x$: $A_x$의 값을 $998\,244\,353$으로 나눈 나머지를 출력합니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ Q$
$A_1\ A_2\ \cdots\ A_N$
$query_1$
$query_2$
$\vdots$
$query_Q$
```

각 질의는 다음 형식 중 $1$개로 주어집니다.

```text
$1\ k\ x$
```

```text
$2\ x$
```

## 제한

- $1\leq N\leq 2\,000$
- $0\leq A_i<998\,244\,353$
- $1\leq Q\leq 2\,000$
- $1\ k\ x$ 형식의 질의에 대해 $1\leq k<998\,244\,353$, $1\leq x\leq 10^9$
- $2\ x$ 형식의 질의에 대해 $1\leq x\leq N$
- $2\ x$ 형식의 질의는 적어도 $1$개 주어집니다.
- 입력은 모두 정수입니다.

## 출력

$2\ x$ 형식의 질의 개수를 $m$이라고 할 때, $m$줄을 출력하세요.

$i\ (1\leq i\leq m)$번째 줄에는 $2\ x$ 형식의 질의 중 $i$번째 질의에 대한 답을 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 3
3 1 4 1
2 3
1 2 1
2 3
```

#### 출력

```text
4
18
```

- $1$번째 질의에서는 $A_3=4$이므로 $4$를 출력합니다.
- $2$번째 질의에서 $A$의 **가중치 $2$인 누적합**은 $(3, 7, 18, 37)$입니다. 따라서 $A$를 이 수열로 바꿉니다.
- $3$번째 질의에서는 $A_3=18$이므로 $18$을 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
3 2
1 1 2
1 3 2
2 2
```

#### 출력

```text
7
```

$A$의 **가중치 $3$인 누적합**은 $(1, 4, 14)$입니다. 또한 이 수열의 **가중치 $3$인 누적합**을 구하면 $(1, 7, 35)$가 됩니다. 따라서 $1$번째 질의 후에는 $A=(1, 7, 35)$입니다.

$2$번째 질의에서는 위 결과에 따라 $A_2=7$이므로 $7$을 출력합니다.

#### 출력

3
