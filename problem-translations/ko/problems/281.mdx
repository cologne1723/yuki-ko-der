## 문제

kamipeipaa 군의 집 마당에는 일렬로 놓인 대나무 3개가 있습니다.

kamipeipaa 군은 다음 조건을 만족시키려고 합니다.

- 대나무 3개의 높이가 서로 모두 다릅니다.
- 가운데 대나무의 높이가 가장 높거나 가장 낮습니다.

대나무 하나를 선택해 “그 대나무의 높이가 $h$라면 $\max(0,h-d)$로 만든다”라는 마법을 반복해서 사용하여 조건을 만족시키려고 합니다.

조건을 만족시키기 위해 마법을 사용해야 할 때, 최소 몇 번 사용해야 하는지 구하세요.

높이가 0인 대나무도 대나무로 간주합니다. 대나무의 순서는 바꾸지 않고 입력 순서를 유지합니다.

## 입력

```text
d
H_1
H_2
H_3
```

첫째 줄에 마법으로 높이를 변화시키는 양 $d$가 주어집니다. 이어지는 3개 줄에 $i$번째 대나무의 높이 $H_i$가 각각 주어집니다.

- $0 \le d \le 10^9$
- $0 \le H_i \le 10^9$

## 출력

조건을 만족시킬 수 있도록 마법을 사용해야 하는 최소 횟수를 출력하세요. 불가능하면 `-1`을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
1
3
3
4
```

### 샘플 1 {file="sample1.out"}

```text
1
```

가운데 대나무에 마법을 한 번 사용하면 조건을 만족시킬 수 있습니다.

### 샘플 2 {file="sample2.in"}

```text
411
4
1
5
```

### 샘플 2 {file="sample2.out"}

```text
0
```

마법을 사용할 필요가 없는 경우도 있습니다.

### 샘플 3 {file="sample3.in"}

```text
2
3
10
12
```

### 샘플 3 {file="sample3.out"}

```text
2
```

### 샘플 4 {file="sample4.in"}

```text
1
0
0
0
```

### 샘플 4 {file="sample4.out"}

```text
-1
```

마법을 사용해도 어쩔 수 없는 경우가 있습니다.
