## 문제

문자열 $S$의 부분 문자열 중 문자열 treeone과 일치하는 것을 모두 forest로 치환하여 얻는 문자열 $T$를 출력하세요.

## 입력

~~~text
$S$
~~~

소문자 알파벳만으로 이루어진 문자열 $S$가 주어집니다.

$1\leq |S|\leq100$입니다.

## 출력

문자열 $T$를 1줄에 출력하세요. 마지막에는 줄바꿈을 추가하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
treeone
~~~

#### 출력

~~~text
forest
~~~

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
treeoneone
~~~

#### 출력

~~~text
forestone
~~~

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
beet
~~~

#### 출력

~~~text
beet
~~~
