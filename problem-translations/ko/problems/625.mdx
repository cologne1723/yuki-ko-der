## 문제

산타클로스 $N$명이 $M$개의 선물 배정을 정하려 합니다.

### 선물 배정 방법

1. 현역 산타클로스 중 수염이 가장 긴 산타클로스가 선물 배정을 제안합니다.
2. 본인을 포함한 현역 산타클로스가 각자 찬성 또는 반대 투표를 합니다.
   - 과반수가 찬성하면 그 배정으로 선물을 나눠 주러 갑니다.
   - 과반수의 찬성을 얻지 못하면 배정을 제안한 산타클로스가 즉시 은퇴합니다.
3. 배정이 결정될 때까지 1, 2를 반복합니다.

### 산타클로스의 특징

산타클로스는 다음 우선순위로 의사 결정합니다.

1. 가능한 한 많은 선물을 나눠 주고 싶어 합니다.
2. 자신에게 배정되는 선물이 0개라도 은퇴하는 것보다 선호합니다.
3. 자신에게 배정되는 선물 수가 같다면 현역 산타클로스 수가 적은 쪽을 선호합니다.
4. 수염이 짧은 산타클로스에게 더 많은 선물이 배정되는 쪽을 선호합니다.

산타클로스는 수염이 긴 순서대로 1번부터 $N$번까지 번호가 매겨져 있으며, 1번의 수염이 가장 깁니다.

$N,M$이 주어질 때 각 산타클로스에게 배정되는 선물 수를 출력하세요. 은퇴한 산타클로스에게 배정되는 선물 수는 -1로 표시합니다.

## 입력

```text
N M
```

산타클로스 수 $N$과 선물 수 $M$이 공백으로 주어집니다.

- $1\le N\le1000$
- $1\le M\le20000$

## 출력

각 산타클로스에게 배정되는 선물 수를 한 줄에 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text

```

출력:

```text
5 0 0
```

### 샘플 2 {file="sample2.in"}

```text

```

출력:

```text
100
```

### 샘플 3 {file="sample3.in"}

입력:

```text
8 3
```

출력:

```text
-1 0 1 0 0 1 0 1
```
