## 문제 설명

차완무시 군은 원소 수가 $N$인 정수 수열 $A$를 가지고 있습니다. $A$의 $i$($1 \le i \le N$)번째 원소는 $A_i$입니다.

$N-1$번, 차완무시 군은 다음 연산을 수행합니다(예제 1을 참고하세요).

- $i$번째 연산에서는 $A$를 $(A_1+A_2,A_2+A_3,\dots,A_{N-i}+A_{N-i+1})$로 바꿉니다.

연산을 수행한 후의 $A_1$을 $10^9+7$로 나눈 나머지를 구하세요.

## 제한

입력은 모두 정수입니다.

$2 \le N \le 100$

$0 \le A_i \le 1\,000\,000\,000$

## 입력

```text
$N$
$A_1\ A_2\ \dots\ A_N$
```

첫 번째 줄에 $N$이 주어집니다.

두 번째 줄에 연산을 수행하기 전의 $A$가 공백으로 구분되어 주어집니다.

## 출력

연산을 수행한 후의 $A_1$을 $10^9+7$로 나눈 나머지를 한 줄에 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
3 10 100 1000
```

#### 출력

```text
1333
```

$A$는 다음과 같이 변합니다.

$(3,10,100,1000)\mathbin{\to}(13,110,1100)\mathbin{\to}(123,1210)\mathbin{\to}(1333)$

### 예제 2 {file=""}

#### 입력

```text
3
0 0 0
```

#### 출력

```text
0
```

### 예제 3 {file=""}

#### 입력

```text
5
1000000000 1000000000 1000000000 1000000000 1000000000
```

#### 출력

```text
999999895
```

$10^9+7$로 나눈 나머지를 구하세요.
