## 문제

세로 H칸, 가로 W칸의 격자가 있습니다.

독립적으로 균일한 확률로 다음 과정을 두 번 수행합니다.

- 세로 A칸, 가로 B칸인 직사각형을 하나 골라 검은색으로 칠합니다.

직사각형의 왼쪽 위 칸은 가능한 모든 위치 중에서 균일하게 선택합니다. 두 직사각형을 칠한 뒤 검은색이 된 칸의 수의 기댓값을 구하세요.

답은 분수로 나타낼 수 있습니다. 답을 `998244353`로 나눈 나머지를 출력하세요. 즉, 답이 서로소인 정수 `p/q`로 표현될 때 `p × q^-1 mod 998244353`을 출력하세요.

## 제약

- `1 ≤ A ≤ H ≤ 2 × 10^5`
- `1 ≤ B ≤ W ≤ 2 × 10^5`

## 입력

입력은 다음 형식으로 주어집니다.

```text
H W A B
```

## 출력

답을 한 줄에 출력하세요.

## 예제

### 입력

```text
2 3 1 2
```

### 출력

```text
748683268
```

두 직사각형의 위치가 독립적으로 선택되며, 답은 `13/4`입니다.
