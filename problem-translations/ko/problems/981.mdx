## 문제 설명

$p$를 소수라고 합니다. $x^k \equiv a \pmod p$의 해를 하나 구하세요. 해가 존재하지 않으면 $-1$을 출력하세요.

## 입력

```text
$T$
$p_1 \; k_1 \; a_1$
$p_2 \; k_2 \; a_2$
$\vdots$
$p_T \; k_T \; a_T$
```

$T$개의 테스트 케이스가 주어집니다.

$i$번째 테스트 케이스에 대해 $x^{k_i} \equiv a_i \pmod {p_i}$의 해를 하나 출력하세요. 해가 존재하지 않으면 $-1$을 출력하세요.

각 $p_i$는 소수입니다.

## 제한

- $1 \le T \le 1\,000$
- $1 \le k_i \le 1\,000$ ($1 \le i \le T$)
- $2 \le p_i \le 10^9 + 7$ ($1 \le i \le T$)
- $1 \le a_i < p_i$ ($1 \le i \le T$)

문제 공개 후 알고리즘 고속화에 성공했으므로 다음 테스트 케이스가 추가되었습니다(2020/02/10).

- $1 \le T \le 1\,000$
- $1 \le k_i \le 10^9$ ($1 \le i \le T$)
- $2 \le p_i \le 10^{18}$ ($1 \le i \le T$)
- $1 \le a_i < p_i$ ($1 \le i \le T$)

이는 `evil` 케이스로 추가된 것이므로 상태에는 영향을 주지 않습니다.

또한 다음 케이스가 `evil_hard`로 추가되었습니다(2020/02/13).

- $1 \le T \le 1\,000$
- $1 \le k_i < p_i$ ($1 \le i \le T$)
- $2 \le p_i \le 10^{18}$ ($1 \le i \le T$)
- $1 \le a_i < p_i$ ($1 \le i \le T$)

## 출력

$x^{k_i} \equiv a_i \pmod {p_i}$의 해를 각 줄에 출력하세요. 해가 존재하지 않으면 $-1$을 출력하세요. 마지막에 줄바꿈하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
13 2 4
```

#### 출력

```text
11
```

$11^2 \equiv 4 \pmod {13}$입니다. $2^2 \equiv 4 \pmod {13}$이므로 $2$를 출력해도 됩니다.

### 예제 2 {file=""}

#### 입력

```text
1
3 2 2
```

#### 출력

```text
-1
```

$x^2 \equiv 2 \pmod 3$을 만족하는 $x$는 존재하지 않습니다.
