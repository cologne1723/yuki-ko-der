## 문제 설명

소수 $p_1,\ldots,p_N$이 주어집니다. 각 $i$에 대해 $2^x\equiv x\pmod {p_i}$를 만족하는 $10^{18}$ 이하의 양의 정수 $x$를 하나 찾으세요.

## 입력

```text
N
p_1
\vdots
p_N
```

- $1\leq N\leq1000$
- $2\leq p_i\leq10^9$
- $p_i$는 소수입니다.

## 출력

$i$번째 줄에 조건을 만족하는 $x$를 출력하세요. 존재하지 않으면 $-1$을 출력하세요. 해가 여러 개면 아무 것이나 출력해도 됩니다.

## 예제

### 예제 1 {file="01_sample_01.txt"}
#### 입력
```text
3
5
3
2
```
#### 출력
```text
3
4
2
```
