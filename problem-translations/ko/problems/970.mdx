## 문제 설명

수열 변환 머신의 투입구에 $n$개 원소를 가진 수열 $a$를 넣으면, 배출구에서 $n$개 원소를 가진 수열 $b$가 나옵니다.

여기서 $b$의 $i$번째 원소 $b_i$의 값은 $a$에서 $i$번째 원소 $a_i$를 제거한 $n-1$개 원소의 산술 평균과 같습니다. $1 \le i \le n$입니다.

예를 들어 수열 $a=\{3,5,7\}$을 넣으면, 배출되는 수열 $b$의 각 값은 다음과 같습니다.

$b_1=\frac{5+7}{2}=6$, $b_2=\frac{3+7}{2}=5$, $b_3=\frac{3+5}{2}=4$

어느 날 당신은 수열 변환 머신의 배출구에 $N$개 원소를 가진 정수열 $y_1,\ldots,y_N$이 있는 것을 발견했습니다.

아무래도 과거의 당신이 어떤 정수열 $x_1,\ldots,x_N$을 넣고 그대로 잊어버린 것 같습니다.

당신은 어떤 정수열을 넣은 결과 $y$가 나왔는지 궁금해졌고, 이를 구하기로 했습니다.

## 입력

```text
$N$
$y_1\ y_2\ \ldots\ y_N$
```

## 제한

- $2 \le N \le 100\,000$
- $-1\,000 \le y_i \le 1\,000$ ($1 \le i \le N$)
- 입력은 모두 정수입니다.

## 출력

구해야 하는 정수열 $x$의 각 값을 공백으로 구분하여 한 줄에 출력하세요.

제한을 만족하는 모든 입력에 대해 답이 유일하게 존재함이 보장됩니다.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text

```

#### 출력

```text
3 5 7
```

문제 설명 첫 부분에서 예로 등장한 수열 $a$, $b$에 대응합니다.

### 예제 2 {file=""}


#### 출력

```text

```

### 예제 3 {file=""}

#### 입력

```text

```

#### 출력

