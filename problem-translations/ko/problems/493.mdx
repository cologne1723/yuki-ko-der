## 문제

다음과 같은 수열을 생각합니다.

```text
f(1)={1}
f(2)={1,4,1}
f(3)={1,4,1,9,1,4,1}
f(n)=f(n-1) + n^2 + f(n-1)
```

이러한 수열을 이어 붙여 문자열로 만드는 것을 생각합니다.

예를 들어 $f(3)$은 `1419141`이고, 수열이 ${9,11,10}$이면 `91110`입니다.

이때 $K,L,R$이 주어집니다.

$f(K)$를 문자열로 만들었을 때 $L$번째 문자부터 $R$번째 문자까지의 숫자 합과 곱을 구하세요.

곱에 대해서만 $1000000007(10^9+7)$로 나눈 나머지를 구하세요.

단, 0이 포함되면 보통 곱이 0이 되어 흥미롭지 않으므로, 합과 곱을 계산할 때만 `0`을 `10`으로 취급합니다.

$R$이 $f(K)$를 문자열로 만들었을 때의 문자 수를 초과하면 `-1`을 출력하세요.

예를 들어 $f(K)$가 `91110`이고 $L=2,R=5$이면 합은 $1+1+1+10=13$, 곱은 $1*1*1*10=10$입니다.

$f(K)$가 `1419141`이고 $L=1,R=7$이면 합은 $1+4+1+9+1+4+1=21$, 곱은 $1*4*1*9*1*4*1=144$입니다.

$f(K)$가 `7777777`이고 $L=4,R=5$이면 합은 $7+7=14$, 곱은 $7*7=49$입니다.

앞의 예에서 해당 부분 문자열은 각각 `1110`, `1419141`, `77`입니다.

참고로 $f(1)$부터 $f(5)$를 문자열로 만들면 다음과 같습니다.

```text
f(1) → "1"
f(2) → "141"
f(3) → "1419141"
f(4) → "1419141161419141"
f(5) → "1419141161419141251419141161419141"
```

## 입력

```text
$K\ L\ R$
```

$1\leq K\leq10^9$

$1\leq L\leq R\leq10^{18}$

## 출력

$f(K)$를 문자열로 만들었을 때 $L$번째부터 $R$번째까지의 숫자 합과 곱을 $1000000007$로 나눈 나머지를 공백으로 구분하여 한 줄에 출력하세요.

$L,R$은 1부터 세는 인덱스입니다.

문자 수를 초과하는 $R$이 주어지면 `-1`을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3 1 7
```

출력:

```text
21 144
```

문제에서 설명한 예입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
5 12 19
```

출력:

```text
24 360
```

12번째부터 19번째까지의 문자열은 `19141251`이므로 합은 24, 곱은 360입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
10 510 515
```

출력:

```text
17 96
```

### 샘플 4 {file="sample4.in"}

입력:

```text
10 1 2016
```

출력:

```text
-1
```

$f(10)$의 수열로 만든 문자열 길이는 1151이므로 2016번째 문자는 없습니다.
