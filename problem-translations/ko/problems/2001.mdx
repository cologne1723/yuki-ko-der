$L$ 이상 $R$ 이하의 양의 정수인 순서 있는 세쌍 $(x,y,z)$ 중 다음 조건을 모두 만족하는 개수를 $998244353$으로 나눈 나머지를 구하세요.

$$x+A\le y,\qquad y+B\le z,\qquad x+C\le z.$$

## 입력

```text
L R
A B C
```

$1\le L\le R\le10^{18}$, $0\le A,B,C\le10^{18}$입니다.

## 출력

조건을 만족하는 세쌍의 개수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1 4
1 1 1
```

#### 출력

```text
4
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 7
0 1 2
```

#### 출력

```text
16
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1 1000000000000000000
314 159 265
```

#### 출력

```text
547930521
```
