## 문제

간선에 영소문자 라벨이 붙은 연결 무방향 그래프에서 정점 1에서 정점 $N$으로 가는 경로를 하나 출력하세요. 경로의 라벨 문자열은 회문이 아니어야 하며, 같은 정점과 간선을 여러 번 지나도 됩니다. 간선 통과 횟수는 $2N$ 이하이어야 합니다.

## 입력

$N,M$과 간선 $(A_i,B_i,C_i)$가 주어집니다.

## 출력

조건을 만족하는 경로를 문제의 형식으로 출력하세요.
