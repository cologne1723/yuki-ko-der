$N$개 정점의 트리에서 0개 이상의 간선을 제거해 그래프 $G$를 만든다냥. $G$의 연결 요소 크기를 $V_1,\ldots,V_k$라 할 때 점수를 $\prod_iV_i$로 정의한다냥. 가능한 모든 $G$의 점수 합을 구하라냥.

## 조건

- $2\le N\le2\times10^5$

## 입력

```text
N
A_1 B_1
\vdots
A_{N-1} B_{N-1}
```

## 출력

점수 합을 $998244353$으로 나눈 나머지를 출력하라냥.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
1 2
1 3
```

#### 출력

```text
8
```

#### 입력

```text

2 3
3 4
1 6
```

#### 출력

```text
135
```
