## 문제

정수 `N`이 주어집니다. `1,...,3N`의 순열 `P` 중

`Σ P_i P_{N+i} = Σ P_{N+i} P_{2N+i}`

를 만족하는 것을 좋은 순열이라 합니다. 좋은 순열이 존재하는지 판정하고, 존재하면 하나 구성하세요.

## 제약

- `1 ≤ N ≤ 2×10^5`

## 입력

```text
N
```

## 출력

좋은 순열을 하나 출력하세요. 존재하지 않으면 `-1`을 출력하세요.
