## 문제

4진수 N(4)이 주어집니다.

N(4)이 3(10)으로 나누어떨어지면 Fizz, 5(10)으로 나누어떨어지면 Buzz, 둘 다로 나누어떨어지면 FizzBuzz를 출력하세요. 어느 쪽으로도 나누어떨어지지 않으면 N(4) 자체를 출력하세요.

m진법으로 표기한 수 N을 N(m)으로 나타냅니다.

## 입력

```text
N(4)
```

N(4)는 양의 정수이고 자릿수 |N(4)|는 1 ≤ |N(4)| ≤ 2 × 10^6입니다.

## 출력

답을 한 줄에 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3
```

출력:

```text
Fizz
```

### 샘플 2 {file="sample2.in"}

입력:

```text
11
```

출력:

```text
Buzz
```

11(4) = 5(10)입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
33
```

출력:

```text
FizzBuzz
```

33(4) = 15(10)입니다.

### 샘플 4 {file="sample4.in"}

입력:

```text
1333
```

출력:

```text
1333
```
