## 문제

직선 $l$ 위에 점이 $N$개 있습니다. 점들의 위치는 정수 $a_1,a_2,\dots,a_N$입니다.

임의의 두 점 사이 거리의 최솟값과 최댓값을 구하세요.

그림의 $a_n$은 $a_N$의 오타입니다. (2022/08/09 추가)

## 입력

~~~text
$N$
$a_1$ $a_2$ $a_3$ $\dots$ $a_N$
~~~

입력은 2줄입니다. 첫째 줄에 점의 수 $N$, 둘째 줄에 점의 위치가 주어집니다.

- $2\leq N\leq1000$
- $a_i\leq a_{i+1}\ (1\leq i\leq N-1)$
- $-10^5\leq a_i\leq10^5\ (1\leq i\leq N)$

## 출력

첫째 줄에 거리의 최솟값, 둘째 줄에 거리의 최댓값을 출력하세요. 마지막에는 줄바꿈을 추가하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
4
-1 0 2 3
~~~

#### 출력

~~~text
1
4
~~~

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
3
-1 1 1
~~~

#### 출력

~~~text
0
2
~~~

같은 위치에 여러 점이 있을 수도 있으며, 이 경우 거리는 0입니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
2
-100000 100000
~~~

#### 출력

~~~text
200000
200000
~~~
