번호가 1부터 $N$까지인 공이 있고 각 공은 빨강 또는 파랑입니다. $i$개를 골라 번호순으로 놓았을 때 인접한 공의 색이 모두 다르도록 고르는 방법의 수를 각 $i=1,\ldots,N$에 대해 $998244353$으로 구하세요.

## 입력

```text
N
S
```

## 출력

$i$번째 답을 $i$번째 줄에 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
RRBR
```

#### 출력

```text
4
3
2
0
```
