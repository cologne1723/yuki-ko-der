현재까지 최소 $N$회의 출입 기록이 있습니다. ID가 $X_i$인 부원이 시각 $L_i-0.1$부터 $R_i+0.1$까지 방에 있었다는 정보가 주어집니다. 다음 쿼리를 순서대로 처리하세요.

`1 x t`는 ID $x$가 시각 $t$에 방에 있었다는 것이 알려졌으면 `Yes`, 아니면 `No`를 출력합니다. `2 t`는 시각 $t$에 방에 있었다고 알려진 부원 수를 출력합니다. `3 x l r`은 ID $x$가 $l-0.1$부터 $r+0.1$까지 있었다는 기록을 추가합니다.

## 조건

- $1\le N,Q\le10^5$
- ID는 길이 5 이하의 소문자 문자열입니다.
- 모든 시각과 구간 끝점은 1 이상 $10^9$ 이하입니다.
- 같은 ID의 기록 구간은 서로 겹치지 않습니다.

## 입력

```text
N
X1 L1 R1
...
XN LN RN
Q
query1
...
queryQ
```

## 출력

쿼리 1과 2에 대한 답을 입력 순서대로 출력하세요.
