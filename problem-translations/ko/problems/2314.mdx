0과 1로 이루어진 문자열 $S$가 주어집니다. 마지막 문자가 0이면 1로, 1이면 0으로 바꾼 문자열을 출력하세요.

## 조건

- $1\le \lvert S\rvert\le8$
- $S$는 0과 1로 이루어집니다.

## 입력

문자열 $S$가 주어집니다.

## 출력

마지막 문자를 바꾼 문자열을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
100
```

#### 출력

```text
101
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1
```

#### 출력

```text
0
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
01001011
```

#### 출력

```text
01001010
```
