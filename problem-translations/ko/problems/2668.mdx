좋은 점은 양의 정수 좌표이고 $x+y$가 $2n$ 이하의 짝수인 점입니다. 두 좋은 점의 맨해튼 거리가 2일 때 간선을 잇는 그래프에서, 각 정점까지의 거리가 좌표 합에 맞고 간선들이 서로 교차하지 않는 좋은 신장 트리들의 잎 정점 $x$좌표 곱의 합을 $m$으로 나눈 나머지를 구하세요.

## 조건

- $2\le n\le5\times10^6$, $1\le m\le10^9$

## 입력

```text
$n$ $m$
```

## 출력

답을 출력하세요.
