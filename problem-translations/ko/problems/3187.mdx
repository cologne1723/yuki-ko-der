## 문제 설명

$3$ 이상의 정수 $N$과 소수 $P$가 주어집니다. 또한 $a=N$으로 초기화된 변수가 있습니다.

$a$가 $2$ 이하가 될 때까지 다음 연산을 반복해서 수행합니다.

- $1$ 이상 $a$ 이하의 정수 $b$를 균등하게 무작위로 선택합니다. $a$를 $b$로 나눈 나머지를 $c$라고 하고, $a$를 $a-c$로 바꿉니다. 여기서 $b$는 연산마다 독립적으로 선택됩니다.

연산 횟수의 기댓값을 법 $P$에서의 값으로 구하세요.

입력으로 주어지는 $N$, $P$에 대해서는 법 $P$에서 답을 정의할 수 있는 경우만 주어집니다.

정확히는 입력으로 주어지는 $N$에 대해 연산 횟수의 기댓값은 항상 유리수이며, 서로소인 음이 아닌 정수 $x$, $y$를 사용하여 $\frac{x}{y}$로 나타낼 수 있음이 보장됩니다. 또한 입력으로 주어지는 $P$에 대해 $y \not\equiv 0 \pmod P$임이 보장됩니다. 이때 $yz \equiv x \pmod P$, $0 \leq z < P$를 만족하는 음이 아닌 정수 $z$가 유일하게 정해지므로, 이 $z$를 출력하세요.

## 입력

```text
$N\ P$
```

입력은 다음 제한을 만족합니다.

## 제한

- $3 \leq N \leq 3 \times 10^5$
- $9 \times 10^8 \leq P \leq 10^9$
- $P$는 소수입니다.
- 입력은 모두 정수입니다.
- 법 $P$에서 답이 정의됩니다.

## 출력

연산 횟수의 기댓값을 법 $P$에서의 값으로 출력하고, 개행하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 998244353
```

#### 출력

```text
332748125
```

예를 들어 다음과 같은 연산 결과가 나올 수 있습니다.

- $1$번째 연산에서 $b=3$을 선택합니다. $c=2$이므로 $a$를 $5-2=3$으로 바꿉니다.
- $2$번째 연산에서 $b=2$를 선택합니다. $c=1$이므로 $a$를 $3-1=2$로 바꿉니다.

이때 연산 횟수는 $2$회이며, 이 결과가 나올 확률은 $\frac{1}{15}$입니다.

연산 횟수의 기댓값은 $\frac{22}{3}$임을 증명할 수 있습니다.
