## 문제 설명

$H\times W$ 토러스 격자의 각 칸에 음이 아닌 정수를 적습니다. 다음 조건을 모두 만족하면서 적힌 정수의 최댓값을 최소화하는 방법을 구하세요.

- 각 칸에 적힌 정수는 모두 다릅니다.
- 인접한 임의의 두 칸에 적힌 정수를 $x,y$라고 할 때, $x\oplus y=2^k$를 만족하는 음이 아닌 정수 $k$가 존재합니다. $x\oplus y$는 $x$와 $y$의 비트 단위 배타적 논리합입니다.

위에서 $i+1$번째 행, 왼쪽에서 $j+1$번째 열의 칸을 $(i,j)$라고 할 때, 인접한 칸은 $((i-1)\bmod H,j)$, $((i+1)\bmod H,j)$, $(i,(j-1)\bmod W)$, $(i,(j+1)\bmod W)$의 최대 네 칸입니다.

답이 여러 개이면 아무거나 출력해도 됩니다. 조건을 만족하는 방법이 없으면 $-1$을 출력하세요.

## 입력

표준 입력으로 다음 형식의 입력이 주어집니다.

```text
$H\ W$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $2\leq H,W$
- $HW\leq 5\times 10^5$

## 출력

조건을 만족하는 방법이 있으면 적힌 정수의 최댓값이 최소인 방법을 다음 형식으로 하나 출력하세요. $A_{i,j}$는 위에서 $i+1$번째 행, 왼쪽에서 $j+1$번째 열의 칸에 적는 정수입니다. 조건을 만족하는 방법이 없으면 $-1$을 출력하세요.

```text
$A_{0, 0}\ A_{0, 1}\ \ldots\ A_{0, W-1}$
$A_{1, 0}\ A_{1, 1}\ \ldots\ A_{1, W-1}$
$\vdots$
$A_{H-1, 0}\ A_{H-1, 1}\ \ldots\ A_{H-1, W-1}$
```

마지막에 줄바꿈을 출력하세요.
