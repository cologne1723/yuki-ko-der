## 문제 설명

서로 다른 소수 $4$개의 곱으로 나타낼 수 있는 양의 정수를 1122형 수라고 합니다.

예를 들어 $1\,122=2\times 3\times 11\times 17$과 $210=2\times 3\times 5\times 7$은 1122형 수이고, $12=2^2\times 3$과 $81=3^4$는 1122형 수가 아닙니다.

정수 $N$이 주어질 때, $N$ 이하인 1122형 수의 개수를 구하세요.

### 점수

예상 해답의 코드 길이는 $112$바이트입니다.

제출한 소스 코드의 코드 길이가 $x$이고 이 문제의 예상 해답 코드 길이가 $y$일 때, 해당 소스 코드의 점수는 다음과 같이 계산됩니다.

- $y\leq x$일 때: $\lfloor100\exp(-0.012(x-y))\rfloor$점
- $x<y$일 때: $101$점

이 문제의 점수는 이 문제에 제출된 소스 코드 점수의 최댓값입니다.

## 입력

```text
$N$
```

## 제한

- $1\leq N\leq 3.5\times 10^6$
- 입력은 모두 정수입니다.

## 출력

답을 출력하고, 마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
500
```

#### 출력

```text
4
```

$500$ 이하인 1122형 수는 $210$, $330$, $390$, $462$의 $4$개입니다.

### 예제 2 {file=""}

#### 입력

```text
1122
```

#### 출력

```text
18
```

### 예제 3 {file=""}

#### 입력

```text
3000000
```

#### 출력

```text
305541
```
