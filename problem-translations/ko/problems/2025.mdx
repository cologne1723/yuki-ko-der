오름차순으로 정렬된 수열 $S$에는 $1$ 이상 $N$ 이하의 정수 $v$가 정확히 $c_v$개씩 있습니다. $S$의 길이 $L$인 부분 수열들을 열로 보았을 때, 사전순 $k_i$번째로 작은 부분 수열에 포함된 각 숫자의 개수를 질의마다 출력하세요. 같은 열이면 선택한 인덱스가 달라도 하나로 셉니다.

## 입력

```text
N L
c_1 c_2 ... c_N
Q
k_1
...
k_Q
```

$1\le N\le4$, $1\le L,Q\le100000$, $1\le k_i\le10^{18}$입니다.

## 출력

각 답에 대해 $1,2,\ldots,N$의 개수를 출력하세요. 존재하지 않으면 `-1`을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 3
2 2 2
4
1
2
3
6
```

#### 출력

```text
2 1 0
2 0 1
1 2 0
0 2 1
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text

1 2 3
3
6
1000
2
```

#### 출력

```text
-1
-1
1 1 2
```
