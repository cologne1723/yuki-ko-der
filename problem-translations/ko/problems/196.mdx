## 문제 설명

정점이 $N$개인 루트가 있는 트리와 정수 $K$가 주어집니다. 이 트리의 각 정점을 흰색 또는 검은색으로 칠합니다.

다음 $2$가지 조건을 모두 만족하는 칠하기 방법의 수를 $1\,000\,000\,007$로 나눈 나머지를 구하세요.

1. 검은색으로 칠한 정점이 정확히 $K$개입니다.
2. 검은색으로 칠한 임의의 정점 $v$에 대해 $v$의 모든 자식도 검은색입니다.

(용어는 [트리 (수학) - Wikipedia](http://ja.wikipedia.org/wiki/%E6%9C%A8_%28%E6%95%B0%E5%AD%A6%29)를 참고하세요.)

## 입력

```text
$N\ K$
$a_0\ b_0$
$\vdots$
$a_{N-2}\ b_{N-2}$
```

- 정점에는 $0$부터 $N-1$까지 번호가 붙고 정점 $0$이 루트입니다.
- $0 \le i \le N-2$에 대해 $0 \le a_i < b_i \le N-1$이며 $2$개의 정점 $a_i,b_i$는 $1$개의 간선으로 직접 연결됩니다.
- 입력 그래프는 트리입니다.

## 제한

- $2 \le N \le 2\,000$, $0 \le K \le N$

## 출력

조건을 만족하는 칠하기 방법의 수를 $1\,000\,000\,007$로 나눈 나머지를 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
6 1
0 1
0 2
1 3
2 4
2 5
```

#### 출력

```text
3
```

정점 $3, 4, 5$ 중 $1$개만 검은색으로 칠하고 나머지 정점은 전부 흰색으로 칠하면 됩니다. 자식이 없는 정점에서는 모든 자식이 검은색이라는 조건이 항상 성립합니다.

### 예제 2 {file=""}

#### 입력

```text
6 2
0 1
0 2
1 3
2 4
2 5
```

#### 출력

```text
4
```

검은색 정점 집합이 $\{1, 3\}, \{3, 4\}, \{3, 5\}, \{4, 5\}$ 중 $1$개이면 조건을 만족합니다.

### 예제 3 {file=""}

#### 입력

```text
6 3
0 1
0 2
1 3
2 4
2 5
```

#### 출력

```text
4
```

검은색 정점 집합이 $\{1, 3, 4\}, \{1, 3, 5\}, \{2, 4, 5\}, \{3, 4, 5\}$ 중 $1$개입니다.
