## 문제 설명

정점이 $N$개인 rooted tree와 정수 $K$가 주어집니다. 이 트리의 각 정점을 흰색 또는 검은색으로 칠합니다.

다음 두 조건을 모두 만족하는 칠하기 방법의 수를 $1{,}000{,}000{,}007$로 나눈 나머지를 구하세요.

1. 검은색으로 칠한 정점이 정확히 $K$개입니다.
2. 검은색으로 칠한 임의의 정점 $v$에 대해 $v$의 모든 자식도 검은색입니다.

## 입력

```text
N K
a_0 b_0
:
a_{N-2} b_{N-2}
```

- $2 \le N \le 2000$, $0 \le K \le N$
- 정점에는 0부터 $N-1$까지 번호가 붙고 정점 0이 루트입니다.
- $0 \le i \le N-2$에 대해 $0 \le a_i < b_i \le N-1$이며 두 정점은 하나의 간선으로 직접 연결됩니다.
- 입력 그래프는 트리입니다.

## 출력

조건을 만족하는 칠하기 방법의 수를 $1{,}000{,}000{,}007$로 나눈 나머지를 출력하세요.

## 예제

### 예제 1

```text
6 1
0 1
0 2
1 3
2 4
2 5
```

```text
3
```

정점 3, 4, 5 중 하나만 검은색으로 칠하면 됩니다. 자식이 없는 정점에서는 모든 자식이 검은색이라는 조건이 항상 성립합니다.

### 예제 2

```text
6 2
0 1
0 2
1 3
2 4
2 5
```

```text
4
```

검은색 정점 집합이 `{1, 3}`, `{3, 4}`, `{3, 5}`, `{4, 5}` 중 하나이면 조건을 만족합니다.

### 예제 3

```text
6 3
0 1
0 2
1 3
2 4
2 5
```

```text
4
```

검은색 정점 집합이 `{1, 3, 4}`, `{1, 3, 5}`, `{2, 4, 5}`, `{3, 4, 5}` 중 하나입니다.
