## 문제 설명

길에 알록달록한 막대가 떨어져 있는 것을 발견했습니다. 좌우 방향으로 놓인 이 막대는 충분히 가늘고 $N$개의 부분으로 나뉘어 있으며, 왼쪽에서 $i$번째 부분은 색 $A_i$로 칠해져 있습니다.

이대로도 알록달록하지만, 더 아름답게 만들기 위해 “같은 색은 나타난다면 모두 하나의 구간에 연속해서 나타난다”는 조건을 만족시키려고 합니다.

이를 위해 다음 연산을 $0$회 이상 수행합니다.

- 막대를 한 곳에서 자릅니다. 만들어진 두 막대의 위치를 서로 바꾸고 이어 붙입니다. (각 막대를 뒤집지는 않습니다.)

조건을 만족시킬 수 있는지, 만족시킬 수 있다면 최소 몇 번의 연산으로 조건을 만족시킬 수 있는지 구하세요.

## 입력

```text
$N$
$A_1\ A_2\ A_3\ \dots\ A_N$
```

## 제한

$1 \le N \le 100\,000$

$1 \le A_i \le N$

$A_i$는 정수입니다.

## 출력

조건을 만족시키는 것이 불가능하다면 `-1`을 출력하세요.

그렇지 않다면 조건을 만족시키기 위해 필요한 연산 횟수를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 2 1
```

#### 출력

```text
1
```

예를 들어 가장 왼쪽 부분의 오른쪽 끝에서 잘라 연산하면, 연산 후 막대의 색은 왼쪽부터 $2,1,1$이 되어 조건을 만족합니다.

### 예제 2 {file=""}

#### 입력

```text
3
1 2 3
```

#### 출력

```text
0
```

그대로도 조건을 만족합니다.

### 예제 3 {file=""}

#### 입력

```text
5
1 2 1 2 1
```

#### 출력

```text
-1
```

아무리 노력해도 조건을 만족시킬 수 없습니다.
