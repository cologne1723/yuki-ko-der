## 문제 설명

길이 $N$인 영소문자 문자열 $S$가 주어집니다.

$S$의 비어 있지 않은 연속 부분 문자열 중 회문인 것의 개수를 구하세요.

문자열로서 같은 부분 문자열이라도 꺼낸 위치가 다르면 서로 다른 것으로 세어야 합니다.

### 점수

예상 해답의 길이는 $124$바이트입니다.

제출한 소스 코드의 코드 길이가 $x$이고 이 문제의 예상 해답 코드 길이가 $y$일 때, 해당 소스 코드의 점수는 다음과 같이 계산됩니다.

- $y\leq x$일 때: $\lfloor100\exp(-0.012(x-y))\rfloor$점
- $x<y$일 때: $101$점

이 문제의 점수는 이 문제에 제출된 소스 코드 점수의 최댓값입니다.

## 입력

```text
$N$
$S$
```

입력은 다음 형식으로 주어집니다.

- $1$번째 줄에 문자열의 길이 $N$이 주어집니다.
- $2$번째 줄에 영소문자로 이루어진 길이 $N$인 문자열 $S$가 주어집니다.

## 제한

- $1\leq N\leq 500$
- $N$은 정수입니다.
- $S$는 영소문자로 이루어진 길이 $N$인 문자열입니다.

## 출력

답을 출력하고, 마지막에 개행을 출력하세요.

## 예제

```text

```

#### 출력

```text
8
```

`a a b a b aa aba bab`의 $8$개가 회문인 부분 문자열입니다.
