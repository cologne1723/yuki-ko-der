MMA 문자열은 서로 다른 두 종류의 알파벳으로 이루어진 길이 3의 문자열이며, 첫 번째와 두 번째 문자가 같은 문자열입니다. 대문자 문자열 $S$가 주어질 때, 연속하지 않아도 되는 부분 수열 중 MMA 문자열인 것의 개수를 구하세요. 선택한 위치 집합이 다르면 다른 방법으로 셉니다.

## 조건

- $3\le|S|\le2\times10^5$
- $S$는 대문자 알파벳으로만 이루어집니다.

## 입력

```text
S
```

## 출력

답을 출력하세요.
