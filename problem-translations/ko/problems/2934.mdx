## 문제 설명

각 자릿수의 합이 $N$ 이하인 양의 정수 중 $K$번째로 작은 양의 정수를 구하세요.

## 입력

```text
$N\ K$
```

## 제한

- $1 \leq N, K \leq 10^{18}$
- 입력은 모두 정수입니다.
- 답의 자릿수는 $10^5$자리 이하임이 보장됩니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 10
```

#### 출력

```text
100
```

각 자릿수의 합이 $3$ 이하인 양의 정수는 작은 순서대로 $1$, $2$, $3$, $10$, $11$, $12$, $20$, $21$, $30$, $100$, $101$ ... 입니다.

$10$번째로 작은 양의 정수는 $100$입니다.

### 예제 2 {file=""}

#### 입력

```text
33 1000000000000000000
```

#### 출력

```text
1020002210002200600501111300120
```

답이 $64$비트 정수에 들어가지 않을 수 있습니다.
