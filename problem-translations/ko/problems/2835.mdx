## 문제 설명

정수 $N$개가 있습니다. $i$번째 정수는 $A_i$입니다. $\mathrm{First}$君과 $\mathrm{Second}$君이 번갈아 가며 다음 연산을 한 번씩 수행합니다.

- 정수를 하나 골라 삭제합니다. 그 후 남아 있는 정수를 모두 $-1$배합니다.

$\mathrm{First}$君이 먼저 연산을 수행하며, 정수가 모두 삭제되면 종료합니다.

$\mathrm{First}$君이 삭제한 정수의 합을 $X$, $\mathrm{Second}$君이 삭제한 정수의 합을 $Y$라고 합니다. $\mathrm{First}$君은 $X-Y$를 최댓값으로 만들고 싶어 하며, $\mathrm{Second}$君은 $X-Y$를 최솟값으로 만들고 싶어 합니다.

두 사람이 최선을 다했을 때 최종적인 $X-Y$를 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
```

## 제한

- $1 \le N \le 2 \times 10^5$
- $|A_i| \le 10^9$ $(1 \le i \le N)$
- 입력은 모두 정수입니다.

## 출력

두 사람이 최선을 다했을 때 최종적인 $X-Y$를 정수로 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
-1 4 -2
```

#### 출력

```text
1
```

처음에 $\mathrm{First}$君이 $4$를 골라 삭제하고, 남은 정수를 $-1$배합니다. 남은 정수는 $1,2$가 됩니다.

다음으로 $\mathrm{Second}$君이 $2$를 골라 삭제하고, 남은 정수를 $-1$배합니다. 남은 정수는 $-1$입니다.

마지막으로 $\mathrm{First}$君이 $-1$을 골라 삭제합니다. 남은 정수는 없습니다.

$X=4+(-1)=3$, $Y=2$이므로 $X-Y=1$입니다.
