## 문제 설명

문자 `S`, `K`, `G`, `.`로 이루어진 문자열 $T$가 주어집니다.

문자열 $T$에 포함된 모든 `.`을 `S`, `K`, `G` 중 $1$개로 각각 치환하여 얻는 문자열 중 다음 조건을 만족하는 것이 존재하는지 판정하고, 존재한다면 그중 $1$개를 구성하세요.

- `SKG`는 $T$의 연속 부분 문자열이 아닙니다.

## 입력

```text
$T$
```

## 제한

- $T$의 길이는 $1$ 이상 $2\times 10^5$ 이하입니다.
- $T$는 문자 `S`, `K`, `G`, `.`만으로 이루어집니다.

## 출력

조건을 만족하는 문자열이 존재하지 않는 경우, `No`를 $1$번째 줄에 출력하세요.

존재하는 경우, $1$번째 줄에 `Yes`를 출력한 후 $2$번째 줄에 조건을 만족하는 문자열을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
S.K.G
```

#### 출력

```text
Yes
SKKSG
```

`SKKSG`는 `S.K.G`에 포함된 `.`을 `S`, `K`, `G` 중 $1$개로 치환하여 얻은 문자열이며, 연속 부분 문자열로 `SKG`를 포함하지 않으므로 조건을 만족합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
SSSSSKGKKKSKGSKG.............................................
```

#### 출력

```text
No
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
S
```

#### 출력

```text
Yes
S
```
