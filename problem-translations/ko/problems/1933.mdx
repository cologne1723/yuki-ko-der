a,b,c로 이루어진 문자열 $S$와 음이 아닌 정수 $A,B,C$가 주어집니다. a를 $A$개, b를 $B$개, c를 $C$개 포함하고 $S$를 부분 수열로 포함하는 문자열 $T$의 개수를 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
$S$
$A\ B\ C$
```

$1\le\lvert S\rvert\le2\times10^5$, $0\le A,B,C\le2\times10^5$, $A+B+C>0$입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
abc
2 1 1
```

#### 출력

```text
3
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
a
400 0 0
```

#### 출력

```text
1
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
abcababcbabcbacbbab
314 159 265
```

#### 출력

```text
453546717
```
