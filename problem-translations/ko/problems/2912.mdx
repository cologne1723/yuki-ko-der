## 문제 설명

처음에 양의 정수 $N$, 음이 아닌 정수 $M$, 그리고 자기 루프와 다중 간선을 갖지 않는 $N$개 정점 $M$개 간선의 가중치가 있는 무방향 그래프 $G$가 주어집니다.

다음과 같은 문제를 생각합니다.

입력으로 음이 아닌 정수 $R$이 주어집니다.

$G$에서 가중치가 $R$보다 큰 간선을 삭제해서 얻어지는 가중치가 있는 무방향 그래프의 연결 요소 개수를 구하세요. 이하 이 값을 이 문제의 답이라고 부릅니다.

입력으로 양의 정수 $T$가 주어집니다. $T$개의 문제에 답하세요.

### 배경

위상수학적 데이터 분석(Topological Data Analysis)이라는 분야에서는 가중치가 있는 무방향 그래프에 [퍼시스턴트 호몰로지](https://en.wikipedia.org/wiki/Persistent_homology)라는 차수가 매겨진 불변량을 정의하며, 이를 널리 응용합니다. 차수를 $1$개 고정할 때마다 퍼시스턴트 호몰로지는 음이 아닌 실수로 색인된 [단체 호몰로지](https://ja.wikipedia.org/wiki/%E5%8D%98%E4%BD%93%E7%9A%84%E3%83%9B%E3%83%A2%E3%83%AD%E3%82%B8%E3%83%BC)라는 기하학적 불변량의 계열 데이터를 제공하고, 그 자체 또는 그 쌍대 불변량이 이루는 계열 데이터는 다른 기하학적 불변량을 어떤 의미에서는 근사하는 계열이 됩니다. [1] 정리 3.5, 정리 5.1을 참고하세요.

이번 문제는 가중치와 계열의 색인을 정수로 제한했을 때 퍼시스턴트 호몰로지의 $0$차 부분을 계산하는 문제로 생각할 수 있습니다.

## 입력

$G$의 정점에는 $N$ 미만의 각 음이 아닌 정수 $n$을 붙이고 정점 $n$이라고 부릅니다. $G$의 간선에는 $M$ 미만의 각 음이 아닌 정수 $m$을 붙이고 간선 $m$이라고 부릅니다.

$M$ 미만의 각 음이 아닌 정수 $m$에 대해, 간선 $m$의 양 끝점을 정점 $i_m$과 정점 $j_m$으로 두고 간선 $m$의 가중치를 $w_m$으로 둡니다. $i_m$과 $j_m$은 $i_m < j_m$를 만족하는 $N$ 미만의 음이 아닌 정수입니다.

$T$ 이하의 각 양의 정수 $t$에 대해, $t$번째 문제의 입력 $R$을 $R_t$로 둡니다.

입력은 다음 형식으로 표준 입력에서 $3+M$개의 줄에 걸쳐 주어집니다.

~~~text
$N\ M$
$i_0\ j_0\ w_0$
$\vdots$
$i_{M-1}\ j_{M-1}\ w_{M-1}$
$T$
$R_1\ \cdots\ R_T$
~~~

- $1$번째 줄에 $N$, $M$이 반각 공백으로 구분되어 주어집니다.
- $M$ 미만의 각 음이 아닌 정수 $m$에 대해, $2+m$번째 줄에 $i_m$, $j_m$, $w_m$이 반각 공백으로 구분되어 주어집니다.
- $2+M$번째 줄에 $T$가 주어집니다.
- $3+M$번째 줄에 $T$ 이하의 각 양의 정수 $t$에 대한 $R_t$가 $t$가 작은 순서대로 반각 공백으로 구분되어 주어집니다.

## 제한

입력은 다음 제한을 만족합니다.

- $N$은 $0 \leq N \leq 10^5$를 만족하는 정수입니다.
- $M$은 $0 \leq M \leq \min \{\frac{1}{2}N(N-1),10^5\}$를 만족하는 정수입니다.
- $M$ 미만의 각 음이 아닌 정수 $m$에 대해 다음을 만족합니다.
  - $i_m$과 $j_m$은 $0 \leq i_m < j_m < N$을 만족하는 정수입니다.
  - $w_m$은 $1 \leq w_m \leq 10^5$를 만족하는 정수입니다.
- $T$는 $1 \leq T \leq 10^5$를 만족하는 정수입니다.
- $T$ 이하의 임의의 양의 정수 $t$에 대해 $R_t$는 $0 \leq R_t \leq 10^5$를 만족하는 정수입니다.

## 출력

$T$ 이하의 각 양의 정수 $t$에 대해, $t$번째 문제의 답을 $t$번째 줄에 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

~~~text
2 1
0 1 1
1
2
~~~

#### 출력

~~~text
1
~~~

$\{0,1\}$에 대응하는 간선의 가중치는 $1$입니다.

가중치가 $2$보다 큰 간선을 삭제하는 연산에서는 $G$가 변하지 않으므로 연결 요소는 $1$개입니다.

### 예제 2 {file=""}

#### 입력

~~~text
2 1
0 1 2
1
1
~~~

#### 출력

~~~text
2
~~~

$\{0,1\}$에 대응하는 간선의 가중치는 $2$입니다.

가중치가 $1$보다 큰 간선을 삭제하는 연산에서는 $\{0,1\}$에 대응하는 간선이 삭제되므로, 정점 $2$개의 가중치가 있는 이산 무방향 그래프를 얻게 되고 연결 요소는 $2$개입니다.

### 예제 3 {file=""}

#### 입력

~~~text
2 1
0 1 1
3
2 0 1
~~~

#### 출력

~~~text
1
2
1
~~~

$\{0,1\}$에 대응하는 간선의 가중치는 $1$입니다.

가중치가 $2$보다 큰 간선을 삭제하는 연산에서는 $G$가 변하지 않으므로 연결 요소는 $1$개입니다.

가중치가 $0$보다 큰 간선을 삭제하는 연산에서는 $G$에서 $\{0,1\}$에 대응하는 간선이 삭제되므로, 정점 $2$개의 가중치가 있는 이산 무방향 그래프를 얻게 되고 연결 요소는 $2$개입니다.

가중치가 $1$보다 큰 간선을 삭제하는 연산에서는 $G$가 변하지 않으므로 연결 요소는 $1$개입니다. $3$번째 문제에서 생각해야 하는 무방향 그래프의 정의는 $G$에서 가중치가 $1$보다 큰 간선을 삭제해서 얻어지는 가중치가 있는 무방향 그래프이며, $2$번째 문제에서 생각한 가중치가 있는 무방향 그래프에서 가중치가 $1$보다 큰 간선을 삭제해서 얻어지는 가중치가 있는 무방향 그래프가 **아님**에 주의하세요.
