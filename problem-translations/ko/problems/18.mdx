## 문제 설명

타로는 암호에 관심이 있어 새로운 암호 방식을 생각하고 있습니다.
오래전에 개발된 카이사르 암호를 참고하여 조금 바꾼 더 복잡한 암호를 만들기로 했습니다.

카이사르 암호는 평문(암호화되지 않은 문)의 알파벳을 오른쪽으로 $N$번 이동하는 방식입니다. 예를 들어 $N=1$이면 `A`는 `B`, `M`은 `N`, `Z`는 `A`가 됩니다.

타로는 문자마다 $N$의 값을 바꾸어 1번째 문자는 1칸, 2번째 문자는 2칸, …과 같이 “$i$번째 문자를 오른쪽으로 $i$칸 이동”하기로 했습니다. 이동 결과 `Z`를 넘으면 카이사르 암호와 마찬가지로 `A`로 돌아갑니다. 오른쪽으로 이동한다는 것은 알파벳 순서에서 다음 문자로 바꾸는 것입니다.

타로는 이 새로운 암호를 “우사 암호”라고 이름 붙였습니다.

입력으로 우사 암호로 암호화된 문자열이 주어집니다. 이를 복호화한 문자열을 출력하세요.

## 입력

```text
S
```

문자열 $S$가 한 줄에 주어집니다. $(|S| \le 1024)$
$S$를 구성하는 문자는 대문자 알파벳(`A`~`Z`)뿐이며, 복호화한 문자열도 모두 대문자 알파벳으로 이루어집니다.

## 출력

입력 문자열을 복호화한 문자열을 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1

#### 입력

```text
BCD
```

#### 출력

```text
AAA
```

### 예제 2

#### 입력

```text
ABCDEFGHIJKLMNOPQRSTUVWXYZ
```

#### 출력

```text
ZZZZZZZZZZZZZZZZZZZZZZZZZZ
```
