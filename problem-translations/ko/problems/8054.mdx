## 문제 설명

다음 조건을 만족하는 양의 정수 $(a, b, c)$를 $1$개 찾으세요.

- $a^2+b^2=c^2$
- $b=a+1$
- $c$는 십진법 표기로 $X$자리입니다.

조건을 만족하는 $(a, b, c)$는 반드시 존재한다는 것을 증명할 수 있습니다.

## 만우절 요소는 어디?

모릅니다.

## 입력

```text
$X$
```

## 제한

- $1 \le X \le 18$
- $X$는 정수입니다.

## 출력

조건을 만족하는 $a$, $b$, $c$를 공백으로 구분하여 $1$줄에 출력하세요.

답이 여러 개 존재하는 경우에는 그중 어느 것을 출력해도 됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
3 4 5
```

- $3^2+4^2=25=5^2$
- $4=3+1$
- $5$는 $1$자리 정수입니다.

### 예제 2 {file=""}

#### 입력

```text
3
```

#### 출력

```text
119 120 169
```

$(696, 697, 985)$를 출력해도 정답입니다.

### 예제 3 {file=""}

#### 입력

```text
9
```

#### 출력

