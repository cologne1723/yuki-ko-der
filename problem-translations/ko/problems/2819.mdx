**이 문제는 대화형 문제입니다.**

## 문제 설명

$\mathbb{B} \coloneqq \{0,1\}$ 위의 이항 연산 $\otimes \colon \mathbb{B} \times \mathbb{B} \to \mathbb{B}$가 다음 조건을 모두 만족합니다.

- $0 \otimes 0=P_{0,0}$
- $0 \otimes 1=P_{0,1}$
- $1 \otimes 0=P_{1,0}$
- $1 \otimes 1=P_{1,1}$

단, 네 수 $P_{0,0}$, $P_{0,1}$, $P_{1,0}$, $P_{1,1}$은 모두 숨겨져 있어 주어지지 않습니다.

여러분은 채점 프로그램에 다음 질문을 정확히 $1$번 할 수 있습니다.

- 먼저 다음 조건을 모두 만족하는 길이 $n$인 수열 $v=(v_1,v_2,\dots,v_n)$을 자유롭게 선택합니다.
  - $3\leq n<256$
  - $\{v_1,v_2,\dots,v_n\}\subset\mathbb{B}$
- 그다음 $(\cdots((v_1\otimes v_2)\otimes v_3)\otimes\cdots)\otimes v_n$의 값을 질문합니다.

입력으로 주어지는 $\{X,Y\}\subset\mathbb{B}$인 $X$, $Y$에 대해 $X\otimes Y$의 값을 구하세요.

## 입력

먼저 채점 프로그램이 표준 입력으로 다음 형식의 $X$, $Y$를 줍니다.

```text
$X\ Y$
```

그 후 질문에 대한 답으로 채점 프로그램이 표준 입력으로 다음 형식의 $t$를 줍니다. 여기서 $t$는
$(\cdots((v_1\otimes v_2)\otimes v_3)\otimes\cdots)\otimes v_n$의 값입니다.

```text
$t$
```

## 제한

- $\{P_{0,0},P_{0,1},P_{1,0},P_{1,1}\}\subset\mathbb{B}$
- $\{X,Y\}\subset\mathbb{B}$
- $P_{0,0}$, $P_{0,1}$, $P_{1,0}$, $P_{1,1}$의 값은 각 테스트 케이스에서 고정되어 있습니다.

## 출력

먼저 다음 형식으로 수열 $v$와 그 길이 $n$을 표준 출력에 출력하세요.

```text
$n$
$v_1\ v_2\ \dots\ v_n$
```

마지막으로 구한 $X\otimes Y$의 값을 한 줄에 출력하고 프로그램을 종료하세요.

출력할 때마다 줄 끝에 개행을 넣고 표준 출력을 flush하세요. 조건을 만족하지 않는 출력을 한 경우의 채점 결과는 정의되지 않습니다. 여분의 공백이나 개행을 출력하는 것도 조건을 만족하지 않는 출력에 해당합니다. 상호작용이 끝난 뒤에는 즉시 프로그램을 종료하세요.

## 예제

### 예제 1 {file=""}

다음은 $(P_{0,0},P_{0,1},P_{1,0},P_{1,1})=(1,0,1,0)$인 경우의 상호작용 예입니다.

#### 입력

```text
0 0
```

처음에 $(X,Y)=(0,0)$이 주어집니다.

#### 출력

```text
3
0 0 0
```

#### 입력

```text
1
```

질문에 대한 답으로 $t=1$이 주어집니다.

#### 출력

```text
1
```

$v=(v_1,v_2,v_3)=(0,0,0)$으로 질문하면
$(v_1\otimes v_2)\otimes v_3=(0\otimes0)\otimes0=1$입니다. 실제로
$(0\otimes0)\otimes0=P_{0,0}\otimes0=1\otimes0=P_{1,0}=1$입니다.

이제 $0\otimes0=0$이라고 가정하면 $(0\otimes0)\otimes0=0\otimes0=0$이 되어 위 결과와 모순입니다. 따라서 $0\otimes0=1$이고, $X\otimes Y=0\otimes0=1$입니다.

모든 테스트 케이스에서 $P_{0,0}$, $P_{0,1}$, $P_{1,0}$, $P_{1,1}$, $X$, $Y$의 값은 모두 $0$ 또는 $1$입니다.
