## 문제

그래프는 정점과 간선으로 이루어진 자료 구조입니다. 간선으로 두 정점을 연결하면 정점과 정점을 이어서, 연결된 정점 사이를 자유롭게 이동할 수 있습니다.

정점이 $N$개 주어집니다. 처음에는 모든 정점이 간선으로 연결되어 있지 않습니다. 정점을 연결할 때 그래프는 다음 규칙을 따릅니다.

- 간선은 반드시 서로 다른 두 정점을 연결합니다.
- 같은 두 정점 사이에 간선이 2개 이상 존재하지 않습니다.

모든 정점을 서로 이동할 수 있도록 연결하는 데 필요한 간선의 최소 개수를 구하세요.

## 입력

```text
N
```

- $2 \leq N \leq 13$

## 출력

필요한 간선의 최소 개수를 한 줄에 출력하세요. 마지막에 개행을 넣으세요.

## 샘플

### 입력 1 {file="stdin"}

```text
2
```

### 출력 1 {file="stdout"}

```text
1
```

정점 0과 정점 1이 있습니다. 두 정점을 간선 하나로 연결하면 됩니다.

### 입력 2 {file="stdin"}

```text
4
```

### 출력 2 {file="stdout"}

```text
3
```

정점 0, 1, 2, 3이 있습니다. 예를 들어 0과 1, 1과 2, 2와 3을 연결할 수 있습니다. 또는 0과 1, 1과 2, 1과 3을 연결할 수도 있습니다. 어느 경우든 필요한 간선은 3개입니다.

### 입력 3 {file="stdin"}

```text
13
```

### 출력 3 {file="stdout"}

```text
12
```

13개의 정점으로 만들 수 있는 그래프의 형태는 많지만, 필요한 최소 간선 수는 12개입니다.
