비음이 아닌 정수 $A,B$가 주어질 때 다음 한쪽 극한을 구하라냥.

$$\lim_{x\to B+0}A^x$$

## 조건

<details>
<summary>한쪽 극한의 정의를 모르는 사람을 위한 설명 (클릭하면 열립니다)</summary>

다음 조건을 만족하는 실수 $\alpha$가 유일하게 존재합니다.

- 임의의 양의 실수 $\epsilon$에 대해, 다음 조건을 만족하는 양의 실수 $\delta$가 존재합니다.
  - 임의의 양의 실수 $x$에 대해 $0<x-B<\delta$이면 $|A^x-\alpha|<\epsilon$입니다.

이러한 $\alpha$를 $\displaystyle\lim_{x\to B+0}A^x$라고 씁니다.

</details>

- $A,B$는 $10$ 이하의 비음이 아닌 정수이다냥.
- 답은 비음이 아닌 정수이다냥.

## 입력

```text
A
B
```

## 출력

한쪽 극한의 값을 출력하라냥.
