비음이 아닌 정수 $A,B$가 주어질 때 다음 한쪽 극한을 구하라냥.

$$\lim_{x\to B+0}A^x$$

## 조건

- $A,B$는 $10$ 이하의 비음이 아닌 정수이다냥.
- 답은 비음이 아닌 정수이다냥.

## 입력

```text
A
B
```

## 출력

한쪽 극한의 값을 출력하라냥.

예제는 원문을 참고하라냥.
