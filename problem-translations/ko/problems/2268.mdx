문자 `a`, `b`로 이루어진 길이 $N$의 NG 단어가 $N$개 주어진다냥. 이 NG 단어가 아닌 길이 $N$의 문자열을 하나 출력하라냥. 항상 존재함이 보장된다냥.

## 조건

- $1\le N\le1000$

## 입력

```text
N
NG_1
\vdots
NG_N
```

## 출력

NG 단어가 아닌 문자열을 하나 출력하라냥.
