## 문제 설명

어느 마을에 크기가 $2N \times 2N$인 수박밭이 있습니다. 이 수박밭은 정사각형이며, 좌표 $(-N,-N)$과 좌표 $(N,N)$을 잇는 선분이 대각선이 되도록 놓여 있습니다. 수박밭의 내부(경계선을 포함)에 있는 각 격자점에는 수박이 $1$개씩 있습니다.

이 마을에 찾아온 星の戦士는 수박을 매우 좋아합니다. 수박을 빨아들여 먹으려던 그는 위화감을 느꼈습니다. 좌표 $(0,0)$에 있어야 할 수박이 없고, 대신 수박 모양의 폭탄이 있었기 때문입니다.

이에 마을에서 수박을 폭탄과 바꿔치기한 목격자를 찾았고, 다음과 같은 증언을 들었습니다.

- 大王이 수박밭의 수박 $3$개를 폭탄으로 바꾸었습니다. 폭탄으로 바뀐 수박은 총 $3$개뿐입니다. 이후 폭탄의 좌표를 $O,A,B$라고 하며, 원점에 있는 폭탄의 좌표를 $O$라고 합니다.
- 삼각형 $OAB$는 $\angle AOB$가 직각인 직각삼각형입니다.

$(0,0)$ 이외의 수박 폭탄도 찾고 싶다고 말하자, 탐문 중에 탐사기를 받을 수 있었습니다. 이 도구는 좌표 $X$를 지정하면 다음과 같이 동작합니다.

- $\cos \angle AXB$의 부호와 $\cos^2 \angle AXB$를 출력합니다.

星の戦士는 복사 능력을 사용할 수 있습니다. 구체적으로는 해골 무늬가 있는 폭탄 모양의 마물을 빨아들인 뒤, 좌표 $(x,y)$와 반지름 $r$을 선택하여 좌표 $(x,y)$를 중심으로 하고 반지름이 $r$인 원의 내부(경계선을 포함)에 있는 모든 것을 소멸시킵니다.

폭탄을 제거할 때 그에게는 다음과 같은 바람이 있습니다.

- 폭탄은 위험하므로 $O,A,B$에 있는 폭탄을 모두 소멸시키고 싶습니다.
- 복사 능력은 $1$번만 사용할 수 있고, 수박을 최대한 남기고 싶으므로 $r$을 최대한 작게 하고 싶습니다.

탐사기를 최대 $300$번 사용하여 위의 모든 바람을 만족하는 좌표와 반지름을 찾아 알려주세요. 단, 반지름은 제곱한 값으로 출력하세요. 이 조건에 따라 바람을 모두 만족하는 좌표와 반지름은 정확히 $1$개만 존재합니다.

## 입력

```text
$N$
```

처음에 $N$이 주어집니다.

탐사기를 사용하는 질의에 대해 저지 측에서 다음 형식으로 답을 제공합니다.

```text
$P\ u\ v$
```

$X,A,B$가 서로 다르면 $P$는 `-`, `+`, `0` 중 $1$개이며, 각각 $\cos \angle AXB$의 부호가 음수, 양수, $0$임을 뜻합니다. $u,v$는 정수이고 $\cos^2 \angle AXB=\frac{u}{v}$를 만족하며, $v$가 양수인 기약분수로 표현한 경우입니다. 그렇지 않으면 $P$는 `?`이고 $u=v=0$입니다.

단, $v>10^{18}$인 경우에는 $1 \leq v \leq 10^{18}$이 되도록 유리수 근사를 적용한 $u,v$가 반환됩니다.

## 제한

- $3 \leq N \leq 10^8$
- $N$은 정수입니다.

숨겨진 좌표 $A(x_A,y_A)$와 $B(x_B,y_B)$는 다음 조건을 만족합니다.

- $A$와 $B$는 프로그램 간 상호작용이 시작되기 전에 고정됩니다.
- $-N \leq x_A,x_B,y_A,y_B \leq N$
- $A$와 $B$는 격자점입니다.
- $O,A,B$는 일직선 위에 있지 않습니다.
- 삼각형 $OAB$는 $\angle AOB = \frac{\pi}{2}$인 직각삼각형입니다.

## 출력

좌표 $Z(x_Z,y_Z)$에서 탐사기를 사용하는 질의는 다음 형식으로 출력하세요. 질의 횟수가 $300$번을 초과하면 오답입니다.

```text
$1\ x_Z\ y_Z$
```

이때 다음 조건을 만족해야 합니다. 조건을 만족하지 않는 경우의 채점 결과는 정해져 있지 않습니다.

- $-10^9 \leq x_Z,y_Z \leq 10^9$
- $x_Z$와 $y_Z$는 각각 소수점 이하 자릿수가 최대 $9$자리입니다.

조건을 만족하는 좌표 $ANS(x_{ANS},y_{ANS})$와 반지름의 제곱 $r^2$를 출력하는 경우에는 다음 형식으로 출력하세요. 이 출력을 마치면 프로그램을 종료해야 합니다.

```text
$2\ x_{ANS}\ y_{ANS}\ r^2$
```

이때 다음 조건을 만족해야 합니다. 조건을 만족하지 않는 경우의 채점 결과는 정해져 있지 않습니다.

- $-10^9 \leq x_{ANS},y_{ANS} \leq 10^9$
- $0 \leq r^2 \leq 10^{19}$
- $x_{ANS},y_{ANS},r^2$는 각각 소수점 이하 자릿수가 최대 $9$자리입니다.

중심 $(x_{ANS},y_{ANS})$이고 반지름이 $r$인 원의 내부(경계선을 포함)에 폭탄 $3$개가 모두 들어 있으며, 이보다 $r$을 더 작게 만들 수 없다면 정답입니다.

참값과의 오차가 $10^{-10}$ 이하가 되도록 준비한 예상 해와의 상대 오차 또는 절대 오차가 $10^{-5}$ 이하이면 정답으로 인정됩니다.

## 예제

### 예제 1 {file=""}

#### 출력

```text
1 0 0
1 5.5 1.5
1 -2 3
1 3 2
2 0 0 13
```

#### 입력

저지가 프로그램에 보내는 입력입니다.

```text
3
0 0 1
+ 1 1
? 0 0
? 0 0
```

처음에 $N$이 주어지고, 비밀리에 $A(-2,3)$과 $B(3,2)$가 정해져 있다고 가정합니다.

$1$번째 질의에서는 $\angle AOB=\frac{\pi}{2}$이므로 $\cos \angle AOB=0$입니다.

$2$번째 질의에서는 $\angle AXB=0$이므로 $\cos \angle AXB=1$입니다.

$3$번째와 $4$번째 질의에서는 각을 이룰 수 없으므로 위와 같은 저지의 출력이 나옵니다.

답으로 중심 $(0,0)$, 반지름 $\sqrt{13}$을 출력했습니다. 원의 내부에 폭탄 $3$개가 들어가지만, 이보다 폭탄 $3$개를 포함하면서 반지름을 더 작게 만들 수 있으므로 오답입니다.

또한 `-00.7`처럼 앞에 `0`이 붙은 값이나 `18.90.3`, `+1c.5`처럼 소수로 해석할 수 없는 값을 출력하면 오답입니다.
