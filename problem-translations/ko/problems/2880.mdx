## 문제 설명

양의 정수 $N$, $M$이 주어집니다.

$\displaystyle\max_{1 \leq x \leq N} \left(\sum_{i=1}^{M} (x \bmod i)\right)$

을 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ M$
```

## 제한

- $1 \leq N,M \leq 2\times 10^5$
- $N$, $M$은 정수입니다.

## 출력

답을 출력하고, 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2
```

#### 출력

```text
1
```

$x=1$일 때,
$\displaystyle\sum_{i=1}^{M}(x \bmod i)=1 \bmod 1+1 \bmod 2=1$입니다.

$x=2$일 때,
$\displaystyle\sum_{i=1}^{M}(x \bmod i)=2 \bmod 1+2 \bmod 2=0$입니다.

$x=3$일 때,
$\displaystyle\sum_{i=1}^{M}(x \bmod i)=3 \bmod 1+3 \bmod 2=1$입니다.

따라서 $1$, $0$, $1$의 최댓값인 $1$을 출력합니다.
