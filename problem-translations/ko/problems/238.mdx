## 문제

이 문제는 [Codeforces Round #286 (Div. 2) 문제 A](http://codeforces.com/problemset/problem/505/A)의 입력 제한을 변경한 문제입니다.

K 씨가 영소문자로 이루어진 문자열 $s$를 주었습니다. 여기에 영소문자를 정확히 하나 삽입하여 회문으로 만들고 싶다고 합니다. 회문은 앞에서 읽어도 뒤에서 읽어도 문자가 같은 순서로 나타나는 문자열입니다. 예를 들어 `noon`, `testset`, `a`는 회문이지만 `test`, `kitayuta`는 회문이 아닙니다.

삽입할 문자는 어떤 영소문자여도 되고, $s$의 어느 위치에 삽입해도 됩니다. 문자열의 맨 앞이나 맨 뒤에 삽입해도 됩니다. $s$가 이미 회문이어도 문자를 하나 삽입해야 합니다.

$s$에 영소문자 하나를 삽입하여 회문으로 만들 수 있으면 그 결과인 회문을 하나 출력하세요. 불가능하면 대문자 `NA`를 출력하세요. 가능한 회문이 여러 개라면 그중 아무 것이나 출력해도 됩니다.

## 입력

```text
s
```

- $1 \leq |s| \leq 10^5$
- $s$의 각 문자는 영소문자입니다.

## 출력

$s$에 영소문자 하나를 삽입해 만들 수 있는 회문을 출력하세요. 불가능하면 `NA`를 출력하세요. 해가 여러 개이면 그중 하나를 출력해도 정답입니다.

## 샘플

### 입력 1 {file="stdin"}

```text
revive
```

### 출력 1 {file="stdout"}

```text
reviver
```

끝에 `r`을 삽입하면 회문이 됩니다.

### 입력 2 {file="stdin"}

```text
ee
```

### 출력 2 {file="stdout"}

```text
eye
```

여러 해가 있습니다. 예를 들어 `eve`를 출력해도 정답입니다.

### 입력 3 {file="stdin"}

```text
kitayuta
```

### 출력 3 {file="stdout"}

```text
NA
```

문자 하나를 삽입하는 것만으로는 회문으로 만들 수 없습니다.
