이 문제는 [Codeforces Round #286 (Div. 2) 문제 A](http://codeforces.com/problemset/problem/505/A)의 입력 제한을 변경한 문제입니다.

## 문제 설명

K氏가 영소문자로 이루어진 문자열 $s$를 주었습니다. 여기에 영소문자를 정확히 $1$개 삽입하여 회문으로 만들고 싶다고 합니다. 회문은 앞에서 읽어도 뒤에서 읽어도 문자가 같은 순서로 나타나는 문자열입니다. 예를 들어 `noon`, `testset`, `a`는 회문이지만 `test`, `kitayuta`는 회문이 아닙니다.

삽입할 문자는 어떤 영소문자여도 되고, $s$의 어느 위치에 삽입해도 됩니다. 문자열의 맨 앞이나 맨 뒤에 삽입해도 됩니다. $s$가 이미 회문이어도 문자를 $1$개 삽입해야 합니다.

$s$에 영소문자 $1$개를 삽입하여 회문으로 만들 수 있으면 그 결과인 회문을 $1$개 출력하세요. 불가능하면 대문자 `NA`를 출력하세요. 가능한 회문이 여러 개라면 그중 아무 것이나 출력해도 됩니다.

## 입력

```text
$s$
```

## 제한

- $1 \leq |s| \leq 10^5$
- $s$의 각 문자는 영소문자입니다.

## 출력

$s$에 영소문자 $1$개를 삽입해 만들 수 있는 회문을 출력하세요. 불가능하면 `NA`를 출력하세요. 해가 여러 개이면 그중 $1$개를 출력해도 정답입니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
revive
```

#### 출력

```text
reviver
```

끝에 `r`을 삽입하면 회문이 됩니다.

### 예제 2 {file=""}

#### 입력

```text
ee
```

#### 출력

```text
eye
```

여러 해가 있습니다. 예를 들어 `eve`를 출력해도 정답입니다.

### 예제 3 {file=""}

#### 입력

```text
kitayuta
```

#### 출력

```text
NA
```

문자 $1$개를 삽입하는 것만으로는 회문으로 만들 수 없습니다.
