## 문제 설명

길이가 $N$인 정수 수열 $A=(A_1,A_2,\cdots,A_N)$가 주어집니다.

다음 연산을 원하는 횟수만큼 수행할 수 있습니다.

- $1$ 이상 $|A|$ 이하인 서로 다른 $2$개의 정수 $i,j$의 순서쌍 $(i,j)$를 선택합니다. 단, $A_i\leq 0$, $A_j\geq 0$이어야 합니다. $A$의 끝에 $A_i+A_j$를 추가한 뒤, $A$에서 $i$번째 원소와 $j$번째 원소를 동시에 삭제합니다.

$A$의 원소 개수를 $1$개로 만들 수 있는지 판정하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
```

$1$번째 줄에 수열의 길이 $N$이 주어집니다.

$2$번째 줄에 수열 $A$의 원소 $A_1,A_2,\cdots,A_N$이 공백으로 구분되어 주어집니다.

## 제한

- $1\leq N\leq 2\times 10^5$
- $-10^9\leq A_i\leq 10^9$
- 입력은 모두 정수입니다.

## 출력

$A$의 원소 개수를 $1$개로 만들 수 있다면 `Yes`를, 그렇지 않다면 `No`를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2
3 5
```

#### 출력

```text
No
```

$i=1,j=2$로 선택해도 $i=2,j=1$로 선택해도 연산을 수행할 수 없습니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3
-45 8 10
```

#### 출력

```text
Yes
```

다음과 같이 하면 목적을 달성할 수 있습니다.

- $i=1,j=2$로 선택해 연산을 수행합니다. $A=(10,-37)$가 됩니다.
- $i=2,j=1$로 선택해 연산을 수행합니다. $A=(-27)$가 됩니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
5
-1000000000 -100000000 -10000000 -1000000 1000000000
```

#### 출력

```text
Yes
```
