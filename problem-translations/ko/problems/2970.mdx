## 문제 설명

$L \leq R$를 만족하는 $6$개의 정수 $C_0, C_1, C_2, C_3, L, R$가 주어집니다.

$L \leq x \leq R$를 만족하는 모든 실수 $x$에 대한 $|C_0 + C_1 x + C_2 x^2 + C_3 x^3|$의 최솟값

$\min_{L \leq x \leq R} |C_0 + C_1 x + C_2 x^2 + C_3 x^3|$

을 구하세요. 단, 최솟값이 존재한다는 것은 증명할 수 있습니다.

## 입력

입력은 다음 형식으로 표준 입력에서 $2$개의 줄에 걸쳐 주어집니다.

```text
$C_0\ C_1\ C_2\ C_3$
$L\ R$
```

첫째 줄에 $C_0, C_1, C_2, C_3$가 공백으로 구분되어 주어집니다. 둘째 줄에 $L, R$이 공백으로 구분되어 주어집니다.

## 제한

- $C_0$는 $-10 \leq C_0 \leq 10$을 만족하는 정수입니다.
- $C_1$는 $-10 \leq C_1 \leq 10$을 만족하는 정수입니다.
- $C_2$는 $-10 \leq C_2 \leq 10$을 만족하는 정수입니다.
- $C_3$는 $-10 \leq C_3 \leq 10$을 만족하는 정수입니다.
- $L$과 $R$은 $-10 \leq L \leq R \leq 10$을 만족하는 정수입니다.

## 출력

$L \leq x \leq R$를 만족하는 모든 실수 $x$에 대한 $|C_0 + C_1 x + C_2 x^2 + C_3 x^3|$의 최솟값

$\min_{L \leq x \leq R} |C_0 + C_1 x + C_2 x^2 + C_3 x^3|$

을 한 줄에 출력하세요.

마지막에 개행을 출력하세요.

이 문제는 소수 오차 허용 문제입니다. 정확한 답의 소수점 이하 $6$자리 정밀도 근사값과의 절대 오차 또는 상대 오차가 $10^{-3}$ 이하이면 정답으로 처리됩니다.

여기서 실수 $x$의 소수점 이하 $6$자리 정밀도 근사값이란, 소수점 이하 $6$자리 이하의 유한소수로 나타낼 수 있으며 $x$를 초과하지 않는 실수 중 최댓값을 뜻합니다.

또한 저지 측의 사정으로 출력은 $500$자리 미만이어야 합니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0 0 0 0
0 0
```

#### 출력

```text
0.000000
```

$f(x) = C_0 + C_1 x + C_2 x^2 + C_3 x^3 = 0 + 0x + 0x^2 + 0x^3$로 둡니다. $|f(x)|$는 구간 $[L,R] = [0,0]$에서 $0$이라는 값만 가지므로,

$\min_{L \leq x \leq R} |f(x)| = 0$

입니다.

### 예제 2 {file=""}

#### 입력

```text
0 -1 0 0
1 2
```

#### 출력

```text
1.000000
```

$f(x) = C_0 + C_1 x + C_2 x^2 + C_3 x^3 = -x$로 둡니다. $|f(x)| = |x|$는 구간 $[L,R] = [1,2]$에서 $x$와 같고 엄격하게 증가하므로,

$\min_{L \leq x \leq R} |f(x)| = |f(L)| = 1$

입니다.

### 예제 3 {file=""}

#### 입력

```text
1 0 1 0
-1 1
```

#### 출력

```text
1.000000
```

$f(x) = C_0 + C_1 x + C_2 x^2 + C_3 x^3 = 1+x^2$로 둡니다. $|f(x)| = 1+x^2$는 구간 $[L,R] = [-1,1]$에서 아래로 볼록하고 $x = 0$일 때 최솟값을 가지므로,

$\min_{L \leq x \leq R} |f(x)| = |f(0)| = 1$

입니다.

### 예제 4 {file=""}

#### 입력

```text
0 0 0 1
-1 2
```

#### 출력

```text
0.000000
```

$f(x) = C_0 + C_1 x + C_2 x^2 + C_3 x^3 = x^3$로 둡니다. $|f(x)| = |x^3|$는 구간 $[L,R] = [-1,2]$에 영점(방정식 $|f(x)| = 0$의 해) $x = 0$을 가지므로,

$\min_{L \leq x \leq R} |f(x)| = 0$

입니다.
