## 문제 설명

어느 날 KCPC에 $Y$엔의 수입이 생겼습니다. 이때 KCPC 예산의 잔액도 $Y$엔입니다. KCPC는 $N$개의 이벤트에서 이 예산을 사용했습니다. 구체적으로 $i$번째 이벤트에서 예산을 $A_i$엔 사용했습니다.

모든 이벤트가 끝났을 때 예산이 얼마 남아 있는지 구하세요. 단, 적자인 경우, 즉 사용한 금액의 합이 $Y$엔보다 큰 경우에는 대신 `red`를 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$Y\ N$
$A_1\ A_2\ \cdots\ A_N$
```

$Y$는 처음 예산을 나타내는 정수이고, $N$은 이벤트 개수를 나타내는 정수입니다. $A_i$는 $i$번째 이벤트에서 사용한 금액을 나타내는 정수입니다.

## 제한

- $1 \le Y \le 10^9$
- $1 \le N \le 100$
- $1 \le A_i \le 10^7$
- 입력은 모두 정수입니다.

다음과 같은 부분점이 설정되어 있습니다.

| 부분점 | 배점 | 제한 |
| --- | ---: | --- |
| 부분점 $1$ | $20$% ($20$점) | $N=1$ |
| 부분점 $2$ | $10$% ($10$점) | 답이 `red`입니다. |
| 부분점 $3$ | $30$% ($30$점) | 답이 `red`가 아닙니다. |
| 부분점 $4$ | $40$% ($40$점) | 추가 제한이 없습니다. |

## 출력

답을 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
10000 1
8500
```

#### 출력

```text
1500
```

처음에 $10\,000$엔의 예산이 있고 $8\,500$엔을 지출하면 $1\,500$엔이 남습니다.

### 예제 2 {file=""}

#### 입력

```text
15000 2
9000 8000
```

#### 출력

```text
red
```

처음에는 $15\,000$엔의 예산이 있지만, 총 $9\,000+8\,000=17\,000$엔을 지출하여 적자입니다. 따라서 `red`를 출력합니다.

### 예제 3 {file=""}

#### 입력

```text
1000000000 3
10000000 10000000 9999999
```

#### 출력

```text
970000001
```
