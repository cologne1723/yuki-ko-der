## 문제 설명

오리온 군은 합창곡을 작곡하기로 했습니다. 코드 진행이 너무 단순하면 지루한 곡이 되고, 너무 복잡하면 이해할 수 없는 곡이 되므로, 적당히 복잡한 코드 진행이 되도록 만들고 싶습니다. 여기서 코드 진행은 연속하는 두 코드로 정의합니다. 사용할 수 있는 코드는 코드 $1$부터 코드 $300$까지 $300$종류이고, 사용할 수 있는 코드 진행은 $M$종류입니다. $i$번째 코드 진행은 코드 $P_i$ 다음에 코드 $Q_i$로 진행하는 진행이며($Q_i \ne P_i$), 그 복잡도는 $C_i$입니다. 코드 $N$개를 연결한 곡 중 복잡도의 합이 정확히 $K$가 되는 곡이 몇 가지인지 구하세요. 답은 매우 커질 수 있으므로, $10^9+7$로 나눈 나머지를 구하세요.

## 입력

```text
$N\ M\ K$
$P_1\ Q_1\ C_1$
$P_2\ Q_2\ C_2$
$\dots$
$P_M\ Q_M\ C_M$
```

입력은 모두 정수입니다.

## 제한

- $2 \le N \le 300$
- $1 \le M \le 300$
- $0 \le K \le 300$
- $1 \le P_i, Q_i \le 300$
- $P_i \ne Q_i$
- $i \ne j$이면 $(P_i, Q_i) \ne (P_j, Q_j)$
- $0 \le C_i \le 300$

## 출력

복잡도의 합이 정확히 $K$가 되는 곡이 몇 가지인지, $10^9+7$로 나눈 나머지를 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 6 2
1 2 0
1 3 0
2 1 1
3 1 0
2 3 0
3 2 2
```

#### 출력

```text
6
```

$1$-$2$-$3$-$2$, $3$-$1$-$3$-$2$, $1$-$3$-$2$-$3$, $2$-$3$-$2$-$3$, $3$-$2$-$3$-$1$, $2$-$1$-$2$-$1$의 $6$가지가 있습니다.

### 예제 2 {file=""}

#### 입력

```text
3 1 3
1 2 3
```

#### 출력

```text
0
```

애초에 곡을 만들 수 없습니다.
