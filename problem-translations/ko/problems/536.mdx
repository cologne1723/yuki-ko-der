## 문제

어떤 분야에서는 인공지능의 이름을 지을 때 만든 사람의 ID를 변형한 것을 인공지능 이름으로 사용하는 관습이 있습니다.

만든 사람의 ID는 소문자 영문자로 이루어진 길이 2 이상 10 이하의 문자열입니다.

* 만든 사람의 ID가 끝의 두 글자가 ai라면, 인공지능 이름은 ID의 끝 두 글자를 대문자로 바꾼 것입니다.
* 위 조건을 만족하지 않으면, 인공지능 이름은 ID 끝에 -AI를 붙인 것입니다.

표준 입력으로 만든 사람의 ID가 주어집니다. 관습에 따라 인공지능 이름을 출력하세요.

## 입력

```text
S
```

S는 만든 사람의 ID입니다.

2 ≤ |S| ≤ 10

문자열 S는 소문자 영문자로 이루어집니다.

## 출력

문제의 관습에 따라 인공지능 이름을 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
samurai
```

출력:

```text
samurAI
```

ID의 끝 두 글자가 ai이므로 끝 두 글자를 대문자로 바꾼 문자열을 출력합니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
yuki
```

출력:

```text
yuki-AI
```

ID의 끝이 ai가 아니므로 ID 끝에 -AI를 붙인 문자열을 출력합니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
maibuyoh
```

출력:

```text
maibuyoh-AI
```

문자열 안에 ai가 포함되어 있지만 끝이 아니므로 끝 두 글자를 대문자로 바꾸지 않고 끝에 -AI를 붙입니다.
