## 문제 설명

원점 $O=(0,0)$을 중심으로 하는 반지름 $R$인 원주 위에 서로 다른 $3$개의 점을 잡아 삼각형을 만들었습니다. 이때 삼각형의 무게중심 $G$는 좌표 $(G_X,G_Y)$에 있습니다. 이 삼각형의 수심 좌표를 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$R\ G_X\ G_Y$
```

## 제한

- $1\leq R\leq 10^{18}$
- $-10^{18}<G_X,G_Y<10^{18}$
- $|OG|<R$
- 입력은 모두 정수입니다.

## 출력

수심의 $X$ 좌표와 수심의 $Y$ 좌표를 공백으로 구분하여 출력하세요.

정답과의 절대 오차 또는 상대 오차가 $10^{-6}$ 이하이면 정답으로 판정됩니다.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
5 -2 1
```

#### 출력

```text
-6.000000000 3.000000000
```

정답과의 절대 오차 또는 상대 오차가 $10^{-6}$ 이하이면 정답으로 판정됩니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 0 0
```

#### 출력

```text
0 0
```
