## 주의

언어에 따라 실행 시간 제한이 빡빡할 수 있습니다. C++/Java/C# 등 빠른 언어로 푸는 것을 권장합니다.

C++는 특별히 최적화하지 않아도 $442$ms에 통과했습니다. Java 초보자인 출제자가 Java로 작성해 $1\,118$ms에 통과했습니다. C# 초보자인 출제자가 C#으로 작성했을 때 $1$〜$2$개 케이스에서 시간 초과가 났지만, camypaperさん의 입출력 메서드를 복사해 사용하자 $1\,747$ms에 통과했습니다. Python 초보자인 출제자가 PyPy로 시도해도 시간 초과로 실패했지만, 조금 더 개선하자 약 $1.2$초에 통과했습니다. Python3로 통과한 사람도 몇 명 있습니다.

## 이야기

어떤 연예인의 흉내를 내는 연예인이 나타났습니다.

## 문제 설명

그는 “$3$의 배수 또는 $3$이 들어 있는 수”일 때 `바보`가 되고, $P$의 배수($P$는 $8$, $80$, $800$ 중 $1$개)일 때 `수줍음`을 보입니다.

$A$ 이상 $B$ 이하의 정수 중 `바보`가 되면서 `수줍음`을 보이지 않는 수가 몇 개인지 $10^9+7$로 나눈 나머지를 구하세요.

## 입력

```text
$A\ B\ P$
```

모든 입력은 정수입니다.

## 제한

- $1 \le A \le B \le 10^{200\,000} = 10^{2 \times 10^5}$
- $P$는 $8$, $80$, $800$ 중 $1$개입니다.

## 출력

$A$ 이상 $B$ 이하의 정수 중 `바보`가 되면서 `수줍음`을 보이지 않는 수의 개수를 $10^9+7$로 나눈 나머지를 출력하세요.
