카드 `i`에 `A_i` 또는 `B_i`를 적을 수 있을 때, 카드에 적힌 서로 다른 정수 종류 수의 최댓값을 구합니다.

`1 <= A_i,B_i <= M`인 모든 입력 `M^{2N}`개에 대한 해의 합을 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `1 <= N,M <= 2 * 10^5`

## 입력

`N M`이 주어집니다.

## 출력

모든 입력에 대한 답의 합을 출력하세요.
