## 문제 설명

문자열 $S$가 주어집니다. 그 안의 각 숫자를 $1$자리 수로 간주하여 모두 더한 값을 구하세요.

예를 들어 `1test23`이라는 문자열에 포함된 숫자의 합은 $1+2+3=6$입니다.

2016/05/31 추가: 숫자가 없는 경우에는 $0$을 출력하세요.

## 입력

```text
$S$
```

$|S|$는 문자열 $S$의 길이입니다. 문자열 $S$는 반각 영숫자로만 이루어집니다.

## 제한

- $1 \le |S| \le 10\,000$

## 출력

각 숫자의 합을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1test23
```

#### 출력

```text
6
```

$1+2+3=6$입니다. $1+23$이 아니라는 점에 주의하세요.

### 예제 2 {file=""}

#### 입력

```text
2015
```

#### 출력

```text
8
```

### 예제 3 {file=""}

#### 입력

```text
1a2b3c4d5e6f7g8h90
```

#### 출력

```text
45
```
