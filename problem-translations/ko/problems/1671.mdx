`P`를 `1,2,...,N`의 균등한 무작위 순열로 선택합니다. `Q`를 `Q_{P_i}=i`로 정의합니다.

순회 비용을

$\lvert Q_1-Q_2\rvert + \lvert Q_2-Q_3\rvert + \cdots + \lvert Q_{N-1}-Q_N\rvert + \lvert Q_N-Q_1\rvert$

으로 정의할 때, 순회 비용의 기대값을 `10^9+7`로 나눈 값을 구하세요.

<details>
<summary>기대값을 $10^9+7$로 나눈 값을 출력한다는 것은? (클릭하여 펼치기)</summary>

구할 값은 반드시 유리수입니다. 이를 기약분수 $\frac{p}{q}$라고 합시다. $q\not\equiv0\pmod{10^9+7}$임을 증명할 수 있습니다. 이때 $rq\equiv p\pmod{10^9+7}$을 만족하는 $0$ 이상 $10^9+7$ 미만의 정수 $r$가 유일하게 정해지므로, $r$을 출력하세요.

</details>

## 제약

- `2 <= N`

## 입력

`N`이 주어집니다.

## 출력

기대값을 `10^9+7`로 나눈 값을 출력하세요.
