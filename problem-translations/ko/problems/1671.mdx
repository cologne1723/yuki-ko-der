`P`를 `1,2,...,N`의 균등한 무작위 순열로 선택합니다. `Q`를 `Q_{P_i}=i`로 정의합니다.

순회 비용을

`|Q_1-Q_2| + |Q_2-Q_3| + ... + |Q_{N-1}-Q_N| + |Q_N-Q_1|`

으로 정의할 때, 순회 비용의 기대값을 `10^9+7`로 나눈 값을 구하세요.

## 제약

- `2 <= N`

## 입력

`N`이 주어집니다.

## 출력

기대값을 `10^9+7`로 나눈 값을 출력하세요.
