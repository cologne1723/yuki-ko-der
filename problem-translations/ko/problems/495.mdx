## 문제

`(^^*)`은 b 씨가 생각해 낸 이모티콘입니다.

`(^^*)`에는 왼쪽을 향한 형태와 오른쪽을 향한 형태의 두 종류가 있습니다.

`(^^*)`은 왼쪽을 향하고, `(*^^)`은 오른쪽을 향합니다.

당신은 b 씨에게서 `(^^*)`과 `(*^^)`만 각각 원하는 개수만큼 무작위 순서로 이어 붙인 뒤 마지막에 `#`을 붙인 문자열 $S$를 받았습니다.

당신의 임무는 왼쪽 방향과 오른쪽 방향이 각각 몇 개인지 세는 것입니다.

예를 들어 `(^^*)(^^*)(*^^)(*^^)(^^*)(*^^)(*^^)#`라면 왼쪽 방향은 3개, 오른쪽 방향은 4개입니다.

## 입력

```text
$S$
```

문자열 $S$가 한 줄에 주어집니다.

$S$는 `(^^*)`과 `(*^^)`을 각각 원하는 개수만큼 무작위 순서로 이어 붙이고 마지막에 `#`을 붙인 문자열입니다.

$1\leq|S|\leq100000$입니다. 단, $|S|$는 문자열 $S$의 길이입니다.

## 출력

왼쪽 방향 개수와 오른쪽 방향 개수를 이 순서로 한 줄에 공백으로 구분하여 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
(^^*)(^^*)(*^^)(*^^)(^^*)(*^^)(*^^)#
```

출력:

```text
3 4
```

문제에서 든 예입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
(^^*)(^^*)(^^*)#
```

출력:

```text
3 0
```

### 샘플 3 {file="sample3.in"}

입력:

```text
#
```

출력:

```text
0 0
```

문자열이 처음부터 `#`인 경우도 있습니다.
