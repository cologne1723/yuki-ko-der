## 문제

각 돌은 타입 `0` 또는 `1`이고 무게 `w_i`, 가치 `v_i`를 가집니다. 일부를 골라 총 무게가 `W` 이하이고, 두 타입의 총 무게 차이가 `D` 이하가 되도록 할 때 가치 합의 최댓값을 구하세요.

## 제약

- `1 ≤ N,W,D ≤ 5000`
- `1 ≤ w_i,v_i ≤ 5000`

## 입력

```text
N W D
t_1 w_1 v_1
⋮
t_N w_N v_N
```

## 출력

최대 가치를 출력하세요.
