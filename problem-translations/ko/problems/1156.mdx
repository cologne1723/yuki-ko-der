## 문제 설명

Mitsubachi 군은 소풍을 갈 때마다 목적지를 본뜬 암호 산술 수식을 만들었습니다. 중학교 1학년 때는 `シイタ+ケヤマ=イキタイ`, 중학교 2학년 때는 `オオツカ+コクサイ=ビジツカン`, 중학교 3학년 때는 `spring+eight=picnic`을 만들었습니다.

$1$ 이상 $3$ 이하의 정수 $N$이 주어질 때 중학교 $N$학년 때 만든 암호 산술 수식을 풀어 주세요. 답은 합만 출력하면 됩니다. 예를 들어 $N=2$이면 `ビジツカン`에 해당하는 값을 출력합니다.

해가 여러 개라면 그중 하나만 출력하세요. 해를 여러 개 출력하면 오답입니다. 암호 산술 수식의 규칙은 [규칙](https://ja.wikipedia.org/wiki/覆面算)을 따릅니다.

## 입력

```text
$N$
```

$1 \leq N \leq 3$

## 출력

답을 한 줄에 출력하고 마지막에 줄바꿈을 넣으세요.
