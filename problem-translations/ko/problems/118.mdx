## 문제 설명

$N$개의 대나무 높이가 각각 $A_i$일 때, 그중 3개를 자유롭게 선택하고 자유롭게 배열할 수 있습니다. 이때 몇 가지 선택 조합이 카도마쓰 수열이 되는지 알고 싶습니다.

카도마쓰 수열은 선택한 3개의 길이를 내림차순으로 정렬했을 때 두 번째로 긴 것이 왼쪽 또는 오른쪽에 있고, 3개의 길이가 모두 다르다는 조건을 만족하는 것입니다.

$N$개 대나무의 높이가 주어질 때 카도마쓰 수열로 만들 수 있는 3개 선택 방법의 수를 구하세요. 배열 순서가 달라도 같은 대나무 조합이면 하나로 셉니다. 대나무에는 번호가 있어 서로 구별됩니다.

답이 int보다 커질 수 있으므로 $10^9+7$로 나눈 나머지를 구하세요.

## 입력

```text
N
A_1 A_2 ... A_N
```

모든 입력은 정수입니다. $(3 \le N \le 100\,000,\ 1 \le A_i \le 100)$

## 출력

카도마쓰 수열이 되는 조합 수를 $10^9+7$로 나눈 나머지로 출력하세요.

## 예제

```text
3
1 2 3
```

```text
1
```

이 3개의 대나무로 카도마쓰 수열을 만들 수 있습니다.

```text
6
1 2 2 3 3 3
```

```text
6
```

길이 2인 대나무와 길이 3인 대나무는 각각 구별되므로 선택 방법은 6가지입니다.

```text
10
13 54 87 47 99 33 2 56 95 85
```

```text
120
```

이 경우는 ${}_{10}C_3$와 같습니다.
