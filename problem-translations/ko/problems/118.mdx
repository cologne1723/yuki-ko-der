## 문제 설명

현관에 장식할 카도마쓰를 만들다가 한 가지 사실을 깨달았습니다.

$N$개의 대나무 높이가 각각 $A_i$일 때, 그중 $3$개를 자유롭게 선택하고 자유롭게 배열할 수 있습니다. 이때 몇 가지 선택 조합이 카도마쓰 수열이 되는지 알고 싶습니다.

카도마쓰 수열은 선택한 $3$개의 대나무를 배열했을 때 두 번째로 긴 대나무가 왼쪽 또는 오른쪽에 있고, $3$개의 길이가 모두 다른 수열입니다.

$N$개 대나무의 높이가 주어질 때 카도마쓰 수열로 만들 수 있는 $3$개 선택 방법의 수를 구하세요. 배열 순서가 달라도 같은 대나무 조합이면 하나로 셉니다. 대나무에는 번호가 있어 서로 구별됩니다.

답은 `int` 범위를 넘을 수 있지만 `long` 범위는 넘지 않는다고 합니다. 답을 $10^9+7$로 나눈 나머지를 구하세요.

## 입력

```text
$N$
$A_1\ A_2\ \dots\ A_N$
```

$N$은 대나무의 수이며, $A_1,\dots,A_N$은 각 대나무의 높이입니다. 모든 입력은 정수입니다.

## 제한

- $3 \le N \le 100\,000$
- $1 \le A_i \le 100$ $(1 \le i \le N)$

## 출력

카도마쓰 수열이 되는 조합 수를 $10^9+7$로 나눈 나머지로 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 2 3
```

#### 출력

```text
1
```

이 $3$개의 대나무로 카도마쓰 수열을 만들 수 있습니다.

### 예제 2 {file=""}

#### 입력

```text
6
1 2 2 3 3 3
```

#### 출력

```text
6
```

길이 $2$인 대나무와 길이 $3$인 대나무는 각각 구별되므로 선택 방법은 $6$가지입니다.

### 예제 3 {file=""}

#### 입력

```text
10
13 54 87 47 99 33 2 56 95 85
```

#### 출력

```text
120
```

이 경우는 ${}_{10}C_3$와 같습니다.
