## 문제 설명

$XY$ 좌표 평면 위에 서로 다른 정수 좌표의 점이 $N$개 주어집니다. 각 점에는 점수가 정해져 있습니다.

A君은 변이 $X$축과 $Y$축에 평행한 직사각형의 경계가 점과 겹치지 않게 하면서 가능한 많은 점을 둘러싸고 싶습니다. 단, 둘러싼 점들의 점수 합은 $B$ 이하이어야 합니다.

둘러쌀 수 있는 점 개수의 최댓값을 구하세요.

## 입력

```text
$N\ B$
$X_0\ Y_0\ P_0$
$X_1\ Y_1\ P_1$
$\vdots$
$X_{N-1}\ Y_{N-1}\ P_{N-1}$
```

점의 수 $N$과 점수 합의 상한 $B$가 주어집니다. 이어지는 $N$줄에 정수 좌표를 갖는 점의 정보가 주어지며, $X_i,Y_i$는 $i$번째 점의 좌표, $P_i$는 그 점의 점수입니다.

## 제한

- $1 \le N \le 400$
- $1 \le B \le 4\,000\,000$
- $-1\,000\,000\,000 \le X_i,Y_i \le 1\,000\,000\,000$
- $1 \le P_i \le 10\,000$
- $i \ne j$이면 $(X_i,Y_i) \ne (X_j,Y_j)$

## 출력

둘러쌀 수 있는 점 개수의 최댓값을 $1$줄에 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 3
-1 0 1
0 0 2
1 0 3
```

#### 출력

```text
2
```

점 $(-1,0),(0,0),(1,0)$의 점수는 각각 $1$점, $2$점, $3$점입니다. $(-1,0)$과 $(0,0)$의 점수 합은 $3$ 이하이므로 이 $2$개의 점을 직사각형으로 둘러쌀 수 있습니다.

### 예제 2 {file=""}

#### 입력

```text
3 3
-1 0 1
0 0 3
0 1 2
```

#### 출력

```text
1
```

점 $(-1,0)$, $(0,0)$, $(0,1)$의 점수는 각각 $1$점, $3$점, $2$점입니다. 이 $3$개의 점 중 어느 점이든 $1$개만 직사각형으로 둘러쌀 수 있습니다. 직사각형으로 둘러싼다는 것은 $(0,0)$을 둘러싸지 않고 $(-1,0)$과 $(0,1)$만 둘러싸는 것이 불가능하다는 뜻에 주의하세요.

### 예제 3 {file=""}

#### 입력

```text
5 3
-1 0 100
0 1 100
0 0 2
0 -1 100
1 0 100
```

#### 출력

```text
1
```

점이 $5$개 있습니다. 가운데 점 $1$개만 직사각형으로 둘러쌀 수 있습니다.
