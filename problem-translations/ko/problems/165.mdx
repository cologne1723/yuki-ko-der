## 문제 설명

$XY$ 좌표 평면 위에 서로 다른 정수 좌표의 점이 $N$개 주어집니다. 각 점에는 점수가 정해져 있습니다.

A는 변이 $X$축과 $Y$축에 평행한 직사각형으로 다른 점과 겹치지 않게 가능한 많은 점을 둘러싸고 싶습니다. 단, 둘러싼 점들의 점수 합은 $B$ 이하이어야 합니다.

둘러쌀 수 있는 점 개수의 최댓값을 구하세요.

## 입력

```text
N B
X_0 Y_0 P_0
X_1 Y_1 P_1
:
X_{N-1} Y_{N-1} P_{N-1}
```

- $1 \le N \le 400$
- $1 \le B \le 4{,}000{,}000$
- $-1{,}000{,}000{,}000 \le X_i,Y_i \le 1{,}000{,}000{,}000$
- $1 \le P_i \le 10{,}000$
- $i \ne j$이면 $(X_i,Y_i) \ne (X_j,Y_j)$

## 출력

둘러쌀 수 있는 점 개수의 최댓값을 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

```text
3 3
-1 0 1
0 0 2
1 0 3
```

```text
2
```

점 $(-1,0),(0,0),(1,0)$의 점수는 각각 1, 2, 3입니다. $(-1,0)$과 $(0,0)$의 점수 합은 3 이하이므로 이 두 점을 직사각형으로 둘러쌀 수 있습니다.

### 예제 2 {file=""}

```text
3 3
-1 0 1
0 0 3
0 1 2
```

```text
1
```

세 점 중 어느 한 점이든 하나만 직사각형으로 둘러쌀 수 있습니다. 직사각형으로 둘러싼다는 것은 $(0,0)$을 둘러싸지 않고 $(-1,0)$과 $(0,1)$만 둘러싸는 것이 불가능하다는 뜻에 주의하세요.

### 예제 3 {file=""}

```text
5 3
-1 0 100
0 1 100
0 0 2
0 -1 100
1 0 100
```

```text
1
```

가운데 점 하나만 직사각형으로 둘러쌀 수 있습니다.

### 예제 4 {file=""}

```text
12 345
-3 74 32
68 -19 9
46 2 48
-20 -42 24
18 3 85
-31 -76 8
-80 32 82
-47 74 34
68 2 37

```

```text
8
```
