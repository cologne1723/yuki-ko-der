## 문제 설명

입력으로 주어지는 정수 $A$, $B$에 대해 다항식 $Ax^B$를 $x^2+x+1$로 나눈 나머지를 구하세요.

## 입력

```text
$A\ B$
```

$A$, $B$는 정수입니다.

## 제한

- $-10^{18} \leq A \leq 10^{18}$
- $0 \leq B \leq 10^{18}$

## 출력

나눈 나머지를 $ax+b$로 나타낼 수 있을 때, $a\ b$를 반각 공백 $1$개로 구분하여 출력하고 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
10000 10000
```

#### 출력

```text
10000 0
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
20000 20000
```

#### 출력

```text
-20000 -20000
```
