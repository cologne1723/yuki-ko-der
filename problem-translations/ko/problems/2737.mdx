## 문제

문자열 `N`개 중 서로 다른 두 문자열 `S_i,S_j`를 골라 `S_iS_j`로 이어 붙입니다. 가능한 서로 다른 결과 문자열의 개수를 구하세요.

## 제약

- `2 ≤ N ≤ 50`
- 각 문자열은 길이 1 이상 100 이하의 소문자 문자열입니다.
- 문자열은 서로 다르고, 전체 길이 합은 300 이하입니다.

## 입력

```text
N
S_1
⋮
S_N
```

## 출력

답을 출력하세요.
