## 문제 설명

양의 정수 $M$이 주어집니다.

$2^{128}$을 $M$으로 나눈 나머지를 구하세요.

## 입력

```text
$M$
```

## 제한

$1 \le M < 2^{60}$

## 출력

$M$으로 나눈 나머지를 출력하고 줄 바꿈하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
0
```

$2^{128}$을 $1$로 나눈 나머지는 $0$입니다.

### 예제 2 {file=""}

#### 입력

```text
5
```

#### 출력

```text
1
```

$2^{128}$을 $5$로 나눈 나머지는 $1$입니다.

#### 출력

```text
4096
```
