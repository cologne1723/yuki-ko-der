## 문제 설명

$N$개의 숫자가 주어질 때 이를 $K$개의 그룹으로 나누세요. 각 그룹에는 숫자가 $1$개 이상 포함되어야 합니다.

예를 들어 숫자 $\{10,3,23,91,5\}$를 $K=3$개의 그룹으로 나눌 때 $\{\{3,91\},\{23,5\},\{10\}\}$은 올바르지만 $\{\{\},\{3,5,10\},\{23,91\}\}$은 허용되지 않습니다.

각 그룹의 평균을 구하고, 최댓값에서 최솟값을 뺀 뒤 소수점 이하를 올림한 값을 “평균의 차이”라고 합니다.
평균의 차이가 최대가 되도록 그룹을 나눌 때 평균의 차이를 구하세요.

## 입력

```text
$N$
$K$
$n_1$
$n_2$
$\vdots$
$n_N$
```

숫자의 개수 $N$, 그룹의 개수 $K$, 각 숫자 $n_i$가 위 형식으로 주어집니다.

## 제한

- $3 \le N \le 9$
- $3 \le K \le N$
- $1 \le n_i \le 1\,000$ $(1 \le i \le N)$

## 출력

답을 문자열로 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
3
555
20
432
301
21
```

#### 출력

```text
535
```

예를 들어 $\{\{555\},\{21,20\},\{432,301\}\}$로 나누면 평균은 $\{555/1,(21+20)/2,(432+301)/2\}=\{555,20.5,366.5\}$입니다.
평균의 최댓값과 최솟값의 차이는 $555-20.5=534.5$이고, 소수점 이하를 올리면 $535$입니다.


#### 출력
