## 문제

정점 1을 루트로 하는 무방향 루트 트리가 있습니다. 각 정점에는 돌이 놓여 있습니다. 번갈아 루트가 아닌 정점 중 돌이 하나 이상 있는 정점 `v`를 고르고, 그곳의 돌을 1개 이상 `K`개 이하 제거해 모두 부모 정점으로 옮깁니다.

더 이상 움직일 수 없게 된 사람이 패배합니다. 두 사람이 최선의 전략을 사용할 때 승자를 판정하세요.

## 제약

- `1 ≤ T ≤ 10^5`, `2 ≤ N ≤ 2×10^5`
- 모든 테스트 케이스의 `N` 합은 `2×10^5` 이하입니다.
- `1 ≤ K,A_i ≤ 10^9`

## 입력

```text
T
N K
X_1 Y_1
⋮
X_{N-1} Y_{N-1}
A_1 A_2 ... A_N
```

## 출력

코어가 이기면 `K`, 파체가 이기면 `P`를 출력하세요.
