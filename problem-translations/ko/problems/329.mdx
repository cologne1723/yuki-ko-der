## 문제

서로 다른 집합 $N$개 $A_1,\ldots,A_N$의 원소 수 $w_1,\ldots,w_N$와, $1\le i,j\le N$인 쌍 $(i,j)$의 집합 $E$가 주어집니다.

함수 $f:A_i\to A_j$가 “살아 있다”고 다음과 같이 정의합니다.

1. $i=j$이면 $f$는 살아 있습니다.
2. $(i,j)\in E$이면 $f$는 살아 있습니다.
3. $f:A_i\to A_j$, $g:A_j\to A_k$가 살아 있으면 합성 함수 $g\circ f$도 살아 있습니다.

1〜3으로 살아 있다고 알 수 있는 함수만 살아 있는 함수로 간주합니다.

살아 있는 함수 중 전사 함수의 개수를 출력하세요.

모든 입력에 대해 같은 출력을 내는 함수는 같은 함수로 간주합니다. 또한 집합 $A_1,\ldots,A_N$의 각 원소는 모두 다르다고 합니다.

## 입력

```text
N M
w_1 w_2 … w_N
i_1 j_1
⋮
i_M j_M
```

- $1 \le N \le 200$
- $0 \le M \le N^2$
- $1 \le w_k \le 1000$
- $1 \le i_k,j_k \le N$
- 서로 다른 $k$가 나타내는 쌍 $(i_k,j_k)$는 모두 다릅니다.

$w_k$는 집합 $A_k$의 원소 수이고, $(i_k,j_k)$는 $E$의 원소인 쌍입니다.

## 출력

살아 있는 전사 함수의 개수를 $10^9+7$로 나눈 나머지를 한 줄에 출력하세요.

마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
1 0
3
```

### 샘플 1 {file="sample1.out"}

```text
6
```

원소를 `{1,2,3}`이라고 하면 전사 함수가 6가지 있습니다.

### 샘플 2 {file="sample2.in"}

```text
3 4
2 1 2
1 2
2 1
2 3
3 2
```

### 샘플 2 {file="sample2.out"}

```text
7
```

$A_1\to A_1$의 전사가 2개, $A_1\to A_2$가 1개, $A_2\to A_2$가 1개, $A_3\to A_3$가 2개, $A_3\to A_2$가 1개이므로 합계 7개입니다. $A_1\to A_2$와 $A_2\to A_3$의 함수를 합성해 만든 $A_1\to A_3$ 함수는 전사가 아니라는 점에 주의하세요.

### 샘플 3 {file="sample3.in"}

```text
4 3
1 2 3 4
4 2
2 3
3 1
```

### 샘플 3 {file="sample3.out"}

```text
0
```
