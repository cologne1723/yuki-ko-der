양의 정수 $N,X$가 주어집니다. $0<A_1<A_2<\cdots<A_N$이고 합이 $X$인 수열이 존재하는지 판정하고, 존재하면 사전순으로 가장 작은 수열을 출력하세요.

## 조건

- $1\le T\le10^5$, $1\le N\le2\times10^5$, $1\le X\le10^{18}$
- 모든 테스트 케이스에서 $N$의 합은 $2\times10^5$ 이하입니다.

## 입력

```text
$T$
$N$ $X$
```

## 출력

각 테스트 케이스에 대해 가능한 수열을 공백으로 출력하고, 불가능하면 `-1`을 출력하세요.
