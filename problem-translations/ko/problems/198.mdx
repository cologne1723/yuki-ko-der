## 문제 설명

사탕이 들어 있는 상자가 $N$개 있습니다. $i$번째 상자에는 사탕이 $C_i$개 들어 있습니다. A君은 모든 상자의 사탕 수를 같게 해야 합니다. A君은 손에 사탕을 $B$개 가지고 있습니다.

A君이 할 수 있는 작업은 다음 $2$가지입니다.

- 손에 있는 사탕 $1$개를 원하는 상자에 넣습니다.
- 원하는 상자에서 사탕 $1$개를 꺼내 손에 가집니다.

A君은 가능한 한 작업 횟수를 줄이고 싶습니다. 필요한 최소 작업 횟수를 구하세요.

## 입력

```text
$B$
$N$
$C_1$
$C_2$
$\vdots$
$C_N$
```

## 제한

- $0 \le B \le 1\,000\,000\,000=10^9$
- $1 \le N \le 10$
- $0 \le C_i \le 1\,000\,000\,000=10^9$

## 출력

모든 상자의 사탕 수를 같게 만들기 위한 최소 작업 횟수를 $1$줄에 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
3
0
1
2
```

#### 출력

```text
2
```

A君은 처음에 사탕을 $1$개 가지고 있습니다. 상자가 $3$개 있고 각각 사탕이 $0$개, $1$개, $2$개 들어 있습니다. 손에 있는 사탕 $1$개를 빈 상자에 넣고, 사탕 $2$개인 상자에서 $1$개를 꺼내면 모든 상자가 $1$개가 됩니다.

### 예제 2 {file=""}

#### 입력

```text
1
3
0
0
1
```

#### 출력

```text
1
```

A君은 처음에 사탕을 $1$개 가지고 있습니다. 상자가 $3$개 있고 각각 사탕이 $0$개, $0$개, $1$개 들어 있습니다. 사탕 $1$개인 상자에서 $1$개를 꺼내 모든 상자를 $0$개로 만들 수 있습니다.

### 예제 3 {file=""}

#### 입력

```text
0
4
0
4
2
2
```

#### 출력

```text
4
```

사탕 $4$개인 상자에서 $2$개를 꺼내고, 손에 있는 $2$개를 사탕 $0$개인 상자에 넣으면 $4$번의 작업으로 모두 $2$개가 됩니다.

### 예제 4 {file=""}

#### 입력

```text
1000000000
1
1000000000
```

#### 출력

```text
0
```

작업을 할 필요가 없습니다.
