## 문제 설명

사탕이 들어 있는 상자가 $N$개 있습니다. $i$번째 상자에는 사탕이 $C_i$개 들어 있습니다. A는 모든 상자의 사탕 수를 같게 해야 합니다. A는 손에 사탕을 $B$개 가지고 있습니다.

A가 할 수 있는 작업은 다음 두 가지입니다.

- 손에 있는 사탕 1개를 원하는 상자에 넣습니다.
- 원하는 상자에서 사탕 1개를 꺼내 손에 가집니다.

A는 작업 횟수를 가능한 한 줄이고 싶습니다. 필요한 최소 작업 횟수를 구하세요.

## 입력

```text
B
N
C_1
C_2
:
C_N
```

- $0 \le B \le 10^9$
- $1 \le N \le 10$
- $0 \le C_i \le 10^9$

## 출력

모든 상자의 사탕 수를 같게 만들기 위한 최소 작업 횟수를 출력하세요.

## 예제

### 예제 1 {file=""}

```text
1
3
0
1
2
```

```text
2
```

손에 있는 사탕 1개를 빈 상자에 넣고, 사탕 2개인 상자에서 1개를 꺼내면 모든 상자가 1개가 됩니다.

### 예제 2 {file=""}

```text
1
3
0
0
1
```

```text
1
```

사탕 1개인 상자에서 1개를 꺼내 모든 상자를 0개로 만들 수 있습니다.

### 예제 3 {file=""}

```text
0
4
0
4
2
2
```

```text
4
```

사탕 4개인 상자에서 2개를 꺼내고, 손에 있는 2개를 사탕 0개인 상자에 넣으면 네 번의 작업으로 모두 2개가 됩니다.

### 예제 4 {file=""}

```text
1000000000
1
1000000000
```

```text
0
```
