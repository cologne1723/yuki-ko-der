정수 $a,p,q$가 주어집니다. $a(x-p)(x-q)=ax^2+bx+c$가 다항식으로 같을 때의 정수 $b,c$에 대해 $b^2>4ac$인지 판정하세요.

## 조건

- 입력 정수의 자릿수는 최대 $10^5$입니다.
- $a\ne0$입니다.

## 입력

```text
a p q
```

## 출력

조건을 만족하면 `Yes`, 아니면 `No`를 출력하세요.
