## 문제

등차수열을 매우 좋아하는 리안 군은 길이 $N$인 수열을 길에서 주웠습니다. 수열의 각 원소를 바꿀 수 있는 수열 할아버지에게 부탁해 이 수열을 등차수열로 만들기로 했습니다.

할아버지는 수열의 $i$번째 원소 $a_i$를 $b_i$로 바꾸는 데 $(a_i-b_i)^2$의 비용을 요구합니다. 각 원소는 최대 한 번만 바꿉니다.

예를 들어 $\{3,3,4\}$를 $\{5,5,5\}$로 바꾸는 비용은 $4+4+1=9$, $\{3,3.5,4\}$로 바꾸는 비용은 $0+0.25+0=0.25$입니다.

비용이 최소가 되도록 바꾼 등차수열의 초항 $b_1$, 공차 $d$, 비용 $c$를 구하세요.

## 입력

~~~text
$N$
$a_1\ a_2\ \ldots\ a_N$
~~~

첫째 줄에 수열의 원소 수 $N$이 주어지고, 둘째 줄에 각 원소 $a_i$가 공백으로 주어집니다.

- $2\leq N\leq1000$
- $0\leq a_i\leq10^5$

입력은 모두 정수입니다.

## 출력

첫째 줄에 최적 등차수열의 초항 $b_1$과 공차 $d$를 공백으로 출력하고, 둘째 줄에 비용 $c$를 출력하세요. 각 값의 오차는 $10^{-6}$ 이하이면 허용됩니다. 마지막에는 줄바꿈을 추가하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
3
3 3 4
~~~

#### 출력

~~~text
2.83333333333333 0.5
0.166666666666667
~~~

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
5
0 0 0 0 10000
~~~

#### 출력

~~~text
-2000 2000
40000000
~~~

$b_1$이 음수가 될 수도 있습니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
7
6 5 4 3 2 1 0
~~~

#### 출력

~~~text
6 -1
0
~~~

$d$가 음수가 되거나 $c$가 0이 될 수도 있습니다.
