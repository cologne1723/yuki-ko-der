## 문제 설명

$A+B$를 계산하세요.

하지만 `+`가 싫으므로 `+`를 사용해서는 안 됩니다. 소스 코드에 `+` 문자가 있으면 오답입니다.

템플릿에서 `+`를 사용하는 사람은 주의하세요. 특히 입력 처리나 C++의 `bits/stdc++.h`를 사용할 때 조심해야 합니다.

## 입력

```text
$A\ B$
```

$1$번째 줄에 $A$와 $B$가 공백으로 구분되어 주어집니다.

## 제한

$0\le A,B\le10^9$

## 출력

$A+B$의 결과를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 2
```

#### 출력

```text
3
```

### 예제 2 {file=""}

#### 입력

```text
765 346
```

#### 출력

```text
1111
```
