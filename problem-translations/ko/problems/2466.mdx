음이 아닌 정수 $N$에 대해 다음 무한 중첩 제곱근의 값을 구하세요.

$$\sqrt{1+N\sqrt{1+(N+1)\sqrt{1+(N+2)\sqrt{\cdots}}}}$$

## 조건

- $0\le N\le10^9$

## 입력

```text
N
```

## 출력

값을 출력하세요.
