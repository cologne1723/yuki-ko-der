## 문제 설명

$N$행 $M$열의 격자에서 $i$행 $j$열에 있는 칸을 $(i,j)$라고 합니다.

다음 연산을 반복하여 모든 칸의 색을 흰색으로 만들 수 있는 색칠된 격자를 **좋은 격자**라고 정의합니다.

- 다음 $4$가지 도형 중 $1$개로 둘러싸이는 $3$개의 칸을 선택하여 해당 칸들의 색을 반전합니다. **단, 도형은 회전할 수 없습니다.**

![색을 반전할 수 있는 $4$가지 도형](https://cdn-ak.f.st-hatena.com/images/fotolife/m/milkcoffeen/20240719/20240719104642.jpg)

엄밀히 말하면 다음 연산 중 $1$가지를 수행합니다.

- 정수 $x,y$ ($1 \leq x \leq N-2$, $1 \leq y \leq M$)를 선택하고, $3$개의 칸 $(x,y),(x+1,y),(x+2,y)$의 색을 반전합니다.
- 정수 $x,y$ ($1 \leq x \leq N$, $1 \leq y \leq M-2$)를 선택하고, $3$개의 칸 $(x,y),(x,y+1),(x,y+2)$의 색을 반전합니다.
- 정수 $x,y$ ($1 \leq x \leq N-1$, $1 \leq y \leq M-1$)를 선택하고, $3$개의 칸 $(x,y),(x+1,y),(x+1,y+1)$의 색을 반전합니다.
- 정수 $x,y$ ($1 \leq x \leq N-1$, $1 \leq y \leq M-1$)를 선택하고, $3$개의 칸 $(x,y),(x,y+1),(x+1,y+1)$의 색을 반전합니다.

$N$행 $M$열의 격자가 주어집니다. 주어지는 격자의 각 칸은 흰색 또는 검은색으로 칠해져 있거나, 아직 색칠되지 않았습니다.

$S_{i,j}$가 `W`, `B`이면 $(i,j)$는 각각 흰색, 검은색으로 칠해진 칸이고, `?`이면 색칠되지 않은 칸입니다.

주어지는 격자에서 색칠되지 않은 각 칸을 흰색 또는 검은색으로 칠하는 방법 중, 칠한 후의 격자가 **좋은 격자**가 되는 방법의 수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ M$
$S_{1,1}S_{1,2}\cdots S_{1,M}$
$\vdots$
$S_{N,1}S_{N,2}\cdots S_{N,M}$
```

## 제한

- $3 \leq N,M \leq 500$
- $N,M$은 정수입니다.
- $S_{i,j}$는 `W`, `B`, `?` 중 $1$개입니다.

## 출력

답을 정수로 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 4
??BW
WBBW
WWWW
```

#### 출력

```text
1
```

$(1,1),(1,2)$의 $2$개 칸이 색칠되지 않은 칸이므로, 색칠 방법은 모두 $2^2=4$가지입니다.

$(1,1)$을 검은색, $(1,2)$를 흰색으로 칠하면 다음 그림과 같이 $2$번의 연산으로 모든 칸을 흰색으로 만들 수 있으므로 좋은 격자입니다.

![예제 1의 연산](https://cdn-ak.f.st-hatena.com/images/fotolife/m/milkcoffeen/20240720/20240720005543.png)

좋은 격자가 되는 색칠 방법은 이 $1$가지뿐입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 3
WWW
WBW
BBW
```

#### 출력

```text
0
```

주어지는 격자는 좋은 격자가 아닙니다. 색을 반전하는 도형은 회전할 수 없다는 점에 주의하세요.
