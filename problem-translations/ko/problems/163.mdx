## 이야기

Zelda는 어제 PC에 비밀번호를 설정했습니다.

오늘 PC를 켠 뒤 어제 입력한 비밀번호로 로그인할 수 없다는 것을 알아차렸습니다. 생각해 보니 Caps Lock이 켜진 상태인 것을 모르고 입력한 것 같습니다. 입력 중에는 비밀번호가 `*`로 가려져 표시되어 알아차리지 못했습니다.

## 문제 설명

비밀번호에는 대문자와 소문자의 반각 영문 알파벳 $52$종만 사용합니다. Caps Lock은 입력한 알파벳이 소문자이면 대문자로, 대문자이면 소문자로 입력되게 하는 기능입니다.

어제 입력했어야 하는 비밀번호가 주어질 때, 실수로 설정된 현재 비밀번호를 출력하세요.

## 입력

```text
$S$
```

$S$는 대문자 또는 소문자 반각 영문 알파벳 $52$종으로 이루어진 문자열입니다.

## 제한

- $1 \le |S| \le 100$

## 출력

실수로 설정된 현재 비밀번호를 $1$줄에 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
CapsLock
```

#### 출력

```text
cAPSlOCK
```

Caps Lock을 켠 채 `CapsLock`을 입력하면 이렇게 됩니다.

키 자체의 존재 의의가 의심받고 있다는 사실은 어둠의 힘 때문에 언급해서는 안 됩니다.

참고로 Mac에서는 Shift를 눌러도 소문자가 되지 않습니다.

### 예제 2 {file=""}

#### 입력

```text
ABCdef
```

#### 출력

```text
abcDEF
```

### 예제 3 {file=""}

```text
A
```

#### 출력
