## 문제 설명

서로 다른 네 점의 정수 좌표가 주어졌습니다. 모눈종이에 이 네 점을 꼭짓점으로 하는 정사각형을 그리는 것이 할 일입니다.

하지만 네 점 중 한 점의 좌표를 잃어버렸습니다. 나머지 세 점의 좌표가 주어질 때, 한 점을 추측하여 정사각형을 그릴 수 있다면 그 점의 좌표를 출력하세요. 정사각형을 만들 수 없다면 $-1$을 출력하세요.

## 입력

```text
$X_1\ Y_1\ X_2\ Y_2\ X_3\ Y_3$
```

세 점의 좌표 $(X_1,Y_1)$, $(X_2,Y_2)$, $(X_3,Y_3)$가 공백으로 구분되어 주어집니다. 모든 좌표는 정수입니다.
세 점은 서로 다른 좌표이며, 각각 정사각형의 어느 꼭짓점인지는 알 수 없습니다.

## 제한

$-100 \le X_1,Y_1,X_2,Y_2,X_3,Y_3 \le 100$

## 출력

정사각형을 만들 수 있는 나머지 한 점 $(X_4,Y_4)$를 $X_4$, $Y_4$ 순서로 한 줄에 출력하세요. $X_4$와 $Y_4$ 사이에는 공백을 넣습니다.
정사각형을 만들 수 없다면 $-1$만 한 줄에 출력하세요. 어느 경우든 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0 0 1 0 0 1
```

#### 제한

$-100 \le X_1,Y_1,X_2,Y_2,X_3,Y_3 \le 100$

## 출력

```text
1 1
```

$(0,0)$, $(1,0)$, $(0,1)$이 주어졌습니다. 나머지 점을 $(1,1)$로 정하면 변의 길이가 $1$인 정사각형을 만들 수 있습니다.

### 예제 2 {file=""}

#### 입력

```text
0 0 2 0 2 1
```

#### 제한

$-100 \le X_1,Y_1,X_2,Y_2,X_3,Y_3 \le 100$

## 출력

```text
-1
```

직사각형은 만들 수 있지만 정사각형은 만들 수 없으므로 $-1$입니다.

### 예제 3 {file=""}

#### 입력

```text
1 2 2 -1 -1 -2
```

#### 제한

$-100 \le X_1,Y_1,X_2,Y_2,X_3,Y_3 \le 100$

## 출력

```text
-2 1
```

정사각형의 변은 $x$축이나 $y$축과 평행하지 않아도 됩니다.

### 예제 4 {file=""}

#### 입력

```text
8 10 14 14 13 9
```

#### 제한

$-100 \le X_1,Y_1,X_2,Y_2,X_3,Y_3 \le 100$

## 출력

```text
9 15
```
