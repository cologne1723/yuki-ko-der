## 문제

음이 아닌 정수 A와 B의 비트별 배타적 논리합이 음이 아닌 정수 C라는 것을 알고 있습니다.

A와 C가 주어질 때 B가 무엇이었는지 답하세요.

배타적 논리합에 대한 설명은 다음 링크를 참고할 수 있습니다.

https://ja.wikipedia.org/wiki/%E6%8E%92%E4%BB%96%E7%9A%84%E8%AB%96%E7%90%86%E5%92%8C

## 입력

```text
A C
```

A와 C는 음이 아닌 정수입니다. 0 ≤ A,C ≤ 1000000000000 = 10^12

## 출력

음이 아닌 정수 B를 한 줄에 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
1 3
```

출력:

```text
2
```

1과 배타적 논리합을 취해 3이 되는 수는 2입니다.
