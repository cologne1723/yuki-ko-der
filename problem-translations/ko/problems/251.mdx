## 문제

정수 $N$과 $M$이 주어질 때 $N^M$을 129402307로 나눈 나머지를 출력하세요. 129402307은 소수입니다.

## 입력

```text
N
M
```

첫째 줄에 정수 $N$, 둘째 줄에 정수 $M$이 주어집니다.

- $0 \leq N < 10^{100000}$
- $0 \leq M < 10^{100000}$
- $N=0$이고 $M=0$인 입력은 주어지지 않습니다.

## 출력

계산 결과를 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

```text
2
8
```

### 출력 1 {file="stdout"}

```text
256
```

$2^8=256$입니다.

### 입력 2 {file="stdin"}

```text
7382974343
3432476397
```

### 출력 2 {file="stdout"}

```text
27853659
```

### 입력 3 {file="stdin"}

```text
129402306
129402306
```

### 출력 3 {file="stdout"}

```text
1
```

$129402306^{129402306}$을 129402307로 나눈 나머지는 1입니다.
