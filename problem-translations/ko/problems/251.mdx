## 문제 설명

정수 $N$과 $M$이 주어질 때 $N^M$을 $129\,402\,307$로 나눈 나머지를 출력하세요. $129\,402\,307$은 소수입니다.

## 입력

```text
$N$
$M$
```

$1$번째 줄에 정수 $N$, $2$번째 줄에 정수 $M$이 주어집니다.

## 제한

- $0 \leq N < 10^{100\,000}$
- $0 \leq M < 10^{100\,000}$
- $N=0$이고 $M=0$인 입력은 주어지지 않습니다.

## 출력

계산 결과를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
8
```

#### 출력

```text
256
```

$2^8=256$입니다.

### 예제 2 {file=""}

#### 입력

```text
7382974343
3432476397
```

#### 출력

```text
27853659
```

### 예제 3 {file=""}

#### 입력

```text
129402306
129402306
```

#### 출력

```text
1
```

$129\,402\,306^{129\,402\,306}$을 $129\,402\,307$로 나눈 나머지는 $1$입니다.
