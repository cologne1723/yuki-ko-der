각 테스트 케이스의 $N,K$에 대해 $N\ge a_1\ge\cdots\ge a_k\ge0$인 모든 정수열의 다음 값의 합 $f(k)$를 정의합니다.

$$\binom N{a_1}\binom{a_1}{a_2}\cdots\binom{a_{k-1}}{a_k}$$

$\sum_{k=1}^K f(k)$를 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
T
N K
```

## 출력

각 테스트 케이스의 답을 출력하세요.
