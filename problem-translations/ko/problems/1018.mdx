## 문제 설명

길이가 $N$인 문자열 $S$와 양의 정수 $M$, 길이가 $Q$인 수열 $K_1,\ldots,K_Q$가 주어집니다.

문자열 $S$를 $M$번 반복하여 만든 문자열을 $T$라고 합니다. $T$의 접미사 $T_1,T_2,\ldots,T_{NM}$을 사전순으로 정렬했을 때, $K_1,\ldots,K_Q$번째 접미사를 구하세요.

단, $T$의 접미사 $T_i$란 $T$의 $i$번째 문자부터 끝까지의 부분 문자열이라고 합니다.

## 입력

```text
$N\ M\ Q$
$S$
$K_1\ K_2\ \ldots\ K_Q$
```

입력은 모두 정수 또는 문자열로 주어집니다.

## 제한

- $1 \le N \le 100\,000$
- $1 \le M \le 1\,000\,000\,000$
- $1 \le Q \le \min(NM, 100\,000)$
- $S$는 영소문자 알파벳으로 이루어진 길이 $N$인 문자열입니다.
- $K_i$는 양의 정수이며, $1 \le K_1 < K_2 < \cdots < K_Q \le NM$을 만족합니다.

## 출력

각 $i$에 대해 $K_i$번째 접미사가 $T_{n_i}$가 되도록 하는 $n_i$를 구하여 공백으로 구분해 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4 2 8
puyo
1 2 3 4 5 6 7 8
```

#### 출력

```text
8 4 5 1 6 2 7 3
```

$T = \text{puyopuyo}$입니다. 접미사를 사전순으로 정렬하면 다음 순서가 됩니다.

- $T_8 = \text{o}$
- $T_4 = \text{opuyo}$
- $T_5 = \text{puyo}$
- $T_1 = \text{puyopuyo}$
- $T_6 = \text{uyo}$
- $T_2 = \text{uyopuyo}$
- $T_7 = \text{yo}$
- $T_3 = \text{yopuyo}$
