## 문제 설명

길이가 $N$인 수열 $x_1, x_2, \dots, x_N$이 주어집니다. $1 \le k \le N$을 만족하는 각 정수 $k$에 대해, $\sum_{i=1}^k \sqrt{x_i}$를 구하세요.

허용 오차가 매우 엄격하게 설정되어 있으므로 주의하세요. 입출력의 양이 많으므로 빠른 입출력을 사용하세요. C, C++, Python3 이외의 언어에서는 AC를 얻지 못할 수도 있습니다. $20$MB 이상 출력하면 OLE가 되므로 주의하세요.

## 입력

```text
$N$
$x_1$
$x_2$
$\vdots$
$x_N$
```

입력은 모두 정수입니다.

## 제한

- $1 \le N \le 10^6$
- $0 \le x_i < 10^{18}$

## 출력

정답으로 인정되려면 절대 오차와 상대 오차 중 작은 값이 $10^{-15}$ 이하여야 합니다.

$N$줄 출력하세요. $k$번째 줄에는 $\sum_{i=1}^k \sqrt{x_i}$를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
3
4
5
```

#### 출력

```text
1.73205080756887729
3.73205080756887729
5.96811878506866699
```

$1$번째 줄은 $\sqrt{3}$, $2$번째 줄은 $\sqrt{3}+\sqrt{4}$, $3$번째 줄은 $\sqrt{3}+\sqrt{4}+\sqrt{5}$입니다. 절대 오차와 상대 오차 중 작은 값이 $10^{-15}$ 이하이면 정답으로 인정됩니다.

```text

```
