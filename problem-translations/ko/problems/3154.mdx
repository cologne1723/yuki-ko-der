## 문제 설명

$2$차원 좌표 평면 위에 서로 다른 위치에 $N$개의 점이 있습니다. $i$번째 점($1 \leq i \leq N$)의 좌표는 $(X_i,Y_i)$입니다.

처음에는 선분이 $1$개도 그어져 있지 않습니다. 서로 다른 $2$개의 점을 적절히 선택하여 선분으로 잇는 조작을 $N$번 반복해서 엄밀히 볼록한 $N$각형을 만들 수 있는지 판정하세요.

엄밀히 볼록한 $N$각형이란 모든 내각이 $180$도 미만인 $N$각형 $(3 \leq N)$을 말합니다. 내각이 $180$도인 꼭짓점이 있는 경우에 주의하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$X_1\ Y_1$
$X_2\ Y_2$
$\vdots$
$X_N\ Y_N$
```

각 좌표 행의 $X_i$, $Y_i$는 $i$번째 점의 좌표를 나타내는 정수입니다.

## 제한

- $3 \leq N \leq 2 \times 10^{5}$
- $0 \leq X_i,Y_i \leq 10^{9}$ $(1 \leq i \leq N)$
- $i \neq j$이면 $(X_i,Y_i) \neq (X_j,Y_j)$
- 입력은 모두 정수입니다.

## 출력

엄밀히 볼록한 $N$각형을 만들 수 있다면 `Yes`를, 그렇지 않다면 `No`를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
0 0
4 0
3 3
0 4
```

#### 출력

```text
Yes
```

점 $1$과 점 $4$, 점 $4$와 점 $3$, 점 $3$과 점 $2$, 점 $2$와 점 $1$을 이으면 볼록 $4$각형을 만들 수 있습니다. 따라서 `Yes`를 출력하세요.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
4
0 0
1 1
4 0
0 4
```

#### 출력

```text
No
```

어떻게 선분을 이어도 볼록 $4$각형을 만들 수 없습니다. 따라서 `No`를 출력하세요.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
5
0 0
2 0
4 0
3 3
0 4
```

#### 출력

```text
No
```

점 $1$과 점 $2$, 점 $2$와 점 $3$, 점 $3$과 점 $4$, 점 $4$와 점 $5$, 점 $5$와 점 $1$을 이으면 볼록 다각형을 만들 수 있습니다. 그러나 점 $1$, 점 $2$, 점 $3$이 일직선상에 있고 점 $2$는 $5$각형의 꼭짓점이라고 할 수 없으므로, 이는 볼록 $4$각형이 됩니다.

이 외에는 어떻게 선분을 그어도 볼록 $5$각형을 만들 수 없습니다. 따라서 `No`를 출력하세요.
