`(a,b)` 라이더는 두 좌표 차가 `a,b`인 여러 방향으로 한 번에 이동합니다. `N x N` 장기판에 라이더 3개를 놓아 `A->B->C->A`를 각각 한 수에 이동할 수 있고 세 위치가 일직선이 아니게 하는 배치의 개수를 구하세요.

## 입력

`N a b`가 주어집니다.

## 출력

조건을 만족하는 배치의 개수를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 2 20
```

#### 출력

```text
960
```

### 예제 2 {file=""}

#### 입력

```text
1 1 9
```

#### 출력

```text
0
```

### 예제 3 {file=""}

#### 입력

```text
0 0 9
```

#### 출력

```text
0
```

### 예제 4 {file=""}

#### 입력

```text
123 456 1000000000
```

#### 출력

```text
110827630
```
