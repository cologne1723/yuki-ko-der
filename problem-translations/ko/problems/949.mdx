## 문제 설명

ken 씨와 koo 씨는 둘이 팀을 이루어 「음주 경쟁 프로그래밍 콘테스트 (Inshu Competitive Programming Contest; **ICPC**)」에 참가하기로 했습니다.

ICPC는 $N$개의 문제로 이루어진 콘테스트이며, 다음 행동을 몇 번 수행하여 가능한 한 많은 문제를 풀려고 합니다.

- 팀원 중 한 명이 술을 마신 뒤, 아직 풀지 않은 문제를 하나 골라 풉니다.

각 팀원의 **기여도**가 정해져 있습니다. ken 씨가 $i$번 술을 마신 직후의 기여도는 $A_i$이고, koo 씨가 $i$번 술을 마신 직후의 기여도는 $B_i$입니다. $0 \le i \le N$입니다.

각 문제의 **난이도**도 정해져 있습니다. $i$번째 문제의 난이도는 $D_i$입니다. $1 \le i \le N$입니다. 난이도가 $D_i$인 문제는 그 시점의 팀원 기여도 합이 $D_i$ 이상이면 풀 수 있습니다.

각 팀원의 기여도와 각 문제의 난이도가 주어질 때, 최적 전략으로 풀 수 있는 문제 수의 최댓값을 구하세요.

## 입력

```text
$N$
$A_0\ A_1\ \ldots\ A_N$
$B_0\ B_1\ \ldots\ B_N$
$D_1\ D_2\ \ldots\ D_N$
```

첫 번째 줄에 문제의 개수를 나타내는 정수 $N$이 주어집니다.

두 번째 줄에 $N+1$개의 정수가 공백으로 구분되어 주어집니다. 그중 $i+1$번째 정수 $A_i$는 ken 씨가 $i$번 술을 마신 직후의 기여도입니다. $0 \le i \le N$입니다.

세 번째 줄에 $N+1$개의 정수가 공백으로 구분되어 주어집니다. 그중 $i+1$번째 정수 $B_i$는 koo 씨가 $i$번 술을 마신 직후의 기여도입니다. $0 \le i \le N$입니다.

네 번째 줄에 $N$개의 정수가 공백으로 구분되어 주어집니다. 그중 $i$번째 정수 $D_i$는 $i$번째 문제의 난이도입니다. $1 \le i \le N$입니다.

입력은 총 $4$줄이며 다음 제한을 만족합니다.

## 제한

- 입력은 모두 정수입니다.
- $1 \le N \le 3\,000$
- $-10^5 \le A_i, B_i \le 10^5$ ($0 \le i \le N$)
- $A_i \ge A_{i+1}$ ($0 \le i < N$)
- $B_i \ge B_{i+1}$ ($0 \le i < N$)
- $1 \le D_i \le 2 \times 10^5$ ($1 \le i \le N$)

## 출력

풀 수 있는 문제 수의 최댓값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
5 3 0 -1 -2
5 4 1 0 -3
5 7 4 8
```

#### 출력

```text
3
```

예를 들어 다음과 같이 행동하면 문제를 $3$개 풀 수 있습니다.

- koo 씨가 술을 마십니다. 기여도 합은 $5 + 4 = 9$가 됩니다. 그리고 $4$번째 문제를 풉니다.
- ken 씨가 술을 마십니다. 기여도 합은 $3 + 4 = 7$이 됩니다. 그리고 $1$번째 문제를 풉니다.
- ken 씨가 술을 마십니다. 기여도 합은 $0 + 4 = 4$가 됩니다. 그리고 $3$번째 문제를 풉니다.
