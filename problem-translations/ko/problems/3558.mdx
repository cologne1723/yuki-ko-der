## 문제 설명

세로 $N$행, 가로 $2N$열의 칸으로 이루어진 격자가 있습니다.

각 칸은 흰색 또는 검은색으로 칠해져 있으며, 전체적으로 흰색 칸은 정확히 $N^2$개이고 검은색 칸도 정확히 $N^2$개입니다.

위에서 $i$번째 행($1 \leq i \leq N$), 왼쪽에서 $j$번째 열($1 \leq j \leq 2N$)에 있는 칸의 색은 문자 $S_{i,j}$로 나타냅니다. $S_{i,j}$가 `.`이면 흰색을, `#`이면 검은색을 의미합니다.

다음 조작을 $0$회 이상 원하는 횟수만큼 수행할 수 있습니다.

- 변을 공유하며 인접하고 색이 서로 다른 $2$개의 칸을 선택하고, 선택한 칸의 색을 서로 바꿉니다.

격자의 왼쪽 절반($1 \leq j \leq N$)에 있는 모든 칸을 흰색으로, 오른쪽 절반($N+1 \leq j \leq 2N$)에 있는 모든 칸을 검은색으로 만드는 것이 목표입니다.

목표를 달성하기 위해 필요한 조작 횟수의 최솟값을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$S_1$
$S_2$
$\vdots$
$S_N$
```

$S_i$는 길이 $2N$인 문자열이며, `.`과 `#`으로 이루어져 있습니다.

## 제한

- $1 \leq N \leq 1\,000$
- $N$은 정수입니다.
- $S_i$는 `.`과 `#`으로 이루어진 길이 $2N$의 문자열입니다.
- 격자 전체에 `.`과 `#`이 각각 정확히 $N^2$개 있습니다.

다음과 같은 부분점이 설정되어 있습니다.

| 부분점 | 배점 | 제한 |
| --- | ---: | --- |
| 부분점 | $10$% ($20$점) | $N \leq 3$ |
| 만점 | $90$% ($180$점) | 추가 제한 없음 |

## 출력

목표를 달성하기 위해 필요한 조작 횟수의 최솟값을 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
#.
```

#### 출력

```text
1
```

조작을 $1$회 수행하면 목표를 달성할 수 있습니다.

#### 입력

```text

..##
..##
```

#### 출력

```text

```

처음부터 목표를 달성했으므로 조작할 필요가 없습니다.

```text
3
.#.###
#.#...
##..#.
```

#### 출력
