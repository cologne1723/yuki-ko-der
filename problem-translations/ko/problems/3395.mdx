## 문제 설명

`A`, `B`로 이루어진 길이 $N$의 문자열 $S$가 주어집니다.

Alice さん과 Bob さん은 $S$를 사용해 게임을 합니다. 다음 동작을 Alice さん, Bob さん 순서로 **정확히 $1$번씩** 수행합니다.

- 다음 중 $1$개를 수행합니다.
  - $1 \leq l \leq r \leq N$을 만족하는 정수쌍 $(l,r)$을 $1$개 고릅니다. $S$의 $l$번째 문자부터 $r$번째 문자까지 각각에 대해 `A`를 `B`로, `B`를 `A`로 바꿉니다.
  - 아무것도 하지 않습니다.

Alice さん의 목표는 최종 $S$를 사전순으로 가능한 한 작게 만드는 것이고, Bob さん의 목표는 최종 $S$를 사전순으로 가능한 한 크게 만드는 것입니다.

$2$명이 최선의 플레이를 했을 때의 최종 $S$를 구하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

### 최선의 플레이란?

`A`와 `B`로 이루어진 길이 $N$의 문자열 $X$ 중 다음 조건을 모두 만족하는 것은 정확히 $1$개 존재한다는 것을 증명할 수 있습니다.

- Bob さん이 어떤 동작을 하더라도 Alice さん이 적절히 게임을 진행하면 최종 $S$를 사전순으로 $X$ 이하로 만들 수 있습니다.
- Alice さん이 어떤 동작을 하더라도 Bob さん이 적절히 게임을 진행하면 최종 $S$를 사전순으로 $X$ 이상으로 만들 수 있습니다.

이 $X$를 $2$명이 최선의 플레이를 했을 때의 최종 $S$로 정의합니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $t$번째 ($1 \leq t \leq T$) 테스트 케이스를 $\mathrm{case}_t$라고 합니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$S$
```

각 테스트 케이스의 $1$번째 줄에 $N$이 주어집니다.

$2$번째 줄에 `A`와 `B`로 이루어진 길이 $N$의 문자열 $S$가 주어집니다.

## 제한

- $1 \leq T \leq 125\,000$
- $1 \leq N \leq 250\,000$
- $S$는 `A`와 `B`로 이루어진 길이 $N$의 문자열입니다.
- $T$, $N$은 정수입니다.
- $1$개의 입력 파일에서 $N$의 합은 $500\,000$을 넘지 않습니다.

## 출력

$T$줄 출력합니다. $t$번째 줄 ($1 \leq t \leq T$)에는 $t$번째 테스트 케이스의 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
8
ABABBBAB
1
A
16
AAAABBBBAAAABBBB
```

#### 출력

```text
BBAAAAAB
B
BBAABBBBAAAABBBB
```

$1$번째 테스트 케이스에서는 예를 들어 다음과 같이 게임이 진행됩니다.

- Alice さん이 $(l,r)=(4,6)$을 고릅니다. $S$가 `ABAAAAAB`로 바뀝니다.
- Bob さん이 $(l,r)=(1,1)$을 고릅니다. $S$가 `BBAAAAAB`로 바뀝니다.

$2$번째 테스트 케이스에서는 Alice さん이 어떤 동작을 하더라도 Bob さん은 $S$를 `B`로 만들 수 있습니다.
