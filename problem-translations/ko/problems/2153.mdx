Discord 서버에서 $N$번의 색상 신고가 시간순으로 주어진다냥. 각 신고는 신고자의 이름 $S_i$와 색 $C_i$로 이루어진다냥. 같은 사람이 여러 번 신고하면 가장 최근 신고가 우선한다냥. 최종적으로 각 색의 코더가 몇 명인지 구하라냥. 색은 $0,1,\ldots,7$의 8종류이다냥.

## 조건

- $1\le N\le2\times10^3$
- $1\le|S_i|\le2\times10^2$
- 이름은 영문 대소문자로만 이루어진다냥.
- $0\le C_i\le7$

## 입력

```text
N
S_1 C_1
\vdots
S_N C_N
```

## 출력

색 $0$부터 $7$까지에 해당하는 코더 수를 각각 한 줄에 출력하라냥.
