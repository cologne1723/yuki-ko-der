미세계 수식의 기호 `$`를 덧셈 또는 뺄셈으로, `&`를 곱셈 또는 버림 나눗셈으로 바꾸어 올바른 우리 세계의 수식을 만드세요. 연산 우선순위와 왼쪽 결합 규칙은 일반 수식과 같고, 계산 중 값은 $0$ 이상 $M$ 이하입니다.

## 입력

```text
M ans
expr
```

주어진 식은 미세계에서 `expr=ans`를 나타내며 $1\le M\le300$, 식 길이는 $1000$ 이하입니다.

## 출력

가능한 수식 하나를 출력하고, 없으면 `-1`을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
100 21
1$2&3$4&5
```

#### 출력

```text
1+2/3+4*5
```

### 예제 2 {file=""}

#### 입력

```text
100 51
2&51&2
```

#### 출력

```text
-1
```

### 예제 3 {file=""}

#### 입력

```text
100 0
2&(4$3)
```

#### 출력

```text
2/(4+3)
```

### 예제 4 {file=""}

#### 입력

```text
300 0
150$200
```

#### 출력

```text
-1
```
