## 문제 설명

이 문제는 배열에 여러 조작을 수행한 뒤 최종 배열을 구하는 문제입니다. 배열의 값이 매우 커질 수 있으므로 각 원소가 짝수인지 홀수인지만 출력하세요.

경고: 의도한 C++ 구현은 약 1초(967ms)에 실행됩니다. 다른 언어에서는 의도한 해법과 같은 방법을 사용하면 시간 초과가 발생할 수 있습니다. 의도한 해법은 특별히 고도로 최적화하지 않은 단순한 구현입니다.

배열 $A$의 연속하는 부분 배열을 $A[i,j]=A_i,A_{i+1},\ldots,A_j$로 나타냅니다. 예를 들어 $B=A[i,i+10]$이면 $B_3=A_{i+2}$입니다.

먼저 원소 수 $N$, 난수의 시드 $S$, 난수 생성 매개변수 $X,Y,Z$가 주어집니다. 다음과 같이 배열을 만듭니다.

$A_1=S$

$A_{k+1}=(X \times A_k+Y)\bmod Z \quad (1 \le k \le N-1)$

그 후 다음 형식의 조작을 $Q$회 수행합니다. 네 양의 정수 $S,T,U,V$가 주어지면 $B=A_{S,T}$를 복사하고, 다음을 수행합니다.

$A_k \mathrel{\gets} A_k+B_{k-U+1} \quad (U \le k \le V)$

모든 조작을 수행한 뒤, 각 원소가 짝수이면 `E`, 홀수이면 `O`로 나타낸 길이 $N$의 문자열을 출력하세요. `O`는 숫자 0이 아니라 알파벳 대문자 O입니다.

## 입력

```text
N S X Y Z
Q
S_1 T_1 U_1 V_1
S_2 T_2 U_2 V_2
\vdots
S_Q T_Q U_Q V_Q
```

$S_k,T_k,U_k,V_k$는 $k$번째 조작의 $S,T,U,V$입니다.

- $1 \le N \le 2\,000\,000$
- $0 \le S,X,Y \le 10^9$
- $1 \le Z \le 10^9$
- $0 \le Q \le 200\,000$
- $1 \le S_k \le T_k \le N$
- $1 \le U_k \le V_k \le N$
- $T_k-S_k=V_k-U_k \le 100\,000$

## 출력

최종 배열을 위 규칙으로 나타낸 문자열을 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
10 8 1 3 5
3
3 5 7 9
3 10 1 8
1 3 1 3
```

#### 출력

```text
EEEOOOOEEE
```

처음 배열은 $(8,1,4,2,0,3,1,4,2,0)$입니다. 첫 번째 조작 후에는 $(8,1,4,2,0,3,5,6,2,0)$, 두 번째 조작 후에는 $(12,3,4,5,5,9,7,6,2,0)$, 세 번째 조작 후에는 $(24,6,8,5,5,9,7,6,2,0)$입니다. 따라서 답은 앞뒤가 같은 문자열 `EEEOOOOEEE`입니다. 회문이네요. 신난다!
