## 문제

함수 $f(x_1,x_2,\dots,x_N)=\sum_{i=1}^{N}a_ix_i=a_1x_1+a_2x_2+\dots+a_Nx_N$를 정의합니다. $f(x_1,x_2,\dots,x_N)=C$라는 제약 아래에서 $\sum_{i=1}^{N}x_i$의 최솟값을 구하세요.

$x_i$는 음이 아닌 정수 변수이고, $a_i$, $C$는 1 이상의 정수 상수입니다. 음이 아닌 정수해가 없으면 `-1`을 출력하세요.

## 입력

```text
C
N
a_1 a_2 ⋯ a_N
```

모든 입력은 정수입니다.

- $1 \leq C \leq 100000=10^5$
- $1 \leq N \leq 100$
- $1 \leq a_i \leq 100000=10^5$

## 출력

문제의 제약을 만족하는 $\sum_{i=1}^{N}x_i$의 최솟값을 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

```text
10
3
3 2 1
```

### 출력 1 {file="stdout"}

```text
4
```

이때 $f=3x_1+2x_2+x_3$입니다. $3x_1+2x_2+x_3=10$을 만족하는 해는 여러 개 있지만, $\sum x_i$의 최솟값은 $(x_1,x_2,x_3)=(3,0,1)$일 때의 4입니다.

### 입력 2 {file="stdin"}

```text
20
4
3 7 12 25
```

### 출력 2 {file="stdout"}

```text
4
```

$(x_1,x_2,x_3,x_4)=(2,2,0,0)$일 때 최솟값은 4입니다.

### 입력 3 {file="stdin"}

```text
100
3
90 9 12
```

### 출력 3 {file="stdout"}

```text
-1
```

$90x_1+9x_2+12x_3=100$을 만족하는 음이 아닌 정수해가 없으므로 `-1`을 출력합니다.

### 입력 4 {file="stdin"}

```text
100
1
50
```

### 출력 4 {file="stdout"}

```text
2
```

### 입력 5 {file="stdin"}

```text
100000
4
100000 50000 25000 12500
```

### 출력 5 {file="stdout"}

```text
1
```
