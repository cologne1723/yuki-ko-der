## 문제

$L$ 이상 $R$ 이하의 정수 $k$ 중 다음 조건을 만족하는 것의 개수를 구하세요. 정수 계수 다항식 $f(x)$가 존재하여 방정식 $f(x)=P$는 서로 다른 정수해를 5개 이상 가지고, $f(x)=k$는 정수해를 가져야 합니다.

## 입력

$T$개의 테스트 케이스 $(P_i,L_i,R_i)$가 주어집니다.

- $1\leq T\leq10^5$
- $|P_i|,|L_i|,|R_i|\leq2\times10^5$, $L_i\leq R_i$

## 출력

각 테스트 케이스의 답을 출력하세요.
