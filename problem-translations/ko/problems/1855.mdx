원주 위에 등간격인 $2N$개의 점이 시계 방향으로 번호가 붙어 있습니다. 문자열 $S$의 문자가 `R`이면 해당 점은 빨간색, `B`이면 파란색입니다.

## 문제

모든 점을 같은 색끼리 $N$개의 쌍으로 나누는 방법을 좋은 분할이라 합니다. 각 쌍을 잇는 선분을 그렸을 때, 서로 교차하는 두 선분의 선택 수를 점수로 정의합니다. 좋은 분할의 점수의 기댓값을 $998244353$로 계산해 출력하세요.

문자열 $S$는 문자 $C_i$를 $V_i$번 반복한 블록들의 연결로 주어집니다.

## 입력

```text
N X
C_1 V_1
...
C_X V_X
```

$1\le N\le499122176$입니다.

## 출력

기댓값을 문제의 정의에 따라 출력하세요.
