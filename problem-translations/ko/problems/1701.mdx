모든 상품 가격이 2의 배수인 상점에 서로 다른 상품 `N`개가 있습니다. 각 상품은 한 번만 반값으로 만들 수 있습니다.

상품을 하나 이상 골라 각 상품을 원래 가격 또는 반값으로 정했을 때, 가격 합이 `W`가 되는 선택 방법의 수를 구하세요.

## 제약

- `1 <= N <= 13`
- `0 <= W,a_i <= 10^9`
- `a_i`는 2의 배수입니다.

## 입력

`N W`와 상품 가격 `a_1,...,a_N`이 주어집니다.

## 출력

조건을 만족하는 방법의 수를 출력하세요.
