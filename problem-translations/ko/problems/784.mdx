## 문제

음이 아닌 정수 $N$이 주어집니다. 아래에서 세 자리마다 쉼표를 찍으세요. 맨 앞에는 쉼표를 붙이면 안 됩니다.

## 입력

~~~text
$N$
~~~

$0\leq N\leq1000000000=10^9$인 음이 아닌 정수입니다.

## 출력

정답을 한 줄에 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
123456
~~~

#### 출력

~~~text
123,456
~~~

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
12345678
~~~

#### 출력

~~~text
12,345,678
~~~

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
123
~~~

#### 출력

~~~text
123
~~~

쉼표가 붙지 않는 경우도 있습니다.
