## 문제 설명

길이 $N$인 음이 아닌 정수 수열 $A$가 주어집니다. $\displaystyle\prod_{k=1}^N A_k^{A_k!}$을 $10^9+7$로 나눈 나머지를 구하세요. 답이 $0$이면 대신 $-1$을 출력하세요.

## 입력

```text
N
A_1 A_2 \ldots A_N
```

- $1\leq N\leq2\times10^5$
- $0\leq A_i\leq10^9$

## 출력

답이 양수이면 나머지를, 그렇지 않으면 $-1$을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}
#### 입력
```text
3
3 3 3
```
#### 출력
```text
225159029
```
