## 문제

F개의 면을 가진 정F면체 모양의 주사위가 있습니다.

각 면에는 1부터 F까지의 정수가 하나씩 적혀 있고, 서로 다른 두 면의 정수는 서로 다릅니다.

모든 면이 나올 확률은 1/F로 같습니다.

이 주사위를 N번 던졌을 때 나온 눈 중 큰 순서로 K번째 값의 기댓값은 얼마일까요?

## 입력

```text
F N K
```

F는 4,6,8,12,20 중 하나입니다.

1 ≤ N ≤ 100

1 ≤ K ≤ N

N,K는 정수입니다.

## 출력

구한 기댓값을 출력하세요. 상대 오차 10^−6 이하인 답을 허용합니다.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
4 2 1
```

출력:

```text
3.125
```

정사면체 주사위를 2번 던질 때 가능한 결과는 (1,1)부터 (4,4)까지 16가지입니다.

그중 최댓값이 4인 경우가 7개, 3인 경우가 5개, 2인 경우가 3개, 1인 경우가 1개이므로 기댓값은 (7×4+5×3+3×2+1×1)/16 = 25/8 = 3.125입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
6 1 1
```

출력:

```text
3.5
```

일반적인 6면체 주사위 눈의 기댓값이므로 (1+2+3+4+5+6)/6 = 3.5입니다.
