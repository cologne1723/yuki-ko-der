`N`개 정점의 트리에서 `K`개 정점 `D_1,...,D_K`에 도토리가 있습니다. 다람쥐가 임의의 정점에 나타나고, 도토리가 있는 모든 정점을 방문할 때까지 인접 정점으로 이동합니다.

각 시작 정점 `X=1,...,N`에 대해 모든 도토리 정점을 방문하는 최소 이동 횟수를 구하세요.

## 제약

- `2 <= N <= 10^5`
- `1 <= K <= N`
- 주어지는 그래프는 트리입니다.

## 입력

트리와 도토리가 놓인 정점 목록이 주어집니다.

## 출력

각 시작 정점에 대한 답을 출력하세요.
