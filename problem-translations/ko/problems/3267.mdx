## 문제 설명

$2$ 이상인 정수 $N$이 주어집니다.

$(1,2,\dots,N)$의 순열인 $2$개의 수열의 쌍 $(P=(P_1,P_2,\dots,P_N), Q=(Q_1,Q_2,\dots,Q_N))$ 중 다음 조건을 만족하는 것이 존재하는지 판정하고, 존재한다면 그중 $1$개를 출력하세요.

- $S_i=P_i+Q_i\ (i=1,2,\dots,N)$으로 정의되는 길이 $N$인 수열 $S=(S_1,S_2,\dots,S_N)$가 공차 $1$인 등차수열입니다.

## 입력

입력의 $1$번째 줄에 정수 $N$이 주어집니다.

```text
$N$
```

## 제한

- $N$은 정수이며, $2\leq N\leq 2\times 10^5$를 만족합니다.

## 출력

조건을 만족하는 쌍 $(P,Q)$가 존재하지 않으면 `No`를 출력하세요.

존재한다면 다음 형식에 따라 $1$번째 줄에 `Yes`, $2$번째 줄에 $P$, $3$번째 줄에 $Q$를 출력하세요.

```text
Yes
$P_1\ P_2\ \dots\ P_N$
$Q_1\ Q_2\ \dots\ Q_N$
```

조건을 만족하는 쌍이 여러 개 존재한다면 그중 어느 것을 출력해도 정답으로 인정됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
```

#### 출력

```text
No
```

조건을 만족하는 쌍 $(P,Q)$는 존재하지 않습니다.

### 예제 2 {file=""}

#### 입력

```text
3
```

#### 출력

```text
Yes
1 3 2
2 1 3
```

$P=(1,3,2), Q=(2,1,3)$일 때 $S=(3,4,5)$는 공차 $1$인 등차수열입니다.
