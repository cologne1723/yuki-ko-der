## 이야기

> ドールちゃん은 귀엽습니다.

## 문제 설명

ドール의 けものミラクル(필살기)은 레벨이 $1,2,3,4,5$일 때 주는 대미지 배율이 각각 $390$, $429$, $468$, $507$, $546$입니다. 단, 공격 타입이 `Beat`일 때는 레벨이 $1$ 높은 것으로 간주하여 배율을 계산합니다.

레벨을 나타내는 정수 $L$과 공격 타입을 나타내는 문자열 $S$가 주어집니다. 이때 ドール의 けものミラクル의 배율을 출력하세요. 단, 레벨 $6$ 이상에 해당하는 배율을 출력해야 하는 입력은 주어지지 않습니다.

필요하다면 다음 텍스트를 사용해도 됩니다.

```text
390,429,468,507,546
```

## 입력

입력은 다음 형식으로 주어집니다. $L$은 레벨을 나타내는 정수이고, $S$는 공격 타입을 나타내는 문자열입니다.

```text
$L\ S$
```

## 제한

- $1\leq L\leq 5$
- $S$는 다음 $3$개의 문자열 중에서 선택합니다: `Action`, `Beat`, `Try`.
- $L=5$일 때 $S$는 `Beat`이 아닙니다.
- $L$은 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1 Action
```

#### 출력

```text
390
```

이제부터 키워서 강하게 만들어 줍시다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 Beat
```

#### 출력

```text
429
```

공격 타입에 따라 조금 강해집니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
5 Try
```

#### 출력

```text
546
```

레벨을 최대로 강화한 것 같습니다.
