## 문제 설명

길이 $N$인 구간 $[0,N)$의 낚시터에서 낚시를 합니다.

모든 물고기는 다음 규칙에 따라 움직입니다.

- 시각 $t$에 왼쪽을 향하고 위치 $x$에 있는 물고기는 시각 $t+1$에 방향을 바꾸지 않고 위치 $x-1$로 이동합니다. 단, $x=0$이면 그 자리에서 오른쪽을 향하도록 방향을 바꿉니다.
- 시각 $t$에 오른쪽을 향하고 위치 $x$에 있는 물고기는 시각 $t+1$에 방향을 바꾸지 않고 위치 $x+1$로 이동합니다. 단, $x=N-1$이면 그 자리에서 왼쪽을 향하도록 방향을 바꿉니다.

즉, 물고기가 향하는 방향으로 이동할 수 있으면 $1$만큼 이동하고, 이동할 수 없으면 그 자리에서 방향만 반대로 바꿉니다.

시각 $t=0$에는 물고기가 없습니다. 각 시각 $t$ ($1 \le t \le Q$)에 다음 $3$종류 중 $1$개의 쿼리가 주어지므로 총 $Q$개의 쿼리를 순서대로 처리하세요. $1$부터 세는 $t$번째 쿼리는 시각 $t$에 실행됩니다.


## 입력

```text
$N\ Q$
$x_1\ y_1\ z_1$
$\vdots$
$x_i\ y_i\ z_i$
$\vdots$
$x_Q\ y_Q\ z_Q$
```

$1$번째 줄에 구간의 길이인 정수 $N$과 쿼리 수인 정수 $Q$가 주어집니다.

다음 $Q$줄에는 다음 형식 중 $1$개의 쿼리가 주어집니다.

- $L\ y\ z$: 위치 $y$에 왼쪽을 향하는 물고기 $z$마리를 놓습니다.
- $R\ y\ z$: 위치 $y$에 오른쪽을 향하는 물고기 $z$마리를 놓습니다.
- $C\ y\ z$: 시각 $t$에 구간 $[y,z)$ 안에 있는 물고기의 총수를 출력합니다.


## 제한

- $2 \le N \le 20\,000$
- $1 \le Q \le 20\,000$

- $x_i$가 `L` 또는 `R`이면 $0 \le y_i < N$, $1 \le z_i \le 10^8$
- $x_i$가 `C`이면 $0 \le y_i < z_i \le N$

## 출력

`C` 쿼리에 대한 답을 주어진 순서대로, 각각 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
10 3
R 2 1
L 5 1
C 4 5
```

#### 출력

```text
2
```

각 시각의 물고기 상태는 다음과 같습니다. `L`은 왼쪽, `R`은 오른쪽을 향하는 물고기이고, `{...}`는 그 위치의 물고기 목록, `-`는 물고기가 없는 위치입니다.

| 시각 | 상태 |
| --- | --- |
| $t=0$ | `----------` |
| $t=1$ | `--{R}-------` |
| $t=2$ | `---{R}-{L}----` |
| $t=3$ | `----{R,L}-----` |

### 예제 2 {file=""}

#### 입력

```text
5 5
L 1 2
R 4 2
C 2 4
C 2 4
C 2 4
```

#### 출력

```text
0
2
4
```

각 시각의 물고기 상태는 다음과 같습니다.

| 시각 | 상태 |
| --- | --- |
| $t=0$ | `-----` |
| $t=1$ | `-{L,L}---` |
| $t=2$ | `{L,L}---{R,R}` |
| $t=3$ | `{R,R}---{L,L}` |
| $t=4$ | `-{R,R}-{L,L}-` |
| $t=5$ | `--{R,R,L,L}--` |

물고기는 경계에 도달한 뒤 더 이동할 수 없을 때 방향을 바꿉니다.

### 예제 3 {file=""}

#### 입력

```text
4 3
R 3 3
C 0 4
C 1 2
```

#### 출력

```text

0
```

각 시각의 물고기 상태는 다음과 같습니다.

| 시각 | 상태 |
| --- | --- |
| $t=0$ | `----` |
| $t=1$ | `---{R,R,R}` |
| $t=2$ | `---{L,L,L}` |
| $t=3$ | `--{L,L,L}-` |
