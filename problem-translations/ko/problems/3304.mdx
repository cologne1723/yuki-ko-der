## 문제 설명

조건 $X < Y < Z < N$을 만족하는 양의 정수 $X$, $Y$, $Z$에 대하여, 각각의 아래 $K$자리를 $x$, $y$, $z$라고 합니다.

다음 조건을 모두 만족하는 $X$, $Y$, $Z$의 조합이 몇 가지인지 구하세요.

- $0 < Y - X = Z - Y$
- $0 < x - y = y - z$

단, 답이 매우 커질 수 있으므로 $998\,244\,353$으로 나눈 나머지를 출력하세요.

$T$개의 테스트 케이스가 주어지므로, 각각의 답을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\text{case}_1$
$\vdots$
$\text{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ K$
```

## 제한

- 입력은 모두 정수입니다.
- $10 \leq N \leq 10^{18}$
- $1 \leq K$
- $10^K \leq N$
- $1 \leq T \leq 10^5$

## 출력

$998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
21 1
2025 2
123456789012345678 9
```

#### 출력

```text
4
231310
889386892
```

예를 들어 $(N, K) = (21, 1)$인 경우, 조건을 만족하는 $(X, Y, Z)$의 조합은 $(2, 11, 20)$, $(4, 12, 20)$, $(6, 13, 20)$, $(8, 14, 20)$의 $4$가지입니다.

$(2, 11, 20)$에 대하여 살펴보면, $(X, Y, Z) = (2, 11, 20)$, $(x, y, z) = (2, 1, 0)$이고, $0 < 9 = 11 - 2 = 20 - 11$ 및 $0 < 1 = 2 - 1 = 1 - 0$을 만족합니다.
