## 문제 설명

타로와 지로가 게임을 하고 있습니다.

테이블 위에 컵 3개가 있고, 그중 하나에만 바깥에서 보이지 않도록 동그라미 표시가, 나머지 2개에는 엑스 표시가 되어 있습니다.

타로가 보았을 때 왼쪽 컵부터 1번, 2번, 3번으로 번호를 붙입니다. 처음에 동그라미가 어느 컵에 있는지 공개한 뒤 지로가 여러 번 컵의 위치를 서로 바꾸므로, 타로는 동그라미가 어느 컵에 있는지 맞혀야 합니다.

컵을 바꾸는 중이나 바꾼 뒤에도 항상 왼쪽부터 1번, 2번, 3번으로 번호를 다시 매깁니다. 처음을 제외하면 컵에 붙은 표시는 볼 수 없습니다.

처음 동그라미가 있는 컵의 위치와 지로가 바꾼 컵의 위치가 주어질 때, 마지막에 동그라미가 있는 컵의 위치를 출력하세요.

## 입력

```text
N
M
P_1 Q_1
P_2 Q_2
\dots
P_M Q_M
```

첫째 줄에 처음 동그라미가 있는 컵의 위치 $N$이 주어집니다. $(1 \le N \le 3)$
둘째 줄에 컵을 바꾼 횟수 $M$이 주어집니다. $(1 \le M \le 200)$
이후 $M$개의 줄에 바꿀 컵의 위치 $P_i,Q_i$가 공백으로 구분되어 주어집니다. $(1 \le P_i,Q_i \le 3; 1 \le i \le M; P_i \ne Q_i)$

## 출력

마지막에 동그라미가 있는 컵의 위치를 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1

#### 입력

```text
1
1
1 3
```

#### 출력

```text
3
```

처음에는 왼쪽(1번) 컵에 동그라미가 있고, 왼쪽(1번) 컵과 오른쪽(3번) 컵을 바꾸었으므로 마지막에는 오른쪽(3번) 컵에 동그라미가 있습니다.

### 예제 2

#### 입력

```text
1
3
2 3
3 2
2 3
```

#### 출력

```text
1
```

처음 위치에서 변하지 않습니다.
