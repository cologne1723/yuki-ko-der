## 문제 설명

太郎君과 二郎君은 게임을 하고 있습니다.

테이블 위에 컵 $3$개가 있고, 그중 $1$개에만 바깥에서 보이지 않도록 ○ 표시가, 나머지 $2$개에는 × 표시가 되어 있습니다.

太郎君이 보았을 때 왼쪽 컵부터 $1$번, $2$번, $3$번으로 번호를 붙입니다. 처음에 ○가 어느 컵에 있는지 공개한 뒤 二郎君이 여러 번 컵의 위치를 서로 바꾸므로, 太郎君은 ○가 어느 컵에 있는지 맞혀야 합니다.

컵을 바꾸는 중이나 바꾼 뒤에도 항상 왼쪽부터 $1$번, $2$번, $3$번으로 번호를 다시 매깁니다. 처음을 제외하면 컵에 붙은 표시는 볼 수 없습니다.

처음 ○가 있는 컵의 위치와 二郎君이 바꾼 컵의 위치가 주어질 때, 마지막에 ○가 있는 컵의 위치를 출력하세요.

## 입력

```text
$N$
$M$
$P_1\ Q_1$
$P_2\ Q_2$
$\vdots$
$P_M\ Q_M$
```

처음 ○가 있는 컵의 위치를 나타내는 정수 $N$과 컵을 바꾼 횟수인 정수 $M$이 각각 $1$줄에 주어집니다.
이후 $M$개의 줄에 바꿀 $2$개의 컵의 위치를 나타내는 정수 $P_i,Q_i$가 공백으로 구분되어 주어집니다.

## 제한

- $1 \le N \le 3$
- $1 \le M \le 200$
- $1 \le P_i,Q_i \le 3$ $(1 \le i \le M)$
- $P_i \ne Q_i$ $(1 \le i \le M)$

## 출력

마지막에 ○가 있는 컵의 위치를 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
1
1 3
```

#### 출력

```text
3
```

처음에는 왼쪽($1$번) 컵에 ○가 있고, 왼쪽($1$번) 컵과 오른쪽($3$번) 컵을 바꾸었으므로 마지막에는 오른쪽($3$번) 컵에 ○가 있습니다.

### 예제 2 {file=""}

#### 입력

```text
1
3
2 3
3 2
2 3
```

#### 출력

```text
1
```

○가 처음 위치에서 변하지 않습니다.
