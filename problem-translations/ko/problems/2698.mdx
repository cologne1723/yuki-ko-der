## 문제

난이도가 다른 `N`개의 가상 콘테스트가 있습니다. 각 콘테스트는 `M`문제이며, `i`번째 콘테스트의 난이도는 등차수열 `A_i, A_i+B_i, ..., A_i+(M-1)B_i`입니다. 행과 열 방향 모두 난이도가 감소하지 않습니다.

hibit의 처음 레이팅은 `X`이고, 콘테스트 `i`에 참가할 때마다 레이팅이 `C_i` 증가합니다. 각 참가 전에 현재 레이팅 `R`과 콘테스트의 모든 문제 난이도 차이의 절댓값 합이 최소인 콘테스트를 고릅니다. 여러 개면 번호가 가장 작은 콘테스트를 고릅니다. `Q`번 참가할 때마다 참가할 콘테스트 번호를 출력하세요.

## 제약

- `2 ≤ N ≤ 10^5`, `2 ≤ M ≤ 10^9`, `1 ≤ Q ≤ 2×10^5`
- `0 ≤ X,C_i ≤ 10^9`
- 모든 문제 난이도는 `0` 이상 `10^9` 이하이고 주어진 단조 조건을 만족합니다.

## 입력

```text
N M
A_1 B_1
⋮
A_N B_N
Q
X
C_1 C_2 ... C_N
```

## 출력

각 참가에서 선택한 콘테스트 번호를 공백으로 출력하세요.
