## 문제 설명

길이 $N$인 수열 $A$와 정수 $M$이 주어집니다. 각 $K=1,2,\ldots,M$에 대해 다음 값을 $998\,244\,353$으로 나눈 나머지를 구하세요.

$S_K:=\sum_{i=1}^{N}A_i^K$

## 입력

```text
$N\ M$
$A_1\ A_2\ \cdots\ A_N$
```

## 제한

- $1 \leq N,M \leq 100\,000$
- $0 \leq A_i < 998\,244\,353$
- 입력은 모두 정수입니다.

## 출력

$S_1,S_2,\ldots,S_M$을 $998\,244\,353$으로 나눈 나머지를 공백으로 구분해 출력하세요.

마지막에 줄바꿈을 넣으세요.

```text
10 3

```
#### 출력
```text
55 385 3025
```
