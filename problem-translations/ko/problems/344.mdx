## 문제

주어진 음이 아닌 정수 $n$에 대해 $(1+\sqrt3)^n$의 정수 부분을 1000으로 나눈 나머지, 즉 $\left\lfloor(1+\sqrt3)^n\right\rfloor\bmod1000$을 계산하세요.

## 입력

```text
n
```

$n$은 정수이며 $0\le n\le10^9$입니다.

## 출력

값을 출력하고 마지막에 개행하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
0
```

### 샘플 1 {file="sample1.out"}

```text
1
```

$\left\lfloor(1+\sqrt3)^0\right\rfloor=\left\lfloor1\right\rfloor=1$입니다.

### 샘플 2 {file="sample2.in"}

```text
2
```

### 샘플 2 {file="sample2.out"}

```text
7
```

$\left\lfloor(1+\sqrt3)^2\right\rfloor=\left\lfloor7.464\cdots\right\rfloor=7$입니다.

### 샘플 3 {file="sample3.in"}

```text
12
```

### 샘플 3 {file="sample3.out"}

```text
927
```

### 샘플 4 {file="sample4.in"}

```text
123456789
```

### 샘플 4 {file="sample4.out"}

```text
920
```
