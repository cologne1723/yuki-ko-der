## 문제 설명

주어진 음이 아닌 정수 $n$에 대해 $(1+\sqrt3)^n$의 정수 부분을 $1\,000$으로 나눈 나머지, 즉 $\left\lfloor(1+\sqrt3)^n\right\rfloor\bmod1\,000$을 계산하세요.

## 입력

```text
$n$
```

$n$은 정수입니다.

## 제한

$0\le n\le10^9$

## 출력

값을 출력하고 마지막에 개행하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0
```

#### 출력

```text
1
```

$\left\lfloor(1+\sqrt3)^0\right\rfloor=\left\lfloor1\right\rfloor=1$입니다.

### 예제 2 {file=""}

#### 입력

```text
2
```

#### 출력

```text
7
```

$\left\lfloor(1+\sqrt3)^2\right\rfloor=\left\lfloor7.464\cdots\right\rfloor=7$입니다.

### 예제 3 {file=""}

#### 입력

```text
12
```

#### 출력

```text
927
```

### 예제 4 {file=""}

#### 입력

```text
123456789
```

#### 출력

```text
920
```
