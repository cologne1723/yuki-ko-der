## 문제

문자의 순서가 오름차순인 문자열을 좋은 문자열이라고 합니다. 주어진 $N$개의 문자열 각각을 선택하거나 선택하지 않고, 선택한 문자열들을 원하는 순서로 이어 붙여 좋은 문자열 $X$를 만들 때 가능한 $|X|$의 최댓값을 구하세요.

## 입력

첫째 줄에 $N$이 주어지고, 다음 $N$줄에 문자열 $S_i$가 주어집니다.

- $1\leq N\leq200000$
- 각 문자열은 영소문자로 이루어집니다.
- 전체 문자열 길이의 합은 $200000$ 이하입니다.

## 출력

가능한 길이의 최댓값을 출력하세요.
