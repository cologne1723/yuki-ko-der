## 문제 설명

서로 다른 $3$개의 정수 $P$, $Q$, $R$이 주어집니다.

$Q$가 $P$, $R$의 중점 $\frac{P+R}{2}$과 일치하는지 판정하세요.

## 입력

입력은 표준 입력에서 다음 형식으로 $1$줄에 주어집니다.

```text
$P\ Q\ R$
```

$1$번째 줄에 $P$, $Q$, $R$이 공백으로 구분되어 주어집니다.

## 제한

- $P$는 $-10\leq P\leq 10$을 만족하는 정수입니다.
- $Q$는 $-10\leq Q\leq 10$을 만족하는 정수입니다.
- $R$은 $-10\leq R\leq 10$을 만족하는 정수입니다.
- $P$, $Q$, $R$은 서로 다릅니다.

## 출력

$Q$가 $P$, $R$의 중점 $\frac{P+R}{2}$과 일치하면 `Yes`를 출력하고, 일치하지 않으면 `No`를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
-1 0 1
```

#### 출력

```text
Yes
```

$\frac{P+R}{2}=\frac{(-1)+1}{2}=0=Q$입니다.

### 예제 2 {file=""}

#### 입력

```text
4 2 0
```

#### 출력

```text
Yes
```

$\frac{P+R}{2}=\frac{4+0}{2}=2=Q$입니다.

### 예제 3 {file=""}

#### 입력

```text
0 -1 2
```

#### 출력

```text
No
```

$\frac{P+R}{2}=\frac{0+2}{2}=1\neq -1=Q$입니다.

### 예제 4 {file=""}

#### 입력

```text
0 1 3
```

#### 출력

```text
No
```

$\frac{P+R}{2}=\frac{0+3}{2}=1.5\neq 1=Q$입니다.
