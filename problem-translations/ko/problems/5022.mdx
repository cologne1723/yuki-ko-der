## 문제 설명

$N \times N$ 격자가 주어집니다. 위에서 $i$번째, 왼쪽에서 $j$번째 칸 $(i,j)$에는 $0 \leq A_{i,j} < 2^{20}$을 만족하는 정수 $A_{i,j}$가 쓰여 있습니다.

또한 숫자 $s=0$을 가지고 있으며, 처음에는 $(1,1)$에 있습니다.

다음 조작을 최대 $T$번 수행하여, 조작이 끝났을 때의 모든 $A_{i,j}$의 합 $S = \sum_{i=1}^{N}\sum_{j=1}^{N} A_{i,j}$을 최대한 크게 만드세요.

1. **이동**: 위, 아래, 왼쪽, 오른쪽 중 원하는 방향으로 $1$칸 이동합니다. 단, 격자 밖으로 나갈 수 없습니다.
   - `U`: $(i,j)$에서 $(i-1,j)$로 이동합니다. (위로 이동)
   - `D`: $(i,j)$에서 $(i+1,j)$로 이동합니다. (아래로 이동)
   - `L`: $(i,j)$에서 $(i,j-1)$로 이동합니다. (왼쪽으로 이동)
   - `R`: $(i,j)$에서 $(i,j+1)$로 이동합니다. (오른쪽으로 이동)
2. **쓰기**: `W` — 현재 칸이 $(i,j)$일 때, $A_{i,j}$를 $A_{i,j} \mathbin{\oplus} s$로 바꿉니다.
3. **복사**: `C` — 현재 칸이 $(i,j)$일 때, $s$를 $s \mathbin{\oplus} A_{i,j}$로 바꿉니다.

### 비트 단위 XOR이란

음이 아닌 정수 $A$, $B$의 비트 단위 XOR $A \mathbin{\oplus} B$는 다음과 같이 정의됩니다.

- $A \mathbin{\oplus} B$를 이진 표기로 나타냈을 때 $2^k$ ($k \geq 0$)의 자리 숫자는, $A$, $B$를 이진 표기로 나타냈을 때 해당 자리의 숫자 중 정확히 $1$개만 $1$이면 $1$이고, 그렇지 않으면 $0$입니다.

예를 들어, $3 \mathbin{\oplus} 5 = 6$입니다. (이진 표기로 나타내면 $011 \mathbin{\oplus} 101 = 110$입니다.)

## 입력

```text
$N\ T$
$A_{1,1}\ A_{1,2}\ \cdots\ A_{1,N}$
$A_{2,1}\ A_{2,2}\ \cdots\ A_{2,N}$
$\vdots$
$A_{N,1}\ A_{N,2}\ \cdots\ A_{N,N}$
```

## 제한

- $N=10$
- $T=1\,000$
- $0 \leq A_{i,j} < 2^{20}$ ($1 \leq i,j \leq N$)
- $A_{i,j}$는 정수입니다.

## 출력

조작 횟수를 $M$ ($M \leq T$)이라고 할 때, 다음 형식으로 출력하세요.

```text
$op_1$
$op_2$
$\vdots$
$op_M$
```

- 각 $op_k$는 `U`, `D`, `L`, `R`, `W`, `C` 중 $1$개입니다.
- 다음과 같은 출력을 하면 `WA`로 판정됩니다.
  - 격자 밖으로 이동하는 경우: $(i,j)$에서 $i < 1$, $i > N$, $j < 1$, 또는 $j > N$이 되는 이동
  - 조작 횟수가 $T$를 초과하는 경우
  - 유효하지 않은 조작 문자를 출력하는 경우

## 점수

조작이 끝났을 때의 $S = \sum_{i=1}^{N}\sum_{j=1}^{N} A_{i,j}$가 점수가 됩니다.

테스트 케이스는 총 $50$개이며, 각 테스트 케이스의 점수 합이 제출 점수가 됩니다.

단, $1$개 이상의 테스트 케이스에서 잘못된 출력 또는 실행 시간 제한 초과가 발생하면 제출 전체가 `WA` 또는 `TLE`로 판정됩니다.

각 참가자의 점수는 문제의 「스코어 순」 탭에서 확인할 수 있습니다.

## 입력 생성 방법

- $A_{i,j}$는 $0$ 이상 $2^{20}$ 미만인 정수 중에서 균일하게 무작위로 선택됩니다.
