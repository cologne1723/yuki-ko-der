## 문제 설명

변수 $x$에 대한 수식 $f(x)$가 있습니다. 이 수식은 $Q$개의 기호(피연산자 또는 연산자)로 이루어진 수열 $S = (s_1, s_2, \cdots, s_Q)$로 주어집니다.

$S$는 역폴란드 표기법으로 표현되어 있으며, 다음 순서로 계산하면 $f(x)$의 값을 구할 수 있습니다.

처음에 빈 수열 $A$가 있습니다.

다음 조작을 $i = 1, 2, \cdots, Q$의 순서로 수행합니다. 각 조작 직전의 $A$를 길이 $n$인 수열 $(A_1, A_2, \cdots, A_n)$이라고 합니다.

- $s_i$가 피연산자(정수 또는 `X`)인 경우 다음 조작을 수행합니다.
  - 정수인 경우, $A$를 길이 $n + 1$인 수열 $(A_1, A_2, \cdots, A_n, \bm{s_i})$로 갱신합니다.
  - `X`인 경우, $A$를 길이 $n + 1$인 수열 $(A_1, A_2, \cdots, A_n, \bm{x})$로 갱신합니다.

- $s_i$가 연산자(`+`, `min`, `max` 중 하나)인 경우 다음 조작을 수행합니다. 이때 $n \ge 2$임이 보장됩니다.
  - `+`인 경우, $A$를 길이 $n - 1$인 수열 $(A_1, A_2, \cdots, A_{n-2}, \bm{A_{n-1} + A_n})$로 갱신합니다.
  - `min`인 경우, $A$를 길이 $n - 1$인 수열 $(A_1, A_2, \cdots, A_{n-2}, \bm{\min\{A_{n-1}, A_n\}})$로 갱신합니다.
  - `max`인 경우, $A$를 길이 $n - 1$인 수열 $(A_1, A_2, \cdots, A_{n-2}, \bm{\max\{A_{n-1}, A_n\}})$로 갱신합니다.

모든 조작이 끝난 후 $A$의 길이는 $1$이 됨이 보장됩니다. 이때의 $A_1$이 계산 결과입니다.

이때 $f(x) = Y$를 만족하는 **비음이 아닌 정수** $x$ 중 최솟값을 구하세요. 그러한 $x$가 존재하지 않으면 $-1$을 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$Q\ Y$
$s_1\ s_2\ \cdots\ s_Q$
```

## 제한

- $Q$, $Y$는 정수입니다.
- $1 \le Q \le 2 \times 10^5$
- $0 \le Y \le 10^{13}$ (2024년 10월 16일 0시 15분에 $10^{14}$에서 변경되었습니다.)
- $s_i$는 피연산자(정수 또는 `X`) 또는 연산자(`+`, `min`, `max` 중 하나)입니다.
- $s_i$가 정수라면 $0 \le s_i \le 10^9$입니다.
- 문제의 절차로 계산할 때 모순이 생기는 입력은 주어지지 않습니다.

## 출력

$f(x) = Y$를 만족하는 비음이 아닌 정수 $x$ 중 최솟값을 출력하세요. 그러한 $x$가 존재하지 않으면 $-1$을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 5
X 2 +
```

#### 출력

```text
3
```

주어진 수식은 $f(x) = x + 2$입니다. $f(x) = 5$를 풀면 $x = 3$입니다.

### 예제 2 {file=""}

#### 입력

```text
7 9
X X 3 max + 11 min
```

#### 출력

```text
-1
```

$f(x) = \min\big\{x + \max\{x, 3\}, 11\big\} = 9$를 만족하는 비음이 아닌 정수 $x$는 존재하지 않습니다. 이 경우 $-1$을 출력합니다.

### 예제 3 {file=""}

#### 입력

```text
11 10
X X X X X + + + + 10 max
```

#### 출력

```text
0
```

$f(x) = Y$를 만족하는 비음이 아닌 정수 $x$가 여러 개 존재할 수 있습니다. 이 경우 방정식을 만족하는 $x$의 최솟값을 출력합니다.
