## 문제 설명

돌무더기 $N$개가 있으며, 돌무더기 $i$에는 돌이 $A_i$개 있습니다.

Alice와 Bob은 이 돌무더기들로 게임을 합니다. Alice부터 시작해 번갈아 다음 동작을 수행합니다.

> 자기 차례인 플레이어는 돌이 하나 이상 있는 돌무더기 $i$를 하나 선택하고, **돌무더기 $i$에서 돌 하나를 제거합니다.**
>
> 이 동작으로 **돌무더기 $i$의 돌이 $0$개가 되면, $i$ 뒤에 있는 돌무더기 $i+1,i+2,\ldots,N$의 돌도 모두 $0$개가 됩니다.**

돌이 하나 이상 있는 돌무더기가 남아 있는 동안 이 동작을 반복합니다. 자기 차례에 **동작을 수행할 수 없는 플레이어가 패배합니다.**

$T$개의 테스트 케이스가 주어집니다. 각 테스트 케이스에서 두 사람이 최적으로 행동할 때 Alice와 Bob 중 누가 이기는지 판별하세요.

## 입력

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

$\mathrm{case}_t$는 $t$번째 테스트 케이스이며 $(1 \leq t \leq T)$, 형식은 다음과 같습니다.

```text
$N$
$A_1\ A_2\ \dots\ A_N$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $1 \leq T \leq 10^5$
- $1 \leq N$
- $1 \leq A_i \leq 10^{9}$
- 모든 테스트 케이스의 $N$의 합은 $2 \times 10^5$ 이하입니다.

## 출력

$T$줄을 출력하세요. 각 테스트 케이스에 대해 Alice가 이기면 `Alice`, Bob이 이기면 `Bob`을 한 줄에 출력하세요.

## 예제

### 예제 1 {file="00_sample_1.txt"}

#### 입력

```text
3
2
1 2
3
3 1 2
1
3
```

#### 출력

```text
Alice
Bob
Alice
```

첫 번째 테스트 케이스에서 Alice는 돌무더기 $1$에서 돌 하나를 제거할 수 있습니다. 그러면 돌무더기 $1$의 돌이 $0$개가 되므로, 돌무더기 $1$부터 뒤쪽에 있는 돌무더기, 즉 돌무더기 $1$과 돌무더기 $2$의 돌이 모두 $0$개가 됩니다. 따라서 Bob은 동작을 수행할 수 없고 Alice가 이깁니다.
