## 문제 설명

컵라면 $N$개가 있습니다. $i$번째 컵라면을 완성하려면 뜨거운 물이 $A_i$ mL 필요합니다.

당신은 뜨거운 물을 붓기 위한 주전자를 가지고 있으며, 현재 주전자에는 뜨거운 물이 $X$ mL 들어 있습니다.

모든 컵라면을 완성하기 위해 주전자에 추가해야 하는 뜨거운 물의 양을 mL 단위로 구하세요. 주전자의 용량은 충분히 크고, 증발 등으로 뜨거운 물이 손실되지 않는다고 가정합니다.

## 입력

```text
$N\ X$
$A_1\ A_2\ A_3\ \dots\ A_N$
```

입력은 다음 제한을 만족합니다.

## 제한

- $1 \le N \le 100$
- $0 \le X \le 10\,000$
- $0 \le A_i \le 1\,000$ ($1 \le i \le N$)
- 입력은 모두 정수입니다.

## 출력

정답이 되는 수치를 단위 없이 $1$줄에 출력하고, 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 400
300 300 500
```

#### 출력

```text
700
```

필요한 뜨거운 물의 총량은 $1\,100$ mL입니다. 따라서 주전자에 뜨거운 물을 $700$ mL 추가하면 충분합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 1000
400
```

#### 출력

```text
0
```

뜨거운 물을 추가할 필요는 없습니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
7 926
314 159 265 358 979 323 846
```

#### 출력

```text
2318
```
