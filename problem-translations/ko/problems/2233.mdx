비음이 아닌 정수 $a,b,c$에 대해 $K$번 반복한다냥. 동시에 $(a,b,c)$를 $\left(\lfloor(b+c)/2\rfloor,\lfloor(c+a)/2\rfloor,\lfloor(a+b)/2\rfloor\right)$로 바꾼 뒤 최종 $a+b+c$를 구하라냥.

## 조건

- $1\le T\le10^5$
- $0\le a,b,c,K\le10^{18}$

## 입력

```text
T
a b c K
\vdots
```

## 출력

각 테스트 케이스의 답을 한 줄에 하나씩 출력하라냥.
