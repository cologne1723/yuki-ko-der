문자열 $S_1,\ldots,S_N$을 순서대로 봅니다. 현재 문자열 $S_i$에 대해 이전 문자열 $S_j$에서 인접한 두 문자를 최대 한 번 교환해 $S_i$로 만들 수 있는 $j<i$가 존재하면 반응합니다.

## 입력

```text
N
S_1
...
S_N
```

문자열은 비어 있지 않은 소문자 문자열이고 전체 길이 합은 $10^6$ 이하입니다.

## 출력

각 문자열에 반응하면 `Yes`, 아니면 `No`를 출력하세요.
