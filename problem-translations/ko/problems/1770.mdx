0에서 시작해 매 차례 `1` 이상 `K` 이하를 더한 수를 선언합니다. `N` 이상을 선언하면 패배하고, 직전 상대가 더한 수와 같은 수를 더해도 즉시 패배합니다.

당신이 선공일 때, 최적으로 플레이해 이길 수 있다면 첫 선언으로 가능한 수를 오름차순으로 출력하세요. 이길 수 없으면 `0`을 출력하세요.

## 제약

- `1 <= K < N <= 2 * 10^5`

## 입력

`N K`가 주어집니다.

## 출력

가능한 첫 선언을 한 줄에 하나씩 출력하세요.
