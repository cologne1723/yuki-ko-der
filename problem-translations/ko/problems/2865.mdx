## 이야기

당신은 ゆ～さん의 평행 세계 연구를 돕는 조수입니다. 어느 날, 평행 세계 중 $1$개에 ゆ～さん과 함께 휘말리고 말았습니다.

ゆ～さん은 주변을 둘러보다가 $1$가지 사실을 깨달았습니다. “이 세계, 수를 세는 방법이 정말 기분 나쁘네...”

우리 세계에서는 기본적으로 $10$진법을 사용하며 각 자릿수가 $9$를 넘지 않습니다. 하지만 이 세계에서는 각 자릿수마다 서로 다른 값의 상한을 정하고, 그 값을 넘지 않도록 수를 세는 것 같습니다.

“마치 야드파운드법 같군. 좋아, 자네. 이 세계의 수 중에서 작은 순서대로 $K$번째 값을 바로 계산할 수 있는 코드를 작성해 두게. 아, 저건 대체 뭐지...?”

ゆ～さん은 부탁만 해 둔 뒤 이 세계에서 흥미로운 것을 발견했는지 눈을 반짝이며 어딘가 먼 곳으로 달려갔습니다. 돌아올 때까지 부탁받은 코드를 작성해 둘까요.

## 문제 설명

십진법에서 $B$가 $A$의 부분집합이라는 것은 십진법의 각 자리에서 $B$의 값이 $A$ 이하라는 뜻입니다.

더 엄밀하게는 다음과 같습니다.

각각의 $A$와 $B$는 다음과 같이 나타내는 방법이 유일하게 정해집니다.

$A=a_0\times 10^0+a_1\times 10^1+\dots$

$B=b_0\times 10^0+b_1\times 10^1+\dots$

단, $0\leq a_i,b_i\leq 9$입니다. 이때 모든 음이 아닌 정수 $i$에 대해 $a_i\geq b_i$이면 $B$는 십진법에서 $A$의 부분집합입니다.

음이 아닌 정수 $N$과 양의 정수 $K$가 주어집니다. 십진법에서 $N$의 부분집합인 음이 아닌 정수 중 $K$번째로 작은 수를 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ K$
```

$N$은 음이 아닌 정수이고 $K$는 양의 정수입니다.

## 제한

- $0\leq N\leq 10^{18}$
- $1\leq K\leq 10^{18}$
- 십진법에서 $N$의 부분집합인 음이 아닌 정수는 $K$개 이상 존재합니다.

## 출력

답을 $1$줄에 출력하고, 마지막에 개행하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
12 3
```

#### 출력

```text
2
```

십진법에서 $12$의 부분집합인 수는 작은 순서대로 $0,1,2,10,11,12$입니다.

따라서 그중 $3$번째로 작은 수 $2$를 출력합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
0 1
```

#### 출력

```text
0
```

십진법에서 $0$의 부분집합인 수는 $0$ $1$개뿐이므로 $0$을 출력합니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1000000000000000000 2
```

#### 출력

```text
1000000000000000000
```

답이 $32$비트 정수형에 들어가지 않을 수 있음에 유의하세요.
