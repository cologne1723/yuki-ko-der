선수 $10^{100}$명 중 처음에는 등번호 1부터 $N$까지가 경기장에 있습니다. 경기장 선수 한 명을 무작위로 골라 옐로카드를 줍니다. 첫 카드는 아무 일도 없고, 두 번째 카드를 받으면 퇴장하며 아직 경기장에 들어온 적 없는 선수 중 등번호가 가장 작은 선수가 들어옵니다.

$K$번의 사건 직후 경기장 선수 중 등번호 최댓값의 기댓값을 $998244353$으로 출력하세요.

## 입력

```text
N K
```

## 출력

기댓값을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 2
```

#### 출력

```text
332748121
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
2 3
```

#### 출력

```text
3
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1 5000
```

#### 출력

```text
2501
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
11 2023
```

#### 출력

```text
35139493
```
