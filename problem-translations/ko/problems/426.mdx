## 문제

3 × 3 행렬 Aᵢ (0 ≤ i < n)와 2 × 2 행렬 Bᵢ (0 < i ≤ n)가 있습니다. 초기값은 모두 단위 행렬입니다.

3차원 벡터열 aᵢ (0 ≤ i ≤ n)와 2차원 벡터열 bᵢ (0 ≤ i ≤ n)를 다음과 같이 정의합니다.

- aᵢ₊₁ = Aᵢaᵢ
- bᵢ₋₁ = Bᵢbᵢ + [[6i, 6i+1, 6i+2], [6i+3, 6i+4, 6i+5]]aᵢ

점화식의 초기값으로 a₀, bₙ이 주어집니다. 다음 4종류의 쿼리를 처리하세요.

1. `a i`: Aᵢ를 변경합니다.
2. `b i`: Bᵢ를 변경합니다.
3. `ga i`: aᵢ의 각 원소를 10^9 + 7로 나눈 나머지를 출력합니다.
4. `gb i`: bᵢ의 각 원소를 10^9 + 7로 나눈 나머지를 출력합니다.

## 입력

첫째 줄에 n, 둘째 줄에 a₀의 세 원소, 셋째 줄에 bₙ의 두 원소, 넷째 줄에 쿼리 수 q가 주어집니다. 이후 q개 줄에 쿼리가 주어집니다.

```text
n
a₀₍₀₎ a₀₍₁₎ a₀₍₂₎
bₙ₍₀₎ bₙ₍₁₎
q
query₁
⋮
query_q
```

- 1 ≤ n ≤ 100000
- 1 ≤ q ≤ 10000
- a₀ = [a₀₍₀₎, a₀₍₁₎, a₀₍₂₎]ᵀ
- bₙ = [bₙ₍₀₎, bₙ₍₁₎]ᵀ
- a₀와 bₙ의 원소는 각각 0 이상 100 미만의 정수입니다.
- `ga` 또는 `gb` 쿼리가 적어도 하나 존재합니다.

### 쿼리 a

```text
a i a00 a01 a02 a10 a11 a12 a20 a21 a22
```

Aᵢ를 다음 행렬로 변경합니다.

```text
[[a00, a01, a02],
 [a10, a11, a12],
 [a20, a21, a22]]
```

- 0 ≤ i < n
- Aᵢ의 원소는 0 이상 100 미만의 정수입니다.

### 쿼리 b

```text
b i b00 b01 b10 b11
```

Bᵢ를 다음 행렬로 변경합니다.

```text
[[b00, b01],
 [b10, b11]]
```

- 0 < i ≤ n
- Bᵢ의 원소는 0 이상 100 미만의 정수입니다.

### 쿼리 ga, gb

```text
ga i
gb i
```

- 0 ≤ i ≤ n

## 출력

`ga` 쿼리에는 `a0 a1 a2`, `gb` 쿼리에는 `b0 b1` 형식으로 출력합니다.
