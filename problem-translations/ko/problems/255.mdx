## 문제

*Splarrraaay*는 [Splarraay](http://yukicoder.me/problems/625)의 속편인 간단한 배열 칠하기 게임입니다. 플레이어는 팀 A, B, C, D, E로 나뉘어 각 팀의 색으로 하나의 배열을 서로 칠합니다. 최종 점수는 해당 팀 색의 두께 합과 아래 보너스 점수의 합이며, 점수가 가장 높은 팀이 승리합니다.

규칙은 다음과 같습니다.

1. 길이 $N$이고 어떤 색으로도 칠해지지 않은 배열이 주어집니다. 모든 원소에서 모든 색의 두께는 0입니다.
2. 5개 팀은 구간 $[l,r]$을 자신의 색으로 칠합니다. 칠하지 않은 원소는 자신의 색으로 칠하고 두께를 1로 합니다. 이미 자신의 색이면 두께를 1 늘립니다. 다른 팀의 색이면 나중에 칠한 색으로 덮어쓰고 다른 색의 두께를 0으로 만든 뒤 자신의 색 두께를 1로 합니다.
3. 비정기적으로 보너스 기회가 주어집니다. 구간 $[l,r]$에서 팀 $X$의 색 두께 합을 $X_{lr}$($X=A,B,C,D,E$)라고 할 때, 최댓값을 가진 팀에 $\max(A_{lr},B_{lr},C_{lr},D_{lr},E_{lr})$의 보너스 점수를 줍니다. 최댓값이 여러 팀이면 어느 팀에도 보너스를 주지 않습니다.
4. 게임이 종료되면 전체 구간 $[0,N-1]$에서 각 팀 색 두께의 합과 지금까지의 보너스 점수 합이 그 팀의 점수입니다.

게임은 이미 종료되었습니다. 각 팀의 행동과 보너스 기회의 상세 내용이 시간 순서대로 주어질 때 최종 점수를 계산하세요.

## 입력

```text
N
Q
x_1 l_1 r_1
x_2 l_2 r_2
⋮
x_Q l_Q r_Q
```

- $N$: 배열의 길이
- $Q$: 팀 행동 횟수와 보너스 기회 횟수의 합
- $x_k=0$: 구간 $[l_k,r_k]$의 보너스 기회
- $x_k=1,2,3,4,5$: 각각 팀 A, B, C, D, E가 구간 $[l_k,r_k]$을 칠함
- $1 \leq N \leq 10^{13}$
- $0 \leq Q \leq 150000=1.5\times10^5$
- $0 \leq x_k \leq 5$
- $0 \leq l_k \leq r_k\lt N$

## 출력

팀 A, B, C, D, E의 점수를 순서대로 공백 구분하여 $10^{18}+9$로 나눈 나머지를 출력하세요.
