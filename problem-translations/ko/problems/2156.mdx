문자 `ぞ`와 `い`로만 이루어지고, `ぞ`로 시작하며 `い`를 하나 이상 포함하고, `い`가 연속해서 두 번 나오지 않는 문자열을 조이 문자열이라고 하자냥. 길이 $N$인 조이 문자열의 개수를 $998244353$으로 나눈 나머지를 구하라냥.

## 조건

- $2\le N\le10^{18}$

## 입력

```text
N
```

## 출력

답을 출력하라냥.
