## 참고

Python으로는 예상 풀이가 시간 초과하므로 PyPy로 제출하는 것을 권장합니다.

## 문제

점 $P$가 3차원 격자에서 움직입니다. 시각 0에 $P$는 원점 $(0,0,0)$에 있습니다. 시각 $t$에 $(x,y,z)$에 있다면 시각 $t+1$에는 $(x+1,y,z)$, $(x,y+1,z)$, $(x,y,z+1)$, $(x-1,y,z)$, $(x,y-1,z)$, $(x,y,z-1)$ 중 하나로 이동하며 각 이동 확률은 $1/6$입니다.

시각 $T$의 좌표가 $d \le ax+by+cz \le e$를 만족할 확률을 $p$라 하면 $6^T p$는 정수입니다. $6^T p$를 $10^9+7$로 나눈 나머지를 구하세요.

## 입력

```text
T
a b c d e
```

첫째 줄에 시각 $T$, 둘째 줄에 조건의 매개변수 $a,b,c,d,e$가 주어집니다.

- $1 \le T \le 500$
- $|a|,|b|,|c| \le 20$
- $(a,b,c)\ne(0,0,0)$
- $-10000 \le d \le e \le 10000$

## 출력

$6^T p$를 $10^9+7$로 나눈 나머지를 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
1
1 0 0 1 1
```

출력:

```text
1
```

시각 1에 $x=1$ 평면에 있으면 되므로 $(1,0,0)$으로 이동하면 조건을 만족합니다. 확률은 $1/6$이므로 $6\times(1/6)=1$입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
3
-2 0 0 -4 2
```

출력:

```text
202
```

### 샘플 3 {file="sample3.in"}

입력:

```text
6
1 -1 0 0 0
```

출력:

```text
9024
```

### 샘플 4 {file="sample4.in"}

입력:

```text
120
12 -1 2 -1212 1212
```

출력:

```text
504758737
```
