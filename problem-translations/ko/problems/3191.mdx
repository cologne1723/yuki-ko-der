## 문제 설명

길이가 $N$인 양의 정수열 $A=(A_1,A_2,\dots,A_N)$과 양의 정수 $X$가 주어집니다.

여기서 $A_1,A_2,\dots,A_N,X$의 값은 각각 $1,2,3,4$ 중 $1$개입니다.

$4$행 $4$열의 양의 정수 표 $f$가 멋진 표라는 것은 다음 조건을 모두 만족한다는 뜻입니다. 표의 위에서부터 $i$번째 행, 왼쪽에서부터 $j$번째 열의 원소를 $f(i,j)$라고 합니다.

- 표에 포함된 $16$개의 원소는 각각 $1,2,3,4$ 중 $1$개입니다.
- $f(f(\dots f(f(A_1,A_2),A_3),\dots),A_N)=X$를 만족합니다.

멋진 표가 존재하는지 판정하고, 존재한다면 $1$개 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
$X$
```

## 제한

- 입력은 모두 정수입니다.
- $2 \le N \le 100$
- $A_1,A_2,\dots,A_N,X$는 각각 $1,2,3,4$ 중 $1$개입니다.

## 출력

$1$번째 줄에 멋진 표가 존재하면 `Yes`를, 존재하지 않으면 `No`를 출력하세요.

멋진 표가 존재한다면 이어서 $4$줄을 출력하세요. 그중 $i=1,2,3,4$번째 줄에는 $f(i,1),f(i,2),f(i,3),f(i,4)$를 공백으로 구분하여 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
1 2 3 4
3
```

#### 출력

```text
Yes
1 2 3 4
2 3 4 1
3 4 1 2
4 1 2 3
```

$f(f(f(1,2),3),4)=f(f(2,3),4)=f(4,4)=3$을 만족합니다.

여기서 $f$를 이항 연산으로 생각하면 왼쪽 결합임에 주의하세요.

### 예제 2 {file=""}

#### 입력

```text
2
4 3
1
```

#### 출력

```text
Yes
3 3 1 3
3 1 1 3
3 3 1 3
3 1 1 1
```
