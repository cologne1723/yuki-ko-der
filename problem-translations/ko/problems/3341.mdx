## 문제 설명

정수 $N$이 주어집니다. $1$부터 $N^2$까지의 번호가 붙은 $N^2$개의 정점을 가지는 단순 연결 무향 그래프 중 다음 조건을 모두 만족하는 그래프를 **아름다운 그래프**라고 합니다.

- $1 \leq i < j \leq N^2$를 만족하는 모든 정수의 쌍 $(i,j)$에 대하여, 정점 $i$와 정점 $j$ 사이의 최단 경로 길이는 $N$ 이하입니다.
- 모든 정점의 차수는 $4$입니다.
- $1 \leq i \leq N^2$를 만족하는 모든 정수 $i$에 대하여, $i$에 인접한 $4$개의 정점의 번호의 합을 $A_i$라고 하면 $4i \equiv A_i \pmod{N^2}$가 성립합니다.

단순 연결 무향 그래프란 자기 자신으로 이어지는 간선($2$개의 끝점이 같은 정점인 간선)이나 다중 간선(같은 $2$개의 정점 사이에 여러 개 존재하는 간선)이 없고, 임의의 $2$개의 정점 사이를 간선을 따라 이동할 수 있는 그래프를 뜻합니다.

아름다운 그래프가 존재하는지 판정하고, 존재한다면 그 예를 $1$개 제시하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

## 제한

- $1 \leq N \leq 50$
- 입력되는 값은 모두 정수입니다.

## 출력

아름다운 그래프가 존재하지 않는다면 $-1$을 출력하세요.

존재한다면 $1$번째 줄에 간선의 개수 $M$을 출력하세요. 이어지는 $M$개의 줄 중 $i$번째 줄에는 $2$개의 정수를 공백으로 구분하여 출력하세요. 이 $2$개의 정수는 $i$번째 간선의 양 끝점인 정점 번호를 나타냅니다.

구성한 그래프가 아름다운 그래프라면 정답으로 인정됩니다.
