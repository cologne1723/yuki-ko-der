## 문제 설명

Vega는 벽돌로 평면 피라미드를 만들려고 합니다.

정원에는 이미 벽돌이 빈틈없이 $N$열 쌓여 있으며, $i$번째 열에 쌓인 개수는 $A_i$입니다.

처음 배치에서 벽돌을 몇 개 옮겨 피라미드 모양으로 재배치하려고 합니다.

피라미드 배치란 $1$부터 시작하여 중심 위치까지 $1$씩 증가하고, 중심 이후에는 $1$씩 감소하는 배치입니다. 예를 들어 `[1,2,3,4,3,2,1]`과 같습니다. 따라서 피라미드 배치의 열 수는 홀수입니다.

피라미드와 다른 곳에 버리는 장소도 있으며, 피라미드 배치에 사용하지 않은 벽돌은 그곳으로 옮길 수 있습니다.

이동이란 임의의 열 맨 위에 있는 벽돌 하나를 들어 다른 열이나 버리는 장소로 옮기는 것입니다.

피라미드는 처음 배치의 1번째 열에 있는 벽돌의 위치에서 시작한다고 합니다. 주어진 열 수보다 더 큰 열 수의 피라미드가 될 수도 있습니다.

처음 배치에서 벽돌을 0개 이상 옮겨 피라미드 배치를 만들기 위한 최소 이동 횟수를 구하세요.

피라미드가 놓이는 장소에는 피라미드 하나만 있고, 필요 없는 벽돌은 모두 버리는 장소로 옮긴다고 합니다.

모든 벽돌은 같은 크기의 정육면체입니다.

## 입력

```text
N
A_1 A_2 ... A_N
```

모든 입력은 정수입니다.

- $1 \le N \le 100$
- $1 \le A_i \le 100$

## 출력

피라미드 배치를 만들기 위한 최소 이동 횟수를 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

```text
5
2 2 2 1 2
```

```text
2
```

1번째 열의 벽돌을 3번째 열로 옮기고 5번째 열의 벽돌을 4번째 열로 옮기면 피라미드 배치가 됩니다. 따라서 벽돌 2개를 옮기면 됩니다.

```text
3
3 2 3
```

```text
4
```

벽돌 4개를 버리는 장소로 옮기면 피라미드 배치가 됩니다.
