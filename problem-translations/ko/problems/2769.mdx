## 문제

2차원 평면에 서로 다른 점 `N`개가 주어집니다. 이 중 서로 다른 네 점을 골라 만들 수 있는 사각형 중 마름모인 것의 개수를 구하세요.

## 제약

- `4 ≤ N ≤ 1000`
- 좌표는 `-10^9` 이상 `10^9` 이하입니다.

## 입력

```text
N
x_1 y_1
⋮
x_N y_N
```

## 출력

마름모의 개수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
9
0 0
0 1
0 2
1 0
1 1
1 2
2 0
2 1
2 2
```

#### 출력

```text
6
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
4
0 0
0 1
2 0
2 1
```

#### 출력

```text
0
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
16
0 0
0 1
0 2
0 3
1 0
1 1
1 2
1 3
2 0
2 1
2 2
2 3
3 0
3 1
3 2
3 3
```

#### 출력

```text
22
```
