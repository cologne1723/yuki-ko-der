## 문제

2차원 평면에 서로 다른 점 `N`개가 주어집니다. 이 중 서로 다른 네 점을 골라 만들 수 있는 사각형 중 마름모인 것의 개수를 구하세요.

## 제약

- `4 ≤ N ≤ 1000`
- 좌표는 `-10^9` 이상 `10^9` 이하입니다.

## 입력

```text
N
x_1 y_1
⋮
x_N y_N
```

## 출력

마름모의 개수를 출력하세요.
