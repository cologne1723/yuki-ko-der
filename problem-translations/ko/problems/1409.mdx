## 문제

`xv+1`이 소수인 양의 정수 `v,x`가 주어집니다. 다음을 만족하는 오름차순 수열 `a_1,...,a_x`를 하나 출력하세요.

- `1\le a_1<\cdots<a_x\le xv`
- `1\le k<x`에 대해 `\sum_i a_i^k`는 `xv+1`로 나누어떨어집니다.
- `\sum_i a_i^x`를 `xv+1`로 나눈 나머지는 `x`입니다.

`T`개의 테스트 케이스가 주어집니다.

## 입력

테스트 케이스 수와 각 `v,x`가 주어집니다.

## 출력

각 테스트 케이스에 대해 조건을 만족하는 수열을 출력하세요.
