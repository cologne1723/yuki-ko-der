## 이야기

yuki君은 수열 안에 같은 값이 나란히 놓이면 행복해집니다.

## 문제 설명

$N$개의 원소로 이루어진 수열 $A$가 주어집니다. $A$의 인접한 원소를 정확히 $1$번만 서로 바꾸어, 서로 같은 값을 가진 인접한 원소 쌍이 $1$쌍 이상 존재하도록 만들 수 있는지 판정하세요.

보다 형식적으로, 다음 조작을 정확히 $1$번 수행합니다.

- 임의의 $i$ ($1 \le i \le N-1$)를 선택하고, $A_i$와 $A_{i+1}$을 서로 바꿉니다.

조작 후 $1 \le j \le N-1$인 $j$ 중 $A_j=A_{j+1}$를 만족하는 $j$가 존재하도록 만들 수 있는지 판정하세요.

## 입력

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
```

$1$번째 줄에 수열의 원소 개수 $N$이 주어집니다.

$2$번째 줄에 수열의 원소 $A_1,A_2,\dots,A_N$이 주어집니다.

## 제한

- $2 \le N \le 500$
- $1 \le A_i \le 100$
- 입력은 모두 정수입니다.

## 출력

조건을 만족하면 `Yes`를, 만족하지 않으면 `No`를 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
1 3 2 3
```

#### 출력

```text
Yes
```

$i=3$에 대해 조작하면 $A_3$과 $A_4$가 서로 바뀌어 $A=(1,3,3,2)$가 됩니다.

이때 $A_2=3$, $A_3=3$이므로 같은 원소가 서로 이웃하게 되어 조건을 만족합니다.

### 예제 2 {file=""}

#### 입력

```text
5
1 1 1 1 1
```

#### 출력

```text
Yes
```

어떻게 조작해도 조건을 만족합니다.

### 예제 3 {file=""}

#### 입력

```text
5
1 2 3 4 1
```

#### 출력

```text
No
```
