## 문제

함수 `f(i)=A_i`와 그 합성 `f^k(i)`를 정의합니다. `N`개 정점의 그래프에 모든 `i`와 `L ≤ k ≤ R`에 대해 `i`에서 `f^k(i)`로 향하는 길이 1의 간선을 추가합니다.

`Q`개의 질의 `(S_i,T_i)`에 대해 정점 `S_i`에서 `T_i`까지의 최단 거리를 출력하세요. 도달할 수 없으면 `-1`을 출력합니다.

## 제약

- `2 ≤ N ≤ 10^5`, `1 ≤ L ≤ R ≤ 10^5`, `1 ≤ Q ≤ 10^5`
- `1 ≤ A_i ≤ N`, `S_i ≠ T_i`

## 입력

```text
N L R
A_1 A_2 ... A_N
Q
S_1 T_1
⋮
S_Q T_Q
```

## 출력

각 질의의 답을 출력하세요.
