## 문제 설명

$N$명의 참가자가 있으며, $i$번째 참가자를 참가자 $i$라고 부릅니다.

이 중 $M$쌍은 사이가 나빠서 같은 팀에 넣을 수 없습니다.

모든 참가자를 정확히 $2$개의 팀으로 나눌 수 있는지 판정하세요.
단, $2$개 팀 중 $1$개가 비어 있어도 괜찮습니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ M$
$a_1\ b_1$
$\vdots$
$a_M\ b_M$
```

각 $a_i$와 $b_i$는 사이가 나쁜 $1$쌍을 나타냅니다.

## 제한

- $2\le N\le 2\times 10^5$
- $0\le M\le 2\times 10^5$
- $1\le a_i<b_i\le N$
- 같은 쌍은 $2$번 이상 주어지지 않습니다.
- 입력은 모두 정수입니다.

## 출력

나눌 수 있다면 `Yes`를, 나눌 수 없다면 `No`를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="1_sample_1.txt"}

#### 입력

```text
4 3
1 2
2 3
3 4
```

#### 출력

```text
Yes
```

참가자 $1,3$과 참가자 $2,4$로 나누면, 사이가 나쁜 모든 쌍이 서로 다른 팀에 들어갑니다.

### 예제 2 {file="1_sample_2.txt"}

#### 입력

```text
3 3
1 2
2 3
1 3
```

#### 출력

```text
No
```

$3$명이 서로 모두 사이가 나쁘므로, $2$개의 팀으로 나눌 수 없습니다.
