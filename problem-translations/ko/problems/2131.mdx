소문자 문자열 $T$에 대해, $T$의 부분 수열 중 연속한 부분 문자열로 `con`을 $i$번 포함하는 것이 존재하는 최대의 음이 아닌 정수를 $f(T)$라고 하자냥. 여기서 부분 수열은 반드시 연속할 필요가 없냥.

길이 $N$인 모든 소문자 문자열 $S$에 대해 $f(S)$의 합을 구하고, $998244353$으로 나눈 나머지를 출력하라냥.

## 조건

- $3 \le N \le 3000$

## 입력

입력은 다음 형식으로 주어진냥.

```text
N
```

## 출력

답을 $998244353$으로 나눈 나머지를 출력하라냥.

예제는 원문을 참고하라냥.
