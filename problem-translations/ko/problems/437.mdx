## 문제

C군은 수를 사용하는 게임을 하고 있습니다. 먼저 양의 정수 N이 주어집니다. 게임의 목표는 N에서 몇 개의 cww 수를 잘 골라 뽑아 그 합을 최대한 크게 만드는 것입니다.

- cww 수는 10진수 표기가 cww인 수입니다. 단, c ≠ 0이고 c ≠ w입니다. 예를 들어 355와 700은 cww 수지만 123, 551, 099는 cww 수가 아닙니다.
- 게임은 다음과 같이 진행됩니다.

```text
N = a₀ a₁ ... aₗ₋₁ (10진수 표기)
I = {0, 1, ..., L-1}
score = 0

반복:
    I에서 서로 다른 세 원소 i, j, k (i < j < k)를 선택한다.
    x = aᵢ aⱼ aₖ가 cww 수이면
        score += x
        I에서 i, j, k를 제거한다.
    x가 cww 수가 되는 i,j,k 선택 방법이 없으면 종료한다.
```

C군이 최종적으로 얻을 수 있는 score의 최댓값을 구하세요.

## 입력

양의 정수 N이 한 줄에 주어집니다.

```text
N
```

- 1 ≤ N ≤ 10^12

## 출력

C군이 얻을 수 있는 score의 최댓값을 한 줄에 출력하고, 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
133144
```

### 샘플 1 출력 {file="sample1.out"}

```text
344
```

처음에 (i,j,k) = (2,4,5)를 고르면 cww 수 344를 만들 수 있습니다. 남은 부분에서는 cww 수를 만들 수 없으므로 이것이 최대 score입니다. (0,1,2), (3,4,5)를 차례로 고르면 133과 144를 만들 수 있지만 합은 277로 344보다 작습니다.

### 샘플 2 {file="sample2.in"}

```text
11
```

### 샘플 2 출력 {file="sample2.out"}

```text
0
```

cww 수를 하나도 만들 수 없으므로 답은 0입니다.

### 샘플 3 {file="sample3.in"}

```text
2718281828
```

### 샘플 3 출력 {file="sample3.out"}

```text
1821
```
