## 문제

정수 $N$이 주어집니다. 다음 조건을 만족하는 양의 정수 $N$개로 이루어진 수열 하나를 구성하세요. 조건을 만족하는 수열은 반드시 존재함이 증명되어 있습니다.

- 모든 원소의 합을 3으로 나눈 나머지가 1입니다.
- 모든 원소의 곱이 3의 배수입니다.
- 모든 원소의 합이 312456 이하입니다.

## 입력

~~~text
$N$
~~~

$2\leq N\leq10^5$인 정수입니다.

## 출력

조건을 만족하는 수열 하나를 출력하세요. 각 숫자 사이에는 공백을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
3
~~~

#### 출력

~~~text
12344 12632 2142
~~~

합은 27118이고 3으로 나눈 나머지는 1이며, 곱은 3의 배수이므로 조건을 만족합니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
4
~~~

#### 출력

~~~text
4086 3264 1123 2478
~~~
