## 문제 설명

$H \times W$ 격자가 있습니다. 위에서 $i$번째 행, 왼쪽에서 $j$번째 열에 있는 칸을 $(i,j)$로 나타냅니다. 각 칸의 상태는 문자 $S_{i,j}$로 나타내며, `.`이면 빈 칸, `#`이면 장애물 칸, `R`이면 로봇 칸을 의미합니다.

또한 이 격자는 토러스 형태입니다. 즉, 칸 $(i,W)$의 오른쪽에 있는 칸은 $(i,1)$이고, 칸 $(H,j)$의 아래쪽에 있는 칸은 $(1,j)$입니다.

로봇 칸은 격자에 정확히 $1$개 존재하며, 처음에는 로봇 칸에 로봇이 $1$개 놓여 있습니다. TSG くん은 다음 조작을 수행할 수 없게 될 때까지 반복합니다.

- 로봇이 놓인 칸의 오른쪽 아래 칸이 장애물 칸이 아니라면, 로봇을 오른쪽 아래 칸으로 이동합니다.

조작이 종료하는지 판정하고, 종료한다면 최종적으로 로봇이 놓인 칸을 구하세요.

## 입력

```text
$H\ W$
$S_{1,1}S_{1,2}\cdots S_{1,W}$
$S_{2,1}S_{2,2}\cdots S_{2,W}$
$\vdots$
$S_{H,1}S_{H,2}\cdots S_{H,W}$
```

각 입력 행은 $W$개의 문자를 공백 없이 이어 붙인 문자열입니다.

입력은 다음 제한을 만족합니다.

## 제한

- $1 \leq H,W \leq 1\,000$
- $H$, $W$는 정수입니다.
- $S_{i,j}$는 `.`, `#`, `R` 중 $1$개입니다.
- $S_{i,j}=$ `R`인 $(i,j)$가 정확히 $1$개 존재합니다.

## 출력

조작이 종료한다면 최종적으로 로봇이 놓인 칸을 $(i,j)$라고 할 때, $i$, $j$를 공백으로 구분하여 출력하세요.

조작이 종료하지 않는다면 대신 `loop`를 출력하세요.

마지막 줄바꿈이나 공백의 유무는 상관없습니다. 공백으로 구분하는 대신 줄바꿈으로 구분해도 됩니다.

## 점수

예상 해답의 길이는 $108$바이트입니다.

제출한 소스 코드의 코드 길이가 $x$이고 이 문제의 예상 해답 코드 길이가 $y$일 때, 해당 소스 코드의 점수는 $\max(500-x+y,100)/2$점입니다.

이 문제의 점수는 이 문제에 제출된 소스 코드의 점수 중 최댓값입니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 4
..R#
#.#.
....
##..
```

#### 출력

```text
3 1
```

로봇은 처음에 $(1,3)$에 놓여 있습니다. 그 후 조작에 의해 $(2,4)$, $(3,1)$로 이동하고, $(4,2)$가 장애물 칸이므로 조작할 수 없게 됩니다.

따라서 최종적으로 로봇이 놓인 칸인 $(3,1)$을 공백으로 구분하여 출력하세요.

### 예제 2 {file=""}

#### 입력

```text
3 3
...
.R.
...
```

#### 출력

```text
loop
```

로봇은 $(2,2)$, $(3,3)$, $(1,1)$, $(2,2)$, $(3,3)$, $\ldots$와 같이 이동하므로 조작이 끝나지 않습니다.

따라서 `loop`를 출력하세요.
