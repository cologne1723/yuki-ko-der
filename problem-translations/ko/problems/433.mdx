## 문제

ICPC 국내 예선에 총 N개의 팀이 참가했습니다. 팀에는 0, 1, ..., N − 1의 번호가 붙어 있습니다.

각 팀에 대해 푼 문제 수, 페널티, 어느 대학의 팀인지가 주어집니다. 국내 예선을 통과할 수 있는 팀은 K개이며, 다음 알고리즘으로 한 팀씩 선발합니다.

1. 아직 선발되지 않은 팀 중 푼 문제 수가 가장 많은 팀을 선발합니다.
2. 푼 문제 수가 가장 많은 팀이 여러 개이면, 지금까지 선발된 같은 대학 팀 수가 가장 적은 팀을 선발합니다.
3. 푼 문제 수와 지금까지 선발된 같은 대학 팀 수가 같은 팀이 여러 개이면, 페널티가 가장 적은 팀을 선발합니다.

이 정보로부터 국내 예선을 통과한 팀을 구하세요.

## 입력

첫째 줄에 참가 팀 수 N과 선발 팀 수 K가 주어집니다. 다음 N개 줄에 각 팀의 정보가 주어지며, Sᵢ는 i번째 팀이 푼 문제 수, Pᵢ는 페널티, Uᵢ는 출신 대학을 수치화한 값입니다.

```text
N K
S₁ P₁ U₁
S₂ P₂ U₂
⋮
S_N P_N U_N
```

- 1 ≤ N ≤ 10^5
- 1 ≤ K ≤ N
- 0 ≤ Sᵢ ≤ 10
- 0 ≤ Pᵢ ≤ 10^6
- 1 ≤ Uᵢ ≤ 10^5
- Pᵢ, Uᵢ는 정수입니다.
- 서로 다른 i, j에 대해 (Sᵢ, Pᵢ)와 (Sⱼ, Pⱼ)는 같지 않습니다.

## 출력

선발된 K개 팀을 0-indexed로, 선발된 순서대로 한 줄에 하나씩 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
5 3
3 100 1
4 200 1
4 300 1
3 150 2
2 50 2
```

### 샘플 1 출력 {file="sample1.out"}

```text
1
2
3
```

먼저 1번 팀을 선택합니다. 가장 많은 문제를 푼 팀은 1번과 2번이지만 같은 대학 출신이므로 지금까지 선발된 같은 대학 팀 수도 같습니다. 페널티가 더 작은 1번 팀이 먼저 선발됩니다.

다음으로 아직 선발되지 않은 팀 중 가장 많은 문제를 푼 팀은 2번뿐이므로 2번 팀이 선발됩니다.

마지막으로 0번과 3번 팀이 가장 많은 문제를 풀었습니다. 대학 1에서는 이미 2팀이 선발되었지만 대학 2에서는 아직 한 팀도 선발되지 않았으므로 3번 팀이 선발됩니다. 따라서 선발 순서대로 K개 팀을 출력하면 1, 2, 3입니다.

### 샘플 2 {file="sample2.in"}

```text
3 2
4 100 1
5 300 2
3 100 2
```

### 샘플 2 출력 {file="sample2.out"}

```text
1
0
```

선발된 순서대로 출력해야 한다는 점에 주의하세요.
