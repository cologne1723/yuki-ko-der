길이 `N`인 두 수열 `A,B`가 있습니다. `k>=2`, `ki,kj<=N`인 양의 정수 `k,i,j`를 골라 `A_{ki}`와 `A_{kj}`를 교환할 수 있습니다.

이 연산으로 `A`를 `B`로 만들 수 있는지 판정하세요.

## 제약

- `1 <= T,N <= 10^5`
- `1 <= A_i,B_i <= 10^9`
- 모든 테스트 케이스에서 `N`의 합은 `10^5` 이하입니다.

## 입력

테스트 케이스마다 `N`, 수열 `A`, 수열 `B`가 주어집니다.

## 출력

가능하면 `Yes`, 아니면 `No`를 출력하세요.
