## 문제

2차원 좌표 (AX,AY)에 보물이 묻혀 있지만, 당신은 그 좌표값을 모릅니다. AX와 AY는 모두 0 이상 100000 이하의 정수입니다.

어떤 좌표를 질문하면 보물 위치까지의 맨해튼 거리를 알 수 있습니다.

100번 이내의 질문으로 보물이 묻힌 위치를 특정하세요.

## 입출력 설명

이 문제는 리액티브 문제입니다.

질문할 좌표 (X,Y)를 다음과 같이 X와 Y 사이를 반각 공백으로 구분해 출력하세요. 출력 마지막에는 줄바꿈을 넣습니다.

X,Y는 부호 있는 32비트 정수에 들어가는 정수로 출력해야 합니다.

출력한 뒤에는 매번 flush해야 합니다.

출력이 끝날 때마다 출력한 위치에서 보물 위치까지의 맨해튼 거리를 표준 입력으로 받습니다.

질문은 최대 100번 할 수 있으며, 맨해튼 거리가 0인 출력을 한 뒤 종료하면 정답입니다.

## 샘플 코드

```cpp
 // 좌표 (0,0)부터 (0,99)까지 시도합니다.
int main(){
  for(int i=0;i<100;i++){
    cout << 0 << " " << i << endl;
    int d;
    cin>>d;
    if(d==0)return 0;
  }
  return 0;
}
```
