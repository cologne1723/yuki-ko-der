## 문제 설명

테이블 위에 $N$개의 정수가 왼쪽부터 오른쪽으로 $1$줄로 나열되어 있습니다.

이제 다음 연산을 $0$회 이상 원하는 횟수만큼 수행합니다.

- 정수 $l,r$을 $1 \le l \le r \le N$이 되도록 선택합니다. 테이블의 왼쪽에서 $l,l+1,\dots,r$번째 정수를 모두 그 정수들의 최댓값으로 바꿉니다.

연산을 수행한 후 각 정수의 절댓값의 합으로 가능한 최댓값을 구하세요.

## 입력

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
```

$1$번째 줄에 테이블 위에 나열된 정수의 개수 $N$이 주어집니다.

$2$번째 줄에 테이블 위에 나열된 $N$개의 정수 $A_1,A_2,\dots,A_N$이 공백으로 구분되어 주어집니다.

## 제한

- $1 \le N \le 200\,000$
- $-1\,000\,000\,000 \le A_i \le 1\,000\,000\,000$

## 출력

연산을 수행한 후 각 정수의 절댓값의 합으로 가능한 최댓값을 출력하세요.

마지막에 개행을 출력하세요.
