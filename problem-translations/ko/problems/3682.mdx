## 문제 설명

하늘색 실력자인 岩井星人さん과 초록색 실력자인 岩井星人さん이 싸웁니다.

하늘색 실력자인 岩井星人さん의 처음 체력은 $H_C$, 공격력은 $A_C$, 속도는 $S_C$입니다.

초록색 실력자인 岩井星人さん의 처음 체력은 $H_G$, 공격력은 $A_G$, 속도는 $S_G$입니다.

싸움은 다음과 같이 진행됩니다.

1. $2$명의 岩井星人さん의 속도가 다르면 속도가 더 큰 岩井星人さん이 공격합니다. 다른 岩井星人さん은 공격을 받습니다. 속도가 같으면 $1/2$ 확률로 하늘색 실력자인 岩井星人さん이 공격하고, $1/2$ 확률로 초록색 실력자인 岩井星人さん이 공격합니다.
2. $1$번에서 공격하지 않은 岩井星人さん이 공격합니다.
3. $1$번으로 돌아갑니다.

공격이 이루어지면 공격을 받은 岩井星人さん의 체력이 공격한 岩井星人さん의 공격력만큼 감소합니다.

$2$명의 岩井星人さん 모두 기합의 머리띠를 가지고 있으므로, 공격을 받아 체력이 $0$ 이하가 될 때 $1/10$ 확률로 체력을 $1$ 남기고 버틸 수 있습니다. 체력이 $1$인 상태에서 공격을 받을 때도 $1/10$ 확률로 체력을 $1$ 남기고 버틴다는 점에 주의하세요.

더 형식적으로, 현재 체력이 $H$인 岩井星人さん이 공격력 $A$인 岩井星人さん의 공격을 받을 때 다음과 같이 됩니다.

- $H>A$이면 공격을 받은 岩井星人さん의 새로운 체력은 $H-A$입니다.
- $H\leq A$이면 공격을 받은 岩井星人さん의 새로운 체력은 $1/10$ 확률로 $1$, $9/10$ 확률로 $H-A$입니다.

어느 한쪽의 체력이 $0$ 이하가 된 즉시 싸움은 종료되고, 체력이 $0$ 이하가 된 岩井星人さん이 패배합니다. (패배하지 않은 岩井星人さん이 승리합니다.)

싸움이 끝났을 때 하늘색 실력자인 岩井星人さん이 이길 확률을 $\mathrm{mod}\ 998\,244\,353$로 구하세요.

### 확률 $\mathrm{mod}\ 998\,244\,353$이란

구해야 하는 확률은 반드시 유리수가 된다는 것이 증명되어 있습니다. 또한 이 문제의 제한에서 그 값을 기약분수 $\frac{P}{Q}$로 나타냈을 때 $Q\not\equiv 0\pmod{998\,244\,353}$가 된다는 것도 증명되어 있습니다.

따라서 $R\times Q\equiv P\pmod{998\,244\,353}$, $0\leq R<998\,244\,353$를 만족하는 정수 $R$이 유일하게 정해집니다. 이 $R$을 출력하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $\mathrm{case}_i$는 $i$번째 테스트 케이스를 의미합니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식입니다.

```text
$H_C\ A_C\ S_C\ H_G\ A_G\ S_G$
```

## 제한

- 입력은 모두 정수입니다.
- $1\leq T\leq2\times10^4$
- $1\leq H_C,A_C,S_C,H_G,A_G,S_G\leq10^{18}$

## 출력

$T$개의 줄에 출력하세요. $i$번째 줄에는 $i$번째 테스트 케이스의 답을 출력하세요.
