## 문제 설명

$N$쌍의 부부, 총 $2N$명이 여행을 가기로 했습니다.

$2N$명은 여러 그룹으로 나뉘어 각 그룹 구성원의 차로 이동합니다. 모든 부부는 큰 차를 가지고 있어 그룹에 차가 한 대만 있으면 그룹 전체가 이동할 수 있습니다.

단, 각 부부가 차를 빌려주는 것은 부부가 같은 그룹에 있을 때뿐입니다. 따라서 각 그룹이 차로 안전하게 여행하려면 그룹에 부부 한 쌍 이상이 포함되어야 합니다.

조건을 만족하는 그룹 분할 방법의 수를 $10^9+7$로 나눈 나머지로 출력하세요.

## 입력

```text
N
```

$(1 \le N \le 555)$

## 출력

모두가 여행할 수 있는 그룹 분할 방법의 수를 한 줄에 출력하세요.

예상 풀이에서 최대 입력의 실행 시간은 Python으로 1.2초입니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
```

#### 출력

```text
2
```

두 부부를 A-a, B-b라고 합시다(A와 a가 부부이고, B와 b가 부부입니다).

- 한 그룹으로 이동하는 경우는 `{AaBb}` 1가지입니다.
- 두 그룹으로 이동하는 경우는 `{Aa, Bb}` 1가지입니다.

따라서 합계는 2가지입니다. `{Ab, aB}`와 같은 분할은 두 그룹 모두 차를 사용할 수 없으므로 조건을 만족하지 않습니다.

### 예제 2 {file=""}

#### 입력

```text
3
```

#### 출력

```text
11
```

세 부부를 A-a, B-b, C-c라고 합시다.

- 한 그룹으로 이동하는 경우는 `{AaBbCc}` 1가지입니다.
- 두 그룹으로 이동하는 경우는 다음 9가지입니다.
  - `{AaBb, Cc}`, `{AaCc, Bb}`, `{Aa, BbCc}`
  - `{AaC, Bbc}`, `{Aac, BbC}`, `{ABb, aCc}`, `{aBb, ACc}`, `{AaB, bCc}`, `{Aab, BCc}`
- 세 그룹으로 이동하는 경우는 `{Aa, Bb, Cc}` 1가지입니다.

따라서 합계는 11가지입니다.
