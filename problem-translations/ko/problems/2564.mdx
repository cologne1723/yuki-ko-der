$T$개의 테스트 케이스가 주어집니다. $xy$평면 위의 두 자동차가 각각 초속 $1$로 이동할 때, 어느 시각에 두 자동차가 같은 좌표에 있으면 충돌한다고 합니다. 충돌 여부를 판정하세요.

## 조건

- $1\le T\le10^5$
- 좌표는 $-10^9$ 이상 $10^9$ 이하이고 두 시작점은 다릅니다.
- 방향은 `R`, `L`, `U`, `D` 중 하나입니다.

## 입력

```text
$T$
$x_1$ $y_1$ $d_1$
$x_2$ $y_2$ $d_2$
```

## 출력

각 테스트 케이스에 대해 충돌하면 `Yes`, 아니면 `No`를 출력하세요.

## 예제

### 예제 1 {file="1_sample_1.txt"}

#### 입력

```text
2
1 1 U
1 5 D
3 2 U
5 4 L
```

#### 출력

```text
Yes
Yes
```

### 예제 2 {file="1_sample_2.txt"}

#### 입력

```text
1
1 2 L
3 4 D
```

#### 출력

```text
No
```

### 예제 3 {file="1_sample_3.txt"}

#### 입력

```text
3
998244353 0 U
0 998244353 R
998244353 998244353 U
0 0 D
0 0 R
998244353 0 L
```

#### 출력

```text
Yes
No
Yes
```
