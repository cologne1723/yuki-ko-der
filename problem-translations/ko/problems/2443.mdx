$N$개의 정수 계수 $2\times2$ 행렬 $A_n$이 주어집니다. 모든 행렬식은 1입니다. 쿼리 $(L,R,x,y)$마다 벡터 $(x,y)$에 $A_{L+1},A_{L+2},\ldots,A_R$를 순서대로 곱한 뒤 결과를 $B$로 나눈 나머지를 출력하세요.

## 입력

```text
N B Q
A1의 4개 성분
...
AN의 4개 성분
L R x y
```

## 출력

각 쿼리의 두 나머지를 출력하세요.
