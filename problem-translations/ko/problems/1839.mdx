각 원소가 1부터 9인 길이 $N$의 수열 $a_1,\ldots,a_N$이 주어집니다. $X_{1,j}=a_j$로 정하고, $i>1$일 때 $X_{i,j}$를 $X_{i-1,j}$와 $X_{i-1,j+1}$의 십진 표기를 이어 붙인 수로 정합니다. $X_{i-1,N+1}=X_{i-1,1}$로 봅니다.

## 문제

각 $j$에 대해 $X_{N,j}$를 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
N
a_1 a_2 ... a_N
```

$2\le N\le10^5$, $1\le a_i\le9$입니다.

## 출력

$N$개의 답을 각각 한 줄에 출력하세요.
