## 문제 설명

어떤 온라인 저지에는 저지 서버가 $1$대 있으며, $N$개의 제출을 큐의 앞에서부터 순서대로 처리합니다. 제출 $i$의 실행 시간은 $T_i$밀리초입니다. 모든 제출은 시각 $0$에 큐에 들어가며, 서버는 시각 $0$부터 처리를 시작합니다.

제출 $i$의 저지가 완료되는 시각은 $C_i = T_1 + T_2 + \cdots + T_i$입니다.

$Q$개의 질의가 주어집니다. 각 질의에서는 시각 $X_j$가 주어지므로, 시각 $X_j$까지 저지가 완료된 제출의 수를 출력하세요. 즉, $C_i \le X_j$를 만족하는 $i$의 개수를 구하세요.

## 입력

```text
$N\ Q$
$T_1\ T_2\ \cdots\ T_N$
$X_1$
$X_2$
$\vdots$
$X_Q$
```

입력은 모두 정수입니다.

## 제한

- $1 \le N \le 200\,000$
- $1 \le Q \le 200\,000$
- $1 \le T_i \le 10^9$
- $0 \le X_j \le 10^{18}$

부분 점수는 다음과 같습니다.

- 샘플: 샘플 케이스 ($10$%, $25$점)
- 소과제: $N, Q \le 200$ ($30$%, $75$점)
- 대과제: 추가 제한 없음 ($60$%, $150$점)

## 출력

$Q$개의 줄에 각 질의의 답을 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 3
3 1 4 1 5
5
14
2
```

#### 출력

```text
2
5
0
```

각 제출의 완료 시각은 $C = [3, 4, 8, 9, 14]$입니다.

$X = 5$일 때 $C_1 = 3 \le 5$, $C_2 = 4 \le 5$, $C_3 = 8 > 5$이므로 $2$개입니다.

$X = 14$일 때 모든 $C_i \le 14$이므로 $5$개입니다.

$X = 2$일 때 $C_1 = 3 > 2$이므로 $0$개입니다.

### 예제 2 {file=""}

#### 입력

```text
3 4
10 10 10
0
9
10
30
```

#### 출력

```text
0
0
1
3
```

완료 시각은 $C = [10, 20, 30]$입니다.

$X = 0$일 때 $0$개, $X = 9$일 때 $0$개, $X = 10$일 때 $1$개, $X = 30$일 때 $3$개입니다.

### 예제 3 {file=""}

#### 입력

```text
1 1
1000000000
1000000000
```

#### 출력

```text
1
```
