## 이야기

세상에서는 gcc `4.8.1`을 화석이라고 부르는 것 같습니다.

## 문제 설명

화석이라고 불리는 버전이 $A.B.C$ 형식으로 주어집니다. 같은 형식으로 주어진 버전이 화석 버전인지 판정하세요.

화석 버전이면 `YES`, 아니면 `NO`를 출력하세요.

화석 버전이란 기준 버전과 같거나 그보다 오래된 버전입니다. 오래된 버전은 `.`으로 구분된 수를 왼쪽부터 비교했을 때 처음으로 다른 값이 더 작은 버전입니다. 예를 들어 $4.8.1$보다 $4.7.9$가 오래되었고, $4.9.0$과 $5.0.1$은 새 버전입니다.

## 입력

```text
$A_0.B_0.C_0$
$A_1.B_1.C_1$
```

$1$번째 줄은 화석이라고 불리는 기준 버전, $2$번째 줄은 판정할 버전입니다. 각 성분은 정수이며 `.`으로 구분됩니다.

## 제한

$(0 \le i \le 1)$

$(0 \le A_i \le 100)$

$(0 \le B_i \le 100)$

$(0 \le C_i \le 100)$

## 출력

판정할 버전이 화석 버전이면 `YES`, 아니면 `NO`를 출력하세요.
출력 끝에는 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4.8.1
4.8.0
```

#### 출력

```text
YES
```

4.8.1이 화석 버전이면 그보다 오래된 4.8.0도 화석 버전입니다.

### 예제 2 {file=""}

#### 입력

```text
0.0.0
1.1.1
```

#### 출력

```text
NO
```

초기 버전만 화석이라고 불리는 것 같습니다.

### 예제 3 {file=""}

#### 입력

```text
1.2.3
3.2.1
```

#### 출력

```text
NO
```
