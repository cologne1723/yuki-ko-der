## 문제 설명

세상에서는 gcc `4.8.1`을 화석이라고 부르는 것 같습니다.

화석이라고 불리는 버전이 $A.B.C$ 형식으로 주어집니다. $A,B,C$는 각각 0 이상 100 이하의 정수입니다. 같은 형식으로 주어진 버전이 화석 버전인지 판정하세요.

화석 버전이면 `YES`, 아니면 `NO`를 출력하세요.

화석 버전이란 기준 버전과 같거나 그보다 오래된 버전입니다. 오래된 버전은 `.`으로 구분된 수 중 더 왼쪽에 있는 값이 더 작은 버전입니다. 예를 들어 $4.8.1$보다 $4.7.9$가 오래되었고, $4.9.0$과 $5.0.1$은 새 버전입니다.

## 입력

```text
A_0.B_0.C_0
A_1.B_1.C_1
```

첫째 줄은 화석이라고 불리는 기준 버전, 둘째 줄은 판정할 버전입니다. 입력은 정수이며 `.`으로 구분됩니다. $(0 \le i \le 1,\ 0 \le A_i,B_i,C_i \le 100)$

## 출력

판정할 버전이 화석 버전이면 `YES`, 아니면 `NO`를 출력하세요.

## 예제

```text
4.8.1
4.8.0
```

```text
YES
```

4.8.1이 화석 버전이면 그보다 오래된 4.8.0도 화석 버전입니다.

```text
0.0.0
1.1.1
```

```text
NO
```

초기 버전만 화석이라고 불리는 것 같습니다.

```text
1.2.3
3.2.1
```

```text
NO
```
