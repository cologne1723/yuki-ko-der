## 문제

난이도 1, 1.5, 2, 2.5의 문제가 각각 $A,B,C,D$개 있고, 한 문제를 푸는 데 각각 $P,Q,R,S$분이 걸립니다. 정확히 $T$분에 $N$문제를 풀었을 때, 난이도별로 푼 문제 수의 가능한 조합 하나를 출력하세요. 해가 존재하는 입력만 주어집니다.

## 제약

- $1\leq A,B,C,D\leq10^4$
- $1\leq P,Q,R,S\leq10^4$
- $1\leq T\leq4\times10^8$
- $1\leq N\leq A+B+C+D$

## 입력

~~~text
A B C D N
P Q R S T
~~~

## 출력

조건을 만족하는 $(n_a,n_b,n_c,n_d)$를 한 줄에 출력하세요.

## 샘플

### 입력 {file="stdin"}

~~~text
1 3 3 3 8
5 10 15 20 120
~~~

### 출력 {file="stdout"}

~~~text
1 1 3 3
~~~

총 시간은 $1\times5+1\times10+3\times15+3\times20=120$분입니다.
