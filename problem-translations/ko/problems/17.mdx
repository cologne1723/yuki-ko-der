## 문제 설명

$0$번부터 $N-1$번까지 $N$개의 지점이 있습니다. 지점 사이를 이동하는 비용이 $M$개 주어지고, 각 지점에는 머무는 비용이 있습니다.

$0$번 지점에서 $N-1$번 지점에 도착할 때까지 $0$번과 $N-1$번을 제외한 서로 다른 두 지점에 머물러야 합니다. 머무를 지점은 자유롭게 선택할 수 있습니다.

이 조건에서 이동 비용과 머무는 비용의 합의 최솟값을 구하세요.

어떤 도시를 지나가지만 그곳에 머물지 않을 수도 있습니다.

## 입력

```text
N
S_0
S_1
\dots
S_i
\dots
S_{N-1}
M
A_1 B_1 C_1
A_2 B_2 C_2
\dots
A_j B_j C_j
\dots
A_M B_M C_M
```

첫째 줄에 지점의 수 $N$이 주어집니다. $(4 \le N \le 50)$
이후 $N$개의 줄에 $0$번부터 $N-1$번까지 각 지점의 머무는 비용 $S_i$가 주어집니다. $(1 \le S_i \le 1000; 0 \le i \le N-1)$ 단, $0$번과 $N-1$번 지점의 머무는 비용은 $0$입니다.

다음 줄에 이동 정보의 개수 $M$이 주어집니다. $(1 \le M \le N(N-1)/2)$
이후 $M$개의 줄에 출발지 $A_j$, 도착지 $B_j$, 이동 비용 $C_j$가 주어집니다. $(0 \le A_j,B_j \le N-1; 1 \le C_j \le 1000; 1 \le j \le M)$

$A_j$에서 $B_j$로, 그리고 $B_j$에서 $A_j$로 모두 이동할 수 있습니다. 즉, 무방향 그래프입니다. $A_j \ne B_j$이며 같은 두 지점 사이의 이동은 여러 개 주어지지 않습니다.

$0$번에서 $N-1$번으로 가는 경로가 반드시 존재하고, 양 끝점을 제외한 서로 다른 두 지점에 머무를 수 있음이 보장됩니다. 단, $0$번에서 도달할 수 없는 지점이 있을 수 있습니다.

이동 비용과 머무는 비용의 단위는 같으므로 서로 더할 수 있습니다.

## 출력

이동 비용과 머무는 비용의 합의 최솟값을 한 줄에 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
0
2
100
0
5
0 1 1
0 2 1
1 2 1
1 3 1
2 3 2
```

#### 출력

```text
105
```

지점 1과 2에는 반드시 머물러야 합니다. $0 \rightarrow 2 \rightarrow 1 \rightarrow 3$ 순서로 이동하고 두 지점에 머무르면 최소 비용 105가 됩니다.
