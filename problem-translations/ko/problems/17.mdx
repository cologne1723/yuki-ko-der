## 문제 설명

$0$번부터 $N-1$번까지 $N$개의 지점이 있습니다. 한 지점에서 다른 지점으로 이동하는 비용이 $M$개 주어집니다. 각 지점에는 숙박 비용이 있습니다.

$0$번 지점에서 $N-1$번 지점에 도착할 때까지 $0$번과 $N-1$번을 제외한 서로 다른 $2$개 지점에 숙박해야합니다. 숙박 할 지점은 자유롭게 선택할 수 있습니다.

이 조건에서 이동 비용과 숙박 비용 총합의 최솟값을 구하세요.

어떤 지점을 지나가지만 그곳에 숙박하지 않을 수도 있습니다.

## 입력

```text
$N$
$S_0$
$S_1$
$\vdots$
$S_{N-1}$
$M$
$A_1\ B_1\ C_1$
$A_2\ B_2\ C_2$
$\vdots$
$A_M\ B_M\ C_M$
```

$N$은 지점 수이며, 이후 $N$개의 줄에 $0$번부터 $N-1$번까지 각 지점에 숙박 비용 $S_i$가 주어집니다.
$M$은 이동 정보의 개수입니다. 이후 $M$개의 줄에 두 지점 $A_j$, $B_j$와 그 사이의 이동 비용 $C_j$가 주어집니다.
두 방향 모두 이동할 수 있습니다. (즉, 무방향 그래프입니다.) 같은 두 지점 사이의 이동 정보는 중복해서 주어지지 않습니다.
이동 비용과 숙박 비용은 단위가 같으므로 서로 더할 수 있습니다.

## 제한

- $4 \le N \le 50$
- $S_0=S_{N-1}=0$
- $1 \le S_i \le 1\,000$ $(1 \le i \le N-2)$
- $1 \le M \le N(N-1)/2$
- $0 \le A_j,B_j \le N-1$ $(1 \le j \le M)$
- $A_j \ne B_j$ $(1 \le j \le M)$
- $1 \le C_j \le 1\,000$ $(1 \le j \le M)$
- $0$번 지점에서 $N-1$번 지점으로 가는 경로가 존재합니다.
- 양 끝점을 제외한 서로 다른 $2$개 지점에 숙박할 수 있습니다.

## 출력

이동 비용과 숙박 비용의 합의 최솟값을 한 줄에 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
0
2
100
0
5
0 1 1
0 2 1
1 2 1
1 3 1
2 3 2
```

#### 출력

```text
105
```

지점은 모두 $4$개이며, $1$번과 $2$번 지점에는 반드시 숙박해야 합니다. $0 \rightarrow 2 \rightarrow 1 \rightarrow 3$ 순서로 이동하고 두 지점에 숙박하면 최소 비용 $105$가 됩니다.
