참고로 [연속 세제곱 합](https://yukicoder.me/problems/11795), [연속 거듭제곱 합 (소규모)](https://yukicoder.me/problems/12100), [연속 거듭제곱 합 (대규모)](https://yukicoder.me/problems/12101)은 이 순서로 대략적인 상위 호환 관계에 있습니다.

## 문제 설명

$3$개의 양의 정수 $E$, $L$, $R$에 대해 $S(E, L, R)$를 다음과 같이 정의합니다.

$S(E, L, R) \coloneqq \sum_{i = L}^R i^E$

양의 정수 $N$이 주어집니다. 다음 $2$가지 조건을 모두 만족하는 $3$개의 양의 정수 $E$, $L$, $R$로 이루어진 순서 있는 튜플 $(E, L, R)$을 모두 구하세요.

- $1 \le L \le R$
- $S(E, L, R) = N$

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

## 제한

- $2 \le N \le 10^{24}$
- 입력되는 $N$은 $32$비트 정수형과 $64$비트 정수형에 들어가지 않을 수 있음에 주의하세요.

## 출력

문제의 조건을 만족하는 튜플을 해라고 부릅니다. 이 문제의 제한 아래에서는 해가 유한 개임을 증명할 수 있습니다.

해가 모두 $C$개이고, 사전순으로 작은 순서대로

$(E_1, L_1, R_1)$, $(E_2, L_2, R_2)$, $\dots$, $(E_C, L_C, R_C)$

라고 할 때, 다음 형식으로 $C + 1$줄을 출력하세요. 각 줄은 공백으로 구분하고, 마지막에도 줄바꿈을 출력하세요.

```text
$C$
$E_1\ L_1\ R_1$
$E_2\ L_2\ R_2$
$\vdots$
$E_C\ L_C\ R_C$
```

$C$가 커질 수 있으므로, 빠른 방법으로 입출력하는 것을 권장합니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
```

#### 출력

```text
1
1 2 2
```

다음 식이 성립합니다. $L = R$이어도 된다는 점에 주의하세요.

- $S(1, 2, 2) = 2^1 = 2$

$(1, 2, 2)$는 유일한 해입니다.

### 예제 2 {file=""}

#### 입력

```text
24979
```

#### 출력

```text
4
1 12489 12490
1 24979 24979
2 62 67
4 5 10
```

해가 여러 개일 수도 있습니다.

다음 식이 성립합니다.

- $S(1, 12\,489, 12\,490) = 12\,489^1 + 12\,490^1 = 24\,979$
- $S(1, 24\,979, 24\,979) = 24\,979^1 = 24\,979$
- $S(2, 62, 67) = 62^2 + 63^2 + 64^2 + 65^2 + 66^2 + 67^2 = 24\,979$
- $S(4, 5, 10) = 5^4 + 6^4 + 7^4 + 8^4 + 9^4 + 10^4 = 24\,979$

해는 사전순으로 작은 것부터 이 순서로 출력하세요.
