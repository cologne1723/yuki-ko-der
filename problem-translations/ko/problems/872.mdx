## 문제

$N$개의 정점으로 이루어진 트리가 있습니다. $i(1 \leq i \leq N-1)$번째 간선은 정점 $u_i$와 정점 $v_i$를 양방향으로 연결하며 길이는 $w_i$입니다. 정점 $s$와 정점 $t$ 사이의 최단 거리를 $d_{s,t}$라고 할 때, $\sum_{s=1}^{N} \sum_{t=1}^{N} d_{s,t}$를 구하세요. $d_{i,i}=0(1 \leq i \leq N)$으로 정의합니다.

## 입력

~~~text
N
u_1 v_1 w_1
u_2 v_2 w_2
⋮
u_{N-1} v_{N-1} w_{N-1}
~~~

다음 조건을 만족합니다.

- $2 \leq N \leq 2×10^5$
- $1 \leq u_i,v_i \leq N\ (1 \leq i \leq N-1)$
- $1 \leq w_i \leq 100\ (1 \leq i \leq N-1)$
- 주어지는 그래프는 트리입니다.

## 출력

답을 한 줄에 출력하세요. 마지막에 줄 바꿈을 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

~~~text
3
1 2 1
2 3 2
~~~

### 출력 1 {file="stdout"}

~~~text
12
~~~

$d_{1,2}=1,d_{1,3}=3,d_{2,1}=1,d_{2,3}=2,d_{3,1}=3,d_{3,2}=2$이므로 답은 $12$입니다.

### 입력 2 {file="stdin"}

~~~text
5
2 5 2
2 3 10
1 3 8
3 4 7
~~~

### 출력 2 {file="stdout"}

~~~text
256
~~~
