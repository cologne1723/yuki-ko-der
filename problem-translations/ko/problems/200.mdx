## 문제 설명

“카드 파이트!”라는 게임이 유행하고 있습니다. 이 게임의 플레이어를 카드 파이터라고 합니다.

카드 파이터는 숫자가 하나씩 쓰인 카드를 여러 장 가지고 있습니다. 매 경기 손에 든 카드 한 장을 자유롭게 내고 숫자의 크기를 겨룹니다. 숫자가 같으면 무승부이며 승패가 발생하지 않습니다. 사용한 카드는 경기장에 내놓고, 모든 카드를 다 내면 지금까지 낸 카드를 모두 회수하여 다시 사용할 수 있습니다.

A는 카드 파이터의 왕입니다. A와 C는 대회의 결승에서 싸우게 되었고, A는 C보다 많이 이기고 싶습니다. C는 A가 이길 수 있도록 협조하기로 했습니다. 두 사람은 A의 승리 횟수가 최대가 되도록 카드를 내는 순서를 함께 정합니다. A는 최대 몇 경기에서 이길 수 있을까요? 무승부와 패배 횟수는 고려하지 않습니다.

## 입력

```text
N
A
B_1 B_2 ... B_A
C
D_1 D_2 ... D_C
```

- $1 \le N \le 50$: 경기 수
- $1 \le A \le 50$: A가 가진 카드 수
- $1 \le B_i \le 100$: A의 카드 숫자
- $1 \le C \le 50$: C가 가진 카드 수
- $1 \le D_i \le 100$: C의 카드 숫자

## 출력

두 사람이 A의 승리 횟수를 최대로 하도록 순서를 정했을 때 A의 승리 횟수를 출력하세요.

## 예제

### 예제 1

```text
3
2
2 3
3
1 2 3
```

```text
2
```

A는 `2,3,2`, C는 `3,2,1` 순서로 내면 A가 두 경기에서 이길 수 있습니다. A는 카드가 없어지면 카드를 회수하여 다시 사용할 수 있습니다.

### 예제 2

```text
10
3
2 2 2
4
3 3 3 3
```

```text
0
```

어떤 순서로도 A는 이길 수 없습니다.

### 예제 3

```text
7
3
4 5 6
6
1 2 3 4 5 10
```

```text
6
```

예를 들어 A가 `4,5,6,5,6,4,6`, C가 `1,2,3,4,5,10,1` 순서로 내면 7경기 중 6경기에서 A가 이깁니다.
