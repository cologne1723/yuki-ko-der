길이 $N$의 순열 $P$가 주어집니다. 길이가 홀수이고 중앙값이 부분 수열의 정확히 가운데 위치하는 부분 수열의 개수를 구하세요.

## 조건

- $1\le N\le300000$
- $P$는 $1,2,\ldots,N$의 순열입니다.

## 입력

```text
$N$
$P_1$ $P_2$ $\cdots$ $P_N$
```

## 출력

답을 $998244353$으로 나눈 나머지를 출력하세요.
