## 문제 설명

오리온 군에게는 좋아하는 노래가 $N$곡 있고, 노래 $i$($1 \le i \le N$)의 호감도는 $A_i$입니다. 오리온 군은 자신의 감정을 파악하는 데 서툴기 때문에 $A_i - A_j \ge D$가 아니면 노래 $i$를 노래 $j$보다 더 좋아한다고 인식하지 못합니다. $1$부터 $N$까지 각각의 $i$에 대해, 노래 $i$를 노래 $j$보다 더 좋아한다고 인식하는 $j$가 몇 개인지 구하세요.

## 입력

```text
$N\ D$
$A_1$
$A_2$
$\dots$
$A_N$
```

첫 번째 줄에 노래 수 $N$과 $D$가 주어집니다.

이어서 $N$개의 줄에 $A_i$가 주어집니다.

입력은 모두 정수입니다.

## 제한

$1 \le N \le 2 \times 10^5$

$1 \le D \le 10^9$

$1 \le A_i \le 10^9$

## 출력

$N$개의 줄에 출력하세요. $i$번째 줄에는 $A_i - A_j \ge D$($1 \le j \le N$, $i \ne j$)를 만족하는 $j$의 개수를 출력하세요. 마지막에 개행을 출력하세요.
