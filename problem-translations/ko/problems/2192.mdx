정수 $B\ge2$와 $0\le N<B$가 주어진다냥. $B$로 나눈 나머지가 $N$인 제곱수가 존재하는지 판정하라냥.

## 조건

- $2\le B\le10^{14}$
- $0\le N<B$

## 입력

```text
B N
```

## 출력

그러한 제곱수가 존재하면 `YES`, 없으면 `NO`를 출력하라냥.
