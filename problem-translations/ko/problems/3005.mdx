## 문제 설명

서로 다른 $xy$ 좌표의 격자점 $A = (A_x, A_y)$, $B = (B_x, B_y)$, $C = (C_x, C_y)$, $D = (D_x, D_y)$가 하나의 원주 위에 있는지 판정하세요. 하나의 원주 위에 있다면 `YES`를, 그렇지 않다면 `NO`를 출력하세요.

## 입력

```text
$A_x\ A_y$
$B_x\ B_y$
$C_x\ C_y$
$D_x\ D_y$
```

첫 번째 줄에는 점 $A$의 좌표 $A_x, A_y$, 두 번째 줄에는 점 $B$의 좌표 $B_x, B_y$, 세 번째 줄에는 점 $C$의 좌표 $C_x, C_y$, 네 번째 줄에는 점 $D$의 좌표 $D_x, D_y$가 공백으로 구분되어 주어집니다.

## 제한

- $-100 \leq A_x, A_y, B_x, B_y, C_x, C_y, D_x, D_y \leq 100$
- 네 점 $A, B, C, D$는 서로 다릅니다.

## 출력

네 점이 하나의 원주 위에 있다면 `YES`를, 그렇지 않다면 `NO`를 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
-3 1
-3 -1
3 1
3 -1
```

#### 출력

```text
YES
```

네 점은 직사각형의 꼭짓점이므로 하나의 원주 위에 있습니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
0 0
0 3
4 0
100 100
```

#### 출력

```text
NO
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
0 0
-10 3
100 -30
-50 15
```

#### 출력

```text
NO
```

네 점이 하나의 직선 위에 있으므로 `NO`가 출력됩니다.
