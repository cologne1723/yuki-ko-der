$N$ 이하의 양의 정수 $x,y$의 쌍 $(x,y)$ 중 $x<y$이고 $1<\gcd(x,y)<x$를 만족하는 것은 몇 개인지 구하세요.

$\gcd(x,y)$는 $x$와 $y$의 최대공약수를 뜻합니다.

## 조건

- $1 \le N \le 10^6$
- 입력은 정수입니다.

## 입력

```text
$N$
```

## 출력

조건을 만족하는 쌍의 개수를 한 줄에 출력하세요.
