## 문제 설명

어떤 온라인 저지에는 여러 대의 저지 서버가 있으며, 제출된 프로그램을 병렬로 처리합니다. 여기서는 그중 $1$대의 서버에 주목합니다.

이 서버의 큐에는 프로그램 $N$개가 들어 있습니다. 프로그램 $i$를 실행하는 데는 $T_i-0.1$초가 걸립니다.

시각 $0$에 서버는 대기 상태입니다.

이 서버에 $N$번의 ‘실행 명령’이 시각 $s_1<s_2<\cdots<s_N$에 전달됩니다. 서버는 실행 명령을 받았을 때 대기 상태라면 큐의 선두에 있는 프로그램을 꺼내 실행을 시작합니다. 실행 중이라면 큐의 선두에 있는 프로그램은 다른 서버로 보내집니다.

프로그램 $i$가 시각 $t$에 실행을 시작하면 시각 $t+T_i-0.1$에 완료되고 서버는 대기 상태로 돌아갑니다.

이 서버에서 실행된 프로그램의 수를 구하세요.

## 입력

```text
$N$
$T_1\ T_2\ \cdots\ T_N$
$s_1\ s_2\ \cdots\ s_N$
```

$1$번째 줄에 프로그램의 수를 나타내는 정수 $N$이 주어집니다.

$2$번째 줄에 프로그램 $i$의 실행 시간에 관한 정수 $T_i$가 주어집니다.

$3$번째 줄에 실행 명령의 시각을 나타내는 정수 $s_i$가 주어집니다.

## 제한

- 입력은 모두 정수입니다.
- $1\le N\le1\,000$
- $1\le T_i\le10^9$
- $1\le s_1<s_2<\cdots<s_N\le10^9$

## 출력

이 서버에서 실행된 프로그램의 수를 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
2 3 1
1 4 6
```

#### 출력

```text
2
```

시각 $1$: 대기 중 → 프로그램 $1$을 실행 시작합니다($T=2$, 시각 $2.9$에 완료).

시각 $4$: 대기 중 → 프로그램 $2$를 실행 시작합니다($T=3$, 시각 $6.9$에 완료).

시각 $6$: 실행 중 → 프로그램 $3$은 다른 서버로 보내집니다.

### 예제 2 {file=""}

#### 입력

```text
5
1 2 3 4 1
1 2 4 5 8
```

#### 출력

```text
4
```

시각 $1$: 대기 중 → 프로그램 $1$을 실행 시작합니다($T=1$, 시각 $1.9$에 완료).

시각 $2$: 대기 중 → 프로그램 $2$를 실행 시작합니다($T=2$, 시각 $3.9$에 완료).

시각 $4$: 대기 중 → 프로그램 $3$을 실행 시작합니다($T=3$, 시각 $6.9$에 완료).

시각 $5$: 실행 중 → 프로그램 $4$는 다른 서버로 보내집니다.

시각 $8$: 대기 중 → 프로그램 $5$를 실행 시작합니다($T=1$, 시각 $8.9$에 완료).
