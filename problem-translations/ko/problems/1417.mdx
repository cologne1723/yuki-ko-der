## 문제

양의 정수의 각 자리 숫자를 모두 곱한 값을 자릿수곱이라 합니다. `1` 이상 `N` 이하의 정수 중 자릿수곱이 100의 배수인 양의 정수의 개수를 `10^9+7`로 나눈 나머지를 구하세요.

## 입력

`1\le N\le10^{10000}`인 정수 `N`이 주어집니다.

## 출력

답을 출력하세요.
