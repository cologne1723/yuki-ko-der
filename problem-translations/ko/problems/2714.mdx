## 문제

딸기 `i`의 특징은 네 문자열 `S_{i,1},...,S_{i,4}`로 표현됩니다. 네 문자열에 `akai`, `marui`, `okii`, `umai`가 순서와 관계없이 정확히 한 번씩 포함될 때 그 딸기를 아마오우라고 합니다.

`N`개의 딸기 중 아마오우의 개수를 구하세요.

## 제약

- `1 ≤ N ≤ 100`
- 각 문자열은 소문자 영어로 이루어진 길이 1 이상 5 이하의 문자열입니다.

## 입력

```text
N
S_{1,1} S_{1,2} S_{1,3} S_{1,4}
⋮
S_{N,1} S_{N,2} S_{N,3} S_{N,4}
```

## 출력

답을 출력하세요.
