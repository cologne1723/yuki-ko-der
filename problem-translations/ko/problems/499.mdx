## 문제

정수 N이 주어집니다. 정수 N을 출력하세요.

단, 입력은 10진수 표기이고 출력은 7진수 표기여야 합니다.

## 입력

```text
N
```

입력 N은 0 ≤ N ≤ (10^9)10을 만족합니다.

## 출력

N을 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
18
```

출력:

```text
24
```

(18)10 = (24)7입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
7
```

출력:

```text
10
```

(7)10 = (10)7입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
1000000000
```

출력:

```text
33531600616
```
