## 문제

무한한 2차원 격자의 각 칸에 반시계 방향 소용돌이 순서로 번호가 붙어 있습니다. 중앙의 칸은 `1`이며, 그 주변 칸부터 차례로 번호가 증가합니다.

시작 칸 `S`에서 출발해 상하좌우로 인접한 칸으로 이동하여 목표 칸 `T`에 도착합니다. 지나간 모든 칸의 번호를 XOR한 값을 벌점이라고 합니다. 같은 칸을 여러 번 지나가면 그때마다 번호를 XOR합니다.

벌점이 최소가 되면서 이동 횟수가 제한 이하인 경로를 하나 출력하세요.

## 입력

한 줄에 시작 칸의 번호 `S`와 목표 칸의 번호 `T`가 주어집니다.

`1 \le S,T \le 10^9`, `S \ne T`입니다.

## 출력

조건을 만족하는 경로를 다음 형식으로 출력하세요.

첫째 줄에 가능한 최소 벌점 `X`를 출력합니다. 둘째 줄에 이동 횟수 `K`를 출력합니다. 셋째 줄에 시작 칸에서 목표 칸까지의 경로를 나타내는 이동 정보를 출력합니다.

이동 횟수는 `2 \times 10^5` 이하이어야 합니다.

여러 경로가 있으면 그중 아무 것이나 출력해도 됩니다.
