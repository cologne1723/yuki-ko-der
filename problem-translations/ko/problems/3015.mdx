## 문제 설명

오른쪽으로 치우치는 것을 아주 좋아하는 岩井星人さん은 특히 문자열 안의 `110`이라는 연속 부분 문자열을 `011`로 바꾸는 연산을 좋아합니다.

문자열 $S$가 주어집니다. 岩井星人さん이 이 연산을 수행할 수 있는 횟수의 최댓값을 구하세요.

## 입력

```text
$S$
```

## 제한

- $S$의 길이는 $1$ 이상 $2 \times 10^6$ 이하입니다.
- $S$는 `0` 또는 `1`로만 이루어져 있습니다.

## 출력

수행할 수 있는 연산 횟수의 최댓값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
10110110
```

#### 출력

```text
3
```

`10110110` → `10011110` → `10011011` → `10001111`과 같이 바꿀 수 있습니다.

### 예제 2 {file=""}

#### 입력

```text
0000000010000001111
```

#### 출력

```text
0
```

岩井星人さん은 더 이상 오른쪽으로 붙을 수 없습니다.
