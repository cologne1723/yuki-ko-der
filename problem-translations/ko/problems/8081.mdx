## 문제 설명

길이가 $N$인 문자열 $S$가 주어집니다. $S$의 각 문자는 대문자 또는 소문자 알파벳입니다. 문자열 $S$를 출력하는 HQ9+의 **$1$줄** 소스 코드를 작성하여 출력하세요.

그러한 소스 코드가 존재하지 않는 경우에는 대신 $-1$을 출력하세요.

※ HQ9+에 대해서는 [여기](https://ja.wikipedia.org/wiki/HQ9%2B)를 읽거나, 다음 C++ 또는 Python3 구현을 확인하세요.

단, HQ9+의 처리계로는 다음 링크에 있는 C++ 코드 또는 Python3 코드를 사용한다고 가정합니다. 이 문제에 대한 답은 존재한다면 어느 처리계를 사용해도 같은 동작을 하는 것이 보장됩니다.

[HQ9p.cpp](https://gist.github.com/kotatsugame/f689a4a200176bd2cbffe6f6d36ea358) [HQ9p.py](https://gist.github.com/kotatsugame/8a5a5019ce449889ba6a8e3db04ac24e)

중요한 점은 여기서 사용하는 처리계가 HQ9+의 소스 코드를 $1$번째 개행 직전까지만 인식한다는 것입니다. $2$줄 이상에 걸친 코드는 $1$번째 줄의 개행 직전까지만 읽히며, Q 명령으로 출력되는 문자열도 그 범위까지만 출력됩니다.

따라서 이 처리계를 사용했을 때 문자열 $S$를 출력하는 HQ9+의 소스 코드가 존재한다면, 반드시 $1$줄인 소스 코드도 존재한다고 할 수 있습니다.

## 입력

```text
$N$
$S$
```

## 제한

- $1 \leq N \leq 10^5$
- $N$은 정수입니다.
- $|S|=N$
- $S$의 각 문자는 대문자 또는 소문자 알파벳입니다.

## 출력

문제 설명에서 지정한 처리계를 사용해 실행했을 때 문자열 $S$를 출력하는 HQ9+의 소스 코드를 **$1$줄로** 출력하고, 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1
Q
```

#### 출력

```text
Q
```

Q 명령을 사용하면 소스 코드 자체가 출력됩니다. 이것은 "Q"이므로 입력 문자열과 일치합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3
abc
```

#### 출력

```text
-1
```

문자열 "abc"만을 출력하는 HQ9+의 소스 코드가 존재하지 않는다는 것을 알 수 있습니다.
