$2N\times2N$ 격자의 색을 바꿀 수 있습니다. 한 번의 조작은 흰 칸 하나와 검은 칸 하나를 골라 서로 색을 바꾸는 것입니다. 검은 칸의 점수 합에 더해, 격자가 좌우 대칭이면 $K$를 보너스로 얻을 때 가능한 점수의 최댓값을 구하세요.

## 입력

```text
N K
S_1
...
S_{2N}
C_{1,1} ... C_{1,2N}
...
C_{2N,1} ... C_{2N,2N}
```

## 출력

가능한 점수의 최댓값을 출력하세요.
