빨간색 막대 `n`개, 초록색 막대 `n`개, 파란색 막대 `n`개가 있습니다. 각 막대의 길이는 각각 `r_i`, `g_i`, `b_i`입니다.

빨간색 막대 하나, 초록색 막대 하나, 파란색 막대 하나를 선택하여 다음 조건을 모두 만족하는 선택의 개수를 구하세요.

## 조건

- 세 막대로 넓이가 양수인 삼각형을 만들 수 있습니다.
- 선택한 빨간색 막대의 길이 `r_i`가 세 막대 길이의 최댓값입니다.

## 입력

입력은 표준 입력으로 주어집니다.

- 첫째 줄에 `n`이 주어집니다.
- 둘째 줄에 `r_1, r_2, ..., r_n`이 주어집니다.
- 셋째 줄에 `g_1, g_2, ..., g_n`이 주어집니다.
- 넷째 줄에 `b_1, b_2, ..., b_n`이 주어집니다.

## 제약

- `1 <= n <= 2 * 10^5`
- 모든 막대의 길이는 `1` 이상 `3000` 이하입니다.

## 출력

조건을 만족하는 선택의 개수를 출력하세요.
