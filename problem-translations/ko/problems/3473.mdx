## 문제 설명

정수 $N$, $M$이 주어집니다. 각 원소가 $0$ 이상 $2^M-2$ 이하인 길이 $N$의 정수열 $A=(A_1,A_2,\cdots,A_N)$ 중에서 $A_1,A_2,\cdots,A_N$의 비트별 논리합이 $2^M-1$이 되는 것의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

## 입력

입력은 다음 형식으로 주어집니다. 여기서 $\mathrm{case}_i$는 $i$번째 테스트 케이스를 나타냅니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ \ M$
```

## 제한

- $1\le T\le 100$
- $1\le N\le 10^9$
- $2\le M\le 10^9$
- 입력은 전부 정수입니다.

## 출력

각 테스트 케이스에 대한 답을 $1$줄에 출력하고, 마지막에 개행하세요.

#### 입력

```text

```

#### 출력

```text

```

- $1$번째 테스트 케이스에서 조건을 만족하는 $A$는 $(1,2)$와 $(2,1)$의 $2$개입니다.
- $2$번째 테스트 케이스에서는 조건을 만족하는 $A$가 존재하지 않습니다.
