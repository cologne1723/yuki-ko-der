## 문제 설명

양의 정수 $N,X$와 길이 $N$의 양의 정수 수열 $A=(A_1,A_2,\cdots,A_N)$이 주어집니다. 변수 $x$가 있으며 처음에는 $x=X$입니다.

$i=1,2,\cdots,N$ 순서로 각 $i$에 대해 다음 두 연산 중 하나만 합니다.

- 유형 $1$: $x$를 $A_i$로 바꿉니다.
- 유형 $2$: $x$를 $x\div A_i$로 바꿉니다.

모든 시점, 즉 초기 상태와 각 연산 직후에 $x$가 정수인 연산열의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

어떤 정수 $k$ $(1\leq k\leq N)$가 존재해 $i=k$일 때 선택한 연산의 유형이 다를 때, 그리고 그때에만 두 연산열을 구별합니다.

## 입력

표준 입력으로 다음 형식의 입력이 주어집니다.

```text
$N\ X$
$A_1\ A_2\ \ldots\ A_N$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $1 \leq N \leq 2\times 10^5$
- $1 \leq X \leq 10^{18}$
- $1 \leq A_i \leq 10^{18}$

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4 10
2 5 5 1
```

#### 출력

```text
10
```

예를 들어 다음 연산을 하면 모든 시점에 $x$가 정수라는 조건을 만족합니다. 처음에는 $x=10$입니다.

- $i=1$일 때 유형 $2$의 연산으로 $x=10\div 2=5$로 바꿉니다.
- $i=2$일 때 유형 $1$의 연산으로 $x=5$로 바꿉니다.
- $i=3$일 때 유형 $2$의 연산으로 $x=5\div 5=1$로 바꿉니다.
- $i=4$일 때 유형 $1$의 연산으로 $x=1$로 바꿉니다.

이러한 연산열은 $10$개입니다.
