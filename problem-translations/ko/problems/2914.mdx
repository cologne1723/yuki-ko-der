## 문제 설명

입력의 처음에 양의 정수 $N$, $M$이 주어집니다.

어떤 마을에는 $N$개의 광장과, 광장들을 양방향으로 연결하는 $M$개의 도로가 있습니다.

광장에는 $N$ 이하의 각 양의 정수 $i$로 번호가 붙어 있으며, 광장 $i$라고 부릅니다.

도로에는 $M$ 이하의 각 양의 정수 $j$로 번호가 붙어 있으며, 도로 $j$는 광장 $u_j$와 광장 $v_j$를 연결합니다. ($u_j$, $v_j$는 서로 다른 $N$ 이하의 양의 정수입니다.)

**直進大好きbot**은 이 마을의 도로를 직진하는 것을 매우 좋아하는 bot입니다. **直進大好きbot**은 어느 도로를 어느 방향으로 직진했는지에 따라 상쾌함이라는 정수값이 변합니다.

구체적으로, $M$ 이하의 임의의 양의 정수 $j$에 대해 **直進大好きbot**이 도로 $j$를 광장 $u_j$에서 광장 $v_j$를 향해 직진하면 상쾌함이 $w_j$만큼 증가하고, 반대 방향으로 직진하면 상쾌함이 $w_j$만큼 감소합니다. ($w_j$는 음이 아닌 정수입니다.)

**直進大好きbot**은 이 마을의 어떤 광장에서 출발하여 도로만 직진하고 출발한 광장으로 돌아오는 경로 중 다음 $2$가지 조건을 만족하는 것을 **상쾌한 경로**라고 부르며 찾고 있습니다.

- 경로에서 같은 도로를 방향과 관계없이 두 번 지나지 않습니다.
- 돌아왔을 때의 상쾌함이 출발할 때의 상쾌함보다 큽니다.

여러분은 **直進大好きbot** 대신 **상쾌한 경로**를 찾아 주세요.

## 입력

입력은 다음 형식으로 표준 입력에서 $1+M$개의 줄로 주어집니다.

```text
$N\ M$
$u_1\ v_1\ w_1$
$\vdots$
$u_M\ v_M\ w_M$
```

- 첫 번째 줄에 $N$, $M$이 공백으로 구분되어 주어집니다.
- $M$ 이하의 각 양의 정수 $j$에 대해 $1+j$번째 줄에 $u_j$, $v_j$, $w_j$가 공백으로 구분되어 주어집니다.

## 제한

입력은 다음 제한을 만족합니다.

- $N$은 $2 \leq N \leq 100\,000$을 만족하는 정수입니다.
- $M$은 $1 \leq M \leq 100\,000$을 만족하는 정수입니다.
- $M$ 이하의 임의의 양의 정수 $j$에 대해 다음을 만족합니다.
  - $u_j$, $v_j$는 $u_j \ne v_j$ 및 $1 \leq u_j \leq N$, $1 \leq v_j \leq N$을 만족하는 정수입니다.
  - $w_j$는 $0 \leq w_j \leq 100\,000$을 만족하는 정수입니다.

## 출력

**상쾌한 경로**가 존재하지 않는 경우 `-1`을 출력하세요.

```text
$-1$
```

**상쾌한 경로**가 존재하는 경우 그중 하나를 다음 형식으로 $3$개의 줄에 걸쳐 출력하세요.

- 첫 번째 줄에 지나갈 도로의 개수를 나타내는 양의 정수 $L$을 출력하세요.
- 두 번째 줄에 출발하는 광장의 번호 $S$를 출력하세요.
- 세 번째 줄에 지나는 순서대로 $L$개의 도로 번호 $E_1$, $\ldots$, $E_L$을 공백으로 구분하여 출력하세요.

```text
$L$
$S$
$E_1\ \cdots\ E_L$
```

이 문제는 스페셜 저지 문제입니다. 정답이 여러 가지라면 그중 어느 것이든 출력해도 됩니다.

단, 위에서 설명한 출력 형식을 지켜야 합니다. 예를 들어 마지막에 불필요한 공백을 넣었을 때 저지의 동작은 보장되지 않습니다.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 1
1 2 1
```

#### 출력

```text
-1
```

**상쾌한 경로**는 존재하지 않습니다. 도로 $1$이 광장 $1$과 광장 $2$를 연결하지만 다른 도로가 없으므로, 어느 광장에서 출발해도 같은 도로를 두 번 지나지 않고 원래 광장으로 돌아올 수 없습니다.

### 예제 2 {file=""}

#### 입력

```text
2 2
1 2 0
2 1 1
```

동일한 광장 쌍을 여러 도로가 연결하는 경우도 있다는 점에 주의하세요.

#### 출력

```text
2
1
1 2
```

도로 $1$은 광장 $1$과 광장 $2$를 연결하며, 도로 $1$을 어느 방향으로 직진해도 상쾌함은 변하지 않습니다.

도로 $2$는 광장 $2$와 광장 $1$을 연결하며, 광장 $2$에서 광장 $1$을 향해 도로 $2$를 직진하면 상쾌함이 $1$만큼 증가하고, 반대 방향으로 직진하면 상쾌함이 $1$만큼 감소합니다.

따라서 광장 $1$에서 출발하여 도로 $1$, 도로 $2$ 순서로 직진하면 상쾌함이 $1$ 증가한 상태로 광장 $1$로 돌아올 수 있습니다.

이 밖에도 예를 들어 다음과 같이 출력해도 정답입니다.

```text
2
2
2 1
```

### 예제 3 {file=""}

#### 입력

```text
3 3
1 2 1
2 3 2
1 3 3
```

#### 출력

```text
-1
```

**상쾌한 경로**는 존재하지 않습니다. 예를 들어 광장 $1$에서 출발하여 도로 $1$, 도로 $2$, 도로 $3$ 순서로 직진해 광장 $1$로 돌아와도 최종적인 상쾌함의 변화는 $1+2-3=0$입니다.
