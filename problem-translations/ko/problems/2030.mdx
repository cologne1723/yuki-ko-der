서로 다른 두 문자열 $x,y$가 주어집니다. $x$를 $10^{100}$번 이어 붙인 문자열을 $X$, $y$를 $10^{100}$번 이어 붙인 문자열을 $Y$라 할 때 사전순으로 더 큰 것을 고르세요.

## 입력

```text
T
x
y
```

$1\le T\le10^4$이고, 모든 테스트 케이스에서 각 문자열 길이의 합은 $10^6$ 이하입니다.

## 출력

각 테스트 케이스에서 사전순으로 더 큰 문자열이 $X$이면 `X`, $Y$이면 `Y`를 출력하세요.
