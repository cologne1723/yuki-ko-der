서로 다른 두 문자열 $x,y$가 주어집니다. $x$를 $10^{100}$번 이어 붙인 문자열을 $X$, $y$를 $10^{100}$번 이어 붙인 문자열을 $Y$라 할 때 사전순으로 더 큰 것을 고르세요.

<details>
<summary>사전순이란? (클릭하여 펼치기)</summary>

서로 다른 두 문자열 $X,Y$가 주어졌을 때 사전순 대소는 다음과 같이 정합니다. $X$의 $i$번째 문자를 $X_i$로 나타냅니다.

- 두 문자열 중 짧은 문자열의 길이를 $L$이라 합니다.
- $X_i\ne Y_i$인 $i$ ($1\le i\le L$)가 있으면, 가장 작은 $i$를 $j$라 합니다. 알파벳 순서에서 $X_j<Y_j$이면 $X<Y$, $X_j>Y_j$이면 $X>Y$입니다.
- 그런 $i$가 없으면 길이 $|X|,|Y|$를 비교합니다. $|X|<|Y|$이면 $X<Y$, $|X|>|Y|$이면 $X>Y$입니다.

</details>

## 입력

```text
T
x
y
```

$1\le T\le10^4$이고, 모든 테스트 케이스에서 각 문자열 길이의 합은 $10^6$ 이하입니다.

## 출력

각 테스트 케이스에서 사전순으로 더 큰 문자열이 $X$이면 `X`, $Y$이면 `Y`를 출력하세요.
