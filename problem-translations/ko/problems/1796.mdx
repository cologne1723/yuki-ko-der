정점 `N`개의 무향 트리와 각 정점의 값 `Q_i`가 주어집니다. `dist(u,v)`를 두 정점 사이 단순 경로의 간선 수라 할 때, 각 `p`에 대해

`E_p = sum_i ((N!)^2 * Q_i) / (dist(p,i)+1)^2`

를 계산하고 `998244353`으로 나눈 나머지를 출력하세요.

## 입력

트리와 정점 값이 주어집니다.

## 출력

각 `E_p`의 나머지를 출력하세요.
