## 문제

Ame 군은 ‘유키코더’를 운영하는 누나 Yuki 씨를 돕게 되었습니다.

이번에 Ame 군이 맡은 일은 대회의 첫 번째 문제로 사용할 간단한 문제를 만드는 것입니다.

그래서 Ame 군은 다음과 같은 A + B 문제를 만들기로 했습니다.

### 문제

첫 번째 줄에 정수 $A$, 두 번째 줄에 정수 $B$가 주어질 때 $A+B$를 출력하세요.

### 입력

```text
$A$
$B$
```

입력은 모두 정수이며 다음 제약을 만족합니다.

$0\leq A,B\leq12345$

### 출력

$A+B$의 결과를 한 줄에 출력하세요.

마지막에 줄바꿈을 출력하세요.

이렇게 순조롭게 테스트 케이스까지 만든 Ame 군이었지만, 사실 테스트 케이스를 생성하는 프로그램에 버그가 있었다는 사실이 밝혀졌습니다.

그래서 Ame 군은 테스트 케이스가 앞서 설명한 문제의 형식과 제약을 만족하는지 확인하는 프로그램을 작성하기로 했습니다.

또한 leading zero(문자열 앞에 이어지는 불필요한 0)가 있는 경우에도 형식을 만족하지 않는 것으로 합니다.

### 입력

```text
$A$
$B$
```

첫 번째 줄에 문자열 $A$, 두 번째 줄에 문자열 $B$가 주어집니다.

각 문자열은 반각 영숫자(0-9, A-Z, a-z)만으로 이루어지며, 공백이나 `+`, `-` 등의 기호는 포함하지 않습니다.

각 문자열의 길이는 1 이상 5 이하임이 보장됩니다.

### 출력

입력이 앞서 설명한 A + B 문제의 형식과 제약을 만족하면 `OK`, 만족하지 않으면 `NG`를 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
123
4eF
```

출력:

```text
NG
```

`123`은 문제가 없지만 `4eF`가 숫자가 아니므로 잘못된 입력입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
21000
00012
```

출력:

```text
NG
```

`21000`은 12345보다 크므로 제약을 만족하지 않습니다.

`00012`에는 문자열 앞에 불필요한 0이 있으므로 형식을 만족하지 않습니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
FFFF
0x10
```

출력:

```text
NG
```

둘 다 잘못된 입력입니다.

### 샘플 4 {file="sample4.in"}

입력:

```text
0
12345
```

출력:

```text
OK
```
