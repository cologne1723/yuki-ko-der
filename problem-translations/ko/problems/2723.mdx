## 문제

`K`, `P`, `-`로 이루어진 문자열 `S`가 주어집니다. 번갈아 다음 작업을 합니다. `-`가 아닌 문자만으로 이루어진 연속 구간 `[x,y]`를 고르고, 구간 밖에 `-`가 아닌 문자가 하나 이상 있도록 한 뒤 구간을 모두 `-`로 바꿉니다.

더 고를 수 없을 때 남은 문자는 정확히 하나입니다. 마지막 문자가 `K`이면 코어의 승리, 아니면 파체의 승리입니다. 두 사람이 최선의 전략을 사용할 때 승자를 판정하세요.

## 제약

- `1 ≤ T ≤ 10^5`, `1 ≤ N ≤ 5×10^5`
- 모든 테스트 케이스의 `N` 합은 `5×10^5` 이하입니다.

## 입력

```text
T
N
S
⋮
```

## 출력

코어가 이기면 `K`, 파체가 이기면 `P`를 출력하세요.
