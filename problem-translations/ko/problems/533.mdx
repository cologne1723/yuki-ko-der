## 문제

Tatsuya는 오늘 어느 복합 건물 5층에서 면접이 있습니다. 운동 부족을 해소하기 위해 계단으로 면접장까지 가려고 합니다.

계단 수는 정확히 N칸입니다. 한 번의 점프로 1칸, 2칸, 3칸 중 하나를 올라갈 수 있습니다.

복합 건물 전체에 이상한 기운이 흐르고 있어(또는 면접에 대한 긴장감 같은 심리적 이유로) 같은 칸 수의 점프를 연속해서 할 수 없습니다.

Tatsuya가 면접장까지 점프하는 방법은 몇 가지일까요? 답이 매우 커질 수 있으므로 10^9+7로 나눈 나머지를 구하세요.

## 입력

```text
N
```

첫 번째 줄에 면접장까지의 계단 수 N이 주어집니다. 1 ≤ N ≤ 1000000

## 출력

정확히 N칸 올라가는 점프 방법의 수를 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
2
```

출력:

```text
1
```

한 번의 점프로 2칸 올라가는 방법뿐입니다. 1칸 + 1칸처럼 같은 칸 수의 점프를 연속해서 할 수는 없습니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
4
```

출력:

```text
3
```

(1,2,1), (3,1), (1,3)의 3가지입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
49993
```

출력:

```text
407466683
```
