## 문제 설명

음이 아닌 정수 $N$이 주어집니다. 다음 조건을 만족하는 정수 쌍 $(X,Y)$ 중 $X\times Y$가 최대가 되는 것을 $1$개 구하세요. 조건을 만족하는 $(X,Y)$는 적어도 $1$개 존재합니다.

- $0\leq X,Y$
- $X+Y\leq N$
- $X\oplus Y=X+Y$

여기서 $\oplus$는 비트별 배타적 논리합을 나타냅니다.

$T$개의 테스트 케이스 모두에 대해 답을 구하세요.

### 비트별 배타적 논리합이란?

$x\oplus y$는 $x,y$를 각각 이진수로 바꾼 뒤, 각 자리에 대해 배타적 논리합(값이 다르면 $1$, 같으면 $0$)을 취한 값입니다.

예를 들어 $12\oplus 10=1100_{(2)}\oplus 1010_{(2)}=0110_{(2)}=6$이고, $100\oplus 100=0$입니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$T$
$case_1$
$case_2$
$\vdots$
$case_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- $1\leq T\leq 2\times 10^5$
- $0\leq N\leq 10^{18}$
- 입력은 모두 정수입니다.

## 출력

$T$줄에 걸쳐 출력하세요. $i$번째 줄에는 $i$번째 테스트 케이스에 대한 답을 출력하세요. 조건을 만족하는 것이라면 어떤 것을 출력해도 정답으로 인정됩니다.

출력한 뒤 마지막에 개행 문자를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
3
0
271828182845904
```

#### 출력

```text
2 1
0 0
140737488355328 131090694490576
```

$1$번째 테스트 케이스에서 $2\oplus 1=2+1=3$이고, 조건을 만족하는 $(X,Y)$ 중 $X\times Y$가 최대가 되는 것은 $(2,1)$입니다.

$(1,2)$도 정답으로 인정됩니다.

주어지는 $N$과 출력해야 하는 $X,Y$가 $32$비트 정수형에 들어가지 않을 수 있다는 점에 주의하세요. (C++를 사용하는 경우 `int` 대신 `long long`을 사용하세요.)
