## 문제

정수 n이 주어집니다. X = n! mod (10^9+7)을 구하세요.

## 입력

```text
n
```

입력은 0 ≤ n ≤ 10^18을 만족합니다.

## 출력

X를 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
5
```

출력:

```text
120
```

5! = 120입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
0
```

출력:

```text
1
```

### 샘플 3 {file="sample3.in"}

입력:

```text
100
```

출력:

```text
437918130
```

100! = 93326215443944152681699238856266700490715968264381621468592963895217599993229915608941463976156518286253697920827223758251185210916864000000000000000000000000입니다.
