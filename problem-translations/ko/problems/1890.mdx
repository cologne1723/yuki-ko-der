길이 $N$의 수열 $A$가 주어지고 빈 수열 $B$를 준비합니다. 각 $i$에 대해 $1,\ldots,A_i$로 이루어진 수열 $P_i$를 만들고, 그 원소를 순서대로 $B$에 삽입합니다. 이후 $B$는 변경하지 않습니다.

## 문제

각 질의에서 정수 $S_i$가 주어질 때, $\sum_{k=1}^{n}B_k\ge S_i$를 만족하는 최소 $n$을 구하세요. 존재하지 않으면 `-1`을 출력합니다.

## 입력

```text
N Q
A_1 A_2 ... A_N
S_1
...
S_Q
```

$1\le N\le100$, $1\le Q\le10^5$, $\sum A_i\le10^5$, $1\le S_i\le10^9$입니다.

## 출력

각 질의의 답을 한 줄에 출력하세요.
