## 이야기

[구간 XOR](https://yukicoder.me/problems/no/2990)의 XOR 부분을 MEX로 바꾸기만 한 문제를 내자! → 풀지 못했다...

## 문제 설명

양의 정수 $N$, $M$이 주어집니다.

$0\le x\le N$을 만족하는 각 정수 $x$에 대해, 다음 조건을 모두 만족하는 길이 $N$의 정수열 $A=(A_0,A_1,\dots,A_{N-1})$의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

- $0$ 이상 $N$ 미만인 모든 정수 $i$에 대해 $0\le A_i<i+M$입니다.
- $\mathrm{MEX}(A)=x$입니다.

여기서 $\mathrm{MEX}(A)$는 $A$에 포함되지 않는 가장 작은 음이 아닌 정수입니다.

## 입력

입력은 $1$개의 줄에 주어지며, 양의 정수 $N$, $M$이 공백으로 구분되어 주어집니다.

```text
$N\ M$
```

## 제한

- $1\le N\le 5\times 10^5$
- $1\le M\le 5\times 10^5$
- 입력은 모두 정수입니다.

## 출력

$N+1$개의 줄을 출력하세요.

$i+1$번째 줄에는 $x=i$일 때의 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 1
```

#### 출력

```text
0
2
3
1
```

$x=0$일 때 조건을 만족하는 $A$가 존재하지 않으므로, $1$번째 줄에는 $0$을 출력합니다.

$x=1$일 때 조건을 만족하는 모든 $A$는 $(0,0,0)$, $(0,0,2)$이므로, $2$번째 줄에는 $2$를 출력합니다.

$x=2$일 때 조건을 만족하는 모든 $A$는 $(0,0,1)$, $(0,1,0)$, $(0,1,1)$이므로, $3$번째 줄에는 $3$을 출력합니다.

$x=3$일 때 조건을 만족하는 모든 $A$는 $(0,1,2)$이므로, $4$번째 줄에는 $1$을 출력합니다.

### 예제 2 {file=""}

#### 출력

$x=3$일 때 조건을 만족하는 모든 $A$는 $(0,1,2)$, $(0,2,1)$, $(1,0,2)$, $(1,2,0)$이므로, $4$번째 줄에는 $4$를 출력합니다.
