## 문제

`H × W` 격자에서 세로로 인접한 칸은 이동 시간 1, `i`행에서 가로로 인접한 칸은 이동 시간 `i`입니다. `N`개의 출구가 주어질 때, 각 출구에서 다른 출구로 이동하는 최단 시간의 최솟값을 구하세요.

## 제약

- `1 ≤ H,W ≤ 10^9`, `2 ≤ N ≤ 2×10^5`
- 출구 좌표는 서로 다릅니다.

## 입력

```text
H W N
A_1 B_1
⋮
A_N B_N
```

## 출력

각 출구에 대한 답을 한 줄에 하나씩 출력하세요.
