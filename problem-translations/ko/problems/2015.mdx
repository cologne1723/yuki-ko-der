$N$단 계단에 $M$명이 있고, 각 사람은 한 번에 $1$단 또는 $2$단씩 올라갑니다. 계단 $i$를 밟은 사람 수가 $A_i$가 되는 올라가는 방법이 존재하는지 판정하세요.

## 입력

```text
T
N M
A_1 A_2 ... A_N
```

$A_N=M$이고, 모든 테스트 케이스의 $N$ 합은 $2\times10^5$ 이하입니다.

## 출력

각 테스트 케이스에 대해 가능하면 `Yes`, 아니면 `No`를 출력하세요.
