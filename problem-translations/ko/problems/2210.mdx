길이 $N$의 수열 $A$가 주어진다냥. $A$의 $i$번째 원소를 제거해 얻는 수열을 $X_i$라 하자냥. $X_1,\ldots,X_N$을 사전순으로 정렬했을 때 $K$번째 수열을 구하라냥.

## 조건

- $2\le N\le2\times10^5$
- $1\le K\le N$
- $1\le A_i\le N$

## 입력

```text
N K
A_1 A_2 \cdots A_N
```

## 출력

답 수열의 원소를 공백으로 구분해 출력하라냥.
