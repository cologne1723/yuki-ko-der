## 문제 설명

타로가 사는 지역에는 지하철역이 $N$개 있고 0부터 $N-1$까지 번호가 붙어 있습니다. 역과 역은 노선으로 연결되어 있으며, 각 노선의 이동 시간이 정해져 있습니다.

타로는 역 $S$에서 역 $G$까지의 최단 경로를 구하려 합니다. 최단 경로가 여러 개일 수 있으므로 그중 사전순으로 가장 작은 경로를 출력하세요.

최단 경로란 이용하는 노선의 이동 시간 합이 최소인 경로입니다. 환승 시간 등은 고려하지 않습니다. 경로에는 출발역과 목적역이 포함됩니다. 두 경로의 역을 각각 $(p_1,p_2,\ldots,p_k)$와 $(q_1,q_2,\ldots,q_l)$로 나타낼 때, 어떤 $j$에 대해 앞의 $j-1$개가 같고 $p_j\lt q_j$이면 첫 번째 경로가 사전순으로 작다고 합니다.

## 입력

```text
N M S G
a_1 b_1 c_1
:
a_M b_M c_M
```

노선은 양방향으로 이용할 수 있습니다.

- $2 \le N \le 200$
- $N-1 \le M \le N(N-1)/2$
- $1 \le c_i \le 10^4$
- $0 \le S,G,a_i,b_i \le N-1$
- $S \ne G$, $a_i \ne b_i$
- 같은 역의 쌍을 직접 연결하는 노선은 최대 1개입니다.
- $S$에서 $G$로 가는 경로는 반드시 존재합니다.

## 출력

최단 경로 중 사전순으로 가장 작은 경로를 역 번호 순서대로 공백으로 구분해 한 줄에 출력하세요. 출발역과 목적역도 포함합니다.

## 예제

### 예제 1

```text
4 3 0 3
0 2 100
2 1 200
1 3 300
```

```text
0 2 1 3
```

역 0에서 3으로 가는 경로가 하나뿐입니다.

### 예제 2

```text
4 4 0 3
0 2 100
2 3 100
0 1 200
1 3 200
```

```text
0 2 3
```

두 경로의 이동 시간 합은 각각 200과 400이므로 첫 번째 경로를 출력합니다.

### 예제 3

```text
4 4 0 3
0 2 100
2 3 100
0 1 100
1 3 100
```

```text
0 1 3
```

두 경로의 이동 시간이 같지만 $(0,1,3)$이 $(0,2,3)$보다 사전순으로 작습니다.
