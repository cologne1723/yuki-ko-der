## 문제 설명

太郎君이 사는 지역에는 지하철역이 $N$개 있고 $0$부터 $N-1$까지 번호가 붙어 있습니다. 역과 역은 노선으로 연결되어 있으며, 각 노선의 이동 시간이 정해져 있습니다.

급한 용무가 있는 太郎君은 역 $S$에서 역 $G$까지의 최단 경로를 구하려 합니다. 최단 경로가 여러 개일 수 있으므로 그중 사전순으로 가장 작은 경로를 출력하세요.

최단 경로란 이용하는 노선의 이동 시간 합이 최소인 경로입니다. 환승 시간 등은 고려하지 않습니다. 경로에는 출발역과 목적역이 포함됩니다. 경로 $P$와 $Q$의 역을 각각 $(p_1,p_2,\ldots,p_k)$와 $(q_1,q_2,\ldots,q_l)$로 나타낼 때, 어떤 $j$에 대해 앞의 $j-1$개가 같고 $p_j\lt q_j$이면 경로 $P$가 경로 $Q$보다 사전순으로 작다고 합니다.

## 입력

```text
$N\ M\ S\ G$
$a_1\ b_1\ c_1$
$\vdots$
$a_M\ b_M\ c_M$
```

$1$번째 줄에 역의 수 $N$, 노선의 수 $M$, 출발역 $S$, 목적역 $G$가 공백으로 구분되어 주어집니다. 이어지는 $M$줄은 노선 정보이며, $a_i$, $b_i$, $c_i$는 역 $a_i$와 역 $b_i$를 잇는 노선의 이동 시간이 $c_i$임을 나타냅니다. 노선은 양방향으로 이용할 수 있습니다.

## 제한

- $2 \le N \le 200$
- $N-1 \le M \le N(N-1)/2$
- $1 \le c_i \le 10^4$
- $0 \le S,G,a_i,b_i \le N-1$
- $S \ne G$, $a_i \ne b_i$
- 같은 역의 쌍을 직접 연결하는 노선은 최대 $1$개입니다.
- $S$에서 $G$로 가는 경로는 반드시 존재합니다.

## 출력

```text
$S\ v_2\ v_3\ \dots\ v_{k-1}\ G$
```

최단 경로 중 사전순으로 가장 작은 경로에서 지나는 역 번호를 순서대로 공백으로 구분해 $1$줄에 출력하세요. 출발역과 목적역도 포함합니다. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 3 0 3
0 2 100
2 1 200
1 3 300
```

#### 출력

```text
0 2 1 3
```

역 $0$에서 역 $3$으로 가는 경로는 $(0,2,1,3)$의 $1$개뿐이므로 이 경로를 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
4 4 0 3
0 2 100
2 3 100
0 1 200
1 3 200
```

#### 출력

```text
0 2 3
```

역 $0$에서 역 $3$으로 가는 경로는 $(0,2,3)$과 $(0,1,3)$의 $2$개입니다. 이동 시간 합은 각각 $200$과 $400$이므로 경로 $(0,2,3)$을 출력합니다.

### 예제 3 {file=""}

#### 입력

```text
4 4 0 3
0 2 100
2 3 100
0 1 100
1 3 100
```

#### 출력

```text

```

예제 $2$와 마찬가지로 역 $0$에서 역 $3$으로 가는 경로는 $(0,2,3)$과 $(0,1,3)$의 $2$개입니다. 이번에는 $2$개의 경로의 이동 시간이 같지만 $(0,1,3)$이 $(0,2,3)$보다 사전순으로 작으므로 경로 $(0,1,3)$을 출력합니다.
