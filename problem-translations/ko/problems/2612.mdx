평면 위의 $N$개 점을 색 1, 2, 3 중 하나로 칠합니다. 같은 색인 두 점 사이의 맨해튼 거리의 최댓값을 그 색칠의 미묘함이라 할 때, 미묘함의 최솟값을 구하세요.

## 조건

- $1\le N\le2\times10^5$
- $1\le x_i,y_i\le10^9$, 점들은 서로 다릅니다.

## 입력

```text
$N$
$x_1$ $y_1$
\vdots
$x_N$ $y_N$
```

## 출력

미묘함의 최솟값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
2 2
1 3
3 2
4 1
3 3
```

#### 출력

```text
2
```

### 예제 2 {file=""}

#### 입력

```text
3
1 1
2 2
3 3
```

#### 출력

```text
0
```

### 예제 3 {file=""}

#### 입력

```text
10
57 71
29 39
46 32
85 19
34 57
79 13
60 72
55 46
79 12
13 18
```

#### 출력

```text
47
```
