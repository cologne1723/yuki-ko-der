평면 위의 $N$개 점을 색 1, 2, 3 중 하나로 칠합니다. 같은 색인 두 점 사이의 맨해튼 거리의 최댓값을 그 색칠의 미묘함이라 할 때, 미묘함의 최솟값을 구하세요.

## 조건

- $1\le N\le2\times10^5$
- $1\le x_i,y_i\le10^9$, 점들은 서로 다릅니다.

## 입력

```text
$N$
$x_1$ $y_1$
\vdots
$x_N$ $y_N$
```

## 출력

미묘함의 최솟값을 출력하세요.
