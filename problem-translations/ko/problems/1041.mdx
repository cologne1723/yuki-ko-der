## 문제 설명

다카하시 군은 직선 대학(약칭: 직대)의 학생입니다.

직선 대학의 오늘 강의에서는 공선인 점(같은 직선 위에 있는 점들)에 대해 다루었습니다. 다카하시 군은 오늘 강의가 재미있다고 생각했으므로, 좌표평면 위에 $N$개의 점을 찍고 하나의 직선이 최대 몇 개의 점을 지나는지 알아보기로 했습니다. 다카하시 군이 $i$번째로 찍은 점의 좌표는 $(X_i,Y_i)$입니다.

하지만 다카하시 군은 도중에 지쳐서 잠들어 버렸습니다. 다카하시 군 대신 이 문제의 답을 구해 주세요.

## 입력

```text
$N$
$X_1\ Y_1$
$X_2\ Y_2$
$\vdots$
$X_N\ Y_N$
```

## 제한

$2 \le N \le 100$

$0 \le X_i,Y_i \le 100$

$i \ne j$이면 $(X_i,Y_i) \ne (X_j,Y_j)$입니다.

입력은 모두 정수입니다.

## 출력

다카하시 군이 찍은 점을 지나는 점의 개수가 최대인 직선이 지나는 점의 개수를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
1 2
3 4
```

#### 출력

```text
2
```

$(1,2)$와 $(3,4)$를 지나는 직선 외에는 $2$개의 점을 지나는 직선이 없습니다.

### 예제 2 {file=""}

#### 입력

```text
4
1 2
2 4
3 7
4 8
```

#### 출력

```text
3
```

$(1,2)$, $(2,4)$, $(4,8)$은 한 직선 위에 있습니다.

### 예제 3 {file=""}

#### 입력

```text
4
0 0
0 1
1 0
1 1
```

#### 출력

```text
2
```
