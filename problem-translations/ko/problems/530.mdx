## 문제

yuki의 출생 연도 Y가 주어집니다.

간단히 하기 위해 생일은 1월 1일이라고 합니다.

yuki의 2017년 6월 23일 현재 나이를 대신 계산하세요.

## 입력

```text
Y
```

입력 Y는 1970 ≤ Y ≤ 2017을 만족합니다.

## 출력

yuki의 현재 나이를 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
1997
```

출력:

```text
20
```

1997년생인 사람은 현재 20세입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
2017
```

출력:

```text
0
```

나이는 0부터 세기 시작합니다.
