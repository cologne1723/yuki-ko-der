## 이야기

ゆ～さん은 バーチャルこゃーそ学園에서 공부하는 학생입니다. 오늘은 「수학 2」 교재로 일차함수를 공부하려고 합니다.

공부하던 중 ゆ～さん은 문득 중얼거렸습니다.

「음, 지쳤다... 기분 전환하고 싶다...」

선생님은 그 말을 듣고 말했습니다.

「그럼, 「함수 맞히기 게임」을 해 볼까. 모처럼이니 프로그래밍 대회 문제로 만들어 줄게. 프로그래밍 대회는 기분 전환이잖아?」

## 문제 설명

> **대화형 문제를 처음 접하는 분께 드리는 주의사항**
>
> 이 문제는 **대화형 문제**입니다.
>
> 여러분의 프로그램과 채점 프로그램이 표준 입출력을 통해 서로 통신하도록 프로그램이 실행됩니다.
>
> 따라서 프로그램에서 출력한 뒤에 입력을 받아야 합니다. 이때 출력을 flush하지 않으면 채점 프로그램이 프로그램의 출력을 읽지 못하고, 프로그램이 입력을 받으려 해도 채점 프로그램이 입력을 주지 않아 교착 상태가 발생할 수 있습니다.
>
> 출력의 flush에 대해서는 문제문과 입출력 항목에 있는 접기 내용을 참고하세요.
>
> 구체적인 예시는 다음과 같습니다. (Rust에서 proconio 크레이트를 사용하는 경우 이 항목을 확인하는 것을 권장합니다.)
>
> **C++의 경우**
>
> 다음은 선언한 `int`형 정수 $x$를 사용해 질문을 $1$회 하고, 그 질문에 대응하는 $R$을 받는 코드입니다. (이 코드는 이 문제의 풀이 코드가 아닙니다.)
>
> ```cpp
> #include<iostream>
> using namespace std;
>
> int main(){
>     int x = 0;
 >     cout << "? " << x << endl;//endlを使用すると自動的にflushされる。
>     int R;
>     cin >> R;//R=f(x)を満たすRを受け取る
>     return 0;
> }
> ```
>
> **Python의 경우**
>
> 다음은 선언한 정수 $x$를 사용해 질문을 $1$회 하고, 그 질문에 대응하는 $R$을 받는 코드입니다. (이 코드는 이 문제의 풀이 코드가 아닙니다.)
>
> ```python
> import sys
>
> x = 0
> print(f"? {x}")# 改行あり（通常は自動でflushされる）
> R = int(input())# R=f(x)を満たすRを受け取る
> ```
>
> **Java의 경우**
>
> 다음은 선언한 `int`형 정수 $x$를 사용해 질문을 $1$회 하고, 그 질문에 대응하는 $R$을 받는 코드입니다. (이 코드는 이 문제의 풀이 코드가 아닙니다.)
>
> ```java
> import java.util.Scanner;
>
> public class Main {
>     public static void main(String[] args) {
>         Scanner sc = new Scanner(System.in);// 標準入力の設定
>         int x = 0;
>         System.out.println("? " + x);  // 改行あり（通常は自動でflushされる）
>         int R = sc.nextInt();// R=f(x)を満たすRを受け取る
>     }
> }
> ```
>
> **C의 경우**
>
> 다음은 선언한 `int`형 정수 $x$를 사용해 질문을 $1$회 하고, 그 질문에 대응하는 $R$을 받는 코드입니다. (이 코드는 이 문제의 풀이 코드가 아닙니다.)
>
> ```c
> #include <stdio.h>
>
> int main() {
>     int x = 0;
>     printf("? %d\n", x);// この命令ではflushは行われない
>     fflush(stdout);// flushを行う
>     int R;
>     scanf("%d", R)// R=f(x)を満たすRを受け取る
>     return 0;
> }
> ```
>
> **Rust의 경우**
>
> Rust 사용자는 proconio 크레이트를 사용하는 경우가 많다고 가정하지만, 채점 환경에서는 릴리스 빌드가 됩니다.
>
> 이 경우 입력을 한 번에 모두 읽게 되어 대화형 문제에서 채점 결과가 `TLE`가 될 수 있습니다.
>
> `input_interactive!` 매크로를 사용하면 이를 피할 수 있습니다.
>
> 다음은 `input_interactive!` 매크로를 사용해 선언한 정수 $x$로 질문을 $1$회 하고, 그 질문에 대응하는 $R$을 받는 코드입니다. (이 코드는 이 문제의 풀이 코드가 아닙니다.)
>
> ```rust
> use proconio::input_interactive;
>
> fn main() {
>     let mut x = 0;
>     println!("? {}", x);// 改行あり(通常は自動でflushされる)
>     input_interactive!(R: i64);// R=f(x)を満たすRを受け取る
> }
> ```
>
> **Nim의 경우**
>
> 다음은 선언한 정수 $x$를 사용해 질문을 $1$회 하는 코드입니다. (이 코드는 이 문제의 풀이 코드가 아닙니다.)
>
> ```nim
> import strutils
>
> var x = 0 
> echo "? ", x  # 改行あり（通常は自動でflushされる）
> var R = readLine(stdin).parseInt()# R=f(x)を満たすRを受け取る
> ```

이 문제는 **대화형 문제**(여러분이 작성한 프로그램과 채점 프로그램이 표준 입출력을 통해 통신하는 형식의 문제)입니다.

함수 $f$는 정수 $a,b$를 사용해 $f(x)=ax+b$로 나타낼 수 있다는 사실이 알려져 있습니다.

$a,b$의 값은 주어지지 않지만, $a,b$가 모두 $-100$ 이상 $100$ 이하라는 것이 제한에 의해 보장됩니다.

다음 형식의 질문을 최대 $100$회 할 수 있습니다. $a,b$를 특정하세요.

- $-1\,000$ 이상 $1\,000$ 이하인 정수 하나를 선택해 $x$로 하고, $f(x)$의 값을 질문합니다.

## 입력

이 문제는 **대화형 문제**(여러분이 작성한 프로그램과 채점 프로그램이 표준 입출력을 통해 통신하는 형식의 문제)입니다.

처음에는 입력이 주어지지 않습니다.

다음 질문을 최대 $100$회 할 수 있습니다.

- $-1\,000$ 이상 $1\,000$ 이하인 정수 $x$의 값을 출력하고, 채점 프로그램에 $f(x)$의 값을 질문합니다.

위 질문을 할 때는 다음 형식으로 출력하세요. 특히 `? `(`?`와 공백)을 $x$ 앞에 출력해야 한다는 점에 주의하세요.

```text
$?\ x$
```

그 후 출력 결과를 flush하세요.

### 출력 flush란?

일반적으로 프로그램의 표준 출력은 버퍼링되므로, 어느 정도 데이터가 쌓일 때까지 출력되지 않습니다. 그러나 대화형 문제에서는 「출력했을 때 즉시 채점 프로그램에 전달되는 것」이 필요합니다.

따라서 수동으로 flush하여 데이터가 쌓이기를 기다리지 않고 출력해야 합니다.

구체적인 예시는 문제 앞의 주의사항에 있는 각 언어의 코드를 참고하세요. Rust에서 proconio 크레이트를 사용하는 경우 해당 항목을 확인하는 것을 권장합니다.

또한 [대화형 문제에 관한 안내](https://yukicoder.me/wiki/reactive)도 참고하세요.

질문을 하면 출력한 $x$에 대해 $R=f(x)$를 만족하는 $R$의 값이 채점 프로그램으로부터 다음 형식으로 주어지므로, 이를 표준 입력에서 받으세요. 제한에 의해 $R$은 반드시 정수임이 보장됩니다.

```text
$R$
```

단, 다음 조건을 만족하면 대신 오류 응답 $-10^9$가 주어집니다. (제한에 의해 정당한 질문에 대한 답으로 $-100\,000\,000$이 주어지는 일은 없다는 것이 보장됩니다.)

- 조건을 만족하지 않거나 잘못된 값을 출력했습니다.
- 질문 횟수가 $100$회를 초과했습니다.

이때 채점 프로그램은 이미 `WA`로 판정했으므로 **즉시 프로그램을 종료하세요.**

질문을 반복해 $a,b$를 특정했다면 다음 형식으로 $a,b$를 출력하세요. 특히 `! `(`!`와 공백)을 $a$와 $b$ 앞에 출력해야 한다는 점에 주의하세요.

```text
$!\ a\ b$
```

그 후 출력 결과를 flush하고, 즉시 프로그램을 종료하세요.

## 제한

- $-100\leq a,b\leq 100$
- $a,b$는 정수입니다.

## 출력

출력할 때마다 줄 끝에 개행을 넣고 표준 출력을 flush하세요. 그렇게 하지 않으면 채점 결과가 `TLE`가 될 수 있습니다.

대화 도중 잘못된 출력을 하거나 프로그램이 도중에 종료된 경우의 채점 결과는 보장되지 않습니다. 특히 프로그램 실행 중 런타임 오류가 발생한 경우 채점 결과가 `RE`가 아니라 `WA` 또는 `TLE`가 될 수 있다는 점에 주의하세요.

답을 출력했다면 즉시 프로그램을 종료하세요. 그렇지 않으면 채점 결과는 보장되지 않습니다.

출력 flush에 관한 자세한 내용은 [대화형 문제에 관한 안내](https://yukicoder.me/wiki/reactive)도 참고하세요.

이 문제의 채점 프로그램은 적응형이 아닙니다. 즉, 프로그램이 실행된 시점에 $f(x)=ax+b$를 만족하는 $(a,b)$가 어떤 것인지 결정되어 있습니다.

인터랙션 중 출력 flush가 필요한 구체적인 코드는 문제 앞의 주의사항에 있는 C++, Python, Java, C, Rust, Nim 예시를 그대로 참고하세요.

출력 flush에 관한 자세한 내용은 [대화형 문제에 관한 안내](https://yukicoder.me/wiki/reactive)도 참고하세요.
