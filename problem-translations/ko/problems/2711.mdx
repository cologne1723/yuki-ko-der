## 문제

`N × M` 격자의 각 칸에 전구가 있습니다. 전구를 켜거나 끄는 방법 중, 모든 인접한 두 열 `j,j+1`에 대해 두 열 모두 켜진 행의 수가 `K` 이상인 방법의 수를 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `1 ≤ K ≤ N ≤ 5`
- `1 ≤ M ≤ 2 × 10^4`

## 입력

```text
N M K
```

## 출력

답을 출력하세요.
