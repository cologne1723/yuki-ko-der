## 문제 설명

수업 중에도 놀고 있는 dave는 과학 실험 중에 여러 무게의 추를 모두 사용하여 저울이 정확히 수평이 되도록 하는 추의 조합이 있는지 궁금해졌습니다. 모든 추를 사용해야 하므로 남는 추가 있어서는 안 됩니다.

그런 조합이 있는지 dave에게 알려 주어 수업에 집중하게 하세요.

그런 조합이 있으면 `possible`, 없으면 `impossible`을 출력하세요.

## 입력

```text
N
W_1 W_2 W_3 \dots W_N
```

첫째 줄에 추의 개수를 나타내는 정수 $N$이 주어집니다. $(2 \le N \le 100)$
둘째 줄에 각 추의 무게를 나타내는 정수 $W_i$가 공백으로 구분되어 주어집니다. $(1 \le W_i \le 100)$
$W_i$와 $W_j$가 같은 값을 가질 수도 있습니다.

## 출력

`possible` 또는 `impossible`을 한 줄에 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 2 3
```

#### 출력

```text
possible
```

왼쪽에 $1$과 $2$, 오른쪽에 $3$을 놓으면 수평이 됩니다.

### 예제 2 {file=""}

#### 입력

```text
5
1 2 3 4 5
```

#### 출력

```text
impossible
```

모든 추를 사용하여 저울을 수평으로 만들 수 있는 조합이 없습니다. dave에게 빨리 알려 주지 않으면 수업이 끝나 버립니다.

### 예제 3 {file=""}

#### 입력

```text
15
62 8 90 2 24 62 38 64 76 60 30 76 80 74 72
```

#### 출력

```text
impossible
```
