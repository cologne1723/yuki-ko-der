## 문제 설명

$3$개의 단어로 이루어진 문자열이 공백으로 구분되어 주어집니다. 주어진 $3$개 단어의 첫 글자를 각각 꺼내 대문자로 변환한 뒤 이어 붙인 약어(아크로님)를 생성하세요.

## 입력

```text
$s_1\ s_2\ s_3$
```

## 제한

- $s_1$, $s_2$, $s_3$은 각각 영소문자(`a`-`z`)만으로 이루어집니다.
- 각 단어의 길이는 $1$ 이상 $10$ 이하입니다.

## 출력

생성한 약어를 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
three letter acronym
```

#### 출력

```text
TLA
```

### 예제 2 {file=""}

#### 입력

```text
in for loop
```

#### 출력

```text
IFL
```

### 예제 3 {file=""}

#### 입력

```text
a b c
```

#### 출력

```text
ABC
```
