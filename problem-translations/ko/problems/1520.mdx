## 문제

$H\times W$ 격자에서 $(1,1)$에서 $(H,W)$로 이동합니다. 한 번에 아래 또는 오른쪽으로만 이동할 수 있습니다.

경로의 지그재그 정도를 경로가 방향을 바꾸는 칸의 수로 정의합니다. 가능한 모든 $\binom{H+W-2}{H-1}$개 경로의 지그재그 정도 합을 구하세요.

## 입력

첫째 줄에 테스트 케이스 수 $T$가 주어지고, 각 줄에 $H,W$가 주어집니다.

## 출력

각 테스트 케이스의 합을 $10^9+7$로 나눈 나머지를 출력하세요.
