## 문제

6면체 주사위를 n번 던집니다. 주사위의 모든 면이 한 번 이상 나올 확률을 구하세요.

## 입력

```text
n
```

1 ≤ n ≤ 10^6

## 출력

n번 던져 모든 면이 나올 확률을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
1
```

출력:

```text
0
```

한 번 던져 모든 면이 나올 수는 없습니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
6
```

출력:

```text
0.015432098765432
```

(1/6)^6 × 6!입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
7
```

출력:

```text
0.054012345
```

### 샘플 4 {file="sample4.in"}

입력:

```text
50
```

출력:

```text
0.99934071
```

이 정도면 거의 확실하게 모든 면이 나옵니다.
