## 문제

$\sum_{n=1}^{\infty}1/n^2=\pi^2/6$이라는 유명한 공식이 있습니다. 이제 비음이 아닌 실수 $x$가 주어질 때, 급수 $\sum_{n=1}^{\infty}1/(x+n)^2$의 극한값을 계산하세요.

오차는 절대 오차 또는 상대 오차 $10^{-9}$까지 허용됩니다.

## 입력

```text
$x$
```

$0\leq x\leq1000$

## 출력

문제의 급수의 극한값을 한 줄에 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
0
```

출력:

```text
1.6449340668482426
```

$\pi^2/6=1.6449340668482264\cdots$입니다. 오차가 $10^{-9}$ 이하이면 허용됩니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
1.5
```

출력:

```text
0.490357756100235
```

### 샘플 3 {file="sample3.in"}

입력:

```text
1000
```

출력:

```text
0.0009995001666667166
```
