길이 $n+1$의 수열 $A,B,C$와 정수 $x$가 주어집니다. $0\le j,k\le n$, $i=j+k\le n$인 모든 $(i,j,k)$에 대해 $A_iB_jC_kx^{ijk}$의 합을 계산하세요. 결과는 $943718401$로 나눈 나머지입니다.

## 조건

- $0\le n\le2\times10^5$
- 모든 입력 값은 $943718401$ 미만의 음이 아닌 정수입니다.

## 입력

```text
n x
A0 ... An
B0 ... Bn
C0 ... Cn
```

## 출력

답을 $943718401$로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text

1 2 3
4 5 6
7 8 9
```

#### 출력

```text
4716
```
