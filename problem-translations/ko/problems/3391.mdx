## 문제 설명

yu23578君은 $1$부터 $N$까지의 번호가 붙은 $N$종류의 도미노를 종류마다 $10^{100}$개씩 가지고 있습니다. 도미노 $i$의 크기는 $A_i$입니다.

yu23578君은 이 중에서 도미노를 $M$개 골라 가로로 일렬로 늘어놓기로 했습니다. 다음 조건을 만족하는 도미노 배치 방법의 수를 $\mathrm{mod}\ 998\,244\,353$로 구하세요.

- 서로 이웃한 도미노의 크기 차이는 $K$ 이하입니다.

## 입력

```text
$N\ M\ K$
$A_1\ A_2\ A_3\ \cdots\ A_N$
```

$1$번째 줄에 도미노 종류의 수 $N$, 고를 도미노의 수 $M$, 인접한 도미노의 크기 차이에 대한 제한 $K$가 주어집니다.

$2$번째 줄에 각 도미노 종류의 크기 $A_1,A_2,\ldots,A_N$이 주어집니다.

## 제한

- $1 \le N,M \le 10\,000$
- $0 \le K \le 10^9$
- $1 \le A_i \le 10^9$
- 입력은 모두 정수입니다.

## 출력

조건을 만족하는 도미노 배치 방법의 수를 $\mathrm{mod}\ 998\,244\,353$로 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 2 2
3 1 4
```

#### 출력

```text
7
```

조건을 만족하는 배치는 다음 $7$가지입니다.

- (도미노 $1$, 도미노 $1$)
- (도미노 $1$, 도미노 $2$)
- (도미노 $1$, 도미노 $3$)
- (도미노 $2$, 도미노 $1$)
- (도미노 $2$, 도미노 $2$)
- (도미노 $3$, 도미노 $1$)
- (도미노 $3$, 도미노 $3$)

따라서 $7$을 출력하세요.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 1 1000000000
1000000000
```

#### 출력

```text
1
```


#### 출력

```text

```
