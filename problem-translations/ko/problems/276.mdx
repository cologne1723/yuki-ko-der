## 문제

중학교 수학에서는 “연속하는 3개의 양의 정수의 합은 3으로 나누어떨어진다”라는 명제가 참임을 증명합니다.

이를 조금 일반화하여 다음 명제를 생각합니다.

> 연속하는 $N$개의 양의 정수의 합은 $X$로 나누어떨어진다.

양의 정수 $N$이 주어질 때, 이 명제가 참이 되도록 하는 가장 큰 양의 정수 $X$를 구하세요.

## 입력

```text
N
```

한 줄에 $N$이 주어집니다.

- $1 \le N \le 10^9$

## 출력

명제를 참이 되게 하는 가장 큰 양의 정수 $X$를 한 줄에 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
3
```

### 샘플 1 {file="sample1.out"}

```text
3
```

연속하는 3개의 양의 정수의 합이 3의 배수가 된다는 것은 중학교 수학에서 배운 사람도 많을 것입니다. 예를 들어 $1+2+3=6$은 3의 배수이고, $2+3+4=9$도 3의 배수입니다.

### 샘플 2 {file="sample2.in"}

```text
2
```

### 샘플 2 {file="sample2.out"}

```text
1
```

$1+2=3$, $2+3=5$, $100+101=201$ 등을 생각하면 가장 큰 $X$는 1입니다.
