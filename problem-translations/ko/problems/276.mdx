## 문제 설명

다음 명제를 생각합니다.

> 연속하는 $N$개의 양의 정수의 합은 $X$로 나누어떨어진다.

양의 정수 $N$이 주어질 때, 이 명제가 참이 되도록 하는 가장 큰 양의 정수 $X$를 구하세요.

### 배경

중학교 수학에서는 “연속하는 $3$개의 양의 정수의 합은 $3$으로 나누어떨어진다”라는 명제가 참임을 증명합니다.

위 명제는 이를 조금 일반화한 것입니다.

## 입력

```text
$N$
```

$1$줄에 $N$이 주어집니다.

## 제한

- $1 \le N \le 10^9$

## 출력

```text
$X$
```

명제를 참이 되게 하는 가장 큰 양의 정수 $X$를 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
```

#### 출력

```text
3
```

연속하는 $3$개의 양의 정수의 합이 $3$의 배수가 된다는 것은 중학교 수학에서 배운 사람도 많을 것입니다. 예를 들어 $1+2+3=6$은 $3$의 배수이고, $2+3+4=9$도 $3$의 배수입니다.

### 예제 2 {file=""}

#### 입력

```text
2
```

#### 출력

```text
1
```

$1+2=3$, $2+3=5$, $100+101=201$ 등을 생각하면 가장 큰 $X$는 $1$입니다.
