## 문제 설명

동전이 들어 있거나 비어 있는 모자 3개가 나란히 있습니다. A는 처음에 모든 모자의 상태를 보여 줍니다.

한 번의 조작으로 왼쪽 두 모자 또는 오른쪽 두 모자를 내용물과 함께 서로 바꿀 수 있습니다. A는 관객에게 정확히 $N$번 원하는 조작을 하도록 부탁합니다. 조작 횟수는 알 수 있지만 어떤 조작을 했는지는 보이지 않습니다.

A가 모든 모자를 열었을 때 가능한 상태가 아니라면 마술은 성공입니다. 성공이면 `SUCCESS`, 실패면 `FAILURE`를 출력하세요.

## 입력

```text
S_{before}
N
S_{after}
```

- `S_before`와 `S_after`는 `o`와 `x`로 이루어진 길이 3의 문자열입니다.
- 왼쪽부터 `o`는 동전이 들어 있음, `x`는 비어 있음을 나타냅니다.
- $0 \le N \le 2{,}000{,}000{,}000$

## 출력

마술이 성공하면 `SUCCESS`, 실패하면 `FAILURE`를 한 줄에 출력하세요.

## 예제

### 예제 1

```text
xxo
1
oxx
```

```text
SUCCESS
```

오른쪽 모자의 동전이 한 번의 조작 후 왼쪽으로 이동한 상태는 왼쪽 두 모자나 오른쪽 두 모자를 바꾸어서는 만들 수 없습니다.

### 예제 2

```text
xoo
2
oox
```

```text
FAILURE
```

먼저 왼쪽 두 모자를 바꾸고 다음에 오른쪽 두 모자를 바꾸면 가능한 상태입니다.

### 예제 3

```text
ooo
0
xxx
```

```text
SUCCESS
```

0번 조작으로도 모자의 동전이 모두 사라진 상태는 가능하지 않습니다.

### 예제 4

```text
oxo
2000000000
oxo
```

```text
FAILURE
```

가능한 상태이므로 실패입니다.
