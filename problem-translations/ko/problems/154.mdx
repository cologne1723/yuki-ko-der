## 문제 설명

교토의 시내버스에는 여러 노선이 있습니다. 각 노선에서 그날의 막차와 막차의 바로 전 버스는 전광판의 불빛 색이 평소와 다릅니다. 평소에는 흰색, 막차의 바로 전 버스는 초록색, 막차는 빨간색입니다.

유키는 첫차부터 막차까지 어떤 도로를 지나가는 모든 버스의 불빛 색을 확인하고 본 순서대로 메모했습니다. 이 메모가 실제로 가능한 순서를 나타내는지 판정하세요.

모든 노선의 시내버스는 매일 3대 이상 운행하며, 하루 동안 같은 경로를 운행한다고 가정합니다.

## 입력

첫째 줄에 테스트 케이스 수 $T$가 주어집니다. 각 테스트 케이스에는 문자열 $S$가 주어집니다. $S$의 $i$번째 문자는 $i$번째로 본 버스의 불빛 색을 나타내며, `W`는 흰색, `G`는 초록색, `R`은 빨간색입니다.

- $1 \le T \le 1000$
- $1 \le |S| \le 1000$

## 출력

가능한 패턴이면 `possible`, 불가능하면 `impossible`을 각 테스트 케이스마다 한 줄에 출력하세요.

## 예제

### 예제

```text
5
WWWWWWWWWGR
WWWWGWGRR
WWWWWWWWWWWWWWGRRG
WGRWGR
WWWWWWWWWWWWWWWWWGGWGWGGWGWGGGWGG
```

```text
possible
possible
impossible
possible
impossible
```

첫 번째는 한 노선만 있는 경우입니다. 두 번째는 두 노선이 있는 경우입니다. 세 번째는 한 노선에서 막차 뒤에 초록색 버스가 오는 것처럼 되어 이상하므로 불가능합니다. 네 번째처럼 한 노선의 막차가 끝난 뒤 다른 노선이 운행을 시작할 수도 있습니다. 다섯 번째는 막차가 없으므로 불가능합니다.
