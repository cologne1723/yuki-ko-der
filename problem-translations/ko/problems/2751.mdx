## 문제

소인수를 중복해서 세었을 때 소인수의 개수가 정확히 3개인 양의 정수를 429-like Number라고 합니다. `Q`개의 정수에 대해 각각 429-like Number인지 판정하세요.

## 제약

- `1 ≤ Q ≤ 10^4`
- `1 ≤ A_i ≤ 10^10`

## 입력

```text
Q
A_1
⋮
A_Q
```

## 출력

각 수가 조건을 만족하면 `Yes`, 아니면 `No`를 출력하세요.
