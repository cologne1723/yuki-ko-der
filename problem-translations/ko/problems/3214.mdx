## 문제 설명

$2$차원 평면 위에 $N$개의 점이 존재합니다. $i\ (1 \leq i \leq N)$번째 점의 좌표는 $(X_i,Y_i)$이고, 점의 가치는 $V_i$입니다.

각 변이 $x$축 또는 $y$축과 평행하고 변의 길이가 $A$인 정사각형을 정확히 $1$개 지정합니다. 이때 정사각형의 내부(경계를 포함)에 있는 점들의 가치 합으로 가능한 최댓값을 출력하세요.

## 입력

```text
$N\ A$
$X_1\ Y_1\ V_1$
$X_2\ Y_2\ V_2$
$\vdots$
$X_N\ Y_N\ V_N$
```

## 제한

- $1 \leq N \leq 100\,000$
- $-10^9 \leq X_i,Y_i \leq 10^9$
- $-10^9 \leq V_i \leq 10^9$
- $1 \leq A \leq 10^9$
- 입력은 모두 정수입니다.

## 출력

각 변이 $x$축 또는 $y$축과 평행하고 변의 길이가 $A$인 정사각형을 정확히 $1$개 지정했을 때, 정사각형의 내부(경계를 포함)에 있는 점들의 가치 합으로 가능한 최댓값을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4 3
3 5 9
7 8 25
4 3 18
-1 2 -14
```

#### 출력

```text
27
```

정사각형 영역을 $2 \leq X \leq 5$, $3 \leq Y \leq 6$으로 지정하면 가치의 합 $27$을 얻을 수 있습니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 4
1 0 -2
5 0 3
6 0 -4
```

#### 출력

```text
3
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
9 2
0 0 -3
1 0 2
2 0 3
2 0 2
3 0 -3
0 2 -4
1 2 1
2 2 1
3 2 -4
```

#### 출력

```text
9
```

완전히 같은 좌표에 여러 점이 존재할 수도 있습니다.
