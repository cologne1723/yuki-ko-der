길이 $M$인 수열 $X=(X_1,X_2,\ldots,X_M)$에 대해 다음 조작을 생각합니다. $i$를 골라 $X_i$를 제외한 모든 원소를 $-1$ 감소시킵니다.

길이 2 이상인 수열 $X$에 이 조작을 원하는 횟수만큼 수행해 모든 원소를 0으로 만들 수 있으면 $X$를 좋은 수열이라고 합니다. 길이 $N$인 수열 $A$에서 원소를 순서를 유지하며 임의로 골라 만들 수 있는 $2^N$개 수열 중 좋은 수열의 개수를 구하세요.

## 입력

```text
N
A_1 A_2 ... A_N
```

$2\le N\le50$, $0\le A_i\le100$입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
3 1 4
```

#### 출력

```text
4
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3
1 1 4
```

#### 출력

```text
3
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
5
0 0 0 0 0
```

#### 출력

```text
26
```


#### 출력

```text
52063
```
