## 문제 설명

타로는 카탈로그 쇼핑을 아주 좋아합니다.

오늘도 카탈로그에서 상품을 골라 구매했지만, 타로는 매우 부자라서 상품을 대충 고르고는 무엇을 샀는지 늘 잊어버립니다.

다행히 신용 카드 명세서가 남아 있어 구매한 상품의 총액만 알 수 있습니다.

타로가 무엇을 샀는지 계산하여 상품 번호를 알려 주세요. 단, 한 상품을 여러 개 구매하지 않았다고 가정합니다.

## 입력

```text
N S
P_1
P_2
\dots
P_N
```

첫째 줄에 카탈로그에 실린 상품 수 $N$과 구매 총액 $S$가 공백으로 구분되어 주어집니다. $(1 \le N \le 31; 1 \le S \le 310\,000\,000)$
이후 $N$개의 줄에 상품 번호 $i$의 가격 $P_i$가 주어집니다. $(1 \le i \le N; 1 \le P_i \le 10\,000\,000)$

## 출력

구매한 상품의 상품 번호를 한 줄에 오름차순으로, 하나의 공백으로 구분하여 출력하세요. 줄 끝에 줄바꿈 문자를 출력하세요.
구매한 상품의 조합이 여러 개라면 가능한 모든 조합을 오름차순으로 출력하세요. 조합 안에서 더 작은 상품 번호가 먼저 나오는 조합을 먼저 출력하세요. 출력 예제 4와 5를 참고하세요.

출력 행 수가 50개 이상이 되는 입력은 주어지지 않습니다.
