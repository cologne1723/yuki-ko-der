## 문제 설명

太郎君은 카탈로그 쇼핑을 아주 좋아합니다.

오늘도 카탈로그에서 상품을 골라 구매했지만, 太郎君은 매우 부자라서 상품을 대충 고르고는 무엇을 샀는지 늘 잊어버립니다.

다행히 신용 카드 명세서가 남아 있어 구매한 상품의 총액만 알 수 있습니다.

太郎君이 무엇을 샀는지 계산하여 상품 번호를 알려 주세요. 단, $1$개 상품을 여러 개 구매하지 않았다고 가정합니다.

## 입력

```text
$N\ S$
$P_1$
$P_2$
$\vdots$
$P_N$
```

$N$은 카탈로그의 상품 수, $S$는 구매 총액을 나타내는 정수입니다.
이후 $N$개의 줄에 $i$번 상품의 가격을 나타내는 정수 $P_i$가 주어집니다.

## 제한

- $1 \le N \le 31$
- $1 \le S \le 310\,000\,000$
- $1 \le P_i \le 10\,000\,000$ $(1 \le i \le N)$
- 구매한 상품의 조합으로 가능한 경우의 수가 $50$개 이상이 되는 입력은 주어지지 않습니다.

## 출력

구매한 상품의 상품 번호를 $1$줄에 오름차순으로, $1$개의 공백으로 구분하여 출력하세요. 줄 끝에 줄바꿈 문자를 출력하세요.
구매한 상품의 조합이 여러 개라면 가능한 모든 조합을 오름차순으로 출력하세요. (조합 안에서 더 작은 상품 번호가 먼저 나오는 조합을 먼저 출력하세요. 출력 예제 4와 5를 참고하세요.)
