## 문제 설명

Sara는 “신기한 주머니”를 얻었습니다.
신기한 주머니에 비스킷을 넣고 두드리면 넣은 비스킷의 개수가 $2$배가 됩니다.

Sara는 처음에 비스킷 $1$개를 가지고 있으며, 신기한 주머니를 사용해 정확히 $N$개로 만든 뒤 모두 먹고 싶습니다. (다 먹을 수 없으므로 개수가 $N$개를 초과해서는 안 됩니다.)

정확히 $N$개로 만들기 위해 주머니를 두드려야 하는 최소 횟수를 구하세요.

## 입력

```text
$N$
```

Sara가 먹고 싶은 비스킷 개수 $N$이 주어집니다.

## 제한

$1 \le N \le 100\,000\,000$

## 출력

주머니를 두드리는 최소 횟수를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
```

#### 출력

```text
2
```

처음 비스킷 $1$개를 주머니에 넣고 두드리면 $2$개가 됩니다. 그중 $1$개를 다시 주머니에 넣고 두드리면 총 $3$개가 됩니다. 따라서 $2$번 두드리면 됩니다.

### 예제 2 {file=""}

#### 입력

```text
4
```

#### 출력

```text
2
```

처음 $1$개를 두드려 $2$개로 만든 뒤, $2$개를 그대로 다시 두드리면 총 $4$개가 됩니다.

### 예제 3 {file=""}

#### 입력

```text
1000
```

#### 출력

```text
10
```
