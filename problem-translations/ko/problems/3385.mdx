## 이야기

naka9 君은 아름다운 경관으로 유명한 TSG 왕국으로 여행을 계획하고 있습니다.

naka9 君은 지점 $1$에서 지점 $N$까지 하이킹하려고 하지만, 여러 번 오르내리고 싶지는 않습니다.

## 문제 설명

TSG 왕국에는 $1$번 지점부터 $N$번 지점까지의 지점과 이들을 연결하는 $M$개의 도로가 있습니다. $i$번째 도로는 서로 다른 $2$개의 지점 $a_i$, $b_i$를 양방향으로 연결합니다. $2$개의 지점을 직접 연결하는 도로는 최대 $1$개입니다.

또한 각 지점 $i$는 이 $N$개 지점 중에서 표고가 $H_i$번째로 낮습니다. 여기서 $H_i$는 서로 다릅니다.

그래서 어떤 지점까지 올라간 뒤 어떤 지점부터 내려가는 경로를 찾으려고 합니다. 즉, 지점 $v_1(=1),v_2,\ldots,v_K(=N)$을 순서대로 지나갈 때, 어떤 $1\leq j\leq K$에 대하여 $H_{v_1},\ldots,H_{v_j}$가 단조 증가하고 $H_{v_j},\ldots,H_{v_K}$가 단조 감소하는 경로를 찾습니다.

이 조건을 만족하는 경로 중 길이가 가장 긴 경로의 길이를 출력하세요.

단, 조건을 만족하는 경로가 존재하지 않으면 그 사실을 출력하세요.

### 경로와 경로의 길이

지점 $1$에서 지점 $N$까지 길이 $K$인 경로가 존재한다는 것은 다음 조건을 만족하는 $1$ 이상 $N$ 이하의 정수열 $v_1,v_2,\ldots,v_K$가 존재한다는 뜻입니다.

- $v_1=1$
- $v_K=N$
- $i=1,2,\ldots,K-1$에 대하여 지점 $v_i$와 지점 $v_{i+1}$를 직접 연결하는 도로가 존재합니다.

## 입력

```text
$N\ M$
$H_1\ H_2\ \cdots\ H_N$
$a_1\ b_1$
$\vdots$
$a_M\ b_M$
```

$1$번째 줄에 지점의 수를 나타내는 정수 $N$과 도로의 수를 나타내는 정수 $M$이 주어집니다.

$2$번째 줄에 각 지점의 표고 순위를 나타내는 정수 $H_1,H_2,\ldots,H_N$이 주어집니다.

이후 $M$개 줄에 걸쳐 $i$번째 도로가 연결하는 $2$개의 지점 $a_i$, $b_i$가 주어집니다.

## 제한

- $2\leq N\leq 100\,000$
- $1\leq M\leq\min(100\,000,\frac{N(N-1)}{2})$
- $1\leq H_i\leq N\ (1\leq i\leq N)$
- $i\neq j$일 때 $H_i\neq H_j$
- $1\leq a_i<b_i\leq N\ (1\leq i\leq M)$
- $i\neq j$일 때 $(a_i,b_i)\neq(a_j,b_j)$
- 입력은 모두 정수입니다.

## 출력

조건을 만족하는 경로의 길이를 출력하세요. 단, 그러한 경로가 존재하지 않으면 $-1$을 출력하세요. 마지막으로 개행도 출력하세요.

## 점수

예상 해답의 길이는 $297$바이트입니다.

제출한 소스 코드의 길이가 $x$이고 이 문제의 예상 해답 코드 길이가 $y$일 때, 해당 소스 코드의 점수는 다음과 같이 계산됩니다.

- $y\leq x$일 때: $\lfloor100\exp(-0.012(x-y))\rfloor$점
- $x<y$일 때: $101$점

이 문제의 점수는 이 문제에 제출된 소스 코드 점수의 최댓값입니다.
