5차 순열 $A,B$가 1행 표기법으로 주어진다냥. 합성 순열 $A\circ B$를 구하라냥. 즉 각 $i$에 대해 $(A\circ B)(i)=A(B(i))$이다냥.

<details>
<summary>순열과 $1$행 표기법에 관한 설명 (클릭하여 펼치기)</summary>

양의 정수 $n$에 대해, $n$차 순열은 대략 $n$ 이하의 양의 정수를 섞는 함수입니다. 더 정확하게는 다음과 같이 정의합니다.

**정의 (순열).** $n$ 이하의 양의 정수 전체의 집합을 $I_n$이라 둡니다. $n$차 순열은 $I_n$에서 $I_n$으로 가는 전단사 함수입니다.

예를 들어 $I_n$의 항등 함수는 $n$차 순열이며, 항등 순열이라고 합니다.

$n$차 순열 $a,b$가 주어졌을 때 함수의 합성 $a\circ b$도 $n$차 순열이며, $a,b$의 합성 순열이라고 합니다. 즉 합성 순열 $a\circ b$는 $n$ 이하의 각 양의 정수 $i$를 $a(b(i))$로 보내는 함수입니다.

$n$차 순열을 나타내는 방법은 여러 가지입니다. 예를 들어 각 양의 정수 $i$의 대응값을 $i$가 작은 순서대로 나열하는 표기법을 $1$행 표기법이라고 합니다. 표기법에 따라 나열한 수 전체를 괄호로 묶거나 쉼표로 구분하기도 하지만, 여기서는 괄호 없이 공백으로 구분합니다.

예를 들어 $n=5$라 합시다. $5$ 이하의 각 양의 정수 $i$를 $2i\equiv j\pmod 5$를 만족하는 유일한 $5$ 이하의 양의 정수 $j$로 보내는 함수 $a$는 $5$차 순열이며 다음과 같습니다.

$\begin{array}{rcl}
a(1)&=&2\\
a(2)&=&4\\
a(3)&=&1\\
a(4)&=&3\\
a(5)&=&5
\end{array}$

따라서 $1$행 표기법에서 $a$는 $2\ 4\ 1\ 3\ 5$로 나타냅니다. 일반적으로 $5$차 순열 $a$는 $1$행 표기법으로 $a(1)\ a(2)\ a(3)\ a(4)\ a(5)$라고 씁니다.

</details>

## 조건

- $A$와 $B$는 5차 순열이다냥.

## 입력

첫째 줄에 $A(1),\ldots,A(5)$, 둘째 줄에 $B(1),\ldots,B(5)$가 주어진다냥.

## 출력

$A\circ B$의 1행 표기법을 출력하라냥.
