## 문제 설명

길이가 $M$인 정수열 $X$에 대해 $f(X)$를 다음과 같이 정의합니다.

- $X_i > X_j$를 만족하는 $(i,j)$의 개수($1 \le i < j \le M$)

정수 $N$이 주어집니다.

$N$행 $N$열의 행렬 $S$를 생각하고, 위에서 $i$번째 행, 왼쪽에서 $j$번째 열의 원소를 $S_{i,j}$라고 합니다.

여기서 $0 \le S_{i,j} \le 10^6$입니다.

정수열 $A$를 다음과 같이 정의합니다.

- $A_i = f([S_{i,1}, S_{i,2}, \dots, S_{i,N}])$ ($1 \le i \le N$)

정수열 $B$를 다음과 같이 정의합니다.

- $B_j = f([S_{1,j}, S_{2,j}, \dots, S_{N,j}])$ ($1 \le j \le N$)

정수 $K$가 주어집니다. $f(A) + f(B) = K$를 만족하는 $S$를 구성하세요. 구성할 수 없다면 그 사실을 보고하세요.

답이 여러 개라면 그중 하나를 구하세요.

## 제한

$1 \le N \le 1\,000$

$0 \le K \le 1\,000\,000\,000$

$N$, $K$는 정수입니다.

## 입력

```text
$N\ K$
```

입력은 $1$줄로 주어집니다.

$N$, $K$가 공백으로 구분되어 주어집니다.

## 출력

구성할 수 없는 경우 `No`를 한 줄에 출력하세요.

그렇지 않은 경우 `Yes`를 한 줄에 출력한 뒤, $N$줄을 출력하세요.

$i+1$번째 줄에는 $S_{i,1}, S_{i,2}, \dots, S_{i,N}$을 공백으로 구분하여 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 3
```

#### 출력

```text
Yes
3 2 3
2 3 1
1 3 2
```

$A_1 = f([3,2,3]) = 1$

$A_2 = f([2,3,1]) = 2$

$A_3 = f([1,3,2]) = 1$

$B_1 = f([3,2,1]) = 3$

$B_2 = f([2,3,3]) = 0$

$B_3 = f([3,1,2]) = 2$

따라서 $A=[1,2,1]$, $B=[3,0,2]$가 됩니다.

$f(A)+f(B)=f([1,2,1])+f([3,0,2])=1+2=3$이므로, 이 $S$는 조건을 만족합니다.
