## 문제 설명

구별할 수 있는 $N$마리의 순록이 있습니다. 이 순록 중에서 정확히 $K$마리의 순록을 고르는 조합은 몇 가지인지 구하세요. 단, 선택되는 순록의 집합이 같고 고르는 순서만 다른 경우에는 같은 고르기로 간주합니다.

또한 답이 매우 커질 수 있으므로, 답을 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 입력

```text
$N\ K$
```

## 제한

- $1\leq N\leq 10^9$
- $0\leq K\leq N$

## 출력

답을 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
5 3
```

#### 출력

```text
10
```

구별할 수 있는 $5$마리의 순록 중에서 정확히 $3$마리의 순록을 고르는 조합은 $10$가지입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
33 16
```

#### 출력

```text
168558757
```

구별할 수 있는 $33$마리의 순록 중에서 정확히 $16$마리의 순록을 고르는 조합은 $1\,166\,803\,110$가지입니다. $998\,244\,353$으로 나눈 나머지인 $168\,558\,757$을 출력하세요.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
998244355 2
```

#### 출력

```text
1
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
998244355 3
```

#### 출력

```text
0
```
