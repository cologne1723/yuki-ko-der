## 문제 설명

크기가 $N$인 서로 다른 양의 정수로 이루어진 집합 $S = \{S_1,S_2,...S_N\}$에 대해 다음과 같이 점수를 정의합니다.

직관적으로 $S$의 점수는 ${\rm lcm}(S_i,S_j)$ ($1 \leq i < j \leq N$)로 가능한 서로 다른 값의 개수입니다.

엄밀한 정의는 다음과 같습니다.

- $S$의 점수를 다음 조건을 만족하는 정수 $m$의 개수로 정의합니다.
  - 어떤 정수 $i,j$ ($1 \leq i < j \leq N$)가 존재하여 $m = {\rm lcm}(S_i,S_j)$입니다.
  - ${\rm lcm}(x,y)$는 $x$와 $y$의 최소공배수를 나타냅니다.

가능한 집합 $S$ 중 점수가 **최소**가 되는 집합을 $1$개 출력하세요.

## 입력

```text
$N$
```

## 제한

- $N$은 $2$ 이상 $10$ 이하인 정수입니다.
- $1 \leq S_i \leq 10^9$
- $S_i \neq S_j$ ($1 \leq i < j \leq N$)

위의 제한을 만족하면서 점수가 최소가 되는 집합 $S$가 존재함을 증명할 수 있습니다.

## 출력

집합 $S$를 다음 형식으로 출력하세요.

```text
$S_1\ S_2\ \dots\ S_N$
```

정답이 여러 개 존재할 수 있으며, 그중 어떤 것을 출력해도 정답으로 인정됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
```

#### 출력

```text
2 6 3
```

$S = \{2,6,3\}$에 대해 다음이 성립합니다.

- ${\rm lcm}(S_1,S_2) = {\rm lcm}(2,6) = 6$
- ${\rm lcm}(S_1,S_3) = {\rm lcm}(2,3) = 6$
- ${\rm lcm}(S_2,S_3) = {\rm lcm}(3,6) = 6$

이때 $S$의 점수는 $1$이며, 이는 달성 가능한 최솟값입니다.

그 밖에도 `1500 300 500`과 같은 출력을 정답으로 인정합니다.

반면 $S = \{2,4,8\}$에 대해서는 다음이 성립합니다.

- ${\rm lcm}(S_1,S_2) = {\rm lcm}(2,4) = 4$
- ${\rm lcm}(S_1,S_3) = {\rm lcm}(2,8) = 8$
- ${\rm lcm}(S_2,S_3) = {\rm lcm}(4,8) = 8$

이때 $S$의 점수는 $2$입니다. 이는 달성 가능한 최솟값이 아니므로 `2 4 8`이라는 출력은 오답으로 판정됩니다.
