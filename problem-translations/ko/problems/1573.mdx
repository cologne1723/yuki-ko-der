## 문제

양의 정수 $x,y$에 대해 $f(x,y)=\sum_{i\mid x,,1\leq i\leq y}(x+i)$로 정의합니다. $\sum_{i=1}^{n}f(i,m)$을 $998244353$으로 나눈 나머지를 구하세요.

## 입력

$n,m$이 주어집니다.

- $1\leq n,m\leq10^9$

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
6 3
```

#### 출력

```text
60
```

### 예제 2 {file=""}

#### 입력

```text
2020 1000
```

#### 출력

```text
17124456
```

### 예제 3 {file=""}

#### 입력

```text
1000000000 562967432
```

#### 출력

```text
954330278
```
