## 문제 설명

수직선의 정수 좌표에 $N$개의 점이 있습니다.

그중 같은 좌표가 아닌 두 점을 골라 두 점 사이의 거리를 구합니다. $i$번째 점의 좌표를 $X_i$, $j$번째 점의 좌표를 $X_j$라고 하면 거리는 $|X_i-X_j|$입니다.

이때 거리가 최소가 되는 두 점을 골랐을 때, 두 점 사이의 최소 거리를 구하세요. 조건에 맞는 두 점을 고를 수 없으면 $0$을 출력하세요.

## 입력

```text
N
X_1 X_2 ... X_N
```

모든 입력은 정수입니다.

- $1 \le N \le 100\,000$
- $0 \le X_i \le 1\,000\,000$

## 출력

조건에 맞는 두 점 사이의 최소 거리를 출력하세요. 두 점을 고를 수 없으면 $0$을 출력하세요.

## 예제

```text
3
0 51 100
```

```text
49
```

좌표 51과 100의 점을 고르면 최소 거리 49가 됩니다.

```text
4
0 1 1 0
```

```text
1
```

같은 좌표의 점이 주어질 수도 있습니다.
