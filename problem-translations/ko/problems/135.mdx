## 문제 설명

수직선의 정수 좌표에 $N$개의 점이 있습니다.

그중 같은 좌표가 아닌 $2$개의 점을 골라 $2$개의 점 사이의 거리를 구합니다. $i$번째 점의 좌표를 $X_i$, $j$번째 점의 좌표를 $X_j$라고 하면 거리는 $|X_i-X_j|$입니다.

이때 거리가 최소가 되는 $2$개의 점을 골랐을 때, $2$개의 점 사이의 최소 거리를 구하세요. 조건에 맞는 $2$개의 점을 고를 수 없으면 $0$을 출력하세요.

## 입력

```text
$N$
$X_1\ X_2\ \cdots\ X_N$
```

모든 입력은 정수입니다.

## 제한

- $1 \le N \le 100\,000$
- $0 \le X_i \le 1\,000\,000$, $1 \le i \le N$

## 출력

조건에 맞는 $2$개의 점 사이의 최소 거리를 출력하세요. $2$개의 점을 고를 수 없으면 $0$을 출력하세요.

출력 끝에는 개행을 포함해야 합니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
0 51 100
```

#### 출력

```text
49
```

좌표 $51$과 $100$의 점을 고르면 최소 거리 $49$가 됩니다.

### 예제 2 {file=""}

#### 입력

```text
4
0 1 1 0
```

#### 출력

```text
1
```

같은 좌표의 점이 주어질 수도 있습니다.
