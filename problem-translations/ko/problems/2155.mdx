현재 색 $L$에서 시작해 색 $A_1,A_2,\ldots,A_N$을 순서대로 원하는 만큼 섞을 수 있다냥. 색 $A$와 $B$를 섞으면 $\lfloor(A+B)/2\rfloor$가 된다냥. 각 색은 건너뛸 수도 있지만 순서를 바꿀 수는 없다냥. 최종 색으로 $M$을 만들 수 있는지 판정하라냥.

## 조건

- $1\le N\le100$
- $1\le M,L,A_i\le1000$

## 입력

```text
N M L
A_1 A_2 \cdots A_N
```

## 출력

만들 수 있으면 `Yes`, 없으면 `No`를 출력하라냥.
