## 문제 설명

이 문제는 **통신 문제**입니다. 작성한 프로그램이 여러 프로세스로 실행되며, 채점 시스템과의 입출력으로 대화합니다.

Alice와 Bob으로서 다음 절차를 수행하는 프로그램을 작성하세요. 절차는 단계 $1$과 단계 $2$로 이루어지며, 단계 $1$ 직후에 단계 $2$를 진행합니다.

### 단계 $1$

- Alice와 Bob은 채점 시스템에서 양의 정수 $N$을 받습니다.
- Alice와 Bob은 채점 시스템에 양의 정수 $k$를 보냅니다.

### 단계 $2$

- Alice는 채점 시스템에서 정점에 $1$부터 $N$까지 번호가 붙은 정점 $N$개의 트리 $T$를 받습니다.
- Alice는 Bob에게 $1$ 이상 $N$ 이하의 정수로 이루어진 길이 $k$의 수열 $A=(A_1,A_2,\cdots,A_k)$를 보냅니다.
- Bob은 정점에 $1$부터 $N$까지 번호가 붙은 트리 중 $T$와 같은 트리 하나를 답합니다.

두 트리 $T,T'$가 같다는 것은 모든 $1\leq u\lt v\leq N$에 대해, $T$에 정점 쌍 $(u,v)$를 연결하는 간선이 존재하는 것과 $T'$에 해당 간선이 존재하는 것이 동치라는 뜻입니다.

**$T$에 관계없이 위 문제를 맞히는 데 필요한 $k$의 최솟값을 $k_{\min}$이라고 합니다. 단계 $1$에서 Alice와 Bob이 출력하는 $k$는 $k_{\min}$이어야 합니다.**

## 입력

이 **통신 문제**에서는 Alice로 동작하는 프로그램과 Bob으로 동작하는 프로그램이 채점 시스템과의 입출력으로 대화합니다. 먼저 어느 역할로 동작해야 하는지 나타내는 문자열 $\mathrm{player}$가 주어집니다. `Alice`이면 Alice로, `Bob`이면 Bob으로 동작하세요.

```text
$\mathrm{player}$
```

이후 단계 $1$, 단계 $2$ 순서로 진행합니다.

### 단계 $1$

Alice와 Bob 모두 정수 $N$을 받습니다.

```text
$N$
```

출력 절에 따라 $k$를 출력한 뒤, $k$의 조건을 만족하지 않으면 채점기가 $-1$을 출력합니다. 이때 이미 오답으로 판정되었으며 채점 시스템도 종료합니다.

### 단계 $2$

Alice에게 트리 $T$가 다음 형식으로 주어집니다.

```text
$U_1\ V_1$
$U_2\ V_2$
$\vdots$
$U_{N-1}\ V_{N-1}$
```

$U_i,V_i$는 $1$ 이상 $N$ 이하의 정수이며, 각 $i$ $(1\leq i\leq N-1)$에 대해 정점 $U_i$와 $V_i$가 간선으로 연결되어 있다는 뜻입니다.

Alice가 수열 $A$를 출력하면 Bob은 그 수열을 다음 형식으로 받습니다.

```text
$A_1\ A_2\ \ldots\ A_k$
```

## 제한

- $3\leq N\leq 1\,000$
- $T$는 정점에 $1$부터 $N$까지 번호가 붙은 정점 $N$개의 트리입니다.
- $N$은 정수입니다.

## 출력

### 단계 $1$

$N$을 받은 뒤 Alice와 Bob은 각각 양의 정수 $k$를 다음 형식으로 출력하세요.

```text
$k$
```

$k$는 $1\leq k\leq 2\,000$인 정수여야 하며, Alice와 Bob이 출력한 $k$는 같아야 합니다. 문제 설명에서 요구한 $k_{\min}$을 출력해야 합니다.

### 단계 $2$

트리 $T$를 받은 뒤 Alice는 $1$ 이상 $N$ 이하의 정수로 이루어진 길이 $k$의 수열 $A$를 다음 형식으로 출력하세요.

```text
$A_1\ A_2\ \ldots\ A_k$
```

수열 $A$를 받은 뒤 Bob은 트리 $T$와 같은 트리를 다음 형식으로 출력하세요.

```text
$U_1\ V_1$
$U_2\ V_2$
$\vdots$
$U_{N-1}\ V_{N-1}$
```

$U_i,V_i$는 $1$ 이상 $N$ 이하의 정수여야 하며, 각 $i$ $(1\leq i\leq N-1)$에 대해 정점 $U_i$와 $V_i$가 간선으로 연결되어 있다는 뜻입니다. 트리가 같다는 정의는 문제 설명과 같습니다.

### 주의 사항

- 출력할 때마다 마지막에 줄바꿈을 넣고 표준 출력을 flush하세요. 그렇지 않으면 판정이 `TLE`가 될 수 있습니다.
- $-1$을 받으면 즉시 프로그램을 종료하세요. 종료하면 판정은 `WA`이며, 종료하지 않으면 판정은 정해져 있지 않습니다.
- 답을 모두 출력한 뒤에도 즉시 프로그램을 종료하세요. 종료하지 않으면 판정은 정해져 있지 않습니다.
- 불필요한 줄바꿈은 잘못된 출력 형식으로 간주하므로 출력하지 마세요.
