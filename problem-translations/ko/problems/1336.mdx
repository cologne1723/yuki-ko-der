## 문제

칠판에 `N`개의 정수 `A_1,...,A_N`이 적혀 있습니다. 다음 연산을 `N-1`번 수행합니다.

칠판에서 서로 다른 위치에 적힌 두 수를 균일한 확률로 고르고, 두 수의 합과 곱을 더한 수를 새로 적은 뒤 고른 두 수를 지웁니다.

마지막에 남은 수의 기댓값을 구하세요. 기댓값은 음이 아닌 유리수이며, 0이면 `0`을 출력합니다. 그 외에는 기약분수 `P/Q`에 대해 `XQ\equiv P\pmod{10^9+7}`인 `X`를 출력하세요.

## 입력

첫째 줄에 테스트 케이스 수 `T`가 주어지고, 각 테스트 케이스에 `N`과 수열이 주어집니다.

## 출력

각 테스트 케이스의 답을 출력하세요.
