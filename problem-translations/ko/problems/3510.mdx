## 문제 설명

길이 $N-1$인 정수열 $A=(A_1,\ldots,A_{N-1})$가 주어집니다.

`R`, `P`, `S`만으로 이루어진 문자열 $S$에 대해 $f(S)$를 다음과 같이 정의합니다.

### 동작

- $i=1,2,\ldots,N-1$의 순서로 총 $N-1$번 동작을 수행합니다.
  - $S_{A_i}=S_{A_i+1}$이면 동작을 중단합니다.
  - 그렇지 않으면 $S_{A_i}$와 $S_{A_i+1}$가 가위바위보를 하여 승패를 정합니다. 진 문자를 제거합니다.
    - `R`과 `P`에서는 `R`이 집니다.
    - `P`와 `S`에서는 `P`가 집니다.
    - `S`와 `R`에서는 `S`가 집니다.
- $N-1$번의 동작을 수행한 뒤의 문자열을 $f(S)$로 정의합니다.

$A$의 제한에 의해, 문자열 $S$를 적절히 선택하면 $N-1$번의 동작을 수행할 수 있음이 보장됩니다.

$f(S)=\texttt{R}$, $\texttt{P}$, $\texttt{S}$가 되도록 하는 문자열 $S$ 중 사전순으로 $K$번째로 작은 것을 각각 구하세요. 그러한 문자열이 존재하지 않으면 이를 보고하세요.

$T$개의 테스트 케이스가 주어지므로 각 테스트 케이스에 대해 위 문제를 해결하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $\mathrm{case}_i$는 $i$번째 테스트 케이스를 나타냅니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식의 $2$개 행으로 주어집니다.

```text
$N\ K$
$A_1\ A_2\ \cdots\ A_{N-1}$
```

## 제한

- $1\leq T\leq 10^5$
- $2\leq N\leq 2\times 10^5$
- $1\leq A_i\leq N-i\ (1\leq i\leq N-1)$
- $1\leq K\leq 10^{18}$
- $1$개 파일에서 모든 테스트 케이스의 $N$의 합은 $2\times 10^5$ 이하입니다.
- 입력은 모두 정수입니다.

## 출력

각 테스트 케이스에 대해 다음과 같이 $3$개 행을 출력하세요.

- $1$번째 행에 $f(S)=\texttt{R}$이 되도록 하는 문자열 $S$ 중 사전순으로 $K$번째로 작은 것이 존재하면 이를 출력하세요. 존재하지 않으면 $-1$을 출력하세요.
- $2$번째 행에 $f(S)=\texttt{P}$가 되도록 하는 문자열 $S$ 중 사전순으로 $K$번째로 작은 것이 존재하면 이를 출력하세요. 존재하지 않으면 $-1$을 출력하세요.
- $3$번째 행에 $f(S)=\texttt{S}$가 되도록 하는 문자열 $S$ 중 사전순으로 $K$번째로 작은 것이 존재하면 이를 출력하세요. 존재하지 않으면 $-1$을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
5 1
4 2 2 1
5 3
4 2 2 1
7 10000
6 2 2 1 1 1
```

#### 출력

```text
RPRPS
PPSRS
PPRPS
RPSPR
PRSPS
PPSPR
-1
-1
-1
```

$1$번째 테스트 케이스에서는 다음과 같이 동작합니다.

- `RPRPS`에 동작을 수행하면 `RPRPS` → `RPRS` → `RPS` → `RS` → `R`이 됩니다.
- `PPSRS`에 동작을 수행하면 `PPSRS` → `PPSR` → `PSR` → `PR` → `P`가 됩니다.
- `PPRPS`에 동작을 수행하면 `PPRPS` → `PPRS` → `PPS` → `PS` → `S`가 됩니다.

각 문자열은 해당 결과를 만드는 문자열 중 사전순으로 $1$번째로 작습니다.
