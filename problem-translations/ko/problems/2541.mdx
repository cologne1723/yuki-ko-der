0과 1로 이루어진 문자열 $S$를 하나 이상의 비어 있지 않은 연속 문자열로 나눌 때, 모든 조각에 1이 하나 이상 포함되는 분할 방법의 수를 $998244353$으로 나눈 나머지를 구하세요.

## 조건

- $2\le N\le2\times10^5$

## 입력

```text
N
S
```

## 출력

답을 출력하세요.
