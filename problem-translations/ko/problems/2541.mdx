0과 1로 이루어진 문자열 $S$를 하나 이상의 비어 있지 않은 연속 문자열로 나눌 때, 모든 조각에 1이 하나 이상 포함되는 분할 방법의 수를 $998244353$으로 나눈 나머지를 구하세요.

## 조건

- $2\le N\le2\times10^5$

## 입력

```text
$N$
$S$
```

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
101
```

#### 출력

```text
3
```

조건을 만족하는 분할은 `10`, `1`로 나누기, `1`, `01`로 나누기, `101`을 그대로 두기의 $3$가지입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3
010
```

#### 출력

```text
1
```

조건을 만족하는 분할은 `010`을 그대로 두는 $1$가지뿐입니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
20
01001010101001010110
```

#### 출력

```text
7776
```
