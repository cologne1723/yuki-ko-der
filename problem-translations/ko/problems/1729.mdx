16진수 표기에 `A`부터 `F`만 나타나는 정수 `N`이 주어집니다. `A`부터 `F`는 각각 10부터 15를 뜻합니다.

`N`을 8진수로 나타냈을 때 가장 많이 나타나는 숫자를 출력하세요. 여러 숫자가 공동 최다이면 작은 순서대로 모두 출력하세요.

## 제약

- `N`은 16진수 표기로 주어집니다.
- `N`은 `A`부터 `F`만으로 이루어지고 길이는 200 이하입니다.

## 입력

16진수 표기의 `N`이 주어집니다.

## 출력

조건을 만족하는 8진수 숫자를 출력하세요.
