## 문제 설명

$N$명의 참가자를 $K$개의 팀으로 나눕니다.

어떤 $2$개의 팀을 선택해도 인원수의 차이가 $1$ 이하가 되도록 나눌 때, 각 팀의 인원수를 구하세요.

## 입력

```text
$N\ K$
```

## 제한

- $1 \le K \le N \le 10^5$
- 입력은 모두 정수입니다.

## 출력

각 팀의 인원수를 인원수가 많은 순서로 공백으로 구분하여 $1$줄에 출력하세요.
마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file="1_sample_1.txt"}

#### 입력

```text
7 3
```

#### 출력

```text
3 2 2
```

$7$명을 $3$개의 팀으로 나눕니다. $3, 2, 2$로 나누면 차이가 $1$ 이하입니다.

### 예제 2 {file="1_sample_2.txt"}

#### 입력

```text
6 3
```

#### 출력

```text
2 2 2
```

나누어떨어지는 경우에는 모든 팀의 인원수가 같아집니다.

### 예제 3 {file="1_sample_3.txt"}

#### 입력

```text
5 5
```

#### 출력

```text
1 1 1 1 1
```
