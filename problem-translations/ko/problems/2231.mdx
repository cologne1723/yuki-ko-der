길이 $N$의 문자열 $S_1$에 `?`가 포함되어 있고, 길이 $M$의 문자열 $S_2$가 주어진다냥. 물음표를 소문자로 바꾸어 $S_1$이 연속 부분 문자열로 $S_2$를 포함하도록 만들고, 가능한 경우 사전순으로 가장 작은 문자열을 출력하라냥. 불가능하면 $-1$을 출력하라냥.

## 조건

- $1\le T\le10^5$
- $1\le M\le N\le5\times10^5$
- 모든 테스트 케이스의 $N$의 합은 $5\times10^5$ 이하이다냥.

## 입력

```text
T
N M S_1 S_2
\vdots
```

## 출력

각 테스트 케이스의 답을 출력하라냥.
