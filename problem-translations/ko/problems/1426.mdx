## 문제

양의 정수 수열 `A`의 앞에서부터의 OR 누적값이 비석에 기록되어 있습니다. 발견되지 않은 비석의 값은 `-1`이고, 마지막 비석은 발견되었습니다.

발견된 모든 기록과 일치하는 수열 `A`의 개수를 `10^9+7`로 나눈 나머지를 구하세요.

## 입력

`N`과 `B_1,...,B_N`이 주어집니다.

## 출력

가능한 수열의 개수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
1 -1 3
```

#### 출력

```text
8
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
5
5 -1 -1 -1 4
```

#### 출력

```text
0
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
7
-1 -1 -1 -1 -1 -1 7777777
```

#### 출력

```text
281468948
```
