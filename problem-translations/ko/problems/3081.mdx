[문제 I](https://yukicoder.me/problems/no/3082)에는 이 문제의 저지 프로그램 일부를 구현하는 문제가 있습니다.

## 문제 설명

$N$의 양의 배수이면서 회문인 수를 $1$개 출력하세요.

이 문제의 제한 아래에서는 이러한 정수이면서 아래 출력 형식을 만족하는 것이 $1$개 이상 존재함을 증명할 수 있습니다.

### 회문이란

양의 정수가 회문이라는 것은, 맨 앞에 $0$이 오지 않는 십진법 표기로 나타냈을 때 각 자릿수에 대해 위에서 $i$번째 숫자와 아래에서 $i$번째 숫자가 같은 것을 뜻합니다.

## 입력

```text
$N$
```

## 제한

- $1 \leq N \leq 10^{12}$
- $N$은 $10$의 배수가 아닌 정수입니다.

## 출력

반복 구조를 이용하면 자릿수가 매우 큰 수라도 출력할 수 있습니다. 답인 정수의 십진법 표기를 문자열로 보았을 때, 이를 「$S_1$을 $T_1$번 반복한 것」→「$S_2$를 $T_2$번 반복한 것」→ $\cdots$ →「$S_K$를 $T_K$번 반복한 것」으로 나타낼 수 있다면 다음 형식으로 출력하세요.

```text
$K$
$S_1\ T_1$
$\vdots$
$S_K\ T_K$
```

단, 모든 $T_i$가 $10^{18}$ 이하이고 $S_i$의 문자 수 합계가 $2\times 10^5$ 이하가 되도록 하세요. 형식적으로 다음 조건을 모두 만족해야 합니다.

- $1 \leq K \leq 2\times 10^5$
- $S_i$ $(1 \leq i \leq K)$는 숫자 `0123456789`로만 이루어진 문자열입니다.
- $S_1$의 $1$번째 문자는 `0`이 아닙니다.
- $1 \leq |S_i| \leq 2\times 10^5$ $(1 \leq i \leq K)$
- $\displaystyle\sum_{i=1}^{K}|S_i| \leq 2\times 10^5$
- $1 \leq T_i \leq 10^{18}$ $(1 \leq i \leq K)$
- $K$, $T_i$ $(1 \leq i \leq K)$는 정수입니다.

입출력 예제가 도움이 될 것입니다.

본 문제는 스페셜 저지입니다. 답이 여러 개 존재할 수 있습니다. 또한 출력 형식을 만족하지 않는 제출에 대한 저지의 동작은 정의되지 않습니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
23
```

#### 출력

```text
1
161 1
```

`161`을 $1$번 반복한 수는 `161`입니다. $161$은 $23$의 배수이면서 회문입니다. 또는 다음과 같이 출력해도 정답으로 처리됩니다.

#### 출력

```text
3
1 1
3 4
1 1
```

#### 출력

```text
1
133331 1
```

`1`을 $1$번 반복하고, `3`을 $4$번 반복하고, `1`을 $1$번 반복하면 `133331`을 나타냅니다. 따라서 이 출력은 $133\,331$을 나타냅니다. $133\,331$은 $23$의 배수이면서 회문입니다.
