## 문제

길이 `N`인 순열 `P`에 대해 `f(P)=Σ_{i=1}^{N-1}|P_i-P_{i+1}|^K`로 정의합니다. `1,...,N`의 모든 `N!`개 순열에 대한 `f(P)`의 합을 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `2 ≤ N ≤ 10^9`
- `1 ≤ K ≤ 10^6`

## 입력

```text
N K
```

## 출력

답을 출력하세요.
