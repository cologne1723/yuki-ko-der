양의 정수 $N$과 음이 아닌 정수 $K$가 주어집니다. $N$을 $A$로 나눈 나머지가 $K$가 되도록 하는 양의 정수 $A$의 개수를 구하세요.

## 조건

- $1\le N\le10^{12}$
- $0\le K<N$

## 입력

```text
N K
```

## 출력

조건을 만족하는 $A$의 개수를 출력하세요.

## 예제

### 입력 1

```text
38 3
```

### 출력 1

```text
3
```
