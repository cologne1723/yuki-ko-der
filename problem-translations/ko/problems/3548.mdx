## 문제 설명

양의 정수 $n$에 대해, $f(n)$을 "$n$을 십진법으로 나타냈을 때 포함된 숫자 중 최댓값"으로 정의합니다.

예를 들어 $f(314)=4$, $f(10)=1$, $f(998\,244\,353)=9$입니다.

양의 정수 $N$이 주어집니다. $1\leq L\leq R\leq 10^{18}$을 만족하는 정수 $L$, $R$ 중에서

$f(L)+f(L+1)+\cdots+f(R)=N$

을 만족하는 $L$, $R$을 정해 제시하세요.

이 문제의 제한에서는 조건을 만족하는 $L$, $R$이 반드시 존재함이 보장됩니다.

테스트 케이스가 $T$개 주어지므로, 각각에 대해 답을 구하세요.

## 입력

입력은 표준 입력에서 다음 형식으로 주어집니다. 여기서 $t$번째 테스트 케이스를 $\mathrm{case}_t$로 나타냅니다($1\leq t\leq T$).

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- 입력되는 값은 모두 정수입니다.
- $1\leq T\leq 10^5$
- $1\leq N\leq$ **$10^{17}$**

## 출력

$T$개의 줄을 출력하고, $t$번째 줄에는 $t$번째 테스트 케이스에 대한 답을 출력하세요.

각 테스트 케이스에 대해 답이 되는 $L$, $R$을 이 순서로 공백으로 구분하여 출력하세요. 답이 여러 개 존재한다면 그중 어느 것이든 출력해도 정답으로 인정됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
23
5
99999999999999999
```

#### 출력

```text
58 60
5 5
888888888888888890 900000000000000000
```

$1$번째 테스트 케이스에서는 $f(58)+f(59)+f(60)=8+9+6=23$이 됩니다.
