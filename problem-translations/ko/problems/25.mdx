## 문제 설명

peach는 분수로 나타낸 수가 유한소수로 표현되는지 알고 싶어졌습니다.
“유한소수”란 $1/8=0.125$와 같이 유한한 소수로 표현되는 수입니다. $4/3=1.33333\dots$과 같은 수는 유한소수로 표현할 수 없습니다.

64비트 부호 있는 정수로 표현할 수 있는 자연수 $N$, $M$이 주어집니다. $N/M$이 유한소수로 표현되는지 판정하세요.

유한소수로 표현할 수 있다면 0이 아닌 가장 마지막 자릿수의 숫자를 출력하세요. 유한소수로 표현할 수 없다면 $-1$을 출력하세요.

정수가 되어 소수점이 필요 없는 경우에도 0이 아닌 가장 마지막 자릿수의 숫자를 구해야 합니다.

## 입력

```text
N
M
```

첫째 줄에 분자의 자연수 $N$이 주어집니다. $(1 \le N \le 9\,223\,372\,036\,854\,775\,807)$
둘째 줄에 분모의 자연수 $M$이 주어집니다. $(1 \le M \le 9\,223\,372\,036\,854\,775\,807)$

## 출력

유한소수로 표현할 수 있다면 0이 아닌 마지막 숫자를, 표현할 수 없다면 $-1$을 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1

#### 입력

```text
7
5
```

#### 출력

```text
4
```

$7/5=1.4$는 유한소수이므로 마지막 숫자는 4입니다.

### 예제 2

#### 입력

```text
2
3
```

#### 출력

```text
-1
```

$2/3$은 유한소수로 표현할 수 없으므로 $-1$입니다.

### 예제 3

#### 입력

```text
10
3
```

#### 출력

```text
-1
```

### 예제 4

#### 입력

```text
20
2
```

#### 출력

```text
1
```

$20/2=10$이지만, 0이 아닌 가장 작은 자릿수에서 보았을 때 마지막 숫자가 1이므로 1을 출력합니다.

### 예제 5

#### 입력

```text
12345
30517578125
```

#### 출력

```text
6
```
