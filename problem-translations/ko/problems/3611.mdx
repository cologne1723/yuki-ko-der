## 문제 설명

고양이 $N$마리가 일렬로 늘어서 있습니다. $i$번째 고양이는 왼쪽에서 $i$번째 위치에 있고, 키는 $H_i$입니다. 모든 고양이의 키는 서로 다릅니다.

이 고양이들이 다음 조건을 만족하는지 판정하세요.

- 어떤 정수 삼중항 $(x,y,z)$가 존재하며, 다음 조건을 모두 만족합니다.
  - $1<x<y<z<N$
  - $1\leq i<x$를 만족하는 모든 $i$에 대해 $H_i>H_{i+1}$
  - $x\leq i<y$를 만족하는 모든 $i$에 대해 $H_i<H_{i+1}$
  - $y\leq i<z$를 만족하는 모든 $i$에 대해 $H_i>H_{i+1}$
  - $z\leq i<N$을 만족하는 모든 $i$에 대해 $H_i<H_{i+1}$

$T$개의 테스트 케이스가 주어지므로, 모든 테스트 케이스에 대해 답을 구하세요.

## 입력

```text
$T$
$\text{case}_1$
$\text{case}_2$
$\vdots$
$\text{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$H_1\ H_2\ \ldots\ H_N$
```

## 제한

- $1\leq T\leq 4\times 10^4$
- $5\leq N\leq 2\times 10^5$
- $1\leq H_i\leq 10^9\ (1\leq i\leq N)$
- $H_i\neq H_j\ (i\neq j)$
- 모든 테스트 케이스에서 $N$의 합은 $2\times 10^5$ 이하입니다.
- 입력은 모두 정수입니다.

이 문제에는 부분 점수가 설정되어 있습니다.

| 부분 문제 | 배점 | 제한 |
| --- | ---: | --- |
| 부분 문제 $1$ | $30$점 | $N=5$ |
| 부분 문제 $2$ | $60$점 | $N\leq100$, 모든 테스트 케이스에서 $N$의 합은 $100$ 이하 |
| 부분 문제 $3$ | $60$점 | 추가 제한 없음 |

## 출력

$T$줄에 출력하세요.

$i\ (1\leq i\leq T)$번째 줄에는 $i$번째 테스트 케이스의 수열 $H$가 조건을 만족한다면 `Yes`를, 그렇지 않다면 `No`를 출력하세요.

9
