$0$ 이상 $10^N$ 미만의 정수 중 99의 배수를 우아한 수라고 하며, 그 집합을 $X$라 합니다. 각 우아한 수 $x$의 십진수 각 자리 합을 $d(x)$라 할 때, $\sum_{x\in X}d(x)^K$를 $998244353$으로 나눈 나머지를 구하세요.

## 조건

- $2\le N,K\le10^5$

## 입력

```text
N K
```

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2 2
```

#### 출력

```text
324
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 1
```

#### 출력

```text
180
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
14 2013
```

#### 출력

```text
212631289
```
