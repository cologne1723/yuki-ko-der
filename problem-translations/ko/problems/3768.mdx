## 문제 설명

길이 $N$의 음이 아닌 정수 수열 $A=(A_1,A_2,\dots,A_N)$가 주어집니다.

$1$ 이상 $N$ 이하의 서로 다른 정수 네 개로 이루어진 순서 있는 튜플 $(i,j,k,l)$은 $\displaystyle\binom{N}{4}\cdot 4!$가지입니다. 이들 모두에 대한 $|(A_i \oplus A_j)-(A_k \oplus A_l)|$의 합을 $998\,244\,353$으로 나눈 나머지를 구하세요.

$\oplus$는 비트 단위 XOR를 나타냅니다.

## 입력

```text
$N$
$A_1\ A_2\ \dots\ A_N$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $4 \leq N \leq 2 \times 10^5$
- $0 \leq A_i < 2^{18}$

## 출력

가능한 모든 $(i,j,k,l)$에 대한 $|(A_i \oplus A_j)-(A_k \oplus A_l)|$의 합을 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
2 3 5 7
```

#### 출력

```text
40
```

가능한 $(i,j,k,l)$은 $(1,2,3,4)$를 재배열한 것으로, $24$가지입니다.

예를 들어 $(i,j,k,l)=(1,2,3,4)$이면 $|(A_i \oplus A_j)-(A_k \oplus A_l)|=|(2\oplus 3)-(5\oplus 7)|=|1-2|=1$입니다.
