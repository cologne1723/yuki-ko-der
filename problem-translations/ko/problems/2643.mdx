각 $i=1,\ldots,N$에 대해 $i$번째 조건만 제외하고, 모든 $j$에 대해 $0\le A_j\le K$이고 $\sum_{k=j}^{R_j}A_k=X_j$인 정수열 $A$가 존재하는지 판정하세요.

## 조건

- $1\le N\le5000$, $0\le K\le10^9$
- $i\le R_i\le N$, $0\le X_i\le NK$

## 입력

```text
$N$ $K$
$R_1$ $X_1$
\vdots
$R_N$ $X_N$
```

## 출력

각 $i$에 대한 답을 한 줄에 하나씩 `Yes` 또는 `No`로 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2
2 1
2 2
3 0
```

#### 출력

```text
Yes
Yes
No
```

$i=2$일 때, 예를 들어 $A=(1,0,0)$은 $0\leq A_1\leq2,\ 0\leq A_2\leq2,\ 0\leq A_3\leq2$이고 $A_1+A_2=1,\ A_3=0$이므로 모든 조건을 만족합니다.

$i=3$일 때는 모든 조건을 만족하는 $A$가 없습니다.
