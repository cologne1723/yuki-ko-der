## 문제

철도 동호회 회원들은 yukicoder선의 모든 특별 열차를 타려고 합니다.

yukicoder선은 서쪽에서 동쪽으로 달리는 분기 없는 하나의 노선입니다. 서쪽부터 0번, 1번, 2번, …, N−1번 역 순서로 N개의 역이 있습니다.

특별 열차는 M개이며, 특별 열차 i는 Sa_i역에서 Sb_i역 또는 그 반대 방향으로 탈 수 있습니다. 중간 하차는 할 수 없습니다.

회원들의 계획은 다음과 같습니다.

* yukicoder선의 임의의 역에 모입니다.
* 특별 열차만 이용해 역에서 갈아타며 이동합니다.
* 어떤 특별 열차를 한 방향으로 한 번 타면 만족하며, 같은 열차를 편도보다 많이 타지 않습니다.
* yukicoder선에 있는 모든 특별 열차를 탑니다.
* 마지막으로 임의의 역에서 해산합니다.

이 계획을 달성할 수 있는지 판정하세요.

## 입력

```text
N M
Sa0 Sb0
Sa1 Sb1
…
Sa{M-1} Sb{M-1}
```

N은 역의 수이며 2 ≤ N ≤ 500입니다.

M은 특별 열차의 수이며 1 ≤ M ≤ N×(N−1)/2입니다.

Sai,Sbi는 i번째 특별 열차를 탈 수 있는 역이며 0 ≤ Sai < Sbi ≤ N−1입니다.

모든 Sai,Sbi 조합은 서로 다릅니다.

## 출력

계획을 달성할 수 있으면 YES, 달성할 수 없으면 NO를 한 줄에 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
5 2
0 4
3 4
```

출력:

```text
YES
```

0번 특별 열차는 0번 역과 4번 역을 왕복하고, 1번 특별 열차는 3번 역과 4번 역을 왕복합니다.

회원들은 먼저 0번 역에 모여 0번 열차로 4번 역까지 이동한 뒤, 1번 열차로 3번 역까지 이동하고 3번 역에서 해산할 수 있습니다.

3번 역에 모여 0번 역에서 해산하는 방법도 가능합니다.

단, 4번 역에 모이면 안 됩니다. 4번 역에서 어느 한 열차를 편도로 타면 만족해 돌아갈 수 없고, 다른 열차를 탈 수 없기 때문입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
5 2
0 2
3 4
```

출력:

```text
NO
```

0번 열차는 0번 역과 2번 역을 왕복하고, 1번 열차는 3번 역과 4번 역을 왕복합니다. 어떤 방법으로도 특별 열차만 이용해 2번 역과 3번 역 사이를 이동할 수 없으므로 모든 열차를 탈 수 없습니다.

10 11

0 9
6 9
0 2
1 2
1 6
2 3
0 4
3 4

```

출력:

NO
```

불가능한 것 같습니다.
