## 문제 설명

くらげさん은 오늘 물을 $N$ ml 마시고 싶습니다.

이제부터 $500$ ml의 물이 들어 있는 페트병을 $1$병씩 계속 사서, 마시고 싶은 물의 양에 대한 가지고 있는 물의 부족량을 $100$ ml 미만으로 만들려고 합니다.

현재 가지고 있는 물의 양이 $0$ ml일 때, くらげさん은 페트병을 최소 몇 개 사야 하는지 구하세요.

단, 페트병은 무한히 판매되고 있다고 가정합니다.

## 입력

```text
$N$
```

마시고 싶은 물의 양을 나타내는 정수 $N$이 주어집니다.

## 제한

- $0 \le N \le 10^9$
- 입력은 모두 정수입니다.

## 출력

くらげさん이 사야 하는 물의 병 수를 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
700
```

#### 출력

```text
2
```

물 $1$병을 사면 $500$ ml밖에 마실 수 없지만, $2$병을 사면 $1\,000$ ml를 마실 수 있습니다.
따라서 くらげさん은 물을 $2$병 사므로, $2$를 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
550
```

#### 출력

```text
1
```

물 $1$병을 사면 $500$ ml밖에 마실 수 없지만, 마시고 싶은 양인 $550$ ml에 대해 부족한 양은 $50$ ml이므로 くらげさん은 물을 더 사지 않습니다.
따라서 $1$을 출력합니다.

### 예제 3 {file=""}

#### 입력

```text
2300
```

#### 출력

```text
5
```
