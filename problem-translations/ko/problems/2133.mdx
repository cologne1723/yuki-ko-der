$1,2,\ldots,N$의 순열 $P$ 중 다음 조건을 모두 만족하는 것의 개수를 구하라냥.

각 $i=1,2,\ldots,Q$에 대해 구간 $[L_i,R_i]$를 생각한다냥. $P_{L_i},P_{L_i+1},\ldots,P_{R_i}$에서 임의의 접두사에 대해 짝수의 개수는 홀수의 개수 이하이고, 구간 전체에서 짝수의 개수와 홀수의 개수는 같아야 한다냥. 또한 전체 순열의 모든 접두사 $P_1,\ldots,P_k$에 대해서도 짝수의 개수는 홀수의 개수 이하이어야 한다냥.

## 조건

- $1 \le N \le 2\times 10^5$
- $0 \le Q \le 60$
- $1 \le L_i < R_i \le N$

## 입력

입력은 다음 형식으로 주어진냥.

```text
N Q
L_1 R_1
L_2 R_2
\vdots
L_Q R_Q
```

## 출력

조건을 만족하는 순열의 개수를 $998244353$으로 나눈 나머지를 출력하라냥.
