## 문제 설명

당신은 트레이딩 카드 게임 「yu☆ki☆왕」에 빠져 있습니다.

이 게임에는 $N$종류의 카드가 있고, 당신은 이미 몇 장을 가지고 있습니다. 모든 종류의 카드를 모으고 싶지만, 같은 종류의 카드를 덱에 최대 $3$장 넣을 수 있으므로 각 종류를 최소 $3$장씩 모아야 합니다.

카드를 한 장씩 구매할 때 어떤 종류를 얻는지는 완전히 무작위입니다. 현재 가진 카드와 관계없이 각 종류를 얻을 확률은 $1/N$입니다.

컴플리트할 때까지 구매하게 되는 카드 수의 기댓값을 구하세요.

## 입력

```text
$N$
$A_1\ A_2\ \dots\ A_N$
```

$N$은 카드의 종류 수입니다.
둘째 줄에는 각 종류의 보유 카드 수 $A_1,\dots,A_N$이 공백으로 구분되어 주어집니다. $A_i$는 $i$번째 종류의 카드 수입니다. $(1 \le i \le N)$

## 제한

- $1 \le N \le 100$
- $0 \le A_i \le 10$ $(1 \le i \le N)$

## 출력

기댓값을 한 줄에 출력하세요. 마지막에 줄 바꿈을 출력하세요.

절대 오차 또는 상대 오차가 $10^{-6}$ 이하이면 정답으로 인정합니다.
