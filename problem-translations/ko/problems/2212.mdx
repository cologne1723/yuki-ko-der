$2^N\times2^N$ 격자의 모든 칸에 $0$ 이상 $2^{2N}$ 미만의 정수를 하나씩 써서 모든 정수가 정확히 한 번씩 등장하게 하라냥. 모든 행과 열에 포함된 수의 비트 XOR가 1이 되도록 하는 작성 방법이 존재하는지 판정하고, 존재하면 하나 구성하라냥.

## 조건

- $1\le N\le10$

## 입력

```text
N
```

## 출력

불가능하면 $-1$을 출력하라냥. 가능하면 행렬을 출력하라냥.
