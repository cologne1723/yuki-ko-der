$2^N\times2^N$ 격자의 모든 칸에 $0$ 이상 $2^{2N}$ 미만의 정수를 하나씩 써서 모든 정수가 정확히 한 번씩 등장하게 하라냥. 모든 행과 열에 포함된 수의 비트 XOR가 1이 되도록 하는 작성 방법이 존재하는지 판정하고, 존재하면 하나 구성하라냥.

## 조건

<details>
<summary>비트 단위 XOR란? (클릭하면 펼쳐집니다)</summary>

음이 아닌 정수 $X,Y$에 대해 비트 단위 XOR $X\oplus Y$를 다음과 같이 정의합니다.

- $X\oplus Y$를 $2$진법으로 나타냈을 때 $2^k$ 자리($k\ge0$)의 숫자는 $X,Y$의 해당 자리 숫자 중 정확히 하나가 $1$이면 $1$, 그렇지 않으면 $0$입니다.

예를 들어 $3\oplus5=6$, $1\oplus1=0$입니다.

일반적으로 $k$개의 음이 아닌 정수 $p_1,p_2,\ldots,p_k$의 비트 단위 XOR는 $(\cdots((p_1\oplus p_2)\oplus p_3)\oplus\cdots)\oplus p_k$로 정의하며, 이 값은 $p_1,p_2,\ldots,p_k$의 순서와 무관함을 증명할 수 있습니다.

</details>

- $1\le N\le10$

## 입력

```text
N
```

## 출력

불가능하면 $-1$을 출력하라냥. 가능하면 행렬을 출력하라냥.
