$N$개 정점의 트리가 주어집니다. 각 정점 $v$에 대해 $v$와의 거리가 정확히 2인 정점의 개수를 구하세요.

## 조건

- $2\le N\le3\times10^5$
- 주어진 그래프는 트리입니다.

## 입력

```text
N
u1 v1
...
uN-1 vN-1
```

## 출력

정점 $v$와의 거리가 2인 정점의 개수를 $N$줄에 걸쳐 출력하세요.
