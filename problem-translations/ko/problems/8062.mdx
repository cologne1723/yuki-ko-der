## 문제 설명

$A+B$와 같은 수를 출력하세요.

## 입력

```text
$A\ B$
```

$1$번째 줄에 $2$개의 수 $A$와 $B$가 공백으로 구분되어 주어집니다.

## 제한

- $|A|, |B| \leq 10$

## 출력

$A+B$와 같은 수를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0 1
```

#### 출력

```text
1
```

### 예제 2 {file=""}

#### 입력

```text
1 -1
```

#### 출력

```text
0
```

### 예제 3 {file=""}

#### 입력

```text
-0 0
```

#### 출력

```text
0
```
