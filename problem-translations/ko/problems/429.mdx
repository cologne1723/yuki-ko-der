## 문제

컵 1부터 컵 $N$까지 $N$개의 컵에 대해 교환 방법과 최종 배치가 주어집니다. $X$번째 교환에서 교환한 두 컵의 위치를 맞히세요.

- 처음에는 위치 $i$에 컵 $i$가 있었습니다.
- $k$번째 교환에서는 위치 $A_k,B_k$에 있는 컵을 교환했습니다. $(1\le k\le K; k\ne X)$
- 최종적으로 위치 $i$에는 컵 $C_i$가 있었습니다.

## 입력

```text
N K X
A₁ B₁
A₂ B₂
⋮
A_K B_K
C₁ C₂ ... C_N
```

- $2\le N\le100\,000$
- $1\le K\le100\,000$
- $1\le X\le K$
- $i\ne X$일 때 $1\le A_i<B_i\le N$
- $i=X$일 때 $A_i$와 $B_i$는 `?`
- $1\le C_i\le N$
- $C_i$는 서로 다릅니다.
- 답은 존재합니다.

## 힌트

case 1〜case 10에서는 $N\le100; K\le1\,000$입니다. 답은 유일하게 정해집니다.

## 출력

오름차순으로 출력하세요. 즉 $A_X<B_X$가 되도록 출력하세요. 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 6 4
1 3
1 2
2 3
? ?
2 3
1 3
1 2 3
```

#### 출력

```text
1 3
```

4번째 교환에서 위치 1, 3의 컵을 교환하면 컵 배치는 다음과 같이 바뀝니다.

`123` → `321` → `231` → `213` → `312` → `321` → `123`

```text
2 4
```
