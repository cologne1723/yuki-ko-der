## 문제

N개의 컵(컵 1〜컵 N)에 대해 교환 방법과 최종 배치가 주어집니다. X번째 교환에서 교환한 두 컵의 위치를 맞히세요.

- 처음에는 위치 i에 컵 i가 있었습니다.
- k번째 교환(1 ≤ k ≤ K, k ≠ X)에서는 위치 Aₖ, Bₖ에 있는 컵을 교환했습니다.
- 최종적으로 위치 i에는 컵 Cᵢ가 있었습니다.

## 입력

```text
N K X
A₁ B₁
A₂ B₂
⋮
A_K B_K
C₁ C₂ ... C_N
```

- 2 ≤ N ≤ 100000
- 1 ≤ K ≤ 100000
- 1 ≤ X ≤ K
- i ≠ X일 때 1 ≤ Aᵢ < Bᵢ ≤ N
- i = X일 때 Aᵢ = ?, Bᵢ = ?
- 1 ≤ Cᵢ ≤ N
- Cᵢ는 서로 다릅니다.
- 답은 존재합니다.

## 힌트

case 1〜case 10에서는 N ≤ 100, K ≤ 1000입니다. 답은 유일하게 정해집니다.

## 출력

오름차순으로 출력하세요. 즉 A_X < B_X가 되도록 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
3 6 4
1 3
1 2
2 3
? ?
2 3
1 3
1 2 3
```

### 샘플 1 출력 {file="sample1.out"}

```text
1 3
```

4번째 교환에서 위치 1, 3의 컵을 교환하면 컵 배치는 다음과 같이 바뀝니다.

```text
123
321
231
213
312
321
123
```

### 샘플 2 {file="sample2.in"}

```text
4 3 3
1 2
3 4
? ?
2 3 4 1
```

### 샘플 2 출력 {file="sample2.out"}

```text
2 4
```

### 샘플 3 {file="sample3.in"}

```text
5 7 1
? ?
3 5
2 4
1 3
2 3
1 4
4 5
5 1 4 3 2
```

### 샘플 3 출력 {file="sample3.out"}

```text
2 5
```
