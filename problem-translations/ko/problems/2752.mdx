## 문제

## 제약

- `1 ≤ T ≤ 10^5`
- `1 ≤ L ≤ 10^18`

## 입력

```text
T
L_1
⋮
L_T
```

## 출력

각 답을 한 줄에 하나씩 출력하세요.
