## 문제

문자열 $S$가 주어집니다.

$S$의 비어 있지 않은 연속 부분 문자열에서 문자 종류 수의 평균을 구하세요.

## 입력

~~~text
$S$
~~~

- $1\leq |S|\leq 10^6$
- $S$는 영문 소문자만으로 이루어집니다.

## 출력

문자 종류 수의 평균을 출력하세요. 절대 오차는 $10^{-5}$까지 허용됩니다.

마지막에 줄바꿈을 출력하세요.

## 샘플

### 샘플 1 {file=""}

#### 입력

~~~text
ei
~~~

#### 출력

~~~text
1.33333
~~~

'ei'의 비어 있지 않은 연속 부분 문자열은 'e', 'i', 'ei'의 3개이고, 각각의 문자 종류 수는 $1$, $1$, $2$입니다.

따라서 $\frac{1+1+2}{3}=\frac{4}{3}\fallingdotseq 1.33333\cdots$입니다.

#### 입력

~~~text

~~~

#### 출력

~~~text
2.33333
~~~

~~~
