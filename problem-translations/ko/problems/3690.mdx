## 문제 설명

양의 정수 $A$, $B$가 주어집니다.

$A$와 $B$의 양의 공약수인 모든 정수 $d$에 대한 $\mu(d)$의 합을 구하세요.

### 배경

양의 정수 $N$에 대해 $\mu(N)$의 값은 다음과 같이 정의됩니다.

- $N=1$일 때, $\mu(N)=1$입니다.
- $N$이 어떤 소수의 제곱으로 나누어떨어질 때, $\mu(N)=0$입니다.
- $N$이 서로 다른 $K$개의 소수의 곱과 같을 때, $\mu(N)=(-1)^K$입니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$A\ B$
```

## 제한

- $A$, $B$는 $1$ 이상 $10^{18}$ 이하의 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
24 60
```

#### 출력

```text
0
```

$24$와 $60$의 양의 공약수는 $1,2,3,4,6,12$의 $6$개입니다.

따라서 답은
$\mu(1)+\mu(2)+\mu(3)+\mu(4)+\mu(6)+\mu(12)=1-1-1+0+1+0=0$
입니다.

### 예제 2 {file=""}

#### 입력

```text
31 13
```

#### 출력

```text
1
```
