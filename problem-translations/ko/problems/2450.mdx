양의 정수 $A$가 어떤 양의 정수 $k$에 대해 $A+1=10^k$를 만족하면 99와 비슷한 수라고 합니다. 주어진 $N$이 99와 비슷한 수인지 판정하세요.

## 조건

- $1\le N\le10^{100}$

## 입력

```text
N
```

## 출력

조건을 만족하면 `Yes`, 아니면 `No`를 출력하세요.
