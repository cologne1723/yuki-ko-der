## 문제 설명

$1$ 이상 $K$ 이하의 정수로 이루어진 원소 수 $N$인 수열 $S$를 생각합니다.

그러한 모든 수열 $S$와 집합 $\{1,2,\ldots,N\}$의 진부분집합 $T$의 조합에 대해 $\displaystyle\prod_{i\in T}S_i$를 합한 값을 구하세요. 답이 매우 커질 수 있으므로 $10^9+7$로 나눈 나머지를 출력하세요. 공집합의 모든 원소의 곱은 $1$로 정의합니다.

## 입력

```text
N K
```

- $1 \leq N \leq 2\times10^5$
- $1 \leq K \leq 10^{18}$
- 입력은 모두 정수입니다.

## 출력

답을 $10^9+7$로 나눈 나머지를 한 줄에 출력하세요. 마지막에 줄바꿈을 넣으세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}
#### 입력
```text
2 2
```
#### 출력
```text
16
```

### 예제 2 {file="01_sample_02.txt"}
#### 입력
```text
4 3
```
#### 출력
```text
5265
```

### 예제 3 {file="01_sample_03.txt"}
#### 입력
```text
3435 2835
```
#### 출력
```text
618988899
```
