## 입력

각 행에 서로 다른 숫자가 주어집니다.

어떤 행에는 숫자 $0$이 주어지는 것이 보장됩니다.

그 밖의 입력에 관한 제한은 없습니다.

## 출력

숫자 $0$이 입력될 때까지 각 숫자에 대응하는 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
0
```

#### 출력

```text
k
```

```text
8
3
7
0
```

#### 출력

```text

d
```

4
0
