## 문제 설명

정점에 $1$부터 $N$까지의 번호가 붙은 $N$개 정점의 트리인 무방향 그래프 $G$가 주어집니다.

$i$번째 $(1 \leq i \leq N - 1)$ 간선은 정점 $U_i$와 정점 $V_i$를 연결합니다.

집합 $\{1, 2, \cdots, N\}$의 부분집합 $S$로 가능한 것은 $2^N$개입니다.
이 중 다음 조건을 모두 만족하는 것의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

- $S$의 원소 수는 $2$ 이상입니다.
- 다음 연산을 수행한 뒤의 $G$도 트리입니다.

  - $u, v \in S$이고 $u < v$인 모든 $u, v$에 대해, $G$에 정점 $u$와 정점 $v$를 연결하는 간선이 없으면 추가하고, 있으면 제거합니다.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

## 입력

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

입력은 표준 입력에서 다음 형식으로 주어집니다. 여기서 $\mathrm{case}_t$ $(1 \leq t \leq T)$는 $t$번째 테스트 케이스를 나타냅니다.

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$U_1\ V_1$
$U_2\ V_2$
$\vdots$
$U_{N - 1}\ V_{N - 1}$
```

## 제한

- $1 \leq T \leq 10^4$
- 각 테스트 케이스에 대해 다음 조건을 모두 만족합니다.
  - $2 \leq N \leq 2 \times 10^5$
  - $1 \leq U_i < V_i \leq N$
  - 주어지는 무방향 그래프 $G$는 트리입니다.
- $1$개의 입력 파일에서 $N$의 총합은 $2 \times 10^5$ 이하입니다.
- 입력은 모두 정수입니다.

## 출력

$T$줄 출력하세요. $t$번째 줄에는 $t$번째 테스트 케이스에 대한 답을 출력하세요.

여기서 $998\,244\,353$으로 나눈 나머지를 출력하는 것을 잊지 않도록 주의하세요.
