## 문제 설명

아무것도 그려져 있지 않은 $xy$ 좌표평면이 있습니다. 이곳에 왼쪽 아래 좌표가 $(X_a, Y_a)$이고 오른쪽 위 좌표가 $(X_b, Y_b)$인, **원점을 내부에 포함하는** 직사각형을 그리고 내부를 색칠합니다. 직사각형의 각 변은 $x$축 또는 $y$축과 평행합니다.

직사각형은 $1$번째 직사각형부터 $N$번째 직사각형까지 하나씩 늘어납니다. 직사각형이 늘어날 때마다 전체 넓이가 얼마나 늘어나는지 구하세요.

## 입력

```text
$N$
$Xa_1$ $Ya_1$ $Xb_1$ $Yb_1$
$Xa_2$ $Ya_2$ $Xb_2$ $Yb_2$
$\vdots$
$Xa_N$ $Ya_N$ $Xb_N$ $Yb_N$
```

$N$은 양의 정수입니다.

$(Xa_i, Ya_i)$는 $i$번째 직사각형의 왼쪽 아래 좌표입니다.

$Xa_i$, $Ya_i$는 음의 정수입니다.

$(Xb_i, Yb_i)$는 $i$번째 직사각형의 오른쪽 위 좌표입니다.

$Xb_i$, $Yb_i$는 양의 정수입니다.

## 제한

$1 \le N \le 40\,000$

$-20\,000 \le Xa_i, Ya_i \le -1$

$1 \le Xb_i, Yb_i \le 20\,000$

## 출력

답을 $N$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="sample1.in"}

#### 입력

```text
2
-2 -2 1 1
-1 -1 2 2
```

#### 출력

```text
9
5
```

첫 번째 직사각형의 넓이는 $9$입니다. 다음 직사각형의 넓이도 $9$이지만 첫 번째 직사각형과 겹치는 부분을 제외하므로 늘어난 부분의 넓이는 $5$입니다.

### 예제 2 {file="sample2.in"}

#### 입력

```text
3
-1 -2 1 2
-2 -1 2 1
-3 -3 3 3
```

#### 출력

```text
8
4
24
```

### 예제 3 {file="sample3.in"}

#### 입력

```text
2
-1 -1 1 1
-1 -1 1 1
```

#### 출력

```text
4
0
```

늘어나지 않는 경우도 있습니다.
