## 문제 설명

다음 조건을 만족하는 양의 정수를 **동화수**라고 합니다.

- (맨 앞에 불필요한 $0$을 붙이지 않은) $10$진법 표기에서 $6$자리이고, $10^i$의 자리 숫자를 $d_i$라고 할 때 $d_5=d_4$, $d_3=d_0$, $d_2=d_1$이 모두 성립합니다.

예를 들어 $112\,332$와 $555\,555$는 **동화수**이지만, $110\,101$과 $120$은 **동화수**가 아닙니다.

또한 다음 조건을 만족하는 정수를 **Ex동화수**라고 합니다.

- 어떤 **동화수** $k$와 양의 정수 $E$가 존재하여 $E\times(-k)$로 나타낼 수 있습니다.

양의 정수 $N$과 소수 $P$가 주어집니다. 절댓값이 $N$ 이하인 **Ex동화수**의 총합을 $P$로 나눈 나머지를 $0$ 이상 $P$ 미만인 값으로 구하세요.

## 입력

```text
$N\ P$
```

입력은 다음 제한을 만족합니다.

## 제한

- $1\leq N\leq 10^9$
- $10^8\leq P<10^9$
- $P$는 소수입니다.
- 입력은 모두 정수입니다.

## 출력

절댓값이 $N$ 이하인 **Ex동화수**의 총합을 $P$로 나눈 나머지를 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1729 998244353
```

#### 출력

```text
0
```

절댓값이 $1\,729$ 이하인 **Ex동화수**는 존재하지 않습니다. 따라서 총합도 $0$이므로 $0$을 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
998244353 998244353
```

#### 출력

```text
910462579
```

소수 $P$로 나눈 나머지를 출력해야 한다는 점에 주의하세요.
