## 문제 설명

카드 $5$장이 주어집니다. 각 카드에는 $1$ 이상 $13$ 이하의 정수 중 $1$개가 쓰여 있습니다. 카드에 쓰인 정수의 조합에 따라 핸드가 결정됩니다.

주어진 $5$장의 카드가 다음 핸드 중 어느 것에 해당하는지 판정하세요. 여러 핸드에 해당하면 아래에서 먼저 설명한 핸드로 판정합니다.

- `FULL HOUSE`: 어떤 수가 정확히 $3$개이고, 다른 수가 정확히 $2$개 있습니다.
- `THREE CARD`: 어떤 수가 정확히 $3$개 있습니다.
- `TWO PAIR`: 어떤 수가 정확히 $2$개이고, 다른 수가 정확히 $2$개 있습니다.
- `ONE PAIR`: 어떤 수가 정확히 $2$개 있습니다.

## 입력

```text
$A_1\ A_2\ A_3\ A_4\ A_5$
```

$A_i$는 $i$번째 카드에 쓰인 정수입니다. ($1 \leq i \leq 5$)

## 제한

$1 \leq A_i \leq 13$ ($1 \leq i \leq 5$)

## 출력

해당하는 핸드의 이름을 출력하세요. 어떤 핸드에도 해당하지 않으면 `NO HAND`를 출력하세요. 마지막에 개행을 넣으세요.

출력은 다음 중 $1$개입니다.

```text
FULL HOUSE
THREE CARD
TWO PAIR
ONE PAIR
NO HAND
```

## 예제

### 예제 1 {file=""}

#### 입력

```text

```

#### 출력

```text
FULL HOUSE
```

$5$가 $3$장이고 $6$이 $2$장이므로 `FULL HOUSE`입니다.



#### 출력

