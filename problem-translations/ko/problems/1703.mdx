남자 `N`명과 여자 `M`명이 있습니다. 가능한 남녀 쌍 `(x,y)`가 `a_i=x`, `b_i=y`인 입력 쌍으로 주어집니다.

사람을 중복해 사용할 수 없고, 만든 쌍을 `(x_i,y_i)`라 할 때 순서가 `i<j`이면 `x_i<x_j`와 `y_i<y_j`를 모두 만족해야 합니다. 만들 수 있는 쌍의 최대 개수를 구하세요.

## 입력

`N M Q`와 가능한 쌍 `a_i b_i`가 주어집니다.

## 출력

만들 수 있는 쌍의 최대 개수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1 1 1
1 1
```

#### 출력

```text
1
```

각각 $1$명뿐입니다. 이 왕국은 괜찮을까요?

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 3 2
1 2
2 3
```

#### 출력

```text
2
```

$C=((1,2),(2,3))$입니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
3 3 3
1 2
2 3
3 1
```

#### 출력

```text
2
```

$C=((1,2),(2,3))$입니다.

세 번째 조건 때문에 $C=((1,2),(2,3),(3,1))$로 만들 수 없다는 점에 주의하세요.
