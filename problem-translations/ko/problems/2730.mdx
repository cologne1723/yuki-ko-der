## 문제

타입 X 수하물 `N`개는 무게가 1이고 가치가 `A_i`입니다. 타입 Y 수하물 `M`개는 무게가 `B_j`, 가치가 `C_j`입니다. 원하는 수만큼 골라 총 무게가 `W` 이하가 되도록 넣을 때 가치 합의 최댓값을 구하세요.

## 제약

- `1 ≤ N ≤ 10^6`, `1 ≤ M ≤ 20`
- `1 ≤ W ≤ 10^15`
- `1 ≤ A_i,B_j,C_j ≤ 10^9`

## 입력

```text
N M W
A_1 ... A_N
B_1 ... B_M
C_1 ... C_M
```

## 출력

최대 가치를 출력하세요.

## 예제

### 예제 1 {file="sample_0"}

#### 입력

```text
3 2 3
10 20 15
2 3
100 10
```

#### 출력

```text
120
```

#### 입력

```text

```

#### 출력

```text
10
```


#### 출력

```text
59
```
