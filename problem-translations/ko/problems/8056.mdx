## 문제 설명

서로 다른 $2$개의 홀수 소수 $P$와 $Q$의 곱인 정수 $N$이 주어집니다. $P$와 $Q$를 출력하세요.

단, 양자 컴퓨터에 접근하여 $N$과 서로소인 $N$ 미만의 양의 정수 $A$에 대해 법 $N$에서의 $A$의 위수를 질의할 수 있습니다.

정수 $N\ge 2$와 $N$과 서로소인 양의 정수 $A$에 대해, 법 $N$에서의 $A$의 위수란 $A^R\equiv 1\pmod N$을 만족하는 가장 작은 양의 정수 $R$을 말합니다.

## 입력

입력의 $1$번째 줄에 $N$이 주어집니다.

```text
$N$
```

$N$은 $2^{1\,024}$ 미만의 양의 정수이며, 서로 다른 홀수 소인수를 정확히 $2$개 가집니다.

$N$과 서로소인 $N$ 미만의 양의 정수 $A$를 질의하면, 법 $N$에서의 $A$의 위수가 입력으로 주어집니다.

## 제한

질의 횟수에는 제한이 없지만, 질의에 대한 응답 시간도 포함하여 제한 시간 이내에 $N$의 서로 다른 $2$개의 소인수를 출력해야 합니다.

## 출력

질의는 다음 형식으로 출력하세요.

```text
$?\ A$
```

조건을 만족하지 않는 $A$를 질의하면 오답으로 처리됩니다.

정답은 다음 형식으로 출력하세요.

```text
$!\ P\ Q$
```

$P,Q>1$이고 $PQ=N$을 만족하면 정답으로 처리됩니다.
