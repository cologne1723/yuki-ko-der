역 `0`부터 `2^N`까지 일렬로 있고, `i`번 열차는 역 번호가 `2^i`의 배수인 역에만 정차합니다. 모든 열차는 서쪽에서 동쪽으로만 운행합니다.

각 승객의 출발역 `S_i`에서 도착역 `T_i`까지 최적으로 환승할 때, 도착역을 포함해 이동 중 정차하는 역 수의 최솟값을 구하세요.

## 제약

- `1 <= N <= 60`
- `1 <= Q <= 10^5`
- `0 <= S_i < T_i <= 2^N`

## 입력

`N Q`와 각 승객의 `S_i T_i`가 주어집니다.

## 출력

각 승객의 최솟값을 한 줄에 하나씩 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 4
1 7
3 6
2 3
5 8
```

#### 출력

```text
4
2
1
2
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 2
0 2
1 2
```

#### 출력

```text
1
1
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
32 5
510479020 902533247
494473032 2564665701
1753815 4290493471
3925045722 4058246871
1578437576 3200987099
```

#### 출력

```text
29
30
43
29
36
```
