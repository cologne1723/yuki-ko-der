## 문제 설명

K는 프로그래밍 대회에 참가하는 것을 좋아하며 오늘도 FAC(First Accept Contest)에 참가합니다. FAC는 각 문제를 가장 먼저 푼 사람에게만 점수가 더해지는 독특한 대회입니다. 최종 점수가 가장 높은 사람이 1위입니다.

K는 대회에 조금 늦게 참가했고, 이미 몇 문제는 풀린 상태입니다. K는 모든 문제를 순간적으로 풀 수 있습니다. 늦게 참가한 K가 1위가 될 수 있으면 `YES`, 그렇지 않으면 `NO`를 출력하세요. 1위와 같은 점수여도 1위로 간주합니다. 대회에는 K 외에 100명이 참가합니다.

## 입력

```text
N
a_0 ... a_{N-1}
b_0 ... b_{N-1}
```

- $1 \le N \le 100$
- $1 \le a_i \le 100$
- $0 \le b_i \le 100$
- $a_i$는 $i$번째 문제의 점수입니다.
- $b_i$는 $i$번째 문제를 푼 사람의 번호이며, 0이면 아직 아무도 풀지 않았다는 뜻입니다.

## 출력

K가 1위가 될 수 있으면 `YES`, 될 수 없으면 `NO`를 출력하세요.

## 예제

### 예제 1 {file=""}

```text
4
1 100 100 100
0 1 2 3
```

```text
NO
```

아직 남은 문제는 1점짜리 하나뿐입니다.

### 예제 2 {file=""}

```text
3
10 20 30
1 0 0
```

```text
YES
```

50점을 얻을 수 있으므로 1위가 될 수 있습니다.

### 예제 3 {file=""}

```text
3
10 20 30
0 0 1
```

```text
YES
```

동점이어도 1위로 간주됩니다.
