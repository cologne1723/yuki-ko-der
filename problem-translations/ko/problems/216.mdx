## 문제 설명

K君은 프로그래밍 대회에 참가하는 것을 좋아하며 오늘도 FAC(First Accept Contest)에 참가합니다. FAC는 각 문제를 가장 먼저 푼 사람에게만 점수가 더해지는 독특한 대회입니다. 최종 점수가 가장 높은 사람이 $1$위입니다.

K君은 대회에 조금 늦게 참가했고, 이미 몇 문제는 풀린 상태입니다. K君은 프로이므로 모든 문제를 순간적으로 풀 수 있습니다. 늦게 참가한 K君이 $1$위가 될 수 있으면 `YES`, 그렇지 않으면 `NO`를 출력하세요. $1$위와 같은 점수여도 $1$위로 간주합니다. **대회에는 K君 외에 $100$명이 참가합니다.**

## 입력

```text
$N$
$a_0\ \cdots\ a_{N-1}$
$b_0\ \cdots\ b_{N-1}$
```

$1$번째 줄에는 문제의 개수 $N$이 주어집니다.

$2$번째 줄에는 $i$번째 문제의 점수 $a_i$가 공백으로 구분되어 주어집니다.

$3$번째 줄에는 $i$번째 문제를 푼 사람의 번호 $b_i$가 공백으로 구분되어 주어집니다. $b_i$가 $0$이면 아직 아무도 풀지 않았다는 뜻입니다.

## 제한

- 입력은 모두 정수입니다.
- $1 \le N \le 100$
- $1 \le a_i \le 100$
- $0 \le b_i \le 100$

## 출력

K君이 $1$위가 될 수 있으면 `YES`, 될 수 없으면 `NO`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
1 100 100 100
0 1 2 3
```

#### 출력

```text
NO
```

아직 남은 문제는 $1$점짜리 $1$개뿐입니다.

### 예제 2 {file=""}

#### 입력

```text
3
10 20 30
1 0 0
```

#### 출력

```text
YES
```

$50$점을 얻을 수 있으므로 $1$위가 될 수 있습니다.

### 예제 3 {file=""}

#### 입력

```text
3
10 20 30
0 0 1
```

#### 출력

```text
YES
```

동점이어도 $1$위로 간주됩니다.
