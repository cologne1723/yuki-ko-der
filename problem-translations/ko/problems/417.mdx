## 문제

때는 1634년, 네덜란드에서 튤립 버블이 일어나기 시작하던 시기입니다. 아름다운 튤립이 잇달아 생겨나고 사람들은 신품종에 열광하기 시작했으며, 그 이야기는 시골 영주의 귀에도 들어갔습니다.

영주는 튤립 밭을 만들려고 하지만 좋은 품종은 터무니없는 가격이 붙기 시작했습니다. 당신은 영주의 대리인으로서 튤립 구근 값을 마련하기 위해 마을을 돌며 임시 세금을 걷게 되었습니다. 시간은 돈입니다. 영주는 하루빨리 돈을 마련해 심는 계절인 가을이 끝나기 전에 튤립 밭을 만들고 싶어 합니다. 당신은 최대한 많은 세금을 가지고 제한 시간 안에 돌아오기를 기대받고 있습니다.

마을에서 얻는 세수, 어떤 마을과 마을 사이를 가도로 이동하는 데 걸리는 시간, 그리고 세수를 가지고 영주에게 돌아오기까지의 제한 시간이 주어집니다. 이 데이터로부터 제한 시간까지 돌아오면서 얻을 수 있는 세수의 최댓값을 구하세요.

단, 같은 마을에서는 세금을 여러 번 걷을 수 없습니다.

## 입력

마을을 정점, 가도를 변으로 보면 마을과 가도는 트리 구조를 이룹니다. 마을 번호는 0부터 N − 1까지이며, 마을 0에 영주가 있습니다. 마을 0에서 출발하여 제한 시간 안에 마을 0으로 돌아와야 합니다. 제한 시간에 정확히 도착해도 제시간에 도착한 것으로 봅니다. 제한 시간 안이라면 다른 마을로 가기 위해 마을 0을 여러 번 지나가도 됩니다.

```text
N M
U₀
⋮
Uₙ₋₁
A₁ B₁ C₁
⋮
Aₙ₋₁ Bₙ₋₁ Cₙ₋₁
```

첫째 줄에 마을 수 N과 제한 시간까지 남은 시간 M이 공백으로 주어집니다. 이어지는 N개 줄에는 마을 0부터 N − 1까지의 세수가 순서대로 주어집니다. 이어지는 N − 1개 줄에는 마을을 연결하는 가도 정보가 주어집니다. 가도 Aᵢ와 Bᵢ를 이동하는 데는 어느 방향이든 편도 Cᵢ시간이 걸립니다.

- 1 ≤ N ≤ 200
- 1 ≤ M ≤ 2000
- 1 ≤ Uᵢ ≤ 10000000
- 0 ≤ Aᵢ,Bᵢ < N
- 1 ≤ Cᵢ ≤ 1000

주어지는 수는 모두 정수입니다.

## 출력

얻을 수 있는 최대 세수 T를 한 줄에 출력하세요. 마지막에 개행을 출력하세요.
