## 문제 설명

$N$개 원소로 이루어진 정수열 $A = (A_1, A_2, \cdots, A_N)$이 주어집니다.

$A$에서 최장 증가 부분 수열을 뽑는 방법의 수를 구하세요.

뽑은 부분 수열이 수열로서 같더라도, 선택한 위치의 집합이 다르면 다른 방법으로 셉니다.

즉, $1 \le I_1 < I_2 < \cdots < I_M \le N$이고 $A_{I_1} < A_{I_2} < \cdots < A_{I_M}$이 되는 정수열 $I$ 중 원소 수 $M$이 최대인 것은 몇 가지인지 구하세요.

단, 답을 $1\,000\,000\,007$로 나눈 나머지를 출력하세요.

## 입력

```text
$N$
$A_1 \; A_2 \; \cdots \; A_N$
```

## 제한

- $N$, $A_i$는 정수입니다.
- $1 \le N \le 2 \times 10^5$
- $-10^9 \le A_i \le 10^9$ ($1 \le i \le N$)

## 출력

$A$의 최장 증가 부분 수열을 뽑는 방법의 수를 $1\,000\,000\,007$로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
1 4 2 5 3
```

#### 출력

```text
3
```

최장 증가 부분 수열을 뽑는 방법은 다음 $3$가지입니다.

- $(A_1, A_2, A_4) = (1, 4, 5)$
- $(A_1, A_3, A_4) = (1, 2, 5)$
- $(A_1, A_3, A_5) = (1, 2, 3)$

### 예제 2 {file=""}

#### 입력

```text
3
1 1 2
```

#### 출력

```text
2
```

최장 증가 부분 수열을 뽑는 방법은 다음 $2$가지입니다. 이 둘은 서로 다른 것으로 센다는 점에 주의하세요.

- $(A_1, A_3) = (1, 2)$
- $(A_2, A_3) = (1, 2)$

### 예제 3 {file=""}

#### 입력

```text
12
1 1 2 2 3 1 2 4 3 3 4 4
```

#### 출력

```text
40
```

$(1, 2, 3, 4)$라는 부분 수열이 많이 있습니다.
