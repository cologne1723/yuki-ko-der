## 문제 설명

이로하는 게이밍 전봇대 $N$개를 발견했습니다. 전봇대는 일렬로 서 있고, 각각 $1,2,\cdots,M$ 중 하나의 색으로 빛납니다.

전봇대 $i$의 색에 관한 정보로 정수 $C_i$가 주어집니다.

- $1 \leq C_i \leq M$이면 전봇대 $i$는 색 $C_i$로 빛납니다.
- $C_i=0$이면 전봇대 $i$가 너무 눈부셔서 어떤 색으로 빛나는지 알 수 없습니다.

$C_i=0$인 전봇대의 개수를 $T$라고 합니다. 이 $T$개 전봇대의 색을 각각 $1,2,\cdots,M$ 중 하나로 정하는 방법은 $M^T$가지입니다.

각각의 방법에 대해, $M$가지 색의 전봇대를 각각 적어도 하나씩 포함하는 연속 구간 $[l,r]\ (1 \leq l \leq r \leq N)$의 개수를 생각합니다.

모든 색 배정 방법에 대한 이 개수의 합을 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

```text
$N\ M$
$C_1\ C_2\ \cdots\ C_N$
```

## 제한

- $1 \leq N \leq 3 \times 10^5$
- $1 \leq M \leq 16$
- $0 \leq C_i \leq M$
- 입력으로 주어지는 모든 수는 정수입니다.

## 출력

답을 한 줄에 출력하세요.

## 예제

### 예제 1 {file="01_sample_01"}

#### 입력

```text
5 3
1 2 1 0 0
```

#### 출력

```text
18
```

- $(1,2,1,1,1),(1,2,1,1,2),(1,2,1,2,1),(1,2,1,2,2)$: $0$개
- $(1,2,1,1,3)$: 구간 $[1,5],[2,5]$의 $2$개
- $(1,2,1,2,3)$: 구간 $[1,5],[2,5],[3,5]$의 $3$개
- $(1,2,1,3,1)$: 구간 $[1,4],[1,5],[2,4],[2,5]$의 $4$개
- $(1,2,1,3,2)$: 구간 $[1,4],[1,5],[2,4],[2,5],[3,5]$의 $5$개
- $(1,2,1,3,3)$: 구간 $[1,4],[1,5],[2,4],[2,5]$의 $4$개

$0+2+3+4+5+4=18$입니다.
