## 이야기

???「Re는 물론 ‘레텐’이라는 뜻이야」

ゆ～さん은 한문 연습 문제를 풀고 있습니다. 아직 시작한 지 얼마 되지 않았기 때문에, 오늘 배우는 내용은 한문을 읽는 순서에 관한 것입니다.

하지만 그 연습 문제에 적힌 한문은 대략 사람을 위한 것이라고는 생각하기 어려울 정도로 길었습니다. 그래서 ゆ～さん은 한문의 가에리텐을 입력하면 읽는 순서가 출력되는 프로그램을 원하게 되었습니다.

그리고 그 일을 당신에게 의뢰했습니다. 아마 기계에게 시키더라도 상당히 번거로운 부류의 일일 테지만……

## 문제 설명

$N$개의 문자가 있고, 각각 문자 $1,\dots,N$이라는 번호가 붙어 있습니다.

문자 $i$에는 숫자 $A_i,B_i$가 붙어 있으며, $N$개의 문자는 다음 규칙에 따른 순서로 정확히 $1$번씩 읽힙니다.

- $A_i=1$이면 문자 $i$를 문자 $i+1$의 다음에 읽습니다.
- $B_i=2$이면 $j>i$이고 $B_j=1$인 가장 작은 $j$를 찾아, 문자 $i$를 문자 $j$의 다음에 읽습니다.
- 위에 해당하지 않으면 번호가 작은 문자를 먼저 읽습니다.

제한에 의해 문자를 읽는 순서는 유일하게 정해지며, 모든 문자를 정확히 $1$번씩 읽게 된다는 것이 보장됩니다.

$k=1,\dots,N$에 대해 $k$번째로 읽히는 문자의 번호를 $N$줄에 걸쳐 출력하세요.

**제한이 복잡하다는 점에 주의하세요.**

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$A_1\ B_1$
$A_2\ B_2$
$\vdots$
$A_N\ B_N$
```

## 제한

- $2\leq N\leq2\times10^5$
- $A_i\in\{0,1\}$
- $B_i\in\{0,1,2\}$
- $A_N=0$
- $B_N\neq2$
- $1$ 이상 $N$ 이하인 모든 $i$에 대해, $B_1,B_2,\dots,B_i$ 중 $1$과 같은 것의 개수를 $D$, $2$와 같은 것의 개수를 $E$라고 하면 다음을 만족합니다.
  - $D\leq E$
  - $E-D\leq1$
- $B_1,B_2,\dots,B_N$ 중 $1$과 같은 것의 개수와 $2$와 같은 것의 개수는 같습니다.
- $A_i=1$이면 $B_{i+1}\neq1$입니다.
- $A_i=1$이면 $B_i\neq2$입니다.
- $B_i=2$이면 $B_{i+1}=0$입니다.
- 입력은 모두 정수입니다.

## 출력

$N$줄에 걸쳐 출력하세요. $i$번째 줄에는 $i$번째로 읽히는 문자의 번호를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
0 0
1 0
0 0
```

#### 출력

```text
1
3
2
```

먼저 문자 $1$이 읽힙니다. 다음으로 $A_2=1$이므로 문자 $3$이 먼저 읽히고, 문자 $2$는 그 뒤에 읽힙니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
5
0 0
1 0
0 2
0 0
0 1
```

#### 출력

```text
1
4
5
3
2
```

문자는 다음 순서로 읽힙니다.

- 문자 $1$이 읽힙니다.
- $A_2=1$, $B_3=2$이므로 먼저 문자 $4$가 읽힙니다.
- 그다음 문자인 문자 $5$가 읽힙니다.
- 문자 $5$가 읽혔으므로 문자 $3$을 읽을 수 있게 됩니다. 문자 $3$이 읽힙니다.
- 문자 $3$이 읽혔으므로 문자 $2$를 읽을 수 있게 됩니다. 문자 $2$가 읽힙니다.
