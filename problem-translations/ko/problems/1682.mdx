`N`개의 동전이 있고, `i`번째 동전의 앞면 확률은 `P_i/100`입니다. 하나 이상을 골라 모두 던졌을 때 앞면 수가 홀수면 Alice, 짝수면 Bob이 이깁니다.

Alice의 승리 확률이 `1/2`보다 큰 선택 방법의 수를 `10^9+7`로 나눈 나머지를 구하세요.

## 제약

- `1 <= N <= 100`
- `0 <= P_i <= 100`

## 입력

`N`과 `P_1,...,P_N`이 주어집니다.

## 출력

답을 `10^9+7`로 나눈 나머지를 출력하세요.
