## 문제 비주얼

문제 비주얼을 공개합니다.

![문제 비주얼](../images/3434/1.png)

## 공지

저지 결과가 `QLE`인 경우 문제 또는 저지에 오류가 있을 수 있습니다. 제보해 주세요.

## 문제 설명

チェリーちゃん은 빨간 카드를 $N$장 손에 들고 있습니다. $i$번째 빨간 카드에는 정수 $A_i$가 쓰여 있습니다.

또한 손에 든 카드와 별개로, 덱에는 파란 카드 $N$장이 쌓여 있습니다. 위에서 $j$번째 파란 카드에는 정수 $B_j$가 쓰여 있습니다.

チェリーちゃん은 다음 행동을 순서대로 합니다.

- 가지고 있는 빨간 카드 $N$장 중에서 $0$장 이상 원하는 수만큼을 고릅니다. 그리고 고른 카드를 모두 먹습니다.
- 파란 카드를 **위에서부터 순서대로**, 먹은 빨간 카드와 **같은 수만큼** 뽑아 손에 넣습니다.

행동이 끝나면 チェリーちゃん은 빨간 카드와 파란 카드를 합쳐 $N$장 가지고 있습니다. 이 카드 $N$장에 쓰인 정수의 합을 **점수**라고 합니다.

점수를 최대로 만드는 빨간 카드 먹는 방법을 $1$개 제시하세요.

**$T$개의 테스트 케이스에 대해 답하세요.**

## 입력

입력은 다음 형식으로 주어집니다.

```text
$T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
$B_1\ B_2\ \cdots\ B_N$
```

$1$번째 줄에 테스트 케이스의 수 $T$가 주어집니다. 각 테스트 케이스에서 $1$번째 줄에 카드의 수 $N$, $2$번째 줄에 빨간 카드에 쓰인 정수 $A_1,\ldots,A_N$, $3$번째 줄에 덱의 위에서부터 순서대로 파란 카드에 쓰인 정수 $B_1,\ldots,B_N$이 주어집니다.

## 제한

- $1\leq T\leq 2\times 10^5$
- 각 테스트 케이스에 대해 $1\leq N\leq 2\times 10^5$
- 각 테스트 케이스에 대해 $-10^9\leq A_i\leq 10^9\ (1\leq i\leq N)$
- 각 테스트 케이스에 대해 $-10^9\leq B_j\leq 10^9\ (1\leq j\leq N)$
- 모든 테스트 케이스에서 $N$의 합은 $2\times 10^5$ 이하입니다.
- 입력은 모두 정수입니다.

## 출력

출력은 $T$줄로 이루어집니다. $t\ (1\leq t\leq T)$번째 줄에는 다음과 같이 길이 $N$인 `0`과 `1`로 이루어진 문자열 $S$를 출력하세요.

- $i$번째 빨간 카드를 먹지 않는다면 $S$의 $i$번째 문자를 `0`으로 합니다.
- $i$번째 빨간 카드를 먹는다면 $S$의 $i$번째 문자를 `1`로 합니다.

점수를 최대로 만드는 먹는 방법이 여러 가지라면 그중 $1$개를 제시하면 됩니다.

## 예제

### 예제 1 {file="0_Sample_1.txt"}

#### 입력

```text
3
3
10 30 20
15 25 5
4
1 2 3 4
100 200 300 400
6
0 0 0 0 0 0
100 -1000 0 0 0 0
```

#### 출력

```text
101
1111
001000
```

$1$번째 테스트 케이스에서 チェリーちゃん은 처음에 빨간 카드 $3$장을 가지고 있고, 각 카드에는 $10,30,20$이 쓰여 있습니다. 또한 덱에는 파란 카드 $3$장이 쌓여 있으며, 위에서부터 $15,25,5$가 쓰여 있습니다.

チェリーちゃん이 $1$번째와 $3$번째 빨간 카드를 먹고, 파란 카드를 먹은 빨간 카드와 같은 수인 $2$장 뽑는다고 합시다. 그러면 가지고 있는 카드 $3$장에 쓰인 정수는 순서와 관계없이 $15,30,25$가 됩니다.

이때 점수는 $15+30+25=70$입니다. 또한 점수를 $70$보다 크게 만들 수 없으므로 $S=$`101`은 정답입니다.

チェリーちゃん이 먹을 빨간 카드는 자유롭게 고를 수 있지만, 덱에서 뽑는 파란 카드는 위에서부터만 뽑을 수 있다는 점에 주의하세요.

$2$번째 테스트 케이스에서는 가지고 있는 카드 $4$장을 모두 먹고 덱에서 $4$장을 모두 뽑아야 점수가 최대가 됩니다.

$3$번째 테스트 케이스에서는 빨간 카드 $6$장 중 정확히 $1$장을 먹는 방법이라면 어떤 방법이든 점수가 최대가 됩니다. 따라서 정답인 $S$는 `001000`뿐만 아니라 `000010`이나 `100000`이어도 됩니다.
