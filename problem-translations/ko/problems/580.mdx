## 문제

어느 여관은 매월 초와 9일을 쉬고, 2일부터 8일까지 손님 예약을 받습니다.

손님은 2일 00:00부터 8일 23:59까지의 어느 시간 범위 안에서 예약합니다.

1인용 객실 수 n과 m명의 체크인·체크아웃 예약 시각이 분 단위로 주어집니다.

숙박하는 손님 수를 최대로 할 때 몇 명이 숙박할 수 있는지 구하세요.

체크아웃 뒤에는 객실 청소가 필요하므로 다음 손님은 체크아웃 시각에서 1분의 간격을 둔 뒤에 입실할 수 있습니다. 예를 들어 12시에 체크아웃한 객실에는 12시에 예약한 손님이 들어갈 수 없고, 12시 1분부터 예약할 수 있습니다.

## 입력

```text
n m
d1 hh1:mm1 o1 hho1:mmo1
…
dm hhm:mmm om hhom:mmom
```

n은 1인용 객실 수, m은 손님 수입니다.

0 < n < 101

0 < m < 1001

이후 m개 줄은 손님의 체크인·체크아웃 날짜와 시각입니다.

di, hhi, mmi는 체크인 날짜와 시각입니다. 1 < di < 9, 00 ≤ hhi < 24, 00 ≤ mmi < 60

oi, hhoi, mmoi는 체크아웃 날짜와 시각입니다. 1 < oi < 9, 00 ≤ hhoi < 24, 00 ≤ mmoi < 60

체크아웃은 체크인과 같거나 이후라고 가정해도 됩니다. 체크인과 같은 시각에 체크아웃하는 경우에도 체크아웃 1분 후부터 객실을 예약할 수 있습니다. 이 경우 손님은 1분 이하만 객실을 사용하고 남은 1분 동안 기적적으로 청소했다고 가정해도 됩니다.

## 출력

예약을 조정해 숙박 인원을 최대로 했을 때의 숙박 인원 U를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
1 3
3 10:00 3 10:00
3 10:00 3 10:00
3 10:01 3 10:02
```

출력:

```text
2
```

객실은 하나뿐입니다. 10시에 숙박하는 손님이 사용하고, 10시 1분부터 숙박하는 손님이 사용하므로 두 명이 숙박할 수 있습니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
2 7
3 12:30 4 15:30
3 16:30 3 16:30
3 16:31 4 15:29
4 15:30 7 15:30
2 02:00 3 15:29
3 15:10 4 15:29
3 12:47 4 14:27
```

출력:

```text
5
```

두 객실을 잘 배정하면 5명이 숙박할 수 있습니다.
