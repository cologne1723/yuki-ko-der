## 문제

크리스마스 트리에 장식 $N$개를 달려고 합니다. 장식에는 0번부터 $N-1$번까지 번호가 붙어 있고, 각 장식 아래에는 원하는 만큼 다른 장식을 매달 수 있습니다. 꼭대기에 0번 장식을 달고 나머지는 임의의 순서로 아래에 매달았습니다.

서로 다른 두 장식을 고르는 $\binom{N}{2}$가지 중 다음 두 조건을 만족하는 경우의 수를 구하세요.

- 한 장식에서 위로 따라가면 다른 장식에 도달할 수 있습니다.
- 위에 있는 장식의 번호가 아래에 있는 장식의 번호보다 작습니다.

## 입력

~~~text
$N$
$A_1\ A_2\ \ldots\ A_{N-1}$
~~~

$N$은 양의 정수입니다. $(2\le N\le200\,000)$ $A_i$는 $i$번 장식이 매달린 바로 위 장식의 번호이며 $0\leq A_i\leq N-1$입니다.

## 출력

정답을 한 줄에 출력하고 마지막에 줄바꿈을 출력하세요.

## 예제

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
2
0
~~~

#### 출력

~~~text
1
~~~

장식은 두 개입니다. 0번 아래에 1번이 매달려 있으므로 두 장식을 고르는 한 가지가 조건을 만족합니다. 1번에서 위로 가면 0번에 도달하며, 위의 0번이 더 작은 번호입니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
3
0 0
~~~

#### 출력

~~~text
2
~~~

장식은 세 개이며, 0번 아래에 1번과 2번이 매달려 있습니다. 0번과 1번, 0번과 2번은 조건을 만족하지만 1번과 2번은 서로 위로 이어지지 않습니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
3
2 0
~~~

#### 출력

~~~text
2
~~~

장식은 세 개이며, 0번 아래에 2번, 2번 아래에 1번이 매달려 있습니다. 0번과 1번, 0번과 2번은 조건을 만족합니다. 1번에서 2번으로 올라갈 수 있지만 위의 2번 번호가 더 크므로 1번과 2번은 조건을 만족하지 않습니다.
