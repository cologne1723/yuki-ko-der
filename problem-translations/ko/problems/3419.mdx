## 문제 설명

길이 $N$인 문자열 $S$와 $(1,2,\ldots,N)$의 순열 $P=(P_1,P_2,\ldots,P_N)$가 주어집니다.

모든 $i$ ($1\leq i\leq N$)에 대해 $S$의 $i$번째 문자를 $S$의 $P_i$번째 문자로 동시에 치환한 문자열 $S$를 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$S$
$P_1\ P_2\ \cdots\ P_N$
```

$N$은 문자열의 길이입니다. $S$는 영문 소문자로 이루어진 길이 $N$의 문자열입니다. $P_i$는 $i$번째 자리에 가져올 원본 $S$의 문자 위치를 나타냅니다.

## 제한

- $1\leq N\leq100$
- $S$는 영문 소문자로 이루어진 길이 $N$의 문자열입니다.
- $1\leq P_i\leq N$ ($1\leq i\leq N$)
- $i\neq j$이면 $P_i\neq P_j$입니다.

## 출력

치환한 문자열 $S$를 출력하세요.
