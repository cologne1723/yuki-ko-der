## 문제 설명

여러분은 yukicoder에서 개최되는 스피드런 콘테스트에 참가하게 되었습니다.

스피드런 콘테스트에서는 난이도 $1$, $1.5$, $2$, $2.5$의 $4$단계로 나뉜 문제들이 출제됩니다.
난이도 $1$인 문제는 $A$개 출제되며, 문제 하나를 푸는 데 $P$분이 걸립니다.
난이도 $1.5$인 문제는 $B$개 출제되며, 문제 하나를 푸는 데 $Q$분이 걸립니다.
난이도 $2$인 문제는 $C$개 출제되며, 문제 하나를 푸는 데 $R$분이 걸립니다.
난이도 $2.5$인 문제는 $D$개 출제되며, 문제 하나를 푸는 데 $S$분이 걸립니다.

여러분은 이 스피드런에서 정확히 $T$분에 $N$개의 문제를 풀었습니다.
이때 난이도별로 푼 문제 수의 조합 중 가능한 것을 하나 출력하세요.

이 문제에서는 해가 존재하는 입력만 주어집니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$A\ B\ C\ D\ N$
$P\ Q\ R\ S\ T$
```

입력은 모두 정수입니다.

## 제한

- $1 \le A,B,C,D \le 10\,000$
- $1 \le P,Q,R,S \le 10\,000$
- $1 \le T \le 4 \times 10^8$
- $1 \le N \le A+B+C+D$
- 주어진 입력에 대해 해가 적어도 $1$개 존재합니다.

## 출력

난이도 $1$, $1.5$, $2$, $2.5$인 문제를 각각 $n_a$, $n_b$, $n_c$, $n_d$개 풀었다고 할 때, 다음 형식으로 출력하세요.
조건을 만족하는 $(n_a,n_b,n_c,n_d)$의 조합이 여러 개라면 그중 어느 것이든 정답으로 인정됩니다.

```text
$n_a\ n_b\ n_c\ n_d$
```

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1 3 3 3 8
5 10 15 20 120
```

#### 출력

```text
1 1 3 3
```

난이도 $1$, $1.5$, $2$, $2.5$인 문제를 각각 $1$개, $1$개, $3$개, $3$개 푼 경우, 푸는 데 걸린 시간의 합은 $1 \times 5 + 1 \times 10 + 3 \times 15 + 3 \times 20 = 120$분입니다.

이 밖에 `0 3 2 3`을 출력해도 정답입니다.
