## 문제 설명

수열에 대해 다음 연산을 생각합니다.

- 수열의 임의의 위치를 선택하여 $0$을 삽입합니다. 그 후, 삽입한 위치의 바로 왼쪽에 수가 존재하면 그 수에 $1$을 더하고, 마찬가지로 바로 오른쪽에 수가 존재하면 그 수에 $1$을 더합니다.

$0$만으로 이루어진 길이 $1$인 수열에서 시작하여, 연산을 몇 번 수행한 결과 최종적으로 길이 $N$인 수열 $A$가 되도록 하는 연산 방법의 수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

$2$개의 연산 방법이 다르다는 것은 연산 횟수가 다르거나, 어떤 $i$에 대해 $i$번째 삽입 위치가 다른 것을 의미합니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
```

$1$번째 줄에 수열의 길이 $N$이 주어집니다.

$2$번째 줄에 최종 수열 $A$의 $N$개 원소 $A_1,\ A_2,\ \ldots,\ A_N$이 공백으로 구분되어 주어집니다.

## 제한

- $1\leq N\leq 2\times 10^5$
- $0\leq A_i\leq 10^9$
- 입력은 모두 정수입니다.

## 출력

답을 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
0 2 0
```

#### 출력

```text
2
```

$1$번째 연산에서 가장 왼쪽에 삽입하고, $2$번째 연산에서 가장 오른쪽에 삽입하면 수열은 $0\to 0,1\to 0,2,0$으로 변합니다.

### 예제 2 {file=""}

#### 입력

```text
2
0 0
```

#### 출력

```text
0
```

최종적으로 수열이 $0,0$이 되도록 하는 연산 방법은 존재하지 않습니다.

### 예제 3 {file=""}

#### 입력

```text
20
1 0 5 0 1 1 4 2 0 2 0 7 0 1 1 2 0 5 0 2
```

#### 출력

```text
454727167
```
