1보다 큰 어떤 제곱수로도 나누어지지 않는 양의 정수를 제곱인수가 없는 수라고 합니다.

`L` 이상 `R` 이하인 정수 중 제곱인수가 없는 수의 개수를 구하세요.

## 제약

- `1 <= L <= R <= 10^18`
- `R-L <= 10^6`

## 입력

`L R`이 주어집니다.

## 출력

답을 출력하세요.
