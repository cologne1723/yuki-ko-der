## 문제

N개의 로마 숫자 R1, R2, R3, …, Rn이 있습니다.

이 N개의 로마 숫자를 모두 더한 결과 A는 얼마일까요? 출력도 로마 숫자로 하세요.

단, MMMCMXCIX(아라비아 숫자로 3999)보다 큰 수가 되면 ERROR를 출력하세요.

로마 숫자는 다음 7개의 영문자를 조합해 나타냅니다.

I = 1, V = 5, X = 10, L = 50, C = 100, D = 500, M = 1000

또한 로마 숫자에서는 같은 문자를 4개 연속으로 쓰는 것이 금지되어 있습니다.

다음 숫자는 감산법으로 표기해야 합니다.

IV = 4, IX = 9, XL = 40, XC = 90, CD = 400, CM = 900

## 입력

```text
N
R1 R2 R3 … Rn
```

N은 2 이상 100 이하입니다.

R은 로마 숫자 I부터 MMMCMXCIX까지(아라비아 숫자로 1부터 3999까지)입니다.

## 출력

A를 로마 숫자 문자열로 출력하세요.

MMMCMXCIX(아라비아 숫자로 3999)보다 큰 수가 되면 ERROR를 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
2
II III
```

출력:

```text
V
```

2 + 3 = 5입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
5
IV XXI CCCXL III MMCMVI
```

출력:

```text
MMMCCLXXIV
```

4 + 21 + 340 + 3 + 2906 = 3274입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
4
M M M M
```

출력:

```text
ERROR
```

1000 + 1000 + 1000 + 1000 = 4000입니다. 수치가 범위를 초과했으므로 ERROR입니다.
