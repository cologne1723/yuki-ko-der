처음에 빈 문자열 $T,U$가 있다냥. A 키는 $T$의 끝에 `a`를 추가하고, B 키는 `b`를 추가한다냥. C 키는 $U$를 현재 $T$로 바꾸며, V 키는 $U$를 $T$의 끝에 추가한다냥. `a`와 `b`로 이루어진 문자열 $S$가 주어질 때 $T$를 $S$와 같게 만드는 최소 키 입력 횟수를 구하라냥.

## 조건

- $S$는 `a`, `b`로 이루어진 문자열이다냥.
- $1\le |S|\le2\times10^5$

## 입력

```text
S
```

## 출력

최소 키 입력 횟수를 출력하라냥.
