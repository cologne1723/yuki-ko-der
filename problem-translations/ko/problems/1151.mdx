## 문제 설명

null 씨와 kiri 씨가 챌린지 게임을 합니다. 처음에 카드 $N$장이 있고, $i$번째 카드에는 양의 정수 $A_i$가 쓰여 있습니다.

처음 두 사람의 점수는 모두 $0$점입니다. null 씨부터 시작해 번갈아 다음을 수행합니다.

- 아직 제거되지 않은 카드 한 장을 골라 ‘챌린지’합니다.
- 고른 카드에 $a$가 쓰여 있다면 챌린지는 $1/a$의 확률로 성공합니다.
- 성공하면 카드를 제거하고 챌린지한 사람의 점수에 $a$점을 더합니다.
- 실패하면 카드를 제거하지 않고 점수도 변하지 않습니다.
- 성공과 실패에 관계없이 자신의 차례를 끝내고 상대 차례가 됩니다.

모든 카드가 제거될 때까지 반복합니다. 모든 카드가 제거되었을 때 점수가 높은 사람이 이기며, 동점이면 kiri 씨가 이깁니다. 두 사람이 자신의 승률을 최대화하도록 행동할 때 null 씨가 이길 확률을 구하세요.

## 입력

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
```

- $1 \leq N \leq 10$
- $1 \leq A_i \leq 20$

## 출력

답을 한 줄에 출력하고 마지막에 줄바꿈을 넣으세요. 절대 오차 또는 상대 오차가 $10^{-6}$ 이하이면 정답으로 인정합니다. 이 문제의 제한에서는 답의 확률이 유일하게 정해집니다.

## 예제

### 예제 1 {file=""}
#### 입력
```text
2
1 2
```
#### 출력
```text
0.6666666667
```

두 번째 카드가 쓰인 $2$를 얻는 사람이 이깁니다. $2$가 쓰인 카드가 남아 있는 동안 그 카드를 고르는 것이 최선이며, 챌린지 성공률은 $1/2$입니다. null 씨가 이길 확률은 $1/2+(1/2)^3+(1/2)^5+\cdots=2/3$입니다.

### 예제 2 {file=""}
#### 입력
```text
4
1 1 1 1
```
#### 출력
```text
0
```

`1`이 쓰인 카드는 챌린지하면 반드시 성공합니다. 동점이면 kiri 씨가 이깁니다.

### 예제 3 {file=""}
#### 입력
```text
5
3 4 5 9 11
```
#### 출력
```text
0.4818994264
```
