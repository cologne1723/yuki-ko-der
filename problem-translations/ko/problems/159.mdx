## 문제 설명

USB 커넥터에 대해 “두 번 뒤집으면 꽂힌다”고 말하는 경우가 있습니다. 타로는 USB를 꽂을 때 다음 절차를 따릅니다.

처음 USB는 확률 $p$로 앞면, 확률 $1-p$로 뒷면을 향합니다. USB를 꽂으려고 시도합니다. 앞면이면 확률 $q$로 꽂히고 확률 $1-q$로 꽂히지 않습니다. 뒷면이면 꽂히지 않습니다.

꽂히지 않았다면 앞면이면 뒷면으로, 뒷면이면 앞면으로 뒤집은 뒤 다시 꽂기를 시도합니다. 꽂혔다면 절차를 종료합니다. USB를 꽂는 각 시도는 서로 독립이라고 가정합니다.

이 절차에서 USB를 정확히 $i$번 뒤집고 종료할 확률을 $P_i$라고 합니다. $P_1\lt P_2$인지 판정하세요.

## 입력

```text
p q
```

- $0 \le p \le 1$
- $0.1 \le q \le 1$
- $p,q$는 소수점 이하 5자리까지 주어집니다.
- $|P_1-P_2| \ge 10^{-5}$

## 출력

$P_1\lt P_2$이면 `YES`, 그렇지 않으면 `NO`를 출력하세요.

## 예제

### 예제 1

```text
0.80000 0.50000
```

```text
YES
```

이 경우 $P_1=0.1$, $P_2=0.2$입니다.

### 예제 2

```text
0.60000 0.50000
```

```text
NO
```

이 경우 $P_1=0.2$, $P_2=0.15$입니다.
