## 문제 설명

올바른 괄호열을 다음 조건 중 $1$가지를 만족하는 문자열로 정의합니다.

- 빈 문자열
- 어떤 올바른 괄호열 $A$가 존재하여, `(`, $A$, `)`를 이 순서대로 이어 붙인 것
- 비어 있지 않은 올바른 괄호열 $A$, $B$가 존재하여, $A$, $B$를 이 순서대로 이어 붙인 것

예를 들어 `(())()`은 올바른 괄호열이고, `()(`과 `)(`은 올바른 괄호열이 아닙니다.

양의 짝수 $N$에 대하여 길이 $N$인 **A형 올바른 괄호열**을 다음과 같이 정의합니다.

- $1 \le i \le N/2$일 때 $S_i$는 `(`입니다.
- $N/2+1 \le i \le N$일 때 $S_i$는 `)`입니다.

예를 들어 `(())`, `((((()))))`는 A형 올바른 괄호열입니다.

양의 짝수 $N$에 대하여 길이 $N$인 **B형 올바른 괄호열**을 다음과 같이 정의합니다.

- $i$가 홀수일 때 $S_i$는 `(`입니다.
- $i$가 짝수일 때 $S_i$는 `)`입니다.

예를 들어 `()()`, `()()()()()`은 B형 올바른 괄호열입니다.

길이 $N$인 **A형 또는 B형** 올바른 괄호열 $S$가 주어집니다. $0$, $1$로 이루어진 길이 $N$의 수열 $T$ 중 다음 조건을 만족하는 것의 개수를 구하세요.

- $T_i = 0$인 정수 $i$ ($1 \le i \le N$)가 존재하는 경우, $T_i = 0$인 $i$를 오름차순으로 $P_1,\ldots,P_k$라 합니다. $S_{P_1},\ldots,S_{P_k}$를 순서대로 이어 붙인 문자열을 $X$라 할 때, $X$는 올바른 괄호열이어야 합니다.
- $T_i = 1$인 정수 $i$ ($1 \le i \le N$)가 존재하는 경우, $T_i = 1$인 $i$를 오름차순으로 $Q_1,\ldots,Q_l$라 합니다. $S_{Q_1},\ldots,S_{Q_l}$를 순서대로 이어 붙인 문자열을 $Y$라 할 때, $Y$는 올바른 괄호열이어야 합니다.

답은 매우 커질 수 있으므로, $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$S$
```

## 제한

- $2 \le N \le 5\times 10^5$
- $N$은 짝수입니다.
- $S$는 A형 또는 B형 올바른 괄호열입니다.

## 출력

조건을 만족하는 $T$의 개수를 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
(())
```

#### 출력

```text
6
```

입력 문자열은 A형 올바른 괄호열입니다. 조건을 만족하는 $T$와 그에 대응하는 $X$, $Y$는 다음과 같습니다.

| $T$ | $X$ | $Y$ |
| --- | --- | --- |
| `0000` | `(())` | 없음 |
| `0101` | `()` | `()` |
| `0110` | `()` | `()` |
| `1001` | `()` | `()` |
| `1010` | `()` | `()` |
| `1111` | 없음 | `(())` |

총 $6$개이므로 $6$을 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
4
()()
```

#### 출력

```text
4
```

입력 문자열은 B형 올바른 괄호열입니다.

### 예제 3 {file=""}

#### 입력

```text
2
()
```

#### 출력

```text
2
```

입력 문자열은 A형이면서 B형인 올바른 괄호열입니다.

### 예제 4 {file=""}

#### 입력

```text
40
(((((((((((((((((((())))))))))))))))))))
```

#### 출력

```text
88808106
```

$998\,244\,353$으로 나눈 나머지를 출력한다는 점에 주의하세요.
