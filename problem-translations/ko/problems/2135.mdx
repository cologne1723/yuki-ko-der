정점에 $1,2,\ldots,N$의 번호가 붙고 변에는 번호가 붙지 않은 $N$정점 $M$변의 무향 단순 그래프 $G=(V,E)$가 있다냥. 모든 $|V'|=5$인 $V$의 부분집합 $V'$에 대해, $V'$가 유도하는 부분 그래프가 길이 $5$인 사이클을 포함하도록 하는 그래프의 개수를 구하라냥.

유도 부분 그래프란 양 끝점이 모두 $V'$에 포함되는 $E$의 변을 모두 변으로 가지며 정점 집합이 $V'$인 그래프를 뜻한다냥.

## 조건

- $5\le N\le 300$
- $0\le M\le\frac{N(N-1)}2$

## 입력

```text
N M
```

## 출력

그래프의 개수를 $998244353$으로 나눈 나머지를 출력하라냥.
