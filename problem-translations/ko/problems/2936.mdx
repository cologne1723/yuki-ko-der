## 문제 설명

양의 정수 $N$과 음이 아닌 정수 $M$이 주어집니다.

$0 \leq A_i \leq M$을 만족하는 길이 $N$의 음이 아닌 정수열 $A$는 $(M+1)^N$개 있습니다.

이 모든 수열에 대한 $\mathrm{mex}(A)^2$의 합을 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ M$
```

## 제한

- $1 \leq N \leq 2 \times 10^5$
- $0 \leq M \leq 10^9$

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2 2
```

#### 출력

```text
11
```

- $A=(0,0)$일 때 $\mathrm{mex}(A)^2=1^2=1$입니다.
- $A=(0,1)$일 때 $\mathrm{mex}(A)^2=2^2=4$입니다.
- $A=(0,2)$일 때 $\mathrm{mex}(A)^2=1^2=1$입니다.
- $A=(1,0)$일 때 $\mathrm{mex}(A)^2=2^2=4$입니다.
- $A=(1,1)$일 때 $\mathrm{mex}(A)^2=0^2=0$입니다.
- $A=(1,2)$일 때 $\mathrm{mex}(A)^2=0^2=0$입니다.
- $A=(2,0)$일 때 $\mathrm{mex}(A)^2=1^2=1$입니다.
- $A=(2,1)$일 때 $\mathrm{mex}(A)^2=0^2=0$입니다.
- $A=(2,2)$일 때 $\mathrm{mex}(A)^2=0^2=0$입니다.

따라서 답은 $1+4+1+4+0+0+1+0+0=11$입니다.
