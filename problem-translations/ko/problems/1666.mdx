`a^b` (`a >= 1`, `b >= 2`)로 나타낼 수 있는 양의 정수를 거듭제곱 수라고 합니다.

`K`번째로 작은 거듭제곱 수를 구하세요.

## 제약

- `1 <= T <= 500`
- `1 <= K <= 10^9`

## 입력

첫째 줄에 테스트 케이스 수 `T`, 각 테스트 케이스에 `K`가 주어집니다.

## 출력

각 테스트 케이스의 답을 한 줄에 하나씩 출력하세요.
