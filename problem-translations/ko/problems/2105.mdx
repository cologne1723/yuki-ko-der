$a_i$를 $0,1,\ldots,C+i-1$ 중에서 독립적으로 균등하게 골라 수열을 만듭니다. 모든 $K$에 대해 처음 $K$개 원소의 MEX가 $X$가 되지 않을 확률의 극한 $\lim_{N\to\infty}p_N$을 $998244353$로 계산하세요.

## 입력

```text
C X
```

$0\le C,X\le2000$입니다.

## 출력

극한을 출력하세요.
