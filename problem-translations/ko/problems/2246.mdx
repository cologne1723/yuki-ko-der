$1\le a<b\le9$와 비음이 아닌 정수 $c$를 정하자냥. 처음 $X=10a+b$로 두고 $c$번 반복해 $X\leftarrow10X+b$로 바꿔 얻는 수를 꼬리 수라고 한다냥. 꼬리 수를 오름차순으로 나열했을 때 $N$번째 수를 구하라냥.

## 조건

- $1\le N\le1333333$

## 입력

```text
N
```

## 출력

$N$번째 꼬리 수를 출력하라냥.
