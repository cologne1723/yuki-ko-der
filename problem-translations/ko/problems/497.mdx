## 문제

N개의 직육면체 상자가 있습니다. 크기는 서로 다양합니다.

이 상자들 중 몇 개를 골라 마트료시카처럼 작은 상자를 큰 상자 안에 넣는 일을 반복해, 겹쳐 넣은 상자를 만들려고 합니다.

최대 몇 겹으로 상자를 겹쳐 넣을 수 있을까요?

상자는 방향을 바꾸거나 옆으로 눕혀 사용해도 됩니다.

(원하는 방향으로 바꾸거나 옆으로 눕힌 뒤의) 상자 i의 너비, 깊이, 높이가 상자 j의 너비, 깊이, 높이보다 각각 엄밀하게 작을 때에만 상자 i를 상자 j 안에 넣을 수 있습니다.

상자 하나 안에 상자 두 개를 직접 넣더라도 3겹은 아닙니다.

## 입력

```text
N
X1 Y1 Z1
X2 Y2 Z2
...
XN YN ZN
```

1 ≤ N ≤ 1000

1 ≤ Xi,Yi,Zi < 10^8

N, Xi, Yi, Zi는 모두 정수입니다.

상자의 개수는 N개입니다.

i번째 상자의 크기는 세 변의 길이가 각각 Xi,Yi,Zi입니다.

## 출력

상자를 겹쳐 넣을 수 있는 최대 겹수를 정수로 출력하세요.

상자를 전혀 겹쳐 넣을 수 없는 경우에는 1을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
4
2 2 2
1 1 1
3 3 3
4 1 4
```

출력:

```text
3
```

다음 그림처럼 크기 (1,1,1)인 상자를 크기 (2,2,2)인 상자 안에 넣고, 그것을 크기 (3,3,3)인 상자 안에 넣으면 3겹으로 만들 수 있습니다.

크기 (4,1,4)인 상자는 사용하지 않았습니다.

여기서 “크기 (X,Y,Z)인 상자”란 세 변의 길이가 각각 X,Y,Z인 상자를 뜻합니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
2
1 1 3
2 4 2
```

출력:

```text
2
```

크기 (1,1,3)인 상자를 옆으로 눕히면 크기 (2,4,2)인 상자 안에 넣을 수 있습니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
2
5 5 3
4 3 3
```

출력:

```text
1
```

각 상자의 방향을 어떻게 바꾸더라도 한 상자를 다른 상자 안에 넣을 수 없습니다.

전혀 겹쳐 넣을 수 없으므로 답은 1입니다.
