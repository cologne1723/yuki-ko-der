## 문제

잠에서 깼지만 늦잠의 계절이므로 5분 더 자려고 합니다.

첫 번째 기상 시각이 주어질 때, 그로부터 5분 뒤의 시각을 구하세요.

## 입력

```text
T
```

T는 hh:mm 형식으로 주어집니다.

0 ≤ hh ≤ 23이고, 0 ≤ hh ≤ 9인 경우에는 앞에 0을 붙여 두 자리로 표시합니다.

0 ≤ mm ≤ 59이고, 0 ≤ mm ≤ 9인 경우에는 앞에 0을 붙여 두 자리로 표시합니다.

따라서 00:00 ≤ T ≤ 23:59입니다.

입력 파일 끝에는 줄바꿈이 있습니다.

## 출력

T에서 5분 뒤의 시각을 hh:mm 형식으로 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
08:10
```

출력:

```text
08:15
```

시와 분 모두 0을 채워 두 자리로 표시하세요.

### 샘플 2 {file="sample2.in"}

입력:

```text
23:59
```

출력:

```text
00:04
```

날짜가 바뀐 뒤까지 늦잠을 잘 수도 있습니다.
