## 문제 설명

당신은 메이드 카페 「제로칸☀타이요」에서 일하는 메이드입니다.
오늘은 단골 주인님께 타피오카 밀크티를 내드리게 되었지만, 바로 직전에 맛없는 타피오카를 실수로 밀크티에 넣었을지도 모른다는 것을 깨달았습니다.

타피오카는 $N$알이며, $1,2,\cdots,N$번으로 구별됩니다. $i$번 타피오카의 맛은 양의 정수 $b_i$입니다. 지금 $1,2,\cdots,M$번 타피오카는 밀크티 안에 들어 있고, 나머지 타피오카는 주방에 있습니다. 타피오카 밀크티의 맛은 그 안에 들어 있는 타피오카의 맛의 총합과 같습니다.

당신은 정확히 $K$번만 모에모에 파워를 사용하여 타피오카를 순간이동시킬 수 있습니다. 파워를 사용할 때마다 각 알이 독립적으로 확률 $\frac{p}{q}$로, 밀크티 안에 있는 타피오카는 주방으로, 주방에 있는 타피오카는 밀크티 안으로 이동합니다. 밀크티 안과 주방에 있는 타피오카의 개수는 반드시 보존되는 것은 아니며, 순간이동이 일어날 확률은 알마다 독립이고, 파워를 사용했는데도 알이 하나도 이동하지 않는 경우도 있습니다.

정확히 $K$번 모에모에 파워를 사용한 뒤 주인님께 내드릴 타피오카 밀크티 맛의 기댓값은 얼마일까요?

기댓값은 유리수가 되며, 제약 아래에서 양의 정수 $x$와 $10^9+7$의 배수가 아닌 양의 정수 $y$를 사용하여 $\frac{x}{y}$로 나타낼 수 있음이 보장됩니다. 그리고 $0\le R < 10^9+7$이고 $x \equiv yR \pmod{10^9+7}$를 만족하는 유일한 음이 아닌 정수 $R$을 출력하세요.

## 입력

```text
$N\;M\;K\;p\;q$
$b_1$
$b_2$
$\vdots$
$b_N$
```

입력은 다음 제한을 만족합니다. 입력량이 많으므로 Python 등이 아니라 PyPy, C++ 등의 빠른 언어를 사용하는 것을 권장합니다.

## 제한

- $1\le N\le 10^5$
- $0\le M\le N$
- $1\le K\le 10^{12}$
- $1\le p < q\le 10^9$
- $1\le b_i\le 10^9$ ($1\le i\le N$)
- 입력은 모두 정수입니다.

## 출력

문제 설명에서 제시한 형식으로 기댓값을 출력하고, 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 0 1 1 2
1
```

#### 출력

```text
500000004
```

넣는 것을 잊은 타피오카가 $1$번의 파워 사용으로 순간이동할 확률은 $\frac{1}{2}$입니다.

### 예제 2 {file=""}

#### 입력

```text
4 3 4 1 4
4
4
4
4
```

#### 출력

```text
250000010
```

구하는 기댓값은 $\frac{33}{4}$이므로, $33\equiv 4R\pmod{10^9+7}$를 만족하는 $0$ 이상 $10^9+7$ 미만의 유일한 정수 $R=250\,000\,010$을 출력합니다.

#### 입력

```text
5 2 314159265358 1729 87539319
12345678
99999996
99999997
99999998
99999999
```

#### 출력

```text
57524728
```
