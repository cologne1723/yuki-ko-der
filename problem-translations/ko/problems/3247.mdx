## 문제 설명

각 원소가 $1$, $2$, $-1$, $-2$ 중 하나인 길이 $N$의 수열 $A$와 정수 $K$가 주어집니다.

또한 $0 = B_1 < B_2 < \dots < B_L = N$을 만족하는 길이 $L$의 정수열 $B$에 대해 그 **점수**를 다음과 같이 정의합니다.

- $1 \leq i \leq L - 1$을 만족하는 모든 정수 $i$에 대해 $A_{B_i + 1} \times A_{B_i + 2} \times \dots \times A_{B_{i+1}} = 8$이면, 점수는 $\displaystyle\sum_{i=1}^{L-1}(B_{i+1} - B_i)^K$입니다.
- 그렇지 않으면 점수는 $0$입니다.

정수열 $B$로 가능한 것은 $2^{N-1}$개이며, 그 모든 정수열에 대한 점수의 합을 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ K$
$A_1\ A_2\ \cdots\ A_N$
```

$1$번째 줄에 수열의 길이인 정수 $N$과 정수 $K$가 주어집니다.

$2$번째 줄에 수열 $A$의 원소 $N$개 $A_1, A_2, \dots, A_N$이 공백으로 구분되어 주어집니다.

## 제한

- 입력은 모두 정수입니다.
- $1 \leq N \leq 8.88 \times 10^5$
- $1 \leq K \leq 8.88 \times 10^8$
- $A_i \in \{1, 2, -1, -2\}$

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
5 2
1 2 2 -1 -2
```

#### 출력

```text
25
```

점수가 $0$이 아닌 정수열 $B$는 $B = (0, 5)$인 $1$개뿐입니다.

$B = (0, 5)$의 점수는 $(5 - 0)^2 = 25$이므로 점수의 합은 $25$입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
8 8
1 1 1 1 1 1 1 1
```

#### 출력

```text
0
```

어떤 정수열 $B$에 대한 점수도 $0$이므로 점수의 합은 $0$입니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
8 3
2 -2 -1 2 1 -2 2 -2
```

#### 출력

```text
280
```

점수가 $0$이 아닌 정수열 $B$는 $B = (0, 4, 8)$과 $B = (0, 5, 8)$의 $2$개입니다.

- 정수열 $B = (0, 4, 8)$의 점수는 $(4 - 0)^3 + (8 - 4)^3 = 128$입니다.
- 정수열 $B = (0, 5, 8)$의 점수는 $(5 - 0)^3 + (8 - 5)^3 = 152$입니다.

따라서 모든 정수열 $B$에 대한 점수의 합은 $128 + 152 = 280$입니다.

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
18 888000000
1 2 -1 -2 1 2 1 2 -1 -2 1 2 1 2 -1 -2 1 2
```

#### 출력

```text
921567506
```

점수의 합을 $998\,244\,353$으로 나눈 나머지를 출력하세요.
