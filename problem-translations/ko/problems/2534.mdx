정수 $N$에서 시작해 1이 될 때까지 짝수면 2로 나누고 홀수면 $3n+1$로 바꾸는 과정을 수행합니다. $P(N)$이 50회 이내에 1에 도달하는지 판정하고, 그렇다면 정지 단계 수를 출력하세요.

## 조건

- $-1000\le N\le1000$

## 입력

```text
N
```

## 출력

50회 이내에 정지하면 `Yes`와 단계 수를, 아니면 `No`를 출력하세요.
