각 테스트 케이스에 대해 다음 조건을 만족하는 양의 정수 3개로 이루어진 중복집합 `{a,b,c}`를 모두 구성하고, 그 개수와 함께 출력하세요.

## 조건

- `0 < a,b,c <= 10^9`
- 변의 길이가 `a,b,c`인 삼각형이 존재하며 넓이가 `S`입니다.
- `a+b+c=T`입니다.

## 제약

- `1 <= t <= 20`
- `1 <= S <= 7.5 * 10^8`
- `3 <= T <= 3 * 10^9`
- 입력은 모두 정수입니다.

## 입력

첫째 줄에 테스트 케이스 수 `t`가 주어지고, 각 테스트 케이스에 `S,T`가 주어집니다.

## 출력

각 테스트 케이스에서 조건을 만족하는 집합의 개수를 먼저 출력한 뒤, 모든 집합을 출력하세요.
