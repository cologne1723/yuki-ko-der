## 문제 설명

주어지는 $N$개 값의 합을 구하세요.

## 입력

```text
N
A_1
A_2
:
A_i
:
A_N
```

첫째 줄에 값의 개수를 나타내는 정수 $N$이 주어집니다. $(1 \le N \le 100)$

이어지는 $N$개 줄에 값 $A_i$가 주어집니다. $(-10^{10} \le A_i \le 10^{10},\ 1 \le i \le N)$

값은 정수 또는 유한소수로 주어지며, 소수인 경우 소수점 이하 최대 10자리까지 주어질 수 있습니다.

## 출력

모든 값을 더한 결과를 출력하세요.

결과에 소수가 포함되지 않더라도 소수점 이하 10자리까지 출력하세요.

마지막에 줄 바꿈을 출력하세요.
