$1\le N<10^9$인 양의 정수 $N$이 주어집니다. $1\le M<10^{18}$인 양의 정수 $M$을 하나 구하세요. 정수 덧셈으로 계산한 $A=N+M$이, 문자열 이어 붙이기로 계산한 $B$ (즉 $N$과 $M$을 이어 쓴 수)를 나누어야 합니다.

## 입력

```text
T
N
```

$1\le T\le100$입니다.

## 출력

각 테스트 케이스의 $M$을 출력하세요. 앞에 0을 붙이지 마세요.
