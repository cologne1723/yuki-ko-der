## 문제

두 더미에 각각 $A,B$개의 돌이 있습니다. 돌이 남아 있는 동안 더미 하나에서 원하는 양의 돌을 제거합니다. 돌을 제거한 뒤 두 더미의 개수가 다르면 플레이어가 교대하고, 같으면 같은 사람이 계속합니다.

마지막 돌을 가져간 사람이 승리할 때, 최선으로 플레이하면 누가 이기는지 출력하세요.

## 입력

$A,B$가 주어집니다.

- $1\leq A,B\leq10^9$

## 출력

P가 이기면 `P`, Q가 이기면 `Q`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 2
```

#### 출력

```text
Q
```

### 예제 2 {file=""}

#### 입력

```text
4 3
```

#### 출력

```text
Q
```

### 예제 3 {file=""}

#### 입력

```text
12398742 83717408
```

#### 출력

```text
P
```
