## 문제 설명

원소가 $4$개인 양의 정수 집합 $A = \{a_1, a_2, a_3, a_4\}$에 대해, 다음 조건을 만족하면 **좋은 집합**이라고 정의합니다.

$1 \le i < j \le 4$를 만족하는 순서쌍 $(i, j)$ 중에서 $a_1+a_2+a_3+a_4$가 $a_i+a_j$의 배수인 순서쌍이 정확히 $\mathbf{4}$개입니다.

원소가 $N$개인 양의 정수 집합 $S = \{s_1, s_2, \dots, s_N\}$가 주어집니다.

$Q$개의 질의가 주어집니다. $q$번째 질의는 정수의 순서쌍 $(t_q, x_q)$로 주어지며, 내용은 다음과 같습니다.

- $t_q = 1$인 경우: $S$에 $x_q$를 추가합니다.
- $t_q = 2$인 경우: $S$에서 $x_q$를 삭제합니다.

각 질의를 처리할 때마다 $S$의 부분집합 중 **좋은 집합**인 것의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ Q$
$s_1\ s_2\ \cdots\ s_N$
$t_1\ x_1$
$t_2\ x_2$
$\vdots$
$t_Q\ x_Q$
```

## 제한

- 입력은 모두 정수입니다.
- $1 \le N, Q \le 2\times 10^5$
- $1 \le s_i \le 10^9$ $(1 \le i \le N)$
- $s_i \ne s_j$ $(1 \le i < j \le N)$
- $t_q \in \{1, 2\}$
- $1 \le x_q \le 10^9$
- $t_q = 1$인 경우, 그 직전에는 $x_q \notin S$임이 보장됩니다.
- $t_q = 2$인 경우, 그 직전에는 $x_q \in S$임이 보장됩니다.

## 출력

$Q$줄에 걸쳐 출력하세요. $q$번째 줄에는 $q$번째 질의를 처리한 직후 $S$의 부분집합 중 **좋은 집합**인 것의 개수를 $998\,244\,353$으로 나눈 나머지를 출력하세요.
