## 문제 설명

문자열 $T$가 다음 조건을 모두 만족하면 $T$를 **좋은 문자열**이라고 합니다.

- 마지막 $5$글자는 `HAPPY`입니다.
- 끝부분 이외에는 연속 부분 문자열로 `HAPPY`가 나타나지 않습니다.

영어 대문자 (`A-Z`)로 이루어진 길이 $N$의 문자열 $S$가 주어집니다. $S$의 한 글자를 골라 다른 문자로 바꾸는 연산을 몇 번이든 할 수 있습니다.

$S$를 **좋은 문자열**로 만드는 데 필요한 연산 횟수의 최솟값을 구하세요.

## 입력

```text
$N$
$S$
```

## 제한

- $5 \leq N \leq 3 \times 10^5$
- $N$은 정수입니다.
- $S$는 영어 대문자 (`A-Z`)로 이루어진 길이 $N$의 문자열입니다.

## 출력

답을 한 줄에 출력하세요.

## 예제

### 예제 1 {file="01_sample_01"}

#### 입력

```text
9
KAGUYABAD
```

#### 출력

```text
4
```

`KAGUHAPPY`로 바꾸면 $4$번의 연산으로 **좋은 문자열**을 만들 수 있습니다.

### 예제 2 {file="01_sample_02"}

#### 입력

```text
10
HAPPYHAPPY
```

#### 출력

```text
1
```

### 예제 3 {file="01_sample_03"}

#### 입력

```text
5
HAPPY
```

#### 출력

```text
0
```
