$\{1,2,\ldots,2^N-1\}$의 부분집합 $S$가 좋다는 것은 서로 다른 부분집합 $U,V\subseteq S$에 대해 $f(U)\ne f(V)$인 것을 뜻합니다. 좋은 집합의 개수를 $998244353$으로 나눈 나머지를 구하세요.

<details>
<summary>$\mathrm{OR}$란? (클릭하여 펼치기)</summary>

$\mathrm{OR}$는 비트별 논리합을 나타냅니다.

</details>

## 입력

```text
N
```

$1\le N\le5000$입니다.

## 출력

좋은 집합의 개수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2
```

#### 출력

```text
5
```

#### 입력

```text
4
```

#### 출력

```text
98
```

#### 입력


#### 출력

```text
457732232
```
