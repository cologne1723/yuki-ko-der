길이 $N$의 수열 $A$가 주어집니다. 다음 조건을 만족하는 정수열 $B=(B_1,\ldots,B_M)$를 생각합니다.

$$1\le B_1<\cdots<B_M\le N,\qquad \sum_{i=1}^{M}A_{B_i}=K$$

## 문제

그러한 $B$가 존재하는지 판정하세요. 없다면 `-1`을, 있다면 어떤 $B$를 골라도 반드시 포함되는 인덱스의 개수를 출력하세요.

## 입력

```text
N K
A_1 A_2 ... A_N
```

$1\le N\le10^4$, $0\le K\le1000$, $0\le A_i\le K$입니다.

## 출력

조건을 만족하는 $B$가 없으면 `-1`, 있으면 필수 인덱스 개수를 출력하세요.
