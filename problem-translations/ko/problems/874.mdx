## 문제

`?`, `*`, 소문자 알파벳으로 이루어진 정규 표현식의 부분집합 문자열 $A$, $B$가 주어집니다.

여기서 `?`는 바로 앞 문자의 0회 또는 1회 반복을, `*`는 바로 앞 문자의 0회 이상 반복을 나타냅니다. 각각의 정규 표현식으로 생성되는 문자열의 집합을 $G_A$, $G_B$라고 합니다. 예를 들어 $A=$ `a?b*`이면 $G_A=\{``, `a`, `b`, `ab`, `bb`, `abb`, `bbb`, `abbb`, \ldots\}$입니다.

소문자 알파벳만으로 이루어진 문자열 $a$, $b$에 대해 편집 거리 $d(a,b)$를, 한 문자의 삽입·삭제·치환으로 $a$를 $b$로 바꾸는 데 필요한 최소 횟수로 정의합니다.

예를 들어 `abcdefgh`와 `zcdefgha`의 편집 거리를 생각해 봅시다. `abcdefgh`에서 `a`를 삭제하고, `b`를 `z`로 치환하고, `a`를 추가하면 `zcdefgha`로 바꿀 수 있으며 이것이 최소 횟수이므로 $d(`abcdefgh`, `zcdefgha`)=3$입니다.

$A$, $B$ 사이의 정규 표현식 간 거리를 $D(A,B)=\min_{(a,b)\in G_A\times G_B}d(a,b)$로 정의합니다. 즉, $A$, $B$로 각각 생성할 수 있는 모든 문자열 쌍 중 편집 거리가 가장 작은 값을 구하세요.

## 입력

~~~text
A
B
~~~

- $A$, $B$는 `?`, `*`, 소문자 알파벳으로 이루어진 문자열입니다.
- `?`와 `*`가 $A$ 또는 $B$ 안에서 연속으로 나타나지 않습니다. 즉, `??`, `?*`, `*?`, `**`를 부분 문자열로 포함하지 않습니다.
- $A$, $B$의 첫 문자는 `?` 또는 `*`가 아닙니다.
- $1 \leq |A| \leq 2000$
- $1 \leq |B| \leq 2000$

## 출력

$D(A,B)$를 한 줄에 출력하세요. 마지막에 줄 바꿈을 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

~~~text
ab?c
abc
~~~

### 출력 1 {file="stdout"}

~~~text
0
~~~

$G_A=\{`ac`, `abc`\}$이고 $G_B=\{`abc`\}$입니다. $d(`ac`,`abc`)=1$, $d(`abc`,`abc`)=0$이므로 0을 출력합니다.

### 입력 2 {file="stdin"}

~~~text
a*bcd
aaaabd?
~~~

### 출력 2 {file="stdout"}

~~~text
1
~~~

예를 들어 $a=$ `aaaabcd`, $b=$ `aaaabd`로 하면 편집 거리가 1이며, 이것이 최솟값입니다.

### 입력 3 {file="stdin"}

~~~text
aaaaabbbaaaaa
a*b?c*
~~~

### 출력 3 {file="stdout"}

~~~text
3
~~~

`b?`의 유혹을 뿌리치고 $b=$ `aaaaaaaaaaaaa`로 하면 편집 거리가 3이며, 이것이 최솟값입니다.

### 입력 4 {file="stdin"}

~~~text
aaaaabbbaaaaa
a*b?a*
~~~

### 출력 4 {file="stdout"}

~~~text
2
~~~

`b?`의 제안을 받아들여 $b=$ `aaaaaabaaaaaa`로 하면 편집 거리가 2이며, 이것이 최솟값입니다.
