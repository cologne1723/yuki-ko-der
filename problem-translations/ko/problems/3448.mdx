## 문제 설명

다음 조건을 모두 만족하는 문자열 $S$를 **좋은 문자열**이라고 합니다. 여기서 $S$의 $i$번째 문자를 $S_i$, $S$의 길이를 $|S|$로 나타냅니다.

- $3\leq |S|$
- $S$는 숫자로만 이루어집니다.
- $S_1$은 `0`이 아닙니다.
- $S_1\neq S_2$
- $S_1\neq S_{|S|}$
- $S_2\neq S_{|S|}$
- $S_2=S_3=\cdots=S_{|S|-1}$

예를 들어 `167`, `93336`, `1000000007`은 **좋은 문자열**입니다. 또한 `1221`, `09991`, `998244353`은 **좋은 문자열이 아닙니다**.

양의 정수 $N$, $K$가 주어집니다.

길이가 $N+2$ 이하인 **좋은 문자열** 중 사전순으로 $K$번째로 작은 문자열을 $U$라고 할 때, $|U|$, $U_1$, $U_2$, $U_{|U|}$를 구하세요. 문제의 제한에 의해 그러한 문자열 $U$가 존재함이 보장됩니다.

$T$개의 테스트 케이스가 주어지므로, 각 테스트 케이스에 대해 답을 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$T$
$case_1$
$case_2$
$\vdots$
$case_T$
```

여기서 $case_i$는 $i$번째 테스트 케이스를 나타내며, 다음 형식으로 주어집니다.

```text
$N\ K$
```

## 제한

- $1\leq T\leq 10^5$
- $1\leq N\leq 2\times 10^9$
- $1\leq K\leq 648N$
- 입력은 모두 정수입니다.

## 출력

$T$줄에 걸쳐 출력하세요.

$i$번째 줄에는 $case_i$에 대한 답을 다음 형식으로 공백으로 구분하여 출력하세요.

```text
$|U|\ U_1\ U_2\ U_{|U|}$
```
