## 문제 설명

kazuppa町에는 $N$개의 지점과 $R$개의 도로가 있습니다. 도로 $i$에서는 지점 $U_i$와 지점 $V_i$ 사이를 양방향으로 이동할 수 있으며, 도보로 이동하는 데는 $W_i$분, 오토마 차량으로 이동하는 데는 $A_i$분, 수동 차량으로 이동하는 데는 $M_i$분이 걸립니다. 도로를 이동할 때는 이외의 교통수단을 사용할 수 없습니다.

또한 kazuppa町은 바다에 접해 있으므로, 각 지점 사이를 배로 이동할 수 있습니다. 지점 $i$에서 지점 $j$로 배를 사용해 이동하는 데는 $S_i+S_j+C$분이 필요합니다.

또한 각 지점에서 면허를 취득할 수 있습니다. 지점 $i$에서 오토마 전용 면허를 취득하는 데는 $X_i$분, 수동 면허를 취득하는 데는 $Y_i$분, 선박 면허를 취득하는 데는 $Z_i$분이 필요합니다.

kazuppa町에서는 소지한 면허에 따라 다음과 같이 교통수단을 사용할 수 있습니다.

- 자동차 면허를 어느 것도 가지고 있지 않은 경우, 도로 이동에는 도보만 사용할 수 있습니다.
- 오토마 전용 면허는 가지고 있지만 수동 면허는 가지고 있지 않은 경우, 도로 이동에는 도보 또는 오토마 차량만 사용할 수 있습니다.
- 수동 면허를 가지고 있는 경우, 도로 이동에는 도보, 오토마 차량, 수동 차량을 모두 사용할 수 있습니다.
- 선박 면허를 가지고 있는 경우에만 배를 사용할 수 있습니다.

Bread君은 처음에 지점 $1$에 있으며, 어떤 면허도 가지고 있지 않습니다. 적절히 행동했을 때 지점 $N$에 도착하는 데 필요한 최소 시간을 구하세요.

## 입력

```text
$N\ R\ C$
$X_1\ X_2\ \dotsc\ X_N$
$Y_1\ Y_2\ \dotsc\ Y_N$
$Z_1\ Z_2\ \dotsc\ Z_N$
$S_1\ S_2\ \dotsc\ S_N$
$U_1\ V_1\ W_1\ A_1\ M_1$
$U_2\ V_2\ W_2\ A_2\ M_2$
$\vdots$
$U_R\ V_R\ W_R\ A_R\ M_R$
```

## 제한

- $1\leq N\leq 30\,000$
- $1\leq R\leq 60\,000$
- $1\leq C\leq 10^{14}$
- $1\leq X_i,Y_i,Z_i\leq 10^9$
- $1\leq S_i\leq 10^{14}$
- $1\leq U_i<V_i\leq N$
- $1\leq W_i,A_i,M_i\leq 10^9$
- 입력은 모두 정수입니다.

부분점이 설정되어 있습니다.

| 부분 문제 | 배점 | 제한 |
| --- | ---: | --- |
| 부분 문제 $1$ | $20$점 | $N=2,\ R=1$ |
| 부분 문제 $2$ | $40$점 | $W_i=A_i=M_i=1,\ C=10^{14}$이며, 지점 $1$에서 도로를 따라 지점 $N$에 도착할 수 있습니다. |
| 부분 문제 $3$ | $50$점 | $W_i=A_i=M_i,\ C=10^{14}$이며, 지점 $1$에서 도로를 따라 지점 $N$에 도착할 수 있습니다. |
| 부분 문제 $4$ | $50$점 | $C=10^{14}$이며, 지점 $1$에서 도로를 따라 지점 $N$에 도착할 수 있습니다. |
| 부분 문제 $5$ | $50$점 | $W_i=A_i=M_i$ |
| 부분 문제 $6$ | $40$점 | 추가 제한 없음 |

## 출력

답을 $1$줄에 출력하세요.

#### 입력

다음과 같이 행동합니다.

- 지점 $1$에서 선박 면허를 취득합니다. $1$분이 걸립니다.
- 지점 $1$에서 지점 $3$으로 도보로 이동합니다. $1$분이 걸립니다.
- 지점 $3$에서 오토마 전용 면허를 취득합니다. $1$분이 걸립니다.
- 지점 $3$에서 지점 $2$로 오토마 차량을 타고 이동합니다. $1$분이 걸립니다.
- 지점 $2$에서 수동 면허를 취득합니다. $1$분이 걸립니다.
- 지점 $2$에서 지점 $4$로 수동 차량을 타고 이동합니다. $1$분이 걸립니다.
- 지점 $4$에서 지점 $5$로 배를 타고 이동합니다. $10+2+1=13$분이 걸립니다.

이때 걸리는 시간은 총 $19$분입니다.

$19$분 미만으로 만들 수 없으므로 $19$를 출력합니다.
