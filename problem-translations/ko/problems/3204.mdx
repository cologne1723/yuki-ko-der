## 문제 설명

양의 정수 $N$이 주어집니다. $N$을 십진법으로 나타냈을 때 각 자리를 재배열하여 얻을 수 있는 정수 중 제곱수가 존재하는지 판정하세요.

존재한다면 그러한 제곱수 중 최솟값을, 존재하지 않는다면 $-1$을 출력하세요.

단, 재배열한 결과의 맨 앞에 불필요한 $0$(leading zero)이 포함되어도 괜찮지만, 출력할 때는 불필요한 $0$을 포함해서는 안 됩니다.

## 입력

```text
$T$
$N_1$
$N_2$
$\vdots$
$N_T$
```

$T$는 테스트 케이스의 수이며, $N_i$는 $i$번째 테스트 케이스에서의 $N$입니다.

## 제한

- $1 \leq T \leq 100\,000$
- $1 \leq N \leq 10^9$
- 입력은 모두 정수입니다.

## 출력

$T$줄 출력하세요. $i$번째 줄에는 $i$번째 테스트 케이스의 답을 출력하세요.

## 예제

### 예제 1 {file="01_sample1.txt"}

#### 입력

```text
6
18
2025
2024
8886519
62506357
4000
```

#### 출력

```text
81
225
-1
9865881
6375625
4
```

$1$번째 테스트 케이스에서 `18`은 `81`로 재배열하면 제곱수가 됩니다.

$2$번째 테스트 케이스에서 `2025`를 재배열하여 제곱수가 되는 것은 `0225`, `2025`입니다. 가장 작은 값은 `0225`가 나타내는 $225$이므로 $225$를 출력하세요.

$3$번째 테스트 케이스에서 `2024`를 재배열하여 제곱수가 되는 것은 존재하지 않으므로 $-1$을 출력하세요.
