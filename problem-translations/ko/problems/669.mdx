## 문제

타케야군은 신주쿠의 추억 골목의 한 야키토리집에서 술 대결을 합니다.

- 가게 주인과 타케야군이 번갈아 술을 마십니다.
- 술 종류는 $N$가지입니다.
- 자기 차례에 한 종류를 골라 1~$K$ml를 마십니다.
- 술을 마실 수 없게 된 사람이 패배합니다.

두 사람 모두 술을 마실 수 없다는 것은 남은 술이 없다는 뜻입니다. 타케야군이 선공하며, 모두 최선의 수를 둔다고 할 때 타케야군이 이기는지 판정하세요.

## 입력

```text
N K
A1 A2 ... AN
```

- $1\le N,K\le1000$
- $0\le A_i\le1000000$

$A_i$는 술 $i$의 초기량(ml)입니다.

## 출력

이기면 YES, 지면 NO를 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3 10
0 0 0
```

출력:

```text
NO
```

처음부터 술이 전혀 없어 패배합니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
5 1
0 0 0 2 0
```

출력:

```text
NO
```

### 샘플 3 {file="sample3.in"}

입력:

```text
2 5
11 13
```

출력:

```text
YES
```

드디어 이겼습니다.

### 샘플 4 {file="sample4.in"}

입력:

```text
4 30
134 12 500 15000
```

출력:

```text
YES
```
