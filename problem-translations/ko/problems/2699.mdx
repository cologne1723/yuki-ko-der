## 문제

`10^N-1`을 `10^M+1`로 나눈 나머지를 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `1 ≤ T ≤ 2 × 10^5`
- 각 테스트 케이스에 대해 `1 ≤ N,M ≤ 10^9`

## 입력

```text
T
N_1 M_1
⋮
N_T M_T
```

## 출력

각 테스트 케이스의 답을 한 줄에 하나씩 출력하세요.
