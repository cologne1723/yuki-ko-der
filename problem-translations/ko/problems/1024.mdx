## 문제 설명

앞에서부터 이 순서로 일렬로 선 $N$명의 아이가 있습니다. 아이에게는 $1, 2, \ldots, N$의 번호가 붙어 있습니다. $M$번의 이동이 이루어집니다. $i$번째($1 \leq i \leq M$) 이동에서는 사람 $a_i$가 사람 $b_i$의 바로 뒤로 이동합니다(사람 $b_i$의 뒤에 사람이 있는 경우에는 그 사이로 끼어듭니다).

각 $i$($1 \leq i \leq M$)에 대해, $M$번의 이동 중 $i$번째 이동만 건너뛰고 나머지 이동을 순서대로 수행했을 때 최종 줄에서 앞에서부터 $k_i$번째 사람의 번호를 구하세요.

## 입력

```text
$N\ M$
$a_1\ b_1\ k_1$
$a_2\ b_2\ k_2$
$\vdots$
$a_M\ b_M\ k_M$
```

## 제한

- $2 \leq N, M \leq 2 \times 10^5$
- $1 \leq a_i, b_i, k_i \leq N$
- $a_i \neq b_i$
- 입력은 모두 정수입니다.

## 출력

$M$개의 줄에 출력하세요. $i$번째 줄($1 \leq i \leq M$)에는 $M$번의 이동 중 $i$번째 이동만 건너뛰고 나머지 이동을 순서대로 수행했을 때 최종 줄에서 앞에서부터 $k_i$번째 사람의 번호를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 3
1 2 3
4 2 1
3 1 4
```

#### 출력

```text
2
2
3
```

- $1$번째 이동을 건너뛰고 $2$, $3$번째 이동만 수행하면 줄은 $(1, 2, 3, 4)\to (1, 2, 4, 3)\to (1, 3, 2, 4)$로 변합니다. 이 최종 줄에서 앞에서부터 $3$번째 사람의 번호는 $2$입니다.
- $2$번째 이동을 건너뛰고 $1$, $3$번째 이동만 수행하면 줄은 $(1, 2, 3, 4)\to (2, 1, 3, 4)\to (2, 1, 3, 4)$로 변합니다. 이 최종 줄에서 앞에서부터 $1$번째 사람의 번호는 $2$입니다.
- $3$번째 이동을 건너뛰고 $1$, $2$번째 이동만 수행하면 줄은 $(1, 2, 3, 4)\to (2, 1, 3, 4)\to (2, 4, 1, 3)$로 변합니다. 이 최종 줄에서 앞에서부터 $4$번째 사람의 번호는 $3$입니다.
