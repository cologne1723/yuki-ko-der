한 자리 양의 정수가 `N`개 있습니다. 정수 `i`는 `c_i`개 있습니다 (`1 <= i <= 9`). 이들을 재배열해 `N`자리 십진수 `M`으로 만들 때, 가능한 모든 `M`의 합을 `10^9+7`로 나눈 나머지를 구하세요.

## 입력

첫째 줄에 `N`, 둘째 줄에 `c_1, c_2, ..., c_9`가 주어집니다.

## 제약

- `1 <= N <= 2 * 10^5`
- `c_i >= 0`, `sum(c_i) = N`
- 입력은 정수입니다.

## 출력

답을 `10^9+7`로 나눈 나머지를 출력하세요.
