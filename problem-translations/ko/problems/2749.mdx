## 문제

피보나치 수를 `F_1=F_2=1`, `F_n=F_{n-1}+F_{n-2}`로 정의합니다. 모든 양의 정수 `k`에 대해 `F_k`가 `N`의 배수인 것과 `k`가 어떤 정수 `m`의 배수인 것이 동치가 되도록 하는 유일한 양의 정수 `m=a(N)`을 구하세요.

## 제약

- `1 ≤ N ≤ 400`

## 입력

```text
N
```

## 출력

`a(N)`을 출력하세요.
