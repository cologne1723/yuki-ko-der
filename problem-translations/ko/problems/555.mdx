## 문제

addeight는 고등학생입니다.

지금 세계사 보고서를 컴퓨터로 작성하고 있습니다.

하지만 세계사를 어려워해서 보고서에는 아직 알파벳 A만 적혀 있습니다.

보고서에 N글자 이상 쓰지 않으면 무서운 세계사 선생님에게 혼나게 됩니다.

그래서 addeight는 복사와 붙여넣기만으로 N글자 이상의 문자열을 만들기로 했습니다.

복사하면 보고서의 모든 문자열이 클립보드에 복사되고, 붙여넣기하면 보고서 문자열 뒤에 클립보드 문자열이 추가됩니다.

복사와 붙여넣기에는 각각 C,V의 비용이 듭니다. N글자 이상 만드는 최소 비용을 구하세요.

클립보드의 초기 상태는 빈 문자열입니다.

## 입력

```text
N
C V
```

2 ≤ N ≤ 50000

1 ≤ C,V ≤ 1000

## 출력

N글자 이상 만드는 데 필요한 최소 비용을 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
6
3 2
```

출력:

```text
12
```

| 조작 | 보고서 문자열 | 클립보드 문자열 |
| --- | --- | --- |
| 시작 상태 | A |  |
| 복사 | A | A |
| 붙여넣기 | AA | A |
| 복사 | AA | AA |
| 붙여넣기 | AAAA | AA |
| 붙여넣기 | AAAAAA | AA |

복사를 2번, 붙여넣기를 3번 했으므로 총 비용은 12입니다. 복사, 붙여넣기, 붙여넣기, 복사, 붙여넣기 순서로도 비용 12에 6글자를 만들 수 있습니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
10
1 3
```

출력:

```text
15
```

복사, 붙여넣기, 복사, 붙여넣기, 복사, 붙여넣기, 붙여넣기를 하면 비용 15로 12글자를 만들 수 있습니다. 비용 15로 10글자 이상 만드는 방법은 이 외에도 있습니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
100
1000 1
```

출력:

```text
1099
```

복사한 뒤 붙여넣기를 99번 합니다.
