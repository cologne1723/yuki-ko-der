같은 길이의 양의 정수 수열 `A,B` 중, 모든 원소가 `1` 이상 `N` 이하이고 각각 엄격히 증가하며 `sum |A_i-B_i|=M`인 쌍의 개수를 구하세요.

## 제약

- `1 <= N <= 5000`
- `1 <= M <= 1000`

## 입력

`N M`이 주어집니다.

## 출력

답을 `998244353`으로 나눈 나머지를 출력하세요.
