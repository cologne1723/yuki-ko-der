## 문제

수직선 위의 `N`개 좌표 `X_1,...,X_N`이 주어집니다. 각 질의 `(l,r,x)`에 대해 다음 값을 구하세요.

\[
\min(|X_l-x|,|X_{l+1}-x|,\ldots,|X_r-x|)
\]

## 입력

`N`, 좌표 수열, `Q`, 그리고 `Q`개의 `l_i r_i x_i`가 주어집니다.

`1\le N\le3\times10^5`, `1\le Q\le10^5`, `1\le X_i,x_i\le10^9`이며 모든 `X_i`는 서로 다릅니다.

## 출력

각 질의의 답을 한 줄에 출력하세요.
