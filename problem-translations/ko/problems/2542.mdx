길이 $L$인 양갱에 $N$개의 절단선이 있습니다. 홀수 개 $k$개의 절단선을 골라 양갱을 $k+1$개의 조각으로 나누고, 홀수 번호 조각은 A가, 짝수 번호 조각은 B가 가집니다. $|A-B|$의 최솟값을 구하세요.

## 조건

- $2\le L\le10^5$, $1\le N\le100$
- $0<X_1<\cdots<X_N<L$

## 입력

```text
L N
X1 X2 ... XN
```

## 출력

$|A-B|$의 최솟값을 출력하세요.
