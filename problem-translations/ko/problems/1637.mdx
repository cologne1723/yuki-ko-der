정점 `1`을 루트로 하는 `N`개 정점의 트리가 주어집니다. 모든 정점의 비용은 처음에 0입니다.

각 질의에서 정점 `p_j`를 루트로 하는 서브트리의 모든 정점 비용에 `x_j`를 더한 뒤, 전체 정점 비용의 합을 출력하세요.

## 제약

- `2 <= N,Q <= 10^5`
- `1 <= a_i,b_i,p_j <= N`
- `1 <= x_j <= 10^8`
- 주어지는 그래프는 트리입니다.

## 입력

트리의 간선 `a_i b_i`와 질의 `p_j x_j`가 주어집니다.

## 출력

각 질의 후 전체 비용의 합을 한 줄에 하나씩 출력하세요.
