## 문제 설명

**이 문제는 반응형 형식(채점기 측 프로그램과 대화하며 실행해야 하는 형식)의 문제입니다.**

**格子点大好きbot**은 **격자점**(좌표가 정수인 점)을 아주 좋아하는 봇입니다.

**格子点大好きbot**은 수직선 위의 **격자점**에 있으며, 그 좌표 $X$를 비밀로 하고 있습니다.

$X$를 알아내기 위해 다음과 같은 일련의 대화(이하 질문이라고 합니다)를 $0$회 이상 $2$회 이하의 원하는 횟수만큼 진행합니다.

1. 먼저 $-10^3 \leq x \leq 10^3$을 만족하는 정수 $x$를 고르고, 수직선 위에서 $x$와 $X$ 사이의 거리 $|x-X|$를 묻습니다.
2. 이어서 **格子点大好きbot**이 $|x-X|$를 대답합니다.

그 후 $X$를 구하세요.

## 입력

먼저 $0$회 이상 $2$회 이하의 원하는 횟수만큼 질문하세요. 질문은 표준 입출력을 사용하여 다음 형식으로 진행합니다.

1. 먼저 `?`와 $-10^3 \leq x \leq 10^3$을 만족하는 정수 $x$를 반각 공백으로 구분하여 $1$줄에 출력하세요.

```text
$?\ x$
```

2. 이어서 $|x-X|$가 $1$줄에 주어집니다.

```text
$|x-X|$
```

## 제한

$X$는 입력으로 주어지지 않지만, 다음 제한을 만족합니다.

- $X$는 모든 질문을 하기 전에 고정됩니다. 즉, 질문 전후로 변하지 않습니다.
- $X$는 $-10^3 \leq X \leq 10^3$을 만족하는 정수입니다.

입력은 다음 제한을 만족합니다.

- $-10^3 \leq x \leq 10^3$을 만족하는 임의의 정수 $x$에 대해 $x$와 $X$ 사이의 거리를 물었을 때의 답인 입력 $|x-X|$는 $0 \leq |x-X| \leq 2 \times 10^3$을 만족하는 정수입니다.

## 출력

다음 형식으로 이 문제의 답을 표준 출력에 출력하세요.

- `!`와 $X$를 반각 공백으로 구분하여 $1$줄에 출력하세요.

```text
$!\ X$
```

마지막에 개행을 출력하세요.

반응형 형식의 문제에 익숙하지 않다면 [반응형 형식 문제에 대한 정리](https://yukicoder.me/wiki/reactive)도 참고하세요.

이 문제에서 다음 지시를 따르지 않은 제출의 채점 결과는 보장하지 않습니다.

- 출력은 지정된 형식을 엄격하게 따라야 합니다. 예를 들어 불필요한 공백을 넣지 마세요.
- 출력할 때마다 끝에 개행을 넣고 표준 출력을 flush하세요.
- 이 문제의 답을 출력한 후에는 프로그램을 즉시 종료하세요.

## 예제

### 예제 1 {file=""}

$X=1$인 상황에서의 대화 예시입니다.

#### 출력

```text
? 1
```

수직선 위에서 $1$과 $X$ 사이의 거리 $|1-X|$를 물었습니다.

#### 입력

```text
0
```

**格子点大好きbot**은 $|1-X|=0$이라고 대답했습니다.

#### 출력

```text
! 1
```

$X=1$이라고 답했습니다. 이는 정답입니다.

질문은 최대 $2$회까지 할 수 있지만, 이처럼 $1$회만 질문하고 답해도 됩니다.
