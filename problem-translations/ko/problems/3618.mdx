## 문제 설명

고양이 $N$마리가 $1$줄로 늘어서 있습니다. 왼쪽에서 $i$번째 고양이는 왼쪽에서 $i$번째 위치에 있으며, 키는 $H_i$입니다. 모든 고양이의 키는 서로 다르다고 보장됩니다.

여러분은 이 고양이 중 몇 마리를 선택하여 키를 바꿀 수 있습니다. 키를 바꾼 뒤 고양이의 키는 음이 아닌 임의의 실숫값이 될 수 있습니다.

고양이의 키를 바꾼 뒤 다음 조건을 만족하게 하려 할 때, 고양이의 키를 최소 몇 번 바꾸어야 하는지 구하세요.

- 어떤 정수 $(x,y,z)$가 존재하여 다음 조건을 모두 만족합니다.
  - $1 < x < y < z < N$
  - $1 \leq i < x$를 만족하는 모든 $i$에 대하여 $H_i > H_{i+1}$
  - $x \leq i < y$를 만족하는 모든 $i$에 대하여 $H_i < H_{i+1}$
  - $y \leq i < z$를 만족하는 모든 $i$에 대하여 $H_i > H_{i+1}$
  - $z \leq i < N$을 만족하는 모든 $i$에 대하여 $H_i < H_{i+1}$

$T$개의 테스트 케이스가 주어지므로, 각각에 대한 답을 구하세요.

## 입력

```text
$T$
$\text{case}_1$
$\text{case}_2$
$\vdots$
$\text{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$H_1\ H_2\ \ldots\ H_N$
```

## 제한

- $1 \leq T \leq 4\times 10^4$
- $5 \leq N \leq 2\times 10^5$
- $1 \leq H_i \leq 10^9\ (1 \leq i \leq N)$
- $H_i \neq H_j\ (i \neq j)$
- 모든 테스트 케이스에서 $N$의 합은 $2\times 10^5$ 이하입니다.
- 입력은 모두 정수입니다.

이 문제에는 서브태스크에 의한 부분 점수가 설정되어 있습니다.

| 서브태스크 이름 | 배점 | 제한 |
| --- | ---: | --- |
| 서브태스크 $1$ | $70$점 | $N=5$ |
| 서브태스크 $2$ | $70$점 | $T\leq 50,\ N\leq 8$ |
| 서브태스크 $3$ | $140$점 | $N\leq 7\,000$, 모든 테스트 케이스에서 $N$의 합은 $7\,000$ 이하 |
| 서브태스크 $4$ | $70$점 | 추가 제한 없음 |

## 출력

$T$줄 출력하세요.

$i$번째 줄에는 $i$번째 테스트 케이스에 대한 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
7
9 3 4 2 7 6 1
9
9342 314 159 256 2718 1024 1414 169 231
```

#### 출력

```text
2
1
```

$1$번째 테스트 케이스를 생각해 봅시다.

예를 들어, $5$번째 원소를 $4$로, $7$번째 원소를 $6.1$로 바꾼 $(9,3,4,2,4,6,6.1)$은 $(x,y,z)=(2,3,4)$로 문제문의 조건을 만족합니다.

문제문의 조건을 $2$번 미만의 변경으로 만족할 수 없으므로 답은 $2$입니다.
