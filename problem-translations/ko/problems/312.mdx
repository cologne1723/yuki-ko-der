## 문제

초보 프로그래머인 신입 군은 프로그램에 다음 두 종류의 주석을 작성하고 있습니다.

- 연속한 `#` 2개 뒤에 주석이 적혀 있는 일반 주석 (예: `## 주석`)
- 연속한 `#` $N$개로 작성된 프로그램 구분 주석 (예: `#########` ($N=9$))

상사인 당신은 구분 주석이 불필요하므로 삭제하라고 신입 군을 지도해야 합니다. 신입 군은 이미 구분 주석을 많이 작성했기 때문에 하나씩 손으로 삭제하는 것은 비효율적입니다. 따라서 치환 기능으로 구분 주석을 제거하기로 했습니다.

치환 기능은 지정한 문자열을 별도로 지정한 문자열로 바꾸는 기능입니다. 이번에는 연속한 `#` 여러 개로 이루어진 문자열을 빈 문자열(길이 0인 문자열)로 바꾸어 구분 주석을 제거합니다.

낭비를 싫어하는 당신은 치환할 때 $N$개의 `#`를 모두 쓰지 않아도 구분 주석을 빈 문자열로 만들 수 있는 경우가 있다는 것을 알아챘습니다. 예를 들어 구분 주석이 `#########`($#` 9개)로 이루어져 있다면 `###`($#` 3개)를 빈 문자열로 치환하여 구분 주석을 완전히 삭제할 수 있습니다.

일반 주석은 삭제하지 않으면서 구분 주석을 완전히 삭제하는 치환을 할 때, 작성해야 하는 `#`의 개수의 최솟값을 구하세요.

단, 치환은 한 번만 할 수 있습니다. 여러 번으로 나누어 치환할 수 없습니다.

## 입력

```text
N
```

$N$은 $3$ 이상 $10^{12}$ 이하의 정수입니다.

## 출력

일반 주석을 삭제하지 않고 구분 주석을 완전히 삭제하는 치환에 작성해야 하는 `#`의 최솟값을 개행과 함께 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
9
```

### 샘플 1 {file="sample1.out"}

```text
3
```

문제 설명의 예입니다. `#` 3개마다 빈 문자열로 치환하면 일반 주석을 삭제하지 않고 구분 주석을 모두 삭제할 수 있습니다.

### 샘플 2 {file="sample2.in"}

```text
30
```

### 샘플 2 {file="sample2.out"}

```text
3
```

`#` 2개마다 빈 문자열로 치환해도 구분 주석을 모두 삭제할 수 있지만, 일반 주석도 삭제되므로 2개마다 치환할 수 없습니다.

### 샘플 3 {file="sample3.in"}

```text
114514
```

### 샘플 3 {file="sample3.out"}

```text
31
```

### 샘플 4 {file="sample4.in"}

```text
8573912969
```

### 샘플 4 {file="sample4.out"}

```text
421
```
