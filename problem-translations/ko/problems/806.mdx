## 문제

umg 군은 $N$개 정점의 무방향 나무를 가지고 있습니다. 간선 $(a_i,b_i)$를 $(a_i,c_i)$로 바꾸는 조작을 할 수 있습니다. 이때 서로 다른 세 정점 $u,v,w$를 골라 간선 $(u,v)$를 $(u,w)$로 바꿉니다.

이 조작을 몇 번 수행해 나무를 경로로 만들려고 합니다. 경로란 차수가 1인 정점이 정확히 두 개인 무방향 나무입니다. 필요한 최소 조작 횟수를 구하세요.

## 입력

~~~text
$N$
$a_1\ b_1$
$\vdots$
$a_{N-1}\ b_{N-1}$
~~~

$3\leq N\leq10^5$이며 주어지는 그래프는 나무입니다. $1\leq a_i,b_i\leq N$이고 간선은 서로 다릅니다.

## 출력

정답을 한 줄에 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
4
1 2
1 3
1 4
~~~

#### 출력

~~~text
1
~~~

간선 (2,1)을 (2,4)로 바꾸면 됩니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
3
1 2
2 3
~~~

#### 출력

~~~text
0
~~~

처음부터 경로이므로 조작할 필요가 없습니다.
