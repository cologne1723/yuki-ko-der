**주의: 이 문제는 실행 시간 제한이 매우 엄격하게 설정되어 있습니다.**

## 문제 설명

$H$행 $W$열의 정수로 이루어진 표 $A$가 주어집니다.

각 행 $i (1 \leq i \leq H)$의 체크섬 $S_i$를

$S_i = \left(\sum_{j=1}^{W} A_{i,j}\right) \bmod 2^{32}$

로 정의합니다. 또한 데이터 전체의 체크섬 $T$를

$T = \left(\sum_{i=1}^{H} S_i\right) \bmod 2^{32}$

로 정의합니다.

각 행 $i (1 \leq i \leq H)$에 대해 검증 코드 $C_i$를

$C_i = (S_i+T) \bmod 2^{32}$

로 정의합니다. $C_1,C_2,\ldots,C_H$를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$H\ W$
$A_{1,1}\ A_{1,2}\ \ldots\ A_{1,W}$
$A_{2,1}\ A_{2,2}\ \ldots\ A_{2,W}$
$\vdots$
$A_{H,1}\ A_{H,2}\ \ldots\ A_{H,W}$
```

## 제한

- $1\leq H\leq 10^6$
- $1\leq W$
- $HW\leq 4\times 10^6$
- $0\leq A_{i,j}<10^9$
- 입력되는 값은 모두 정수입니다.

## 출력

$C_1,C_2,\ldots,C_H$를 이 순서대로, $1$줄에 $1$개씩 십진 표기의 음이 아닌 정수로 출력하세요.

출력 마지막에 개행을 넣으세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2
1 2
3 4
5 6
```

#### 출력

```text
24
28
32
```

각 행의 체크섬은 차례대로 $3,7,11$이고 $T=21$입니다. 따라서 검증 코드는 차례대로 $24,28,32$가 됩니다.

### 예제 2 {file=""}

#### 입력

```text
2 5
900000000 900000000 900000000 900000000 900000000
999999999 0 1 999999998 500000000
```

#### 출력

```text
2910065406
910065404
```

$1$번째 행의 합은 $4\,500\,000\,000$이므로 $S_1=205\,032\,704$입니다. 또한 $S_2=2\,499\,999\,998$이므로 $T=2\,705\,032\,702$입니다. 따라서 $C_1=2\,910\,065\,406$, $C_2=910\,065\,404$가 됩니다.

### 예제 3 {file=""}

#### 입력

```text
4 3
0 1 2
999999999 999999998 999999997
400000000 400000000 400000000
123456789 987654321 42
```

#### 출력

```text
1016143856
4016143847
2216143853
2127255005
```

각 행의 체크섬은 차례대로 $3,2\,999\,999\,994,1\,200\,000\,000,1\,111\,111\,152$입니다. 이들의 합을 $2^{32}$로 나눈 나머지는 $1\,016\,143\,853$이므로 $T=1\,016\,143\,853$입니다.
