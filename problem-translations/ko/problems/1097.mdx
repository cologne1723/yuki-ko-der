## 문제 설명

정수 $X$가 있습니다. $X$의 초기값은 $0$입니다. 또한, 길이가 $N$인 수열 $A_0,A_1,\cdots,A_{N-1}$이 주어집니다.

이제 다음 연산을 반복해서 수행합니다.

연산: $X$를 $N$으로 나눈 나머지를 계산하여 $r$이라고 합니다. $X$에 $A_r$을 더합니다.

$Q$개의 질의가 주어집니다. 각 질의에서 양의 정수 $K$가 주어지므로, $K$번째 연산을 수행한 후의 $X$의 값을 구하세요.

## 입력

```text
$N$
$A_0\ A_1\ \cdots\ A_{N-1}$
$Q$
$K_1$
$K_2$
$\vdots$
$K_Q$
```

입력은 다음 제한을 만족합니다.

## 제한

- 입력은 모두 정수입니다.
- $1 \leq N \leq 10^5$
- $1 \leq A_i \leq 10^6$ ($0 \leq i < N$)
- $1 \leq Q \leq 10^5$
- $1 \leq K_i \leq 10^{12}$ ($1 \leq i \leq Q$)

## 출력

$Q$줄 출력하세요.

$i$번째 줄($1 \leq i \leq Q$)에는 $K_i$번째 연산을 수행한 후의 $X$의 값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
3 3 2 4 7
2
2
4
```

#### 출력

```text
7
16
```

첫 번째 연산에서는 $r=0$이므로 $X=0+A_0=0+3=3$이 됩니다.

두 번째 연산에서는 $r=3$이므로 $X=3+A_3=3+4=7$이 됩니다.

세 번째 연산에서는 $r=2$이므로 $X=7+A_2=7+2=9$가 됩니다.

네 번째 연산에서는 $r=4$이므로 $X=9+A_4=9+7=16$이 됩니다.

따라서 두 번째와 네 번째 연산을 수행한 후의 $X$의 값은 각각 $7$, $16$이므로, $7$과 $16$을 출력합니다.
