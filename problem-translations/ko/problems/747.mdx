## 문제

$\frac27=0.285714285714\ldots$는 285714가 영원히 반복되는 순환소수입니다. $\frac27$의 소수점 이하 $N^K$번째 자리를 구하세요.

## 입력

~~~text
$N$
$K$
~~~

$1\leq N\leq10^{100000}$인 정수 $N$과 $1\leq K\leq10^{100000}$인 정수 $K$가 각각 한 줄에 주어집니다.

## 출력

$\frac27$의 소수점 이하 $N^K$번째 자리를 출력하세요. 마지막에는 줄바꿈을 추가하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
2
3
~~~

#### 출력

~~~text
8
~~~

$\frac27$의 소수점 이하 $2^3=8$번째 자리는 8입니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
3
2
~~~

#### 출력

~~~text
5
~~~

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
9999
9999
~~~

#### 출력

~~~text
5
~~~

### 샘플 4 {file="sample4.in"}

#### 입력

~~~text
314159265358979323846264338327950
28841971693993751058209749445
~~~

#### 출력

~~~text
8
~~~
