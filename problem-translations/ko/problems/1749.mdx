`N`개 도시와 양방향 도로가 있습니다. 0일에 도시 0에서 감염자 1명이 발생하고, 각 도시의 `i`일 감염자 수는 인접 도시들의 `i-1`일 감염자 수 합입니다.

`T`일의 도시 0 감염자 수를 `998244353`으로 나눈 나머지를 구하세요.

## 입력

`N M T`와 도로 정보가 주어집니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 3 2
0 1
0 2
1 2
```

#### 출력

```text
2
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 4
0 3
1 3

0 4

```

#### 출력

```text
22
```


#### 출력

```text
0
```
