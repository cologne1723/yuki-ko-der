양의 유리수 $u=p/q$를 나타내는 서로소 양의 정수쌍을 $(p(u),q(u))$라 합니다. 서로소인 $2\le P<Q$가 주어질 때 $1\le q(L),q(R)<Q$이고 $0<L<P/Q<R$인 유리수쌍 중 $R-L$이 최소인 $(L,R)$를 찾습니다.

## 문제

$p(L)+q(L)+p(R)+q(R)$를 구하세요.

## 입력

```text
P Q
```

$2\le P<Q\le10^9$이고 서로소입니다.

## 출력

답을 출력하세요.
