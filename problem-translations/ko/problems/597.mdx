## 문제

N개의 문자열이 주어집니다. 이를 순서대로 이어 붙인 문자열을 출력하세요.

## 입력

```text
N
S1
S2
…
SN
```

1 ≤ N ≤ 10

1 ≤ |Si| ≤ 20

Si는 a-z로만 이루어집니다.

## 출력

S1S2…를 이어 붙인 문자열을 출력하세요. 사이에 공백 등을 넣지 마세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
2
con
cat
```

출력:

```text
concat
```

### 샘플 2 {file="sample2.in"}

입력:

```text
3
servalcat
sandcat
margaycat
```

출력:

```text
servalcatsandcatmargaycat
```

### 샘플 3 {file="sample3.in"}

입력:

```text
4
ko
un
ko
un
```

출력:

```text
kounkoun
```

행운을 빕니다.
