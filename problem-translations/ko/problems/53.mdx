## 문제 설명

다음 점화식으로 정의되는 수열 $\{A_k\}_{k=0}^{\infty}$의 $N$번째 항 $A_N$을 구하세요.

$A_0=4$

$A_1=3$

$4A_k=19A_{k-1}-12A_{k-2}$ $(k \ge 2)$

(참고: 트릭이 필요한 문제입니다.)

## 입력

```text
$N$
```

구할 항의 번호 $N$이 주어집니다.

## 제한

$0 \le N \le 100$

## 출력

$A_N$의 값을 한 줄에 출력하세요. 절대 오차 또는 상대 오차가 $10^{-9}$ 이하이면 정답으로 인정합니다.
답의 절댓값 $|A_N|$은 $10^{50}$을 초과하지 않습니다. 출력 후 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0
```

#### 출력

```text
4.00000000
```

### 예제 2 {file=""}

#### 입력

```text
4
```

#### 출력

1.265625
