문자열 $A$로 시작하는 가장 짧은 팰린드롬을 하나 출력하라냥. 가능한 답이 여러 개면 아무거나 출력해도 된다냥.

## 조건

- $1\le|A|\le100$
- $A$는 영문 소문자로 이루어진다냥.

## 입력

```text
A
```

## 출력

조건을 만족하는 팰린드롬을 출력하라냥.
