## 문제

각 여행자는 여러 도시를 방문하고, 방문한 도시들의 집 수를 모두 XOR한 값을 보고했습니다. 모든 보고와 일치하는 도시별 집 수를 하나 구성하세요.

각 `X_i`는 `0\le X_i<2^{30}`입니다. 모순이 있으면 `-1`을 출력하세요.

## 입력

`N M`과 각 여행자의 방문 도시 목록 및 XOR 값이 주어집니다.

## 출력

조건을 만족하는 수열 또는 `-1`을 출력하세요.
