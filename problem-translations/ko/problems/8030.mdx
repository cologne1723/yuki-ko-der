## 문제 설명

주어진 $n$개의 양의 정수 각각에 대해 소수인지 판정하세요.

## 입력

입력은 표준 입력에서 다음 형식으로 주어집니다.

```text
$n$
$x_0$
$x_1$
$\vdots$
$x_{n-1}$
```

$1$번째 줄에는 질의의 개수 $n$이 주어집니다.

$2$번째 줄부터 $n$개의 소수 판정 대상인 양의 정수가 주어집니다. 각 줄에 정수 $1$개가 주어집니다.

## 제한

- $n$은 양의 정수입니다.
- $1 \leq n \leq 10\,000$입니다.
- $1 \leq x_i < 2^{63}$입니다. ($64$비트 부호 있는 정수에 들어갑니다.)

## 출력

각 양의 정수에 대해 그 값과 소수인지 여부를 반각 공백으로 구분하여 입력 순서를 유지한 채 출력하고, 줄바꿈하세요. 소수라면 $1$, 소수가 아니라면 $0$을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
10
2
1
5
```

#### 출력

```text
10 0
2 1
1 0
5 1
```

$1$번째 줄이 $4$이므로 $4$개의 양의 정수에 대해 소수 판정을 수행합니다. $10$과 $1$은 소수가 아니므로 수 자체와 공백에 이어 $0$을 출력합니다. $2$와 $5$는 소수이므로 $1$을 출력하세요.
