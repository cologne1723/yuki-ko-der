$\mathrm{shift}(x)=\lfloor x/2\rfloor+2^{15}(x\bmod2)$로 정의합니다. 원하는 횟수만큼 $A_i$를 각각 `shift` 값으로 바꿀 수 있을 때, 최종 $A_1\mathbin{\mathrm{OR}}\cdots\mathbin{\mathrm{OR}}A_N$의 최댓값을 구하세요.

## 입력

```text
N
A_1 A_2 ... A_N
```

$1\le N\le2\times10^5$, $1\le A_i<2^{16}$입니다.

## 출력

최댓값을 출력하세요.
