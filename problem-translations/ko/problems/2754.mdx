## 문제

수열을 누적합으로 바꾼 뒤 첫 항을 버리는 작업을 길이가 1이 될 때까지 반복합니다. 마지막 남은 항을 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `1 ≤ N ≤ 2×10^5`
- `0 ≤ A_i < 998244353`

## 입력

```text
N
A_1 A_2 ... A_N
```

## 출력

답을 출력하세요.
