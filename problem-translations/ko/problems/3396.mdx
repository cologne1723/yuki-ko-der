제약에 비해 실행 시간 및 사용 메모리 제한이 엄격하게 설정되어 있습니다.

예상 풀이를 구현한 제출($40$~$60$줄 / $1\,000$~$1\,300$바이트 정도)의 실행 시간과 실행 시 사용 메모리 양은 다음과 같습니다.

C++: $1\,145$ms / $7\,720$KB, C#(csc): $1\,757$ms / $28\,800$KB, PyPy: $1\,723$ms / $77\,800$KB입니다.

특히 Python 등의 인터프리터형 언어에서는 사용 메모리 제한이 매우 엄격합니다. 양해해 주세요.

## 문제 설명

정수열 $M$, $R$이 있으며, 처음에는 $2$개의 수열 모두 비어 있습니다. $Q$개의 쿼리를 처리하세요. 쿼리는 다음 $3$가지 중 $1$가지입니다.

- 추가 쿼리 $1\ m\ r$: $M$의 뒤에 $m$을, $R$의 뒤에 $r$을 각각 추가합니다.
- 삭제 쿼리 $2\ k$: $M$, $R$ 각각의 뒤에서 $k$개의 원소를 삭제합니다.
- 출력 쿼리 $3\ m$: $M=(M_1,M_2,\dots,M_n)$, $R=(R_1,R_2,\dots,R_n)$이라 합니다. 모든 $i=1,2,\dots,n$에 대해 $X\bmod M_i=R_i$를 만족하는 음이 아닌 정수 $X$가 존재한다면, 그러한 $X$ 중 최솟값을 $m$으로 나눈 나머지를 출력합니다. 특히 $M$, $R$이 비어 있다면 $0$을 출력합니다. 그러한 $X$가 존재하지 않는다면 $-1$을 출력합니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$Q$
$\mathrm{query}_1$
$\mathrm{query}_2$
$\ \vdots$
$\mathrm{query}_Q$
```

$\mathrm{query}_i$는 $i$번째 쿼리를 나타내며, 다음 $3$가지 형식 중 $1$가지입니다.

```text
$1\ m\ r$
```

```text
$2\ k$
```

이 쿼리가 주어질 때 $2$개의 수열 $M$, $R$의 길이는 모두 $k$ 이상입니다.

```text
$3\ m$
```

## 제한

- $Q$는 $1$ 이상 $10^4$ 이하의 정수입니다.
- 추가 쿼리의 $m$, $r$은 $0\leq r\lt m\leq 10^9$를 만족하는 정수입니다.
- 삭제 쿼리의 $k$는 양의 정수입니다.
- 출력 쿼리의 $m$은 $1$ 이상 $10^9$ 이하의 정수입니다.

## 출력

각 쿼리에 대한 답을 줄 바꿈으로 구분하여 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
10
1 3 2
1 5 3
1 7 2
3 100
1 10 7
3 1
2 2
1 10 8
1 21 5
3 1225
```

#### 출력

```text
23
-1
68
```

$1$번째 출력 쿼리의 조건은 $X\bmod 3=2$, $X\bmod 5=3$, $X\bmod 7=2$이며, 이를 만족하는 최소의 음이 아닌 정수 $X$는 $X=23$입니다.

$2$번째 출력 쿼리의 조건은 $X\bmod 3=2$, $X\bmod 5=3$, $X\bmod 7=2$, $X\bmod 10=7$이며, 이를 만족하는 음이 아닌 정수 $X$는 존재하지 않습니다.

$3$번째 출력 쿼리의 조건은 $X\bmod 3=2$, $X\bmod 5=3$, $X\bmod 10=8$, $X\bmod 21=5$이며, 이를 만족하는 최소의 음이 아닌 정수 $X$는 $X=68$입니다.
