## 문제 설명

수열 $a_1, a_2, \dots, a_N$이 있습니다.

$S_i = \sum_{j = i}^{i + K - 1} a_j = a_i + a_{i+1} + \dots + a_{i + K - 1}$로 정의하고, **다중**(추가)집합 $S = \{S_1, S_2, \dots, S_{N-K + 1}\}$을 정의합니다.

이때 $l(1 \le l \le Q)$번째 질의에서는 $x_l$ 이하인 $S$의 원소 개수를 출력하세요.

다르게 말하면, $S_1, S_2, \dots, S_{N - K + 1}$ 중 $x_l$ 이하인 것의 개수를 출력하세요.

## 입력

```text
$N\ K$
$a_1\ a_2\ \dots\ a_N$
$Q$
$x_1$
$x_2$
$\dots$
$x_Q$
```

## 제한

$1 \le N, Q \le 10^5$

$-10^4 \le a_i \le 10^4$

$1 \le K \le N$

$-10^9 \le x_l \le 10^9$

입력은 모두 정수입니다.

## 출력

$Q$개의 답을 줄바꿈으로 구분하여 $Q$줄에 걸쳐 출력하세요. 마지막에 줄바꿈을 출력하세요.
