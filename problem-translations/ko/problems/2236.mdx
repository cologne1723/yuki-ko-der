연결되지 않을 수도 있는 단순 무향 그래프의 정점이 흰색 또는 검은색으로 칠해져 있다냥. 간선을 골라 양 끝 정점의 색을 반전하는 조작으로 모든 정점을 흰색으로 만들 수 있는지 판정하고, 가능하면 최소 조작 횟수를 구하라냥.

## 조건

- $2\le N\le40$
- $1\le M\le\min(N(N-1)/2,40)$

## 입력

```text
N M
a_1 b_1
\vdots
a_M b_M
c_1 \cdots c_N
```

## 출력

가능하면 최소 횟수를, 불가능하면 $-1$을 출력하라냥.
