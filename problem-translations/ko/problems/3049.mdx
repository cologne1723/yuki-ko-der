## 이야기

대회를 개최할 때 난이도 역전이나 난이도 절벽이 적은 문제 세트를 만들고 싶습니다.

## 문제 설명

길이 $N$인 양의 정수 수열 $D=(D_1,D_2,\ldots,D_N)$과 음이 아닌 정수 $T$, 양의 정수 $X,Y$가 주어집니다.

$T,X,Y$에 대해 길이 $k$인 수열 $A=(A_1,A_2,\ldots,A_k)$의 **불만도** $f(A)$를 다음과 같이 정의합니다.

### **$f(A)$의 정의**

정수 $i\in\{1,2,\ldots,k-1\}$ 중 $A_{i+1}-A_i>T$를 만족하는 정수의 개수를 $p$, $A_{i+1}-A_i<0$을 만족하는 정수의 개수를 $q$라고 하면, 불만도 $f(A)$를 다음과 같이 정의합니다.

$f(A)=pX+qY$

모든 $k=1,2,\ldots,N$에 대해 다음 **문제** $k$를 해결하세요.

### **문제 $k$**

$D$에서 원소를 $k$개 선택하고 임의의 순서로 배열해 얻는 길이 $k$ 수열의 **불만도**의 최솟값을 구하세요.

더 형식적으로는 $\displaystyle\min_{I\in\mathcal{I}_{N,k}}f(D[I])$를 구하세요. 여기서 $\mathcal{I}_{N,k}$는 다음 조건을 모두 만족하는 길이 $k$ 정수 수열 $I=(I_1,I_2,\ldots,I_k)$ 전체의 집합이며, $D[I]=(D_{I_1},D_{I_2},\ldots,D_{I_k})$입니다.

- 모든 $i\in\{1,2,\ldots,k\}$에 대해 $I_i\in\{1,2,\ldots,N\}$입니다.
- 모든 $i,j\in\{1,2,\ldots,k\}$에 대해 $i\neq j$이면 $I_i\neq I_j$입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

$1$번째 줄에 $N$, $T$, $X$, $Y$가 공백으로 구분되어 주어지고, $2$번째 줄에 $D_1,D_2,\ldots,D_N$이 공백으로 구분되어 주어집니다.

```text
$N\ T\ X\ Y$
$D_1\ D_2\ \cdots\ D_N$
```

입력은 모두 정수입니다.

## 제한

- $1\leq N\leq 5\times 10^5$
- $0\leq T\leq 10^9$
- $1\leq X,Y\leq 10^9$
- $1\leq D_i\leq 10^9$

## 출력

**문제** $k$의 답을 $S_k$라고 할 때, $S_1,S_2,\ldots,S_N$을 이 순서대로 공백으로 구분하여 $1$줄에 출력하고 줄바꿈하세요.

```text
$S_1\ S_2\ \cdots\ S_N$
```

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2 1 2
1 7 5
```

#### 출력

```text
0 0 1
```

이 입력은 $N=3$, $T=2$, $X=1$, $Y=2$, $D=(1,7,5)$를 나타냅니다.

- $k=1$일 때 가능한 수열은 $(1)$, $(7)$, $(5)$의 $3$개이며, 어느 수열의 불만도도 $0$입니다. 따라서 $k=1$의 답은 $0$입니다.
- $k=2$일 때 가능한 수열은 $(1,7)$, $(7,1)$, $(1,5)$, $(5,1)$, $(7,5)$, $(5,7)$의 $6$개입니다. 각 불만도는 다음과 같으므로 $k=2$의 답은 $0$입니다.
  - $(1,7)$, $(1,5)$는 $p=1$, $q=0$이므로 불만도는 $1$입니다.
  - $(7,1)$, $(5,1)$, $(7,5)$는 $p=0$, $q=1$이므로 불만도는 $2$입니다.
  - $(5,7)$은 $p=0$, $q=0$이므로 불만도는 $0$입니다.
- $k=3$일 때 가능한 수열은 $(1,7,5)$, $(7,1,5)$, $(1,5,7)$, $(5,1,7)$, $(7,5,1)$, $(5,7,1)$의 $6$개입니다. 각 불만도는 다음과 같으므로 $k=3$의 답은 $1$입니다.
  - $(1,7,5)$, $(7,1,5)$, $(5,1,7)$은 $p=1$, $q=1$이므로 불만도는 $3$입니다.
  - $(1,5,7)$은 $p=1$, $q=0$이므로 불만도는 $1$입니다.
  - $(5,7,1)$은 $p=0$, $q=1$이므로 불만도는 $2$입니다.
  - $(7,5,1)$은 $p=0$, $q=2$이므로 불만도는 $4$입니다.

### 예제 2 {file=""}

#### 입력

```text
5 4 3 2
1 1 1 1 1
```

#### 출력

```text
0 0 0 0 0
```

어떻게 선택하더라도 항상 불만도는 $0$입니다. 값이 같은 원소라도 인덱스가 다르면 여러 개 선택할 수 있습니다.
