## 문제 설명

物理好き君은 스탬프 랠리에 참가하려고 합니다.

$1$번부터 $N$번까지 번호가 붙은 $N$개의 장소에는 각각 다른 스탬프가 설치되어 있습니다. 그중 서로 다른 스탬프를 $M$개 이상 모으면 경품을 받을 권리를 얻습니다. 단, 경품을 받을 수 있는 장소는 $K$개의 장소 $A_1, \dots, A_K$뿐입니다.

장소 $i$에서 장소 $j$로 이동하는 데에는 $T_{i,j}$만큼 시간이 걸립니다.

$T_{i,j}$는 다음 $3$가지 조건을 만족합니다.

- $T_{i,i}=0\ (1 \leq i \leq N)$
- $1 \leq T_{i,j} \leq 10^5\ (1 \leq i,j \leq N,\ i \ne j)$
- $T_{i,j} \leq T_{i,k}+T_{k,j}\ (1 \leq i,j,k \leq N)$

스탬프 랠리를 시작할 장소를 자유롭게 선택할 수 있을 때, 경품을 받을 때까지 걸리는 시간의 최솟값을 구하세요.

스탬프 랠리를 시작한 장소와 경품을 받는 장소에서도 스탬프를 찍을 수 있습니다.

또한 이동에 걸리는 시간만 고려하면 되며, 스탬프를 찍는 시간과 경품을 받는 데 걸리는 시간은 무시할 수 있습니다.

## 입력

```text
$N\ M\ K$
$A_1\ \dots\ A_K$
$T_{1,1}\ \dots\ T_{1,N}$
$\vdots$
$T_{N,1}\ \dots\ T_{N,N}$
```

## 제한

- 입력은 모두 정수입니다.
- $1 \leq N \leq 16$
- $1 \leq M \leq \min(N,5)$
- $1 \leq K \leq N$
- $1 \leq A_1 < A_2 < \dots < A_K \leq N$
- $T_{i,i}=0\ (1 \leq i \leq N)$
- $1 \leq T_{i,j} \leq 10^5\ (1 \leq i,j \leq N,\ i \ne j)$
- $T_{i,j} \leq T_{i,k}+T_{k,j}\ (1 \leq i,j,k \leq N)$

## 출력

경품을 받을 때까지 걸리는 시간의 최솟값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2 1
3
0 1 1
1 0 1
1 1 0
```

#### 출력

```text
1
```

예를 들어 장소 $2$에서 스탬프 랠리를 시작하고 장소 $2$에서 장소 $3$으로 이동하면 스탬프를 $2$개 모을 수 있으며, 장소 $3$에서 경품을 받을 수 있습니다.

이때 경품을 받을 때까지 걸리는 시간은 $1$입니다.

스탬프 랠리를 시작한 장소와 경품을 받는 장소에서도 스탬프를 모을 수 있다는 점에 주의하세요.

경품을 받을 때까지 걸리는 시간을 $1$ 미만으로 만들 수 없으므로 $1$을 출력합니다.

장소 $1$에서 스탬프 랠리를 시작하면 이동하지 않고 경품을 받을 수 있습니다.
