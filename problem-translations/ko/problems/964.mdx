## 문제 설명

예를 들어 `2020`은 $2$종류의 숫자를 각각 $2$개씩 사용하여 만든 수입니다.

$N$이 주어집니다.

$N$종류의 숫자를 각각 $N$개씩 사용하여 수를 만드세요.

단, `0`으로 시작하는 수는 인정하지 않습니다.

주의: 숫자는 `0`부터 `9`까지의 $10$종류입니다.

## 입력

```text
$N$
```

$N$은 양의 정수입니다.

## 제한

$1 \le N \le 10$

## 출력

답이 여러 개라면 그중 하나를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
1
```

`0`은 오답입니다. 주의하세요.

### 예제 2 {file=""}

#### 입력

```text
2
```

#### 출력

```text
2020
```
