## 문제

문자열 S가 주어집니다. S에 575가 포함되면 YES, 포함되지 않으면 NO를 출력하세요.

575가 포함된다는 것은 S의 부분 문자열 Ssub가 “575”가 되는 것이 존재한다는 뜻입니다.

## 입력

```text
S
```

1 ≤ |S| ≤ 100

S는 영숫자 a-z, A-Z, 0-9만으로 이루어집니다.

## 출력

S에 575가 포함되면 YES, 포함되지 않으면 NO를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
a575z
```

출력:

```text
YES
```

a575z

### 샘플 2 {file="sample2.in"}

입력:

```text
57Z5
```

출력:

```text
NO
```

57과 5 사이가 떨어져 있으므로 안 됩니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
5757575
```

출력:

```text
YES
```

여러 개 있어도 괜찮습니다.

### 샘플 4 {file="sample4.in"}

입력:

```text
0x1BF52
```

출력:

```text
NO
```

수상한 16진수이므로 안 됩니다.

### 샘플 5 {file="sample5.in"}

입력:

```text
MD5374d5502ef19c061204c2651c7f19f9b
```

출력:

```text
NO
```

해시값을 계산해 주는 사이트가 멋대로 사전에 등록해 두기도 해서 조금 무섭죠.
