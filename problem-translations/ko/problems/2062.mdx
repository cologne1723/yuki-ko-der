비어 있지 않은 부분집합 $S$에 대해 $f(S)=(\sum_{i\in S}A_i)\bmod999630629$로 정의합니다. 모든 비어 있지 않은 부분집합에 대한 $f(S)$의 합을 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
N
A_1 A_2 ... A_N
```

$1\le N\le10^5$, $1\le A_i\le10^4$입니다.

## 출력

요구한 합을 출력하세요.

## 예제

```text
3 5
```

#### 출력

```text
16
```

1
