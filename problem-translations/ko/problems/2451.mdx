길이 $N$의 정수열 $A$가 있습니다. 한 번의 연산에서 하나의 원소에서 $N-1$을 빼고 나머지 모든 원소에 1을 더합니다. 연산을 0회 이상 수행해 모든 원소를 같게 만들 수 있는지 판정하세요.

## 조건

- $2\le N\le5\times10^5$
- $-10^9\le A_i\le10^9$

## 입력

```text
N
A1 A2 ... AN
```

## 출력

가능하면 `Yes`, 불가능하면 `No`를 출력하세요.
