## 문제 설명

영문 문자열 $S$, $T$가 주어집니다.

$S$와 $T$는 첫 글자가 반드시 대문자입니다.

$S$의 첫 글자를 $F$, $T$의 첫 글자를 $L$이라고 할 때, $F.L.$ 형식으로 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$S$
$T$
```

## 제한

- $1 \leq |S|, |T| \leq 30$
- $S$, $T$는 영문 문자열입니다.
- $S$, $T$의 첫 글자는 영문 대문자입니다.

여기서 $|S|$, $|T|$는 각각 문자열 $S$, $T$의 길이를 나타냅니다.

## 출력

$S$의 첫 글자를 $F$, $T$의 첫 글자를 $L$이라고 할 때, $F.L.$ 형식으로 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
Taro
Tanaka
```

#### 출력

```text
T.T.
```

`Taro`의 첫 글자 `T`와 `Tanaka`의 첫 글자 `T`를 점으로 연결하여 `T.T.`로 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
Ruby
Python
```

#### 출력

```text
R.P.
```

### 예제 3 {file=""}

#### 입력

```text
A
Z
```

#### 출력

```text
A.Z.
```

문자열의 길이가 $1$인 경우에도 같은 방식으로 첫 글자를 가져와 출력합니다.
