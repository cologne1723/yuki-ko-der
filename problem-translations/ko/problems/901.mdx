## 문제 설명

niuez의 마을에 사는 사람들은 최근 ‘세 나무 공물’에 싫증이 나기 시작했습니다. 요즘은 ‘$K$ 나무(일본어로 케이크와 발음이 같습니다)’가 유행한다고 합니다.

$0$번부터 $N-1$번까지 번호가 붙은 정점 $N$개와 간선 $N-1$개로 이루어진 무방향 트리가 있습니다. $i$번 간선은 $u_i$번 정점과 $v_i$번 정점을 양 끝점으로 하며, 가중치는 $w_i$입니다. $0 \le i < N-1$입니다.

다음 형식의 쿼리 $Q$개를 처리하세요. $i$번 쿼리의 형식은 다음과 같습니다. $0 \le i < Q$입니다.

$k_i\ x_0\ x_1\ \cdots\ x_{k_i-1}$

서로 다른 정점 $k_i$개인 $x_0$번, $x_1$번, $\ldots$, $x_{k_i-1}$번 정점을 모두 포함하는 트리의 연결 부분 그래프 중 정점 수가 최소인 것을 고르고, 그 부분 그래프에 포함된 간선의 가중치 합을 구하세요.

(출제자 공지) 2019/10/4 21:44 잘못된 용어를 수정했습니다.

이러한 트리의 부분 그래프가 유일하게 정해진다는 것을 증명할 수 있습니다.

## 입력

```text
$N$
$u_0\ v_0\ w_0$
$\vdots$
$u_{N-2}\ v_{N-2}\ w_{N-2}$
$Q$
$\mathrm{query}_0$
$\vdots$
$\mathrm{query}_{Q-1}$
```

$\mathrm{query}_i$는 위에서 설명한 $i$번 쿼리이며, 한 줄에 주어집니다. $0 \le i < Q$입니다.

각 쿼리의 입력 형식은 다음과 같습니다.

```text
$k_i\ x_0\ x_1\ \cdots\ x_{k_i-1}$
```

## 제한

- $2 \le N \le 10^5$
- $0 \le u_i, v_i < N$, $u_i \ne v_i$ ($0 \le i < N-1$)
- $(u_i, v_i) = (u_j, v_j) \Leftrightarrow i = j$ ($0 \le i, j < N-1$)
- $0 \le w_i \le 10^5$ ($0 \le i < N-1$)
- $1 \le Q \le 10^5$
- $1 \le \sum_{i=0}^{Q-1} k_i \le 10^5$
- 입력은 모두 정수입니다.

각 $i$번 쿼리는 다음 조건을 만족합니다. $0 \le i < Q$입니다.

- $1 \le k_i \le N$
- $0 \le x_j < N$ ($0 \le j < k_i$)
- $x_0, x_1, \ldots, x_{k_i-1}$은 서로 다릅니다.

## 출력

$Q$줄에 걸쳐 각 쿼리의 답을 입력된 순서대로 한 줄에 정수 하나씩 출력하세요.
