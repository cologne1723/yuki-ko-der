## 문제

Alice는 덧셈과 뺄셈을 할 때 기호를 반대로 해석합니다. 예를 들어 Alice에게 $5+3$은 $5-3$으로, $5-3$은 $5+3$으로 계산됩니다.

두 정수 $x$, $y$와 연산자 하나로 이루어진 식이 주어질 때, Alice가 계산한 결과를 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다. 입력에는 공백이 없습니다.

```text
x op y
```

여기서 $x$, $y$는 정수이고, $op$는 `+` 또는 `-`입니다. $x$, $y$는 각각 $-10000$ 이상 $10000$ 이하이며, 양의 수에는 `+` 기호가 붙을 수 있고 음의 수에는 `-` 기호가 붙습니다. $+0$, $-0$, $0$도 입력으로 주어질 수 있습니다.

## 출력

Alice가 계산한 결과를 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

```text
5+3
```

### 출력 1 {file="stdout"}

```text
2
```

### 입력 2 {file="stdin"}

```text
10-20
```

### 출력 2 {file="stdout"}

```text
30
```

### 입력 3 {file="stdin"}

```text
-2+-3
```

### 출력 3 {file="stdout"}

```text
1
```
