## 문제 설명

보통 사람은 문자열 `x+y`를 $x+y$로, 문자열 `x-y`를 $x-y$로 해석합니다. 그런데 アリス는 덧셈과 뺄셈을 할 때 기호를 반대로 해석합니다. 즉, 문자열 `x+y`를 $x-y$로, 문자열 `x-y`를 $x+y$로 해석합니다.

$2$개의 정수 $x$, $y$와 연산자 $1$개로 이루어진 식이 주어질 때, アリス가 계산한 결과를 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다. 입력에는 공백이 없습니다.

```text
$x op y$
```

여기서 $x$, $y$는 정수이고, $op$는 `+` 또는 `-`입니다. $x$, $y$의 앞에는 부호가 붙을 수 있습니다.

정수가 $0$이면 `+0`, `-0`, `0`의 $3$가지 입력이 가능합니다. 정수가 $1$이면 `+1`, `1`의 $2$가지 입력이 가능하며, 정수가 $-1$이면 `-1`의 $1$가지 입력이 가능합니다.

## 제한

- $-10\,000 \le x \le 10\,000$
- $-10\,000 \le y \le 10\,000$

## 출력

アリス가 계산한 결과를 $1$줄에 출력하세요. 마지막에 줄바꿈을 하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5+3
```

#### 출력

```text
2
```

입력은 `5+3`이지만, $5-3$의 계산 결과인 $2$를 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
10-20
```

#### 출력

```text
30
```

### 예제 3 {file=""}

#### 입력

```text
-2+-3
```

#### 출력

```text
1
```

입력의 $x,y$에는 부호가 포함될 수 있습니다.
