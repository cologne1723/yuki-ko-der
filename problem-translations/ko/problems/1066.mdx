## 문제 설명

상자가 $N$개 있습니다. $i$번 상자($1 le i le N$)에는 공이 $A_i$개 들어 있습니다.

더 구체적으로, $i$번 상자에는 색 $1$부터 색 $A_i$까지의 모든 색 공이 하나씩 들어 있습니다.

각 상자에서 공을 하나씩 꺼냈을 때, 색 $1$인 공이 $B_i$개 포함되는 경우의 수를 $998244353$으로 나눈 나머지를 출력하세요. 이 작업을 $Q$개의 질의에 대해 수행합니다. $i$번째 질의($1 le i le Q$)에서 요구하는 값은 $B_i$에 대한 경우의 수입니다.

## 입력

```text
$N\ Q$
$A_1\ A_2\ ...\ A_N$
$B_1\ B_2\ ...\ B_Q$
```

## 제한

$1 \le N \le 6\,000$

$1 \le Q \le N+1$

$1 \le A_i \le 2 \times 10^5$ ($1 \le i \le N$)

$0 \le B_i \le N$ ($1 \le i \le Q$)

입력은 모두 정수입니다.

## 출력

$Q$개의 질의에 대한 답을 출력하고, 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 4
3 4 5
0 1 2 3
```

#### 출력

```text
24
26
9
1
```

공을 꺼내는 방법은 모두 $60$가지입니다. 그중 색 $1$인 공이 하나도 포함되지 않는 방법은 $24$가지입니다.


#### 출력

```text
6
8
1
```

