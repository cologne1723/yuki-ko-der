**※ 이 문제는 A 문제를 완전히 포함합니다. 이 문제를 맞힌 코드를 A 문제에 제출하면 A 문제도 맞힐 수 있습니다.**

## 문제 설명

양의 정수 $N,M$이 주어집니다.

$N$ 이하의 양의 정수 $a$와 $M$ 이하의 양의 정수 $b$의 모든 쌍에 대한 $a$와 $b$의 최소공배수의 합을 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

```text
$N\ M$
```

## 제한

- $N,M$은 $1$ 이상 **$3\times10^7$** 이하의 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 3
```

#### 출력

```text
16
```

$lcm(1,1)+lcm(1,2)+lcm(1,3)+lcm(2,1)+lcm(2,2)+lcm(2,3)=1+2+3+2+2+6=16$입니다.

### 예제 2 {file=""}

#### 입력

```text
31 13
```

#### 출력

```text
34342
```

### 예제 3 {file=""}

#### 입력

```text
30000000 30000000
```

#### 출력

```text
973741238
```

$998\,244\,353$으로 나눈 나머지를 출력해야 한다는 점에 주의하세요.
