## 문제

양의 정수 `N`의 약수 중 하나를 번갈아 선언합니다. 이미 선언된 수는 선언할 수 없습니다. 먼저 `N`을 선언한 사람이 패배합니다. 두 사람이 최선의 전략을 사용할 때 누가 이기는지 판정하세요.

## 제약

- `1 ≤ T ≤ 1000`
- `1 ≤ N ≤ 1000`

## 입력

```text
T
N_1
⋮
N_T
```

## 출력

각 테스트 케이스에서 코어가 이기면 `K`, 파체가 이기면 `P`를 출력하세요.
