## 문제

알려지지 않은 비트 $B[0..N-1]$에 대해 1의 개수가 $K$ 이상이면 $a[N]=1$, 아니면 0이 되도록 연산을 구성하세요. 사용할 수 있는 연산은 상수 대입 `UPD`, AND, XOR입니다.

모든 입력 비트에 대해 올바른 결과를 내는 연산열을 출력해야 하며, 연산 수는 10000 이하입니다.

## 입력

$N,K$, 테스트 케이스 수와 각 테스트 케이스의 비트열이 주어집니다.

## 출력

문제의 형식에 맞는 연산열을 출력하세요.
