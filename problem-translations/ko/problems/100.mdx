## 문제 설명

$N$개의 세로선과 인접한 세로선을 가로로 잇는 가로선으로 이루어진 아미다쿠지를 생각합시다.

완전히 같은 모양의 아미다쿠지 2개를 위아래로 연결한 것을 “직렬 아미다쿠지”라고 합니다.

아미다쿠지의 출발점과 도착점의 대응이 주어질 때, 그 대응을 만족하는 직렬 아미다쿠지가 존재하는지 판정하세요.

## 입력

```text
N
a_1 ... a_N
```

첫째 줄에 세로선의 수를 나타내는 $N$이 주어집니다. $(2 \le N \le 50)$

둘째 줄에 출발점과 도착점의 대응을 나타내는 $a_i$가 공백으로 주어집니다. $(1 \le a_i \le N)$

이는 왼쪽에서 $i$번째 세로선에서 출발하면 왼쪽에서 $a_i$번째 세로선에 도착한다는 뜻입니다. $a_1,\ldots,a_N$은 모두 서로 다릅니다.

## 출력

출발점과 도착점의 대응을 만족하는 직렬 아미다쿠지가 존재하면 `Yes`, 존재하지 않으면 `No`를 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

```text
2
1 2
```

```text
Yes
```

그림과 같은 직렬 아미다쿠지가 존재합니다.

### 예제 2 {file=""}

```text
3
2 3 1
```

```text
Yes
```

그림과 같은 직렬 아미다쿠지가 존재합니다.

### 예제 3 {file=""}

```text
2
2 1
```

```text
No
```
