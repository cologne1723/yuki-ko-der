## 문제 설명

정점이 $N$개인 루트 트리가 있습니다.

루트 트리의 정점에는 $1$부터 $N$까지 번호가 붙어 있고, 루트는 정점 $1$입니다. 또한, $i$번 간선($1 \leq i < N$)은 정점 $v_i$와 정점 $w_i$를 양방향으로 연결합니다.

$k=1,2,\cdots,N$에 대하여 다음 문제를 해결하세요.

트리의 두 정점의 순서 있는 쌍 $(v,w)$ 중 최근 공통 조상(LCA)이 정점 $k$인 쌍의 개수를 구하세요.

## 입력

```text
$N$
$v_1\ w_1$
$v_2\ w_2$
$\vdots$
$v_{N-1}\ w_{N-1}$
```

입력은 다음 제한을 만족합니다.

## 제한

- 입력은 모두 정수입니다.
- $1 \leq N \leq 2\times10^5$
- $1 \leq v_i,w_i \leq N$ ($1 \leq i < N$)
- 주어진 그래프는 트리입니다.

## 출력

$N$줄 출력하세요.

$i$번째 줄($1 \leq i \leq N$)에는 $k=i$일 때의 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 2
1 3
```

#### 출력

```text
7
1
1
```

정점 $v$와 정점 $w$의 LCA가 정점 $1$이 되는 $(v,w)$의 쌍은 $(1,1)$, $(1,2)$, $(1,3)$, $(2,1)$, $(2,3)$, $(3,1)$, $(3,2)$의 $7$개입니다.

정점 $v$와 정점 $w$의 LCA가 정점 $2$가 되는 $(v,w)$의 쌍은 $(2,2)$ 하나뿐입니다.

정점 $v$와 정점 $w$의 LCA가 정점 $3$이 되는 $(v,w)$의 쌍은 $(3,3)$ 하나뿐입니다.

따라서 $k=1,2,3$에 대한 답은 각각 $7,1,1$입니다.
