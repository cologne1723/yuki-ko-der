## 문제

$1$부터 $N$까지의 순열 $P$가 주어집니다. $|P_i-P_j|\leq1$인 두 위치의 값을 교환하는 작업을 원하는 만큼 할 수 있습니다.

순열을 오름차순으로 만들 수 있는지 판정하고, 가능하면 최소 작업 횟수를 구하세요.

## 입력

$N$과 순열 $P$가 주어집니다.

## 출력

가능하면 최소 횟수를, 불가능하면 $-1$을 출력하세요.
