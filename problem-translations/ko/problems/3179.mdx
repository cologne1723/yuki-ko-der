## 문제 설명

$N$ 이하의 비음이 아닌 정수 중에서, $P$로 나눈 나머지가 $A$이고 $Q$로 나눈 나머지가 $B$이며 $R$로 나눈 나머지가 $C$인 정수는 몇 개인지 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$P\ Q\ R$
$A\ B\ C$
```

$N$, $P$, $Q$, $R$, $A$, $B$, $C$는 정수입니다. $N$은 구간의 상한이고, $P$, $Q$, $R$은 나눗셈의 제수이며, $A$, $B$, $C$는 각각의 나머지입니다.

## 제한

- $0 \leq N \leq 10^{18}$
- $1 \leq P,Q,R \leq 10^6$
- $P$와 $Q$는 서로소입니다.
- $Q$와 $R$는 서로소입니다.
- $R$와 $P$는 서로소입니다.
- $0 \leq A < P$
- $0 \leq B < Q$
- $0 \leq C < R$
- 입력으로 주어지는 값은 모두 정수입니다.

## 출력

답을 출력하세요. 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
71
2 3 5
0 1 2
```

#### 출력

```text
2
```

$3$개의 나머지 조건을 만족하는 수는 $22$, $52$, $82$, $\ldots$입니다. 이 중 $N(=71)$ 이하인 수는 $22$, $52$의 $2$개이므로 $2$를 출력합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
2005
1 1 1
0 0 0
```

#### 출력

```text
2006
```

$1$과 $1$은 서로소라는 점에 주의하세요. 또한 $0$이 조건을 만족하는 수가 될 수 있다는 점에도 주의하세요.
