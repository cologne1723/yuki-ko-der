## 공지

C++와 비슷한 정도의 속도를 내는 언어를 사용하는 것을 권장합니다.

## 문제 설명

길이가 $N$인 양의 정수열 $A$가 주어지며, $A$의 $i$번째 원소는 $A_i$입니다.

$Q$개의 질의가 주어지므로 각각의 답을 구하세요.

질의 $i$에서는 $1 \leq L_i < R_i \leq N$을 만족하는 $2$개의 정수 $L_i$, $R_i$와 양의 정수 $X_i$, 그리고 `L` 또는 `R` 중 $1$개인 문자 $c_i$가 주어집니다.

수직선이 있고, $L_i \leq j \leq R_i$를 만족하는 각각의 정수 $j$에 대해 좌표 $A_j$에 점 $j$가 있다고 합시다.

수직선 위의 점을 좌표가 오름차순이 되도록 정렬한 열을 $B_1, B_2, \cdots, B_{R_i-L_i+1}$이라고 합니다.

열 $B$에 대해 $C_j = B_{j+1}-B_j$로 정의되는 길이 $R_i-L_i$의 열 $C$를 만듭니다.

$c_i$가 `L`이면 $C$의 원소 중 $X_i$ 이하인 것 가운데 최댓값을, `R`이면 $C$의 원소 중 $X_i$ 이상인 것 가운데 최솟값을 구하세요. 그런 원소가 존재하지 않는다면 그 사실을 보고하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ Q$
$A_1\ A_2\ \cdots\ A_N$
$Query_1$
$\vdots$
$Query_Q$
```

여기서 $Query_i$는 질의 $i$를 나타내며, 각각 다음 형식으로 주어집니다.

```text
$L_i\ R_i\ X_i\ c_i$
```

## 제한

- $N$, $Q$, $A_i$는 정수입니다.
- $2 \leq N \leq 10^5$
- $1 \leq Q \leq 10^5$
- $1 \leq A_i \leq 10^7$
- 질의 $i$에 대해 다음 조건을 만족합니다.
  - $L_i$, $R_i$, $X_i$는 정수입니다.
  - $c_i$는 `L` 또는 `R`입니다.
  - $1 \leq L_i < R_i \leq N$
  - $1 \leq X_i \leq 10^7$

## 출력

$Q$줄에 걸쳐 출력하세요. $i$번째 줄에는 질의 $i$의 답으로, 구하는 값이 존재한다면 그 값을, 존재하지 않는다면 $-1$을 출력하고 줄바꿈하세요.
