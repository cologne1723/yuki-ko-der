## 문제 설명

Rating 가위바위보는 다음 규칙으로 진행하는 게임입니다.

- 두 사람이 각각 독립적으로 바위, 가위, 보 중 하나를 냅니다.
- 두 사람의 `Rating`이 다르면 `Rating`이 높은 사람을 승자로 합니다.
- 두 사람의 `Rating`이 같고 낸 손이 다르면 일반적인 가위바위보의 승자를 승자로 합니다.
- 두 사람의 `Rating`과 낸 손이 모두 같으면 무승부입니다.

null 군의 `Rating` $A$와 가위바위보의 손 $B$, tRue 군의 `Rating` $C$와 가위바위보의 손 $D$가 주어집니다. 승자를 출력하세요. 무승부라면 `Draw`를 출력하세요.

가위바위보의 규칙은 일반적인 규칙을 따릅니다.

## 제한

- $0 \leq A,C \leq 4\,000$
- $0 \leq B,D \leq 2$
- $B,D$는 각각 $0$이면 바위, $1$이면 가위, $2$이면 보를 나타냅니다.
- 입력은 모두 정수입니다.

## 입력

```text
$A\ B\ C\ D$
```

## 출력

승자를 출력하세요. 구체적으로 `null`, `tRue`, `Draw` 중 하나를 출력하세요.

마지막에 줄바꿈을 넣으세요.
