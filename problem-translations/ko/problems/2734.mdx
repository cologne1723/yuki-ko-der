## 문제

정수 `A_1,...,A_N`이 있습니다. 순열 `P`를 고른 뒤 순서대로 `x ← 10^{d(A_{P_i})}x + A_{P_i}`를 적용합니다. 여기서 `d(y)`는 십진수 자릿수입니다. 최종 `x`로 가능한 최솟값을 구하고, 그 값을 `998244353`으로 나눈 나머지를 출력하세요.

## 제약

- `1 ≤ N ≤ 2×10^5`
- `1 ≤ A_i ≤ 10^18`

## 입력

```text
N
A_1 A_2 ... A_N
```

## 출력

최솟값의 나머지를 출력하세요.
