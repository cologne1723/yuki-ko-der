`N`명의 사람이 줄을 서 있고 `K`일 동안 파티를 합니다. 매일 각 사람은 독립적으로 떠날지 남을지 선택하며, 떠나기로 한 사람 중 양옆 어느 쪽에도 남기로 한 사람이 없는 사람은 집을 떠납니다.

모든 파티가 두 명 이상으로 진행되면 성공도는 사람 `i`의 참가 일수 `D_i`에 대해 `sum A_i^{D_i}`이고, 하루라도 참가자가 한 명 이하이면 성공도는 0입니다.

가능한 모든 선택 방법에 대한 성공도의 합을 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `2 <= N <= 10^5`
- `1 <= K <= 14`
- `1 <= A_i < 998244353`

## 입력

`N K`와 `A_1,...,A_N`이 주어집니다.

## 출력

답을 `998244353`으로 나눈 나머지를 출력하세요.
