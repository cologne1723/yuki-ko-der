## 문제 설명

$N$행 $N$열의 바둑판이 있고, $i$행 $j$열째 칸을 $(i, j)$로 나타냅니다. 처음에는 모든 칸이 빈칸입니다.

이제 다음 조건을 모두 만족하도록 바둑판의 칸에 돌을 놓으려고 합니다.

- 돌이 놓인 칸은 모두 연결되어 있습니다(*1).
- 돌이 놓인 칸은 정확히 $K$개입니다.
- 돌이 놓인 칸과 상하좌우로 인접한 빈칸은 정확히 $K$개입니다.

이와 같이 돌을 놓는 방법이 존재하는지 판정하고, 존재한다면 그 방법을 $1$가지 출력하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답하세요.

*1. 돌이 놓인 $2$개의 칸 $(i, j)$, $(i', j')$가 연결되어 있다는 것은 다음 조건을 만족한다는 뜻입니다.

- 칸 $(i, j)$에서 상하좌우로 인접한 돌이 놓인 칸으로 이동하는 동작을 반복하여 칸 $(i', j')$에 도달할 수 있습니다.

돌이 놓인 칸이 모두 연결되어 있다는 것은 임의의 돌이 놓인 칸의 쌍이 연결되어 있다는 뜻입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $\mathrm{case}_t\ (1 \leq t \leq T)$는 $t$번째 테스트 케이스를 나타냅니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ K$
```

## 제한

- $1 \leq T$
- 각 테스트 케이스에 대해 다음 조건을 모두 만족합니다.
  - $2 \leq N \leq 500$
  - $1 \leq K \leq N^2$
- $1$개의 입력 파일에서 $N^2$의 합은 $5\times 10^5$를 넘지 않습니다.
- 입력은 모두 정수입니다.

## 출력

$T$개의 테스트 케이스에 대한 답을 번호 순서대로 줄바꿈으로 구분하여 출력하세요.

각 테스트 케이스에 대해 문제의 조건을 만족하는 돌 배치가 존재한다면 `Yes`를, 존재하지 않는다면 `No`를 출력하세요.

또한 `Yes`인 경우 줄을 바꾼 뒤 돌 배치를 다음 형식으로 출력하세요.

```text
$C_{1, 1}\ C_{1, 2}\ \ldots\ C_{1, N}$
$C_{2, 1}\ C_{2, 2}\ \ldots\ C_{2, N}$
$\vdots$
$C_{N, 1}\ C_{N, 2}\ \ldots\ C_{N, N}$
```

여기서 $C_{i, j} (1 \leq i, j \leq N)$는 $(i, j)$ 칸에 돌이 놓여 있으면 `#`, 그렇지 않으면 `.`입니다.

문제의 조건을 만족하는 돌 배치가 여러 개라면 그중 어느 것이든 출력해도 정답으로 판정됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
5 10
9 1
```

#### 출력

```text
Yes
.....
#####
#####
.....
.....
No
```

$1$번째 테스트 케이스에서 출력 예시의 배치는 조건을 만족합니다. 그 이유는 다음과 같습니다.

- 돌이 놓인 칸은 모두 연결되어 있습니다.
- 돌이 놓인 칸의 개수와 돌이 놓인 칸에 상하좌우로 인접한 빈칸의 개수가 모두 $K = 10$입니다.

$2$번째 테스트 케이스에서는 조건을 만족하는 돌 배치가 존재하지 않습니다.
