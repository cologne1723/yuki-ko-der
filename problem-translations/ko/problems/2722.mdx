## 문제

연못 위에 `1,...,N+1`번 발판이 있습니다. 두 사람이 발판 `N+1`에서 시작해 번갈아 다음 행동을 합니다. `1 ≤ i ≤ N`을 고르고 `N+1`에서 `i`로 이동한 뒤, 현재 위치에 `i`를 계속 더하며 `min(x,N+1)`로 이동합니다. 마지막에 발판 `i`를 원격으로 파괴합니다.

행동 시작 시 발판 1만 파괴되지 않은 상태이거나, 이동 목적지가 이미 파괴된 발판이면 그 행동을 한 사람이 패배합니다. 최선의 전략에서 코어가 이기는지 파체가 이기는지 판정하세요.

## 제약

- `1 ≤ T ≤ 10^5`
- `1 ≤ N ≤ 10^12`

## 입력

```text
T
N_1
⋮
N_T
```

## 출력

코어가 이기면 `K`, 파체가 이기면 `P`를 각 줄에 출력하세요.
