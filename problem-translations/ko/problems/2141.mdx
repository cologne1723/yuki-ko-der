길이가 $N$이고 합이 $M$인 음이 아닌 정수열 $A$를 생각하자냥. $A$에 대해 다음 값을 $f(A)$라고 하자냥. 번호가 붙은 $N$개의 상자와 $M$개의 공이 있고, 각 상자 $i$에 공을 $A_i$개 넣는 방법의 수를 $f(A)$로 정의한다냥. $f(A)$의 최댓값을 구하고 $998244353$으로 나눈 나머지를 출력하라냥.

## 조건

- $1\le N,M\le10^6$

## 입력

```text
N M
```

## 출력

최댓값을 $998244353$으로 나눈 나머지를 출력하라냥.

예제는 원문을 참고하라냥.
