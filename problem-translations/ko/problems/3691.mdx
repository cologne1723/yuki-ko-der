## 문제 설명

양의 정수 $N$이 주어집니다.

$1$ 이상 $N$ 이하인 모든 정수 $k$에 대한 $\mu(k)$의 합을 구하세요.

### 배경

양의 정수 $N$에 대해 $\mu(N)$의 값은 다음과 같이 정의됩니다.

- $N=1$일 때, $\mu(N)=1$입니다.
- $N$이 어떤 소수의 제곱으로 나누어떨어질 때, $\mu(N)=0$입니다.
- $N$이 서로 다른 $K$개의 소수의 곱과 같을 때, $\mu(N)=(-1)^K$입니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- $N$은 $1$ 이상 $10^7$ 이하의 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
6
```

#### 출력

```text
-1
```

$\mu(1)+\mu(2)+\mu(3)+\mu(4)+\mu(5)+\mu(6)=1-1-1+0-1+1=-1$입니다.
