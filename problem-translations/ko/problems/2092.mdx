넓게 감소하는 수열 $A_1,\ldots,A_N$이 주어집니다. 위에서 $i$번째 행에 정사각형 $A_i$개를 놓아 만든 영 도형에서 왼쪽 $j$번째 열에 있는 정사각형 수를 각 $j=1,\ldots,A_1$에 대해 구하세요.

## 입력

```text
N
A_1 A_2 ... A_N
```

## 출력

각 열의 정사각형 수를 출력하세요.
