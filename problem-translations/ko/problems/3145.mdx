## 이야기

nauclhltくん은 로맨틱한 괄호열을 생각해 냈습니다!

## 문제 설명

문자열 $X$가 **별괄호열**이라는 것은 다음 조건을 만족하는 것을 말합니다.

- $X$에 연속 부분 문자열로 포함된 `(*)`을 삭제하는 조작을 $0$회 이상 반복하여 $X$를 빈 문자열로 만들 수 있습니다.

양의 정수 $N$이 주어집니다. 길이가 $N$인 **별괄호열**로 생각할 수 있는 것은 모두 몇 개인지 구하세요.

답은 매우 커질 수 있으므로, 입력으로 주어지는 양의 정수 $M$으로 나눈 나머지를 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ M$
```

## 제한

- $1 \leq N \leq 1\,500$
- $2 \leq M \leq 10^9$
- $N$, $M$은 정수입니다.

## 출력

길이 $N$인 **별괄호열**의 개수를 $M$으로 나눈 나머지를 $r$이라고 할 때, 다음 형식으로 $1$줄에 출력하세요.

```text
$r$
```

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
6 2
```

#### 출력

```text
1
```

길이가 $6$인 **별괄호열**은 `(*)(*)`, `(*(*))`, `((*)*)`의 $3$개입니다. 따라서 $3$을 $2$로 나눈 나머지인 $1$이 답입니다.

여기서 $M$은 소수가 아닐 수도 있다는 점에 주의하세요.

### 예제 2 {file=""}

#### 입력

```text
4 998244353
```

#### 출력

```text
0
```

길이가 $4$인 **별괄호열**은 존재하지 않습니다.

### 예제 3 {file=""}

#### 입력

```text
1500 998244353
```

#### 출력

```text
201238254
```

이 예제에서는 $998\,244\,353$으로 나눈 나머지를 출력합니다.
