이 문제의 실행 시간 제한은 $10\,000$ms입니다. 풀이에 따라 실행 시간 제한이 엄격할 수 있으므로 빠른 언어를 사용하는 것을 권장합니다.

참고로 출제자의 풀이 실행 시간은 C++에서 $1\,355$ms, PyPy3에서 $4\,923$ms, Python3에서 $10\,000$ms 이상(즉, `TLE`)입니다.

## 문제 설명

$8$차원 정수 성분 벡터 $a$에 대해, $a$의 $1$번째 성분을 $a$의 끝으로 이동하여 얻는 $8$차원 정수 성분 벡터를 $a$의 순환 벡터라고 합니다.

예를 들어 $(\textcolor{red}{0},1,2,3,4,5,6,7)$의 순환 벡터는 $(1,2,3,4,5,6,7,\textcolor{red}{0})$입니다.

입력으로 $8$개의 $8$차원 음이 아닌 정수 성분 벡터 $A_1,A_2,A_3,A_4,A_5,A_6,A_7,A_8$이 주어집니다.

각 $i=2,3,\cdots,8$에 대해 $i$가 작은 순서대로 다음 처리를 수행하여 $A_1$을 갱신했을 때, 최종적인 $A_1$을 영벡터로 만들 수 있는지 판정하세요.

1. 먼저 원하는 횟수만큼($0$회 이상) $A_1$을 $A_1$의 순환 벡터로 바꿉니다.
2. 다음으로 $A_1$을 $A_1-A_i$로 바꿉니다.

## 입력

입력은 다음 형식으로 표준 입력에서 $8$줄에 걸쳐 주어집니다. 각 $i$에 대해 $i$번째 줄에는 $A_{i,1},A_{i,2},\cdots,A_{i,8}$이 $j$가 작은 순서대로 구분자 없이 이어서 주어집니다.

```text
$A_{1,1}\ A_{1,2}\ A_{1,3}\ A_{1,4}\ A_{1,5}\ A_{1,6}\ A_{1,7}\ A_{1,8}$
$A_{2,1}\ A_{2,2}\ A_{2,3}\ A_{2,4}\ A_{2,5}\ A_{2,6}\ A_{2,7}\ A_{2,8}$
$A_{3,1}\ A_{3,2}\ A_{3,3}\ A_{3,4}\ A_{3,5}\ A_{3,6}\ A_{3,7}\ A_{3,8}$
$A_{4,1}\ A_{4,2}\ A_{4,3}\ A_{4,4}\ A_{4,5}\ A_{4,6}\ A_{4,7}\ A_{4,8}$
$A_{5,1}\ A_{5,2}\ A_{5,3}\ A_{5,4}\ A_{5,5}\ A_{5,6}\ A_{5,7}\ A_{5,8}$
$A_{6,1}\ A_{6,2}\ A_{6,3}\ A_{6,4}\ A_{6,5}\ A_{6,6}\ A_{6,7}\ A_{6,8}$
$A_{7,1}\ A_{7,2}\ A_{7,3}\ A_{7,4}\ A_{7,5}\ A_{7,6}\ A_{7,7}\ A_{7,8}$
$A_{8,1}\ A_{8,2}\ A_{8,3}\ A_{8,4}\ A_{8,5}\ A_{8,6}\ A_{8,7}\ A_{8,8}$
```

$8$ 이하의 각 양의 정수 $i,j$에 대해 $A_i$의 $j$번째 성분을 $A_{i,j}$라고 합니다.

## 제한

- $8$ 이하의 모든 양의 정수 $i,j$에 대해 $A_{i,j}$는 $0 \leq A_{i,j} \leq 9$를 만족하는 정수입니다.

## 출력

최종적인 $A_1$을 영벡터로 만들 수 있다면 `Yes`를 출력하고, 그렇지 않다면 `No`를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
00000000
00000000
00000000
00000000
00000000
00000000
00000000
00000000
```

#### 출력

```text
Yes
```

어떻게 조작해도 최종적인 $A_1$은 영벡터입니다.

### 예제 2 {file=""}

#### 입력

```text
01111111
10000000
10000000
10000000
10000000
10000000
10000000
10000000
```

#### 출력

```text
Yes
```

처음에는 $A_1=(0,1,1,1,1,1,1,1)$로 주어집니다. 예를 들어 다음과 같이 조작합니다.

- $i=2$일 때
  - $A_1$을 $A_1$의 순환 벡터 $(1,1,1,1,1,1,1,0)$으로 바꿉니다.
  - $A_1$을 $A_1-A_2=(0,1,1,1,1,1,1,0)$으로 바꿉니다.
- $i=3$일 때
  - $A_1$을 $A_1$의 순환 벡터 $(1,1,1,1,1,1,0,0)$으로 바꿉니다.
  - $A_1$을 $A_1-A_3=(0,1,1,1,1,1,0,0)$으로 바꿉니다.
- $i=4$일 때
  - $A_1$을 $A_1$의 순환 벡터 $(1,1,1,1,1,0,0,0)$으로 바꿉니다.
  - $A_1$을 $A_1-A_4=(0,1,1,1,1,0,0,0)$으로 바꿉니다.
- $i=5$일 때
  - $A_1$을 $A_1$의 순환 벡터 $(1,1,1,1,0,0,0,0)$으로 바꿉니다.
  - $A_1$을 $A_1-A_5=(0,1,1,1,0,0,0,0)$으로 바꿉니다.
- $i=6$일 때
  - $A_1$을 $A_1$의 순환 벡터 $(1,1,1,0,0,0,0,0)$으로 바꿉니다.
  - $A_1$을 $A_1-A_6=(0,1,1,0,0,0,0,0)$으로 바꿉니다.
- $i=7$일 때
  - $A_1$을 $A_1$의 순환 벡터 $(1,1,0,0,0,0,0,0)$으로 바꿉니다.
  - $A_1$을 $A_1-A_7=(0,1,0,0,0,0,0,0)$으로 바꿉니다.
- $i=8$일 때
  - $A_1$을 $A_1$의 순환 벡터 $(1,0,0,0,0,0,0,0)$으로 바꿉니다.
  - $A_1$을 $A_1-A_8=(0,0,0,0,0,0,0,0)$으로 바꿉니다.

이렇게 조작하면 최종적인 $A_1$을 영벡터로 만들 수 있습니다.

### 예제 3 {file=""}

#### 입력

```text
90000009
10000000
10000000
00100000
00100000
00001000
00001000
00000039
```

#### 출력

```text
Yes
```

처음에는 $A_1=(9,0,0,0,0,0,0,9)$로 주어집니다. 예를 들어 다음과 같이 조작합니다.

- $i=2$일 때
  - $A_1$을 $A_1$의 순환 벡터로 바꾸는 조작을 $7$회 반복하여 $A_1$을 $(9,9,0,0,0,0,0,0)$으로 갱신합니다.
  - $A_1$을 $A_1-A_2=(8,9,0,0,0,0,0,0)$으로 바꿉니다.
- $i=3$일 때
  - $A_1$을 $A_1$의 순환 벡터로 바꾸는 조작을 $0$회 반복합니다.
  - $A_1$을 $A_1-A_3=(7,9,0,0,0,0,0,0)$으로 바꿉니다.
- $i=4$일 때
  - $A_1$을 $A_1$의 순환 벡터로 바꾸는 조작을 $6$회 반복하여 $A_1$을 $(0,0,7,9,0,0,0,0)$으로 갱신합니다.
  - $A_1$을 $A_1-A_4=(0,0,6,9,0,0,0,0)$으로 바꿉니다.
- $i=5$일 때
  - $A_1$을 $A_1$의 순환 벡터로 바꾸는 조작을 $0$회 반복합니다.
  - $A_1$을 $A_1-A_5=(0,0,5,9,0,0,0,0)$으로 바꿉니다.
- $i=6$일 때
  - $A_1$을 $A_1$의 순환 벡터로 바꾸는 조작을 $6$회 반복하여 $A_1$을 $(0,0,0,0,5,9,0,0)$으로 갱신합니다.
  - $A_1$을 $A_1-A_6=(0,0,0,0,4,9,0,0)$으로 바꿉니다.
- $i=7$일 때
  - $A_1$을 $A_1$의 순환 벡터로 바꾸는 조작을 $0$회 반복합니다.
  - $A_1$을 $A_1-A_7=(0,0,0,0,3,9,0,0)$으로 바꿉니다.
- $i=8$일 때
  - $A_1$을 $A_1$의 순환 벡터로 바꾸는 조작을 $6$회 반복하여 $A_1$을 $(0,0,0,0,0,0,3,9)$으로 갱신합니다.
  - $A_1$을 $A_1-A_8=(0,0,0,0,0,0,0,0)$으로 바꿉니다.

이렇게 조작하면 최종적인 $A_1$을 영벡터로 만들 수 있습니다.
