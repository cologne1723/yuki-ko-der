`D`일 동안 매일 `N`종류의 요리 중 하나를 골라 먹습니다. 요리 `i`는 조리할 때 기운이 `P_i` 감소하고, 먹으면 `Q_i` 증가합니다. 같은 요리를 연속으로 고를 수 없습니다.

처음 기운은 0이며, `D`일 동안 기운의 최솟값을 최대화할 때 그 최댓값을 구하세요.

## 제약

- `2 <= N,D <= 1000`
- `1 <= P_i,Q_i <= 10^5`

## 입력

`N D`와 각 요리의 `P_i Q_i`가 주어집니다.

## 출력

최적 행동에서 기운의 최솟값을 출력하세요.
