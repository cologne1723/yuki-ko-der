**문제 비주얼**

▶ 문제 비주얼 공개

![문제 비주얼](../images/3164/1.png)

## 이야기

가로로 긴 화단이 있습니다.

## 문제 설명

이 화단은 $1$줄로 늘어선 $N$개의 구획으로 나뉘어 있습니다. 왼쪽에서 $i$번째 구획을 구획 $i$라고 합니다.

구획 $i$($1 \leq i \leq N$)에는 장미가 $A_i$송이 피어 있습니다. 각 구획에 대해 장미가 $1$송이 이상 피어 있을 때, 그리고 그 경우에만 그 구획을 **장미가 피어 있는 구획**이라고 합니다.

서로 다른 $2$개의 구획 $i$, $j$에 대해 $\lvert i-j\rvert=1$일 때, 그리고 그 경우에만 구획 $i$와 구획 $j$가 **인접해 있다**고 합니다.

다음 형식으로 주어지는 $Q$개의 질의에 답하세요.

- 질의 $q$($1 \leq q \leq Q$): 구획 $X_q$에 피어 있는 장미의 수가 $B_q$송이로 **증가**했다고 할 때, 구획 $X_q$에서 장미가 피어 있는 인접한 구획 사이를 $0$회 이상 이동하여 도달할 수 있는 구획에 피어 있는 장미 수의 합을 구하세요.

즉, 다음 문제를 해결하세요.

장미 수가 변한 후 구획 $j$에 피어 있는 장미 수를 $C_j$라고 합니다. 다음 조건을 만족하는 $1$ 이상 $N$ 이하의 정수 $i$에 대해 $C_i$의 합을 구하세요.

- 다음 조건을 만족하는 길이 $1$ 이상의 정수열 $(p_1,p_2,\ldots,p_n)$이 존재합니다.
  - $k=1,2,\ldots,n$에 대해 $1 \leq p_k \leq N$입니다.
  - $p_1=X_q$, $p_n=i$입니다.
  - $k=1,2,\ldots,n-1$에 대해 구획 $p_k$와 구획 $p_{k+1}$가 인접해 있습니다. 즉, $\lvert p_k-p_{k+1}\rvert=1$입니다.
  - $k=1,2,\ldots,n$에 대해 구획 $p_k$는 장미가 피어 있는 구획입니다. 즉, $C_{p_k} \geq 1$입니다.

제한으로부터 구획 $X_q$는 반드시 장미가 피어 있는 구획이 된다는 점에 유의하세요.

$Q$개의 질의는 서로 독립입니다. 즉, 어떤 질의에서 변한 장미 수는 다른 질의에 영향을 주지 않습니다.

## 입력

입력은 표준 입력으로 다음 형식으로 주어집니다.

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
$Q$
$X_1\ B_1$
$X_2\ B_2$
$\vdots$
$X_Q\ B_Q$
```

## 제한

- $1 \leq N \leq 3 \times 10^5$
- $0 \leq A_i < 10^9$ ($1 \leq i \leq N$)
- $1 \leq Q \leq 3 \times 10^5$
- $1 \leq X_q \leq N$ ($1 \leq q \leq Q$)
- $A_{X_q} < B_q \leq 10^9$ ($1 \leq q \leq Q$)
- 입력은 모두 정수입니다.

## 출력

출력은 $Q$줄로 이루어집니다. $q$번째 줄($1 \leq q \leq Q$)에 질의 $q$에 대한 답을 정수로 출력하세요.

입출력의 크기가 커질 수 있으므로 빠른 방법으로 입출력하는 것을 권장합니다.

## 예제

### 예제 1 {file="0_sample_1.txt"}

#### 입력

```text
10
1 0 3 4 5 0 7 0 0 10
3
4 100
2 2
7 7777777
```

#### 출력

```text
108
15
7777777
```

질의 $1$에서는 구획 $4$에 피어 있는 장미 수가 $4$송이에서 $100$송이로 변합니다. 이때 구획 $4$에서 인접한 구획 사이를 $0$회 이상 이동하여 도달할 수 있는 구획은 구획 $3$, 구획 $4$, 구획 $5$의 $3$개입니다. 구획 $3$, 구획 $4$, 구획 $5$에 피어 있는 장미 수의 합은 $3+100+5=108$입니다.

질의 $2$에서는 구획 $2$에 피어 있는 장미 수가 $0$송이에서 $2$송이로 변합니다. 여기서 질의 $1$에서 변한 구획 $4$의 장미 수는 질의 $2$에 영향을 주지 않습니다. 즉, $100$송이가 아니라 $4$송이라는 점에 유의하세요.

이때 구획 $2$에서 인접한 구획 사이를 $0$회 이상 이동하여 도달할 수 있는 구획은 구획 $1$, 구획 $2$, 구획 $3$, 구획 $4$, 구획 $5$의 $5$개입니다. 구획 $1$, 구획 $2$, 구획 $3$, 구획 $4$, 구획 $5$에 피어 있는 장미 수의 합은 $1+2+3+4+5=15$입니다.
