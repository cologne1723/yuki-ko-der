## 이야기

みなほし「LCP array에 대해 알 것 같아!」

みなほし「최댓값인 경우는 풀었으니, 분명 최솟값인 경우도 쉽게 풀 수 있겠지?」

## 문제 설명

양의 정수 $N$이 주어집니다. `a` 또는 `b`로 이루어진 길이 $N$인 문자열 중 LCP array의 원소 합이 **최소**가 되는 문자열을 구성하세요.

### 배경

길이 $N$인 문자열 $S$에 대해, $S$의 $N$개 접미사를 사전순으로 정렬한 배열을 $S$의 suffix array라고 합니다.

$i=1,2,\dots,N-1$에 대해, $S$의 suffix array에서 $i$번째 원소와 $i+1$번째 원소의 최장 공통 접두사의 길이를 구한 배열을 $S$의 LCP array (Longest Common Prefix Array)라고 합니다.

이 문제는 여러 테스트 케이스로 구성됩니다. $T$개의 테스트 케이스에 답하세요.

## 입력

```text
$T$
$case_1$
$\vdots$
$case_T$
```

$i=1,2,\dots,T$에 대해 $case_i$는 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- $1 \leq T \leq 600$
- $2 \leq N \leq 2 \times 10^5$
- 모든 테스트 케이스에 대한 $N$의 합은 $2 \times 10^5$ 이하입니다.
- 입력은 모두 정수입니다.

## 출력

$T$줄에 출력하세요. $i$번째 줄에는 $i$번째 테스트 케이스에 대해, `a` 또는 `b`로 이루어진 길이 $N$인 문자열 중 LCP array의 원소 합이 최소가 되는 문자열을 출력하세요.

주어진 $N$에 대해 조건을 만족하는 문자열이 여러 개 존재하는 경우, 그중 어느 것을 출력해도 정답으로 인정됩니다.

## 예제

### 예제 1 {file="01_sample_01.txt"}
#### 입력

```text
3
2
3
4
```

#### 출력

```text
ab
abb
aabb
```

`ab`의 LCP array는 $[0]$이며, 합은 $0$입니다.

`abb`의 LCP array는 $[0,1]$이며, 합은 $1$입니다.

`aabb`의 LCP array는 $[1,0,1]$이며, 합은 $2$입니다.

어느 경우든 길이 $N$이고 `a` 또는 `b`로 이루어진 문자열에서 생각할 수 있는 LCP array의 원소 합 중 최솟값이 됩니다.
