## 이야기

어떤 세계에서는 지구에서 사람들이 사용하는 것처럼 $10$진수를 다룹니다.

## 문제 설명

단 $1$가지 다른 점은 숫자 $4$와 $7$을 비교할 때만 $4$가 $7$보다 크다는 것입니다.

단순히 $4$와 $7$의 순서가 뒤바뀐 것은 아닙니다. 이 세계의 수에서는 추이성이 성립하지 않는다고 생각해도 됩니다.

단, 자릿수를 비교하는 방법은 지구에서 사람들이 사용하는 방식과 같습니다.

서로 다른 정수 $A,B$가 주어질 때, 이 세계에서 더 큰 수를 출력하세요.

## 입력

```text
$A\ B$
```

$A$와 $B$는 서로 다른 정수입니다.

## 제한

- $0 \le A \le 2\times 10^9$
- $0 \le B \le 2\times 10^9$

## 출력

$A$와 $B$ 중 더 큰 수를 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 7
```

#### 출력

```text
4
```

$4$와 $7$을 비교하면 $4$가 더 큽니다. 당연한 결과입니다.

### 예제 2 {file=""}

#### 입력

```text
5 7
```

#### 출력

```text
7
```

$5$와 $7$이라면 $7$이 더 큽니다.

### 예제 3 {file=""}

#### 입력

```text
40 170
```

#### 출력

```text
170
```

$2$자리 정수보다 $3$자리 정수가 더 큽니다.

### 예제 4 {file=""}

#### 입력

```text
1237564890 1234567890
```

#### 출력

```text
1234567890
```
