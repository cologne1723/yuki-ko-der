## 문제

어떤 세계에서는 지구에서 사람들이 사용하는 것처럼 십진수와 수를 다룹니다.

단 한 가지 다른 점은 숫자 4와 7을 비교할 때만 4가 7보다 크다는 것입니다.

단순히 4와 7의 순서가 뒤바뀐 것은 아닙니다. 이 세계의 수에서는 추이성이 성립하지 않는다고 생각해도 됩니다.

단, 자릿수를 비교하는 방법은 지구에서 사람들이 사용하는 방식과 같습니다.

서로 다른 정수 $A,B$가 주어질 때, 이 세계에서 더 큰 수를 출력하세요.

## 입력

```text
A B
```

$A$와 $B$는 서로 다른 정수입니다.

- $0 \le A \le 2\times 10^9$
- $0 \le B \le 2\times 10^9$

## 출력

$A$와 $B$ 중 더 큰 수를 한 줄에 출력하세요.

마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
4 7
```

### 샘플 1 {file="sample1.out"}

```text
4
```

4와 7을 비교하면 4가 더 큽니다. 당연한 결과입니다.

### 샘플 2 {file="sample2.in"}

```text
5 7
```

### 샘플 2 {file="sample2.out"}

```text
7
```

5와 7이라면 7이 더 큽니다.

### 샘플 3 {file="sample3.in"}

```text
40 170
```

### 샘플 3 {file="sample3.out"}

```text
170
```

2자리 정수보다 3자리 정수가 더 큽니다.

### 샘플 4 {file="sample4.in"}

```text
1237564890 1234567890
```

### 샘플 4 {file="sample4.out"}

```text
1234567890
```
