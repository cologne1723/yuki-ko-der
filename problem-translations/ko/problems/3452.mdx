## 문제 설명

양의 정수 $N$과 $(1,2,\dots,N)$의 순열 $P=(P_1,P_2,\dots,P_N)$가 주어집니다.

각 $k=1,2,\dots,N$에 대해 다음 조건을 만족하는 순열 중 사전순으로 가장 작은 것의 **롤링 해시**를 구하세요.

- $P$를 정확히 $k$개의 비어 있지 않은 연속 부분열로 나눕니다. 그 부분열들의 순서를 바꾼 뒤 이어 붙여서 $(1,2,\dots,N)$의 순열을 만듭니다.

단, 양의 정수열 $a=(a_1,a_2,\dots,a_n)$의 **롤링 해시**는 다음과 같이 정의합니다.

$\sum_{i=1}^{n}a_i\cdot 10^{n-i}\pmod{998\,244\,353}$

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

## 입력

```text
$T$
$case_1$
$case_2$
$\vdots$
$case_T$
```

여기서 $case_i$는 $i$번째 테스트 케이스를 나타내며, 다음 형식으로 주어집니다.

```text
$N$
$P_1\ P_2\ \cdots\ P_N$
```

## 제한

- $1\leq T\leq 2\times 10^5$
- $1\leq N\leq 2\times 10^5$
- $P$는 $(1,2,\dots,N)$의 순열입니다.
- 모든 테스트 케이스에 대한 $N$의 합은 $2\times 10^5$ 이하입니다.
- 입력은 모두 정수입니다.

## 출력

$T$줄 출력하세요.

$i$번째 줄에는 $i$번째 테스트 케이스의 $k=1,2,\dots,N$에 대한 답을 이 순서대로 공백으로 구분하여 출력하세요.
