원점을 중심으로 하고 반지름이 $R$인 원형 케이크를 $x$축과 평행한 $K$개의 직선으로 잘라 $K+1$개의 같은 넓이 조각으로 나눕니다. 직선은 $y=l$ 꼴이며, 모든 $l$을 오름차순으로 출력하세요.

## 조건

- $1\le R,K\le10^5$
- 절대 오차 또는 상대 오차가 $10^{-5}$ 이하이면 정답입니다.

## 입력

정수 $R,K$가 주어집니다.

## 출력

답을 오름차순으로 한 줄에 하나씩 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1 2
```

#### 출력

```text
-0.2649320846028
0.2649320846028
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
100 1
```

#### 출력

```text
0
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
16 5
```

#### 출력

```text
-8.852683396809
-4.238913353644
0
4.238913353644
8.852683396809
```
