## 문제

`N`개 정수의 합이 `X`입니다. 각 `i`에 대해 `A_i`를 제외한 합을 계산해 `S_i`로 기록했지만, 정확히 하나의 계산 결과가 실제 값의 2배가 되었습니다. 잘못 계산한 항목의 올바른 값을 출력하세요.

## 입력

`N X`와 `S_1,...,S_N`이 주어집니다.

`2\le N\le2\times10^5`, `0\le X\le10^9`입니다.

## 출력

잘못 계산한 결과의 올바른 값을 출력하세요.
