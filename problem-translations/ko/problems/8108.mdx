## 문제 설명

양의 정수 $n$이 주어집니다. 다음과 같이 정의되는 $f(n)$의 값을 법 $998\,244\,353$에서 구하세요.

$ f(n) = \dfrac{ (A + G)(C - F) }{ D \sqrt{ B - A + E } }
\left( \left( \dfrac{ K + \sqrt{ \left\lfloor \dfrac{ A (J K)^{J} }{ H + J } \right\rfloor } }{ L } \right)^{ \dfrac{ J n }{ I }}
- \left( \dfrac{ -G \log_{K} (G I + I J L) }
{ \dfrac{ \gcd(F, A - G + H) }{ I - G } + \left( \dfrac{ K^{J} }{ C } \right)^{ \sin \left( \dfrac{ A + I + L }{ K } \pi \right) } } \right)^{ \dfrac{ n }{ B^{E} } } \right) $

단, $\lfloor x \rfloor$는 $x$ 이하인 가장 큰 정수를 나타내며, $\gcd(x,y)$는 $x$와 $y$의 최대공약수를 나타냅니다.

또한 $\sin x$의 인수는 호도법으로 나타냅니다. 즉, ‘$x$라디안’입니다.

위 식의 $A, B, C, D, E, F, G, H, I, J, K, L$은 모두 **정수** 상수이며, 서기 2024년 4월 1일 현재 아래 ‘수학 퀴즈’ 항목에 적힌 모든 문장을 올바른 문장으로 만듭니다.

단, 【】로 둘러싸인 상수에는 그 아래에 제시된 선택지 중 가장 적절한 것을 정확히 $1$개 선택하고, 그 번호를 대입하세요.

예를 들어 다음 문장이 있다면 $x$에는 $3$을 대입하세요.

- 【$x$】란 $2$ 이상인 정수이며, $1$과 자기 자신 이외에 양의 약수를 가지지 않는 것입니다.

  【$x$】의 선택지:

  1. 홀수
  2. 짝수
  3. 소수
  4. 합성수

### 수학 퀴즈

- $2\,024$를 소인수분해하면 $2\,024 = 2^{A} \times 11 \times B$로 나타낼 수 있습니다.

- $3$ 이상인 임의의 정수 $m$에 대하여, 정$m$각형의 내각의 합과 외각의 합은 도수법으로 각각 $(C m + D)$도, $(E m + F)$도입니다.

- 동전이 $1$개 있습니다. 이 동전을 $1$번 던졌을 때 앞면이 나올 확률은 $\dfrac{1}{3}$이고, 뒷면이 나올 확률은 $\dfrac{2}{3}$입니다.

  이 동전을 연속으로 $x$번 던졌을 때 앞면이 적어도 $1$번 나올 확률을 $p(x)$로 나타냅니다.

  이때 $p(1) = \dfrac{G}{3}$이고 $p(3) = \dfrac{H}{27}$입니다.

- 다음 의문문에 대한 답으로 가장 적절한 것은 【$I$】입니다.

  - 호주의 수도는 어디인가요?

### 주의

이 문제의 제한 아래에서 $f(n)$은 유리수임이 보장됩니다.

이를 기약분수 $p / q$로 나타냈을 때, $p \equiv q \times r \pmod{998\,244\,353}$를 만족하는 정수 $r$ $(0 \le r < 998\,244\,353)$가 유일하게 정해지는 것이 보장됩니다. 이 $r$을 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$n$
```

- $1$번째 줄에 $n$이 주어집니다.

## 제한

- $1 \le n \le 1\,000$
- $n$은 정수입니다.

## 출력

답을 $1$줄에 출력하세요.
