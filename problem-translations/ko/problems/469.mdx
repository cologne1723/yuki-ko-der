## 문제

길이 $N$인 수열 $x=(x_0,x_1,x_2,\dots,x_{N-1})$가 있습니다.

처음에는 수열 $x=(0,0,0,\dots,0)$입니다.

다음 두 종류의 쿼리 $Q$개가 주어지므로 순서대로 처리하세요.

- 구간 덧셈 쿼리 `! L R K`: $L\leq i\lt R$에 대해 $x_i$를 $x_i+K$로 갱신합니다.
- 질문 쿼리 `?`: 현재 수열 $x$와 같은 값을 처음 갖게 된 것은 몇 번째 쿼리 처리 후인지 답하세요.

초기 상태는 0번째 쿼리 처리 후라고 합니다.

즉 답해야 하는 질문 쿼리를 $q$번째 쿼리($1\leq q\leq Q$)라고 하고, $i$번째 쿼리 처리 후의 $x$ 값을 $x^i$라고 하겠습니다. 초기 상태는 $x^0=(0,0,0,\dots,0)$입니다. 이때 $\min\{i\mid0\leq i\leq Q\land x^i=x^{q-1}\}$를 출력하세요.

## 입력

```text
N Q
$C_1$
$C_2$
...
$C_Q$
```

첫 번째 줄에 수열의 길이 $N$과 쿼리 수 $Q$가 주어집니다.

$i+1$번째 줄($1\leq i\leq Q$)에 문제에서 설명한 형식 중 하나의 쿼리가 주어집니다.

구간 덧셈 쿼리일 때 왼쪽 끝 $L_i$는 $0\leq L_i\lt N$, 오른쪽 끝 $R_i$는 $L_i\lt R_i\leq N$, 더할 양 $K_i$는 $-100\lt K_i\leq100$을 만족하며 모두 정수입니다.

## 출력

질문 쿼리에 대해 주어진 순서대로 답을 출력하세요.

각 답 뒤에 줄바꿈을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3 6
! 1 3 1
! 0 2 2
! 0 3 -2
?
! 2 3 2
?
```

출력:

```text
3
1
```

처리는 다음과 같이 진행됩니다.

- 처음에는 $x=(0,0,0)$입니다.
- 1번째 쿼리를 처리하면 $x=(0,1,1)$입니다.
- 2번째 쿼리를 처리하면 $x=(2,3,1)$입니다.
- 3번째 쿼리를 처리하면 $x=(0,1,-1)$입니다.
- 4번째 쿼리에 답합니다. 이때 $x=(0,1,-1)$이며, $x$가 이 값을 처음 갖게 된 것은 3번째 쿼리 처리 후이므로 3을 출력합니다.
- 5번째 쿼리를 처리하면 $x=(0,1,1)$입니다.
- 6번째 쿼리에 답합니다. 이때 $x=(0,1,1)$은 1번째 쿼리 직후와 5번째 쿼리 후에 나타났으므로, 더 이른 쿼리 번호인 1을 출력합니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
3 2
?
?
```

출력:

```text
0
0
```

### 샘플 3 {file="sample3.in"}

입력:

```text
100000 6

! 0 100000 2
! 0 100000 3
! 0 100000 4
! 0 100000 -7
?
```

출력:

```text
2
```
