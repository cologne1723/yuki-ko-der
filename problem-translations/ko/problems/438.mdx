## 문제

Cww라는 프로그래밍 언어가 있습니다. Cww의 소스 코드는 다음 조건을 만족해야 실행할 수 있습니다.

- 소스 코드는 `c`, `w`, `C`, `W` 네 종류의 문자만으로 이루어집니다.
- 소스 코드는 한 줄의 문자열이며, 마지막에 개행이 필요합니다.

실행 가능한 Cww 소스 코드(문자열)를 S라고 합니다. Cww 실행 프로그램은 S를 입력으로 받아 다음과 같이 동작합니다.

- 실행 프로그램은 스택을 가지며, 초기 스택 원소 수는 0입니다.
- S의 i번째 문자를 Sᵢ라고 할 때, S₁, S₂, ...를 왼쪽부터 순서대로 읽습니다.
- `c`를 읽으면 스택 맨 위에 정수 x를 추가합니다.
- `w`를 읽으면 스택 맨 위에 정수 y를 추가합니다.
- 스택 위에서 첫 번째 원소를 a, 두 번째 원소를 b라고 할 때 `C`를 읽으면 a,b를 꺼내고 맨 위에 a + b를 추가합니다.
- 같은 방식으로 `W`를 읽으면 a,b를 꺼내고 맨 위에 a − b를 추가합니다.
- 읽을 문자열이 없어지면 스택 맨 위의 정수 z를 꺼내 출력하고 종료합니다.
- 스택에서 원소를 꺼낼 때 스택이 비어 있으면 오류(WA)로 종료합니다. `C`나 `W`를 읽을 때는 원소를 2개 꺼낸다는 점에 주의하세요.

Cww 초보자인 cww 씨는 정수 z를 출력하는 Cww 프로그램을 만들고 있습니다. 정수 x,y,z가 주어질 때 z를 출력하는 Cww 소스 코드 하나를 만드세요. 단, 소스 코드는 개행을 제외하고 10000자 이하여야 합니다. 어떤 방법으로도 10000자 이내에서 z를 출력할 수 없다면 `NO`를 한 줄에 출력하세요.

## 입력

정수 x, y, z가 주어집니다.

```text
x y z
```

- 0 ≤ x,y,z ≤ 100000000

## 출력

z를 출력하는 Cww 소스 코드 S를 출력하세요. S는 1자 이상 10000자 이하여야 합니다. 구성할 수 없다면 `NO`를 한 줄에 출력하세요. `NO`가 아닌 경우 S에 `c`, `w`, `C`, `W` 이외의 문자가 포함되면 오류입니다. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
1 2 3
```

### 샘플 1 출력 {file="sample1.out"}

```text
cwC
```

`cwC`는 c로 x=1을 스택에 넣고, w로 y=2를 넣은 뒤, C로 2+1=3을 남겨 3을 출력합니다. `wcC`나 `wwCcWccWW` 등도 정답입니다.

### 샘플 2 {file="sample2.in"}

```text
2 3 7
```

### 샘플 2 출력 {file="sample2.out"}

```text
cwwCwCW
```

`cwwCwCW`는 스택에 2, 3, 3을 넣고 3+3=6, 6+3=9를 만든 뒤 9−2=7을 남겨 7을 출력합니다.

### 샘플 3 {file="sample3.in"}

```text
42 72 88
```

### 샘플 3 출력 {file="sample3.out"}

```text
NO
```

주어진 제약 안에서는 정답 소스 코드를 만들 수 없으므로 대신 `NO`를 출력합니다.
