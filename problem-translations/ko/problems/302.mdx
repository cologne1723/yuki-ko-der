## 문제 설명

$1$부터 $6$까지의 정수가 같은 확률로 나오는 일반적인 주사위가 있습니다.

이 주사위를 독립적으로 $N$번 굴렸을 때 눈의 합이 $L$ 이상 $R$ 이하가 될 확률을 구하세요.

## 입력

```text
$N$
$L\ R$
```

## 제한

- $1 \le N \le 10^{18}$
- $0 \le L \le R \le 10^{18}$

## 출력

답인 확률을 $1$줄에 출력하세요.

출력값과 준비된 답의 차이가 $2\times10^{-5}$ 이하이면 정답으로 인정됩니다. 준비된 답은 실제 답과 절대 오차가 $10^{-5}$ 이하라고 생각해도 됩니다. 초기 데이터 세트에서는 이보다 오차가 훨씬 작지만, 추가 케이스가 있을 수 있음을 고려해 이와 같이 설정되어 있습니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
1 4
```

#### 출력

```text
0.166666666666667
```

주사위 $2$개를 굴려 합이 $1$ 이상 $4$ 이하가 되는 눈의 조합은 $36$가지 중 $(1,1),(1,2),(1,3),(2,1),(2,2),(3,1)$의 $6$가지이므로 답은 $6/36$입니다.

### 예제 2 {file=""}

#### 입력

```text
10000

```

#### 출력

```text
0.648645471121652
```

### 예제 3 {file=""}

#### 입력

```text
9876543210
0 1000000000000000000
```

#### 출력

```text
1
```
