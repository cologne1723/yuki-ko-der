## 문제 설명

개그맨 A君은 예명 $S$를 생각했습니다.

처음에 B師匠에게 의견을 구하자 처음부터 $t$번째 문자($0$부터 시작)를 $1$글자 지우라는 말을 들었습니다.

다음으로 C師匠에게 의견을 구하자 처음부터 $u$번째 문자($0$부터 시작)를 $1$글자 지우라는 말을 들었습니다.

A君은 B師匠과 C師匠이 말한 대로 문자를 지우기로 했습니다. B師匠과 C師匠의 의견이 같으면 지우는 문자는 $1$글자이고, 의견이 다르면 $2$글자입니다.

$S,t,u$가 주어질 때 B師匠과 C師匠의 의견을 반영해 만들어진 예명을 출력하세요.

## 입력

```text
$S\ t\ u$
```

- 문자열 $S$는 소문자 알파벳으로 이루어집니다.

## 제한

- $3 \le |S| \le 50$
- $0 \le t \le |S|-1$
- $0 \le u \le |S|-1$

## 출력

만들어진 A君의 예명을 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
yukicoder 0 4
```

#### 출력

```text
ukioder
```

A君이 처음 생각한 예명은 `yukicoder`입니다. B師匠은 $0$번째 문자인 `y`를, C師匠은 $4$번째 문자인 `c`를 지우라고 했습니다. 결국 `y`와 `c`를 지운 `ukioder`로 예명이 정해집니다.

### 예제 2 {file=""}

#### 입력

```text
aaa 0 0
```

#### 출력

```text
aa
```

B師匠과 C師匠 모두 $0$번째 문자인 `a`를 지우라고 했습니다. A君이 지운 것은 $0$번째 문자인 `a` $1$개뿐입니다.

### 예제 3 {file=""}

#### 입력

```text
nmnmnmnmnmnmnm 13 12
```

#### 출력

```text
nmnmnmnmnmnm
```

마지막 $2$글자가 없어진 셈입니다.
