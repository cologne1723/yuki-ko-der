## 문제

개그맨 A 군은 예명 $S$를 생각했습니다.

처음에 B 스승에게 의견을 구하자 처음부터 $t$번째 문자(0-index)를 한 글자 지우라는 말을 들었습니다.

다음으로 C 스승에게 의견을 구하자 처음부터 $u$번째 문자(0-index)를 한 글자 지우라는 말을 들었습니다.

A 군은 B 스승과 C 스승이 말한 대로 문자를 지우기로 했습니다. 두 스승의 의견이 같으면 지우는 문자는 한 글자이고, 의견이 다르면 두 글자입니다.

$S,t,u$가 주어질 때 두 스승의 의견을 반영해 만들어진 예명을 출력하세요.

## 입력

```text
S t u
```

- 문자열 $S$는 소문자 알파벳으로 이루어집니다.
- $3 \le |S| \le 50$
- $0 \le t \le |S|-1$
- $0 \le u \le |S|-1$

## 출력

만들어진 A 군의 예명을 한 줄에 출력하세요.

마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
yukicoder 0 4
```

### 샘플 1 {file="sample1.out"}

```text
ukioder
```

A 군이 처음 생각한 예명은 `yukicoder`입니다. B 스승은 0번째 문자인 `y`를, C 스승은 4번째 문자인 `c`를 지우라고 했습니다. 결국 `y`와 `c`를 지운 `ukioder`로 예명이 정해집니다.

### 샘플 2 {file="sample2.in"}

```text
aaa 0 0
```

### 샘플 2 {file="sample2.out"}

```text
aa
```

B 스승과 C 스승 모두 0번째 문자인 `a`를 지우라고 했습니다. A 군이 지운 것은 0번째 문자인 `a` 하나뿐입니다.

### 샘플 3 {file="sample3.in"}

```text
nmnmnmnmnmnmnm 13 12
```

### 샘플 3 {file="sample3.out"}

```text
nmnmnmnmnmnm
```

마지막 두 글자가 없어진 셈입니다.
