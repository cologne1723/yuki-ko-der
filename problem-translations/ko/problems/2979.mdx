## 문제 설명

세 변의 길이가 모두 정수인 직각삼각형 중 둘레가 $N$ 이하인 것의 개수를 구하세요.

## 입력

입력은 표준 입력에서 $1$줄로 주어집니다.

```text
$N$
```

첫째 줄에 정수 $N$이 주어집니다.

## 제한

- $N$은 $1 \leq N \leq 10^{12}$를 만족하는 정수입니다.
- 샘플을 제외하고 테스트 케이스는 $26$개 있습니다.
- 테스트 케이스 $1$부터 $14$까지는 $N \leq 10^7$을 만족합니다. (★$2.5$ 정도)

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
30
```

#### 출력

```text
3
```

세 변의 길이가 $(3,4,5)$, $(6,8,10)$, $(5,12,13)$인 $3$개의 직각삼각형이 조건을 만족합니다.

### 예제 2 {file=""}

#### 입력

```text
10000000
```

#### 출력

```text
9706567
```

### 예제 3 {file=""}

#### 입력

```text
1000000000000
```

#### 출력

```text
1779214833461
```
