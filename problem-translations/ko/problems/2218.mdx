정수열 $A$의 비연속 부분 수열 $(B_1,\ldots,B_k)$ 중 모든 $i$에 대해 $B_{i+1}$이 $B_i$의 배수인 것의 최대 길이를 구하라냥. 길이 1인 부분 수열은 항상 조건을 만족한다냥.

## 조건

- $1\le N\le10^5$
- $1\le A_i\le10^5$

## 입력

```text
N
A_1 A_2 \cdots A_N
```

## 출력

조건을 만족하는 부분 수열의 최대 길이를 출력하라냥.
