정류장 `C`개가 있고 시각 0에 정류장 1에 버스 `M`대가 있습니다. 매 시각 각 버스는 독립적으로 현재 정류장에 머물거나 다른 정류장으로 이동하며, 모든 정류장을 각각 확률 `1/C`로 선택합니다.

시각 `N`에 정류장 1에 버스가 한 대 이상 있을 확률을 `10^9+7`에서의 값으로 출력하세요.

## 제약

- `2 <= C <= 10^5`
- `1 <= N <= 10^9`

## 입력

`C N M`이 주어집니다.

## 출력

확률을 출력하세요.
