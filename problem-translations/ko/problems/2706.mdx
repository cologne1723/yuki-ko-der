## 문제

연필 1다스는 12자루이고, Nafmo 1세트는 `A`자루입니다. Nafmo 한 세트의 가격은 `B`엔입니다.

Nafmo 세트를 몇 개 사서 연필을 `X`자루 이상 얻으려고 할 때, 필요한 최소 금액을 구하세요.

## 제약

- `1 ≤ A,B,X ≤ 1000`

## 입력

```text
A B X
```

## 출력

필요한 최소 금액을 출력하세요.
