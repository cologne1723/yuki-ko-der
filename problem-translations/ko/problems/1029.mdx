## 문제 설명

$K$를 $1$ 이상인 정수라고 합니다. 문자 `J` $K$개, 문자 `O` $K$개, 문자 `I` $K$개를 이 순서로 나열한 문자열을 **레벨 $K$의 JOI 문자열**이라고 합니다.

[친구 비바코에게 문자열을 받은 비타로](https://atcoder.jp/contests/joi2020ho/tasks/joi2020ho_b)는 답례로 레벨 $K$의 JOI 문자열을 만들려고 합니다. 그래서 비타로는 문자열을 판매하는 「문자열 가게」에 가기로 했습니다.

문자열 가게에서는 $N$종류의 문자열을 판매합니다. $i$번째 $(1 \le i \le N)$ 문자열의 가격은 $C_i$엔입니다.

비타로는 문자열을 몇 개 구매하여 원하는 순서로 나열한 뒤, 모두 연결하여 문자열 $S$를 만듭니다. 이때 같은 문자열을 여러 개 구매해도 되고, 구매하지 않는 문자열이 있어도 됩니다.

비타로는 $S$가 레벨 $K$의 JOI 문자열을 **부분열**로 포함하도록 문자열을 골라 구매하려고 합니다. 이때 최소 얼마가 필요한지 구하는 프로그램을 작성하세요. 어떤 방법으로도 조건을 만족하는 문자열을 만들 수 없다면 대신 $-1$을 출력하세요.

## 주석

문자열 $S$가 문자열 $T$의 부분열이라는 것은 $T$에서 몇 개의 문자를 뽑아 순서를 유지한 채 나열하여 $S$를 만들 수 있다는 뜻입니다.

예를 들어 `"yuki"`, `"ykd"`, `"yukicoder"`, (빈 문자열)은 `"yukicoder"`의 부분열이지만, `"a"`, `"ike"` 등은 부분열이 아닙니다.

## 입력

```text
$N\ K$
$S_1\ C_1$
$S_2\ C_2$
\dots
$S_N\ C_N$
```

$N$, $K$, $C_i$ $(1 \le i \le N)$는 정수입니다.

$S_i$ $(1 \le i \le N)$는 문자 `J`, `O`, `I` 중 하나만으로 이루어진 문자열입니다.

## 제한

- $1 \le N \le 80$
- $1 \le K \le 10^5$
- $0 \le C_i \le 10^9$ $(1 \le i \le N)$
- $1 \le |S_i| \le 80$ $(1 \le i \le N)$

## 출력

문제 설명의 조건을 만족하는 문자열 $S'$를 만드는 데 필요한 최소 금액을 출력하세요. 어떤 방법으로도 조건을 만족하는 문자열을 만들 수 없다면 대신 `-1`을 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 2
JOI 50
JJOI 30
IOI 20
```

#### 출력

```text
70
```

두 번째 문자열을 $1$개, 세 번째 문자열을 $2$개 구매하여 그 순서대로 연결하는 것이 최적입니다.

(21:34 추가) 이렇게 만든 문자열은 `"JJOIIOIIOI"`가 되며, 길이 $2$인 JOI 문자열을 부분열로 포함합니다.

비용은 $30+20 \times 2=70$엔입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 2
JJJJ 1
```

#### 출력

```text
-1
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
5 5
IOOOJ 28
JIJOOJIII 12
JIJOJIO 7
OIOJIOII 16
OJOJOJ 27
```

#### 출력

```text
40
```

두 번째 문자열을 $1$개, 세 번째 문자열을 $4$개 구매하는 것이 최적입니다.
