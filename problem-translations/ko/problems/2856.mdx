## 문제 설명

MMA의 정크 마켓에는 상품 $2N$개가 각각 판매되고 있습니다.

$i$번째 상품은 일반인이 $A_i$엔을 지불하고 구매할 수 있고, MMA 부원은 $B_i$엔을 지불하고 구매할 수 있습니다.

일반인과 MMA 부원이 게임을 합니다. 일반인이 선공, MMA 부원이 후공으로 번갈아 가며 다음 동작을 반복합니다.

- 정크 마켓의 상품 중 아직 구매되지 않은 상품 $1$개를 선택해 구매합니다.

정크 마켓의 상품을 전부 구매하면 게임이 종료됩니다.

일반인이 지불한 금액을 $X$, MMA 부원이 지불한 금액을 $Y$라고 할 때, 일반인은 $X-Y$를 최소화하려고 하고 MMA 부원은 $X-Y$를 최대화하려고 합니다.

서로 최적으로 행동했을 때의 $X-Y$ 값을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$A_1\ A_2\ \cdots\ A_{2N}$
$B_1\ B_2\ \cdots\ B_{2N}$
```

## 제한

- $1 \leq N \leq 1\,000$
- $1 \leq A_i, B_i \leq 10^9$
- 입력은 전부 정수입니다.

## 출력

답을 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
100 200
150 300
```

#### 출력

```text
-200
```

일반인이 $1$번째 상품을 구매하면 MMA 부원은 $2$번째 상품을 구매할 수밖에 없으므로 $X-Y=100-300=-200$이 됩니다.

### 예제 2 {file=""}

#### 입력

```text
3
100 200 350 400 550 600
400 200 300 100 150 500
```

#### 출력

```text
-50
```
