양의 정수 $N,M$과 순열 $A=(A_1,A_2,\ldots,A_N)$가 주어집니다.

순열 $P=(P_1,P_2,\ldots,P_N)$ 중, 각 $i$에 대해 처음 $x=i$로 두고 $x$를 $P_x$로 바꾸는 조작을 $M$번 수행한 결과가 $A_i$가 되는 것의 개수를 $10^9+7$로 나눈 나머지를 구하세요.

## 입력

```text
N M
A_1 A_2 ... A_N
```

$1\le N\le10^3$, $1\le M\le10^9$이고 $A$는 순열입니다.

## 출력

조건을 만족하는 순열 $P$의 개수를 출력하세요.
