## 문제 설명

$xy$평면 위의 $4$점 $(1,1),(1,H),(W,H),(W,1)$을 꼭짓점으로 하는 직사각형 영역 안(경계선 포함)에 격자점 $N$개 $(x_1,y_1),(x_2,y_2),\ldots,(x_N,y_N)$가 있습니다.

이 영역 안의 격자점 중 주어진 $N$개의 모든 점까지의 맨해튼 거리가 같은 점의 개수를 구하세요.

즉, 다음 조건을 모두 만족하는 정수 $2$개로 이루어진 순서쌍 $(X,Y)$의 개수를 구하세요.

- $X$는 $1 \le X \le W$를 만족합니다.
- $Y$는 $1 \le Y \le H$를 만족합니다.
- 어떤 정수 $d$가 존재하여 $|X-x_i|+|Y-y_i|=d$가 모든 $i$에 대해 성립합니다. $1 \le i \le N$입니다.

## 입력

```text
$W\ H$
$N$
$x_1\ y_1$
$x_2\ y_2$
$\vdots$
$x_N\ y_N$
```

입력은 다음 제한을 만족합니다.

## 제한

- $W$, $H$, $N$, $x_i$, $y_i$는 정수입니다.
- $1 \le W \le 10^9$
- $1 \le H \le 10^9$
- $2 \le N \le 100\,000$
- $1 \le x_i \le W$ ($1 \le i \le N$)
- $1 \le y_i \le H$ ($1 \le i \le N$)
- $(x_i,y_i) \ne (x_j,y_j)$ ($1 \le i,j \le N$, $i \ne j$)

## 출력

조건을 만족하는 점의 개수를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 5
3
1 3
3 5
5 1
```

#### 출력

```text
2
```

조건을 만족하는 점은 $(3,2),(4,3)$의 $2$개입니다.

```

조건을 만족하는 점은 $(2,2)$의 $1$개입니다.

```

#### 출력

```text
3
```

조건을 만족하는 점은 $(2,2),(3,2),(4,2)$의 $3$개입니다.
