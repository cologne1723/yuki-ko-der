트리에서 정점 1에 말을 놓고 인접한 미방문 정점으로 번갈아 이동합니다. 한 번 방문한 정점은 다시 방문할 수 없습니다. Halc는 종료까지 턴 수를 최대화하고 Sapp는 최소화합니다. Halc가 선공 또는 후공일 때의 종료 턴 수를 각각 구하세요.

## 입력

```text
N
a1 b1
...
aN-1 bN-1
```

## 출력

Halc가 선공인 경우와 후공인 경우의 답을 각각 출력하세요.
