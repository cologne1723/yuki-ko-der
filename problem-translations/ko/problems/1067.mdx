## 문제 설명

상자 $N$개가 있습니다. $i$번 상자($1 \le i \le N$)에는 공이 $A_i$개 들어 있습니다.

더 구체적으로, $i$번 상자에는 색 $1$부터 색 $A_i$까지 모든 색의 공이 하나씩 들어 있습니다.

이때 $Q$개의 쿼리에 답하세요. $i$번째 쿼리($1 \le i \le Q$)는 다음과 같습니다.

- 각 상자에서 공을 하나씩 꺼냈을 때, 색 $l_i$부터 색 $r_i$까지 각각의 색에 대해 그 색의 공이 $p_i$개 포함되는 경우의 수를 $998244353$으로 나눈 나머지를 모두 구하고, 그 배타적 논리합을 $998244353$으로 나눈 나머지를 출력하세요.

## 입력

```text
$N\ Q$
$A_1\ A_2\ \dots\ A_N$
$l_1\ r_1\ p_1$
$l_2\ r_2\ p_2$
$\vdots$
$l_Q\ r_Q\ p_Q$
```

첫째 줄에 상자의 개수 $N$과 쿼리의 개수 $Q$가 주어집니다.

둘째 줄에 $i$번 상자에 들어 있는 공의 개수를 나타내는 정수 $A_i$가 주어집니다.

그다음 $Q$개 줄에 각 쿼리의 정수 $l_i$, $r_i$, $p_i$가 주어집니다.

## 제한

- $1 \le N \le 6\,000$
- $1 \le Q \le 5\,000$
- $1 \le A_i \le 10^9$ ($1 \le i \le N$)
- $1 \le l_i \le r_i \le \max(A_1,A_2,\dots,A_N)$ ($1 \le i \le Q$)
- $0 \le r_i-l_i \le 200$ ($1 \le i \le Q$)
- $0 \le p_i \le N$ ($1 \le i \le Q$)
- 입력은 모두 정수입니다.

## 출력

$Q$개의 쿼리에 답하고, 마지막에 줄바꿈을 출력하세요.
