문자 `(` `A`개, `)` `B`개, `o` `C`개, `x` `D`개로 이루어진 문자열 중 다음 조건을 만족하는 것의 개수를 `10^9+7`로 나눈 나머지를 구하세요.

모든 `o`를 `()`, 모든 `x`를 `)(`로 치환한 결과가 올바른 괄호 문자열이어야 합니다.

<details>
<summary>올바른 괄호 문자열의 정의</summary>

올바른 괄호 문자열은 다음 조건 중 하나를 만족하는 문자열입니다.

- 빈 문자열
- 올바른 괄호 문자열인 비어 있지 않은 문자열 $s,t$가 존재하며, 이 순서대로 이어 붙인 문자열
- 올바른 괄호 문자열인 문자열 $s$가 존재하며, `(`, $s$, `)`를 이 순서대로 이어 붙인 문자열

</details>

## 제약

- `1 <= T <= 10^5`
- `0 <= A,B,C,D <= 10^5`
- `A+B+C+D >= 1`

## 입력

첫째 줄에 테스트 케이스 수 `T`, 각 테스트 케이스에 `A B C D`가 주어집니다.

## 출력

각 테스트 케이스의 답을 `10^9+7`로 나눈 나머지로 출력하세요.
