반지름이 `r`인 원에 내접하는 삼각형 중 넓이가 가장 큰 삼각형의 넓이를 구하세요.

## 입력

입력은 표준 입력으로 주어집니다.

- 첫째 줄에 테스트 케이스 수 `t`가 주어집니다.
- 다음 `t`개 줄에 각각 원의 반지름 `r`이 주어집니다.

## 제약

- `1 <= t <= 100`
- `1 <= r <= 100`

## 출력

각 테스트 케이스에 대해 최대 넓이를 한 줄에 하나씩 출력하세요.
