## 문제 설명

길이가 $N$인 수열 $A$가 주어집니다. $Q$개의 질의가 주어지므로, 주어진 순서대로 처리하세요.

질의는 다음 $3$가지 형식 중 하나입니다.

- $1\ k\ x$: $A_k$의 값을 $x$로 변경합니다.
- $2$: $A$를 값의 오름차순으로 정렬합니다.
- $3\ k$: $A_k$의 값을 출력합니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ Q$
$A_1\ \cdots\ A_N$
$\mathrm{query}_1$
$\mathrm{query}_2$
$\vdots$
$\mathrm{query}_Q$
```

첫째 줄에 수열의 길이 $N$과 질의의 개수 $Q$가 공백으로 구분되어 주어집니다.

둘째 줄에 수열 $A$의 $N$개 원소가 공백으로 구분되어 주어집니다.

그다음 $Q$개 줄에 주어진 순서대로 처리할 질의가 하나씩 주어집니다. $i$번째 질의인 $\mathrm{query}_i$는 다음 형식 중 하나입니다.

```text
$1\ k\ x$
```

```text
$2$
```

```text
$3\ k$
```

## 제한

- $1\leq N,Q\leq 3\times 10^5$
- $1\leq A_1,A_2,\ldots,A_N\leq 10^{18}$
- $1\ k\ x$ 형식의 질의에 대해 $1\leq k\leq N$, $1\leq x\leq 10^{18}$
- $3\ k$ 형식의 질의에 대해 $1\leq k\leq N$
- 입력은 모두 정수입니다.

## 출력

$3$번 형식의 질의 개수를 $q$라고 할 때, $q$개의 줄을 출력하세요. $j$번째 줄에는 $3$번 형식의 질의 중 $j$번째 질의에 대한 답을 출력하세요. $(1\leq j\leq q)$
