흰 공 `N`개에 각각 `1,2,...,N` 번호가 붙어 있습니다. `i`번째 작업에서 공 `A_i` 또는 공 `B_i` 중 하나를 검은색으로 칠합니다.

`N`번의 작업으로 모든 공을 검은색으로 칠할 수 있는지 판정하세요. 가능하다면 각 작업에서 선택할 공도 출력하세요.

## 제약

- `1 <= N <= 10^5`
- `1 <= A_i,B_i <= N`

## 입력

첫째 줄에 `N`, 다음 `N`개 줄에 `A_i B_i`가 주어집니다.

## 출력

불가능하면 `-1`을 출력하세요. 가능하면 각 작업에서 선택할 공의 번호를 출력하세요.
