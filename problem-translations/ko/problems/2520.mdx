평면의 몬스터 $i$는 $(X_i,Y_i)$에 있고 체력 $H_i$를 가집니다. $(x,y)$에서 폭발 마법을 쓰면 몬스터 $i$의 체력이 $\max(M-|x-X_i|-|y-Y_i|,0)$만큼 감소합니다. 정확히 $i$마리의 체력이 0 이하가 되는 점들의 영역 넓이를 $998244353$으로 계산하세요.

## 입력

```text
N M
X1 Y1 H1
...
XN YN HN
```

## 출력

각 $i=1,\ldots,N$에 대한 넓이를 출력하세요.
