## 문제 설명

타로 군은 $a$-$b$ 파스칼의 삼각형을 생각했습니다. 첫 번째 단을 $a$, $b$로 하고, $n$번째 단의 왼쪽에서 $k$번째 숫자를 $(n,k)$라고 할 때 다음과 같이 정의합니다.

- $k=1$일 때 $(n,k)=a$입니다.
- $k=n+1$일 때 $(n,k)=b$입니다.
- 그 외에는 $(n,k)=(n-1,k)+(n-1,k-1)$입니다.

$a$, $b$, $n$, $k$가 주어졌을 때 $(n,k)$가 무엇인지, 그리고 $n$번째 단의 각 수를 제곱한 값의 합이 얼마인지 구하세요. 두 답을 각각 줄을 바꾸어 출력하세요.

답은 매우 커질 수 있으므로 $10^9+7$로 나눈 나머지를 출력하세요.

(문제 설명을 수정했습니다. 2020년 7월 26일 10시 51분)

## 입력

```text
a b
n k
```

$2 \leq n \leq 200\,000$

$2 \leq k \leq n$

$1 \leq a,b \leq 10^{18}$

## 출력

첫 번째 줄에 $a$-$b$ 파스칼의 삼각형의 $(n,k)$를 출력하세요.

두 번째 줄에 $a$-$b$ 파스칼의 삼각형의 $n$번째 단에서 각 수를 제곱한 값의 합을 출력하세요.

답은 $10^9+7$로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1 1
2 2
```

#### 출력

```text
2
6
```

$1$-$1$ 파스칼의 삼각형의 두 번째 단은 $1,2,1$이므로 $(2,2)$는 $2$이고, 제곱의 합은 $1^2+2^2+1^2=6$입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
67463748573648574 73849583747586922
200000 100000
```

#### 출력

```text
279914183
789206154
```
