$N$개의 양의 정수 $A_i$와 양의 정수 $M,C$가 주어집니다. $s=1,\ldots,\sum A_i$ 각각에 대해 $A$에서 $C$개를 골라 합이 $s$가 되는 방법의 수를 $M$으로 나눈 나머지를 구하세요.

## 입력

```text
N M C
A_1 ... A_N
```

$1\le N\le90$, $2\le M\le10^9$, $1\le C\le N$, $\sum A_i\le10^5$입니다.

## 출력

각 $s$의 답을 공백으로 구분해 출력하세요.
