## 문제 설명

유키코다국에는 $1$번부터 시작하는 번호가 붙은 국도가 있습니다. 국도를 구별하기 위해 같은 번호의 국도는 두 개 이상 존재하지 않습니다.

유키코다성에서 국도 $1$호선이 시작합니다. 국도는 반드시 언젠가 왼쪽과 오른쪽 길로 갈라집니다. 국도는 더 작은 번호의 국도부터 사용 가능한 더 작은 번호를 사용하여 분기하며, 분기할 때 왼쪽 국도의 번호는 오른쪽 국도보다 반드시 작습니다.

$1$호선은 왼쪽 $2$호선과 오른쪽 $3$호선으로 갈라집니다. $2$호선은 왼쪽 $4$호선과 오른쪽 $5$호선, $3$호선은 왼쪽 $6$호선과 오른쪽 $7$호선으로 갈라집니다. $4$호선은 왼쪽 $8$호선과 오른쪽 $9$호선, $5$호선은 왼쪽 $10$호선과 오른쪽 $11$호선으로 갈라집니다. 이 규칙으로 국도 번호가 붙습니다.

A는 유키코다성을 출발해 되돌아가지 않고 여러 분기점을 지났습니다. 각 분기점에서 왼쪽과 오른쪽 중 어느 쪽으로 갔는지 순서대로 기억하고 있습니다. 현재 몇 호선을 걷고 있는지 구하세요.

## 입력

```text
$S$
```

분기 방향을 나타내는 문자열 $S$가 주어집니다. $S$는 `L`과 `R`로 이루어져 있습니다.

`L`은 왼쪽, `R`은 오른쪽으로 이동했음을 뜻합니다. 문자열의 앞쪽이 가장 오래된 기억이고 뒤로 갈수록 최근 기억입니다. $S$가 빈 문자열일 수 있지만, 입력 끝에는 반드시 줄바꿈 문자가 있습니다. 따라서 빈 문자열인 경우에도 줄바꿈 문자 하나를 입력받습니다.

## 제한

$0 \le |S| \le 30$

## 출력

A가 걷고 있는 국도 번호를 한 줄에 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
LR
```

#### 출력

```text
5
```

처음 $1$호선에서 왼쪽으로 가면 $2$호선, 다시 오른쪽으로 가면 $5$호선입니다. 첫 분기에서 $1$호선은 왼쪽 $2$호선과 오른쪽 $3$호선으로 나뉘고, 다음 분기에서 $2$호선은 왼쪽 $4$호선과 오른쪽 $5$호선으로 나뉩니다.

### 예제 2 {file=""}

#### 입력

```text
RLL
```

#### 출력

```text
12
```

$1$호선에서 오른쪽으로 $3$호선, 왼쪽으로 $6$호선, 다시 왼쪽으로 $12$호선에 도착합니다. 각 분기의 왼쪽과 오른쪽 국도는 차례로 $2$호선과 $3$호선, $6$호선과 $7$호선, $12$호선과 $13$호선입니다.
