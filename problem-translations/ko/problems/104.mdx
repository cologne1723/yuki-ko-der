## 문제 설명

유키코다국에는 1번부터 시작하는 번호가 붙은 국도가 있습니다. 국도를 구별하기 위해 같은 번호의 국도는 두 개 이상 존재하지 않습니다.

유키코다성에서 국도 1호선이 시작합니다. 국도는 반드시 언젠가 왼쪽과 오른쪽 길로 갈라집니다. 국도는 더 작은 번호의 국도부터 사용 가능한 더 작은 번호를 사용하여 분기하며, 분기할 때 왼쪽 국도의 번호는 오른쪽 국도보다 반드시 작습니다.

1호선은 왼쪽 2호선과 오른쪽 3호선으로 갈라집니다. 2호선은 왼쪽 4호선과 오른쪽 5호선, 3호선은 왼쪽 6호선과 오른쪽 7호선으로 갈라집니다. 4호선은 왼쪽 8호선과 오른쪽 9호선, 5호선은 왼쪽 10호선과 오른쪽 11호선으로 갈라집니다. 이 규칙으로 국도 번호가 붙습니다.

A는 유키코다성을 출발해 되돌아가지 않고 여러 분기점을 지났습니다. 각 분기점에서 왼쪽과 오른쪽 중 어느 쪽으로 갔는지 순서대로 기억하고 있습니다. 현재 몇 호선을 걷고 있는지 구하세요.

## 입력

```text
S
```

분기 방향을 나타내는 문자열 $S$가 주어집니다. $S$는 `L`과 `R`로 이루어진 길이 0 이상 30 이하의 문자열입니다.

`L`은 왼쪽, `R`은 오른쪽으로 이동했음을 뜻합니다. 문자열의 앞쪽이 가장 오래된 기억이고 뒤로 갈수록 최근 기억입니다. 입력 문자열은 마지막에 반드시 줄 바꿈이 포함되므로 길이 0인 입력은 주어지지 않습니다.

## 출력

A가 걷고 있는 국도 번호를 한 줄에 출력하세요.

## 예제

```text
LR
```

```text
5
```

처음 1호선에서 왼쪽으로 가면 2호선, 다시 오른쪽으로 가면 5호선입니다.

```text
RLL
```

```text
12
```

1호선에서 오른쪽으로 3호선, 왼쪽으로 6호선, 다시 왼쪽으로 12호선에 도착합니다.
