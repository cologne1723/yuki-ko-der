지난주 공개된 yukicoder contest 509의 D문제 「[슈퍼피보나치 수 찾기](https://yukicoder.me/problems/no/3625)」를 원안으로 작성한 문제입니다.

따라서 콘테스트 종료 직후 이 문제를 공개할 예정이었지만, 출제자의 부주의로 신청 날짜가 $1$주일 늦어졌습니다. 죄송합니다.

## 문제 설명

양의 정수 $K$가 주어집니다.

다음 조건을 모두 만족하는 가장 작은 양의 정수 $n$을 구하세요. 존재하지 않는다면 $-1$을 출력하세요.

- $n$의 자릿수 합은 $K$입니다.
- $10^x\leq n<10^{x+1}$를 만족하는 유일한 정수를 $x$라 하고, $n$을 십진수로 해석했을 때 $10^i$의 자리의 값을 $n_i$라 정의합니다. 모든 $0\leq i\leq x-2$를 만족하는 음이 아닌 정수 $i$에 대해 $n_{i+2}>n_{i+1}+n_i$가 성립해야 합니다.

$n<100$일 때는 항상 $2$번째 조건을 만족한다는 점에 유의하세요.

$T$개의 테스트 케이스가 주어지므로 각각에 대해 답을 구하세요.

## 입력

```text
$T$
$Test_1$
$Test_2$
$\vdots$
$Test_T$
```

$T$는 테스트 케이스의 개수입니다. 각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$K$
```

## 제한

- 입력되는 값은 모두 정수입니다.
- $1\leq T\leq 1\,000$
- $1\leq K\leq 1\,000\,000$
- 모든 테스트 케이스의 $K$의 합은 $1\,000\,000$ 이하입니다.

## 출력

$T$줄에 걸쳐 출력하세요.

$i$번째 줄에는 $i$번째 테스트 케이스의 답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2
16
9231
```

#### 출력

```text
79
-1
```

$1$번째 테스트 케이스에서는 $n=952, 8\,521, 97$ 등이 문제 설명의 조건을 만족합니다. 문제 설명의 조건을 만족하는 가장 작은 양의 정수는 $79$이므로 $79$를 출력합니다.

$2$번째 테스트 케이스에서는 조건을 만족하는 $n$이 존재하지 않으므로 $-1$을 출력합니다.
