## 문제 설명

$256$자리 이진수를 잘 선택하여, 다음 조건을 앞에서부터 순서대로 최대한 많이 만족시키세요.

조건 $i$ ($0 \le i < 2\,048$): 다음 $3$가지 중 적어도 $1$가지를 만족합니다.

1. **오른쪽에서** $(a_i + 1)$번째 자리가 $p_i$입니다.
2. **오른쪽에서** $(b_i + 1)$번째 자리가 $q_i$입니다.
3. **오른쪽에서** $(c_i + 1)$번째 자리가 $r_i$입니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$a_0\ b_0\ c_0\ p_0\ q_0\ r_0$
$a_1\ b_1\ c_1\ p_1\ q_1\ r_1$
$\vdots$
$a_{2\,047}\ b_{2\,047}\ c_{2\,047}\ p_{2\,047}\ q_{2\,047}\ r_{2\,047}$
```

$a_i$, $b_i$, $c_i$, $p_i$, $q_i$, $r_i$는 입력으로 주어지는 정수입니다.

## 제한

- 입력의 모든 정수는 다음 범위에서 같은 확률로 무작위로 선택됩니다.
- $0 \le a_i, b_i, c_i < 256$
- $p_i$, $q_i$, $r_i$는 각각 $0$ 또는 $1$입니다.

## 출력

$256$자리 이진수를 출력하세요. $1$번째 문자가 `'0'` 또는 `'1'`이 아니면 WA입니다. 그 외의 경우, 읽어 들인 자리 수가 부족하면 부족한 자리 수만큼 앞에 `'0'`이 추가됩니다. 자리 수가 많으면 처음 $256$자리만 읽어 들입니다.

## 채점 방법

만족하지 못한 조건 중 번호가 가장 작은 조건의 번호가 해당 케이스의 점수입니다. 모든 조건을 만족했다면 해당 케이스의 점수는 $2\,048$점입니다.

테스트 케이스는 $100$개이며, 모든 케이스의 점수 합이 제출의 점수가 됩니다.
