이 문제는 **인터랙티브 문제**(여러분이 작성한 프로그램과 저지 프로그램이 표준 입출력을 통해 상호작용하는 형식의 문제)입니다.

## 이야기

$80$%의 확률로만 계산에 성공하는 계산기로 계산하는 모습을 시뮬레이션해 봅시다.

## 문제 설명

변수 $A$, $B$, $C$ 중 $1$개에 $x \times y$의 값이 저장된 상태로 만드는 것이 목표입니다.

여기에는 $A$, $B$, $C$라는 $3$개의 변수가 있습니다. 처음에 변수 $A$, $B$는 저지 시스템이 미리 준비한 양의 정수 $x$, $y$로 각각 초기화되고, $C$는 $0$으로 초기화됩니다.

$1 \leq x \leq 888$, $1 \leq y \leq 888$입니다.

여러분은 이 변수에 대해 다음 조작 $1$ 또는 조작 $2$ 중 $1$개를 수행할 수 있습니다.

- **조작 $1$**: 변수 $A$, $B$, $C$ 중 $1$개를 선택해 그 값을 저지 시스템에 질의합니다.
  - 질의한 변수의 실제 값이 $z$일 때, 저지 시스템은 $80$%의 확률로 $z$를 반환하고, $20$%의 확률로 $1 \leq w \leq 8\,888\,888$, $w \neq z$를 만족하는 저지가 선택한 정수 $w$를 반환합니다. ($w$를 선택하는 방법이 **반드시 무작위인 것은 아닙니다**.)
- **조작 $2$**: 변수의 덧셈을 수행합니다. $A$, $B$, $C$ 중에서 중복을 허용하여 변수 $v_1$, $v_2$, $v_3$을 각각 $1$개씩 선택하고, 저지 시스템에 변수 $v_1$의 값과 변수 $v_2$의 값의 합(이하 이를 $s$라 합니다)을 변수 $v_3$에 대입하도록 합니다.
  - **단, $v_1 \neq v_3$, $v_2 \neq v_3$를 만족해야 합니다. 또한 조작할 때 $s$의 값이 $8\,888\,888$을 초과해서는 안 됩니다.**
  - 저지 시스템은 $80$%의 확률로 변수 $v_3$의 값을 $s$로 바꾸고, $20$%의 확률로 변수 $v_3$의 값을 저지가 선택한 $1 \leq w \leq 8\,888\,888$, $w \neq s$를 만족하는 정수 $w$로 바꿉니다. ($w$를 선택하는 방법이 **반드시 무작위인 것은 아닙니다**.)
  - 이때 변수 $v_1$과 $v_2$의 값은 바뀌지 않고 그대로입니다.

$8\,888$회 이내의 조작으로 목표를 달성하세요.

$x$, $y$의 값은 상호작용을 시작하기 전에 결정됩니다.

## 입력

이 문제는 **인터랙티브 문제**(여러분이 작성한 프로그램과 저지 프로그램이 표준 입출력을 통해 상호작용하는 형식의 문제)입니다.

조작 $1$에 대한 질문의 답은 다음 형식으로 표준 입력에 주어집니다.

```text
$z$
```

여기서 $z$는 저지 시스템에서 반환되는 질문의 답입니다. 자세한 내용은 문제 설명을 참고하세요.

조작 $2$에 대한 질문의 답은 다음 형식으로 표준 입력에 주어집니다.

```text
$z$
```

조작 $2$가 정상적으로 수행되면 $z = 0$이 주어집니다. 단, **변수 $v_3$의 값이 $s$로 바뀌었는지는 알려 주지 않는다는 점에 주의하세요.**

잘못된 질문을 했거나 조작 횟수의 합이 $8\,888$회를 초과하면 $z = -1$이 주어집니다. 이 경우 이미 오답으로 판정되었으므로 즉시 프로그램을 종료하세요.

## 제한

- $1 \leq x, y \leq 888$
- $x$, $y$는 정수입니다.

## 출력

조작 $1$을 수행할 때는 다음 형식으로 출력하세요. 여기서 $v$는 값을 질의할 변수의 이름이며, `A`, `B`, `C` 중 $1$개입니다.

```text
$?\ v$
```

조작 $2$를 수행할 때는 다음 형식으로 출력하세요. 여기서 $v_1$, $v_2$, $v_3$은 덧셈에 사용할 변수의 이름이며, `A`, `B`, `C` 중 $1$개입니다. 또한 $v_1 \neq v_3$, $v_2 \neq v_3$를 만족하도록 선택해야 합니다.

```text
$+\ v_1\ v_2\ v_3$
```

변수 $A$, $B$, $C$ 중 $1$개에 $x \times y$의 값이 저장된 상태가 되면 다음 형식으로 보고하세요. 여기서 $v$는 $x \times y$가 저장된 변수의 이름이며, `A`, `B`, `C` 중 $1$개입니다.

```text
$!\ v$
```

지정한 변수의 값이 $x \times y$이면 정답이고, 그렇지 않으면 오답입니다.

**출력할 때마다 반드시 표준 출력을 flush하세요. 그렇지 않으면 TLE가 될 수 있습니다.**

잘못된 출력을 하면 저지 결과는 정의되지 않습니다.

입력으로 $z = -1$이 주어진 뒤 프로그램을 즉시 종료하지 않으면 저지 결과는 정의되지 않습니다.

$x \times y$가 저장된 변수를 보고한 뒤에는 프로그램을 즉시 종료하세요. 그렇지 않으면 저지 결과는 정의되지 않습니다.

**$x \times y$가 저장된 변수를 보고하는 출력은 질문 횟수에 포함되지 않습니다.**

인터랙티브 문제에 익숙하지 않다면 [인터랙티브 형식 문제에 관한 안내](https://yukicoder.me/wiki/reactive)도 확인하세요.

## 예제

다음은 $x = 2$, $y = 4$인 경우의 정답이 되는 입출력 예입니다.

아래의 「설명」에서는 각 변수의 실제 값을 바탕으로 설명하지만, 실제로는 이 값을 직접 확인할 수 없다는 점에 주의하세요.

### 예제 1 {file=""}

#### 출력

```text
? A
```

변수 $A$의 값을 질문합니다.

#### 입력

```text
2
```

저지 시스템이 $2$를 반환했습니다. 이처럼 저지 시스템이 질문한 변수의 값을 반환하는 일은 $80$%의 확률로 발생합니다.

#### 출력

```text
? B
```

변수 $B$의 값을 질문합니다.

#### 입력

```text
3123142
```

저지 시스템이 $3\,123\,142$를 반환했습니다. 이처럼 저지 시스템이 질문한 변수의 값과 다른 값을 반환하는 일은 $20$%의 확률로 발생합니다.

#### 출력

```text
+ A B C
```

변수 $C$에 변수 $A$, $B$의 값의 합을 대입하는 조작을 요청합니다.

#### 입력

```text
0
```

조작 $2$가 정상적으로 수행되었으므로 $0$이 반환되었지만, 실제로 대입된 값은 $2 + 4 = 6$이 아니라 $1\,128\,089$였습니다. 따라서 $(A, B, C) = (2, 4, 1\,128\,089)$가 됩니다. 이처럼 $2$개 변수의 합과 다른 정수로 바뀌는 일은 $20$%의 확률로 발생합니다.

#### 출력

```text
+ B B C
```

변수 $C$에 변수 $B$, $B$의 값의 합을 대입하는 조작을 요청합니다. $v_1 = v_2$여도 된다는 점에 주의하세요.

#### 입력

```text
0
```

조작 $2$가 정상적으로 수행되었으므로 $0$이 반환되었고, 실제로 $4 + 4 = 8$이 대입되었습니다. 따라서 $(A, B, C) = (2, 4, 8)$이 됩니다. 이처럼 $2$개 변수의 합으로 바뀌는 일은 $80$%의 확률로 발생합니다.

#### 출력

```text
! C
```

변수 $C$의 값이 $x \times y = 2 \times 4 = 8$임을 보고했습니다. 실제로 $C = 8$이므로 정답입니다. 여기서 프로그램을 종료하세요.
