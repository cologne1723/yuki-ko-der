## 문제 설명

문자열 $S$의 각 문자를 자유롭게 재배열했을 때, 연속하는 부분문자열로 나타나는 `yukari`의 개수를 $Y$, `akari`의 개수를 $A$, `yuzukizu`의 개수를 $X$라고 합니다. 가능한 $Y$, $A$, $X$의 최댓값을 각각 구하세요.

단, $Y$, $A$, $X$의 값은 각각 독립적으로 구해야 합니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$S$
```

문자열 $S$가 주어집니다.

## 제한

- 입력은 모두 영소문자로 이루어집니다.
- $1\leq |S|\leq 10^6$ ($|S|$는 $S$의 길이입니다.)
- $S$는 영소문자로 이루어집니다.

## 출력

답을 다음과 같이 출력하세요.

```text
$Y\ A\ X$
```

## 예제

### 예제 1 {file=""}

#### 입력

```text
yuzukizuari
```

#### 출력

```text
1 0 1
```

이 문자열은 잘 재배열하면 `yukari`와 `yuzukizu`를 각각 $1$개씩 만들 수 있습니다.

- $S$를 `yukarizuzui`로 재배열합니다. 이때 연속하는 부분문자열로 나타나는 `yukari`의 개수는 $1$개입니다.
- $S$를 `yuzukizuari`로 재배열합니다. 이때 연속하는 부분문자열로 나타나는 `yuzukizu`의 개수는 $1$개입니다.

반대로 `akari`는 $S$의 각 문자를 어떻게 재배열해도 만들 수 없습니다.
