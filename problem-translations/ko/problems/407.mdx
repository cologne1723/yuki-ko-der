## 문제

타로는 오늘도 가까운 강둑에 왔습니다. 곧 N마리(N ≥ 3)의 오리 무리가 쉬러 왔습니다. 이 오리들은 조금 별나서 다음 규칙으로 쉴 장소를 정한다고 합니다.

강은 충분히 길고 곧게 흐르므로 강둑과 평행하도록 x축을 잡고, 적당한 원점 x = 0을 정합니다. 오리 i (0 ≤ i < N)가 쉴 장소를 x축 위에서 좌표가 xᵢ인 점으로 나타냅니다. 좌표의 열 (x₀, x₁, ..., xₙ₋₁)은 다음 조건을 만족합니다. 여기서 L은 N마리의 오리 모두가 좋아하는 하나의 양의 정수입니다.

1. x₀, x₁, ..., xₙ₋₁은 모두 음이 아닌 정수입니다.
2. 0 ≤ x₀ < x₁ < x₂ < ... < xₙ₋₁ ≤ L입니다.
3. x₁ − x₀ = x₂ − x₁ = ... = xₙ₋₁ − xₙ₋₂ = d이며, d는 소수입니다.

좌표의 열이 위 조건을 만족할 때에만 이를 오리 등소수 간격 수열이라고 합니다. 오리 무리의 부탁을 받은 타로는 오리 등소수 간격 수열인 좌표 열의 개수 Mₙ,ₗ을 계산하려 했지만 잘할 수 없었습니다. N과 L이 주어질 때 대신 Mₙ,ₗ을 계산하세요.

## 입력

첫째 줄에 양의 정수 N과 L이 공백으로 주어집니다.

```text
N L
```

- 3 ≤ N ≤ 10^6
- 1 ≤ L ≤ 10^7

## 출력

음이 아닌 정수 Mₙ,ₗ을 한 줄에 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
3 5
```

### 샘플 1 출력 {file="sample1.out"}

```text
2
```

이 경우 오리 등소수 간격 수열인 (x₀, x₁, x₂)는 (0, 2, 4)와 (1, 3, 5)뿐입니다.

### 샘플 2 {file="sample2.in"}

```text
5 12
```

### 샘플 2 출력 {file="sample2.out"}

```text
6
```

오리 등소수 간격 수열인 (x₀, x₁, x₂, x₃, x₄)는 다음 6개뿐입니다.

- (0, 2, 4, 6, 8)
- (0, 3, 6, 9, 12)
- (1, 3, 5, 7, 9)
- (2, 4, 6, 8, 10)
- (3, 5, 7, 9, 11)
- (4, 6, 8, 10, 12)
