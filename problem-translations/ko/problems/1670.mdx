`N`종류의 피규어를 모읍니다. `M`종류의 가챠 중 `i`번째를 뽑으면 피규어 `1`부터 `A_i` 중 하나를 같은 확률로 얻습니다.

모든 종류를 하나 이상 얻을 때까지 가챠를 뽑되, 기대 횟수가 최소가 되도록 선택합니다. 이때 기대 횟수를 `998244353`으로 나눈 값을 출력하세요.

## 제약

- `1 <= N <= 2 * 10^5`
- `1 <= M <= N`
- `1 <= A_i <= N`, `A_i < A_{i+1}`, `A_M=N`

## 입력

`N M`과 `A_1,...,A_M`이 주어집니다.

## 출력

기대 횟수를 `998244353`으로 나눈 값을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2 2
1 2
```

#### 출력

```text
499122179
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
5 3
1 3 5
```

#### 출력

```text
349385533
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
2000 10
20 123 234 456 489 1029 1342 1567 1890 2000
```

#### 출력

```text
832309006
```
