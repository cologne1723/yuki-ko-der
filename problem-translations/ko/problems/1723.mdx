`X^A`가 `Y^B`의 배수인지 판정하세요.

## 제약

- `1 <= X,Y <= 10^12`
- `1 <= A,B <= 10^16`

## 입력

`X A Y B`가 주어집니다.

## 출력

배수이면 `Yes`, 아니면 `No`를 출력하세요.
