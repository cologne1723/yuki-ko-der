문자열로 같은 수를 세 번 이어 붙여 만든 수를 3배수라고 정의합니다. 단, 최상위 자리가 0인 수는 3배수가 아닙니다. 예를 들어 111과 141414는 3배수이고 000과 010101은 아닙니다.

## 문제

$1$ 이상 $N$ 이하의 3배수 개수를 구하세요.

## 입력

```text
N
```

$1\le N\le10^{15}$입니다.

## 출력

답을 출력하세요.
