## 문제

N개의 지점 1,2,…,N이 순서대로 직선 위에 놓여 있고, 지점 i의 고도는 Hi입니다.

ushi는 현재 지점 1에 있습니다. 지점 1을 제외한 모든 지점을 한 번 이상 방문하려고 합니다. 끝나는 지점은 어디든 괜찮습니다.

다음 두 조작을 몇 번이든 할 수 있습니다.

* 인접한 지점으로 이동합니다. 등산을 싫어하므로 현재 지점 i에서 인접한 지점 j로 이동할 때 max(0,Hj−Hi)의 에너지를 소비합니다.
* 원하는 지점으로 워프합니다. 워프 1회마다 에너지 P를 소비합니다.

모든 지점을 방문하는 데 필요한 최소 에너지를 구하세요.

## 입력

```text
N P
H1 H2 … HN
```

첫 번째 줄에 지점 수 N (2 ≤ N ≤ 200000)과 워프 1회의 에너지 P (0 ≤ P ≤ 10^9)가 주어집니다.

두 번째 줄에 각 지점의 고도 Hi (0 ≤ Hi ≤ 10^9)가 주어집니다.

## 출력

모든 지점을 방문하는 데 필요한 최소 에너지를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
6 3
1 1 10 10 100 100
```

출력:

```text
3
```

지점 1에서 지점 6으로 에너지 3을 소비해 워프한 뒤 지점 5,4,3,2 순서로 이동할 수 있습니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
6 5
100 1 3 0 10 100
```

출력:

```text
7
```

지점 1,2,3 순서로 이동한 뒤 지점 3에서 지점 6으로 워프하고 지점 5,4로 이동할 수 있습니다. 지점 2에서 3으로 이동할 때 2, 워프할 때 5를 소비해 합계는 7입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
10 1000000000
0 1000000000 0 1000000000 0 1000000000 0 1000000000 0 1000000000
```

출력:

```text
5000000000
```

답이 32비트 정수형에 들어가지 않을 수 있으므로 주의하세요.

### 샘플 4 {file="sample4.in"}

입력:

```text
4 0
0 1000000000 0 1000000000
```

출력:

```text
0
```

모든 지점을 워프해 방문하면 됩니다.
