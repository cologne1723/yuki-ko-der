## 문제 설명

빨강, 초록, 파랑 돌을 $1$개씩 사용하면 장신구 $1$개를 만들 수 있습니다.

같은 색 돌 $2$개를 다른 색 돌 $1$개로 교환할 수 있습니다.

처음 가지고 있는 빨강·초록·파랑 돌로 장신구를 최대 몇 개 만들 수 있는지 구하세요.

## 입력

```text
$R\ G\ B$
```

정수 $R,G,B$는 각각 빨강, 초록, 파랑 돌의 개수입니다.

## 제한

$0 \le R,G,B \le 10\,000\,000$

## 출력

만들 수 있는 장신구의 최대 개수를 한 줄에 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 1 1
```

#### 출력

```text
1
```

빨강 돌 $2$개, 초록 돌 $1$개, 파랑 돌 $1$개가 있습니다. 각 색 돌을 $1$개씩 사용하면 장신구 $1$개를 만들 수 있고, 빨강 돌 $1$개가 남지만 더는 장신구를 만들 수 없습니다.

### 예제 2 {file=""}

#### 입력

```text
1 0 3
```

#### 출력

```text
1
```

빨강 돌 $1$개, 초록 돌 $0$개, 파랑 돌 $3$개가 있습니다. 초록 돌이 없지만 파랑 돌 $2$개를 초록 돌 $1$개로 바꿀 수 있습니다. 그러면 빨강·초록·파랑 돌을 $1$개씩 사용해 장신구 $1$개를 만들 수 있습니다.

### 예제 3 {file=""}

#### 입력

```text
2 2 0
```

#### 출력

```text
0
```

빨강 돌 $2$개, 초록 돌 $2$개, 파랑 돌 $0$개가 있습니다. 이 경우에는 어떻게 해도 장신구를 만들 수 없습니다.

### 예제 4 {file=""}

#### 입력

```text
5 18 36
```

#### 출력

```text
16
```
