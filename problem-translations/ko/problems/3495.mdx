## 문제 설명

다음 문제를 생각합니다.

입력으로 $4$개의 양의 정수 $N$, $M$, $L$, $B$가 주어집니다.

다음 값을 $B$로 나눈 나머지를 구하세요. 이 값을 이 문제의 답이라고 합니다.

$\displaystyle \sum_{n=0}^{\lfloor \frac{N}{2} \rfloor} \binom{N}{2n} M^n L^{\lfloor \frac{N}{2} \rfloor - n}$

단, $\lfloor \frac{N}{2} \rfloor$는 $\frac{N}{2}$를 넘지 않는 가장 큰 정수를 나타냅니다.

입력의 $1$번째 줄에 양의 정수 $T$가 주어집니다. $T$개의 문제에 답하세요.

## 입력

각 양의 정수 $t$ ($T$ 이하)에 대해, $t$번째 문제에 대한 입력 $N$, $M$, $L$, $B$를 각각 $N_t$, $M_t$, $L_t$, $B_t$로 나타냅니다.

입력은 다음 형식으로 표준 입력에서 $1+T$개의 줄에 걸쳐 주어집니다.

```text
$T$
$N_1\ M_1\ L_1\ B_1$
$\vdots$
$N_T\ M_T\ L_T\ B_T$
```

- $1$번째 줄에 $T$가 주어집니다.
- $T$ 이하의 각 양의 정수 $t$에 대해, $1+t$번째 줄에 $N_t$, $M_t$, $L_t$, $B_t$가 반각 공백으로 구분되어 주어집니다.

## 제한

입력은 다음 제한을 만족합니다.

- $T$는 $1 \leq T \leq 10\,000$을 만족하는 정수입니다.
- $T$ 이하의 임의의 양의 정수 $t$에 대해 다음을 만족합니다.
  - $N_t$는 $1 \leq N_t \leq 10^{18}$을 만족하는 정수입니다.
  - $M_t$는 $1 \leq M_t \leq 10^{18}$을 만족하는 정수입니다.
  - $L_t$는 $1 \leq L_t \leq 10^{18}$을 만족하는 정수입니다.
  - $B_t$는 $1 \leq B_t \leq 10^9$를 만족하는 정수입니다.

## 출력

$T$ 이하의 각 양의 정수 $t$에 대해, $t$번째 줄에 $t$번째 문제에 대한 답을 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
1 1 2 3
2 2 3 5
3 1 2 3
4 2 1 3
```

#### 출력

```text
1
0
2
2
```

$1$번째 문제에 대해,

$\displaystyle \sum_{n=0}^{\lfloor \frac{N}{2} \rfloor} \binom{N}{2n} M^n L^{\lfloor \frac{N}{2} \rfloor - n} = \binom{1}{0} 1^0 2^0 = 1$

이고, $1$을 $B = 3$으로 나눈 나머지는 $1$입니다.

$2$번째 문제에 대해,

$\displaystyle \sum_{n=0}^{\lfloor \frac{N}{2} \rfloor} \binom{N}{2n} M^n L^{\lfloor \frac{N}{2} \rfloor - n} = \binom{2}{0} 2^0 3^1 + \binom{2}{2} 2^1 3^0 = 3 + 2 = 5$

이고, $5$를 $B = 5$로 나눈 나머지는 $0$입니다.

$3$번째 문제에 대해,

$\displaystyle \sum_{n=0}^{\lfloor \frac{N}{2} \rfloor} \binom{N}{2n} M^n L^{\lfloor \frac{N}{2} \rfloor - n} = \binom{3}{0} 1^0 2^1 + \binom{3}{2} 1^1 2^0 = 2 + 3 = 5$

이고, $5$를 $B = 3$으로 나눈 나머지는 $2$입니다.

$4$번째 문제에 대해,

$\displaystyle \sum_{n=0}^{\lfloor \frac{N}{2} \rfloor} \binom{N}{2n} M^n L^{\lfloor \frac{N}{2} \rfloor - n} = \binom{4}{0} 2^0 1^2 + \binom{4}{2} 2^1 1^1 + \binom{4}{4} 2^2 1^0 = 1 + 12 + 4 = 17$

이고, $17$을 $B = 3$으로 나눈 나머지는 $2$입니다.
