## 문제

heno 군은 길이 $N$의 정수열 $A_1,\ldots,A_N$과 정수 $X$를 가지고 있습니다. 정수열에서 0개 이상을 골라 선택한 모든 정수의 비트별 배타적 논리합을 계산했을 때 결과가 $X$가 되는 선택 방법의 수를 생각합니다.

heno 군은 XOR을 아주 좋아해 이 문제는 조금 쉬웠습니다. 그래서 다음 형식의 조건 $M$개를 추가합니다.

- $0\ l\ r$: $A_l,\ldots,A_r$에서 고르는 개수는 짝수입니다. 0개도 가능합니다.
- $1\ l\ r$: $A_l,\ldots,A_r$에서 고르는 개수는 홀수입니다.

모든 조건을 만족하면서 XOR 결과가 $X$가 되도록 고르는 방법의 수를 $10^9+7$로 나눈 나머지를 구하세요. 아무것도 고르지 않았을 때 XOR은 0입니다.

## 입력

~~~text
$N\ M\ X$
$A_1\ A_2\ \cdots\ A_N$
$type_1\ l_1\ r_1$
$\vdots$
$type_M\ l_M\ r_M$
~~~

$1\leq N\leq300$, $0\leq M\leq\min(300,N(N+1)/2)$, $0\leq X,A_i\leq10^9$입니다. $type_i$는 0 또는 1이고 $1\leq l_i\leq r_i\leq N$입니다. 서로 다른 조건의 $(l_i,r_i)$는 다릅니다.

입력은 모두 정수입니다.

## 출력

조건을 만족하는 선택 방법의 수를 $10^9+7$로 나눈 나머지를 한 줄에 출력하세요.

## 예제

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
4 2 3
1 1 2 2
0 2 3
0 1 4
~~~

#### 출력

~~~text
2
~~~

가능한 선택은 {a_1,a_4}와 {a_2,a_3}입니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
4 1 3
1 1 2 2
1 1 4
~~~

#### 출력

~~~text
0
~~~

전체에서 홀수 개를 고르면서 XOR을 3으로 만들 수 없습니다.

#### 입력

~~~text

1 2 3 4 5 6 7
0 2 4
0 5 6
1 2 6
~~~

#### 출력

~~~text
0
~~~
