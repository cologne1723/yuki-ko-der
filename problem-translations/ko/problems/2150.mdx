29XX년, yukicoder는 유료 서비스가 되었다냥. 사이트 서포터가 아닌 사용자는 문제를 한 문제 풀 때마다 1엔을 내야 한다냥. 매일 사이트 서포터가 될지 선택할 수 있으며, 서포터가 되면 하루 회비 $K$엔과 가입 시점의 가입비 $X$엔을 내야 한다냥. 가입비는 전날 서포터가 아니었던 사람이 다음 날 서포터가 될 때 부과된다냥.

ramdos 군은 내일부터 $N$일 동안 과거 문제를 풀 계획이다냥. $i$일 후에 $A_i$문제를 풀 예정이고, 오늘은 서포터가 아니다냥. 목표를 달성하는 데 필요한 최소 비용을 구하라냥.

## 조건

- $1\le N\le2\times10^5$
- $1\le K,X\le10^9$
- $1\le A_i\le10^9$

## 입력

```text
N K X
A_1 A_2 \cdots A_N
```

## 출력

필요한 비용의 최솟값을 출력하라냥.

예제는 원문을 참고하라냥.
