평면 위의 서로 다른 $N$개 점 $P_i$가 주어진다냥. 좌표 중복을 허용해 $n+1$개의 점 $Q_0,\ldots,Q_n$을 배치하여 모든 $P_i$가 어떤 선분 $Q_{j-1}Q_j$ 위에 놓이도록 할 때 가능한 양의 정수 $n$의 최솟값을 구하라냥.

## 조건

- $1\le N\le12$
- $\lvert X_i\rvert,\lvert Y_i\rvert\le100$

## 입력

```text
$N$
$X_1\ Y_1$
$X_2\ Y_2$
$\vdots$
$X_N\ Y_N$
```

## 출력

최솟값을 출력하라냥.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
6
0 0
2 0
3 1
2 2
0 2
-1 1
```

#### 출력

```text
3
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
4
3 1
0 0
5 -2
5 -5
```

#### 출력

```text
2
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1
-100 -100
```

#### 출력

```text
1
```

6
