$H\times W$ 격자에 음이 아닌 정수를 써서 각 행의 합이 $A_i$ 이상 $B_i$ 이하가 되게 합니다. 각 열 합을 $S_j$라 할 때, 모든 가능한 작성 방법에 대한 $S_1S_2\cdots S_W$의 합을 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
H W
A1 B1
...
AH BH
```

## 출력

답을 출력하세요.
