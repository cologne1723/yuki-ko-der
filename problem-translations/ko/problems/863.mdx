## 문제

E869120 군은 yukicoder에 소스 코드를 제출했습니다.

그 결과 다음과 같은 정보를 얻었습니다.

- $N=5000$일 때 실행 시간은 소수점 이하를 버려 $A$밀리초입니다.
- $N=200000$일 때 실행 시간은 소수점 이하를 버려 $B$밀리초입니다.

그가 제출한 소스 코드는 계산량이 정확히 $P\cdot N$회 ($P$는 자연수)인 코드이거나, 정확히 $Q\cdot N^2$회 ($Q$는 자연수)인 코드 중 하나입니다.

실행 시간 정보로 판단하여 계산량이 선형 시간($P\cdot N$회)이면 $1$을, $N^2$에 비례하면 $2$를 출력하세요.

yukicoder의 저지 시스템은 매우 안정적이므로 실행 속도는 항상 변하지 않는다고 가정합니다.

## 제약

- $A$는 $1$ 이상 $25000000$ 이하인 정수입니다.
- $B$는 $1$ 이상 $1000000000$ 이하인 정수입니다.
- 입력은 문제문의 조건을 만족합니다.

## 입력

~~~text
$A$
$B$
~~~

## 출력

계산량이 선형 시간($P\cdot N$회)이면 $1$을, $N^2$에 비례하면 $2$를 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 샘플

### 샘플 1 {file=""}

#### 입력

~~~text
2
106
~~~

#### 출력

~~~text
1
~~~

$N=5000$일 때 2밀리초, $N=200000$일 때 106밀리초가 걸렸으므로 선형 시간이라고 보는 것이 타당합니다.

### 샘플 2 {file=""}

#### 입력

~~~text
77
124200
~~~

#### 출력

~~~text
2
~~~

$N=5000$일 때 77밀리초, $N=200000$일 때 124200밀리초(124.2초)가 걸렸으므로 $N^2$에 비례하는 시간이라고 보는 것이 타당합니다.

### 샘플 3 {file=""}

#### 입력

~~~text
2160000
86400000
~~~

#### 출력

~~~text
1
~~~

보통은 있을 수 없는 일이지만, 이 제출은 상수 배수가 매우 큰 선형 시간 풀이인 듯합니다. 왜 그럴까요?
