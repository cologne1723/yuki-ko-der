## 문제 설명

양의 정수 $N$이 주어집니다.

$\sigma(n)=d(n)^N$을 만족하는 양의 정수 $n$의 총합을 소수 $998\,244\,353$으로 나눈 나머지를 구하세요.

단, $\sigma(n)$은 $n$의 양의 약수의 합을, $d(n)$은 $n$의 양의 약수 개수를 나타냅니다.

## 입력

```text
$N$
```

## 제한

- $1\le N\le10^2$

## 출력

$\sigma(n)=d(n)^N$을 만족하는 양의 정수 $n$의 총합을 소수 $998\,244\,353$으로 나눈 나머지를 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
1
```

### 예제 2 {file=""}

#### 입력

```text
2
```

#### 출력

```text
4
```
