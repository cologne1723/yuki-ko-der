비음이 아닌 정수 성분의 $3\times3$ 행렬 $A$와 양의 정수 $N,B$가 주어집니다. $A^N x$가 단위 정육면체 $[0,1]^3$에 속하는 모든 실수 벡터 $x$의 집합을 $X$라 하고 그 부피를 $V$라 합니다. $V^{-1}$을 $B$로 나눈 나머지를 구하세요. $V=0$이면 답은 무한대입니다.

## 입력

```text
N B
A의 3개 행
```

## 출력

답을 출력하세요.
