## 문제 설명

각 원소가 값 집합 $\{1,2,3\}$의 원소인 길이 $N$의 수열 $(x_1,\dots,x_N)$ 중 다음 $M$개의 조건을 모두 만족하는 것이 존재하는지 판정하세요.

존재한다면 그중 $1$개를 출력하세요.

조건 $i$는 $x_{p_i}=a_i$와 $x_{q_i}=b_i$라는 $2$개의 등식 중 적어도 $1$개가 성립한다는 뜻입니다.

## 입력

```text
$N\ M$
$p_1\ q_1\ a_1\ b_1$
$\vdots$
$p_M\ q_M\ a_M\ b_M$
```

입력은 모두 정수입니다.

## 제한

- $2\le N\le 100\,000$
- $1\le M\le 100\,000$
- $1\le p_i<q_i\le N$
- $1\le a_i\le 3$이며 $1\le b_i\le 3$

## 출력

모든 조건을 만족하는 $(x_1,\dots,x_N)$이 존재한다면, 그중 $1$개를 공백으로 구분하여 출력하세요.

존재하지 않는다면 $-1$을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2
1 2 1 2
2 3 2 1
```

#### 출력

```text
1 2 3
```

조건은 $(x_1=1 \vee x_2=2)\wedge(x_2=2 \vee x_3=1)$입니다.

예를 들어 $x_1=1$, $x_2=2$, $x_3=3$은 조건을 만족합니다.
