양의 정수 변수 $N$에 대해 다음 조작을 원하는 횟수만큼 수행할 수 있습니다. 조작하지 않아도 됩니다.

양의 정수 $A,B$를 골라 $A+B=N$이라 선언하고, $N$을 $A\times B$로 바꿉니다.

## 문제

현재 $N=X$일 때, 조작을 반복해 $N=Y$로 만들 수 있는지 판정하세요.

## 입력

```text
T
X Y
```

$1\le T\le2\times10^5$, $1\le X,Y\le10^9$입니다.

## 출력

각 테스트 케이스에 대해 가능하면 `Yes`, 불가능하면 `No`를 출력하세요.
