## 문제

`1/N`을 순환소수로 나타냈을 때 순환 마디의 길이를 구하세요. 유한소수로 나타낼 수 있는 경우 길이는 `1`로 합니다.

`T`개의 테스트 케이스에 답하세요.

## 입력

첫째 줄에 `T`, 각 테스트 케이스에 `N`이 주어집니다.

`1\le T\le100`, `2\le N\le10^9`입니다.

## 출력

각 답을 한 줄에 출력하세요.
