직사각형 $0\le x\le n$, $0\le y\le m$에서 $(0,0)$에서 $(n,m)$까지 이동합니다. 한 번 방문한 점은 다시 방문할 수 없고, 다음 다섯 이동 중 하나만 할 수 있습니다: $(x+1,y-1)$, $(x+1,y)$, $(x+1,y+1)$, $(x,y+1)$, $(x-1,y+1)$. 가능한 이동 방법 수를 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
T
n m
```

## 출력

각 테스트 케이스의 답을 출력하세요.
