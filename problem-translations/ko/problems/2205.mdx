$N$개 정점의 트리가 주어지고 각 정점은 흰색($0$) 또는 검은색($1$)이다냥. 간선을 하나 골라 양 끝 정점의 색을 동시에 반전하는 조작을 원하는 만큼 할 수 있다냥. 모든 정점을 검은색으로 만들 수 있는지 판정하고, 가능하면 최소 조작 횟수를 구하라냥.

## 조건

- $2\le N\le2\times10^5$
- $c_i$는 0 또는 1이다냥.

## 입력

```text
N
a_1 b_1
\vdots
a_{N-1} b_{N-1}
c_1 \cdots c_N
```

## 출력

가능하면 최소 횟수를, 불가능하면 $-1$을 출력하라냥.
