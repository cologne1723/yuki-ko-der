서로 다른 길이 $M$의 소문자 문자열 $S_1,\ldots,S_N$이 주어집니다.

## 문제

모든 $S_i$가 부분 문자열(연속일 필요 없음)이 되는 길이 $M+1$의 소문자 문자열 $T$의 개수를 구하세요.

## 입력

```text
N M
S_1
...
S_N
```

$2\le N\le M$, $4\le NM\le10^6$이며 문자열들은 서로 다릅니다.

## 출력

답을 출력하세요.
