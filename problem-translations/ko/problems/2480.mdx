합이 $N$이고, 등장하는 원소 종류가 정확히 두 개의 서로 인접한 양의 정수인 수열의 길이가 될 수 있는 값의 종류 수를 구하세요.

## 조건

- $1\le N\le10^9$

## 입력

```text
N
```

## 출력

가능한 길이의 종류 수를 출력하세요.
