일렬로 놓인 $N$개의 수정 중 실체가 있는 수정과 환영이 있을 수 있습니다. 모든 구간에 포함된 실체 수정 개수의 홀짝을 기록했더니 홀수인 구간이 $K$개였습니다. 가능한 수정 배열의 수를 $998244353$으로 나눈 나머지를 구하세요.

## 조건

- $1\le T\le10^5$
- $1\le N_i\le10^5$
- $0\le K_i\le N_i(N_i+1)/2$

## 입력

```text
T
N1 K1
...
NT KT
```

## 출력

각 테스트 케이스의 답을 출력하세요.
