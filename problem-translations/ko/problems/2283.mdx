0, 1, ?로 이루어진 길이 $N$의 문자열 $S$가 주어집니다. 모든 `?`를 0 또는 1로 바꾸어 같은 문자가 세 번 연속 나타나지 않게 할 수 있는지 판정하세요. 문자열의 끝과 시작은 연결되어 있다고 합니다.

$T$개의 테스트 케이스를 처리하세요.

## 조건

- $1\le T\le 5\times10^4$
- $3\le N\le 10^5$
- 모든 테스트 케이스의 $N$의 합은 $2\times10^5$ 이하입니다.

## 입력

첫째 줄에 $T$가 주어지고, 각 테스트 케이스에 $N,S$가 주어집니다.

## 출력

가능하면 `Yes`, 불가능하면 `No`를 출력하세요.
