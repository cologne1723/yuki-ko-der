## 문제 설명

$N$개의 정점과 $0$개의 변이 있는 무방향 그래프가 있습니다. 각 정점에는 처음에 $0$이 쓰여 있습니다.

다음 쿼리를 $Q$회 처리하세요.

$i$번째 쿼리에서는 $T_i$, $A_i$, $B_i$가 주어집니다.

- $T_i=1$일 때

  정점 $A_i$와 정점 $B_i$ 사이에 새로운 무방향 변을 추가합니다.

  변을 추가한 뒤에도 그래프는 단순 그래프(자기 자신으로의 변과 여러 변을 갖지 않는 그래프)임이 보장됩니다.

- $T_i=2$일 때

  정점 $A_i$를 포함하는 연결 성분에 속한 모든 정점(정점 $A_i$를 포함)에 쓰인 수에 $B_i$를 더합니다.

- $T_i=3$일 때

  현재 정점 $A_i$에 쓰인 수를 출력합니다.

입출력량에 주의하세요. `std::cin`/`std::cout`을 사용하면 `scanf`/`printf`를 사용한 경우보다 약 $600$ms 느려졌습니다.

## 입력

```text
$N\ Q$
$T_1\ A_1\ B_1$
$T_2\ A_2\ B_2$
$T_3\ A_3\ B_3$
$\hspace{16pt}\vdots$
$T_Q\ A_Q\ B_Q$
```

첫째 줄에 정점의 개수 $N$과 쿼리의 개수 $Q$가 주어집니다.

이후 $Q$개의 줄에 $i$번째 쿼리의 $T_i$, $A_i$, $B_i$가 주어집니다.

## 제한

$1 \le N \le 5 \times 10^5$

$1 \le Q \le 5 \times 10^5$

$T_i$는 $1$, $2$, $3$ 중 하나입니다.

- $T_i=1$일 때: $1 \le A_i \le N$, $1 \le B_i \le N$
- $T_i=2$일 때: $1 \le A_i \le N$, $-2000 \le B_i \le 2000$
- $T_i=3$일 때: $1 \le A_i \le N$, $B_i=0$

그래프는 항상 단순 그래프입니다.

입력은 모두 정수입니다.

## 출력

$T_i=3$인 모든 쿼리에 대한 답을 한 줄에 하나씩 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 9
2 1 10
3 1 0
1 1 2
2 2 20
1 1 3
2 2 40
3 1 0
3 2 0
3 3 0
```

#### 출력

```text
10
70
60
40
```

쿼리 1: 정점 1에 쓰인 수가 $0$에서 $10$이 됩니다.

쿼리 2: 정점 1에 쓰인 수는 $10$입니다.

쿼리 3: 정점 1과 정점 2를 연결합니다.

쿼리 4: 정점 2와 연결된 정점 1, 2에 쓰인 수에 $20$을 더합니다.

쿼리 5: 정점 1과 정점 3을 연결합니다.

쿼리 6: 정점 2와 연결된 정점 1, 2, 3에 쓰인 수에 $40$을 더합니다.

쿼리 7: 정점 1에 쓰인 수는 $70$입니다.

쿼리 8: 정점 2에 쓰인 수는 $60$입니다.

쿼리 9: 정점 3에 쓰인 수는 $40$입니다.
