## 이야기

ゆーてぃーさん은 자신의 이름에 들어 있는 `U`와 `T`가 알파벳 순서에서 서로 이웃한다는 사실을 알아차렸습니다.

이를 계기로 서로 이웃하는 다른 문자 조합도 있는지 알아보기로 했습니다.

## 문제 설명

알파벳 순서에서 서로 이웃한다는 것은, 영어 대문자 $2$개가 주어진 순서와 관계없이 알파벳 순서에서 연속한다는 뜻입니다. `A`와 `Z`는 서로 이웃하지 않습니다.

영어 대문자 $C_1, C_2$가 서로 이웃하는 문자 조합인지 판정하세요.

## 입력

```text
$C_1\;C_2$
```

## 제한

- $C_1, C_2$는 영어 대문자입니다.

## 출력

서로 이웃하는 문자 조합이면 `Yes`를, 그렇지 않으면 `No`를 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
U T
```

#### 출력

```text
Yes
```

알파벳 순서에서 `T` 다음은 `U`이며, `T`와 `U`는 서로 이웃하는 문자 조합이므로 `Yes`를 출력합니다.


### 예제 2 {file=""}

#### 입력

```text
A I
```

#### 출력

```text
No
```

`A`와 `I`는 서로 이웃하는 문자 조합이 아닙니다.


### 예제 3 {file=""}

#### 입력

```text
Y Z
```

#### 출력

```text
Yes
```
