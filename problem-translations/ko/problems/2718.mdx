## 문제

악기 `i`는 기본 음 높이 `A_i`와 그 `B_i`배까지의 배음을 동시에 냅니다. 두 악기의 조화도는 두 악기가 공통으로 내는 음 높이의 종류 수입니다.

모든 `i<j`에 대한 조화도의 최댓값을 구하세요.

## 제약

- `2 ≤ N ≤ 2×10^5`
- `1 ≤ A_i ≤ 2×10^5`, `1 ≤ B_i ≤ 10^9`

## 입력

```text
N
A_1 B_1
⋮
A_N B_N
```

## 출력

답을 출력하세요.
