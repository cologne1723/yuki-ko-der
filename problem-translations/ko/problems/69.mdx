## 문제 설명

같은 길이의 문자열 $A$와 문자열 $B$가 주어집니다.

문자열 $A$의 순서를 자유롭게 바꿀 수 있을 때, 문자열 $A$와 문자열 $B$를 같게 만들 수 있는지 판정하세요.

## 입력

```text
$A$
$B$
```

문자열 $A$와 $B$가 각각 $1$줄에 주어집니다. $2$개의 문자열의 길이는 항상 같습니다.

문자는 모두 소문자 알파벳 `a`부터 `z`로 구성됩니다.

## 제한

$1 \le |A|,|B| \le 10$

## 출력

가능하면 `YES`, 불가능하면 `NO`를 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
dog
god
```

#### 출력

```text
YES
```

`dog`의 `d`와 `g`를 바꾸면 `god`가 되므로 답은 `YES`입니다.

### 예제 2 {file=""}

#### 입력

```text
cat
tea
```

#### 출력

```text
NO
```

`cat`을 어떻게 재배열해도 `tea`로 만들 수 없으므로 답은 `NO`입니다.

### 예제 3 {file=""}

#### 입력

```text
silence
license
```

#### 출력

```text
YES
```

### 예제 4 {file=""}

#### 입력

```text
yukicoder
yukicoder
```

#### 출력

```text
YES
```

처음부터 $2$개의 문자열이 일치하는 경우도 있습니다.

### 예제 5 {file=""}

#### 입력

```text
hurjztkyua
urjukzthua
```

#### 출력

```text
NO
```

의미 없는 문자열이 입력으로 주어질 수도 있습니다.
