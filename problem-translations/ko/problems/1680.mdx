다음 두 조건을 모두 만족하는 정수쌍 `(x,y)`의 개수를 구하세요.

$\lvert x+y\rvert \leq A$, $\lvert x-y\rvert \leq B$

## 제약

- `0 <= A,B <= 10^18`

## 입력

`A B`가 주어집니다.

## 출력

답을 `10^9+7`로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1
```

#### 출력

```text
5
```

### 예제 2 {file=""}

#### 입력

```text
3 0
```

#### 출력

```text
3
```

### 예제 3 {file=""}

#### 입력

```text
998244353 924844033
```

#### 출력

```text
693995100
```
