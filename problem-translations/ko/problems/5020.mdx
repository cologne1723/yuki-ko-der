## 공지

**실행 시간 제한은 $1$초입니다.**

**또한 저지 상태에 따라 실행 시간이 최대 $0.05$~$0.1$초 정도 길게 표시될 수 있으니 주의하세요.**

## 문제 설명

책상 위에 $N$장의 카드가 놓여 있고, $1$부터 $N$까지의 번호가 붙어 있습니다. 각 카드의 앞면과 뒷면에는 무작위 $18$자리 정수가 쓰여 있습니다. 카드 $i$ $(1 \leq i \leq N)$의 앞면에는 정수 $A_i$가, 뒷면에는 정수 $B_i$가 쓰여 있습니다.

다음 조작을 $50$회 이내로 수행하여 카드 $1$의 앞면과 뒷면에 쓰인 정수를 가능한 한 $5 \times 10^{17}$에 가깝게 만드세요. 단, $\lfloor x \rfloor$는 $x$의 소수점 이하를 버린 값입니다.

- $2$장의 카드 $u$, $v$ $(1 \leq u,v \leq N,\ u \neq v)$를 선택합니다.
- 카드 $u$, $v$의 앞면에 현재 쓰인 정수를 각각 $a$, $b$라고 할 때, $2$장의 카드 앞면에 쓰인 정수를 각각 $\lfloor (a+b)/2 \rfloor$로 바꿉니다.
- 카드 $u$, $v$의 뒷면에 현재 쓰인 정수를 각각 $c$, $d$라고 할 때, $2$장의 카드 뒷면에 쓰인 정수를 각각 $\lfloor (c+d)/2 \rfloor$로 바꿉니다.

### 점수

모든 조작이 끝난 시점에 카드 $1$의 앞면과 뒷면에 쓰인 정수와 $5 \times 10^{17}$의 차의 절댓값을 각각 $V_1$, $V_2$라고 합니다.

이때 점수는 다음과 같이 계산됩니다.

$\left\lfloor 2\,000\,000 - 100\,000 \log_{10}(\max(V_1,V_2)+1) \right\rfloor$

만약 $\max(V_1,V_2)=0$이라면, 조작 횟수를 $X$라고 할 때 $2\,000\,050-X$점을 얻습니다.

단, 출력이 올바르지 않으면 `WA`로 판정됩니다. 올바르지 않은 출력은 다음과 같습니다.

- 출력 형식을 따르지 않은 경우. 특히 $u_i=v_i$인 경우
- 조작을 $50$회 초과하여 수행한 경우

테스트 케이스는 총 $50$개이며, 모든 테스트 케이스의 점수 합이 제출 점수가 됩니다.

만점은 $1$억 점입니다. 몇 점을 얻을 수 있을까요?

## 입력

```text
$N$
$A_1\ B_1$
$A_2\ B_2$
$\vdots$
$A_N\ B_N$
```

## 제한

- $N=45$
- $10^{17} \leq A_i < 10^{18}$ $(1 \leq i \leq N)$
- $10^{17} \leq B_i < 10^{18}$ $(1 \leq i \leq N)$
- $A_i$, $B_i$는 조건을 만족하는 정수 중 균일하게 무작위로 선택됩니다.

## 출력

조작 횟수를 $X$회라고 하고, $i$번째 조작 $(1 \leq i \leq X)$에서 선택하는 $2$장의 카드 번호를 $u_i$, $v_i$라고 할 때, 다음 형식으로 출력하세요.

```text
$X$
$u_1\ v_1$
$u_2\ v_2$
$\vdots$
$u_X\ v_X$
```

이 출력 예시에서는 조작에 따라 카드 $1$, $2$, $3$, $4$에 쓰인 정수가 다음과 같이 변합니다.

- 조작 전
  - 앞면: $3.3 \times 10^{17}$, $4.2 \times 10^{17}$, $5.6 \times 10^{17}$, $7.7 \times 10^{17}$
  - 뒷면: $4.7 \times 10^{17}$, $2.8 \times 10^{17}$, $5.4 \times 10^{17}$, $6.9 \times 10^{17}$
- $1$회 조작 후
  - 앞면: $3.3 \times 10^{17}$, $4.9 \times 10^{17}$, $4.9 \times 10^{17}$, $7.7 \times 10^{17}$
  - 뒷면: $4.7 \times 10^{17}$, $4.1 \times 10^{17}$, $4.1 \times 10^{17}$, $6.9 \times 10^{17}$
- $2$회 조작 후
  - 앞면: $3.3 \times 10^{17}$, $6.3 \times 10^{17}$, $4.9 \times 10^{17}$, $6.3 \times 10^{17}$
  - 뒷면: $4.7 \times 10^{17}$, $5.5 \times 10^{17}$, $4.1 \times 10^{17}$, $5.5 \times 10^{17}$
- $3$회 조작 후
  - 앞면: $4.8 \times 10^{17}$, $4.8 \times 10^{17}$, $4.9 \times 10^{17}$, $6.3 \times 10^{17}$
  - 뒷면: $5.1 \times 10^{17}$, $5.1 \times 10^{17}$, $4.1 \times 10^{17}$, $5.5 \times 10^{17}$

조작 종료 후 앞면에 쓰인 정수, 뒷면에 쓰인 정수와 $5 \times 10^{17}$의 차는 각각 $V_1=2 \times 10^{16}$, $V_2=10^{16}$입니다.

따라서 $\lfloor 2\,000\,000 - 100\,000 \times \log_{10}(\max(2 \times 10^{16},10^{16})+1) \rfloor=369\,897$점을 얻습니다.

**이 예제는 $N=4$이며, 문제의 제한을 만족하지 않는다는 점에 주의하세요.**
