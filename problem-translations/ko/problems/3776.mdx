## 문제 설명

아무것도 적혀 있지 않은 $3\times 3$ 격자가 있습니다. 다음 조건을 모두 만족하도록 각 칸에 양의 정수를 하나씩 적습니다. 위에서 $i+1$번째, 왼쪽에서 $j+1$번째 칸 $(0\le i,j<3)$에 적은 수를 $A_{ij}$라고 합니다.

- $i=0,1,2$에 대해 $A_{i0}A_{i1}A_{i2}=K$입니다.
- $j=0,1,2$에 대해 $A_{0j}A_{1j}A_{2j}=K$입니다.

즉, 각 행과 열에 있는 세 정수의 곱이 모두 정확히 $K$가 되도록 적습니다. 이러한 방법의 수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

$T$개의 테스트 케이스 각각에 대해 답하세요.

## 입력

```text
$T$
$case_1$
$case_2$
$case_3$
$\vdots$
$case_T$
```

$case_i$는 $i$번째 테스트 케이스이며, 다음 형식으로 주어집니다.

```text
$K$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $1\le T\le 10^5$
- $1\le K\le 10^6$

## 출력

$T$줄을 출력하세요. $i$번째 줄에는 $i$번째 테스트 케이스의 답을 출력하세요. 마지막에 줄바꿈을 출력하세요.

