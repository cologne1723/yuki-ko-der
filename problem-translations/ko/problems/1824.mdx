## 정의

세 원소의 수열 $v=(a_1,a_2,a_3)$가 다음 조건을 만족하면 카도마츠 열이라고 합니다.

- $a_1,a_2,a_3$가 모두 서로 다릅니다.
- $a_2$가 세 원소 중 가장 크거나 가장 작습니다.

길이 $2N$의 수열 $A=(N,N-1,\ldots,2,1,N,N-1,\ldots,2,1)$이 주어집니다. $(A_i,A_j,A_k)$가 카도마츠 열이 되는 $i<j<k$의 조합 수를 출력하세요.

## 입력

첫째 줄에 테스트 케이스 수 $T$가 주어지고, 각 테스트 케이스에 정수 $N$이 주어집니다.

```text
T
N
```

$1\le T\le10^4$, $3\le N\le10^6$입니다.

## 출력

각 테스트 케이스의 답을 줄바꿈해 출력하세요.
