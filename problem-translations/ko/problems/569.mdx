## 문제

누나는 강력한 힘을 얻어 26×26 격자의 경로를 셀 수 있게 되었습니다.

하지만 그 힘으로는 3×1000000000000000000 격자의 경로를 셀 수 없습니다. 누나를 도와주세요.

3×N 격자는 세로로 4개, 가로로 N+1개의 꼭짓점이 격자 모양으로 연결된 무방향 그래프입니다.

## 입력

```text
N
```

1 ≤ N ≤ 10^18

## 출력

3×N 격자의 왼쪽 위 꼭짓점에서 오른쪽 아래 꼭짓점까지 같은 꼭짓점을 두 번 지나지 않고 도착하는 방법의 수를 10^9+7로 나눈 나머지를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
1
```

출력:

```text
8
```

### 샘플 2 {file="sample2.in"}

입력:

```text
2
```

출력:

```text
38
```

### 샘플 3 {file="sample3.in"}

입력:

```text
100
```

출력:

```text
244451960
```
