리액티브 문제라고 쓰여 있지만 스페셜 저지 문제입니다. 해가 여러 개 존재합니다.

## 문제 설명

$3$ 이상 $10^6$ 이하를 만족하는 원하는 정수 $N$을 $1$개 선택하고, $xy$ 평면에서 둘레 위에 $N$개의 꼭짓점을 갖는 엄격한 볼록 $N$각형을 구성하세요.

단, 다음 조건을 모두 만족해야 합니다.

- 각 꼭짓점의 좌표 $(x_i,y_i)$는 $-10^9 \le x_i,y_i \le 10^9$를 만족하는 정수입니다.
- 연속한 $3$개의 꼭짓점을 순서대로 $p_i,p_j,p_k$라고 할 때, 점 $p_j$는 점 $p_i$와 점 $p_k$를 잇는 선분 위에 존재하지 않습니다.
- 서로 다른 임의의 $2$개 꼭짓점은 겹치지 않습니다.

**출력 형식에 주의하세요.**

스코어 문제는 제출 간격을 $5$분 비워야 합니다.

yukicoder의 사양상 출력은 최대 $20$MB이지만, 리액티브 저지로 만들어 이를 우회합니다.

따라서 실행 시간 제한에는 저지에 걸리는 시간도 포함됩니다. 저지는 최대 약 $600$ms가 걸리므로, 실질적인 **실행 제한 시간은 $2$초**입니다.

실행 시간을 측정할 때는 온라인 실행을 사용하세요. 다른 환경과 속도가 다를 수 있습니다.

출력량이 많으므로 빠른 언어를 사용하는 것을 권장합니다.

저지의 미비로 정답이 되어 버리는 예를 발견했다면 질문에 ‘어떤 경우에 정답이 되어 버리는지’를 알려 주세요. 가능하다면 대처 방법도 알려 주시면 감사하겠습니다.

시스템 테스트는 없지만, 저지의 미비 등으로 리저지가 진행될 수 있으므로 구현 방법에 따라 점수가 변동할 수 있습니다. 양해해 주세요.

## 입력

입력은 없습니다.

## 제한

- $3 \le N \le 10^6$

선택한 $N$이 점수가 됩니다.

$3 \le N \le 10^6$을 만족하지 않으면 부정답입니다.

## 출력

다음 형식으로 출력하세요.

```text
$N$
$x_1\ y_1$
$\vdots$
$x_N\ y_N$
```

먼저 $1$번째 줄에 선택한 $N$을 출력하세요.

그다음 $N$개의 꼭짓점을 **반시계 방향 순서**로 $N$줄에 걸쳐 출력하세요. $i+1$번째 줄에는 반시계 방향 순서에서 $i$번째 꼭짓점 $(x_i,y_i)$를 공백으로 구분하여 출력하세요.

형식에 맞지 않는 출력에 대한 저지의 동작은 정의되지 않습니다. 정답이 되지 않을 수 있습니다.

**저지의 사정상 공백과 개행은 구분됩니다. 모든 값을 공백으로 구분하여 $1$줄에 출력하는 등은 부정답입니다.**

**또한 마지막에는 반드시 개행하고, 반드시 플러시하세요.**
