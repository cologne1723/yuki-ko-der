길이 `2^N`인 수열 `A=(A_0,...,A_{2^N-1})`가 주어집니다. 원소는 `-1` 또는 `0` 이상 `2^30` 미만의 정수입니다.

모든 `-1`을 범위 내 정수로 바꾸어 모든 `i,j`에 대해 `A_{i XOR j} >= A_i XOR A_j`를 만족시킬 수 있는지 판정하고, 가능하면 한 가지 방법을 출력하세요.

## 제약

- `1 <= N <= 7`
- `-1 <= A_i < 2^30`

## 입력

`N`과 수열 `A`가 주어집니다.

## 출력

가능하면 조건을 만족하는 수열을 출력하고, 불가능하면 문제의 출력 형식에 따라 불가능함을 출력하세요.
