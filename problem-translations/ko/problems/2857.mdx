## 문제 설명

길이가 $N$이고 각 원소가 $1$ 이상 $M$ 이하인 정수열 중 다음 조건을 만족하는 것을 좋은 정수열이라고 합니다.

- 정수열을 $A$라고 할 때, $1 \leq i \leq N - 1$을 만족하는 모든 정수 $i$에 대해
  $\left|\left\lfloor \frac{M}{A_i} \right\rfloor - \left\lfloor \frac{M}{A_{i+1}} \right\rfloor\right| \leq K$

좋은 정수열은 모두 몇 가지 가능한지 구하세요.

답은 매우 커질 수 있으므로, $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ M\ K$
```

$N$, $M$, $K$는 정수입니다.

## 제한

- $1 \leq N \leq 10^9$
- $1 \leq M \leq 1\,000$
- $0 \leq K \leq M$
- 입력은 모두 정수입니다.

## 출력

문제의 답을 $998\,244\,353$으로 나눈 나머지를 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 3 1
```

#### 출력

```text
5
```

좋은 정수열로 가능한 것은 $(1, 1)$, $(2, 2)$, $(2, 3)$, $(3, 2)$, $(3, 3)$으로 총 $5$가지입니다.

### 예제 2 {file=""}

#### 입력

```text
100 100 38
```

#### 출력

```text
412066770
```

$998\,244\,353$으로 나눈 나머지를 출력하세요.
