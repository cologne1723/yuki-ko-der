길이 $N$의 수열 $A,B$가 주어집니다.

## 조작

다음 두 조작을 합쳐 최대 10000번 수행해 $\max(A)<\min(B)$를 만족시키세요.

- $(P,Q)$를 골라 $A_P$를 $A_P\oplus B_Q$로 바꿉니다.
- $(P,Q)$를 골라 $B_Q$를 $A_P\oplus B_Q$로 바꿉니다.

항상 조건을 만족하는 방법이 존재하며 최소 횟수일 필요는 없습니다.

<details>
<summary>비트 단위 XOR란? (클릭하여 펼치기)</summary>

두 음이 아닌 정수 $X,Y$에 대해 $X\oplus Y$는 다음과 같이 정의됩니다.

- $X\oplus Y$를 이진수로 나타냈을 때 $2^k$의 자리($k\geq0$)는, $X$와 $Y$의 해당 자리 중 정확히 하나가 $1$이면 $1$, 그렇지 않으면 $0$입니다.

예를 들어 $3\oplus5=6$, $1\oplus1=0$입니다.

</details>

## 입력

```text
N
A_1 ... A_N
B_1 ... B_N
```

$1\le N\le3000$, $1\le A_i,B_i<2^{30}$입니다.

## 출력

조건을 만족하는 조작 순서를 출력하세요.
