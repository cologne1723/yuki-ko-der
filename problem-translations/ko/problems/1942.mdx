정수 앞에 있는 0을 선행 0이라고 합니다. 양의 정수 $N$과 각각 선행 0을 0개 이상 붙인 길이 5의 문자열 $S_i$가 주어집니다.

## 문제

각 $S_i$에서 선행 0을 제거한 값을 출력하세요.

## 입력

```text
N
S_1
...
S_N
```

$1\le N\le10000$입니다.

## 출력

선행 0을 제거한 값을 각 줄에 출력하세요.
