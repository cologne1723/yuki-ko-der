## 문제

`2` 이상 `N` 이하의 정수 중 소인수의 개수의 최댓값을 구하세요. 소인수의 개수는 중복을 포함합니다.

## 제약

- `2 ≤ N ≤ 10^18`

## 입력

```text
N
```

## 출력

최댓값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
12
```

#### 출력

```text
2
```

### 예제 2 {file=""}

#### 입력

```text
1000000000000000000
```

#### 출력

```text
15
```
