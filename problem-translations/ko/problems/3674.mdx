## 문제 설명

Alice에게는 $N$가지 행동이 있고, Bob에게는 $M$가지 행동이 있습니다.

Alice가 $i\ (1 \leq i \leq N)$번 행동을 선택하고 Bob이 $j\ (1 \leq j \leq M)$번 행동을 선택했을 때, 점수는 $A_{i,j}$가 됩니다. 여기서 $A_{i,j}$는 음수일 수도 있습니다.

이 게임은 다음 순서로 진행됩니다.

1. Alice가 자신의 각 행동을 선택할 확률(확률 분포)을 정합니다.
2. Bob이 Alice가 정한 확률 분포를 알고 자신의 각 행동을 선택할 확률을 정합니다.
3. $2$명이 각자 정한 확률 분포에 따라 서로 독립적으로 행동을 $1$개씩 선택합니다.

Alice가 $i$번 행동을 선택할 확률을 $p_i$, Bob이 $j$번 행동을 선택할 확률을 $q_j$라고 하면 점수의 기댓값은

$\sum_{i=1}^{N}\sum_{j=1}^{M}p_iq_jA_{i,j}$

입니다. 단, $p_i, q_j \geq 0$, $\sum_{i=1}^{N} p_i = 1$, $\sum_{j=1}^{M} q_j = 1$입니다.

Alice는 점수의 기댓값을 최댓값으로 만들려고 하고, Bob은 점수의 기댓값을 최솟값으로 만들려고 합니다. Alice가 최적의 확률 분포를 선택하고, 이에 대해 Bob도 최적의 확률 분포를 선택했을 때의 점수의 기댓값, 즉

$\max_{\substack{p_i\geq0\\\sum_{i=1}^{N} p_i=1}}\min_{\substack{q_j\geq0\\\sum_{j=1}^{M} q_j=1}}\sum_{i=1}^{N}\sum_{j=1}^{M}p_iq_jA_{i,j}$

을 구하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

**※ 샘플 이외의 각 테스트 케이스에서 $A_{i,j}$는 무작위로 생성된 값입니다. 자세한 내용은 「입력의 생성 방법」 절을 확인하세요.**

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

$\mathrm{case}_k$는 $k$번째 테스트 케이스를 나타내며, 형식은 다음과 같습니다.

```text
$N\ M$
$A_{1,1}\ A_{1,2}\ \cdots\ A_{1,M}$
$A_{2,1}\ A_{2,2}\ \cdots\ A_{2,M}$
$\vdots$
$A_{N,1}\ A_{N,2}\ \cdots\ A_{N,M}$
```

## 제한

- $1\leq T\leq 20$
- $1\leq N,M\leq 200$
- $1$개의 입력에 포함된 모든 테스트 케이스에 대한 $N\times M$의 합은 $200\,000$ 이하입니다.
- $-10\,000\leq A_{i,j}\leq 10\,000$
- 입력되는 값은 모두 정수입니다.

## 입력의 생성 방법

$T$ 및 각 테스트 케이스의 $N, M$은 제한 범위 안에서 정해집니다.

샘플 이외의 테스트 케이스에서는 각 $A_{i,j}$가 정수 구간 $[-10\,000, 10\,000]$에서 서로 독립적으로 균등하게 선택됩니다.

단, 저지에 사용되는 테스트 케이스는 고정되어 있습니다.

## 출력

$T$줄을 출력하세요. $k$번째 줄에는 $k$번째 테스트 케이스에서 $2$명이 최적의 확률 분포를 선택했을 때의 점수의 기댓값을 출력하세요.

저지가 보유한 기준값은 참값과의 절대 오차가 $10^{-10}$ 이하임이 보장됩니다.

출력한 값과 기준값의 절대 오차 또는 상대 오차가 $10^{-6}$ 이하이면 정답으로 판정됩니다.

출력의 끝에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 1
3
2 2
1 -1
-1 1
2 2
-1 -4
-3 -2
```

#### 출력

```text
3.0
0.0
-2.5
```

$1$번째 테스트 케이스에서는 $2$명 모두 선택할 수 있는 행동이 $1$개뿐이므로 점수는 반드시 $3$입니다.

$2$번째 테스트 케이스에서는 Alice가 각 행동을 확률 $1/2$로 선택하면 Bob이 어느 행동을 선택해도 점수의 기댓값은 $0$입니다. 반면 Alice가 $1$개의 행동을 확률 $1/2$보다 크게 선택하면 Bob은 (Alice의 확률 분포를 알고 있으므로) 점수의 기댓값이 음수가 되는 행동을 선택할 수 있습니다. 따라서 $2$명이 최적의 확률 분포를 선택했을 때의 점수의 기댓값은 $0$입니다.

$3$번째 테스트 케이스에서는 Alice가 $1$번째 행동을 확률 $1/4$, $2$번째 행동을 확률 $3/4$로 선택하면 Bob이 어느 행동을 선택해도 점수의 기댓값은 $-5/2$입니다. 반면 Bob이 $1$번째와 $2$번째 행동을 각각 확률 $1/2$로 선택하면 Alice가 어느 행동을 선택해도 점수의 기댓값은 $-5/2$입니다. 따라서 Alice가 어떤 확률 분포를 선택해도 Bob은 점수의 기댓값을 $-5/2$ 이하로 만들 수 있습니다. 그러므로 $2$명이 최적의 확률 분포를 선택했을 때의 점수의 기댓값은 $-5/2$입니다.
