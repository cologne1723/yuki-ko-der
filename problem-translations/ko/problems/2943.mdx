## 문제 설명

인덱스는 $0$부터 시작합니다.

문자열 $s$, $t$와 정수 $i$에 대해 $F(s,t,i)$를 다음과 같이 정의합니다.

- 문자열 $u$가 있습니다. 처음에는 빈 문자열입니다.
- $j=0,1,\dots,|s|-1$에 대해, $2^j\lor i=i$라면 $u$의 끝에 $s_j$를 추가합니다.
  - 즉, $i$를 이진수로 나타냈을 때 $j$번째 자리가 $1$이라면 $u$의 끝에 $s_j$를 추가합니다.
- $F(s,t,i)$는 위의 조작으로 만들어진 $u$의 부분수열에 포함된 $t$의 개수입니다.

예를 들어 $s=$`aabc`, $t=$`ac`, $i=11$일 때 $u$는 `aac`가 됩니다.

그리고 $u$의 부분수열에는 `ac`가 $2$개 포함되어 있으므로 $F(s,t,i)=2$입니다.

이때 문자열 $S$와 $T$가 주어집니다. 다음 값을 $998\,244\,353$으로 나눈 나머지를 구하세요.

$\displaystyle\sum_{i=0}^{2^{|S|}-1} F(S,T,i)$

단, 이 문제에서 부분수열은 문자열에서 $0$개 이상의 요소를 제거한 뒤, 남은 요소를 원래 순서대로 연결하여 얻는 문자열로 정의합니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$S\ T$
```

$S$와 $T$는 영문 소문자로만 이루어진 문자열입니다.

## 제한

- $1\leq |T|\leq |S|\leq 10^5$
- $|T|\leq 10^3$
- $S$, $T$는 모두 영문 소문자로 이루어집니다.

## 출력

답을 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
aab ab
```

#### 출력

```text
4
```

예를 들어 $i=0$일 때 $u$는 빈 문자열이 됩니다.
$u$의 부분수열에 포함된 `ab`의 개수는 $0$입니다.

또한 $i=5$일 때 $u=$`ab`가 됩니다.
$u$의 부분수열에 포함된 `ab`의 개수는 $1$입니다.

이런 식으로 생각하면 답은 $0+0+0+0+0+1+1+2=4$가 됩니다.
