0 또는 1인 $N$항 수열 $A$를 앞에서부터 NAND한 결과를 $X$, 뒤에서부터 NAND한 결과를 $Y$라 합니다. NAND는 $[0,0]=[0,1]=[1,0]=1$, $[1,1]=0$으로 정의합니다.

## 문제

0이 $K$개, 1이 $N-K$개인 수열 중 $X=Y$인 것의 개수를 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
N K
```

$2\le N\le2\times10^5$, $0\le K\le N$입니다.

## 출력

답을 출력하세요.
