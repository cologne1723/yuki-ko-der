## 문제 설명

대회 사이트 “*h₂etkṓdr̥”에서 ganmodokix군의 색은 현재 파란색입니다.

ganmodokix군은 노란색이 되고 싶으므로, `ao`를 모두 `ki`로 바꾸고 싶어 합니다.

문자열 $S$가 주어집니다. $S$에 연속한 부분 문자열 `ao`가 있다면 이를 모두 `ki`로 바꾸어 출력하세요.

## 입력

```text
$S$
```

## 제한

- $S$는 모두 영소문자로 이루어집니다.
- $|S|=7$

## 출력

바꾼 뒤의 문자열을 출력하고, 마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
aoaoaoi
```

#### 출력

```text
kikikii
```

모든 `ao`를 각각 `ki`로 바꿉니다.

### 예제 2 {file=""}

#### 입력

```text
alohaoe
```

#### 출력

```text
alohkie
```

연속한 `ao`를 바꾸세요.

### 예제 3 {file=""}

#### 입력

```text
aokisan
```

#### 출력

```text
kikisan
```
