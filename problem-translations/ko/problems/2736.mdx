## 문제

사탕 `A+B`개를 Alice에게 `A`개, Bob에게 `B`개 나누었습니다. 상대가 가진 사탕 수가 자신의 사탕 수의 2배보다 많으면 불평합니다. 둘 다 불평하지 않는지 판정하세요.

## 제약

- `1 ≤ A,B ≤ 500`

## 입력

```text
A B
```

## 출력

둘 다 불평하지 않으면 `Yes`, 한 명이라도 불평하면 `No`를 출력하세요.
