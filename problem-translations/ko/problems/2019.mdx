문자열 $X$의 `?`를 숫자로 바꿔 얻는 문자열 중, 앞의 불필요한 $0$을 제거했을 때 $3$의 배수가 되는 것의 개수를 $f(X)$라 합니다. 주어진 문자열 $S$의 모든 연속 부분 문자열에 대한 $f$의 합을 구하세요.

## 입력

```text
N
S
```

$1\le N\le2\times10^5$이며 $S$는 숫자와 `?`로 이루어집니다.

## 출력

요구한 합을 $998244353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
1?3
```

#### 출력

```text
15
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
5
12345
```

#### 출력

```text
7
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
3
???
```

#### 출력

```text
414
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
32
31415926????????23846264????????
```

#### 출력

```text
945855420
```
