길이 $N$의 수열 $A$가 있다냥. 최대 $K$번까지 다음 조작을 할 수 있다냥. $1\le i\le N$을 골라 $A_i,A_{i+1},\ldots,A_N$을 각각 $i$만큼 증가시킨다냥. 조작 후 수열의 최솟값을 최대화했을 때 그 값을 구하라냥.

## 조건

- $1\le N\le10^5$
- $0\le K\le10^9$
- $0\le A_i\le10^{14}$

## 입력

```text
N K
A_1 \cdots A_N
```

## 출력

가능한 최솟값의 최댓값을 출력하라냥.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 2
3 4 2 1 0
```

#### 출력

```text
4
```

### 예제 2 {file=""}

#### 입력

```text
3 0
0 0 0
```

#### 출력

```text
0
```

### 예제 3 {file=""}

#### 입력

```text
10 100
901 780 604 576 569 569 515 488 379 100
```

#### 출력

```text
724
```

### 예제 4 {file=""}

#### 입력

```text
1 1000000000
100000000000000
```

#### 출력

```text
100001000000000
```
