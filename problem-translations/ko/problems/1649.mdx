2차원 평면의 `N`개 점 `p_i=(x_i,y_i)`가 주어집니다. 모든 점 쌍의 맨해튼 거리의 제곱의 합을 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `2 <= N <= 2 * 10^5`
- `1 <= x_i,y_i <= 10^9`
- 점들은 서로 다릅니다.

## 입력

첫째 줄에 `N`, 다음 `N`개 줄에 `x_i y_i`가 주어집니다.

## 출력

답을 `998244353`으로 나눈 나머지를 출력하세요.
