## 문제 설명

양의 정수 $A$, $B$, $C$가 주어집니다. $A^B$가 $C$로 나누어떨어지는 동안 $C$로 반복해서 나눌 수 있는 최대 횟수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

여기서 $C$는 $2$ 이상임이 보장됩니다.

$T$개의 테스트 케이스가 주어지므로 각각에 대해 답을 구하세요.

## 입력

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

여기서 $\mathrm{case}_i$는 $i$번째 테스트 케이스를 의미하며, 각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$A\ \ B\ \ C$
```

## 제한

- $1 \le T \le 100$
- $1 \le A, B \le 10^{40}$
- $2 \le C \le 10^{40}$
- 입력은 모두 정수입니다.

## 출력

각 테스트 케이스에 대해 $A^B$가 $C$로 나누어떨어지는 동안 $C$로 반복해서 나눌 수 있는 최대 횟수를 $998\,244\,353$으로 나눈 나머지를 출력하고 줄을 바꾸세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
2 3 4
1 2 3
2 1000000000 2
```

#### 출력

```text
1
0
1755647
```

$1$번째 테스트 케이스에서 $A^B=8$을 $4$로 반복해서 나눌 수 있는 최대 횟수는 $1$회입니다.

$2$번째 테스트 케이스에서 $A^B=1$은 $3$으로 나눌 수 없으므로 최대 횟수는 $0$회입니다.

$3$번째 테스트 케이스에서는 $998\,244\,353$으로 나눈 나머지를 출력해야 한다는 점에 주의하세요.
