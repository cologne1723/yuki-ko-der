격자점에 사는 UMA들의 위치가 주어집니다. 격자점이 아닌 곳에 서로 겹치지 않게 동서남북 방향의 KMA를 설치하여 각 UMA를 관찰할 수 있게 할 때 필요한 KMA의 최소 개수를 구하세요. 불가능하면 $-1$입니다.

## 조건

- $1\le N\le16$
- $0\le x_i,y_i\le1000$, UMA 위치는 서로 다릅니다.

## 입력

```text
$N$
$x_1$ $y_1$
\vdots
$x_N$ $y_N$
```

## 출력

최소 개수를 출력하세요.
