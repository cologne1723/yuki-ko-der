## 이야기

어떤 인기 태고 게임이 가까운 미래에 진화하여 돌아왔습니다. 판정도 기존 게임과 크게 달라져서, 노트마다 판정 종류의 구성이 달라집니다.

## 문제 설명

노트 수가 $N$인 곡의 플레이가 끝났습니다. $i$번째 노트($1 \leq i \leq N$)에는 $A_i+B_i$단계의 판정이 있습니다. 위에서부터 $A_i$종류에 해당하는 판정이면 콤보가 이어지고, 아래에서부터 $B_i$종류에 해당하는 판정이면 콤보가 끊깁니다.

이제 결과를 통해 최대 콤보가 $K$콤보였다는 것을 알게 되었습니다. 이와 같은 결과의 수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

노트 $1$개의 판정이라도 다르면 $2$개의 결과를 서로 다른 것으로 셉니다.

노트는 음표를, 콤보는 연속해서 위쪽 $A_i$단계의 판정으로 칠 수 있었던 횟수를, 최대 콤보는 곡이 끝날 때까지의 콤보 중 최댓값을, 결과는 성적이 기록된 것을 의미합니다.

## 입력

```text
$N\ K$
$A_1\ A_2\ \ldots\ A_N$
$B_1\ B_2\ \ldots\ B_N$
```

$1$번째 줄에 노트 수 $N$과 최대 콤보 $K$가 주어집니다.

$2$번째 줄에 각 노트의 콤보가 이어지는 판정의 종류 수 $A_1,A_2,\ldots,A_N$이 주어집니다.

$3$번째 줄에 각 노트의 콤보가 끊기는 판정의 종류 수 $B_1,B_2,\ldots,B_N$이 주어집니다.

입력은 모두 정수입니다.

## 제한

- $1 \leq N \leq 2 \times 10^5$
- $1 \leq K \leq N$
- $1 \leq A_i,B_i \leq 10^8$ ($1 \leq i \leq N$)

## 출력

최대 콤보가 $K$인 결과의 수를 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2
2 2 2
1 1 1
```

#### 출력

```text
8
```

각 판정을 위에서부터 `p`, `g`, `b`라고 하고, `b`일 때만 콤보가 끊긴다고 합시다. 최대 콤보가 $2$인 결과는 다음 $8$가지입니다.

`ppb`, `pgb`, `gpb`, `ggb`, `bpp`, `bpg`, `bgp`, `bgg`

`pbp`나 `ppg` 등은 각각 최대 콤보가 $1$, $3$이므로 조건을 만족하지 않습니다.

### 예제 2 {file=""}

#### 입력

```text
2 2
1 3
3 1
```

#### 출력

```text
3
```

#### 입력

```text
3 2
1 1 1
51543 45318957 51345
```

#### 출력

102888
