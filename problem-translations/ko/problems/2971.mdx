**이 문제의 실행 시간 제한은 $1\,000$[ms]입니다.**

## 문제 설명

음이 아닌 정수 $N$이 주어집니다.

$\displaystyle \int_0^1 \sqrt{x^3 + N^3} \ dx$

를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 $1$줄로 주어집니다.

```text
$N$
```

첫 번째 줄에 $N$이 주어집니다.

## 제한

- $N$은 $0 \leq N \leq 10^3$을 만족하는 정수입니다.

## 출력

$\displaystyle \int_0^1 \sqrt{x^3 + N^3} \ dx$

의 값을 소수로 표시하여 $1$줄에 출력하세요.

마지막에 줄 바꿈을 출력하세요.

이 문제는 스페셜 저지를 사용하는 소수 오차 허용 문제입니다. 정확한 답의 소수점 이하 $6$자리 정밀도 근삿값과의 절대 오차가 $10^{-3}$ 이하이면 정답으로 처리됩니다.

단, 여기서 실수 $x$의 소수점 이하 $6$자리 정밀도 근삿값이란 소수점 이하 $6$자리 이하의 유한 소수 표시를 가지며 $x$를 초과하지 않는 실수 중 최댓값을 뜻합니다.

출력은 위 형식을 엄격하게 따라야 합니다. 예를 들어 불필요한 공백이 있을 때 저지가 어떻게 동작할지는 보장되지 않습니다.

또한 저지 측의 사정으로 출력은 $100$자 이하로 작성하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0
```

#### 출력

```text
0.4
```

피적분 함수 $\sqrt{x^3 + N^3} = x^{\frac{3}{2}}$는 원시 함수 $\frac{2}{5} x^{\frac{5}{2}}$를 가집니다. 따라서

$\displaystyle \int_0^1 \sqrt{x^3 + N^3} \ dx = \left[ \frac{2}{5} x^{\frac{5}{2}} \right]_0^1 = \frac{2}{5} \times 1^{\frac{5}{2}} - \frac{2}{5} \times 0^{\frac{5}{2}} = \frac{2}{5} = 0.4$

가 됩니다. 이 밖에도

```text
0.401
```

이나

```text
0.399
```

를 출력하면 상대 오차는 $2.5 \times 10^{-3} > 10^{-3}$이지만 절대 오차가 $10^{-3}$이므로 정답으로 처리됩니다. 반면

```text
0.4011
```

이나

```text
0.3989
```

를 출력하면 절대 오차가 $10^{-3} + 10^{-4} > 10^{-3}$이므로 오답입니다.

### 예제 2 {file=""}

#### 입력

```text
1
```

#### 출력

```text
1.111447
```

구하는 적분값의 소수점 이하 $6$자리 정밀도 근삿값은 $1.111447$입니다. 이 밖에도

```text
1.110447
```

이나

```text
1.112447
```

를 출력해도 절대 오차가 $10^{-3}$이므로 정답으로 처리되지만,

```text
1.1104469999999
```

이나

```text
1.1124470000001
```

을 출력하면 상대 오차는 $10^{-3}$ 이하이지만 절대 오차가 $10^{-3} + 10^{-13} > 10^{-3}$이므로 오답입니다.

### 예제 3 {file=""}

#### 입력

```text
2
```

#### 출력

```text
2.871864
```

구하는 적분값의 소수점 이하 $6$자리 정밀도 근삿값은 $2.871864$입니다.
