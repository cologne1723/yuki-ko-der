## 문제 설명

yuki 씨는 다음과 같은 문제를 만들었습니다.

길이가 $N$인 수열 $a$가 주어집니다.

다음 $2$종류의 쿼리 $Q$개에 답하세요.

- `1 x y`: $a_x$를 $y$로 변경합니다. ($0 \le x < N$, $0 \le y < M$)
- `2 x y`: $a_x + a_{x+1} + \cdots + a_y \pmod M$을 출력합니다. ($0 \le x \le y < N$)

Binary Indexed Tree를 알고 있나요? yuki 씨는 알고 있습니다.

이 문제는 Binary Indexed Tree를 사용하여 풀 수 있습니다.

yuki 씨는 Binary Indexed Tree를 좋아합니다.

그런데 집합과 이항 연산의 순서쌍으로, 좋은 조건을 만족하는 것을 아벨 군이라고 합니다.

(정확한 정의는 [Wikipedia의 아벨 군 문서](https://ja.wikipedia.org/wiki/アーベル群)를 참조하세요.)

일반적으로 Binary Indexed Tree에는 아벨 군의 구조를 올릴 수 있다고 알려져 있습니다.

즉, 집합 $\{0, \ldots, M-1\}$이 이항 연산 ★에 의해 아벨 군을 이룬다면 위 문제의 두 번째 쿼리를 다음과 같이 바꾸어도 Binary Indexed Tree로 풀 수 있습니다.

- `2 x y`: $a_x ★ a_{x+1} ★ \cdots ★ a_y$를 출력합니다.

집합 $\{0, \ldots, M-1\}$ 위의 이항 연산 중 아벨 군을 이루는 것은 몇 종류 있을까요? $\mod 10^9+7$로 답하세요.

## 입력

```text
$M$
```

## 제한

$1 \le M < 10^6$

## 출력

집합 $\{0, \ldots, M-1\}$ 위의 이항 연산 중 아벨 군을 이루는 것의 개수를 $\mod 10^9+7$로 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
```

#### 출력

```text
3
```

다음 $3$종류의 연산이 존재합니다.

$x ★ y = x+y \pmod 3$

| ★ | 0 | 1 | 2 |
|---|---:|---:|---:|
| 0 | 0 | 1 | 2 |
| 1 | 1 | 2 | 0 |
| 2 | 2 | 0 | 1 |

$x ★ y = x+y+1 \pmod 3$

| ★ | 0 | 1 | 2 |
|---|---:|---:|---:|
| 0 | 1 | 2 | 0 |
| 1 | 2 | 0 | 1 |
| 2 | 0 | 1 | 2 |

$x ★ y = x+y+2 \pmod 3$

| ★ | 0 | 1 | 2 |
|---|---:|---:|---:|
| 0 | 2 | 0 | 1 |
| 1 | 0 | 1 | 2 |
| 2 | 1 | 2 | 0 |

### 예제 2 {file=""}

#### 입력

```text
4
```

#### 출력

```text
16
```

$x ★ y = x+y+k \pmod 4$나 $x ★ y = x \ \mbox{XOR}\ y \ \mbox{XOR}\ k\ (0\leq k < 4)$ 등 외에도 다음과 같은 수수께끼의 연산도 조건을 만족합니다.

| ★ | 0 | 1 | 2 | 3 |
|---|---:|---:|---:|---:|
| 0 | 3 | 2 | 0 | 1 |
| 1 | 2 | 3 | 1 | 0 |
| 2 | 0 | 1 | 2 | 3 |
| 3 | 1 | 0 | 3 | 2 |

이 수수께끼의 연산은 예를 들어 Python에서 다음과 같이 계산됩니다.

`pow(2,pow(3,x,5)+pow(3,y,5)+1,5)%4`
