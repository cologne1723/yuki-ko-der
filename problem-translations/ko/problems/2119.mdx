비음이 아닌 정수 $N$, 양의 정수 $M$, 길이 $M$의 양의 정수열 $B$와 정수열 $C$가 주어집니다. 모든 $m<M$에 대해 $n\equiv C_m\pmod{B_m}$인 $N$ 이하의 비음이 아닌 정수가 존재하는지 판정하고, 존재하면 최솟값을 구하세요.

## 입력

```text
N M
B_0 ... B_{M-1}
C_0 ... C_{M-1}
```

## 출력

조건을 만족하는 최솟값을 출력하세요.
