## 문제

집합 `S={N}`에서 시작합니다. 번갈아 `2` 이상 `N` 이하의 정수 `x` 중 아직 `S`에 없고, `S`의 어떤 원소 `y`와 서로소가 아닌 것을 하나 골라 `S`에 추가합니다. 더 이상 움직일 수 없게 된 사람이 패배합니다.

## 제약

- `1 ≤ T ≤ 10^5`
- `2 ≤ N ≤ 3×10^6`

## 입력

```text
T
N_1
⋮
N_T
```

## 출력

코어가 이기면 `K`, 파체가 이기면 `P`를 출력하세요.
