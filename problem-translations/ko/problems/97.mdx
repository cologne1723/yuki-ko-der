## 문제 설명

길이 $N$인 수열 $A$가 주어집니다.

쿼리로 $q_i$가 주어질 때, 집합 $\{(q_i \times a) \bmod 100\,003 \mid a \in A\}$의 최댓값을 구하세요. $x \bmod y$는 $x$를 $y$로 나눈 나머지를 나타냅니다.

수열 $A$는 직접 주어지지 않습니다. 다음 코드에서 `generateA`를 호출한 것과 동일하게 생성하세요.

```cpp
unsigned xor128_x = 123456789, xor128_y = 362436069, xor128_z = 521288629, xor128_w = 88675123;
unsigned xor128() {
    unsigned t = xor128_x ^ (xor128_x << 11);
    xor128_x = xor128_y; xor128_y = xor128_z; xor128_z = xor128_w;
    return xor128_w = xor128_w ^ (xor128_w >> 19) ^ (t ^ (t >> 8));
}
void generateA(int N, int A[]) {
    for(int i = 0; i < N; ++ i)
        A[i] = xor128() % 100003;
}
```

## 입력

```text
$N\ Q$
$q_1$
$\vdots$
$q_Q$
```

정수 $N,Q$는 각각 수열의 길이와 쿼리의 수입니다.
이어지는 $Q$개 줄에는 각 쿼리를 나타내는 정수 $q_i$가 주어집니다. $(1 \le i \le Q)$

수열 $A$는 입력으로 주어지지 않으며, 위 코드와 같이 직접 생성해야 한다는 점에 주의하세요.

## 제한

- $1 \le N,Q \le 100\,003$
- $0 \le q_i < 100\,003$ $(1 \le i \le Q)$

## 출력

각 쿼리의 답을 출력하고 줄 바꿈하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 3
1
100
100002
```

#### 출력

```text
97597
73872
23262
```

$A=[76\,741,85\,364,97\,597]$입니다. 각 쿼리에서 최댓값은 각각 $1 \times 97\,597$, $100 \times 76\,741$, $100\,002 \times 76\,741$을 $100\,003$으로 나눈 나머지입니다.
