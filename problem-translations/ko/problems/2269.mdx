입력 $N$에 대해 $\lfloor e(N!)\rfloor$의 마지막 자리를 구하라냥. $T$개의 테스트 케이스를 처리하라냥.

## 조건

- $1\le T\le10^5$
- $0\le N\le10^{18}$

## 입력

```text
T
N_1
\vdots
N_T
```

## 출력

각 답을 한 줄에 하나씩 출력하라냥.
