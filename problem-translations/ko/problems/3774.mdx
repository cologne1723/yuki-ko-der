## 문제 설명

영어 소문자로만 이루어진 문자열 $S$가 주어집니다. 다음 조건을 만족하는 음이 아닌 정수 $C$의 최솟값을 구하세요.

- $S$의 문자 중 정확히 $C$개를 각각 원하는 영어 소문자로 바꾸어 $S$를 팰린드롬으로 만들 수 있습니다.

이 문제의 제한 아래에서는 조건을 만족하는 음이 아닌 정수 $C$가 존재함을 증명할 수 있습니다.

## 입력

```text
$S$
```

## 제한

- $S$의 길이를 $|S|$라 할 때, $1\le |S|\le 10^6$
- $S$는 영어 소문자로만 이루어진 문자열입니다.

## 출력

조건을 만족하는 $C$의 최솟값을 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
waiwaiac
```

#### 출력

```text
2
```

$S$의 $5$번째와 $8$번째 문자를 각각 `w`, `w`로 바꾸면 `waiwwiaw`가 되며, 이는 팰린드롬입니다. $1$개 이하의 문자를 바꾸어 팰린드롬을 만들 수는 없으므로 답은 $2$입니다.

### 예제 2 {file=""}

#### 입력

```text
aba
```

#### 출력

```text
0
```

$S$가 처음부터 팰린드롬일 수도 있음에 주의하세요.

### 예제 3 {file=""}

#### 입력

```text
yukicoder
```

#### 출력

```text
4
```
