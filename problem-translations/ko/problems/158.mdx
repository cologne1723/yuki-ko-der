## 문제 설명

A는 1000엔 지폐를 $A_{1000}$장, 100엔 동전을 $A_{100}$개, 1엔 동전을 $A_1$개 가지고 있습니다.

B에게 지폐와 동전의 종류를 구분하지 않고 정확히 $D_b$엔을 지불하면, 1000엔 지폐 $B_{1000}$장, 100엔 동전 $B_{100}$개, 1엔 동전 $B_1$개를 받습니다. $D_b$엔보다 많이 지불할 수는 없으며, 받는 금액은 항상 지불한 금액보다 적습니다.

C에게도 정확히 $D_c$엔을 지불하면 1000엔 지폐 $C_{1000}$장, 100엔 동전 $C_{100}$개, 1엔 동전 $C_1$개를 받습니다. 이때도 $D_c$엔보다 많이 지불할 수 없고, 받는 금액은 항상 지불한 금액보다 적습니다.

B 또는 C에게 돈을 지불하고 돈을 받는 행위를 심부름 1회로 셉니다. A는 심부름을 많이 하면 칭찬받으므로, 방문 순서와 지불 방법을 정해 가능한 심부름 횟수를 최대로 하려 합니다. 가능한 최대 횟수를 구하세요.

## 입력

```text
A_{1000} A_{100} A_1
D_b
B_{1000} B_{100} B_1
D_c
C_{1000} C_{100} C_1
```

- 처음 가진 돈은 최대 10000엔입니다.
- $0 \le A_{1000} \times 1000+A_{100} \times 100+A_1 \le 10000$
- $A_{1000},A_{100},A_1$은 모두 0 이상인 정수입니다.
- $1 \le D_b,D_c \le 10000$
- $B_{1000} \times 1000+B_{100} \times 100+B_1 < D_b$
- $C_{1000} \times 1000+C_{100} \times 100+C_1 < D_c$
- $B_{1000},B_{100},B_1,C_{1000},C_{100},C_1$은 모두 0 이상인 정수입니다.

## 출력

A가 할 수 있는 심부름 횟수의 최댓값을 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

```text
0 1 12
110
0 1 2
6
0 0 1
```

```text
2
```

B에게 가면 110엔을 100엔 동전 1개와 1엔 동전 2개로 바꿀 수 있습니다. C에게 가면 6엔을 1엔 동전 1개로 바꿀 수 있습니다. C에게 두 번 갈 수 있으므로 최대 횟수는 2회입니다.

### 예제 2 {file=""}

```text
10 0 0
900
0 5 300
1001
1 0 0
```

```text
0
```

처음에는 1000엔 지폐만 가지고 있으므로 900엔도 1001엔도 정확히 지불할 수 없습니다.

### 예제 3 {file=""}

```text
0 1 0
100
0 0 12
3
0 0 1
```

```text
6
```

먼저 B에게 가서 100엔을 1엔 동전 12개로 바꿉니다. 이어서 C에게 가서 3엔을 1엔 동전으로 바꾸는 심부름을 5회 할 수 있으므로 합계 6회입니다.

### 예제 4 {file=""}

```text
2 30 2572
5088
3 11 403
8447
1 1 3378
```

```text
5
```
