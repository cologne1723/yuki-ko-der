## 문제 설명

A君은 $1\,000$엔 지폐를 $A_{1\,000}$장, $100$엔 동전을 $A_{100}$개, $1$엔 동전을 $A_1$개 가지고 있습니다.

Bさん에게 지폐와 동전의 종류를 구분하지 않고 정확히 $D_b$엔을 지불하면, $1\,000$엔 지폐 $B_{1\,000}$장, $100$엔 동전 $B_{100}$개, $1$엔 동전 $B_1$개를 받습니다. $D_b$엔보다 많이 지불할 수는 없으며, 받는 금액은 항상 지불한 금액보다 적습니다.

Cさん에게도 정확히 $D_c$엔을 지불하면 $1\,000$엔 지폐 $C_{1\,000}$장, $100$엔 동전 $C_{100}$개, $1$엔 동전 $C_1$개를 받습니다. 이때도 $D_c$엔보다 많이 지불할 수 없고, 받는 금액은 항상 지불한 금액보다 적습니다.

Bさん 또는 Cさん에게 돈을 지불하고 돈을 받는 행위를 심부름 $1$회로 셉니다. A君은 심부름을 많이 하면 칭찬받으므로, 방문 순서와 지불 방법을 정해 가능한 심부름 횟수를 최대로 하려 합니다. 가능한 최대 횟수를 구하세요.

## 입력

```text
$A_{1\,000}\ A_{100}\ A_1$
$D_b$
$B_{1\,000}\ B_{100}\ B_1$
$D_c$
$C_{1\,000}\ C_{100}\ C_1$
```

## 제한

- 처음 가진 돈은 최대 $10\,000$엔입니다.
- $0 \le A_{1\,000} \times 1\,000+A_{100} \times 100+A_1 \le 10\,000$
- $A_{1\,000},A_{100},A_1$은 모두 $0$ 이상인 정수입니다.
- $1 \le D_b,D_c \le 10\,000$이며 $D_b,D_c$는 양의 정수입니다.
- $B_{1\,000} \times 1\,000+B_{100} \times 100+B_1 < D_b$
- $C_{1\,000} \times 1\,000+C_{100} \times 100+C_1 < D_c$
- $B_{1\,000},B_{100},B_1,C_{1\,000},C_{100},C_1$은 모두 $0$ 이상인 정수입니다.

## 출력

A君이 할 수 있는 심부름 횟수의 최댓값을 $1$줄에 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0 1 12
110
0 1 2
6
0 0 1
```

#### 출력

```text
2
```

A君은 처음에 $1\,000$엔 지폐 $0$장, $100$엔 동전 $1$개, $1$엔 동전 $12$개를 가지고 있습니다.

Bさん에게 가면 $110$엔을 $100$엔 동전 $1$개와 $1$엔 동전 $2$개로 바꿀 수 있습니다. 그러면 $100$엔 동전 $1$개와 $1$엔 동전 $4$개가 남고, 더 이상 심부름을 할 수 없습니다.

Cさん에게 가면 $6$엔을 $1$엔 동전 $1$개로 바꿀 수 있습니다. Cさん에게 $2$번 다녀오면 $100$엔 동전 $1$개와 $1$엔 동전 $2$개가 남고, 더 이상 심부름을 할 수 없습니다. 따라서 Cさん에게 $2$번 가는 것이 최선이며 최대 횟수는 $2$회입니다.

### 예제 2 {file=""}

#### 입력

```text
10 0 0
900
0 5 300
1001
1 0 0
```

#### 출력

```text
0
```

A君은 처음에 $1\,000$엔 지폐 $10$장, $100$엔 동전 $0$개, $1$엔 동전 $0$개를 가지고 있습니다.

Bさん에게 가면 $900$엔을 $100$엔 동전 $5$개와 $1$엔 동전 $300$개로 바꿀 수 있습니다. Cさん에게 가면 $1\,001$엔을 $1\,000$엔 지폐 $1$장으로 바꿀 수 있습니다.

하지만 A君은 $1\,000$엔 지폐만 가지고 있으므로 $900$엔도 $1\,001$엔도 정확히 지불할 수 없습니다. 따라서 심부름을 $1$번도 할 수 없습니다.

### 예제 3 {file=""}

#### 입력

```text
0 1 0
100
0 0 12
3
0 0 1
```

#### 출력

```text
6
```

A君은 처음에 $1\,000$엔 지폐 $0$장, $100$엔 동전 $1$개, $1$엔 동전 $0$개를 가지고 있습니다.

먼저 Bさん에게 가서 $100$엔을 $1$엔 동전 $12$개로 바꿉니다. 이어서 Cさん에게 가서 $3$엔을 $1$엔 동전으로 바꾸는 심부름을 $5$회 할 수 있으므로 합계 $6$회입니다.
