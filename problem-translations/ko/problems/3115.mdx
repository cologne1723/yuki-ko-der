## 알림

이 문제는 인터랙티브 문제입니다.

## 문제 설명

저지는 $100$ 이상 $10^5$ 이하인 정수 $X$를 숨겨 두고 있습니다. 다음 조작을 정확히 $1$회 수행하여 조작 후의 $X'$를 알아내세요.

1. $100$ 이상 $10^5$ 이하인 정수 $A$, $B$를 선언하여 저지에게 전달합니다.
2. $Y=A^B \bmod (10^9+7)$로 둡니다.
3. 저지가 $K=\gcd(X,Y)$를 알려 줍니다.
4. $X'$를 $X^A \bmod B$로 설정합니다.

저지는 적응형입니다. 지금까지 받은 답변과 모순되지 않는 범위에서 도중에 $X$의 값을 변경할 수 있습니다.

## 입력

처음에는 입력이 주어지지 않습니다.

먼저 $A$, $B$를 출력합니다.

```text
$A\ B$
```

그다음 저지가 계산한 $K$가 주어집니다.

```text
$K$
```

이후 추측한 $X'$를 출력합니다.

```text
$X'$
```

마지막으로 결과를 나타내는 정수 $\mathrm{ret}$가 주어집니다.

```text
$\mathrm{ret}$
```

$\mathrm{ret}=1$이면 추측이 옳다는 뜻입니다. $\mathrm{ret}=0$이면 추측이 틀렸다는 뜻입니다.

## 제한

- $100 \le X \le 10^5$

## 출력

각각의 값을 출력한 뒤 flush하세요.

- $A$, $B$를 출력할 때는 입력 절의 형식을 따릅니다.
- 추측한 $X'$를 출력할 때는 입력 절의 형식을 따릅니다.

C++에서는 `std::cout<<std::endl`, Python3에서는 `print(flush=True)` 등의 방법을 사용할 수 있습니다.

출력 형식이 잘못된 경우 저지 결과가 정의되지 않을 수 있습니다.

## 예제

### 예제 1 {file=""}

저지는 $X=100$으로 설정합니다. 이 값은 알려 주지 않습니다.

#### 출력

```text
123 456
```

당신은 $A=123$, $B=456$으로 정했습니다.

저지는 $Y=123^{456} \pmod{10^9+7}=565\,291\,922$를 계산합니다.

#### 입력

```text
2
```

저지는 $K=\gcd(X,Y)=2$를 계산하여 알려 줍니다.

저지는 $X'=100^{123}\pmod{456}=64$를 계산합니다. 이 값은 알려 주지 않습니다.

#### 출력

```text
64
```

당신은 $X'=64$라고 추측했습니다.

하지만 $X=106$으로 설정해도 $A$, $B$, $K$와 모순되지 않습니다.

저지는 $X=106$으로 변경합니다. 이에 따라 $X'=106^{123}\pmod{456}=400$으로 변경됩니다.

#### 입력

```text
0
```

추측이 틀렸다고 판정되어 $\mathrm{ret}=0$이 주어집니다.
