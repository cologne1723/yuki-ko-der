## 문제

`N × N` 격자에서 Alice는 빨강, Bob은 검정으로 칠합니다. Alice는 `(K,1)`, Bob은 `(K,N)`에서 시작하며 Alice부터 번갈아 인접한 칸으로 이동해 자신의 색으로 칠합니다. 상대 색 칸으로는 이동할 수 없습니다.

`10^18+N^2`턴 후 빨간 칸이 더 많으면 `Alice`, 그렇지 않으면 `Bob`을 출력하세요.

## 제약

- `2 ≤ N ≤ 10^5`
- `1 ≤ K ≤ N`

## 입력

```text
N K
```

## 출력

승자의 이름을 출력하세요.
