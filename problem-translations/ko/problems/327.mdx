## 문제

0부터 시작하는 수 $N$을 대응하는 알파벳 열로 변환하려고 합니다.

## 입력

```text
N
```

$N$은 정수입니다.

## 출력

대응하는 대문자 알파벳 열을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
0
```

### 샘플 1 {file="sample1.out"}

```text
A
```

0은 `A`에 대응합니다.

### 샘플 2 {file="sample2.in"}

```text
25
```

### 샘플 2 {file="sample2.out"}

```text
Z
```

### 샘플 3 {file="sample3.in"}

```text
26
```

### 샘플 3 {file="sample3.out"}

```text
AA
```

`Z` 다음은 `AA`입니다.
