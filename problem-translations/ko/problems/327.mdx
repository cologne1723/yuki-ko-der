## 문제 설명

$0$부터 시작하는 수 $N$을 대응하는 알파벳 열로 변환하려고 합니다.

알파벳 열은 $26$개의 대문자 알파벳으로 수를 표현한 것입니다. 구체적으로 다음 순서를 따르며, 쉼표로 구분된 각 항목은 $1$개의 알파벳 열입니다.

$A,B,C,\dots,Z,AA,AB,\dots,AZ,BA,BB,\dots,ZZ,AAA,\dots,ZZZ,AAAA,\dots$

정수 $N$이 주어지면 $N$번째 알파벳 열을 구하세요.

## 입력

```text
$N$
```

$N$은 정수입니다.

## 제한

- $0 \le N \le 1\,000\,000\,000\,000=10^{12}$

## 출력

대응하는 대문자 알파벳 열을 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0
```

#### 출력

```text
A
```

$0$은 `A`에 대응합니다.

### 예제 2 {file=""}

#### 입력

```text
25
```

#### 출력

```text
Z
```

### 예제 3 {file=""}

#### 입력

```text
26
```

#### 출력

```text
AA
```

`Z` 다음은 `AA`입니다.
