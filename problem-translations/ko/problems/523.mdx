## 문제

F는 한가해서 가끔 재미있는 일을 생각해 냅니다. 오늘도 F는 어떤 일을 생각해 냈습니다.

1부터 N까지 번호가 붙은 초록색 LED N개를 준비하고, 그 모든 LED를 빨간색으로 만드는 가능한 모든 절차를 시험해 보는 것입니다.

절차는 다음과 같습니다.

* 각 LED에는 스위치가 하나 있습니다.
* 스위치를 누르면 초록색 LED는 노란색으로, 노란색 LED는 빨간색으로 켜집니다.
* 빨간색 LED에는 조작할 수 없습니다.

참견하기 좋아하는 당신은 F를 위해 가능한 조작 순서의 수를 계산하기로 했습니다.

## 입력

```text
N
```

N (1 ≤ N ≤ 10^7)이 한 줄에 주어집니다.

## 출력

가능한 조작 순서의 수를 1000000007로 나눈 나머지를 한 줄에 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
2
```

출력:

```text
6
```

N=2일 때 가능한 조작 순서는 다음 6가지입니다.

1을 노란색으로, 2를 노란색으로, 1을 빨간색으로, 2를 빨간색으로

1을 노란색으로, 2를 노란색으로, 2를 빨간색으로, 1을 빨간색으로

2를 노란색으로, 1을 노란색으로, 1을 빨간색으로, 2를 빨간색으로

2를 노란색으로, 1을 노란색으로, 2를 빨간색으로, 1을 빨간색으로

1을 노란색으로, 1을 빨간색으로, 2를 노란색으로, 2를 빨간색으로

2를 노란색으로, 2를 빨간색으로, 1을 노란색으로, 1을 빨간색으로
