## 문제 설명

수열 $a_1, a_2, a_3, \dots, a_{10}$을 맞혀 보세요.

## 입력

```text
$N$
```

정수 $N$이 주어집니다.

## 제한

- $1 \leq N \leq 10$

## 출력

정수 $a_N$을 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
7
```

$a_1 = 7$이므로 $7$을 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
5
```

#### 출력

```text
5
```

$a_5 = 5$이므로 $5$를 출력합니다.
