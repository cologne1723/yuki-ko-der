## 문제

Kokoyubi는 보물 좌표 P(Xt,Yt,Zt)와 자신과 보물 사이의 거리 Dt를 알려 주는 훌륭한 보물 발견기를 가지고 있습니다.

하지만 여러 번 사용하다 보니 좌표가 표시되지 않고 정확한 거리 Dt가 아니라 정확히 계산되지 않은 거리 D가 표시됩니다.

그래도 가까워지면 D가 작아지고 멀어지면 커지므로 가까워지는지 멀어지는지는 알 수 있습니다. 이를 이용해 보물 좌표를 찾아 Kokoyubi의 보물 찾기를 도와주세요.

Xt,Yt,Zt의 범위는 각각 −100 이상 100 이하인 정수입니다. 거리는 유클리드 거리입니다.

## 주의 사항

이 문제는 리액티브 형식입니다. 자세한 내용은 “리액티브 형식의 문제란”을 참고하세요.

질의는 질문 질의와 응답 질의를 합쳐 최대 200회 할 수 있습니다.

### 질문 질의

```text
? X Y Z
```

−150 ≤ X,Y,Z ≤ 150인 정수 좌표 Q(X,Y,Z)와 보물 좌표 P 사이의 부정확한 거리 D를 알고 싶다면 위 형식으로 출력하세요.

출력하면 D를 표준 입력으로 받습니다. 0 ≤ D < 2^31인 정수이며 부정확한 거리입니다.

i번째 질의 좌표와 보물 사이의 정확한 거리를 Di,t, 부정확한 거리를 Di라 할 때, Da,t ≤ Db,t이면 Da ≤ Db이고 Da,t > Db,t이면 Da > Db임이 보장됩니다.

질문 질의 형식이 잘못되면 D는 −1이 됩니다.

### 응답 질의

```text
! X Y Z
```

정확한 보물 좌표 P(Xt,Yt,Zt)를 알게 되면 위 형식으로 출력하고 프로그램을 종료하세요.

응답 질의는 한 번만 사용할 수 있습니다.

## 샘플 코드

```cpp
#include "bits/stdc++.h"
using namespace std;
int ask(int x, int y, int z) {
  int d;
  cout << "?" << " " << x << " " << y << " " << z << endl;
  cin >> d;
  return d;
}
void answer(int x, int y, int z) {
  cout << "!" << " " << x << " " << y << " " << z << endl;
}
int main(void) {
  int a[3] = {10, 10, 10};
  ask(a[0], a[1], a[2]);
  answer(a[0], a[1], a[2]);
  return 0;
}
```
