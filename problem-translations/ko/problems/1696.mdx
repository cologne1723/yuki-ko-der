`1` 이상 `K` 이하의 정수로 이루어진 길이 `N`의 수열 `A` 중, 각 구간 `[L_i,R_i]`마다 그 구간 안에 포함되는 원소 `A_j`가 하나 이상 존재하는 수열의 개수를 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `1 <= N <= 10^9`
- `1 <= K <= 1500`
- `1 <= M <= min(2 * 10^5,K(K+1)/2)`
- `1 <= L_i <= R_i <= K`

## 입력

`N K`, `M`, 그리고 `M`개의 구간 `L_i R_i`가 주어집니다.

## 출력

조건을 만족하는 수열의 개수를 출력하세요.

```text
2

4 5
```

#### 출력

```text
12
```
