길이 $1$ 이상 $60000$ 이하의 영문 소문자 문자열 $S$를 하나 출력하라냥. $S$의 연속하지 않아도 되는 부분 수열 중 `con`인 것의 개수가 정확히 $M$개가 되도록 해야 한다냥. 서로 다른 위치를 선택한 부분 수열은 서로 다른 것으로 센다냥.

## 조건

- $0\le M\le10^{12}$

## 입력

```text
M
```

## 출력

조건을 만족하는 문자열 $S$를 출력하라냥. 여러 개라면 아무거나 출력해도 된다냥.
