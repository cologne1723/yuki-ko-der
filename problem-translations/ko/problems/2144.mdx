양의 정수 $N,M$에 대해 좋은 수열을 정의한다냥. 길이가 $N$이고 각 원소가 $0$ 이상 $M-2$ 이하이며, 인접한 두 원소를 골라 각각 1씩 더하는 연산을 반복하여 모든 원소를 $M$의 배수로 만들 수 있으면 좋은 수열이다냥. 길이 $N$의 비음수 정수열 $A$가 주어질 때 좋은 수열인지 판정하고, 좋은 경우 사전순으로 몇 번째인지 구하라냥.

## 조건

- $2\le N\le2\times10^5$
- $3\le M\le10^6$
- $0\le A_i\le M-2$

## 입력

```text
N M
A_1 A_2 \cdots A_N
```

## 출력

좋은 수열이면 사전순 순위를 $998244353$으로 나눈 나머지를, 아니면 $-1$을 출력하라냥.

예제는 원문을 참고하라냥.
