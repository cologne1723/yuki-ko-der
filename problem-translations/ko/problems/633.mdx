## 문제

어떤 마을에서 버스가 각 지역에 한 번씩 정차합니다. 버스 정류장은 1~$n$번이고 버스는 1번부터 $n$번까지 순서대로 이동합니다. 승객이 정류장 $i$에서 $i+1$로 가는 요금은 $a_i$엔입니다. $i$에서 $j$로 가는 요금은 $a_i+\cdots+a_{j-1}$엔입니다.

정류장 $i$에서 내린 사람 수를 $b_i$, 탄 사람 수를 $c_i$라 합니다. 버스는 정류장에 도착하면 먼저 $b_i$명을 내리게 한 뒤 $c_i$명을 태웁니다. 모든 승객이 낸 요금의 합을 구하세요. 버스는 처음에 승객 없이 1번 정류장에 도착하고, $b_1=c_n=0$이며, $n$번 정류장에서 모든 승객이 내립니다.

## 입력

```text
n
a1
...
a(n-1)
b1 c1
...
bn cn
```

- $2\le n\le100$
- $0\le a_i\le100$
- 내리는 사람 수는 도착 시 승객 수 이하입니다.
- $0\le c_i\le100$

## 출력

모든 승객이 낸 요금의 합을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
4
11
7
3
0 3
2 4
1 0
4 0
```

출력:

```text
80
```

각 정류장에서 3명이 타고, 2명이 내리고 4명이 타고, 1명이 내리고, 마지막에 4명이 내립니다. 총 요금은 80엔입니다.
