## 문제 설명

양의 정수 $n$이 주어집니다. 다음 값을 구하세요.

$\displaystyle \sum_{a_1=1}^{\infty}\sum_{a_2=1}^{\infty}\cdots\sum_{a_n=1}^{\infty}\frac{1}{{a_1}^2B}$

단,

$A=\displaystyle\prod_{k=1}^{n}{a_k}^2$

$B=\displaystyle\sum_{k=1}^{n}\frac{A}{{a_k}^2}$

답의 소수 부분은 버리고 출력하세요.

## 입력

```text
n
```

- $1 \leq n \leq 50$

## 출력

답의 소수 부분을 버린 값을 한 줄에 출력하세요. 마지막에 줄바꿈을 넣으세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}
#### 입력
```text
1
```
#### 출력
```text
1
```

$\displaystyle\sum_{a_1=1}^{\infty}\frac{1}{{a_1}^2}$이므로 유명한 바젤 문제입니다.
