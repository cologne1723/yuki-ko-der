## 문제 설명

null 군은 길이 $n$인 순열 $P = \{1, 2, \dots, n\}$을 재배열한 수열 $A = \{a_1, a_2, \dots, a_n\}$과 $B = \{b_1, b_2, \dots, b_n\}$을 가지고 있습니다.

null 군은 다음 연산을 반복하여 $A = B$로 만들려고 합니다.

- $1 \le i \le n - 1$을 만족하는 정수 $i$를 하나 선택하여 $a_i$와 $a_{i+1}$을 교환합니다.

$A = B$로 만드는 데 필요한 연산 횟수의 최솟값을 구하세요.

단, $1 \le j \le n$을 만족하는 모든 $j$에 대하여 $a_j = b_j$가 성립할 때 $A = B$로 정의합니다.

## 입력

```text
$n$
$a_1\ a_2\ \dots a_n$
$b_1\ b_2\ \dots b_n$
```

$A$와 $B$는 순열 $P$를 재배열한 수열입니다.

입력은 모두 정수입니다.

## 제한

$1 \le n \le 10^5$

## 출력

$A = B$로 만드는 데 필요한 연산 횟수의 최솟값을 한 줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="sample1.in"}

#### 입력

```text
5
1 5 4 2 3
2 1 4 3 5
```

#### 출력

```text
5
```

예를 들어 다음과 같이 연산하면 연산 횟수가 최솟값이 되며, 이보다 적은 연산 횟수로 조건을 만족하는 방법은 없습니다.

$1, 5, 4, 2, 3 \rightarrow 1, 5, 2, 4, 3 \rightarrow 1, 2, 5, 4, 3 \rightarrow 2, 1, 5, 4, 3 \rightarrow 2, 1, 4, 5, 3 \rightarrow 2, 1, 4, 3 ,5$

```text

```
