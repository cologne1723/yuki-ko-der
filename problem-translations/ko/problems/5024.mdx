## 이야기

고대 유적 깊숙한 곳, 마법소녀 うな는 보석이 잠들어 있는 홀에 들어섰습니다. うな는 이 유적에 잠든 보석을 가능한 한 많이 회수하고 싶어 합니다.

## 문제 설명

고대 유적의 바닥은 격자 모양입니다. 유적은 $N \times N$ 격자로 나타낼 수 있습니다. 격자의 각 칸에는 보석이 놓여 있으며, 그 가치는 음이 아닌 정수로 주어집니다.

유적의 바닥은 매우 약해서 $1$번 밟은 칸은 무너집니다. 따라서 같은 칸을 $2$번 지날 수 없습니다.

또한 유적의 붕괴는 서서히 진행되고 있어 너무 오래 탐색하면 붕괴에 휘말립니다. 그러므로 うな는 탐색할 수 있는 칸이 최대 $T$개입니다.

うな는 임의의 칸에서 탐색을 시작하여 인접한 칸으로 이동하면서 보석을 회수합니다. 회수할 수 있는 보석 가치의 합이 최대가 되는 경로를 구하세요.

### 문제 설정

격자의 왼쪽 위 칸을 $(0,0)$이라 하고, 여기에서 아래로 $i$칸, 오른쪽으로 $j$칸 이동한 칸의 좌표를 $(i,j)$로 나타냅니다.

각 칸 $(i,j)$에는 보석의 가치를 나타내는 음이 아닌 정수 $A_{i,j}$가 쓰여 있습니다.

길이 $L$인 경로 $1$개를 선택할 수 있습니다($1 \le L \le T$). 이 경로는 다음 조건을 만족해야 합니다.

- 처음에 원하는 칸 $(i_0,j_0)$ $1$개를 선택합니다.
- 모든 $k$ ($0 \le k < L-1$)에 대하여 $(i_k,j_k)$와 $(i_{k+1},j_{k+1})$는 상하좌우로 인접해야 합니다.
- 모든 $(i_k,j_k)$는 서로 달라야 합니다(같은 칸을 $2$번 방문해서는 안 됩니다).

### 점수

방문한 칸이

$(i_0,j_0), (i_1,j_1), \ldots, (i_{L-1},j_{L-1})$

이라면 점수는 칸의 가치 합, 즉

$\mathrm{Score} = \sum_{k=0}^{L-1} A_{i_k,j_k}$

으로 정의됩니다.

테스트 케이스는 총 $50$개이며, 각 테스트 케이스 점수의 합이 제출 점수가 됩니다.

### 입력 생성 방법

각 테스트 케이스는 다음과 같이 생성됩니다.

- $T$는 $1$ 이상 $N^2$ 이하인 정수 중에서 균등하게 무작위로 생성됩니다.
- 각 칸 $(i,j)$에 대하여 독립적으로 다음과 같이 생성됩니다.
  - $x_{i,j}$를 구간 $[0,3]$의 균등분포를 따르는 실수로 생성합니다.
  - $A_{i,j} = \lfloor 10^{x_{i,j}} \rfloor$로 합니다.

### 샘플 코드

무엇부터 작성해야 할지 모르겠다면 먼저 다음 코드를 그대로 제출해 보세요.

이 코드는 격자를 왼쪽 위부터 지그재그로 이동하며 위에서부터 $T$칸만 방문하는 단순한 풀이입니다.

점수는 그다지 높지 않지만 문제 형식에 맞는 올바른 출력을 내므로 AC(정답)를 받을 수 있습니다.

이 코드를 출발점으로 삼아 다음과 같은 방법을 생각해 보면 더 높은 점수를 노릴 수 있습니다.

- 가치가 높은 칸을 우선하여 방문하려면 어떻게 해야 하는가
- 경로를 어떻게 개선할 수 있는가

#### C++ 샘플 코드

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    int N, T;
    cin >> N >> T;

    vector<vector<int>> A(N, vector<int>(N));
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < N; j++) {
            cin >> A[i][j];
        }
    }

    vector<pair<int, int>> path;

    for (int i = 0; i < N; i++) {
        if (i % 2 == 0) {
            // 左から右へ
            for (int j = 0; j < N; j++) {
                path.push_back(make_pair(i, j));
                if (path.size() == T) {
                    break;
                }
            }
        } else {
            // 右から左へ
            for (int j = N - 1; j >= 0; j--) {
                path.push_back(make_pair(i, j));
                if (path.size() == T) {
                    break;
                }
            }
        }

        if (path.size() == T) {
            break;
        }
    }

    cout << path.size() << endl;
    for (int k = 0; k < path.size(); k++) {
        cout << path[k].first << " " << path[k].second << endl;
    }

    return 0;
}
```

#### Python 샘플 코드

```python
N, T = map(int, input().split())

A = []
for _ in range(N):
    row = list(map(int, input().split()))
    A.append(row)

path = []

for i in range(N):
    if i % 2 == 0:
        # 左から右へ
        for j in range(N):
            path.append((i, j))
            if len(path) == T:
                break
    else:
        # 右から左へ
        for j in range(N - 1, -1, -1):
            path.append((i, j))
            if len(path) == T:
                break

    if len(path) == T:
        break

print(len(path))
for i, j in path:
    print(i, j)
```

## 입력

```text
$N\ T$
$A_{0,0}\ A_{0,1}\ \ldots\ A_{0,N-1}$
$A_{1,0}\ A_{1,1}\ \ldots\ A_{1,N-1}$
$\vdots$
$A_{N-1,0}\ A_{N-1,1}\ \ldots\ A_{N-1,N-1}$
```

$1$번째 줄에 격자의 크기 $N$과 방문할 수 있는 최대 칸 수 $T$가 주어집니다.

그다음 $N$개의 줄에 각 칸 $(i,j)$의 보석 가치 $A_{i,j}$가 주어집니다. 각 줄에는 $N$개의 정수가 공백으로 구분되어 주어집니다.

## 제한

- $N = 20$
- $1 \le T \le N^2$
- $1 \le L \le T$
- $0 \le A_{i,j} \le 10^3$
- $0 \le i,j < N$
- 입력은 모두 정수입니다.

## 출력

길이 $L$인 경로를 다음 형식으로 출력하세요.

```text
$L$
$i_0\ j_0$
$i_1\ j_1$
$\vdots$
$i_{L-1}\ j_{L-1}$
```
