## 문제

`⌊√N⌋`이 십진법으로 몇 자리인지 구하세요. `⌊x⌋`는 `x` 이하인 가장 큰 정수입니다.

## 입력

정수 `N`이 주어집니다.

`1 \le N \le 10^{100000}`입니다.

## 출력

`⌊√N⌋`의 십진법 자릿수를 출력하세요.
