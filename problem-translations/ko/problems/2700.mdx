## 문제

출력 전용 문제입니다. 0-1 배낭 문제에서 가치/무게 비율이 큰 순서로 물건을 고르는 그리디 풀이가 대부분의 용량에서 최적해보다 엄밀히 작아지도록 물건들을 하나 구성하세요.

`1 ≤ N ≤ 2000`, `1000 ≤ W ≤ 2000`, `1 ≤ v_i ≤ 10^9`, `1 ≤ w_i ≤ W`를 만족해야 합니다. 용량 `p=1,...,W` 중 그리디 해가 최적해보다 작지 않은 `p`는 최대 하나여야 합니다.

## 출력

조건을 만족하는 `N`, `W`와 `N`개의 `(v_i,w_i)`를 출력하세요.
