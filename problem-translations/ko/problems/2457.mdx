처음에는 모든 칸이 흰 $H\times W$ 격자입니다. 매번 가능한 $K\times K$ 스탬프 위치를 균등하게 골라 총 $N$번 찍습니다. 찍은 칸은 흰색이면 검게 변합니다. 최종 격자의 검은 칸 수의 기댓값을 $998244353$으로 나눈 값을 구하세요.

## 조건

- $1\le H,W\le998244352$
- $1\le N\le10^9$
- $1\le K\le\min(H,W,10^3)$

## 입력

```text
H W N K
```

## 출력

기댓값을 $998244353$으로 나눈 값을 출력하세요.
