## 문제 설명

각 $i=1,2,\ldots,N$에 대해 십진 표기로 정확히 $d_i$자리인 0 이상의 정수의 개수를 구하세요.

## 입력

```text
N
d_1
\vdots
d_N
```

- $1\leq N\leq100$
- $1\leq d_i\leq100$

## 출력

$i$번째 문제의 답을 $i$번째 줄에 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}
#### 입력
```text
3
3
5
20
```
#### 출력
```text
900
90000
90000000000000000000
```
