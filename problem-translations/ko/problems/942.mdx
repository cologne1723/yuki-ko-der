## 문제 설명

유키 왕국의 국왕인 yuki 씨는 다가오는 크리스마스에 대비해 선물 $N$개를 준비했습니다.

선물에는 ‘가치’라는 값이 정해져 있으며, $i$번째 선물의 가치는 $i$입니다. $1 \le i \le N$입니다.

현재 유키 왕국에는 아이 $K$명이 있습니다.

yuki 씨는 왕국의 아이들에게 준비한 선물을 다음 조건을 모두 만족하도록 나누어 주고 싶습니다.

- 각 아이가 받는 선물의 수가 같습니다.
- 각 아이가 받는 선물 가치의 합이 같습니다.

yuki 씨는 왕국의 재상인 여러분에게 그러한 나누는 방법이 존재하는지, 존재한다면 어떻게 나누면 되는지 물었습니다.

## 입력

다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ K$
```

## 제한

- $1 \le N \le 200\,000$
- $1 \le K \le N$
- $K$는 $N$의 약수입니다.
- 입력은 모두 정수입니다.

## 출력

조건을 만족하는 선물 나누는 방법이 존재하지 않으면 `No`를 출력하세요.

존재하면 `Yes`를 출력한 뒤 줄 바꿈하고, 이어서 $K$줄을 출력하세요.

이때 출력의 $i+1$번째 줄에는 $i$번째 아이가 받는 선물의 번호를 공백으로 구분해 출력하세요. $1 \le i \le K$입니다.

조건을 만족하는 나누는 방법이 여러 가지라면 그중 어느 것이든 정답으로 인정됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 2
```

#### 출력

```text
Yes
2 3
1 4
```

### 예제 2 {file=""}

#### 입력

```text
6 2
```

#### 출력

```text
No
```
