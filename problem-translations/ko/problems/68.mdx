## 문제 설명

유우키는 $N$개의 막대를 가지고 있으며, $i$번째 막대의 길이는 $L_i$입니다.

막대는 (길이를 나누는 방향으로) 자유롭게 자를 수 있지만, 이어 붙일 수는 없습니다.

유우키는 길이가 같은 막대를 만들려고 합니다. 몇 개를 만들 때 어느 정도 길이까지 만들 수 있는지 궁금해졌습니다.

길이가 같은 막대 $K_1,K_2,\ldots,K_Q$개를 각각 만들 때, 만들 수 있는 막대 길이의 최댓값을 구하세요.

## 입력

```text
$N$
$L_1\ L_2\ \dots\ L_N$
$Q$
$K_1\ K_2\ \dots\ K_Q$
```

막대의 개수 $N$, 각 막대의 길이 $L_1,L_2,\dots,L_N$, 질의 수 $Q$, 각 질의에서 만들 막대의 개수 $K_1,K_2,\dots,K_Q$가 위 형식으로 주어집니다. 각 행의 값은 공백으로 구분되어 주어집니다.

## 제한

- $1 \le N \le 100\,000$
- $1 \le L_i \le 1\,000\,000\,000$ $(1 \le i \le N)$
- $1 \le Q \le 100\,000$
- $1 \le K_i \le 500\,000$ $(1 \le i \le Q)$


## 출력

$i$번째 줄에 $K_i$개의 길이가 같은 막대를 만들 때 가능한 길이의 최댓값을 출력하세요.

절대 오차 또는 상대 오차가 $10^{-9}$ 이하이면 정답으로 인정합니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
10 20
2
3 4
```

#### 출력

```text
10.00
6.666666666666667
```

길이 $20$인 막대를 정확히 $2$등분하면 길이 $10$인 막대 $3$개를 만들 수 있습니다. 또한 길이 $20$인 막대를 $3$등분하고, 길이 $10$인 막대에서 $20/3$만큼 잘라 남은 부분을 버리면 길이 $20/3$인 막대 $4$개를 만들 수 있습니다.
