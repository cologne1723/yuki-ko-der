## 문제 설명

카구야와 이로하는 불꽃놀이 축제에 참가합니다.

축제가 시작되기 전에 두 사람은 각각 $xy$평면 위에서 원하는 지점 하나를 골라 이동합니다. 고른 지점의 좌표는 실수여도 되며, 두 사람이 같은 지점을 골라도 됩니다.

축제에서는 불꽃 $N$발을 쏘아 올립니다. $i$번째 불꽃을 쏘아 올리는 지점의 좌표는 $(X_i,Y_i)$입니다.

음이 아닌 실수 $D$에 대해, 불꽃을 쏘아 올리는 지점과의 [맨해튼 거리](https://ja.wikipedia.org/wiki/%E3%83%9E%E3%83%B3%E3%83%8F%E3%83%83%E3%82%BF%E3%83%B3%E8%B7%9D%E9%9B%A2)가 $D$ 이하인 지점에 있는 사람은 그 불꽃을 볼 수 있습니다.

모든 불꽃을 카구야와 이로하 중 적어도 한 사람이 볼 수 있게 하는 $D$의 최솟값을 $D_{\min}$이라고 할 때, $2D_{\min}$을 구하세요. 이 값은 항상 정수입니다.

## 입력

```text
$N$
$X_1\ Y_1$
$X_2\ Y_2$
$\vdots$
$X_N\ Y_N$
```

## 제한

- $1 \leq N \leq 3 \times 10^5$
- $0 \leq X_i,Y_i \leq 10^9$
- $i \neq j$이면 $(X_i,Y_i) \neq (X_j,Y_j)$입니다.
- 입력으로 주어지는 모든 수는 정수입니다.

## 출력

답을 한 줄에 출력하세요.

## 예제

### 예제 1 {file="01_sample_01"}

#### 입력

```text
3
0 0
1 0
2 0
```

#### 출력

```text
1
```

카구야가 $(0.5,0)$에, 이로하가 $(2,0)$에 있다고 합시다. 각 불꽃과 두 사람 사이의 맨해튼 거리는 다음과 같습니다.

- 첫 번째 불꽃 $(0,0)$: 카구야와의 거리가 $0.5$입니다.
- 두 번째 불꽃 $(1,0)$: 카구야와의 거리가 $0.5$입니다.
- 세 번째 불꽃 $(2,0)$: 이로하와의 거리가 $0$입니다.

모든 불꽃이 두 사람 중 한 사람과의 거리가 $0.5$ 이내인 곳에 있으므로 $D=0.5$는 조건을 만족합니다.

이것이 최솟값이므로 $D_{\min}=0.5$입니다. 따라서 출력할 $2D_{\min}$은 $1$입니다.

### 예제 2 {file="01_sample_02"}

#### 입력

```text
4
0 0
0 4
4 0
4 4
```

#### 출력

```text
4
```

예를 들어 카구야가 $(0,2)$에, 이로하가 $(4,2)$에 있으면 모든 불꽃을 적어도 한 사람이 볼 수 있습니다.

### 예제 3 {file="01_sample_03"}

#### 입력

```text
1
0 0
```

#### 출력

```text
0
```
