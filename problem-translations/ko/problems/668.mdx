## 문제

6.0*10^23은 아보가드로 상수입니다. 정수 $N$을 같은 형식으로 표시하세요. 즉 a.b*10^c 형태에서 a.b는 소수점 둘째 자리 이하를 반올림하고 $1\le a\le9$가 되도록 합니다. 답은 유일합니다.

## 입력

```text
N
```

$100\le N<10^{100000}$

## 출력

변환한 $N$을 한 줄에 출력하세요. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
602214129000000000000000
```

출력:

```text
6.0*10^23
```

아보가드로 상수의 상세한 값입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
149600000
```

출력:

```text
1.5*10^8
```

지구에서 태양까지의 평균 거리(km)입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
299792458
```

출력:

```text
3.0*10^8
```

빛의 속도(m/s)입니다.

### 샘플 4 {file="sample4.in"}

입력:

```text
9999999999
```

출력:

```text
1.0*10^10
```

숫자 부분뿐 아니라 지수 부분에도 주의하세요.
