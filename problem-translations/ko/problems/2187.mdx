정수 $A$가 주어질 때, $x^3+y^3+z^3\equiv A\pmod{333}$이고 $x^4+y^4+z^4\le4444^4$인 양의 정수 순서쌍이 아닌 순서 있는 세쌍 $(x,y,z)$의 개수를 구하라냥.

## 조건

- $A$는 $333$ 이하의 양의 정수이다냥.

## 입력

```text
A
```

## 출력

조건을 만족하는 세쌍의 개수를 출력하라냥.
