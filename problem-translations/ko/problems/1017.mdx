## 문제 설명

양의 정수로 이루어진 길이 $N$인 수열 $A = A_1,A_2,\ldots,A_N$이 있습니다.
각 $i\in\{1,2,\ldots,N\}$에 대해 다음 연산을 수행하여 수열 $B = B_1,B_2,\ldots,B_N$을 만들려고 합니다.

- $x_i\in\{-1,0,1\}$을 선택하고 $B_i = A_ix_i$로 정합니다.

다음 두 조건이 모두 성립하도록 하세요.

- 수열 $B$의 합은 $0$입니다. 즉, $\sum_{i=1}^NB_i=0$입니다.
- 수열 $B$에 $0$이 아닌 항이 존재합니다.

## 입력

```text
N
A_1 A_2 \cdots A_N
```

입력은 모두 정수입니다.

## 제한

$1\leq N\leq 150\,000$

$1\leq A_i\leq 150\,000$

## 출력

연산으로 조건을 만족하는 수열을 얻는 것이 불가능하면 `No`를 출력하세요. 가능한 경우에는 첫 번째 줄에 `Yes`를 출력하고, 두 번째 줄에 연산 후의 수열 $B = B_1,B_2,\ldots,B_N$을 공백으로 구분하여 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
5
1 2 3 4 5
```

#### 출력

```text
Yes
1 -2 0 -4 5
```

그 밖에도 `0 -2 3 4 -5`, `0 2 3 0 -5` 등의 수열을 얻을 수 있습니다.
조건을 만족한다면 어떤 수열을 출력해도 정답으로 판정됩니다.
단, `0 0 0 0 0`은 조건을 만족하지 않습니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3
2019 5 1
```

#### 출력

```text
No
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
2
10 10
```

#### 출력

```text
Yes
10 -10
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
9
314 159 265 358 979 323 846 264 338
```

#### 출력

```text
Yes
314 159 0 358 0 -323 -846 0 338
```
