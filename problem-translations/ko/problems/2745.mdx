## 문제

각 플레이어는 문자열 `S_i`를 알고 있습니다. 1단계에서 각자 양의 정수를 선언하고, 선언값의 최솟값을 `K`로 둡니다. 2단계에서 각 플레이어는 자신의 문자열에서 서로 다른 두 위치의 문자를 골라 교환하는 작업을 정확히 `K`번 합니다.

최종 문자열 중 사전순으로 가장 작은 문자열을 가진 모든 사람이 승리하며, 승자는 `N+1-X`점을 얻습니다(`X`는 승자 수). 모두 자신의 점수를 최대화할 때 각 플레이어의 점수를 구하세요.

## 제약

- `N ≥ 2`, `2 ≤ |S_i| ≤ 10^5`
- 전체 문자열 길이 합은 `2×10^5` 이하입니다.

## 입력

```text
N
S_1
⋮
S_N
```

## 출력

각 플레이어의 점수를 한 줄에 하나씩 출력하세요.
