## 문제 설명

문자열 $T$가 "뱀 문자열"이라고 불리는 조건을 다음과 같이 정의합니다.

문자열 $T$의 길이를 $N$이라고 할 때, 어떤 정수 $i$($1\leq i\leq N-1$)가 존재하여 $T$를 $i$번째 문자와 $i+1$번째 문자 사이에서 나누고 앞부분과 뒷부분을 서로 바꾸었을 때 원래 문자열 $T$로 돌아와야 합니다.

즉, $T=T_{i+1}T_{i+2}\cdots T_NT_1T_2\cdots T_i$를 만족해야 합니다. ($T_i$는 $T$의 $i$번째 문자를 나타냅니다.)

영문 대문자로 이루어진 문자열 $S$가 주어집니다. $S$의 길이를 $N$이라고 할 때, 다음 연산을 원하는 횟수만큼 반복할 수 있습니다.

- 정수 $i$($1\leq i\leq N$)를 선택하고, $S_i$를 원하는 영문 대문자로 바꿉니다.

연산 횟수를 가능한 한 적게 사용하여 $S$를 뱀 문자열 $S^\prime$으로 만드세요.

### 주의

- 제출한 프로그램이 TLE(Time Limit Exceeded; 시간 초과)가 되는 경우에는 알고리즘을 더 효율적으로 만들 수 있는지 검토하세요.
- 사용하는 언어에 따라 올바른 알고리즘을 작성했더라도 TLE가 발생할 수 있습니다. Python을 사용하는 경우 일반적인 Python 구현체(CPython)가 아니라 더 빠른 구현체인 PyPy를 사용하는 것을 권장합니다. C++와 PyPy에서는 제한 시간 안에 통과하는 것을 확인했습니다.

## 입력

```text
$S$
```

문자열 $S$가 주어집니다.

## 제한

- $S$는 영문 대문자로 이루어진 문자열입니다.
- $2\leq |S|\leq 2\times 10^6$

## 출력

```text
$S^\prime$
```

정답이 되는 $S^\prime$이 여러 개 존재한다면 그중 어느 것이든 출력해도 됩니다.

출력 마지막에는 줄바꿈을 넣으세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
ABCBBBACC
```

#### 출력

```text
ABCABCABC
```

$4$번째, $6$번째, $8$번째 문자를 각각 A, C, B로 바꾸면 `ABCABCABC`가 되어 뱀 문자열이 됩니다. ($3$번째 문자와 $4$번째 문자 사이에서 나누면 됩니다.) $3$회 미만의 치환으로는 뱀 문자열을 만들 수 없으므로 `ABCABCABC`가 정답입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
ABCDEFG
```

#### 출력

```text
AAAAAAA
```

$2$번째 문자부터 $7$번째 문자까지를 A로 바꾸면 `AAAAAAA`가 되며, 이는 뱀 문자열입니다. ($1$번째 문자와 $2$번째 문자 사이에서 나누면 됩니다.) `ABCDEFG`는 $6$회 미만의 치환으로 뱀 문자열로 만들 수 없으므로 `AAAAAAA`가 정답입니다. (`BBBBBBB` 등도 정답이라는 점에 주의하세요.)
