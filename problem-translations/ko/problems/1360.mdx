## 문제

`N`종류의 소리 `i`를 울리면 `A_i`점을 얻습니다. 여러 소리를 동시에 울리면 각 점수의 합을 얻고, 동시에 울린 모든 쌍 `(i,j)`에 대해 추가로 `B_{i,j}`점을 얻습니다.

하나 이상의 소리를 골라 얻을 수 있는 최대 점수와 그 선택을 출력하세요.

## 입력

`N`, `A_i`, 대칭 행렬 `B_{i,j}`가 주어집니다.

`1\le N\le18`, `0\le A_i\le10^9`, `-10^9\le B_{i,j}\le10^9`입니다.

## 출력

최대 점수와 선택한 소리의 목록을 출력하세요.

## 예제

### 예제 1 {file="1_Sample_1.txt"}

#### 입력

```text
2
2 3
0 -4
-4 0
```

#### 출력

```text
3
2
```

### 예제 2 {file="1_Sample_2.txt"}

#### 입력

```text
3
10 20 30
0 -2 3
-2 0 -5
3 -5 0
```

#### 출력

```text
56
1 2 3
```

### 예제 3 {file="1_Sample_3.txt"}

#### 입력

```text
4
1 1 1 1
0 -10 -10 -10
-10 0 -10 -10
-10 -10 0 -10
-10 -10 -10 0
```

#### 출력

```text
1
1
```
