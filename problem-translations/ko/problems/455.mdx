## 참고

이 문제는 Advent Calendar Contest Advent Calendar 2016의 6일 차 문제로 만들어졌습니다.

## 문제

12월의 어느 날, 문득 밤하늘을 올려다보니 별이 가득 펼쳐져 있었습니다.

Y 군은 그중에서 ‘겨울의 대삼각형’을 이루는 별 3개를 찾았지만, 마지막 하나를 좀처럼 찾지 못하고 있습니다.

Y 군이 발견한 별 2개만 존재하는 세로 $H$, 가로 $W$ 크기의 밤하늘 상태가 주어집니다.

이 밤하늘에서 별 3개를 이었을 때 삼각형이 되도록 별 하나를 추가하세요.

삼각형은 어떤 모양이어도 정답입니다.

추가: 해답은 하나 이상 존재함이 보장됩니다.

## 보충

별 3개를 이었을 때 삼각형이 된다는 것은 예를 들어 다음과 같은 상태를 뜻합니다.

`*`는 별을, `-`는 아무것도 없음을 나타냅니다.

```text
---------*--
-*----------
------------
---------*--
*-----------
*-----------
------------
-*----------
```

별 3개가 일직선 위에 있으면 삼각형이 아닙니다.

```text
----*-------
----*-------
------------
----*-------
-*----------
----*-------
------------
----------*-
```

## 입력

```text
$H$ $W$
$S_1$
$S_2$
$\vdots$
$S_H$
```

첫 번째 줄에 밤하늘의 세로 크기 $H$, 가로 크기 $W$가 주어집니다.

이후 $H$개의 줄에 Y 군이 본 밤하늘 상태가 길이 $W$인 문자열 $S_i$로 주어집니다.

$S_i$는 별을 나타내는 `*`와 아무것도 없음을 나타내는 `-`만으로 이루어집니다.

별은 정확히 2개만 존재함이 보장됩니다.

$H,W$는 정수입니다.

$2\leq H,W\leq100$

## 출력

별 3개가 삼각형을 이루도록 별 하나를 추가한 밤하늘 상태를 입력과 같은 형식으로, 길이 $W$인 문자열 $H$개로 출력하세요.

마지막에 줄바꿈을 출력하세요.
