소문자 영어 문자열 `S`가 회문이 아니지만, 어떤 한 글자를 제거하면 회문이 되는 경우 거의 회문이라고 합니다.

길이 `N`인 거의 회문 문자열의 개수를 `998244353`으로 나눈 나머지를 구하세요.

## 제약

- `1 <= T <= 10^5`
- `1 <= N <= 10^6`

## 입력

테스트 케이스 수 `T`와 각 테스트 케이스의 `N`이 주어집니다.

## 출력

각 테스트 케이스의 답을 출력하세요.
