어제까지 참가한 `N`명의 사용자 이름과 레이팅, 오늘 참가한 `M`명의 사용자 이름과 레이팅이 주어집니다. 한 번 이상 대회에 참가한 각 사용자의 현재 레이팅을 구하세요.

이번 대회에 참가한 사용자는 오늘 레이팅을, 참가하지 않은 사용자는 이전 레이팅을 사용합니다.

## 입력

두 그룹의 사용자 이름과 레이팅이 주어집니다.

## 출력

한 번 이상 참가한 사용자들의 현재 레이팅을 문제의 형식에 맞게 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 2
user 30  
harurun 10
harurun 100
user 9999
```

#### 출력

```text
harurun 100
user 9999
```

사용자 이름의 사전순으로 출력하세요.

### 예제 2 {file=""}

#### 입력

```text
0 1
harurun 50
```

#### 출력

```text
harurun 50
```

어제까지의 참가자가 없을 수도 있습니다.

### 예제 3 {file=""}

#### 입력

```text
1 1
harurun 2000
Harurun 2000
```

#### 출력

```text
Harurun 2000
harurun 2000
```

대문자와 소문자를 구분합니다.
