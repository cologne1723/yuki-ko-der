## 주의

이 문제는 문제 [키즈나](https://yukicoder.me/problems/3124)에 변경 쿼리가 추가된 온라인 버전입니다. 제한도 조금 다릅니다.

## 문제 설명

길이 $N$인 정수열 $A$가 주어집니다. 처음에 수열 $A$의 $i$번째 값은 $A_i$입니다.

다음 두 종류의 쿼리가 총 $Q$개 주어지므로 온라인으로 처리하세요.

- $1\ X\ Y$: 쿼리 1입니다. 원소 $A_X$의 값을 $Y$로 변경하세요.
- $2\ L\ R$: 쿼리 2입니다. 다음 함수 $f$의 최솟값을 구하세요.

  $f(x) = \sum_{k = L}^{R} |x - A_k|$

입력은 인코딩되어 주어집니다. 자세한 내용은 「디코딩 방법」을 참조하세요.

## 입력

```text
$N \; Q$
$A_1 \; A_2 \; \cdots \; A_{N - 1} \; A_N$
$\mathrm{query}_1$
$\vdots$
$\mathrm{query}_Q$
```

쿼리 1의 형식은 다음과 같습니다.

```text
$1 \; X \; Y$
```

쿼리 2의 형식은 다음과 같습니다.

```text
$2 \; L \; R$
```

## 제한

- $1 \le N, Q < 2^{16}$
- $0 \le A_i < 2^{40}$
- $A_i$는 $1 \le i \le N$에 대해 정의됩니다.
- 쿼리 2가 하나 이상 포함됩니다.
- $i$번째 쿼리 $\mathrm{query}_i$는 $1 \le i \le Q$에 대해 다음 제한 중 하나를 만족합니다.
  - $1\ X\ Y$인 경우
    - $1 \le X \le N$
    - $0 \le Y < 2^{40}$
    - $X$와 $Y$는 인코딩되어 주어집니다.
  - $2\ L\ R$인 경우
    - $1 \le L, R \le N$
    - $L$과 $R$은 인코딩되어 주어집니다.
- 입력은 모두 정수입니다.

제한은 인코딩 전 값에 대한 것입니다. 인코딩 후 값이 위 제한을 만족한다고 보장되지 않는다는 점에 주의하세요.

## 디코딩 방법

인코딩된 값을 디코딩한 뒤 쿼리에 답하세요. 디코딩은 다음과 같이 수행합니다.

어떤 쿼리에 대해, 그 쿼리보다 앞선 쿼리 2에 대한 답을 모두 bitwise-XOR한 값을 $s$라고 합니다(아직 쿼리 2가 주어지지 않았다면 $s = 0$으로 합니다).

해당 쿼리에서 $L$, $R$, $X$는 각각 $s \bmod 2^{16}$과 bitwise-XOR한 값으로 바꿉니다. $Y$는 $s \bmod 2^{40}$과 bitwise-XOR한 값으로 바꿉니다. 디코딩한 뒤 $L > R$이면 이 둘을 서로 바꿉니다.

여기서 $\bmod$는 정수 나머지 연산이며, bitwise-XOR는 $2$진법으로 나타냈을 때 각 자리에서 XOR를 수행하는 연산입니다.

## 출력

각 쿼리 2에 대해 답을 정수로 한 줄에 출력하세요.

쿼리 2에 대한 답은 항상 음이 아닌 정수임을 증명할 수 있습니다.
