A와 B로 이루어진 길이 $N$의 문자열 $S$가 주어집니다. $S$에 포함된 연속 부분 문자열 `AB`를 원하는 만큼 골라 삭제할 수 있습니다.

## 문제

조작 후 얻을 수 있는 문자열 중 사전순으로 가장 큰 것을 구하세요.

## 입력

첫째 줄에 테스트 케이스 수 $T$가 주어지고, 각 테스트 케이스에 $N$과 $S$가 주어집니다.

```text
T
N
S
```

$1\le T\le10^4$, $1\le N\le2\times10^5$이며 $N$의 총합은 $2\times10^5$ 이하입니다.

## 출력

각 테스트 케이스의 답을 출력하세요.
