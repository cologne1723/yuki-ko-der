## 문제

$p+q=r^2$를 만족하는 $N$ 이하의 소수 순서쌍 $(p,q,r)$의 개수를 구하세요.

## 입력

~~~text
$N$
~~~

$1\leq N\leq5\times10^5$이며 입력은 정수입니다.

## 출력

답을 한 줄에 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
10
~~~

#### 출력

~~~text
3
~~~

조건을 만족하는 것은 $(2,2,2),(7,2,3),(2,7,3)$입니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
500000
~~~

#### 출력

~~~text
81
~~~
