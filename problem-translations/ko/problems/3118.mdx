## 문제 설명

양의 정수 $N,A$가 주어집니다. $N$ 이하의 양의 정수 $K$에 대해 다음 문제를 생각하고, 그 답을 $f(K)$라고 합니다.

> **문제**
>
> 변수 $C$가 있고, 처음에는 $C=K$입니다. 한 번의 연산으로 $C$에 $1$을 더하거나 $A$를 곱할 수 있습니다.
>
> $C=N$으로 만들기 위해 필요한 최소 연산 횟수를 구하세요.

$N$ 이하의 모든 양의 정수 $K$에 대한 $f(K)$의 합, 즉 $\displaystyle\sum_{i=1}^{N}f(i)$을 $998\,244\,353$으로 나눈 나머지를 구하세요.

테스트 케이스는 총 $T$개 주어집니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\text{case}_1$
$\text{case}_2$
$\vdots$
$\text{case}_T$
```

여기서 $\text{case}_i$는 $i$번째 테스트 케이스를 의미합니다.

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ A$
```

## 제한

- $1 \leq T \leq 10\,000$
- $1 \leq N \leq 10^{18}$
- $1 \leq A \leq 10^{18}$

## 출력

$T$줄에 걸쳐 출력하세요. $j$번째 줄($1 \leq j \leq T$)에는 $\text{case}_j$에 대한 $\displaystyle\sum_{i=1}^{N}f(i)$을 $998\,244\,353$으로 나눈 나머지를 출력하고, 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
5 2
1 1
271828459045235602 314159265358979323
```

#### 출력

```text
8
0
487598590
```

이 입력에는 테스트 케이스가 $3$개 포함됩니다. 첫 번째 테스트 케이스에 대해 설명하겠습니다.

$f(1)=3$입니다. $1$에 $2$를 $2$번 곱한 후 $1$을 더하면 $3$번의 연산으로 $1$을 $5$로 만들 수 있고, $2$번 이하의 연산으로 $1$을 $5$로 만들 수 없음을 증명할 수 있기 때문입니다.

같은 방식으로 생각하면 $f(2)=2$, $f(3)=2$, $f(4)=1$, $f(5)=0$입니다.

이들의 합은 $3+2+2+1+0=8$이므로 첫 번째 테스트 케이스의 답은 $8$입니다. 따라서 $8$을 출력합니다.
