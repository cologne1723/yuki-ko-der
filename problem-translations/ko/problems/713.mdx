## 문제

나마 군은 학교에서 소수에 대해 배웠습니다. 소수란 1과 자기 자신 이외의 약수를 갖지 않는 수이며, 1은 소수가 아닙니다. 예를 들면 $2,3,5,7,11,13,\dots$이 소수입니다.

소수 자체에서는 규칙성을 찾지 못했지만 소수의 합에는 규칙성이 있을지도 모른다고 생각했습니다. $N$ 이하의 소수의 총합을 출력하세요.

## 입력

~~~text
$N$
~~~

$1\leq N\leq1000$인 정수 $N$이 주어집니다.

## 출력

$N$ 이하의 소수의 합을 출력하세요. 마지막에는 줄바꿈을 추가하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
7
~~~

#### 출력

~~~text
17
~~~

$7$ 이하의 소수는 $2,3,5,7$이므로 $2+3+5+7=17$을 출력하면 됩니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
12
~~~

#### 출력

~~~text
28
~~~

$N$이 소수라는 보장은 없습니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
334
~~~

#### 출력

~~~text
9854
~~~

334라는 숫자에는 특별한 의미가 없습니다. 거짓말입니다.
