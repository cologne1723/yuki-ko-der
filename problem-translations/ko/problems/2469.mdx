정 $N$각형의 모든 변과 대각선 중, 공통 끝점을 가지며 서로 수직인 두 선분의 조합 개수를 구하세요.

## 조건

- $1\le T\le10^5$
- $3\le N_i\le10^9$

## 입력

```text
T
N1
...
NT
```

## 출력

각 테스트 케이스의 답을 한 줄에 하나씩 출력하세요.
