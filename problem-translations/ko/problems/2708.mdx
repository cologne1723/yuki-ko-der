## 문제

`H × W` 격자에서 `o` 칸에 도착하면 보석을 하나 얻고, `x` 칸에 도착하면 하나 잃습니다. `#` 칸은 통과할 수 없습니다. 처음 `(1,1)`은 `o`이고, 보석 0개에서 시작해 도착하며 보석 1개를 얻습니다.

오른쪽과 아래로만 이동해 `(H,W)`에 최단 거리로 도착하는 경로 중, 보석이 0개인 상태에서 보석을 잃는 일이 없는 경로의 수를 구하세요.

## 제약

- `2 ≤ H,W ≤ 10`
- 각 칸은 `o`, `x`, `#` 중 하나이며 `(H,W)`는 `#`가 아닙니다.

## 입력

```text
H W
A_{1,1}...A_{1,W}
⋮
A_{H,1}...A_{H,W}
```

## 출력

조건을 만족하는 경로 수를 출력하세요.
