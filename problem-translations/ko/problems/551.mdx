## 프롤로그

작성자의 예상 해법은 C#으로 약 1700ms가 걸리므로 LL 계열 언어로는 어려울 수도 있습니다.

여름 방학이라고 하면, 필자가 어렸을 때는 여름 방학 숙제로 계산 연습장에서 대량의 계산 연습을 하곤 했습니다.

이것은 여름 방학 숙제로 이차방정식 연습을 산더미처럼 받았던 어느 여름날의 일입니다.

kuuso 소년: “매일매일 이차방정식만 풀다니, 아무래도 질렸어.”

신: “그럼 이건 어떠냐?”

하늘에서 목소리가 들린 것 같더니 눈앞의 계산 연습장이 갑자기 눈부시게 빛났습니다.

눈부셔서 눈을 감고 잠시 후 조심스럽게 눈을 뜨자, 그곳에는 겉보기에는 특별할 것 없는 원래의 계산 연습장이 있었습니다.

kuuso 소년: “방금 그 빛은 대체 뭐였지. 뭐, 됐어.”

혼잣말하며 계산 연습장을 펼치자 낯선 위화감이 느껴졌습니다.

“(문제) 다음 이차방정식을 풀어라”

X^2 + 2X + 2 ≡ 0 (mod 5)

아무래도 신의 변덕으로 소수 법의 세계에 던져진 모양입니다.

아직 이차방정식이 10000문제나 남았는데 어떻게 해야 할지 완전히 절망한 kuuso 소년.

신: “이건 보너스다, 허허.”

정신을 차려 보니 kuuso 소년의 왼손에는 이 세계의 열쇠라고 할 수 있는 숫자 하나가 쥐어져 있었습니다.

## 문제

홀수 소수 P와 그 원시근 R이 주어집니다.

Q개의 이차방정식 AiX^2 + BiX + Ci ≡ 0 (mod P) (i=1부터 Q)를 풀어 주세요.

## 입력

```text
P R
Q
A1 B1 C1
A2 B2 C2
…
AQ BQ CQ
```

모든 입력은 정수이며 다음 제약을 만족합니다.

3 ≤ P ≤ 10^9

2 ≤ R ≤ P−1

1 ≤ Q ≤ 10^4

1 ≤ Ai < P

0 ≤ Bi < P

0 ≤ Ci < P

P는 소수입니다.

R은 P를 법으로 하는 원시근입니다.

x ≠ 0이 소수 p의 원시근이라는 것은 임의의 k (1 ≤ k ≤ p−2)에 대해 x^k ≠ 1 (mod p)인 성질을 뜻합니다. 바꾸어 말하면 p−1제곱을 했을 때 처음으로 1이 됩니다.

## 출력

Q줄로 출력하며, i번째 이차방정식 AiX^2 + BiX + Ci ≡ 0 (mod P)의 해를 i번째 줄에 출력하세요.

해는 0 ≤ X ≤ P−1 범위에 있어야 하며, 여러 개이면 공백으로 구분해 오름차순으로 모두 출력하세요.

해가 존재하지 않으면 -1을 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
5 2
3
1 0 0
1 0 1
1 0 2
```

출력:

```text
0
2 3
-1
```

첫 번째 식은 X^2 ≡ 0, 두 번째 식은 X^2 + 1 ≡ 0, 세 번째 식은 X^2 + 2 ≡ 0입니다.

mod 5의 세계에서는 0^2 ≡ 0, 1^2 ≡ 1, 2^2 ≡ 4, 3^2 ≡ 4, 4^2 ≡ 1이므로 위와 같은 결과가 됩니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
5 2
3
1 2 0
1 2 1
1 2 2
```

출력:

```text
0 3
4
1 2
```

예를 들어 mod 5의 세계에서는 2가 원시근입니다. 2^0 ≡ 1, 2^1 ≡ 2, 2^2 ≡ 4, 2^3 ≡ 3, 2^4 ≡ 1입니다.

1 ≡ 2^0, 2 ≡ 2^1, 3 ≡ 2^3, 4 ≡ 2^2입니다.
