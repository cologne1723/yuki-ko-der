$M\times N$ 격자에 보물을 묻습니다. 각 칸에는 최대 하나, 각 행에는 최대 두 개만 묻을 수 있고, 같은 행에서 보물이 인접하면 안 됩니다. 단, 첫 열과 마지막 열은 서로 인접합니다. 가능한 배치 수를 $998244353$으로 구하세요.

## 입력

```text
T
N M
```

## 출력

각 테스트 케이스의 답을 출력하세요.
