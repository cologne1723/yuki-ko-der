## 문제 설명

다음과 같이 수열 $X$를 정의합니다.

```text
X_0 = seed
X_n = 1 + (X_{n-1} ^ 2 + X_{n-1} \times 12345) \% 100000009    (1 <= n <= N)
```

여기서 `%`는 나머지 연산입니다.
위 정의로 만들어지는 $N+1$개 원소의 수열 $X$에서 $K$개의 숫자를 선택하여 곱한 값을 $T$라고 합니다. $T$를 $B$진수로 나타냈을 때 끝에 붙는 0의 개수가 최소가 되는 $T$에서, 그 0의 개수가 얼마인지 구하세요.

예를 들어 $B=18$이고 $T$가 십진수로 612라면 $T$는 18진수로 `1g0`이므로 끝의 0은 1개입니다. $B=3$이고 $T$가 십진수로 36이라면 $T$는 3진수로 `1100`이므로 끝의 0은 2개입니다.

## 입력

```text
Q
seed_1 N_1 K_1 B_1
seed_2 N_2 K_2 B_2
\ldots
seed_Q N_Q K_Q B_Q
```

첫째 줄에 질의 수 $Q$가 주어집니다. $(1 \le Q \le 1000)$
이후 $Q$개의 줄에 $seed$, $N$, $K$, $B$가 주어집니다. $(1 \le seed \le 100\,000\,009; 1 \le N \le 10\,000; 1 \le K \le N+1; 2 \le B \le 36)$

## 출력

각 질의에 대해 끝의 0 개수의 최솟값을 한 줄에 하나씩 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1

#### 입력

```text
4
98808561 8 6 18
61316635 15 11 4
37650646 100 86 20
98630457 1000 647 2
```

#### 출력

```text
1
2
6
142
```
