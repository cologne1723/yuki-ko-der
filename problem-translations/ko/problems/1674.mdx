길이 `N`인 수열 `A_i`가 주어집니다. 모든 `i`에 대해 `X + A_i = X XOR A_i`를 만족하는 양의 정수 `X`의 최솟값을 구하세요.

주어진 제약에서 조건을 만족하는 `X`는 항상 존재합니다.

## 입력

`N`과 `A_1,...,A_N`이 주어집니다.

## 출력

조건을 만족하는 `X`의 최솟값을 출력하세요.
