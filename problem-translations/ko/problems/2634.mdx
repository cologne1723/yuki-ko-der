정점 $i$에 값 $A_i$가 있는 트리가 주어집니다. 각 $i$에 대해 $A_i\le A_j$인 정점 $j$ 중 $i,j$ 사이 거리의 최댓값을 구하세요.

## 조건

- $2\le N\le2\times10^5$
- $0\le A_i\le10^9$

## 입력

```text
$N$
$A_1$ $A_2$ $\cdots$ $A_N$
$u_1$ $v_1$
\vdots
$u_{N-1}$ $v_{N-1}$
```

## 출력

각 정점의 답을 공백으로 출력하세요.
