## 문제

H행 W열의 모눈종이가 있습니다. 모눈종이의 i행 j열 칸을 (i,j)라고 합니다. 왼쪽 위 칸이 (1,1)이고, 행 번호가 증가하는 방향은 아래쪽, 열 번호가 증가하는 방향은 오른쪽입니다.

왼쪽 위 칸이 (a,b), 오른쪽 아래 칸이 (c,d)인 직사각형 영역을 {(a,b),(c,d)}라고 하겠습니다.

각 칸에는 `c` 또는 `w`가 적혀 있습니다. C군은 어떤 직사각형 영역에 치와와가 몇 마리 포함되어 있는지 알고 싶습니다. C군에 따르면 직사각형 영역 R = {(a,b),(c,d)}에 존재하는 치와와 수는 다음 조건을 만족하는 칸의 순서 있는 쌍 ((i₁,j₁),(i₂,j₂),(i₃,j₃))의 개수와 같습니다.

- 세 칸은 모두 R 내부입니다. 즉 a ≤ i₁,i₂,i₃ ≤ c이고 b ≤ j₁,j₂,j₃ ≤ d입니다.
- 세 칸은 모두 서로 다르고, 위·아래·왼쪽·오른쪽 중 한 방향으로 이 순서대로 놓여 있습니다. 칸들이 인접할 필요는 없습니다. 즉 다음 중 하나가 성립합니다.
  - i₁ = i₂ = i₃이고 j₁ < j₂ < j₃
  - i₁ = i₂ = i₃이고 j₁ > j₂ > j₃
  - i₁ < i₂ < i₃이고 j₁ = j₂ = j₃
  - i₁ > i₂ > i₃이고 j₁ = j₂ = j₃
- (i₁,j₁)에는 `c`, (i₂,j₂)와 (i₃,j₃)에는 `w`가 적혀 있습니다.

C군은 Q개의 직사각형 영역에 대해 질문합니다. 각 영역 안에 존재하는 치와와 수를 알려주세요. 답은 32비트 정수형에 들어가지 않을 수 있습니다.

## 입력

첫째 줄에 모눈종이의 행 수 H와 열 수 W가 주어집니다. 다음 H개 줄에 각 행의 문자열 sᵢ가 주어집니다. 이어서 Q와 Q개의 질문 (aᵢ,bᵢ,cᵢ,dᵢ)가 주어집니다.

```text
H W
s₁
s₂
...
s_H
Q
a₁ b₁ c₁ d₁
a₂ b₂ c₂ d₂
...
a_Q b_Q c_Q d_Q
```

- 1 ≤ H,W ≤ 500
- sᵢ는 길이 W이며 `c`, `w` 이외의 문자를 포함하지 않습니다.
- 1 ≤ Q ≤ 10000
- 1 ≤ aᵢ,cᵢ ≤ H, 1 ≤ bᵢ,dᵢ ≤ W
- aᵢ ≤ cᵢ, bᵢ ≤ dᵢ
- 질문의 직사각형은 왼쪽 위 (aᵢ,bᵢ), 오른쪽 아래 (cᵢ,dᵢ)입니다.

## 출력

Q개의 줄을 출력합니다. i번째 줄에 i번째 질문의 답을 출력하세요. 답은 32비트 정수형에 들어가지 않을 수 있습니다. 마지막에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
5 5
cwcww
wwwcw
wcwcw
ccwcc
wwwww
4
1 1 3 3
1 2 4 5
4 1 4 5
5 1 5 1
```

### 샘플 1 출력 {file="sample1.out"}

```text
3
11
0
0
```

첫 번째 질문에서 조건을 만족하는 순서는 ((1,1),(2,1),(3,1)), ((2,3),(2,2),(2,1)), ((3,1),(3,2),(3,3))입니다. 두 번째 질문에서는 예를 들어 ((3,1),(3,3),(3,4)), ((4,2),(2,2),(1,2)), ((3,2),(3,3),(3,5)) 등이 조건을 만족합니다.
