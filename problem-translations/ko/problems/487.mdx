## 문제

2017이 소수라는 사실을 기념하여 p 씨는 다음 계산식을 생각해 냈습니다.

$$X=2017+(2017\times2017)^{2017}$$

하지만 이 계산을 실제로 하면 엄청나게 큰 수가 된다는 것을 알고 $X$를 구체적으로 계산하는 것을 포기했습니다.

그래서 수치 계산에 능숙한 당신에게, 적어도 $X$를 자연수 $M$으로 나눈 나머지를 구해 달라고 부탁했습니다.

$M$이 주어질 때 $X$를 $M$으로 나눈 나머지를 출력하는 프로그램을 작성하세요.

## 입력

```text
$M$
```

$M$이 한 줄에 주어집니다.

$1\leq M\leq2017$

## 출력

$X$를 $M$으로 나눈 나머지를 한 줄에 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
523
```

출력:

```text
127
```

### 샘플 2 {file="sample2.in"}

입력:

```text
2016
```

출력:

```text
2
```

### 샘플 3 {file="sample3.in"}

입력:

```text
2017
```

출력:

```text
0
```

$X$는 2017의 배수입니다.

### 샘플 4 {file="sample4.in"}

입력:

```text
1
```

출력:

```text
0
```

$X$가 어떤 수이더라도 1로 나눈 나머지는 0입니다.
