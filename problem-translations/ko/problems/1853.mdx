양의 정수 $X$에 대해 $f(X)$를 다음과 같이 정의합니다. $A=0$에서 시작해 $A$에 1을 더하기, 1을 빼기, 2를 곱하기의 세 조작으로 $A=X$를 만들 때 필요한 최소 조작 횟수를 $f(X)$라 합니다.

## 문제

양의 정수 $N$이 주어질 때 $\sum_{i=1}^{N}f(i)$를 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
N
```

$1\le N\le10^{18}$입니다.

## 출력

답을 출력하세요.
