조건 $A_1+\cdots+A_N=B$ 및 $A_1\oplus\cdots\oplus A_N=C$를 만족하는 길이 $N$의 비음이 아닌 정수열의 개수를 구하라냥.

## 조건

- $1\le N\le6\times10^4$
- $0\le B,C<2^{60}$

## 입력

```text
N B C
```

## 출력

수열의 개수를 $998244353$으로 나눈 나머지를 출력하라냥.
