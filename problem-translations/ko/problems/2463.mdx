$1$부터 $N$까지의 숫자와 $1$부터 $M$까지의 기호 조합 카드가 각각 한 장씩 있습니다. 위에서부터 카드를 5장 들고 시작하며, 일부를 버리고 덱 위에서 같은 수를 보충하는 작업을 반복해 스트레이트 플러시를 만들 때 필요한 최소 작업 횟수를 구하세요. 스트레이트 플러시는 같은 기호이고 숫자가 연속한 5개이거나 $1,N-3,N-2,N-1,N$인 조합입니다.

## 조건

- $5\le N\le500$, $1\le M\le500$
- 모든 카드 조합은 정확히 한 장씩 있습니다.

## 입력

```text
N M
n1 m1
...
nNM mNM
```

## 출력

최소 작업 횟수를 출력하세요.
