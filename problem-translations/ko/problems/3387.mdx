## 문제 설명

길이가 $N$인 양의 정수 수열 $A$가 모든 정수 $i$($1 \leq i \leq N$)에 대해

$A_i + A_{N-i+1} = A_1 + A_N$

을 만족할 때, $A$를 `23578 수열`이라고 합니다. 이 정의는 F 문제와 동일합니다.

길이가 $N$인 양의 정수 수열 $A$가 주어집니다. $A$가 `23578 수열`인지 판정하세요.

## 입력

```text
$N$
$A_1\ A_2\ A_3\ \cdots\ A_N$
```

$1$번째 줄에 수열의 길이 $N$이 주어집니다.

$2$번째 줄에 수열 $A$의 항 $A_1,A_2,\ldots,A_N$이 공백으로 구분되어 주어집니다.

## 제한

- $1 \leq N \leq 100$
- $1 \leq A_i \leq 100$
- 입력은 모두 정수입니다.

## 출력

$A$가 `23578 수열`이면 `Yes`를, 그렇지 않으면 `No`를 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
5
2 3 5 7 8
```

#### 출력

```text
Yes
```

수열 $A=(2,3,5,7,8)$은 다음을 만족합니다.

- $A_1 + A_5 = 10 = A_1 + A_5 = 10$
- $A_2 + A_4 = 10 = A_1 + A_5 = 10$
- $A_3 + A_3 = 10 = A_1 + A_5 = 10$
- $A_4 + A_2 = 10 = A_1 + A_5 = 10$
- $A_5 + A_1 = 10 = A_1 + A_5 = 10$

따라서 23578 수열입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
4
2 3 5 7
```

#### 출력

```text
No
```

수열 $A=(2,3,5,7)$은 다음을 만족합니다.

- $A_1 + A_4 = 9 = A_1 + A_4 = 9$
- $A_2 + A_3 = 8 \neq A_1 + A_4 = 9$
- $A_3 + A_2 = 8 \neq A_1 + A_4 = 9$
- $A_4 + A_1 = 9 = A_1 + A_4 = 9$

따라서 23578 수열이 아닙니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1
100
```

#### 출력

```text
Yes
```

수열 $A=(100)$은 다음을 만족합니다.

- $A_1 + A_1 = 200 = A_1 + A_1 = 200$

따라서 23578 수열입니다.
