## 문제 설명

$N\times N$ 격자의 각 칸에 음이 아닌 정수를 적습니다. 위에서 $i$번째 행, 왼쪽에서 $j$번째 열의 칸에 적는 정수를 $A_{i,j}$라고 할 때, 다음 조건을 모두 만족하는 방법을 하나 출력하세요. 없으면 $-1$을 출력하세요.

- $A_{i,j}$ $(1\le i,j\le N)$는 $2^{30}$ 미만의 음이 아닌 정수입니다.
- 각 $i=1,2,\ldots,N$에 대해 $\displaystyle \bigwedge_{j=1}^{N} A_{i,j}=X_i$입니다.
- 각 $j=1,2,\ldots,N$에 대해 $\displaystyle \bigvee_{i=1}^{N} A_{i,j}=Y_j$입니다.
- 각 $k=1,2,\ldots,2N-1$에 대해 $\displaystyle \bigoplus_{i+j-1=k} A_{i,j}=Z_k$입니다.

테스트 케이스가 $T$개 주어집니다. 각각 답을 출력하세요.

### 기호의 정의

- $\displaystyle \bigwedge_{j=1}^{N} A_{i,j}$는 $A_{i,1},A_{i,2},\ldots,A_{i,N}$의 비트 단위 AND, 즉 $\displaystyle A_{i,1}\mathbin{\mathrm{AND}}A_{i,2}\mathbin{\mathrm{AND}}\cdots\mathbin{\mathrm{AND}}A_{i,N}$입니다.
- $\displaystyle \bigvee_{i=1}^{N} A_{i,j}$는 $A_{1,j},A_{2,j},\ldots,A_{N,j}$의 비트 단위 OR, 즉 $\displaystyle A_{1,j}\mathbin{\mathrm{OR}}A_{2,j}\mathbin{\mathrm{OR}}\cdots\mathbin{\mathrm{OR}}A_{N,j}$입니다.
- $1\le i,j\le N$이고 $i+j-1=k$인 인덱스 쌍을 $(i_1,j_1),(i_2,j_2),\ldots,(i_m,j_m)$이라고 합시다. $\displaystyle \bigoplus_{i+j-1=k} A_{i,j}$는 $A_{i_1,j_1},A_{i_2,j_2},\ldots,A_{i_m,j_m}$의 비트 단위 XOR, 즉 $\displaystyle A_{i_1,j_1}\mathbin{\mathrm{XOR}}A_{i_2,j_2}\mathbin{\mathrm{XOR}}\cdots\mathbin{\mathrm{XOR}}A_{i_m,j_m}$입니다.

## 입력

표준 입력으로 다음 형식의 입력이 주어집니다. $case_i$는 $i$번째 테스트 케이스입니다.

```text
$T$
$case_1$
$case_2$
$\vdots$
$case_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$X_1\ X_2\ \ldots\ X_N$
$Y_1\ Y_2\ \ldots\ Y_N$
$Z_1\ Z_2\ \ldots\ Z_{2N-1}$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $1\leq T\leq 10^5$
- $1\leq N\leq 500$
- $0\leq X_i\lt 2^{30}$
- $0\leq Y_j\lt 2^{30}$
- $0\leq Z_k\lt 2^{30}$
- 한 입력 파일에서 $N^2$의 합은 $2.5\times 10^5$ 이하입니다.

## 출력

각 테스트 케이스에 대해 조건을 만족하는 방법이 있으면 다음 형식으로 하나를 출력하세요. 없으면 $-1$을 출력하세요.

```text
$A_{1, 1}\ A_{1, 2}\ \ldots\ A_{1, N}$
$A_{2, 1}\ A_{2, 2}\ \ldots\ A_{2, N}$
$\vdots$
$A_{N, 1}\ A_{N, 2}\ \ldots\ A_{N, N}$
```

각 테스트 케이스의 출력 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
3
1 0 2
7 7 3
3 4 0 0 2
1
1
0
0
```

#### 출력

```text
3 5 1
1 6 2
7 2 2
-1
```

첫 번째 테스트 케이스에서는 다음이 성립하므로 정답입니다.

- $\displaystyle \bigwedge_{j=1}^{N} A_{1,j}=3\ \mathrm{AND}\ 5\ \mathrm{AND}\ 1=1$
- $\displaystyle \bigwedge_{j=1}^{N} A_{2,j}=1\ \mathrm{AND}\ 6\ \mathrm{AND}\ 2=0$
- $\displaystyle \bigwedge_{j=1}^{N} A_{3,j}=7\ \mathrm{AND}\ 2\ \mathrm{AND}\ 2=2$
- $\displaystyle \bigvee_{i=1}^{N} A_{i,1}=3\ \mathrm{OR}\ 1\ \mathrm{OR}\ 7=7$
- $\displaystyle \bigvee_{i=1}^{N} A_{i,2}=5\ \mathrm{OR}\ 6\ \mathrm{OR}\ 2=7$
- $\displaystyle \bigvee_{i=1}^{N} A_{i,3}=1\ \mathrm{OR}\ 2\ \mathrm{OR}\ 2=3$
- $\displaystyle \bigoplus_{i+j-1=1} A_{i,j}=3$
- $\displaystyle \bigoplus_{i+j-1=2} A_{i,j}=5\ \mathrm{XOR}\ 1=4$
- $\displaystyle \bigoplus_{i+j-1=3} A_{i,j}=1\ \mathrm{XOR}\ 6\ \mathrm{XOR}\ 7=0$
- $\displaystyle \bigoplus_{i+j-1=4} A_{i,j}=2\ \mathrm{XOR}\ 2=0$
- $\displaystyle \bigoplus_{i+j-1=5} A_{i,j}=2$

두 번째 테스트 케이스에서는 모든 조건을 만족하는 $A_{1,1}$이 없습니다.
