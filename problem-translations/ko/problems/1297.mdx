## 문제 설명

동서로 늘어선 섬 $1,2,\ldots,N$에 각 섬마다 동상을 하나씩 세웁니다. 장인 $i$는 섬 $i$에 살며, 섬 $j$에 동상을 세워 달라고 부탁할 때 작업비는 매번 $a_i$, 장인 $i$에게 처음 부탁할 때 설계비 $b_i$, $i\neq j$이면 교통비 $|i-j|C$가 듭니다.

모든 동상을 세우는 데 필요한 최소 비용을 구하세요.

## 입력

```text
N C
a_1 b_1
\vdots
a_N b_N
```

## 출력

최소 비용을 출력하세요.
