sepa는 열심히 공부한 덕분에 내일부터 시작하는 $N$일 중 평일을 최대 $M$일까지 휴일로 바꿀 수 있게 되었습니다.

휴일을 만들 때 길이 $N$인 문자열 $S$에 다음 규칙이 적용됩니다.

## 휴일 변경 규칙

- $S_i$가 `-`이면 오늘부터 $i$일 후는 원래 평일이지만 휴일로 바꿀 수 있습니다.
- $S_i$가 `o`이면 오늘부터 $i$일 후는 이미 휴일입니다.
- $S_i$가 `x`이면 오늘부터 $i$일 후는 평일이며 휴일로 바꿀 수 없습니다.

모든 조작이 끝난 뒤, 다음 조건을 만족하는 날은 모두 휴일로 바뀝니다.

- $2 \le i \le N-1$이고, 오늘부터 $i-1$일 후와 $i+1$일 후가 휴일이며 $S_i\ne\text{x}$이면 오늘부터 $i$일 후도 휴일이 됩니다.

sepa가 최적으로 행동할 때 내일부터 시작하는 $N$일 중 휴일의 최댓값을 구하세요.

## 조건

- $3 \le N \le 10^5$
- $0 \le M \le N$
- $S_i$는 `-`, `o`, `x` 중 하나입니다.
- $S_1$과 $S_N$은 `x`입니다.

## 입력

```text
$N$ $M$
$S$
```

## 출력

휴일의 최댓값을 한 줄에 출력하세요.
