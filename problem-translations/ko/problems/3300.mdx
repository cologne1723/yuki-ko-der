## 문제 설명

발판이 $10^{100}$개 있고, 발판에는 $1, 2, \ldots, 10^{100}$의 번호가 순서대로 붙어 있습니다.
또한 개구리는 발판 $1$에 있습니다.

이제 sepa와 ryota가 게임을 합니다. sepa가 선공이고 ryota가 후공이며, 다음 동작을 번갈아 반복합니다.

- 개구리가 발판 $i$에 있을 때, 발판 $i+A$ 또는 발판 $i+B$로 이동합니다.

개구리를 $N \leq k$를 만족하는 발판 $k$로 이동시키면, 그 차례의 플레이어가 패배하고 게임이 종료됩니다.

$2$명의 플레이어가 모두 최적으로 행동할 때 어느 쪽이 게임에서 이기는지 판정하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ A\ B$
```

입력은 모두 정수입니다.

## 제한

- $2 \leq N \leq 10^{18}$
- $1 \leq A < B \leq 10^{18}$
- 입력은 모두 정수입니다.

## 출력

$2$명의 플레이어가 최적으로 행동했을 때 sepa가 이기는 경우 `sepa`를, ryota가 이기는 경우 `ryota`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
6 2 3
```

#### 출력

```text
sepa
```

처음에 sepa가 개구리를 발판 $1$에서 발판 $4$로 이동시키면, ryota가 어떻게 행동하더라도 반드시 sepa가 이길 수 있습니다.

### 예제 2 {file=""}

#### 입력

```text
1000000000000 38 2357
```

#### 출력

```text
ryota
```
