## 문제 설명

太郎くん은 제야의 종을 치게 되었습니다.

太郎くん은 종을 $1$번 칠 때마다 太郎君의 번뇌가 $1$개 줄어들며, 번뇌가 없어질 때까지 계속 칩니다.

太郎くん의 번뇌는 $N$개 있고, 종을 $1$번 치는 데 $A$초가 걸립니다.

현재 시각은 2025년 12월 31일 $H$시 $M$분 $S$초입니다. 太郎くん이 지금부터 종을 치기 시작할 때, 종을 치는 중이거나 종을 다 친 시점에 해를 넘을 수 있는지 구하세요.

여기서 해를 넘는다는 것은 해가 바뀌는 것을 뜻하며, 여기서는 날짜가 2025년 12월 31일이므로 날짜가 바뀌는 것을 의미합니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ A\ H\ M\ S$
```

## 제한

- $1\leq N\leq500$
- $1\leq A\leq300$
- $0\leq H\leq23$
- $0\leq M\leq59$
- $0\leq S\leq59$
- 입력은 모두 정수입니다.

## 출력

太郎君이 종을 치는 중이거나 종을 다 친 시점에 해를 넘는다면 `Yes`를, 해를 넘지 않는다면 `No`를 출력하세요. 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
108 100 23 0 0
```

#### 출력

```text
Yes
```

太郎くん은 $3$시간 만에 종을 다 치므로, 종을 치면서 해를 넘을 수 있습니다.

### 예제 2 {file=""}

#### 입력

```text
150 300 0 0 0
```

#### 출력

```text
No
```

### 예제 3 {file=""}

#### 입력

```text
150 60 21 30 0
```

#### 출력

```text
Yes
```

종을 다 친 시점에 $0$시가 되는 경우도 있습니다.
