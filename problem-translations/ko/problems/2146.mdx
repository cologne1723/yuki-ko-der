원소가 모두 $2$의 거듭제곱인 공집합이 아닌 다중집합 $S$를 생각하자냥. 원소 수를 $x$, 원소의 종류 수를 $y$, 최댓값을 $2^z$라 하고 비용을 $Ax+By+Cz$로 정의한다냥. 각 $0\le k<N$에 대해 원소 합을 $N$으로 나눈 나머지가 $k$인 $S$의 비용 최솟값을 구하라냥.

## 조건

- $2\le N\le2\times10^5$
- $1\le A,B,C\le10^9$

## 입력

```text
N A B C
```

## 출력

$i$번째 줄에 나머지가 $i-1$일 때의 답을 출력하라냥.
