## 문제

[No.386 탐욕스러운 영주](http://yukicoder.me/problems/no/386)의 변형 버전입니다.

어떤 나라에 N개의 마을이 있습니다. 마을들은 N-1개의 가도로 서로 연결되어 있어 자유롭게 오갈 수 있습니다.

이 나라의 영주는 세수를 늘리기 위해 마을에 검문소를 설치하고, 이곳을 지나는 행상인에게 통행세를 부과하기로 했습니다. 행상인은 각 마을을 지날 때마다 통행세가 시행된 뒤 지금까지 그 마을을 지나간 행상인 수에 1을 더한 만큼의 돈을 내야 합니다. 수요가 높으면 가격도 높아지는 것이 경제의 이치겠지요.

통행세가 시행된 뒤 Q명의 행상인이 각각 마을 Aᵢ에서 마을 Bᵢ까지 가도를 따라 최단 경로로 이동했다는 사실을 알고 있습니다. 나라가 얻게 될 통행세의 총액을 출력하세요.

행상인은 이동 중 들르는 마을의 검문소뿐 아니라 마을 Aᵢ와 마을 Bᵢ의 검문소에도 통행세를 내야 합니다.

## 입력

입력은 모두 정수입니다. 첫째 줄에 마을 수 N, 다음 N-1개 줄에 가도로 연결된 마을 정보가 주어집니다. i번째 가도는 마을 uᵢ와 마을 vᵢ를 연결합니다. N+1번째 줄에 행상인 수 Q가 주어지고, 이어지는 Q개 줄에 i번째 행상인의 출발지 마을 Aᵢ와 도착지 마을 Bᵢ가 주어집니다.

```text
N
u₁ v₁
⋮
uₙ₋₁ vₙ₋₁
Q
A₁ B₁
⋮
A_Q B_Q
```

제약은 다음과 같습니다.

- 2 ≤ N ≤ 10^5
- 1 ≤ uᵢ,vᵢ ≤ N
- uᵢ ≠ vᵢ
- 1 ≤ Q ≤ 10^5
- 1 ≤ Aᵢ,Bᵢ ≤ N
- Aᵢ ≠ Bᵢ

## 출력

통행세의 총액을 한 줄에 출력하세요. 답이 32비트 정수에 들어가지 않을 수 있으므로 주의하세요.


### 샘플 1 출력 {file="sample1.out"}

```text
15
```

행상인 3명이 순서대로 이동했다고 가정합니다. (합계만 출력하므로 각자가 실제로 낸 금액은 중요하지 않습니다.)

첫 번째 행상인은 마을 1에서 1, 마을 2에서 1의 통행세를 냅니다.

두 번째 행상인은 마을 3에서 1, 마을 2에서 2, 마을 4에서 1의 통행세를 냅니다. 마을 2는 이미 첫 번째 행상인이 지나갔으므로 2를 내야 합니다.

세 번째 행상인은 마을 4에서 2, 마을 2에서 3, 마을 1에서 2, 마을 5에서 1, 마을 6에서 1의 통행세를 냅니다.

합계는 1+1+1+2+1+2+3+2+1+1 = 15입니다.
