## 문제

3차원 공간의 네 점 $A,B,C,D$가 주어집니다. 삼각형 $ABC$가 놓인 평면(평면 $ABC$)에 수직인 방향으로 삼각형 $ABC$를 늘려 만든 삼각기둥 내부에 점 $D$가 있는지 판정하세요. 평면 $ABC$가 $XY$평면과 평행하다는 보장은 없습니다.

점 $D$를 평면 $ABC$에 투영한 점과 삼각형 $ABC$의 각 변 사이의 거리는 모두 0.01 이상입니다.

## 입력

```text
x1 y1 z1
x2 y2 z2
x3 y3 z3
x4 y4 z4
```

각 $x_i,y_i,z_i$는 $i$번째 점의 좌표인 정수입니다.

- $-10^6\le x_i,y_i,z_i\le10^6$

## 출력

삼각기둥 내부에 있으면 YES, 그렇지 않으면 NO를 한 줄에 출력하세요. 그 외의 내용은 출력하면 안 됩니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
0 0 0
2 0 0
1 2 0
1 1 1
```

출력:

```text
YES
```

이 경우 삼각형 $ABC$가 $XY$평면과 평행하므로 점 $D$를 $XY$평면에 투영한 뒤 점이 삼각형 내부인지 판정하면 됩니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
3 0 0
0 3 0
0 0 3
1 1 9
```

출력:

```text
NO
```

이 경우 삼각형 $ABC$는 $XY$평면과 평행하지 않습니다.
