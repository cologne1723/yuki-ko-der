## 문제

수직선 위에 집과 우체통이 늘어서 있습니다.

우체통에는 목적지인 집이 적힌 우편물이 들어 있습니다.

모든 우편물을 우체통에서 회수해 목적지의 집까지 배달해야 합니다.

필요한 최소 이동 거리를 구하세요. 배달의 시작점과 끝점은 자유롭게 선택할 수 있고, 우편물은 한 번에 몇 개든 운반할 수 있습니다.

## 입력

```text
N M
x1 d1
y1 y2 … yd1
x2 d2
y1 y2 … yd2
…
xM dM
y1 y2 … ydM
```

1 ≤ N ≤ 7 × 10^6

1 ≤ M ≤ 5 × 10^5

0 ≤ xi < N, 0 ≤ yi < N

1 ≤ di이며 sum(di) ≤ 10^6

정수 좌표 [0,N)에 집과 우체통이 놓여 있습니다. M은 우체통의 수입니다.

xi는 i번째 우체통의 위치입니다.

di는 i번째 우체통에 들어 있는 우편물의 수입니다.

xi,di 다음 줄의 yj는 i번째 우체통의 j번째 편지가 배달될 집의 위치입니다.

우편물의 목적지 좌표와 우편물이 들어 있는 우체통의 좌표가 같을 수도 있습니다.

## 출력

모든 우편물을 목적지까지 배달하는 데 필요한 최소 이동 거리를 출력하세요.

```text
1
```

출력:

```text

```
