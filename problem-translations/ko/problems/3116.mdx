## 문제 설명

$N$개의 칸 $1,2,\ldots,N$이 일직선상에 서로 인접하게 놓여 있습니다.

$1 \leq i < N$일 때, 칸 $i$와 칸 $i+1$은 인접합니다.

플레이어는 비용 $1$을 지불하면 인접한 칸으로 이동할 수 있습니다.

칸에는 텔레포터가 설치되어 있을 수 있습니다. 칸 $x$에 비용 $c$인 텔레포터가 설치되어 있다면, 현재 위치와 관계없이 비용 $c$를 지불하면 칸 $x$로 이동할 수 있습니다.

처음에는 텔레포터가 존재하지 않습니다. $Q$개의 질의가 주어지므로 순서대로 처리하세요.

- 질의 $1$: 칸 $1$에서 칸 $x$까지 이동하는 데 필요한 비용의 최솟값을 출력하세요.
- 질의 $2$: 칸 $x$에 새로 비용 $c$인 텔레포터를 설치합니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ Q$
$Query_1$
$Query_2$
$\vdots$
$Query_Q$
```

$Query_i$는 다음 형식 중 $1$개입니다.

질의 $1$의 경우:

```text
$1\ x$
```

질의 $2$의 경우:

```text
$2\ x\ c$
```

## 제한

- $1 \leq N \leq 2 \times 10^5$
- $1 \leq Q \leq 2 \times 10^5$
- 질의 $1$은 $1$개 이상 주어집니다.
- 질의 $1$에 대해 $1 \leq x \leq N$입니다.
- 질의 $2$에 대해 $1 \leq x \leq N$입니다.
- 질의 $2$에 대해 $1 \leq c \leq 10^9$입니다.

## 출력

질의 $1$의 답을 주어진 순서대로 줄바꿈으로 구분하여 출력하세요.
