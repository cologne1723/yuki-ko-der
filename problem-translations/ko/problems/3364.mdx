## 문제 설명

太郎君은 처음에 빈 배열 $A=()$를 가지고 있습니다. 太郎君은 다음 **연산**을 $L$회 수행하여 길이가 $L$인 배열을 완성합니다.

단, 연산 횟수 $L$은 $1 \le L \le N$을 만족하는 임의의 정수입니다.

- $1$ 이상 $N$ 이하인 정수 $1$개를 선택하고, 선택한 값을 $A$의 끝에 추가합니다.

완성한 길이 $L$의 배열은 다음 **조건**을 만족해야 합니다.

- $L$을 완성한 배열의 길이, $A_i$를 배열의 $i$번째 수라고 할 때, $\gcd(A_1,A_2,\ldots,A_L) \equiv 0 \pmod L$을 만족합니다.

  단, $\gcd(x)=x$로 정의합니다.

위 **연산**으로 만들 수 있고 **조건**을 만족하는 배열이 모두 몇 종류 존재하는지 그 종류 수를 구하세요. 답이 매우 커질 수 있으므로, $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 입력

```text
$N$
```

입력은 위 형식으로 표준 입력에서 주어집니다.

## 제한

- $N$은 정수입니다.
- $1 \le N \le 10^{11}$

## 출력

$998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}


#### 출력

```text
3
```

$A=(1),(2),(2,2)$가 조건을 만족합니다.
