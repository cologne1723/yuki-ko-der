$2$ 이상인 정수 $N$에 대해 길이 $3N$의 문자열 $S$를 하나 구성하세요. 문자는 A, B, C만 사용합니다. 연속 부분 문자열 `ABC`를 삭제하는 것만으로는 빈 문자열로 만들 수 없어야 하고, 연속일 필요 없는 부분 수열 `ABC`를 삭제하는 것만으로는 빈 문자열로 만들 수 있어야 합니다. 또한 `AA`, `BB`, `CC`를 포함하면 안 됩니다.

## 조건

- $1\le T\le100$, $2\le N\le100$

## 입력

```text
$T$
$N$
\vdots
```

## 출력

각 테스트 케이스에 대해 조건을 만족하는 문자열을 한 줄에 하나씩 출력하세요.
