**이 문제는 8이 포함된 수 세기 (쉬움)(콘테스트 A 문제)와 설정이 같고, 제한과 그 밖의 세부 사항만 다릅니다.**

**이 문제를 정답으로 맞히는 코드를 제출하면 8이 포함된 수 세기 (쉬움)도 정답으로 맞힐 수 있습니다.**

## 이야기

AngrySadEight さん은 숫자 $8$을 매우 좋아합니다. 그래서 $8$이 포함된 수가 몇 개인지 세어 보기로 했습니다.

## 문제 설명

십진 표기에 숫자 $8$이 포함된 $N$ 이하의 양의 정수가 몇 개인지 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

$N$은 정수입니다.

## 제한

- $1 \le N < 10^{888\,888}$

## 출력

정답은 매우 커질 수 있으므로, 정답을 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
8
```

#### 출력

```text
1
```

$8$ 이하의 양의 정수 중 $8$이 포함된 수는 $8$이며, $1$개입니다. 따라서 $1$을 출력하세요.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
88
```

#### 출력

```text
17
```

$88$ 이하의 양의 정수 중 $8$이 포함된 수는 $8, 18, 28, 38, 48, 58, 68, 78, 80, 81, 82, 83, 84, 85, 86, 87, 88$의 $17$개입니다. 따라서 $17$을 출력하세요.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1
```

#### 출력

```text
0
```

$1$ 이하의 양의 정수 중 $8$이 포함된 수는 존재하지 않습니다. 따라서 $0$을 출력하세요.

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
888
```

#### 출력

```text
241
```

### 예제 5 {file="01_sample_05.txt"}

#### 입력

```text
888888888888888888888888
```

#### 출력

```text
241265183
```

입력이 $64$비트 정수의 범위 안에 들어오지 않을 수 있음에 주의하세요. 또한 정답을 $998\,244\,353$으로 나눈 나머지를 출력하세요.
