## 문제

Yuki 씨는 어떤 문자열을 중간에 아무것도 넣지 않고 두 번 연속 읽었습니다. 같은 문자열을 두 번 연속 읽었는지 확인하세요.

## 입력

~~~text
$S$
~~~

$S$는 소문자 알파벳으로 이루어진 문자열이며 $2\leq|S|\leq20$입니다.

## 출력

같은 문자열을 두 번 연속 읽었다면 YES, 그렇지 않다면 NO를 출력하세요. 마지막에는 줄바꿈을 추가하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
yukicoderyukicoder
~~~

#### 출력

~~~text
YES
~~~

조건을 만족합니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
yukicoder
~~~

#### 출력

~~~text
NO
~~~

조건을 만족하지 않습니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
aaaa
~~~

#### 출력

~~~text
YES
~~~

aa를 두 번 반복해 읽었으므로 조건을 만족합니다.

### 샘플 4 {file="sample4.in"}

#### 입력

~~~text
aaaaa
~~~

#### 출력

~~~text
NO
~~~

조건을 만족하지 않습니다.
