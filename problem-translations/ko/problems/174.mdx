## 이야기

A君과 B君은 카드 게임을 좋아합니다.

## 문제 설명

$1$부터 $1\,000$까지의 정수가 $1$개씩 쓰인 카드 $1\,000$장이 있고, $2$명의 사람에게 각각 $N$장씩 나눠 줍니다. A君의 카드는 $A_1,\ldots,A_N$, B君의 카드는 $B_1,\ldots,B_N$입니다.

게임은 아주아주아주 간단합니다. 게임은 $N$경기로 이루어집니다. 각 경기에서 각자 카드 $1$장을 내고, 더 큰 숫자의 카드를 낸 사람이 경기에서 이깁니다. 승자는 $2$장의 카드 숫자의 합을 점수로 얻으며, $1$번 낸 카드는 다시 사용할 수 없습니다. 모든 경기 후 총점이 더 큰 사람이 승자이며, 동점이면 승자는 없습니다.

A君이 이길 확률을 계산하려고 했지만… 너무 불쌍하므로 승패는 신경 쓰지 말고 A君이 얻는 총점의 기댓값을 구하세요.

$2$명의 사람은 작은 카드를 일찍 내는 습관이 있습니다. 사용할 수 있는 카드가 $1$장뿐이면 반드시 그 카드를 냅니다. $2$장 이상이면 현재 카드 중 가장 작은 카드를 A君은 확률 $P_A$, B君은 확률 $P_B$로 내고, 나머지 카드는 모두 같은 확률로 냅니다. 선택은 과거 경기 결과나 현재 카드 상태와 독립입니다.

## 입력

```text
$N\ P_A\ P_B$
$A_1\ A_2\ \cdots\ A_N$
$B_1\ B_2\ \cdots\ B_N$
```

## 제한

- $1 \le N \le 20$
- $0.500 \le P_A,P_B \le 0.999$
- $P_A,P_B$는 소수점 이하 $3$자리 이하입니다.
- 모든 카드 숫자는 $1$ 이상 $1\,000$ 이하입니다.
- 모든 카드 숫자 $A_1,\ldots,A_N,B_1,\ldots,B_N$은 서로 다릅니다.

## 출력

A君이 얻는 총점의 기댓값을 출력하세요. 절대 오차 또는 상대 오차가 $10^{-9}$ 이하이면 정답으로 인정됩니다.
