## 문제 설명

이하에서는 열 $X$와 정수 $s,t\ (s<t)$에 대해, 인덱스가 $0$부터 시작하는 열 $X_s, X_{s+1}, \ldots, X_{t-1}$을 $X[s,t)$로 나타냅니다. 단, $X_{|X|+m}=X_m$으로 합니다.

또한 어떤 열의 원소 합이 $0$일 때, 그 열을 **레이와**라고 합니다.

레이와인 열 $X[s,t)\ (s<t)$가 **유일하다**는 것은 $s<x<t$를 만족하는 어떤 정수 $x$에 대해서도 $X[s,x)$가 레이와가 아님을 뜻합니다.

다음 조건을 모두 만족하는 정수열 $A$의 개수를 $10^9+7$로 나눈 나머지를 구하세요.

- $A$의 모든 원소는 $-1$ 또는 $1$입니다.
- $A$는 레이와입니다.
- $0\le l<|A|$ 및 $l<r$을 만족하는 정수 $l,r$의 순서쌍 중 $A[l,r)$가 유일한 것은 정확히 $K$개입니다.

## 입력

```text
$K$
```

## 제한

- 입력은 모두 정수입니다.
- $1\le K\le10^9$

## 출력

정답을 출력하고, 마지막에 개행을 넣으세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
```

#### 출력

```text
6
```

예를 들어 $A=\{1,-1,1,-1\}$이라고 하면 $A[0,2)$, $A[1,3)$, $A[2,4)$, $A[3,5)$가 유일합니다.

### 예제 2 {file=""}

#### 입력

```text
3
```

#### 출력

```text
0
```

조건을 만족하는 열은 존재하지 않습니다.

### 예제 3 {file=""}

#### 입력

```text
100000
```

#### 출력

```text
149033233
```

$10^9+7$로 나누는 것을 잊지 마세요.

### 예제 4 {file=""}

#### 입력

```text
114514810
```

#### 출력

```text
438430625
```
