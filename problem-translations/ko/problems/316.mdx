## 참고

이 문제는 [Advent Calendar Contest Advent Calendar 2015](http://www.adventar.org/calendars/912)의 $9$일차 문제로 만들어졌습니다.

## 이야기

yumechiくん은 프로그래밍 초보라 FizzBuzz 문제를 풀고 있습니다. 하지만 일반적인 FizzBuzz는 너무 쉬워서 조금 더 발전된 문제를 풀어 보려고 합니다.

일반적인 FizzBuzz에서는 $3$의 배수일 때 `Fizz`, $5$의 배수일 때 `Buzz`를 출력하지만, yumechiくん은 $3$의 배수 또는 $5$의 배수인 수를 세려고 합니다. 예를 들어 $1$ 이상 $100$ 이하에서 $3$의 배수 또는 $5$의 배수인 수는 $47$개입니다.

## 문제 설명

yumechiくん은 이를 발전시켜, $1$ 이상 $N$ 이하에서 $3$개의 정수 $a,b,c$ 중 적어도 $1$개의 배수인 수(즉, $a$ 또는 $b$ 또는 $c$의 배수인 수)의 개수를 세려고 합니다. 당신은 지기 싫어하므로 이 이야기를 들은 즉시 yumechiくん보다 빨리 프로그램을 완성하려고 코딩을 시작했습니다.

## 입력

```text
$N$
$a\ b\ c$
```

$1$번째 줄에 범위의 끝점 $N$, $2$번째 줄에 $3$개의 정수 $a,b,c$가 주어집니다.

## 제한

- $1 \le N \le 10^9$
- $1 \le a \le b \le c \le 10^4$

## 출력

$1$ 이상 $N$ 이하에서 $a,b,c$ 중 적어도 $1$개의 배수인 수의 개수를 출력하세요.

마지막에 개행을 출력하세요.

```text

```

#### 출력

