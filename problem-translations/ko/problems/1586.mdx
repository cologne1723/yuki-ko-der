## 문제

수열 $A$에 대해 서로 다른 $i,j$를 골라 동시에 $A_i$를 1 증가시키고 $A_j$를 1 감소시키는 작업을 여러 번 할 수 있습니다.

이 작업으로 모든 원소를 같은 값으로 만들 수 있는지 판정하세요.

## 입력

$N$과 수열 $A$가 주어집니다.

- $2\leq N\leq100000$
- $1\leq A_i\leq10^9$

## 출력

가능하면 `Yes`, 불가능하면 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
48 51 51
```

#### 출력

```text
Yes
```

### 예제 2 {file=""}

#### 입력

```text
7
80 90 65 65 80 50 65
```

#### 출력

```text
No
```

### 예제 3 {file=""}

#### 입력

```text
3
219 219 219
```

#### 출력

```text
Yes
```
