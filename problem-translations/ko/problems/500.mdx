## 문제

팩토리얼 계산기는 어떤 양의 정수의 팩토리얼이든 2초 이내에 계산하는 계산기입니다.

양의 정수 N을 입력하고 “!” 버튼을 누르면 N의 팩토리얼 N!을 계산합니다.

단, 팩토리얼 계산기의 액정이 고장 나서 아래 12자리까지만 표시됩니다.

양의 정수 N을 입력하고 “!” 버튼을 누른 뒤 계산기의 표시가 어떻게 되는지 출력하세요.

## 입력

```text
$N$
```

N은 양의 정수입니다. 1 ≤ N ≤ 999999999999

## 출력

답을 한 줄에 출력하세요. 출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
4
```

출력:

```text
24
```

4!은 4 × 3 × 2 × 1 = 24입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
12
```

출력:

```text
479001600
```

12! = 479001600입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
24
```

출력:

```text
239439360000
```

답은 최대 아래 12자리까지만 표시된다는 점에 주의하세요.
