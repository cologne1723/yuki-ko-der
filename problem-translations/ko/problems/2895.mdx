## 문제 설명

길이 $N$인 음이 아닌 정수 수열 $A = (A_1, A_2, \dots, A_N)$이 주어집니다.

다음 조건을 만족하는 비어 있지 않은 수열 $B$가 존재하는지 판정하고, 존재한다면 그중 $1$개를 제시하세요. 여기서 $B$의 길이를 $M$이라고 합니다.

- $1 \le B_i \le N$
- $1 \le i < j \le M$일 때 $B_i \ne B_j$
- $A_{B_1} \oplus A_{B_2} \oplus \dots \oplus A_{B_M} = 0$

여기서 음이 아닌 정수 $x$, $y$에 대해 $x \oplus y$는 $x$와 $y$의 배타적 논리합을 나타냅니다.

## 입력

```text
$N$
$A_1\ \ A_2\ \cdots\ A_N$
```

$N$은 수열 $A$의 길이입니다.

$2$번째 줄에 수열 $A$의 원소 $A_1$, $A_2$, $\dots$, $A_N$이 주어집니다.

## 제한

- $1 \le N \le 2 \times 10^5$
- $0 \le A_i < 2^{60}$
- 입력은 모두 정수입니다.

## 출력

조건을 만족하는 $B$가 존재하지 않는 경우 $-1$을 출력하고 줄바꿈하세요.

그렇지 않은 경우 다음 형식으로 출력하세요.

```text
$M$
$B_1\ \ B_2\ \ \cdots\ B_M$
```

조건을 만족하는 출력이 여러 개라면 그중 $1$개를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
2 0 2 4
```

#### 출력

```text
2
1 3
```

$A_{B_1} \oplus A_{B_2} = A_1 \oplus A_3 = 2 \oplus 2 = 0$이므로 이 출력은 올바릅니다.

그 밖에도 다음과 같은 출력이 정답으로 인정됩니다.

```text
1
2
```

### 예제 2 {file=""}

#### 입력

```text
3
2024 20 24
```

#### 출력

```text
-1
```

조건을 만족하는 $B$는 존재하지 않습니다.
