## 문제

케이크의 맛 `x`는 처음에 1입니다. 향신료 A는 `x←2x+1`, 향신료 B는 `x←3x+1`로 바꿉니다. 맛이 `N`이 되도록 하는 향신료 사용 순서는 정확히 하나 존재합니다.

그 순서를 A와 B로 이루어진 문자열로 출력하세요. 사용하지 않아도 되면 빈 줄을 출력합니다.

## 제약

- `1 ≤ N ≤ 10^18`
- 주어진 수는 두 연산으로 만들 수 있고 해가 둘 이상 존재하지 않습니다.

## 입력

```text
N
```

## 출력

향신료 사용 순서를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
9
```

#### 출력

```text
BA
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1
```

#### 출력

```text

```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
7
```

#### 출력

```text
AA
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
1035
```

#### 출력

```text
BABABBA
```
