## 문제 설명

입력의 $1$번째 줄에 양의 정수 $N$, $M$이 주어집니다. 처음에는 집합 $\Delta$가 공집합으로 주어집니다. 다음에서 설명하는 $M$개의 질의를 주어진 순서대로 처리하세요.

$q$번째 질의는 $1 \leq A_q < B_q < C_q \leq N$을 만족하는 정수 $A_q$, $B_q$, $C_q$으로 주어집니다. $\Delta$에 $\{A_q,B_q,C_q\}$의 공집합이 아닌 부분집합 $\{A_q\},\{B_q\},\{C_q\},\{A_q,B_q\},\{B_q,C_q\},\{A_q,C_q\},\{A_q,B_q,C_q\}$을 모두 원소로 추가하여 갱신합니다.

각 질의에 대해 $\Delta$가 コーエン-マコーレー인지 판정하세요.

단, $\Delta$가 ‘コーエン-マコーレー’라는 것은 다음 $3$가지 조건을 모두 만족하는 것을 의미합니다.

- (`CO`) $\Delta$는 연결입니다.
- (`H1`) $H_1(\Delta; \mathbb{F}_2) = 0$입니다.
- (`LK`) $\{i\} \in \Delta$인 각 $i$에 대해 ${\rm link}_\Delta \{i\}$가 연결입니다.

용어를 설명합니다. $\Delta$는 $\emptyset \not\in \Delta$이고, $\sigma \in \Delta$ 및 $\emptyset \neq \tau \subseteq \sigma$이면 $\tau \in \Delta$인 조건을 만족합니다. 이러한 것을 추상 단체 복합체라고 합니다. 정점 수가 유한한 추상 단체 복합체는 독립성 시스템에서 공집합을 제거한 것과 다름없습니다.

추상 단체 복합체 $\Delta$가 비연결이라는 것은, 공집합이 아닌 서로소인 $2$개의 추상 단체 복합체 $\Delta_1$, $\Delta_2$를 사용하여 $\Delta = \Delta_1 \cup \Delta_2$로 나타낼 수 있다는 뜻입니다.

비연결이 아니면 연결이라고 합니다.

${\rm link}_\Delta \{i\} := \{ \sigma \in \Delta \, | \, i \not\in \sigma$이고 $\{i\} \cup \sigma \in \Delta \}$

는 추상 단체 복합체입니다.

조건 `H1`은 다음과 같이 바꾸어 말할 수 있습니다.

$\Delta$에 속하는 원소 $1$개짜리 집합을 ‘점’, 원소 $2$개짜리 집합을 ‘간선’, 원소 $3$개짜리 집합을 ‘면’이라고 부릅니다.

$\Delta$의 간선을 흰색 또는 검은색으로 칠한다고 합시다. ‘좋은 색칠’이란 각 점 $\{i\}$에 대해 $\{i,j\}$라는 형태로 나타나는 검은색 간선의 개수가 짝수인 색칠입니다.

처음에 모든 간선을 흰색으로 칠하고, 면 $\{i,j,k\}$를 $1$개 선택하여 $3$개의 간선 $\{ i, j \}, \{ j, k \}, \{ k, i \}$의 색을 반전하는 조작을 반복해서 얻을 수 있는 ‘좋은 색칠’을 ‘면에 의한 색칠’이라고 합니다.

$2$번째 조건은 ‘좋은 색칠’이 반드시 ‘면에 의한 색칠’이라는 뜻으로 바꾸어 말할 수 있습니다.

### 배경

추상 단체 복합체는 그 ‘기하학적 실현’을 생각하면 이해하기 쉽습니다.

$\{i\} \in \Delta$인 $i$에 대응하는 정점 $v_i$를 가져옵니다. $\{i,j\} \in \Delta$이면 $v_i$, $v_j$ 사이에 선분을 그립니다. $\{i,j,k\} \in \Delta$이면 $v_i$, $v_j$, $v_k$ $3$개의 점이 이루는 삼각형을 채웁니다.

이렇게 해서 얻는 도형이 ‘기하학적 실현’입니다. 물론 간선이나 삼각형이 이상하게 교차하지 않도록 고차원 공간 안에 잘 배치해야 합니다.

예를 들어, 추상 단체 복합체

$\{ \{1, 2, 3\}, \{1, 3, 4\}, \{1, 2, 4\}, \{2, 3, 4\}, \{1, 2\}, \{1, 3\}, \{1, 4\}, \{2, 3\}, \{2, 4\}, \{ 3, 4\}, \{1\}, \{2\}, \{3\}, \{4\} \}$

의 ‘기하학적 실현’은 정사면체입니다.

즉, 추상 단체 복합체는 삼각형을 붙여 만든 다면체에서 삼각형들의 면, 간선, 점이 어떻게 연결되는지에 대한 정보를 추출한 것입니다.

이처럼 기하학적으로 생각하면 추상 단체 복합체가 비연결인 것과 그 기하학적 실현이 비연결인 것은 동치입니다.

#### 가환대수 용어를 아는 사람을 위한 설명

$\underline{i} = (i_1, \dots, i_k), 1 \leq i_1 < \dots < i_k \leq N, \{ i_1, \dots, i_k \} \not\in \Delta$에 대해 단항식 $X_{\underline{i}} := X_{i_1} \cdots X_{i_k}$로 생성되는 $\mathbb{F}_2[X_1, \dots, X_N]$의 아이디얼을 $I_\Delta$라고 합시다.

$\mathbb{F}_2[\Delta] := \mathbb{F}_2[X_1, \dots, X_N] / I_\Delta$를 $\Delta$의 スタンレー-ライズナー 환이라고 부릅니다. 이 환이 コーエン-マコーレー인지 판정하는 문제입니다.

#### 여담

$d$차원 모멘트 곡선 $M_d = \{ (t, t^2, \dots, t^d) \,|\, t \in \mathbb{R} \}$ 위의 서로 다른 $N > d$개의 점의 볼록 껍질을 $C(N,d)$라고 씁니다.

$d-1$차원 볼록 다면체 $\Delta$의 $i$차원 면의 개수를 $f_{\Delta,i}$라고 하고, $f_\Delta = (f_{\Delta,0}, \dots, f_{\Delta,d-1})$라고 씁니다. 이를 $f$-벡터라고 부릅니다.

$\Delta$가 $d-1$차원 구면과 위상동형일 때, $\Delta$의 정점 수를 $v$라고 하면 $f_{\Delta,i} \leq f_{C(v,d),i}$ ($i = 0, \dots, d-1$)가 성립하지 않겠느냐는 추측을 ‘상한 추측’이라고 부릅니다.

이는 $i \leq \lfloor d/2 \rfloor$일 때 성립하고 $f$-벡터에 일종의 대칭성이 있기 때문에 자연스럽게 제기된 추측이지만, スタンレー는 이를 증명할 방법을 알지 못했습니다.

그러던 어느 날, ライズナー라는 사람이 ライズナー 환이 コーエン-マコーレー라는 위상적·조합적 판정 조건을 **상한 추측을 알지 못한 채 학위 논문에서** 발표했습니다.

$\Delta$가 $d-1$차원 구면과 위상동형일 때 $\Delta$의 ライズナー 환이 コーエン-マコーレー라는 사실이 판정 조건에서 밝혀지는 동시에, コーエン-マコーレー 환에서는 앞의 부등식이 성립한다는 것을 바로 알 수 있으므로 상한 추측이 풀려 버린 것입니다!

해설에 참고 문헌이 있으므로 관심이 있는 분은 그쪽도 참고하세요.

## 입력

$1$번째 줄에 정수 $N$, $M$이 공백으로 구분되어 주어집니다.

다음 $M$개의 줄에 $q$번째 질의를 나타내는 정수 $A_q$, $B_q$, $C_q$가 공백으로 구분되어 주어집니다.

```text
$N\ M$
$A_1\ B_1\ C_1$
$\vdots$
$A_M\ B_M\ C_M$
```

## 제한

- $3 \leq N \leq 10^3$
- $1 \leq M \leq 10^3$
- 모든 $q = 1, \dots, M$에 대해 $1 \leq A_q < B_q < C_q \leq N$

## 출력

주어지는 질의 $1 \leq A_q < B_q < C_q \leq N$ ($q = 1, \dots, M$)에 대해, $q$번째 질의까지 처리한 뒤의 $\Delta$를 기준으로 다음과 같이 $q$번째 줄에 출력하세요.

- $\Delta$가 `CO`를 만족하지 않으면 `CO`를 출력합니다.
- 그렇지 않고 $\Delta$가 `H1`을 만족하지 않으면 `H1`을 출력합니다.
- 그렇지 않고 $\Delta$가 `LK`를 만족하지 않으면 `LK`를 출력합니다.
- 그렇지 않으면, 즉 コーエン-マコーレー이면 `CM`을 출력합니다.

마지막에 개행을 출력하세요.

최종적으로 만들어지는 $\Delta$는 기하학적 실현이 정사면체인 추상 단체 복합체입니다.

예를 들어

${\rm link}_\Delta \{1\} = \{ \{2,3\}, \{2,4\}, \{3,4\}, \{2\}, \{3\}, \{4\} \}$

는 기하학적 실현이 삼각형(변만 있는)이며 연결입니다.

모든 좋은 색칠이 면에 의한 색칠이라는 것은 모든 색칠을 열거하면 확인할 수 있을 것입니다.
