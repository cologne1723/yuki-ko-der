## 문제 설명

양의 정수 $N$, $S$, $T$, $K$와 길이가 $N$인 정수열 $A = (A_1, A_2, \ldots, A_N)$가 주어집니다.

변수 $i$는 처음에 $i = S$로 초기화되어 있습니다.

다음 조작을 원하는 만큼 수행해 $i = T$로 만드는 것이 목표입니다.

- 조작: $A_i + A_j \leq K$가 되도록 $j$를 선택하고, $i$를 $j$로 변경합니다.

$i = T$로 만드는 데 필요한 조작 횟수의 최솟값을 출력하세요. $i = T$로 만드는 것이 불가능하면 $-1$을 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ S\ T\ K$
$A_1\ A_2\ \cdots\ A_N$
```

$1$번째 줄에 양의 정수 $N$, $S$, $T$, $K$가 공백으로 구분되어 주어집니다.

$2$번째 줄에 정수열 $A$의 $N$개 원소 $A_1, A_2, \ldots, A_N$이 공백으로 구분되어 주어집니다.

## 제한

- $2 \leq N \leq 2 \times 10^5$
- $1 \leq S, T \leq N$
- $S \neq T$
- $1 \leq A_i \leq 10^9$
- $1 \leq K \leq 10^9$
- 입력은 모두 정수입니다.

## 출력

$i = T$로 만드는 데 필요한 조작 횟수의 최솟값을 출력하세요. 불가능하면 $-1$을 출력하세요.

출력한 뒤 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 1 3 9
5 4 5
```

#### 출력

```text
2
```

처음에 $i = 1$입니다.

$A_1 + A_2 = 9 \leq 9$이므로 $i = 2$로 변경합니다.

$A_2 + A_3 = 9 \leq 9$이므로 $i = 3$으로 변경합니다.

$2$번의 조작으로 $i = 3$이라는 목표를 달성할 수 있습니다.

$1$번의 조작으로 $i = 3$으로 만들 수는 없으므로 $2$를 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
2 1 2 1
61 99
```

#### 출력

```text
-1
```

$i = 1$인 상태에서 $i = 2$로 만드는 것은 불가능합니다.
