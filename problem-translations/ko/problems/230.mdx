## 문제

*Splarraay*는 배열을 칠하는 간단한 게임입니다. 플레이어는 팀 A와 팀 B로 나뉘며, 각 팀을 나타내는 색으로 하나의 배열을 서로 칠합니다. 최종 점수는 해당 팀의 색으로 칠해진 원소의 수와 아래에서 설명하는 보너스 점수의 합으로 정해지고, 점수가 높은 팀이 승리합니다.

규칙은 다음과 같습니다.

1. 길이 $N$이고 어떤 색으로도 칠해지지 않은 배열이 주어집니다.
2. 두 팀은 배열의 어떤 구간 $[l,r]$을 자신의 팀 색으로 칠합니다. 칠하려는 위치에 이미 색이 칠해져 있으면 나중에 칠한 색으로 덮어씁니다.
3. 비정기적으로 보너스 기회가 주어집니다. 보너스 기회에서는 구간 $[l,r]$이 주어지고, 그 시점에 팀 A가 구간 $[l,r]$에서 칠한 원소 수를 $A_{l,r}$, 팀 B가 칠한 원소 수를 $B_{l,r}$라고 할 때 더 큰 값을 가진 팀에 $\max(A_{l,r},B_{l,r})$의 보너스 점수를 줍니다. $A_{l,r}$와 $B_{l,r}$가 같으면 어느 팀에도 보너스 점수를 주지 않습니다.
4. 시간 제한으로 게임이 종료되면, 전체 구간 $[0,N-1]$에서 해당 팀의 색으로 칠해진 원소 수와 그때까지 얻은 보너스 점수의 합이 그 팀의 점수가 됩니다.

게임은 이미 종료되었고 이제 점수만 계산하면 됩니다. 각 팀의 행동 기록과 보너스 기회의 상세 내용이 시간 순서대로 주어질 때 최종 점수를 계산하세요.

## 입력

```text
N
Q
x l r
```

- $N$: 서로 칠할 배열의 길이
- $Q$: 각 팀의 행동 횟수와 보너스 기회 횟수의 합. 다음 $Q$개 줄에 행동 또는 보너스 기회의 상세 내용이 시간 순서대로 주어집니다.
- $x=0$: 구간 $[l,r]$의 보너스 기회
- $x=1$: 팀 A가 구간 $[l,r]$을 칠하는 행동
- $x=2$: 팀 B가 구간 $[l,r]$을 칠하는 행동

모든 입력은 정수이며 다음 제약을 만족합니다.

- $1 \leq N \leq 100\,000$
- $1 \leq Q \leq 100\,000$
- $0 \leq x \leq 2$
- $0 \leq l \leq r \leq N-1$

## 출력

팀 A의 점수와 팀 B의 점수를 공백으로 구분하여 출력하세요. 마지막에 개행을 넣으세요.

```text
팀 A의 점수 팀 B의 점수
```

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
2
1 0 3
2 2 4
```

#### 출력

```text
2 3
```

배열은 다음과 같이 변합니다.

```text
[-----]
[AAAA-]
[AABBB]
```

### 예제 2 {file=""}

#### 입력

```text
5
3
1 0 4
2 1 3
0 4 4
```

#### 출력

```text
3 3
```

배열은 다음과 같이 변합니다.

```text
[-----]
[AAAAA]
[ABBBA]
[ABBBA] Bonus! A +1
```

### 예제 3 {file=""}

#### 입력

```text
6
6
1 1 2
2 4 5
0 2 4
2 0 3
1 1 5
0 0 5
```

#### 출력

```text
10 1
```

배열은 다음과 같이 변합니다.

```text
[------]
[-AA---]
[-AA-BB]
[-AA-BB] Bonus!
[BBBBBB]
[BAAAAA]
[BAAAAA] Bonus! A +5
```

첫 번째 보너스 기회에서는 $A_{2,4}=B_{2,4}=1$이므로 어느 팀에도 보너스 점수가 들어가지 않습니다. 두 번째 보너스 기회에서는 $A_{0,5}=5>B_{0,5}=1$이므로 A에 5점의 보너스가 주어집니다.
