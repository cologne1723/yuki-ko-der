## 공지

**이 문제의 점수 순위는 [여기](https://yukicoder.me/problems/no/5010/score)에서 확인하세요.**

이 문제는 [Advent Calendar Contest 2022](https://adventar.org/calendars/7521) $17$일 차의 **문제 $1$**입니다.

난이도는 Advent Calendar Contest에 맞추어 부여되었습니다. 올바른 출력을 하면 대회에서 점수를 얻을 수 있습니다.

## 문제에 관한 규칙

Advent Calendar Contest 2022 $17$일 차의 `Better Mo's Algorithm is Needed!!`는 $2$개의 문제로 이루어져 있습니다.

- **문제 $1$: `Better Mo's Algorithm is Needed!! (Unweighted)`**
- 문제 $2$: `Better Mo's Algorithm is Needed!! (Weighted)`

이 문제는 **문제 $1$**입니다.

문제 $2$와의 차이점은 다음과 같습니다.

- $WT=1$로 고정되어 있습니다.
- $W_i=100$으로 고정되어 있습니다.
- 문제 $2$의 $W$는 기댓값이 약 $50$이 되도록 생성됩니다. 따라서 문제 $2$에서는 문제 $1$의 $2$배 이상인 점수를 기대할 수 있습니다.

이 문제의 종합 순위는 다음과 같이 결정됩니다.

- 문제 $1$의 점수와 문제 $2$의 점수의 합이 높은 참가자가 더 높은 순위입니다.
- 이 방법으로 순위를 정할 수 없으면 공동 순위입니다.

종합 순위는 대회 기간이 끝난 뒤 수동으로 집계합니다.

**점수 문제이므로 마지막 제출 후 $5$분 동안은 다음 제출을 할 수 없습니다.**

이 문제에 대해 출제자가 대회 중 허용하는 언급 규칙은 다음과 같습니다.

- 풀이에 직접 관련되지 않는 부분(로컬 테스트 방법 등)은 논의하거나 상담할 수 있습니다.
- 자원자가 비주얼라이저를 만들어 공개하는 등의 행위도 허용됩니다.
- **자신의 풀이를 직접 언급하거나 코드를 공유하는 것도 허용됩니다.**
  - 단, 이로 인해 다른 참가자가 답안을 개선했다면 그 점수는 개선한 코드를 제출한 참가자의 점수가 됩니다.

대회 기간이 끝난 뒤 리저지나 시스템 테스트 등은 예정되어 있지 않습니다.

2022-12-17 23:30:00에 대회 기간이 끝나며, 해설 페이지에서 테스트 케이스 생성에 사용한 시드를 공개합니다.

## 문제 설명

길이 $N$인 수열인 가중치 $W=(W_1,W_2,\dots,W_N)$가 주어집니다.

또한 $1\leq L_i\leq R_i\leq N$을 만족하는 구간 $[L_i,R_i]$가 $Q$개 주어집니다.

$(1,2,\dots,Q)$의 순열인 $P=(P_1,P_2,\dots,P_Q)$를 적절히 정하여, 다음과 같이 정의되는 실행 시간 $T$를 최소화하세요.

실행 시간 $T$는 다음과 같이 정의됩니다.

- 먼저 $T=\displaystyle\sum_{k=L_{P_1}}^{R_{P_1}}W_k$로 설정합니다.
- 다음으로 $i=1,2,\dots,Q-1$에 대해 다음을 수행합니다.
  - $[a,b]=[L_{P_i},R_{P_i}]$, $[c,d]=[L_{P_{i+1}},R_{P_{i+1}}]$로 설정합니다.
  - $\alpha=\min(a,c)$, $\beta=\max(a,c)$로 설정하고, $T$에 $\displaystyle\sum_{k=\alpha}^{\beta-1}W_k$를 더합니다. $a=c$일 때 더하는 값은 $0$입니다.
  - $\gamma=\min(b,d)$, $\delta=\max(b,d)$로 설정하고, $T$에 $\displaystyle\sum_{k=\gamma+1}^{\delta}W_k$를 더합니다. $b=d$일 때 더하는 값은 $0$입니다.

## 입력

```text
$N\ Q\ WT\ ST$
$W_1\ W_2\ \dots\ W_N$
$L_1\ R_1$
$L_2\ R_2$
$\vdots$
$L_Q\ R_Q$
```

$WT$는 $W$의 생성 방법을, $ST$는 구간의 생성 방법을 나타내는 정수입니다. 자세한 내용은 뒤에서 설명합니다.

## 제한

- 입력은 모두 정수입니다.
- $N=200\,000$
- $Q=200\,000$
- $WT=1$
- $1\leq ST\leq3$
- $W_i=100$
- $1\leq L_i\leq R_i\leq N$

## 출력

순열 $P$를 다음 형식으로 출력하세요.

```text
$P_1\ P_2\ \dots\ P_Q$
```

## 점수

이 문제에는 테스트 케이스가 $120$개 있습니다.

각 테스트 케이스의 점수는 $\min\left(\operatorname{round}\left(\dfrac{10^{18}}{T}\right),10^{16}\right)$입니다.

이 문제의 최종 점수는 모든 테스트 케이스의 점수 합입니다.

## 입력 생성 방법

$l$ 이상 $r$ 이하인 정수를 반환하는 균일 난수를 $\operatorname{rnd}(l,r)$로 나타냅니다.

$N=200\,000$, $Q=200\,000$은 고정되어 있습니다.

이 문제에서는 $WT=1$입니다. $WT=1$이면 모든 $i$에 대해 $W_i=100$입니다.

또한 $ST$는 $1$, $2$, $3$ 중 $1$개이며, 테스트 케이스에는 각 $ST$가 같은 수만큼 포함됩니다.

$ST=1$이면 구간 $[L_i,R_i]$는 반드시 방법 $1$로 생성됩니다.

$ST=2$이면 구간 $[L_i,R_i]$는 반드시 방법 $2$로 생성됩니다.

$ST=3$이면 각 구간에 대해 방법 $1$과 방법 $2$ 중 $1$개를 동일한 확률로 독립적으로 선택하고, 선택한 방법으로 구간을 생성합니다.

방법 $1$:

- $x=\operatorname{rnd}(1,N)$, $y=\operatorname{rnd}(1,N)$으로 생성합니다.
- $x>y$이면 $x$와 $y$를 교환합니다.
- 생성되는 구간은 $[x,y]$입니다.

방법 $2$:

- $l=\operatorname{rnd}(1,N)$으로 생성합니다.
- $x=\operatorname{rnd}(1,N-l+1)$로 생성하고 $y=x+l-1$로 설정합니다.
- 생성되는 구간은 $[x,y]$입니다.
