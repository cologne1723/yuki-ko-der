## 문제

색은 `M`차원 벡터 `(C_1, C_2, ..., C_M)`로 표현됩니다. 각 성분은 `0` 이상 `100` 이하의 정수입니다.

서로 다른 색을 가진 카드가 `N`장 있습니다. `i`번째 카드의 색은 `(C_{i,1}, C_{i,2}, ..., C_{i,M})`이고, 불투명도는 `T_i%`입니다.

서로 다른 두 카드 `i, j`를 고르고, 카드 `i`를 카드 `j` 위에 겹칩니다. 이때 만들어지는 색 `Y`의 각 성분은 다음과 같습니다.

`Y_k = (T_i / 100) × C_{i,k} + (1 - T_i / 100) × (T_j / 100) × C_{j,k}`

어떤 순서로 두 카드를 골랐을 때 목표 색 `X`와 같은 색을 만들 수 있는지 판정하세요.

## 제약

- `2 ≤ N ≤ 2 × 10^5`
- `1 ≤ M ≤ 10`
- `0 ≤ X_k < 2^16`
- `0 ≤ C_{i,k} < 2^16`
- `0 < T_i ≤ 100`
- 카드의 색은 서로 다릅니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
N M
X_1 X_2 ... X_M
C_{1,1} C_{1,2} ... C_{1,M} T_1
⋮
C_{N,1} C_{N,2} ... C_{N,M} T_N
```

## 출력

만들 수 있으면 `Yes`, 만들 수 없으면 `No`를 출력하세요.
