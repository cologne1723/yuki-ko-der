## 문제 설명

$X_1 + X_2 + \dots + X_N$과 $Y_1 + Y_2 + \dots + Y_N$을 각각 $998\,244\,353$으로 나눈 나머지를 구하세요.

입력으로 주어지는 정수 $X_1, Y_1$에 대해 $X_n, Y_n$을 다음과 같이 귀납적으로 정의합니다.

$X_{n+1} = X_1X_n - 5Y_1Y_n$

$Y_{n+1} = X_1Y_n + X_nY_1$

## 입력

```text
$X_1\ Y_1\ N$
```

$1$번째 줄에 정수 $X_1$, $Y_1$, $N$이 주어집니다.

## 제한

- $-10^{18} \leq X_1, Y_1 \leq 10^{18}$
- $1 \leq N \leq 10^{18}$

## 출력

$X_1 + X_2 + \dots + X_N$과 $Y_1 + Y_2 + \dots + Y_N$을 각각 $998\,244\,353$으로 나눈 나머지를 반각 공백 $1$개로 구분하여 출력하세요. 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1 1 1
```

#### 출력

```text
1 1
```

$N = 1$이므로 $X_1, Y_1$을 그대로 출력하면 됩니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 1 2
```

#### 출력

```text
7 7
```

$X_1 = 3, Y_1 = 1$이므로 $X_2 = 3 \times 3 - 5 \times 1 \times 1 = 4$, $Y_2 = 3 \times 1 + 3 \times 1 = 6$입니다.

$X_1 + X_2 = 7, Y_1 + Y_2 = 7$입니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1 -1 9
```

#### 출력

```text
998241312 755
```
