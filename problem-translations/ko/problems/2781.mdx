## 문제 설명

정수 $A$, $B$가 $2$개 주어집니다. 단, $B \neq 0$입니다.

$A$를 $B$로 나눈 나머지를 구하세요.

단, 이 문제에서 "$A$를 $B$로 나눈 나머지"란 $A = Bq+r$을 만족하는 정수 $q$가 존재하며, $|B|$보다 작은 유일한 음이 아닌 정수 $r$을 뜻합니다.

## 입력

입력은 다음 형식으로 표준 입력에서 $1$줄에 주어집니다.

```text
$A\ B$
```

즉, $A$, $B$가 반각 공백으로 구분되어 주어집니다.

## 제한

- $A$는 $-10^2 \leq A \leq 10^2$를 만족하는 정수입니다.
- $B$는 $-10^2 \leq B \leq 10^2$ 및 $B \neq 0$을 만족하는 정수입니다.

## 출력

$A$를 $B$로 나눈 나머지를 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1
```

#### 출력

```text
0
```

$1 = 1 \times 1 + 0$이고 $0 < |1|$이므로, $1$을 $1$로 나눈 나머지는 $0$입니다.

### 예제 2 {file=""}

#### 입력

```text
1 -2
```

#### 출력

```text
1
```

이처럼 $B$가 음수일 수도 있으므로 주의하세요.

$1 = (-2) \times 0 + 1$이고 $1 < |{-2}|$이므로, $1$을 $-2$로 나눈 나머지는 $1$입니다.

### 예제 3 {file=""}

#### 입력

```text
-1 2
```

#### 출력

```text
1
```

이처럼 $A$가 음수일 수도 있으므로 주의하세요.

$-1 = 2 \times (-1) + 1$이고 $1 < |2|$이므로, $-1$을 $2$로 나눈 나머지는 $1$입니다.
