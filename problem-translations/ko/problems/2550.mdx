$N$단 계단에서 0단에서 출발해 $N$단으로 점프합니다. $i$번째 행동에서 $x$단에서 $j$단으로 점프하면 $iA_j$점을 얻습니다. 가능한 모든 점프 순서에 대한 총점의 합을 $998244353$으로 나눈 나머지를 구하세요.

## 조건

- $1\le N\le2\times10^5$
- $0\le A_i<998244353$

## 입력

```text
N
A1 A2 ... AN
```

## 출력

답을 출력하세요.
