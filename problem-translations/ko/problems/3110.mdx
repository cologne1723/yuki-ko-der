## 문제 설명

영문 대문자로 이루어진 문자열 $S$가 CPCTF적이라는 것은, $S$의 길이가 $5$이고 $S_i = S_j$인 것과 $i = j \vee \{i,j\} = \{1,3\}$인 것이 동치라는 뜻입니다. 여기서 $S_i$는 $S$의 $i$번째 문자를 나타냅니다.

즉, $1$번째 문자와 $3$번째 문자만 같고 나머지 문자는 $S$에 각각 $1$번씩만 나타나는, 길이가 $5$인 영문 대문자 문자열을 CPCTF적이라고 합니다.

예를 들어 `ABACD`는 CPCTF적이지만 `ABABC`는 CPCTF적이지 않습니다.

길이가 $N$인 영문 대문자 문자열 $S$가 주어집니다. $S$의 연속하지 않아도 되는 부분수열 중 CPCTF적인 것은 몇 개인지 구하세요.

단, 부분수열은 추출한 위치가 다르면 문자열이 같더라도 서로 다른 것으로 셉니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$S$
```

## 제한

- $1 \leq N \leq 30$
- $S$는 길이가 $N$인 영문 대문자만으로 이루어진 문자열입니다.

## 출력

$1$줄에 CPCTF적인 부분수열의 개수를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
11
NEOSHOWCASE
```

#### 출력

```text
16
```

문자열 `NEOSHOWCASE`에는 부분수열로 `OSOCE`가 포함되어 있으며, 이는 CPCTF적인 문자열입니다.

이 문자열에 포함된 CPCTF적인 부분수열은 $1$번째 문자와 $3$번째 문자가 `O`인 것 $16$개입니다.

### 예제 2 {file=""}

#### 입력

```text
3
PPC
```

#### 출력

```text
0
```

### 예제 3 {file=""}

#### 입력

```text
30
CPCTFCPCTFCPCTFCPCTFCPCTFCPCTF
```

#### 출력

```text
4011
```
