## 문제

배열 $a[0],a[1],\ldots,a[1,000,000,000]$이 처음에는 모두 0입니다. 다음 두 질의를 처리하고, 모든 타입 1 질의의 값 합을 한 줄에 출력하세요.

타입 0은 $0\ x\ y$ 형식이며 $a[x]$의 값을 $y$만큼 증가시킵니다.

타입 1은 $1\ l\ r$ 형식이며 당시 $a[l]+a[l+1]+\ldots+a[r]$를 답에 더합니다.

답 변수 ans를 0으로 초기화한 뒤 모든 질의를 처리하세요.

## 입력

~~~text
$n$
$q_1$
$\vdots$
$q_n$
~~~

$2\leq n\leq100000$이고 이어지는 $n$줄에 질의가 주어집니다. 모든 입력은 정수이며, $0\leq x,l,r\leq10^9$, $l\leq r$, $0\leq y\leq1000$입니다.

## 출력

마지막 질의 처리 후 ans를 한 줄에 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
10
0 5 2
0 4 3
1 3 5
0 2 1
1 2 4
0 4 2
0 4 4
0 7 1
1 2 5
1 0 10
~~~

#### 출력

~~~text
34
~~~

ans는 타입 1 질의마다 5, 9, 21, 34로 증가하고 마지막에 34가 출력됩니다.
