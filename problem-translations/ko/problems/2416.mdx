체력이 $h$인 슬라임을 공격하면 슬라임이 사라지고, 체력이 $\lfloor h/A\rfloor$인 슬라임 두 마리가 생깁니다. 모든 슬라임의 체력을 0 이하로 만들면 승리합니다. 체력 $H$인 슬라임 한 마리를 이기는 데 필요한 최소 공격 횟수를 구하세요.

## 조건

- $1\le H\le10^{12}$
- $2\le A\le10^{12}$

## 입력

```text
H A
```

## 출력

최소 공격 횟수를 출력하세요.

## 예제

### 입력 1

```text
3 2
```

### 출력 1

```text
3
```
