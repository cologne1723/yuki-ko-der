## 문제 설명

양의 정수 $N$, $K$($K \leq N$)가 주어집니다.

$1 \leq a,b \leq K$이고 $x=a \times b$를 만족하는 정수쌍 $(a,b)$가 존재하지 않는 양의 정수 $x$를 “좋은” 수라고 정의합니다.

$N$ 이하인 가장 큰 좋은 양의 정수 $x$를 출력하세요. 그러한 $x$가 존재하지 않으면 $-1$을 출력하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 문제를 해결하세요.

## 입력

```text
$T$
$case_1$
$case_2$
$\vdots$
$case_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ K$
```

입력은 모두 다음 제한을 만족합니다.

## 제한

- $1 \leq T \leq 10$
- $1 \leq K \leq N \leq 10^9$
- $N$, $K$는 정수입니다.

## 출력

$answer_i$를 $case_i$에 대한 답이라고 할 때, 다음 형식으로 출력하고 마지막에 개행을 출력하세요.

```text
$answer_1$
$answer_2$
$\vdots$
$answer_T$
```

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
16 5
100 100
2 1
```

#### 출력

```text
14
-1
2
```

- $1$번째 테스트 케이스에서 $x=14$는 $1 \leq a,b \leq 5$이고 $x=a \times b$를 만족하는 정수쌍 $(a,b)$가 존재하지 않으므로 좋은 수입니다.
- $x=15,16$은 각각 $5$ 이하의 양의 정수를 사용해 $15=3 \times 5$, $16=4 \times 4$로 나타낼 수 있으므로 좋은 수가 아닙니다.
- 따라서 $N=16$ 이하에서 $14$보다 큰 좋은 수는 존재하지 않으므로 답은 $14$입니다.
- $2$번째 테스트 케이스에는 $N$ 이하인 좋은 정수 $x$가 존재하지 않습니다.
