## 문제

`N × N` 보드에서 A와 B가 빙고 게임을 합니다. 처음에는 모든 칸이 `.`입니다.

A가 빈 칸 하나를 골라 `A`로 칠하고, A의 빙고가 있으면 A가 승리합니다. 없으면 B가 빈 칸 하나를 골라 `B`로 칠하고, B의 빙고가 있으면 B가 승리합니다. 빙고란 가장 최근에 칠한 칸과 같은 문자가 세로, 가로 또는 대각선으로 `N`칸 연속하는 상태입니다.

A는 자신의 차례에 한 칸을 칠하면 빙고가 되는 직선이 있음을 발견했습니다. 현재 보드가 주어질 때, A의 리치인 직선의 수를 구하세요. 리치는 빈 칸 하나를 적절히 칠해 빙고가 되는 직선입니다.

## 제약

- `2 ≤ N ≤ 100`
- 각 문자열은 `A`, `B`, `.`로 이루어진 길이 `N`의 문자열입니다.
- 리치는 하나 이상 존재하고, 현재 빙고는 없습니다.

## 입력

```text
N
S_1
⋮
S_N
```

## 출력

A의 리치인 직선의 수를 출력하세요.
