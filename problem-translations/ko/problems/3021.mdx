## 문제 설명

`Python3`, `PyPy3`에는 표준 라이브러리에 `eval`이라는 함수가 있습니다. ([공식 레퍼런스](https://docs.python.org/ja/3.13/library/functions.html#eval))

이 함수는 인수로 받은 문자열을 코드로 해석하고 그 결과를 반환합니다. 예를 들어 `eval("1+1")`을 실행하면 $2$가 반환됩니다.

다음 조건을 만족하는 문자열 $X$를 **계산 가능한 문자열**이라고 정의합니다.

- $X$의 각 문자는 `0`을 제외한 숫자 또는 연산자(`123456789+-` 중 하나)입니다.
- $X$의 마지막 문자는 `0`을 제외한 숫자(`123456789` 중 하나)입니다.
- $X$에서 연산자(`+-` 중 하나)끼리는 서로 인접하지 않습니다.

`0`을 제외한 숫자, 연산자, `?`(`123456789+-?` 중 하나)로 이루어진 문자열 $S$가 주어집니다.

여기서 $S$에 포함된 모든 `?`를 각각 `0`을 제외한 숫자 또는 연산자(`123456789+-` 중 하나)로 바꾸어 계산 가능한 문자열 $S'$를 만드는 것을 생각합니다.

이렇게 만들 수 있는 계산 가능한 문자열 $S'$ 중, 수식으로 해석했을 때 계산 결과가 최대가 되는 것을 구하세요. 문제의 제한 아래에서는 항상 $S'$를 만들 수 있음이 보장됩니다.

$T$개의 테스트 케이스가 주어지므로 각각에 대해 답을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $\mathrm{case}_i\ (i=1,2,\ldots,T)$는 $i$번째 테스트 케이스입니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$S$
```

## 제한

- $1\leq T\leq10^4$입니다. $T$는 정수입니다.
- $1\leq|S|\leq5\times10^5$입니다. $|S|$는 $S$의 길이입니다.
- 각 입력에서 모든 테스트 케이스의 $|S|$의 합은 $5\times10^5$ 이하입니다.
- $S$의 각 문자는 `123456789+-?` 중 하나입니다.
- $S$의 마지막 문자는 `123456789` 중 하나 또는 `?`입니다.
- $S$에서 `+-` 중 하나인 연산자끼리는 서로 인접하지 않습니다.

## 출력

$T$줄을 출력하고, $i$번째 줄에는 $i$번째 테스트 케이스의 답을 출력하세요.

각 테스트 케이스에 대해 만들 수 있는 $S'$ 중, 수식으로 해석했을 때 계산 결과가 최대가 되는 것을 출력하세요.

- $5$번째 테스트 케이스에서는 주어진 $S$에 따라 계산 결과가 매우 커질 수도 있습니다.
