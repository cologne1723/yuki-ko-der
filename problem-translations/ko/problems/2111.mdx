정수열 $A=(a_1,\ldots,a_N)$가 주어집니다. 길이 $2$ 이상인 모든 부분 수열 $A'$에 대해 인접한 원소 차이의 합 $\sum_{j=1}^{k-1}(a'_j-a'_{j+1})$을 합한 값을 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
N
a_1 a_2 ... a_N
```

$2\le N\le2\times10^5$, $0\le a_i<998244353$입니다.

## 출력

답을 출력하세요.
