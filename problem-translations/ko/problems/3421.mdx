## 문제 설명

실숫값 함수 $f(x) = ax^3 + bx^2 + cx + d$를 생각합니다.

$f(x)$가 극값을 $2$개 가지는 경우 `Yes`를, 그 외의 경우 `No`를 출력하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대한 답을 구하세요.

### 극값이란?

실숫값 함수 $g(x)$에서 점 $a$를 포함하는 충분히 작은 어떤 열린 구간 안의 임의의 $b$에 대하여, $b \neq a \Longrightarrow g(b) < g(a)$가 성립하면 $g(a)$를 극댓값이라고 합니다.

$b \neq a \Longrightarrow g(b) > g(a)$가 성립하면 $g(a)$를 극솟값이라고 합니다.

극댓값과 극솟값을 합쳐 극값이라고 합니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$case_1$
$case_2$
$\vdots$
$case_T$
```

각 테스트 케이스는 다음 형식입니다.

```text
$a\ b\ c\ d$
```

## 제한

- $1\leq T \leq 10\,000$
- $-100 \leq a, b, c, d \leq 100$
- 입력은 모두 정수입니다.

## 출력

$T$줄 출력하세요.

$i$번째 줄에는 $i$번째 테스트 케이스에 대하여 $f(x)$가 극값을 $2$개 가지면 `Yes`를, 그렇지 않으면 `No`를 출력하세요.
