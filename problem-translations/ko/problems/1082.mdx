## 문제 설명

원소 수가 $N$인 음이 아닌 정수 수열 $A$가 있습니다. $A$의 $i$($1 \le i \le N$)번째 원소는 $A_i$입니다.

차완무시 군은 다음 연산을 수행합니다.

- $A$를 자유롭게 재배열합니다.
- $B_j = A_j \oplus A_{j+1}$($1 \le j \le N-1$)인 음이 아닌 정수 수열 $B$를 만듭니다.
- $X = B_1 \oplus B_2 \oplus B_3 \oplus \dots \oplus B_{N-1}$를 구합니다.

$X$의 최댓값을 구하세요.

단, $\oplus$는 비트 XOR을 나타내는 기호입니다.

※ XOR을 모르는 사람은 [이 페이지](https://ja.wikipedia.org/wiki/%E6%8E%92%E4%BB%96%E7%9A%84%E8%AB%96%E7%90%86%E5%92%8C)를 참고하세요.

## 제한

- $2 \le N \le 2 \times 10^3$
- $0 \le A_i \le 10^9$
- $N$과 $A_i$는 정수입니다.

## 입력

```text
$N$
$A_1\ A_2\ \dots\ A_N$
```

첫 번째 줄에 정수 $N$이 주어집니다.

두 번째 줄에 음이 아닌 정수 수열 $A$가 공백으로 구분되어 주어집니다.

## 출력

$X$의 최댓값을 한 줄에 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
11 13 17
```

#### 출력

```text
28
```

$A$의 재배열 방법은 $(11,13,17)$, $(11,17,13)$, $(13,11,17)$, $(13,17,11)$, $(17,11,13)$, $(17,13,11)$입니다.

이 중 $A$가 $(13,11,17)$일 때 $B$는 $(6,26)$이 되고 $X=28$이 됩니다. 이것이 $X$의 최댓값입니다.

또한 $A$가 $(17,11,13)$일 때도 $X=28$이 됩니다.

### 예제 2 {file=""}

#### 입력

```text
5
1 1 1 1 1
```

#### 출력

```text
0
```

$A$를 어떻게 재배열해도 $X=0$이 됩니다.

### 예제 3 {file=""}

#### 입력

```text
8
47 36 12 71 79 85 81 74
```

#### 출력

```text
126
```
