양의 정수 `n`이 주어집니다. `n = i^j + k` (`i`는 양의 정수, `j,k`는 음이 아닌 정수)로 나타낼 때 `i+j+k`가 최소가 되도록 하는 최솟값을 구하세요.

모든 양의 정수 `x`에 대해 `x^0=1`로 정의합니다.

## 제약

- `1 <= n <= 10^18`

## 입력

`n`이 주어집니다.

## 출력

답을 출력하세요.
