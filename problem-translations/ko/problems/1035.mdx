## 문제 설명

$1$부터 $N$까지의 서로 다른 번호가 각각 적힌 $N$개의 상자를 $M$종류의 페인트를 사용해 색칠합니다.

이때 $M$종류의 색을 모두 사용해야 하며, 각 상자는 반드시 어떤 색으로든 칠해야 합니다.

색칠하는 방법의 총 개수는 몇 개인가요? 답이 매우 커질 수 있으므로 $10^9+7$로 나눈 나머지를 출력하세요.

## 입력

```text
N M
```

입력은 정수입니다.

## 제한

$1 \leq M \leq N \leq 10^5$

## 출력

답을 한 줄에 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 2
```

#### 출력

```text
6
```

페인트의 색을 $1$, $2$로 하고, $3$개 상자의 색을 $(a,b,c)$로 나타내면 $(a,b,c)=(1,1,2),(1,2,1),(2,1,1),(2,2,1),(2,1,2),(1,2,2)$의 $6$가지 색칠 방법이 있습니다.

### 예제 2 {file=""}

#### 입력

```text
4 4
```

#### 출력

```text
24
```

### 예제 3 {file=""}

#### 입력

```text
100000 100000
```

#### 출력

```text
457992974
```
