각 값 $x$가 수열에 $L_x$번 이상 $R_x$번 이하 등장하는 길이 $m$의 수열을 좋은 수열이라 합니다. 좋은 수열이 존재하는지 판정하고, 존재하면 가능한 전도 수의 최댓값을 구하세요.

## 입력

```text
T
n m
L1 ... Ln
R1 ... Rn
```

## 출력

불가능하면 `-1`, 가능하면 최대 전도 수를 출력하세요.
