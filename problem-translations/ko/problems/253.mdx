## 이야기

ユキコちゃん과 당신은 양초를 사용하는 게임을 합니다.

## 문제 설명

양초의 처음 길이는 $X$cm입니다. **$X$는 $10$ 이상 $10^9$ 이하인 어떤 정수입니다.** 게임 중 ユキコちゃん은 양초를 볼 수 있지만 당신은 볼 수 없고 처음 길이도 모릅니다.

게임은 다음과 같이 진행됩니다.

1. ユキコちゃん이 양초에 불을 붙입니다.
2. 당신은 ユキコちゃん에게 음이 아닌 정수 $Y$에 대해 ‘**현재 양초의 길이가 $Y$cm인가요?**’라고 질문할 수 있습니다.
3. ユキコちゃん은 현재 양초의 길이가 $Y$cm보다 **짧은지**, **긴지**, **같은지** 답합니다.
4. **양초가 $1$cm 짧아집니다.** 단, 이미 다 타서 $0$cm가 되었다면 $0$cm인 채로 유지됩니다.
5. 더 질문하고 싶으면 $2$번 단계로 돌아가고, 그렇지 않으면 종료합니다.

질문 $100$번 이내에 양초의 처음 길이 $X$를 맞히세요.

## 입력

질문 질의를 실행하면 응답 프로그램이 답변 프로그램의 표준 입력으로 결과를 돌려줍니다. 현재 양초의 길이가 $Y$보다 짧으면 **$-1$**, 길면 **$1$**, 같으면 **$0$**이 입력됩니다. **질문 질의를 실행한 뒤에는 반드시 결과를 받아야 합니다.** 그렇지 않으면 응답 프로그램이 입력을 처리하지 못해 오답이 될 수 있습니다.

## 출력

제출한 프로그램(이하 답변 프로그램)은 표준 출력으로 $2$종류의 질의를 출력해야 합니다. 질문 질의는 현재 양초의 길이가 음이 아닌 정수 $Y$인지 묻는 질문 질의이고, 답변 질의는 양초의 처음 길이 $X$가 음이 아닌 정수 $Y$라고 답하는 답변 질의입니다.

질문 질의의 형식은 다음과 같습니다.

```text
$?\ Y$
```

답변 질의의 형식은 다음과 같습니다.

```text
$!\ Y$
```

질문 질의와 답변 질의에서 **$Y$가 정수가 아니거나**, **$Y$가 음수이거나**, **$Y$가 $32$비트 부호 있는 정수의 범위를 벗어나면** **오답**입니다.

각 질의의 끝에는 개행을 넣으세요. **출력한 뒤에는 출력 버퍼를 flush하세요.** flush하지 않으면 응답 프로그램이 입력을 처리하지 못해 시간 제한을 초과할 수 있고, 그 결과 오답이 될 수 있습니다.

답변 질의를 실행한 뒤에는 즉시 프로그램을 종료하세요. 종료가 늦어 시간 제한을 초과할 수 있습니다. 제한 시간 안에 종료하고, 질문 횟수가 $100$회 이내이며, 답변 질의로 출력한 $Y$와 $X$가 일치하면 정답입니다.

## 주의 사항

- 저지의 제한 시간은 $2$초이며 응답 프로그램의 반응 시간도 포함됩니다.
- $2$종류의 질의 이외의 내용을 출력하면 오답입니다.
- 표준 에러 출력은 질문 질의, 답변 질의, 잘못된 출력 중 어느 것으로도 간주하지 않습니다.

## 프로그램 예시

```cpp
int ask(int Y){
    cout << "? " << Y << endl;
    int res;
    cin >> res;
    return res;
}
int main(){
    int res = 123;
    for(int i=0;i<100;i++){
        int Y = rand() % 10000;
        if(ask(Y) == 0){
            res = 456;
            break;
        }
    }
    cout << "! " << res << endl;
    return 0;
}
```
