## 문제 설명

Alice와 Bob이 길이 $N$인 수열 $A$를 사용해 게임을 합니다. 처음에는 모든 $1 \leq i \leq N$에 대해 $A_i=-1$입니다.

Alice부터 시작해 $2$명은 번갈아 다음과 같은 일련의 조작을 수행합니다.

- $A_i=-1$인 $i$가 존재하지 않는다면 게임을 종료합니다.
- 그러한 $i$가 존재한다면 먼저 $1$ 이상 $N$ 이하의 정수 $x$와 $A_i=-1$인 $i$를 $1$개 선택합니다. 단, $x$는 $A$에 포함되어 있지 않아야 합니다.
- 그 후 $A_i$를 $x$로 바꿉니다.

게임을 종료한 후, 수열 $A$에 다음 조작을 $N-1$번 수행합니다.

- 조작을 시작할 때 $A$의 길이를 $n$이라고 하면, $A$를 $(A_1+A_2,A_2+A_3,\dots,A_{n-1}+A_n)$으로 바꿉니다.

최종적으로 $A$에는 정수 $1$개만 남는다는 것이 증명됩니다. 그 정수를 $X$라고 합니다.

문자열 $S$는 `Odd` 또는 `Even`이며, 이 게임의 승패는 다음과 같이 판정됩니다.

- $S$가 `Odd`일 때 $X$가 홀수이면 Alice의 승리이고, 짝수이면 Bob의 승리입니다.
- $S$가 `Even`일 때 $X$가 짝수이면 Alice의 승리이고, 홀수이면 Bob의 승리입니다.

$2$명이 각자의 승리를 목표로 최적으로 행동할 때, Alice와 Bob 중 누가 승리하는지 구하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답하세요.

## 입력

```text
$T$
$\text{testcase}_1$
$\text{testcase}_2$
$\vdots$
$\text{testcase}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ S$
```

## 제한

- $1 \leq T \leq 2\times 10^{5}$
- $1 \leq N \leq 10^{18}$
- $S$는 `Odd` 또는 `Even`입니다.
- $T$, $N$은 정수입니다.

## 출력

$T$줄 출력하세요.

$i$번째 줄에는 $i$번째 테스트 케이스에서 Alice가 승리한다면 `Alice`를, Bob이 승리한다면 `Bob`을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1
3 Even
```

#### 출력

```text
Alice
```

이 입력 예제에서는 $1$개의 테스트 케이스만 주어집니다.

예를 들어, 이 게임은 다음과 같이 진행됩니다.

- 처음에는 $(A_1,A_2,A_3)=(-1,-1,-1)$입니다.
- Alice가 $x=2,i=2$를 선택해 조작합니다. $(A_1,A_2,A_3)=(-1,2,-1)$이 됩니다.
- Bob이 $x=1,i=3$을 선택해 조작합니다. $(A_1,A_2,A_3)=(-1,2,1)$이 됩니다.
- Alice가 $x=3,i=1$을 선택해 조작합니다. $(A_1,A_2,A_3)=(3,2,1)$이 됩니다.
- Bob이 선택할 수 있는 $i$가 존재하지 않으므로 게임을 종료합니다.
- $A$에 조작을 수행합니다. $1$번째 조작으로 $A=(A_1+A_2,A_2+A_3)=(5,3)$이 되고, $2$번째 조작으로 $A=(A_1+A_2)=(8)$이 됩니다. 따라서 $X=8$입니다.
- $S$가 `Even`이고 $X$가 짝수이므로 Alice가 승리합니다.

이는 $2$명이 최적으로 행동한 경우가 아닐 수도 있지만, $2$명이 최적으로 행동하더라도 승자는 Alice라는 것이 증명됩니다.

이 진행에서 Alice가 $2$번째 조작에서 $x=1$을 선택하는 것은 불법입니다. $A_3=1$이므로 이미 $1$이 포함되어 있기 때문입니다.

또한 Bob이 $1$번째 조작에서 $i=2$를 선택하는 것도 불법입니다. $A_2=2$이고 $-1$이 아니기 때문입니다.
