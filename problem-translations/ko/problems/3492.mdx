> **주의**
>
> 이 문제의 실행 시간 제한은 $4\,000$ms입니다. 실행 시간이 빠듯하므로 빠른 언어·실행 환경을 사용하는 것을 권장합니다.
>
> 참고로 출제자 풀이의 실행 시간은 C++에서 $577$ms, PyPy3에서 $1\,596$ms, Python3에서 $10\,000$ms를 초과하여 `TLE`가 됩니다.

## 문제 설명

입력의 처음에 $3$개의 양의 정수 $N$, $B$, $Q$가 주어집니다.

길이 $N$인 음이 아닌 정수열 $A$가 주어지며, 처음에는 모든 성분이 $0$입니다.

이후 설명할 $Q$개의 질의를 주어진 순서대로 처리하여 $A$를 갱신하세요.

각 질의는 $1\leq L\leq M\leq R\leq N$을 만족하는 $3$개의 정수 $L$, $M$, $R$과 $2$개의 음이 아닌 정수 $C$, $D$의 조합 $(L,M,R,C,D)$입니다.

질의 $(L,M,R,C,D)$는 다음과 같이 처리합니다.

1. 먼저 $L\leq i\leq R$를 만족하는 각 양의 정수 $i$에 대해 $A$의 $i$번째 성분을 $A_i+(i+C)^D$로 바꾸어 $A$를 갱신합니다.
2. 다음으로 갱신된 $A$에 대한 $A_M$을 $B$로 나눈 나머지를 구합니다. 이하 이 값을 이 질의에 대한 답이라고 합니다.

단, $N$ 이하의 각 양의 정수 $i$에 대해 $A$의 $i$번째 성분을 $A_i$로 나타냅니다.

## 입력

$Q$ 이하의 각 양의 정수 $q$에 대해 $q$번째 질의를 $(L_q,M_q,R_q,C_q,D_q)$로 나타냅니다.

입력은 다음 형식으로 표준 입력에서 $1+Q$줄에 걸쳐 주어집니다.

- $1$번째 줄에 $N$, $B$, $Q$가 공백으로 구분되어 주어집니다.
- $Q$ 이하의 각 양의 정수 $q$에 대해 $1+q$번째 줄에 $L_q$, $M_q$, $R_q$, $C_q$, $D_q$의 각 성분이 공백으로 구분되어 주어집니다.

```text
$N\ B\ Q$
$L_1\ M_1\ R_1\ C_1\ D_1$
$\vdots$
$L_Q\ M_Q\ R_Q\ C_Q\ D_Q$
```

## 제한

입력은 다음 제한을 만족합니다.

- $N$은 $1\leq N\leq 10^4$인 정수입니다.
- $B$는 $1\leq B\leq 10^9$인 정수입니다.
- $Q$는 $1\leq Q\leq 10^4$인 정수입니다.
- $Q$ 이하의 임의의 양의 정수 $q$에 대해 다음을 만족합니다.
  - $L_q$, $M_q$, $R_q$는 $1\leq L_q\leq M_q\leq R_q\leq N$을 만족하는 정수입니다.
  - $C_q$는 $0\leq C_q\leq 10^{18}$을 만족하는 정수입니다.
  - $D_q$는 $0\leq D_q\leq 10^2$를 만족하는 정수입니다.

## 출력

$Q$ 이하의 각 양의 정수 $q$에 대해 $q$번째 질의에 대한 답을 $q$번째 줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 2 1
1 1 1 2 0
```

#### 출력

```text
1
```

처음에 길이 $N=1$인 음이 아닌 정수열 $A$가 $(0)$으로 주어집니다.

$1$번째 질의 $(L_1,M_1,R_1,C_1,D_1)=(1,1,1,2,0)$에 의해 먼저 $A$가

$\displaystyle (A_1+(1+C_1)^{D_1})=(0+(1+2)^0)=(1)$

로 바뀝니다. 따라서 갱신된 $A$에 대한 $A_{M_1}=A_1$은 $1$이고, $1$을 $B=2$로 나눈 나머지는 $1$입니다.

이번에는 $Q=1$이므로 이것으로 모든 처리가 끝납니다.

### 예제 2 {file=""}

#### 입력

```text
2 3 1
1 2 2 1 1
```

#### 출력

```text
0
```

처음에 길이 $N=2$인 음이 아닌 정수열 $A$가 $(0,0)$으로 주어집니다.

$1$번째 질의 $(L_1,M_1,R_1,C_1,D_1)=(1,2,2,1,1)$에 의해 먼저 $A$가

$\displaystyle (A_1+(1+C_1)^{D_1},A_2+(2+C_1)^{D_1})=(0+(1+1)^1,0+(2+1)^1)=(2,3)$

으로 바뀝니다. 따라서 갱신된 $A$에 대한 $A_{M_1}=A_2$는 $3$이고, $3$을 $B=3$으로 나눈 나머지는 $0$입니다.

이번에는 $Q=1$이므로 이것으로 모든 처리가 끝납니다.

### 예제 3 {file=""}

#### 입력

```text
3 4 2
1 1 2 0 2
2 2 3 2 1
```

#### 출력

```text
1
0
```

처음에 길이 $N=3$인 음이 아닌 정수열 $A$가 $(0,0,0)$으로 주어집니다.

$1$번째 질의 $(L_1,M_1,R_1,C_1,D_1)=(1,1,2,0,2)$에 의해 먼저 $A$가

$\displaystyle (A_1+(1+C_1)^{D_1},A_2+(2+C_1)^{D_1},A_3)=(0+(1+0)^2,0+(2+0)^2,0)=(1,4,0)$

으로 바뀝니다. 따라서 갱신된 $A$에 대한 $A_{M_1}=A_1$은 $1$이고, $1$을 $B=4$로 나눈 나머지는 $1$입니다.

$2$번째 질의 $(L_2,M_2,R_2,C_2,D_2)=(2,2,3,2,1)$에 의해 먼저 $A$가

$\displaystyle (A_1,A_2+(2+C_2)^{D_2},A_3+(3+C_2)^{D_2})=(1,4+(2+2)^1,0+(3+2)^1)=(1,8,5)$

로 바뀝니다. 따라서 갱신된 $A$에 대한 $A_{M_2}=A_2$는 $8$이고, $8$을 $B=4$로 나눈 나머지는 $0$입니다.

이번에는 $Q=2$이므로 이것으로 모든 처리가 끝납니다.
