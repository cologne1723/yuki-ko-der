## 이야기

茜ちゃん과 葵ちゃん은 기하를 공부하고 있습니다.

공부를 계속하던 중 이등변삼각형에 관심을 가지게 된 것 같습니다.

## 문제 설명

길이가 $N$인 수열 $A=(A_1,A_2,\cdots,A_N)$이 주어집니다.

다음 조건을 모두 만족하는 정수 튜플 $(i,j,k)$의 개수를 구하세요.

- $1\leq i<j<k\leq N$
- 변의 길이가 각각 $A_i,A_j,A_k$인, 정삼각형이 아닌 비퇴화 이등변삼각형이 존재합니다.

비퇴화 삼각형이란 $3$개의 꼭짓점이 $1$개의 직선 위에 놓이지 않는 삼각형을 말합니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$A_1\ A_2\ \ldots\ A_N$
```

## 제한

- $3\leq N\leq3\times10^5$
- $1\leq A_i\leq10^9\ (1\leq i\leq N)$
- 입력은 모두 정수입니다.

## 출력

문제 설명의 조건을 만족하는 정수 튜플 $(i,j,k)$의 개수를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
2 2 3 5 5
```

#### 출력

```text
4
```

다음 $4$개의 정수 튜플이 조건을 만족합니다: $(i,j,k)=(1,2,3),(1,4,5),(2,4,5),(3,4,5)$.

예를 들어 $(i,j,k)=(1,2,3)$일 때 변의 길이가 각각 $A_1=2,A_2=2,A_3=3$인 비퇴화 이등변삼각형이 존재합니다.

반면 $(i,j,k)=(1,2,5)$일 때는 변의 길이가 $2,2,5$인 비퇴화 이등변삼각형이 존재하지 않으므로 조건을 만족하지 않습니다.

### 예제 2 {file=""}

```text

```

#### 출력

```text
0
```

정삼각형은 제외하고 세는 것에 주의하세요.
