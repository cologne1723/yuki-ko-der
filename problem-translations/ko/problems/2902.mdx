## 문제 설명

$2$ 이상인 정수 $N$이 주어집니다.

$2$ 이상인 정수 $b$를 선택하면, $N!=p_b\times b^{e_b}$가 되도록 하는 양의 정수 $p_b$와 음이 아닌 정수 $e_b$가 유일하게 정해집니다. 단, $p_b$는 $b$로 나누어떨어지지 않습니다.

$\sum_{b=2}^{N!}e_b$를 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

```text
$N$
```

정수 $N$이 주어집니다.

## 제한

- $2\leq N\leq10^6$
- 입력은 모두 정수입니다.

## 출력

$\sum_{b=2}^{N!}e_b$를 $998\,244\,353$으로 나눈 나머지를 출력하고, 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
```

#### 출력

```text
3
```

$3!=6$입니다.

$b=2$인 경우, $6=3\times2^1$이므로 $p_2=3$, $e_2=1$입니다. $3$은 $2$로 나누어떨어지지 않습니다.

$b=3$인 경우, $6=2\times3^1$이므로 $p_3=2$, $e_3=1$입니다. $2$는 $3$으로 나누어떨어지지 않습니다.

$b=4$인 경우, $6=6\times4^0$이므로 $p_4=6$, $e_4=0$입니다. $6$은 $4$로 나누어떨어지지 않습니다.

$b=5$인 경우, $6=6\times5^0$이므로 $p_5=6$, $e_5=0$입니다. $6$은 $5$로 나누어떨어지지 않습니다.

$b=6$인 경우, $6=1\times6^1$이므로 $p_6=1$, $e_6=1$입니다. $1$은 $6$으로 나누어떨어지지 않습니다.

따라서 $\sum_{b=2}^{N!}e_b=\sum_{b=2}^{6}e_b=1+1+0+0+1=3$이 답입니다.
