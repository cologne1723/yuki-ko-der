C 문제와 D 문제는 문제 설정과 제한이 같고, 실행 시간 제한만 다릅니다.

이 문제(C 문제)의 실행 시간 제한은 $10\,000$ms입니다.

## 문제 설명

$N$개의 정점으로 이루어진 트리 $A$가 주어집니다. $A$의 정점에는 $1,2,\dots,N$의 번호가 붙어 있으며, $i=1,2,\dots,N-1$에 대해 $i$번째 간선은 $A$의 정점 $u_i$와 $v_i$를 연결합니다.

트리 $A$의 $2$개 정점 $p,q$ 사이의 거리를 $d_A(p,q)$라고 합니다.

또한 $N$개의 정점으로 이루어진 트리 $B$가 주어집니다. $B$의 정점에도 $1,2,\dots,N$의 번호가 붙어 있으며, $j=1,2,\dots,N-1$에 대해 $j$번째 간선은 $B$의 정점 $x_j$와 $y_j$를 연결합니다.

트리 $B$의 $2$개 정점 $p,q$ 사이의 거리를 $d_B(p,q)$라고 할 때, 다음 값을 $2^{64}$로 나눈 나머지를 구하세요.

$\sum_{p=1}^{N}\sum_{q=1}^{N}d_A(p,q)d_B(p,q)$

## 입력

```text
$N$
$u_1\ v_1$
$u_2\ v_2$
$\vdots$
$u_{N-1}\ v_{N-1}$
$x_1\ y_1$
$x_2\ y_2$
$\vdots$
$x_{N-1}\ y_{N-1}$
```

## 제한

- $2\leq N\leq 2\times 10^5$
- $1\leq u_i,v_i,x_j,y_j\leq N$
- $A,B$는 각각 주어진 간선으로 트리를 이룹니다.

## 출력

답을 $1$줄에 출력하세요.
