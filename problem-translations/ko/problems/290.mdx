## 문제 설명

`0`과 `1`로만 이루어진 길이 $N$인 문자열 $S$가 주어집니다.

$S[a,b]$를 $S$의 $a$번째 문자부터 $b$번째 문자까지(양 끝 포함)를 이어 붙인 부분 문자열이라고 합니다.

$1\le i\le j$이고 $j+(j+1-i)\le N$인 $2$개의 정수 $i,j$에 대해 $S[i,j]=S[j+1,j+(j+1-i)]$를 만족하는 경우가 존재하는지 판정하세요.

## 입력

```text
$N$
$S$
```

$1$번째 줄에 정수 $N$이 주어집니다. $2$번째 줄에 `0`과 `1`로만 이루어진 길이 $N$인 문자열 $S$가 주어집니다.

## 제한

- $1 \le N \le 10^6$

## 출력

문제의 조건을 만족하는 정수 쌍이 존재하면 `YES`, 존재하지 않으면 `NO`를 $1$줄에 출력하세요. 따옴표는 출력하지 않습니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
0
```

#### 출력

```text
NO
```

### 예제 2 {file=""}

#### 입력

```text
2
00
```

#### 출력

```text
YES
```

$(i,j)=(1,1)$이 문제의 조건을 만족합니다.

### 예제 3 {file=""}

#### 입력

```text
14
00110101101010
```

#### 출력

```text
YES
```

예를 들어 $S[3,7]=S[8,12]=$`11010`이므로 $(i,j)=(3,7)$ 등이 조건을 만족합니다.
