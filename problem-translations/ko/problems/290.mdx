## 문제

0과 1로만 이루어진 길이 $N$인 문자열 $S$가 주어집니다.

$S[a,b]$를 $S$의 $a$번째 문자부터 $b$번째 문자까지(양 끝 포함)를 이어 붙인 부분 문자열이라고 합니다.

$1\le i\le j$이고 $j+(j+1-i)\le N$인 두 정수 $i,j$에 대해 $S[i,j]=S[j+1,j+(j+1-i)]$를 만족하는 경우가 존재하는지 판정하세요.

## 입력

```text
N
S
```

첫째 줄에 정수 $N$이 주어집니다. 둘째 줄에 0과 1로만 이루어진 길이 $N$인 문자열 $S$가 주어집니다.

- $1 \le N \le 10^6$

## 출력

문제의 조건을 만족하는 정수 쌍이 존재하면 `YES`, 존재하지 않으면 `NO`를 한 줄에 출력하세요. 따옴표는 출력하지 않습니다.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
1
0
```

### 샘플 1 {file="sample1.out"}

```text
NO
```

### 샘플 2 {file="sample2.in"}

```text
2
00
```

### 샘플 2 {file="sample2.out"}

```text
YES
```

$(i,j)=(1,1)$이 문제의 조건을 만족합니다.

### 샘플 3 {file="sample3.in"}

```text
14
00110101101010
```

### 샘플 3 {file="sample3.out"}

```text
YES
```

예를 들어 $S[3,7]=S[8,12]=11010$이므로 $(i,j)=(3,7)$ 등이 조건을 만족합니다.
