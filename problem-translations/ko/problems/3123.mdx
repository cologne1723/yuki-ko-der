이 문제의 실행 시간 제한은 케이스당 $10$초입니다.

## 문제 설명

양의 정수 $T$, $M$이 주어집니다.
그 후 $T$개의 테스트 케이스가 주어지므로, 각각에 대해 다음 문제의 답을 구하세요.

$(1,2,\ldots,N)$의 순열 $P$에 대해, 아래의 조작을 $0$회 이상 반복해서 얻을 수 있는 서로 다른 순열의 개수를 $P$의 점수 $f(P)$라고 합니다.

이하, 순열 $P$의 $i$($1 \leq i \leq N$)번째 원소를 $P_i$라고 합니다.

각 조작에서는 다음 $2$개의 처리 중 하나를 골라 수행합니다.

- 조작 $1$: 모든 $i=1,2,\ldots,N$에 대해 $P_{R_i}=i$를 만족하는 $(1,2,\ldots,N)$의 순열 $R$로 $P$를 바꿉니다.
- 조작 $2$: 모든 $i=1,2,\ldots,N$에 대해 $R_i=P_{N-i+1}$를 만족하는 $(1,2,\ldots,N)$의 순열 $R$로 $P$를 바꿉니다.

$(1,2,\ldots,N)$의 순열 $P$로 가능한 것은 $N!$가지입니다. 각 순열의 점수 $f(P)$의 합을 $M$으로 나눈 나머지를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T\ M$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

여기서 $\mathrm{case}_i$는 $i$번째 테스트 케이스를 나타냅니다.

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- $1 \leq T \leq 10^6$
- $1 \leq N \leq 5 \times 10^6$
- $1 \leq M \leq 10^9$
- 입력은 모두 정수입니다.

## 출력

답을 $T$줄에 걸쳐 출력하세요.

$i$번째 줄($1 \leq i \leq T$)에는 $i$번째 테스트 케이스의 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 998244353
3
1
4478429
```

#### 출력

```text
20
1
722594001
```

$N=3$일 때, 순열 $(1,2,3)$에 조작 $1$을 수행하면 $(1,2,3)$을 얻습니다. 조작 $2$를 수행하면 $(3,2,1)$을 얻습니다.

$(1,2,3)$에 대해 조작 $1$과 조작 $2$를 $0$회 이상 반복해서 얻을 수 있는 순열은 이 $2$가지뿐입니다. 따라서 $f((1,2,3))=2$입니다.

다른 순열에 대해서도 같은 방식으로 계산하면 점수의 합이 $20$임을 알 수 있습니다.
