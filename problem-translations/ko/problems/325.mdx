## 문제 설명

점 $(x_1,y_1)$과 점 $(x_2,y_2)$ 사이의 맨해튼 거리는 $|x_1-x_2|+|y_1-y_2|$로 나타냅니다.

직사각형의 왼쪽 아래 좌표 $(x_1,y_1)$와 오른쪽 위 좌표 $(x_2,y_2)$가 주어집니다. $(x_1,y_1),(x_2,y_1),(x_2,y_2),(x_1,y_2)$의 $4$개의 점으로 둘러싸인 직사각형의 닫힌 영역 안에, $(0,0)$에서의 맨해튼 거리가 $d$ 이하인 격자점이 몇 개인지 구하세요.

## 입력

```text
$x_1\ y_1\ x_2\ y_2\ d$
```

직사각형의 왼쪽 아래 좌표, 오른쪽 위 좌표, 맨해튼 거리 $d$가 공백으로 주어집니다. 모든 입력은 정수입니다.

## 제한

- $-10^9 \le x_1 < x_2 \le 10^9$
- $-10^9 \le y_1 < y_2 \le 10^9$
- $0 \le d \le 2\times10^9$

## 출력

범위 안에 있는 $(0,0)$에서의 맨해튼 거리가 $d$ 이하인 격자점의 개수를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0 0 3 3 3
```

#### 출력

```text
10
```

$(0,0),(0,1),(0,2),(0,3),(1,0),(1,1),(1,2),(2,0),(2,1),(3,0)$의 $10$개입니다.

### 예제 2 {file=""}

#### 입력

```text
-3 -3 0 0 2
```

#### 출력

```text
6
```

### 예제 3 {file=""}

#### 입력

```text
1 1 3 3 3
```

#### 출력

```text
3
```
