## 문제 설명

원소 수가 $N$인 수열 $A_1, A_2, \cdots, A_N$이 주어집니다.

$1 \leq l \leq r \leq N$을 만족하는 정수 $l$, $r$에 대하여 $S(l,r)=\displaystyle\sum_{k=l}^{r}A_k=A_l+A_{l+1}+\cdots+A_r$로 정의합니다.

$1 \leq l \leq r \leq N$을 만족하는 모든 정수 순서쌍 $(l,r)$에 대한 $S(l,r)$의 합을 구하세요.

## 입력

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
```

입력은 다음 제한을 만족합니다.

- 입력은 모두 정수입니다.
- $1 \leq N \leq 2 \times 10^5$
- $0 \leq A_i \leq 10^6$ ($1 \leq i \leq N$)
- 답은 $10^{18}$ 이하입니다.

## 출력

답을 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
3 4 5
```

#### 출력

```text
40
```

$S(1,1)=3$

$S(1,2)=3+4=7$

$S(1,3)=3+4+5=12$

$S(2,2)=4$

$S(2,3)=4+5=9$

$S(3,3)=5$

따라서 이들의 총합인 $40$을 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
5
2 12 7 0 15
```

#### 출력

```text
244
```

수열 $A$에 $0$이 포함될 수도 있습니다.

### 예제 3 {file=""}

#### 입력

```text
1
0
```

#### 출력

```text
0
```
