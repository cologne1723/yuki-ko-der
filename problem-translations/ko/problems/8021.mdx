Python에 기본으로 포함된 SQLite를 yukicoder에서 실행해 보는 실험적인 문제입니다. 여러 가지 문제가 있을 수도 있습니다.

## 문제 설명

$xy$ 평면 위에 $n$개의 점이 있습니다.

이 점들은 다음과 같은 구조로 SQLite 데이터베이스에 저장되어 있습니다.

```text
CREATE TABLE point( id INTEGER PRIMARY KEY, x INTEGER, y INTEGER);
```

```text
>TABLE point
+----+---+---+
|  id|  x|  y|
+----+---+---+
|   1| x1| y1|
+----+---+---+
|   2| x2| y2|

(略)

|   n| xn| yn|
+----+---+---+
```

다음과 같은 질의가 $q$개 주어지므로, 이에 답할 수 있는 SQLite 실행 문을 출력하세요.

- $x_l \leq x_i \leq x_h$, $y_l \leq y_i \leq y_h$인 점의 개수를 출력하세요.

## 입력

점의 정보는 공개되지 않습니다.

질의 입력은 다음 형식으로 주어집니다.

```text
$q$
${x_l}_1\ {x_h}_1\ {y_l}_1\ {y_h}_1$
$\vdots$
${x_l}_q\ {x_h}_q\ {y_l}_q\ {y_h}_q$
```

## 제한

점에 대한 제한:

- $1 \leq n \leq 10^3$
- $0 \leq x_i \leq 10^9$
- $0 \leq y_i \leq 10^9$
- 점의 좌표는 모두 정수이며, 여러 점이 같은 위치에 존재하지 않습니다.

질의에 대한 제한:

- $1 \leq q \leq 10^3$
- $0 \leq {x_l}_i \leq {x_h}_i \leq 10^9$
- $0 \leq {y_l}_i \leq {y_h}_i \leq 10^9$

## 출력

각 질의마다 $1$개의 `SELECT` 문을 사용하세요. $i$번째 `SELECT` 문의 결과가 $i$번째 질의의 답으로 간주됩니다.

SQL 문의 구분자로 `;`을 사용하므로, **문장 끝의 `;`을 잊지 마세요.**

`SELECT` 문 이외의 문도 사용할 수 있습니다.

**이 문제는 리액티브 문제입니다. 출력할 때 `flush`하는 것을 잊지 마세요.**

참고: 답안 프로그램에는 질의 결과가 반환되지 않습니다.

## 예제

### 예제 1 {file=""}

#### 입력

판정 측의 점 배치가 다음과 같은 경우를 가정한 예시입니다. 다음 점 목록은 비공개이며 실제 입력으로 주어지는 데이터가 아닙니다.

```text
(3, 2)
(8, 2)
(9, 8)
(3, 1)
(4, 4)
(1, 4)
(0, 4)
(3, 7)
(0, 8)
(7, 2)
```

다음은 실제로 입력으로 주어지는 질의입니다.

```text
2
6 7 2 7
10 10 10 10
```

#### 출력

$1$번째 질의에서는 $6 \leq x \leq 7$, $2 \leq y \leq 7$인 점이 $(7,2)$ $1$개뿐이므로, $1$이 반환되도록 하는 `SELECT` 문을 출력하면 정답으로 간주됩니다.

$2$번째 질의에서는 $(10,10)$이 점들 중에 존재하지 않으므로, $0$이 반환되도록 하는 `SELECT` 문을 출력하면 정답으로 간주됩니다.

```text
SELECT count(*) FROM point WHERE x=7 AND y=2;
SELECT count(*) FROM point WHERE x=10 AND y=10;
```

실제 점들은 공개되지 않으므로, 조금 더 고민해 보세요.
