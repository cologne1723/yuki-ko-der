책 `N`권이 위에서부터 번호 순서로 쌓여 있습니다. 위에서 `i`번째 책을 꺼내 읽는 데 체력 `i`를 사용하고, 읽은 뒤 맨 위에 다시 놓습니다.

`M`번 읽을 책이 주어지며 `-1`인 항목은 `N`권 중 하나를 균등하게 무작위로 선택합니다. 총 소모 체력의 기대값을 `998244353`으로 나눈 값을 구하세요.

## 제약

- `1 <= N,M <= 2 * 10^5`
- `A_i=-1` 또는 `1 <= A_i <= N`

## 입력

`N M`과 읽을 책의 목록 `A`가 주어집니다.

## 출력

기대값을 `998244353`으로 나눈 값을 출력하세요.
