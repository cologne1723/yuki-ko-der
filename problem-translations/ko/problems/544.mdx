## 문제

연애에 실패한 Y는 정수에서 7을 지워 사람들을 불행하게 만들려고 합니다.

어느 자리에든 7이 포함된 음이 아닌 정수 N이 주어질 때, A+B=N을 만족하면서 어느 자리에도 7이 포함되지 않는 정수 A,B를 구하세요.

해가 여러 개라면 어느 것을 구해도 됩니다.

## 입력

```text
N
```

음이 아닌 정수 N이 주어집니다.

0 ≤ N ≤ 10^9

N의 어느 자리에는 7이 포함됩니다.

## 출력

조건을 만족하는 정수 A,B를 공백으로 구분해 출력하세요.

해가 존재하지 않으면 -1을 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

-10^9 ≤ A ≤ 10^9

-10^9 ≤ B ≤ 10^9

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
7
```

출력:

```text
3 4
```

3+4=7입니다. 해는 이 외에도 있습니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
17
```

출력:

```text
20 -3
```

음수도 사용할 수 있습니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
77777
```

출력:

```text
-22223 100000
```

여러 자리에 7이 포함된 경우도 있습니다.

### 샘플 4 {file="sample4.in"}

입력:

```text
123456789
```

출력:

```text
12345689 111111100
```
