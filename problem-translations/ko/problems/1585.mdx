## 문제

정수 $N$이 세제곱수인지 판정하세요.

## 입력

$1\leq N\leq10^{18}$인 정수 $N$이 주어집니다.

## 출력

세제곱수이면 `Yes`, 아니면 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1331
```

#### 출력

```text
Yes
```

### 예제 2 {file=""}

#### 입력

```text
288
```

#### 출력

```text
No
```

### 예제 3 {file=""}

#### 입력

```text
1000000000000000000
```

#### 출력

```text
Yes
```
