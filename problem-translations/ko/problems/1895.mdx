양의 정수 $x$의 양의 약수 합을 $f(x)$라 합니다. $L\le R$인 양의 정수 $L,R$에 대해 $\sum_{k=L}^{R}f(k)$를 2로 나눈 나머지를 구하세요.

## 입력

```text
T
L R
```

$1\le T\le10^4$, $1\le L\le R\le10^{15}$입니다.

## 출력

각 테스트 케이스의 답을 출력하세요.
