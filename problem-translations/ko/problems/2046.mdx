서로 다른 양의 정수 $A_1,\ldots,A_N$이 주어집니다. 다음 값을 구하세요.

$$\sum_{i<j}|(A_i\bmod A_j)-(A_j\bmod A_i)|.$$

## 입력

```text
N
A_1 A_2 ... A_N
```

$2\le N\le2\times10^5$, $1\le A_i\le2\times10^5$이며 $A_i$는 서로 다릅니다.

## 출력

요구한 합을 출력하세요.
