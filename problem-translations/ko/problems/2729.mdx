## 문제

정수 `A_1,...,A_N`이 있습니다. 순열 `P`를 하나 고른 뒤 순서대로 `x ← 10x + A_{P_i}`를 적용합니다. 최종 `x`로 가능한 최솟값을 `998244353`으로 나눈 나머지를 구하세요. 실제 `x`의 최솟값을 구한 뒤 나머지를 취해야 합니다.

## 제약

- `1 ≤ N ≤ 2×10^5`
- `1 ≤ A_i ≤ 10^18`

## 입력

```text
N
A_1 A_2 ... A_N
```

## 출력

최솟값의 나머지를 출력하세요.
