## 문제

`N × N` 격자의 각 칸을 세로와 가로로 `K`배 확대해 `NK × NK` 격자를 출력하세요. 확대된 격자의 `(i,j)`는 원래 격자의 `(floor(i/K), floor(j/K))`와 같은 문자입니다.

## 제약

- `1 ≤ N,K ≤ 10`
- 각 칸은 `.` 또는 `#`입니다.

## 입력

```text
N K
A_{0,0}...A_{0,N-1}
⋮
A_{N-1,0}...A_{N-1,N-1}
```

## 출력

확대된 격자를 출력하세요.
