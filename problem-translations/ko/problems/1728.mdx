밑면이 한 변 1인 정`N`각형이고 옆 모서리 길이가 2인 정`N`각기둥 `Γ_N`의 `2N`개 꼭짓점을 `C`가지 색으로 칠합니다.

회전으로 일치하는 색칠을 같은 것으로 볼 때 가능한 색칠 방법의 수를 `10^9+7`로 나눈 나머지를 구하세요.

## 제약

- `1 <= T <= 10`
- `3 <= N <= 10^9`
- `1 <= C <= 10^9`

## 입력

테스트 케이스마다 `N C`가 주어집니다.

## 출력

각 테스트 케이스의 답을 출력하세요.
