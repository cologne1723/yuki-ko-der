$N$개의 논리 변수 $x_1,\ldots,x_N$가 있고, 각 변수에는 0 또는 1을 대입할 수 있습니다. 조건을 저장하는 스택 $S$는 처음에 비어 있습니다.

쿼리 `1 u v`는 $x_u$와 $x_v$가 같은 값이 되도록 하는 조건을 추가하고, `2 u v`는 두 변수가 다른 값이 되도록 하는 조건을 추가합니다. `3`은 스택을 비웁니다.

각 쿼리 처리 후 현재 조건을 모두 만족하는 대입 방법의 수를 $998244353$으로 나눈 나머지를 출력하세요.

## 조건

- $1\le N,Q\le 2\times10^5$
- $1\le u_i,v_i\le N$
- 쿼리 유형은 1, 2, 3 중 하나입니다.

## 입력

첫째 줄에 $N,Q$, 다음 $Q$개 줄에 쿼리가 주어집니다.

## 출력

각 쿼리 후의 답을 한 줄에 하나씩 출력하세요.
