## 문제 설명

정수 $3$개 $A$, $B$, $C$가 주어집니다. 단, $A \neq 0$이고 $B^2 - 4AC > 0$입니다. 특히 이차방정식 $A x^2 + B x + C = 0$은 서로 다른 실수해 $2$개를 가지며, 이들은

$\displaystyle \frac{-B \pm \sqrt{B^2 - 4AC}}{2A}$

로 나타낼 수 있습니다.

$2$개의 해를 작은 순서대로 $\alpha$, $\beta$라고 할 때, $\alpha < n < \beta$를 만족하는 정수 $n$의 개수를 구하세요.

## 입력

입력은 표준 입력으로 다음 형식의 $1$줄이 주어집니다.

```text
$A\ B\ C$
```

$1$번째 줄에 $A$, $B$, $C$가 공백으로 구분되어 주어집니다.

## 제한

- $A$는 $1 \leq |A| \leq 1\,000\,000$을 만족하는 정수입니다.
- $B$는 $|B| \leq 1\,000\,000$을 만족하는 정수입니다.
- $C$는 $|C| \leq 1\,000\,000$을 만족하는 정수입니다.
- $B^2 - 4AC > 0$입니다.

## 출력

$\alpha < n < \beta$를 만족하는 정수 $n$의 개수를 $1$줄에 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1 0
```

#### 출력

```text
0
```

$A x^2 + B x + C = x^2 + x = (x+1)x$이므로 $\alpha = -1$, $\beta = 0$입니다.

$-1 < n < 0$을 만족하는 정수 $n$은 존재하지 않습니다.

### 예제 2 {file=""}

#### 입력

```text
2 8 6
```

#### 출력

```text
1
```

$A x^2 + B x + C = 2x^2 + 8x + 6 = 2(x + 3)(x + 1)$이므로 $\alpha = -3$, $\beta = -1$입니다.

$-3 < n < -1$을 만족하는 정수 $n$은 $-2$만 존재합니다.

### 예제 3 {file=""}

#### 입력

```text
-1 -2 1
```

#### 출력

```text
3
```

$A x^2 + B x + C = -x^2 - 2x + 1 = -(x + 1 + \sqrt{2})(x + 1 - \sqrt{2})$이므로 $\alpha = -1 - \sqrt{2}$, $\beta = -1 + \sqrt{2}$입니다.

$-2.42 < -1 - \sqrt{2} < -2.41$이고 $0.41 < -1 + \sqrt{2} < 0.42$이므로, $-1 - \sqrt{2} < n < -1 + \sqrt{2}$를 만족하는 정수 $n$은 $-2$, $-1$, $0$의 $3$개입니다.
