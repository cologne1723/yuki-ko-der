## 문제 설명

양의 정수 $n$이 좋은 수라는 것은 다음 조건을 만족하는 것으로 정의합니다.

- $n$을 십진수로 해석했을 때 $10^i$의 자리의 값을 $n_i$라고 하면, $n_{i+2} > n_{i+1} + n_i$를 만족하는 음이 아닌 정수 $i$가 존재합니다.

또한, 양의 정수 $n$에 대해 $f(n)$을 $n$ 이상인 좋은 수 중 최솟값으로 정의합니다.

양의 정수 $N$이 주어집니다. $f(1) + f(2) + \cdots + f(N)$을 $998\,244\,353$으로 나눈 나머지를 구하세요.

$T$개의 테스트 케이스가 주어지므로 각각에 대해 답을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- 입력되는 값은 모두 정수입니다.
- $1 \leq T \leq 200$
- $1 \leq N \leq 10^{18}$

## 출력

각 테스트 케이스에 대한 답을 순서대로 줄바꿈으로 구분하여 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
10
668
169231
1000000000000000000
```

#### 출력

```text
1000
245820
346334860
992299114
```

좋은 수를 오름차순으로 나열하면 $100, 200, 201, 210, 300, 301, 302, 310, 311, 320, 400, \cdots$가 됩니다.

$1$번째 테스트 케이스에서는 $k = 1, 2, \cdots, 10$ 모두에 대해 $k$ 이상인 가장 작은 좋은 수가 $100$이므로, 답은 $100 \times 10 = 1\,000$입니다.
