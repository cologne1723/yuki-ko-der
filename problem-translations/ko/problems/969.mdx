## 문제 설명

사야카는 양손을 사용해 가위바위보를 하기로 했습니다.

“가위바위보!”라는 구호와 함께 오른손과 왼손을 각각 바위, 가위, 보 중 하나로 냈더니, 오른손에서 세운 손가락 수와 왼손에서 세운 손가락 수의 합이 $X$가 되었다고 합니다.

다음과 같이 간주합니다.

- 바위는 손가락을 $0$개 세운 것입니다.
- 가위는 손가락을 $2$개 세운 것입니다.
- 보는 손가락을 $5$개 세운 것입니다.

승부가 비겼을 가능성이 있는지 판정하세요.

## 입력

```text
$X$
```

$X$는 문제 설명과 모순되지 않는 음이 아닌 정수입니다.

## 출력

승부가 비겼을 가능성이 있다면 `Yes`를, 그렇지 않다면 `No`를 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0
```

#### 출력

```text
Yes
```

오른손과 왼손이 모두 바위인 경우만 가능하므로 승부가 비깁니다.

### 예제 2 {file=""}

#### 입력

```text
7
```

#### 출력

```text
No
```

“오른손이 가위이고 왼손이 보인 경우”와 “오른손이 보이고 왼손이 가위인 경우”의 $2$가지가 가능합니다.

전자는 오른손의 승리이고 후자는 왼손의 승리이므로, 어느 쪽이든 비기지 않습니다.
