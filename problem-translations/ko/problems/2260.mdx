소수 $P$와 서로 다른 양의 정수열 $A$가 주어진다냥. 모든 쌍에 대해 $v_P(|A_i-A_j|)$를 더한 값을 구하라냥. $v_P(n)$은 $n$이 $P$로 나누어지는 횟수이다냥.

## 조건

- $2\le N\le10^5$
- $P$는 $10^9$ 이하의 소수이다냥.
- $1\le A_i\le10^9$

## 입력

```text
N P
A_1 \cdots A_N
```

## 출력

답을 출력하라냥.
