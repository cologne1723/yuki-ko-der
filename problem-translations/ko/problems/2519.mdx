수열에서 두 원소 $x,y$를 골라 제거하고 $f(x,y)$를 끝에 추가하는 연산을 $N-1$번 수행합니다. $f(x,y)$는 모든 충분히 큰 정수가 $px+qy$ 꼴로 표현되기 시작하는 최소 정수이며, 존재하지 않으면 0입니다. 최종 하나의 원소의 최솟값과 연산 과정을 출력하세요.

## 입력

```text
N
A1 A2 ... AN
```

## 출력

문제에서 지정한 형식으로 최솟값과 연산 방법을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2
3 5
```

#### 출력

```text
8
1 2
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
2
100 100
```

#### 출력

```text
0
1 2
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
6
173448 104807 158459 62861 173448 173448
```

#### 출력

```text
0
1 5
4 5
2 3
1 3
1 2
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
3
199993 199997 199999
```

#### 출력

```text
7999440010999938
1 2
1 2
```
