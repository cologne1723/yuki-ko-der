## 문제 설명

yuki 씨는 이제부터 $N$개의 가게에서 쇼핑합니다.
$i$번째 가게에서는 합계 $A_i$엔을 지불할 예정입니다.

yuki 씨는 「거스름돈은 필요 없습니다」라고 말하고 계산하는 것이 멋있다고 생각하므로, 모든 $i$($1 \le i \le N$)에 대해 다음을 만족하도록 쇼핑하고 싶습니다.

- $i$번째 가게에서 $B_i$엔($B_i > A_i$)을 지불합니다.
- 「거스름돈은 필요 없습니다」라고 말하고 거스름돈을 받지 않은 채 그 가게에서 쇼핑을 끝냅니다.

처음에 yuki 씨의 지갑에는 천 엔 지폐가 $X$장, 오천 엔 지폐가 $Y$장, 만 엔 지폐가 $Z$장 들어 있습니다.
멋있게 「거스름돈은 필요 없습니다」라고 말하기 위해 동전은 가지고 있지 않습니다.
조건을 만족하는 쇼핑이 가능한지 판정하세요.

## 입력

```text
N X Y Z
A_1 ... A_N
```

## 제한

- $N$, $X$, $Y$, $Z$는 정수이며, $1 \le N \le 10^5$, $0 \le X \le 10^9$, $0 \le Y \le 10^9$, $0 \le Z \le 10^9$를 만족합니다.
- $A_i$는 정수이며, $1 \le A_i \le 10^9$를 만족합니다.

## 출력

조건을 만족하는 쇼핑이 가능하면 `Yes`, 불가능하면 `No`를 출력하세요.
마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2 1 1 1
2020 10100
```

#### 출력

```text
Yes
```

가게 $1$에서 오천 엔 지폐를, 가게 $2$에서 천 엔 지폐와 만 엔 지폐를 사용하면 조건을 달성할 수 있습니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
4 0 0 3
100 100 100 100
```

#### 출력

```text
No
```

가지고 있는 금액은 $30000$엔이고 지불액의 합계는 $400$엔이지만, 조건을 만족할 수 없습니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
2 0 1 1
123 10000
```

#### 출력

```text
No
```

$10000$엔을 지불할 때 만 엔 지폐를 $1$장만 사용하면 조건을 만족하지 않습니다.

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
3 0 9 0
10000 10000 10000
```

#### 출력

```text
Yes
```

오천 엔 지폐를 한 번에 $3$장씩 사용합니다.
