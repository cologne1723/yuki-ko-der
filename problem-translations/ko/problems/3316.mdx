## 이야기

岩井星에서는 지구에서 큰 활약을 하고 있는 yiwiy9(わいいわいわいナイン)さん의 이름을 본떠, $0$과 $1$과 $8$만으로 가능한 한 적은 횟수로 $81\,181\,819$를 만드는 놀이가 유행하고 있습니다. 우리도 실제로 이 놀이를 해 봅시다.

## 문제 설명

$81\,181\,819$ 미만의 음이 아닌 정수 $N$이 주어집니다.

다음 조건을 모두 만족하는 양의 정수열 $p_1,p_2,\ldots,p_k$ 중 $k$가 최소인 것을 $1$개 출력하세요.

- $\displaystyle\sum_{i=1}^k p_i+N=81\,181\,819$
- $p_i$를 $10$진법으로 나타냈을 때, $0$, $1$, $8$만으로 이루어져 있습니다.

조건을 만족하는 $k$가 최소인 $p$가 여러 개 존재한다면, 그중 무엇을 출력해도 됩니다.

$T$개의 테스트 케이스가 주어지므로, 모두 답하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. $TestCase_k$는 $k$번째 테스트 케이스를 나타냅니다.

```text
$T$
$TestCase_1$
$TestCase_2$
$\vdots$
$TestCase_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- $1\le T\le 10$
- $0\le N<81\,181\,819$
- 입력은 모두 정수입니다.

## 출력

$T$개의 테스트 케이스에 대해 표준 출력에 줄바꿈으로 구분하여 순서대로 출력하세요. 각 테스트 케이스에 대해 $k$와 길이 $k$인 수열 $p_1,p_2,\ldots,p_k$를 다음 형식으로 출력하세요.

```text
$k$
$p_1$
$p_2$
$\vdots$
$p_k$
```

마지막에 줄바꿈을 출력하세요.

$1$번째 테스트 케이스에 대해 다음과 같습니다.

- $p=(-8,11,11)$은 적절하지 않습니다. $p$는 양의 정수열이어야 하기 때문입니다.
- $p=(11,1)$은 적절하지 않습니다. $\displaystyle\sum_{i=1}^k p_i+N=81\,181\,819$이어야 하기 때문입니다.
- $p=(13,1)$은 적절하지 않습니다. $p_1$을 $10$진법으로 나타냈을 때 $3$이 포함되어 있기 때문입니다.
- $p=(8,1,1,1,1,1,1)$은 적절하지 않습니다. 조건을 만족하는 $p$ 중 $k$가 최소가 아니기 때문입니다.

$p=(11,1,1,1)$도 해 중 $1$개이므로, 이를 출력해도 됩니다.
