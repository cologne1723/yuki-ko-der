$N$개 그룹에 문제가 있고 $i$번째 그룹에는 $P_i$문제가 있다냥. 매일 각 그룹에서 하나씩 문제가 출제되며, 최근 $K$일 이내에 출제된 문제는 후보에서 제외되고 나머지 중 균등하게 독립적으로 선택된다냥. hibit 군은 매일 참가한다냥. 그룹 $i$의 문제를 처음 풀면 $s_i$분, 과거에 출제된 문제면 $t_i$분이 걸린다냥. 하루의 $N$문제를 60분 이내에 모두 푸는 것을 전완이라고 할 때, 처음 전완하는 날을 $X$라 하자냥. 모든 추첨 결과에서 전완할 수 없다면 $-1$을 출력하고, 가능하면 $X$의 최솟값, 최댓값, 기대값을 구하라냥.

## 조건

- $1\le N\le6$
- $1\le K\le4$
- $K<P_i\le5$
- $1\le t_i\le s_i\le60$

## 입력

```text
N K
P_1 s_1 t_1
\vdots
P_N s_N t_N
```

## 출력

모든 결과에서 전완할 수 없으면 $-1$을 출력하라냥. 그렇지 않으면 최솟값, 최댓값, 기대값을 공백으로 구분해 출력하라냥. 기대값의 오차는 $10^{-6}$ 이하여야 한다냥.
