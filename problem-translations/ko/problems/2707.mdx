## 문제

길이 `N`인 대문자 문자열 `S`가 주어집니다. `A`부터 `Z`까지 각 문자가 `S`에 등장하는 횟수를 순서대로 이어 붙인 문자열 `X`를 출력하세요.

## 제약

- `1 ≤ N ≤ 10^5`
- `S`는 대문자 영어 문자로만 이루어집니다.

## 입력

```text
N
S
```

## 출력

문자열 `X`를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01"}

#### 입력

```text
5
ABCDE
```

#### 출력

```text
11111000000000000000000000
```

### 예제 2 {file="01_sample_02"}

#### 입력

```text
12
AAAAAAAAAABB
```

#### 출력

```text
102000000000000000000000000
```
