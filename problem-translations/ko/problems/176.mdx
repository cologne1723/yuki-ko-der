## 문제 설명

Yuki王国에서는 $A$엔과 $B$엔 $2$종류의 우표를 발행합니다.

이 $2$종류의 우표를 적절히 조합해 우편물에 $T$엔 이상 붙이려 합니다. 단, 우표의 합계 금액은 가능한 한 적어야 합니다. 이때 붙이게 되는 우표의 합계 금액을 구하세요.

$2$종류를 모두 사용할 필요는 없으며, 우표 개수에는 제한이 없습니다.

## 입력

```text
$A\ B\ T$
```

## 제한

- $1 \le A < B \le 10^9$
- $1 \le T \le 10^9$
- $A,B,T$는 정수입니다.

## 출력

우표의 합계 금액을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
50 80 120
```

#### 출력

```text
130
```

$50$엔과 $80$엔 우표로 정확히 $120$엔을 만들 수 없으므로, 각각 $1$장씩 사용한 $130$엔이 $120$엔 이상인 최소 금액입니다.

### 예제 2 {file=""}

#### 입력

```text
123 456 1
```

#### 출력

```text
123
```

$2$종류를 모두 사용할 필요가 없으므로 $123$엔 우표 $1$장을 붙입니다.

### 예제 3 {file=""}

#### 입력

```text
1234 1688 10000
```

#### 출력

```text
10000
```

잘 조합하면 정확히 $10\,000$엔을 만들 수 있습니다.
