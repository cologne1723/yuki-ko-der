## 문제 설명

문자열 $S$와 $T$가 주어집니다. $2$개 문자열의 길이는 모두 $n$입니다.

문자열 $S$의 문자 $S[i]$를 $1$개 선택하여 원하는 소문자 영문자로 변경하는 연산을 원하는 횟수만큼 수행할 수 있습니다. $S$를 $T$로 바꾸는 데 필요한 최소 연산 횟수를 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$n$
$S$
$T$
```

$1$번째 줄에는 문자열 $S,T$의 길이를 나타내는 정수 $n$이 주어집니다. $2$번째 줄과 $3$번째 줄에는 각각 $S,T$가 주어집니다.

## 제한

- $1 \leq n \leq 1\,000$
- $S$와 $T$는 길이 $n$인 소문자 영문자 문자열입니다.

## 출력

필요한 최소 연산 횟수를 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
7
aaabbcc
aabbccc
```

#### 출력

```text
2
```

$3$번째 문자를 `a`에서 `b`로 바꾸면 `aaabbcc`에서 `aabbbcc`가 됩니다.

이어서 $5$번째 문자를 `b`에서 `c`로 바꾸면 `aabbbcc`에서 `aabbccc`가 됩니다.

### 예제 2 {file=""}

#### 입력

```text
5
abcde
abcde
```

#### 출력

```text
0
```

연산이 필요하지 않으므로 $0$을 출력합니다.

### 예제 3 {file=""}

#### 입력

```text
8
hidamari
yunocchi
```

#### 출력

```text
7
```
