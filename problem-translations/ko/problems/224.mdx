## 문제

문자열 $S$와 $T$가 주어집니다. 두 문자열의 길이는 같습니다.

문자열의 한 문자를 원하는 소문자 영문자로 변경하는 연산을 원하는 횟수만큼 수행할 수 있습니다. $S$를 $T$로 바꾸는 데 필요한 최소 연산 횟수를 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
n
S
T
```

- $1 \leq n \leq 1000$
- $S$와 $T$는 길이 $n$인 소문자 영문자 문자열입니다.

## 출력

필요한 최소 연산 횟수를 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

```text
7
aaabbcc
aabbccc
```

### 출력 1 {file="stdout"}

```text
2
```

### 입력 2 {file="stdin"}

```text
5
abcde
abcde
```

### 출력 2 {file="stdout"}

```text
0
```

### 입력 3 {file="stdin"}

```text
8
hidamari
yunocchi
```

### 출력 3 {file="stdout"}

```text
7
```
