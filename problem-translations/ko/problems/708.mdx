## 문제

（＋－）의 식 $S$가 주어집니다. 이를 계산하세요.

（＋－）의 식은 다음 조건을 만족하는 식입니다.

- +, -, (, ), 0부터 9까지의 숫자만으로 이루어집니다.
- 괄호는 일대일로 대응하고 최대 한 겹입니다. 즉, 괄호가 같은 횟수만큼 나타나며 여는 괄호 다음에 닫는 괄호가 나오기 전에 다시 여는 괄호가 나올 수 없습니다.
- 숫자가 2개 이상 연속하지 않습니다.
- 부호가 2개 이상 연속하지 않습니다.

4-(2-1)은 조건을 만족하지만 4*2-1/1, 4.2+3, (7-(7+7)), 77+7, 4+-3은 만족하지 않습니다.

## 입력

~~~text
$S$
~~~

입력은 1줄이며, 문제를 나타내는 $S\ (1\leq|S|\leq100)$가 주어집니다.

## 출력

계산 결과를 출력하세요. 출력 마지막에는 줄바꿈을 추가하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
3+4-2
~~~

#### 출력

~~~text
5
~~~

$3+4-2=5$인 것은 누구나 아는 사실입니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
3-(1-1)
~~~

#### 출력

~~~text
3
~~~

$3-(1-1)=3$인 것도 누구나 아는 사실입니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
1-(2-1)+(2+2)-3
~~~

#### 출력

~~~text
1
~~~
