처음에 길이 $N$의 수열 $A$가 모두 0입니다. 아무것도 하지 않거나 접두사, 접미사, 전체 수열에 1을 더하는 작업을 정확히 $M$번 수행해 $A=B$가 되는 작업열의 수를 $998244353$으로 나눈 나머지를 구하세요.

## 조건

- $1\le N,M\le1000$
- $0\le B_i\le M$

## 입력

```text
N M
B1 B2 ... BN
```

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4 2
1 1 1 0
```

#### 출력

```text
2
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
4 2
1 1 1 1
```

#### 출력

```text
8
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
4 3
0 3 2 2
```

#### 출력

```text
0
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text

```

#### 출력

```text
362672301
```

### 예제 5 {file="01_sample_05.txt"}

#### 입력

```text

1
```

#### 출력

```text
1
```
