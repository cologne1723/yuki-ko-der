## 이야기

> 「그래, 밤을 멈추고 있던 건…… 너희들이었구나」

어떤 세계에서는 영야의 술법으로 밤이 오래 이어지고 있습니다.

## 문제 설명

다항식 $f(x)=A_1x^N+A_2x^{N-1}+\cdots+A_Nx-1$이 있습니다. $f(t)=0$을 만족하는 양의 실수 $t$가 존재한다면 시각 $t$에 밤이 끝납니다. 존재하지 않는다면 밤은 끝나지 않습니다.

밤이 끝나는지 판정하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
```

$1$번째 줄에는 정수 $N$이 주어집니다. $2$번째 줄에는 $N$개의 정수 $A_1,A_2,\dots,A_N$이 주어집니다.

## 제한

- $1\leq N\leq 100\,000$
- $0\leq A_i\leq 1\,000\,000\,000$
- 입력은 모두 정수입니다.

## 출력

밤이 끝난다면 `Yes`를, 그렇지 않다면 `No`를 $1$줄에 출력하세요.

마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
1 2
```

#### 출력

```text
Yes
```

$f(x)=x^2+2x-1$입니다. $f(t)=0$을 만족하는 실수 $t$는 $t=-1\pm\sqrt{2}$이고, $-1+\sqrt{2}$는 양수이므로 시각 $-1+\sqrt{2}$에 밤이 끝납니다. 따라서 답은 `Yes`입니다.

### 예제 2 {file=""}

#### 입력

```text
1
0
```

#### 출력

```text
No
```

$f(x)=-1$입니다. 따라서 $f(t)=0$을 만족하는 양의 실수 $t$는 존재하지 않습니다. 따라서 답은 `No`입니다.
