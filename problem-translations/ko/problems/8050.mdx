## 문제 설명

정수 $y$, $u$, $k$, $i$, $c$, $o$, $d$, $e$, $r$이 주어집니다. $f(y, u, k, i, c, o, d, e, r)$를 $256$으로 나눈 나머지를 구하세요.

함수 $f: \mathbb{Z}^9 \rightarrow \mathbb{Z}$의 정의는 [여기](https://gist.github.com/kuretchi/585a57b3bf75c7250dcc1612ea64ff73#file-f-txt)를 참고하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$y\ u\ k\ i\ c\ o\ d\ e\ r$
```

모든 값은 정수입니다.

## 제한

- $0 \le y, u, k, i, c, o, d, e, r \le 2$

## 출력

구한 값을 $1$줄에 출력하고, 마지막에 개행하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
0 0 0 0 0 0 0 0 0
```

#### 출력

```text
153
```

$f(0, 0, 0, 0, 0, 0, 0, 0, 0) = -3\,707\,495$입니다. $256$으로 나눈 나머지인 $153$을 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
0 1 2 0 1 2 0 1 2
```

#### 출력

```text
97
```

$f(0, 1, 2, 0, 1, 2, 0, 1, 2) = 20\,951\,649$입니다. $256$으로 나눈 나머지인 $97$을 출력합니다.

### 예제 3 {file=""}

#### 입력

```text
2 2 2 2 2 2 2 2 2
```

#### 출력

```text
223
```

$f(2, 2, 2, 2, 2, 2, 2, 2, 2) = 20\,330\,200\,799$입니다. $256$으로 나눈 나머지인 $223$을 출력합니다.

## 비고

제출 코드의 크기는 최대 $64$ KiB로 제한됩니다. 또한 저지 환경에서는 네트워크에 접근할 수 없습니다.
