$N$개 정점의 완전 그래프에서 정점 $i,j$를 잇는 간선의 가중치를 $A_i,A_j$의 최소공배수로 정의합니다.

## 문제

최소 신장 트리에 포함되는 간선 가중치 합을 구하세요.

## 입력

```text
N
A_1 A_2 ... A_N
```

$2\le N\le10^6$, $1\le A_i\le10^5$입니다.

## 출력

답을 출력하세요.
