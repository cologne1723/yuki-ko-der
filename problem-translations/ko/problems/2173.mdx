서로 다른 위치에 $N$개의 별이 있다냥. 별은 빨간색 또는 파란색이고, 정확히 $K$개의 별을 포함하며 두 색을 모두 하나 이상 포함하는 모임을 별자리라고 하자냥. 별자리의 빨간 별과 파란 별을 서로 나누는 직선이 존재하지 않으면 좋은 별자리라고 한다냥. 단, 별이 직선 위에 놓인 경우에는 나눈 것으로 보지 않는다냥. 좋은 별자리가 존재하는지 판정하라냥.

## 조건

- $3\le K\le N\le3000$
- $0\le|X_i|,|Y_i|\le10^9$
- 모든 위치는 서로 다르다냥.

## 입력

```text
N K
X_1 Y_1 C_1
\vdots
X_N Y_N C_N
```

## 출력

좋은 별자리가 존재하면 `Yes`, 아니면 `No`를 출력하라냥.
