## 문제

소수 $P$와 $\bmod P$에서 덧셈·곱셈·나눗셈을 할 수 있는 프로그래밍 언어가 있습니다. $P$는 입력으로 주어지지 않지만 $10^8\lt P\lt10^9$인 소수이며, 미리 정해져 있습니다.

이 언어로 덧셈을 최대 100회, 곱셈을 최대 100회, 나눗셈을 최대 1회 수행하여 다음 문제의 답을 구하는 프로그램을 작성하세요.

변수 $x$는 처음에 0입니다. $i=1,2,\ldots,N$에 대해 순서대로 다음 연산을 수행합니다.

- $op_i=+$이면 $x$를 $x+A_i\pmod P$로 바꿉니다.
- $op_i=*$이면 $x$를 $x\times A_i\pmod P$로 바꿉니다.
- $op_i=/$이면 $x$를 $x/A_i\pmod P$로 바꿉니다.

여기서 $a/b\pmod P$는 $a\equiv bc\pmod P$를 만족하는 $0\leq c\lt P$인 유일한 정수입니다. 모든 연산 후의 $x$를 구하세요.

## 프로그램 사양

프로그램은 영소문자로 표시되는 26개 변수 `a`–`z`를 사용할 수 있습니다. 각 변수는 $0$ 이상 $P$ 미만의 정수를 저장하며, 시작 시 모든 변수는 0입니다. 시작 시 길이 $N$인 배열 $A$가 주어지고 읽을 수 있지만 수정할 수 없습니다. 실행 종료 시 변수 `a`에 답이 들어 있어야 합니다.

첫 줄에는 명령 수 $M\geq0$, 다음 $M$줄에는 명령을 적습니다. 명령은 위에서부터 순서대로 실행됩니다.

- `add X Y Z`: $X$에 $Y+Z\pmod P$를 대입합니다.
- `mul X Y Z`: $X$에 $Y\times Z\pmod P$를 대입합니다.
- `div X Y Z`: $X$에 $Y/Z\pmod P$를 대입합니다. $Z\ne0$이어야 합니다.

`Y,Z`는 변수 또는 배열 원소이며, 배열의 $i$번째 원소는 `A[i]`로 참조합니다.

## 제약

- $10^8\lt P\lt10^9$인 소수입니다.
- 덧셈과 곱셈은 각각 100회 이하, 나눗셈은 1회 이하입니다.
- $A_i$는 $1\leq A_i<10^8$입니다.

## 입력

프로그램 실행 시 별도의 입력은 주어지지 않으며, 길이 $N$인 배열 $A$가 제공됩니다.

## 출력

프로그램 종료 시 변수 `a`에 답을 저장하세요.
