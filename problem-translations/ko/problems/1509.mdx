## 문제

길이 $N$인 순열 $P$에 대해 다음 두 작업을 원하는 순서와 횟수만큼 수행할 수 있습니다.

- $1\leq i\leq N-A$인 $i$를 골라 $P_i$와 $P_{i+A}$를 교환합니다.
- $1\leq i\leq N-B$인 $i$를 골라 $P_i$와 $P_{i+B}$를 교환합니다.

초기 순열과 관계없이 $P$를 오름차순으로 정렬할 수 있는지 판정하세요.

## 입력

첫째 줄에 테스트 케이스 수 $T$가 주어집니다. 각 테스트 케이스에 $N,A,B$가 주어집니다.

- $1\leq T\leq5\times10^4$
- $2\leq N\leq10^{18}$
- $1\leq A,B<N$

## 출력

각 테스트 케이스에 대해 가능하면 `YES`, 불가능하면 `NO`를 출력하세요.
