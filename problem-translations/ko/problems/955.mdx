## 문제 설명

계수 $a, b, c$가 정수인 방정식 $ax^2 + bx + c = 0$의 실수해가 유한 개인지 판정하고, 유한 개라면 개수와 해를, 무한히 많다면 $-1$을 출력하세요.

## 입력

```text
$a\ b\ c$
```

## 제한

- 입력은 모두 정수입니다.
- $-10^9 \le a, b, c \le 10^9$

## 출력

실수해의 개수가 유한 개인 경우, 첫 번째 줄에 실수해의 개수 $N$을 출력하세요. 이어서 $N$줄에 실수해를 작은 순서부터 출력하세요. 절대 오차와 상대 오차 중 작은 쪽이 $10^{-11}$ 이하이면 정답으로 인정합니다.

실수해가 무한히 많이 존재하는 경우에는 $-1$을 출력하세요.

마지막에 줄바꿈을 출력하세요.
