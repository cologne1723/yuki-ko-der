실행 시간 제한은 $6\,000$ms입니다. 빠른 언어·처리계의 사용을 권장합니다.

참고로, 출제자 풀이의 실행 시간은 C++에서 $425$ms, PyPy3에서 $5\,153$ms입니다.

## 문제 설명

$L \leq \min\{N,M\}$을 만족하는 $3$개의 양의 정수 $N$, $M$, $L$과 길이 $N$인 정수열 $A$, 길이 $M$인 정수열 $B$가 주어집니다.

집합 $\mathbb{N} \cap [1,N] = \{1,\ldots,N\}$의 길이 $L$인 순열 $P$와 집합 $\mathbb{N} \cap [1,M] = \{1,\ldots,M\}$의 길이 $L$인 순열 $Q$에 대해 다음과 같이 정의합니다.

$f(P,Q) = \sum_{k=1}^{L} \left|A_{P_k} - B_{Q_k}\right|$

$P$, $Q$를 바꾸었을 때 $f(P,Q)$의 최솟값을 구하세요.

단, 정수열 $a$와 그 길이 이하인 양의 정수 $i$에 대해 $a_i$는 $a$의 $i$번째 성분을 나타냅니다.

### 길이가 지정된 순열의 정의

집합 $X$와 음이 아닌 정수 $\ell$에 대해 $X$의 길이 $\ell$인 순열이란 $X$의 원소로 이루어진 길이 $\ell$인 열이며, 모든 성분이 서로 다른 것을 말합니다.

$X$의 길이 $\ell$인 순열이 존재하기 위한 필요충분조건은 $X$의 원소가 $\ell$개 이상인 것입니다. 특히 $L \leq \min\{N,M\}$이므로 $\mathbb{N} \cap [1,N] = \{1,\ldots,N\}$의 길이 $L$인 순열 $P$와 $\mathbb{N} \cap [1,M] = \{1,\ldots,M\}$의 길이 $L$인 순열 $Q$는 존재합니다.

예를 들어 원소가 $3$개인 집합 $\{1,2,3\}$의 길이 $2$인 순열은 $(1,2)$, $(1,3)$, $(2,1)$, $(2,3)$, $(3,1)$, $(3,2)$의 $6$가지입니다.

## 입력

입력은 표준 입력으로 다음 형식의 $3$줄로 주어집니다.

- $1$번째 줄에 $N$, $M$, $L$이 공백으로 구분되어 주어집니다.
- $2$번째 줄에 $N$ 이하인 각 양의 정수 $i$에 대한 $A_i$가 $i$가 작은 순서대로 공백으로 구분되어 주어집니다.
- $3$번째 줄에 $M$ 이하인 각 양의 정수 $j$에 대한 $B_j$가 $j$가 작은 순서대로 공백으로 구분되어 주어집니다.

```text
$N\ M\ L$
$A_1\ \cdots\ A_N$
$B_1\ \cdots\ B_M$
```

## 제한

입력은 다음 제한을 만족합니다.

- $N$은 $1 \leq N \leq 10^3$을 만족하는 정수입니다.
- $M$은 $1 \leq M \leq 10^3$을 만족하는 정수입니다.
- $L$은 $1 \leq L \leq \min\{N,M\}$을 만족하는 정수입니다.
- $N$ 이하인 임의의 양의 정수 $i$에 대해 $A_i$는 $-10^3 \leq A_i \leq 10^3$을 만족하는 정수입니다.
- $M$ 이하인 임의의 양의 정수 $j$에 대해 $B_j$는 $-10^3 \leq B_j \leq 10^3$을 만족하는 정수입니다.

## 출력

$P$, $Q$를 바꾸었을 때 $f(P,Q)$의 최솟값을 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 2 1
1 0
0 -1
```

#### 출력

```text
0
```

예를 들어 $P=(2)$, $Q=(1)$일 때

$f(P,Q) = \left|A_{P_1} - B_{Q_1}\right| = |0 - 0| = 0$

입니다.

$f(P,Q)$의 값은 $0$보다 작아질 수 없습니다.

### 예제 2 {file=""}

#### 입력

```text
3 2 2
0 2 4
5 1
```

#### 출력

```text
2
```

예를 들어 $P=(3,1)$, $Q=(1,2)$일 때

$f(P,Q) = \left|A_{P_1} - B_{Q_1}\right| + \left|A_{P_2} - B_{Q_2}\right| = |4 - 5| + |0 - 1| = 2$

입니다.

$f(P,Q)$의 값은 $2$보다 작아질 수 없습니다.

### 예제 3 {file=""}

#### 입력

```text
3 3 3
0 0 0
1 1 1
```

#### 출력

```text
3
```

$P$, $Q$를 어떻게 선택하더라도

$f(P,Q) = \left|A_{P_1} - B_{Q_1}\right| + \left|A_{P_2} - B_{Q_2}\right| + \left|A_{P_3} - B_{Q_3}\right| = |0 - 1| + |0 - 1| + |0 - 1| = 3$

입니다.

### 예제 4 {file=""}

#### 입력

```text
5 5 1
2 5 5 12 13
0 3 9 9 18
```

#### 출력

```text
1
```

예를 들어 $P=(1)$, $Q=(2)$일 때

$f(P,Q) = \left|A_{P_1} - B_{Q_1}\right| = |2 - 3| = 1$

입니다.

$f(P,Q)$의 값은 $1$보다 작아질 수 없습니다.

### 예제 5 {file=""}

#### 입력

```text
5 5 2
2 5 5 12 13
0 3 9 9 18
```

#### 출력

```text
4
```

$L$ 이외에는 예제 $4$와 같습니다. 예를 들어 $P=(1,2)$, $Q=(1,2)$일 때

$f(P,Q) = \left|A_{P_1} - B_{Q_1}\right| + \left|A_{P_2} - B_{Q_2}\right| = |2 - 0| + |5 - 3| = 4$

입니다.

$f(P,Q)$의 값은 $4$보다 작아질 수 없습니다.

### 예제 6 {file=""}

#### 입력

```text
5 5 4
2 5 5 12 13
0 3 9 9 18
```

#### 출력

```text
11
```

$L$ 이외에는 예제 $5$와 같습니다. 예를 들어 $P=(1,2,4,5)$, $Q=(1,2,3,4)$일 때

$f(P,Q) = \left|A_{P_1} - B_{Q_1}\right| + \left|A_{P_2} - B_{Q_2}\right| + \left|A_{P_3} - B_{Q_3}\right| + \left|A_{P_4} - B_{Q_4}\right| = |2 - 0| + |5 - 3| + |12 - 9| + |13 - 9| = 11$

입니다.

$f(P,Q)$의 값은 $11$보다 작아질 수 없습니다.
