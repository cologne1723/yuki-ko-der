**이 문제는 8이 포함된 수 세기 (어려움)(콘테스트 C 문제)와 설정이 같고, 제한과 그 밖의 세부 사항만 다릅니다.**

**8이 포함된 수 세기 (어려움)를 정답으로 맞히는 코드를 제출하면 이 문제도 정답으로 맞힐 수 있습니다.**

## 이야기

AngrySadEight さん은 숫자 $8$을 매우 좋아합니다. 그래서 $8$이 포함된 수가 몇 개 있는지 세어 보기로 했습니다.

## 문제 설명

$N$ 이하의 양의 정수 중 십진법으로 나타냈을 때 숫자 $8$이 포함된 것의 개수를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

## 제한

- $N$은 정수입니다.
- $1\leq N\leq888$입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
8
```

#### 출력

```text
1
```

$8$ 이하의 양의 정수 중 $8$이 포함된 수는 $1$개이며, 그 수는 $8$입니다. 따라서 $1$을 출력하세요.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
88
```

#### 출력

```text
17
```

$88$ 이하의 양의 정수 중 $8$이 포함된 것은 $8, 18, 28, 38, 48, 58, 68, 78, 80, 81, 82, 83, 84, 85, 86, 87, 88$의 $17$개입니다. 따라서 $17$을 출력하세요.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1
```

#### 출력

```text
0
```

$1$ 이하의 양의 정수 중 $8$이 포함된 것은 존재하지 않습니다. 따라서 $0$을 출력하세요.

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
888
```

#### 출력

```text
241
```
