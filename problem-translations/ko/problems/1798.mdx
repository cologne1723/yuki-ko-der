AtCoder 상점이 `N`엔어치를 구매했습니다. `P`%는 외상으로 지불하고 나머지를 당좌예금으로 지불할 때, 당좌예금으로 지불하는 금액을 구하세요.

## 제약

- `1000 <= N <= 100000`
- `0 <= P <= 100`
- 결과는 정수입니다.

## 입력

`N P`가 주어집니다.

## 출력

당좌예금으로 지불하는 금액을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
10000 50
```

#### 출력

```text
5000
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1000 1
```

#### 출력

```text
990
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
30000 15
```

#### 출력

```text
25500
```

### 예제 4 {file="01_sample_03.txt"}

#### 입력

```text
62000 100
```

#### 출력

```text
0
```
