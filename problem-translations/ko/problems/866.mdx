## 주의

빠른 언어가 아니면 실행 시간 제한 안에 들어오지 못할 수 있습니다.

## 문제

$H\times W$ 격자가 있습니다. 위에서 $i$번째 행, 왼쪽에서 $j$번째 열의 칸을 $(i,j)$로 나타냅니다. 왼쪽 위 칸은 $(1,1)$, 오른쪽 아래 칸은 $(H,W)$입니다.

각 칸에는 영문 소문자 $c_{i,j}$가 쓰여 있습니다.

왼쪽 위 칸이 $(a,b)$이고 오른쪽 아래 칸이 $(c,d)$인 정사각형 영역을 생각합니다. 다음 조건을 만족해야 합니다.

$1\leq a\leq c\leq H$, $1\leq b\leq d\leq W$, $c-a=d-b$

이 정사각형 영역 안에 포함된 문자의 종류 수가 정확히 $P$가지일 때, 이 정사각형을 ‘레벨 $P$의 정사각형’이라고 합니다.

레벨 $K$의 정사각형이 몇 개 있는지 구하세요.

## 제약

- $H,W$는 $1$ 이상 $2000$ 이하인 정수입니다.
- $K$는 $1$ 이상 $26$ 이하인 정수입니다.
- $c_{i,j}$는 a부터 z까지의 영문 소문자 중 하나입니다.

## 입력

~~~text
$H$ $W$ $K$
$c_{1,1}c_{1,2}c_{1,3}$...$c_{1,W}$
$c_{2,1}c_{2,2}c_{2,3}$...$c_{2,W}$
$c_{3,1}c_{3,2}c_{3,3}$...$c_{3,W}$
...
$c_{H,1}c_{H,2}c_{H,3}$...$c_{H,W}$
~~~

## 출력

레벨 $K$의 정사각형 개수를 출력하세요.

마지막에 줄바꿈을 출력하세요.

- 왼쪽 위 $(1,1)$, 오른쪽 아래 $(2,2)$인 정사각형 영역
- 왼쪽 위 $(1,2)$, 오른쪽 아래 $(2,3)$인 정사각형 영역
- 왼쪽 위 $(1,3)$, 오른쪽 아래 $(2,4)$인 정사각형 영역

- 왼쪽 위 $(3,1)$, 오른쪽 아래 $(4,2)$인 정사각형 영역
- 왼쪽 위 $(3,2)$, 오른쪽 아래 $(4,3)$인 정사각형 영역
- 왼쪽 위 $(3,3)$, 오른쪽 아래 $(4,4)$인 정사각형 영역
