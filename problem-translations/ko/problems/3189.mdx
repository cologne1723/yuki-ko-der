## 문제 설명

$N$개의 정점으로 이루어진 트리가 주어집니다. $i$번째 간선은 정점 $U_i$와 정점 $V_i$를 연결합니다.

처음에는 모든 정점이 흰색으로 칠해져 있습니다. $Q$개의 질의를 처리하세요.

각 질의는 다음 $2$가지 형식 중 $1$개입니다.

- $1\ v$: 질의 직전 시점에 정점 $v$가 흰색이면 검은색으로, 검은색이면 흰색으로 바꿉니다.
- $2\ v$: 정점 $v$와 검은색 정점 사이의 거리로 가능한 최솟값을 출력하세요. 이 질의 시점에 검은색 정점이 $1$개 이상 존재하는 것이 보장됩니다.

## 입력

```text
$N$
$U_1\ V_1$
$U_2\ V_2$
$\vdots$
$U_{N-1}\ V_{N-1}$
$Q$
$\mathrm{Query}_1$
$\mathrm{Query}_2$
$\vdots$
$\mathrm{Query}_Q$
```

여기서 $\mathrm{Query}_i$는 $i$번째 질의에 해당하는 내용입니다.

각 질의는 다음 형식 중 $1$개로 주어집니다.

```text
$1\ v$
```

```text
$2\ v$
```

## 제한

- $2 \le N \le 10^5$
- $1 \le U_i < V_i \le N$
- $1 \le Q \le 10^5$
- $1 \le v \le N$
- 입력은 모두 정수입니다.
- 주어지는 그래프는 트리입니다.
- $2$로 시작하는 질의 시점에 검은색 정점이 존재합니다.

## 출력

$2$로 시작하는 질의에 대한 답을 출력하고 줄을 바꾸세요.
