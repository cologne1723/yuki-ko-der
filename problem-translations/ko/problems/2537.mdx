수열 $A$에 대해 $X_A(\ell,r)$를 $P_{A_\ell}\Rightarrow X_A(\ell+1,r)$로 오른쪽 결합해 정의합니다. 각 $r$에 대해 $X_A(1,r)$가 참이 되는 진릿값 할당의 수를 $B$로 나눈 나머지를 구하세요.

<details>
<summary>명제 변수의 진릿값 할당을 모르는 사람을 위한 설명 (클릭하면 열립니다)</summary>

$N$ 이하의 각 양의 정수 $i$에 대한 $P_i$의 진릿값 할당은 대략 각 양의 정수 $i$에 대해 $P_i$가 참인지 거짓인지 정하는 대응입니다.

좀 더 형식적으로는 $N$ 이하의 양의 정수 전체의 집합에서 $\{0,1\}$로 가는 함수입니다. 이 정식화가 납득된다면 이 보충 설명은 필요하지 않으므로 대략적인 설명만 적었습니다.

</details>

## 입력


```text
N B
A1 A2 ... AN
```

## 출력

각 $r=1,\ldots,N$의 답을 출력하세요.
