## 이야기

岩井星人さん의 경쟁 프로그래밍 사이트 사용자 ID는 `yiwiy9`입니다.

## 문제 설명

여기서 $1$ 이상인 회문수의 끝에 $9$를 덧붙인 정수를 岩井 수라고 합니다. 예를 들어 $381\,839$, $19$, $999$는 岩井 수이지만, $9\,119$, $709$, $9$는 岩井 수가 아닙니다.

岩井 수 $N$이 주어집니다. 다음 조건을 모두 만족하는 정수를 $1$개 출력하세요.

- 岩井 수입니다.
- $N$의 배수입니다.
- $10^9$ 이상 $10^{2\,000}$ 이하입니다.

또한 이 문제의 제한 아래에서는 조건을 만족하는 수가 반드시 존재한다는 것을 증명할 수 있습니다.

### 배경

음이 아닌 정수 $X$를 $10$진법으로 나타낸 문자열(앞에 $0$이 붙지 않음)이 회문일 때, $X$를 회문수라고 합니다. 예를 들어 $38\,183$, $1$, $99$는 회문수입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

정수 $N$이 주어집니다.

## 제한

- $N \leq 10^9$
- $N$은 岩井 수입니다.

## 출력

조건을 만족하는 수를 $1$개 출력하세요.

조건을 만족하는 수가 여러 개 존재하는 경우, 그중 어느 것을 출력해도 정답으로 인정됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
19
```

#### 출력

```text
1001110019
```

$1\,001\,110\,019$는 岩井 수입니다. 또한 $1\,001\,110\,019$는 $19$의 배수이고, $10^9 \leq 1\,001\,110\,019 \leq 10^{2\,000}$을 만족합니다.

그 밖에도 예를 들어 $123\,456\,789\,012\,332\,109\,876\,543\,219$ 등이 조건을 만족하므로, 이를 출력해도 정답입니다.

### 예제 2 {file=""}

#### 입력

```text
381839
```

#### 출력

```text
1000800019
```
