## 문제

어떤 엔지니어는 수작업으로 $A$분 걸리는 작업 하나를 $B$초에 끝내는 프로그램을 만드는 데 $C$시간이 걸립니다.

가능한 한 빨리 이 작업 $X$개를 끝내려 할 때, $X$가 몇 이상이면 프로그램을 작성해야 할까요? $X$가 아무리 커도 작성하지 않아야 한다면 $-1$을 출력하세요.

수작업 시간과 프로그램 사용 시간이 같은 경우에도 프로그램을 작성합니다. (2018/09/28 수정)

## 입력

~~~text
$A$ $B$ $C$
~~~

- $1\leq A,B,C\leq10^9$
- 입력은 모두 정수입니다.

## 출력

조건을 만족하는 정수 하나를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
3 3 3
~~~

#### 출력

~~~text
62
~~~

$A=180$초, $B=3$초, $C=10800$초입니다. 61개까지는 수작업이 $61\times180=10980$초, 프로그램이 $10800+61\times3=10983$초입니다. 62개부터는 수작업이 11160초, 프로그램이 10986초이므로 62개 이상이면 프로그램을 작성합니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
30 3 3
~~~

#### 출력

~~~text
7
~~~

6개는 수작업 10800초, 프로그램 10818초이지만 7개는 수작업 12600초, 프로그램 10821초입니다. 따라서 7개 이상이면 프로그램을 작성합니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
1 70 1
~~~

#### 출력

~~~text
-1
~~~

수작업이 프로그램을 실행하는 것보다 빠르므로 프로그램을 작성하지 않습니다.

### 샘플 4 {file="sample4.in"}

#### 입력

~~~text
180 8100 85885
~~~

#### 출력

~~~text
114514
~~~

114514개 이상이면 프로그램을 작성해야 합니다.
