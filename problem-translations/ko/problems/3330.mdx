**주의:** 이 문제는 시간 제한이 엄격하여 PyPy3에서 정답을 확인하지 못했습니다. C++에 준하는 속도의 언어를 사용하세요.

## 문제 설명

길이 $N$인 수열 $A$와 $A$에 대한 $K$개의 연산이 주어집니다. 연산 $k$는 $k$번째로 주어지는 연산을 뜻합니다.

- 연산 $k$
  - $1 \leq p_k \leq N$을 만족하는 양의 정수 $p_k$와 양의 정수 $X_k$가 주어집니다. $A_{p_k}$를 $\max(A_{p_k}, X_k)$로 변경합니다.

$Q$개의 질의가 주어집니다. 각 질의는 다음과 같습니다.

- 질의 $j$
  - $1 \leq L_j \leq R_j \leq K$, $1 \leq D_j \leq U_j \leq N$을 만족하는 양의 정수 $L_j$, $R_j$, $D_j$, $U_j$가 주어집니다. $L_j \leq k \leq R_j$를 만족하는 각 양의 정수 $k$에 대해 연산 $k$를 오름차순으로 수행했을 때, 갱신된 $A$에서 $\sum_{i=D_j}^{U_j}{A_i}$의 값을 출력합니다.

이 연산은 다른 질의에 영향을 주지 않습니다.

모든 질의에 답하세요.

## 입력

```text
$N\ K\ Q$
$A_1\ \cdots\ A_N$
$\mathit{Update}_1$
$\vdots$
$\mathit{Update}_K$
$\mathit{Query}_1$
$\vdots$
$\mathit{Query}_Q$
```

$1$번째 줄에 $N$, $K$, $Q$가 주어집니다.

$2$번째 줄에 $A_1, \ldots, A_N$이 주어집니다.

$\mathit{Update}_k$는 $k$번째 연산을 나타내며, 다음 형식으로 주어집니다.

```text
$p_k\ X_k$
```

$\mathit{Query}_j$는 $j$번째 질의를 나타내며, 다음 형식으로 주어집니다.

```text
$L_j\ R_j\ D_j\ U_j$
```

## 제한

- 모든 입력은 정수입니다.
- $1 \leq N, K, Q \leq 1.5 \times 10^5$
- $1 \leq A_i \leq 10^9$
- 각 연산에 대해 다음 조건을 만족합니다.
  - $1 \leq p_k \leq N$
  - $1 \leq X_k \leq 10^9$
- 각 질의에 대해 다음 조건을 만족합니다.
  - $1 \leq L_j \leq R_j \leq K$
  - $1 \leq D_j \leq U_j \leq N$

## 출력

$Q$개의 줄에 출력하세요. $j$번째 줄에는 질의 $j$의 답을 출력하고 줄바꿈하세요.

## 예제

#### 입력

```text

1 3

```

#### 출력

```text
23
9
26
32
```

예를 들어 질의 $1$에서는 연산 $2$번부터 $4$번까지를 오름차순으로 적용합니다. 그 결과 $A = [1, 5, 11, 6, 5]$가 되므로, $A[1:4]$의 합은 $23$입니다. 여기서 $A[1:4]$는 닫힌 구간으로 나타냈습니다.

다른 질의에서 연산을 적용한 결과 $A$는 각각 다음과 같습니다.

- $[3, 5, 3, 4, 5]$
- $[1, 2, 13, 6, 7]$
- $[3, 5, 11, 6, 7]$
