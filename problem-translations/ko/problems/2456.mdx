흰 격자에 $k\times k$ 정사각형 스탬프를 원하는 횟수만큼 찍어 주어진 흑백 격자 $X$를 만들 수 있다고 합니다. 한 번 찍은 칸은 흰색이면 검게 칠해지고 이미 검은 칸은 그대로입니다. $X$를 만들 수 있는 스탬프 크기의 최댓값을 구하세요.

## 조건

- $1\le H,W\le2000$
- 격자에는 검은 칸이 하나 이상 있습니다.

## 입력

```text
H W
S1
...
SH
```

## 출력

가능한 스탬프 크기의 최댓값을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 3
##.
###
.##
```

#### 출력

```text
2
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 3
###
###
###
```

#### 출력

```text
3
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
5 6
###.##
##.###
#####.
.###..
######
```

#### 출력

```text
1
```
