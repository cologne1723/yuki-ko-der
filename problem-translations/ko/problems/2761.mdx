## 문제

길이 `L`인 문자열 `N`개가 있습니다. 다음 질의를 순서대로 처리하세요.

- `1 k c d`: 모든 문자열에서 `k`번째 문자가 `c`인 경우 `d`로 바꿉니다.
- `2 t`: `t`를 접두사로 가지는 문자열의 개수를 출력합니다.

## 제약

- `1 ≤ N ≤ 1000`, `1 ≤ L ≤ 3000`, `1 ≤ Q ≤ 4000`
- 문자열은 소문자 영어로 이루어집니다.

## 입력

```text
N L Q
S_1
⋮
S_N
query_1
⋮
query_Q
```

## 출력

2번 질의의 답을 순서대로 출력하세요.

실행 시간 제한 때문에 사용하는 처리계에 따라 의도한 풀이로도 AC를 받지 못할 수 있습니다. 특히 Python 사용자는 PyPy3를 선택하는 것을 권장합니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 3 3
aaa
aba
bbb
ccc
2 aa
1 2 b a
2 aa
```

#### 출력

```text
1
2
```

처음에는 $S=(\mathrm{aaa},\mathrm{aba},\mathrm{bbb},\mathrm{ccc})$입니다.

- 첫 번째 질의: `aa`를 접두사로 가지는 문자열은 $S_1$의 $1$개입니다.
- 두 번째 질의: $S=(\mathrm{aaa},\mathrm{aaa},\mathrm{bab},\mathrm{ccc})$로 바뀝니다.
- 세 번째 질의: `aa`를 접두사로 가지는 문자열은 $S_1,S_2$의 $2$개입니다.
