## 문제

길이 `L`인 문자열 `N`개가 있습니다. 다음 질의를 순서대로 처리하세요.

- `1 k c d`: 모든 문자열에서 `k`번째 문자가 `c`인 경우 `d`로 바꿉니다.
- `2 t`: `t`를 접두사로 가지는 문자열의 개수를 출력합니다.

## 제약

- `1 ≤ N ≤ 1000`, `1 ≤ L ≤ 3000`, `1 ≤ Q ≤ 4000`
- 문자열은 소문자 영어로 이루어집니다.

## 입력

```text
N L Q
S_1
⋮
S_N
query_1
⋮
query_Q
```

## 출력

2번 질의의 답을 순서대로 출력하세요.
