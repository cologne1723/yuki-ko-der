## 문제 설명

$n$을 $1$ 이상의 정수라고 합니다.

$a+b+c+d+e+f+g+h=6n$을 만족하면서 다음 조건도 만족하는 정수 튜플 $(a,b,c,d,e,f,g,h)$의 개수 $G(n)$을 구하세요.

$0\le a,b,c,d,e,f,g,h\le n$

## 입력

```text
$n$
```

입력은 정수로 주어집니다.

## 제한

- $1 \le n \le 100$

## 출력

$G(n)$을 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
28
```

$0$이 $2$개, $1$이 $6$개이므로 ${}_8\mathrm{C}_2=28$가지입니다.

### 예제 2 {file=""}

#### 입력

```text
10
```

#### 출력

```text
796510
```

### 예제 3 {file=""}

#### 입력

```text
100
```

#### 출력

```text
2721355068691
```
