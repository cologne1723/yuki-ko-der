## 문제

Yuki 호텔은 인터넷으로 예약을 받고 있습니다.

그런데 어느 날 시스템에 문제가 발생해 이미 예약된 객실에도 예약을 받을 수 있게 되었습니다.

그 결과 예약이 겹쳤고, 숙박할 수 없게 된 손님에게 요금을 환불한 뒤 Yuki 호텔의 비용 부담으로 다른 호텔로 바꾸어 주기로 했습니다.

Yuki 호텔 숙박 요금 P1, 변경할 호텔 숙박 요금 P2, Yuki 호텔 예약 현황 R이 주어질 때 이날 Yuki 호텔의 손실액 C를 계산하세요.

손실액은 다음과 같이 계산합니다.

손실액 = Yuki 호텔의 기회손실액 + 변경에 든 비용

기회손실이란 중복 예약이 없었다면 원래 Yuki 호텔이 얻을 수 있었던 금액입니다.

객실 하나에 예약이 겹쳐도 한 팀의 손님은 숙박할 수 있습니다. 예를 들어 같은 객실에 예약 3건이 들어와도 한 팀은 숙박할 수 있고 두 팀은 다른 호텔로 변경해야 합니다.

## 입력

```text
P1
P2
N
R1
…
RN
```

P1: Yuki 호텔 숙박 요금

P2: 변경할 호텔 숙박 요금

N: 예약 건수

Ri: 예약된 객실 번호

1 ≤ P1,P2 ≤ 100000

1 ≤ N ≤ 100

1 ≤ Ri ≤ 999

## 출력

Yuki 호텔의 손실액 C를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
20000
17000
3
302
511
511
```

출력:

```text
37000
```

511호 예약이 중복되었습니다. Yuki 호텔의 손실은 37000입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
30000
50000
5
402
402
605
605
605
```

출력:

```text
240000
```

402호와 605호에서 예약이 중복되었습니다. Yuki 호텔의 손실은 240000입니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
12000
7200
10
112
309
402
510
102
201
305
304

302
```

출력:

```text
0
```

예약 10건이 있었지만 중복은 발생하지 않았습니다. 손실은 0입니다. 중복이 한 건도 발생하지 않는 경우도 있습니다.
