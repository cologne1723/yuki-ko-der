## 문제 설명

음이 아닌 정수 $N$과 음이 아닌 정수 계수를 가지는 $N$차 정사각행렬 $D$가 주어집니다.

### 음이 아닌 정수 계수를 가지는 $N$차 정사각행렬이란?

간단히 말하면 세로 $N$행, 가로 $N$열로 배치된 곳에 음이 아닌 정수를 나열한 것입니다. 벡터와 마찬가지로 전체를 괄호로 묶어 보기 쉽게 나타냅니다.

예를 들어 $N=3$일 때

$\displaystyle
A =
\left(
\begin{array}{ccc}
1 & 2 & 3 \\
4 & 5 & 6 \\
7 & 8 & 9
\end{array}
\right)
$

는 음이 아닌 정수 계수를 가지는 $N$차 정사각행렬의 구체적인 예입니다.

$N$ 이하의 임의의 양의 정수 $i$, $j$에 대해, 음이 아닌 정수 계수를 가지는 $N$차 정사각행렬 $A$의 위에서 $i$번째 행, 왼쪽에서 $j$번째 열에 있는 음이 아닌 정수를 $A$의 $(i,j)$ 성분이라고 합니다.

예를 들어 위의 $A$에서는 $(1,1)$ 성분이 $1$, $(1,2)$ 성분이 $2$, $(2,1)$ 성분이 $4$입니다.

$D$의 $1.$ 비퇴화성, $2.$ 대칭성, $3.$ 삼각부등식, $4.$ 강삼각부등식을 각각 다음 성질로 정의합니다.

1. 비퇴화성: $N$ 이하의 임의의 양의 정수 $i$, $j$에 대해 $D(i,j)=0$과 $i=j$는 동치입니다.
2. 대칭성: $N$ 이하의 임의의 양의 정수 $i$, $j$에 대해 $D(i,j)=D(j,i)$입니다.
3. 삼각부등식: $N$ 이하의 임의의 양의 정수 $i$, $j$, $k$에 대해 $D(i,j)\leq D(i,k)+D(k,j)$입니다.
4. 강삼각부등식: $N$ 이하의 임의의 양의 정수 $i$, $j$, $k$에 대해 $D(i,j)\leq\max\{D(i,k),D(k,j)\}$입니다.

단, $N$ 이하의 각 양의 정수 $i$, $j$에 대해 $D$의 $(i,j)$ 성분, 즉 위에서 $i$번째 행의 왼쪽에서 $j$번째 열에 있는 성분을 $D(i,j)$로 나타냅니다.

$D$가 **좋은 행렬**이라는 것은 $D$가 $1.$ 비퇴화성, $2.$ 대칭성, $3.$ 삼각부등식을 모두 만족한다는 뜻입니다.

$D$가 **초좋은 행렬**이라는 것은 $D$가 $1.$ 비퇴화성, $2.$ 대칭성, $4.$ 강삼각부등식을 모두 만족한다는 뜻입니다.

$D$가 **좋은 행렬**인지 아닌지와 **초좋은 행렬**인지 아닌지를 판정하세요.

### 배경

기하학과 정수론에서는 거리 공간과 초거리 공간이라는 개념이 자주 사용됩니다. $N$ 이하의 양의 정수 전체의 집합을 $I_N$으로 두고 $D$를 $I_N$ 위의 $2$변수 함수로 생각하면, $D$가 **좋은 행렬**일 필요충분조건은 $(I_N,D)$가 거리 공간인 것이며, $D$가 **초좋은 행렬**일 필요충분조건은 $(I_N,D)$가 초거리 공간인 것입니다. 따라서 이 문제는 $(I_N,D)$가 거리 공간인지 아닌지와 초거리 공간인지 아닌지를 판정하는 문제와 같습니다.

## 입력

입력은 다음 형식으로 표준 입력에서 $1+N$개의 행으로 주어집니다.

```text
$N$
$D(1,1)\ \cdots\ D(1,N)$
$\vdots$
$D(N,1)\ \cdots\ D(N,N)$
```

$1$번째 줄에 $N$이 주어집니다.

$N$ 이하의 각 양의 정수 $i$에 대해, $1+i$번째 줄에 $N$ 이하의 각 양의 정수 $j$에 대한 $D(i,j)$가 $j$가 작은 순서대로 반각 공백으로 구분되어 주어집니다.

## 제한

- $1\leq N\leq 10$을 만족하는 정수입니다.
- $N$ 이하의 임의의 양의 정수 $i$, $j$에 대해 $D(i,j)$는 $0\leq D(i,j)\leq 10$을 만족하는 정수입니다.

## 출력

$D$가 **좋은 행렬**이면 `Yes`를, **좋은 행렬**이 아니면 `No`를 $1$번째 줄에 출력하세요.

$D$가 **초좋은 행렬**이면 `Yes`를, **초좋은 행렬**이 아니면 `No`를 $2$번째 줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
0
```

#### 출력

```text
Yes
Yes
```

음이 아닌 정수 계수를 가지는 $1$차 정사각행렬 $D=(0)$은 **좋은 행렬**이면서 **초좋은 행렬**입니다.

거리 공간을 아는 사람을 위해 말하면, 이 $D$는 $I_N=\{1\}$의 자명한 거리를 나타냅니다.

### 예제 2 {file=""}

#### 입력

```text
1
1
```

#### 출력

```text
No
No
```

음이 아닌 정수 계수를 가지는 $1$차 정사각행렬 $D=(1)$은 $1.$ 비퇴화성을 만족하지 않으므로 **좋은 행렬**도 **초좋은 행렬**도 아닙니다.

### 예제 3 {file=""}

#### 입력

```text
3
0 1 2
1 0 1
2 1 0
```

#### 출력

```text
Yes
No
```

음이 아닌 정수 계수를 가지는 $3$차 정사각행렬

$\displaystyle
D = \left(
\begin{array}{rcl}
\displaystyle 0 &\displaystyle 1 &\displaystyle 2 \\
\displaystyle 1 &\displaystyle 0 &\displaystyle 1 \\
\displaystyle 2 &\displaystyle 1 &\displaystyle 0
\end{array}
\right)
$

은 **좋은 행렬**이지만, $4.$ 강삼각부등식을 만족하지 않으므로 **초좋은 행렬**은 아닙니다.

실수를 아는 사람을 위해 말하면, 이 $D$는 유클리드 거리를 $I_N=\{1,2,3\}$에 제한한 것을 나타냅니다.

### 예제 4 {file=""}

#### 입력

```text
3
0 2 1
2 0 2
1 2 0
```

#### 출력

```text
Yes
Yes
```

음이 아닌 정수 계수를 가지는 $3$차 정사각행렬

$\displaystyle
D = \left(
\begin{array}{rcl}
\displaystyle 0 &\displaystyle 2 &\displaystyle 1 \\
\displaystyle 2 &\displaystyle 0 &\displaystyle 2 \\
\displaystyle 1 &\displaystyle 2 &\displaystyle 0
\end{array}
\right)
$

은 **좋은 행렬**이면서 **초좋은 행렬**입니다.

$p$진수를 아는 사람을 위해 말하면, 이 $D$는 $2$진 거리를 $2$배한 것을 $I_N=\{1,2,3\}$에 제한한 것을 나타냅니다.
