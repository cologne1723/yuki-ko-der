## 문제 설명

소수 주사위의 면에는 $2,3,5,7,11,13$, 합성수 주사위의 면에는 $4,6,8,9,10,12$가 쓰여 있습니다.

어떤 보드게임에서 $0$번 칸에서 시작하여 $N$번 칸에 도착하면 골인합니다. 매 턴 소수 주사위 $P$개와 합성수 주사위 $C$개를 굴리고, 눈의 합을 $x$라 할 때 현재 $k$번 칸에서 $\min(k+x,N)$번 칸으로 이동합니다.

같은 종류의 주사위는 서로 구별하지 않을 때, 골인하는 방법의 패턴 수를 $1\,000\,000\,007$ ($10^9+7$)로 나눈 나머지를 구하세요.

## 입력

```text
$N\ P\ C$
```

## 제한

- $1 \le N \le 1\,000\,000\,000\,000\,000\,000 = 10^{18}$
- $0 \le P,C \le 5$
- $P+C \ge 1$

## 출력

골인하는 방법의 패턴 수를 $10^9+7$로 나눈 나머지를 출력하세요. 출력한 뒤에는 줄바꿈을 하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1 1
```

#### 출력

```text
36
```

$1$턴에 반드시 골인하며 $2$개 주사위의 눈 조합은 $6 \times 6=36$가지입니다.

### 예제 2 {file=""}

#### 입력

```text
1 2 0
```

#### 출력

```text
21
```

예제 1과 마찬가지로 $1$턴에 반드시 골인합니다. 소수 주사위 $2$개는 구별하지 않으므로 눈의 조합은 순서를 무시한 $(2,2),(2,3),(2,5),(2,7),(2,11),(2,13),(3,3),(3,5),(3,7),(3,11),(3,13),(5,5),(5,7),(5,11),(5,13),(7,7),(7,11),(7,13),(11,11),(11,13),(13,13)$의 $21$가지입니다.

### 예제 3 {file=""}

#### 입력

```text
5 2 0
```

#### 출력

```text
41
```

첫 턴에 $(2,2)$가 아닌 $20$가지 경우는 $1$턴에 골인합니다. $(2,2)$인 경우 $1$턴이 더 필요하고 $2$번째 턴에는 $21$가지 패턴이 있습니다.

### 예제 4 {file=""}

#### 입력

```text
6 2 0
```

#### 출력

```text
61
```

첫 턴에 $(2,2),(2,3)$이 아닌 $19$가지 경우는 $1$턴에 골인합니다. 이 $2$가지 경우에는 $1$턴이 더 필요하고, $2$번째 턴의 눈은 각각 $21$가지 패턴이 있습니다.

### 예제 5 {file=""}

#### 입력

```text
1 5 5
```

#### 출력

```text
63504
```

$1$턴에 반드시 골인하지만, 주사위 눈의 패턴 수는 그리 작지 않습니다.

### 예제 6 {file=""}

#### 입력

```text
100000 4 5
```

#### 출력

```text
906961798
```

힘내거라. 호호.
