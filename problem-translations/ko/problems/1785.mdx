`<` 또는 `<=`로 이루어진 길이 `N-1`의 부등호열 `I`에 대해, `1 <= A_1 ieq_1 A_2 ... ieq_{N-1} A_N <= K`를 만족하는 정수열의 개수를 점수로 정의합니다.

가능한 모든 `I`의 점수 합을 `10^9+7`로 나눈 나머지를 구하세요.

## 제약

- `2 <= N <= 2 * 10^5`
- `2 <= K <= 5 * 10^8`

## 입력

`N K`가 주어집니다.

## 출력

점수의 총합을 출력하세요.
