소문자로 이루어진 문자열 $S$가 주어집니다. $i$번째에서 나누어 앞부분 $U=S_1\cdots S_i$, 뒷부분 $V=S_{i+1}\cdots S_N$를 만들었을 때 $U$가 사전순으로 $V$보다 엄격히 작은 $i$의 개수를 구하세요.

## 조건

- 테스트 케이스 수 $T\ge1$
- 각 문자열 길이는 2 이상이고, 전체 길이 합은 $3\times10^5$ 이하입니다.

## 입력

```text
T
N
S
```

## 출력

각 테스트 케이스의 답을 한 줄에 하나씩 출력하세요.
