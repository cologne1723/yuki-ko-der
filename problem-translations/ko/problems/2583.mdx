정수 $N$과 다항식 $A(x)=\sum_{i=0}^{M-1}a_ix^i$가 주어집니다. $F_0(x)=x$이고 $k>0$일 때 $F_k(x)=A(x)F_{k-1}(x)+(x^2-1)F'_{k-1}(x)$로 정의합니다. $F_N(x)=\sum b_ix^i$라 할 때 $b_0$부터 $b_{N+1}$까지를 구하세요.

## 조건

- $0\le N\le10^5$, $1\le M\le10^5$
- $0\le a_i<998244353$

## 입력

```text
$N$ $M$
$a_0$ $a_1$ $\cdots$ $a_{M-1}$
```

## 출력

$b_0,b_1,\ldots,b_{N+1}$를 공백으로 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 1
0
```

#### 출력

```text
2 0 998244345 0 6
```

#### 입력

```text

```

#### 출력

```text
5 1 998244266 998244230 51
```
