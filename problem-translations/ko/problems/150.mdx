## 문제 설명

문자열이 $T$개 주어집니다. $i+1$번째 ($1 \le i \le T$) 줄에는 문자열 $S_i$가 주어집니다.

문자열 $S_i$를 앞에서부터 검색했을 때 부분 문자열 `good`을 찾을 수 있고, 그 뒤에서 부분 문자열 `problem`을 찾을 수 있으면 $S_i$를 좋은 문제라고 합니다. $2$개 중 $1$개라도 전혀 찾을 수 없다면 좋은 문제가 아닙니다.

문자열 $S_i$의 임의의 위치에 있는 문자 $1$개를 `a`〜`z` 중 $1$개로 바꾸는 조작을 반복할 수 있습니다. $S_i$를 좋은 문제로 만들기 위해 필요한 조작 횟수의 최솟값을 $K_i$라고 할 때, $K_i$를 출력하세요.

## 입력

```text
$T$
$S_1$
$\vdots$
$S_T$
```

## 제한

- $1 \le T \le 100$
- 각 $S_i$의 길이는 $11$ 이상 $100$ 이하입니다.
- $S_i$의 모든 문자는 `a`〜`z` 중 $1$개입니다.

## 출력

$i$번째 줄에 $K_i$를 출력하세요. $1$번째 줄은 $i=1$에 해당합니다. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
veryverygoodproblem
goodexcellentproblems
problemgood
```

#### 출력

```text
0
0
10
```

$S_1=$ `veryverygoodproblem`, $S_2=$ `goodexcellentproblems`, $S_3=$ `problemgood`입니다. $S_1$과 $S_2$는 처음부터 좋은 문제이므로 $K_1=0$, $K_2=0$입니다. $S_3$은 $3$번째 문자 `o` 이외의 문자를 바꾸어 `goodproblem`으로 만들 수 있으므로 $K_3=10$입니다.
