## 문제 설명

양의 정수 $N$과 양의 정수 수열 $(A_1,A_2,\dotsc,A_N)$, $(B_1,B_2,\dotsc,B_N)$이 주어집니다.

$\displaystyle\min_{1\leq k\leq N} \max_{1\leq l\leq k\leq r\leq N} \frac{\sum_{i=l}^r A_i}{\sum_{i=l}^r B_i}$를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
$B_1\ B_2\ \cdots\ B_N$
```

## 제한

- $1\leq N\leq 10^5$
- $1\leq A_i,B_i\leq 10^9$
- 입력은 모두 정수입니다.

## 출력

답을 $1$줄에 출력하세요.

참값과의 절대 오차 또는 상대 오차가 $10^{-6}$ 이하이면 정답으로 판정됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 2 3
3 2 1
```

#### 출력

```text
1
```

$k=1$일 때 조건을 만족하는 $(l,r)$은 $(1,1),(1,2),(1,3)$이고, 이들의 $\frac{\sum_{i=l}^r A_i}{\sum_{i=l}^r B_i}$는 $\frac{1}{3},\frac{3}{5},1$입니다. 따라서 $\displaystyle\max_{1\leq l\leq k\leq r\leq N} \frac{\sum_{i=l}^r A_i}{\sum_{i=l}^r B_i}=1$입니다.

$k=2$일 때 조건을 만족하는 $(l,r)$은 $(1,2),(1,3),(2,2),(2,3)$이고, 이들의 $\frac{\sum_{i=l}^r A_i}{\sum_{i=l}^r B_i}$는 $\frac{3}{5},1,1,\frac{5}{3}$입니다. 따라서 $\displaystyle\max_{1\leq l\leq k\leq r\leq N} \frac{\sum_{i=l}^r A_i}{\sum_{i=l}^r B_i}=\frac{5}{3}$입니다.

$k=3$일 때 조건을 만족하는 $(l,r)$은 $(1,3),(2,3),(3,3)$이고, 이들의 $\frac{\sum_{i=l}^r A_i}{\sum_{i=l}^r B_i}$는 $1,\frac{5}{3},3$입니다. 따라서 $\displaystyle\max_{1\leq l\leq k\leq r\leq N} \frac{\sum_{i=l}^r A_i}{\sum_{i=l}^r B_i}=3$입니다.

그러므로 답은 $\min(1,\frac{5}{3},3)=1$이므로 $1$을 출력하세요.
