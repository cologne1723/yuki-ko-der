## 이야기

岩井星人さん은 콘테스트 중 자신의 순위를 항상 신경 씁니다.

따라서 문제를 풀고 있는 도중이라도 岩井星人さん은 순위표를 보지 않고는 못 배깁니다.

중요한 일이므로 한 번 더 말하겠습니다. **岩井星人さん은 (순위표를) 보지 않고는 못 배깁니다.**

## 문제 설명

岩井星人さん은 이제 어떤 프로그래밍 콘테스트에 참가합니다. 이 콘테스트에서는 참가자에게 **새 레이트 예측값**이라는 정수값이 설정되며, 시작 시점의 岩井星人さん의 새 레이트 예측값은 $1\,200$입니다.

또한 이 콘테스트에서 새 레이트 예측값은 임의의 정수가 될 수 있으며, 특히 **음수가 될 수도 있음**에 주의해야 합니다.

`0`과 `1`로 이루어진 길이 $N$인 문자열 $S'$가 주어집니다. $S'$를 $10^{100}$번 반복한 문자열을 $S$라고 합니다.

이제 岩井星人さん에게 $10^{100}$개의 이벤트가 순서대로 발생합니다. $i$번째 이벤트는 $S$의 $i$번째 문자에 따라 다음과 같이 정해집니다.

- $S$의 $i$번째 문자가 `0`인 경우, 岩井星人さん의 새 레이트 예측값이 $1$ 감소합니다.
- $S$의 $i$번째 문자가 `1`인 경우, 순위표를 보지 않고는 못 배기는 岩井星人さん은 순위표에서 현재 새 레이트 예측값을 확인합니다.
  - 현재 새 레이트 예측값이 $1\,199$ 이하라면, 죽을힘을 다해 문제를 풀어 **AC**를 받습니다. 그 결과 岩井星人さん의 새 레이트 예측값이 $1$ 증가합니다.
  - 현재 새 레이트 예측값이 $1\,200$ 이상이라면, [「서버 비용이 아까워!」](https://youtu.be/5_U2tdHLmP4?si=VDlMZqEWopvyXprk&t=4210)라고 외치기만 하고 아무것도 하지 않습니다. 岩井星人さん의 새 레이트 예측값은 변하지 않습니다.

순위표를 보지 않고는 못 배기는 岩井星人さん이 $A$번째 **AC**를 받는 것은 몇 번째 이벤트가 발생했을 때인지 구하세요.

단, 콘테스트의 문제 수는 충분히 많아서 岩井星人さん이 모든 문제를 풀 수는 없다고 가정합니다. 또한 제한으로부터 답은 $2 \times 10^{18}$ 이하의 정수임이 보장됩니다.

## 입력

```text
$N\ A$
$S'$
```

$1$번째 줄에 정수 $N$, $A$가 공백으로 구분되어 주어집니다.

$2$번째 줄에 `0`과 `1`로 이루어진 문자열 $S'$가 주어집니다.

## 제한

- $2 \le N \le 2 \times 10^5$
- $1 \le A \le 10^{12}$
- $S'$는 `0`과 `1`로 이루어진 문자열입니다.
- $|S'|=N$
- $S'$에는 `0`과 `1`이 각각 적어도 $1$개씩 포함됩니다.
- $N$, $A$는 정수입니다.

## 출력

岩井星人さん이 $A$번째 **AC**를 받는 이벤트가 몇 번째 이벤트인지 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 3
10100
```

#### 출력

```text
8
```

岩井星人さん에게 다음과 같은 이벤트가 발생합니다.

- $S$의 $1$번째 문자는 `1`입니다. 현재 岩井星人さん의 새 레이트 예측값은 $1\,200$이므로 새 레이트 예측값은 변하지 않습니다.
- $S$의 $2$번째 문자는 `0`입니다. 현재 岩井星人さん의 새 레이트 예측값은 $1\,200$이므로 새 레이트 예측값이 $1$ 감소하여 $1\,199$가 됩니다.
- $S$의 $3$번째 문자는 `1`입니다. 현재 岩井星人さん의 새 레이트 예측값은 $1\,199$이므로 문제를 풀어 **AC**를 받고, 새 레이트 예측값이 $1$ 증가하여 $1\,200$이 됩니다.
- $S$의 $4$번째 문자는 `0`입니다. 현재 岩井星人さん의 새 레이트 예측값은 $1\,200$이므로 새 레이트 예측값이 $1$ 감소하여 $1\,199$가 됩니다.
- $S$의 $5$번째 문자는 `0`입니다. 현재 岩井星人さん의 새 레이트 예측값은 $1\,199$이므로 새 레이트 예측값이 $1$ 감소하여 $1\,198$가 됩니다.
- $S$의 $6$번째 문자는 `1`입니다. 현재 岩井星人さん의 새 레이트 예측값은 $1\,198$이므로 문제를 풀어 **AC**를 받고, 새 레이트 예측값이 $1$ 증가하여 $1\,199$가 됩니다.
- $S$의 $7$번째 문자는 `0`입니다. 현재 岩井星人さん의 새 레이트 예측값은 $1\,199$이므로 새 레이트 예측값이 $1$ 감소하여 $1\,198$가 됩니다.
- $S$의 $8$번째 문자는 `1`입니다. 현재 岩井星人さん의 새 레이트 예측값은 $1\,198$이므로 문제를 풀어 **AC**를 받고, 새 레이트 예측값이 $1$ 증가하여 $1\,199$가 됩니다.

$3$번째 **AC**를 받은 것은 $8$번째 이벤트가 발생했을 때이므로 $8$을 출력합니다.
