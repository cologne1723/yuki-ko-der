## 문제

수열 `A`의 모든 공집합이 아닌 부분 수열 `B`에 대해, `B`의 모든 공집합이 아닌 연속 부분 수열 `C`의 원소 합을 더합니다. 이 값을 모든 `B`에 대해 다시 더한 결과를 `998244353`으로 나눈 나머지를 구하세요.

부분 수열과 연속 부분 수열은 값이 같아도 선택한 인덱스 집합이 다르면 서로 다르게 셉니다.

## 제약

- `1 ≤ N ≤ 2×10^5`
- `0 ≤ A_i < 998244353`

## 입력

```text
N
A_1 A_2 ... A_N
```

## 출력

답을 출력하세요.
