가로 $2$, 세로 $N$인 격자의 모든 칸이 흰색이다냥. 정확히 $K$칸을 골라 빨간색으로 칠한 뒤, 각 칸에 수를 써야 한다냥. $1$부터 $N$까지의 정수가 각각 정확히 두 번 등장하고, 왼쪽에서 $j$번째 열의 흰 칸에는 $j$가 쓰여야 한다냥. 가능한 최종 상태의 수를 $998244353$으로 나눈 나머지를 구하라냥.

## 조건

- $1\le T\le10^5$ 또는 $T\le5$
- $1\le N\le10^{18}$
- $0\le K\le\min(2N,10^{18})$

## 입력

```text
T
N_1 K_1
\vdots
N_T K_T
```

## 출력

각 테스트 케이스의 답을 한 줄에 하나씩 출력하라냥.
