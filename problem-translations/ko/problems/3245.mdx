## 이야기

Y $8$, Y $88$, Y $888$, Y $8\,888$ 화폐를 사용해 화폐 장수에 편중이 없도록 정확한 금액을 지불할 수 있나요?

yuki국에 사는 Alice가 어느 가게에서 물건을 샀더니 계산 금액이 Y $N$이 되었습니다.

Alice는 Y $8$, Y $88$, Y $888$, Y $8\,888$ 화폐를 각각 $10^{100}$장씩 가지고 있습니다.

## 문제 설명

통화 단위로 유키달러를 사용하는 yuki국에서는 $x$ 유키달러를 앞에 Y를 붙여 Y $x$로 표기합니다. 화폐는 Y $8$, Y $88$, Y $888$, Y $8\,888$의 $4$종류입니다.

돈을 지불하는 방법에 신경 쓰는 Alice는 다음 조건을 만족하도록 지불하려고 합니다.

- 정확한 금액을 지불합니다.
  - 즉, Y $8$, Y $88$, Y $888$, Y $8\,888$ 화폐를 지불한 장수를 각각 $A$, $B$, $C$, $D$라고 할 때, $8A + 88B + 888C + 8\,888D = N$을 만족합니다.
- 어떤 화폐에 대해서도 지불한 장수가 지불에 사용한 전체 장수의 절반 미만입니다.
  - 즉, $S = A + B + C + D$라고 할 때 $A, B, C, D < \dfrac{S}{2}$를 만족합니다.

위 조건을 만족하는 Y $N$의 지불 방법이 존재하는지 판정하고, 존재한다면 그중 $1$개를 구하세요.

$T$개의 테스트 케이스가 주어지므로 각각에 답하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $\mathrm{case}_i$는 $i$번째 테스트 케이스를 나타냅니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

$1$번째 줄에 테스트 케이스의 개수인 정수 $T$가 주어집니다.

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
```

각 테스트 케이스에 정수 $N$이 주어집니다.

## 제한

- 입력은 모두 정수입니다.
- $1 \leq T \leq 8.88 \times 10^4$
- $1 \leq N \leq 8.88 \times 10^{17}$

## 출력

$T$줄에 걸쳐 출력하세요. $i$번째 줄에는 $i$번째 테스트 케이스에 대해 조건을 만족하는 Y $N$의 지불 방법이 존재하지 않으면 $-1$을, 존재하면 Y $8$, Y $88$, Y $888$, Y $8\,888$ 화폐를 지불한 장수인 $A$, $B$, $C$, $D$를 공백으로 구분하여 이 순서대로 출력하세요. 답이 여러 개라면 그중 어느 것을 출력해도 정답으로 인정됩니다.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
8
984
80574336
878787878787878787
```

#### 출력

```text
-1
1 1 1 0
888 8888 888 8888
-1
```

$1$번째 테스트 케이스에서 $(A, B, C, D) = (1, 0, 0, 0)$이라는 지불 방법은 $1$번째 조건을 만족하는 유일한 지불 방법이지만, $2$번째 조건을 만족하지 않습니다. 따라서 조건을 만족하는 지불 방법은 존재하지 않습니다.

$2$번째 테스트 케이스에서 $(A, B, C, D) = (1, 1, 1, 0)$이라는 지불 방법은 $888 \times 1 + 88 \times 1 + 8 \times 1 = 984$를 만족하므로 $1$번째 조건을 만족하고, 어떤 화폐의 사용 장수도 전체 사용 장수인 $3$장의 절반 미만이므로 $2$번째 조건도 만족합니다. 따라서 이 출력은 정답입니다.
