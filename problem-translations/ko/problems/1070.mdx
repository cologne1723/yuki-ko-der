## 문제 설명

Yuki 군은 양의 정수 $A$와 $B$를 왼쪽부터 이 순서대로 작성했습니다. 하지만 두 수 사이에 공백을 넣지 않았기 때문에 하나의 양의 정수 $C$처럼 보입니다.

$C$가 주어질 때, 원래 정수 $A$, $B$로 가능한 경우의 수를 구하세요.

양의 정수로서 앞에 `0`이 오는 수는 인정하지 않습니다.

## 입력

```text
$C$
```

$C$는 양의 정수입니다.

## 제한

$10 < C < 10^{100}$

답이 반드시 $1$가지 이상 존재하는 $C$가 주어집니다.

## 출력

답을 출력하고 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="sample1.in"}

#### 입력

```text
1234
```

#### 출력

```text
3
```

`1 234`, `12 34`, `123 4`의 $3$가지가 있습니다.

### 예제 2 {file="sample2.in"}

#### 입력

```text
1010
```

#### 출력

```text
1
```

`10 10`의 $1$가지만 가능합니다.

### 예제 3 {file="sample3.in"}

#### 입력

```text
222
```

#### 출력

```text
2
```

`2 22`, `22 2`의 $2$가지가 있습니다.
