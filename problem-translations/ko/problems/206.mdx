## 문제 설명

길이 $L$인 수열 $A=\{A[0],A[1],\ldots,A[L-1]\}$와 길이 $M$인 수열 $B=\{B[0],B[1],\ldots,B[M-1]\}$가 있습니다. 두 수열은 각각 중복 원소가 없습니다. 모든 원소는 $1$ 이상 $N$ 이하의 정수입니다.

수열 $X$에 값 $Y$가 포함된다는 것은 $X$의 원소 중 하나 이상이 $Y$인 것을 뜻합니다.

수열 $B$의 모든 원소에 일률적으로 $v$를 더한 수열을 $B_v$라고 할 때, $A$와 $B_v$에 모두 포함되는 정수 값의 개수를 구하세요. $v$는 $0 \le v \le Q-1$의 범위를 가집니다.

## 입력

```text
L M N
A[0] ... A[L-1]
B[0] ... B[M-1]
Q
```

- $1 \le N \le 100{,}000$
- $1 \le L,M \le N$
- $1 \le A[i],B[i] \le N$
- $1 \le Q \le N$

추가 제한:

- subtask 1: $N \le 3000$, $Q=1$
- subtask 2: $N \le 3000$
- subtask 3: $Q=1$
- subtask 4: 추가 제한 없음

## 출력

$Q$줄을 출력합니다. $i+1$번째 줄에는 $A$와 $B_i$에 모두 포함되는 정수 값의 개수를 출력하세요.

## 예제

### 예제 1 {file=""}

```text

```

```text
2
2
1
1
1
```

각각 $B_0=\{1,2\}$, $B_1=\{2,3\}$, $B_2=\{3,4\}$, $B_3=\{4,5\}$, $B_4=\{5,6\}$입니다.


```text
4
```

```text

```

조건을 만족하는 값이 존재하지 않는 경우도 있습니다.
