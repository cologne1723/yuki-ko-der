## 문제 설명

어떤 함수 $f: N \to N$이 존재합니다. 양의 정수 $n$이 주어질 때, $f(n)$을 계산하여 출력하세요.

또한 함수의 내용이 올바른지 확인하고 싶습니다. $n$으로 $-1$이 주어지면 함수 $f(n)$의 Ruby 구현을 출력하세요. `def`와 `end`는 출력하지 않고 함수 본문만 출력하세요.

함수 $f(n)$의 본문은 Ruby 식으로 작성했을 때 공백 문자(스페이스·개행·탭)를 포함하지 않으며, $8$자 이하라는 사실이 알려져 있습니다. (`2*n-1`이나 `123+n`과 같은 형태입니다.)

또한 $f(n)$의 본문, 즉 $n=-1$일 때 출력하는 것의 개행을 제외한 문자열의 MD5 해시는 `6ab55fc60c925306aa812f3763fbc1b7`입니다.

**주의! 이 문제는 특수한 문제입니다. 문제문이나 테스트 케이스만으로 답을 $1$개로 결정할 수 없습니다. 열심히 추측하세요.**

**주의! 이 문제를 풀려면 Ruby 처리 환경과 Ruby 지식이 필요합니다.**

## 입력

```text
$n$
```

입력으로 정수 $n$이 주어집니다.

## 제한

- $1 \le n \le 10$ 또는 $n=-1$

## 출력

$n$이 양의 정수이면 $f(n)$을 출력하세요.

$n=-1$이면 함수 $f(n)$의 Ruby 구현을 출력하세요. `def`와 `end`는 출력하지 않고 함수 본문만 출력하세요.

마지막에 줄바꿈 문자를 출력하세요.
