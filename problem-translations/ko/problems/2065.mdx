각 질의에 대해 $\sum_{k=L_i}^{R_i}\min(X_i,A_k)$를 구하세요.

## 입력

```text
N Q
A_1 A_2 ... A_N
L_1 R_1 X_1
...
L_Q R_Q X_Q
```

$1\le N,Q\le10^5$, $1\le A_k,X_i\le10^9$입니다.

## 출력

각 질의의 값을 한 줄에 출력하세요.
