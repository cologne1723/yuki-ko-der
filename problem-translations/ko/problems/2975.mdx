**이 문제의 실행 시간 제한은 $10\,000$ms입니다.**

## 문제 설명

$M \leq N$을 만족하는 $2$개의 양의 정수 $N$, $M$과 소수 $P$가 주어집니다.

먼저 표기와 용어를 정의하겠습니다. 양의 정수열 $A$에 대해 $A$의 원소의 총곱을 $\Pi(A)$로 정의합니다.

$N$ 이하의 서로 다른 양의 정수 $M$개로 이루어진 순열을 $(N,M)$ 순열이라고 합니다.

$(N,M)$ 순열 $A$에 대해, $A$의 비어 있지 않은 모든 엄격 증가 부분수열 $a$에 대한 $\Pi(a)$의 합을 $f(A)$로 정의합니다. 이때 부분수열은 연속할 필요가 없습니다.

$(N,M)$ 순열은 모두 ${}_N P_M = \frac{N!}{(N-M)!}$개입니다. 이들 중에서 $(N,M)$ 순열 $A$를 무작위로, 즉 각각이 선택될 확률이 같도록 선택했을 때 $f(A)$의 기댓값을 법 $P$에서 나타낸 값을 구하세요.

여기서 유리수 $x$의 법 $P$에서의 값이란 다음 $2$가지 조건을 만족하는 유일한 정수 $r$을 뜻합니다.

- $0 \leq r < P$입니다.
- $x$를 기약분수로 나타낸 것을 $\frac{n}{d}$라고 할 때, $d$는 양의 정수이고 $n$은 $d$와 서로소인 정수이며 $n \equiv dr \pmod{P}$입니다.

단, 이러한 $r$이 존재하기 위한 필요충분조건은 위의 $d$와 $P$가 서로소인 것입니다. 또한 정수 $\ell$과 $m$이 서로소라는 것은 $\ell$과 $m$을 모두 나누는 양의 정수가 $1$뿐이라는 뜻입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 $1$줄로 주어집니다.

```text
$N\ M\ P$
```

$1$번째 줄에 $N$, $M$, $P$가 공백으로 구분되어 주어집니다.

## 제한

입력은 다음 제한을 만족합니다.

- $N$은 $1 \leq N \leq 9\,600$을 만족하는 정수입니다.
- $M$은 $1 \leq M \leq N$을 만족하는 정수입니다.
- $P$는 $N < P \leq 10^9$를 만족하는 소수입니다.

## 출력

$f(A)$의 기댓값을 법 $P$에서 나타낸 값이 유일하게 존재한다면, 그 값을 $1$줄에 출력하세요.

그렇지 않다면 $-1$을 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1 2
```

#### 출력

```text
1
```

$(N,M) = (1,1)$이고 $(N,M)$ 순열 $A$는 $(1)$뿐입니다. $(1)$의 비어 있지 않은 엄격 증가 부분수열은 $(1)$뿐이며, $\Pi((1)) = 1$이므로 $f((1)) = 1$입니다.

따라서 $f(A)$는 확률 $1$로 $1$의 값을 가지며, $f(A)$의 기댓값은 $1$입니다. 그리고 $1$을 법 $P = 2$에서 나타낸 값은 $1$입니다.

### 예제 2 {file=""}

#### 입력

```text
2 1 3
```

#### 출력

```text
0
```

$(N,M) = (2,1)$이고 $(N,M)$ 순열 $A$는 $(1)$과 $(2)$의 $2$가지입니다. 예제 $1$에서 본 것처럼 $f((1)) = 1$입니다. $(2)$의 비어 있지 않은 엄격 증가 부분수열은 $(2)$뿐이며, $\Pi((2)) = 2$이므로 $f((2)) = 2$입니다.

따라서 $f(A)$는 확률 $2^{-1}$로 $1$의 값을 가지고, 확률 $2^{-1}$로 $2$의 값을 가집니다. 그러므로 $f(A)$의 기댓값은 $2^{-1} \times 1 + 2^{-1} \times 2 = 2^{-1} 3$입니다. 그리고 $2^{-1} 3$을 법 $P = 3$에서 나타낸 값은 $0$입니다.

### 예제 3 {file=""}

#### 입력

```text
2 2 5
```

#### 출력

```text
4
```

$(N,M) = (2,2)$이고 $(N,M)$ 순열 $A$는 $(1,2)$와 $(2,1)$의 $2$가지입니다. $(1,2)$의 비어 있지 않은 엄격 증가 부분수열은 $(1)$, $(2)$, $(1,2)$의 $3$가지이고, 각 부분수열의 원소의 총곱은 각각 $1$, $2$, $2$이므로 $f((1,2)) = 1+2+2 = 5$입니다. $(2,1)$의 비어 있지 않은 엄격 증가 부분수열은 $(1)$과 $(2)$의 $2$가지이고, 각 부분수열의 원소의 총곱은 각각 $1$, $2$이므로 $f((2,1)) = 1+2 = 3$입니다.

따라서 $f(A)$는 확률 $2^{-1}$로 $5$의 값을 가지고, 확률 $2^{-1}$로 $3$의 값을 가집니다. 그러므로 $f(A)$의 기댓값은 $2^{-1} \times 5 + 2^{-1} \times 3 = 4$입니다. 그리고 $4$를 법 $P = 5$에서 나타낸 값은 $4$입니다.
