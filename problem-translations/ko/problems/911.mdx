## 문제 설명

길이가 $N$인 수열 $A$가 있으며, 모든 원소는 서로 다릅니다.

다음 연산을 정확히 $1$번 수행합니다.

1. $L$ 이상 $R$ 이하인 정수 $x$를 고릅니다.
2. 수열의 각 원소 $A_i$를 $A_i\ \mathrm{XOR}\ x$로 바꿉니다.

$\mathrm{XOR}$는 [비트 단위 배타적 논리합](https://ja.wikipedia.org/wiki/%E6%8E%92%E4%BB%96%E7%9A%84%E8%AB%96%E7%90%86%E5%92%8C#%E3%83%93%E3%83%83%E3%83%88%E3%81%94%E3%81%A8%E3%81%AE%E6%8E%92%E4%BB%96%E7%9A%84%E8%AB%96%E7%90%86%E5%92%8C)을 나타냅니다.

연산 후 수열이 엄격히 증가하게 만드는 $x$의 개수를 구하세요.
여기서 엄격히 증가한다는 것은 모든 $i$에 대해 $A_i < A_{i+1}$이 성립한다는 뜻입니다. $1 \le i < N$입니다.

## 입력

```text
$N\ L\ R$
$A_1\ A_2\ \cdots\ A_N$
```

입력은 모두 정수입니다.

## 제한

- $1 \le N \le 2 \times 10^5$
- $0 \le L \le R < 2^{61}$
- $0 \le A_i < 2^{61}$이며 $1 \le i \le N$입니다.
- $i \ne j$이면 $A_i \ne A_j$입니다. $1 \le i, j \le N$입니다.

## 출력

답을 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
6 1325 1350
1332 1335 1334 1329 1328 1331
```

#### 출력

```text
4
```

예를 들어 $x = 1\,333$으로 고르면 연산 후 수열은 $\{1, 2, 3, 4, 5, 6\}$이 되며, 이 수열은 엄격히 증가합니다.

반면 $x = 1\,334$로 고르면 연산 후 수열은 $\{2, 1, 0, 7, 6, 5\}$가 되며, 이 수열은 엄격히 증가하지 않습니다.

### 예제 2 {file=""}

#### 입력

```text
4 100 500
1 7 41 23
```

#### 출력

```text
0
```

수열이 엄격히 증가하게 만드는 $x$가 하나도 없을 수도 있습니다.

### 예제 3 {file=""}

#### 입력

```text
1 0 10000
1
```

#### 출력

```text
10001
```
