## 문제

$N$ 이하의 서로 다른 세 소수의 조합 $(a,b,c)\ (2\leq a\lt b\lt c\leq N)$ 중 $a+b+c$가 소수인 것은 몇 개인가요?

## 입력

~~~text
$N$
~~~

$5\leq N\leq100000$입니다.

## 출력

조건을 만족하는 소수 조합 $(a,b,c)$의 개수를 출력하세요. 마지막에는 줄바꿈을 추가하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
11
~~~

#### 출력

~~~text
2
~~~

11 이하의 소수는 2, 3, 5, 7, 11이므로 조합은 10개입니다. 그중 $3+5+11=19$, $5+7+11=23$인 2개가 조건을 만족합니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
1000
~~~

#### 출력

~~~text
241580
~~~

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
10000
~~~

#### 출력

~~~text
74588542
~~~

### 샘플 4 {file="sample4.in"}

#### 입력

~~~text
100000
~~~

#### 출력

~~~text
28694800655
~~~

답은 32비트 정수에 들어가지 않을 수 있습니다. 예상 풀이가 PyPy3에서 간신히 통과하므로 더 빠른 언어를 권장합니다.
