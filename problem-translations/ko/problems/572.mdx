## 문제

요정이 악보에 따라 연주합니다.

음표가 하나씩 놓인 악보에서 어떤 음 다음에 특정 음을 연주하면 일정한 점수를 얻습니다.

악보에 적을 음표 수 n, 음의 종류 수 m, 어떤 음 다음에 어떤 음을 연주했을 때 얻는 점수의 표가 주어집니다.

이 데이터로 가능한 최고 점수의 악보를 작성했을 때 점수를 구하세요. 악보 평가는 점수의 단순한 합입니다.

요정은 같은 음이 연속되는 것을 싫어하므로 같은 음을 연속해 연주할 수 없습니다.

## 입력

```text
n
m
A11 … A1m
…
Am1 … Amm
```

1 ≤ n ≤ 5 × 10^9

2 ≤ m ≤ 30

0 < Ai,j ≤ 100

Ai,j는 i번째 음 뒤에 j번째 음을 연주하면 Ai,j점이 추가된다는 뜻입니다. 같은 음을 연속할 수 없으므로 Ai,i=0입니다.

Ai,j는 정수라고 가정해도 됩니다.

## 출력

가능한 최고 점수를 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.
