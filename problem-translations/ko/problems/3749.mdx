## 문제 설명

변수 $a_1,a_2,a_3$가 있으며, 처음에는 $(a_1,a_2,a_3)=(B_1,B_2,B_3)$입니다. 다음 연산을 원하는 횟수만큼 할 수 있습니다.

- 서로 다른 정수 $i,j\in\{1,2,3\}$를 고릅니다. $a_i,a_j$를 동시에 각각 $a_i-\min(a_i,A_j-a_j)$, $a_j+\min(a_i,A_j-a_j)$로 바꿉니다.

목표는 $(a_1,a_2,a_3)=(C_1,C_2,C_3)$으로 만드는 것입니다. 가능한지 판별하고, 가능하면 필요한 최소 연산 횟수를 구하세요.

테스트 케이스는 총 $T$개입니다.

## 입력

다음 형식으로 입력이 주어집니다. $\text{case}_i$는 $i$번째 테스트 케이스입니다.

```text
$T$
$\text{case}_1$
$\text{case}_2$
$\vdots$
$\text{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$A_1 \ A_2 \ A_3$
$B_1 \ B_2 \ B_3$
$C_1 \ C_2 \ C_3$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $1\le T\le 10^4$
- $A_i\ge 1$
- $A_1+A_2+A_3\le 10^{18}$
- $0\le B_i,C_i\le A_i$
- $B_1+B_2+B_3=C_1+C_2+C_3$

## 출력

$T$줄을 출력하세요. $i$번째 줄에는 $\text{case}_i$에서 목표를 달성할 수 없으면 $-1$을, 가능하면 필요한 최소 연산 횟수를 출력하세요.

```text

```

첫 번째 테스트 케이스에서는 다음 두 번의 연산으로 목표를 달성할 수 있습니다.

- $i=1,j=2$로 연산하면 $(a_1,a_2,a_3)=(1,2,0)$입니다.
- $i=2,j=3$으로 연산하면 $(a_1,a_2,a_3)=(1,1,1)$입니다.

한 번 이하의 연산으로는 목표를 달성할 수 없으므로 답은 $2$입니다.
