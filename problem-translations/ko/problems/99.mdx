## 문제 설명

1차원 수직선의 정수 좌표에 말이 $N$개 있습니다.

각 말의 초기 좌표 $X_1,X_2,\ldots,X_N$은 서로 다릅니다.

한 번의 조작으로 말 $1$개를 움직일 수 있습니다. 현재 좌표가 $x$라면 $x+2$ 또는 $x-2$로 이동할 수 있습니다.

단, 이동할 위치에 이미 말이 있으면 이동할 수 없습니다. 또한 이동하면서 말을 뛰어넘으면, 이동한 말과 그 말이 뛰어넘은 말이 모두 사라집니다.

말의 수를 최소화하고 싶습니다. 조작은 몇 번이든 할 수 있을 때, 마지막까지 남는 말의 수의 최솟값을 구하세요.

## 입력

```text
$N$
$X_1\ X_2\ \dots\ X_N$
```

정수 $N$은 말의 수입니다. 다음 줄에는 각 말의 초기 정수 좌표 $X_1,\dots,X_N$이 공백으로 구분되어 주어집니다.

## 제한

- $1 \le N \le 100\,000$
- $-1\,000\,000\,000 \le X_k \le 1\,000\,000\,000$ $(1 \le k \le N)$

## 출력

남는 말의 수의 최솟값을 한 줄에 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
1 2 4 3
```

#### 출력

```text
0
```

좌표 $2$의 말이 좌표 $1$의 말을 뛰어넘고, 이어서 좌표 $4$의 말이 좌표 $3$의 말을 뛰어넘으면 모든 말이 사라집니다.

### 예제 2 {file=""}

#### 입력

```text
10
-746 0 11 98 1 14 998 123 837 15
```

#### 출력

```text
0
```

잘 조작하면 모든 말을 없앨 수 있습니다.

### 예제 3 {file=""}

#### 입력

```text
5
1000000000 -1000000000 0 987654321 -123456789
```

#### 출력

```text
1
```

말이 사라질 때는 $2$개씩 사라지므로 마지막에 말 $1$개는 반드시 남습니다. 또한 말 $4$개를 없앨 수 있습니다.
