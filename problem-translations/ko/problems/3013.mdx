## 이야기

岩井星人さん은 머리띠를 더 사기 위해 고향인 ~~오사카부~~ **岩井星**로 돌아왔습니다.

## 문제 설명

처음에 岩井星人さん은 $Y$엔을 가지고 있습니다.

岩井星에는 $N$개의 도시가 있고, 각각 $1, 2, \ldots, N$의 번호가 붙어 있습니다. 현재 岩井星人さん은 공항이 있는 **도시 $1$에** 있습니다.

또한 岩井星에는 도시와 도시를 연결하는 $M$개의 도로가 있습니다.

$i$번째 도로는 도시 $A_i$와 도시 $B_i$를 양방향으로 연결하며, 이동하는 동안 나쁜 사람에게 $C_i$엔을 빼앗깁니다. 소지금이 $X$엔인 상태에서 돈을 빼앗기면 소지금은 $\max(X - C_i, 0)$엔이 됩니다.

또한 岩井星에는 $P$개의 가게가 있습니다. $i$번째 가게는 도시 $D_i$에 있으며, 머리띠를 $1$개당 $E_i$엔에 판매합니다. 가게에서는 소지금 한도 내에서 머리띠를 $0$개 이상 원하는 만큼 살 수 있습니다. 단, $1$개의 도시에 있는 가게는 최대 $1$개입니다.

이때 岩井星人さん은 도시 $1$에서 출발하여 머리띠를 최대 몇 개 살 수 있는지 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ M\ P\ Y$
$A_1\ B_1\ C_1$
$A_2\ B_2\ C_2$
$\vdots$
$A_M\ B_M\ C_M$
$D_1\ E_1$
$D_2\ E_2$
$\vdots$
$D_P\ E_P$
```

$1$번째 줄에 도시의 수 $N$, 도로의 수 $M$, 가게의 수 $P$, 처음 소지금 $Y$가 주어집니다.

다음 $M$개의 줄에 각 도로가 연결하는 도시 $A_i$, $B_i$와 이동 중 빼앗기는 금액 $C_i$가 주어집니다.

그다음 $P$개의 줄에 가게가 있는 도시 $D_i$와 머리띠 $1$개당 가격 $E_i$가 주어집니다.

## 제한

- $2 \leq N \leq 2 \times 10^5$
- $1 \leq M \leq \min\left(2 \times 10^5, \dfrac{N(N-1)}{2}\right)$
- $1 \leq A_i < B_i \leq N\ (1 \leq i \leq M)$
- $(A_i, B_i) \neq (A_j, B_j)\ (1 \leq i < j \leq M)$
- $1 \leq C_i \leq 10^9\ (1 \leq i \leq M)$
- $1 \leq P \leq N$
- $1 \leq D_i \leq N\ (1 \leq i \leq P)$
- $D_i \neq D_j\ (1 \leq i < j \leq P)$
- $1 \leq E_i \leq 10^9\ (1 \leq i \leq P)$
- $1 \leq Y \leq 10^{18}$
- 입력은 모두 정수입니다.

## 출력

岩井星人さん이 살 수 있는 머리띠의 최대 개수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 3 2 19
1 3 4
2 3 1
1 2 5
2 5
3 4
```

#### 출력

```text
3
```

처음에 岩井星人さん은 $19$엔을 가지고 있습니다.

도시 $1$에서 도시 $2$로 이동할 때 $5$엔을 빼앗긴 뒤, 도시 $2$에서 머리띠를 $1$개 삽니다. 그곳에서 $1$엔을 빼앗기면서 도시 $3$으로 이동하고 머리띠를 $2$개 사면, 합계 $3$개를 살 수 있으므로 $3$을 출력합니다.
