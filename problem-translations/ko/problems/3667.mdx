이 문제는 X/BlueSky/Discord에서 공개된 적이 있는 문제입니다.

## 문제 설명

$N$개의 영소문자로 이루어진 문자열 $A_1, A_2, \dots, A_N$이 주어집니다.

또한, 현재 빈 문자열인 문자열 $S$가 있습니다.

다음 $Q$개의 질의를 주어진 순서대로 처리하세요.

- $1\ x$: 문자열 $S$의 끝에 영소문자 $x$를 $1$개 추가합니다.
- $2$: 문자열 $S$의 끝 문자를 $1$개 삭제합니다.
- $3$: $A_1, \dots, A_N$ 중 현재의 $S$를 접두사로 갖는 문자열의 개수를 출력합니다.

$S$가 비어 있을 때는 $N$개의 문자열 모두가 $S$를 접두사로 갖는다는 점에 유의하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$A_1$
$A_2$
$\vdots$
$A_N$
$Q$
$\text{query}_1$
$\text{query}_2$
$\vdots$
$\text{query}_Q$
```

각 $\text{query}_i$는 다음 형식 중 $1$개입니다.

```text
$1\ x$
```

```text
$2$
```

```text
$3$
```

## 제한

- $1 \le N, Q \le 2 \times 10^5$
- $A_i$는 영소문자로 이루어진 길이 $1$ 이상의 문자열입니다.
- 모든 $A_i$의 길이의 합은 $2 \times 10^5$ 이하입니다.
- 질의 $1$의 $x$는 $1$개의 영소문자입니다.
- 질의 $2$를 처리할 때 $S$는 비어 있지 않습니다.
- 질의 $3$은 각 테스트 케이스에 $1$개 이상 존재합니다.
- $N$, $Q$는 정수입니다.

## 출력

질의 $3$의 개수를 $k$라고 할 때, $k$줄을 출력하세요.

$i$번째 줄에는 $i$번째 질의 $3$에 대한 답, 즉 현재의 $S$를 접두사로 갖는 문자열의 개수를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
apple
api
application
8
1 a
1 p
3
1 p
3
2
1 i
3
```

#### 출력

```text
3
2
1
```

처음에 $S$는 빈 문자열입니다.

- $1$번째 질의 `1 a`에서 $S$는 `a`가 됩니다.
- $2$번째 질의 `1 p`에서 $S$는 `ap`가 됩니다.
- $3$번째 질의 `3`에서는 `ap`를 접두사로 갖는 문자열이 `apple`, `api`, `application`의 $3$개이므로 $3$을 출력합니다.
- $4$번째 질의 `1 p`에서 $S$는 `app`이 됩니다.
- $5$번째 질의 `3`에서는 `app`을 접두사로 갖는 문자열이 `apple`, `application`의 $2$개이므로 $2$를 출력합니다.
- $6$번째 질의 `2`에서 끝 문자가 삭제되어 $S$는 다시 `ap`가 됩니다.
- $7$번째 질의 `1 i`에서 $S$는 `api`가 됩니다.
- $8$번째 질의 `3`에서는 `api`를 접두사로 갖는 문자열이 `api` $1$개뿐이므로 $1$을 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
2
cat
dog
5
3
1 c
1 o
3
2
```

#### 출력

```text
2
0
```

- $1$번째 질의 `3`에서는 $S$가 빈 문자열입니다. 모든 문자열이 빈 문자열을 접두사로 가지므로 $N$과 같은 $2$를 출력합니다.
- 그 후 $S$는 `c` $\to$ `co`로 변합니다.
- $4$번째 질의 `3`에서는 `co`를 접두사로 갖는 문자열이 존재하지 않으므로 $0$을 출력합니다.

### 예제 3 {file=""}

#### 입력

```text
3
abc
abc
a
4
1 a
3
1 b
3
```

#### 출력

```text
3
2
```

$A$에는 같은 문자열이 여러 개 포함될 수도 있습니다.

$S$가 `ab`일 때, `abc`($1$번째)와 `abc`($2$번째)가 조건을 만족합니다.

### 예제 4 {file=""}

#### 입력

```text
4
a
aa
aaa
aaaa
7
1 a
1 a
1 a
3
2
3
2
```

#### 출력

```text
2
3
```

- $4$번째 질의를 처리할 때 $S$는 `aaa`이고, 이를 접두사로 갖는 문자열은 `aaa`, `aaaa`의 $2$개입니다.
- $6$번째 질의를 처리할 때 $S$는 `aa`이고, 이를 접두사로 갖는 문자열은 `aa`, `aaa`, `aaaa`의 $3$개입니다.

### 예제 5 {file=""}

#### 입력

```text
1
z
6
1 z
3
1 z
3
2
3
```

#### 출력

```text
1
0
1
```

- $S$가 `z`일 때, `z`를 접두사로 갖는 문자열은 `z` $1$개입니다.
- $S$가 `zz`일 때, $S$를 접두사로 갖는 문자열은 존재하지 않으므로 $0$을 출력합니다. $S$의 길이가 $A_i$의 길이를 초과할 수도 있습니다.
- 그 후 끝 문자가 삭제되어 $S$가 다시 `z`가 되고, 답은 $1$이 됩니다.
