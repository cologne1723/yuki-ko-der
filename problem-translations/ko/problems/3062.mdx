## 문제 설명

高橋君은 수열 $A=(A_0,A_1,\dots,A_{N-1})$와 $(1,2,\dots,N)$의 순열 $P=(P_0,P_1,\dots,P_{N-1})$을 가지고 있습니다. 처음에 $A$의 모든 원소는 $0$입니다.

高橋君은 다음 연산을 $1$회 이상 수행했습니다.

- 정수 $k$($0\leq k\leq N-1$)를 선택하고, 모든 $i=0,1,\dots,N-1$에 대하여 $A_i$를 $\max(A_i,P_{(i-k)\mathbin{\bmod} N})$으로 바꿉니다.

연산 후의 수열 $A$가 주어집니다. 순열 $P$로 가능할 수 있는 것의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

```text
$N$
$A_0\ A_1\ \dots\ A_{N-1}$
```

입력은 다음 제한을 만족합니다.

## 제한

- 입력은 모두 정수입니다.
- $2\leq N\leq 3\,000$
- $1\leq A_i\leq N$ ($0\leq i\leq N-1$)

## 출력

순열 $P$로 가능할 수 있는 것의 개수를 $998\,244\,353$으로 나눈 나머지를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
2 3 3
```

#### 출력

```text
6
```

예를 들어 $P=(2,3,1)$인 경우를 생각해 봅시다.

高橋君이 다음 순서로 연산을 수행하면 수열 $A$가 입력과 같아집니다.

1. $k=0$을 선택합니다. $A=(\max(0,2),\max(0,3),\max(0,1))=(2,3,1)$이 됩니다.
2. $k=1$을 선택합니다. $A=(\max(2,1),\max(3,2),\max(1,3))=(2,3,3)$이 됩니다.

$P$가 $(1,2,3)$의 어떤 순열이더라도 $A=(2,3,3)$이 될 가능성이 있습니다.

### 예제 2 {file=""}

#### 입력

```text
3
1 3 3
```

#### 출력

```text
0
```

순열 $P$로 가능할 수 있는 것이 존재하지 않을 수도 있습니다.


#### 출력
