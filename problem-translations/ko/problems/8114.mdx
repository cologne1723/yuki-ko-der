## 문제 설명

$2$ 이상인 정수 $N$이 주어집니다. 다음 $2$가지 판정 중 $1$가지를 선택하여 실제로 수행하세요.

- $1$번째 판정: $N$이 소수인지 판정합니다.
- $2$번째 판정: $N+1$이 소수인지 판정합니다.

## 입력

```text
$N$
```

## 제한

- $2\le N \le 10^{100\,000}$
- $N$은 정수입니다.

## 출력

$1$번째 판정을 선택한 경우 $1$번째 줄에 $0$을, $2$번째 판정을 선택한 경우 $1$번째 줄에 $1$을 출력하세요.

그다음 판정하는 수가 소수라면 $2$번째 줄에 `Yes`를, 소수가 아니라면 `No`를 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
10
```

#### 출력

```text
1
Yes
```

$10+1$인 $11$은 소수입니다. $1$번째 판정을 선택해 $10$을 소수가 아니라고 판정해도 됩니다.

### 예제 2 {file=""}

#### 입력

```text
2222222222222222222222222222222222222222222222222222222222222
```

#### 출력

```text
0
No
```

$N$이 매우 커질 수 있다는 점에 주의하세요.
