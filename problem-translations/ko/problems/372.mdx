## 주의

예상 풀이는 C++로 구현되어 최악의 경우 $1$〜$2$초 정도 걸립니다(제한 시간은 $6$초). 다른 언어로 구현하면 시간 초과 가능성이 높습니다. Java는 $3\,667$ms이고, 테스터 풀이의 Python(PyPy)은 TLE입니다.

## 문제 설명

문자 `0`부터 `9`로 이루어진 문자열 $S$와 양의 정수 $M$이 주어집니다. $1$개 이상의 문자를 고른 부분 수열 중, $10$진수로 해석했을 때 $M$의 배수가 되는 것의 개수를 $1\,000\,000\,007=10^9+7$로 나눈 나머지로 출력하세요.

문자열 $S$의 부분 수열은 $1\le a_1<a_2<\cdots<a_k\le|S|$인 $(a_i)_i$를 사용해 $S[a_1]S[a_2]\cdots S[a_k]$로 나타내는 문자열입니다($S[i]$는 $S$의 $i$번째 문자). 위치가 달라 문자열 자체는 같은 부분 수열은 서로 다른 것으로 셉니다. 예를 들어 $S=$`110`이면 $1$번째·$3$번째 문자로 만든 `10`과 $2$번째·$3$번째 문자로 만든 `10`은 별개입니다.

부분 수열의 길이가 $2$ 이상이면 `0`으로 시작하는 것은 세지 않습니다. 예를 들어 $S=$`02`, $M=2$일 때 `02`는 $2$의 배수로 세지 않습니다.

## 입력

```text
$S$
$M$
```

$1$번째 줄에 문자열 $S$, $2$번째 줄에 양의 정수 $M$이 주어집니다.

## 제한

- $1\le|S|\le10\,000$
- $1\le M\le20\,000$
- $S$의 각 문자는 `0`〜`9`입니다.
- 파일명이 `testcase-small1-`로 시작하는 샘플은 $1\le|S|\le16$, $1\le M\le1\,000$입니다.
- 파일명이 `testcase-small2-`로 시작하는 샘플은 $1\le|S|\le10\,000$, $1\le M\le1\,000$입니다.

## 출력

결과를 출력하세요. 마지막에 개행하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
012
3
```

#### 출력

```text
2
```

`0`, `12`의 $2$종류입니다. `012`는 `0`으로 시작하고 길이가 $2$ 이상이므로 세지 않습니다.

### 예제 2 {file=""}

#### 입력

```text
220
2
```

#### 출력

```text
7
```

$1$번째 문자의 `2`, $2$번째 문자의 `2`, `0`, `22`, $1$·$3$번째 문자의 `20`, $2$·$3$번째 문자의 `20`, `220`으로 총 $7$종류입니다.

### 예제 3 {file=""}

#### 입력

```text
123456789123456789
1
```

#### 출력

```text
262143
```

$262\,143=2^{18}-1$입니다.
