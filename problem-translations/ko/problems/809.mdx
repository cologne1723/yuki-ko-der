## 문제

양의 정수 $A,B,C$가 있고 $A\times B=C$입니다. $C$가 주어질 때 $A$와 $B$를 출력하세요. 답이 여러 개면 하나만 출력해도 됩니다.

## 입력

~~~text
$C$
~~~

$1\leq C\leq1000000000=10^9$인 양의 정수입니다.

## 출력

$A$와 $B$를 한 줄에 공백 하나로 구분해 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
6
~~~

#### 출력

~~~text
2 3
~~~

2×3=6입니다.
