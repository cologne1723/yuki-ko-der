## 문제 설명

$5\,000\,000\,000\,000\,000$개의 변수 $x_1, x_2, \dots, x_{5\,000\,000\,000\,000\,000}$이 있습니다. 각 변수 $x_1, x_2, \dots, x_{5\,000\,000\,000\,000\,000}$에 참 또는 거짓을 각각 할당하여 논리식 $f(x_1, x_2, \dots, x_{5\,000\,000\,000\,000\,000})$을 참으로 만들 수 있는지 판정하세요.

단, $f(x_1, x_2, \dots, x_{5\,000\,000\,000\,000\,000})$는 다음과 같이 정의됩니다.

$\displaystyle f(x_1, x_2, \dots, x_{5\,000\,000\,000\,000\,000}) := \bigwedge_{i=1}^{N} (x_{a_i} \vee x_{a_i +1} \vee \cdots \vee x_{b_i})$

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$a_1\ b_1$
$\vdots$
$a_N\ b_N$
```

$N$은 구간의 개수입니다. $i$번째 구간의 $a_i$와 $b_i$는 $i$번째 항 $(x_{a_i} \vee \cdots \vee x_{b_i})$에 사용되는 구간의 양 끝점입니다.

## 제한

- $1 \leq N \leq 10^5$
- $1 \leq a_i \leq b_i \leq 5\,000\,000\,000\,000\,000$

## 출력

조건을 만족하는 할당이 존재하면 `Yes`를, 존재하지 않으면 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
1 1
2 2
```

#### 출력

```text
Yes
```

$f(x_1, x_2, \dots, x_{5\,000\,000\,000\,000\,000}) = x_1 \wedge x_2$이므로, $x_1 = x_2 = 1$이기만 하면 됩니다.
