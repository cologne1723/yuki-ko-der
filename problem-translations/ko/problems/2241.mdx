변수 $m=N$에서 시작해 $m=1$로 만들자냥. 한 번의 조작으로 $m$을 나눌 수 있는 최대한의 $2^k$로 나누거나, 양의 정수 $k$를 골라 $m\leftarrow mk+1$로 바꿀 수 있다냥. 필요한 최소 조작 횟수를 구하라냥.

## 조건

- $2\le N\le10^9$

## 입력

```text
N
```

## 출력

최소 조작 횟수를 출력하라냥.
