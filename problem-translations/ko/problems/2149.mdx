넓은 의미로 단조 증가하는 양의 정수열 $A_1,A_2,\ldots,A_N$이 주어진다냥. $A_i\ge2$인 원소 하나에서 2를 빼거나, $A_i=A_{i+1}\ge1$인 인접한 두 원소에서 각각 1을 빼는 조작을 할 수 있다냥. 조작 후에도 수열은 넓은 의미로 단조 증가해야 한다냥. 더 이상 조작할 수 없을 때까지 반복하여 모든 원소를 0으로 만드는 조작 방법의 수를 구하라냥.

## 조건

- $1\le N\le1000$
- $1\le A_1\le A_2\le\cdots\le A_N\le1000$

## 입력

```text
N
A_1 A_2 \cdots A_N
```

## 출력

조작 방법의 수를 $998244353$으로 나눈 나머지를 출력하라냥.
