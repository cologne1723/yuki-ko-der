## 문제 설명

$(1,2,\ldots,N)$의 순열 $(P_1,P_2,\ldots,P_N)$이 주어집니다. 좌표평면 위에 $N$개의 점 $(i,P_i)$를 배치합니다.

$2$개의 점 $A=(a_1,a_2)$, $B=(b_1,b_2)$가 $a_1<b_1$이고 $a_2<b_2$를 만족할 때, $B$는 $A$의 그림자에 있다고 합니다.

다음 작업을 수행하세요.

1. 현재 평면 위에 있는 점 중 어떤 점의 그림자에도 있지 않은 점들의 집합을 $S$라고 합니다.
2. $S$에 속한 점들의 $x$좌표 최솟값과 $y$좌표 최솟값을 출력합니다.
3. 평면에서 $S$에 속한 점들을 삭제합니다.
4. 평면 위에 점이 없다면 종료하고, 그렇지 않으면 1.로 돌아갑니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$P_1\ P_2\ \cdots\ P_N$
```

$1$번째 줄에 순열의 크기 $N$이 주어집니다.

$2$번째 줄에 순열 $(P_1,P_2,\ldots,P_N)$이 주어집니다.

## 제한

- $1\leq N\leq 2\times 10^5$
- $(P_1,P_2,\ldots,P_N)$은 $(1,2,\ldots,N)$의 순열입니다.
- 입력은 모두 정수입니다.

## 출력

출력 횟수를 $M$이라 하고, $i$번째 출력에서 $x$좌표 최솟값과 $y$좌표 최솟값을 각각 $x_i$, $y_i$라고 합니다. 다음 형식으로 출력하세요.

```text
$x_1\ y_1$
$x_2\ y_2$
$\vdots$
$x_M\ y_M$
```

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
5
2 4 3 1 5
```

#### 출력

```text
1 1
2 3
5 5
```

점 $(1,2)$, $(2,4)$, $(3,3)$, $(4,1)$, $(5,5)$를 배치합니다. 어떤 점의 그림자에도 있지 않은 점들의 집합은 $S=\{(1,2),(4,1)\}$이므로 `1 1`을 출력합니다.

$S$에 속한 점들을 삭제하면 남는 점은 $(2,4)$, $(3,3)$, $(5,5)$입니다. 이때 $S=\{(2,4),(3,3)\}$이므로 `2 3`을 출력합니다.

다시 $S$에 속한 점들을 삭제하면 $(5,5)$만 남으므로 `5 5`를 출력합니다.

그 후 평면 위에 점이 없어지므로 종료합니다.
