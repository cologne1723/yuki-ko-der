## 문제 설명

양의 정수 $N$, $Q$와 모든 원소가 $0$ 또는 $1$인 길이 $N$의 수열 $A=(A_1,A_2,\ldots,A_N)$가 주어집니다.

$i=1,2,\ldots,Q$에 대해 다음 연산을 수행합니다.

- $L_i$, $R_i$가 주어지므로 $A_{L_i},A_{L_i+1},\ldots,A_{R_i}$를 뒤집습니다.

모든 연산을 수행한 후의 $A$를 출력하세요.

단, $x$를 뒤집는다는 것은 $x=0$이면 $x=1$로, $x=1$이면 $x=0$으로 바꾸는 것을 의미합니다.

또한 이 제약에서 $x\neq0$이고 $x\neq1$인 $x$를 뒤집는 경우는 없습니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ Q$
$A_1\ A_2\ \ldots\ A_N$
$L_1\ R_1$
$L_2\ R_2$
$\vdots$
$L_Q\ R_Q$
```

입력은 모두 정수입니다.

## 제한

- $1\leq N,Q\leq5\times10^5$
- $A_i=0$ 또는 $A_i=1$
- $1\leq L_i\leq R_i\leq N$
- 입력은 모두 정수입니다.

## 출력

모든 연산을 수행한 후의 $A$를 다음 형식으로 출력하고, 마지막에 줄바꿈을 출력하세요.

```text
$A_1\ A_2\ \ldots\ A_N$
```

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 3
0 0 0 0 0
1 5
2 4
3 3
```

#### 출력

```text
1 0 1 0 1
```

처음에 $A=(0,0,0,0,0)$입니다.

$1$번째 쿼리에서는 $A_1,A_2,A_3,A_4,A_5$를 뒤집어 $A=(1,1,1,1,1)$이 됩니다.

$2$번째 쿼리에서는 $A_2,A_3,A_4$를 뒤집어 $A=(1,0,0,0,1)$이 됩니다.

$3$번째 쿼리에서는 $A_3$을 뒤집어 $A=(1,0,1,0,1)$이 됩니다.

따라서 모든 연산을 수행한 후 $A=(1,0,1,0,1)$이 되므로 이를 출력합니다.
