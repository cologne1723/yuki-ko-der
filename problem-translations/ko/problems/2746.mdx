## 문제

빨간 블록 `R`개와 파란 블록 `B`개로 피라미드를 만듭니다. `k`번째 층은 같은 색 블록 `k^2`개를 사용합니다. 만들 수 있는 피라미드의 최대 층 수를 구하세요.

## 제약

- `1 ≤ R,B ≤ 10^18`

## 입력

```text
R B
```

## 출력

최대 층 수를 출력하세요.
