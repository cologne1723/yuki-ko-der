식당에 $K$종류의 요리가 있고 $N$명의 손님이 온다냥. 손님 $i$는 시각 $L_i$에 입장하고 $R_i-0.1$에 퇴장하며, 요리 하나를 주문한다냥. 어떤 시각에 같은 요리를 주문한 두 손님이 동시에 매장에 있도록 하는 주문 방법의 수를 구하라냥.

## 조건

- $1\le N\le10^5$
- $1\le K\le10^9$
- $1\le L_i<R_i\le2\times10^5$

## 입력

```text
N K
L_1 R_1
\vdots
L_N R_N
```

## 출력

주문 방법의 수를 $998244353$으로 나눈 나머지를 출력하라냥.
