## 문제

길이 $N$인 수열 $a$와 음이 아닌 정수 $X$가 주어집니다. $a_i+a_j=X$를 만족하는 순서쌍 $(i,j)$의 개수를 구하세요.

## 입력

~~~text
$N$ $X$
$a_1$ $a_2$ ... $a_N$
~~~

첫째 줄에 수열의 길이 $N$과 음이 아닌 정수 $X$가 공백으로 주어집니다. 둘째 줄에 수열 $a$의 원소 $N$개가 공백으로 주어집니다.

## 제약

- $1\leq N\leq10^5$
- $0\leq X\leq10^9$
- $0\leq a_i\leq10^5\ (1\leq i\leq N)$
- 입력은 모두 정수입니다.

## 출력

조건을 만족하는 순서쌍 $(i,j)$의 개수를 1줄에 출력하세요. 마지막에는 줄바꿈을 추가하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
3 4
1 2 3
~~~

#### 출력

~~~text
3
~~~

조건을 만족하는 것은 $(1,3),(2,2),(3,1)$의 3개입니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
4 6
2 4 4 3
~~~

#### 출력

~~~text
5
~~~

조건을 만족하는 것은 $(1,2),(1,3),(2,1),(3,1),(4,4)$의 5개입니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
4 5
1 2 0 6
~~~

#### 출력

~~~text
0
~~~

조건을 만족하는 순서쌍은 존재하지 않습니다.
