## 이야기

kamipeipaa君은 이과 학생이라 실험을 매우 좋아합니다. 오늘은 습기를 가진 $2$개의 시료를 합성하는 실험을 하고 있습니다.

## 문제 설명

kamipeipaa君에게 시료가 $2N$개 있고, $i$번째 시료의 습기는 정수 $A_i$로 나타냅니다.

시료 중 $2$개를 골라 합성하는 작업을 $N$회 반복합니다. 합성된 물질의 습기는 사용한 $2$개의 시료의 습기의 합입니다. 합성 결과가 음수이면 `Dry`, 양수이면 `Wet`, $0$이면 `Moist`라고 합니다. 합성 후 물질은 위험하므로 다시 사용할 수 없으며, 합성에 사용한 시료도 사라집니다.

실험 결과로 `Dry`, `Wet`, `Moist`인 물질을 각각 최대 몇 개 만들 수 있는지 구하세요. $3$종류의 최댓값은 각각 구합니다.

## 입력

```text
$N$
$A_1\ A_2\ \cdots\ A_{2N}$
```

$1$번째 줄에 합성 횟수를 나타내는 정수 $N$이 주어집니다. $2$번째 줄에 시료의 습기를 나타내는 정수 $A_i$가 공백으로 구분되어 주어집니다.

## 제한

- $1 \le N \le 100\,000$
- $-100\,000 \le A_i \le 100\,000$

## 출력

`Dry`, `Wet`, `Moist`인 합성 물질을 각각 만들 수 있는 최대 개수를 공백으로 구분해 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
-4 -3 -2 -1 1 2 3 4
```

#### 출력

```text
3 3 4
```

예를 들어 $(-4,3),(-3,2),(-2,1),(-1,4)$로 합성하면 `Dry`를 $3$개 만들 수 있습니다. $(-3,4),(-2,3),(-1,2),(-4,1)$로 합성하면 `Wet`을 $3$개, $(-4,4),(-3,3),(-2,2),(-1,1)$로 합성하면 `Moist`를 $4$개 만들 수 있습니다.

### 예제 2 {file=""}

#### 입력

```text
2
1 2 3 4
```

#### 출력

```text
0 2 0
```

어떻게 합성해도 `Wet`인 물질만 만들 수 있습니다.
