## 문제 설명

길이 $N$인 양의 정수 수열 $A=(A_1,A_2,\ldots,A_N)$이 주어집니다.

$A$의 연속 부분열 중 등차수열인 것 가운데 가장 긴 것의 길이를 구하세요.

### 점수

예상 해답의 길이는 $114$바이트입니다.

제출한 소스 코드의 길이가 $x$이고 이 문제의 예상 해답 코드 길이가 $y$일 때, 해당 소스 코드의 점수는 다음과 같이 계산됩니다.

$\max(500-x+y,100)$

점수는 이 문제에 제출된 소스 코드 점수의 최댓값입니다.

### 샘플 프로그램 (C++)

C++로 작성한 답안 예시를 보여 줍니다. 이 코드를 제출하면 $194$점을 얻을 수 있습니다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
  int N;
  cin >> N;
  vector<int> A(N);
  for(int i = 0; i < N; i++) {
    cin >> A[i];
  }
  int ans = 1;
  for(int i = 0; i < N - 1; i++) {
    int d = A[i + 1] - A[i];
    for(int j = i + 1; j < N; j++) {
      if(A[j] - A[j - 1] != d) {
        break;
      }
      if(ans < j - i + 1) {
        ans = j - i + 1;
      }
    }
  }
  cout << ans << endl;
}
```

## 입력

```text
$N$
$A_1\ A_2\ \ldots\ A_N$
```

## 제한

- 입력은 모두 정수입니다.
- $1\leq N\leq 2\,000$
- $1\leq A_i\leq 10^9$

## 출력

답을 $1$줄에 출력하세요.

마지막 개행이나 공백의 유무는 상관없습니다.

$A$의 연속 부분열 중 등차수열인 것 가운데 길이가 $3$보다 긴 것은 존재하지 않으므로, $3$을 출력하세요.
