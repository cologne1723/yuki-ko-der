## 문제 설명

문제 설명은 [Many Quotients hard](https://yukicoder.me/problems/4960)와 같지만 제한이 완화되어 있습니다.

양의 정수 $N$이 주어집니다. 양의 정수 $K$로 $N$을 나눈 몫을 $N/K$로 나타낼 때, $N/1,N/2,\ldots,N/N$ 중 서로 다른 정수가 몇 종류 나오는지 구하세요.

## 입력

```text
$N$
```

$N$은 정수이며 $1 \leq N \leq 100\,000$입니다.

## 출력

답을 한 줄에 출력하고 마지막에 줄바꿈을 넣으세요.

## 예제

### 예제 1 {file=""}
#### 입력
```text
3
```
#### 출력
```text
2
```

$3/1$, $3/2$, $3/3$의 값은 각각 $3$, $1$, $1$이므로 $2$종류의 값이 나옵니다.

### 예제 2 {file=""}
#### 입력
```text
319
```
#### 출력
```text
34
```
