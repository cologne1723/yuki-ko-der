이 문제는 인터랙티브 문제입니다. 오름차순으로 놓인 카드 더미 3개에서 게임을 진행합니다. 두 더미의 맨 위 카드를 제거할 때 두 숫자의 합 최댓값을 기록하며, 더미가 하나만 남으면 기록값을 $10^{100}$으로 끝냅니다. 게임 시작 전 최대 3회의 비교 질의로 카드 값을 비교해 게임 종료 기록을 최소화하세요.

## 입력 및 출력

질의는 `? i x j y` 형식으로 출력하고 비교 결과를 읽습니다. 전략을 정한 뒤 문제에서 요구하는 형식으로 답을 출력하세요.
