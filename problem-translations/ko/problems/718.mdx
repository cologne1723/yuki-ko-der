## 문제

수열 $F_i$를 다음과 같이 정의합니다.

~~~text
F_0 = 0
F_1 = 1
F_{i+2} = F_{i+1} + F_i
~~~

주어진 정수 $N$에 대해 $\sum_{i=1}^{N}F_i^2=F_1^2+F_2^2+\cdots+F_N^2$를 계산하세요.

답을 $1000000007$로 나눈 나머지를 출력하세요.

## 입력

~~~text
$N$
~~~

$1\leq N\leq10^{10}$입니다.

## 출력

$\sum_{i=1}^{N}F_i^2$를 $1000000007$로 나눈 나머지를 1줄에 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
8
~~~

#### 출력

~~~text
714
~~~

$1^2+1^2+2^2+3^2+5^2+8^2+13^2+21^2=714$가 정답입니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
33550336
~~~

#### 출력

~~~text
381853718
~~~

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
10000000000
~~~

#### 출력

~~~text
128493982
~~~

$N$은 32비트 정수에 들어가지 않을 수 있습니다.
