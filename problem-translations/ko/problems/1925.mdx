YUKI는 일차원에 갇혀 영차원으로 망명하려 합니다. $x_1<\cdots<x_{N+1}$인 세포벽이 있고, 인접한 벽 사이의 $N$개 구간이 세포입니다. 두 플레이어가 벽 하나를 번갈아 파괴하면 인접한 세포가 합쳐집니다.

## 문제

YUKI가 선공, 삼칠차원이 후공일 때 마지막 세포의 크기를 각각 최대로 또는 최소로 하려 합니다. 최적으로 플레이한 마지막 크기를 구하세요. 입력 $A_i=x_{i+1}-x_i$가 주어집니다.

## 입력

```text
N
A_1 A_2 ... A_N
```

$1\le N\le10^5$, $1\le A_i\le10^9$입니다.

## 출력

마지막 세포의 크기를 출력하세요.
