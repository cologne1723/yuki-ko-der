한 자리 양의 정수가 `N`개 있고, 정수 `i`는 `c_i`개 있습니다 (`1 <= i <= 9`). 이들을 재배열해 `N`자리 십진수 `M`으로 만들 때, `f(M)`의 최댓값을 구하세요.

여기서 `f(n)`은 양의 정수 `n`을 2로 나눌 수 있는 횟수입니다.

## 입력

첫째 줄에 `N`, 둘째 줄에 `c_1, c_2, ..., c_9`가 주어집니다.

## 제약

- `1 <= N <= 14`
- `c_i >= 0`, `sum(c_i) = N`

## 출력

`f(M)`의 최댓값을 출력하세요.
