$N$개의 $A,B$ 쌍 각각에 대해 $\sqrt A+\sqrt B<X$를 만족하는 최소 정수 $X$를 구하세요.

## 조건

- $1\le N\le2.5\times10^5$
- $1\le A,B\le10^9$

## 입력

```text
N
A1 B1
...
AN BN
```

## 출력

각 쿼리의 답을 한 줄에 하나씩 출력하세요.
