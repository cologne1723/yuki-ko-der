## 문제 설명

A는 원을 그리려고 합니다. 원을 그릴 때 다음 조건을 만족해야 합니다.

- 원의 중심은 $XY$ 평면의 원점입니다.
- 원의 지름은 반드시 정수여야 합니다.
- 정수 좌표의 지정된 점 $P(X_p,Y_p)$가 반드시 원의 내부에 있어야 합니다.

여기서 내부란 원의 선과 겹치지 않는 안쪽을 뜻합니다.

그릴 수 있는 원의 지름의 최솟값을 구하세요.

힌트: 피타고라스 정리를 사용하세요.

## 입력

```text
$X_p\ Y_p$
```

점 $P$의 좌표를 나타내는 정수 $X_p,Y_p$가 공백으로 구분되어 주어집니다.

## 제한

$-10\,000 \le X_p,Y_p \le 10\,000$

## 출력

그릴 수 있는 원의 지름의 최솟값을 한 줄에 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 0
```

#### 출력

```text
7
```

지름 $6$인 원을 그리면 점 $P$가 원과 겹칩니다. 따라서 지름 $7$인 원을 그리면 점 $P$가 원의 내부에 들어갑니다.

### 예제 2 {file=""}

#### 입력

```text
-3 4
```

#### 출력

```text
11
```

지름 $10$인 원을 그리면 점 $P$가 원과 겹칩니다. 따라서 지름 $11$인 원을 그리면 점 $P$가 원의 내부에 들어갑니다.

### 예제 3 {file=""}

#### 입력

```text
4 4
```

#### 출력

```text
12
```

점 $P(4,4)$는 지름 $12$인 원을 그리면 내부에 들어갑니다.

### 예제 4 {file=""}

#### 입력

```text
0 0
```

#### 출력

```text
1
```

점 $P$가 원점이므로 지름 $1$인 원을 그리면 내부에 들어갑니다.
