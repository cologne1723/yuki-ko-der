## 문제 설명

A는 원을 그리려고 합니다. 원을 그릴 때 다음 조건을 만족해야 합니다.

- 원의 중심은 $XY$ 평면의 원점입니다.
- 원의 지름은 반드시 정수여야 합니다.
- 정수 좌표의 지정된 점 $P(X_p,Y_p)$가 반드시 원의 내부에 있어야 합니다.

여기서 내부란 원의 선과 겹치지 않는 안쪽을 뜻합니다.

그릴 수 있는 원의 지름의 최솟값을 구하세요.

힌트: 피타고라스 정리를 사용하세요.

## 입력

```text
X_p Y_p
```

점 $P(X_p,Y_p)$의 좌표가 주어집니다. $X_p,Y_p$는 정수입니다. $(-10\,000 \le X_p,Y_p \le 10\,000)$

## 출력

그릴 수 있는 원의 지름의 최솟값을 한 줄에 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

```text
3 0
```

```text
7
```

지름 6인 원을 그리면 점 $P$가 원과 겹칩니다. 따라서 지름 7인 원을 그려야 점 $P$가 원의 내부에 들어갑니다.

```text
-3 4
```

```text
11
```

지름 10인 원을 그리면 점 $P$가 원과 겹칩니다. 따라서 지름 11인 원을 그려야 합니다.

```text
4 4
```

```text
12
```

점 $P(4,4)$는 지름 12인 원을 그리면 내부에 들어갑니다.

```text
0 0
```

```text
1
```

점 $P$가 원점이므로 지름 1인 원을 그리면 내부에 들어갑니다.
