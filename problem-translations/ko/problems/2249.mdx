정점 $1,\ldots,N$의 완전 그래프에서 $i<j$인 변의 가중치는 $\gcd(i,j)$이다냥. 두 정점 사이 거리 $dist(x,y)$를 경로의 가중치 합 최솟값으로 정의할 때, 모든 정점 쌍의 거리 합을 구하라냥.

## 조건

- $1\le T\le2\times10^5$
- $2\le N\le10^7$

## 입력

```text
T
N_1
\vdots
N_T
```

## 출력

각 테스트 케이스의 답을 출력하라냥.
