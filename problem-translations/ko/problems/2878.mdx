## 이야기

올해 東大寺学園의 문화제인 [菁々祭](https://seiseisai.com/2024/)의 주제는 `IGNITION`입니다.

## 문제 설명

정수 $i$가 주어집니다. 문자열 `IGNITION`의 $i$번째 문자를 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$i$
```

## 제한

- $1 \leq i \leq 8$
- $i$는 정수입니다.

## 출력

답을 출력하고, 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
I
```

`IGNITION`의 $1$번째 문자는 `I`입니다.

### 예제 2 {file=""}

#### 입력

```text
3
```

#### 출력

```text
N
```

`IGNITION`의 $3$번째 문자는 `N`입니다.

### 예제 3 {file=""}

#### 입력

```text
8
```

#### 출력

```text
N
```
