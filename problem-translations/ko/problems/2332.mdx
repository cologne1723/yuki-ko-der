길이 $N$인 수열 $A$, 길이 $M$인 수열 $B,C$가 주어집니다. 빈 수열 $S$의 뒤에 $A$의 접두사 $(A_1,\ldots,A_k)$를 붙이는 연산을 반복하여 길이 $M$으로 만듭니다. 현재 길이를 $l$이라 할 때 $1\le k\le\min(M-l,N)$이고 비용은 $kC_l$입니다.

$S$를 $B$와 같게 만들 수 있는지 판정하고, 가능하면 최소 비용을 구하세요.

## 조건

- $1\le N,M\le2\times10^5$
- $1\le A_i,B_i,C_i\le10^9$

## 입력

$N,M$, 수열 $A,B$, 비용 $C_0,\ldots,C_{M-1}$가 주어집니다.

## 출력

가능하면 최소 비용을, 불가능하면 $-1$을 출력하세요.
