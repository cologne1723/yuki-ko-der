## 이야기

또다시 수박밭에 폭탄이 숨겨졌지만, 이번에는 다른 능력으로 자동 탐색하여 대처합시다.

탐사기도 더 직접적인 것이 되었습니다.

가능한 한 수박을 지키고 안전하게 만들 수 있도록 협조해 주세요.

여기쯤 트라우마를 남겨 두겠습니다. [코사인 폭탄 파괴자](https://yukicoder.me/problems/no/2831) (이것 때문에 왠지 비난받았습니다.)

## 문제 설명

점 $A$와 점 $B$의 맨해튼 거리를 $\text{dist}(A,B)$로 나타냅니다.

$N$개의 격자점 $D_i(1\leq i\leq N)$가 있고, 각각의 좌표는 $(x_i,y_i)$입니다. $N$은 주어지지만 각 좌표는 주어지지 않습니다.

다음 질의를 최대 $300$회까지 할 수 있습니다.

- 격자점 $A$를 선택하면 $\sum_{i=1}^{N}\text{dist}(A,D_i)$가 주어집니다.

이 질의를 사용하여 격자점 중 $\sum_{i=1}^{N}\text{dist}(A,D_i)$가 최소가 되는 격자점 $A$를 구하세요. 단, 정답이 여러 개라면 그중 하나를 구하면 정답으로 인정됩니다.

## 입력

처음에 $N$이 주어집니다.

```text
$N$
```

## 제한

- $1 \leq N \leq 100$
- $N$은 정수입니다.
- $-10^8 \leq x_i,y_i \leq 10^8$ ($1\leq i\leq N$)
- $D_i$ ($1\leq i\leq N$)는 격자점입니다.
- 각 좌표는 테스트 케이스마다 고정되어 있습니다. 즉, 질의 내용에 따라 좌표가 변하지 않습니다.

## 출력

점 $A$의 좌표를 $(x,y)$로 하여 질의를 보낼 때는 다음 형식으로 출력하세요.

```text
$1\ x\ y$
```

단, 다음 제한을 만족해야 합니다.

- $-10^9 \leq x,y \leq 10^9$
- $A$는 격자점입니다.

질의에 대한 답을 $d$라고 하면 다음 형식으로 주어집니다.

```text
$d$
```

정답의 좌표를 $(x,y)$로 출력할 때는 다음 형식으로 출력하세요.

```text
$2\ x\ y$
```

단, 다음 제한을 만족해야 합니다.

- $-10^9 \leq x,y \leq 10^9$
- 정답의 점은 격자점입니다.

각 출력 뒤에는 반드시 줄 바꿈을 하고 출력 버퍼를 flush하세요. 그렇게 하지 않으면 채점 결과가 TLE나 WA가 될 수 있습니다.

부정확한 출력이나 동작에 대한 채점 결과는 정해져 있지 않습니다. 여분의 공백이나 줄 바꿈 등을 출력하지 않도록 주의하세요.

정답의 좌표를 출력했다면 즉시 프로그램을 종료하세요. 종료하지 않으면 채점 결과가 정해져 있지 않습니다.

정답 출력은 질의 횟수에 포함되지 않습니다.

0
