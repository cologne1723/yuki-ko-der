## 문제 설명

문자 `1`, `3`, `5`, `7`, `9`로 이루어진 길이가 $N$인 문자열 $S$가 있습니다.

다음 연산을 최대한 많이 하려고 합니다.

- $S$의 부분 수열 중 수로 해석했을 때 소수가 되는 것을 하나 골라 삭제합니다.

고르는 부분 수열은 연속하지 않아도 됩니다.

연산 횟수의 최댓값을 구하세요.

## 입력

```text
$N$
$S$
```

## 제한

- $1 \le N \le 2 \times 10^5$
- $S$는 문자 `1`, `3`, `5`, `7`, `9`로 이루어진 길이가 $N$인 문자열입니다.
- $N$은 정수입니다.

## 출력

답을 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
6
993711
```

#### 출력

```text
3
```

예를 들어 다음과 같이 연산하면 됩니다.

1. `993711`에서 두 번째 문자 `9`와 네 번째 문자 `7`로 이루어진 부분 수열 `97`을 골라 삭제하면 `9311`이 됩니다.
2. `9311`에서 두 번째 문자 `3`을 골라 삭제하면 `911`이 됩니다.
3. `911`에서 두 번째와 세 번째 문자로 이루어진 부분 수열 `11`을 골라 삭제하면 `9`가 됩니다.

$97$, $3$, $11$은 모두 소수입니다.

### 예제 2 {file=""}

#### 입력

```text
5
99999
```

#### 출력

```text
0
```

수로 해석했을 때 소수가 되는 부분 수열이 없으므로 연산을 한 번도 할 수 없습니다.

### 예제 3 {file=""}

#### 입력

```text
4
1333
```

#### 출력

```text
3
```
