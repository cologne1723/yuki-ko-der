양의 정수 `N,M`이 주어집니다. 길이가 60 이하인 비음이 아닌 정수열 `A`를 구성해 다음 조건을 만족시키세요.

`N/M = A_0 + 1/(A_1 + 1/(A_2 + ...))`

## 입력

`N M`이 주어집니다.

## 출력

조건을 만족하는 수열 `A`를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
36 11
```

#### 출력

```text
3 3 1 2
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
20 1
```

#### 출력

```text
20
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
10 23
```

#### 출력

```text
0 2 3 3
```
