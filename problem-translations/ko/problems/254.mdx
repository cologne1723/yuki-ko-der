## 문제

양의 정수 $N$이 주어집니다. 다음 조건을 모두 만족하는 문자열 $S$를 하나 구하세요.

- $1 \leq |S| \leq 10^5$
- 영소문자만으로 이루어집니다.
- 인접한 두 문자는 서로 다릅니다.
- 회문인 부분 문자열이 정확히 $N$개 포함됩니다.

## 입력

```text
N
```

- $1 \leq N \leq 10^9$

## 출력

조건을 모두 만족하는 문자열 $S$를 하나 출력하세요. 존재하지 않으면 대신 원하는 초밥 재료 이름을 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

```text
1
```

### 출력 1 {file="stdout"}

```text
a
```

`b`, `z` 등을 출력해도 정답입니다.

### 입력 2 {file="stdin"}

```text
4
```

### 출력 2 {file="stdout"}

```text
iwi
```

회문인 부분 문자열 `i`, `w`, `i`, `iwi`가 총 4개 포함됩니다.
