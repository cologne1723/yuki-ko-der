## 문제 설명

양의 정수 $N$이 주어집니다. 다음 조건을 모두 만족하는 문자열 $S$를 $1$개 구하세요.

- $1 \leq |S| \leq 10^5$
- 영소문자만으로 이루어집니다.
- 인접한 $2$개의 문자는 서로 다릅니다.
- 회문인 부분 문자열이 정확히 $N$개 포함됩니다.

## 입력

```text
$N$
```

## 제한

- $1 \leq N \leq 10^9$

## 출력

조건을 모두 만족하는 문자열 $S$를 $1$개 출력하세요. 존재하지 않으면 대신 원하는 초밥 재료 이름을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
a
```

`b`, `z` 등을 출력해도 정답입니다.

### 예제 2 {file=""}

#### 입력

```text
4
```

#### 출력

```text
iwi
```

회문인 부분 문자열 `i`, `w`, `i`, `iwi`가 총 $4$개 포함됩니다.
