## 이야기

[岩井星人さん](https://www.youtube.com/@yiwiy9)은 프로그래밍 대회에 참가했을 때의 모습을 실황 영상으로 YouTube에 올리고 있습니다.

사실 岩井星人さん이 사용하는 프로그래밍 언어는 시기에 따라 달라집니다.

## 문제 설명

어떤 사이트에서는 프로그래밍 언어를 사용해 프로그래밍 능력을 겨루는 대회가 여러 번 열리고 있습니다.

각 정수 $n$ ($1 \leq n \leq 420$)에 대해, 岩井星人さん은 $n$번째 대회에 다음 프로그래밍 언어를 사용해 참가합니다.

- $1 \leq n \leq 295$일 때, **C++**를 사용합니다.
- $296 \leq n \leq 416$일 때, **Rust**를 사용합니다.
- $417 \leq n \leq 420$일 때, **Python**을 사용합니다.

$L$번째 대회부터 $R$번째 대회까지 岩井星人さん이 사용하는 프로그래밍 언어를 변경한 횟수를 구하세요.

더 엄밀하게는 $L \leq i < i+1 \leq R$를 만족하는 정수 $i$ 중에서, $i$번째 대회와 $i+1$번째 대회에서 사용하는 프로그래밍 언어가 서로 다른 것의 개수를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$L\ R$
```

입력 줄에 정수 $L$, $R$이 주어집니다.

## 제한

- $1 \leq L \leq R \leq 420$
- 입력값은 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
245 420
```

#### 출력

```text
2
```

$295$번째 대회부터 $296$번째 대회까지와 $416$번째 대회부터 $417$번째 대회 사이에서 사용하는 언어를 변경하므로, 총 $2$번 변경합니다.

### 예제 2 {file=""}

#### 입력

```text
417 417
```

#### 출력

```text
0
```

이 경우 岩井星人さん은 타고난 Pythonista입니다.

### 예제 3 {file=""}

#### 입력

```text
290 300
```

#### 출력

```text
1
```
