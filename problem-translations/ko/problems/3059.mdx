## 문제 설명

$N$명의 플레이어 $1,2,\dots,N$이 있습니다.

이제 $(1,2,\dots,N)$의 순열 $P$를 사용해 $Q$회의 토너먼트를 진행합니다. $i$번째 토너먼트는 다음과 같이 진행됩니다.

1. 앞에서부터 플레이어 $P_{L_i}, P_{L_i+1}, \dots, P_{R_i}$가 나열된 대기열을 만듭니다.
2. 대기열에 플레이어가 $1$명 남을 때까지 다음 과정을 반복합니다.
   - 대기열의 앞에서부터 $2$명의 플레이어가 경기를 합니다. 플레이어 번호가 큰 플레이어가 승리하고 대기열의 맨 뒤로 이동하며, 플레이어 번호가 작은 플레이어는 대기열에서 나갑니다.

$i=1,2,\dots,N$ 각각에 대해, $Q$회의 토너먼트에서 플레이어 $i$가 승리한 경기 수의 합을 구하세요.

## 입력

```text
$N$
$P_1\ P_2\ \dots\ P_N$
$Q$
$L_1\ R_1$
$L_2\ R_2$
$\vdots$
$L_Q\ R_Q$
```

$1$번째 줄에 플레이어 수를 나타내는 정수 $N$이 주어집니다.

$2$번째 줄에 순열 $P$의 원소 $P_1,P_2,\dots,P_N$이 공백으로 구분되어 주어집니다.

$3$번째 줄에 토너먼트 수를 나타내는 정수 $Q$가 주어집니다.

이후 $Q$개의 줄에 각 토너먼트에서 사용할 구간의 양 끝을 나타내는 정수 $L_i$, $R_i$가 공백으로 구분되어 주어집니다.

## 제한

- 입력은 모두 정수입니다.
- $2 \le N \le 2\times 10^5$
- $1 \le Q \le 2\times 10^5$
- $P$는 $(1,2,\dots,N)$의 순열입니다.
- $1 \le L_i < R_i \le N$

## 출력

$i$번째 줄에 플레이어 $i$가 승리한 경기 수의 합을 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
3 1 4 2 5
1
1 5
```

#### 출력

```text
0
0
1
1
2
```

처음에 플레이어 번호가 $(3,1,4,2,5)$ 순서로 나열된 상태에서 토너먼트를 시작합니다.

- $1$번째 경기에서는 플레이어 $3$과 플레이어 $1$이 경기하고, 플레이어 $3$이 승리합니다. 대기열의 상태는 $(4,2,5,3)$이 됩니다.
- $2$번째 경기에서는 플레이어 $4$와 플레이어 $2$가 경기하고, 플레이어 $4$가 승리합니다. 대기열의 상태는 $(5,3,4)$가 됩니다.
- $3$번째 경기에서는 플레이어 $5$와 플레이어 $3$이 경기하고, 플레이어 $5$가 승리합니다. 대기열의 상태는 $(4,5)$가 됩니다.
- $4$번째 경기에서는 플레이어 $4$와 플레이어 $5$가 경기하고, 플레이어 $5$가 승리합니다. 대기열의 상태는 $(5)$가 됩니다.
