0, 1, 2가 적힌 공이 각각 $A,B,C$개 있습니다. 공이 하나 이하로 남을 때까지 두 공을 골라 동시에 먹습니다. 숫자가 $x,y$이면 $(x+y)\bmod3$의 만족도를 얻을 때, 만족도 합의 최댓값을 구하세요.

## 입력

```text
T
A B C
```

$1\le T\le10^5$입니다.

## 출력

각 테스트 케이스의 최댓값을 출력하세요.
