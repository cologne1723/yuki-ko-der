## 문제 설명

합창에서 사용하는 음악 기호 중에 '미요시 악센트'라고 하는 것이 있습니다. 미요시 악센트는 한 음 안에 크레셴도와 데크레셴도를 만들도록 연주하라는 지시입니다. 오리온 군은 이를 길이가 $4$인 수열 $A_1, A_2, A_3, A_4$에 적용하기로 했습니다. $A_1 < A_2$이고 $A_3 > A_4$이면 미요시 악센트라고 하고, 그렇지 않은 경우에는 미요시 악센트가 아니라고 정의합니다. $A_1, A_2, A_3, A_4$가 주어질 때 이 수열이 미요시 악센트인지 판정하세요.

## 입력

```text
$A_1\ A_2\ A_3\ A_4$
```

$A_1$부터 $A_4$까지가 공백으로 구분되어 주어집니다.

입력은 모두 정수입니다.

## 제한

$1 \le A_i \le 9$ ($1 \le i \le 4$)

## 출력

미요시 악센트이면 `YES`를, 미요시 악센트가 아니면 `NO`를 출력하세요. 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 3 3 2
```

#### 출력

```text
YES
```

$A_1 < A_2$이고 $A_3 > A_4$이므로 미요시 악센트입니다.

### 예제 2 {file=""}

#### 입력

```text
2 4 7 9
```

#### 출력

```text
NO
```

$A_3 < A_4$이므로 미요시 악센트가 아닙니다.

### 예제 3 {file=""}

#### 입력

```text
4 4 7 2
```

#### 출력

```text
NO
```

$A_1 = A_2$이므로 미요시 악센트가 아닙니다.
