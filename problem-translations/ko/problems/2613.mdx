정수 $N$과 소수 $P$가 주어집니다. 모든 $0\le R\le N$에 대해 $\binom NR$을 $P$로 나눈 나머지를 더한 값을 다시 $998244353$으로 나눈 나머지를 구하세요.

## 조건

- $1\le N\le10^{18}$
- $2\le P\le2\times10^5$, $P$는 소수입니다.

## 입력

```text
$N$ $P$
```

## 출력

답을 출력하세요.
