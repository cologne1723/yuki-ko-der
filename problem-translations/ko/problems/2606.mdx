영소문자열 $S$가 주어집니다. 빈 문자열 $X$의 뒤에 문자를 원하는 만큼 붙입니다. 매번 $X$가 회문이면 $S$에 나타나는 $X$의 등장 횟수에 $\lvert X\rvert$를 곱한 점수를 얻고, 회문이 아니면 점수를 얻지 않습니다. 얻을 수 있는 최대 점수를 구하세요. 등장 횟수는 겹치는 구간도 셉니다.

## 조건

- $1\le \lvert S\rvert\le2\times10^5$
- $S$는 영소문자열입니다.

## 입력

```text
$S$
```

## 출력

최대 점수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
baabaabaacaa
```

#### 출력

```text
34
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
abc
```

#### 출력

```text
1
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
zzzzabcddcba
```

#### 출력

```text
20
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
disablepixellightsmirrorresolutionturnoffmirrorocclusionreflectlayersmaximumantialiasing
```

#### 출력

```text
21
```
