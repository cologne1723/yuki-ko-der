## 문제

길이 `N`인 이진 수열 `A`로 시작합니다. 원형 수열 `B_0=A`에 대해 다음을 반복합니다.

`B_{i+1,j}`는 `(B_{i,j-1}=1이고 B_{i,j}=0)` 또는 `(B_{i,j}=1이고 B_{i,j+1}=1)`이면 1, 그 외에는 0입니다. 모든 인덱스는 `N`으로 나눈 나머지입니다.

다음 극한의 유리수 값을 `998244353`으로 나눈 값을 구하세요.

`lim_{T→∞} (1/T) Σ_{i=0}^{T-1} B_{i+1,0}(1-B_{i,0})`

<details>
<summary>유리수 $\text{mod }998\,244\,353$란?</summary>

유리수를 출력할 때는 먼저 그 유리수를 분수 $\frac{y}{x}$로 나타내세요. 여기서 $x,y$는 정수이고 $x$는 $998\,244\,353$으로 나누어떨어지면 안 됩니다. 이 문제의 제한 아래에서는 항상 이러한 표현이 가능합니다. 그런 다음 $xz\equiv y\pmod{998\,244\,353}$을 만족하는 $0$ 이상 $998\,244\,353$ 이하의 유일한 정수 $z$를 출력하세요.

</details>

## 제약


- `3 ≤ N ≤ 2×10^5`
- `A_i`는 0 또는 1입니다.

## 입력

```text
N
A_0 A_1 ... A_{N-1}
```

## 출력

극한을 `998244353`으로 나눈 값을 출력하세요.
