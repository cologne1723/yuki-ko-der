여름에 필요한 `watermelon`, `beachball`, `shrinebell` 중 서로 다른 두 문자열 $S,T$를 가지고 있습니다. 가지고 있지 않은 나머지 하나를 출력하세요.

## 입력

```text
$S$ $T$
```

## 조건

- $S,T$는 세 문자열 중 하나이고 서로 다릅니다.

## 출력

가지고 있지 않은 문자열을 출력하세요.
