올바른 괄호열 $S$가 주어집니다. 각 문자를 빨강 또는 파랑으로 칠해, 빨간 문자만 추출한 문자열 $X$와 파란 문자만 추출한 문자열 $Y$가 모두 올바른 괄호열이 되도록 하는 색칠 방법의 수를 구하세요.

## 입력

```text
N
S
```

$2\le N\le3000$입니다.

## 출력

색칠 방법의 수를 $998244353$으로 나눈 나머지를 출력하세요.
