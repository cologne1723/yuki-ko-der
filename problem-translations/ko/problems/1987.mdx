각각 $a,b,c$초 후 모래가 모두 떨어지는 모래시계 세 개로 정확히 $X$초를 잴 수 있는지 판정하세요. 처음에는 모든 모래가 아래로 떨어진 상태이며, 모래가 떨어지는 중에도 특정 시각에 모래시계를 뒤집을 수 있습니다. 어떤 조작 또는 모래가 모두 떨어진 시각 사이의 간격이 $X$초이면 측정한 것으로 봅니다.

## 입력

```text
a b c
X
```

$1\le a,b,c,X\le10^{12}$입니다.

## 출력

측정할 수 있으면 `Yes`, 없으면 `No`를 출력하세요.
