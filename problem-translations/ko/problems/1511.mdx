## 문제

양의 정수 $A,B$가 주어집니다. $(A\mid B)-(A\mathbin{\&}B)$를 구하세요. $\mid$는 bitwise OR, $\&$는 bitwise AND입니다.

## 입력

$A,B$가 주어집니다.

- $1\leq A,B\leq1000$

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1
```

#### 출력

```text
0
```

### 예제 2 {file=""}

#### 입력

```text
3 5
```

#### 출력

```text
6
```
