## 주의

정답 판정에 약 1분이 걸립니다. 주의하세요.

## 문제

square1001은 길이 $N$인 수열 $A=(A_0,A_1,A_2,\dots,A_{N-1})$을 찾았습니다.

John과 Brus는 수열 $v=(A_{k\mathbin{\%}N},A_{(k+1)\mathbin{\%}N},A_{(k+2)\mathbin{\%}N},\dots,A_{(k+N-1)\mathbin{\%}N})$에 대해 다음 프로그램을 실행하고, 모든 $k$에 대한 최종 cnt 값을 즉시 구했습니다.

~~~text
cnt = 0
for i = 0 to N-1
    for j = 0 to N-2
        if v[j] > v[j+1]
            swap v[j] and v[j+1]
            add 1 to cnt
~~~

하지만 John과 Brus, 그리고 그들이 작성한 코드는 사라졌습니다. 당신은 그들을 대신해 이 문제를 해결하는 프로그램을 작성해야 합니다.

## 입력

~~~text
$N$
$A_0$
$A_1$
:
$A_{N-1}$
~~~

첫째 줄에 수열의 길이 $N$이 주어집니다.

$0\leq i\lt N$인 각 $i$에 대해, $i+2$번째 줄에 수열의 $i$번째 값 $A_i$가 주어집니다.

## 출력

$0\leq i\lt N$인 각 $i$에 대해, $v=(A_{i\mathbin{\%}N},A_{(i+1)\mathbin{\%}N},A_{(i+2)\mathbin{\%}N},\dots,A_{(i+N-1)\mathbin{\%}N})$에 대해 위 프로그램을 실행했을 때의 최종 cnt 값을 $i+1$번째 줄에 출력하세요.

## 제약

- $1\leq N\leq500000$
- $1\leq A_i\leq1000000000\ (0\leq i\lt N)$

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
5
2
5
1
4
3
~~~

#### 출력

~~~text
5
7
3
7
5
~~~

예를 들어 수열 $(2,5,1,4,3)$에 프로그램을 실행하면 수열은 다음과 같이 변합니다.

~~~text
(2, 5, 1, 4, 3) -> (2, 1, 5, 4, 3) -> (2, 1, 4, 5, 3) -> (2, 1, 4, 3, 5) -> (1, 2, 4, 3, 5) -> (1, 2, 3, 4, 5)
~~~

5번 변했으므로 최종 cnt 값은 5입니다.
