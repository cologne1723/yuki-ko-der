한 자리 양의 정수가 `N`개 있습니다. 정수 `i`는 `c_i`개 있습니다 (`1 <= i <= 9`). 이들을 재배열해 `N`자리 십진수 `M`으로 만들 때, `M`이 `K`의 배수가 되는 경우의 수를 구하세요.

## 입력

첫째 줄에 `N`, `K`, 둘째 줄에 `c_1, c_2, ..., c_9`가 주어집니다.

## 제약

- `1 <= N <= 14`
- `1 <= K <= 1000`
- `c_i >= 0`, `sum(c_i) = N`
- 입력은 정수입니다.

## 출력

`K`의 배수가 되는 `M`의 개수를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 6
1 1 1 0 0 0 0 0 0
```

#### 출력

```text
2
```

### 예제 2 {file=""}

#### 입력

```text
3 2
1 2 0 0 0 0 0 0 0
```

#### 출력

```text
2
```

### 예제 3 {file=""}

#### 입력

```text
4 3

```

#### 출력

```text
0
```

### 예제 4 {file=""}

#### 입력

```text
9 123
1 1 1 1 1 1 1 1 1
```

#### 출력

```text
8832
```
