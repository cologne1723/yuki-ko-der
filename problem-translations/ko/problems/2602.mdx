서로 다른 세 점 $(X_A,Y_A),(X_B,Y_B),(X_C,Y_C)$를 포함하는 최소 반지름의 원이 플레이 영역입니다. $Q$개의 물건이 주어질 때 각 물건이 원 안 또는 원주 위에 있는지 판정하세요.

## 조건

- $1\le Q\le2\times10^5$
- 모든 좌표의 절댓값은 $10^4$ 이하입니다.

## 입력

```text
$Q$
$X_A$ $Y_A$ $X_B$ $Y_B$ $X_C$ $Y_C$
$X_1$ $Y_1$
\vdots
$X_Q$ $Y_Q$
```

## 출력

각 물건이 원 안 또는 원주 위에 있으면 `Yes`, 아니면 `No`를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
5
1 0 -1 0 0 2
0 1
0 2
0 3
2 2
0 -1
```

#### 출력

```text
Yes
Yes
No
No
No
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3
-1 0 0 0 1 0
0 1
0 -1
1 1
```

#### 출력

```text
Yes
Yes
No
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
5
0 0 6 0 0 8
6 8
7 7
7 1
-1 7
-1 1
```

#### 출력

```text
Yes
Yes
Yes
Yes
Yes
```
