서로 다른 세 점 $(X_A,Y_A),(X_B,Y_B),(X_C,Y_C)$를 포함하는 최소 반지름의 원이 플레이 영역입니다. $Q$개의 물건이 주어질 때 각 물건이 원 안 또는 원주 위에 있는지 판정하세요.

## 조건

- $1\le Q\le2\times10^5$
- 모든 좌표의 절댓값은 $10^4$ 이하입니다.

## 입력

```text
$Q$
$X_A$ $Y_A$ $X_B$ $Y_B$ $X_C$ $Y_C$
$X_1$ $Y_1$
\vdots
$X_Q$ $Y_Q$
```

## 출력

각 물건이 원 안 또는 원주 위에 있으면 `Yes`, 아니면 `No`를 출력하세요.
