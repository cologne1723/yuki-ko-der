## 문제

합동인 두 원뿔이 있습니다. 두 원뿔의 밑면 반지름은 `R`, 높이는 `H`입니다. 두 밑면은 같은 평면 위에 있고, 두 꼭짓점은 그 평면의 같은 쪽에 있습니다. 꼭짓점 사이의 거리는 `D`입니다.

두 원뿔의 공통 부분의 부피를 구하세요.

## 입력

`R`, `H`, `D`가 주어집니다. 모두 양의 실수이며 소수점 이하 둘째 자리까지 주어집니다.

`R,H \le 10^4`, `D \le 2R`입니다.

## 출력

공통 부분의 부피를 한 줄에 출력하세요.

## 문제

정수 `T`와 `N`개의 정점, `M`개의 가중치가 있는 그래프가 주어집니다. 같은 두 정점을 잇는 간선은 최대 하나이고, 자기 자신으로 향하는 간선은 없습니다.

`T=0`이면 그래프는 무방향 그래프이며, 각 간선은 양방향으로 연결됩니다. `T=1`이면 그래프는 유향 그래프이며, 각 간선은 주어진 방향으로만 연결됩니다.

그래프에 존재하는 사이클 중 크기가 가장 작은 것을 구하세요. 사이클의 크기는 포함된 간선 가중치의 합입니다. 사이클이 없으면 `-1`을 출력하세요.

## 입력

첫째 줄에 `T`, `N`, `M`이 주어지고, 이후 `M`개 줄에 각 간선의 양 끝점과 가중치가 주어집니다.

`T`는 `0` 또는 `1`입니다.

## 출력

최소 사이클 크기를 출력하세요. 사이클이 없으면 `-1`을 출력하세요.

## 문제

서로 구별되는 `N`개의 공이 있고, 처음에는 모두 무색입니다. 각 공에 `M`가지 색 중 하나를 골라 칠합니다.

색칠이 끝난 뒤, 하나 이상의 공을 선택했을 때 선택한 공에 사용된 색의 종류가 정확히 `K`개가 되는 선택 방법의 수를 생각합니다. 가능한 모든 색칠 방법에 대해 이 값을 계산한 총합을 `998244353`으로 나눈 나머지를 출력하세요.

## 입력

`N M K`가 주어집니다.

`1 \le K \le M \le N \le 10^5`입니다.

## 출력

답을 `998244353`으로 나눈 나머지를 출력하세요.
