블록 0부터 9를 $N\times6$ 배열로 배치한 뒤, 가로 또는 세로로 같은 종류 블록 3개가 연속하면 표시해 삭제하고 중력으로 떨어뜨리는 게임을 한다냥. 삭제된 블록이 3개보다 많거나 0개면 실패하고, 모두 없어지면 성공한다냥. 성공하는 배치가 존재하는지 판정하고 가능하면 하나 출력하라냥.

## 조건

- $N$은 원문 조건을 따른다냥.

## 입력

```text
N
```

## 출력

가능하면 배치 예를 출력하고, 불가능하면 원문 형식에 따라 출력하라냥.
