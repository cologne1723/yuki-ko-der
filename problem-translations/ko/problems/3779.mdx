## 문제 설명

램프 $N$개가 가로로 한 줄로 놓여 있습니다. 왼쪽에서 $i$번째 램프를 램프 $i$라고 합니다 $(1\le i\le N)$. 각 램프는 **꺼진 상태**와 **켜진 상태** 중 하나이며, 램프마다 달린 버튼을 누를 때마다 상태가 바뀝니다.

램프의 초기 상태는 길이 $N$의 문자열 $S$로 주어집니다. $S$는 `o`와 `x`로 이루어져 있으며, $i$번째 문자가 `o`이면 램프 $i$가 처음에 켜져 있고, `x`이면 꺼져 있습니다.

이제 $N$번의 연산을 합니다. $i$번째 연산 $(1\le i\le N)$에서는 다음 두 연산 중 정확히 하나를 골라 수행합니다.

- 연산 $L$: $j=1,2,\cdots,i$에 대해 램프 $j$의 버튼을 한 번씩 누릅니다.
- 연산 $R$: $j=i,i+1,\cdots,N$에 대해 램프 $j$의 버튼을 한 번씩 누릅니다.

어느 연산을 선택해도 램프 $i$의 버튼은 반드시 누른다는 점에 주의하세요.

$N$번의 연산을 적절히 선택하여 모든 연산이 끝난 뒤 모든 램프가 켜져 있도록 할 수 있는지 판별하고, 가능하다면 그러한 연산열 하나를 출력하세요.

## 입력

```text
$N$
$S$
```

## 제한

- $1\le N\le 2\times 10^5$
- $S$는 `o`와 `x`로 이루어진 길이 $N$의 문자열입니다.
- $N$은 정수입니다.

## 출력

조건을 만족하는 연산열이 없다면 `No`를 한 줄에 출력하세요.

있다면 첫째 줄에 `Yes`를 출력하고, 둘째 줄에 연산열을 나타내는 문자열 $T$를 출력하세요. $T$는 `L`과 `R`로 이루어진 길이 $N$의 문자열입니다. $i$번째 문자가 `L`이면 $i$번째에 연산 $L$을, `R`이면 연산 $R$을 수행한다는 뜻입니다.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
oxox
```

#### 출력

```text
Yes
LLLL
```

$4$번의 연산으로 램프의 상태는 `oxox` $\rightarrow$ `xxox` $\rightarrow$ `ooox` $\rightarrow$ `xxxx` $\rightarrow$ `oooo`로 바뀝니다.

### 예제 2 {file=""}

#### 입력

```text
1
o
```

#### 출력

```text
No
```

### 예제 3 {file=""}

#### 입력

```text
10
ooxxxoxoxo
```

#### 출력

```text
Yes
LRRLRRRRRR
```
