## 문제 설명

양의 정수 $N$, $M$과 $1$ 이상 $N$ 이하의 정수로 이루어진 정수열 $(L_1,L_2,\dotsc,L_M)$, $(R_1,R_2,\dotsc,R_M)$가 주어집니다.

이제 다음 문제를 생각합니다.

> 길이가 $N$인 수열 $(A_1,A_2,\dotsc,A_N)$이 있습니다. 처음에는 $A_i=i$입니다.
>
> $k=1,2,\dotsc,t$의 순서로 $A$의 $L_{((k-1)\bmod M)+1}$번째 원소와 $R_{((k-1)\bmod M)+1}$번째 원소를 교환하는 연산을 수행한 뒤의 $A_x$를 구하세요.

이 문제에는 $Q$개의 상황이 주어집니다. $i$번째 상황에서는 $t=T_i$, $x=X_i$로 하여 위 문제의 답을 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N\ M\ Q$
$L_1\ R_1$
$L_2\ R_2$
$\vdots$
$L_M\ R_M$
$T_1\ X_1$
$T_2\ X_2$
$\vdots$
$T_Q\ X_Q$
```

## 제한

- $2 \leq N \leq 100\,000$
- $1 \leq M,Q \leq 200\,000$
- $1 \leq L_i < R_i \leq N$
- $1 \leq X_i \leq N$
- $1 \leq T_i \leq 10^{18}$
- 입력은 모두 정수입니다.

다음과 같은 부분 문제가 설정되어 있습니다.

| 부분 문제 | 배점 | 제한 |
| --- | ---: | --- |
| 부분 문제 $1$ | $15$점 | $N=2,\ M=1$ |
| 부분 문제 $2$ | $15$점 | $M=1$ |
| 부분 문제 $3$ | $45$점 | $N\leq 2\,000,\ M\leq 4\,000,\ T_i\leq M$ |
| 부분 문제 $4$ | $60$점 | $T_i\leq M$ |
| 부분 문제 $5$ | $75$점 | $T_i\leq M^2,\ Q\leq 500$ |
| 부분 문제 $6$ | $30$점 | $N\leq 300,\ M=10^5,\ T_i\leq 10^{10}$ |
| 부분 문제 $7$ | $60$점 | 추가 제한은 없습니다. |

## 출력

$Q$줄을 출력하세요.

$i$번째 줄에는 $i$번째 상황에 대한 답을 출력하세요. ($1 \leq i \leq Q$)

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 3 3
1 2
3 4
4 5
4 3
2 4
8 1
```

#### 출력

```text
4
3
2
```

$1$번째 상황을 생각합니다.

처음에는 $A=(1,2,3,4,5)$입니다.

$k=1$ 연산을 수행한 뒤에는 $A=(2,1,3,4,5)$, $k=2$ 연산을 수행한 뒤에는 $A=(2,1,4,3,5)$, $k=3$ 연산을 수행한 뒤에는 $A=(2,1,4,5,3)$, $k=4$ 연산을 수행한 뒤에는 $A=(1,2,4,5,3)$입니다.

따라서 $1$번째 상황의 답은 $4$입니다.

이 케이스는 부분 문제 $5$, $6$, $7$의 제한을 만족합니다.
