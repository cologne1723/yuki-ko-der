## 문제 설명

깊이가 $d$인 포화 이진 트리가 주어집니다.
여기서 포화 이진 트리는 모든 정점이 리프이거나 자식을 $2$개 가지며, 모든 리프의 깊이가 같은 트리입니다.
루트의 깊이는 $1$이고, 리프의 깊이는 $d$입니다.

깊이가 $i$이고 왼쪽에서 $j$번째인 정점의 위치를 $2^{i-1}+j-1$로 정의합니다. $1 \le i \le d$, $1 \le j \le 2^{i-1}$입니다.
위치가 $x$인 정점을 $x$번 정점이라고 부릅니다.

이 트리의 정점 $2^d-1$개에 $1$부터 $2^d-1$까지의 서로 다른 번호를 하나씩 적으려고 합니다.
이때 다음 조건을 만족해야 합니다.

- 모든 정점 $i, j$에 대해, $i$번 정점의 깊이가 $j$번 정점의 깊이보다 크면 $i$번 정점에 적힌 번호가 $j$번 정점에 적힌 번호보다 커야 합니다.
- $l$이 적힌 정점과 $r$이 적힌 정점을 잇는 경로에 포함된 간선의 수는 $k$개여야 합니다.

이러한 번호 배치의 총개수를 구하세요. 답이 매우 커질 수 있으므로 $10^9+7$로 나눈 나머지를 구하세요.
두 번호 배치가 다르다는 것은 어떤 정점 $i$에 적힌 번호가 두 배치에서 다르다는 뜻입니다.

## 입력

```text
$d\ l\ r\ k$
```

입력은 모두 정수입니다.

## 제한

- $2 \le d \le 20$
- $1 \le l < r \le 2^d-1$
- $1 \le k \le 10^5$

## 출력

답을 한 줄에 출력하세요. 마지막에 줄바꿈을 출력하세요.
