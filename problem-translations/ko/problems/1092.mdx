## 문제 설명

소수 $P$, $N$개의 음이 아닌 정수 $A_i$($1 \le i \le N$), 그리고 $N - 1$개의 `+`, `-`, `*`, `/` 중 하나로 이루어진 문자열 $S$가 주어집니다. $S$의 $j$번째($1 \le j \le N - 1$) 문자를 $operator_j$라고 할 때, 다음 값을 계산하여 출력하세요.

$\mod P$에서 $((\dots ((A_1\ operator_1\ A_2)\ operator_2\ A_3)\ operator_3\ \dots\ A_{N-1})\ operator_{N-1}\ A_N)$

바꾸어 말하면, 연산자와 관계없이 계산 순서는 앞에서부터로 하여 계산하세요.

단, $\mod P$에서 나눗셈 `p/q`는 $p \equiv qr \pmod P$ 및 $0 \le r < P$를 만족하는 유일한 정수 $r$를 해로 정의합니다.

## 입력

```text
$P\ N$
$A_1\ A_2\ \dots\ A_N$
$S$
```

## 제한

$2 \le P \le 10^9$

$1 \le N \le 10^5$

$P$는 소수입니다.

$1 \le A_i < P$

$|S| = N - 1$

$S$는 `+`, `-`, `*`, `/`만으로 이루어집니다.

## 출력

답을 한 줄에 출력하세요. 마지막에 줄바꿈을 출력하세요.
