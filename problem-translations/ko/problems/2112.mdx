$H\times W$ 격자에 $1$부터 $HW$까지의 정수를 하나씩 배치하여 모든 인접한 $2\times2$ 블록의 네 수 합이 같은 정수 $S$가 되게 할 수 있는지 판정하고, 가능하면 하나 출력하세요.

## 입력

```text
H W
```

$2\le H,W\le1000$입니다.

## 출력

가능하면 `Yes`와 조건을 만족하는 격자를, 불가능하면 `No`를 출력하세요.
