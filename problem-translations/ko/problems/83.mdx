## 문제 설명

당신은 「최대 매칭 문제」라는 유명한 문제를 풀고 있습니다.

성냥이 몇 개 주어질 때, 성냥을 나란히 놓아 표시할 수 있는 가장 큰 수를 구하는 문제입니다.

수는 $0$부터 $9$까지의 숫자를 가로로 나열하여 표시합니다. 숫자의 표시 방법은 그림과 같습니다.

성냥을 부러뜨려서는 안 되지만, 모두 사용할 필요는 없습니다.

$N$개의 성냥이 주어질 때, 성냥을 나란히 놓아 표시할 수 있는 가장 큰 수를 구하세요.

## 입력

```text
N
```

성냥의 개수 $N$이 주어집니다. $(2 \le N \le 100\,000)$

## 출력

성냥을 나란히 놓아 표시할 수 있는 가장 큰 수를 출력하세요.

마지막에 줄 바꿈을 출력하세요.
