## 사과

Python 등의 언어로 통과할 수 있다고 보장하지 않습니다.

## 문제

원소가 $N$개인 수열 $A=\{a_1,a_2,\ldots,a_N\}$가 주어집니다. 다음 두 종류의 질의 총 $Q$개를 순서대로 처리하세요.

- set i x: $a_i$의 값을 $x$로 변경합니다.
- max l_1 l_2 r_1 r_2: 다음 값

$$\operatorname{range\_max}(l_1,l_2,r_1,r_2)=\max_{(l_1\leq l\leq l_2)\land(r_1\leq r\leq r_2)\land(l\leq r)}\sum_{k=l}^{r}a_k$$

를 출력합니다.

## 입력

~~~text
$N\ Q$
$a_1\ a_2\ \cdots\ a_N$
$query_1$
$query_2$
$\vdots$
$query_Q$
~~~

$1\leq N,Q\leq10^5$, $-10^9\leq a_i\leq10^9$입니다. set 질의는 $1\leq i\leq N$, $-10^9\leq x\leq10^9$이고, max 질의는 $1\leq l_1\leq l_2\leq N$, $1\leq r_1\leq r_2\leq N$, $l_1\leq r_2$를 만족합니다. max 질의는 하나 이상 존재합니다. 입력은 모두 정수입니다.

## 출력

각 max 질의의 값을 한 줄에 하나씩 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
5 6
1 2 -3 -4 5
max 1 2 4 5
max 1 3 2 5
max 3 4 1 5
max 1 5 3 4
set 1 -10
max 1 5 1 1
~~~

#### 출력

~~~text
1
3
1
0
-10
~~~

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
3 5
1000000000 1000000000 1000000000
max 1 3 1 3
set 1 -1000000000
set 2 -1000000000
set 3 -1000000000
max 1 1 3 3
~~~

#### 출력

~~~text
3000000000
-3000000000
~~~
