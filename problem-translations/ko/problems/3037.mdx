## 문제 설명

$N$명이 $1$줄로 앉아 있으며, 왼쪽 끝 사람부터 차례로 $1$부터 $N$까지 번호가 붙어 있습니다.

앉아 있는 사람이 일어서고, 서 있는 사람이 앉는 것을 **토글**한다고 합니다.

$1$번째 신호에서 모든 사람이 일어섭니다. $2$번째 신호에서 $2$번 사람부터 $1$명씩 건너뛰어($2$, $4$, $6$, …) 토글합니다. 그다음 신호에서는 $3$번 사람부터 $2$명씩 건너뛰어($3$, $6$, $9$, …) 토글합니다. 이와 같이 $i$번째 신호에서는 $i$의 배수 번호인 사람이 토글합니다. 마지막으로 $N$번째 신호에서는 $N$번 사람만 토글합니다.

모든 신호가 끝났을 때 서 있는 사람의 수를 구하세요.

## 입력

```text
$N$
```

입력은 표준 입력으로 주어집니다.

## 제한

- $2 \le N \le 10^{18}$

## 출력

모든 신호가 끝났을 때 서 있는 사람의 수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
6
```

#### 출력

```text
2
```

처음에는 $6$명이 $1$줄로 앉아 있으며, 왼쪽부터 차례로 $1,2,3,4,5,6$이라는 번호가 붙어 있습니다.

$1$번째 신호에서 모두 일어서므로, 현재 서 있는 사람은 ($1,2,3,4,5,6$)입니다.

$2$번째 신호에서 $2,4,6$번 사람이 앉으므로, 현재 서 있는 사람은 ($1,3,5$)입니다.

$3$번째 신호에서 $3$번 사람이 앉고 $6$번 사람이 일어섭니다. 현재 서 있는 사람은 ($1,5,6$)입니다.

$4$번째 신호에서 $4$번 사람이 일어서므로, 현재 서 있는 사람은 ($1,4,5,6$)입니다.

$5$번째 신호에서 $5$번 사람이 앉으므로, 현재 서 있는 사람은 ($1,4,6$)입니다.

$6$번째 신호에서 $6$번 사람이 앉으므로, 현재 서 있는 사람은 ($1,4$)입니다.

마지막 신호가 끝났을 때 서 있는 사람은 $2$명이므로 $2$를 출력합니다.
