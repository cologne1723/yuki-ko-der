카드 `N`장에 정수 `A_i`가 하나씩 적혀 있습니다. 적힌 수보다 정확히 1 작은 수가 적힌 카드를 가지고 있지 않은 카드들의 숫자 합을 점수로 정의합니다.

## 제약

- `1 <= N <= 33`
- `3 <= A_i <= 35`
- `A_i`는 서로 다릅니다.

## 입력

`N`과 `A_1,...,A_N`이 주어집니다.

## 출력

점수를 출력하세요.
