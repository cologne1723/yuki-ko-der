## 문제

당신은 웹 업계에서 일하며 작은 업무를 맡았습니다. 웹 서비스 이미지에 공백이 없는 영문 소문자 태그와 점수가 붙어 있는데, 인기 태그를 표시하라는 지시를 받았습니다.

태그의 점수는 그 태그가 붙은 이미지들의 점수 합으로 계산합니다. 점수가 높은 순서로 상위 10개 태그와 총점 $U_i$를 표시하세요. 점수가 같으면 사전순으로 작은 태그를 위에 표시합니다. 태그 종류가 10개 미만이면 모두 표시합니다.

## 입력

```text
N
No1
M1 S1
Tag(1,1) ... Tag(1,M1)
...
NoN
MN SN
Tag(N,1) ... Tag(N,MN)
```

첫째 줄부터 이미지 번호, 태그 수 $M$와 점수 $S$, 태그 목록이 이미지마다 주어집니다. 이미지에는 같은 태그가 중복되지 않습니다.

- $1\le N\le1000$
- $0\le No\lt N$
- $1\le M\le10$, $1\le S\le10$
- 태그는 길이 1 이상 20 이하의 영문 소문자입니다.

## 출력

상위 10개 태그를 규칙에 따라 출력하세요. 태그 종류가 10개 미만이면 전부 출력합니다.

```text
Tag1 U1
...
Tagi Ui
```

마지막에 개행을 출력하세요.
