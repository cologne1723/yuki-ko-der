## 문제

NOT 회로는 0이 입력되면 1을, 1이 입력되면 0을 출력하는 회로입니다.

NOT 회로의 동작을 하는 프로그램을 작성해 보세요.

## 입력

```text
X
```

$X$는 0 또는 1 중 하나입니다.

## 출력

입력이 0이면 1을 출력하세요.

입력이 1이면 0을 출력하세요.

마지막에 개행을 출력하는 것을 잊지 마세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
0
```

### 샘플 1 {file="sample1.out"}

```text
1
```
