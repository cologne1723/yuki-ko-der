28개의 파트 각각에 소메이요시노 또는 사토자쿠라 벚꽃 한 송이를 사용합니다. 파트 $i$의 화려함은 각각 $G_i$ 또는 $H_i$입니다. 전체 화려함의 합을 $M$으로 나눈 나머지를 부케의 아름다움이라 할 때, 소메이요시노를 정확히 $K_q$개 사용하고 아름다움이 $X_q$ 이상인 부케의 수를 각 쿼리마다 구하세요.

## 조건

- $2\le M\le10^9$, $0\le G_i,H_i<M$
- $1\le Q\le100$, $0\le K_q\le28$, $0\le X_q<M$

## 입력

```text
$M$
$G_1$ $\cdots$ $G_{28}$
$H_1$ $\cdots$ $H_{28}$
$Q$
$K_1$ $X_1$
\vdots
$K_Q$ $X_Q$
```

## 출력

각 쿼리의 답을 한 줄에 하나씩 출력하세요.
