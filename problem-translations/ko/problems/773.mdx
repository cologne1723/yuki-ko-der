## 문제

이번 달 23일, 24일, 25일에는 Paken 합숙이 있고 3일 모두 콘테스트(Day1, Day2, Day3)가 있습니다. 양 씨는 참가하려 하지만 $A$일부터 $B$일까지 여행 때문에 참가할 수 없습니다. 양 씨가 참가할 수 있는 콘테스트는 몇 개인가요?

## 입력

~~~text
$A\ B$
~~~

$1\leq A\leq B\leq31$

## 출력

참가할 수 있는 콘테스트 수를 한 줄에 출력하세요.

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text

~~~

#### 출력

~~~text
2
~~~

#### 입력

~~~text

~~~

#### 출력

~~~text
0
~~~

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text

~~~

#### 출력

