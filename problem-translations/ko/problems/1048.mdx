## 문제 설명

T군은 정수 $N$을 가지고 있습니다. 처음에 $N=0$입니다.

T군은 다음 연산을 $K$번 수행합니다.

정수 $i$($L \leq i \leq R$)를 하나 고릅니다. 그 후 $N$을 $N+i$를 $M$으로 나눈 나머지로 바꿉니다.

$K$번의 연산을 수행한 후 다시 $N=0$이 되도록 하는 연산 순서가 존재할까요? 존재한다면 `Yes`를, 존재하지 않는다면 `No`를 출력하세요.

## 입력

```text
L R M K
```

첫째 줄에 정수 $L$, $R$, $M$, $K$가 주어집니다.

## 제한

$L$, $R$, $M$, $K$는 정수입니다.

$0 \leq L \leq R \leq 10^9$

$1 \leq M \leq 10^9$

$0 \leq K \leq 10^9$

## 출력

조건을 만족하는 연산 순서가 존재한다면 `Yes`를, 존재하지 않는다면 `No`를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 7 5 2
```

#### 출력

```text
Yes
```

예를 들어 첫 번째 연산에서 $i=3$, 두 번째 연산에서 $i=7$을 고르면 $N$은 $0 \to 3 \to 0$이 됩니다.

### 예제 2 {file=""}

#### 입력

```text
2 3 4 1
```

#### 출력

```text
No
```

어떻게 $i$를 골라도 $N=0$이 되지 않습니다.

### 예제 3 {file=""}

#### 입력

```text
2 3 4 0
```

#### 출력

```text
Yes
```

연산을 수행하지 않으므로 $N=0$인 상태로 유지됩니다.

### 예제 4 {file=""}

#### 입력

```text
10 53 100 2
```

#### 출력

```text
Yes
```
