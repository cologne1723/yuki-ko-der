## 이 문제에 관하여

이 문제는 April Fool Contest 2023을 위해 제작된 문제입니다. (즉, 장난 문제입니다.)

구체적으로는 취업 시험 등에서 출제될 수 있는 표의 빈칸을 추측하는 문제를 비교적 충실하게 모방했습니다.

이 문제는 모두 오리지널 문제이며, 실제 시험에서 출제된 문제를 도용하거나 재활용한 것이 아닙니다.

문제의 표에 있는 데이터는 문제를 위해 제작된 것으로, 실제 데이터가 아니라는 점에 주의하세요.

## 문제 설명

$5$개의 소문항이 있으며, 모든 문제를 맞힌 경우에만 AC 판정을 받습니다.

각 소문항에서 표가 $1$개씩 주어집니다. 표의 【?】 부분에 들어갈 수치를 추측해 답하세요.

소문항 번호 $N$이 입력으로 주어질 때, $N$번째 문제의 답을 출력하세요.

### 소문제 $1$

![소문제 1의 표](../images/8102/1.png)

다음은 어떤 $5$명의 경쟁 프로그래머의 통계 정보를 정리한 것입니다.

표 제목은 ‘$5$명의 경쟁 프로그래머 주요 통계 정보’입니다. 열은 `레이트`, `활동 지속 연수(년)`, `푼 문제 수`, `팔로워 수`이고, 행의 이름은 `Aさん`, `Bさん`, `Cさん`, `Dさん`, `Eさん`입니다.

### 소문제 $2$

![소문제 2의 표](../images/8102/2.png)

다음은 어떤 서비스의 이용자에게 가입 계기를 설문 조사한 결과입니다.

표 제목은 ‘연도별 가입 계기 선택 인원’입니다. 열은 각 연도이고, 행은 `지인에게 권유받아서`, `취업 활동에 도움이 되어서`, `수업에 도움이 되어서`, `사장이 재미있어서`, `프로그래밍을 좋아해서`, `수학을 좋아해서`, `경우의 수 세기를 좋아해서`입니다.

### 소문제 $3$

![소문제 3의 표](../images/8102/3.png)

다음은 어떤 슈퍼마켓에서 판매한 과자 세트의 구성과 가격입니다.

표 제목은 ‘각 세트 상품의 구성과 가격’입니다. 열은 `세트 A`부터 `세트 F`까지이고, 행은 `초콜릿(개)`, `센베이(개)`, `쿠키(개)`, `마시멜로(개)`, `가쓰오부시(개)`, `가격(엔)`입니다.

### 소문제 $4$

![소문제 4의 표](../images/8102/4.png)

다음은 경쟁 서비스의 핵심 사용자 수 추이를 조사한 결과입니다.

표 제목은 ‘각 서비스의 핵심 사용자 수 추이’입니다. 열은 `연도`이고, 행은 `서비스 A`, `서비스 Y`, `서비스 C`입니다.

### 소문제 $5$

![소문제 5의 표](../images/8102/5.png)

다음은 어떤 대관 장소의 운영에 관한 통계 데이터(2023년도)입니다.

표 제목은 ‘각 이벤트의 통계 정보’입니다. 열은 `이벤트 A`부터 `이벤트 F`까지이고, 행은 `이용자 수(명)`, `사용 홀 수`, `대여 기간(일)`, `이용 시작일`, `비용(만 엔)`입니다.

## 입력

정수 $N$이 주어집니다.

```text
$N$
```

## 제한

- $1 \le N \le 5$

## 출력

$N$번째 표의 빈칸에 들어갈 수치를 $1$번째 줄에 출력하고, 마지막에 줄바꿈하세요.
