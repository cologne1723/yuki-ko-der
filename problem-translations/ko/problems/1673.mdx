일렬로 놓인 `N`개의 램프가 처음에는 모두 꺼져 있습니다. `i`번째 작업에서 `L_i`번째부터 `R_i`번째까지의 램프를 토글합니다.

각 작업 후 켜져 있는 램프의 개수를 출력하세요.

## 제약

- `1 <= N <= 5 * 10^5`
- `1 <= Q <= 10^5`
- `1 <= L_i <= R_i <= N`

## 입력

`N Q`와 각 작업의 구간 `L_i R_i`가 주어집니다.

## 출력

각 작업 후 켜진 램프 수를 한 줄에 하나씩 출력하세요.
