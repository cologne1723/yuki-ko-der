## 문제 설명

길이와 합이 같은 두 음이 아닌 정수 수열 $X=(X_1,X_2,\dots,X_n)$과 $Y=(Y_1,Y_2,\dots,Y_n)$에 대해, $X$에 다음 연산을 반복하여 $Y$와 같게 만드는 데 필요한 연산 횟수의 최솟값을 $f(X,Y)$라고 합니다.

- $1 \leq i \leq n$이고 $X_i>0$인 정수 $i$와, $1 \leq j \leq n$이고 $|i-j|=1$인 정수 $j$를 고릅니다. $X_i$를 $X_i-1$로, $X_j$를 $X_j+1$로 바꿉니다.

길이 $N$의 음이 아닌 정수 수열 $A=(A_1,A_2,\dots,A_N)$가 주어집니다. $A$와 길이 및 합이 같은 모든 음이 아닌 정수 수열 $B$에 대한 $f(A,B)$의 합을 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

```text
$N$
$A_1\ A_2\ \dots\ A_N$
```

## 제한

- 입력으로 주어지는 모든 수는 정수입니다.
- $2 \leq N \leq 10^6$
- $0 \leq A_i$
- $1 \leq \sum_{i=1}^{N} A_i \leq 10^6$

## 출력

가능한 모든 $B$에 대한 $f(A,B)$의 합을 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 0 1
```

#### 출력

```text
8
```

가능한 $B$는 $(0,0,2),(0,1,1),(0,2,0),(1,0,1),(1,1,0),(2,0,0)$의 $6$가지입니다.

$B=(0,0,2)$일 때, 다음과 같이 두 번의 연산으로 $A$를 $B$와 같게 만들 수 있으며 이것이 최소 연산 횟수입니다.

1. $i=1,j=2$를 고릅니다. $A=(0,1,1)$이 됩니다.
2. $i=2,j=3$을 고릅니다. $A=(0,0,2)$가 됩니다.

다른 $B$에 대한 $f(A,B)$의 값은 다음과 같습니다.

- $B=(0,1,1)$이면 $f(A,B)=1$입니다.
- $B=(0,2,0)$이면 $f(A,B)=2$입니다.
- $B=(1,0,1)$이면 $f(A,B)=0$입니다.
- $B=(1,1,0)$이면 $f(A,B)=1$입니다.
- $B=(2,0,0)$이면 $f(A,B)=2$입니다.

따라서 답은 $2+1+2+0+1+2=8$입니다.
