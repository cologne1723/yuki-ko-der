한 번 뽑을 때 확률 $p$로 희귀 캐릭터를 얻습니다. 또한 뽑기를 $K$번 하면 반드시 희귀 캐릭터를 얻습니다. 희귀 캐릭터를 얻을 때까지 뽑기를 계속할 때 뽑기 횟수의 기댓값을 구하세요.

## 입력

```text
T
p K
```

## 출력

각 테스트 케이스의 기댓값을 오차 $10^{-5}$ 이하로 출력하세요.
