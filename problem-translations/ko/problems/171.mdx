## 문제 설명

길이 $1\,000$ 이하의 문자열 $S$가 주어집니다. 문자열 $S$에서 임의의 이웃한 $2$개의 문자를 교환하는 조작을 원하는 횟수만큼 할 수 있을 때, 만들 수 있는 문자열 종류의 수를 $573$으로 나눈 나머지를 구하세요.

입력 문자열 $S$와 같은 문자열은 세지 않습니다. $573$은 **소수가 아니라는** 점에 주의하세요.

## 입력

```text
$S$
```

$1$번째 줄에 문자열 $S$가 주어집니다.

## 제한

- $1 \le |S| \le 1\,000$
- $S$는 대문자 영문 알파벳(`A`~`Z`)으로만 이루어집니다.

## 출력

조작으로 만들 수 있는 문자열 중 입력 문자열 자체를 제외한 종류의 수를 $573$으로 나눈 나머지를 정수로 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
ABC
```

#### 출력

```text
5
```

`ABC`의 이웃한 $2$개의 문자를 여러 번 교환하면 `ABC`, `ACB`, `BAC`, `BCA`, `CAB`, `CBA`의 $6$가지 문자열을 만들 수 있고, 입력 문자열을 제외하면 $5$가지입니다.

### 예제 2 {file=""}

#### 입력

```text
DDDDDD
```

#### 출력

```text
0
```

아무리 교환해도 `DDDDDD` 외에는 만들 수 없습니다. 입력 문자열 자체는 세지 않으므로 `DDDDDD`를 제외한 $0$종류가 답입니다.

### 예제 3 {file=""}

#### 입력

```text
ABCDEFGHIJKLMNOPQRSTUVWXYZ
```

#### 출력

```text
551
```

만들 수 있는 문자열은 $403\,291\,461\,126\,605\,635\,583\,999\,999$종류입니다. $573$으로 나눈 나머지를 구하는 것을 잊지 마세요.
