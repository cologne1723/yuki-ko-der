## 문제 설명

길이 1000 이하의 문자열 $S$가 주어집니다. 문자열 $S$에서 임의의 이웃한 두 문자를 교환하는 조작을 원하는 횟수만큼 할 수 있을 때, 만들 수 있는 문자열 종류의 수를 573으로 나눈 나머지를 구하세요.

입력 문자열 $S$와 같은 문자열은 세지 않습니다. 573은 소수가 아니라는 점에 주의하세요.

## 입력

```text
S
```

- $1 \le |S| \le 1000$
- $S$는 대문자 영문 알파벳으로만 이루어집니다.

## 출력

조작으로 만들 수 있는 문자열 중 입력 문자열 자체를 제외한 종류의 수를 573으로 나눈 나머지를 정수로 출력하세요.

## 예제

### 예제 1 {file=""}

```text
ABC
```

```text
5
```

`ABC`의 이웃한 두 문자를 여러 번 교환하면 6가지 문자열을 만들 수 있고, 입력 문자열을 제외하면 5가지입니다.

### 예제 2 {file=""}

```text
DDDDDD
```

```text
0
```

아무리 교환해도 `DDDDDD` 외에는 만들 수 없습니다.

### 예제 3 {file=""}

```text
ABCDEFGHIJKLMNOPQRSTUVWXYZ
```

```text
551
```

만들 수 있는 문자열은 $403291461126605635583999999$종류입니다. 573으로 나누는 것을 잊지 마세요.
