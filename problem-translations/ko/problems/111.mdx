## 문제 설명

“아바바바바바바, 바아!”

호키치가 여자를 뒤에 둔 채 자신도 모르게 히죽히죽 웃기 시작했습니다.

이는 아쿠타가와 류노스케의 [아바바바바](http://www.aozora.gr.jp/cards/000879/card14.html)에서 인용한 문장입니다.

왜 호키치는 “히죽히죽 웃기 시작했을까요?”

짐작하셨듯이 “아바바바바바바”를 로마자로 바꾼 문자열 `ababababababa`가 회문이기 때문입니다.

문자열 $S$는 `a` 뒤에 `ba`가 여러 번 이어지는 길이 $L$인 문자열입니다. 길이 $L$이 주어지면 $S$는 유일하게 정해집니다. 예를 들어 $L=3$이면 $S$는 `aba`, $L=5$이면 `ababa`입니다.

$L$이 주어질 때 대응하는 $S$에 길이 $2$ 이상인 회문이 몇 개 포함되는지 구하세요.

회문은 앞에서 읽어도 뒤에서 읽어도 같은 문자열입니다. 엄밀히 말해 $S$의 $i$번째 문자를 $S_i$라고 할 때, $i \le j$이고 $0 \le k \le j-i$인 모든 $k$에 대해 $S_{i+k}=S_{j-k}$이면 문자열 $S_i+S_{i+1}+\cdots+S_j$는 길이 $j-i+1$인 회문입니다.

예를 들어 `ababa`는 앞뒤로 읽어도 같으므로 길이 $5$인 회문입니다. 반면 `abab`는 뒤에서 읽으면 `baba`가 되어 앞에서 읽은 것과 다르므로 회문이 아닙니다.

## 입력

```text
$L$
```

`a` 뒤에 `ba`가 여러 번 이어지는 문자열의 길이 $L$이 주어집니다.

## 제한

- $3 \le L < 1\,000\,000\,000$
- $L$은 홀수입니다.

## 출력

문자열에 포함된 길이 $2$ 이상인 회문의 개수를 한 줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
```

#### 출력

```text
4
```

문자열의 길이는 $5$이므로 대응하는 문자열은 `ababa`입니다. `aba` 회문 $2$개, `bab` 회문 $1$개, `ababa` 회문 $1$개가 포함되어 있습니다.

### 예제 2 {file=""}

#### 입력

```text
9
```

#### 출력

```text
16
```

문자열은 `ababababa`입니다.

### 예제 3 {file=""}

#### 입력

```text
200001
```

#### 출력

```text
10000000000
```
