## 문제

상품이 `N`개 있고, `i`번째 상품의 가격은 `A_i`엔, 가치가 `B_i`입니다.

오늘 사용할 수 있는 `M`엔 상품권과 내일 사용할 수 있는 `Q`엔 상품권이 각각 하나씩 있습니다. 오늘 상품을 몇 개 골라 가격 합계가 `M` 이하가 되도록 사고, 내일 상품을 몇 개 골라 가격 합계가 `Q` 이하가 되도록 삽니다. 각 상품은 최대 한 번만 살 수 있습니다. 상품권을 다 쓰지 않아도 되고, 초과 지불하더라도 거스름돈은 받지 않습니다.

얻을 수 있는 가치의 합의 최댓값을 구하세요.

## 제약

- `1 ≤ N ≤ 20`
- `1 ≤ M, Q ≤ 10^9`
- `1 ≤ A_i, B_i ≤ 10^9`

## 입력

입력은 다음 형식으로 주어집니다.

```text
N M Q
A_1 B_1
⋮
A_N B_N
```

## 출력

답을 한 줄에 출력하세요.
