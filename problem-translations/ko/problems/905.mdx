## 문제 설명

길이가 $N$인 정수 수열 $A$와 인덱스 쌍 $l, r$이 주어집니다. 연속 부분 수열 $[A_l, A_{l+1}, \ldots, A_{r-1}, A_r]$이 단조 비감소 수열인지, 단조 비증가 수열인지 각각 판별하세요.

답은 다음과 같이 정의한 두 함수 $f(l, r), g(l, r)$의 값을 이 순서대로 공백으로 구분하여 출력하면 됩니다.

- $f(l, r)$은 부분 수열 $[A_l, A_{l+1}, \ldots, A_{r-1}, A_r]$이 단조 비감소 수열이면 $1$, 그렇지 않으면 $0$입니다.
- $g(l, r)$은 부분 수열 $[A_l, A_{l+1}, \ldots, A_{r-1}, A_r]$이 단조 비증가 수열이면 $1$, 그렇지 않으면 $0$입니다.

이 문제에서 수열 $A_0, \ldots, A_k$가 단조 비감소 수열이라는 것은 모든 $0 \le i < k$에 대해 $A_i \le A_{i+1}$이라는 뜻입니다. 단조 비증가 수열이라는 것은 모든 $0 \le i < k$에 대해 $A_i \ge A_{i+1}$이라는 뜻입니다.

단, 길이가 $1$인 부분 수열은 단조 비감소 수열이면서 단조 비증가 수열이라고 합니다.

인덱스 쌍 $l, r$은 $Q$쌍 주어지므로 모두 처리하세요.

## 입력

```text
$N$
$A_0\ \cdots\ A_{N-1}$
$Q$
$l_0\ r_0$
$\vdots$
$l_{Q-1}\ r_{Q-1}$
```

## 제한

- $1 \le N \le 10^5$
- $-10^{18} \le A_i \le 10^{18}$ ($0 \le i < N$)
- $1 \le Q \le 10^5$
- $0 \le l_i \le r_i \le N-1$ ($0 \le i < Q$)
- 입력은 모두 정수입니다.

## 출력

$Q$줄을 출력하세요. 각 인덱스 쌍 $l_i, r_i$에 대해 $f(l_i, r_i), g(l_i, r_i)$를 이 순서대로 공백으로 구분하여 한 줄에 출력하세요. 인덱스 쌍이 입력된 순서대로 출력하고, 마지막에도 줄바꿈을 출력하세요.
