## 문제

당신은 경쟁 프로그래밍을 하는 사람이며, 친구 31536000의 부탁으로 문제의 테스터가 되었습니다.

문제는 다음과 같습니다.

값 3개가 주어집니다. 그중 2개를 더해서 만들 수 있는 값들 중 두 번째로 큰 값을 출력하세요.

이 문제를 읽고 바로 코드를 작성해 제출했지만 일부 테스트 케이스만 통과하지 않았습니다. 이상하게 생각하여 테스트 케이스를 확인해 보니, 일부 테스트 케이스만 줄바꿈으로 구분되지 않고 공백으로 구분되어 있었습니다. 그래서 잘못된 테스트 케이스에 대해서는 그 사실을 출력하기로 했습니다.

## 입력

~~~text
N
A_1
\vdots
A_N
~~~

- $N=3$
- $1\leq A_i\leq 10^{10}$
- $A_1\ne A_N$
- 모든 입력은 정수입니다.

## 출력

두 값을 더해서 만들 수 있는 값들 중 두 번째로 큰 값을 출력하세요.

단, 입력 형식이 다음과 같다면 대신 `"assert"`를 출력하세요.

~~~text
N
A_1 \ \cdots \ A_N
~~~

어느 경우든 마지막에 줄바꿈을 출력하세요.

이 문제에서 두 번째로 큰 값은 큰 순서로 두 번째인 값을 뜻합니다. (테스트 케이스 2에는 오류가 없습니다.)

## 샘플

### 샘플 1 {file=""}

#### 입력

~~~text
3
1
5
3
~~~

#### 출력

~~~text
6
~~~

1+5, 1+3, 5+3 중 두 번째로 큰 값은 6입니다.

### 샘플 2 {file=""}

#### 입력

~~~text
3
3
3
4
~~~

#### 출력

~~~text
6
~~~

3+3, 3+4, 3+4 중 두 번째로 큰 값은 6입니다. 가능한 값이 6과 7 두 개뿐이므로 두 번째로 큰 값이 6이 되는 것에 주의하세요.

### 샘플 3 {file=""}

#### 입력

~~~text
3
1 5 3
~~~

#### 출력

~~~text
"assert"
~~~

잘못된 테스트 케이스이므로 `"assert"`를 출력합니다.
