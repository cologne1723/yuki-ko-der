## 문제

정의된 함수 `f(N,M)`에 대해 다음 값을 계산합니다. 매 게임에서 앞면이 나올 확률이 현재 `Z`인 동전을 던집니다. 처음에는 `Y=Z=1`입니다.

`i`번째 게임에서 앞면이면 `Y×(-1)^{i+1}`점을 얻고, `Z`를 `i^{M-1}/(i+1)^M×Z`로, `Y`를 `(N-i)×Y`로 바꿉니다. `N`회 후 점수 합의 기댓값을 `f(N,M)`이라 합니다.

`K`가 주어질 때

\[
\sum_{a=1}^{K}\sum_{b=1}^{\infty}\frac{f(b,2a-1)}b
\]

을 `c_0+c_1\pi+\cdots+c_{2K}\pi^{2K}`로 나타낸 계수 `c_i`를 `998244353`로 나눈 값을 출력하세요.

## 입력

`K`가 주어집니다.

## 출력

계수 `c_0,...,c_{2K}`를 공백으로 구분해 출력하세요.
