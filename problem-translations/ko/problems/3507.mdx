## 문제 설명

길이 $N$인 배열 $A=(A_0,A_1,...,A_{N-1})$이 주어집니다. 여기서 각 $A_i$는 $0$ 이상인 정수입니다.

다음 $3$종류의 질의를 총 $Q$회 처리하세요.

여기서 $\text{isqrt}(x)$는 $\sqrt{x}$의 정수 부분을 반환하는 함수, 즉 $\text{isqrt}(x) := \left\lfloor \sqrt{x}\right\rfloor$입니다.

- $0\ l\ r$: $A_l+A_{l+1}+...+A_{r-1}$을 출력합니다.
- $1\ l\ r\ x$: $A_l,A_{l+1},...,A_{r-1}$에 $x$를 대입합니다.
- $2\ l\ r$: $A_l,A_{l+1},...,A_{r-1}$ 모두에 $\text{isqrt}$를 적용합니다. 즉, $l \leq i < r$를 만족하는 모든 $i$에 대해 $A_i$를 $\text{isqrt}(A_i)$로 치환합니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ Q$
$A_0\ A_1\ \cdots\ A_{N-1}$
$\text{query}_1$
$\text{query}_2$
$\vdots$
$\text{query}_Q$
```

$\text{query}_i$는 $i$번째 질의를 나타내며, 다음 형식 중 $1$개로 주어집니다.

```text
$0\ l\ r$
$1\ l\ r\ x$
$2\ l\ r$
```

## 제한

- $1 \leq N \leq 10^5$
- $1 \leq Q \leq 10^5$
- $0 \leq A_i \leq 10^9$
- $0 \leq l \leq r \leq N$
- $0 \leq x \leq 10^9$
- 입력은 모두 정수입니다.

## 출력

합을 구하는 $0$번 질의의 개수를 $k$라고 할 때, $k$개의 줄에 걸쳐 출력하세요.

$i$번째 줄에는 $i$번째 합을 구하는 $0$번 질의에 대한 답을 출력하세요.
