$N$자리 양의 정수 $X$ 이하인 깨지기 쉬운 11의 배수의 개수를 $998244353$으로 나눈 나머지를 구하세요. 10 이상인 수가 11의 배수이고, 십진 표기에서 한 자리 숫자를 삭제해 만든 모든 양의 정수가 11의 배수가 아니면 깨지기 쉬운 수입니다.

## 조건

- $1\le N\le100$
- $X$는 $N$자리 양의 정수입니다.

## 입력

```text
N
X
```

## 출력

답을 출력하세요.
