길이 $N$의 비음수 정수열 $A$가 주어진다냥. $2\le i\le N$인 $i$를 골라 $A_i$를 $A_i\mathbin{\vert}A_{i-1}$로 바꾸는 연산을 원하는 만큼 할 수 있다냥. 연산 후 만들 수 있는 서로 다른 수열의 개수를 구하라냥.

## 조건

- $1\le N\le2\times10^5$
- $0\le A_i<2^{30}$

## 입력

```text
N
A_1 A_2 \cdots A_N
```

## 출력

가능한 수열의 개수를 $998244353$으로 나눈 나머지를 출력하라냥.
