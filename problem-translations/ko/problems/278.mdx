## 문제 설명

다음 명제를 생각합니다.

> 연속하는 $N$개의 양의 정수의 합은 $X$로 나누어떨어진다.

양의 정수 $N$이 주어질 때, 이 명제가 참이 되도록 하는 모든 양의 정수 $X$의 **합**을 구하세요.

### 배경

중학교 수학에서는 “연속하는 $3$개의 양의 정수의 합은 $3$으로 나누어떨어진다”라는 명제가 참임을 증명합니다.

위 명제는 이를 조금 일반화한 것입니다.

## 입력

```text
$N$
```

$1$줄에 $N$이 주어집니다.

## 제한

- $1 \le N \le 2\times 10^{12}$

## 출력

```text
$\sum X$
```

명제를 참이 되게 하는 양의 정수 $X$의 합을 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
```

#### 출력

```text
4
```

$X=1,3$일 때 명제가 참이므로 답은 $1+3=4$입니다.

### 예제 2 {file=""}

#### 입력

```text
2
```

#### 출력

```text
1
```

$X=1$일 때만 명제가 참입니다.

### 예제 3 {file=""}

#### 입력

```text
1145148931919
```

#### 출력

```text
1145148931920
```
