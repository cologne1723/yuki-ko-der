## 문제

중학교 수학에서는 “연속하는 3개의 양의 정수의 합은 3으로 나누어떨어진다”라는 명제가 참임을 증명합니다.

이를 조금 일반화하여 다음 명제를 생각합니다.

> 연속하는 $N$개의 양의 정수의 합은 $X$로 나누어떨어진다.

양의 정수 $N$이 주어질 때, 이 명제가 참이 되도록 하는 모든 양의 정수 $X$의 합을 구하세요.

## 입력

```text
N
```

한 줄에 $N$이 주어집니다.

- $1 \le N \le 2\times 10^{12}$

## 출력

명제를 참이 되게 하는 양의 정수 $X$의 합을 한 줄에 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
3
```

### 샘플 1 {file="sample1.out"}

```text
4
```

$X=1,3$일 때 명제가 참이므로 답은 $1+3=4$입니다.

### 샘플 2 {file="sample2.in"}

```text
2
```

### 샘플 2 {file="sample2.out"}

```text
1
```

$X=1$일 때만 명제가 참입니다.

### 샘플 3 {file="sample3.in"}

```text
1145148931919
```

### 샘플 3 {file="sample3.out"}

```text
1145148931920
```
