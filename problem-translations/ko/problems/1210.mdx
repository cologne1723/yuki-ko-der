## 문제 설명

세로 $N$행, 가로 $M$열의 격자가 있습니다. $N$개의 정수 $A_i$와 $M$개의 정수 $B_j$가 주어집니다. 모든 칸에 $2^X$ 미만인 음이 아닌 정수를 써서 $i$행의 모든 수의 XOR이 $A_i$, $j$열의 모든 수의 XOR이 $B_j$가 되도록 하려 합니다. 가능한 작성 방법의 수를 $10^9+7$로 나눈 나머지를 구하세요.

## 입력

```text
N M X
A_1 \ldots A_N
B_1 \ldots B_M
```

- $1\leq N,M\leq 2\times10^5$
- $1\leq X\leq 60$
- $0\leq A_i,B_j<2^X$

## 출력

가능한 작성 방법의 수를 $10^9+7$으로 나눈 나머지를 출력하세요. 마지막에 줄바꿈을 넣으세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}
#### 입력
```text
2 2 1
1 0
0 1
```
#### 출력
```text
2
```

### 예제 2 {file="01_sample_02.txt"}
#### 입력
```text
1 1 60
12345
67890
```
#### 출력
```text
0
```

#### 입력
```text
10 8 60

941 749 221 649 397 613 804 883
```
#### 출력
```text
542426066
```
