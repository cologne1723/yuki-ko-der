## 문제

$N$을 서로 다른 소수의 합으로 나타낼 수 있다면, 그중 항의 개수가 가장 많은 경우의 개수 $M$을 출력하세요.

## 입력

```text
$N$
```

$1\leq N\leq20000$ (정수)

## 출력

```text
$M$
```

소수 하나만으로 나타내는 경우도 포함합니다.

서로 다른 소수의 합으로 나타낼 수 없다면 `-1`을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
18
```

출력:

```text
3
```

`7+11`과 `2+5+11`이 있지만, `2+5+11` 쪽이 항의 개수가 많으므로 3입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
4
```

출력:

```text
-1
```

4의 경우 `2+2`가 있지만 같은 소수가 포함되어 있으므로 조건을 만족하지 않습니다.

서로 다른 소수의 합으로 나타낼 수 없으므로 `-1`을 출력합니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
3344
```

출력:

```text
41
```
