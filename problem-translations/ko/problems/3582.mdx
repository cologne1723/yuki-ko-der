## 문제 설명

처음에 $2$개의 양의 정수 $N$, $Q$가 주어집니다.

집합 $X$가 처음에는 공집합으로 주어집니다.

이후 설명할 $Q$개의 쿼리를 주어진 순서대로 처리하여 $X$를 갱신하고, 모든 쿼리의 처리를 마친 시점에 다음 조건이 성립하는지 판정하세요.

- 모든 $N$차원 정수 벡터가 $X$에 속한다.

각 쿼리는 $N$ 이하의 음이 아닌 정수 $A$, $B$와 정수 $M$, 그리고 $N$ 이하의 양의 정수만을 원소로 가지는 원소 수 $A$의 집합 $S$, $N$ 이하의 양의 정수만을 원소로 가지는 원소 수 $B$의 집합 $T$의 튜플 $(A,B,M,S,T)$입니다.

쿼리 $(A,B,M,S,T)$를 처리할 때는 부등식

$\sum_{i \in S} x_i \leq M + \sum_{j \in T} x_j$

를 만족하는 모든 $N$차원 정수 벡터 $x$를 $X$에 삽입하여 $X$를 갱신하세요.

단, $N$차원 정수 벡터 $x$와 $N$ 이하의 양의 정수 $i$에 대하여 $x_i$는 $x$의 $i$번째 성분을 나타냅니다.

## 입력

입력은 다음 형식으로 표준 입력에서 $3Q+1$줄에 걸쳐 주어집니다.

```text
$N\ Q$
$(1\text{번째 쿼리})$
$\vdots$
$(Q\text{번째 쿼리})$
```

- $1$번째 줄에 $N$, $Q$가 공백으로 구분되어 주어집니다.
- $Q$ 이하의 각 양의 정수 $q$에 대하여, $q$번째 쿼리가 $3q-1$번째 줄부터 $3q+1$번째 줄까지 $3$줄에 걸쳐 주어집니다.

각 쿼리 $(A,B,M,S,T)$는 다음 형식으로 $3$줄에 걸쳐 주어집니다.

- $1$번째 줄에 $A$, $B$, $M$이 공백으로 구분되어 주어집니다.
- $2$번째 줄에 문자 `S`와 $S$의 각 원소가 오름차순으로 공백으로 구분되어 주어집니다.
- $3$번째 줄에 문자 `T`와 $T$의 각 원소가 오름차순으로 공백으로 구분되어 주어집니다.

```text
$A\ B\ M$
$\texttt{S}\ S$
$\texttt{T}\ T$
```

## 제한

입력은 다음 제한을 만족합니다.

- $N$은 $1 \leq N \leq 10^3$을 만족하는 정수입니다.
- $Q$는 $1 \leq Q \leq 10^3$을 만족하는 정수입니다.
- $Q$ 이하의 임의의 양의 정수 $q$에 대하여, $q$번째 쿼리 $(A,B,M,S,T)$는 다음을 만족합니다.
  - $A$는 $0 \leq A \leq N$을 만족하는 정수입니다.
  - $B$는 $0 \leq B \leq N$을 만족하는 정수입니다.
  - $M$은 $-10^9 \leq M \leq 10^9$를 만족하는 정수입니다.
  - $S$는 $N$ 이하의 양의 정수만을 원소로 가지는 원소 수 $A$의 집합입니다.
  - $T$는 $N$ 이하의 양의 정수만을 원소로 가지는 원소 수 $B$의 집합입니다.
- **$N$ 이하의 임의의 양의 정수 $i$에 대하여, 다음 $2$개의 수의 합은 $2$ 이하입니다.**
  - 쿼리 $(A,B,M,S,T)$ 중 $i \in S$를 만족하는 것의 개수
  - 쿼리 $(A,B,M,S,T)$ 중 $i \in T$를 만족하는 것의 개수

## 출력

모든 쿼리의 처리를 마친 시점에 조건 "모든 $N$차원 정수 벡터가 $X$에 속한다"가 성립하면 `Yes`를, 그렇지 않으면 `No`를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1
1 0 1
S 1
T
```

#### 출력

```text
No
```

$1$번째 쿼리 $(1,0,1,\{1\},\{\})$에 의해 $X$는 공집합 $\{\}$에서

$\displaystyle \{\} \cup \left\{x \in \mathbb{Z}^1 \middle| \sum_{i \in \{1\}} x_i \leq 1 + \sum_{j \in \{\}} x_j \right\} = \{x \in \mathbb{Z}^1 \mid x_1 \leq 1\}$

로 바뀝니다. 예를 들어 $N=1$차원 정수 벡터 $(2)$는 $X$에 속하지 않습니다.

### 예제 2 {file=""}

#### 입력

```text
1 2
1 0 0
S 1
T
0 1 1
S
T 1
```

#### 출력

```text
Yes
```

$1$번째 쿼리 $(1,0,0,\{1\},\{\})$에 의해 $X$는 공집합 $\{\}$에서

$\displaystyle \{\} \cup \left\{x \in \mathbb{Z}^1 \middle| \sum_{i \in \{1\}} x_i \leq 0 + \sum_{j \in \{\}} x_j \right\} = \{x \in \mathbb{Z}^1 \mid x_1 \leq 0\}$

로 바뀝니다. 이어서 $2$번째 쿼리 $(0,1,1,\{\},\{1\})$에 의해 $X$는

$\displaystyle \{x \in \mathbb{Z}^1 \mid x_1 \leq 0\} \cup \left\{x \in \mathbb{Z}^1 \middle| \sum_{i \in \{\}} x_i \leq 1 + \sum_{j \in \{1\}} x_j \right\} = \{x \in \mathbb{Z}^1 \mid x_1 \leq 0 \lor 0 \leq 1 + x_1\} = \mathbb{Z}^1$

로 바뀝니다. 특히 모든 $N=1$차원 정수 벡터가 $X$에 속합니다.

### 예제 3 {file=""}

#### 입력

```text
2 2
0 2 2
S
T 1 2
2 0 -1
S 1 2
T
```

#### 출력

```text
Yes
```

$1$번째 쿼리 $(0,2,2,\{\},\{1,2\})$에 의해 $X$는 공집합 $\{\}$에서

$\displaystyle \{\} \cup \left\{x \in \mathbb{Z}^2 \middle| \sum_{i \in \{\}} x_i \leq 2 + \sum_{j \in \{1,2\}} x_j \right\} = \{x \in \mathbb{Z}^2 \mid 0 \leq 2 + x_1 + x_2\}$

로 바뀝니다. 이어서 $2$번째 쿼리 $(2,0,-1,\{1,2\},\{\})$에 의해 $X$는

$\displaystyle \{x \in \mathbb{Z}^2 \mid 0 \leq 2 + x_1 + x_2\} \cup \left\{x \in \mathbb{Z}^2 \middle| \sum_{i \in \{1,2\}} x_i \leq -1 + \sum_{j \in \{\}} x_j \right\} = \{x \in \mathbb{Z}^2 \mid 0 \leq 2 + x_1 + x_2 \lor x_1 + x_2 \leq -1\} = \mathbb{Z}^2$

로 바뀝니다. 특히 모든 $N=2$차원 정수 벡터가 $X$에 속합니다.
