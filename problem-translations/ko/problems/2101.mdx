수열 $A$가 매일 낮에, $d\ge T_i$이고 현재 양수인 모든 $i$에 대해 $i$번째 값이 $1$씩 감소합니다. $0$일 밤에 받은 수열에 대해 $D_q$일 밤의 구간 합을 각 질의마다 구하세요.

## 입력

```text
N
A_1 T_1
...
A_N T_N
Q
D_1 L_1 R_1
...
D_Q L_Q R_Q
```

$1\le N,Q\le2\times10^5$입니다.

## 출력

각 질의의 구간 합을 출력하세요.
