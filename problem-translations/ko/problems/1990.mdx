처음에 모든 원소가 $0$인 길이 $N$의 수열 $A$가 있습니다. $A_i$와 $A_{i+1}$의 홀짝이 같아지는 인덱스 $i$를 골라 두 원소에 $1$씩 더하는 조작을 반복할 수 있습니다.

이 조작으로 $A$를 주어진 수열 $B$와 같게 만들 수 있는지 판정하세요.

## 입력

```text
N
B_1 B_2 ... B_N
```

$2\le N\le2\times10^5$, $0\le B_i\le10^9$입니다.

## 출력

가능하면 `Yes`, 불가능하면 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
2 3 1 0
```

#### 출력

```text
Yes
```

### 예제 2 {file=""}

#### 입력

```text
3
1 2 1
```

#### 출력

```text
No
```

### 예제 3 {file=""}

#### 입력

```text
5
100 0 100 0 100
```

#### 출력

```text
No
```

### 예제 4 {file=""}

#### 입력

```text
5
3 5 3 2 1
```

#### 출력

```text
No
```

### 예제 5 {file=""}

#### 입력

```text
6
1 2 3 3 2 1
```

#### 출력

```text
Yes
```
