구간 $(l_i,r_i)$가 주어집니다. 모든 $i$에 대해 $l_i\le k+P_i\le r_i$가 되는 순열 $P$가 존재하는 정수 $k$의 개수를 구하세요.

## 조건

- $1\le n\le2\times10^5$
- $1\le l_i\le r_i\le10^9$

## 입력

```text
$n$
$l_1$ $r_1$
\vdots
$l_n$ $r_n$
```

## 출력

조건을 만족하는 정수 $k$의 개수를 출력하세요.
