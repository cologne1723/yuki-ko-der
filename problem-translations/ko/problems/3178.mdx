## 문제 설명

양의 정수 $N$이 주어집니다. $N$을 십진수로 나타냈을 때 각 자리를, 가장 높은 자리가 $0$이 되지 않도록 자유롭게 재배열할 수 있습니다. 이때 만들 수 있는 서로 다른 양의 정수의 개수를 구하세요.

답이 매우 커질 수 있으므로, 답을 $998\,244\,353$으로 나눈 나머지를 출력하세요.

(21:48 추가) 일부 테스트 케이스에는 앞에 $0$이 오는 테스트 케이스가 있습니다. 모든 테스트 케이스에서 자릿수(문자 수)는 $200\,000$ 이하입니다.

(22:26 추가) 앞에 $0$이 오는 경우에는 입력에 포함된 $0$을 모두 정확히 사용하고, 가장 높은 자리가 $0$이 되지 않도록 재배열하는 경우의 수를 답으로 출력하세요.

## 입력

입력은 표준 입력으로 주어집니다.

```text
$N$
```

## 제한

- $1 \leq N < 10^{200\,000}$
- $N$은 정수입니다.
- (21:48 추가) 일부 테스트 케이스에는 앞에 $0$이 오는 테스트 케이스가 있습니다.

## 출력

$998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
120
```

#### 출력

```text
4
```

$102$, $120$, $201$, $210$, 총 $4$개의 수를 만들 수 있습니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
9
```

#### 출력

```text
1
```

만들 수 있는 수는 $9$의 $1$가지뿐입니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
1942
```

#### 출력

```text
24
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
1944
```

#### 출력

```text
12
```

### 예제 5 {file="01_sample_05.txt"}

#### 입력

```text
11123456789995
```

#### 출력

```text
212565247
```

구하는 경우의 수는 $1\,210\,809\,600$이지만, $998\,244\,353$으로 나눈 나머지인 $212\,565\,247$을 출력해야 합니다.
