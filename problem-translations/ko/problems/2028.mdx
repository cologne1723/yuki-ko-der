카드 $N$장이 일렬로 놓여 있고 카드 $i$에는 $A_i$가 적혀 있습니다. 현재 남은 카드 수를 $M$이라 할 때, 왼쪽에서 $i$번째인 카드 중 $i$가 짝수인 카드를 골라 제거하는 조작을 정확히 $K$번 합니다.

제거한 카드에 적힌 수의 합의 최댓값을 구하세요.

## 입력

```text
N K
A_1 A_2 ... A_N
```

$2\le N\le2\times10^5$, $1\le K<N$입니다.

## 출력

최댓값을 출력하세요.
