## 문제

모든 원소가 0으로 초기화된 길이 $N$인 수열 $\{a_i\}_{i=0}^{N-1}$에 대해 $Q$개의 쿼리를 처리하세요.

## 입력

~~~text
$N$ $Q$
$q_1$ $l_1$ $r_1$ $k_1$
\dots
$q_Q$ $l_Q$ $r_Q$ $k_Q$
~~~

- $1\leq N\leq10^6$
- $0\leq Q\leq10^5$
- $q_i\in\{0,1,2,3,4\}$
- $0\leq l_i\leq r_i\lt N$
- $0\leq k_i\leq10^9$

입력은 모두 정수입니다.

## 쿼리

쿼리 $(q,l,r,k)$의 의미는 다음과 같습니다.

- $q=0$: $k\sum_{i=l}^{r}a_i$를 $10^9+7$로 나눈 나머지로 출력하고 줄바꿈합니다.
- $q=1$: $l\leq i\leq r$인 모든 $i$에 대해 $a_i$를 $k$로 바꿉니다.
- $q=2$: $l\leq i\leq r$인 모든 $i$에 대해 $a_i$를 $a_i+k$로 바꿉니다.
- $q=3$: $l\leq i\leq r$인 모든 $i$에 대해 $a_i$를 $a_i\times k$로 바꿉니다.
- $q=4$: $l\leq i\leq r$인 모든 $i$에 대해 $a_i$를 $a_i+kF_i$로 바꿉니다.

여기서 $\{F_n\}$은 피보나치 수열이며 $F_0=0,F_1=1,F_n=F_{n-1}+F_{n-2}\ (n\geq2)$입니다.

테스트 케이스는 총 20개이며, 그중 10개는 $N\leq10^3,\ Q\leq10^3$을 만족합니다.

## 출력

쿼리를 처리하세요.
