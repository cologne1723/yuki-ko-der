정수 $H,W$가 주어집니다. 모든 원소가 0 또는 1이고, 0으로만 이루어진 행이나 열이 없으면 $H\times W$ 행렬을 좋은 행렬이라고 합니다.

## 문제

좋은 행렬의 개수를 $10^9+7$로 나눈 나머지를 구하세요.

## 입력

```text
H W
```

$1\le H,W\le10^6$입니다.

## 출력

답을 출력하세요.
