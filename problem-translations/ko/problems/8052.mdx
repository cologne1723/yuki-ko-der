## 문제 설명

크기가 서로 다른 정사각형이 $N$개 있습니다. $i$번째 ($1 \leq i \leq N$)로 작은 정사각형의 변의 길이는 $A_i$입니다. 이 $N$개의 정사각형을 모두 $1$개씩 나열하여 전체를 정사각형으로 만들 수 있는지 판정하고, 가능하다면 그 배치 방법의 예를 출력하세요. 정사각형끼리 겹치거나 빈틈이 있어서는 안 됩니다.

## 입력

```text
$N$
$A_1\ \cdots\ A_N$
```

입력되는 값은 모두 정수이며, 다음 제한을 만족합니다.

## 제한

- $1 \leq N \leq 26$
- $1 \leq A_1 < \cdots < A_N$
- $A_1^2 + \cdots + A_N^2 \leq 500^2$

## 출력

가능한 경우:

```text
$L$
$c_{1,1}\ \cdots\ c_{1,L}$
$\vdots$
$c_{L,1}\ \cdots\ c_{L,L}$
```

- 완성된 정사각형의 변의 길이를 $L$이라고 합니다.
- 배치 방법은 세로 $L$칸, 가로 $L$칸의 문자 배열 $c$로 나타냅니다.
- 각 칸의 문자는 전체 정사각형에서 그 칸에 해당하는 부분이 $1$번째로 작은 정사각형이면 'A', $2$번째로 작은 정사각형이면 'B', …, $26$번째로 작은 정사각형이면 'Z'로 합니다.

불가능한 경우:

```text
-1
```

### 예제 1 {file=""}

#### 입력

```text
1
3
```

#### 출력

```text
3
AAA
AAA
AAA
```

변의 길이가 $3$인 정사각형 $1$개를 나열하면 변의 길이가 $3$인 정사각형이 됩니다.

### 예제 2 {file=""}

#### 입력

```text
2
1 3
```

#### 출력

```text
-1
```

정사각형 $2$개의 넓이의 합은 $10$이므로, 정사각형으로 만들 수 있다면 그 변의 길이는 $\sqrt{10}$이어야 합니다. 하지만 이는 불가능합니다.
