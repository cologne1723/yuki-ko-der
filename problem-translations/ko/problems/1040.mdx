## 문제 설명

다카하시 군은 수직 대학(약칭: 직대)의 학생입니다.

수직 대학의 오늘 과제는 서로 수직인 $2$개의 선을 그리는 것입니다.

먼저 다카하시 군은 점 $O$가 한쪽 끝인 $2$개의 긴 선분 $l$, $m$과 점 $O$를 중심으로 하는 작은 원 $C$를 그렸습니다. 그 후 선분 $l$과 원 $C$의 교점을 $A$, 선분 $m$과 원 $C$의 교점을 $B$로 정하고, 원 $C$ 위를 점 $A$에서 걷기 시작하여 점 $B$ 위에서 걷기를 끝냈습니다.

다카하시 군은 원 위를 반시계 방향으로 $N$°만큼 이동했다는 것을 기억하고 있습니다. 다카하시 군이 서로 수직인 $2$개의 선을 그렸는지 판정하세요.

## 입력

```text
$N$
```

## 제한

$1 \le N \le 1\,000$

$N$은 정수입니다.

## 출력

다카하시 군이 서로 수직인 $2$개의 선을 그렸다면 `Yes`를, 그렇지 않다면 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
90
```

#### 출력

```text
Yes
```

### 예제 2 {file=""}

#### 입력

```text
180
```

#### 출력

```text
No
```

### 예제 3 {file=""}

#### 입력

```text
630
```

#### 출력

```text
Yes
```

한 바퀴 이상 이동한 경우도 있습니다.
