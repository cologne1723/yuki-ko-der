## 이야기

「오늘 막 빙의해서 따끈따끈해!」

## 문제 설명

$N$명의 요괴가 있습니다. 요괴 $i$는 $P_i\neq 0$이면 요괴 $P_i$를 식신으로 삼고, $P_i=0$이면 식신이 없습니다.

식신의 식신인 요괴가 몇 명인지 구하세요.

요괴 $i$가 식신의 식신이라고 하는 조건은 다음과 같습니다.

- 다음 조건을 모두 만족하는 순서쌍 $(p,q)$가 존재합니다.
  - $1\leq p,q\leq N$이고 $p\neq q$입니다.
  - 요괴 $p$는 요괴 $i$를 식신으로 삼습니다.
  - 요괴 $q$는 요괴 $p$를 식신으로 삼습니다.
  - 요괴 $q$를 식신으로 삼는 요괴는 존재하지 않습니다.

## 입력

```text
$N$
$P_1\ P_2\ \cdots\ P_N$
```

$N$은 요괴의 수입니다.

$2$번째 줄에는 $P_1,P_2,\dots,P_N$이 공백으로 구분되어 주어집니다. $P_i\neq 0$이면 요괴 $i$가 요괴 $P_i$를 식신으로 삼는다는 뜻이고, $P_i=0$이면 요괴 $i$에게 식신이 없다는 뜻입니다.

## 제한

- $1\leq N\leq 100\,000$
- $0\leq P_i\leq N$ $(1\leq i\leq N)$
- $P_i\neq i$ $(1\leq i\leq N)$
- 입력은 모두 정수입니다.

## 출력

조건을 만족하는 요괴의 수를 $n$이라고 할 때, 다음 형식으로 $1$줄에 출력하세요.

```text
$n$
```

마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text

```

#### 출력

```text
1
```

$3$번째 요괴만 조건을 만족합니다.



