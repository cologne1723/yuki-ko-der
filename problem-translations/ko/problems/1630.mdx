한 자리 양의 정수가 `N`개 있습니다. 정수 `i`는 `c_i`개 있습니다 (`1 <= i <= 9`). 이들을 재배열해 `N`자리 십진수 `M`으로 만들 때, `K`보다 큰 `M` 중 최솟값을 구하세요.

## 입력

첫째 줄에 `N`, `K`, 둘째 줄에 `c_1, c_2, ..., c_9`가 주어집니다.

## 제약

- `1 <= N <= 500000`
- `1 <= K <= 10^500001`
- `c_i >= 0`, `sum(c_i) = N`
- 입력은 정수입니다.

## 출력

조건을 만족하는 `M`이 존재하면 최솟값을 출력하고, 존재하지 않으면 `-1`을 출력하세요.
