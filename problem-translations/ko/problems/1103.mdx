## 문제 설명

$N$개의 정점으로 이루어진 유향 트리가 있습니다. $i$번째 간선은 정점 $A_i$에서 정점 $B_i$를 향해 뻗어 있습니다. 또한 루트가 아닌 각 정점에는 부모로부터 뻗어 나온 유향 간선이 하나씩 있습니다.

함수 $f(a,b)$를 다음과 같이 정의합니다.

- $f(a,b)$는 정점 $a$에서 정점 $b$로 가는 경로의 길이입니다. (정점 $a$에서 정점 $b$로 갈 때 거치는 간선의 수입니다.)
- 경로가 존재하지 않으면 $f(a,b)=0$으로 합니다. 또한 $f(a,a)=0$으로 합니다.

이때 $\displaystyle\sum_{i=1}^{N}\sum_{j=1}^{N}f(i,j)$를 구하세요. 답이 커질 수 있으므로, $10^9+7$로 나눈 나머지를 구하세요.

## 보충

PyPy3에서 통과하는 것을 확인했지만 Python에서는 확인하지 못했습니다.

## 입력

```text
$N$
$A_1\ B_1$
$A_2\ B_2$
$\vdots$
$A_{N-1}\ B_{N-1}$
```

## 제한

- $3 \le N \le 10^6$
- $i \ne j$이면 $(A_i,B_i) \ne (A_j,B_j)$
- $1 \le A_i,B_i \le N$ ($1 \le i \le N-1$)
- 주어지는 그래프는 유향 트리입니다.

## 출력

답을 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
1 2
1 3
```

#### 출력

```text
2
```

구해야 하는 값은 $f(1,2)+f(1,3)+f(2,1)+f(2,3)+f(3,1)+f(3,2)$입니다. 정점 $1$에서 정점 $2,3$으로 가는 길이 $1$인 경로가 존재하므로 $f(1,2)=f(1,3)=1$입니다. 한편, 예를 들어 정점 $2$에서 정점 $3$으로 가는 경로는 존재하지 않으므로 $f(2,3)=0$입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
5
2 1
1 3
1 4
3 5
```

#### 출력

```text
13
```

예를 들어 $f(3,4)=0$, $f(2,5)=3$입니다. 또한 루트는 정점 $1$이라고 단정할 수 없습니다. (이 경우에는 정점 $2$입니다.)
