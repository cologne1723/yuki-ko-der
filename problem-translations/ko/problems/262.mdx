## 문제

Carol은 특수한 주사위 놀이를 하려고 합니다. 1부터 $N$까지 번호가 붙은 칸 $N$개가 일렬로 놓여 있습니다. 1번 칸에서 시작하고, $N$이라고 쓰인 칸이 골인 지점입니다.

현재 칸에 쓰인 숫자를 이진수로 나타냈을 때 1인 비트의 개수만큼 **앞으로** 이동할 수 있습니다. 1보다 작은 칸이나 $N+1$ 이상인 칸으로 이동할 수 없으며, 정확히 $N$번 칸에 도착해야 골인할 수 있습니다.

양의 정수 $N$이 주어질 때 골인할 수 있는 최소 이동 횟수를 구하세요. 시작 칸으로 이동하는 것도 이동 횟수에 포함합니다. 도달할 수 없으면 `-1`을 출력하세요.

## 입력

```text
N
```

- $1 \leq N \leq 10^{12}$

## 출력

최소 이동 횟수 또는 `-1`을 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

```text
3
```

### 출력 1 {file="stdout"}

```text
3
```

### 입력 2 {file="stdin"}

```text
71623783
```

### 출력 2 {file="stdout"}

```text
5691592
```

### 입력 3 {file="stdin"}

```text
1000000000000
```

### 출력 3 {file="stdout"}

```text
-1
```

예를 들어 $N$이 충분히 크면 다음과 같이 진행할 수밖에 없습니다.

```text
이동 횟수   1  2  3  4  5  6  7  8  9 ...
칸          1  2  3  5  7 10 12 14 17 ...
```
