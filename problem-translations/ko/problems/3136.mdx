## 문제 설명

`FizzBuzz16`을 다음과 같이 정의합니다. (※ 의사 코드입니다.)

```text
function FizzBuzz16(i) {
    if ( i % 15 == 0 ) {
        return "FizzBuzz"
    } else if ( i % 3 == 0 ) {
        return "Fizz"
    } else if ( i % 5 == 0 ) {
        return "Buzz"
    } else {
        return i.toString(16).toUpperCase()
    }
}
```

※ `i % 15 == 0`은 정수 `i`를 `15`로 나눈 나머지가 `0`과 같을 때 참이 되는 식입니다.

※ `i.toString(16).toUpperCase()`는 정수 `i`를 $16$진수 표기(영문자는 대문자)의 문자열로 변환하는 처리입니다.

예를 들어 `FizzBuzz16(14)`는 `"E"`, `FizzBuzz16(15)`는 `"FizzBuzz"`, `FizzBuzz16(16)`은 `"10"`, `FizzBuzz16(251)`은 `"FB"`입니다.

`FizzBuzzString16`을 다음과 같이 정의합니다. (※ 의사 코드입니다.)

```text
function FizzBuzzString16(n) {
    s = ""
    for ( i = 1 ; i <= n ; i++ ) {
        s += FizzBuzz16(i)
    }
    return s
}
```

※ `i++`는 정수 `i`의 값을 `1`만큼 증가시키는 처리입니다.

※ `s += `는 문자열 `s`의 맨 뒤에 오른쪽 값의 문자열을 이어 붙이는 처리입니다.

예를 들어 `FizzBuzzString16(4)`는 `"12Fizz4"`, `FizzBuzzString16(16)`은 `"12Fizz4BuzzFizz78FizzBuzzBFizzDEFizzBuzz10"`입니다.

정수 $X$와 $Y$가 주어집니다. `FizzBuzzString16(1000000000000)`의 $X$번째 문자부터 $Y$번째 문자까지(※ $X$번째 문자와 $Y$번째 문자도 포함)에 있는 문자 `F`의 개수와 문자 `B`의 개수의 합을 구하세요.

예를 들어 $X=1$, $Y=5$일 때 `FizzBuzzString16(1000000000000)`의 $1$번째 문자부터 $5$번째 문자까지는 `"12Fiz"`입니다. 문자 `F`는 $1$개, 문자 `B`는 $0$개이므로 합은 $1$입니다.

예를 들어 $X=3$, $Y=18$일 때 `FizzBuzzString16(1000000000000)`의 $3$번째 문자부터 $18$번째 문자까지는 `"Fizz4BuzzFizz78F"`입니다. 문자 `F`는 $3$개, 문자 `B`는 $1$개이므로 합은 $4$입니다.

참고로 의사 코드 이외에도 `FizzBuzz16`과 `FizzBuzzString16`의 정의에 해당하는 코드를 준비했습니다.

```cpp
#include <sstream>

std::string to_hex_string(int64_t i) {
    std::stringstream s;
    s << std::uppercase << std::hex << i;
    return s.str();
}

std::string FizzBuzz16(int64_t i) {
    if (i % 15 == 0) {
        return "FizzBuzz";
    } else if (i % 3 == 0) {
        return "Fizz";
    } else if (i % 5 == 0) {
        return "Buzz";
    } else {
        return to_hex_string(i);
    }
}

std::string FizzBuzzString16(int64_t n) {
    std::string s = "";
    for (int64_t i = 1; i <= n; i++) {
        s += FizzBuzz16(i);
    }
    return s;
}
```

```python
def FizzBuzz16(i):
    if i % 15 == 0:
        return "FizzBuzz"
    elif i % 3 == 0:
        return "Fizz"
    elif i % 5 == 0:
        return "Buzz"
    else:
        return "%X" % i

def FizzBuzzString16(n):
    s = ""
    for i in range(1,n+1):
        s += FizzBuzz16(i)
    return s
```

## 입력

```text
$X$
$Y$
```

$1$번째 줄에 정수 $X$가 주어집니다.

$2$번째 줄에 정수 $Y$가 주어집니다.

## 제한

- $1 \le X \le Y \le 1\,000\,000\,000\,000 = 10^{12}$

## 출력

`FizzBuzzString16(1000000000000)`의 $X$번째 문자부터 $Y$번째 문자까지(※ $X$번째 문자와 $Y$번째 문자도 포함)에 있는 문자 `F`의 개수와 문자 `B`의 개수의 합을 출력하세요.

마지막에 줄 바꿈을 출력하세요.
