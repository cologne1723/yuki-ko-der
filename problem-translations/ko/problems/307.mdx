## 문제

세로 $H$칸, 가로 $W$칸인 격자의 칸을 두 색 잉크로 칠하려고 합니다.

위에서 $R$번째 행, 왼쪽에서 $C$번째 열의 칸을 $(R,C)$로 나타냅니다. 왼쪽 위는 $(1,1)$, 오른쪽 아래는 $(H,W)$입니다. 칸 $(R,C)$는 처음에 색 $A_{R,C}$로 칠해져 있습니다.

어떤 칸 $(R,C)$와 인접한 칸 $(R',C')$가 같은 색이면 두 칸은 연결되어 있다고 합니다. 또한 $(R,C)$와 $(R',C')$가 연결되고 $(R',C')$와 $(R'',C'')$가 연결되면 $(R,C)$와 $(R'',C'')$도 연결되어 있다고 합니다. 인접하다는 것은 두 칸의 맨해튼 거리가 1, 즉 $(R',C')$가 $(R+1,C),(R-1,C),(R,C+1),(R,C-1)$ 중 하나인 경우입니다.

“$(R,C)$와 연결된 모든 칸을 색 $X$로 칠한다”라는 쿼리가 $Q$개 주어집니다. $Q$번 칠하기를 끝낸 뒤 격자의 각 칸 색을 출력하세요.

즉, 페인트 소프트웨어의 ‘채우기’ 기능입니다.

## 입력

```text
H W
A_{1,1} A_{1,2} … A_{1,W}
⋮
A_{H,1} A_{H,2} … A_{H,W}
Q
R_1 C_1 X_1
⋮
R_Q C_Q X_Q
```

모든 입력은 정수이며 다음 조건을 만족합니다.

- $1 \le H,W \le 200$
- $1 \le Q \le 5\times10^4$
- $0 \le A_{R,C},X_i \le 1$
- $1 \le R_i \le H$
- $1 \le C_i \le W$

## 출력

칠하기를 끝낸 뒤 각 칸의 색 $A'_{R,C}$를 $H$줄에 걸쳐, 각 줄에 $W$개의 값을 공백으로 구분하여 출력하세요.
