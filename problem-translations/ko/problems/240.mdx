## 문제

체스의 나이트가 무한히 넓은 $XY$ 좌표 평면을 산책합니다. 나이트의 이동 방식으로 한 번 이동하는 것을 1걸음이라고 합니다. 산책이므로 최대 3걸음까지만 이동합니다.

$(0,0)$에서 시작해 3걸음 이내에 목표 좌표에 도착할 수 있는지 판정하세요.

체스의 나이트는 현재 위치가 $(x,y)$일 때 한 번에 $(x-2,y-1)$, $(x-2,y+1)$, $(x-1,y-2)$, $(x-1,y+2)$, $(x+1,y-2)$, $(x+1,y+2)$, $(x+2,y-1)$, $(x+2,y+1)$ 중 하나로 이동할 수 있는 말입니다.

## 입력

```text
X Y
```

목표 좌표 $(X,Y)$가 주어집니다.

- $-1000000000 \leq X,Y \leq 1000000000$

## 출력

이동할 수 있으면 `YES`를, 이동할 수 없으면 `NO`를 한 줄에 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

```text
1 2
```

### 출력 1 {file="stdout"}

```text
YES
```

1걸음으로 이동할 수 있습니다.

### 입력 2 {file="stdin"}

```text
5 -4
```

### 출력 2 {file="stdout"}

```text
YES
```

정확히 3걸음으로 이동할 수 있습니다.

### 입력 3 {file="stdin"}

```text
100 100
```

### 출력 3 {file="stdout"}

```text
NO
```

3걸음 이내에는 도착할 수 없습니다.

### 입력 4 {file="stdin"}

```text
0 0
```

### 출력 4 {file="stdout"}

```text
YES
```

한 걸음도 움직이지 않고 도착할 수 있습니다.
