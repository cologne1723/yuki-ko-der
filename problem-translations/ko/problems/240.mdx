## 문제 설명

체스의 나이트가 무한히 넓은 $XY$ 좌표 평면을 산책합니다. 나이트의 이동 방식으로 $1$번 이동하는 것을 $1$걸음이라고 합니다. 산책이므로 최대 $3$걸음까지만 이동합니다.

$(0,0)$에서 시작해 $3$걸음 이내에 목표 좌표에 도착할 수 있는지 판정하세요.

체스의 나이트는 현재 위치가 $(x,y)$일 때 $1$번에 $(x-2,y-1)$, $(x-2,y+1)$, $(x-1,y-2)$, $(x-1,y+2)$, $(x+1,y-2)$, $(x+1,y+2)$, $(x+2,y-1)$, $(x+2,y+1)$ 중 $1$곳으로 이동할 수 있는 말입니다.

## 입력

```text
$X\ Y$
```

목표 좌표 $(X,Y)$가 주어집니다.

## 제한

- $-1\,000\,000\,000 \leq X,Y \leq 1\,000\,000\,000$

## 출력

이동할 수 있으면 `YES`를, 이동할 수 없으면 `NO`를 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 2
```

#### 출력

```text
YES
```

$1$걸음으로 이동할 수 있습니다.

### 예제 2 {file=""}

#### 입력

```text
5 -4
```

#### 출력

```text
YES
```

정확히 $3$걸음으로 이동할 수 있습니다.

### 예제 3 {file=""}

#### 입력

```text
100 100
```

#### 출력

```text
NO
```

$3$걸음 이내에는 도착할 수 없습니다.

### 예제 4 {file=""}

#### 입력

```text
0 0
```

#### 출력

```text
YES
```

$1$걸음도 움직이지 않고 도착할 수 있습니다.
