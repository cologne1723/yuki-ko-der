## 문제

$N$과 $K$가 주어집니다. $1$ 이상 $N$ 이하의 정수를 균등하게, 서로 독립적으로 $K$번 선택해 노트에 적습니다.

노트에 적힌 서로 다른 정수의 종류 수의 기댓값에 $N^K$를 곱한 값을 $10^9+7$로 나눈 나머지를 구하세요.

## 입력

$N,K$가 주어집니다.

- $1\leq N,K<10^9+7$

## 출력

요구된 값을 출력하세요.
