## 문제 설명

$N$명의 학생이 있는 반이 있습니다. 학생은 $S_0$君부터 $S_{N-1}$君까지 있습니다. 각 학생에게 $0$부터 $N-1$까지의 출석 번호를 $1$개씩 배정하려고 합니다. 하지만 각 학생에게는 싫어하는 숫자가 $1$개씩 있어서 출석 번호로 배정할 수 없습니다. 어떤 학생에게도 싫어하는 숫자가 배정되지 않도록 출석 번호를 배정하세요.

※ `test2.txt`는 코너 케이스일 수 있습니다. AC를 받지 못했다면 제한을 잘 읽어 보세요.

## 입력

```text
$N$
$A_0$
$A_1$
$\vdots$
$A_{N-1}$
```

$1$번째 줄에 학생 수 $N$이 주어집니다. 다음 $N$개 줄에 학생 $S_i$君이 싫어하는 숫자 $A_i$가 주어집니다.

## 제한

- $1 \leq N \leq 50$
- $0 \leq A_i \leq 49$

## 출력

$S_0$君부터 $S_{N-1}$君까지의 출석 번호를 순서대로 $N$개 줄에 출력하세요. 출석 번호는 중복되지 않아야 하므로 $0$부터 $N-1$까지의 숫자가 $1$개씩 존재해야 합니다. 정답이 여러 개이면 그중 $1$개를 출력하세요. 배정이 불가능하면 $-1$을 $1$줄에 출력하세요. 마지막에 개행을 넣으세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
0
1
2
```

#### 출력

```text
2
0
1
```

$S_0$君은 $0$을, $S_1$君은 $1$을, $S_2$君은 $2$를 싫어하므로 각각 $2$, $0$, $1$을 배정했습니다.

### 예제 2 {file=""}

#### 입력

```text
4
3
3
3
3
```

#### 출력

```text
-1
```

출석 번호 $3$을 누구에게도 배정할 수 없으므로 배정할 수 없습니다.

### 예제 3 {file=""}

#### 입력

```text
5
1
1
1
0
1
```

#### 출력

```text
4
2
0
1
3
```

$S_3$君에는 반드시 출석 번호 $1$을 배정해야 합니다.
