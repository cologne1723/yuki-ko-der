## 문제

$N$명의 학생이 있는 반이 있습니다. 학생은 $S_0$부터 $S_{N-1}$까지 있습니다. 각 학생에게 0부터 $N-1$까지의 출석 번호를 하나씩 배정하려고 합니다. 하지만 각 학생에게는 싫어하는 숫자가 하나씩 있어서 출석 번호로 배정할 수 없습니다. 어떤 학생에게도 싫어하는 숫자가 배정되지 않도록 출석 번호를 배정하세요.

## 입력

```text
N
A_0
A_1
⋮
A_{N-1}
```

첫째 줄에 학생 수 $N$이 주어집니다. 다음 $N$개 줄에 학생 $S_i$가 싫어하는 숫자 $A_i$가 주어집니다.

- $1 \leq N \leq 50$
- $0 \leq A_i \leq 49$

## 출력

$S_0$부터 $S_{N-1}$까지의 출석 번호를 순서대로 $N$개 줄에 출력하세요. 출석 번호는 중복되지 않아야 하므로 0부터 $N-1$까지의 숫자가 하나씩 존재해야 합니다. 정답이 여러 개이면 그중 하나를 출력하세요. 배정이 불가능하면 `-1`을 한 줄에 출력하세요. 마지막에 개행을 넣으세요.

## 샘플

### 입력 1 {file="stdin"}

```text
3
0
1
2
```

### 출력 1 {file="stdout"}

```text
2
0
1
```

$S_0$은 0을, $S_1$은 1을, $S_2$는 2를 싫어하므로 각각 2, 0, 1을 배정했습니다.

### 입력 2 {file="stdin"}

```text
4
3
3
3
3
```

### 출력 2 {file="stdout"}

```text
-1
```

출석 번호 3을 누구에게도 배정할 수 없으므로 배정할 수 없습니다.

### 입력 3 {file="stdin"}

```text
5
1
1
1
0
1
```

### 출력 3 {file="stdout"}

```text
4
2
0
1
3
```

$S_3$에는 반드시 출석 번호 1을 배정해야 합니다.
