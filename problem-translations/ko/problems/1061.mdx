## 문제 설명

길이가 $3N$인 정수 수열 중 다음 조건을 만족하는 것을 “멋진 수열”이라고 합니다.

- 모든 $i$($0 \le i \le N-1$)에 대해 다음 두 조건을 모두 만족합니다.
  - 수열에 $i$가 정확히 $3$번 나타납니다.
  - $i$가 처음 나타나는 위치와 두 번째로 나타나는 위치 사이에 있는 요소의 개수와, $i$가 두 번째로 나타나는 위치와 세 번째로 나타나는 위치 사이에 있는 요소의 개수의 차의 절댓값이 정확히 $i$입니다.

$N$이 주어질 때, “멋진 수열”을 하나 출력하세요.

여러 개 존재한다면 그중 어느 것이든 출력해도 됩니다.

존재하지 않는다면 $-1$을 출력하세요.

## 입력

```text
$N$
```

다음 조건을 만족합니다.

$N$은 $1$ 이상 $10^5$ 이하인 정수입니다.

## 출력

“멋진 수열”이 존재한다면 첫 번째 항부터 순서대로, 각 요소를 반각 공백으로 구분하여 $3N$개의 요소를 출력하세요.

여러 개 존재한다면 그중 어느 것이든 출력해도 됩니다.

존재하지 않는다면 $-1$을 출력하세요.

출력 끝에 개행을 넣으세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text
0 0 0
```

첫 번째 $0$과 두 번째 $0$ 사이에 요소가 $0$개 있습니다.

두 번째 $0$과 세 번째 $0$ 사이에 요소가 $0$개 있습니다.

이 차는 $0$이므로 조건을 만족합니다.

### 예제 2 {file=""}

#### 입력

```text
2
```

#### 출력

```text
-1
```

### 예제 3 {file=""}

#### 입력

```text
3
```

#### 출력

```text
2 0 2 1 0 1 2 0 1
```

$0$ 사이에 있는 요소의 개수는 $2$개와 $2$개이며, 이 차는 $0$이므로 조건을 만족합니다.

$1$ 사이에 있는 요소의 개수는 $1$개와 $2$개이며, 이 차는 $1$이므로 조건을 만족합니다.

$2$ 사이에 있는 요소의 개수는 $1$개와 $3$개이며, 이 차는 $2$이므로 조건을 만족합니다.
