## 문제 설명

타로와 지로는 무전기로 대화하고 있습니다.

두 사람이 사용하는 무전기는 전파로 서로 직접 통신하며, 최대 $1$km 거리까지 대화할 수 있습니다. 또한 중계국을 하나 이상 사이에 두어 통신 거리를 늘릴 수도 있습니다.

무전기와 중계국 사이는 최대 $1$km까지 통신할 수 있지만, 중계국과 중계국 사이는 최대 $10$km까지 통신할 수 있습니다. 각각 정확히 $1$km와 $10$km인 경우도 포함합니다.

2차원 평면에 $N$개의 중계국이 있고, 위치는 $(X_i,Y_i)$로 나타냅니다.

타로와 지로는 이 중계국을 모두 자유롭게 사용할 수 있고, 두 사람은 무전기를 가진 채 2차원 평면 위를 자유롭게 이동할 수 있다고 합니다. 이때 두 사람이 직접 또는 중계국을 이용해 간접적으로 대화할 수 있는 두 사람 사이의 직선 거리(유클리드 거리)의 최댓값을 구하세요.

## 입력

```text
$N$
$X_1\ Y_1$
$\vdots$
$X_N\ Y_N$
```

정수 $N$은 중계국의 수입니다.
이어지는 $N$개 줄에는 각 중계국의 위치를 나타내는 정수 $X_i,Y_i$가 공백으로 구분되어 주어집니다. 좌표의 단위는 km입니다. $(1 \le i \le N)$

같은 좌표에 여러 중계국이 존재하지 않습니다. 즉, $i \ne j$이면 $(X_i,Y_i) \ne (X_j,Y_j)$입니다.

## 제한

- $0 \le N \le 1\,000$
- $-1\,000 \le X_i,Y_i \le 1\,000$ $(1 \le i \le N)$

## 출력

두 사람이 대화할 수 있는 직선 거리의 최댓값을 출력하세요.

절대 오차 또는 상대 오차 중 적어도 하나가 $10^{-6}$ 이하이면 정답으로 인정합니다.

마지막에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
3 3
12 1
```

#### 출력

```text
11.219544457
```

두 중계국 사이의 거리는 $\sqrt{85}$km이므로 통신할 수 있습니다. 각 중계국과 사람 사이도 $1$km까지 통신할 수 있으므로, 두 중계국을 잇는 직선의 연장선 위에 두 사람이 서면 $(\sqrt{85}+2)$km까지 통신할 수 있습니다.

### 예제 2 {file=""}

#### 입력

```text
2
-5 -1
3 6
```

#### 출력

```text
2
```

두 중계국 사이의 거리는 약 $10.6$km이므로 서로 통신할 수 없습니다. 둘 중 하나의 중계국을 사이에 두면 타로와 중계국, 지로와 중계국 사이에서 각각 $1$km까지 통신할 수 있으므로 답은 $2$km입니다.

### 예제 3 {file=""}

#### 입력

```text
5
-8 7
-5 -1
3 5
9 -3
16 4
```

#### 출력

```text
26.186773244
```


### 예제 4 {file=""}

#### 입력

```text
0
```

#### 출력

```text
1
```

중계국이 없으면 직접 통신해야 합니다. 이때 서로의 전파가 도달하는 $1$km가 최대 거리입니다.
