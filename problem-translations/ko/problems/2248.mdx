길이 $N$인 짝수 수열 $A,B$와 수열 $C$가 주어진다냥. 각 $C_i$는 $A_i,B_i,(A_i+B_i)/2$ 중 하나이다냥. $\max(C)-\min(C)$로 가능한 값의 최솟값을 구하라냥.

## 조건

- $1\le N\le2\times10^5$
- $0\le A_i,B_i\le10^9$

## 입력

```text
N
A_1 \cdots A_N
B_1 \cdots B_N
```

## 출력

최솟값을 출력하라냥.
