## 문제 설명

여러분은 $N$개의 나무 블록을 사용하여 탑을 쌓고 있습니다.

탑을 바로 위에서 내려다보면 세로 $3$칸, 가로 $3$칸으로 이루어진 총 $9$칸의 격자로 나뉘어 있습니다. 이 격자의 위에서 $i$번째 행, 왼쪽에서 $j$번째 열에 있는 칸을 $(i, j)$로 나타냅니다.

블록의 크기는 세로 $3$칸, 가로 $1$칸이며 자유롭게 회전할 수 있습니다. 블록이 없어질 때까지 다음과 같이 블록을 쌓습니다.

- 탑은 블록을 쌓아 만듭니다. $h=1,2,\dots$번째 층은 다음과 같이 쌓습니다.

  - $h$가 홀수일 때, $j=1,2,3$의 순서로 각각 $(1,j)$, $(2,j)$, $(3,j)$의 $3$칸을 덮도록 블록을 $1$개씩 쌓습니다.

    도중에 블록이 없어지면 그 즉시 작업을 종료합니다.

    $3$개를 모두 쌓으면 $h+1$번째 층으로 넘어갑니다.

  - $h$가 짝수일 때, $i=1,2,3$의 순서로 각각 $(i,1)$, $(i,2)$, $(i,3)$의 $3$칸을 덮도록 블록을 $1$개씩 쌓습니다.

    도중에 블록이 없어지면 그 즉시 작업을 종료합니다.

    $3$개를 모두 쌓으면 $h+1$번째 층으로 넘어갑니다.

$N$개의 블록을 모두 쌓았을 때, 바로 위에서 내려다본 $9$개의 각 칸에 블록이 몇 개씩 쌓여 있는지 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

## 제한

- $1 \le N \le 10^{12}$
- $N$은 정수입니다.

## 출력

출력은 $3$줄로 이루어집니다.

$i$번째 줄에는 칸 $(i,1)$, $(i,2)$, $(i,3)$에 쌓여 있는 블록의 개수를 공백으로 구분하여 출력하세요.

마지막에 개행을 출력하세요.

답이 $32$비트 정수형(`int` 등)에 들어가지 않을 수 있음에 주의하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
```

#### 출력

```text

1 0 0
1 0 0
```

$1$번째 블록은 홀수 번째 층의 $1$번째 블록이므로 왼쪽 열에 세로로 놓입니다. 따라서 가장 왼쪽 열의 $3$칸에 각각 블록이 $1$개씩 놓인 상태가 됩니다.
