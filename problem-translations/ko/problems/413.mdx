## 문제

프로그래밍 콘테스트에서 다음과 같은 문제가 출제되었습니다.

> 주어진 양의 정수 d에 대해 t² + t ≤ d를 만족하는 가장 큰 정수 t를 구하세요.
>
> - 1 ≤ d ≤ 10^18

콘테스트에 참가한 당신은 다른 참가자가 64비트 C++11(yukicoder에서 동작하는 C++11)로 작성한 다음 답안을 발견했습니다. (32비트 환경에서는 의도한 동작이 일어나지 않는 것 같습니다.)

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long ll;

ll calc(ll d) {
  return (ll)((-1 + sqrt(1 + 4*d)) / 2.0);
}

int main() {
  ll d; cin >> d;
  ll t = calc(d);
  cout << t << endl;
  return 0;
}
```

당신은 이 코드가 잘 챌린지하면 성공할 수 있다고 생각했습니다(실패하는 테스트 케이스를 찾는다는 뜻입니다). 챌린지에 성공하는 테스트 케이스를 10만 건 생성하세요.

※ 10만 = 10^5 = 100000

## 입력

이 문제에는 입력이 없습니다.

## 출력

챌린지에 성공하는 d의 값을 한 줄에 하나씩 10만 건 출력하고, 마지막에 개행을 출력하세요.

저지는 다음과 같이 판정합니다.

- 1번째부터 10만 번째까지 확인합니다. 10만 건에 미치지 못할 때의 동작은 정의되지 않습니다.
- 10만 건 안에 d 값의 중복이 있거나, d가 적절한 범위에 있지 않은 값이 포함되거나, 실패하는 챌린지가 포함되어 있으면 모두 오답(WA)입니다.

## 출력 샘플

다음과 같은 형식으로 수를 출력하세요.

```text
19980604
19980727
19980904
19980930
19981114
19981123
.
.
.
20000507
20010625
```

여기에 출력된 값은 숫자 출력 형식을 명확히 보여 주기 위한 예시일 뿐이며, 올바른 답이라는 뜻은 아닙니다. 총 10만 줄을 출력하세요.
