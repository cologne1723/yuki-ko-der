실수 대칭 $2\times2$ 행렬 $M$이 주어집니다. 각 성분의 절댓값 오차가 $10^{-3}$ 미만이고 모든 성분이 정수부 1자리, 소수부 5자리 표현을 가지는 실수 행렬 $N$ 중 $M-N^3$을 만족하는 근사적인 세제곱근이 존재하는지 판정하고, 존재하면 하나 출력하세요.

## 입력

```text
T
M의 두 행
...
```

## 출력

각 테스트 케이스에 대해 가능하면 `Yes`와 행렬을, 불가능하면 `No`를 출력하세요.
