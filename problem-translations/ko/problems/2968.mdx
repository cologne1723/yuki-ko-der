## 이야기

어떤 방송에서 전설의 명언이 탄생합니다…

???「여러분, 드디어 왔습니다. 최종 오른쪽 아래의 시간입니다.」

## 문제 설명

가로 길이가 $H$, 세로 길이가 $W$인 스마트폰 화면에 방송자의 캐릭터와 아군 캐릭터 $N$개, 적 캐릭터 $M$개가 있습니다. 이후 스마트폰 화면을 $xy$평면으로 생각합니다.

스마트폰 화면의 $4$개 모서리 좌표는 $(0,0),(H,0),(H,W),(0,W)$이고, 스마트폰 화면의 측면은 벽입니다. 방송자의 캐릭터는 $(X,Y)$, 아군 캐릭터는 $(x_i,y_i) (1 \leq i \leq N)$, 적 캐릭터는 $(a_i,b_i) (1 \leq i \leq M)$에 배치되어 있습니다.

방송자의 캐릭터의 처음 속도는 $S$이고, 오른쪽 아래 $45^\circ$, 즉 $X$좌표의 값이 $1$ 증가할 때 $Y$좌표의 값이 $1$ 감소하는 방향으로 출발합니다. 다음 사건이 일어났을 때만 속도와 진행 방향이 변합니다.

- 방송자의 캐릭터가 $i$번째 $(1 \leq i \leq N)$ 아군 캐릭터에 부딪히면 속도가 $A_i$ 증가합니다.
- 방송자의 캐릭터가 $i$번째 $(1 \leq i \leq M)$ 적 캐릭터에 부딪히면 속도가 $B_i$ 감소합니다.
- 방송자의 캐릭터가 벽에 부딪히면 입사각과 반사각이 같도록 튕겨 나가고 속도가 $C$ 감소합니다. 단, 모서리에 부딪힌 경우에는 속도가 $2C$ 감소하고 왔던 길을 되돌아갑니다.

방송자의 캐릭터의 속도가 $0$ 이하가 되면 그 자리에서 멈춥니다. 이때 방송자의 캐릭터가 멈춘 위치, 아군과 부딪힌 횟수, 적과 부딪힌 횟수를 각각 구하세요. 멈추지 않는 경우에는 그 사실을 보고하세요. 단, 아군과 부딪힌 횟수와 적과 부딪힌 횟수는 각각 $998\,244\,353$으로 나눈 나머지를 구하세요.

방송자의 캐릭터 이외의 캐릭터는 움직이지 않으며, 모든 캐릭터의 크기가 작으므로 좌표가 일치하지 않는 한 캐릭터끼리 부딪히지 않습니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$H\ W\ N\ M\ S\ C\ X\ Y$
$x_1\ y_1\ A_1$
$x_2\ y_2\ A_2$
$\vdots$
$x_N\ y_N\ A_N$
$a_1\ b_1\ B_1$
$a_2\ b_2\ B_2$
$\vdots$
$a_M\ b_M\ B_M$
```

$1$번째 줄에 정수 $H,W,N,M,S,C,X,Y$가 공백으로 구분되어 주어집니다.

다음 $N$개의 줄에 아군 캐릭터의 좌표와 충돌 시 속도 증가량을 나타내는 정수 $x_i,y_i,A_i$가 주어집니다.

그다음 $M$개의 줄에 적 캐릭터의 좌표와 충돌 시 속도 감소량을 나타내는 정수 $a_i,b_i,B_i$가 주어집니다.

## 제한

- $3 \leq H,W \leq 10^9$
- $1 \leq N,M \leq 5 \times 10^4$
- $1 \leq S \leq 10^{18}$
- $1 \leq A_i,B_j,C \leq 10^9\ (1 \leq i \leq N,1 \leq j \leq M)$
- $0 < X,x_i,a_j < H\ (1 \leq i \leq N,1 \leq j \leq M)$
- $0 < Y,y_i,b_j < W\ (1 \leq i \leq N,1 \leq j \leq M)$
- 모든 캐릭터가 배치된 좌표는 서로 다릅니다.
- 입력은 모두 정수입니다.

## 출력

멈춘 위치의 좌표를 $(x_{STOP},y_{STOP})$, 아군과 부딪힌 횟수를 $s$, 적과 부딪힌 횟수를 $t$라고 할 때, 다음 형식으로 출력하세요.

아군과 부딪힌 횟수와 적과 부딪힌 횟수는 각각 $998\,244\,353$으로 나눈 나머지를 출력하세요.

멈추지 않는 경우에는 $-1$을 출력하세요.

```text
$x_{STOP}\ y_{STOP}\ s\ t$
```

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 3 1 1 6 1 1 2
2 1 3
3 2 2
```

#### 출력

```text
3 2 2 3
```

처음에 아군과 부딪혀 속도가 $9$가 됩니다.

그다음 벽에 $2$번 부딪혀 속도가 $7$이 됩니다.

그다음 적과 부딪혀 속도가 $5$가 됩니다.

그다음 벽에 $3$번 부딪혀 속도가 $2$가 됩니다.

그다음 아군과 부딪혀 속도가 $5$가 됩니다.

그다음 적과 부딪혀 속도가 $3$이 됩니다.

그다음 모서리에 부딪혀 속도가 $1$이 됩니다.

그다음 적과 부딪혀 속도가 $-1$이 되어 멈춥니다.

아군과 $2$번, 적과 $3$번 부딪혔으므로 위와 같이 출력합니다.

### 예제 2 {file=""}

#### 입력

```text
3 3 1 1 5 1 1 2
2 1 100
2 2 100
```

#### 출력

```text
-1
```

이 경우에는 속도가 계속 증가하므로 멈추지 않습니다. $-1$을 출력하세요.
