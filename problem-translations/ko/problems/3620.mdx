> **주의**
>
> 이 문제의 실행 시간 제한은 $10$초입니다.

## 문제 설명

정수 $n$, $m$이 주어집니다. $n\geq 3$임이 제한으로 보장됩니다.

다음 형식적 멱급수 $f(x)\coloneqq \sum_{i=0}^{n-1}a_i x^i\in \mathbb{F}_{998\,244\,353}[[x]]$, $g(x)\coloneqq \sum_{i=0}^{n-1}b_i x^i\in \mathbb{F}_{998\,244\,353}[[x]]$, $h(x)\coloneqq \sum_{i=0}^{n-1}c_i x^i\in \mathbb{F}_{998\,244\,353}[[x]]$가 주어집니다. 이들은 제한으로부터 다음 성질을 만족함이 보장됩니다.

- $a_0=0$
- $a_1^i\not\equiv a_1\pmod{998\,244\,353}$ ($i=2,3,\dots,n-1$)
- $b_0=0$
- $b_1=1$
- $g(f(x))\equiv a_1g(x)\pmod{x^n}$
- $g(h(x))\equiv h(g(x))\equiv x\pmod{x^n}$

$k=0,1,\dots,m-1$에 대하여 $\mathrm{ans}_k=[x^{n-1}]f^{\langle k\rangle}(x)$를 구하세요. 여기서 $f^{\langle k\rangle}(x)$는 $f(x)$를 $k$번 합성한 것을 나타냅니다.

단, $f^{\langle 0\rangle}(x)=x$입니다.

## 입력

```text
$n\ m$
$a_0\ a_1\ \dots\ a_{n-1}$
$b_0\ b_1\ \dots\ b_{n-1}$
$c_0\ c_1\ \dots\ c_{n-1}$
```

## 제한

- 입력은 모두 정수입니다.
- $3\leq n\leq 200\,000$
- $1\leq m\leq 200\,000$
- $0\leq a_i,b_i,c_i<998\,244\,353$
- $a_0=0$
- $a_1^i\not\equiv a_1\pmod{998\,244\,353}$ ($i=2,3,\dots,n-1$)
- $b_0=0$
- $b_1=1$
- 문제 설명에서 정의된 $f(x),g(x)$는 $g(f(x))\equiv a_1g(x)\pmod{x^n}$을 만족합니다.
- 문제 설명에서 정의된 $g(x),h(x)$는 $g(h(x))\equiv h(g(x))\equiv x\pmod{x^n}$을 만족합니다.

## 출력

다음 형식으로 출력하세요. 단, $\mathrm{ans}_i$는 $0\leq\mathrm{ans}_i<998\,244\,353$를 만족하는 정수입니다.

```text
$\mathrm{ans}_0\ \mathrm{ans}_1\ \dots\ \mathrm{ans}_{m-1}$
```
