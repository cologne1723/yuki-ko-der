## 문제 설명

정점 수가 $N$이고 간선 수가 $M$인 평면 그래프가 주어집니다.

각 정점에 색 $1$, $2$, $3$, $4$ 중 $1$개를 각각 선택하여 칠했을 때, 간선으로 직접 연결된 정점들이 서로 다른 색이 되도록 할 수 있는지 판정하고, 가능하다면 그 방법을 출력하세요.

단, 그래프는 다음 조건으로 생성되었습니다.

1. 정점 수가 $3$이고 간선 수가 $3$인 완전 그래프가 있습니다. 처음에는 정점에 번호가 붙어 있지 않습니다.
2. 다음 작업을 $N-3$번 반복합니다.
   - 그래프 안의 삼각형 면을 $1$개 선택합니다.
   - 면의 내부에 점을 $1$개 추가하고, 선택한 면의 $3$개의 정점 각각과 간선으로 연결합니다.
3. 정점에 $1$부터 $N$까지 번호를 붙입니다.

### 삼각형 면의 정의

평면 그래프의 간선으로 평면은 여러 영역으로 나뉩니다. 이 각각의 영역을 면이라고 합니다. 단, 바깥쪽으로 무한히 뻗어 있는 영역은 외면이라고 합니다.

외면이 아닌 면 중에서 경계가 $3$개의 간선으로 이루어진 것을 삼각형 면이라고 정의합니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ M$
$u_1\ v_1$
$u_2\ v_2$
$\vdots$
$u_M\ v_M$
```

$N$과 $M$은 각각 정점 수와 간선 수입니다. $u_i$와 $v_i$는 $i$번째 간선으로 직접 연결된 정점의 번호입니다.

## 제한

- 입력은 모두 정수입니다.
- $3 \le N \le 2 \times 10^5$
- $M = 3N - 6$
- $1 \le u_i, v_i \le N$
- 주어진 그래프는 문제문의 조건으로 생성된 그래프임이 보장됩니다.

## 출력

조건을 만족하는 칠하는 방법이 존재하지 않으면 `No`를 출력하세요.

정점 $v$ ($1 \le v \le N$)를 색 $C_v$로 칠해서 조건을 만족시킬 수 있다면 다음 형식으로 출력하세요.

```text
Yes
$C_1\ C_2\ \ldots\ C_N$
```

해가 여러 개 존재하는 경우에는 그중 아무 것이나 출력해도 정답으로 인정됩니다.
