`N`개의 무전탑이 있습니다. 두 무전탑 사이에 양방향 통신로를 건설할 수 있으며, 비용은 두 탑 사이 거리입니다.

반지름 `r` 이하인 통신로를 따라 이동하면 두 탑은 통신할 수 있습니다. 통신로를 적절히 건설해 모든 무전탑 쌍이 통신 가능하도록 할 때, 총 건설 비용이 최소가 되는 경우에 가능한 양의 정수 `r` 중 최솟값을 구하세요.

## 제약

- `2 <= N <= 100`
- 모든 간선 후보의 거리는 서로 다른 정수이고 `1 <= C_1 < ... < C_{N(N-1)/2} <= 10^100`입니다.
- 입력은 정수입니다.

## 입력

무전탑 수와 모든 무전탑 쌍의 양 끝점 및 거리가 주어집니다.

## 출력

조건을 만족하는 `r`의 최솟값을 출력하세요.
