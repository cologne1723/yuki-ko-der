## 문제 설명

음이 아닌 정수 $x,y$에 대해 $f(x,y)$를 다음과 같이 정의된 음이 아닌 정수로 둡니다.

$f(x,y)$를 이진 표기로 나타냈을 때, $2^i$($i\ge 0$)의 자리 값은 다음과 같습니다.

- $i$가 짝수이면 $x$의 $2^i$ 자리 값과 $y$의 $2^i$ 자리 값의 논리곱(AND)을 취한 값입니다.
- $i$가 홀수이면 $x$의 $2^i$ 자리 값과 $y$의 $2^i$ 자리 값의 논리합(OR)을 취한 값입니다.

예를 들어 $f(2,14)=10$입니다. (이진 표기로 나타내면 $f(0010_{(2)},1110_{(2)})=1010_{(2)}$입니다.)

음이 아닌 정수 $N,M$이 주어집니다. $f(x,N)=M$을 만족하는 가장 작은 음이 아닌 정수 $x$를 구하세요.

만족하는 정수 $x$가 존재하지 않으면 $-1$을 출력하세요.

## 입력

```text
$N\ M$
```

## 제한

- $0\le N<2^{30}$
- $0\le M<2^{30}$
- 입력은 모두 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
31 14
```

#### 출력

```text
4
```

$f(4,31)=f(00100_{(2)},11111_{(2)})=01110_{(2)}=14$가 성립하고, $4$보다 작은 정수 중 이를 만족하는 $x$는 존재하지 않으므로 $4$를 출력하세요.

### 예제 2 {file=""}

#### 입력

```text
314 159
```

#### 출력

```text
-1
```

이를 만족하는 음이 아닌 정수 $x$가 존재하지 않음을 증명할 수 있습니다.

따라서 $-1$을 출력하세요.

### 예제 3 {file=""}

#### 입력

```text
1073741823 1073741823
```

#### 출력

```text
357913941
```
