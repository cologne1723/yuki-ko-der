## 문제 설명

어느 나라의 통화 단위는 “유키코다”입니다.
$D$유키코다인 물건을 사려고 하는데, 물건 가격에 소비세율 $P$%의 소비세가 추가됩니다.
실제로 지불할 금액을 구하세요. 소수점 이하는 버립니다.

## 입력

```text
D P
```

$D$는 소비세를 포함하지 않은 물건 가격입니다. $(1 \le D \le 10\,000\,000)$
$P$는 소비세율입니다. $(0 \le P \le 100)$

## 출력

소비세를 고려한 실제 지불 금액을 한 줄에 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

## 예제

### 예제 1

#### 입력

```text
100 8
```

#### 출력

```text
108
```

100유키코다인 물건에 소비세율 8%를 적용하면 소비세는 $100\times0.08=8$유키코다이므로 실제 지불액은 108유키코다입니다.

### 예제 2

#### 입력

```text
10 8
```

#### 출력

```text
10
```

소비세는 $10\times0.08=0.8$유키코다이므로 계산상 금액은 10.8이지만 소수점 이하를 버리면 10입니다.

### 예제 3

#### 입력

```text
123 10
```

#### 출력

```text
135
```

### 예제 4

#### 입력

```text
25 16
```

#### 출력

```text
29
```
