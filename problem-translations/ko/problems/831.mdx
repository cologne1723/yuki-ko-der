## 문제

Shuz국에는 도시 $N$개가 있고 1부터 $N$까지 번호가 붙어 있습니다. 모든 두 도시 사이에는 고속도로가 있습니다. 도시 $i$에서 $j$로 편도 이동하면 기본 요금 $i\times j$엔이 들고, $i\lt j$이면 $j-i$엔의 추가 요금, $i\gt j$이면 $i-j$엔의 할인(즉 총 요금은 언제나 $i\times j+j-i$)이 적용됩니다.

원하는 도시에서 출발해 모든 도시를 정확히 한 번씩 방문하고 출발 도시로 돌아오는 데 필요한 최소 요금을 구하세요.

## 입력

~~~text
$N$
~~~

$1\leq N\leq2\times10^6$

## 출력

최소 요금을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
3
~~~

#### 출력

~~~text
11
~~~

2→1에 1엔, 1→3에 5엔, 3→2에 5엔으로 총 11엔입니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
1
~~~

#### 출력

~~~text
0
~~~

도시가 하나뿐이면 순회할 필요가 없습니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
200
~~~

#### 출력

~~~text
1353499
~~~
