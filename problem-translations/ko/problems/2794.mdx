## 문제 설명

길이가 $N-1$인 문자열 $s$가 주어집니다. $s$는 `<`와 `>`로 이루어져 있습니다.

$(1,2,\ldots,N)$의 순열 $(p_1,p_2,\ldots,p_N)$ 중 다음 조건을 모두 만족하는 것은 몇 개인지 구하세요. 답을 $998\,244\,353$으로 나눈 나머지를 구하세요.

- 각 $i$ $(1\leq i\leq N-1)$에 대해, $s$의 $i$번째 문자가 `<`이면 $p_i<p_{i+1}$이고, `>`이면 $p_i>p_{i+1}$입니다.
- $(p_1,p_2,\ldots,p_N)$의 최장 증가 부분 수열의 길이는 $2$입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$s$
```

## 제한

- $N$은 $2$ 이상 $2\times 10^5$ 이하의 정수입니다.
- $s$는 `<`와 `>`로 이루어진 길이 $N-1$의 문자열입니다.

## 출력

조건을 모두 만족하는 순열의 개수를 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
<><
```

#### 출력

```text
2
```

$(2,4,1,3),(3,4,1,2)$가 조건을 만족합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
5
<<<<
```

#### 출력

```text
0
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
35
><>><>>><>>>><>>>>><>>>>>><>>>>>>>
```

#### 출력

```text
592821357
```

답을 $998\,244\,353$으로 나눈 나머지를 구하세요.
