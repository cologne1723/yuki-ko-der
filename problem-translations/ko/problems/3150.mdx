## 문제 설명

방정식 $A \mid X = B$를 만족하는 비음수 정수 $X$의 개수를 출력하세요.

여기서 $\mid$는 이진수로 나타냈을 때 각 비트에 대해 OR 연산을 나타냅니다. 예를 들어 다음과 같습니다.

$(5)_{10} \mid (6)_{10} = (101)_2 \mid (110)_2 = (111)_2 = (7)_{10}$

OR 연산은 $0$ 또는 $1$ 중 하나인 수 $a$, $b$에 대해 다음과 같이 정의됩니다. $a \mid b$는 $a$ 또는 $b$ 중 하나라도 $1$이면 $1$, 그렇지 않으면 $0$입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 십진수로 주어집니다.

```text
$A\ B$
```

## 제한

- $0 \le A,B \le 255$
- 입력은 모두 정수입니다.

## 출력

방정식을 만족하는 비음수 정수 $X$의 개수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
0 6
```

#### 출력

```text
1
```

$(0)_{10} \mid X = (6)_{10}$을 만족하는 $X$는 $(6)_{10}$ $1$개뿐입니다.

$X=(6)_{10}$은 $(0)_{10} \mid (6)_{10}=(6)_{10}$이므로 주어진 방정식을 만족합니다.

이외에 방정식을 만족하는 비음수 정수 $X$는 존재하지 않으므로 $1$을 출력합니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 5
```

#### 출력

```text
2
```

$(1)_{10} \mid X = (5)_{10}$을 만족하는 비음수 정수 $X$는 $(4)_{10}$과 $(5)_{10}$, $2$개입니다.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
3 4
```

#### 출력

```text
0
```

$(3)_{10} \mid X = (4)_{10}$을 만족하는 비음수 정수 $X$는 존재하지 않습니다.

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
29 31
```

#### 출력

```text
16
```
