$N$개 정당의 득표수가 $A_i$로 주어집니다. $B_1<\cdots<B_M$인 정수열에 대해 정당 $i$의 $j$번째 후보 점수는 $A_i/B_j$입니다. 점수가 큰 후보부터, 동점이면 정당 번호가 작은 후보부터 $M$명을 당선시킬 때 당선자들의 정당 번호를 순서대로 출력하세요.

## 조건

- $2\le N,M\le10^5$
- $1\le A_i,B_j\le10^9$

## 입력

```text
N M
A1 ... AN
B1 ... BM
```

## 출력

$M$개의 정당 번호를 한 줄에 하나씩 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 5
180 120 90
1 2 3 4 5
```

#### 출력

```text
1
2
1
3
1
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 3
1000 10000 100000
1 100000000 1000000000
```

#### 출력

```text
3
2
1
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
2 4
499999319 999998638
499999321 999998642 999999999 1000000000
```

#### 출력

```text
2
1
2
2
```
