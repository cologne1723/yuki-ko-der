## 문제 설명

음이 아닌 정수 $4$개 $A$, $B$, $C$, $D$가 주어집니다. 이들을 배열하여 연속하는 정수 $4$개로 만들 수 있는지 판정하세요.

단, 정수 $4$개 $X < Y < Z < W$가 연속한다는 것은 $Y = X+1$, $Z = Y+1$, $W = Z+1$이 모두 성립하는 것을 뜻합니다.

## 입력

```text
$A\ B\ C\ D$
```

입력은 모두 정수입니다.

## 제한

$0 \leq A, B, C, D \leq 100$

## 출력

주어진 정수 $4$개를 배열하여 연속하는 정수 $4$개로 만들 수 있다면 `Yes`를 출력하세요. 그렇지 않다면 `No`를 출력하세요.

출력 끝에 줄 바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 1 2 4
```

#### 출력

```text
Yes
```

입력을 배열하면 `1 2 3 4`로 만들 수 있으며, 이는 연속하는 정수 $4$개입니다.

### 예제 2 {file=""}

#### 입력

```text
0 2 2 4
```

#### 출력

```text
No
```

어떻게 배열해도 연속하는 정수 $4$개로 만들 수 없습니다.
