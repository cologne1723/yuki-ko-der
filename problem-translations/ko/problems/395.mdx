## 문제 설명

어떤 아이돌이 자신을 “$17$세입니다! ($X$진수로)”라고 소개했습니다.

아이돌의 실제 나이는 $10$진수로 $A$세입니다. 이 나이를 밑이 $X$인 진법으로 나타냈을 때 $17$이 되도록 하는 가장 작은 양의 정수 $X$ ($X \geq 2$)를 구하세요. 그런 $X$가 없다면 $-1$을 출력하세요.

## 입력

```text
$A$
```

## 제한

- $A$는 정수입니다.
- $0 \leq A \leq 100$

## 출력

조건을 만족하는 가장 작은 $X$를 한 줄에 출력하세요. 존재하지 않으면 $-1$을 출력하세요.

## 참고

진법에 대한 설명은 [Radix](https://en.wikipedia.org/wiki/Radix#In_numeral_systems)를 참고하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
51
```

#### 출력

```text
44
```

### 예제 2 {file=""}

#### 입력

```text
3
```

#### 출력

```text
-1
```

$3$세인 아이돌은 $17$세라고 할 수 없습니다.

#### 출력
