## 문제

고등학생 야스오 군은 모루가나 선배와 첫 참배를 가기로 했습니다. 선배는 정해진 금액을 정확히 잔돈으로 봉납할 수 있으면 사귀겠다고 말했습니다.

야스오 군은 500엔 동전 $A$개, 100엔 동전 $B$개, 50엔 동전 $C$개, 10엔 동전 $D$개, 5엔 동전 $E$개, 1엔 동전 $F$개를 가지고 있고, 필요한 금액은 $G$엔입니다. 정확히 봉납할 수 있으면 YES, 없으면 NO를 출력하세요.

## 입력

~~~text
$A\ B\ C\ D\ E\ F\ G$
~~~

$0\leq A,B,C,D,E,F\leq10$, $1\leq G\leq5000$

## 출력

YES 또는 NO를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
0 0 0 0 0 1 1
~~~

#### 출력

~~~text
YES
~~~

1엔 동전 한 장으로 1엔을 봉납할 수 있습니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
0 0 2 0 1 9 114
~~~

#### 출력

~~~text
YES
~~~

50엔 동전 2장, 5엔 동전 1장, 1엔 동전 9장으로 114엔을 만들 수 있습니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
0 0 2 0 1 8 114
~~~

#### 출력

~~~text
NO
~~~
