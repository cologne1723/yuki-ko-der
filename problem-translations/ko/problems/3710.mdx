## 문제 설명

유티씨는 벽의 타일을 교체하려고 합니다. 유티씨에게는 원하는 무늬가 $N$개 있습니다.

$i$번째 무늬는 길이 $M$인 문자열 $M$개로 나타냅니다. 문자열 $S_{i,j}$의 $k$번째 문자가 `#`이면 위에서 $j$번째 행, 왼쪽에서 $k$번째 열의 칸이 검은색이어야 하고, `.`이면 검은색이 아니어도 됩니다.

각 무늬는 $90$도 단위로 회전해도 되지만, 좌우나 상하로 뒤집을 수는 없습니다.

모든 무늬의 조건을 만족하는 $M\times M$ 타일에 포함되는 검은 칸 수의 최솟값을 구하세요.

## 입력

```text
$N\ M$
$S_{1, 1}$
$\vdots$
$S_{1, M}$
$\vdots$
$S_{N, 1}$
$\vdots$
$S_{N, M}$
```

## 제한

- $N,M$은 정수입니다.
- $1 \leq N \leq 8$
- $1 \leq M \leq 10$
- $S_{i,j}$는 `#`과 `.`으로 이루어진 길이 $M$의 문자열입니다.

## 출력

모든 무늬의 조건을 만족하는 $M\times M$ 타일에 포함되는 검은 칸 수의 최솟값을 출력하세요. 마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 4
####
....
....
....
....
.##. 
.##. 
....
....
....
....
...#
```

#### 출력

```text
8
```

원하는 무늬는 각각 다음과 같습니다.

```text
####  ....  ....
....  .##.  ....
....  .##.  ....
....  ....  ...#
```

$3$번째 무늬를 $180$도 회전합니다. 다음 무늬로 만들면 검은 칸은 $8$개입니다. $7$개 이하로는 만들 수 없으므로 이것이 최솟값입니다.

```text
####
.##.
.##.
....
```
