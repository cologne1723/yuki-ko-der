> **공지 (2020년 4월 10일 15:06 업데이트)** 테스트 케이스에 입력이 존재하지 않는 것이 있었기 때문에, 문자열 $S$의 길이의 하한을 $1$에서 $0$으로 정정했습니다.

## 문제 설명

문자열 $S$에 대해 다음 연산을 원하는 만큼 수행하는 것을 생각합니다.

- 영소문자 $1$개를 선택하고, 문자열 안에서 그 문자를 모두 공백으로 바꿉니다.

이 연산을 통해 문자열을 다음과 같은 형태로 만들 수 있다면 `Yes`를, 만들 수 없다면 `NO`를 출력하세요.

문자열의 앞부분, 가운데 부분, 뒷부분을 순서대로 이어 붙인 결과가 다음과 같은 형태여야 합니다.

- 앞부분은 $0$개 이상의 공백입니다.
- 가운데 부분은 길이가 $2$ 이상이고, 홀수 번째 문자가 영소문자이며 짝수 번째 문자가 공백인 문자열입니다.
- 뒷부분은 $0$개 이상의 공백입니다.

## 입력

```text
$S$
```

## 제한

- $0 \le |S| \le 100$
- $S$는 영소문자와 공백으로 이루어집니다.

## 출력

조건을 만족하도록 만들 수 있다면 `Yes`를, 만들 수 없다면 `NO`를 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
atcoder
```

#### 출력

```text
Yes
```

예를 들어 `t`, `o`, `e`를 선택하여 연산을 수행하는 방법이 있습니다.

### 예제 2 {file=""}

#### 입력

```text
abcabc
```

#### 출력

```text
NO
```

`'abcabc'`, `' bc bc'`, `'a ca c'`, `'ab ab '`, `'a  a  '`, `' b  b '`, `'  c  c'`, `'      '` 중 어느 것도 조건을 만족하지 않습니다.

#### 출력

```text
Yes
```
