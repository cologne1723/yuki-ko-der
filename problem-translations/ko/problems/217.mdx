## 문제 설명

$N$행 $N$열의 마방진 $1$개를 출력하세요. 일반적으로 마방진은 여러 개 존재하며, 그중 어느 것이든 괜찮습니다.

이 문제에서 $N$행 $N$열 마방진이란 $1$부터 $N^2$까지의 정수를 $N$행 $N$열로 배치한 것으로, 각 행·각 열·$2$개의 대각선에 있는 수의 합이 모두 같은 것을 뜻합니다.

$3$행 $3$열 마방진의 예시는 다음과 같습니다.

```text
2 9 4
7 5 3
6 1 8
```

경쟁 프로그래밍에서 자주 등장하지 않는 알고리즘이므로, 힌트로 [위키백과 「마방진」](http://ja.wikipedia.org/wiki/%E9%AD%94%E6%96%B9%E9%99%A3)의 「마방진을 만드는 방법」을 참고해도 됩니다. 답을 구하려면 여러 알고리즘을 조합해야 합니다.

## 입력

```text
$N$
```

## 제한

- $3 \le N \le 20$
- $N$은 정수입니다.

## 출력

```text
$A_{1,1}\ A_{1,2}\ \dots\ A_{1,N}$
$A_{2,1}\ A_{2,2}\ \dots\ A_{2,N}$
$\vdots$
$A_{N,1}\ A_{N,2}\ \dots\ A_{N,N}$
```

조건을 만족하는 마방진 $1$개를 출력하세요. $y$번째 줄에는 마방진의 $y$번째 행을 $1$번째 열의 수 $A_{y,1}$부터 순서대로 공백으로 구분해 출력하세요. 수 앞뒤에 여분의 공백이 있어도 괜찮습니다.

## 예제

