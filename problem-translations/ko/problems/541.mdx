## 문제

세로로 4개, 가로로 N+1개의 꼭짓점이 격자 모양으로 연결된 무방향 그래프를 3×N 격자라고 합니다.

3×N 격자에 포함되는 단순 사이클의 개수를 10^9+7로 나눈 나머지를 구하세요.

## 입력

```text
N
```

1 ≤ N ≤ 10^18

## 출력

3×N 격자에 포함되는 단순 사이클의 개수를 10^9+7로 나눈 나머지를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
1
```

출력:

```text
6
```

1×1 사이클이 3개, 2×1 사이클이 2개, 3×1 사이클이 1개이므로 모두 6개입니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
20
```

출력:

```text
324214693
```

### 샘플 3 {file="sample3.in"}

입력:

```text
100
```

출력:

```text
652583913
```
