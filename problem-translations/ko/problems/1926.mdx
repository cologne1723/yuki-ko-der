다음과 같이 길이 $N+1$의 수열 $a=(a_0,\ldots,a_N)$를 정의합니다.

$$a_0=K\%M,\qquad a_i=a_{i-1}\%(M-i)\ (1\le i\le N)$$

## 문제

$a_N$을 구하세요.

## 입력

```text
T
N M K
```

$1\le T\le10^5$, $1\le N<M\le10^9$, $1\le K\le10^9$입니다.

## 출력

각 테스트 케이스의 답을 출력하세요.
