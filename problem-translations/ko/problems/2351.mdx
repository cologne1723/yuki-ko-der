나비의 날개는 $N$개 부분으로 나뉘고, 각 부분은 $K$가지 색 중 하나를 같은 확률로 가집니다. 정확히 하나의 부분만 나머지 $N-1$개와 다른 색일 확률을 $998244353$로 나눈 값으로 출력하세요.

## 조건

- $3\le N\le10^5$
- $2\le K\le10^5$

## 입력

정수 $N,K$가 주어집니다.

## 출력

확률을 문제의 정의에 따라 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 2
```

#### 출력

```text
249561089
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
4 2
```

#### 출력

```text
499122177
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
16 2017
```

#### 출력

```text
62053606
```
