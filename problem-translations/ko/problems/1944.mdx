반지름이 $R_1,\ldots,R_N$인 원을 가지고 있습니다. 첫 번째 원을 원점 중심으로 놓고, 이후 원은 직전에 놓은 원과 만나도록 원하는 순서로 놓습니다. 마지막 원이 $(X,Y)$와 접하도록 할 수 있는지 판정하세요.

## 입력

```text
N X Y
R_1 R_2 ... R_N
```

$1\le N\le2\times10^5$, $-10^9\le X,Y\le10^9$, $1\le R_i\le10^5$입니다.

## 출력

가능하면 `Yes`, 불가능하면 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 8 3
1 2 3 1
```

#### 출력

```text
Yes
```

### 예제 2 {file=""}

#### 입력

```text
3 100 0
3 4 2
```

#### 출력

```text
No
```

### 예제 3 {file=""}

#### 입력

```text
3 -1 -2
1 1 5
```

#### 출력

```text
Yes
```
