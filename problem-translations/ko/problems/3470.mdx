## 문제 설명

$N$개의 제출이 있습니다. $i$번째 제출의 실행 시간은 $T_i$밀리초입니다.

모든 쌍 $(i,j)$ ($1 \le i < j \le N$)에 대한 실행 시간 차이의 절댓값 $|T_i-T_j|$의 합을 구하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$T_1\ T_2\ \ldots\ T_N$
```

$1$번째 줄에 제출 수를 나타내는 정수 $N$이 주어집니다.

$2$번째 줄에 각 제출의 실행 시간을 나타내는 정수 $T_1,T_2,\ldots,T_N$이 주어집니다.

## 제한

- 모든 입력은 정수입니다.
- $2 \le N \le 200\,000$
- $0 \le T_i \le 10^8$

이 문제에는 서브태스크에 의한 부분점수가 설정되어 있습니다.

| 서브태스크명 | 배점 | 제한 |
| --- | ---: | --- |
| small | $40$% ($100$점) | $N \le 1\,000$ |
| large | $30$% ($75$점) | 추가 제한 없음 |
| 랜덤large | $30$% ($75$점) | 추가 제한 없음 |

## 출력

$\displaystyle\sum_{1 \le i < j \le N} |T_i-T_j|$을 $1$줄에 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 3 6
```

#### 출력

```text
10
```

$|1-3| + |1-6| + |3-6| = 2 + 5 + 3 = 10$입니다.

### 예제 2 {file=""}

#### 입력

```text
4
5 5 5 5
```

#### 출력

```text
0
```

모든 값이 같으므로 차이는 $0$입니다.

### 예제 3 {file=""}

#### 입력

```text
5
1 2 3 4 5
```

#### 출력

```text
20
```
