## 문제

문자열 분할 기계는 현재 문자열의 부분 수열 중 사전순으로 가장 큰 것을 골라 출력하고 삭제하는 작업을 문자열이 빌 때까지 반복합니다.

영소문자와 `?`로 이루어진 문자열 $S$가 주어집니다. `?`를 임의의 영소문자로 바꾼 문자열 중 문자열 분할 수가 최소인 것을, 여러 개면 사전순으로 가장 작은 것을 구하세요.

## 입력

문자열 $S$가 주어집니다.

## 출력

조건을 만족하는 문자열을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
?c?b?d?
```

#### 출력

```text
ccbbada
```

### 예제 2 {file=""}

#### 입력

```text
????
```

#### 출력

```text
aaaa
```

### 예제 3 {file=""}

#### 입력

```text
?yzab
```

#### 출력

```text
yyzab
```

### 예제 4 {file=""}

#### 입력

```text
?yzabc
```

#### 출력

```text
ayzabc
```

### 예제 5 {file=""}

#### 입력

```text
?yz?xyz?tu?def?abc?
```

#### 출력

```text
xyzxxyzdtuddefaabca
```
