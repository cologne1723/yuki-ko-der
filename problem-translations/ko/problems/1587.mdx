## 문제

짝수 $N$에 대해 $N\times N$ 행렬의 각 칸에 0, 1, 2를 써서 각 행의 합 $A_i$와 각 열의 합 $B_j$를 만들었을 때, $A_1,\ldots,A_N,B_1,\ldots,B_N$이 모두 서로 다르도록 할 수 있는지 판정하세요. 가능하면 하나 구성하세요.

## 입력

짝수 정수 $N$이 주어집니다.

## 출력

불가능하면 `No`, 가능하면 조건을 만족하는 행렬을 출력하세요.
