## 공지

이번에 처음 시도하는 방법으로 테스터를 Gemini 2.5Pro에게 맡겨 보았습니다.

## 문제 설명

$2$개의 양의 정수 $n$, $x$가 주어집니다. 서로 다른 $2$개의 양의 정수 $a$, $b$가 존재하여 $a^x b=n$을 만족하는지 판정하세요. 존재한다면 `Yes`를, 존재하지 않는다면 `No`를 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$n\ x$
```

$2$개의 양의 정수 $n$, $x$가 공백으로 구분되어 주어집니다.

## 제한

- $1 \leq n,x \leq 10^9$

## 출력

`Yes` 또는 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1
```

#### 출력

```text
No
```

### 예제 2 {file=""}

#### 입력

```text
2 1
```

#### 출력

```text
Yes
```
