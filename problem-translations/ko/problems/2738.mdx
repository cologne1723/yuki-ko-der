## 문제

`C`, `P`, `T`, `F`로 이루어진 문자열에서 연속 부분 문자열 `CPC`를 골라 `F`로 바꿀 수 있습니다. 이 작업을 원하는 만큼 한 뒤, 문자열에 포함되는 연속 부분 문자열 `CPCTF`의 최대 개수를 구하세요.

## 제약

- `5 ≤ N ≤ 5×10^5`
- `S`는 길이 `N`이고 `C,P,T,F`만 포함합니다.

## 입력

```text
N
S
```

## 출력

최대 개수를 출력하세요.
