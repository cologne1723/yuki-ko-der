## 문제

서로 다른 양의 정수 `A_1,...,A_N`을 출력하세요. 모든 수는 `10^16` 이하이어야 하며,

\[
\gcd(A_1,A_2)+\cdots+\gcd(A_N,A_1)
\]

이 각 수의 최소공배수와 같아야 합니다. 조건을 만족하는 해가 존재함이 보장됩니다.

## 입력

`3\le N\le50`인 `N`이 주어집니다.

## 출력

조건을 만족하는 수열을 출력하세요.
