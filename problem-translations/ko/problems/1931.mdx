길이 $N$의 양의 정수열 $A,B$가 주어집니다. $\sum_{i=1}^N A_i/B_i$를 기약분수 $c/d$로 나타냈을 때 $c,d$를 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
N
A_1 B_1
...
A_N B_N
```

$1\le N\le2\times10^5$, $1\le A_i,B_i\le2\times10^5$, $\gcd(A_i,B_i)=1$입니다.

## 출력

$c,d$를 공백으로 구분해 출력하세요.
