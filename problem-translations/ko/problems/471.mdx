## 문제

평면 위의 점을 점 $P(p_x,p_y)$를 중심으로 반시계 방향으로 $R$도($R\in\{0,90,180,270\}$) 회전시키는 기계를 회전기라고 합니다.

$N$개의 회전기가 있으며, 회전기 $i$는 평면 위의 점을 점 $P_i({p_i}_x,{p_i}_y)$를 중심으로 반시계 방향으로 $R_i$도($R_i\in\{0,90,180,270\}$) 회전시킵니다.

$M$개 점의 좌표가 주어질 때, 회전기 1부터 회전기 $N$까지 번호순으로 연속 사용한 후 점의 좌표를 출력하세요.

점에 회전기 1을 적용하고, 이어서 회전기 2, $\dots$, 회전기 $N$을 적용합니다.

흔한 문제이므로 한 가지를 바꾸겠습니다.

회전기 정보는 답변자에게 주어지지 않습니다.

대신 최대 10회까지 점 $(x,y)$($x,y$는 정수이고 $|x|,|y|\leq10^4$)에 $N$개의 회전기를 사용한 뒤의 좌표 $(x',y')$를 반환하는 질문 쿼리를 실행할 수 있습니다.

## 입출력

이 문제는 리액티브 문제입니다. 출력을 flush하는 것을 잊지 마세요.

표준 입력으로 $M$개 점이 주어지므로, 먼저 이를 입력받으세요.

```text
$M$
$x_1\ y_1$
$\vdots$
$x_M\ y_M$
```

입력은 모두 정수입니다.

$1\leq M\leq5\times10^4$

$|x_i|,|y_i|\leq10^4$

입력을 받은 뒤 질문 쿼리와 답변 쿼리를 실행하세요.

질문 쿼리는 다음 형식으로 표준 출력에 출력하세요. 끝에 줄바꿈이 필요합니다.

```text
? x y
```

질문 쿼리는 최대 10회 실행할 수 있습니다. 10회를 초과하면 오답입니다.

$x,y$는 정수이고 $|x|,|y|\leq10^4$이어야 합니다. 제약을 만족하지 않으면 저지 프로그램이 정상적으로 동작하지 않을 수 있습니다.

질문 쿼리에 대한 응답은 다음 형식으로 표준 입력에 주어집니다.

```text
$x'\ y'$
```

질문 쿼리로 주어진 점 $(x,y)$를 $N$개의 회전기로 회전시킨 뒤의 좌표 $(x',y')$가 반환됩니다.

$x',y'$는 정수이지만 입력에 따라 $10^4$를 초과할 수 있습니다.

질문 쿼리를 실행한 뒤 답변 쿼리를 다음 형식으로 출력하세요.

```text
!
$x'_1\ y'_1$
$\vdots$
$x'_M\ y'_M$
```

첫 번째 줄에는 `!`, 두 번째 줄 이후에는 처음 주어진 $M$개 점을 회전시킨 뒤의 점을 순서대로 한 줄에 하나씩 출력하세요.

모든 점이 올바르다고 판정되면 정답입니다. 뒤에 불필요한 출력을 하지 마세요.

답변자에게 공개되지는 않지만, $N$개의 회전기는 저지에 다음 형식으로 주어집니다.

```text
$N$
${p_1}_x\ ${p_1}_y\ R_1$
$\vdots$
${p_N}_x\ ${p_N}_y\ R_N$
```

$1\leq N\leq5\times10^4$

$|{p_i}_x|,|{p_i}_y|\leq10^4$

$R_i\in\{0,90,180,270\}$

## 예제

### 샘플 1 {file="sample1.in"}

회전기가 다음과 같은 경우입니다.

```text
2
0 0 90
1 1 90
```

평면 위의 점은 $(0,0)$을 중심으로 90도 회전한 뒤 $(1,1)$을 중심으로 90도 회전합니다.

예: $(1,1)\to(-1,1)\to(1,-1)$

처음에 $M$개 점의 정보를 입력받습니다.

```text
3
0 0
1 0
1 1
```

질문 쿼리는 최대 10회 실행할 수 있습니다. 다음은 그 한 예입니다.

질문

```text
? 0 0
```

응답

```text
2 0
```

질문

```text
? 1 0
```

응답

```text
1 0
```

질문

```text
? 1 1
```

응답

```text
1 -1
```

답변 쿼리

```text
!
2 0
1 0
1 -1
```

$M>10$인 경우에는 이 방법을 사용할 수 없으므로, 궁리하거나 초능력을 사용하여 해결하세요.
