정점 $N$개의 트리에서 일부 간선을 삭제합니다. 각 연결 요소의 점수를 그 요소의 정점 수와 정점에 적힌 최댓값의 곱으로 정의할 때, 모든 간선 삭제 방법에 대한 점수 합을 $998244353$으로 나눈 나머지를 구하세요.

## 입력

```text
N
A_1 ... A_N
u_1 v_1
...
u_{N-1} v_{N-1}
```

## 출력

모든 삭제 방법의 점수 합을 출력하세요.
