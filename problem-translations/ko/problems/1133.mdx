## 문제 설명

null 군은 킴와이프를 매우 좋아합니다.

좌표평면에서 $(0,0)$부터 $(n,n)$까지의 정사각형 안에 있는 모든 격자점에 킴와이프가 하나씩 놓여 있습니다. 좌표평면의 $x$축을 가로 방향, $y$축을 세로 방향으로 하며, $(0,0)$을 왼쪽 아래로 하고 오른쪽과 위쪽을 각각 양의 방향으로 합니다.

null 군은 처음에 $(0,0)$에 있습니다. 이제 $m$번 이동하며, 이동한 위치에 킴와이프가 있으면 그것을 먹습니다. $(0,0)$의 킴와이프는 이미 먹은 것으로 합니다.

$m$번 이동한 뒤 각 격자점에 킴와이프가 남아 있는지 출력하세요.

## 제한

- $1 \leq n \leq 200$
- $1 \leq m \leq 10^6$
- $|s|=m$ ($|s|$는 문자열 $s$의 길이입니다.)
- $n$, $m$은 모두 정수입니다.
- $s$는 `U`, `R`, `L`, `D` 중 하나만 포함합니다.

## 입력

```text
$n\ m$
$s$
```

이동 중 $x$, $y$ 좌표는 모두 $(0,0)$부터 $(n,n)$까지의 정사각형 밖으로 나가지 않습니다.

이동 방법은 문자열 $s$로 나타냅니다. 이동 전 좌표가 $(a,b)$일 때 `U`는 위로 이동하여 $(a,b+1)$로, `R`은 오른쪽으로 이동하여 $(a+1,b)$로, `L`은 왼쪽으로 이동하여 $(a-1,b)$로, `D`는 아래로 이동하여 $(a,b-1)$로 이동하는 것을 뜻합니다.

## 출력

$(n+1) \times (n+1)$개의 값을 출력하세요.

각 격자점에 킴와이프가 있으면 `1`, 없으면 `0`을 공백으로 구분해 출력하세요. 행 끝에는 공백을 넣지 말고 마지막에 줄바꿈을 넣으세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2 8
RRULLURR
```

#### 출력

```text
0 0 0
0 0 0
0 0 0
```

킴와이프를 전부 먹었습니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 2
RL
```

#### 출력

```text
1 1
0 0
```

왼쪽 아래를 $(0,0)$, 오른쪽 위를 $(n,n)$으로 한다는 점에 주의하세요.
