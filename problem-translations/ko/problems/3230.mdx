## 문제 설명

사람 $N$명 $H_1, \dots, H_N$이 서로 편지를 $M$통씩 주고받습니다.

각 사람 $H_n$은 $T_n$일째에 다른 모든 사람에게 $1$번째 편지를 한꺼번에 보냅니다.

각 사람 $H_n$은 다음 조건을 만족한 날에 다른 모든 사람에게 $m+1$번째 편지를 한꺼번에 보냅니다. ($m \geq 1$)

- $H_n$이 $m$번째 편지를 전날 또는 당일까지 보냈습니다.
- 다른 사람 $H_{n'}\ (n' \neq n)$ 모두에게서 $m$번째 편지가 도착했습니다.

여기서 $H_i$가 편지를 보낸 뒤 $H_j$에게 도착할 때까지 걸리는 날짜 수는 $A_{i,j}$입니다.

각 사람 $H_n$에게 다른 모든 사람으로부터 $M$번째 편지가 도착하는 날을 $n=1,\dots,N$에 대해 구하세요.

## 입력

```text
$N\ M$
$T_1\ \cdots\ T_N$
$A_{1,1}\ A_{1,2}\ \cdots\ A_{1,N}$
$\vdots$
$A_{N,1}\ A_{N,2}\ \cdots\ A_{N,N}$
```

입력은 다음 제한을 만족합니다.

## 제한

- $1 \leq N \leq 100$
- $2 \leq M \leq 10^{15}$
- $0 \leq T_n \leq 1\,000$
- $0 \leq A_{i,j} \leq 1\,000$
- $A_{i,i}=0$
- 입력은 모두 정수입니다.
- 답은 모두 $2^{63}$ 미만임이 보장됩니다.

$A_{i,i}$는 문제에서 사용하지 않지만 입력 형식을 간단하게 하기 위해 주어집니다.

## 출력

각 사람 $H_n$에게 다른 모든 사람으로부터 $M$번째 편지가 도착하는 날을 $n=1,\dots,N$에 대해 각각 반각 공백 $1$개로 구분하여 출력하세요. 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3 2
0 4 10
0 2 3
9 0 5
1 7 0
```

#### 출력

```text
26 17 22
```

$H_1$에게 $H_2$의 $1$번째 편지가 도착하는 날은 $4+9=13$일째이고, $H_3$의 $1$번째 편지가 도착하는 날은 $10+1=11$일째입니다. 따라서 $H_1$은 $13$일째에 $2$번째 편지를 보냅니다.

$H_2$에게 $H_1$의 $1$번째 편지가 도착하는 날은 $0+2=2$일째이고, $H_3$의 $1$번째 편지가 도착하는 날은 $10+7=17$일째입니다. 따라서 $H_2$는 $17$일째에 $2$번째 편지를 보냅니다.

$H_3$에게 $H_1$의 $1$번째 편지가 도착하는 날은 $0+3=3$일째이고, $H_2$의 $1$번째 편지가 도착하는 날은 $4+5=9$일째입니다. 따라서 $H_3$는 $10$일째에 $2$번째 편지를 보냅니다. (자신이 $1$번째 편지를 보내기 전에는 $2$번째 편지를 보내지 않는다는 점에 주의하세요.)

$H_1$이 $13$일째에 보낸 $2$번째 편지는 $13+2=15$일째에 $H_2$에게 도착하고, $13+3=16$일째에 $H_3$에게 도착합니다.

$H_2$가 $17$일째에 보낸 $2$번째 편지는 $17+9=26$일째에 $H_1$에게 도착하고, $17+5=22$일째에 $H_3$에게 도착합니다.

$H_3$가 $10$일째에 보낸 $2$번째 편지는 $10+1=11$일째에 $H_1$에게 도착하고, $10+7=17$일째에 $H_2$에게 도착합니다.

따라서 $H_1,H_2,H_3$에게 $2$번째 편지가 모든 사람으로부터 도착하는 날은 각각 $26,17,22$일째입니다.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
3 3
2 8 9
0 0 0
0 0 0
0 0 0
```

#### 출력

```text
9 9 9
```

$H_1$에게 $H_2$의 $1$번째 편지가 도착하는 날은 $8+0=8$일째이고, $H_3$의 $1$번째 편지가 도착하는 날은 $9+0=9$일째입니다. 따라서 $H_1$은 $9$일째에 $2$번째 편지를 보냅니다.

$H_2$에게 $H_1$의 $1$번째 편지가 도착하는 날은 $2+0=2$일째이고, $H_3$의 $1$번째 편지가 도착하는 날은 $9+0=9$일째입니다. 따라서 $H_2$는 $9$일째에 $2$번째 편지를 보냅니다.

$H_3$에게 $H_1$의 $1$번째 편지가 도착하는 날은 $2+0=2$일째이고, $H_2$의 $1$번째 편지가 도착하는 날은 $8+0=8$일째입니다. 따라서 $H_3$는 $9$일째에 $2$번째 편지를 보냅니다. (자신이 $1$번째 편지를 보내기 전에는 $2$번째 편지를 보내지 않는다는 점에 주의하세요.)

$H_1$이 $9$일째에 보낸 $2$번째 편지는 $9+0=9$일째에 $H_2$에게 도착하고, $9+0=9$일째에 $H_3$에게 도착합니다.

$H_2$가 $9$일째에 보낸 $2$번째 편지는 $9+0=9$일째에 $H_1$에게 도착하고, $9+0=9$일째에 $H_3$에게 도착합니다.

$H_3$가 $9$일째에 보낸 $2$번째 편지는 $9+0=9$일째에 $H_1$에게 도착하고, $9+0=9$일째에 $H_2$에게 도착합니다.

$H_1,H_2,H_3$가 $9$일째에 보낸 $2$번째 편지는 서로에게 $9$일째에 도착하므로, $3$명은 $9$일째에 $3$번째 편지를 보냅니다. $3$번째 편지도 $9$일째에 서로에게 도착합니다.

같은 날에 여러 통의 편지를 보낼 수도 있다는 점에 주의하세요.
