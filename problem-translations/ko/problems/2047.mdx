$N$개 정점의 트리가 주어집니다. 간선을 0개 이상 삭제하는 방법 중 모든 연결 요소가 경로 그래프가 되는 방법의 수를 $998244353$으로 나눈 나머지를 구하세요. 경로 그래프는 차수 $1$인 정점이 정확히 두 개이고 나머지 정점의 차수가 $2$인 트리이며, 정점 하나인 그래프는 제외합니다.

## 입력

```text
N
u_1 v_1
...
u_{N-1} v_{N-1}
```

$2\le N\le10^5$입니다.

## 출력

방법의 수를 출력하세요.
