## 문제 설명

$(0,1,2,\cdots,N-1)$의 순열 $P=(P_0,P_1,\cdots,P_{N-1})$가 주어집니다.

목표는 $P=(0,1,2,\cdots,N-1)$로 만드는 것입니다. 이를 위해 다음 $2$가지 연산을 최대 $20\,000$번, 원하는 순서로 수행할 수 있습니다.

- $P_0$과 $P_1$을 교환합니다.
- 모든 $i=0,1,\cdots,N-1$에 대해 $P_i$를 동시에 $P_{(i+1)\ \mathrm{mod}\ N}$으로 바꿉니다.

제한 조건 아래에서는 목표를 반드시 달성할 수 있음이 증명되어 있습니다. 목표를 달성하는 연산 순서의 예를 출력하세요. 연산 횟수를 최소화할 필요는 없습니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$P_0\ P_1\ \cdots\ P_{N-1}$
```

## 제한

- $3\leq N\leq 100$
- $P$는 $(0,1,2,\cdots,N-1)$의 순열입니다.
- 입력은 모두 정수입니다.

## 출력

$M$번의 연산으로 목표를 달성할 수 있다면, $M$개의 문자로 이루어진 문자열을 출력하세요. $i$번째 문자는 $i$번째 연산에서 $P_0$과 $P_1$을 교환하는 경우 `S`, 그렇지 않은 경우 `R`로 하세요.

조건을 만족하는 연산 순서가 여러 가지라면, 그중 어느 것이든 출력해도 됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
3 1 0 2
```

#### 출력

```text
SSRS
```

$1$번째 연산 후 $P=(1,3,0,2)$가 됩니다.

$2$번째 연산 후 $P=(3,1,0,2)$가 됩니다.

$3$번째 연산 후 $P=(1,0,2,3)$가 됩니다.

$4$번째 연산 후 $P=(0,1,2,3)$가 됩니다.

### 예제 2 {file=""}

#### 입력

```text
3
0 1 2
```

#### 출력

```text

```

연산을 수행하지 않아도 이미 목표를 달성한 경우에는 빈 문자열을 출력해도 됩니다.

### 예제 3 {file=""}

#### 입력

```text
3
2 1 0
```

#### 출력

```text
SRR
```

`RS` 등을 출력해도 정답으로 인정됩니다.
