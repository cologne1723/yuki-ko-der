## 문제 설명

$T$개의 테스트 케이스가 주어집니다. 각 테스트 케이스에 대해 다음 문제를 해결하세요.

길이가 $N$인 문자열 $S$가 주어집니다.

빈 문자열 $U$를 가지고 있으며, 다음 작업을 원하는 횟수만큼 수행할 수 있습니다.

- $U$에 $S$를 이어 붙입니다. 즉, $U$를 $US$로 바꿉니다.

문자열 $U$의 연속 부분 문자열에 길이가 $M$ 이상인 회문이 포함되도록 하는 데 필요한 작업 횟수의 최솟값을 구하세요.

아무리 작업을 수행해도 달성할 수 없다면 $-1$을 출력하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\text{case}_1$
$\vdots$
$\text{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ M$
$S$
```

$1$번째 줄에 테스트 케이스의 개수 $T$가 주어집니다.

각 테스트 케이스의 $1$번째 줄에 문자열의 길이 $N$과 필요한 회문의 길이 $M$이 주어지고, $2$번째 줄에 문자열 $S$가 주어집니다.

## 제한

- $1 \leq T \leq 2 \times 10^5$
- $1 \leq N \leq 2 \times 10^5$
- $1 \leq M \leq 10^9$
- $S$는 영문 소문자로 이루어진 길이 $N$의 문자열입니다.
- $1$개의 입력에 포함된 테스트 케이스에 대한 $N$의 총합은 $2 \times 10^5$ 이하입니다.
- $T$, $N$, $M$은 정수입니다.

## 출력

$T$줄에 걸쳐 출력하세요. $i$번째 줄에는 $i$번째 테스트 케이스의 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
4 10
acbc
3 2357
aba
4 2
sepa
```

#### 출력

```text
3
786
-1
```

$1$번째 테스트 케이스에서는 작업을 $3$회 수행하면 $U = $ `acbcacbcacbc`가 됩니다. 이때 연속 부분 문자열로 `cbcacbcacbc`가 포함되며, 이는 길이가 $11$인 회문입니다.
