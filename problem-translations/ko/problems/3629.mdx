## 문제 설명

양의 정수 $N$이 주어집니다.

숫자(`0123456789` 중 $1$개)만으로 이루어진 문자열 $X$에 대해, $\mathcal{P}(X)$를 $X$의 비어 있지 않은 부분 수열(연속하지 않아도 됩니다)을 정수로 해석했을 때 가능한 값 전체의 집합으로 정의합니다.

예를 들어 $x$가 `102`일 때 $\mathcal{P}(x) = \{0, 1, 2, 10, 12, 102 \}$입니다.

또한, $\mathrm{mex}\ \mathcal{P}(X)$를 $\mathcal{P}(X)$에 포함되지 않는 가장 작은 음이 아닌 정수로 정의합니다.

숫자만으로 이루어진 길이 $N$인 문자열 $S$ 중 $\mathrm{mex}\ \mathcal{P}(S)$로 가능한 최댓값을 $M$이라고 합니다.

$\mathrm{mex}\ \mathcal{P}(S') = M$을 만족하는 숫자만으로 이루어진 길이 $N$인 문자열 $S'$를 $1$개 제시하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- $1 \leq T \leq 1\,000$
- $1 \leq N \leq 5 \times 10^5$
- 모든 테스트 케이스에 대한 $N$의 합은 $5 \times 10^5$ 이하입니다.
- 입력은 모두 정수입니다.

## 출력

각 테스트 케이스에 대한 답을 순서대로 줄바꿈으로 구분하여 출력하세요.

조건을 만족하는 $S'$가 여러 개라면, 그중 어느 것이든 정답으로 판정됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
3
1
12
```

#### 출력

```text
102
0
214567893012
```

$1$번째 테스트 케이스에서 $S$가 `102`일 때, $\mathcal{P}(S) = \{0, 1, 2, 10, 12, 102\}$입니다. 따라서 $\mathrm{mex}\ \mathcal{P}(S) = 3$입니다.

실제로 이 값이 길이 $3$인 문자열 $S$에 대해 $\mathrm{mex}\ \mathcal{P}(S)$로 가능한 최댓값입니다.
