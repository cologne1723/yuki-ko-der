`H x W` 격자에서 술래 nok0와 도망자 zkou가 번갈아 상하좌우 인접 칸으로 이동합니다. nok0가 선공이며 두 사람이 같은 칸에 있으면 즉시 잡힙니다.

두 사람이 최적으로 움직일 때 nok0가 zkou를 잡을 수 있는지 판정하세요.

## 입력

격자 크기와 두 사람의 시작 위치가 주어집니다.

## 출력

잡을 수 있으면 `Yes`, 없으면 `No`를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 3
1 1
2 3
```

#### 출력

```text
Yes
```

### 예제 2 {file=""}

#### 입력

```text
2 2
1 1
2 2
```

#### 출력

```text
No
```

### 예제 3 {file=""}

#### 입력

```text
1000000000 1000000000
1 1
1000000000 1000000000
```

#### 출력

```text
No
```
