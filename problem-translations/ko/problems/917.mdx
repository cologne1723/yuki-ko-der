## 문제 설명

원소 $N$개로 이루어진 수열 $A$가 주어집니다. $i$번째 원소는 $A_i$입니다. $1 \le i \le N$입니다. 이 수열의 비어 있지 않은 부분 수열을 생각합니다.

부분 수열은 수열에서 원소를 $0$개 이상 골라 삭제하고, 남은 원소를 원래 순서대로 나열한 수열입니다.

포함된 모든 원소의 최대공약수가 $1$인 수열 $A$의 부분 수열 개수를 구하세요.

두 부분 수열의 원소 값이 모두 같더라도, 원래 수열에서 선택한 원소의 위치가 다르면 서로 다른 부분 수열로 취급한다는 점에 주의하세요.

## 입력

```text
$N$
$A_1\ A_2\ \dots\ A_N$
```

## 제한

- 입력은 모두 정수입니다.
- $1 \le N \le 50$
- $1 \le A_i \le 10^8$ ($1 \le i \le N$)

## 출력

조건을 만족하는 부분 수열의 개수를 출력하세요. 마지막에도 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 2 3
```

#### 출력

```text
5
```

$\{1\}$, $\{1,2\}$, $\{1,3\}$, $\{2,3\}$, $\{1,2,3\}$의 $5$개 부분 수열은 최대공약수가 $1$입니다.

### 예제 2 {file=""}

#### 입력

```text
4
1 1 1 1
```

#### 출력

```text
15
```

원소 값이 모두 같더라도 원래 수열에서 선택한 원소의 위치가 다르면 서로 다른 부분 수열로 취급한다는 점에 주의하세요.

### 예제 3 {file=""}

#### 입력

```text
4
2 4 8 16
```

#### 출력

```text
0
```

부분 수열을 어떻게 골라도 최대공약수가 $1$인 것은 없습니다.

### 예제 4 {file=""}

#### 입력

```text
10
801754 703742 332182 68016 914814 8470 937255 293192 313080 501971
```

#### 출력

```text
763
```
