## 문제 설명

$1$ 이상 $N$ 이하인 정수의 순열 $p_1, p_2, \ldots, p_N$ 중 다음 조건을 만족하는 순열의 개수를 $10^9+7$로 나눈 나머지를 구하세요.

모든 정수 $i$ ($1 \le i \le N$)에 대해 다음 조건을 만족합니다.

- $t_i = 1$이면 $p_i \ge X_i$입니다.
- $t_i = 0$이면 $p_i \le X_i$입니다.

## 입력

```text
$N$
$t_1\; X_1$
$t_2\; X_2$
$\vdots$
$t_N\; X_N$
```

입력은 모두 정수입니다.

## 제한

$1 \le N \le 3\,000$

$t_i = 0, 1$

$1 \le X_i \le N$

## 출력

조건을 만족하는 순열의 개수를 $10^9+7$로 나눈 나머지를 출력하세요. 마지막에 줄바꿈하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 2
0 1
1 1
```

#### 출력

```text
2
```

$(2,1,3)$과 $(3,1,2)$의 $2$개입니다.

### 예제 2 {file=""}

#### 입력

```text
4
1 4
1 4
1 4
1 4
```

#### 출력

```text
0
```

#### 입력

```text

1 1
0 4
1 1
0 5

0 3
```

#### 출력

```text
37314
```
