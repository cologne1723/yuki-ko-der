## 문제

당신은 여러 난제를 해결한 공로로 이 나라의 왕이 될 기회를 얻었습니다. 조건은 Enjapma 왕과 직접 게임을 해 이기는 것입니다.

$H$행 $W$열 격자에 일부 칸에 말이 놓여 있습니다. 문자열 $S_i$의 $j$번째 문자는 위에서 $i$행, 왼쪽에서 $j$열 칸의 상태를 나타내며 o면 말이 있고 -면 없습니다.

왕이 선공이고 두 사람이 번갈아 둡니다. 차례에는 말 하나를 골라 아래 또는 왼쪽의 인접한 빈 칸으로 옮기거나, 말 하나를 판에서 제거할 수 있습니다. 말이 모두 없어져 더 이상 둘 수 없게 된 사람이 패배합니다.

두 사람이 최선으로 플레이할 때 당신이 이겨 왕이 될 수 있는지 판정하세요.

## 입력

~~~text
$H\ W$
$S_1$
$S_2$
$\vdots$
$S_H$
~~~

$1\leq H,W\leq200$이고 각 $S_i$의 길이는 $W$입니다. 문자는 o 또는 -입니다.

## 출력

이길 수 있으면 YES, 없으면 NO를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
3 3
---
-o-
-o-
~~~

#### 출력

~~~text
YES
~~~

왕이 말을 제거하면 당신도 제거하면 됩니다. 왕이 말을 왼쪽으로 옮기면 당신도 말을 옮기세요. 그러면 다음 차례에 왕은 말을 제거할 수밖에 없고 당신도 제거하면 됩니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
2 3
o-o
o--
~~~

#### 출력

~~~text
NO
~~~

어떻게 행동해도 이길 수 없습니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
5 4
-ooo
--o-
---o
-o--
-ooo
~~~

#### 출력

~~~text
YES
~~~
