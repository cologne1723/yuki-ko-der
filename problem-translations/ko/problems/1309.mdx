## 문제 설명

$N$은 홀수입니다. $N$명이 시험을 보고 각자 $0$점 이상 $P$점 이하의 정수 점수를 얻었습니다. 중앙값이 $X$, 최빈값이 $Y$라는 정보에 맞는 점수들이 존재한다면 가능한 점수 합의 최댓값을 구하고, 존재하지 않으면 이를 보고하세요.

중앙값은 점수를 오름차순 정렬했을 때 앞에서 $(N+1)/2$번째 값입니다. 최빈값은 가장 많은 사람이 받은 점수이며, 최빈값이 여러 개면 그 점수들의 평균으로 정의합니다.

## 입력

```text
N P X Y
```

## 출력

조건을 만족하는 점수 합의 최댓값을 출력하세요. 불가능하면 `-1`을 출력하세요.
