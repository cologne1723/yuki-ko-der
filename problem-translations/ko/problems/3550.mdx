## 문제 설명

음이 아닌 정수 $x, y$에 대해 $f(x, y)$를 다음과 같이 정의된 음이 아닌 정수라고 합니다.

- $f(x, y)$를 이진 표기했을 때 $2^i$ ($i \ge 0$)의 자리의 값은 다음과 같습니다.
  - $i$가 짝수라면 $x$의 $2^i$ 자리의 값과 $y$의 $2^i$ 자리의 논리곱(AND)을 취한 값입니다.
  - $i$가 홀수라면 $x$의 $2^i$ 자리의 값과 $y$의 $2^i$ 자리의 논리합(OR)을 취한 값입니다.

예를 들어, $f(2, 14) = 10$입니다. (이진 표기로 나타내면 $f(0010_{(2)}, 1110_{(2)}) = 1010_{(2)}$입니다.)

또한 길이가 $n$ ($n$은 양의 정수)인 음이 아닌 정수열 $X = (X_1, X_2, \cdots, X_n)$에 대해 $F(X)$를 다음과 같이 정의합니다.

- 다음 점화식으로 정의되는 $S_n$의 값을 $F(X)$로 합니다.
  - $S_1 = X_1$
  - $S_k = f(S_{k - 1}, X_k)$ ($2 \le k \le n$)

양의 정수 $N$과 길이가 $N$인 음이 아닌 정수열 $A = (A_1, A_2, \cdots, A_N)$가 주어집니다.

$A$의 비어 있지 않은 부분수열 $B$ (연속일 필요는 없습니다)에 대한 $F(B)$로 가능한 값 중 최댓값을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
```

## 제한

- 입력되는 값은 모두 정수입니다.
- $1 \le N \le 2 \times 10^5$
- $0 \le A_i < 2^{30}$

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
6
3 1 4 1 5 9
```

#### 출력

```text
11
```

$B = (3, 5, 9)$를 선택하면 $f(f(3, 5), 9) = f(3, 9) = 11$로 계산됩니다. $12$ 이상으로 만들 수 없으므로 이것이 최댓값입니다.

```text
9

```
