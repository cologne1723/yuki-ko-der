## 문제 설명

카도마쓰 열이란 왼쪽부터 $A$, $B$, $C$의 순서로 $3$개의 정수가 놓여 있을 때, 모든 값이 서로 다르고 $A$, $B$, $C$ 중 두 번째로 큰 정수가 $A$ 또는 $C$인 경우를 말합니다.

특히 이 문제에서는 카도마쓰 열의 $A$, $B$, $C$가 양의 정수여야 합니다.

$3$개의 양의 정수 $A$, $B$, $C$가 왼쪽부터 이 순서로 주어집니다.

다음 $3$가지 연산을 원하는 횟수만큼 수행하여 최소 비용으로 카도마쓰 열을 만드세요.

- 비용 $X$로 양의 정수 $A$에서 $1$을 뺍니다.
- 비용 $Y$로 양의 정수 $B$에서 $1$을 뺍니다.
- 비용 $Z$로 양의 정수 $C$에서 $1$을 뺍니다.

※ 이 문제에서는 하나의 테스트 케이스에 여러 질의가 주어집니다.

## 입력

```text
$T$
$A_1\ B_1\ C_1\ X_1\ Y_1\ Z_1$
$A_2\ B_2\ C_2\ X_2\ Y_2\ Z_2$
$\vdots$
$A_T\ B_T\ C_T\ X_T\ Y_T\ Z_T$
```

$T$는 주어지는 양의 정수 $A$, $B$, $C$, $X$, $Y$, $Z$ 여섯 개로 이루어진 묶음(질의)의 개수입니다.

$A_i$, $B_i$, $C_i$는 $i$번째로 주어지는 양의 정수 $A$, $B$, $C$입니다.

$X_i$, $Y_i$, $Z_i$는 $i$번째 경우의 비용 $X$, $Y$, $Z$입니다.

## 제한

- $1 \le T \le 10\,000 = 10^4$
- $1 \le A_i, B_i, C_i \le 1\,000\,000\,000 = 10^9$ ($1 \le i \le T$)
- $1 \le X_i, Y_i, Z_i \le 1\,000\,000\,000 = 10^9$ ($1 \le i \le T$)

## 출력

$i$번째 $A_i$, $B_i$, $C_i$, $X_i$, $Y_i$, $Z_i$에 대한 답을 $i$번째 줄에 출력하세요.

카도마쓰 열을 만들 수 없는 경우에는 $-1$을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1
3 3 2 3 2 1
```

#### 출력

```text
4
```

왼쪽 수 $A$에서 $1$을 빼는 연산을 $2$번 수행하면 `1 3 2`가 되어 비용 $6$으로 카도마쓰 열을 만들 수 있습니다.

가운데 수 $B$에서 $1$을 빼는 연산을 $2$번 수행하면 `3 1 2`가 되어 비용 $4$로 카도마쓰 열을 만들 수 있습니다.

이 경우 최소 비용은 $4$입니다.

### 예제 2 {file=""}

#### 입력

```text
3
1 3 2 1 2 3
1 2 3 1 2 3
3 3 3 1 2 3
```

#### 출력

```text
0
-1
5
```
