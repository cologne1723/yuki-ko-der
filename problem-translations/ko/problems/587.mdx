## 문제

소문자 영문자 13개로 이루어진 길이 13의 문자열 S가 주어집니다.

S에 문자 하나를 추가해 서로 다른 7개의 문자 쌍(문자열에 해당 문자가 정확히 2개 존재)을 만들 수 있는지 판정하세요.

## 입력

```text
S
```

소문자 영문자 13개로 이루어진 문자열 S가 한 줄에 주어집니다.

## 출력

서로 다른 7개의 문자 쌍을 만들 수 있으면 추가할 문자를 출력하세요.

불가능하면 Impossible을 한 줄에 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
aabbccddeefgg
```

출력:

```text
f
```

### 샘플 2 {file="sample2.in"}

입력:

```text
ffeeddcccbbaa
```

출력:

```text
Impossible
```

### 샘플 3 {file="sample3.in"}

입력:

```text
hsgeeappashoo
```

출력:

```text
g
```
