## 이야기

당신은 적 로봇을 해킹해 비밀 이미지 데이터를 얻었습니다. 원본 이미지 데이터에 가벼운 2차원 합성곱 처리가 되어 있고, 보안을 통과할 때 픽셀 순서가 무작위로 바뀐 것을 알게 되었습니다. 원본을 유일하게 복원하기는 어렵지만, 원본으로 가능한 예를 만들면 알아낼 수 있는 것이 있을지도 모릅니다.

## 문제

$N\times N$ 행렬 $A$의 각 원소는 음이 아닌 정수입니다. 다음과 같이 $(N-1)\times(N-1)$ 행렬 $B$를 정의합니다.

$$B_{i,j}=A_{i,j}+A_{i,j+1}+A_{i+1,j}+A_{i+1,j+1}$$

$B$의 원소들을 무작위 순서로 배열한 배열 $C$가 주어질 때, 가능한 $A$의 한 예를 구하세요. 존재하지 않으면 그 사실을 출력하세요. $T$개의 테스트 케이스가 주어집니다.

## 제약

- $1\leq T\leq10^4$
- $2\leq N\leq700$
- $0\leq C_i\leq10^6-1$
- 한 입력 파일에서 $N^2$의 합은 $5\times10^5$ 이하입니다.

## 입력

~~~text
T
N
C_1 C_2 ... C_{(N-1)^2}
~~~

## 출력

가능한 행렬이 없으면 `-1`, 있으면 가능한 $A$를 $N$줄에 출력하세요.

## 샘플

### 입력 {file="stdin"}

~~~text
3
3
2 0 2 5
2
9
4
3 1 4 1 5 9 2 6 5
~~~

### 출력 {file="stdout"}

~~~text
2 0 1
0 0 1
0 0 4
2 0
2 5
1 1 0 0
1 0 0 1
2 2 0 4
1 4 0 0
~~~
