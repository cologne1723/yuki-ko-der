## 문제

앞에 놓인 접시 하나에 사과가 $N$개 있습니다. 다음 두 연산을 반복해서 접시를 비울 때 필요한 연산 횟수의 최솟값을 구하세요. 두 연산은 어떤 순서로 수행해도 됩니다.

- 음이 아닌 정수 $k$를 골라 접시에서 사과 $2^k$개를 먹습니다. 접시에 사과가 $2^k$개 이상 없으면 이 연산을 할 수 없습니다.
- 음이 아닌 정수 $k$를 골라 접시에 사과 $2^k$개를 추가합니다.

## 입력

~~~text
N
~~~

정수 $N$이 **불필요한 선행 0이 없는 이진수**로 주어집니다. $(1\le N<2^{200\,000})$

## 출력

연산 횟수의 최솟값을 출력하고 마지막에 줄바꿈을 넣으세요.

## 예제

### 입력 1 {file="stdin"}

~~~text
101
~~~

### 출력 1 {file="stdout"}

~~~text
2
~~~

사과가 $5$개 있습니다. 예를 들어 다음과 같이 연산하면 됩니다.

- 사과 $2^2=4$개를 먹습니다.
- 사과 $2^0=1$개를 먹습니다.

### 입력 2 {file="stdin"}

~~~text
111
~~~

### 출력 2 {file="stdout"}

~~~text
2
~~~

사과 $7$개에 $1$개를 추가한 뒤 $8$개를 먹으면 됩니다.

### 입력 3 {file="stdin"}

~~~text
11110101101110110001100
~~~

### 출력 3 {file="stdout"}

~~~text
8
~~~
