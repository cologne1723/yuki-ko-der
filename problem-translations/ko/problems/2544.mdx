순열 $p$와 구간 질의 $Q$개에 대해 구간 최솟값을 구하는 RMQ 문제의 모든 가능한 입력을 생각합니다. 가능한 모든 순열과 질의 조합에 대한 출력값 총합을 $998244353$으로 나눈 나머지를 구하세요.

## 조건

- $1\le N,Q\le10^6$

## 입력

```text
N Q
```

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
2 2
```

#### 출력

```text
48
```

#### 입력

```text

```

#### 출력

```text
6264
```

#### 입력
