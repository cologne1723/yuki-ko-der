다음 조건을 만족하는 비음이 아닌 정수 순서쌍 $(a,b,c,d,e,f)$의 개수를 구하세요.

$$0\le a\le b\le c\le d\le e\le f\le300$$

$$a^3+b^3+c^3+d^3+e^3+f^3=X$$

## 입력

```text
X
```

## 출력

조건을 만족하는 순서쌍의 개수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
444
```

#### 출력

```text
1
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
986
```

#### 출력

```text
2
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
51298165
```

#### 출력

```text
29423
```

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
8042
```

#### 출력

```text
0
```
