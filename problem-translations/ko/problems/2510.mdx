다음 조건을 만족하는 비음이 아닌 정수 순서쌍 $(a,b,c,d,e,f)$의 개수를 구하세요.

$$0\le a\le b\le c\le d\le e\le f\le300$$

$$a^3+b^3+c^3+d^3+e^3+f^3=X$$

## 입력

```text
X
```

## 출력

조건을 만족하는 순서쌍의 개수를 출력하세요.
