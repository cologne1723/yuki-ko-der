## 문제 설명

길이 $N$의 양의 정수 수열 $A$가 주어집니다.

길이 $N$의 정수 수열 $B$에 대해 스코어 $f(B)$를 다음과 같이 정의합니다.

- 다음 연산을 최대 $1$회 수행합니다.
  - 정수 $i$ ($1 \leq i < N$)를 선택하고, $B_i$와 $B_{i+1}$의 값을 교환합니다.
- 적절하게 연산을 수행했을 때 $A_i < B_i$를 만족하는 $i$ ($1 \leq i \leq N$)의 개수의 최댓값을 $f(B)$로 합니다.

모든 원소가 $1$ 이상 $M$ 이하인 길이 $N$의 정수 수열 $B$로 생각할 수 있는 경우는 $M^N$가지입니다. 이 모든 경우에 대해 스코어 $f(B)$를 구하고, 그 총합을 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ M$
$A_1\ A_2\ \cdots\ A_N$
```

## 제한

- $2 \leq N \leq 2 \times 10^5$
- $1 \leq M \leq 10^9$
- $1 \leq A_i \leq M$ ($1 \leq i \leq N$)
- 입력은 모두 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3 4
1 2 3
```

#### 출력

```text
117
```

$B$로 생각할 수 있는 수열은 $4^3 = 64$가지입니다.
$f([1,1,1])=0$, $f([1,2,1])=1$ 등을 계산하면 스코어의 총합이 $117$임을 알 수 있습니다.


#### 출력

```text
871841628
```
