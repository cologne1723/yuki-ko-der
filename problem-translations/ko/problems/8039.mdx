## 문제 설명

$1$ 이상 $3 \times 10^{10}$ 이하의 정수 $x$가 있습니다. $d(n)$을 $n$의 약수 개수라고 할 때, $d(x), d(x+1), d(x+2), d(x+3), \cdots, d(x+99)$의 값은 각각

$24,24,4,16,80,12,32,16,24,12,96,8,32,4,96,2,48,16,4,80,24,16,16,8,48,32,8,2,48,8,16,16,12,4,48,8,60,24,8,8,48,4,8,16,16,4,64,8,12,32,8,2,160,4,96,12,12,4,64,6,8,16,16,24,72,4,8,16,10,16,32,16,12,16,8,4,64,32,16,32,48,8,12,2,192,4,8,8,48,16,4,24,16,8,32,6,24,32,16,4$입니다.

$x$의 값을 구하세요.

## 입력

이 문제에서는 입력이 주어지지 않습니다.

## 제한

- $1 \leq x \leq 3 \times 10^{10}$

## 출력

$x$의 값을 출력하세요.
마지막에 개행을 출력하세요.
