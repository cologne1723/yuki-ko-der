**※ 이 문제는 실행 시간 제한이 매우 엄격하게 설정되어 있습니다.**

## 문제 설명

당신은 로봇 Alice와 특수한 가위바위보를 하고 있습니다.

이 가위바위보에는 `R`, `S`, `P`, `X`의 $4$종류 손이 있습니다. 당신의 손과 Alice의 손에 대한 승패는 다음 표로 정해집니다.

표의 행은 당신의 손, 열은 Alice의 손을 나타냅니다.

| 당신의 손 / Alice의 손 | `R` | `S` | `P` | `X` |
| --- | --- | --- | --- | --- |
| `R` | 무승부 | 승리 | 무승부 | 패배 |
| `S` | 패배 | 무승부 | 승리 | 무승부 |
| `P` | 무승부 | 패배 | 무승부 | 승리 |
| `X` | 승리 | 무승부 | 패배 | 무승부 |

따라서 Alice의 손을 이기려면 다음 손을 내야 합니다.

| Alice의 손 | 이기는 손 |
| --- | --- |
| `R` | `X` |
| `S` | `R` |
| `P` | `S` |
| `X` | `P` |

Alice는 내부에 부호 없는 $32$비트 정수 `state`를 가지고 있습니다.

처음에 `state`는 $1$ 이상 $2^{32}-1$ 이하인 정수 $1$개로 정해집니다. 당신은 이 초기값을 알 수 없습니다.

Alice는 각 가위바위보에서 다음 의사 코드를 $1$회 실행하여 낼 손을 결정합니다.

```text
state ← 1 이상 2^32-1 이하인 정수 중 하나를 선택한다

function generate_random_number():
    state ← state XOR (state << 13)
    state ← state XOR (state >> 17)
    state ← state XOR (state << 5)
    return state

function choose_hand():
    x ← generate_random_number()

    if x mod 4 = 0:
        return 'R'
    else if x mod 4 = 1:
        return 'S'
    else if x mod 4 = 2:
        return 'P'
    else:
        return 'X'

```

여기서 `XOR`는 비트별 배타적 논리합, `<<`는 왼쪽 비트 시프트, `>>`는 오른쪽 비트 시프트를 나타냅니다.

모든 연산은 부호 없는 $32$비트 정수에서 수행됩니다. 연산 결과가 $32$비트를 초과하면 초과한 상위 비트는 버립니다.

당신은 지금까지 Alice와 $100$번 가위바위보를 했고, Alice가 낸 손을 모두 기록했습니다.

이 기록은 길이가 $100$인 문자열 $T$로 나타냅니다. $T$의 $i$번째 문자는 $i$번째 가위바위보에서 Alice가 낸 손을 나타냅니다.

이 기록을 이용하여 앞으로 진행될 $N$번의 가위바위보에서 모두 승리하세요.

구체적으로, 다음 조건을 만족하는 길이 $N$인 문자열 $U$를 출력하세요.

- $U_i$는 당신이 $100+i$번째 가위바위보에서 낼 손을 나타냅니다.
- 모든 $1\leq i\leq N$에 대해 $U_i$는 Alice가 $100+i$번째에 낼 손을 이깁니다.

덧붙여, 이 문제의 제한에서 서로 다른 초기 상태로 같은 문자열 $T$가 생성되지 않는다는 사실을 증명할 수 있습니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$N$
```

## 제한

- $T$는 길이가 $100$인 문자열입니다.
- $T$의 각 문자는 `R`, `S`, `P`, `X` 중 $1$개입니다.
- $T$는 문제 설명의 의사 코드로 생성되었습니다.
- $1\leq N\leq 2\times 10^5$
- $N$은 정수입니다.

## 출력

정답을 $1$행에 출력하세요.

마지막에 줄 바꿈을 출력하세요.
