## 문제 설명

앞면과 뒷면을 구별할 수 있는 타일 $N$개가 있고, 타일에는 $1,2,\ldots,N$의 번호가 붙어 있습니다. 처음에는 모든 타일이 앞면을 향하고 있습니다.

이제 다음 조작을 $M$번 수행합니다.

- $1 \leq L \leq R \leq N$을 만족하는 양의 정수 $L,R$을 선택하고, 타일 $i\ (L \leq i \leq R)$를 모두 뒤집습니다.

$i$번째 조작에서 선택한 $L,R$을 각각 $L_i,R_i$라고 합니다($1 \leq i \leq M$).

조작열 $((L_i,R_i))_{i=1,\ldots,M}$은 $\left(\frac{N(N+1)}{2}\right)^M$개 있습니다. 이 중 조작을 끝낸 뒤 타일의 상태가 $A_1,A_2,\ldots,A_N$이 되는 조작열의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

여기서 $A_i=0$이면 타일 $i$가 앞면을 향하고 있음을, $A_i=1$이면 타일 $i$가 뒷면을 향하고 있음을 나타냅니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N\ M$
$A_1\ A_2\ \cdots\ A_N$
```

## 제한

- $1 \leq N \leq 5\,000$
- $0 \leq M \leq 5\,000$
- $0 \leq A_i \leq 1$
- 입력은 모두 정수입니다.

## 출력

답을 $998\,244\,353$으로 나눈 나머지를 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 2
0 1 1 0
```

#### 출력

```text
6
```

타일의 상태를 (앞면, 뒷면, 뒷면, 앞면)으로 만드는 조작열 $((L_i,R_i))_{i=1,2}$는 다음 $6$개입니다.

- $((1,1),(1,3))$
- $((1,3),(1,1))$
- $((2,2),(3,3))$
- $((2,4),(4,4))$
- $((3,3),(2,2))$
- $((4,4),(2,4))$

```text

```

#### 출력

```text

```

최종적으로 타일이 뒷면을 향하게 되는 조작열은 존재하지 않습니다.
