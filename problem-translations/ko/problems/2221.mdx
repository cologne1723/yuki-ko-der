엄격히 증가하는 수열 $A$에 대해 양의 정수 $X$의 함수 $f(X)=(X+1)\times\left|\{\lfloor A_i/X\rfloor\}\right|$를 정의한다냥. $f(X)$의 최솟값과, 이를 달성하는 가장 작은 $X$를 구하라냥.

## 조건

- $1\le N\le10^5$
- $0\le A_1<\cdots<A_N\le10^9$

## 입력

```text
N
A_1 A_2 \cdots A_N
```

## 출력

가장 작은 최적의 $X$와 그때의 $f(X)$를 출력하라냥.
