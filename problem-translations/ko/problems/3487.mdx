## 문제 설명

영어 소문자 $s$, $e$와 양의 정수 $N$이 주어집니다.

$s$로 시작하고 $e$로 끝나는 $N$개의 영어 소문자로 이루어진 문자열을 $1$개 출력하세요.

그러한 문자열이 존재하지 않으면 $-1$을 출력하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$s\ e\ N$
```

## 제한

- $s$, $e$는 길이가 $1$인 영어 소문자입니다.
- $1\leq N\leq 10$
- $N$은 정수입니다.

## 출력

답이 여러 개라면 그중 $1$개를 출력하세요.

답이 존재하지 않으면 $-1$을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
c t 3
```

#### 출력

```text
cat
```

`cat`은 `c`로 시작하고 `t`로 끝나는 $3$개의 영어 소문자로 이루어진 문자열입니다.

### 예제 2 {file=""}

#### 입력

```text
q g 10
```

#### 출력

```text
qawsedrftg
```

사전에 없는 단어여도 괜찮습니다.

### 예제 3 {file=""}

#### 입력

```text
s h 1
```

#### 출력

```text
-1
```

`s`로 시작하고 `h`로 끝나는 $1$개의 영어 소문자로 이루어진 문자열은 존재하지 않습니다.
