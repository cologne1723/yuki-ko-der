## 문제

스노보드 종목 중 하나로 하프파이프가 있습니다. 하프파이프에서는 심판 6명이 각각 선수의 연기를 100점 만점으로 평가하고, 최저점 1개와 최고점 1개를 제외한 나머지 4명의 평균을 연기의 점수로 합니다. (참고로 이 채점 방식을 사용하지 않는 대회도 있을 수 있습니다. [참고](http://snow.gnavi.co.jp/ilovesnow/category/snowboard_halfpipe.html))

예를 들어 심판 6명의 점수가 `{10, 20, 30, 40, 50, 60}`이라면 최저점 10과 최고점 60을 제외하여 `{20, 30, 40, 50}`의 평균인 35.00을 점수로 얻습니다. 같은 최저점(최고점)이 여러 개여도 최저점(최고점)으로 제외되는 것은 한 사람의 점수뿐입니다.

- `{50,50,60,70,70,70} -> {50,60,70,70}`
- `{51,51,51,51,51,51} -> {51,51,51,51}`

심판 점수에서 점수를 계산하는 것은 [하프파이프 (1)](http://yukicoder.me/problems/818)에서 했으므로, 이번에는 그 반대를 생각해 봅시다.

연기의 점수 X가 주어질 때, 이를 실현하는 심판 점수 조합이 몇 가지인지 계산하세요. 각 심판의 점수는 0점 이상 100점 이하의 정수이며, 심판은 서로 구별됩니다.

## 입력

점수 X가 소수점 이하 둘째 자리까지 주어집니다.

- 0.00 ≤ X ≤ 100.00

답이 0가지가 되는 입력은 주어지지 않습니다. (2016년 7월 15일 23:20 추가)

```text
X
```

## 출력

점수가 X가 되는 심판 점수 조합의 수를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

```text
0.00
```

### 샘플 1 출력 {file="sample1.out"}

```text
601
```

입력은 소수점 이하 둘째 자리까지 정확하게 주어집니다.

`[0, 0, 0, 0, 0, 0]`과 다음 6가지 형태를 합치면 601가지입니다.

- `[S, 0, 0, 0, 0, 0]` (1 ≤ S ≤ 100)
- `[0, S, 0, 0, 0, 0]` (1 ≤ S ≤ 100)
- `[0, 0, S, 0, 0, 0]` (1 ≤ S ≤ 100)
- `[0, 0, 0, S, 0, 0]` (1 ≤ S ≤ 100)
- `[0, 0, 0, 0, S, 0]` (1 ≤ S ≤ 100)
- `[0, 0, 0, 0, 0, S]` (1 ≤ S ≤ 100)

심판은 서로 구별된다는 점에 주의하세요.

### 샘플 2 {file="sample2.in"}


- `[S, 100, 100, 100, 100, 100]` (0 ≤ S ≤ 99)
- ⋮
- `[100, 100, 100, 100, 100, S]` (0 ≤ S ≤ 99)

총 601가지입니다.
