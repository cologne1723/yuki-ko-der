## 이야기

ゆーてぃーさん은 퀴즈 대회에 참가하고 있습니다.

## 문제 설명

퀴즈 대회에서는 $Q$개의 문제가 순서대로 출제됩니다.

각 문제에 순서대로 답하세요. 문제는 다음 $2$가지 중 $1$개입니다.

- 타입 $1$: 정수 $A$, $B$가 주어집니다. $A+B$의 값을 답하세요.
- 타입 $2$: 현재 몇 번째 문제인지 답하세요.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$Q$
$query_1$
$query_2$
$\vdots$
$query_Q$
```

여기서 $query_i$는 $i$번째 문제를 나타내며, 다음 형식 중 $1$개로 주어집니다.

타입 $1$인 경우:

```text
$1\ A\ B$
```

타입 $2$인 경우:

```text
$2$
```

## 제한

- 입력은 모두 정수입니다.
- $1 \leq Q \leq 100$
- 타입 $1$ 문제에 대해 $1 \leq A,B \leq 1\,000$

## 출력

$Q$줄에 걸쳐 출력하세요. $i(1 \leq i \leq Q)$번째 줄에는 $i$번째 문제에 대한 답을 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
1 3 5
1 13 8
2
```

#### 출력

```text
8
21
3
```

$1$번째 문제에서는 $3+5=8$이므로 $8$을 출력합니다.

$3$번째 문제에서는 $3$번째 문제이므로 $3$을 출력합니다.
