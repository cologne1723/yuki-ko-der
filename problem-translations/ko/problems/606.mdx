## 문제

$N$행 $N$열로 배치된 $N^2$개의 타일에 색을 칠합니다. 색은 1번부터 $K$번까지 $K$가지이며, 처음에는 모든 타일이 1번 색입니다. 총 $Q$번 작업을 수행하고, $i$번째 작업에서 $A_i$가 R이면 $B_i$행, C이면 $B_i$열의 모든 타일을 $C_i$번 색으로 다시 칠합니다. 최종적으로 각 색의 타일이 몇 장인지 구하세요.

## 입력

```text
N K Q
A1 B1 C1
...
AQ BQ CQ
```

$A_i$를 제외한 입력은 모두 정수입니다.

- $1 \le N,K,Q \le 10^5$
- $A_i$는 R 또는 C입니다.
- $1 \le B_i \le N$, $1 \le C_i \le K$

## 출력

최종적으로 $i$번 색이 되는 타일 수를 $i$번째 줄에 출력하세요. 마지막 줄을 포함해 각 줄 끝에 개행을 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
3 4 6
C 1 2
C 2 3
R 2 1
C 3 4
R 3 3
C 2 1
```

출력:

```text
4
1
2
2
```

타일은 원문 그림과 같이 칠해집니다.

### 샘플 2 {file="sample2.in"}

입력:

```text
1 5 2
R 1 4
R 1 4
```

출력:

```text
0
0
0
1
0
```

한 번도 사용되지 않는 색이 있을 수도 있습니다.

### 샘플 3 {file="sample3.in"}

입력:

```text
100000 2 1
R 12345 2
```

출력:

```text
9999900000
100000
```

답이 32비트 정수형에 들어가지 않을 수 있음에 유의하세요.
