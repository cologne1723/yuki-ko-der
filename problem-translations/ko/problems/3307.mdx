## 문제 설명

양의 정수 $A$, $B$, $C$, $D$가 주어집니다. 다음 조건을 만족하는 양의 정수 $i$의 개수를 출력하세요.

- $\text{round}\left(i \times \frac{A}{B}\right) = \text{round}\left(i \times \frac{C}{D}\right)$

여기서 $\text{round}(x)$는 $x$를 소수점 이하에서 반올림한 값입니다.

답이 무한히 많다면 $-1$을 출력하세요.

## 입력

입력은 모두 정수입니다. 입력은 다음 형식으로 주어집니다.

```text
$A\ B\ C\ D$
```

## 제한

- $1 \leq A < B \leq 10^9$
- $1 \leq C < D \leq 10^9$

## 출력

결과를 $1$줄에 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 3 1 4
```

#### 출력

```text
7
```

$i \in \{1, 2, 3, 4, 6, 7, 10\}$일 때 $\text{round}\left(\frac{i}{3}\right) = \text{round}\left(\frac{i}{4}\right)$가 됩니다.

#### 출력

```text
-1
```
