## 문제 설명

yuki국과 coder국이라는 $2$개의 나라가 있습니다. $2$개의 나라 모두 $1$년이 $K$일이며, 날짜를 단순히 $1$년 중 며칠째인지를 나타내는 정수 $n$을 사용하여 「$n$일」로 표시하는 달력을 사용합니다. 날짜를 나타낼 때 「월」은 사용하지 않습니다.

다만 yuki국의 달력과 coder국의 달력은 $1$년이 시작되는 시점이 다릅니다.

구체적으로 yuki국의 달력에서 $1$일일 때 coder국의 달력에서는 $M$일입니다. 일반적으로 yuki국의 달력에서 $k$일일 때 coder국의 달력에서는 $((k + M - 2) \bmod{K}) + 1$일입니다.

예를 들어 $K = 7$, $M = 4$일 때는 다음 그림과 같습니다.

![달력](<../images/2845/1.png>)

(위) yuki국의 달력 기준 / (아래) coder국의 달력 기준

이제 다음 조건을 만족하는 $N$명의 생일 조합이 존재하는지 판정하고, 존재한다면 그 $N$명의 **yuki국의 달력에서의** 생일 조합으로 가능한 예를 $1$개 출력하세요.

$i$번째 사람($1 \leq i \leq N$)의 **yuki국의 달력에서의** 생일을 $A_i$일, **coder국의 달력에서의** 생일을 $B_i$일이라고 합니다.

이때 $2N$개의 정수 $A_1, A_2, \dots, A_N, B_1, B_2, \dots, B_N$이 모두 서로 달라야 합니다.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $\mathrm{case}_i$는 $i$번째 테스트 케이스를 나타냅니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$K\ M\ N$
```

## 제한

- 입력은 모두 정수입니다.
- $1 \leq T \leq 2 \times 10^5$
- $1 \leq M \leq K \leq 2 \times 10^5$
- $1 \leq N \leq K$
- $1$개의 입력 파일에서 $K$의 총합은 $4 \times 10^5$를 넘지 않습니다.

## 출력

각 테스트 케이스에 대해 다음과 같이 출력하세요.

조건을 만족하는 $N$명의 생일 조합이 존재하지 않는 경우, `No`를 출력하세요.

조건을 만족하는 $N$명의 생일 조합이 존재하는 경우, 다음 형식으로 $N$명의 yuki국 달력에서의 생일을 출력하세요.

```text
Yes
$A_1\ A_2\ \cdots\ A_N$
```

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
5 2 2
8 1 1
14 8 7
35 6 17
```

#### 출력

```text
Yes
1 4
No
Yes
1 2 3 4 5 6 7
No
```

$1$번째 테스트 케이스에서는 $1$년이 $5$일로 이루어져 있고, yuki국의 달력에서 $1$일일 때 coder국의 달력에서는 $2$일입니다. 따라서 예를 들어 $A_1 = 1$, $A_2 = 4$로 정하면 $B_1 = 2$, $B_2 = 5$가 되어 조건을 만족합니다.
