## 문제

소문자로 이루어진 길이 `N`인 문자열 `S`를 맞혀야 합니다. `S`는 직접 주어지지 않으며, 소문자 문자열 `T`를 질의하면 `S`와 `T`가 같은 위치의 개수를 알 수 있습니다.

질의는 최대 2500회까지 할 수 있습니다. 문자열 `S`를 알아내세요.

## 제약

- `1 ≤ N ≤ 100`

## 상호작용

`? T`를 출력하고 일치 위치 수를 입력받습니다. 알아냈으면 `! S`를 출력하세요.
