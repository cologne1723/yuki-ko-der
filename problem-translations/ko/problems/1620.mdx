## 문제

숫자 1부터 9로 이루어진 문자열 $S$의 모든 비어 있지 않은 부분 문자열에 대해, 십진 정수로 보았을 때의 값을 모두 더한 합을 구하세요. 부분 문자열은 연속하지 않아도 됩니다.

## 입력

문자열 $S$가 주어집니다.

- $1\leq |S|\leq2\times10^5$
- $S$는 1부터 9로만 이루어집니다.

## 출력

답을 출력하세요.
