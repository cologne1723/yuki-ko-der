## 문제

N개의 정점과 M개의 무방향 변으로 이루어진 단순 무방향 그래프가 있고, 각 정점에는 1부터 N까지 번호가 붙어 있습니다.

이 그래프에 정점 1을 포함하는 길이 5의 단순 사이클이 존재하면 `YES`, 그렇지 않으면 `NO`를 출력하세요.

무방향 그래프에 다음을 만족하는 정점 집합 (a,b,c,d,e)가 존재할 때 길이 5의 단순 사이클이 존재한다고 합니다.

- a,b,c,d,e가 서로 다릅니다.
- 정점 a,b가 인접합니다.
- 정점 b,c가 인접합니다.
- 정점 c,d가 인접합니다.
- 정점 d,e가 인접합니다.
- 정점 e,a가 인접합니다.

## 입력

첫째 줄에 정점 수와 변의 수를 나타내는 정수 N, M이 공백으로 주어집니다. 이어지는 M개 줄의 i번째 줄에 정수 Aᵢ, Bᵢ가 주어지며, 정점 Aᵢ와 Bᵢ 사이에 변이 있음을 나타냅니다. 그래프는 단순 그래프이므로 self-loop와 다중 변은 없습니다.

```text
N M
A₁ B₁
⋮
Aₘ Bₘ
```

- 2 ≤ N ≤ 2 × 10^4
- 0 ≤ M ≤ min(N(N − 1) / 2, 5 × 10^4)
- 1 ≤ Aᵢ, Bᵢ ≤ N

## 출력

답을 한 줄에 출력하세요.
