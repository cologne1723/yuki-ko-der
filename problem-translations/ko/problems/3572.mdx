## 문제 설명

이 문제는 [이 문제](https://onlinemathcontest.com/contests/omcb077/tasks/15781)의 일반화입니다.

양의 정수 $N$이 주어집니다. 최고차항의 계수가 $1$인 실수 계수 $N$차 다항식 $f$가 다음 조건을 만족합니다.

- $\alpha$, $\beta$가 $f$의 근이라면 $\alpha\beta$도 $f$의 근입니다.

이때 $f$로 가능한 다항식의 개수를 소수 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

```text
$N$
```

## 제한

- $1 \le N \le 10^{18}$

## 출력

답을 소수 $998\,244\,353$으로 나눈 나머지를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
```

#### 출력

```text
8
```

### 예제 2 {file=""}

#### 입력

```text
6
```

#### 출력

```text
38
```
