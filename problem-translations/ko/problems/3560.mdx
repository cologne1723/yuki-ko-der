## 문제 설명

$N$개의 칸이 원형으로 나열되어 있습니다.
칸에는 시계 방향으로 $1$부터 $N$까지 순서대로 번호가 붙어 있습니다.
칸 $i$와 칸 $i+1$ ($1\leq i\leq N-1$)은 인접해 있고, 칸 $N$과 칸 $1$도 인접해 있습니다.

처음에는 각 칸에 거대 도롱뇽이 $1$마리씩 있습니다.
다음 연산을 원하는 횟수만큼, $0$회도 가능하게 수행할 수 있습니다.

- 인접한 $2$개의 칸 중 $2$개의 칸 모두에 거대 도롱뇽이 적어도 $1$마리 있는 것을 고릅니다.
- $2$개의 칸 중 $1$개의 칸을 골라 그 칸에 있는 거대 도롱뇽을 모두 다른 칸으로 이동시킵니다.

연산을 끝냈을 때 칸 $A_1,A_2,\dots,A_M$에만 거대 도롱뇽이 남아 있고, 칸 $A_i$에 거대 도롱뇽이 $B_i$마리 있는 상태로 만들 수 있다면 `Yes`를, 만들 수 없다면 `No`를 출력하세요.

$T$개의 테스트 케이스가 주어지므로 각각에 대해 답을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\text{case}_1$
$\text{case}_2$
$\vdots$
$\text{case}_T$
```

여기서 $\text{case}_i$는 $i$번째 테스트 케이스의 입력을 의미합니다.

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ M$
$A_1\ B_1$
$A_2\ B_2$
$\vdots$
$A_M\ B_M$
```

## 제한

- $1\leq T\leq 2\times 10^5$
- $3\leq N\leq 10^9$
- $1\leq M\leq\min(N,2\times 10^5)$
- $1\leq A_1<A_2<\dots<A_M\leq N$
- $1\leq B_i$
- $\sum_{1\leq i\leq M}B_i=N$
- 입력은 모두 정수입니다.
- 모든 테스트 케이스에서 $M$의 합은 $2\times 10^5$ 이하입니다.

### 부분점

이 문제에는 부분점이 설정되어 있습니다.

| 부분점 이름 | 배점 | 제한 |
| --- | ---: | --- |
| 부분점 $1$ | $5$% ($12$점) | $M=1$ 또는 $M=N$ |
| 부분점 $2$ | $20$% ($50$점) | $T\leq 10$, $N\leq 7$ |
| 부분점 $3$ | $15$% ($37$점) | 모든 테스트 케이스에서 $N$의 합이 $2\times 10^3$ 이하 |
| 부분점 $4$ | $40$% ($100$점) | 모든 테스트 케이스에서 $N$의 합이 $2\times 10^5$ 이하 |
| 만점 | $20$% ($50$점) | 추가 제한 없음 |

## 출력

$T$줄에 걸쳐 출력하세요.
$i$번째 줄에는 $i$번째 테스트 케이스에서 조건을 만족하는 상태로 만들 수 있다면 `Yes`를, 만들 수 없다면 `No`를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
4 2
1 2
3 2
3 3
1 1
2 1
3 1
6 3
1 1
3 1
5 4
```

#### 출력

```text
Yes
Yes
No
```

$1$번째 테스트 케이스에서는 다음과 같이 연산하면 조건을 만족합니다.

- 칸 $4$와 칸 $1$을 고르고, 칸 $4$의 거대 도롱뇽을 칸 $1$로 이동시킵니다. 이로 인해 칸 $1$에는 거대 도롱뇽이 $2$마리 있는 상태가 됩니다.
- 칸 $2$와 칸 $3$을 고르고, 칸 $2$의 거대 도롱뇽을 칸 $3$으로 이동시킵니다. 이로 인해 칸 $3$에는 거대 도롱뇽이 $2$마리 있는 상태가 됩니다.

$2$번째 테스트 케이스에서는 아무 연산도 하지 않으면 조건을 만족합니다.

$3$번째 테스트 케이스에서는 조건을 만족하도록 연산할 수 없습니다.

이 입력은 부분점 $1$을 제외한 모든 부분점의 제한을 만족합니다.

```text
2

2026 2
2027 1
```

#### 출력

```text

```

이 입력은 만점의 제한을 만족합니다.
