## 주의

이 문제의 테스트 케이스별 실행 시간 제한은 **$3.0$초**이므로 주의하세요.

## 이야기

비버 ビ太郎와 ビバ子는 마카롱이 들어 있는 상자를 샀습니다.

## 문제 설명

상자에는 $N$개의 마카롱이 들어 있습니다. 마카롱에는 $N$종류의 맛이 있으며, $i$번째 마카롱의 맛은 $A_i$입니다. ($1 \le A_i \le N$)

서로 독립적인 질문 $Q$개가 주어집니다. 각 질문에 답하세요. $i$번째 질문은 다음과 같습니다.

- ビ太郎는 맛이 $L_i$ 이상 $R_i$ 이하인 마카롱을 각 맛마다 $1$개씩, ビバ子는 맛이 $L'_i$ 이상 $R'_i$ 이하인 마카롱을 각 맛마다 $1$개씩 먹고 싶어 합니다. 상자에서 마카롱을 서로 중복되지 않게 각각 $R_i - L_i + 1$개, $R'_i - L'_i + 1$개 골라 먹으면서, 각자가 원하는 모든 맛의 마카롱을 먹을 수 있는 방법이 존재하는지 판정하세요.

## 입력

```text
$N$
$A_1\ A_2\ \cdots\ A_N$
$Q$
$L_1\ R_1\ L'_1\ R'_1$
$L_2\ R_2\ L'_2\ R'_2$
$\vdots$
$L_Q\ R_Q\ L'_Q\ R'_Q$
```

## 제한

- $1 \le N, Q \le 5\times 10^5$
- $1 \le L_i \le R_i \le N$
- $1 \le L'_i \le R'_i \le N$
- 입력은 모두 정수입니다.

### 부분점

이 문제에는 서브태스크에 따른 부분점이 설정되어 있습니다.

| 서브태스크 | 배점 | 제한 |
| --- | --- | --- |
| 소과제 $1$ | $10$% ($20$점) | $N \le 100, Q \le 100$이며, 각 질문에 대해 $L_i=R_i,L'_i=R'_i$ |
| 소과제 $2$ | $30$% ($60$점) | $N \le 100, Q \le 100$ |
| 소과제 $3$ | $60$% ($120$점) | 추가 제한이 없습니다. |

## 출력

$Q$줄을 출력하세요. $i$번째 줄에는 $i$번째 질문에서 조건을 만족하는 방법이 존재하면 `Yes`를, 그렇지 않으면 `No`를 출력하세요.

답 이외에는 아무것도 출력하지 마세요. 입력을 요청하는 문장 등도 출력하지 마세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
6
1 3 2 2 1 4
3
2 4 1 2
1 4 2 3
1 5 1 1
```

#### 출력

```text
Yes
No
No
```

$1$번째 질문에서는 ビ太郎가 $2, 3, 6$번째 마카롱을, ビバ子가 $1, 4$번째 마카롱을 먹으면 됩니다.

$2$번째 질문에서는 맛 $3$인 마카롱이 $1$개밖에 없으므로 조건을 만족할 수 없습니다.

$3$번째 질문에서는 맛 $5$인 마카롱이 없으므로 조건을 만족할 수 없습니다.

이 입력 예시는 소과제 $2,4$의 제한을 만족합니다.


### 예제 2 {file=""}

#### 입력

```text
1
1
1
1 1 1 1
```

#### 출력

```text
No
```

이 입력 예시는 모든 소과제의 제한을 만족합니다.
