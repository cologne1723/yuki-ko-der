## 문제 설명

음이 아닌 정수 $x,y$에 대해 $f(x,y)$를 다음과 같이 정의된 음이 아닌 정수라고 합니다.

- $f(x,y)$를 이진 표기로 나타냈을 때 $2^i$($i\geq 0$)의 자리의 값은 다음과 같습니다.
  - $i$가 짝수라면 $x$의 $2^i$의 자리의 값과 $y$의 $2^i$의 자리의 논리곱(AND)을 취한 값입니다.
  - $i$가 홀수라면 $x$의 $2^i$의 자리의 값과 $y$의 $2^i$의 자리의 논리합(OR)을 취한 값입니다.

예를 들어 $f(2,14)=10$입니다. (이진 표기로 나타내면 $f(0010_{(2)},1110_{(2)})=1010_{(2)}$입니다.)

또한 양의 정수 $n$에 대해 $g(n)$을 다음과 같이 정의합니다.

- $0\leq x,y<n$을 만족하는 모든 정수쌍 $(x,y)$에 대해 $f(x,y)$의 값을 생각합니다. 이 $n^2$개 값의 최빈값 중 최솟값을 $g(n)$으로 정의합니다.

양의 정수 $N$이 주어집니다. $\displaystyle\sum_{n=1}^N g(n)$을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
```

## 제한

- $1\leq N\leq 10^9$
- 입력은 모두 정수입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4
```

#### 출력

```text
4
```

$0\leq x,y\leq N-1$을 만족하는 모든 정수쌍 $(x,y)$에 대한 $f(x,y)$의 값은 다음과 같습니다.

- $f(0,0)=0$, $f(0,1)=0$, $f(0,2)=2$, $f(0,3)=2$
- $f(1,0)=0$, $f(1,1)=1$, $f(1,2)=2$, $f(1,3)=3$
- $f(2,0)=2$, $f(2,1)=2$, $f(2,2)=2$, $f(2,3)=2$
- $f(3,0)=2$, $f(3,1)=3$, $f(3,2)=2$, $f(3,3)=3$

- $g(1)$에서 $[f(0,0)]=[0]$의 최빈값은 $0$이므로 $g(1)=0$입니다.
- $g(2)$에서 $[f(0,0),f(0,1),f(1,0),f(1,1)]=[0,0,0,1]$의 최빈값은 $0$이므로 $g(2)=0$입니다.
- $g(3)$에서 $[0,0,2,0,1,2,2,2,2]$의 최빈값은 $2$이므로 $g(3)=2$입니다.
- $g(4)$에서 $[0,0,2,2,0,1,2,3,2,2,2,2,2,3,2,3]$의 최빈값은 $2$이므로 $g(4)=2$입니다.

따라서 구하는 값은 $g(1)+g(2)+g(3)+g(4)=4$입니다.
