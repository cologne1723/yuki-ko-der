## 문제

yuki국은 무한한 좌표평면이며 모든 격자점에 도시가 하나씩 있습니다. 각 도시에 다음 워프 패널이 있습니다.

- 패널 1: $(x,y)$에서 $(x+a,y+b)$로 이동
- 패널 2: $(x,y)$에서 $(x-a,y-b)$로 이동
- 패널 3: $(x,y)$에서 $(x+c,y+d)$로 이동
- 패널 4: $(x,y)$에서 $(x-c,y-d)$로 이동

국민 $i$는 $(x_i,y_i)$에 삽니다. 유한 번(0번도 가능) 패널을 사용해 국민 $i$의 도시에서 국민 $j$의 도시로 이동할 수 있을 때, 그리고 그때만 두 국민을 같은 그룹으로 묶습니다. 각 그룹은 한 명 이상이어야 합니다. 그룹 수를 구하세요.

## 입력

~~~text
$a\ b\ c\ d$
$N$
$x_1\ y_1$
$\vdots$
$x_N\ y_N$
~~~

$0\leq a,b,c,d\leq10^9$, 두 이동 벡터는 0이 아니고 서로 다릅니다. $1\leq N\leq10^5$, $0\leq x_i,y_i\leq10^9$입니다.

## 출력

국민이 나뉘는 그룹 수를 출력하세요.

## 샘플

### 샘플 1 {file="sample1.in"}

#### 입력

~~~text
1 2 2 2
4
1 2
3 3
1 0
3 1
~~~

#### 출력

~~~text
2
~~~

국민 1과 3은 같은 그룹이고, 국민 4와 2도 같은 그룹이지만 두 그룹 사이에는 이동할 수 없습니다.

### 샘플 2 {file="sample2.in"}

#### 입력

~~~text
0 1 1 0
2
314159265 358979323
314159265 358979323
~~~

#### 출력

~~~text
1
~~~

같은 도시에 여러 국민이 살 수도 있습니다.

### 샘플 3 {file="sample3.in"}

#### 입력

~~~text
2 0 3 0
5
1 0
2 3
5 4
4 3
1 2
~~~

#### 출력

~~~text
4
~~~
