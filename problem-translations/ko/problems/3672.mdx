## 문제 설명

$xyz$ 공간에서 $(X_A,Y_A,Z_A)$를 중심으로 하고 반지름이 $R_A$인 구 $A$와, $(X_B,Y_B,Z_B)$를 중심으로 하고 반지름이 $R_B$인 구 $B$가 주어집니다.

$A$와 $B$의 공통 부분의 부피를 구하세요.

$T$개의 테스트 케이스에 대해 답하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\text{case}_1$
$\text{case}_2$
$\vdots$
$\text{case}_T$
```

$\text{case}_i$는 $i$번째 테스트 케이스를 나타내며, 다음 형식으로 주어집니다.

```text
$X_A\ Y_A\ Z_A\ R_A$
$X_B\ Y_B\ Z_B\ R_B$
```

## 제한

- $1\leq T\leq 100\,000$
- $|X_A|,|Y_A|,|Z_A|,|X_B|,|Y_B|,|Z_B|\leq 1\,000\,000$
- $1\leq R_A,R_B\leq 1\,000\,000$
- 입력은 모두 정수입니다.

## 출력

각 테스트 케이스에 대해 답을 $1$줄에 출력하세요.

저지 프로그램이 준비한 답과의 상대 오차 또는 절대 오차가 $10^{-6}$ 이하이면 정답으로 판정합니다.

저지 프로그램이 준비한 답은 실제 값과의 절대 오차 또는 상대 오차가 $10^{-15}$ 이하임이 보장됩니다.

마지막에 줄 바꿈을 출력하세요.
