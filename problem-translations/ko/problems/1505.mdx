## 문제

0 또는 1로 이루어진 길이 $N$의 수열 $A$가 주어집니다. 구간 곱
\[
\prod_{i=l}^{r}A_i
\]
이 0이 되는 $(l,r)$의 개수를 구하세요.

## 입력

```text
$N$
$A_1$ $\ldots$ $A_N$
```

- $1\leq N\leq2\times10^5$
- $A_i$는 0 또는 1입니다.

## 출력

답을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
1 0 1
```

#### 출력

```text
4
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
5
1 1 1 1 1
```

#### 출력

```text
0
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
10
1 1 0 1 1 1 0 0 1 1
```

#### 출력

```text
43
```
