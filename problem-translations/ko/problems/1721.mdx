정수의 십진 표기에 `4`와 `6`이 모두 포함되어 있으면 아름다운 정수라고 합니다. `N`이 아름다운 정수인지 판정하세요.

## 제약

- `1 <= N <= 10^9`

## 입력

`N`이 주어집니다.

## 출력

아름다운 정수이면 `Beautiful`, 아니면 지정된 부정 답을 출력하세요.
