높이 4, 너비 `4N`인 격자와 T자 테트로미노 `4N`개가 있습니다. 테트로미노를 회전시킬 수 있을 때 격자 전체를 빈틈없이 타일링하는 배치의 개수를 `998244353`으로 나눈 나머지를 구하세요.

테트로미노는 서로 구별하지 않으며, 격자를 뒤집거나 회전해 일치하는 배치는 서로 다른 것으로 셉니다.

## 제약

- `1 <= T <= 100`
- `1 <= N <= 100`

## 입력

테스트 케이스 수 `T`와 각 테스트 케이스의 `N`이 주어집니다.

## 출력

각 테스트 케이스의 답을 출력하세요.
