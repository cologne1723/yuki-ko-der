(출제자 공지) [No.1066번 문제](https://yukicoder.me/problems/no/1066)와 이 문제는 같은 문제이지만, 제한과 실행 시간 제한, 메모리 제한이 다릅니다. (21:30 추가)

## 문제 설명

상자가 $N$개 있습니다. $i$번째 상자($1 \le i \le N$)에는 구슬이 $A_i$개 들어 있습니다.

더 구체적으로, $i$번째 상자에는 색 $1$부터 색 $A_i$까지 모든 색의 구슬이 하나씩 들어 있습니다.

이때 $Q$개의 질의에 답하세요. $i$번째 질의($1 \le i \le Q$)는 다음과 같습니다.

- 각 상자에서 구슬을 하나씩 꺼냈을 때, 색 $1$의 구슬이 $B_i$개 포함되는 경우의 수를 $998244353$으로 나눈 나머지를 출력하세요.

## 입력

```text
N Q
A_1 A_2 ... A_N
B_1 B_2 ... B_Q
```

## 제한

$1 \le N \le 2\times 10^5$

$1 \le Q \le \min(N+1,5\,000)$

$1 \le A_i \le 10^{18}$ ($1 \le i \le N$)

$0 \le B_i \le N$ ($1 \le i \le Q$)

입력은 모두 정수입니다.

## 출력

$Q$개의 질의에 답하고, 마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file=""}


#### 출력

```text

26

1
```

구슬을 꺼내는 방법은 모두 $60$가지입니다. 그중 색 $1$의 구슬이 하나도 포함되지 않는 방법은 $24$가지입니다.
