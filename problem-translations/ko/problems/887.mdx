## 문제

아카네와 아오이는 같은 슬라이드 퍼즐을 갖고 싶어 합니다. 정수 $N$과 $N$차 정사각행렬 $A$가 주어집니다. $N$차 정사각행렬 $X$는 처음에 $X_{i,j}=(i-1)N+(j-1)$입니다.

$X_{i,j}=0$인 칸과 그 상하좌우 인접 칸을 골라 두 값을 교환하는 것을 슬라이드 연산이라고 합니다. 두 칸이 인접하다는 것은 맨해튼 거리가 1이라는 뜻입니다.

행렬 $M$의 재미를 $\sum_{i=1}^{N}\sum_{j=1}^{N}(A_{i,j}\times M_{i,j})$로 정의합니다.

다음 조건을 만족하는 행렬 쌍 $(P,Q)$가 존재하는지 판정하고, 존재하면 하나를 출력하세요: $P\ne Q$, $X$에서 슬라이드 연산으로 각각 $P,Q$를 만들 수 있고, $P$와 $Q$의 재미가 같습니다.

## 제약

- $2\leq N\leq500$
- $1\leq A_{i,j}\leq10^8$

## 입력

~~~text
N
A_{1,1} A_{1,2} ... A_{1,N}
⋮
A_{N,1} A_{N,2} ... A_{N,N}
~~~

## 출력

불가능하면 `No`, 가능하면 `Yes`와 $P$의 $N$개 행, $Q$의 $N$개 행을 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

~~~text
2
1 2
3 4
~~~

### 출력 1 {file="stdout"}

~~~text
Yes
0 2
3 1
0 3
1 2
~~~
