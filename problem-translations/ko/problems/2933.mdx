## 문제 설명

영소문자로 이루어진 문자열 $S$와 $T$가 주어집니다.

$Q$개의 질의를 순서대로 처리하세요. 각 질의는 다음 $3$개 형식 중 정확히 $1$개에 해당합니다.

- $1\ l\ r\ x$: $S[l:r]$의 각 문자에 $\mathrm{ROT}\ x$를 적용합니다.
- $2\ l\ r\ x$: $T[l:r]$의 각 문자에 $\mathrm{ROT}\ x$를 적용합니다.
- $3\ p$: $S[p:|S|]$가 $T[p:|T|]$보다 사전순으로 크면 `Greater`, 같으면 `Equals`, 작으면 `Lesser`를 출력합니다.

문자열 $X$와 정수 $l,r$이 $1 \le l \le r \le |X|$를 만족할 때, $X[l:r]$은 $X$의 $l$번째 문자부터 $r$번째 문자까지의 부분 문자열을 의미합니다.

문자 $\alpha$에 $\mathrm{ROT}\ x$를 적용하는 것은 $\alpha$를 알파벳 순서에서 $x$개 뒤의 영소문자로 바꾸는 것을 의미합니다.
단, 알파벳 순서에서 `z`의 $1$개 뒤 영소문자는 `a`입니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$S$
$T$
$Q$
$\mathrm{query}_1$
$\mathrm{query}_2$
$\vdots$
$\mathrm{query}_Q$
```

여기서 $\mathrm{query}_k$는 $k$번째 질의이며, 다음 $3$개 형식 중 정확히 $1$개로 주어집니다.

```text
$1\ l\ r\ x$
```

```text
$2\ l\ r\ x$
```

```text
$3\ p$
```

## 제한

- $1 \le Q \le 2 \times 10^5$
- $S$와 $T$는 영소문자로 이루어진 길이 $1$ 이상 $2 \times 10^5$ 이하의 문자열입니다.
- $1\ l\ r\ x$ 형식의 질의에 대해 $1 \le l \le r \le |S|$입니다.
- $2\ l\ r\ x$ 형식의 질의에 대해 $1 \le l \le r \le |T|$입니다.
- $0 \le x \le 25$
- $1 \le p \le \min\{|S|,|T|\}$
- $Q,l,r,x,p$는 정수입니다.

## 출력

$3\ p$ 형식의 질의 개수를 $q$개라고 할 때, $q$줄에 걸쳐 출력하세요. $k$번째 줄에는 $k$번째 $3\ p$ 형식의 질의에 대한 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
green
brown
8
3 1
1 3 5 13
3 2
2 1 5 5
1 2 4 10
2 5 5 8
3 4
3 1
```

#### 출력

```text
Greater
Greater
Equals
Lesser
```

처음에는 $S=$ `green`, $T=$ `brown`입니다. 각 질의에 대해 다음과 같습니다.

- $1$번째 질의에서 $S[1:5]=$ `green`, $T[1:5]=$ `brown`입니다. 사전순으로 $S[1:5]$가 $T[1:5]$보다 큽니다.
- $2$번째 질의에서 $S[3:5]$의 각 문자에 $\mathrm{ROT}\ 13$을 적용합니다. $S=$ `grrra`로 바뀝니다.
- $3$번째 질의에서 $S[2:5]=$ `rrra`, $T[2:5]=$ `rown`입니다. 사전순으로 $S[2:5]$가 $T[2:5]$보다 큽니다.
- $4$번째 질의에서 $T[1:5]$의 각 문자에 $\mathrm{ROT}\ 5$를 적용합니다. $T=$ `gwtbs`로 바뀝니다.
- $5$번째 질의에서 $S[2:4]$의 각 문자에 $\mathrm{ROT}\ 10$을 적용합니다. $S=$ `gbbba`로 바뀝니다.
- $6$번째 질의에서 $T[5:5]$의 각 문자에 $\mathrm{ROT}\ 8$을 적용합니다. $T=$ `gwtba`로 바뀝니다.
- $7$번째 질의에서 $S[4:5]=$ `ba`, $T[4:5]=$ `ba`입니다. 사전순으로 $S[4:5]$와 $T[4:5]$가 같습니다.
- $8$번째 질의에서 $S[1:5]=$ `gbbba`, $T[1:5]=$ `gwtba`입니다. 사전순으로 $S[1:5]$가 $T[1:5]$보다 작습니다.
