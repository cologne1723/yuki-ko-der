## 문제 설명

막대 $N$개가 가로로 $1$줄로 나열되어 있습니다. 막대에는 왼쪽부터 막대 $1,2,\dots,N$이라는 번호가 붙어 있으며, 번호가 $i$인 막대를 막대 $i$라고 합니다.

양의 정수 $N$과 `L`, `R`, `U`, `.`로 이루어진 길이 $N$의 문자열 $S$가 주어집니다. 각 막대를 왼쪽으로 넘어뜨린 상태, 오른쪽으로 넘어뜨린 상태 또는 넘어뜨리지 않은 상태로 만들 수 있습니다.

막대 $N$개의 상태가 다음 조건을 모두 만족하면 **올바른** 상태라고 합니다. 이하에서 $i$는 $1 \le i \le N$을 만족하는 정수입니다.

- 오른쪽으로 넘어져 있는 막대의 바로 오른쪽 막대가 왼쪽으로 넘어져 있는 경우가 없어야 합니다. 더 엄밀하게는, 막대 $k$가 오른쪽으로 넘어져 있고 막대 $k+1$이 왼쪽으로 넘어져 있도록 하는 $1 \le k \le N-1$인 정수 $k$가 존재해서는 안 됩니다.
- $S$의 $i$번째 문자가 `L`인 모든 $i$에 대해 막대 $i$가 왼쪽으로 넘어져 있어야 합니다.
- $S$의 $i$번째 문자가 `R`인 모든 $i$에 대해 막대 $i$가 오른쪽으로 넘어져 있어야 합니다.
- $S$의 $i$번째 문자가 `U`인 모든 $i$에 대해 막대 $i$가 넘어져 있지 않아야 합니다.
- $S$의 $i$번째 문자가 `.`인 모든 $i$에 대해 막대 $i$는 왼쪽으로 넘어져 있거나, 오른쪽으로 넘어져 있거나, 넘어져 있지 않아야 합니다.

막대 $N$개의 상태를 정하는 방법 중 **올바른** 방법의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

막대 $i$의 상태가 서로 다른 $i$가 존재할 때, 그리고 그때에만 방법을 서로 다르게 셉니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$N$
$S$
```

$1$번째 줄에 정수 $N$이 주어집니다. $2$번째 줄에 `L`, `R`, `U`, `.`로 이루어진 길이 $N$의 문자열 $S$가 주어집니다.

## 제한

- $1 \le N \le 2 \times 10^5$
- $S$는 `L`, `R`, `U`, `.`로 이루어진 길이 $N$의 문자열입니다.

## 출력

답을 출력하고, 마지막에 개행 문자를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
..L
```

#### 출력

```text
5
```

막대의 상태를 문자열로 나타내는 방법을 다음과 같이 정의합니다. 길이 $N$의 문자열이며 다음 조건을 모두 만족하는 문자열을 해당 상태의 표현으로 정합니다. 이 방법으로는 어떤 막대 상태의 문자열 표현이 유일하게 정해집니다.

- 막대 $i$가 왼쪽으로 넘어져 있으면 $i$번째 문자는 `L`입니다.
- 막대 $i$가 오른쪽으로 넘어져 있으면 $i$번째 문자는 `R`입니다.
- 막대 $i$가 넘어져 있지 않으면 $i$번째 문자는 `U`입니다.

예제 $1$에서 조건을 모두 만족하는 **올바른** 막대 상태의 표현은 `LLL`, `LUL`, `ULL`, `UUL`, `RUL`의 $5$가지입니다.

![예제 1의 막대 상태 그림](../images/2926/1.png)

또한 다음 그림과 같은 막대 상태는 조건을 만족하지 않습니다.

![조건을 만족하지 않는 막대 상태 그림](../images/2926/2.png)

`URL`은 $1$번째 조건을 위반합니다(막대 $2$가 오른쪽으로 넘어져 있고 막대 $3$이 왼쪽으로 넘어져 있습니다).

`LUU`는 $2$번째 조건을 위반합니다(막대 $3$이 넘어져 있지 않습니다).

`RLR`은 $1$번째 조건을 위반합니다(막대 $1$이 오른쪽으로 넘어져 있고 막대 $2$가 왼쪽으로 넘어져 있습니다). 또한 $2$번째 조건도 위반합니다(막대 $3$이 오른쪽으로 넘어져 있습니다).


### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
6
..L..R
```

#### 출력

```text
40
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
8
.RL..U..
```

#### 출력

```text
0
```

막대 $2$를 오른쪽으로, 막대 $3$을 왼쪽으로 넘어뜨려야 하므로 $1$번째 조건을 반드시 위반합니다.

### 예제 4 {file="01_sample_04.txt"}

#### 입력

```text
30
.....R.....U...R..L.........L.
```

#### 출력

```text
144875014
```

**올바른** 막대 상태의 개수를 $998\,244\,353$으로 나눈 나머지를 출력하세요.
