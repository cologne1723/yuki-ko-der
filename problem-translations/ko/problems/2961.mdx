## 이야기

색이 다른 몬스터에 한창 빠져 있습니다. 도와주세요.

한 바퀴 도는 데 $20$분 정도 걸립니다...

## 문제 설명

대인기 몬스터 게임이 출시되었습니다. 이 게임에서는 드물게 색이 다른 몬스터라고 불리는 희귀한 몬스터가 출현합니다.

이 게임에서는 $R$초 주기의 카운터를 사용합니다. 게임을 실행한 시점의 카운터 값은 $0$이고, 실행한 직후부터 $1$초마다 $1$씩 증가합니다. 카운터 값이 $R-1$인 상태에서 다음 $1$초가 지나면 카운터 값은 $0$이 됩니다.

또한 색이 다른 몬스터는 카운터가 $A_i$ $(1 \leq i \leq N)$일 때 반드시 출현하고, 그 이외에는 출현하지 않는다는 사실이 알려져 있습니다.

이제 $Q$개의 질의가 주어집니다. $i$번째 $(1 \leq i \leq Q)$ 질의에서는 $l_i,r_i$가 주어집니다. 다음 질문에 답하세요.

- 게임을 실행한 뒤 $l_i$초 후부터 $r_i$초 후까지의 사이에 색이 다른 몬스터를 잡을 기회의 수를 구하세요. 여기서 구해야 하는 기회의 수는 $l_i \leq t \leq r_i$를 만족하고, "게임을 실행한 뒤 $t$초 후에 색이 다른 몬스터가 출현한다."가 참이 되는 정수 $t$의 개수입니다.

## 입력

```text
$R\ N$
$A_1\ \cdots\ A_N$
$Q$
$l_1\ r_1$
$\vdots$
$l_Q\ r_Q$
```

첫째 줄에 $R$과 $N$이 주어집니다.

둘째 줄에 $A_1,\ldots,A_N$이 주어집니다.

셋째 줄에 질의의 개수 $Q$가 주어집니다.

이후 $Q$개의 줄에 걸쳐 $i$번째 줄에 $i$번째 질의를 나타내는 $l_i$와 $r_i$가 주어집니다.

## 제한

- $2 \leq R \leq 10^6$
- $1 \leq N \leq \min(R,10^5)$
- $0 \leq A_i < R$ $(1 \leq i \leq N)$
- $A_i$는 모두 다릅니다.
- $1 \leq Q \leq 2\,000$
- $1 \leq l_i < r_i \leq 10^9$ $(1 \leq i \leq Q)$
- 입력은 모두 정수입니다.

## 출력

$Q$줄을 출력하세요. $i$번째 $(1 \leq i \leq Q)$ 줄에는 $i$번째 질의의 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5 2
1 3
3
1 4
13 20
89 90
```

#### 출력

```text
2
3
0
```

두 번째 질의에서는 $13$초 후에 카운터가 $3$이 되어 색이 다른 몬스터가 출현합니다. $16$초 후에는 카운터가 $1$이고, $18$초 후에는 카운터가 $3$이므로, 기회는 모두 $3$번입니다.

또한 게임을 실행한 뒤 $l_i$초 후와 $r_i$초 후에 색이 다른 몬스터가 출현하는 경우도 포함하므로 주의하세요.
