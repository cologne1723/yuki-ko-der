이 문제의 제한 시간은 **$4\,000$ms**입니다.

## 문제 설명

입력으로 양의 정수 $L_i, M_i$ $(i = 1, \dots, K)$가 주어집니다. 단, $L_1 < L_2 < \dots < L_K$입니다.

$(L, M)$형 영 도형이란, $i = 1, \dots, K$에 대해 아래에서부터 변의 길이가 $1$인 정사각형을 가로로 $L_i$개 나열한 것을 $M_i$단 쌓아서 만든 도형입니다. 예를 들어 $K = 2$, $(L_1, M_1) = (2, 2)$, $(L_2, M_2) = (3, 1)$이면 다음과 같은 도형이 됩니다.

$\Box\ \Box\ \Box \\
\Box\ \Box \\
\Box\ \Box$

이 영 도형의 정사각형 개수를 $N$이라고 하고, $1$부터 $N$까지의 수를 각 정사각형에 $1$개씩 순서대로 할당한다고 합시다. 각 단에서 숫자가 왼쪽에서 오른쪽으로 갈수록 커지고, 같은 가로 너비를 가진 각 단의 **최좌측**에 할당된 숫자가 아래에서 위로 갈수록 커질 때 이를 “좋은 배치”라고 합니다.

예를 들어 앞의 영 도형에 대해 다음은 좋은 배치입니다.

$2\ \ 4\ \ 5 \\
3\ \ 6 \\
1\ \ 7$

입력으로 주어진 $L_i, M_i$로 만들어지는 영 도형에 대한 좋은 배치의 개수를 $998\,244\,353$으로 나눈 나머지를 구하세요.

## 입력

```text
$K$
$L_1\ M_1$
$\vdots$
$L_K\ M_K$
```

$K$는 영 도형을 구성하는 종류의 수입니다.

$i+1$번째 줄에는 $i$번째 종류의 가로 길이 $L_i$와 단 수 $M_i$가 공백으로 구분되어 주어집니다.

## 제한

- $1 \le K \le 1\,000$
- $1 \le L_1 < L_2 < \dots < L_K$
- $1 \le M_i$ $(i = 1, \dots, K)$
- $L_1M_1 + L_2M_2 + \dots + L_KM_K \le 10^8$

## 출력

입력으로 주어진 $L_i, M_i$로 만들어지는 영 도형에 대한 좋은 배치의 개수를 $998\,244\,353$으로 나눈 나머지를 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
1
2 2
```

#### 출력

```text
3
```

영 도형은

$\Box\ \Box \\
\Box\ \Box$

이며, 좋은 배치는 다음 $3$가지입니다.

$3\ \ 4 \\
1\ \ 2$

$2\ \ 4 \\
1\ \ 3$

$2\ \ 3 \\
1\ \ 4$
