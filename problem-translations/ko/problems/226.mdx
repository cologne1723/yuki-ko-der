## 문제

세로 $H$, 가로 $W$인 격자가 있고, 각 칸에는 `0`, `1`, `?` 중 하나가 쓰여 있습니다.

`?`가 쓰인 모든 칸에 대해 `?`를 지우고 `0` 또는 `1`을 써서 다음 조건을 만족시키려고 합니다. 가능한 방법의 수를 $1\,000\,000\,007$로 나눈 나머지를 구하세요.

모든 $2 \times 2$ 정사각형에는 `0`이 정확히 2개, `1`이 정확히 2개 포함되어야 합니다. 더 정확히, 위에서 $i$번째이자 왼쪽에서 $j$번째 칸의 값을 $v(i,j)$라고 할 때, 모든 $1 \leq i \leq H-1$, $1 \leq j \leq W-1$에 대해 $v(i,j)$, $v(i,j+1)$, $v(i+1,j)$, $v(i+1,j+1)$ 중 `0`이 정확히 2개이고 `1`이 정확히 2개여야 합니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
H W
S_1
S_2
⋮
S_H
```

첫째 줄에 $H$, $W$가 공백으로 구분되어 주어집니다. 다음 $H$개 줄에는 $i$번째 행의 상태를 나타내는 길이 $W$의 문자열 $S_i$가 주어집니다.

- $2 \leq H \leq 100$
- $2 \leq W \leq 100$
- $S_i$는 `0`, `1`, `?`만으로 이루어진 문자열입니다.

## 출력

가능한 방법의 수를 $1\,000\,000\,007$로 나눈 나머지를 출력하세요. 출력 끝에는 개행을 넣으세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 4
?11?
???0
```

#### 출력

```text
2
```

가능한 방법은 다음 2가지입니다.

| 첫 번째 방법 | 두 번째 방법 |
| --- | --- |
| `0111` | `1111` |
| `1000` | `0000` |

### 예제 2 {file=""}

#### 입력

```text
3 3
1??
??0
???
```

#### 출력

```text
3
```

가능한 방법은 다음 3가지입니다.

| 첫 번째 방법 | 두 번째 방법 | 세 번째 방법 |
| --- | --- | --- |
| `101` | `101` | `111` |
| `010` | `010` | `000` |
| `101` | `010` | `111` |
