## 문제 설명

`C`, `P`, `T`로 이루어진 문자열 $S$가 주어집니다. 다음 $2$가지 조건을 모두 만족하도록 $S$의 문자를 재배열하여 출력하세요.

- $S$의 어떤 `T`도 어떤 `C`보다 왼쪽에 나타납니다.
- $S$의 어떤 `C`도 어떤 `P`보다 왼쪽에 나타납니다.

## 입력

```text
$S$
```

문자열 $S$가 주어집니다.

## 제한

- $S$는 `C`, `P`, `T`로 이루어진 길이 $1$ 이상 $100$ 이하의 문자열입니다.

## 출력

문제 설명의 조건을 만족하도록 $S$의 문자를 재배열하여 출력하세요. **단, 조건을 만족하는 재배열이 여러 개라면 그중 사전순으로 가장 작은 것을 출력하세요.**

조건을 만족하는 재배열이 $1$개 이상 존재한다는 것을 증명할 수 있습니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
PCT
```

#### 출력

```text
TCP
```

조건을 만족하는 `PCT`의 재배열은 `TCP` $1$개뿐입니다.

### 예제 2 {file=""}

#### 입력

```text
CCTTPPCPCT
```

#### 출력

```text
TTTCCCCPPP
```

조건을 만족하는 `CCTTPPCPCT`의 재배열은 `TTTCCCCPPP` $1$개뿐입니다.

### 예제 3 {file=""}

#### 입력

```text
PCPCPCCPCC
```

#### 출력

```text
CCCCCCPPPP
```

조건을 만족하는 `PCPCPCCPCC`의 재배열은 `CCCCCCPPPP` $1$개뿐입니다.
