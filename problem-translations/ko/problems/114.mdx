## 이야기

SRM 10000이 열렸던 것도 이제는 옛날 이야기입니다. 여기서는 당시 DIV2 Easy 문제를 소개합니다.

## 문제 설명

문제를 간단히 말하면, 비용이 있는 무방향 그래프가 주어집니다. 그래프의 일부 정점은 “중요한” 정점이며, 모든 중요한 정점을 연결하는 부분 트리 중 트리 간선 비용 합이 최소인 것의 비용 합을 출력하는 문제입니다.

## 입력

```text
$N\ M\ T$
$a_1\ b_1\ c_1$
$a_2\ b_2\ c_2$
$\vdots$
$a_M\ b_M\ c_M$
$v_1$
$v_2$
$\vdots$
$v_T$
```

$N$은 정점 수, $M$은 간선 수, $T$는 중요한 정점 수입니다.
이어지는 $M$개 줄에 주어지는 $3$개의 정수 $a_i,b_i,c_i$는 $a_i$번 정점과 $b_i$번 정점을 비용 $c_i$인 간선이 연결한다는 뜻입니다. $(1 \le i \le M)$
마지막 $T$개 줄에는 중요한 정점의 번호 $v_1,\dots,v_T$가 주어집니다. 이 번호들은 모두 서로 다릅니다.

입력 그래프는 연결되어 있으며 다중 간선과 자기 루프를 포함하지 않습니다.

## 제한

- $1 \le N \le 35$
- $N-1 \le M \le N(N-1)/2$
- $1 \le T \le N$
- $1 \le a_i,b_i \le N$ $(1 \le i \le M)$
- $1 \le v_i \le N$ $(1 \le i \le T)$
- $1 \le c_i \le 100$ $(1 \le i \le M)$

## 출력

```text
$answer$
```

답을 $1$줄에 출력하세요. 마지막에 줄바꿈 문자를 출력하세요.

이 문제는 출제 당시 라이브러리를 붙여 넣기만 하면 되었던 문제입니다. [Steiner Tree 라이브러리](http://www.prefield.com/algorithm/dp/steiner_tree.html)를 참고하세요.
