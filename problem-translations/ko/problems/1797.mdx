`H x W` 패턴을 반복해 무한 격자를 칠하고, 정확히 `K`색을 사용하는 방법의 수를 구하세요. 오른쪽 또는 아래로 양의 횟수만큼 평행 이동한 패턴은 같은 것으로 보고, 회전과 뒤집기는 구분합니다.

## 제약

- `1 <= H*W <= 10`
- `1 <= K <= 3`

## 입력

`H W K`가 주어집니다.

## 출력

가능한 패턴 수를 출력하세요.
