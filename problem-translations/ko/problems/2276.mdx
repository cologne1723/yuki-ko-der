문자 `A`, `C`, `?`로 이루어진 길이 $N$인 문자열 $S$가 주어집니다. `?`를 각각 `A` 또는 `C`로 바꿉니다.

변경 후 문자열에서 부분 수열로 `AC`를 뽑는 방법의 수가 점수입니다. 뽑는 위치가 다르면 다른 방법으로 셉니다.

점수의 최댓값을 구하세요.

## 조건

- $2\le N\le 2\times10^5$
- $S$는 `A`, `C`, `?`로 이루어집니다.

## 입력

```text
N
S
```

## 출력

점수의 최댓값을 출력하세요.
