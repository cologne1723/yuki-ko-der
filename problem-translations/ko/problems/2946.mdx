## 문제 설명

영문 대문자와 `.`으로 이루어진 $H$행 $W$열의 격자 $G$가 주어집니다.

연결 성분의 크기가 $4$ 이상인 모든 연결 성분에 대해, 그 연결 성분에 속하는 모든 칸을 동시에 `.`으로 바꾼 격자를 출력하세요.

$2$개의 칸 $c_1$, $c_2$가 연결되어 있다는 것은, $c_1$에서 $c_2$로 상하좌우로 인접하면서 같은 문자가 쓰인 칸으로 이동하는 것을 반복해서 이동할 수 있다는 뜻입니다.

칸의 집합 $S$가 연결 성분이라는 것은 $S$가 다음 조건을 모두 만족한다는 뜻입니다.

- $S$의 어떤 $2$개의 칸도 서로 연결되어 있습니다.
- $S$에 포함되지 않는 어떤 칸도 $S$에 포함되는 칸과 연결되어 있지 않습니다.

## 입력

입력은 다음 형식으로 주어집니다.

```text
$H\ W$
$G_{1,1}\ G_{1,2}\ \cdots\ G_{1,W}$
$G_{2,1}\ G_{2,2}\ \cdots\ G_{2,W}$
$\vdots$
$G_{H,1}\ G_{H,2}\ \cdots\ G_{H,W}$
```

$1$번째 줄에 격자의 행 수를 나타내는 정수 $H$와 열 수를 나타내는 정수 $W$가 주어집니다.

이후 $H$개의 줄에 격자 $G$가 주어집니다. $i$번째 줄에는 공백 없이 이어진 $W$개의 문자로 $G$의 $i$번째 행이 주어지며, 각 문자는 영문 대문자 또는 `.`입니다.

## 제한

- $1 \leq H \leq 1\,000$
- $1 \leq W \leq 1\,000$
- $G_{i,j}$는 영문 대문자 또는 `.`입니다. $(1 \leq i \leq H, 1 \leq j \leq W)$

## 출력

바꾼 결과인 $H$행 $W$열의 격자를 출력하세요.

마지막에 개행을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4 4
AAAA
ABCB
ADDA
AEEE
```

#### 출력

```text
....
.BCB
.DDA
.EEE
```

같은 문자라도 연결되지 않은 부분은 바꾸지 않는 것에 주의하세요.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 1
.
```

#### 출력

```text
.
```

입력에 `.`이 포함될 수 있음에 주의하세요.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
3 3
ABB
A.B
AAB
```

#### 출력

```text
...
...
...
```

전부 지워집니다.
