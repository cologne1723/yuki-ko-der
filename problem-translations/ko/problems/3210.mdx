## 문제 설명

양의 정수 $N$과 `+`, `0`, `-`로 이루어진 길이 $N$의 문자열 $S$가 주어집니다.

길이 $N$의 정수 수열 $A$가 다음 조건을 모든 $i$($1\leq i\leq N$)에 대해 만족하면 행복한 수열이라고 합니다.

- $S$의 $i$번째 문자가 `+`이면 $A_i>0$입니다.
- $S$의 $i$번째 문자가 `0`이면 $A_i=0$입니다.
- $S$의 $i$번째 문자가 `-`이면 $A_i<0$입니다.

길이 $N$의 행복한 수열 중 최장 증가 부분수열의 길이로 가능한 최댓값을 구하세요.

수열 $X$의 최장 증가 부분수열이란 $X$의 엄격하게 단조 증가하는 부분수열 중 길이가 가장 긴 것을 말합니다. 부분수열의 원소들은 연속하지 않아도 됩니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$N$
$S$
```

## 제한

- $1\leq N\leq 3\times 10^5$
- $N$은 정수입니다.
- $S$는 `+`, `0`, `-`로 이루어진 길이 $N$의 문자열입니다.

## 출력

길이 $N$의 행복한 수열 중 최장 증가 부분수열의 길이로 가능한 최댓값을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
-+-+0
```

#### 출력

```text
3
```

행복한 수열 $A$를 $(-1,1,-2,2,0)$으로 정하면 $A$의 최장 증가 부분수열은 $(-1,1,2)$가 됩니다.

최장 증가 부분수열의 길이가 $4$ 이상인 행복한 수열은 존재하지 않으므로 답은 $3$입니다.

### 예제 2 {file=""}

#### 입력

```text
3
+0-
```

#### 출력

```text
1
```

어떤 행복한 수열을 선택해도 최장 증가 부분수열의 길이는 $2$ 이상이 될 수 없습니다.

### 예제 3 {file=""}

#### 입력

```text
12
+-+-00+-+-00
```

#### 출력

```text
5
```
