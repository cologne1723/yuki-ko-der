## 문제 설명

岩井星人さん이 자신이 주최하는 경쟁 프로그래밍 대회에 참가하고 싶은 사람을 모집했더니 $N$명이 지원했습니다. $i$번째 지원자의 레이팅은 $R_i$입니다.

대회는 팀전이며, 岩井星人さん은 이제 다음과 같이 팀을 나눕니다.

- 임의로 몇 명의 지원자에게 트집을 잡아 대회에 참가하지 못하게 합니다.
- 트집을 잡지 않은 각 지원자를 빨간 팀과 파란 팀 중 $1$곳에 소속시킵니다.

이때 각 팀에는 $1$명 이상이 소속되어야 하며, **빨간 팀에 소속된 사람 수와 파란 팀에 소속된 사람 수가 같아야 합니다**.

각 팀 나누기에서 각 팀의 **실력**은 그 팀에 소속된 사람들의 레이팅 합으로 정의합니다.

岩井星人さん은 대회를 흥미롭게 만들기 위해 빨간 팀과 파란 팀의 실력을 최대한 비슷하게 만들고 싶어 합니다. 岩井星人さん이 최적으로 팀을 나눌 때, 빨간 팀의 실력과 파란 팀의 실력 차의 절댓값이 최소 얼마인지 구하세요.

## 입력

```text
$N$
$R_1\ R_2\ \cdots\ R_N$
```

$1$번째 줄에 지원자 수를 나타내는 정수 $N$이 주어집니다.

$2$번째 줄에 $N$명의 지원자의 레이팅 $R_1, R_2, \ldots, R_N$이 공백으로 구분되어 주어집니다.

입력은 모두 정수입니다.

## 제한

- $2 \leq N \leq 40$
- $0 \leq R_i \leq 8 \times 10^5$ ($1 \leq i \leq N$)

## 출력

빨간 팀과 파란 팀의 실력 차의 절댓값이 최소 얼마인지 정수로 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file="00_sample_01.txt"}

#### 입력

```text
4
1050 1100 1300 1370
```

#### 출력

```text
20
```

$1$번째와 $4$번째 지원자를 빨간 팀에 소속시키고, $2$번째와 $3$번째 지원자를 파란 팀에 소속시키면 빨간 팀의 실력은 $1\,050 + 1\,370 = 2\,420$, 파란 팀의 실력은 $1\,100 + 1\,300 = 2\,400$이므로 빨간 팀과 파란 팀의 실력 차의 절댓값은 $|2\,420 - 2\,400| = 20$입니다. 빨간 팀과 파란 팀의 실력 차의 절댓값을 이보다 작게 만드는 팀 나누기는 존재하지 않습니다.

### 예제 2 {file="00_sample_02.txt"}

#### 입력

```text
6
0 1 2 4 8 16
```

#### 출력

```text
1
```

$1$번째와 $2$번째 지원자를 제외한 지원자들에게 트집을 잡아 참가시키지 않고, $1$번째 지원자를 빨간 팀에, $2$번째 지원자를 파란 팀에 소속시키면 빨간 팀과 파란 팀의 실력 차의 절댓값은 $|0 - 1| = 1$입니다. 빨간 팀과 파란 팀의 실력 차의 절댓값을 이보다 작게 만드는 팀 나누기는 존재하지 않습니다.

### 예제 3 {file="00_sample_03.txt"}

#### 입력

```text
5
1694 491 835 1875 1343
```

#### 출력

```text
7
```
