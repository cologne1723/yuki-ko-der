## 문제 설명

음이 아닌 정수 $n$, $i$에 대해 $n_i$를 $n$을 $10$진법으로 나타냈을 때 $10^i$의 자리 숫자로 정의합니다.

> **정의 1 (단조)**
>
> 양의 정수 $n$이 단조(monotonic)라는 것은 $i<j$이면 $n_i\ge n_j$인 것으로 정의합니다. 특히, $1$자리 양의 정수는 단조입니다.
>
> 예를 들어 $123$, $2\,233\,355\,555$, $1$은 단조이지만 $321$, $998\,244\,353$은 단조가 아닙니다.

> **정의 2 (영구 단조)**
>
> 양의 정수 $n$이 영구 단조(forever-monotonic)라는 것은 임의의 음이 아닌 정수 $k$에 대해 다음 조건이 성립하는 것으로 정의합니다.
>
> - $n$을 ‘$n$을 $10$진법으로 나타냈을 때 각 자리 숫자의 합’으로 바꾸는 연산을 $k$번 반복합니다. 연산 후의 $n$은 단조입니다.

음이 아닌 정수 $N$이 주어집니다. $10^N$ 이상인 영구 단조 정수 중 최솟값을 구하세요.

단, 답이 매우 커질 수 있으므로 답을 $998\,244\,353$으로 나눈 나머지를 출력하세요.

$T$개의 테스트 케이스가 주어지므로 각각에 대해 답하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $\mathrm{case}_i$ $(i=1,2,\cdots,T)$는 $i$번째 테스트 케이스입니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
```

## 제한

- $1\le T\le10^5$
- $0\le N\le10^{14}$
- $T$, $N$은 정수입니다.

## 출력

$T$줄에 걸쳐 출력하세요. $i$번째 줄에는 $i$번째 테스트 케이스의 답을 $998\,244\,353$으로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
6
0
2
9
1024
123456789
99999999999999
```

#### 출력

```text
1
111
112866759
614307571
646823187
411251028
```

$1$번째 테스트 케이스에서 $10^0=1$ 이상인 영구 단조 정수 중 최솟값은 $1$입니다.

$3$번째 테스트 케이스에서 $10^9$ 이상인 영구 단조 정수 중 최솟값은 $1\,111\,111\,112$입니다.
$1\,111\,111\,112$의 각 자리 숫자의 합은 $11$이고, $11$의 각 자리 숫자의 합은 $2$입니다. 이 수들은 모두 단조이므로, 이를 통해 영구 단조임도 알 수 있습니다.

답을 $998\,244\,353$으로 나눈 나머지를 출력해야 한다는 점에 주의하세요.
