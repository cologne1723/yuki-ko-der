## 문제 설명

좌표평면 위에서 처음에 **룩** 또는 **비숍** 중 $1$개를 원점 $(0,0)$에 놓습니다.

각 기물은 다음과 같이 이동할 수 있습니다.

- **룩**: 현재 위치 $(x,y)$에서 임의의 실수 $k$를 선택하여 $(x+k,y)$ 또는 $(x,y+k)$로 $1$번에 이동할 수 있습니다.
- **비숍**: 현재 위치 $(x,y)$에서 임의의 실수 $k$를 선택하여 $(x+k,y+k)$ 또는 $(x-k,y+k)$로 $1$번에 이동할 수 있습니다.

적절한 기물을 선택했을 때, 처음 놓은 기물을 목표 위치 $(G_x,G_y)$로 이동하는 데 필요한 최소 이동 횟수를 구하세요.

## 입력

```text
$G_x\ G_y$
```

## 제한

- $-10^9\leq G_x\leq 10^9$
- $-10^9\leq G_y\leq 10^9$
- 입력은 모두 정수입니다.

## 출력

적절한 기물을 선택했을 때, 놓은 기물을 목표 위치 $(G_x,G_y)$로 이동하는 데 필요한 최소 이동 횟수를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
1 1
```

#### 출력

```text
1
```

### 예제 2 {file=""}

#### 입력

```text
2 3
```

#### 출력

```text
2
```
