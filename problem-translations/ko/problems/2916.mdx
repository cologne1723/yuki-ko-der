**이 문제의 실행 시간 제한은 $3.5$초입니다.**

## 문제 설명

입력의 처음에 $2$ 이상인 정수 $N$과 $2$개의 양의 정수 $M$, $C$가 주어집니다.

어떤 나라에 $N$개의 섬과 섬들을 연결하는 $M$개의 다리가 있습니다. 이 나라에서 이동할 때는 다리를 건너는 방법만 사용할 수 있으며, $2$개의 섬을 연결하는 다리는 최대 $1$개입니다.

섬에는 $N$ 이하의 각 양의 정수 $i$가 번호로 붙어 있으며 섬 $i$라고 부릅니다. 다리에는 $M$ 이하의 각 양의 정수 $m$이 번호로 붙어 있으며 다리 $m$이라고 부릅니다.

$M$ 이하의 각 양의 정수 $m$에 대해 다음이 성립합니다.

- 다리 $m$은 섬 $i_m$과 섬 $j_m$을 연결합니다. $i_m$과 $j_m$은 $1 \leq i_m < j_m \leq N$을 만족하는 정수입니다.
- 다리 $m$을 건널 때, 당시 소지금이 $c$인 사람은 통행료 $\left\lfloor \frac{c}{r_m} \right\rfloor + w_m$를 내야 합니다. $r_m$과 $w_m$은 $c$에 의존하지 않는 양의 정수입니다. 또한 소지금보다 많은 통행료를 낼 수는 없습니다.

$C$ 이하의 각 양의 정수 $c$에 대해, 소지금이 $c$이고 섬 $1$에 있는 사람이 섬 $N$으로 이동할 수 있는지 판정하세요. 이동할 수 있다면 섬 $N$으로 이동한 후의 소지금 최댓값을 구하세요.

## 입력

입력은 표준 입력에서 $1+M$개의 줄로 주어집니다.

- $1$번째 줄에 $N$, $M$, $C$가 공백으로 구분되어 주어집니다.
- $M$ 이하의 각 양의 정수 $m$에 대해 $1+m$번째 줄에 $i_m$, $j_m$, $r_m$, $w_m$이 공백으로 구분되어 주어집니다.

입력 형식은 다음과 같습니다.

```text
$N\ M\ C$
$i_1\ j_1\ r_1\ w_1$
$\vdots$
$i_M\ j_M\ r_M\ w_M$
```

## 제한

입력은 다음 조건을 만족합니다.

- $N$은 $2 \leq N \leq 10$을 만족하는 정수입니다.
- $M$은 $1 \leq M \leq \frac{N(N-1)}{2}$를 만족하는 정수입니다.
- $C$는 $1 \leq C \leq 10^5$를 만족하는 정수입니다.
- $M$ 이하의 임의의 양의 정수 $m$에 대해 다음이 성립합니다.
  - $i_m$과 $j_m$은 $1 \leq i_m < j_m \leq N$을 만족하는 정수입니다.
  - $r_m$은 $1 \leq r_m \leq C$를 만족하는 정수입니다.
  - $w_m$은 $1 \leq w_m \leq C$를 만족하는 정수입니다.
- $M$ 이하의 임의의 양의 정수 $m_0,m_1$에 대해, $m_0 \neq m_1$이면 $(i_{m_0},j_{m_0}) \neq (i_{m_1},j_{m_1})$입니다.

## 출력

$C$ 이하의 각 양의 정수 $c$에 대해, 소지금이 $c$이고 섬 $1$에 있는 사람이 섬 $N$으로 이동할 수 있다면 섬 $N$으로 이동한 후의 소지금 최댓값을, 이동할 수 없다면 $-1$을 $c$번째 줄에 출력하세요.

마지막에 줄바꿈을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2 1 1
1 2 1 1
```

#### 출력

```text
-1
```

처음 소지금을 $c$라고 하겠습니다. $1 \leq c \leq C = 1$이므로 $c=1$입니다.

섬 $1$에서 섬 $N=2$로 이동하려면 섬 $1$과 섬 $2$를 연결하는 다리 $1$을 건너야 합니다. 다리 $1$을 건너려면 통행료 $\left\lfloor \frac{c}{1} \right\rfloor + 1=2$를 내야 하는데, 이는 $c$보다 크므로 낼 수 없습니다.

### 예제 2 {file=""}

#### 입력

```text
2 1 3
1 2 2 1
```

#### 출력

```text
0
0
1
```

처음 소지금을 $c$라고 하겠습니다. $1 \leq c \leq C = 3$입니다.

섬 $1$에서 섬 $N=2$로 이동하려면 섬 $1$과 섬 $2$를 연결하는 다리 $1$을 건너면 됩니다. 다리 $1$을 건너려면 통행료 $\left\lfloor \frac{c}{2} \right\rfloor + 1$을 내야 합니다.

$c=1$일 때 $\left\lfloor \frac{c}{2} \right\rfloor + 1=1$이므로 다리 $1$을 건널 수 있고, 섬 $2$로 이동한 시점의 소지금은 $c-1=0$입니다. 이보다 많은 소지금을 가지고 섬 $2$로 이동할 수는 없습니다.

$c=2$일 때 $\left\lfloor \frac{c}{2} \right\rfloor + 1=2$이므로 다리 $1$을 건널 수 있고, 섬 $2$로 이동한 시점의 소지금은 $c-2=0$입니다. 이보다 많은 소지금을 가지고 섬 $2$로 이동할 수는 없습니다.

$c=3$일 때 $\left\lfloor \frac{c}{2} \right\rfloor + 1=2$이므로 다리 $1$을 건널 수 있고, 섬 $2$로 이동한 시점의 소지금은 $c-2=1$입니다. 이보다 많은 소지금을 가지고 섬 $2$로 이동할 수는 없습니다.

### 예제 3 {file=""}

#### 입력

```text
4 4 5
1 2 3 2
1 3 2 1
2 4 3 1
3 4 2 1
```

#### 출력

```text
-1
-1
0
0
1
```

처음 소지금을 $c$라고 하겠습니다. $1 \leq c \leq C = 5$입니다.

섬 $1$에서 섬 $N=4$로 이동하려면 섬 $1$과 섬 $2$를 연결하는 다리 $1$을 건넌 다음 섬 $2$와 섬 $4$를 연결하는 다리 $3$을 건너거나, 섬 $1$과 섬 $3$을 연결하는 다리 $2$를 건넌 다음 섬 $3$과 섬 $4$를 연결하는 다리 $4$를 건너면 됩니다. 전자의 경로에서는 다리 $1$을 건너기 위해 통행료 $\left\lfloor \frac{c}{3} \right\rfloor + 2$를 내야 하고, 남은 금액을 $c'$이라고 하면 다리 $3$을 건너기 위해 통행료 $\left\lfloor \frac{c'}{3} \right\rfloor + 1$을 추가로 내야 합니다. 후자의 경로에서는 다리 $2$를 건너기 위해 통행료 $\left\lfloor \frac{c}{2} \right\rfloor + 1$을 내야 하고, 남은 금액을 $c'$이라고 하면 다리 $4$를 건너기 위해 통행료 $\left\lfloor \frac{c'}{2} \right\rfloor + 1$을 추가로 내야 합니다.

$c=1$일 때, 전자의 경로에서는 $\left\lfloor \frac{c}{3} \right\rfloor + 2=2>c$이므로 다리 $1$을 건널 수 없습니다. 후자의 경로에서는 $\left\lfloor \frac{c}{2} \right\rfloor + 1=1=c$이므로 다리 $2$를 건널 수 있지만, 섬 $3$으로 이동한 시점의 소지금이 $c'=c-1=0$이 되고 $\left\lfloor \frac{c'}{2} \right\rfloor + 1=1>c'$이므로 다리 $4$를 건널 수 없습니다. 어느 경로로도 섬 $4$로 이동할 수 없습니다.

$c=2$일 때, 전자의 경로에서는 $\left\lfloor \frac{c}{3} \right\rfloor + 2=2=c$이므로 다리 $1$을 건널 수 있지만, 섬 $2$로 이동한 시점의 소지금이 $c'=c-2=0$이 되어 $\left\lfloor \frac{c'}{3} \right\rfloor + 1=1>c'$이므로 다리 $3$을 건널 수 없습니다. 후자의 경로에서는 $\left\lfloor \frac{c}{2} \right\rfloor + 1=2=c$이므로 다리 $2$를 건널 수 있지만, 섬 $3$으로 이동한 시점의 소지금이 $c'=c-2=0$이 되어 $\left\lfloor \frac{c'}{2} \right\rfloor + 1=1>c'$이므로 다리 $4$를 건널 수 없습니다. 어느 경로로도 섬 $4$로 이동할 수 없습니다.

$c=3$일 때, 전자의 경로에서는 $\left\lfloor \frac{c}{3} \right\rfloor + 2=3$이므로 다리 $1$을 건널 수 있지만, 섬 $2$로 이동한 시점의 소지금이 $c'=c-3=0$이 되어 $\left\lfloor \frac{c'}{3} \right\rfloor + 1=1>c'$이므로 다리 $3$을 건널 수 없습니다. 후자의 경로에서는 $\left\lfloor \frac{c}{2} \right\rfloor + 1=2<c$이므로 다리 $2$를 건널 수 있고, 섬 $3$으로 이동한 시점의 소지금이 $c'=c-2=1$이 됩니다. $\left\lfloor \frac{c'}{2} \right\rfloor + 1=1=c'$이므로 다리 $4$를 건널 수 있고, 섬 $4$로 이동한 시점의 소지금은 $c'-1=0$입니다. 이보다 많은 소지금을 가지고 섬 $4$로 이동할 수는 없습니다.

$c=4$일 때, 전자의 경로에서는 $\left\lfloor \frac{c}{3} \right\rfloor + 2=3<c$이므로 다리 $1$을 건널 수 있고, 섬 $2$로 이동한 시점의 소지금이 $c'=c-3=1$이 됩니다. $\left\lfloor \frac{c'}{3} \right\rfloor + 1=1=c'$이므로 다리 $3$을 건널 수 있고, 섬 $4$로 이동한 시점의 소지금은 $c'-1=0$입니다. 후자의 경로에서는 $\left\lfloor \frac{c}{2} \right\rfloor + 1=3<c$이므로 다리 $2$를 건널 수 있고, 섬 $3$으로 이동한 시점의 소지금이 $c'=c-3=1$이 됩니다. $\left\lfloor \frac{c'}{2} \right\rfloor + 1=1=c'$이므로 다리 $4$를 건널 수 있고, 섬 $4$로 이동한 시점의 소지금은 $c'-1=0$입니다. 따라서 전자의 경로와 후자의 경로에서 남는 금액은 같습니다. 이보다 많은 소지금을 가지고 섬 $4$로 이동할 수는 없습니다.

$c=5$일 때, 전자의 경로에서는 $\left\lfloor \frac{c}{3} \right\rfloor + 2=3<c$이므로 다리 $1$을 건널 수 있고, 섬 $2$로 이동한 시점의 소지금이 $c'=c-3=2$가 됩니다. $\left\lfloor \frac{c'}{3} \right\rfloor + 1=1<c'$이므로 다리 $3$을 건널 수 있고, 섬 $4$로 이동한 시점의 소지금은 $c'-1=1$입니다. 후자의 경로에서는 $\left\lfloor \frac{c}{2} \right\rfloor + 1=3<c$이므로 다리 $2$를 건널 수 있고, 섬 $3$으로 이동한 시점의 소지금이 $c'=c-3=2$가 됩니다. $\left\lfloor \frac{c'}{2} \right\rfloor + 1=2=c'$이므로 다리 $4$를 건널 수 있고, 섬 $4$로 이동한 시점의 소지금은 $c'-2=0$입니다. 따라서 전자의 경로가 더 많은 금액을 남깁니다. 이보다 많은 소지금을 가지고 섬 $4$로 이동할 수는 없습니다.
