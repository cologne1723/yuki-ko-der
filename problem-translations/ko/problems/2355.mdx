평면 위에 $N$명의 댄서가 있고, 각 댄서는 자유롭게 방향을 정할 수 있습니다. 자신의 바로 뒤 방향으로 뻗은 반직선 위에 다른 댄서가 두 명 이상 있으면 그 댄서는 불행합니다.

불행한 댄서 수의 최댓값을 구하세요.

## 조건

- $1\le N\le1500$
- $0\le X_i,Y_i\le10^{18}$
- 위치는 서로 다릅니다.

## 입력

첫째 줄에 $N$, 다음 $N$개 줄에 $X_i,Y_i$가 주어집니다.

## 출력

불행한 댄서 수의 최댓값을 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
4
1 1
2 2
3 3
1 3
```

#### 출력

```text
2
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
5
1 1
1 3
2 4
3 3
3 1
```

#### 출력

```text
0
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
9
1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
3 3
```

#### 출력

```text
8
```
