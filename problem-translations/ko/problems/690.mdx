## 문제

다음 조건을 만족하는 그래프를 하나 출력하세요.

- 정점 $N$, 변 $M$개의 유향 그래프이며 변 $i$는 $d1_i$에서 $d2_i$로 향합니다.
- $d1_i\lt d2_i$여야 합니다.
- 정점 1에서 정점 $N$으로 가는 경로 수가 정확히 $K$입니다.
- $1\le N\le32$이고, 두 변이 같은 시작점과 끝점을 동시에 가질 수 없습니다.

## 입력

```text
K
```

$0\le K\le10^9$

## 출력

첫째 줄에 $N,M$, 이후 $M$줄에 각 변을 출력하세요. 여러 정답이 가능한 스페셜 저지입니다.

```text
N M
d1_1 d2_1
...
d1_M d2_M
```

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
2
```

출력:

```text
3 3
1 2
1 3
2 3
```

1→3과 1→2→3의 두 경로가 있습니다.
