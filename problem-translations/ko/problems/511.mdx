## 문제

A와 B는 다음 낙하 게임을 손으로 진행했습니다. 이 게임에서는 가로 너비가 w이고 높이가 무한한 모눈종이를 사용합니다.

A가 선공이며, 차례는 번갈아 돌아옵니다.

1. i번째 차례의 플레이어에게 1×1 블록을 가로 ai개, 세로 bi개 모은 ai×bi 블록이 주어집니다. 이를 원하는 위치에 놓습니다.
2. 각 1×1 블록을 아래가 블록이거나 최하단이 될 때까지 아래로 이동시킵니다.
3. 블록 높이가 새로 득점선 h 이상이 된 열의 수를 셉니다. 그 열의 수만큼 블록을 놓은 플레이어가 점수를 얻습니다.
4. 모든 블록의 높이가 득점선 이상이면 게임을 끝냅니다. 그렇지 않으면 차례를 바꾸고 1로 돌아갑니다.
5. 게임이 끝났을 때 점수가 높은 쪽이 승리합니다.

하지만 게임을 손으로 진행하던 A와 B는 혼란에 빠져 게임이 끝난 것을 알아차리지 못했고, 게임을 계속했습니다. 물론 누가 이겼는지도 알 수 없습니다.

다행히 “i번째 차례의 플레이어가 ai×bi 블록을 xi에 놓았다”라는 로그가 남아 있습니다. 블록을 놓을 때는 왼쪽 끝을 xi에 맞춥니다.

A와 B의 게임 진행 순서 ai, bi, xi (1 ≤ i ≤ n)가 주어집니다. 게임 결과를 알려 주세요.

## 입력

```text
n w h
a1 b1 x1
…
an bn xn
```

1 ≤ n ≤ 100000

1 ≤ h ≤ 10^15

1 ≤ w ≤ 100000

1 ≤ ai ≤ w

1 ≤ bi ≤ 10^9

1 ≤ xi ≤ w − ai + 1

입력되는 수는 모두 자연수입니다.

입력된 순서를 수행한 뒤에는 반드시 게임이 끝난다는 것이 보장됩니다.

## 출력

A가 이기면 A, B가 이기면 B, 비기면 DRAW를 출력하세요.

출력 마지막에는 줄바꿈이 필요합니다.
