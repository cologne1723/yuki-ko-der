## 문제 설명

$N$명의 학생이 있는 반이 있습니다. 학생은 $S_0$君부터 $S_{N-1}$君까지 있습니다. 각 학생에게 $0$부터 $N-1$까지의 출석 번호를 $1$개씩 배정하려고 합니다. 각 학생에게 싫어하는 숫자가 $1$개씩 있을 때, 어떤 학생에게도 싫어하는 숫자가 배정되지 않는 배정 방법의 수를 $10^9+7$로 나눈 나머지로 구하세요.

## 입력

```text
$N$
$A_0$
$A_1$
$\vdots$
$A_{N-1}$
```

$1$번째 줄에 학생 수 $N$이 주어집니다. 다음 $N$개 줄에 학생 $S_i$君이 싫어하는 숫자 $A_i$가 주어집니다.

## 제한

- $1 \leq N \leq 5\,000$
- $0 \leq A_i \leq 4\,999$

## 출력

조건을 만족하는 출석 번호 배정 방법의 수를 $10^9+7$로 나눈 나머지를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
3
0
1
2
```

#### 출력

```text
2
```

`1 2 0`과 `2 0 1`의 $2$가지 배정 방법이 있습니다.

### 예제 2 {file=""}

#### 입력

```text
4
3
3
3
3
```

#### 출력

```text
0
```

### 예제 3 {file=""}

#### 입력

```text
5
1
1
1
0
1
```

#### 출력

```text
24
```
