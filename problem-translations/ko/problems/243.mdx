## 문제

$N$명의 학생이 있는 반이 있습니다. 학생은 $S_0$부터 $S_{N-1}$까지 있습니다. 각 학생에게 0부터 $N-1$까지의 출석 번호를 하나씩 배정하려고 합니다. 각 학생에게 싫어하는 숫자가 하나씩 있을 때, 어떤 학생에게도 싫어하는 숫자가 배정되지 않는 배정 방법의 수를 $10^9+7$로 나눈 나머지로 구하세요.

## 입력

```text
N
A_0
A_1
⋮
A_{N-1}
```

첫째 줄에 학생 수 $N$이 주어집니다. 다음 $N$개 줄에 학생 $S_i$가 싫어하는 숫자 $A_i$가 주어집니다.

- $1 \leq N \leq 5000$
- $0 \leq A_i \leq 4999$

## 출력

조건을 만족하는 출석 번호 배정 방법의 수를 $10^9+7$로 나눈 나머지를 출력하세요.

## 샘플

### 입력 1 {file="stdin"}

```text
3
0
1
2
```

### 출력 1 {file="stdout"}

```text
2
```

`1 2 0`과 `2 0 1`의 2가지 배정 방법이 있습니다.

### 입력 2 {file="stdin"}

```text
4
3
3
3
3
```

### 출력 2 {file="stdout"}

```text
0
```

### 입력 3 {file="stdin"}

```text
5
1
1
1
0
1
```

### 출력 3 {file="stdout"}

```text
24
```
