$H$행 $W$열 격자의 각 칸에 0 이상 77 이하의 정수를 하나씩 쓰려고 합니다. 모든 칸에 대해, 그 칸의 숫자와 상하좌우로 인접한 칸 중 같은 숫자가 쓰인 칸의 개수가 서로 같아야 합니다.

## 문제

조건을 만족하는 숫자 배치가 존재하는지 판정하고, 존재하면 한 가지 예를 출력하세요.

## 입력

```text
T
H W
```

$1\le T\le100$, $1\le H,W\le100$입니다.

## 출력

배치가 없으면 `-1`을 출력하세요. 가능하면 조건을 만족하는 격자를 출력하세요.
