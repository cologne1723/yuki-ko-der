## 문제 설명

소수를 싫어하는 혼다는 적은 수의 소인수로 이루어진 수(서로 다른 소인수의 개수가 적은 수)를 별로 사용하고 싶지 않습니다.

그래서 $2$부터 $N$까지의 수 중 소인수를 $K$개 이상 가지는 수만 사용하기로 했습니다. 하지만 사용할 수 있는 수가 너무 적은 것은 싫어서, 미리 몇 개를 사용할 수 있는지 알아보기로 했습니다.

$N$과 $K$가 주어질 때 사용할 수 있는 수의 개수를 출력하세요.

## 입력

```text
N K
```

모든 입력은 정수입니다.

- $2 \le N \le 2\,000\,000$
- $1 \le K \le 100$

## 출력

$2$ 이상 $N$ 이하인 수 중 서로 다른 소인수의 개수가 $K$개 이상인 수의 개수를 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

```text
2 1
```

```text
1
```

```text
4 2
```

```text
0
```

$2,3,4$ 중 소인수를 2개 이상 가지는 수가 없으므로 답은 $0$입니다.

```text
1000 4
```

```text
23
```
