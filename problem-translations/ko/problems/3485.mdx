## 문제 설명

$495 = 3^2 \times 5 \times 11$과 같이, $a < b < c$를 만족하는 홀수 소수 $a$, $b$, $c$를 사용하여 $n = a^2bc$로 나타낼 수 있는 정수를 495와 비슷한 수라고 합니다.

양의 정수 $L$, $R$($L \leq R$)이 주어집니다. $L \leq x \leq R$를 만족하는 정수 $x$ 중 495와 비슷한 수인 것이 존재하는지 판정하고, 존재한다면 그중 $1$개를 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$L\ R$
```

## 제한

- 입력은 모두 정수입니다.
- $1 \leq L \leq R \leq 4.95 \times 10^{14}$

## 출력

$L \leq x \leq R$를 만족하는 495와 비슷한 수 $x$가 존재한다면 그중 $1$개를, 존재하지 않는다면 $-1$을 출력하세요. 조건을 만족하는 $x$가 여러 개라면 그중 어느 것을 출력해도 정답으로 인정됩니다.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
485 505
```

#### 출력

```text
495
```

$495 = 3^2 \times 5 \times 11$이고, 이는 495와 비슷한 수이므로 $495$를 출력합니다.

$492 = 2^2 \times 3 \times 41$은 $a = 2$가 홀수 소수가 아니므로 495와 비슷한 수가 아니라는 점에 주의하세요.

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1 100
```

#### 출력

```text
-1
```

$1$ 이상 $100$ 이하인 정수 중에는 495와 비슷한 수가 존재하지 않습니다. 따라서 $-1$을 출력하세요.

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
494000000000000 495000000000000
```

#### 출력

```text
494000000000001
```
