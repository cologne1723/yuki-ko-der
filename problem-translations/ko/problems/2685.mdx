## 문제

AIC 세포는 다음과 같이 행동합니다.

- 나이가 `t = 1, 2, ...`일 때, 확률 `P1/P2`로 즉시 새로운 세포 하나를 낳습니다.
- 나이가 `t + 0.5`일 때, 확률 `1 - (Q1/Q2)^t`로 즉시 죽습니다.
- 그 밖의 변화는 일어나지 않습니다.

처음에 세포 하나가 있습니다. 시간 `T + 0.9`일 때 존재하는 세포 수의 기댓값을 `998244353`로 나눈 나머지를 구하세요.

<details>
<summary>기댓값의 $\mathrm{mod}\ 998\,244\,353$ 정의</summary>

구할 기댓값은 반드시 유리수임을 증명할 수 있습니다. 또한 이 문제의 제한에서 기약분수 $\frac{P}{Q}$로 나타냈을 때 $Q$는 $998\,244\,353$으로 나누어떨어지지 않습니다.

이때 $0\leq R<998\,244\,353$이고 $P\equiv QR\pmod{998\,244\,353}$인 정수 $R$이 유일하게 존재합니다. 이 $R$을 답으로 출력하세요.

</details>

## 제약

- `0 ≤ P1 ≤ P2 < 998244353`
- `P2 ≠ 0`
- `0 ≤ Q1 ≤ Q2 < 998244353`
- `Q2 ≠ 0`
- `1 ≤ T ≤ 10^3`

## 입력

입력은 다음 형식으로 주어집니다.

```text
P1 P2 Q1 Q2 T
```

## 출력

답을 한 줄에 출력하세요.
