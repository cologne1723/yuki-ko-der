검은 칸과 흰 칸으로 이루어진 그림 $S$가 주어집니다. 빈 캔버스에 중심과 크기를 정해 X 모양을 여러 번 그려 정확히 같은 그림을 만들 수 있는지 판정하세요. X는 두 대각선 위의 모든 칸을 칠한 도형입니다.

## 조건

- $1\le H\times W\le10^6$
- 각 칸은 `#` 또는 `.`입니다.

## 입력

```text
$H$ $W$
$S_1$
\vdots
$S_H$
```

## 출력

가능하면 `Yes`, 불가능하면 `No`를 출력하세요.
