가장 오른쪽의 돌이 남은 더미를 골라 원하는 수의 돌을 제거하는 게임의 승자를 구하는 문제를 생각합니다. 길이 $N$의 $A$와 질의가 주어질 때, 종류 1은 $A_{X_i}$를 $Y_i$로 바꾸고 종류 2는 구간 $[X_i,Y_i]$를 게임의 더미로 했을 때의 승자를 출력하세요.

## 입력

```text
N Q
A_1 ... A_N
T_1 X_1 Y_1
...
T_Q X_Q Y_Q
```

## 출력

각 종류 2 질의의 승자를 출력하세요.
