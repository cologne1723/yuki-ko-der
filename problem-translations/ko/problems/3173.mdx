**가위바위보의 규칙 (클릭하여 펼칩니다)**

▶ 가위바위보의 규칙 공개

가위바위보는 바위, 가위, 보의 $3$가지 손 모양이 서로 물고 물리는 관계를 이루며, 그 강약 관계로 승패를 정하는 게임입니다.

바위, 가위, 보에는 다음과 같은 관계가 있습니다. 바위는 가위보다 강하고, 가위는 보보다 강하며, 보는 바위보다 강합니다.

가위바위보를 한 모든 사람이 같은 손을 냈거나, 바위·가위·보를 낸 사람이 각각 $1$명 이상이면 무승부입니다.

## 문제 설명

ゆきこちゃん과 こゆきちゃん이 가위바위보를 합니다. 두 사람의 가위바위보에는 다음과 같은 제약과 약속이 있습니다.

- ゆきこちゃん은 바위를 $A_1$회, 가위를 $A_2$회, 보를 $A_3$회 낼 수 있습니다.
- こゆきちゃん은 바위를 $B_1$회, 가위를 $B_2$회, 보를 $B_3$회 낼 수 있습니다.
- 바위, 가위, 보를 낸 횟수의 합은 ゆきこちゃん과 こゆきちゃん에서 같습니다. 즉, 다음을 만족합니다.

  $\displaystyle \sum_{i=1}^{3} A_i = \sum_{i=1}^{3} B_i$

$\displaystyle \sum_{i=1}^{3} A_i$회 가위바위보를 했을 때, ゆきこちゃん이 이기는 횟수로 가능한 최솟값과 최댓값을 구하세요.

무승부인 경우에도 가위바위보를 $1$회 끝낸 것으로 셉니다.

## 입력

입력은 표준 입력에서 다음 형식으로 주어집니다. 여기서 $\mathrm{case}_i\ (i = 1, 2, \cdots, T)$는 $i$번째 테스트 케이스입니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$A_1\ A_2\ A_3$
$B_1\ B_2\ B_3$
```

## 제한

- $1 \leq T \leq 10^4$
- $0 \leq A_i \leq 10^8$ ($1 \leq i \leq 3$)
- $0 \leq B_i \leq 10^8$ ($1 \leq i \leq 3$)
- $\displaystyle \sum_{i=1}^{3} A_i = \sum_{i=1}^{3} B_i$
- 입력은 모두 정수입니다.

## 출력

$T$줄을 출력하고, $i$번째 줄에는 $i$번째 테스트 케이스의 답을 출력하세요.

각 테스트 케이스에서 ゆきこちゃん이 이기는 횟수로 가능한 최솟값을 $\min$, 최댓값을 $\max$라고 할 때, 다음 형식으로 출력하세요.

```text
$\min\ \max$
```
