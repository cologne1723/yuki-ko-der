## 문제

넓이가 n인 원의 반지름을 구하세요. 단, 다음 조건이 있습니다.

* 원주율은 3으로 합니다.
* 오차는 1000000까지 허용됩니다.
* 소수와 정수는 아직 배우지 않았으므로 양의 자연수로 답하세요.

## 입력

```text
n
```

1 ≤ n ≤ 10^12이며, n은 정수입니다.

## 출력

엄밀히 말해, 넓이가 n인 원의 반지름을 원주율 3으로 계산한 실수값을 r이라 할 때, 출력 r_user가 r−10^6 ≤ r_user ≤ r+10^6을 만족하는 양의 자연수이면 정답으로 인정됩니다.

## 샘플

### 샘플 1 {file="sample1.in"}

입력:

```text
4
```

출력:

```text
1000000
```

출력 오차에는 여유가 있습니다.
