## 문제 설명

$N$개의 굿즈가 있습니다. 굿즈 $i$는 $1$개를 구매하는 데 $W_i$엔이 필요하고, $1$개 구매할 때마다 행복도가 $V_i$ 상승합니다. 판매량을 조절하기 위해 굿즈 $i$는 $1$회의 쇼핑에서 최대 $C_i$개까지만 구매할 수 있습니다.

또한, $1$회의 쇼핑에서 $X$엔을 지불할 때마다 행복도가 $Y$ 상승하는 특전 $1$개를 무료로 얻습니다. 즉, $1$회의 쇼핑에서 $x$엔을 지불하면 행복도가 추가로 $\left\lfloor \frac{x}{X}\right\rfloor\times Y$만큼 상승합니다.

굿즈를 적절히 $1$개 이상 구매했을 때, $1$회의 쇼핑에서의 $\frac{행복도의 합계}{지불한 금액}$을 최대로 얼마까지 만들 수 있는지 구하세요.

## 입력

```text
$N\ X\ Y$
$W_1\ V_1\ C_1$
$W_2\ V_2\ C_2$
$\vdots$
$W_N\ V_N\ C_N$
```

## 제한

- $1\leq N\leq 500$
- $1\leq X\leq 500$
- $0\leq Y\leq 500$
- $1\leq W_i\leq 500$
- $1\leq V_i\leq 500$
- $1\leq C_i\leq 500$
- 입력은 모두 정수입니다.

이 문제에는 서브태스크에 의한 부분점이 설정되어 있습니다.

| 서브태스크 이름 | 배점 | 제한 |
| --- | ---: | --- |
| 서브태스크 $1$ | $5$% | $N=1$ |
| 서브태스크 $2$ | $3$% | $Y=0$ |
| 서브태스크 $3$ | $2$% | $X=1$ |
| 서브태스크 $4$ | $10$% | $N\leq 20,\ C_i=1$ |
| 서브태스크 $5$ | $15$% | $N\leq 8,\ C_i\leq 5$ |
| 서브태스크 $6$ | $20$% | $N\leq 100,\ C_i=1$ |
| 서브태스크 $7$ | $30$% | 입력으로 주어지는 값은 모두 $100$ 이하 |
| 서브태스크 $8$ | $15$% | 추가 제한 없음 |

## 출력

답을 $1$줄에 출력하세요.

참값과의 절대 오차 또는 상대 오차가 $10^{-6}$ 이하이면 정답으로 판정됩니다.

## 예제

### 예제 1 {file=""}

#### 입력

```text
4 6 3
2 2 3
3 3 2
4 1 1
8 9 2
```

#### 출력

```text
1.611111111
```

굿즈 $1$을 $1$개, 굿즈 $4$를 $2$개 구매하는 경우를 생각해 봅시다. 지불하는 금액은 $18$이고, 굿즈 자체로 얻는 행복도의 합계는 $20$입니다.

특전은 $\left\lfloor\frac{18}{6}\right\rfloor=3$개 얻을 수 있으므로, 행복도가 추가로 $9$ 상승합니다.

따라서 이 경우의 값은 $\frac{29}{18}$입니다. $\frac{29}{18}$보다 큰 값을 달성할 수 없으므로, $\frac{29}{18}$이 답입니다.
