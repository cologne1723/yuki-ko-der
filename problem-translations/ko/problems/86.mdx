## 문제 설명

유키는 여행지에서 TV를 보려고 합니다.

여행지의 TV 리모컨에는 버튼이 세로 $N$행, 가로 $M$열의 직사각형으로 총 $N \times M$개 배치되어 있으며, 각 버튼을 누르면 대응하는 채널로 TV 화면이 전환됩니다. 하지만 이 지역의 TV에는 시청할 수 있는 채널과 시청할 수 없는 채널이 있습니다.

유키는 시청할 수 있는 채널을 모두 순회하고 싶지만, 여행으로 지쳐 복잡한 순서로 버튼을 누르고 싶지 않습니다. 그래서 다음 규칙에 따라 버튼을 순서대로 누르기로 했습니다.

처음에는 임의의 시청 가능한 채널 버튼을 누릅니다. 다음에는 방금 누른 버튼의 상하좌우 중 한 방향으로 인접한 버튼을 하나 선택합니다. 그 이후에는 인접한 버튼을 차례로 누르며, 다음 버튼은 직전에 이동한 방향과 같은 방향으로 이동한 곳의 버튼 또는 그 방향을 왼쪽으로 90도 회전한 곳의 버튼 중 하나를 선택합니다.

예를 들어 현재 버튼이 직전 버튼보다 한 칸 위에 있다면, 다음에는 현재 버튼에서 한 칸 더 위에 있는 버튼 또는 왼쪽 버튼을 누를 수 있습니다.

시청할 수 없는 채널의 버튼은 누르면 안 됩니다. 시청 가능한 모든 채널 버튼을 정확히 한 번씩 누른 뒤, 마지막에 처음 눌렀던 버튼을 다시 누릅니다. 단, 처음 눌렀던 버튼만 마지막에 한 번 더 눌러도 됩니다.

$N,M$과 각 버튼에 대응하는 채널의 시청 가능 여부가 주어질 때, 위 규칙을 모두 만족하는 버튼 누르기 순서가 존재하는지 판정하세요.

## 입력

```text
N M
A_1
A_2
:
A_N
```

- $1 \le N,M \le 100$
- $A_i$는 `.`과 `#`으로만 이루어진 길이 $M$의 문자열입니다.
- $A_i$의 $j$번째 문자가 `.`이면 $i$행 $j$열 버튼은 시청 가능한 채널에 대응합니다.
- `#`이면 시청할 수 없는 채널에 대응합니다.

각 테스트 케이스에는 시청 가능한 채널이 반드시 2개 이상 포함됩니다.

## 출력

규칙을 만족하는 버튼 누르기 순서가 존재하면 `YES`, 존재하지 않으면 `NO`를 출력하세요.

마지막에 줄 바꿈을 출력하세요.

## 예제

```text
3 4
....
.##.
....
```

```text
YES
```

어느 버튼에서 시작해도 시청 가능한 버튼을 반시계 방향으로 순회하면 됩니다.

```text
3 3
...
...
...
```

```text
NO
```

```text
3 3
..#
...
...
```

```text
YES
```

처음에 가운데 버튼을 누르고, 다음에 그 위 버튼을 누른 뒤 반시계 방향으로 차례로 버튼을 누르면 가운데로 돌아올 수 있습니다. 다른 버튼을 처음에 누르면 처음 버튼으로 돌아올 수 없습니다.
