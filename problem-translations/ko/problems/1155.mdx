## 문제 설명

나다 학교에서는 매년 $11$월에 소풍을 갑니다.

정수 $N$이 주어질 때, 나다 학교 $75$회생이 중학교 $N$학년일 때 소풍으로 갔던 장소를 출력하세요. 한 번의 소풍에서 한 장소에 갔다고 가정합니다(실제로는 한 번의 소풍에서 여러 장소에 갔습니다.)

## 입력

```text
$N$
```

$N$은 정수이며 $1 \leq N \leq 3$입니다.

## 출력

답을 한 줄에 출력하고 마지막에 줄바꿈을 넣으세요.

## 예제

### 예제 1 {file=""}
#### 입력
```text
1
```
#### 출력
```text
Shiitakerando
```

점심 뷔페에서 누군가 나무젓가락을 태우며 놀고 있었습니다. 위험하군요.

### 예제 2 {file=""}
#### 입력
```text
2
```
#### 출력
```text
Otsukakokusaibijutsukan
```

출제자는 이 소풍에서 처음으로 시코쿠 지방에 갔습니다.

### 예제 3 {file=""}
#### 입력
```text
3
```
#### 출력
```text
Spring-8
```

연구자가 커다란 원형 연구실 같은 곳을 자전거로 이동하는 모습이 놀라웠습니다.
