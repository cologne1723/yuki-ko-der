## 문제 설명

문자열 $s$에 대해 $|s|$를 $s$의 길이, $s[i:j]$를 $s$의 $i$번째 문자부터 $j$번째 문자까지의 부분 문자열로 정의합니다. $i > j$이면 $s[i:j]$는 빈 문자열입니다.

`a`, `b`로 이루어진 문자열의 쌍이 $N$개 주어집니다. $i$번째 쌍은 $(X_i, Y_i)$입니다.

또한 문자열 $S$가 있으며, 처음에 $S$는 `a`입니다.

이제 다음과 같이 정의되는 조작을 생각합니다.

여기서 $|X_i| < |Y_i|$라는 조건에 의해 조작이 유한 번 반복된 후 종료하는 것이 보장됩니다.

**조작:** 종료 조건을 만족할 때까지 다음을 반복합니다.

- $X_i$가 $S$의 부분 문자열인 정수 $i$가 존재하지 않거나, $|S| \ge 10^{100}$이면 조작을 즉시 종료합니다.
- 그렇지 않으면 $S[l:r]$가 $X_i$와 일치하는 정수의 $3$튜플 $(i,l,r)$을 $1$개 선택하고, $S[l:r]$를 $Y_i$로 치환합니다.
  - 더 엄밀하게는 $S$를 $S[1:l-1]$, $Y_i$, $S[r+1:|S|]$를 이 순서로 이어 붙인 문자열로 치환합니다.

조작이 끝난 뒤 $S$의 길이를 $10^{100}$ 이상으로 만들 수 있는지 판정하고, 가능하면 `Yes`, 불가능하면 `No`를 출력하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답하세요.

문자열 $t$가 문자열 $s$의 부분 문자열이라는 것은 $s$에서 연속한 일부를 추출해 만든 문자열이 $t$와 일치하는 것을 말합니다. 예를 들어 `aaa`는 `baaab`의 부분 문자열이지만, `bb`는 `baaab`의 부분 문자열이 아닙니다.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다. 여기서 $\mathrm{case}_k$는 $k$번째 테스트 케이스를 나타냅니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N$
$X_1\ Y_1$
$X_2\ Y_2$
$\vdots$
$X_N\ Y_N$
```

$1$번째 줄에 쌍의 개수 $N$이 주어집니다.

이후 $N$개의 줄에 `a`, `b`로 이루어진 문자열 $X_i$, $Y_i$가 공백으로 구분되어 주어집니다.

## 제한

- $1 \le T \le 10^4$
- $1 \le N \le 10^5$
- $1$개의 입력 파일에서 $N$의 총합은 $10^5$ 이하입니다.
- $X_i$, $Y_i$는 `a`, `b`로 이루어진 문자열입니다.
- $1 \le |X_i| < |Y_i| \le 2 \times 10^5$
- $1$개의 입력 파일에서 $\sum_{i=1}^{N}|X_i|$의 총합은 $2 \times 10^5$ 이하입니다.
- $1$개의 입력 파일에서 $\sum_{i=1}^{N}|Y_i|$의 총합은 $2 \times 10^5$ 이하입니다.

## 출력

$T$줄을 출력하고, $k$번째 줄에는 $k$번째 테스트 케이스에 대한 답을 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
5
2
a ba
ba bbba
2
a bb
bbb aaaa
1
b aaabbb
3
a bb
a ab
a aa
5
a bbbb
a bb
ba bbbbb
bbb aabb
bbbbb aaabbb
```

#### 출력

```text
Yes
No
No
Yes
Yes
```

$1$번째 테스트 케이스에서는 예를 들어 다음과 같이 조작할 수 있습니다.

- $i=1$을 선택합니다. $S$의 $1$번째 문자부터 $1$번째 문자까지의 연속 부분 문자열 `a`를 `ba`로 치환합니다.
  - $S$는 `a`에서 `ba`로 갱신됩니다.
- $i=2$를 선택합니다. $S$의 $1$번째 문자부터 $2$번째 문자까지의 연속 부분 문자열 `ba`를 `bbba`로 치환합니다.
  - $S$는 `ba`에서 `bbba`로 갱신됩니다.
- $i=2$를 선택합니다. $S$의 $3$번째 문자부터 $4$번째 문자까지의 연속 부분 문자열 `ba`를 `bbba`로 치환합니다.
  - $S$는 `bbba`에서 `bbbbba`로 갱신됩니다.

이와 같이 조작하면 $S$의 길이는 $6$이 됩니다. 실제로는 조작을 적절히 수행해 $S$의 길이를 $10^{100}$ 이상으로 만들 수 있습니다.
