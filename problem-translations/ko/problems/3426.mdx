※ 이 문제는 Mod K 그래프 증가 (쉬움)과 제약이 다른 문제입니다.

## 문제 설명

$N$개의 정점과 $M$개의 간선으로 이루어진 **단순 연결 무향 그래프** $G$가 주어집니다. $i=1,2,\dots,M$에 대해 $i$번째 간선은 정점 $u_i$와 정점 $v_i$를 연결합니다.

길이 $N$인 수열 $A=(A_1,\dots,A_N)$가 존재하며, 처음에는 모든 원소가 $0$입니다.

다음 연산을 생각합니다.

- $G$에서 $1$개의 간선을 선택하고, 그 양 끝점을 각각 $x,y$라고 합니다. $A_x$를 $(A_x+1)\mathbin{\bmod}K$로, $A_y$를 $(A_y+1)\mathbin{\bmod}K$로 바꿉니다. 여기서 $a\mathbin{\bmod}b$는 $a$를 $b$로 나눈 나머지를 뜻합니다.

연산을 $0$회 이상 수행한 뒤, 최종적으로 수열 $A$를 주어진 수열 $B$와 일치시킬 수 있는지 판정하세요.

$T$개의 테스트 케이스가 주어지므로, 각각에 대해 답을 구하세요.

## 입력

입력은 다음 형식으로 표준 입력에서 주어집니다.

```text
$T$
$\mathrm{case}_1$
$\mathrm{case}_2$
$\vdots$
$\mathrm{case}_T$
```

각 테스트 케이스는 다음 형식으로 주어집니다.

```text
$N\ M\ K$
$u_1\ v_1$
$u_2\ v_2$
$\vdots$
$u_M\ v_M$
$B_1\ B_2\ \cdots\ B_N$
```

## 제한

- $1\leq T\leq 2\times 10^5$
- $1\leq N\leq 2\times 10^5$
- $N-1\leq M\leq 2\times 10^5$
- $1\leq K\leq 10^9$
- $1\leq u_i,v_i\leq N$
- $0\leq B_i<K$
- 주어지는 그래프는 단순 그래프입니다.
- 입력은 모두 정수입니다.
- $1$개의 입력 파일에서 $N$의 합과 $M$의 합은 각각 $2\times 10^5$ 이하입니다.

## 출력

$T$개의 줄에 출력하세요.

$i$번째 줄에는 $i$번째 테스트 케이스에 대해 $A$를 $B$와 일치시킬 수 있으면 `Yes`를, 그렇지 않으면 `No`를 출력하세요.

마지막에는 개행 문자를 출력하세요.

## 예제

### 예제 1 {file=""}

#### 입력

```text
2
3 3 3
1 2
2 3
1 3
1 1 1
2 1 2
1 2
1 0
```

#### 출력

```text
Yes
No
```

$1$번째 테스트 케이스를 생각해 봅시다.

처음 상태에서 $A=(0,0,0)$입니다.

먼저 간선 $1$을 선택해 $2$회 연산을 수행하면 $A=(2,2,0)$이 됩니다.

다음으로 간선 $2$를 선택해 $2$회 연산을 수행하면 $A=(2,1,2)$가 됩니다.

마지막으로 간선 $3$을 선택해 $2$회 연산을 수행하면 $A=(1,1,1)$이 되어 $B=(1,1,1)$과 일치합니다.
