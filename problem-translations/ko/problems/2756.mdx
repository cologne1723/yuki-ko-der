## 문제

`N`칸의 보드에서 칸 `i`에는 `A_i`가 쓰여 있고, 처음 말은 1번 칸에 있습니다. 현재 칸의 수와 서로소가 아닌 수가 쓰인 칸으로만 워프할 수 있습니다.

시작 전에 원하는 칸의 수 `A_i`를 양의 정수 `m`배로 바꿀 수 있으며 비용 `m`을 냅니다. 1번 칸에서 모든 다른 칸으로 이동 가능하게 만드는 최소 비용 합을 구하세요.

## 제약

- `2 ≤ N ≤ 2×10^5`
- `1 ≤ A_i ≤ 2×10^5`

## 입력

```text
N
A_1 A_2 ... A_N
```

## 출력

최소 비용을 출력하세요.
