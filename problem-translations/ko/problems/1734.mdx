비음이 아닌 정수 수열 `A`에서 모든 원소가 0이 될 때까지 다음 작업을 반복합니다.

양수인 원소 중 가장 작은 인덱스를 `j`, 그 값을 `K`라 하고, `j` 이상인 각 `i`에 대해 `A_i >= K`이면 `A_i`에서 `K`를 뺍니다.

작업 횟수를 구하세요.

## 입력

`N`과 수열 `A`가 주어집니다.

## 출력

작업 횟수를 출력하세요.

## 예제

### 예제 1 {file="01_sample_01.txt"}

#### 입력

```text
3
3 1 4
```

#### 출력

```text
2
```

### 예제 2 {file="01_sample_02.txt"}

#### 입력

```text
1
0
```

#### 출력

```text
0
```

### 예제 3 {file="01_sample_03.txt"}

#### 입력

```text
17
1 0 54 21 87 79 79 82 12 28 41 2 53 26 22 80 19
```

#### 출력

```text
10
```
