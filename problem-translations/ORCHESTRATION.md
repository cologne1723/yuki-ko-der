# 번역 작업 배정

번역 기준과 작업 순서는 [WORKFLOW.md](WORKFLOW.md)를 따른다.
이 문서는 배정하는 주체만 읽는다. 개별 번역 담당자에게 실행 지침을 복사하지 않는다.

- 요청받은 대상과 수정 범위를 확인하고 같은 파일을 중복 배정하지 않는다.
- 사용자 지정 모델·실행 조건을 임의로 바꾸지 않는다.
- 완료 보고가 아니라 저장본과 검증 근거로 완료를 판단한다. 수정 전후 결과를 구분한다.
- 환경별 도구 호출·모델 설정·병렬 한도·재개 방법은 로컬 전용
  루트 `AGENTS.local.md`의 참고 목록에서 필요한 실행 문서만 읽는다.
  파일이 없으면 현재 환경과 사용자 요청으로 실행 조건을 확인한다. 없는 도구나 설정을 추정하지 않는다.
