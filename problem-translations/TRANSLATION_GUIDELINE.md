# 한국어 문제 번역 지침

이 지침은 일본어 원문의 문체와 관계없이 모든 한국어 문제 번역에
일관되게 적용한다.

## 문체

- 문제의 분위기를 만드는 이야기, 인물의 성격, 농담, 대화 등의 플레이버
  텍스트는 문제에 필요한 내용과 어조를 살린다.
- 플레이버 텍스트가 아닌 문제 설명, 정의, 연산, 요구 사항, 입력, 출력,
  제약, 주의 사항, 예제 설명은 간결하고 직접적으로 작성한다. 원문의 반복이나
  장황한 표현을 그대로 옮기지 않는다.
- 간결하게 작성한다는 이유로 원문의 문장이나 의미 단위를 삭제하지 않는다.
  원문에 있는 조건, 예외, 가능성, 인과 관계 및 보충 설명을 모두 보존한다.
  여러 문장을 합치거나 중복 표현을 줄일 수는 있지만, 그 과정에서 정보가
  하나라도 빠져서는 안 된다.
- 이미 작성되어 있는 번역 문장은 간결화를 이유로 삭제하지 않는다. 간결성은
  새 번역을 작성할 때의 표현 원칙으로만 적용한다. 기존 문장과 사용자가 작성한
  내용은 그대로 보존한다.
- 명백한 오타는 그대로 옮기지 않고 바로잡는다. 의도한 의미가 실제로
  불분명하면 추측하지 말고 사람이 검토할 수 있도록 표시한다.

## 용어와 어순

- 마을의 번호는 명사 앞에 쓴다. `$i$번 마을`로 쓴다.
- 구체적인 번호에도 같은 어순을 적용하여 `1번 마을`로 쓴다.

## TeX와 숫자

- 모든 TeX 수식은 `$...$`로 표기한다. 예: `$N$`, `$S_i \to T_i$`,
  `$\sum_i A_i$`. `\(...\)`와 `\[...\]`는 사용하지 않는다.
- 십진수는 오른쪽부터 세 자리마다 TeX의 얇은 공백 `\,`을 넣는다. 예:
  `$1\,000$`, `$100\,000$`, `$1\,000\,000$`. `$1000$`, `$100,000$`,
  일반 공백을 사용한 표기는 쓰지 않는다.
- 식별자, 소수, 예제 입력 및 출력에는 자릿수 구분자를 추가하지 않는다.

## 제약 조건

- 값의 제약 조건은 그 값을 소개하는 문장의 끝에 둔다. 관련된 제약 조건이
  여러 개라면 문단의 끝에 모아도 된다.
- 문장의 의미를 현저히 불명확하게 만드는 경우가 아니라면 문장 중간에
  괄호로 제약 조건을 삽입하지 않는다.
- 괄호는 TeX 안에 넣는다.
- 여러 제약 조건은 `;` 으로 구분한다.

권장:

> 마을의 수 `$N$`이 주어집니다. `$(2 \le N \le 50)$`

여러 값을 함께 소개할 때 허용되는 형식:

> 도로의 출발점 `$S_i$`와 도착점 `$T_i$`가 주어집니다. `($1 \le S_i < T_i \le N; S_i \ne T_i)$`

피해야 하는 형식:

> 마을의 수 `$N$ ($2 \le N \le 50$)`이 주어집니다.
